# Теоретические основы

## Определения

- **DevOps** — методология и культурная философия, направленная на сокращение времени поставки ценности (Time-To-Market) через автоматизацию, сотрудничество и непрерывное улучшение.
  - См. подробнее: **[Обзор DevOps](../Concepts/devops_overview.md)**

- **SRE (Site Reliability Engineering)** — инженерный подход к эксплуатации, применяющий методы разработки ПО для создания высоконадежных и масштабируемых систем.
  - См. подробнее: **[Концепции SRE](../Concepts/sre_concepts_main.md)**

## Базовые концепции

### Три пути DevOps

Основополагающие принципы ускорения потока поставки:

1. **Поток (Flow)** — минимизация времени цикла от идеи до реализации.
2. **Обратная связь (Feedback)** — создание быстрых циклов получения информации о качестве работы.
3. **Непрерывное обучение (Continuous Learning)** — культура экспериментов и обмена опытом.

### Метрики надежности SRE

Инструменты управления стабильностью сервисов:

- **SLI (Service Level Indicator)** — измеряемый показатель качества (например, доля успешных запросов).
- **SLO (Service Level Objective)** — целевое значение для SLI (например, 99.9%).
- **SLA (Service Level Agreement)** — внешние обязательства перед клиентами с финансовой ответственностью.
- **Бюджет ошибок (Error Budget)** — запас допустимых сбоев для проведения экспериментов и релизов.

Детальный разбор: **[Концепции SRE: SLA, SLO, SLI](../Concepts/sre_concepts_main.md)**.

## Практические сценарии

### Сравнение DevOps и SRE

Методологии дополняют друг друга, решая задачи с разных сторон:

| Аспект | DevOps | SRE |
| :--- | :--- | :--- |
| **Основной фокус** | Скорость и гибкость (Time-to-Market) | Надежность и стабильность (SLO) |
| **Подход** | Культурная трансформация | Прикладная инженерия |
| **Ключевые метрики** | TTM, частота деплоев | SLI, SLO, Бюджет ошибок |
| **Работа с отказами** | Быстрое восстановление (MTTR) | Управление рисками и причинами |

Подробная сравнительная таблица: **[Сценарии: DevOps vs SRE](../Concepts/devops_overview.md#сравнение-devops-и-sre)**.
