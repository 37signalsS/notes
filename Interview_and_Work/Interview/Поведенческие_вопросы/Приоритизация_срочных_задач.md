# 2.2. Случился пожар: есть две срочные задачи. Как выбирать?

### Определения

* **Тип вопроса:** Проверка способности к приоритизации, принятию решений в стрессовой ситуации и коммуникации.

### Основные концепции

* **Цель:** Продемонстрировать четкий алгоритм действий, где приоритет отдается оценке, эскалации и коммуникации.

### Практические сценарии

**Алгоритм действий:**

1. **Оценка:** Понять, какая из задач критичнее для бизнеса.
2. **Эскалация:** Если право принятия решения не ваше, немедленно сообщить тимлиду или менеджеру.
3. **Принятие решения (если нет выбора):** Если руководство недоступно, выбрать задачу, которую можно решить быстрее, чтобы закрыть хотя бы один "пожар".
4. **Коммуникация:** Обязательно уведомить всех заинтересованных лиц:
    * Тому, чью задачу взяли: "Я взял твою задачу, вернусь с результатом через X времени".
    * Тому, чью задачу отложили: "Прости, у нас пожар. Я сейчас решаю другую задачу, но вернусь к твоей через X времени".
