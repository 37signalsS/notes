# HTTP API Prometheus

## Определения

**HTTP API Prometheus** — набор стабильных HTTP-эндпоинтов, позволяющих внешним системам выполнять [PromQL](./concepts/promql/functions.md)-запросы, получать метаданные о временных рядах, проверять статус сервера и выполнять административные задачи.

| Параметр | Значение |
|---|---|
| **Базовый путь** | `/api/v1/` (стабильная версия) |
| **Методы запроса** | `GET`, `POST` (`Content-Type: application/x-www-form-urlencoded`) |
| **Формат ответа** | JSON |
| **Спецификация** | OpenAPI 3.2 (доступна по пути `/api/v1/openapi.yaml`) |

> **См. также:** [Обзор Prometheus](./overview.md), [PromQL](./concepts/promql/functions.md), [Графики Grafana](../Grafana/grafana_overview.md)

## Основные концепции

### Коды состояния ответов

| Код | Значение | Описание |
|---|---|---|
| `2xx` | Success | Запрос успешно обработан |
| `400` | Bad Request | Ошибка в параметрах запроса |
| `422` | Unprocessable Entity | Синтаксически верный запрос, который невозможно выполнить (например, ошибка в PromQL) |
| `503` | Service Unavailable | Временная ошибка (таймаут выполнения, перегрузка сервера) |

### Типы данных в ответах

Поле `resultType` в JSON-ответе определяет структуру данных:

| `resultType` | Описание | Типичный запрос |
|---|---|---|
| `vector` | Вектор мгновенных значений (Instant vector) | Мгновенный запрос (`/query`) |
| `matrix` | Матрица данных (Range vector) | Запрос за период (`/query_range`) |
| `scalar` | Одиночное числовое значение | Результат скалярного вычисления |
| `string` | Строковое значение | Редкий случай, используется в некоторых специальных функциях |

### Форматы времени

API поддерживает два формата для параметров времени (`time`, `start`, `end`):

- **Unix timestamp:** целое число или число с плавающей точкой (например, `1671278400.123`).
- **RFC3339:** строка (например, `2025-12-17T12:00:00Z`).

## Практические сценарии

### Выполнение мгновенных запросов — `/query`

Используется для получения текущего значения метрик или вычисления выражения в конкретный момент времени.

| Параметр | Обязательный | Описание |
|---|---|---|
| `query` | Да | Выражение на языке PromQL |
| `time` | Нет | Момент времени для вычисления (по умолчанию — время сервера) |

**Пример запроса:**

```bash
curl 'http://localhost:9090/api/v1/query?query=up'
```

### Запросы данных за период — `/query_range`

Используется для построения графиков и анализа динамики метрик.

| Параметр | Обязательный | Описание |
|---|---|---|
| `query` | Да | Выражение на языке PromQL |
| `start` | Да | Начало временного диапазона |
| `end` | Да | Конец временного диапазона |
| `step` | Да | Шаг вычислений (например, `15s`, `1m`, `1h`) |

**Пример запроса:**

```bash
curl 'http://localhost:9090/api/v1/query_range' \
  --data-urlencode 'query=rate(node_cpu_seconds_total{mode="user"}[5m])' \
  --data-urlencode 'start=2025-12-17T09:30:00Z' \
  --data-urlencode 'end=2025-12-17T10:00:00Z' \
  --data-urlencode 'step=1m'
```

### Поиск и метаданные

| Эндпоинт | Описание | Пример |
|---|---|---|
| `/api/v1/series` | Поиск временных рядов по селекторам | `curl -d 'match[]={job="node"}' /api/v1/series` |
| `/api/v1/labels` | Список всех имен меток | `curl /api/v1/labels` |
| `/api/v1/label/<name>/values` | Все значения для конкретной метки | `curl /api/v1/label/instance/values` |
| `/api/v1/metadata` | Информация о метриках (тип, описание, help) | `curl /api/v1/metadata` |

## Дополнительная информация

### Статус и состояние сервера

Данные эндпоинты полезны для отладки и мониторинга самого Prometheus:

| Эндпоинт | Описание |
|---|---|
| `/api/v1/targets` | Список всех настроенных целей сбора и их состояние |
| `/api/v1/rules` | Список загруженных [правил](./rules.md) (Recording и Alerting) |
| `/api/v1/alerts` | Список активных оповещений в данный момент |
| `/api/v1/status/config` | Текущая конфигурация сервера в формате YAML |
| `/api/v1/status/tsdb` | Статистика по базе данных [TSDB](./concepts/tsdb.md) (кардинальность, топ меток) |

### Административные операции

Для использования данных эндпоинтов Prometheus должен быть запущен с флагом `--web.enable-admin-api`.

| Эндпоинт | Метод | Описание |
|---|---|---|
| `/api/v1/admin/tsdb/snapshot` | `POST` | Создание снимка (snapshot) текущих данных TSDB |
| `/api/v1/admin/tsdb/delete_series` | `POST` | Удаление временных рядов по селектору |
| `/-/healthy` | `GET` | Проверка работоспособности (Health check) |
| `/-/ready` | `GET` | Проверка готовности к обработке запросов (Readiness check) |

> **Внимание:** Административное API предоставляет доступ к критическим функциям. Обеспечьте надлежащую защиту сетевого доступа или используйте [механизмы аутентификации](./security.md).
