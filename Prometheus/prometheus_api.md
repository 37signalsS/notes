# HTTP API Prometheus

## Определения

**HTTP API Prometheus** — набор стабильных HTTP-эндпоинтов, позволяющих внешним системам выполнять [PromQL](./concepts/promql/functions.md)-запросы, получать метаданные о временных рядах, проверять статус сервера и выполнять административные задачи.

На 2026 год актуальной является версия **Prometheus v3.x**, которая расширяет API поддержкой OpenTelemetry (OTLP), нативных гистограмм и полной поддержкой UTF-8 для имен метрик и меток.

| Параметр | Значение |
|---|---|
| **Базовый путь** | `/api/v1/` (стабильная версия) |
| **Методы запроса** | `GET`, `POST` (`Content-Type: application/x-www-form-urlencoded`) |
| **Формат ответа** | JSON |
| **Спецификация** | OpenAPI 3.2 (доступна по пути `/api/v1/openapi.yaml`) |

> **См. также:** [Обзор Prometheus](./overview.md), [PromQL](./concepts/promql/functions.md), [Графики Grafana](../Grafana/grafana_overview.md)

## Основные концепции

### Коды состояния ответов

| Код | Значение | Описание |
|---|---|---|
| `2xx` | Success | Запрос успешно обработан |
| `400` | Bad Request | Ошибка в параметрах запроса |
| `422` | Unprocessable Entity | Синтаксически верный запрос, который невозможно выполнить (например, ошибка в PromQL) |
| `503` | Service Unavailable | Временная ошибка (таймаут выполнения, перегрузка сервера) |

### Типы данных в ответах

Поле `resultType` в JSON-ответе определяет структуру данных:

| `resultType` | Описание | Типичный запрос |
|---|---|---|
| `vector` | Вектор мгновенных значений (Instant vector) | Мгновенный запрос (`/query`) |
| `matrix` | Матрица данных (Range vector) | Запрос за период (`/query_range`) |
| `scalar` | Одиночное числовое значение | Результат скалярного вычисления |
| `string` | Строковое значение | Редкий случай, используется в специальных функциях |

**Нативные гистограммы (Native Histograms):** Начиная с версии 3.0, эндпоинты запросов возвращают высокоточные распределения в одном временном ряду, если включена соответствующая функция.

### Форматы времени и UTF-8

- **Форматы времени:** Unix timestamp (секунды.миллисекунды) или RFC3339.
- **UTF-8:** Prometheus 3.0+ поддерживает любые символы UTF-8 в именах метрик и меток без необходимости экранирования (важно для совместимости с OpenTelemetry).

## Практические сценарии

### Выполнение мгновенных запросов — `/query`

Используется для получения текущего значения метрик или вычисления выражения в конкретный момент времени.

| Параметр | Обязательный | Описание |
|---|---|---|
| `query` | Да | Выражение на языке PromQL |
| `time` | Нет | Момент времени для вычисления (по умолчанию — время сервера) |

**Пример запроса:**

```bash
curl 'http://localhost:9090/api/v1/query?query=up'
```

### Запросы данных за период — `/query_range`

Используется для построения графиков и анализа динамики метрик.

| Параметр | Обязательный | Описание |
|---|---|---|
| `query` | Да | Выражение на языке PromQL |
| `start` | Да | Начало временного диапазона |
| `end` | Да | Конец временного диапазона |
| `step` | Да | Шаг вычислений (например, `15s`, `1m`, `1h`) |

**Пример запроса:**

```bash
curl 'http://localhost:9090/api/v1/query_range' \
  --data-urlencode 'query=rate(node_cpu_seconds_total{mode="user"}[5m])' \
  --data-urlencode 'start=2026-07-29T09:30:00Z' \
  --data-urlencode 'end=2026-07-29T10:00:00Z' \
  --data-urlencode 'step=1m'
```

### Поиск метаданных и лимиты

В современных версиях для предотвращения перегрузки рекомендуется использовать параметр `limit`.

| Эндпоинт | Описание | Пример (с лимитом) |
|---|---|---|
| `/api/v1/series` | Поиск временных рядов по селекторам | `curl -G '/api/v1/series' --data-urlencode 'match[]={job="node"}' -d 'limit=1000'` |
| `/api/v1/labels` | Список всех имен меток | `curl '/api/v1/labels?limit=500'` |
| `/api/v1/label/<name>/values` | Все значения для конкретной метки | `curl '/api/v1/label/instance/values?limit=100'` |
| `/api/v1/metadata` | Информация о метриках (тип, описание, help) | `curl '/api/v1/metadata?limit=100'` |

## Дополнительная информация

### Статус и возможности сервера

| Эндпоинт | Описание |
|---|---|
| `/api/v1/features` | Список включенных функций сервера (Native Histograms, Remote Write 2.0 и др.) |
| `/api/v1/targets` | Список всех целей сбора и их состояние |
| `/api/v1/rules` | Список загруженных [правил](./rules.md). С v3.13 используется SHA-256 для пагинации. |
| `/api/v1/status/tsdb` | Статистика по [TSDB](./concepts/tsdb.md). Имеет лимит в 10,000 записей. |
| `/api/v1/status/config` | Текущая конфигурация сервера в формате YAML |

### Интеграция с OpenTelemetry (OTLP)

Prometheus 3.0+ может принимать метрики напрямую по протоколу OTLP без использования коллектора.

- **Эндпоинт приема:** `/api/v1/otlp/v1/metrics`
- **Протокол:** Protobuf через HTTP
- **Совместимость:** Полная поддержка семантических конвенций OTel благодаря UTF-8.

### Удаленная запись (Remote Write 2.0)

Новый стандарт передачи данных между серверами.

- **Возможности:** Передача метаданных, экземпляров (exemplars) и временных меток создания (created timestamps).
- **Оптимизация:** Объем трафика снижен на ~60% по сравнению с v1 благодаря интернированию строк.

### Административные операции

Требуют запуска с флагом `--web.enable-admin-api`.

| Эндпоинт | Метод | Описание |
|---|---|---|
| `/api/v1/admin/tsdb/snapshot` | `POST` | Создание снимка (snapshot) текущих данных TSDB |
| `/api/v1/admin/tsdb/delete_series` | `POST` | Удаление временных рядов по селектору |
| `/-/healthy` | `GET` | Health check |
| `/-/ready` | `GET` | Readiness check |

> **Внимание:** Административное API предоставляет доступ к критическим функциям. Обеспечьте надлежащую защиту или используйте [механизмы аутентификации](./security.md).
