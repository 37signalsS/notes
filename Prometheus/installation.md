# Установка Prometheus

Существует несколько способов установки Prometheus и его компонентов, выбор которого зависит от вашей операционной системы, инфраструктуры и предпочтений в управлении пакетами.

В этом разделе собраны руководства для различных методов установки.

## Методы установки

### 1. Ручная установка (из бинарных файлов)
Этот метод является универсальным для любой Linux-системы. Он включает в себя загрузку официальных бинарных файлов, создание пользователей и настройку `systemd` сервисов для управления Prometheus и его экспортерами.

**→ [Подробное руководство по ручной установке](./manual_installation.md)**

### 2. Установка с помощью Docker и Docker Compose
Развертывание всего стека мониторинга (Prometheus, Grafana, Alertmanager, экспортеры) в виде контейнеров. Этот подход обеспечивает изоляцию и простоту управления зависимостями.

**→ [Подробное руководство по установке в Docker](./prometheus_docker_setup_guide.md)**

### 3. Установка через менеджер пакетов (Debian/Ubuntu)
Простой способ установки с использованием системного менеджера пакетов `apt`. Подходит для быстрого развертывания на серверах под управлением Debian или Ubuntu.

**→ [Подробное руководство по установке через APT](./prometheus_setup_guide.md)**

### 4. Установка в Kubernetes
Для Kubernetes рекомендуется использовать Helm-чарт `kube-prometheus-stack`, который разворачивает не только Prometheus, но и всю необходимую экосистему (Grafana, Alertmanager, Prometheus Operator) для полноценного мониторинга кластера.

**→ [Обзор установки в Kubernetes](./kubernetes/overview.md)**
