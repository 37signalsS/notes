# Blackbox Exporter vs Сторонние SaaS-сервисы мониторинга

## Определения

**Blackbox Exporter** — бесплатный open-source инструмент Prometheus для внешнего (blackbox) мониторинга доступности и производительности сервисов по протоколам HTTP, TCP, ICMP, DNS, gRPC и Unix. Развёртывается и управляется самостоятельно.

**SaaS-мониторинг (Software as a Service)** — облачные сервисы для синтетического мониторинга, предоставляющие готовую инфраструктуру проверок из различных географических точек без необходимости развертывания собственных экспортеров.

*   **Synthetic Monitoring SaaS** — облачные сервисы для синтетических проверок доступности и производительности (Checkly, UptimeRobot, Pingdom, StatusCake).
*   **Observability SaaS** — платформы, объединяющие метрики, логи и трассировки (Datadog, New Relic, Dynatrace).
*   **SLA-гарантия** — обязательства провайдера по времени доступности сервиса мониторинга.
*   **Data Residency** — требования к географическому расположению данных мониторинга.

## Основные концепции

### Сравнительная таблица

| Критерий | Blackbox Exporter | Checkly | UptimeRobot | Pingdom | Datadog Synthetics |
|:---|:---|:---|:---|:---|:---|
| **Лицензия** | Apache 2.0 (бесплатно) | Платный (от $20/мес) | Freemium (от $8/мес) | Платный (от $15/мес) | Платный (от $5/орк) |
| **Self-hosted** | Да | Нет | Нет | Нет | Нет |
| **Протоколы** | HTTP, TCP, ICMP, DNS, gRPC, Unix | HTTP, TCP, DNS, gRPC | HTTP, TCP, DNS | HTTP, TCP | HTTP, TCP, DNS |
| **Гео-распределение** | Свои инстансы | 20+ регионов | 10+ регионов | 100+ регионов | 15+ регионов |
| **API-мониторинг** | Базовый (методы, статус-коды) | Расширенный (SOAP, GraphQL) | Базовый | Базовый | Расширенный |
| **Браузерный мониторинг** | Нет | Да (Playwright) | Нет | Да (Pingdom) | Да (RUM + Synthetics) |
| **Интеграция с Prometheus** | Нативная | Экспорт метрик | Нет | Нет | DogStatsD |
| **Кастомные модули** | Да (blackbox.yml) | Да (scripts) | Ограниченно | Ограниченно | Ограниченно |
| **Настройка алертов** | Через Prometheus/Alertmanager | Встроенные + интеграции | Встроенные | Встроенные | Встроенные |
| **Стоимость при 100 targets** | $0 (инфраструктура) | ~$80/мес | ~$40/мес | ~$75/мес | ~$500/мес |

### Когда выбирать Blackbox Exporter

**Оптимальные сценарии:**
- Уже используете Prometheus/Grafana в стеке мониторинга
- Требуется полный контроль над данными и конфигурацией
- Необходим мониторинг внутренних сервисов (внутри корпоративной сети)
- Нужны нестандартные протоколы (gRPC, Unix sockets, ICMP)
- Ограничения по бюджету или политике безопасности (no-cloud)
- Требуется интеграция с существующими recording rules и SLO-системой

**Ограничения:**
- Географическое покрытие зависит от расположения ваших инстансов
- Нет браузерного мониторинга (JavaScript, рендеринг страниц)
- Требует ручного развертывания и поддержки инфраструктуры
- Нет встроенной исторической аналитики (всё через Prometheus TSDB)

### Когда выбирать SaaS-решение

**Оптимальные сценарии:**
- Нужно глобальное географическое покрытие (проверки из 10+ точек мира)
- Требуется браузерный мониторинг (Core Web Vitals, JS-ошибки)
- Малая команда без возможности поддерживать собственную инфраструктуру мониторинга
- Нужен быстрый старт без настройки Prometheus/Alertmanager
- Внешние API-сервисы с глобальной аудиторией

**Ограничения:**
- Постоянные лицензионные расходы
- Зависимость от стороннего провайдера
- Ограничения по кастомизации (особенно у бюджетных тарифов)
- Данные мониторинга покидают инфраструктуру (potential compliance issue)

### Гибридный подход

Наиболее распространённая стратегия в продакшене — комбинация:

```
┌─────────────────────────────────────────────────────────────────┐
│                    Гибридный мониторинг                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Внутренние сервисы:              Внешние сервисы:             │
│  ┌─────────────────────┐         ┌─────────────────────┐       │
│  │ Blackbox Exporter   │         │ SaaS (Checkly/      │       │
│  │ (внутренняя сеть)   │         │  Pingdom)           │       │
│  │ • HTTP/TCP/DNS      │         │ • Глобальное покрытие│       │
│  │ • gRPC/Unix sockets │         │ • Браузерный тест   │       │
│  │ • Внутренние API    │         │ • Внешний SLA       │       │
│  └─────────┬───────────┘         └─────────┬───────────┘       │
│            │                               │                   │
│            └───────────┬───────────────────┘                   │
│                        │                                       │
│              ┌─────────▼─────────┐                             │
│              │    Prometheus     │                             │
│              │    + Grafana      │                             │
│              │    + Alertmanager │                             │
│              └───────────────────┘                             │
└─────────────────────────────────────────────────────────────────┘
```

**Пример конфигурации:**

```yaml
# Blackbox Exporter — внутренние проверки
scrape_configs:
  - job_name: 'blackbox-internal'
    metrics_path: /probe
    params:
      module: [http_2xx, tcp_connect, grpc_health]
    static_configs:
      - targets:
        - http://api.internal.example.com/health
        - postgres.internal.example.com:5432
        - grpc.internal.example.com:8443
    relabel_configs:
      - source_labels: [__address__]
        target_label: __param_target
      - target_label: __address__
        replacement: blackbox.internal:9115

# Внешние проверки через SaaS (метрики импортируются через Exporter)
# Или: Blackbox Exporter из DMZ для внешних проверок
- job_name: 'blackbox-external'
  metrics_path: /probe
  params:
    module: [http_2xx]
  static_configs:
    - targets:
      - https://www.example.com
      - https://api.example.com
  relabel_configs:
    - source_labels: [__address__]
      target_label: __param_target
    - target_label: __address__
      replacement: blackbox-dmz.example.com:9115
```

### Миграция между решениями

| Этап | Blackbox → SaaS | SaaS → Blackbox |
|:---|:---|:---|
| **1. Пилот** | Настройте SaaS параллельно с Blackbox на 10% targets | Разверните Blackbox Exporter, настройте базовые модули |
| **2. Валидация** | Сравните результаты проверок (доступность, латентность) | Сравните метрики с SaaS в течение 2 недель |
| **3. Миграция** | Переключайте targets по groups (dev → staging → prod) | Настройте Alertmanager для новых алертов |
| **4. Очистка** | Удалите Blackbox инстансы после стабилизации | Отключите SaaS подписку |

## Практические сценарии

### Сценарий 1: Корпоративная инфраструктура (внутренние сервисы)

**Рекомендация:** Blackbox Exporter

Причины:
- Все сервисы доступны из внутренней сети
- Нет необходимости в гео-распределении
- Требуется мониторинг gRPC и внутренних TCP-сервисов
- Ограничения по выводу данных за пределы сети

### Сценарий 2: Глобальный интернет-сервис

**Рекомендация:** SaaS + Blackbox (гибрид)

Причины:
- Важна доступность из разных регионов мира
- Нужен браузерный мониторинг (Core Web Vitals)
- Внутренние микросервисы мониторятся через Blackbox
- Внешний SLA подтверждается независимым SaaS-мониторингом

### Сценарий 3: Малая команда (1–3 инженера)

**Рекомендация:** SaaS (Checkly или UptimeRobot)

Причины:
- Нет ресурсов на поддержку собственной инфраструктуры мониторинга
- Быстрый старт без настройки Prometheus
- Готовые интеграции с Slack, PagerDuty, email

### Сценарий 4: FinOps / Бюджетные ограничения

**Рекомендация:** Blackbox Exporter

Причины:
- $0 за лицензии
- Стоимость только инфраструктуры (VM/контейнеры)
- Экономия при большом количестве targets (>100)

## Дополнительная информация

### Альтернативы Blackbox Exporter (open-source)

| Инструмент | Особенности | Сравнение с Blackbox |
|:---|:---|:---|
| **Grafana Cloud k6** | Браузерный мониторинг + API | Больше функций, но SaaS |
| **Prometheus + Blackbox** | Стандарт Prometheus-экосистемы | Базовый, но расширяемый |
| **Uptime Kuma** | Self-hosted, красивый UI | Проще, но без интеграции с Prometheus |
| **Netdata Cloud** | Real-time + cloud checks | Другая архитектура |
