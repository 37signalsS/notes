# cAdvisor (Container Advisor)

Предоставляет метрики о запущенных контейнерах. Он позволяет отслеживать потребление ресурсов (CPU, память, сеть, I/O) для каждого контейнера. `cAdvisor` является неотъемлемой частью мониторинга в средах [Docker](../../Docker/docker_overview.md) и [Kubernetes](../../Kubernetes/kubernetes_overview.md). Подробнее об интеграции можно почитать в заметке [Интеграция Docker и Prometheus](../../Docker/Docker_metrics/docker_prometheus_integration.md).
