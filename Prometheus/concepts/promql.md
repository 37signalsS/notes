# Основы языка запросов PromQL

**PromQL (Prometheus Query Language)** — это мощный и выразительный язык запросов, разработанный специально для работы с многомерными данными временных рядов. В отличие от SQL, он оптимизирован для вычислений и агрегаций над временными рядами.

## 1. Селекторы (Selectors)

Селекторы используются для выбора временных рядов.

### Вектор мгновенных значений (Instant Vector)

Возвращает по одному сэмплу (последнему) для каждого временного ряда, соответствующего селектору. Это самый распространенный тип запроса.

`node_memory_mem_available_bytes{job="node-exporter"}`

### Вектор диапазона значений (Range Vector)

Возвращает диапазон сэмплов за определённый промежуток времени для каждого временного ряда. Диапазон указывается в квадратных скобках `[]`.

`node_network_receive_bytes_total[5m]`

*Единицы времени: `s` (секунды), `m` (минуты), `h` (часы), `d` (дни), `w` (недели), `y` (годы).*

Векторы диапазона нельзя напрямую отобразить на графике. Они используются в качестве аргументов для функций, таких как `rate()` или `increase()`.

### Матчеры (Matchers)

Внутри селекторов (`{...}`) используются матчеры для фильтрации по лейблам:
*   `=`: Точное равенство.
*   `!=`: Неравенство.
*   `=~`: Соответствие регулярному выражению.
*   `!~`: Несоответствие регулярному выражению.

Пример: `http_requests_total{job=~"api-server|web-server", method!="GET"}`

## 2. Операторы агрегации

Операторы позволяют агрегировать данные по нескольким временным рядам.

`sum(http_requests_total)`

Ключевые операторы:
*   `sum()`: сумма значений.
*   `avg()`: среднее значение.
*   `count()`: количество временных рядов.
*   `min()`, `max()`: минимальное и максимальное значения.
*   `topk(k, <expression>)`: `k` наибольших значений.
*   `bottomk(k, <expression>)`: `k` наименьших значений.

### Группировка (`by` и `without`)

Для сохранения определённых лейблов при агрегации используются операторы `by` и `without`.
*   `by (label1, label2, ...)`: Агрегировать, группируя по указанным лейблам.
*   `without (label1, label2, ...)`: Агрегировать, удаляя указанные лейблы.

Пример: `sum by (path) (http_requests_total)` — посчитает сумму запросов для каждого `path`.

## 3. Функции

PromQL имеет богатый набор функций для работы с данными.

### Функции для счётчиков (Counters)

*   `rate(v range-vector)`: Вычисляет **среднюю скорость** увеличения значения в секунду за указанный диапазон. Идеально подходит для счётчиков.
    `rate(node_network_receive_bytes_total[5m])` — средняя скорость получения данных в байтах/сек за последние 5 минут.

*   `irate(v range-vector)`: Вычисляет **мгновенную скорость** увеличения, используя только две последние точки данных в диапазоне. `irate` более чувствителен к резким скачкам и полезен для отображения пиковых нагрузок, которые `rate` может сгладить за счет усреднения.
    `irate(node_network_receive_bytes_total[1m])`

*   `increase(v range-vector)`: Вычисляет общее увеличение значения за указанный диапазон.
    `increase(http_requests_total[1h])` — сколько всего запросов пришло за последний час.

### Функции для гистограмм

*   `histogram_quantile(φ float, b histogram)`: Вычисляет φ-квантиль (0 ≤ φ ≤ 1) из гистограммы. Это основной способ использования гистограмм.
    `histogram_quantile(0.95, sum(rate(http_request_duration_seconds_bucket[5m])) by (le))` — вычисляет 95-й перцентиль времени ответа.

### Функции сглаживания

*   `avg_over_time(v range-vector)`: Вычисляет среднее значение для каждого временного ряда за указанный диапазон. Используется для сглаживания графиков и получения "скользящего среднего" (moving average).
    `avg_over_time(node_load1[5m])` — покажет сглаженную среднюю нагрузку за последние 5 минут.

### Функции предсказания

*   `predict_linear(v range-vector, t scalar)`: Предсказывает значение временного ряда через `t` секунд в будущем, основываясь на линейной регрессии по данным из `range-vector`. Очень полезна для алертинга, например, о скором окончании места на диске.
    `predict_linear(node_filesystem_free_bytes[1h], 3600 * 4) < 0` — вернет ряды, для которых прогнозируется окончание места на диске в ближайшие 4 часа.

### Модификатор `offset`

Позволяет получить данные из прошлого.
`sum(http_requests_total) offset 1d` — вернет значение суммы запросов, которое было сутки назад.
