# Язык запросов PromQL

**PromQL (Prometheus Query Language)** — это мощный и выразительный **функциональный язык запросов**, разработанный специально для работы с многомерными данными временных рядов в [Prometheus](../overview.md). В отличие от SQL, он оптимизирован для вычислений и агрегаций над временными рядами. PromQL позволяет пользователю выбирать и агрегировать данные временных рядов в режиме реального времени. Результаты могут быть отображены в виде графика в [[../Grafana/grafana_overview.md|Grafana]], в виде табличных данных или использованы внешними системами через [[../prometheus_api.md|HTTP API]]. Другие системы, такие как [Loki](../../Loki/loki_overview.md) и [VictoriaMetrics](../../VictoriaMetrics/overview.md), используют похожие по синтаксису языки запросов (LogQL и MetricsQL соответственно).

## 1. Определения и Типы данных

PromQL оперирует несколькими основными типами данных.

*   **Instant vector (вектор мгновенных значений)** – вектор содержит в себе все значения метрики по запрашиваемой метке времени. Это самый распространенный тип результата.
*   **Range vectors (вектор диапазона значений)** – возвращает все значения для каждого временного ряда за указанный период времени. Это позволяет увидеть изменение метрики во времени.
*   **Scalar (скаляр)** – простое числовое значение с плавающей точкой.

## 2. Базовые концепции: Селекторы и Операторы

### Селекторы (Selectors)

Селекторы используются для выбора временных рядов на основе имени метрики и пар `ключ=значение` — [[labels_and_cardinality.md|лейблов]].

#### Вектор мгновенных значений (Instant Vector)

Содержит по одному сэмплу (последнему) для каждого временного ряда, соответствующего селектору.

`node_memory_mem_available_bytes{job="node-exporter"}`

#### Вектор диапазона значений (Range Vector)

Возвращает набор сэмплов за определённый промежуток времени для каждого временного ряда. Диапазон указывается в квадратных скобках `[]`.

`node_network_receive_bytes_total[5m]`

*Единицы времени: `s` (секунды), `m` (минуты), `h` (часы), `d` (дни), `w` (недели), `y` (годы).*

Векторы диапазона нельзя напрямую отобразить на графике. Они используются в качестве аргументов для функций, таких как `rate()` или `increase()`.

#### Модификатор `offset`

Позволяет получить данные из прошлого, сдвигая точку отсчета запроса назад во времени.
`sum(http_requests_total) offset 1d` — вернет значение суммы запросов, которое было сутки назад.

#### Матчеры (Matchers)

Внутри селекторов (`{...}`) используются матчеры для фильтрации по [[labels_and_cardinality.md|лейблам]]:

*   `=`: Точное равенство.
*   `!=`: Неравенство.
*   `=~`: Соответствие регулярному выражению.
*   `!~`: Несоответствие регулярному выражению.

Пример: `http_requests_total{job=~"api-server|web-server", method!="GET"}`

### Операторы

#### Математические операторы

*   `+` (сложение), `-` (вычитание), `*` (умножение), `/` (деление), `%` (остаток от деления), `^` (возведение в степень).
*   Применяются к `instant vector` и `scalar`.
    *   Пример: `2 ^ 10` вернет `1024`.

#### Операторы сравнения

*   `==` (равно), `!=` (не равно), `>` (больше), `<` (меньше), `>=` (больше или равно), `<=` (меньше или равно).
*   Применяются к `instant vector` и `scalar`. Оператор применяется к каждому значению в векторе, и все элементы, для которых условие не выполняется, исключаются из результата.
*   При добавлении модификатора `bool` результирующий вектор будет содержать `1` для удовлетворяющих условию элементов и `0` для неудовлетворяющих.
    `node_cpu_seconds_total > bool 3`
*   **Пример:** Чтобы лучше понять логику, выполните последовательно запросы и сравните результаты:

    ```promql
    node_cpu_seconds_total
    node_cpu_seconds_total > 3
    node_cpu_seconds_total > bool 3
    ```

#### Логические операторы (только для `instant vector`)

*   `and` (логическое И): результат — элементы `vector1`, для которых в `vector2` есть элементы с точно таким же набором меток.
*   `or` (логическое ИЛИ): результат — все элементы `vector1` плюс элементы `vector2`, которых нет в `vector1`.
*   `unless` (исключающее ИЛИ): результат — элементы `vector1`, для которых нет совпадающих элементов в `vector2`.
*   **Пример:** Чтобы понять логику сопоставления векторов, выполните:

    ```promql
    node_load1 and node_cpu_seconds_total
    node_load1 or node_cpu_seconds_total
    node_load1 unless node_cpu_seconds_total
    ```

#### Приоритет операторов

1. `^`
2. `*`, `/`, `%`
3. `+`, `-`
4. `==`, `!=`, `<=`, `<`, `>=`, `>`
5. `and`, `unless`
6. `or`

## 3. Практические сценарии: Агрегация и Функции

### Операторы агрегации

Операторы позволяют агрегировать данные по нескольким временным рядам. Они могут использоваться с модификаторами `by` (группировать по указанным лейблам) и `without` (группировать по всем лейблам, кроме указанных).

*   `sum()`: сумма значений.
*   `avg()`: среднее значение.
*   `count()`: количество временных рядов.
*   `min()`, `max()`: минимальное и максимальное значения.
*   `stddev()`, `stdvar()`: стандартное отклонение и дисперсия.
*   `topk(k, <expression>)`: `k` наибольших значений.
*   `bottomk(k, <expression>)`: `k` наименьших значений.
*   `count_values("label", ...)`: количество элементов с одинаковым значением.

Пример: `sum by (path) (http_requests_total)` — посчитает сумму запросов для каждого `path`.

### Функции

PromQL предоставляет большой набор функций для работы с данными. Их можно условно разделить на группы в зависимости от типа метрик, с которыми они работают.

> Подробнее о типах метрик см. в заметке **[[../../Concepts/Observability_and_Monitoring/observability_overview.md#2-метрики-metrics|Типы метрик в Prometheus]]**.

#### Функции для счётчиков (Counters)

*   `rate(v range-vector)`: Вычисляет **среднюю скорость** увеличения значения в секунду за указанный диапазон. Идеально подходит для [[../../Concepts/Observability_and_Monitoring/observability_overview.md#counter|счётчиков]]. При сбросе счетчика в 0, данные корректируются.
    `rate(node_network_receive_bytes_total[5m])`
*   `irate(v range-vector)`: Вычисляет **мгновенную скорость** увеличения, используя только две последние точки данных в диапазоне. Более чувствителен к резким скачкам.
    `irate(node_network_receive_bytes_total[1m])`
*   `increase(v range-vector)`: Вычисляет общее увеличение значения за указанный диапазон. По сути, это `rate(v) * <длительность_диапазона>`.
    `increase(http_requests_total[1h])`
*   `resets(v range-vector)`: Подсчитывает количество сбросов счетчика в указанном диапазоне.

#### Функции для измерителей (Gauges)

*   `changes(v range-vector)`: Подсчитывает, сколько раз значение [[../../Concepts/Observability_and_Monitoring/observability_overview.md#gauge|измерителя]] изменялось в диапазоне.
*   `deriv(v range-vector)`: Вычисляет производную (скорость изменения) для временного ряда, используя линейную регрессию. Помогает сгладить выбросы.
*   `predict_linear(v range-vector, t scalar)`: Предсказывает значение временного ряда через `t` секунд в будущем, основываясь на линейной регрессии. Очень полезна для [[../rules.md|алертинга]].
    `predict_linear(node_filesystem_free_bytes[1h], 3600 * 4) < 0` — прогноз окончания места на диске в ближайшие 4 часа.
*   `delta(v range-vector)`: Разница между началом и концом диапазона. Чувствителен к выбросам.
*   `idelta(v range-vector)`: Разница между двумя последними точками.

#### Функции для гистограмм (Histograms)

*   `histogram_quantile(φ float, b histogram)`: Вычисляет φ-квантиль (0 ≤ φ ≤ 1) из [[../../Concepts/Observability_and_Monitoring/observability_overview.md#histogram|гистограммы]]. Это основной способ использования гистограмм для расчета перцентилей.
    `histogram_quantile(0.95, sum(rate(http_request_duration_seconds_bucket[5m])) by (le))`

#### Агрегация по времени (`..._over_time`)

Эти функции агрегируют значения каждого временного ряда в указанном диапазоне и возвращают мгновенный вектор.

*   `avg_over_time(v range-vector)`: Среднее значение за диапазон (скользящее среднее).
*   `max_over_time()`, `min_over_time()`, `sum_over_time()`
*   `count_over_time()`, `quantile_over_time()`, `stddev_over_time()`, `stdvar_over_time()`

#### Математические функции

*   `abs()`, `ln()`, `log2()`, `log10()`, `exp()`, `sqrt()`
*   `ceil()`, `floor()`: Округление вверх и вниз.
*   `round(v, to_nearest)`: Округление до ближайшего целого или до числа, кратного `to_nearest`.
*   `clamp_max(v, max)`, `clamp_min(v, min)`: Ограничивает значения сверху или снизу.

#### Функции времени и даты

*   `time()`: Возвращает текущее время в формате Unix time.
*   `minute()`, `hour()`, `day_of_week()`, `day_of_month()`, `month()`, `year()`: Возвращают компоненты времени для каждой временной метки.
*   `days_in_month()`: Количество дней в месяце.
*   `timestamp()`: Возвращает временную метку каждого сэмпла.

#### Прочие функции

*   `absent()`: Возвращает пустой вектор, если переданный ей вектор содержит значения. В противном случае возвращает `1`. Удобно для проверки отсутствия метрики.
*   `sort()`, `sort_desc()`: Сортировка вектора по значению.

## 4. Продвинутые детали

### Сопоставление векторов

PromQL позволяет производить операции между векторами.

*   **Один к одному (One-to-one):** Операция выполняется между элементами векторов, имеющими идентичный набор лейблов. Модификаторы `on(<label_list>)` и `ignoring(<label_list>)` позволяют указать, какие лейблы учитывать или игнорировать при сопоставлении.
*   **Один ко многим / многие к одному (One-to-many / many-to-one):** Когда одному элементу может соответствовать несколько, используются ключевые слова `group_left` или `group_right`, чтобы указать, какой вектор является "главным".

### Функции для работы с метками (Labels)

*   `label_replace(v, dst_label, replacement, src_label, regex)`: Добавляет новую метку `dst_label` к вектору `v`. Значение новой метки формируется на основе `replacement`, куда можно подставлять группы захвата из `regex`, примененного к `src_label`.
*   `label_join(v, dst_label, separator, src_label_1, src_label_2, ...)`: Объединяет значения нескольких меток `src_label_*` через `separator` и записывает результат в новую метку `dst_label`.

### Сглаживание и прогнозирование

*   `absent()`: Возвращает пустой вектор, если переданный ей вектор содержит значения. В противном случае возвращает `1`. Удобно для проверки отсутствия метрики.
*   `sort()`, `sort_desc()`: Сортировка вектора по значению.
*   `holt_winters(v range-vector, sf, tf)`: Реализует двойное экспоненциальное сглаживание. Полезно для очистки данных от выбросов и оценки трендов.
