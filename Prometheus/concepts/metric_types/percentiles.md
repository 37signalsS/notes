# Перцентили и квантили

## Определения

**Перцентиль (percentile)** — это число, которое показывает, какой процент элементов массива меньше или равен этому числу. Например, 95-й перцентиль времени обработки запросов = 5 секунд означает, что 95% запросов были обработаны за 5 секунд или быстрее.

**Квантиль (quantile)** — обобщённое понятие перцентиля, где значение указывается не в процентах (0–100), а в долях единицы (0–1). Например, 0.95-квантиль = 95-му перцентилю.

**Зачем нужны перцентили:** Перцентили позволяют описать распределение данных одним числом, отбросив выбросы. Это критически важно для мониторинга производительности, где редкие «залипания» запросов не должны искажать общую картину.

> **Пример:** Если большинство HTTP-запросов обрабатываются за 1 секунду, но 1% запросов «висит» по 60 секунд, среднее арифметическое покажет 2–3 секунды, а 95-й перцентиль останется на уровне 1–2 секунд, что лучше отражает типичное поведение системы.

## Сравнение: среднее арифметическое vs медиана vs перцентили

| Метрика | Описание | Пример | Когда использовать |
| :--- | :--- | :--- | :--- |
| **Среднее арифметическое** | Сумма всех значений, делённая на их количество | `sum(a)/len(a)` | Для равномерных распределений без выбросов |
| **Медиана (50-й перцентиль)** | Средний элемент в упорядоченном массиве | `sort_a[3]` для `[0,1,2,10,38,42,50]` | Для оценки «типичного» значения |
| **95-й перцентиль** | 95% элементов ≤ этому значению | `p95 = 5 сек` | Для оценки производительности «для большинства» |
| **99-й перцентиль** | 99% элементов ≤ этому значению | `p99 = 6 сек` | Для оценки «хвостов» распределения |
| **Максимум (100-й перцентиль)** | Максимальный элемент | `max(a) = 50` | Для обнаружения аномалий |

**Пример расчёта:**

```python
a = [1, 2, 0, 10, 50, 42, 38]
sorted_a = [0, 1, 2, 10, 38, 42, 50]

# Среднее арифметическое
sum(a) / len(a)  # 20.43

# Медиана (50-й перцентиль)
sorted_a[3]  # 10

# Минимум (0-й перцентиль)
min(a)  # 0

# Максимум (100-й перцентиль)
max(a)  # 50
```

## Перцентили в Prometheus

В Prometheus перцентили вычисляются двумя способами, в зависимости от типа метрики:

| Тип метрики | Где вычисляется | Агрегация | Точность |
| :--- | :--- | :--- | :--- |
| **[Histogram](./histogram.md)** | На стороне сервера (`histogram_quantile()`) | **Можно** агрегировать | Приблизительная, зависит от корзин |
| **[Summary](./summary.md)** | На стороне клиента | **Нельзя** агрегировать | Точная для одного инстанса |

**Рекомендация:** Для распределённых систем используйте **Histogram**, так как его перцентили можно корректно агрегировать по нескольким инстансам.

## Вычисление перцентилей из Histogram

```promql
# 95-й перцентиль времени обработки запросов по всему кластеру
histogram_quantile(0.95,
  sum(rate(http_request_duration_seconds_bucket[5m])) by (le)
)

# 99-й перцентиль
histogram_quantile(0.99,
  sum(rate(http_request_duration_seconds_bucket[5m])) by (le)
)

# Медиана (50-й перцентиль)
histogram_quantile(0.50,
  sum(rate(http_request_duration_seconds_bucket[5m])) by (le)
)
```

## Агрегация Summary: проблема и решение

**Проблема:** Перцентили из Summary **нельзя агрегировать** с помощью `avg()` или `sum()`, так как они уже вычислены на стороне клиента.

**Пример проблемы:**

```
app1 = [9, 9, 9, 9, 9]        # 5 запросов по 9 сек → p95 = 9
app2 = [1, 1, 1, ..., 1]      # 100 запросов по 1 сек → p95 = 1

# Неправильно:
avg(http_time{quantile="0.95"}) without (instance)  # (9+1)/2 = 5 ❌

# Правильно:
# Честный p95 на общих данных = 1 (так как 100 из 105 запросов = 1 сек)
```

**Решение:** Используйте `max()` вместо `avg()` для агрегации Summary, если нужно отобразить один график:

```promql
# Показать худший сценарий среди всех инстансов
max(http_time{quantile="0.95"}) without (instance)
```

> **Важно:** Это может приводить к false-positive алертам, если тормозит только одна реплика.

## Практические рекомендации

1. **Начните с гистограммы** — сделайте 5–7 корзин (например, `0.1s`, `0.5s`, `1s`, `5s`, `10s`, `+Inf`).
2. **Если не знаете, какие нужны корзины** — возьмите Summary с 95-м перцентилем.
3. **Сравните 95-й перцентиль и медиану** — медиана покажет усреднённое значение, 95-й перцентиль покажет изменения с большей точностью, но спрячет выбросы.
4. **Не агрегируйте Summary с `avg()`** — используйте `max()` или агрегируйте только `_sum` и `_count`.
5. **Понимайте параметры сэмплирования** — для Summary важно знать, за какой период вычисляются перцентили (читайте документацию библиотеки).

## Словарь терминов

| Термин | Описание |
| :--- | :--- |
| **Перцентиль** | Число от 0 до 100, такое что N% элементов ≤ этому числу |
| **Процентиль** | Синоним слова «перцентиль» (другой перевод percentile) |
| **Квартиль** | Четверти: 25%, 50%, 75%, 100% (1-й, 2-й, 3-й, 4-й квартиль) |
| **Квантиль** | Перцентиль без процентов (в долях единицы: 0.25, 0.50, 0.95) |
| **Дециль** | Десятые доли: 10%, 20%, ..., 90% |
