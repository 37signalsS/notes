# Перцентили и квантили: теория и практика

## Определения

**Перцентиль (percentile)** — значение, ниже которого лежит определённый процент наблюдений из набора данных. Например, 95-й перцентиль времени обработки запросов равный 5 секундам означает, что 95% запросов были обработаны за 5 секунд или быстрее.

**Квантиль (quantile)** — обобщение перцентиля, где уровень указывается в долях единицы (0–1), а не в процентах (0–100). Например, 0.95-квантиль эквивалентна 95-му перцентилю. В Prometheus функция `histogram_quantile()` принимает квантили (0.95, 0.99, 0.50).

**Медиана** — 50-й перцентиль (0.5-квантиль), делит упорядоченный массив пополам.

**Назначение:** перцентили описывают распределение данных одним числом и устойчивы к выбросам. В мониторинге производительности редкие задержки запросов не должны искажать общую картину. Среднее арифметическое чувствительно к экстремальным значениям, в то время как перцентили позволяют увидеть реальный пользовательский опыт для большинства запросов.

## Основные концепции

### Статистические меры распределения

| Метрика | Определение | Устойчивость к выбросам | Когда использовать |
|:---|:---|:---|:---|
| **Среднее арифметическое (mean)** | Сумма всех значений, делённая на их количество | Низкая | Равномерные распределения без аномалий |
| **Медиана (p50)** | Средний элемент упорядоченного массива | Высокая | Типичное значение в системе |
| **95-й перцентиль (p95)** | 95% наблюдений меньше или равны этому значению | Высокая | Производительность для большинства клиентов |
| **99-й перцентиль (p99)** | 99% наблюдений меньше или равны этому значению | Высокая | Хвосты распределения, редкие деградации |
| **Максимум (p100)** | Наибольшее наблюдение в наборе | Отсутствует | Обнаружение аномалий, отладка |

### Пример расчёта на наборе данных

Для набора данных `[10, 20, 15, 12, 18, 100, 14]` после сортировки `[10, 12, 14, 15, 18, 20, 100]`:

- **Среднее:** ≈ 27 (искажено выбросом 100)
- **Медиана:** 15 (устойчива к выбросу)
- **p95:** ≈ 75 (результат интерполяции)
- **Максимум:** 100 (показывает аномалию)

### Словарь терминов

| Термин | Определение | Примеры уровней |
|:---|:---|:---|
| **Квантиль** | Значение, ниже которого лежит φ-доля наблюдений (φ ∈ [0,1]) | 0.25, 0.50, 0.95, 0.99 |
| **Перцентиль** | Частный случай квантили, выраженный в процентах (0–100) | 25-й, 50-й, 95-й, 99-й |
| **Квартиль** | Квантили, делящие данные на 4 части | Q1=25%, Q2=50% (медиана), Q3=75% |
| **Дециль** | Квантили, делящие данные на 10 частей | D1=10%, D5=50%, D9=90% |

В Prometheus и PromQL используется термин **quantile** (квантиль).

## Практические сценарии

### Сценарий 1: Выбор уровня квантили для мониторинга

| Уровень | Что показывает | Применение |
|:---|:---|:---|
| **p50 (медиана)** | Типичный пользователь | Общая картина производительности |
| **p95** | 95% запросов проходят вовремя | SLA для большинства клиентов |
| **p99** | 99% запросов проходят вовремя | Строгие SLA, выявление деградаций |
| **p99.9** | 99.9% запросов проходят вовремя | Критичные системы |

Рекомендуется мониторить одновременно p50, p95 и p99. Большая разница между медианой и 99-м перцентилем указывает на наличие тяжелых хвостов в распределении и нестабильность системы.

### Сценарий 2: Вычисление перцентилей в Prometheus

В Prometheus два типа метрик поддерживают работу с перцентилями:

| Тип | Где вычисляется | Агрегируемость | Точность |
|:---|:---|:---|:---|
| **[Histogram](./histogram.md)** | На сервере через `histogram_quantile()` | Можно суммировать по инстансам | Приблизительная, зависит от корзин |
| **[Summary](./summary.md)** | На стороне клиента (экспортёр) | Нельзя агрегировать | Точная для одного инстанса |

Для распределённых систем следует использовать **Histogram**, так как её данные можно корректно агрегировать перед вычислением квантили: `sum by (le) (rate(..._bucket[5m]))`.

### Сценарий 3: Проблема агрегации Summary

Квантили, вычисленные на разных инстансах, нельзя усреднять. Например:

- Реплика A: p95 = 9 секунд (на 5 запросах)
- Реплика B: p95 = 1 секунда (на 100 запросах)
- Среднее p95 = (9 + 1) / 2 = 5 секунд — это значение математически бессмысленно и не отражает реальность.

Для отображения общей картины по нескольким инстансам Summary можно использовать функцию `max()`, которая покажет худший сценарий.

## Дополнительная информация

### Интерполяция квантилей

Prometheus вычисляет квантили через линейную интерполяцию между границами корзин Histogram. Если запрос попадает в широкий диапазон между корзинами, точность падает. Для повышения точности необходимо увеличивать плотность корзин в критически важных диапазонах значений.

### Ограничения и особенности

- **Приближенность:** результат `histogram_quantile()` — это всегда приближение, точность которого ограничена настройками корзин.
- **Монотонность:** функция ожидает монотонно возрастающие значения в корзинах (гарантируется клиентскими библиотеками).
- **Лейбл `le`:** при агрегации корзин гистограммы лейбл `le` должен быть сохранен, иначе вычисление распределения станет невозможным.
