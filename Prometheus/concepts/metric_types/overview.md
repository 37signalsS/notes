# Типы метрик в Prometheus: Обзор

## Определения

**Типы метрик** в [Prometheus](../../../Linux/Networking/Services/BIND/overview.md) — это классификация временных рядов по их семантике, то есть по тому, как их значения изменяются с течением времени. Prometheus выделяет четыре основных типа метрик. Правильный выбор типа является ключевым для корректного анализа данных, агрегации и построения запросов в [PromQL](../promql/data_types.md).

> **См. также:** [Лейблы и кардинальность](../labels_and_cardinality.md) — правильное использование лейблов для всех типов метрик.

## Четыре основных типа метрик

| Тип | Описание | Когда использовать |
|-----|----------|-------------------|
| **[Counter](./counter.md)** | Кумулятивная метрика, растёт или сбрасывается в 0 | Счётчики запросов, ошибок, задач |
| **[Gauge](./gauge.md)** | Метрика с произвольными изменениями | Температура, память, активные соединения |
| **[Histogram](./histogram.md)** | Распределение с корзинами (buckets) | Латентность, размеры запросов |
| **[Summary](./summary.md)** | Распределение с готовыми квантилями | Мониторинг одного процесса |

* **[Histogram](./histogram.md)** — гистограммы с корзинами, histogram_quantile()
* **[Summary](./summary.md)** — сводки с квантилями на стороне клиента
