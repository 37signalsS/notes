# Типы данных PromQL

## Определения

**PromQL (Prometheus Query Language)** — это мощный **функциональный язык запросов**, разработанный для работы с многомерными данными временных рядов в [Prometheus](../../../Linux/Networking/Services/BIND/overview.md). В отличие от SQL, он оптимизирован для вычислений и агрегаций над временными рядами. PromQL позволяет выбирать и агрегировать данные в реальном времени, результаты чего могут быть отображены в [Grafana](../../../Grafana/grafana_overview.md), таблицах или использованы внешними системами через [HTTP API](../../prometheus_api.md).

> **См. также:** [Типы метрик](../metric_types/alerts.md) — counter, gauge, histogram, summary.

### Типы данных

PromQL оперирует четырьмя основными типами данных:

* **Instant vector (вектор мгновенных значений)**: Набор временных рядов, где для каждого ряда есть только одна точка данных (последняя). Это самый частый результат запроса.
* **Range vector (вектор диапазона значений)**: Набор временных рядов, где для каждого ряда сохранен диапазон точек данных за определенный промежуток времени.
* **Scalar (скаляр)**: Простое числовое значение с плавающей точкой.
* **String (строка)**: Строковое значение (в настоящее время в PromQL напрямую не используется).

### Детали реализации типов

#### Instant vector

Массив из key-value, где key — метрика с лейблами, а value — значение в запрошенный момент времени. Это единственный тип, который рисуется на графиках.

**Почему такая структура:** Один запрос может вернуть сразу несколько временных рядов. Каждая метрика с разными значениями лейблов — это разные ряды. Поэтому instant vector всегда возвращается набором key-value, где ключ — это полное описание ряда (имя метрики и все лейблы), чтобы отличать один ряд от другого.

Один instant vector привязан к одному timestamp. Для получения полезных данных (для отображения на графике) к запросам обычно добавляются диапазон времени и шаг, а в ответе возвращаются наборы instant vector-ов, попавшие под диапазон.

**Важно:** Если в запрошенный timestamp нет значения в БД, Prometheus будет искать значения с timestamp меньше, по умолчанию в пределах 5 минут.

#### Range vector

Массив из key-value, где key — метрика, а value — это значение в запрошенный момент времени + массив из [предыдущих значений за какой-то интервал](

Range vector используется для функций, которые считают «изменение за интервал»: `rate()`, `delta()`, `deriv()` и других. Для вычисления производной или дельты нужно иметь хотя бы два значения функции.

**На что влияет интервал в квадратных скобках:**

* **Больше интервал** — более гладкий результат, виден тренд (общая картина)
* **Меньше интервал** — более шумный результат, видны пики и резкие скачки
* **Слишком малый интервал** (менее 2 точек) — нет результата

Range vector нельзя напрямую вывести на график. Его нужно сначала обработать функцией и получить instant vector.

#### Типы в API (vector и matrix)

При работе с веб-интерфейсом Prometheus или API можно заметить, что типы данных называются **vector** и **matrix**:

| Запрос | Вкладка | Тип в JSON | Описание |
|--------|---------|------------|----------|
| `metric{}` | Table | `vector` | Instant vector на один момент времени (добавляется `time`) |
| `metric{}[1m]` | Table | `matrix` | Range vector: текущая точка + массив прошлых точек |
| `metric{}` | Graph | `matrix` | Instant vector за диапазон (start, end, step) |
| `metric{}[1m]` | Graph | **Ошибка** | Range vector нельзя запросить за диапазон |

**Почему matrix для графика:** Одиночный instant vector не нарисуешь на графике — это просто точка в один момент времени. Для графика нужно много точек за диапазон, поэтому в запросе передаются `start`, `end`, `step`. В value лежит массив вида `[(timestamp1, val1), (timestamp2, val2), ...]`.
