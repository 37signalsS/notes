# Типы данных PromQL

## Определения

**PromQL (Prometheus Query Language)** — функциональный язык запросов для работы с многомерными временными рядами в [Prometheus](../../overview.md). Оптимизирован для вычислений и агрегаций над временными рядами в реальном времени. Результаты отображаются в [Grafana](../../../Grafana/grafana_overview.md), таблицах или передаются через [HTTP API](../../prometheus_api.md).

**Типы данных в PromQL** — четыре основных типа, с которыми оперирует язык:

| Тип | Описание | Отображение на графике |
|-----|----------|---------------------------|
| **Instant vector** | Набор рядов с одной точкой данных на каждый ряд | Да |
| **Range vector** | Набор рядов с диапазоном точек за промежуток времени | Нет (требует функции) |
| **Scalar** | Числовое значение с плавающей точкой (float64) | Нет |
| **String** | Строковое значение (литерал) | Нет |

## Базовые концепции

### Instant vector — мгновенные векторы

Массив пар key-value, где key — метрика с набором лейблов, а value — значение в конкретный момент времени. Это основной тип данных для алертинга и визуализации.

**Особенности:**
- **Структура:** Каждая уникальная комбинация лейблов образует отдельный временной ряд.
- **Timestamp:** Все точки в одном векторе привязаны к одному и тому же моменту времени (evaluation time).
- **Staleness (Устаревание):** Если в точный момент запроса данных нет, Prometheus ищет последнее значение «назад» во времени. Этот интервал называется **lookback delta** (по умолчанию 5 минут). Если последнее значение старше 5 минут, ряд считается устаревшим (stale) и не возвращается.

### Range vector — векторы диапазона

Набор временных рядов, содержащих массив данных за определенный интервал времени. Синтаксис: `metric_name[5m]`.

**Назначение:**
- Входные данные для функций скорости изменения (`rate`, `irate`, `increase`).
- Агрегация данных во времени через функции `..._over_time`.
- Требуют минимум две точки данных для вычисления производных.

**Влияние интервала:**
- Слишком короткий интервал (меньше 2× `scrape_interval`) может привести к пустым результатам.
- Длинные интервалы сглаживают графики, но скрывают кратковременные всплески.

### Scalar — скалярные значения

Чистое числовое значение без меток.

**Способы получения:**
- Математические константы и литералы (например, `24`).
- Результат агрегации без группировки (например, `count(up)`).
- Функция `scalar(vector)`: преобразует вектор из одного элемента в скаляр. Если элементов больше одного или нет совсем, функция вернет `NaN`.
- Функция `time()`: возвращает текущий Unix timestamp как скаляр.

### String — строковые значения

Строковые литералы, заключаемые в одинарные, двойные кавычки или обратные апострофы (backticks).

**Ограничения:**
- Не могут быть сохранены в TSDB как значения метрик.
- Используются только как аргументы в некоторых функциях (например, `label_replace`) или в селекторах лейблов.

### Native Histograms — нативные гистограммы

В современных версиях Prometheus (v2.40+) вектры могут содержать не только float64, но и нативные гистограммы. Они хранят распределение данных в разреженных корзинах (buckets) внутри одного временного ряда, обеспечивая более высокую точность перцентилей по сравнению с классическими гистограммами.

## Практические сценарии

### Запрос Instant vector через API

Используется для получения текущего состояния системы (Table view).

```bash
# Мгновенный запрос — возвращает resultType: vector
curl 'http://localhost:9090/api/v1/query?query=node_load1'
```

### Запрос Range vector через API

Используется для получения сырых данных за период.

```bash
# Запрос диапазона — возвращает resultType: matrix
curl 'http://localhost:9090/api/v1/query_range?query=up&start=2026-07-29T10:00:00Z&end=2026-07-29T11:00:00Z&step=1m'
```

### Применение скаляров в расчетах

Скаляры автоматически распространяются на все ряды вектора при бинарных операциях.

```promql
# Перевод байтов в мегабайты (1048576 — скаляр)
node_memory_MemFree_bytes / 1048576
```

### Использование подзапросов (Subqueries)

Подзапросы позволяют динамически создавать range vector из мгновенных векторов для применения функций диапазона.

```promql
# Средний rate за час с шагом 5 минут
avg_over_time(rate(http_requests_total[5m])[1h:5m])
```

## Дополнительная информация

### Результаты API: vector против matrix

В контексте [Prometheus API](../../prometheus_api.md) существует путаница между типами данных PromQL и форматом JSON-ответа:

| Контекст | resultType: vector | resultType: matrix |
|----------|--------------------|--------------------|
| **Instant Query (`/query`)** | Возвращает мгновенные значения рядов. | Возвращает ряды с интервалом `[d]`. |
| **Range Query (`/query_range`)** | Неприменимо. | Всегда возвращает матрицу (набор мгновенных точек для каждого шага). |

### Взаимосвязь с функциями

- **Range vector -> Instant vector:** Функции `rate()`, `increase()`, `delta()`, `deriv()`.
- **Instant vector -> Instant vector:** Операторы агрегации `sum()`, `avg()`, `max()` ([Агрегация](./aggregation.md)) и математические функции `abs()`, `ceil()`.
- **Subqueries:** Позволяют использовать функции диапазона над результатами мгновенных вычислений.
