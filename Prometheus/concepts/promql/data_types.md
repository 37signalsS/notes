# Типы данных PromQL

## Определения

**PromQL (Prometheus Query Language)** — функциональный язык запросов для работы с многомерными временными рядами в [Prometheus](../../overview.md). Оптимизирован для вычислений и агрегаций над временными рядами в реальном времени. Результаты отображаются в [Grafana](../../../Grafana/grafana_overview.md), таблицах или передаются через [HTTP API](../../prometheus_api.md).

**Типы данных в PromQL** — четыре основных типа, с которыми оперирует язык:

| Тип | Описание | Можно нарисовать на графике |
|-----|----------|---------------------------|
| **Instant vector** | Набор рядов с одной точкой данных (последней) на каждый ряд | Да |
| **Range vector** | Набор рядов с диапазоном точек за промежуток времени | Нет (нужна функция) |
| **Scalar** | Простое числовое значение (floating point) | Нет (одна точка) |
| **String** | Строковое значение (не используется напрямую в PromQL) | Нет |

## Базовые концепции

### Instant vector

Массив пар key-value, где key — метрика с лейблами, value — значение в запрошенный момент времени. Это самый частый результат запроса и единственный тип, который рисуется на графиках.

**Структура:** один запрос возвращает несколько временных рядов. Каждая метрика с разными лейблами — отдельный ряд. Ключ — полное описание ряда (имя + все лейблы).

**Привязка ко времени:** один instant vector привязан к одному timestamp. Для графиков Prometheus запрашивает набор instant vector'ов с указанием `start`, `end`, `step`.

**Staleness:** если в запрошенный timestamp нет значения в БД, Prometheus ищет последнее значение в пределах **5 минут** (по умолчанию).

### Range vector

Массив пар key-value, где key — метрика, value — текущее значение + массив предыдущих значений за указанный интервал. Задаётся синтаксисом `[duration]`: `http_requests_total[5m]`.

**Назначение:** используется функциями, считающими изменение за интервал — `rate()`, `delta()`, `deriv()`, `increase()`. Для вычисления производной или дельты нужно минимум 2 значения.

**Влияние интервала:**

| Интервал | Результат |
|----------|-----------|
| Большой | Гладкий график, виден тренд |
| Малый | Шумный график, видны пики |
| < 2 точек | Нет результата |

Range vector нельзя вывести на график напрямую — сначала обрабатывается функцией для получения instant vector.

### Scalar

Простое числовое значение без лейблов. Получается через агрегацию без `by`/`without`:

```promql
# Scalar — один ряд, нет лейблов
count(http_requests_total)
```

Scalar можно использовать в математических операциях с векторами:

```promql
# Scalar + vector = vector с добавлением скаляра
http_requests_total + 100
```

### String

Строковый тип данных. На данный момент не используется напрямую в PromQL-запросах, присутствует в спецификации API.

## Практические сценарии

### Запрос instant vector через API

```bash
# Table view — один момент времени, resultType: vector
curl 'http://localhost:9090/api/v1/query?query=up'
```

### Запрос range vector через API

```bash
# Range query — диапазон точек, resultType: matrix
curl 'http://localhost:9090/api/v1/query_range?query=up&start=2023-01-01T00:00:00Z&end=2023-01-01T01:00:00Z&step=15s'
```

### Range vector в графиках (Graph view)

Одиночный instant vector — точка в один момент времени, не рисуется на графике. Для графика передаются `start`, `end`, `step`, и в ответе — массив `[(ts1, val1), (ts2, val2), ...]` с resultType: `matrix`.

### Scalar в операциях

```promql
# Конвертация байт в гигабайты
node_memory_MemTotal_bytes / 1024 / 1024 / 1024
```

## Дополнительная информация

### Результат API: vector vs matrix

При работе с [Prometheus API](../../prometheus_api.md) типы называются иначе:

| Запрос | View | resultType | Описание |
|--------|------|------------|----------|
| `metric{}` | Table | `vector` | Instant vector на один момент времени |
| `metric{}[1m]` | Table | `matrix` | Range vector: текущая + прошлые точки |
| `metric{}` | Graph | `matrix` | Instant vector за диапазон (start, end, step) |
| `metric{}[1m]` | Graph | **Ошибка** | Range vector нельзя запросить за диапазон |

### Взаимосвязь с функциями

- Функции для counter (`rate()`, `increase()`) принимают **range vector**, возвращают **instant vector** ([Функции PromQL](./functions.md))
- Операторы агрегации (`sum()`, `avg()`) принимают **instant vector**, возвращают **instant vector** с уменьшенным числом рядов ([Агрегация](./aggregation.md))
- Логические операторы (`and`, `or`, `unless`) работают только с **instant vector** ([Селекторы и операторы](./selectors_operators.md))
