# Дашборд Karma

## Определение

**Karma** — дашборд для [Alertmanager](./alertmanager.md), предоставляющий расширенный пользовательский интерфейс для визуализации и управления оповещениями. В отличие от стандартного интерфейса Alertmanager, Karma поддерживает агрегацию данных из нескольких экземпляров, продвинутую фильтрацию и удобную работу с замалчиваниями (silences).

> **См. также:** [Alertmanager](./alertmanager.md), [Обзор Prometheus](./overview.md)

## Основные концепции

### Функциональные возможности

| Функция | Описание |
|---|---|
| Агрегация | Сбор алертов из нескольких экземпляров Alertmanager в едином интерфейсе |
| Фильтрация и поиск | Поиск по меткам (labels), статусу и уровню важности (severity) |
| Группировка | Визуальное объединение алертов для упрощения интерфейса |
| Замалчивания (Silences) | Создание и управление тишинами напрямую из интерфейса Karma |
| Темы оформления | Поддержка тёмной и светлой тем |
| Отсутствие состояния (Stateless) | У Karma нет собственного бэкенда или базы данных — настройки фильтров и интерфейса сохраняются в браузере (localStorage) |

## Практические сценарии

### Установка с помощью Helm

Пример файла параметров **`values.yaml`**:

```yaml
alertmanager:
  servers:
    - name: "main"
      uri: "http://alertmanager-operated.monitoring.svc.cluster.local:9093"

ingress:
  enabled: true
  hosts:
    - name: "karma.my-domain.com"
      path: "/"

readonly: false

replicaCount: 1
resources:
  limits:
    cpu: 100m
    memory: 128Mi
  requests:
    cpu: 50m
    memory: 64Mi
```

**Развёртывание:** выполняется стандартной командой `helm install` или через GitOps-инструменты (например, ArgoCD), используя `Application` ресурс, указывающий на официальный репозиторий с чартом.

### Установка через манифесты Kubernetes

Для развёртывания в Kubernetes создаются следующие стандартные ресурсы:

| Ресурс | Назначение |
|---|---|
| `ConfigMap` | Хранение конфигурации Karma (адреса Alertmanager, настройки фильтрации) |
| `Deployment` | Управление жизненным циклом подов Karma |
| `Service` | Обеспечение внутреннего сетевого доступа к дашборду |
| `Ingress` | Организация внешнего доступа к веб-интерфейсу (опционально) |
