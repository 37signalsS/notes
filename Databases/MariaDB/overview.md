# Обзор MariaDB

MariaDB — это реляционная СУБД, созданная оригинальными разработчиками MySQL как полностью открытый и управляемый сообществом форк. Она стремится сохранять высокую совместимость с MySQL, но при этом активно внедряет новые возможности и поддерживает разнообразие движков хранения.

## История и философия

Изначально MySQL, разработанный компанией MySQL AB, стал де-факто стандартом для веб-приложений в начале 2000-х. В 2008 году MySQL AB была поглощена Sun Microsystems, а в 2010 году Sun, в свою очередь, была поглощена Oracle Corporation.

Опасаясь за будущее MySQL как открытого проекта под управлением Oracle, ключевые разработчики во главе с Майклом "Монти" Видениусом форкнули кодовую базу (на тот момент версии 5.5) и основали MariaDB.

Философия MariaDB заключается в следующем:
- **Открытость:** Разработка ведется полностью открыто и управляется сообществом через MariaDB Foundation.
- **Разнообразие движков:** В отличие от Oracle, который фокусируется почти исключительно на InnoDB, MariaDB активно поддерживает и развивает множество движков хранения.
- **Внедрение новых фич:** Активное добавление нового SQL-синтаксиса, функций и улучшений оптимизатора.

## Версионирование

В отличие от MySQL, MariaDB использует собственную схему версионирования. Например:
- **10.11:** Версия с долгосрочной поддержкой (Long-Term Support, LTS). Рекомендуется для производственных сред.
- **11.3:** Текущая стабильная версия с коротким сроком поддержки, содержащая самые новые возможности.

## Ключевые отличия от MySQL 8

Начиная с версии MySQL 8.0, различия между продуктами стали существенными, что делает прямую миграцию без логического дампа невозможной.

- **Движки хранения:** MariaDB предлагает гораздо более широкий выбор специализированных движков. См. **[Движки хранения в MariaDB](./mariadb_storage_engines.md)**.
- **Query Cache:** В отличие от MySQL 8, где кэш запросов был полностью удален, в MariaDB он сохранен. Он может быть эффективен для нагрузок с преобладанием чтения (много `SELECT`) и редкой записью.
- **Оптимизатор запросов:** Команда MariaDB активно работает над улучшением собственного оптимизатора, добавляя новые возможности и улучшая производительность.
- **SQL-функциональность:**
    - **Типы данных:** Добавлены `UUID`, `INET4`, `INET6` для удобного хранения соответствующих типов данных.
    - **Операторы:** `CREATE OR REPLACE TABLE`, `DELETE ... RETURNING`.
    - **Анализ запросов:** `EXPLAIN` можно записывать в slow query log для анализа планов выполнения медленных запросов.
    - **Регулярные выражения:** Используется PCRE (Perl Compatible Regular Expressions), более мощный и привычный синтаксис по сравнению с POSIX-синтаксисом в MySQL.
- **Процессы:** `PROCESSLIST` показывает прогресс выполнения длительных запросов (например, для `ALTER TABLE`).
- **Кластеризация:** Встроенная поддержка Galera Cluster для создания синхронного мульти-мастер кластера.
- **Системные таблицы:** В MariaDB системные таблицы используют движок Aria, в то время как в MySQL 8 все переведено на InnoDB.
