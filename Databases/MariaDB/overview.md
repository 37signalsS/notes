# MariaDB: Обзор

## Определения

**MariaDB** — это реляционная система управления базами данных (СУБД), созданная оригинальными разработчиками MySQL как полностью открытый и управляемый сообществом форк. Она стремится сохранять высокую совместимость с MySQL, одновременно активно внедряя новые возможности и поддерживая разнообразие движков хранения.

## Основные концепции

### История и философия MariaDB

Изначально MySQL, разработанный компанией MySQL AB, был стандартом для веб-приложений. После поглощения разработчика корпорацией Oracle в 2010 году, ключевые создатели MySQL во главе с Майклом "Монти" Видениусом, опасаясь за будущее проекта, форкнули кодовую базу (версии 5.5) и основали MariaDB.

Философия MariaDB базируется на следующих принципах:

- **Открытость:** Разработка ведется полностью открыто и управляется независимым фондом MariaDB Foundation.
- **Разнообразие движков:** В отличие от MySQL, который фокусируется на InnoDB, MariaDB активно поддерживает и развивает множество специализированных **[движков хранения](storage_engines.md)**.
- **Новые возможности:** Проект нацелен на активное добавление нового SQL-синтаксиса, функций и улучшений оптимизатора запросов.

### Ключевые отличия и преимущества перед MySQL

С версии MySQL 8.0 различия между проектами стали существенными, и их пути значительно разошлись. Основные отличия MariaDB включают:

- **Движки хранения:** MariaDB предлагает гораздо более широкий выбор, включая ColumnStore для аналитики и S3 Storage Engine для архивных данных.
- **Оптимизатор запросов:** Команда MariaDB активно развивает собственный оптимизатор, добавляя уникальные возможности и улучшения производительности, независимые от MySQL.
- **SQL-функциональность:**
  - **Типы данных:** Добавлены `UUID`, `INET4`, `INET6` для удобного и нативного хранения соответствующих типов данных.
  - **Операторы:** Поддерживаются `CREATE OR REPLACE TABLE`, `DELETE ... RETURNING`, что упрощает разработку.
  - **Анализ запросов:** `EXPLAIN` можно записывать напрямую в лог медленных запросов (`slow query log`) для отложенного анализа планов выполнения.
- **Кластеризация:** Встроенная поддержка Galera Cluster обеспечивает создание синхронного мульти-мастер кластера "из коробки".
- **Системные таблицы:** В MariaDB системные таблицы используют движок Aria (улучшенный MyISAM), в то время как в MySQL 8 они переведены на InnoDB.

## Дополнительная информация

- **Проблема миграции:** Из-за накопившихся различий, прямая бинарная миграция (копированием файлов) между MariaDB и MySQL 8 (и выше) невозможна. Единственный надежный способ — **логический дамп** (например, с помощью `mariadb-dump` или `mysqldump`).
