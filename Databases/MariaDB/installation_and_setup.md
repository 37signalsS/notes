# Установка и настройка MariaDB

## Определения

**MariaDB** — реляционная система управления базами данных (RDBMS) с открытым исходным кодом, развивающаяся как высокопроизводительный и функционально богатый форк MySQL.

**LTS (Long Term Support)** — версии с долгосрочной поддержкой (обычно 3–5 лет), которые являются приоритетными для использования в производственных (production) средах из-за их стабильности и гарантированных обновлений безопасности.

## Основные концепции

### Жизненный цикл версий (на июль 2026)

Для обеспечения безопасности и доступа к современным функциям (таким как векторный поиск и оптимизация бинарных логов) рекомендуется использовать актуальные LTS-ветки:
- **12.3 LTS (May 2026):** Рекомендуемая версия для всех новых инсталляций. Поддержка до июня 2029 года.
- **11.4 LTS:** Стабильная версия, широко используемая в облачных образах и текущих проектах.
- **10.11 LTS:** Консервативный выбор для миграции со старых систем (10.x).

### Способы установки

1. **Официальный репозиторий MariaDB Foundation:** Предоставляет самые свежие LTS и Rolling релизы. Рекомендуется для большинства задач.
2. **Репозитории дистрибутива (OS Repositories):** Пакеты адаптированы под конкретную ОС, но часто содержат устаревшие версии.
3. **Docker / Podman:** Идеально для изоляции и быстрой разработки.

### Пакеты специального назначения

В версии 12.3 введен пакет **`mariadb-server-galera`** (для Debian/RPM), который включает все необходимые зависимости для работы кластера Galera «из коробки», упрощая развертывание отказоустойчивых решений.

## Практические сценарии

### Установка в Debian и Ubuntu

Для установки версии 12.3 LTS используйте официальный скрипт автоматической настройки репозитория:

```bash
# 1. Настройка репозитория для версии 12.3
curl -LsS https://r.mariadb.com/downloads/mariadb_repo_setup | sudo bash -s -- --mariadb-server-version="mariadb-12.3"

# 2. Установка сервера и клиента
sudo apt update
sudo apt install -y mariadb-server mariadb-client
```

### Установка в RHEL, Rocky Linux, AlmaLinux

```bash
# Добавление репозитория
curl -LsS https://r.mariadb.com/downloads/mariadb_repo_setup | sudo bash -s -- --mariadb-server-version="mariadb-12.3"

# Установка через DNF
sudo dnf install -y MariaDB-server MariaDB-client
```

### Первоначальный запуск и активация

```bash
# Включение автозапуска и запуск сервиса
sudo systemctl enable --now mariadb

# Проверка статуса службы
systemctl status mariadb
```

### Базовая защита (Mandatory)

После установки ОБЯЗАТЕЛЬНО выполните скрипт первичной настройки безопасности. Он удалит анонимных пользователей, тестовую базу и запретит удаленный вход для root.

```bash
sudo mariadb-secure-installation
```
> Подробный разбор шагов — в **[Безопасная установка СУБД](../installation_security.md)**.

### Проверка авторизации и версии

В современных версиях MariaDB (11.x, 12.x) для локального пользователя root по умолчанию используется плагин `unix_socket`. Это означает, что вы можете войти в консоль без пароля, используя `sudo`.

```bash
# Вход под root (через сокет)
sudo mariadb

# Проверка версии сервера
mariadb -e "SELECT VERSION();"
```

## Дополнительная информация

### Совместимость аутентификации

В версии 12.3 LTS добавлена нативная поддержка плагина **`caching_sha2_password`**. Это упрощает интеграцию с клиентами и драйверами, разработанными для MySQL 8.0+, обеспечивая бесшовную миграцию.

### Диагностика сетевого доступа

По умолчанию MariaDB слушает порт `3306` только на `localhost` (127.0.0.1). Для разрешения внешних подключений необходимо отредактировать параметр `bind-address` в конфигурации.

```bash
# Проверка текущего прослушивания порта
ss -tlnp | grep 3306
```
