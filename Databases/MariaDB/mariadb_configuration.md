# Конфигурация MariaDB

Для сохранения совместимости с экосистемой MySQL, MariaDB использует схожую структуру и расположение конфигурационных файлов.

- **Основной каталог:** `/etc/mysql/`
- **Главный файл:** `/etc/mysql/my.cnf` или `/etc/mysql/mariadb.conf`. Обычно он содержит только ссылки (`!includedir`) на другие каталоги.
- **Каталог с настройками:** `/etc/mysql/mariadb.conf.d/`. Основная конфигурация сервера и клиента производится именно здесь. Файлы в этом каталоге загружаются в алфавитном порядке (поэтому их имена начинаются с чисел, например, `50-server.cnf`).

### Основные файлы в `mariadb.conf.d`

-   `50-client.cnf`: Настройки для клиентских приложений (например, `mariadb`, `mariadb-dump`). Здесь можно задать порт по умолчанию, сокет или пароль.
-   `50-server.cnf`: **Основной файл для настройки сервера.** Здесь задаются параметры, влияющие на производительность, логирование, репликацию и безопасность.
-   `60-galera.cnf`: Конфигурация для Galera Cluster, если он используется.

## Основные параметры в `50-server.cnf`

Конфигурация разделена на секции, например `[mysqld]`, `[server]`, `[mariadb]`.

```ini
[mariadb]
# -- Общие настройки --
# IP-адрес для приема подключений. 127.0.0.1 - только локальные. 0.0.0.0 - все интерфейсы.
bind-address = 127.0.0.1
# Максимальное количество одновременных подключений.
max_connections = 100

# -- Настройки движков --
# Размер буфера для ключей MyISAM/Aria.
key_buffer_size = 16M
# Основной параметр для InnoDB: размер буферного пула для данных и индексов.
# Рекомендуется устанавливать до 70-80% от доступной оперативной памяти на выделенном сервере.
innodb_buffer_pool_size = 128M

# -- Логирование --
# Включение лога медленных запросов.
slow_query_log = 1
# Файл для лога.
slow_query_log_file = /var/log/mysql/mariadb-slow.log
# Время в секундах, после которого запрос считается медленным.
long_query_time = 1
# Записывать в лог explain-план для медленных запросов. Очень полезно для анализа.
log_slow_extra = 1

# -- Бинарный лог (для репликации и восстановления на точку времени) --
# Активирует бинлог. Укажите базовое имя файла.
# log_bin = /var/log/mysql/mysql-bin.log
# Уникальный ID сервера в топологии репликации.
# server_id = 1
```

## Расположение данных и логов

-   **Директория с данными (datadir):** `/var/lib/mysql/`
    -   Здесь хранятся подкаталоги для каждой базы данных, а также файлы логов InnoDB (`ib_logfile*`, `ibdata1`) и Aria (`aria_log*`).
    -   В отличие от MySQL 8, где файлы структуры таблиц (`.frm`) были упразднены, в MariaDB они все еще используются, что напоминает архитектуру MySQL 5.7.
-   **Лог ошибок:** `/var/log/mysql/error.log` или `/var/log/mariadb/mariadb.log`.
-   **Бинарные логи и логи медленных запросов:** Обычно также в `/var/log/mysql/`.

## Клиентские утилиты

MariaDB постепенно переименовывает утилиты с `mysql*` на `mariadb*` для устранения путаницы. Однако для обратной совместимости старые имена работают как символические ссылки или псевдонимы.

| Старое имя | Новое имя | Назначение |
| --- | --- | --- |
| `mysql` | `mariadb` | CLI-клиент для подключения к серверу. |
| `mysqldump` | `mariadb-dump` | Создание логического дампа базы данных. |
| `mysqladmin` | `mariadb-admin` | Утилита для административных задач. |
| `mysqlcheck` | `mariadb-check` | Проверка и восстановление таблиц. |
