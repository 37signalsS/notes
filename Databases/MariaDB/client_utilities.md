# Клиентские утилиты MariaDB

## Определения

**Клиентские утилиты MariaDB** — это набор программ командной строки, предназначенных для взаимодействия с сервером MariaDB, его администрирования, выполнения операций с данными и управления современными рабочими нагрузками (включая AI и кластерные конфигурации).

## Основные концепции

### Ребрендинг и совместимость

MariaDB завершила переход на собственные имена утилит с префиксом `mariadb*`. Хотя старые имена (префикс `mysql*`) сохраняются как символические ссылки для совместимости, в современной документации и скриптах рекомендуется использовать актуальные имена.

| Старое имя | Актуальное имя (12.3 LTS) | Назначение |
| :--- | :--- | :--- |
| `mysql` | `mariadb` | Основной SQL-клиент |
| `mysqldump` | `mariadb-dump` | Логическое резервное копирование |
| `mysqladmin` | `mariadb-admin` | Административные задачи |
| `mysqlcheck` | `mariadb-check` | Обслуживание таблиц (включая Sequence) |
| `mysqlshow` | `mariadb-show` | Просмотр метаданных (БД, таблицы, колонки) |
| `mysqlimport` | `mariadb-import` | Массовая загрузка данных из текстовых файлов |
| `mysqlbinlog` | `mariadb-binlog` | Чтение и обработка бинарных логов |

### Новое поколение: MariaDB Shell

Начиная с версии 12.x, MariaDB продвигает **MariaDB Shell (`mariadb-shell`)** как основной инструмент для разработчиков и администраторов. В отличие от классического клиента, он поддерживает:
- **Мультиязычность:** режимы SQL, JavaScript и Python.
- **Интеграция с AI:** встроенная поддержка **Model Context Protocol (MCP)** для связи базы данных с LLM (Gemini, OpenAI).
- **Форматирование:** нативный вывод в форматах JSON, улучшенные таблицы и постраничная навигация.

## Практические сценарии

### Классический клиент: mariadb

Используется для стандартных SQL-запросов и выполнения скриптов.

```bash
# Подключение с использованием нового каталога скриптов (12.3+)
# Позволяет искать файлы для команды 'source' в указанной директории
mariadb -u admin -p --script-dir=/opt/db_scripts

# Выполнение запроса с выводом в формате JSON (удобно для конвейеров)
mariadb -u user -p -e "SELECT * FROM users" --json
```

### Резервное копирование: mariadb-dump

В версии 12.3 утилита получила поддержку масок (wildcards) для выбора таблиц.

```bash
# Дамп таблиц по маске (все таблицы, начинающиеся на 'logs_')
mariadb-dump -u backup_user -p my_db --wildcards "logs_*" > logs_backup.sql

# Создание дампа всех баз данных с сохранением информации о GTID
mariadb-dump -u root -p --all-databases --gtid > full_cluster_backup.sql
```

### Администрирование: mariadb-admin

```bash
# Проверка переменных состояния (Uptime, Threads, etc.)
mariadb-admin -u root -p extended-status

# Принудительная ротация бинарных логов
mariadb-admin -u root -p flush-logs
```

### Продвинутая работа: mariadb-shell

```bash
# Запуск в режиме Python для автоматизации
mariadb-shell --py

# Внутри shell (Python mode):

```

## Дополнительная информация

### Переменные окружения (12.3 LTS)

Для упрощения настройки в 12.3 введены новые переменные окружения:
- `MARIADB_GROUP_SUFFIX`: позволяет загружать специфические группы настроек из `my.cnf`.
- `MARIADB_HISTFILE`: задает путь к файлу истории команд (вместо `.mysql_history`).

### Диагностические утилиты

- **`mariadb-slap`:** инструмент для нагрузочного тестирования. Позволяет эмулировать конкурентные подключения и замерять время выполнения запросов.
- **`mariadb-wait`:** полезная утилита для скриптов автоматизации (например, в Docker), которая ждет, пока сервер станет доступен для подключений.
