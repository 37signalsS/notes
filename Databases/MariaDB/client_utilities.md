# Клиентские утилиты MariaDB

### Определения

**Клиентские утилиты MariaDB** — это набор программ командной строки, предназначенных для взаимодействия с сервером MariaDB, его администрирования и выполнения различных операций с данными.

### Основные концепции

С целью устранения путаницы с утилитами MySQL, MariaDB провела ребрендинг своих клиентских программ, изменив префикс с `mysql*` на `mariadb*`. Для обеспечения обратной совместимости старые имена сохранены и функционируют как символические ссылки или псевдонимы для новых.

Основное сопоставление старых и новых имен:

| Старое имя | Новое имя |
| --- | --- |
| `mysql` | `mariadb` |
| `mysqldump` | `mariadb-dump` |
| `mysqladmin` | `mariadb-admin` |
| `mysqlcheck` | `mariadb-check` |

### Практические сценарии

- **`mariadb` (ранее `mysql`)**: Основной CLI-клиент для интерактивного подключения к серверу и выполнения SQL-запросов.
- **`mariadb-dump` (ранее `mysqldump`)**: Утилита для создания логических резервных копий баз данных. Подробные примеры использования описаны в разделе **[[backup_and_recovery|Резервное копирование и восстановление]]**.
- **`mariadb-admin` (ранее `mysqladmin`)**: Инструмент для выполнения административных задач, таких как проверка состояния сервера, управление процессами и перезагрузка привилегий.
- **`mariadb-check` (ранее `mysqlcheck`)**: Программа для проверки, восстановления и оптимизации таблиц.

### Дополнительная информация

Настройки для клиентских утилит, такие как порт, сокет или учетные данные по умолчанию, могут быть заданы в конфигурационных файлах. Детали см. в разделе **[[configuration|Конфигурация MariaDB]]**.
