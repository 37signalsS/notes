# Клиентские утилиты MariaDB

## Определения

**Клиентские утилиты MariaDB** — это набор программ командной строки, предназначенных для взаимодействия с сервером MariaDB, его администрирования и выполнения различных операций с данными.

## Основные концепции

С целью устранения путаницы с утилитами MySQL, MariaDB провела ребрендинг своих клиентских программ, изменив префикс с `mysql*` на `mariadb*`. Для обеспечения обратной совместимости старые имена сохранены и функционируют как символические ссылки или псевдонимы для новых.

| Старое имя | Новое имя |
| --- | --- |
| `mysql` | `mariadb` |
| `mysqldump` | `mariadb-dump` |
| `mysqladmin` | `mariadb-admin` |
| `mysqlcheck` | `mariadb-check` |

## Практические сценарии

**`mariadb` (ранее `mysql`):** Основной **CLI (Command Line Interface)** клиент для интерактивного подключения к серверу и выполнения **SQL (Structured Query Language)** запросов.

```bash
# Подключение к локальному серверу
mariadb -u root -p

# Подключение к удалённому серверу
mariadb -h <host> -P <port> -u <user> -p

# Выполнение команды без входа в интерактивный режим
mariadb -u <user> -p -e "SHOW DATABASES;"
```

**`mariadb-dump` (ранее `mysqldump`):** Утилита для создания логических резервных копий баз данных. Подробные примеры использования — в **[Резервное копирование и восстановление](backup_and_recovery.md)**.

```bash
# Дамп одной базы данных
mariadb-dump -u <user> -p <database_name> > backup.sql

# Дамп всех баз данных
mariadb-dump -u <user> -p --all-databases > all_databases.sql
```

**`mariadb-admin` (ранее `mysqladmin`):** Инструмент для выполнения административных задач: проверка состояния сервера, управление процессами, перезагрузка привилегий.

```bash
# Проверка состояния сервера
mariadb-admin -u root -p status

# Остановка сервера
mariadb-admin -u root -p shutdown

# Перезагрузка привилегий
mariadb-admin -u root -p reload
```

**`mariadb-check` (ранее `mysqlcheck`):** Программа для проверки, восстановления и оптимизации таблиц.

```bash
# Проверка всех таблиц в базе данных
mariadb-check -u <user> -p <database_name>

# Восстановление таблиц
mariadb-check -u <user> -p --recover <database_name>

# Оптимизация таблиц
mariadb-check -u <user> -p --optimize <database_name>
```

## Дополнительная информация

Настройки для клиентских утилит, такие как порт, сокет или учетные данные по умолчанию, могут быть заданы в конфигурационных файлах. Детали см. в разделе **[Конфигурация MariaDB](configuration.md)**.
