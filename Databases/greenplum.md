# Greenplum

## 1. Определения

**Greenplum** — это массивно-параллельная (MPP, Massively Parallel Processing) СУБД, основанная на PostgreSQL. Она спроектирована как платформа для крупномасштабных хранилищ данных (DWH) и выполнения сложных аналитических запросов (OLAP).

Ключевая идея — **распараллеливание выполнения запросов** по десяткам и сотням серверов для обработки петабайтных объемов данных.

## 2. Основные концепции

### Архитектура (Shared-Nothing MPP)

Greenplum использует архитектуру **"без разделяемых ресурсов" (shared-nothing)**, где каждый узел в кластере имеет собственные CPU, память и диски.

- **Мастер-хост (Master Host):** Точка входа для клиентов. Хранит метаданные (глобальный каталог), оптимизирует и координирует выполнение запросов. Пользовательские данные на мастере не хранятся.
- **Сегмент-хосты (Segment Hosts):** Рабочие узлы, на которых хранятся и обрабатываются данные. На каждом хосте работает один или несколько **сегментов** (экземпляров PostgreSQL), каждый из которых владеет частью общих данных.

### Распределение данных

Greenplum комбинирует два уровня распределения данных:

1. **Дистрибуция (Distribution):** Строки таблиц распределяются (шардируются) по всем сегментам в кластере на основе **ключа дистрибуции**. Это обеспечивает параллельную обработку.
2. **Партиционирование (Partitioning):** Внутри каждого сегмента таблицы могут быть дополнительно разделены на партиции (например, по датам), что ускоряет выборку данных и упрощает управление ими.

## 3. Практические сценарии

- **Корпоративные хранилища данных (DWH):** Централизованный сбор и анализ данных со всей организации.
- **Business Intelligence (BI) и отчетность:** Построение витрин данных и выполнение тяжелых аналитических запросов для отчетов.
- **Анализ больших данных:** Исследовательский анализ, машинное обучение и другие задачи, требующие сканирования больших объемов данных.

## 4. Дополнительная информация

- **Ориентация на OLAP:** Система оптимизирована для сложных аналитических запросов, а не для частых мелких транзакций (OLTP). Высокая пропускная способность достигается за счет пакетной обработки и параллелизма, но с большими задержками для одиночных запросов.
- **Совместимость с PostgreSQL:** Greenplum основан на PostgreSQL (хотя и не всегда на самой свежей версии), что обеспечивает поддержку стандарта SQL и совместимость со многими инструментами экосистемы, такими как `psql` и `pg_dump`.
- **Экосистема:** Включает инструменты для параллельной загрузки/выгрузки данных (`gpfdist`), а также интеграцию с Apache MADlib для машинного обучения внутри базы данных.
