# Redis vs Memcached: Краткое сравнение

| Критерий | Redis | Memcached |
| :--- | :--- | :--- |
| **Структуры данных** | Строки, хэши, списки, множества, сортированные множества, битмапы, HyperLogLog | Строки (ключ-значение) |
| **Персистентность** | Опционально (RDB/AOF) | Нет |
| **Репликация/Cluster**| Да | Шардинг на уровне клиента |
| **TTL/eviction** | Гибко | Простой TTL и LRU |
| **Сценарии** | Кеш + очереди, счетчики, блокировки | Лёгкий высокоскоростной кеш |

*Выбор: Memcached — минималистичный RAM-кеш для простых строк и огромных объёмов; Redis — богатые структуры данных, кластер, дополнительные примитивы.*

# Redis vs Memcached: Детальное сравнение моделей хранения

Системы кеширования принципиально различаются не только скоростью, но и тем, как именно хранят данные в памяти, управляют их «жизненным циклом» и масштабируются. Выбор между Redis и Memcached во многом определяется моделью хранения и связанными с ней компромиссами.

| Аспект | Redis | Memcached |
| :--- | :--- | :--- |
| **Типы данных** | Структуры и атомарные операции | Байтовые значения |
| **Память** | jemalloc, кодеки, политики eviction | Slab-аллокатор, LRU по классам |
| **TTL** | ms точность, активное+пассивное | Ленивое + crawler, особый смысл >30 дней |
| **Персистентность**| RDB/AOF | Нет |
| **Масштабирование**| Кластер/репликация | Клиентское шардирование |
| **Профиль нагрузки**| Сложные операции | Чистый get/set |

## Модель данных

*   **Redis** — ключ–значение с богатыми структурами: строки, хэши, списки, множества, отсортированные множества, битовые поля, HyperLogLog, геоиндексы, потоки. Для экономии памяти применяются внутренние кодеки (listpack/ziplist, intset, quicklist). Операции над структурами атомарны.
*   **Memcached** — ключ–значение, где значение — непрозрачный массив байт. Сервер не знает формат значений; сложные структуры требуют сериализации на стороне клиента.

### Пример: профиль пользователя как составные поля

**Redis: хэш с полями**
```sql
HSET user:42 name "Alice" age 29 plan "pro"
HGETALL user:42
```

**Memcached: сериализованный JSON**
```csharp
set user:42 300 0 {"name":"Alice","age":29,"plan":"pro"}
get user:42
```
