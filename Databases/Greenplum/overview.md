# Greenplum: Обзор

Greenplum — это массивно-параллельная (MPP, Massively Parallel Processing) платформа для хранения и анализа данных, основанная на PostgreSQL. Она спроектирована для крупномасштабных аналитических задач и хранилищ данных.

## Архитектура

Greenplum использует архитектуру "без разделяемых ресурсов" (shared-nothing), где каждый узел в кластере имеет собственные CPU, память и дисковое пространство.

- **Мастер-хост (Master Host):** Является точкой входа в систему. Сюда подключаются клиенты. Мастер не хранит пользовательские данные, но содержит глобальный системный каталог (метаданные), оптимизирует и координирует выполнение запросов.
- **Сегмент-хосты (Segment Hosts):** Это рабочие узлы, на которых хранятся и обрабатываются данные. На каждом сегмент-хосте работает один или несколько экземпляров PostgreSQL, называемых **сегментами**. Каждый сегмент хранит свою часть данных.

## Ключевые особенности

- **Массивно-параллельная обработка:** Запросы автоматически распараллеливаются и выполняются одновременно на всех сегментах, что позволяет обрабатывать огромные объемы данных.
- **Совместимость с PostgreSQL:** Greenplum основан на PostgreSQL, поэтому он поддерживает стандартный SQL и многие инструменты из экосистемы PostgreSQL.
- **Комбинация партиционирования и шардирования:** Greenplum позволяет комбинировать два уровня распределения данных:
    1.  **Шардирование (Distribution):** Данные распределяются (шардируются) по всем сегментам в кластере на основе ключа дистрибуции.
    2.  **Партиционирование (Partitioning):** Внутри каждого сегмента данные могут быть дополнительно разделены на партиции (например, по дате), как и в стандартном PostgreSQL.
- **Ориентация на аналитику:** Система оптимизирована для сложных аналитических запросов (OLAP), а не для частых транзакционных операций (OLTP).
