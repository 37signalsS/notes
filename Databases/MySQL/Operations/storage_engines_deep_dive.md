# Глубокое погружение в Storage Engines MySQL и Percona

## Определения

*   **MyISAM** — исторический движок хранения MySQL. Не поддерживает транзакции и внешние ключи, использует блокировку на уровне всей таблицы.
*   **Memory Engine** — движок, хранящий данные только в оперативной памяти. Бывший `HEAP`.
*   **TokuDB** — движок на основе **Fractal Tree** индексов, оптимизированный для очень больших объемов данных и сжатия. В 2026 году считается устаревшим (deprecated) в пользу MyRocks.
*   **MyRocks** — современный движок на базе **LSM-дерева** (RocksDB), оптимизированный для интенсивной записи и эффективного сжатия.

---

## Движки Oracle MySQL

### MyISAM: Наследие и системные нужды
Хотя InnoDB является стандартом с версии 5.5, MyISAM всё еще присутствует в экосистеме.

1.  **Системные таблицы:** В MySQL 5.7 и ниже база `mysql` полностью состояла из MyISAM таблиц. В MySQL 8.0+ системные таблицы переведены на InnoDB, но MyISAM остается для некоторых временных таблиц.
2.  **Блокировки:** Главный недостаток — **Table-level locking**. Любой `UPDATE` блокирует всю таблицу для `SELECT`, что делает MyISAM непригодным для конкурентной нагрузки.
3.  **Восстановление:** При сбое питания таблицы MyISAM часто повреждаются. Требуется запуск `REPAIR TABLE`.

### Memory (HEAP)
Идеален для быстрого доступа к временным данным.
*   **Особенности:** Использует только HASH-индексы по умолчанию (очень быстрые точные совпадения, но не работают для диапазонов `> <`).
*   **Ограничения:**
    *   Общий объем ограничен `max_heap_table_size`.
    *   Данные не сохраняются после перезапуска (`SCHEMA` остается, данные — нет).
    *   Не поддерживает типы `TEXT` и `BLOB`.

### Archive
Специализированный движок для логов и аудита.
*   **Принцип:** Использует zlib для сжатия данных при записи. Индексы не поддерживаются (кроме PK на `AUTO_INCREMENT`).
*   **Операции:** Только `INSERT` и `SELECT`. `DELETE` и `UPDATE` запрещены.

## Движки Percona Server (SRE Choice)

### MyRocks (LSM-tree)
Лучший выбор для систем с дефицитом дискового пространства или огромным потоком вставок.

**Архитектура LSM (Log-Structured Merge-tree):**
1.  **MemTable:** Новые данные пишутся в память (в буфер).
2.  **SST (Sorted String Table):** Когда буфер полон, данные сбрасываются на диск как иммутабельные файлы.
3.  **Compaction:** Фоновый процесс объединения SST-файлов разных уровней для удаления дублей и помеченных на удаление строк.

**SRE-преимущества:**
*   **Сжатие:** В 2-3 раза плотнее InnoDB за счет отсутствия пустых мест в страницах B-Tree (фрагментации).
*   **Write Amplification:** Значительно меньше, чем у InnoDB, что продлевает жизнь SSD.

### TokuDB (Fractal Tree)
*   **Статус:** В Percona Server 8.0.28+ и MariaDB 10.6+ поддержка TokuDB прекращена.
*   **Почему заменить на MyRocks:** MyRocks показывает лучшую производительность на современных многоядерных CPU и лучше интегрирован в облачные окружения.

## Практические сценарии

### Выбор движка под задачу

| Задача | Рекомендуемый движок | Почему? |
| :--- | :--- | :--- |
| **Стандартная OLTP** | **InnoDB** | Баланс скорости, надежности и фич. |
| **Логирование (>1ТБ/день)** | **MyRocks** | Минимум Write Amp, отличное сжатие. |
| **Краткосрочный кеш** | **Memory** | Максимальный RPS в RAM. |
| **Архив (Read-only)** | **Archive / S3** | Экономия места. |

### Конвертация таблиц (SRE Best Practice)

Перед конвертацией большой таблицы в MyRocks всегда проверяйте несовместимости (например, отсутствие Foreign Keys).

```sql
-- Проверка текущего использования диска
SELECT engine, COUNT(*), SUM(data_length+index_length)/1024/1024 AS total_mb 
FROM information_schema.tables GROUP BY engine;

-- Миграция на MyRocks
ALTER TABLE heavy_logs ENGINE=RocksDB;
```

## Устранение неполадок (Troubleshooting)

| Проблема | Вероятная причина | Решение |
| :--- | :--- | :--- |
| `Table '...' is marked as crashed` | Сбой MyISAM таблицы. | `REPAIR TABLE table_name;` |
| `The table '...' is full` | Лимит `max_heap_table_size` для Memory. | Увеличьте лимит или очистите таблицу. |
| `Write Stall` в MyRocks | Слишком медленный Compaction. | Проверьте `rocksdb_max_background_compactions` и скорость диска. |
