# Установка и начало работы с MySQL

## Определения

- **`mysql-server`**: Пакет серверной части MySQL — системная служба `mysqld` для управления БД.
- **`mysql`**: Консольный клиент для интерактивного взаимодействия с сервером MySQL.

## Базовые концепции

### Клиент-серверная модель

MySQL работает как фоновый процесс-сервер (`mysqld`), принимающий и обрабатывающий запросы. Пользователи взаимодействуют через клиентские утилиты, основная из которых — `mysql`.

### Безопасность установки

После установки сервер имеет небезопасные настройки по умолчанию (анонимные пользователи, пустые пароли для `root`). Требуется запуск скрипта `mysql_secure_installation` для устранения уязвимостей. Подробности — в [руководстве по безопасной установке SQL-сервера](../installation_security.md).

## Практические сценарии

### Установка на Debian/Ubuntu

```bash
# Установка сервера
sudo apt -y install mysql-server

# Проверка статуса службы
# (в RedHat/CentOS служба может называться mysqld)
sudo systemctl status mysql
```

### Начальная настройка безопасности

Запустите скрипт `mysql_secure_installation` для задания пароля `root`, удаления анонимных пользователей и тестовой БД:

```bash
sudo mysql_secure_installation
```

Подробное описание процесса — в [руководстве по безопасной установке](../installation_security.md).

### Базовые операции в клиенте `mysql`

**Подключение к серверу:**

```bash
# Локальное подключение от имени текущего пользователя
mysql

# Подключение под определенным пользователем (запросит пароль)
mysql -u <username> -p
```

**Работа с базами данных и таблицами:**

```sql
-- Показать все базы данных
SHOW DATABASES;

-- Выбрать базу данных
USE <database_name>;

-- Показать таблицы
SHOW TABLES;
```

**Выход из клиента:**

```sql
EXIT;
-- или
QUIT;
```
