# Установка и начало работы с MySQL

### Определения

-   **`mysql-server`**: Пакет, содержащий серверную часть MySQL — системную службу (`mysqld`), которая управляет базами данных.
-   **`mysql`**: Консольный клиент, утилита для интерактивного взаимодействия с сервером MySQL.

### Базовые концепции

#### 1. Клиент-серверная модель

MySQL функционирует как фоновый процесс-сервер (`mysqld`), который принимает, обрабатывает и отдает данные. Пользователи и приложения взаимодействуют с сервером через клиентские утилиты, основной из которых является `mysql`.

#### 2. Безопасность установки

Сразу после установки сервер MySQL имеет небезопасные настройки по умолчанию (например, анонимные пользователи или пустые пароли для `root`). Первоочередной задачей является запуск скрипта безопасности для устранения этих уязвимостей.

### Практические сценарии

#### 1. Установка на Debian/Ubuntu

```bash
# Установка пакета сервера
sudo apt -y install mysql-server

# Проверка статуса службы
# (в системах на базе RedHat/CentOS служба может называться mysqld)
sudo systemctl status mysql
```

#### 2. Начальная настройка безопасности

После установки необходимо запустить скрипт `mysql_secure_installation` для задания пароля `root`, удаления анонимных пользователей и тестовой базы данных.

> **Важно:** Подробное описание процесса и рекомендации по защите доступны в отдельной заметке.
> 
> **См. → [[SQL/installation_security|Безопасная установка SQL-сервера]]**

#### 3. Базовые операции в клиенте `mysql`

-   **Подключение к серверу:**
    ```bash
    # Подключиться к локальному серверу от имени текущего пользователя Linux
    mysql
    
    # Подключиться под определенным пользователем (запросит пароль)
    mysql -u <username> -p
    ```

-   **Работа с базами данных и таблицами:**
    ```sql
    -- Показать все базы данных
    SHOW DATABASES;
    
    -- Выбрать базу данных для работы
    USE <database_name>;
    
    -- Показать таблицы в текущей базе данных
    SHOW TABLES;
    ```

-   **Выход из клиента:**
    ```sql
    EXIT;
    -- или
    QUIT;
    ```
