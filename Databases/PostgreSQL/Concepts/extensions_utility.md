# Вспомогательные расширения PostgreSQL

## uuid-ossp
Расширение для генерации универсальных уникальных идентификаторов (UUID).
- **Зачем:** Исключает возможность конфликта идентификаторов при копировании, объединении или масштабировании баз данных. Критически важно для распределенных систем.
- **Преимущество:** Упрощает разработку, избавляя от необходимости ручной проверки уникальности ID при слиянии данных из разных источников.

## pgcrypto
Мощное расширение для выполнения криптографических операций (хеширование, шифрование, генерация случайных данных) непосредственно в SQL.

**Основные возможности:**
- **Шифрование данных:** Поддержка AES-256 (симметричное) и PGP (асимметричное). Позволяет защищать чувствительные поля (номера карт, ПДн) в состоянии покоя.
- **Хранение паролей:** Специализированные функции `crypt()` и `gen_salt()` реализуют алгоритм **bcrypt**, устойчивый к перебору.
- **Случайные данные:** Генерация криптографически стойких байтов и UUID v4.

**Безопасность:** Рекомендуется установка в отдельную схему (`crypto`) с ограничением прав доступа. Ключи шифрования должны храниться вне БД (в KMS или переменных окружения).

Подробнее: **[Руководство по pgcrypto](./pgcrypto.md)**.

## citext
Тип данных для регистронезависимых текстовых строк.
- **Зачем:** Упрощает работу с данными, где регистр не имеет значения (например, электронные адреса или логины).
- **Преимущество:** Избавляет от необходимости постоянно использовать функции `lower()` в условиях `WHERE`, что делает код чище и снижает риск ошибок.
