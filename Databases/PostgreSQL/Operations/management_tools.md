# Инструменты управления PostgreSQL

## Определения

**Инструменты управления PostgreSQL** — это набор программных средств (CLI, TUI, GUI, Web) для администрирования, мониторинга, отладки и разработки баз данных PostgreSQL.

**Ключевые категории:**

- **CLI (Command Line Interface):** Стандартные утилиты командной строки (например, `psql`).
- **TUI (Terminal User Interface):** Интерактивные консольные инструменты для мониторинга в реальном времени (`pg_activity`, `pgcenter`).
- **GUI (Graphical User Interface):** Полнофункциональные графические клиенты для разработки и дизайна (`pgAdmin`, `DBeaver`).
- **Web-интерфейсы:** Легковесные инструменты для доступа через браузер, часто используемые в Docker-средах (`pgweb`).

## Предпосылки

Для работы с инструментами управления требуются:

1.  **Сетевой доступ:** Открытый порт (по умолчанию 5432) или настроенный SSH-туннель до сервера БД.
2.  **Конфигурация доступа:** Разрешение в `pg_hba.conf` для IP-адреса администратора и корректный метод аутентификации (`scram-sha-256`).
3.  **Права доступа:** Учетная запись с ролью `pg_monitor` (для TUI/мониторинга) или правами владельца БД (для GUI/разработки).
4.  **Среда исполнения:** Установленный JRE (для DBeaver) или браузер (для pgAdmin Server/pgweb).

## Основные концепции

### Выбор инструмента по сценарию

| Сценарий | Рекомендуемый инструмент | Особенности |
| :--- | :--- | :--- |
| Быстрая отладка на сервере | **[psql](./console_basics.md)** | Всегда доступен, минимальные накладные расходы. |
| Мониторинг "живой" нагрузки | **pg_activity** / **pgcenter** | Визуализация процессов, блокировок и I/O в консоли. |
| Проектирование и разработка | **DBeaver** / **DataGrip** | Визуализация схем, автодополнение, работа с множеством СУБД. |
| Облачное управление (K8s) | **kubectl cnpg** | Управление жизненным циклом через оператор. |

## Практические сценарии

### pgAdmin 4 — универсальный GUI

Самое популярное графическое средство, поставляется в настольной и серверной (Web) версиях.

#### Установка в Ubuntu/Debian
```bash
# Добавление репозитория
curl -fsS https://www.pgadmin.org/static/packages_pgadmin_org.pub | sudo gpg --dearmor -o /usr/share/keyrings/packages-pgadmin-org.gpg
sudo sh -c 'echo "deb [signed-by=/usr/share/keyrings/packages-pgadmin-org.gpg] https://ftp.postgresql.org/pub/pgadmin/pgadmin4/apt/$(lsb_release -cs) pgadmin4 main" > /etc/apt/sources.list.d/pgadmin4.list && apt update'

# Установка (desktop-версия)
sudo apt install pgadmin4-desktop
```

#### Управление ролями
1. В дереве объектов: **Server** → **Login/Group Roles** → **Create**.
2. Вкладка **Privileges**: Настройка прав на вход (`Login?`), создание БД, статус суперпользователя.
3. Вкладка **Membership**: Наследование системных ролей (например, `pg_monitor`).

### Терминальные интерфейсы (TUI)

#### pg_activity
Аналог утилиты `top` для PostgreSQL. Позволяет мониторить активные сессии, ожидания (Wait Events) и нагрузку на диск.
- **Установка:** `sudo apt install pg-activity`
- **Запуск:** `pg_activity -U postgres`
- **Ключевые функции:** Сортировка по CPU/Mem, завершение запросов (Kill), отображение блокировок.

#### pgcenter
Более мощный инструмент для анализа статистики из системных представлений `pg_stat_*`.
- **Особенности:** Отображение статистики по таблицам, индексам, функциям и репликации в реальном времени.

### Профессиональные IDE и клиенты

- **DBeaver Community**:
  - Поддержка NoSQL (MongoDB, Redis) и классических SQL.
  - Мощный визуальный конструктор запросов и ER-диаграмм.
  - Встроенный редактор данных с поддержкой экспорта в 10+ форматов.
- **DataGrip (JetBrains)**:
  - Лучшее в классе автодополнение и инспекция кода.
  - Глубокая интеграция с системами контроля версий (Git).
  - Инструменты рефакторинга SQL-схем.

### Веб-интерфейсы

- **pgweb**: Современный, сверхлегкий (один бинарный файл на Go) просмотрщик БД. Идеален для быстрого развертывания в Docker-окружении.
- **pglite (Modern)**: Использование PostgreSQL прямо в браузере (через WASM) для тестирования и песочниц.

### Облачное управление (Kubernetes)

При использовании **CloudNativePG** управление выполняется через плагин `cnpg` для `kubectl`. Подробнее — **[PostgreSQL в Kubernetes](./kubernetes_deployment.md)**.

```bash
# Проверка состояния кластера
kubectl cnpg status cluster-name

# Переключение мастера (Switchover)
kubectl cnpg switchover cluster-name --target pg-node-2
```

## Валидация и проверка

Для проверки работоспособности выбранного инструмента выполните следующие шаги:

1.  **Тест соединения:** Убедитесь, что инструмент подключается к БД без ошибок `Connection Refused`.
2.  **Проверка прав:** Выполните простой запрос (например, `SELECT 1;`), чтобы убедиться в наличии прав на выполнение команд.
3.  **Проверка инспекции:** Попробуйте раскрыть дерево таблиц (в GUI) или выполнить `\dt` (в psql).

## Устранение неполадок

| Ошибка | Возможная причина | Решение |
| :--- | :--- | :--- |
| **Connection Refused** | Сервер не слушает порт или закрыт Firewall. | Проверьте `listen_addresses` в `postgresql.conf` и настройки `ufw`/`iptables`. |
| **FATAL: no pg_hba.conf entry** | Доступ для данного IP или пользователя не разрешен. | Добавьте запись в `pg_hba.conf` и выполните `SELECT pg_reload_conf();`. |
| **SSH Tunnel Failed** | Некорректные ключи или запрет форвардинга портов. | Проверьте `AllowTcpForwarding yes` в `/etc/ssh/sshd_config` на сервере. |
| **Slow GUI Refresh** | Огромное количество объектов (таблиц/схем) в БД. | В настройках DBeaver/pgAdmin включите фильтрацию схем (Connection Filters). |
