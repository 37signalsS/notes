# Основы работы с PostgreSQL через консоль (psql)

## Определения

**psql** — интерактивный терминальный клиент для PostgreSQL, позволяющий вводить SQL-запросы, отправлять их на сервер и просматривать результаты.

## Основные концепции

### Синтаксис команд psql

- **SQL-команды** заканчиваются точкой с запятой `;`
- **Мета-команды psql** начинаются с обратной косой черты `\` и не требуют `;`
- Для выхода из psql используйте `\q`

### Подключение к серверу

Формат подключения:

```bash
psql -U <пользователь> -h <хост> -p <порт> -d <база_данных>
```

Стандартное подключение к локальному серверу от имени суперпользователя:

```bash
sudo -u postgres psql
```

## Практические сценарии

### Основные мета-команды psql

#### Справочная информация

- `\?` — справка по всем мета-командам
- `\h <команда>` — справка по SQL-команде (например, `\h SELECT`)

#### Подключение и информация о сессии

- `\c <база> <пользователь>` — подключиться к другой базе данных
- `\conninfo` — показать параметры текущего подключения
- `\q` — выход из psql

#### Просмотр объектов базы данных

- `\l` или `\list` — список всех баз данных
- `\dt` — список таблиц в текущей схеме
- `\dt+` — список таблиц с размером и описанием
- `\dv` — список представлений (views)
- `\df` — список функций
- `\du` — список ролей и их привилегий
- `\dn` — список схем

#### Описание структуры объектов

- `\d <таблица>` — описание таблицы (столбцы, типы, индексы)
- `\d+ <таблица>` — расширенное описание таблицы
- `\d <последовательность>` — описание sequence
- `\d <индекс>` — описание индекса

#### Работа с выводом

- `\x` или `\xauto` — переключение в расширенный формат вывода (вертикальный)
- `\a` — переключение между выравниваем и невыравниваем выводом
- `\t` — показывать только данные (без заголовков)
- `\o <файл>` — перенаправление вывода в файл
- `\o` — сброс перенаправления (вывод в терминал)

#### Прочие полезные команды

- `\timing` — включить/выключить отображение времени выполнения запросов
- `\e` — редактировать предыдущий запрос во внешнем редакторе
- `\s <файл>` — сохранить историю команд в файл
- `\i <файл>` — выполнить SQL-скрипт из файла
- `\copy` — импорт/экспорт данных (работает на стороне клиента)

### Базовые операции с базой данных

#### Создание базы данных

```sql
CREATE DATABASE super_heroes;
```

#### Создание роли (пользователя)

```sql
CREATE USER hero_admin WITH PASSWORD 'qwerty';
```

> **Примечание:** В PostgreSQL нет разделения на пользователей и группы — все сущности являются ролями. Подробнее о системе ролей см. **[PostgreSQL: Обзор](../overview.md#основные-концепции)**.

#### Предоставление привилегий

```sql
-- Привилегии на базу данных
GRANT ALL PRIVILEGES ON DATABASE super_heroes TO hero_admin;

-- Привилегии на схему
GRANT ALL ON SCHEMA public TO hero_admin;

-- Привилегии на таблицу
GRANT SELECT, INSERT, UPDATE, DELETE ON TABLE hera_list TO hero_admin;

-- Привилегии на последовательность
GRANT USAGE, SELECT ON SEQUENCE hera_list_id_seq TO hero_admin;
```

#### Создание таблицы

```sql
CREATE TABLE hera_list (
    id SERIAL PRIMARY KEY,
    name CHARACTER VARYING(20),
    s_name CHARACTER VARYING(20),
    age INT
);
```

#### Вставка данных

```sql
INSERT INTO hera_list VALUES (1, 'Peter', 'Parker', 22);
INSERT INTO hera_list VALUES (2, 'Batman', 'Arkham', 40);

-- Вставка с указанием столбцов
INSERT INTO hera_list (name, s_name, age) VALUES ('Tony', 'Stark', 35);
```

#### Выборка данных

```sql
-- Все столбцы
SELECT * FROM hera_list;

-- Конкретные столбцы
SELECT name, age FROM hera_list;

-- С условием
SELECT * FROM hera_list WHERE age > 30;

-- С сортировкой
SELECT * FROM hera_list ORDER BY age DESC;
```

### Пример рабочей сессии

```bash
# 1. Подключение к серверу
sudo -u postgres psql

# 2. Создание базы данных
psql=# CREATE DATABASE super_heroes;

# 3. Создание пользователя
psql=# CREATE USER hero_admin WITH PASSWORD 'qwerty';

# 4. Предоставление прав
psql=# GRANT ALL PRIVILEGES ON DATABASE super_heroes TO hero_admin;

# 5. Выход из psql
psql=# \q

# 6. Подключение к новой базе от имени нового пользователя
psql -U hero_admin -h localhost -d super_heroes

# 7. Проверка подключения
super_heroes=> \conninfo
```

## Дополнительная информация

### Транзакции в psql

psql поддерживает работу с транзакциями:

```sql
-- Начало явной транзакции
BEGIN;

-- Выполнение операций
UPDATE hera_list SET age = 23 WHERE name = 'Peter';
DELETE FROM hera_list WHERE id = 2;

-- Фиксация изменений
COMMIT;

-- Или откат изменений
ROLLBACK;
```

Подробнее о свойствах ACID и уровнях изоляции см. **[Управление параллелизмом](../Concepts/concurrency_and_locking.md)**.
