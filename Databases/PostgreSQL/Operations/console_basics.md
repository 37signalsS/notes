# Основы работы с PostgreSQL через консоль (psql)

## Определения

* **psql:** Интерактивный терминальный клиент для PostgreSQL, позволяющий вводить запросы, отправлять их на сервер PostgreSQL и просматривать результаты.

## Основные концепции

* **Роли (Roles):** В PostgreSQL нет разделения на пользователей и группы. Все сущности, которые могут владеть объектами базы данных и имеют права доступа, называются ролями.
* **Базы данных (Databases):** Изолированные контейнеры для таблиц, представлений, функций и других объектов.
* **Таблицы (Tables):** Структурированные хранилища данных, состоящие из строк и столбцов.
* **Привилегии (Privileges):** Разрешения, определяющие, какие действия может выполнять роль над определенными объектами базы данных.

## Практические сценарии

### Работа с PostgreSQL из консоли (psql)

Этот раздел демонстрирует базовые операции по управлению PostgreSQL через интерактивный клиент `psql`, включая создание базы данных, пользователей, назначение прав и работу с таблицами.

#### 1. Подключение к psql как пользователь `postgres`

Для начала работы необходимо подключиться к `psql` от имени суперпользователя `postgres`:

```bash
sudo -u postgres psql
```

В консоли `psql` команды заканчиваются точкой с запятой `;`.

#### 2. Создание базы данных

Создание новой базы данных с именем `super_heroes`:

```sql
CREATE DATABASE super_heroes;
```

#### 3. Создание пользователя (роли)

Создание новой роли `hero_admin` с паролем `qwerty`:

```sql
CREATE USER hero_admin WITH PASSWORD 'qwerty';
```

#### 4. Предоставление привилегий пользователю на базу данных

Предоставление всех привилегий роли `hero_admin` на базу данных `super_heroes`:

```sql
GRANT ALL PRIVILEGES ON DATABASE super_heroes TO hero_admin;
```

#### 5. Выход из текущей сессии psql

Для выхода используйте:

```sql
\q
```

#### 6. Подключение к созданной базе данных от имени нового пользователя

Подключение к базе данных `super_heroes` как пользователь `hero_admin` на `localhost`:

```bash
psql -U hero_admin -h localhost -d super_heroes
```

#### 7. Проверка информации о текущем подключении

Внутри `psql` можно проверить детали текущего подключения:

```sql
\conninfo
```

#### 8. Создание таблицы

Создание таблицы `hera_list` со столбцами `id`, `name`, `s_name` и `age`:

```sql
CREATE TABLE hera_list (
    id SERIAL PRIMARY KEY,
    name CHARACTER VARYING(20),
    s_name CHARACTER VARYING(20),
    age INT
);
```

#### 9. Вставка данных в таблицу

Вставка двух строк данных в таблицу `hera_list`:

```sql
INSERT INTO hera_list VALUES (1, 'Peter', 'Parker', 22);
INSERT INTO hera_list VALUES (2, 'Batman', 'Arkham', 40);
```

#### 10. Выборка данных из таблицы

* Выборка всех столбцов из таблицы `hera_list`:

    ```sql
    SELECT * FROM hera_list;
    ```

* Выборка определенных столбцов (например, `name` и `age`) из таблицы `hera_list`:

    ```sql
    SELECT name, age FROM hera_list;
    ```
