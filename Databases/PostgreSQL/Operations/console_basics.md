# Работа с PostgreSQL через консоль (psql)

## Определения

**psql** — интерактивный терминальный клиент для PostgreSQL, основной инструмент администратора и разработчика для выполнения SQL-запросов и управления сервером из командной строки.

## Основные концепции

### Синтаксис и режимы работы

- **SQL-команды:** стандартные SQL-инструкции, всегда заканчиваются точкой с запятой `;`.
- **Мета-команды (Backslash commands):** специальные команды psql, начинаются с `\` и выполняются немедленно без `;`.
- **Интерактивный режим:** работа в консоли с получением немедленного ответа.
- **Пакетный режим:** выполнение скриптов через ключ `-f` или перенаправление ввода.

### Подключение к серверу

Базовый формат команды:
```bash
psql -h <хост> -p <порт> -U <пользователь> -d <база_данных>
```

**Способы аутентификации без ручного ввода пароля:**
1. **Файл `.pgpass`:** (рекомендуется) файл в домашней директории пользователя с правами `0600`. Формат: `hostname:port:database:username:password`.
2. **Переменная окружения `PGPASSWORD`:** (менее безопасно) пароль передается в открытом виде в окружение процесса.
3. **Peer-аутентификация:** (для локальных подключений в Linux) psql использует имя системного пользователя. 
   ```bash
   sudo -u postgres psql
   ```

## Практические сценарии

### Полезные мета-команды psql

#### Навигация и информация
- `\l` — список всех баз данных.
- `\c <db_name>` — переключение на другую базу данных.
- `\dn+` — список схем с указанием владельцев и прав доступа.
- `\conninfo` — параметры текущего соединения.

#### Исследование структуры (Introspection)
- `\dt+` — список таблиц с описанием и размером на диске.
- `\d <object>` — подробное описание таблицы, индекса, представления или последовательности.
- `\dv` — список представлений (views).
- `\df+` — список функций с исходным кодом.
- `\du+` — список ролей (пользователей) и их атрибутов.

#### Расширенное управление выводом
- `\x` — переключение в вертикальный режим вывода (удобно для широких таблиц).
- `\timing` — включение замера времени выполнения каждого запроса.
- `\watch <секунды>` — автоматическое повторение последнего запроса через интервал (мониторинг в реальном времени).
- `\pset format <csv/html/latex>` — изменение формата вывода данных.

#### Работа с файлами и редактором
- `\i <file_path>` — выполнение SQL-команд из внешнего файла.
- `\copy ...` — импорт/экспорт данных в CSV. Выполняется **от имени клиента** (не требует прав суперпользователя на сервере, в отличие от SQL-команды `COPY`).
- `\e` — открытие текущего буфера запроса во внешнем редакторе (определяется переменной `EDITOR`).
- `\gexec` — выполнение результата предыдущего запроса как набора SQL-команд (мета-программирование).

### Управление доступом и ролями

В PostgreSQL пользователи и группы объединены в понятие **Роль**.

```sql
-- Создание роли с правом входа (аналог пользователя)
CREATE USER dev_user WITH PASSWORD 'secure_pass';

-- Создание роли без права входа (аналог группы)
CREATE ROLE read_only_group;

-- Наследование прав
GRANT read_only_group TO dev_user;

-- Управление правами на объекты
GRANT USAGE ON SCHEMA public TO dev_user;
GRANT SELECT ON ALL TABLES IN SCHEMA public TO dev_user;
```

### Примеры часто используемых запросов

**Размер базы данных и таблиц:**
```sql
-- Размер текущей БД
SELECT pg_size_pretty(pg_database_size(current_database()));

-- Топ-10 таблиц по размеру
SELECT relname AS "Table", 
       pg_size_pretty(pg_total_relation_size(relid)) AS "Size"
FROM pg_catalog.pg_statio_user_tables 
ORDER BY pg_total_relation_size(relid) DESC 
LIMIT 10;
```

**Поиск активных сессий и блокировок:**
```sql
-- Посмотреть текущие запросы
SELECT pid, state, query, wait_event_type, wait_event 
FROM pg_stat_activity 
WHERE state != 'idle';

-- Принудительное завершение сессии
SELECT pg_terminate_backend(<pid>);
```

## Дополнительная информация

### Настройка psqlrc

Вы можете настроить psql под себя, создав файл `~/.psqlrc`. Полезные настройки:
```sql
\set PROMPT1 '%n@%m:%>%p/%/ %R%# ' -- Кастомизация приглашения
\pset null '[NULL]'              -- Наглядное отображение NULL
\timing on                       -- Всегда показывать время выполнения
```

### Переменные окружения

| Переменная | Описание |
| :--- | :--- |
| `PGHOST` | Хост сервера по умолчанию |
| `PGPORT` | Порт сервера (обычно 5432) |
| `PGUSER` | Имя пользователя для подключения |
| `PGDATABASE` | База данных по умолчанию |
| `EDITOR` | Редактор для команды `\e` (например, `vim` или `nano`) |
