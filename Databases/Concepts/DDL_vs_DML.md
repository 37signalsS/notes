# DDL vs DML: В чем разница между TRUNCATE, DELETE и DROP?

> **Важно:** От базы к базе поведение данных операций может отличаться.

## Определения

-   **DDL (Data Definition Language)** - язык определения данных. Операции изменяют структуру базы данных (`CREATE`, `ALTER`, `DROP`, `TRUNCATE`).
-   **DML (Data Manipulation Language)** - язык манипулирования данными. То есть работают с содержимым таблиц (`SELECT`, `INSERT`, `UPDATE`, `DELETE`).

Основное отличие в том, что DDL работают со структурой базы данных и обычно необратимы. А DML операции работают с данными внутри таблиц и могут быть отменены до подтверждения транзакции.

## Сравнение операций

### DROP

-   **Тип:** DDL (Data Definition Language)
-   **Действие:** Удаляет всю структуру таблицы (или другого объекта БД, например, индекса).
-   **Последствия:** Вместе с таблицей удаляются все ее данные, индексы, ограничения, триггеры. Функции и хранимые процедуры, которые зависят от таблицы, остаются, но становятся недействительными.
-   **Обратимость:** Операция необратимая.
-   **Аналогия:** Снести целый дом.

### TRUNCATE

-   **Тип:** DDL (Data Definition Language)
-   **Действие:** Удаляет **все** данные из таблицы, но оставляет саму структуру таблицы.
-   **Производительность:** Работает очень быстро, так как не ведет подробный лог для отката каждой строки.
-   **Блокировки:** На время выполнения блокирует всю таблицу.
-   **Обратимость:** Операция необратимая.
-   **Аналогия:** Выбросить все содержимое дома, но оставить сам дом.

### DELETE

-   **Тип:** DML (Data Manipulation Language)
-   **Действие:** Удаляет данные из таблицы. Можно удалить строки по условию (`WHERE`) или все строки (если условие не указано).
-   **Производительность:** Работает медленнее, чем `TRUNCATE`, поскольку записывает информацию для отката в лог транзакций для каждой удаленной строки.
-   **Блокировки:** Блокирует только удаляемые строки, а не всю таблицу.
-   **Обратимость:** Операция откатываемая (можно отменить с помощью `ROLLBACK`).
-   **Аналогия:** Выбросить какие-то отдельные вещи из дома.
