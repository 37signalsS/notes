# Neo4j: Кластеризация и высокая доступность

## Neo4j Causal Clustering (Enterprise Edition)

Архитектура **Core** (Raft consensus):
- **Core Servers** (минимум 3): голосующие участники, обеспечивающие согласованность (Linearizable reads и Writes).
- **Read Replicas** (опционально): копии данных для распределения нагрузки чтения.

**Протоколы:**
- **Raft:** consensus для Core серверов. Гарантирует, что запись подтверждена большинством.
- **Bolt Routing:** клиенты подключаются через `neo4j://` URI, маршрутизатор направляет writes на Core и reads на Read Replicas.
