# YugabyteDB: Обзор

YugabyteDB — это высокопроизводительная, облачно-ориентированная (cloud-native) распределенная SQL база данных. Она разработана для обеспечения горизонтальной масштабируемости, отказоустойчивости и географического распределения данных.

## Ключевые особенности

- **Совместимость с PostgreSQL:** YugabyteDB полностью совместима с PostgreSQL на уровне запросов. Это означает, что можно использовать существующие приложения, драйверы и инструменты, разработанные для PostgreSQL, без изменений.
- **Горизонтальное масштабирование:** Как и другие распределенные СУБД, YugabyteDB позволяет легко масштабироваться, добавляя новые узлы в кластер.
- **Распределенные транзакции:** Поддерживает глобальные ACID-транзакции, обеспечивая целостность данных в распределенной среде.
- **Гибкое партиционирование:** Поддерживает как хеш-партиционирование (`PARTITION BY HASH`), так и партиционирование по диапазону (`PARTITION BY RANGE`), что позволяет гибко распределять данные по узлам кластера.
- **Высокая доступность:** Обеспечивает отказоустойчивость за счет автоматической репликации данных между узлами.
