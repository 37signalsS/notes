# Безопасная установка SQL-сервера

### Основные концепции

После первичной установки SQL-сервера (например, MariaDB или MySQL) критически важно выполнить базовую настройку безопасности. Это включает в себя удаление стандартных уязвимостей и повышение общей защищенности системы.

### Практические сценарии

Большинство SQL-серверов предоставляют встроенный инструмент для начальной настройки безопасности. Для MariaDB и MySQL таким инструментом является утилита `mysql_secure_installation`.

**Использование `mysql_secure_installation`:**

Запуск утилиты:
```bash
mysql_secure_installation
```

Утилита последовательно предложит настроить следующие параметры:

*   **Настройка проверки надежности паролей (VALIDATE PASSWORD COMPONENT):** Позволяет установить требования к сложности паролей для пользователей базы данных.
*   **Изменение пароля для пользователя `root`:** Установка надежного пароля для административного пользователя `root`.
*   **Удаление анонимных пользователей:** Удаление учетных записей, которые могут быть использованы для доступа без явных учетных данных.
*   **Отключение удаленного доступа для пользователя `root`:** Запрет подключения пользователя `root` к базе данных извне локальной машины для повышения безопасности.
*   **Удаление тестовой базы данных и доступов к ней:** Удаление демонстрационной базы данных, которая по умолчанию доступна для всех и может представлять угрозу безопасности.
*   **Перезагрузка таблиц привилегий:** Применение всех внесенных изменений в системе привилегий для немедленного вступления в силу.

**Рекомендации:**

*   Всегда устанавливайте надежный пароль для пользователя `root`.
*   Отключайте анонимных пользователей.
*   Ограничивайте удаленный доступ для `root` только при явной необходимости и через защищенные каналы.
*   Удаляйте тестовые базы данных.
