# TimescaleDB

## Определения

**TimescaleDB** — это расширение (extension) для PostgreSQL, которое превращает его в полноценную базу данных временных рядов (time-series database). Оно оптимизировано для хранения и анализа данных, привязанных ко времени, таких как метрики мониторинга, данные с IoT-устройств, финансовые данные и т.д.

## Основные концепции

### Архитектура: Гипертаблицы и Чанки

Основная концепция TimescaleDB — это **гипертаблицы (Hypertables)**.

-   **Гипертаблица** — это абстракция над множеством обычных таблиц PostgreSQL, называемых **чанками (chunks)**.
-   Для пользователя гипертаблица выглядит как единая, обычная таблица.
-   TimescaleDB автоматически партиционирует (разбивает) данные по времени (и, опционально, по другим ключам, например, ID устройства) на эти чанки. Каждый чанк — это отдельная дочерняя таблица.

Такой подход сочетает простоту работы с единой таблицей и преимущества партиционирования для производительности.

### Ключевые особенности

-   **Оптимизация для временных рядов:** Специализированные функции и оптимизации для быстрого выполнения запросов по временным данным.
-   **Автоматическое партиционирование:** TimescaleDB автоматически создает и управляет партициями (чанками) по времени, избавляя от необходимости делать это вручную.
-   **Полная совместимость с SQL:** Поскольку это расширение, TimescaleDB поддерживает полный синтаксис SQL и всю экосистему PostgreSQL.
-   **Горизонтальное масштабирование:** Поддерживает распределение данных по нескольким узлам для масштабирования хранения и производительности.
-   **Гибкое разбиение:** Позволяет создавать партиции не только по времени, но и по другим измерениям (например, `PARTITION BY (time_column, device_id)`).
