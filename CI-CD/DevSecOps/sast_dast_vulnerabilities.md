# Уязвимости SAST и DAST

## Определения

**SAST** и **DAST** специализируются на разных типах уязвимостей из-за различий в подходах: SAST анализирует исходный код, DAST — поведение работающего приложения.

## Основные концепции

### Уязвимости, обнаруживаемые SAST

Статический анализ просматривает код и конфигурации, выстраивая цепочки «источник → преобразование → приёмник».

**Характерные находки:**

- **Инъекции:**
  - **SQL Injection:** Конкатенация строк в запросах.
  - **Command Injection:** Передача пользовательского ввода в системные команды.
  - **LDAP/NoSQL Injection:** Составление запросов из неконтролируемых данных.
- **XSS в шаблонах:** Неэкранированные вставки в HTML/JS.
- **Небезопасная десериализация:** Использование небезопасных десериализаторов.
- **Path traversal:** Использование `../` в путях, небезопасные загрузки файлов.
- **Секреты в коде:** Хардкод токенов, ключей, паролей.
- **Криптографические ошибки:** MD5/SHA-1, отсутствие соли, фиксированные IV.
- **Уязвимости авторизации:** Пропуск проверок прав доступа.

### Уязвимости, обнаруживаемые DAST

Динамический анализ взаимодействует с работающим приложением через входные точки, заголовки и ответы.

**Характерные находки:**

- **XSS (отражённый и хранимый):** Внедрение скриптов в параметры и поля форм.
- **CSRF:** Отсутствие анти-CSRF токенов.
- **Уязвимости аутентификации и сессий:** Слабые политики паролей, фиксация сессии, отсутствие флагов `HttpOnly`/`Secure`.
- **Открытые редиректы:** Перенаправления через параметры URL.
- **Небезопасные заголовки:** Отсутствие HSTS, CSP, X-Frame-Options.
- **Утечки информации:** Листинг директорий, избыточные сообщения об ошибках.
- **SSRF:** Запросы к внутренним ресурсам.
- **Ошибки конфигурации CORS:** Доверие к произвольным Origin.

## Практические сценарии

### Сопоставление уязвимостей по инструментам

| Уязвимость | Пример | Инструмент обнаружения |
| :--- | :--- | :--- |
| **SQL Injection** | Конкатенация запросов | SAST, DAST (SAST быстрее) |
| **Command Injection** | `os.system()`/`Runtime.exec()` | SAST |
| **XSS** | Отражённый через параметр | SAST, DAST (DAST подтверждает эксплуатацию) |
| **CSRF** | Отсутствие токенов | DAST |
| **Небезопасные заголовки** | Отсутствие HSTS/CSP | DAST |
| **Небезопасная десериализация** | Небезопасные декодеры | SAST |
| **Секреты в коде** | API-ключи, токены | SAST |
| **Path Traversal** | `../` в путях к файлам | SAST, DAST |
| **SSRF** | Запросы к внутренним хостам | DAST |
| **Ошибки авторизации** | Пропуск проверки ролей в коде | SAST |

### Пример: Command Injection (Python)

```python
# Уязвимо
host = request.args.get("host")
os.system("ping -c 1 " + host) # host может быть "google.com; rm -rf /"
```

```python
# Безопасно
host = request.args.get("host")
subprocess.run(["ping", "-c", "1", host], check=True)
```

## Дополнительная информация

### Нюансы обнаружения

- **SAST:** Склонен к ложноположительным срабатываниям (не видит контекст выполнения), но незаменим для поиска уязвимостей в логике и неактивном коде.
- **DAST:** Подтверждает реальную эксплуатацию, находит ошибки конфигурации окружения, но может пропустить уязвимости в скрытых эндпоинтах.
- **Комбинирование:** Наиболее эффективная стратегия — покрывает как ошибки реализации, так и дефекты конфигурации.
