# GitLab CI: Каталог Компонентов — Определения

> **SSoT:** [GitLab CI: Каталог Компонентов (CI/CD Catalog)](./ci_cd_catalog_components.md)

## Definitions

**CI/CD Catalog (Components)** — современный подход GitLab к переиспользованию конфигураций, позволяющий создавать версионируемые, типизированные и публикуемые в общем каталоге компоненты — полноценные, изолированные блоки CI/CD логики с явным интерфейсом (`spec:inputs`). Полное описание — в [SSoT](./ci_cd_catalog_components.md#определения).

**Компонент** — YAML-файл (или директория) в репозитории, содержащий конфигурацию GitLab CI с метаданными `spec:inputs` для определения входных параметров. Детали архитектуры — в [SSoT](./ci_cd_catalog_components.md#архитектура-компонента).

**`spec:inputs`** — схема входных параметров компонента, определяющая типы, значения по умолчанию и валидацию через regex. Синтаксис описан в [SSoT](./ci_cd_catalog_components.md#синтаксис-specinputs).

**Интерполяция** — механизм подстановки значений параметров через синтаксис `$[[ inputs.<name> ]]`. Примеры использования — в [SSoT](./ci_cd_catalog_components.md#интерполяция-переменных).
