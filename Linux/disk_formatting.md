## Определение диска

Используйте команду `lsblk`, чтобы увидеть список всех блочных устройств.

```bash
lsblk
```

Найдите в списке нужный диск (например, `/dev/sdb`). 

## Форматирование диска

**ВНИМАНИЕ:** Следующая команда уничтожит все данные на указанном диске. Убедитесь, что вы выбрали правильное устройство.

Отформатируем диск в файловую систему `ext4`. Мы также зададим метку (`LABEL`) с помощью флага `-L`, что может быть полезно для идентификации.

```bash
mkfs.ext4 -L data /dev/sdb
```

*   `-L data`: Задаёт метку `data`. Вы можете выбрать любую другую.
*   `/dev/sdb`: Устройство, которое вы форматируете.
*   Если нужна другая файловая система (например, XFS), используйте `mkfs.xfs`.

## Создание точки монтирования

Создайте каталог, куда будет монтироваться диск.

```bash
sudo mkdir /data
```

## Настройка автоматического монтирования через `/etc/fstab`

Чтобы диск монтировался автоматически при каждой загрузке системы, нужно добавить запись в файл `/etc/fstab`. Самый надёжный способ — использовать **UUID** диска.

1.  **Получение UUID:**
    Узнайте UUID вашего нового отформатированного раздела:
    ```bash
    blkid /dev/sdb
    ```

2.  **Добавьте запись в `/etc/fstab`**.
    Подробное описание структуры файла `/etc/fstab` и всех его опций находится в документе [о файловой системе](./file_system.md#Файл-etcfstab).

3.  **Примените изменения и проверьте монтирование:**
    ```bash
    sudo mount -a
    df -hT /data
    ```
