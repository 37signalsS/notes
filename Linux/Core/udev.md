# Udev

## Определения

**udev** — это подсистема в ядре Linux, которая отвечает за динамическое управление файлами устройств в директории `/dev`. Она автоматически создаёт и удаляет ноды устройств при их подключении или отключении от системы.

**Основные функции udev:**

-   Создание и удаление файлов устройств.
-   Присвоение постоянных имён устройствам.
-   Изменение прав доступа и владельца для файлов устройств.
-   Запуск скриптов или программ при подключении/отключении устройства.

## Основные концепции

### Правила `udev`

Поведение `udev` настраивается с помощью правил, которые хранятся в файлах с расширением `.rules` в директории `/etc/udev/rules.d/`.

**Синтаксис правила:**

1.  **Условия совпадения (match keys):** Определяют, к какому устройству или событию применяется правило (например, `SUBSYSTEM`, `KERNEL`, `ATTR{vendor}`).
2.  **Действия (assignment keys):** Определяют, что нужно сделать, если условия совпали (например, `NAME`, `SYMLINK`, `OWNER`, `RUN`).

### Управление правилами `udev`

После создания или изменения файла правил необходимо сообщить `udev` о необходимости их перечитать и применить, а также, при необходимости, "проиграть" события для существующих устройств:

```bash
# Перезагрузить правила udev
sudo udevadm control --reload-rules

# Заново "проиграть" события для существующих устройств, чтобы применить новые правила
sudo udevadm trigger
```

## Практические сценарии

### Пример правила `udev`

Создадим правило, которое при подключении любого устройства, идентифицированного ядром как `sdb`, будет создавать для него символическую ссылку `/dev/backup` и предоставлять доступ к нему всем пользователям из группы `plugdev`.

```
# /etc/udev/rules.d/10-backup-disk.rules

SUBSYSTEM=="block", KERNEL=="sdb", SYMLINK+="backup", GROUP="plugdev", TAG+="uaccess"
```

-   `SUBSYSTEM=="block"`: Правило применяется только к блочным устройствам.
-   `KERNEL=="sdb"`: Условие срабатывает, если ядро назвало устройство `sdb`.
-   `SYMLINK+="backup"`: Создать символическую ссылку `/dev/backup`.
-   `GROUP="plugdev"`: Установить группу-владельца.
-   `TAG+="uaccess"`: Стандартный тег, который через `systemd-logind` предоставляет доступ к устройству активному пользователю.
