# BIOS и UEFI: Основы и различия

## Определения

### BIOS (Basic Input-Output System)

Низкоуровневое программное обеспечение на микросхеме материнской платы, инициализирующее аппаратные компоненты и запускающее загрузчик ОС при включении ПК.

### UEFI (Unified Extensible Firmware Interface)

Современный стандарт прошивки, пришедший на смену BIOS, предлагающий расширенные возможности взаимодействия с аппаратным обеспечением и ОС. Функционально схож с мини-операционной системой, работающей поверх основной прошивки.

## Основные понятия

### Принципы работы BIOS

1.  **POST (Power-On Self Test):** Самотестирование оборудования при старте ПК. При обнаружении ошибок BIOS сигнализирует звуком или кодами.
2.  **Загрузка ОС:** После POST BIOS ищет и запускает загрузочную запись **MBR (Master Boot Record)**.
3.  **CMOS:** Взаимодействие с энергонезависимой памятью CMOS для хранения настроек (конфигурация, время, параметры загрузки).

### Ограничения BIOS

*   **Диски:** Поддержка загрузки только с дисков до **2.1 ТБ** (использует MBR).
*   **Режим:** Работа в **16-разрядном режиме** процессора, ограничение памяти 1 МБ.
*   **Инициализация:** Проблемы с одновременной инициализацией нескольких устройств.

### Преимущества UEFI

*   **Большие диски:** Загрузка с дисков объемом свыше **2.2 ТБ** (до 9.4 ЗБ) благодаря **GPT (GUID Partition Table)**.
*   **Режим:** Работа в **32-битном или 64-битном режиме**, что ускоряет запуск и расширяет доступ к памяти.
*   **Интерфейс:** Графический интерфейс с поддержкой мыши.
*   **Безопасность:** **Secure Boot** для проверки цифровых подписей загрузчика и ядра ОС, предотвращая запуск вредоносного кода.
*   **Сеть:** Встроенная поддержка сетевой загрузки (PXE) и доступа к сети из прошивки.

### Сравнение BIOS и UEFI

| Характеристика | BIOS | UEFI |
| :--- | :--- | :--- |
| **Схема разделов** | MBR | GPT |
| **Макс. объем диска** | ~2.1 ТБ | ~9.4 ЗБ |
| **Режим процессора** | 16-битный | 32/64-битный |
| **Безопасность** | Отсутствует | Secure Boot |
| **Интерфейс** | Текстовый | Графический |
