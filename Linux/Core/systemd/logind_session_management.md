# Управление сессиями и пользователями: loginctl

## Определения

**`loginctl`** — это утилита командной строки из состава `systemd-logind` для просмотра и управления пользовательскими сессиями, пользователями и физическими рабочими местами (seats).

## Практические сценарии

### Просмотр сессий и пользователей

* **Показать все активные сессии:**

    ```bash
    loginctl list-sessions
    ```

    Вывод показывает ID сессии, UID, имя пользователя, `seat` и `TTY`. `pts/0` обычно означает SSH-сессию, а `tty2` — виртуальный терминал.

* **Получить детальную информацию о сессии:**

    ```bash
    # В машиночитаемом формате
    loginctl show-session <ID>

    # В человекочитаемом формате с деревом процессов
    loginctl session-status <ID>
    ```

* **Просмотреть список пользователей и их статус:**

    ```bash
    loginctl list-users
    loginctl user-status <username>
    loginctl show-user <username>
    ```

### Управление сессиями

* **Корректно завершить сессию:**

    ```bash
    loginctl terminate-session <ID>
    ```

* **Завершить все сессии пользователя:**

    ```bash
    loginctl terminate-user <username>
    ```

* **Принудительно "убить" все процессы сессии (крайняя мера):**

    ```bash
    loginctl kill-session <ID> -s SIGKILL
    ```

* **Заблокировать или разблокировать экран сессии (если поддерживается):**

    ```bash
    loginctl lock-session <ID>
    loginctl unlock-session <ID>
    ```

## Дополнительная информация

### Запуск процессов без активной сессии (linger)

По умолчанию процессы, запущенные пользователем (включая [пользовательские службы](./user_services.md)), завершаются при выходе пользователя из системы. Чтобы разрешить процессам пользователя работать постоянно, даже без активной сессии, используется режим "linger".

Подробно эта функция описана в документе **[Пользовательские службы systemd](./user_services.md)**.
