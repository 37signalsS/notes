# systemd-analyze: Анализ производительности загрузки

## Определения

**`systemd-analyze`** — это штатная утилита `systemd` для анализа производительности процесса загрузки системы. Она позволяет измерять время запуска ядра и пространства пользователя, выявлять юниты, замедляющие запуск, и визуализировать последовательность загрузки.

## Основные концепции

- **Время загрузки (Kernel vs. Userspace)**: `systemd-analyze` разделяет общее время загрузки на две фазы:
  - **Kernel time**: Время, затраченное ядром на инициализацию оборудования и подготовку к запуску пространства пользователя.
  - **Userspace time**: Время с момента передачи управления `systemd` (PID 1) до достижения целевого состояния (например, `multi-user.target`). Именно эту фазу утилита помогает анализировать.

- **Критическая цепь (Critical Chain)**: Это последовательность юнитов, от которой напрямую зависит общее время загрузки. Задержка любого юнита в этой цепи приводит к увеличению общего времени. Анализ критической цепи — ключевой метод для поиска "узких мест".

- **Юниты (Units)**: Анализ производительности строится вокруг юнитов `systemd` (сервисов, таргетов, сокетов и т.д.) и времени, затраченного на их активацию и ожидание зависимостей.

## Практические сценарии

### Общий анализ времени загрузки

Команда без аргументов показывает суммарное время, затраченное на загрузку ядра и пространства пользователя.

```bash
# Показать общее время загрузки (ядро + userspace)
systemd-analyze
```

*Пример вывода: `Startup finished in 3.295s (kernel) + 12.185s (userspace) = 15.480s`*

### Поиск замедляющих юнитов (`blame`)

Выводит список всех активных юнитов, отсортированный по времени, которое потребовалось на их запуск. Помогает быстро найти самые медленные службы.

```bash
# Показать время запуска каждого юнита по убыванию
systemd-analyze blame
```

### Анализ цепи зависимостей (`critical-chain`)

Строит дерево зависимостей для таргета по умолчанию (или указанного) и подсвечивает критическую цепь.

```bash
# Показать критическую цепь, замедлившую загрузку
systemd-analyze critical-chain

# Показать критическую цепь для графического сеанса
systemd-analyze critical-chain graphical.target
```

В выводе время активации самого юнита выделяется красным, а время ожидания зависимостей — знаком `+`.

### Визуализация процесса загрузки (`plot`)

Генерирует SVG-файл с подробной диаграммой параллельного выполнения юнитов, наглядно показывая зависимости и задержки.

```bash
# Сгенерировать plot.svg с диаграммой загрузки
systemd-analyze plot > plot.svg
```

Полученный файл можно открыть в любом браузере для детального изучения.

## Дополнительная информация

Утилита `systemd-analyze` также используется для других задач, не связанных напрямую с анализом производительности загрузки:

- **Проверка синтаксиса юнит-файлов**: `systemd-analyze verify`. Подробнее см. в [документе о юнитах](./units_and_dependencies.md).
- **Анализ выражений календаря**: `systemd-analyze calendar` для отладки [таймеров](./timers.md).
