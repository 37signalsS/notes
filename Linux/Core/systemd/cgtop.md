# systemd-cgtop: Мониторинг ресурсов контрольных групп

## Определения

* **`systemd-cgtop`** — это интерактивная системная утилита для мониторинга потребления ресурсов (CPU, память, I/O) иерархиями контрольных групп (**cgroups**). В отличие от классических инструментов типа `top`, она агрегирует данные не по отдельным процессам, а по логическим объединениям — сервисам, пользователям и контейнерам.
* **Control Group (cgroup)** — механизм ядра ОС (Операционная Система) Linux, позволяющий объединять процессы в иерархические группы для изоляции и ограничения ресурсов.

## Основные концепции

### Преимущества агрегации данных

В современных системах один сервис (например, веб-сервер или база данных) может состоять из десятков процессов. `systemd-cgtop` позволяет увидеть нагрузку на систему целиком от конкретного юнита (unit), избавляя администратора от необходимости вручную суммировать показатели отдельных PID (Process ID).

**Пример отображения в сравнении с top:**

Обычный `top` (разрозненные процессы):

```text
PID   USER      %CPU  COMMAND
101   www-data  15.0  php-fpm: pool www
102   www-data  12.0  php-fpm: pool www
```

`systemd-cgtop` (единый сервис):

```text
Control Group              Tasks   %CPU   Memory
/system.slice/php-fpm.service  2   27.0   124.5M
```

## Практические сценарии

### Поиск "тяжелых" сервисов

Использование флагов сортировки при запуске помогает быстро выявить узкие места.

```bash
# Сортировка по потреблению памяти
systemd-cgtop --order=memory
# → вывод групп с наибольшим использованием RAM

# Сортировка по дисковой нагрузке (I/O)
systemd-cgtop --order=io
# → мониторинг Input/Output операций в реальном времени
```

### Пакетный режим для скриптов

Если необходимо получить моментальный снимок состояния для логирования или автоматизации.

```bash
# Однократный вывод в текстовом формате
systemd-cgtop --batch --iterations=1
# → Control Group                            Tasks   %CPU   Memory  Input/s Output/s
# → /                                          452    1.2     2.4G        -        -
```

### Интерактивное управление (Hotkeys)

Во время работы утилиты можно изменять режим отображения:

| Клавиша | Действие |
| :--- | :--- |
| **`c`** | Сортировать по CPU (Central Processing Unit). |
| **`m`** | Сортировать по памяти. |
| **`i`** | Сортировать по I/O (Input/Output). |
| **`t`** | Сортировать по количеству задач (Tasks). |
| **`%`** | Переключить CPU между процентами и временем. |
| **`q`** | Выход из программы. |
