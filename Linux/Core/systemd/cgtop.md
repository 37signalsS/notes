# systemd-cgtop: Мониторинг ресурсов Control Groups

## Определения

* **`systemd-cgtop`**: Инструмент из пакета `systemd` для интерактивного мониторинга использования ресурсов (CPU, память, I/O) группами контроля (cgroups). Предоставляет агрегированные данные по группам процессов, в отличие от `top`, который показывает отдельные процессы.
* **Control Group (cgroup)**: Механизм ядра Linux для организации процессов в иерархические группы и управления их доступом к системным ресурсам (CPU, память, I/O, сеть). `systemd` активно использует cgroups для изоляции и управления службами.

## Основные концепции

`systemd-cgtop` является аналогом классической утилиты `top`, но ориентирован на `cgroups`. Это критически важно, поскольку современные системы Linux, особенно с `systemd`, организуют сервисы и приложения в cgroups. Например, веб-сервер, такой как Nginx, может порождать сотни worker-процессов. В `top` вы увидите длинный список однотипных процессов, тогда как `systemd-cgtop` объединит их в одну строку, показывая суммарное потребление ресурсов для всего `nginx.service` или `system.slice/nginx`.

Что показывает `top`:

```
PID  USER     CPU%  MEM%  COMMAND
1234 www-data 45.0  12.3  /usr/bin/php-fpm
5678 www-data 32.1  8.7   /usr/bin/php-fpm
```

Что показывает `systemd-cgtop`:

```
Control Group          Tasks  %CPU  Memory
/system.slice/nginx     12    78.2  2.1G
/system.slice/postgresql 8    23.4  1.8G
/system.slice/redis      4    12.1  512M
```

Эта разница позволяет быстро выявлять сервисы или группы сервисов, потребляющие наибольшее количество ресурсов, без необходимости анализировать каждый отдельный процесс.

## Практические сценарии

### Выявление потребителей ресурсов

* **Что тормозит сервер? (по CPU)**:

    ```bash
    systemd-cgtop --order=cpu
    ```

* **Кто съел всю память?**:

    ```bash
    systemd-cgtop --order=memory
    ```

* **Кто нагружает диск? (по I/O)**:

    ```bash
    systemd-cgtop --order=io
    ```

### Фильтрация и мониторинг специфических групп

* **Следить только за веб-сервисами**:

    ```bash
    systemd-cgtop | grep -E '(nginx|apache|php)'
    ```

    (Пример использования `grep` для фильтрации вывода)

### Интерактивный режим и горячие клавиши

В интерактивном режиме `systemd-cgtop` предоставляет удобные горячие клавиши для управления отображением:

| Клавиша | Действие |
| :--- | :--- |
| `p` | Сортировка по пути (path) |
| `t` | Сортировка по количеству задач (tasks) |
| `c` | Сортировка по CPU |
| `m` | Сортировка по памяти (memory) |
| `i` | Сортировка по I/O |
| `%` | Переключение CPU между % и абсолютными значениями |
| `+` | Развернуть дерево cgroups |
| `-` | Свернуть дерево cgroups |
| `q` | Выход |

### Ключи командной строки

| Ключ | Описание |
| :--- | :--- |
| `--order=cpu\|memory\|io\|tasks\|path` | Сортировка по указанному полю |
| `--raw` | Показать сырые значения (без форматирования) |
| `--reverse` | Обратный порядок сортировки |
| `--batch` | Пакетный режим (вывод и выход) |
| `--iterations=N` | Выполнить N итераций и выйти |
| `--delay=SEC` | Задержка между обновлениями (по умолчанию 2с) |
