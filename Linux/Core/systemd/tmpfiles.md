# systemd-tmpfiles: Управление временными файлами и структурой ФС

## Определения

* **`systemd-tmpfiles`** — системный механизм для декларативного создания, удаления и управления объектами файловой системы (файлами, каталогами, сокетами, правами доступа). В современных системах это не просто инструмент очистки `/tmp`, а мощный механизм инициализации структуры ФС при загрузке системы или установке ПО.
* **Конфигурационные файлы (`tmpfiles.d`)** — текстовые файлы в формате `.conf`, описывающие правила обработки путей.
* **Transient Rules** — временные правила, передаваемые через системные учетные данные (`tmpfiles.extra`) или создаваемые «на лету».

## Основные концепции

### Архитектурные компоненты

`systemd-tmpfiles` работает через два основных системных юнита:
1. **`systemd-tmpfiles-setup.service`** — запускается на ранних этапах загрузки. Выполняет создание директорий, файлов и установку прав (типы `d`, `f`, `L`, `p`, `c`, `b`, `z` и др.).
2. **`systemd-tmpfiles-clean.timer`** — периодически запускает **`systemd-tmpfiles-clean.service`** (обычно раз в сутки) для очистки устаревших файлов на основе параметра «Возраст» (типы `d`, `D`, `e`).

### Расположение и приоритет конфигурации

Правила обрабатываются в лексикографическом порядке имен файлов. Если файлы имеют одинаковые имена в разных директориях, применяется только один с наивысшим приоритетом:

| Путь | Назначение | Приоритет |
| :--- | :--- | :--- |
| **`/etc/tmpfiles.d/*.conf`** | Локальные настройки администратора | **Высший** |
| **`/run/tmpfiles.d/*.conf`** | Динамические правила времени выполнения (runtime) | Средний |
| **`/usr/lib/tmpfiles.d/*.conf`** | Правила от дистрибутива и установленных пакетов | Низший |

### Формат строки конфигурации

Каждая строка описывает одну операцию:
```text
Тип  Путь  Режим  Владелец  Группа  Возраст  Аргумент
```

#### Таблица типов директив (Создание и Очистка)

| Тип | Операция | Описание |
| :---: | :--- | :--- |
| **`d`** | Create Directory | Создает директорию, если её нет. Устанавливает права/владельца. |
| **`D`** | Create & Empty | Создает директорию и очищает её содержимое при вызове `--clean`. |
| **`e`** | Clean Dir | Очищает содержимое существующей директории по возрасту. |
| **`f`** | Create File | Создает пустой файл, если его нет. |
| **`F`** | Write File | Создает или перезаписывает файл (аналог `truncate`). |
| **`w`** | Write Content | Дописывает строку в файл. Поддерживает спецификаторы. |
| **`L`** | Symlink | Создает символическую ссылку. Цель — в Аргументе. |
| **`p`** | Named Pipe | Создает именованный канал (FIFO). |
| **`c` / `b`** | Device Node | Создает символьное (`c`) или блочное (`b`) устройство. |

#### Таблица типов директив (Права и Безопасность)

| Тип | Операция | Описание |
| :---: | :--- | :--- |
| **`z`** | Set Permissions | Устанавливает права, владельца и группу (без рекурсии). |
| **`Z`** | Recursive Set | Рекурсивно устанавливает права и восстанавливает контекст SELinux. |
| **`a` / `A`** | Set ACLs | Устанавливает POSIX ACL (рекурсивно для `A`). Суффикс `+` — добавить. |
| **`h` / `H`** | Set Attributes | Устанавливает атрибуты файлов (chattr), например `i` (immutable). |
| **`t` / `T`** | Set xattrs | Устанавливает расширенные атрибуты (xattrs). |

#### Специфические типы для Btrfs

* **`v` / `q` / `Q`** — создание subvolume, управление квотами и группами квот (qgroups) в файловой системе Btrfs.

### Спецификаторы (Specifiers)

В полях «Путь» и «Аргумент» используются переменные:
* **`%m`** — Machine ID хоста.
* **`%b`** — Boot ID текущей загрузки.
* **`%H`** — Hostname системы.
* **`%T` / `%V`** — Директории `/tmp` и `/var/tmp` соответственно.
* **`%u` / `%U`** — Имя и UID текущего пользователя.

## Практические сценарии

### 1. Настройка окружения для сервиса

Создание структуры в `/run` с правами для группы и ACL для мониторинга.
```ini
# /etc/tmpfiles.d/app-monitor.conf
# Тип  Путь            Режим  Пользователь  Группа    Возраст  Аргумент
d      /run/app-data   0750   app-user      www-data  -        -
a+     /run/app-data   -      -             -         -        u:monitor:r-x
```

### 2. Автоматическая очистка старых дампов

Удаление `.sql` файлов из `/var/backups/db/` старше 30 дней.
```ini
# /etc/tmpfiles.d/db-cleanup.conf
# Тип  Путь             Режим  Пользователь  Группа  Возраст  Аргумент
e      /var/backups/db  -      -             -       30d      -
```

### 3. Создание именованного канала (FIFO)

Полезно для интеграции старых приложений, ожидающих пайп.
```ini
# /etc/tmpfiles.d/legacy-pipe.conf
p      /run/app.pipe    0660   root          app-group -        -
```

## Диагностика и управление через CLI

```bash
# Чтение всей итоговой конфигурации (с учетом приоритетов)
systemd-tmpfiles --cat-config

# Принудительное выполнение создания и установки прав
sudo systemd-tmpfiles --create

# Режим предварительного просмотра (dry-run)
sudo systemd-tmpfiles --create --dry-run

# Очистка устаревших файлов (Age)
sudo systemd-tmpfiles --clean

# Применение правил только для конкретного файла конфигурации
sudo systemd-tmpfiles --create /etc/tmpfiles.d/my-app.conf
```

## Дополнительная информация

### Различие /tmp и /var/tmp

| Характеристика | `/tmp` | `/var/tmp` |
| :--- | :--- | :--- |
| **Тип ФС** | Обычно `tmpfs` (RAM) | Дисковая ФС (HDD/SSD) |
| **Стойкость** | Очищается при перезагрузке | Сохраняется после перезагрузки |
| **Очистка** | 10 дней простоя (default) | 30 дней простоя (default) |

### Меры безопасности и лучшие практики

1. **Sticky Bit**: Для общих директорий (как `/tmp`) используйте режим `1777`, чтобы предотвратить удаление чужих файлов.
2. **Неявное создание**: `systemd-tmpfiles` автоматически создает родительские каталоги с правами `0755` (владелец root), если они отсутствуют.
3. **Использование спецификаторов**: Это позволяет делать конфигурацию переносимой между хостами (например, используя `%m`).
