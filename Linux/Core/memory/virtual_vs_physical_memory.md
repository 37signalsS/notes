## Определения

* **Физическая память (RAM)**: Аппаратные чипы на материнской плате, используемые процессором для выполнения кода и хранения данных.
* **Виртуальная память**: Абстракция операционной системы, предоставляющая каждому процессу изолированное адресное пространство. Процессы используют виртуальные адреса, которые аппаратура (MMU) и ядро преобразуют в физические.

## Основные концепции

### Механизм работы

1. **Таблицы страниц (Page Tables)**: Каждое ядро Linux для процесса имеет карту, где хранится информация о расположении виртуальных страниц:
    * В физической памяти (ОЗУ).
    * В пространстве подкачки ([swap](./swap_management.md)) на жестком диске.
    * Отсутствует (память зарезервирована, но не использована).
2. **MMU (Memory Management Unit)**: Аппаратный блок процессора, обеспечивающий мгновенное преобразование виртуальных адресов в физические с использованием таблиц страниц.

### Ключевые преимущества

* **Изоляция процессов**: Каждый процесс изолирован в своем виртуальном адресном пространстве, что предотвращает конфликты памяти между процессами.
* **Эффективное использование ОЗУ**: Общие библиотеки загружаются в физическую память однократно, а их страницы отображаются в виртуальные адресные пространства всех использующих их процессов.
* **Использование памяти сверх объема ОЗУ**: Неактивные страницы могут быть выгружены в swap, освобождая ОЗУ для активных задач.

### Сравнение физической и виртуальной памяти

| Характеристика          | Физическая память (RAM)     | Виртуальная память                  |
| :---------------------- | :-------------------------- | :---------------------------------- |
| **Что это?**            | Реальные аппаратные чипы.   | Абстракция, создаваемая ОС.         |
| **Скорость**            | Очень высокая.              | Медленнее при доступе к swap.       |
| **Размер**              | Ограничен объемом ОЗУ.      | Ограничен архитектурой и диском.    |
| **Доступ**              | Прямой доступ имеет только ядро. | Процессы работают с виртуальными адресами. |

## Практические сценарии

### Проверка размера страницы

Размер страницы по умолчанию (обычно 4 КБ) можно узнать командой:

```bash
getconf PAGESIZE
# 4096
```

Знание размера страницы полезно для анализа производительности и работы с [HugePages](./performance_tuning.md#hugepages-и-transparent-huge-pages-thp).

## Дополнительная информация

### Чрезмерное выделение памяти (Memory Overcommit)

Linux использует механизм **"чрезмерного выделения" (overcommit)**, при котором системе разрешается обещать процессу больше виртуальной памяти, чем реально доступно (RAM + swap). Это повышает эффективность использования ресурсов, так как программы часто резервируют память "про запас", не используя ее полностью.

Попытка процессов использовать всю выделенную память может привести к ее нехватке и активации **[OOM Killer](./performance_tuning.md#memory-overcommit)**.

> Подробное описание режимов работы и тюнинга этого механизма доступно в заметке **[Оптимизация и тонкая настройка памяти](./performance_tuning.md#управление-memory-overcommit)**.
