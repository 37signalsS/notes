# Pressure Stall Information (PSI)

## Определения

**Pressure Stall Information (PSI)** — механизм ядра Linux (с версии 4.20), отслеживающий «давление» на ресурсы CPU, память и I/O. В отличие от загрузки, PSI показывает, сколько времени процессы потеряли из-за нехватки ресурса.

## Основные концепции

### Принцип работы

PSI измеряет **stall time** — время, в течение которого процессы не могли выполняться из-за полной утилизации ресурса.

| Ресурс | Что означает давление |
| :--- | :--- |
| **CPU** | Готовых к выполнению процессов больше, чем доступных ядер |
| **Memory** | Процессы ждут освобождения страниц памяти |
| **I/O** | Процессы ждут завершения операций ввода-вывода |

### Формат вывода

Каждый файл `/proc/pressure/<ресурс>` содержит строки `some` и `full`:

- **`some`** — % времени, когда хотя бы одна задача заблокирована. Указывает на потерю пропускной способности.
- **`full`** — % времени, когда все не-idle процессы заблокированы. Указывает на серьёзное насыщение ресурса.

```
some avg10=2.46 avg60=1.82 avg300=1.21 total=748381
full avg10=0.91 avg60=0.65 avg300=0.45 total=280381
```

`avg10/60/300` — среднее за 10, 60, 300 сек. `total` — суммарное время простоя в микросекундах.

### PSI vs традиционные метрики

| Метрика | Что показывает | Недостаток |
| :--- | :--- | :--- |
| **CPU usage** | % использования CPU | Не показывает, ждут ли процессы |
| **Memory usage** | Объём использованной памяти | Не показывает ожидание выделения |
| **PSI** | Время простоя из-за нехватки | Прямо указывает на потерю производительности |

### Требования и ограничения

- Ядро **4.20+** с `CONFIG_PSI=y`
- Накладные расходы: ~1–3% CPU
- Для cgroup-PSI требуется `CONFIG_PSI=y` и монтированный cgroup v2

## Практические сценарии

### Чтение PSI-метрик

```bash
# Давление на CPU
cat /proc/pressure/cpu

# Давление на память
cat /proc/pressure/memory

# Давление на I/O
cat /proc/pressure/io
```

### PSI в cgroups v2

PSI доступен для каждой контрольной группы, что позволяет ограничивать или завершать процессы при высоком давлении:

```bash
cat /sys/fs/cgroup/<путь>/memory.pressure
cat /sys/fs/cgroup/<путь>/cpu.pressure
cat /sys/fs/cgroup/<путь>/io.pressure
```

Подробнее: **[Control Groups (cgroups)](../cgroups.md)**.

### Мониторинг и алертинг

PSI используется для автомасштабирования и раннего обнаружения проблем:

- **Оркестрация:** Kubernetes/node-problem-detector может использовать PSI для принятия решений о добавлении узлов.
- **Алертинг:** Превышение `full avg10 > 50%` — признак серьёзной деградации.
- **«Шумные соседи»:** Высокое `some` при низком `full` указывает на неравномерное распределение нагрузки.
