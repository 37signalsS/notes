# Настройка параметров ядра (sysctl)

## Определения

**`sysctl`** — утилита для чтения и изменения параметров ядра Linux во время работы системы без необходимости перезагрузки.

**`/proc/sys/`** — виртуальная файловая система, через которую ядро экспортирует свои параметры в пространство пользователя. `sysctl` является удобным интерфейсом к этой ФС.

Инструмент критически важен при настройке системы под конкретные нагрузки: базы данных, узлы Kubernetes, высокопроизводительные прокси-серверы или файловые хранилища. Параметры ядра по умолчанию обычно рассчитаны на универсальность, тогда как реальные задачи требуют тонкой настройки (тюнинга).

## Основные концепции

### Устройство и иерархия

Все настройки сгруппированы по разделам в каталоге `/proc/sys/`. Иерархия в `sysctl` (через точки) соответствует иерархии папок и файлов в `/proc/sys/` (через слэши).

- **`net.*`** — сетевой стек (TCP/IP, маршрутизация, ARP, лимиты соединений).
- **`vm.*`** — управление виртуальной памятью и поведение swap (агрессивность кэширования, swappiness).
- **`kernel.*`** — общие параметры ядра (лимиты PID, параметры dmesg, поведение при Kernel Panic).
- **`fs.*`** — файловые системы и лимиты файловых дескрипторов (inotify, file-max).

### Примеры ключевых параметров

- `net.ipv4.ip_forward` — включение маршрутизации трафика (значение `1`). Необходимо для VPN, шлюзов, Docker и Kubernetes.
- `vm.swappiness` — баланс между использованием оперативной памяти и swap.
- `fs.file-max` — системный лимит на количество открытых файлов.
- `net.core.somaxconn` — максимальный размер очереди прослушиваемых сокетов.

## Практические сценарии

### Основные команды управления

```bash
# Просмотреть все доступные параметры системы
sysctl -a

# Прочитать значение конкретного параметра
sysctl net.ipv4.ip_forward
# → net.ipv4.ip_forward = 0

# Изменить параметр «на лету» (сбросится после перезагрузки)
sudo sysctl -w net.ipv4.ip_forward=1
# → net.ipv4.ip_forward = 1
```

### Сохранение настроек при загрузке

Чтобы изменения стали постоянными, их необходимо добавить в конфигурационные файлы.

- **`/etc/sysctl.conf`** — основной файл конфигурации.
- **`/etc/sysctl.d/*.conf`** — дополнительные файлы (рекомендуется для логического разделения настроек).

**Пример создания дополнительного конфига (`/etc/sysctl.d/99-custom.conf`):**

```conf
# Включить форвардинг пакетов
net.ipv4.ip_forward = 1

# Увеличить лимит открытых файлов
fs.file-max = 2097152

# Уменьшить агрессивность swap
vm.swappiness = 10
```

### Применение конфигурации

```bash
# Применить все конфиги из /etc/sysctl.d/ и /etc/sysctl.conf
sudo sysctl --system

# Применить только основной файл /etc/sysctl.conf
sudo sysctl -p

# Применить конкретный файл
sudo sysctl -p /etc/sysctl.d/99-custom.conf
```
