# Настройка параметров ядра (sysctl)

## Определения

**`sysctl`** — это утилита и механизм в Linux, который позволяет просматривать и изменять параметры ядра "на лету", без необходимости перезагрузки. Эти параметры (tunables) управляют поведением различных подсистем, таких как сеть, виртуальная память, файловая система и безопасность.

## Основные концепции

### Иерархическая структура параметров

Параметры ядра организованы в виде иерархической структуры и доступны через виртуальную файловую систему в `/proc/sys/`. Например, параметр `vm.swappiness` соответствует файлу `/proc/sys/vm/swappiness`. Подробнее о `/proc/sys/` см. в разделе [Виртуальная файловая система /proc](../kernel_interfaces.md#Виртуальная-файловая-система-proc-procfs).

## Практические сценарии

### Просмотр параметров

- **Просмотреть все доступные параметры:**

    ```bash
    sudo sysctl -a
    ```

- **Прочитать значение конкретного параметра:**

    ```bash
    # Способ 1: через утилиту sysctl
    sudo sysctl vm.swappiness
    
    # Способ 2: напрямую из /proc
    cat /proc/sys/vm/swappiness
    ```

- **Найти параметр по ключевому слову:**

    ```bash
    sudo sysctl -a | grep ip_forward
    ```

### Изменение параметров (временно)

Изменения, сделанные этими способами, действуют только до следующей перезагрузки системы.

- **Способ 1: через утилиту `sysctl`**

    ```bash
    sudo sysctl -w vm.swappiness=10
    ```

- **Способ 2: напрямую в `/proc`**

    ```bash
    echo 10 | sudo tee /proc/sys/vm/swappiness
    ```

### Сохранение параметров (постоянные изменения)

Чтобы изменения сохранялись после перезагрузки, их необходимо записать в конфигурационные файлы. `systemd-sysctl` автоматически считывает эти файлы при загрузке.

**Процесс:**

1. **Создайте новый `.conf` файл** в `/etc/sysctl.d/`. Рекомендуется давать файлам префиксы с числами для управления порядком загрузки (например, `99-custom.conf`).

    ```
    # /etc/sysctl.d/99-custom-network.conf
    net.ipv4.ip_forward = 1
    net.core.somaxconn = 4096
    ```

2. **Примените изменения немедленно**, не дожидаясь перезагрузки:

    ```bash
    # Загрузить все файлы .conf из /etc/sysctl.d/
    sudo sysctl --system
    # Или можно указать конкретный файл:
    sudo sysctl -p /etc/sysctl.d/99-custom-network.conf
    ```

## Дополнительная информация

- **Тематическая группировка:** Параметры сгруппированы по подсистемам ядра, что отражено в их именах:
  - `vm.*`: управление виртуальной памятью (например, `vm.swappiness`).
  - `net.*`: настройка сетевого стека (например, `net.ipv4.ip_forward`).
  - `kernel.*`: общие параметры ядра (например, `kernel.hostname`).
  - `fs.*`: параметры файловой системы (например, `fs.file-max`).
- **Безопасность:** Многие критически важные для безопасности параметры настраиваются через `sysctl`. Например, `kernel.dmesg_restrict` (ограничение доступа к логам ядра) или `net.ipv4.tcp_syncookies` (защита от SYN-флуда).
- **Динамические параметры:** Некоторые параметры появляются в `/proc/sys` только после загрузки соответствующих модулей ядра.
