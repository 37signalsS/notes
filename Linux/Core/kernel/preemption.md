# Вытесняющая многозадачность ядра (Preemption)

## Определения

**Kernel Preemption** — механизм, позволяющий ядру Linux принудительно прервать выполнение текущей задачи (даже в режиме ядра) для передачи CPU более высокоприоритетной задаче.

## Основные концепции

### Проблема и решение

В ранних версиях ядро было **невытесняемым (non-preemptive)** — процесс в режиме ядра не мог быть прерван. Это приводило к большим и непредсказуемым задержкам для высокоприоритетных задач.

**Вытесняемое ядро** позволяет планировщику запустить более важную задачу практически в любой момент.

| Аспект | Влияние |
| :--- | :--- |
| **Преимущество** | Улучшает отзывчивость и предсказуемость времени отклика |
| **Недостаток** | Увеличивает накладные расходы на переключения контекста, усложняет код |

### Модели вытеснения

При компиляции ядра выбирается одна из моделей для баланса между отзывчивостью и пропускной способностью:

| Модель | CONFIG_ | Описание | Сценарий |
| :--- | :--- | :--- | :--- |
| **No Forced Preemption** | `PREEMPT_NONE` | Ядро не вытесняется. Задача выполняется до завершения или добровольной блокировки. | Серверы, пакетная обработка |
| **Voluntary Preemption** | `PREEMPT_VOLUNTARY` | Ядро вставляет точки `cond_resched()` для проверки приоритетных задач. | Десктопы, общие серверы |
| **Preemptible Kernel** | `PREEMPT` | Вытеснение в любой безопасной точке (где нет блокировок). | Low-latency, реалтайм-основа |

## Практические сценарии

### Проверка модели вытеснения

```bash
# Проверить конфигурацию ядра (если доступен /proc/config.gz)
zcat /proc/config.gz | grep CONFIG_PREEMPT

# Альтернативно: через boot-конфиг
grep CONFIG_PREEMPT /boot/config-$(uname -r)
```

Вывод:

- `CONFIG_PREEMPT_NONE=y` — невытесняемое ядро
- `CONFIG_PREEMPT_VOLUNTARY=y` — добровольное вытеснение
- `CONFIG_PREEMPT=y` — полностью вытесняемое ядро

### Влияние на latency

Для оценки влияния модели preemption на задержки:

```bash
# Проверить latency с помощью cyclictest (rt-tests)
sudo apt install rt-tests  # Debian/Ubuntu
sudo yum install rt-tests   # RHEL/CentOS
cyclictest -p 80 -m -n -l 10000
```
