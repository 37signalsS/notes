## Определения

**Kernel Preemption (Вытеснение в ядре)** — это механизм, который позволяет ядру Linux принудительно прервать выполнение текущей задачи (даже если она находится в режиме ядра), чтобы отдать процессор более высокоприоритетной задаче, которая стала готова к выполнению.

## Основные концепции

### Проблема и решение

В ранних версиях ядра Linux ядро было **невытесняемым (non-preemptive)**, что означало, что процесс в режиме ядра не мог быть прерван. Это приводило к большим и непредсказуемым задержкам (latency) для высокоприоритетных процессов.

**Вытесняемое ядро** решает эту проблему, позволяя планировщику "вклиниться" и запустить более важную задачу практически в любой момент.

-   **Преимущество:** Значительно улучшает **отзывчивость (responsiveness)** системы и предсказуемость времени отклика.
-   **Недостаток:** Увеличивает накладные расходы из-за более частых переключений контекста и усложнения кода ядра.

## Практические сценарии

### Проверка модели вытеснения

Выбранную модель вытеснения можно проверить, посмотрев конфигурацию запущенного ядра:

```bash
zcat /proc/config.gz | grep PREEMPT
```

## Дополнительная информация

### Модели вытеснения в ядре Linux

При компиляции ядра Linux можно выбрать одну из нескольких моделей вытеснения, чтобы сбалансировать отзывчивость и пропускную способность.

1.  **No Forced Preemption (Server)**
    -   **Описание:** Традиционное невытесняемое ядро. Задача в режиме ядра выполняется до своего завершения или добровольной блокировки.
    -   **Сценарий:** Оптимизировано для максимальной пропускной способности. Идеально для серверов, выполняющих длительные вычислительные задачи.

2.  **Voluntary Kernel Preemption (Desktop)**
    -   **Описание:** Компромиссный вариант. Ядро само вставляет в свой код явные "безопасные" точки, где оно проверяет, не нужно ли уступить процессор другой задаче (`cond_resched()`).
    -   **Сценарий:** Улучшает отзывчивость по сравнению с невытесняемым ядром, но с меньшими накладными расходами. Хорошо подходит для обычных серверов и рабочих станций.

3.  **Preemptible Kernel (Low-Latency Desktop / Real-time)**
    -   **Описание:** Полностью вытесняемое ядро. Прерывание может произойти практически в любой "безопасной" точке кода ядра (где нет блокировок).
    -   **Сценарий:** Обеспечивает наилучшую отзывчивость и минимальные задержки. Является стандартом для большинства десктопных дистрибутивов, а также основой для систем реального времени (PREEMPT_RT).
