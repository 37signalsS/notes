# Изоляция CPU

## Определения

**Изоляция CPU (CPU Isolation)** — набор техник на уровне ядра Linux для резервирования определённых ядер процессора исключительно для критически важных задач, с ограждением их от обычных системных процессов, фоновых задач и обработки прерываний.

## Основные концепции

### Назначение изоляции CPU

Планировщик Linux по умолчанию стремится равномерно распределять нагрузку по всем ядрам. Однако для некоторых приложений критичны даже малейшие задержки, вызванные переключением контекста, обработкой прерываний или фоновыми задачами.

**Основные сценарии применения:**

- **Приложения реального времени (Real-time):** Гарантированное и предсказуемое время отклика.
- **Высокопроизводительные вычисления (HPC):** Минимизация "шума" ОС для научных и финансовых расчётов.
- **Сетевые приложения с низкой задержкой (Low-latency networking):** Высокочастотный трейдинг, DPDK.
- **Виртуализация:** Выделение эксклюзивных ядер для ВМ.

### Ограничения `isolcpus`

- Не защищает ядро от обработки на нём **прерываний (IRQ)**.
- Некоторые потоки ядра (ksoftirqd, rcu_sched) всё ещё могут выполняться на изолированных ядрах.
- Для полной изоляции требуется дополнительная настройка `nohz_full` и `rcu_nocbs`.

## Практические сценарии

### Методы изоляции CPU

1. **`isolcpus`: изоляция от планировщика**

   Параметр загрузки ядра, запрещающий планировщику размещать обычные процессы на указанных ядрах. Запуск процессов на изолированных ядрах возможен только через явную привязку (`taskset`, `numactl`).

   ```bash
   # /etc/default/grub — изолировать ядра 2 и 3
   GRUB_CMDLINE_LINUX_DEFAULT="quiet splash isolcpus=2,3"
   ```

   После обновления GRUB (`sudo update-grub`) требуется перезагрузка.

2. **`nohz_full`: отключение тиков таймера**

   Отключает периодические прерывания системного таймера на указанных ядрах, когда на них выполняется единственный процесс. Устраняет накладные расходы от планирования.

   ```bash
   GRUB_CMDLINE_LINUX_DEFAULT="... nohz_full=2,3"
   ```

3. **`rcu_nocbs`: отключение обратных вызовов RCU**

   Переносит обратные вызовы RCU (Read-Copy-Update) с изолированных ядер на другие, устраняя ещё один источник прерываний.

   ```bash
   GRUB_CMDLINE_LINUX_DEFAULT="... rcu_nocbs=2,3"
   ```

4. **IRQ affinity: перенаправление прерываний**

   Для полной изоляции необходимо перенаправить обработку аппаратных прерываний на неизолированные ядра через `/proc/irq/<номер_irq>/smp_affinity`.

   Подробнее: **[Прерывания (interrupts.md)](./interrupts.md#управление-привязкой-прерываний-irq-affinity)**.
