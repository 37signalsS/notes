## Определения

**`io_uring`** — это современный интерфейс ядра Linux для выполнения высокопроизводительного асинхронного ввода-вывода (I/O), представленный в ядре 5.1. Он разработан с главной целью — минимизировать накладные расходы на системные вызовы.

## Основные концепции

### Проблема старых API

Традиционные [интерфейсы ядра](./kernel_interfaces.md) для I/O в Linux имели недостатки:
-   **Синхронный I/O (`read`, `write`):** Блокирует процесс.
-   **`epoll`:** Отлично для сетевого I/O, но плохо для дискового.
-   **`libaio` (Linux AIO):** Сложный API, ограничения и все равно требовал системных вызовов для каждой операции.

### Как работает `io_uring`: Кольцевые буферы

Ключевая инновация `io_uring` — использование двух **кольцевых буферов**, разделяемых между приложением и ядром, для пакетной обработки запросов без переключений контекста.

1.  **Submission Queue (SQ) - Очередь Запросов:** Приложение помещает сюда операции (SQE).
2.  **Completion Queue (CQ) - Очередь Завершений:** Ядро асинхронно выполняет операции из SQ и помещает результаты (CQE) сюда.

**Процесс работы:**
1.  Приложение заполняет SQ несколькими операциями.
2.  Приложение делает **один** системный вызов `io_uring_enter()`, чтобы уведомить ядро о наличии новых задач и/или дождаться завершения старых.
3.  Ядро обрабатывает всю пачку запросов из SQ.
4.  Приложение считывает результаты из CQ, также без необходимости делать системный вызов для каждого результата.

### Преимущества `io_uring`

-   **Высокая производительность и низкая задержка:** Значительно сокращается количество дорогостоящих переключений контекста между пространством пользователя и ядром.
-   **Пакетная обработка:** Возможность отправлять и получать результаты для множества операций за один системный вызов.
-   **Настоящая асинхронность:** Эффективно работает как с сетевым, так и с дисковым I/O.
-   **Универсальность:** Поддерживает множество системных вызовов (`read`/`write`, `openat`, `accept` и др.).

## Практические сценарии

### Где используется `io_uring`?

`io_uring` быстро становится стандартом для высокопроизводительных приложений на Linux:
-   **Базы данных:** PostgreSQL, ScyllaDB.
-   **Веб-серверы и прокси:** Nginx, Envoy.
-   **Системы виртуализации:** QEMU использует `io_uring` для асинхронной обработки дискового I/O для гостевых систем.
-   **Библиотеки:** `libuv` (основа Node.js) и другие асинхронные фреймворки внедряют поддержку `io_uring`.
