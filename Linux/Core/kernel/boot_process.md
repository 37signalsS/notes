# Процесс загрузки ядра Linux

## Определения

**Ядро (Kernel)** — центральный компонент операционной системы, управляющий аппаратными ресурсами и предоставляющий базовые сервисы (память, процессы, драйверы) всем остальным частям системы.

**initramfs (Initial RAM File System)** — временная корневая файловая система, загружаемая в оперативную память на раннем этапе. Содержит драйверы и инструменты, необходимые для монтирования основной файловой системы (например, для LVM, RAID или LUKS).

**Система инициализации (Init system)** — первый процесс пользовательского пространства (PID 1), запускаемый ядром. Отвечает за запуск служб и приведение системы в рабочее состояние. В современном Linux стандартом является **systemd**.

## Основные концепции

### Цепочка передачи управления

Загрузка Linux — это последовательность этапов, где каждый предыдущий компонент подготавливает среду для следующего:

1. **POST (Power-On Self-Test):** самодиагностика оборудования при включении.
2. **Прошивка (BIOS/UEFI):** инициализация устройств, поиск загрузчика. См. [**BIOS и UEFI**](../firmware_bios_uefi.md).
3. **Загрузчик (GRUB, systemd-boot):** выбор ядра, загрузка `vmlinuz` и `initramfs` в RAM. См. [**GRUB**](../../SystemAdministration/grub.md).
4. **Инициализация ядра:** распаковка ядра, настройка подсистем памяти и планировщика.
5. **Раннее пространство пользователя (Early Userspace):** монтирование `initramfs`, загрузка драйверов дисков, активация LVM/RAID.
6. **Смена корня (switch_root):** переход с `initramfs` на реальный корневой раздел (`/`).
7. **Запуск PID 1:** передача управления системе инициализации (systemd).
8. **Запуск служб:** последовательный старт юнитов до достижения целевого состояния (target).

### Этапы работы ядра

После получения управления от загрузчика ядро проходит следующие фазы:

#### 1. Распаковка и настройка

Ядро распаковывается в памяти. Настраиваются таблицы страниц (Page Tables), прерывания (Interrupts) и инициализируется планировщик. Создается внутренняя `rootfs`.

#### 2. Работа в initramfs

Архив `initramfs` распаковывается в `rootfs`. Запускается скрипт `/init`, который выполняет:

- `modprobe`: загрузка модулей для контроллеров дисков.
- `vgchange -ay`: активация групп томов LVM.
- `mdadm --assemble`: сборка RAID-массивов.
- Запрос пароля для расшифровки разделов.

#### 3. Переход на основную систему

Ядро находит реальный корень по параметру `root=` из командной строки. С помощью команды `switch_root` временная ФС заменяется на настоящую, и запускается `/sbin/init` (systemd).

## Практические сценарии

### Анализ времени загрузки

Утилита `systemd-analyze` позволяет выявить узкие места в процессе старта.

```bash
# Общее время загрузки
systemd-analyze
# → Startup finished in 2.150s (kernel) + 1.230s (initrd) + 8.420s (userspace) = 11.800s

# Список служб, замедляющих старт
systemd-analyze blame | head -n 5
# → 2.100s NetworkManager-wait-online.service
# → 1.050s plymouth-quit-wait.service
# → 0.850s apt-daily.service
```

### Диагностика параметров и логов

```bash
# Параметры, переданные ядру при загрузке
cat /proc/cmdline
# → BOOT_IMAGE=/vmlinuz-6.1 root=UUID=... ro quiet splash

# Логи текущей загрузки
journalctl -b 0 --priority=err
```

### Управление initramfs

При изменении конфигурации дисков (добавление LVM/RAID) необходимо обновить временную ФС.

**Debian/Ubuntu:**

```bash
sudo update-initramfs -u
# → update-initramfs: Generating /boot/initrd.img-6.1.0-21-amd64
```

**RHEL/CentOS/Fedora:**

```bash
sudo dracut --force
```

**Просмотр содержимого:**

```bash
lsinitramfs /boot/initrd.img-$(uname -r) | grep lvm    # Debian
lsinitrd /boot/initramfs-$(uname -r).img | grep lvm    # RHEL
```

### Однопользовательский режим (Recovery)

Для восстановления системы можно прервать обычную загрузку через GRUB:

1. В меню нажать `e` на нужном ядре.
2. Добавить `single` или `init=/bin/bash` в конец строки `linux`.
3. Нажать `F10`. После загрузки перемонтировать корень для записи:

```bash
mount -o remount,rw /
```
