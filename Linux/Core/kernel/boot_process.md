# Процесс загрузки ядра Linux

## Определения

### Ядро (Kernel)

**Ядро** — это центральная часть операционной системы, которая управляет ресурсами компьютера и предоставляет основные сервисы для всех остальных частей системы. Оно отвечает за управление памятью, процессами, файловыми системами и устройствами.

### initramfs (Initial RAM File System)

**initramfs** — это временная корневая файловая система, которая загружается в память на раннем этапе загрузки. Её основная задача — предоставить ядру необходимые инструменты и драйверы для монтирования настоящей корневой файловой системы, особенно если она находится на LVM, RAID или зашифрованном разделе.

### Система инициализации (init)

**Система инициализации** — это первый пользовательский процесс (с PID 1), который запускается ядром. Он отвечает за запуск всех остальных системных служб и демонов, приводя систему в рабочее состояние. В современных дистрибутивах Linux эту роль выполняет **`systemd`**.

## Основные концепции: Этапы загрузки

Процесс загрузки после передачи управления от прошивки можно разделить на следующие ключевые этапы:

### 1. Передача управления от загрузчика (GRUB)

- **Загрузчик** (например, GRUB2) считывает свою конфигурацию, загружает в память ядро (`vmlinuz`) и `initramfs` из каталога `/boot`.
- Он передает ядру параметры командной строки (просмотреть их можно в `cat /proc/cmdline`).
- Наконец, он передает управление ядру, запуская его выполнение.

### 2. Ранняя инициализация ядра

- Ядро распаковывается в памяти.
- Настраиваются базовые подсистемы: управление памятью, таблицы страниц, планировщик, прерывания.
- Создается временная внутренняя файловая система `rootfs`.

### 3. Монтирование `initramfs` и запуск `/init`

- Архив `initramfs` распаковывается поверх `rootfs`.
- Запускается скрипт `/init` из `initramfs`, который выполняет следующие задачи:
  - Загружает необходимые модули ядра (для дисковых контроллеров, файловых систем, LVM, RAID).
  - Активирует тома LVM (`vgchange -ay`) или собирает массивы RAID (`mdadm --assemble`).
  - При необходимости запрашивает пароль для расшифровки LUKS-контейнеров.

### 4. Переключение на корневую ФС (`switch_root`)

- Скрипт в `initramfs` находит настоящую корневую файловую систему, используя параметр `root=` из командной строки ядра.
- Корневая ФС монтируется во временный каталог (например, `/new_root`).
- Выполняется команда `switch_root`, которая меняет корень файловой системы с `initramfs` на настоящую ФС и запускает новую систему инициализации.

### 5. Запуск PID 1: `systemd`

- Запускается процесс `/sbin/init` (который в современных системах является `systemd`). Это первый процесс с PID 1.
- `systemd` анализирует свою конфигурацию и начинает запускать сервисы в соответствии с целевым уровнем (`target`).
- **`multi-user.target`**: Стандартный серверный режим с поддержкой сети и консольного входа.
- **`graphical.target`**: Режим для рабочих станций, который дополнительно запускает графический интерфейс.
- `systemd` управляет жизненным циклом всех служб и обеспечивает готовность системы к работе.

## Практические сценарии

### Анализ и диагностика загрузки

- **Просмотреть параметры ядра текущей загрузки:**

  ```bash
  cat /proc/cmdline
  ```

- **Просмотреть логи ядра и системных служб для текущей загрузки:**

  ```bash
  journalctl -b 0
  ```

- **Проанализировать логи предыдущей загрузки (если был сбой):**

  ```bash
  journalctl -b -1
  ```

- **Проанализировать время загрузки сервисов:**

  ```bash
  systemd-analyze blame
  ```

### Управление `initramfs`

Если вы изменили конфигурацию хранилища (LVM, RAID) или добавили модули ядра, которые нужны для загрузки, необходимо пересобрать `initramfs`.

- **Debian/Ubuntu:**

  ```bash
  # Обновить initramfs для текущего ядра
  sudo update-initramfs -u
  ```

- **RHEL/CentOS/Fedora/AlmaLinux:**

  ```bash
  # Принудительно пересоздать initramfs для текущего ядра
  sudo dracut --force
  ```

- **Просмотреть содержимое `initramfs`:**

  ```bash
  lsinitramfs /boot/initrd.img-$(uname -r) | less
  ```
