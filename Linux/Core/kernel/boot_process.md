# Процесс загрузки ядра Linux

## Определения

**Ядро (Kernel)** — центральный компонент операционной системы, который инициализирует аппаратное обеспечение и предоставляет базовые сервисы (управление памятью, планирование задач, драйверы) для программ пользовательского пространства.

**initramfs (Initial RAM File System)** — временная корневая файловая система (архив `cpio`), загружаемая в оперативную память. Она содержит минимальный набор драйверов и инструментов (LVM, RAID, LUKS, сетевые протоколы), необходимых для поиска и монтирования реальной корневой файловой системы.

**Unified Kernel Image (UKI)** — современный формат загрузочного артефакта (PE-файл), объединяющий ядро, `initramfs`, командную строку ядра и микрокод CPU в единый подписанный исполняемый файл для UEFI.

**Система инициализации (Init system)** — первый процесс пользовательского пространства (PID 1), который запускает все остальные службы. В большинстве современных дистрибутивов используется **systemd**.

## Основные концепции

### Цепочка передачи управления (Boot Chain)

Загрузка системы — это последовательная передача полномочий между компонентами, каждый из которых обладает большей логикой, чем предыдущий:

1.  **Прошивка (Firmware: BIOS/UEFI):** Инициализирует базовое оборудование, выполняет POST и ищет загрузочное устройство. В UEFI-системах запускает `.efi` приложение.
2.  **Загрузчик (Bootloader: GRUB, systemd-boot):** Позволяет выбрать ядро, загружает `vmlinuz` и `initramfs` в память и передает им управление.
3.  **Инициализация ядра:** Ядро распаковывается, настраивает MMU, таблицы страниц и инициализирует основные подсистемы (планировщик, прерывания).
4.  **Раннее пространство пользователя (Early Userspace):** Ядро монтирует `initramfs` как временный корень (`/`). Запускается скрипт или бинарный файл `/init`.
5.  **Смена корня (switch_root):** После подготовки дисков (сборка RAID, активация LVM) `initramfs` удаляется из памяти, управление переходит к реальной файловой системе.
6.  **Запуск PID 1:** Запускается `/sbin/init` (обычно ссылка на `systemd`), который инициализирует службы согласно целевому состоянию (target).

### Современная модель: Unified Kernel Image (UKI)

Традиционная загрузка (раздельные ядро и `initramfs`) уязвима, так как `initramfs` часто не подписан и может быть подменен. Модель UKI решает эту проблему:
- **`systemd-stub`**: Встраивается в UKI и выступает в роли «клея» между UEFI и ядром, извлекая компоненты и измеряя их состояние в **TPM2 (PCR 11)**.
- **Безопасность:** Весь UKI подписывается одной подписью Secure Boot, обеспечивая полную цепочку доверия от прошивки до ядра.
- **Measured Boot:** С помощью `systemd-pcrlock` система может автоматически разблокировать зашифрованные диски (LUKS) только в том случае, если UKI не был изменен.

### Этапы работы в initramfs

Работа во временной ФС критична для сложных систем хранения:
- **Загрузка модулей:** Подгрузка драйверов для контроллеров дисков (NVMe, SATA).
- **Сетевая загрузка:** Инициализация DHCP и монтирование корня по NFS/iSCSI.
- **Расшифровка:** Запрос пароля LUKS или получение ключа из TPM2.
- **Активация томов:** Команды `vgchange -ay` (LVM) или `mdadm --assemble` (RAID).

## Практические сценарии

### Анализ времени загрузки

Утилиты `systemd` предоставляют детальную разбивку этапов старта:

```bash
# Общее время загрузки
systemd-analyze
# → Startup finished in 1.2s (kernel) + 0.8s (initrd) + 5.4s (userspace) = 7.4s

# Графическая схема зависимостей (создает SVG файл)
systemd-analyze plot > boot_analysis.svg
```

### Создание и управление UKI

Для сборки современного образа UKI используется утилита `ukify` (часть `systemd-ukify`):

```bash
# Сборка UKI вручную
/lib/systemd/ukify build \
    --linux=/boot/vmlinuz-linux \
    --initrd=/boot/initramfs-linux.img \
    --cmdline="root=UUID=... rw quiet" \
    --output=/boot/efi/EFI/Linux/system.efi
```

Для управления ключами и автоматического подписания в дистрибутивах (Arch, Fedora) рекомендуется использовать `sbctl`.

### Тюнинг параметров загрузки

Параметры ядра передаются загрузчиком и доступны в реальном времени:

```bash
# Просмотр текущих параметров
cat /proc/cmdline

# Временное изменение (в GRUB)
# Нажать 'e' в меню, добавить параметры в конец строки 'linux'
# Пример для диагностики: 'systemd.debug_shell=1' (запустит shell на tty9)
```

### Пересборка initramfs

При изменении конфигурации железа или дисков необходимо обновить загрузочные образы:

- **Debian/Ubuntu:** `sudo update-initramfs -u -k all`
- **RHEL/Fedora (dracut):** `sudo dracut --force --all`
- **Arch (mkinitcpio):** `sudo mkinitcpio -P`
