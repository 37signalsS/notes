## Определения

**Live Patching (Живое патчинг)** — это технология, позволяющая применять обновления безопасности и исправлять критические ошибки к работающему ядру Linux "на лету", без необходимости перезагрузки системы.

**`kexec`** — это системный вызов, который позволяет загрузить новое ядро Linux непосредственно из текущего работающего ядра, минуя этапы BIOS/UEFI и аппаратной инициализации (POST).

## Основные концепции

### Live Patching: `kpatch` и `ksplice`

- **Как работает:** Инструменты `kpatch` и `ksplice` применяют патчи к работающему ядру прямо в памяти. Они используют механизм `ftrace` для перенаправления вызовов старых, уязвимых функций на новые, исправленные версии, не останавливая работу системы.
- **Назначение:** Используется для критических обновлений безопасности и исправлений серьезных ошибок, не подходит для мажорных обновлений ядра.
- **Преимущества:** Максимальное время безотказной работы (uptime).

### Быстрая перезагрузка: `kexec`

- **Как работает:** `kexec` позволяет загрузить новое ядро из текущего, значительно сокращая время простоя, так как пропускается самый долгий этап — самотестирование оборудования.
- **Преимущества:** Значительно сокращает время перезагрузки по сравнению с полной перезагрузкой системы.

## Практические сценарии

### Использование `kexec`

1. **Загрузить новое ядро в память:**

    ```bash
    # Загрузить новое ядро и initramfs в память, используя текущие параметры командной строки ядра
    sudo kexec -l /boot/vmlinuz-новое-ядро --initrd=/boot/initrd.img-новое-ядро --reuse-cmdline
    ```

2. **Выполнить "перезагрузку":**

    ```bash
    # Система немедленно начнет загрузку нового ядра
    sudo systemctl kexec
    # или
    sudo kexec -e
    ```

## Дополнительная информация

### Реализации Live Patching

- **`kpatch`**: Разработан Red Hat, является основой для сервисов live patching в RHEL, AlmaLinux, Oracle Linux.
- **`ksplice`**: Разработан Oracle, используется в Oracle Linux.
- **Canonical Livepatch**: Сервис от Canonical для систем Ubuntu.
- **KernelCare**: Коммерческий сервис от TuxCare.
