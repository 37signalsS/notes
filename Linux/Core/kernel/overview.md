## Определения

**Ядро (Kernel)** — это самый низкий уровень программного обеспечения и центральный, наиболее важный компонент операционной системы. Оно выступает в роли моста между программным обеспечением и аппаратной частью компьютера.

**Основные задачи ядра:**
-   **Управление процессами:** Запуск, остановка и планирование процессов, выделение им процессорного времени. (См. [Процессы в Linux](../processes/overview.md))
-   **Управление памятью:** Распределение оперативной памяти между процессами, организация виртуальной памяти и подкачки. (См. Управление памятью в Linux)
-   **Управление устройствами:** Взаимодействие с оборудованием через драйверы.
-   **Системные вызовы:** Предоставление программам безопасного интерфейса для запроса услуг у ядра.

## Основные концепции

### Модульная архитектура

Ядро Linux имеет модульную структуру. **Модули ядра** — это фрагменты кода, которые можно динамически загружать в ядро или выгружать из него по мере необходимости. Это позволяет расширять функциональность, не перезагружая систему и не пересобирая ядро.

С помощью модулей реализуются:

-   Драйверы устройств (для видеокарт, сетевых адаптеров, USB-устройств).
-   Драйверы файловых систем (ext4, xfs, btrfs).
-   Сетевые протоколы и многое другое.

#### Lazy Loading (Загрузка по требованию)

Ключевой особенностью является **Lazy Loading** — механизм, при котором модули загружаются не при старте системы, а только тогда, когда они действительно необходимы. Например, модуль для файловой системы `vfat` не будет загружен, пока вы не попытаетесь смонтировать USB-накопитель, отформатированный в FAT32.

#### Управление модулями (`modprobe`)

-   **Просмотреть загруженные модули:** `lsmod`
-   **Загрузить модуль (и его зависимости):** `sudo modprobe <имя_модуля>`
-   **Выгрузить модуль:** `sudo modprobe -r <имя_модуля>`
-   **Запретить загрузку модуля (blacklist):** Создайте `.conf` файл в `/etc/modprobe.d/` с содержанием `blacklist <имя_модуля>`.

### "Загрязнение" ядра (Kernel Taint)

**Taint-флаг** — это механизм ядра, который указывает на то, что система находится в нестандартном или потенциально нестабильном состоянии. "Загрязненное" ядро может усложнить диагностику, и разработчики ядра часто просят воспроизвести проблему на "чистом" ядре.

Состояние флага можно проверить командой `cat /proc/sys/kernel/tainted`. `0` — ядро чистое.

**Основные причины "загрязнения":**
-   `P` (Proprietary Module): Загружен проприетарный (не-GPL) модуль, например, драйвер NVIDIA.
-   `F` (Forcefully Loaded): Модуль был загружен принудительно (`insmod -f`).
-   `O` (Out-of-tree Module): Загружен модуль, не входящий в официальное дерево исходного кода ядра.
-   `W` (Warning): Ядро ранее выдало предупреждение.
-   `M` (Machine Check Error): Произошёл аппаратный сбой.
