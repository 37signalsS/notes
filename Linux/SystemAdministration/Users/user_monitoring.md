# Мониторинг пользователей

- **`id <username>`**: Выводит UID, GID (первичная группа) и `groups` (все группы).
- `who`: Показывает, кто из пользователей в данный момент вошел в систему.
- `w`: Более подробный вывод, чем у `who`, включая запущенные процессы. Подробнее см. в [w: Кто работает в системе](../Diagnostics/Processes/w.md).
- `last`: Показывает историю последних входов в систему.
