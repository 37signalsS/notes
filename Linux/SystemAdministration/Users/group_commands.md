# Управление группами

## Определения

- **`groupadd`** — создание новой группы
- **`groupmod`** — модификация параметров группы
- **`groupdel`** — удаление группы
- **`gpasswd`** — управление членством в группах и паролями групп
- **`newgrp`** — переключение первичной группы в текущей сессии
- **Первичная группа (Primary Group)** — основная группа пользователя, указывается в `/etc/passwd`, файлы создаются с этой группой по умолчанию
- **Дополнительные группы (Supplementary Groups)** — группы для получения дополнительных прав, задаются в `/etc/group`

- **Дополнительные группы:** см. [Определения](#определения)

### Системные и обычные группы

| Диапазон GID | Назначение |
| :--- | :--- |
| **GID 0** | `root` — суперпользователь |
| **GID 1-99** | Статические системные группы |
| **GID 100-999** | Динамические системные группы |
| **GID 1000+** | Обычные группы пользователей |

## Практические сценарии

### Создание групп

```bash
# Создание обычной группы
sudo groupadd new-group

# Создание с указанием GID
sudo groupadd -g 1500 new-group

# Создание системной группы
sudo groupadd -r new-sys-group

# Создание группы с паролем (редко используется)
sudo groupadd -p '$6$salt$hash' new-group
```

### Изменение групп

```bash
# Изменение имени группы
sudo groupmod -n new-name old-name

# Изменение GID
sudo groupmod -g 1501 group-name

# Изменение имени и GID одновременно
sudo groupmod -n new-name -g 1502 old-name
```

### Удаление групп

```bash
# Удаление группы
sudo groupdel group-name

# Нельзя удалить, если группа является первичной для пользователя
```

### Управление членством в группах

#### Как добавить пользователя в группу

```bash
# Добавить пользователя в группу (рекомендуемый способ, -a — append)
sudo usermod -aG groupname username

# Добавить через gpasswd
sudo gpasswd -a username groupname
```

#### Как удалить пользователя из группы

```bash
# Удалить пользователя из группы
sudo gpasswd -d username groupname
```

#### Другие операции с членством

```bash
# Добавить пользователя в несколько групп одновременно
sudo usermod -aG group1,group2,group3 username

# Назначить администратора группы
# Администратор может добавлять/удалять пользователей без root
sudo gpasswd -A username groupname

# Добавить нескольких пользователей в группу (только администратор группы)
sudo gpasswd -M user1,user2,user3 groupname

# Установить пароль группы (для временного доступа)
sudo gpasswd groupname
```

### Переключение группы в сессии

```bash
# Запуск новой оболочки с изменённой первичной группой
newgrp group-name

# Проверка текущей группы
id -gn

# Проверка всех групп пользователя
id -Gn
groups username
```

### Просмотр информации о группах

```bash
# Информация о группе
getent group groupname

# Все группы в системе
getent group

# Пользователи в группе
getent group groupname | cut -d: -f4

# Группы пользователя
groups username

# Основная группа пользователя
id -gn username
```

### Аудит привилегированных групп

```bash
# Проверка членов группы wheel (RHEL/CentOS)
getent group wheel

# Проверка членов группы sudo (Debian/Ubuntu)
getent group sudo

# Проверка членов группы docker
getent group docker

# Все пользователи с UID >= 1000 и их группы
for user in $(awk -F: '$3 >= 1000 {print $1}' /etc/passwd); do
    echo "$user: $(groups $user)"
done
```

## Дополнительная информация

### Распространенные ошибки

| Ошибка | Причина | Решение |
| :--- | :--- | :--- |
| `groupdel: нельзя удалить первичную группу` | Группа является primary для пользователя | Сначала смените первичную группу пользователя |
| `groupmod: GID уже существует` | GID занят другой группой | Используйте другой GID |
| Пользователь не видит новые группы | Группы применятся после перелогина | Используйте `newgrp` или перелогиньтесь |

### Привилегированные группы

| Группа | Назначение | Дистрибутив |
| :--- | :--- | :--- |
| `wheel` | Доступ к `sudo` | RHEL/CentOS/Fedora |
| `sudo` | Доступ к `sudo` | Debian/Ubuntu |
| `docker` | Управление Docker | Все |
| `kvm` | Доступ к KVM | Все |
| `libvirt` | Управление libvirt | Все |
| `wireshark` | Перехват трафика | Все |
| `plugdev` | Доступ к съёмным устройствам | Debian/Ubuntu |
| `video` | Доступ к видеоустройствам | Все |
| `audio` | Доступ к аудиоустройствам | Все |

### Лучшие практики

1. **Принцип наименьших привилегий:** Добавляйте в привилегированные группы (`wheel`, `sudo`, `docker`) только доверенных пользователей
2. **Регулярный аудит:** Проверяйте членство в привилегированных группах
3. **Системные группы:** Не используйте GID < 1000 для обычных групп
