# Управление пользователями

## Создание пользователей (`useradd`, `adduser`)

Настройки по умолчанию для `useradd` можно посмотреть командой `useradd -D` и изменить в файлах `/etc/default/useradd` и `/etc/login.defs`.

- **`adduser`**: интерактивная и более дружелюбная утилита.
- **`useradd`**: низкоуровневая утилита, удобная для скриптов.

```bash
# Интерактивное создание
sudo adduser test-user

# Создание со стандартными параметрами
sudo useradd test-user
```

**Ключевые флаги `useradd`:**

- **-m**: создаёт указанную домашнюю директорию, если она ещё не существует
- **-d /home/test-user**: устанавливает `/home/test-user` в качестве домашней директории
- **-c "Имя Фамилия"**: добавляет комментарий. Например, с именем пользователя
- **-g test**: указывает группу, в которую попадёт пользователь после создания. Можно использовать с GID или именем группы. Указанная группа должна существовать. Используется в сочетании с ключом -N (отменяет автоматическое создание группы с именем пользователя)
- **-G users,wheel**: указывает список дополнительных групп пользователя. Они перечисляются через запятую без пробелов
- **-s /bin/bash**: позволяет настроить доступ к shell. Например: `sudo adduser --shell /bin/sh user3`
- **-r**: создаёт системного пользователя. Используется, когда вам нужно настроить службу на работу из-под конкретного пользователя. По умолчанию данные таких пользователей не вносятся в `/etc/shadow`, для них не создаётся домашняя папка
- **-u**: позволяет указать свой UID, который будет присвоен новому пользователю. В качестве UID указыва целое число. UID должен быть уникален
ется положительное- **-e 2021-01-01**: указывает дату, до которой аккаунт будет активен. Дата задаётся в формате YYYY-MM-DD
- **-f 3**: указывает количество дней до блокировки пользователя, когда его пароль станет недействителен

Очень важно после создания пользователя настроить для него надёжный пароль.

```bash
sudo passwd test-user
```

## Изменение пользователей (`usermod`)

Перед изменением данных пользователя рекомендуется убедиться, что он не активен в системе.

```bash
# Проверить запущенные процессы пользователя
pgrep -l -u username
# Проверить, залогинен ли пользователь
pinky username
```

**Ключевые флаги `usermod`:**

- **-l new-name**: Изменить имя пользователя.
- **-d /home/new-dir -m**: Изменить домашнюю директорию и перенести в нее старое содержимое.
- **-c "Комментарий"**: Изменить комментарий.
- **-a -G group**: **Добавить** пользователя в дополнительную группу. **Ключ `-a` (append) обязателен, иначе пользователь будет удален из всех остальных доп. групп!**
- **-g new_group**: Изменить *первичную* группу.
- **-L**: Заблокировать учетную запись.
- **-U**: Разблокировать учетную запись.
- **-s /bin/nologin**: Отключить пользователю возможность входа в систему.
- **-u new_UID**: Изменить UID пользователя.
- **-e YYYY-MM-DD**: Изменить дату истечения срока действия учетной записи.

## Удаление пользователей (`userdel`)

```bash
# Удалить пользователя вместе с его домашней директорией и почтовым ящиком
sudo userdel -r username

# Принудительное удаление, даже если пользователь активен (использовать с осторожностью!)
sudo userdel -f username
```
