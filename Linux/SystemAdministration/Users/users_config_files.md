# Файлы конфигурации пользователей и групп в Linux

## Определения

- **`/etc/passwd`** — основная база данных учётных записей пользователей.
- **`/etc/shadow`** — файл, содержащий зашифрованные пароли и параметры их срока действия.
- **`/etc/group`** — база данных групп пользователей.
- **`/etc/gshadow`** — зашифрованная информация о группах и их администраторах.
- **`/etc/skel`** — директория-шаблон, содержащая файлы, которые копируются в домашнюю директорию нового пользователя при её создании.

## Базовые концепции

### Формат записей

Большинство конфигурационных файлов пользователей в Linux используют текстовый формат с полями, разделёнными двоеточием (`:`). Каждая строка соответствует одной записи.

### Структура /etc/passwd

Файл доступен для чтения всем пользователям системы. Это необходимо для корректного отображения имён владельцев файлов и групп.

**Формат:** `username:password:UID:GID:GECOS:home_directory:shell`

| Поле | Пример | Описание |
| :--- | :--- | :--- |
| **username** | `magicfun` | Уникальное имя пользователя. |
| **password** | `x` | Признак наличия пароля (`x` означает, что хэш хранится в `/etc/shadow`). |
| **UID** | `1000` | **UID (User ID)** — уникальный числовой идентификатор пользователя. |
| **GID** | `1000` | **GID (Group ID)** — идентификатор основной (первичной) группы пользователя. |
| **GECOS** | `Ivanov I.I.` | **GECOS (General Electric Comprehensive Operating Supervisor)** — информационное поле (обычно содержит полное имя пользователя). |
| **home_directory** | `/home/magicfun` | Путь к домашней директории. |
| **shell** | `/bin/bash` | Путь к командной оболочке, запускаемой при входе. |

**Оболочки для блокировки входа:**

| Оболочка | Описание |
| :--- | :--- |
| `/sbin/nologin` | Выводит сообщение о запрете входа и завершает сессию. Сообщение настраивается в `/etc/nologin.txt`. |
| `/bin/false` | Завершает сессию немедленно без вывода сообщения. |
| `/usr/sbin/nologin` | Аналог `/sbin/nologin` (часто используется в Debian/Ubuntu). |

### Структура /etc/shadow

Файл содержит критически важную информацию и доступен для чтения только пользователю `root`.

**Формат:** `username:password:last_change:min:max:warn:inactive:expire:reserved`

| Поле | Пример | Описание |
| :--- | :--- | :--- |
| **username** | `magicfun` | Имя пользователя. |
| **password** | `$6$...` | Хэш пароля. Знаки `!` или `*` означают, что учётная запись заблокирована. |
| **last_change** | `20215` | Количество дней с 01.01.1970 до последней смены пароля. |
| **min** | `0` | Минимальное количество дней между сменами пароля. |
| **max** | `99999` | Максимальный срок действия пароля в днях. |
| **warn** | `7` | За сколько дней до истечения срока действия пароля выводить предупреждение. |
| **inactive** | (пусто) | Количество дней после истечения срока действия пароля, через которые учётная запись будет заблокирована. |
| **expire** | (пусто) | Дата истечения срока действия учётной записи (дни с 01.01.1970). |

**Формат хэша:** `$id$salt$hashed`. Подробности об алгоритмах приведены в разделе [хэширование паролей](./password_hashing.md).

### Структура /etc/group

Определяет список групп и их первичный состав.

**Формат:** `group_name:password:GID:user_list`

- **group_name**: Имя группы.
- **password**: Пароль группы (используется крайне редко).
- **GID**: Уникальный идентификатор группы.
- **user_list**: Список пользователей, для которых данная группа является дополнительной (через запятую).

## Практические сценарии

### Анализ и поиск данных

```bash
# Просмотр всех пользователей и их оболочек
cat /etc/passwd

# Поиск конкретного пользователя в базе
grep "^username:" /etc/passwd

# Извлечение списка всех имён пользователей
cut -d: -f1 /etc/passwd

# Поиск обычных пользователей (UID >= 1000)
awk -F: '$3 >= 1000 {print $1, $7}' /etc/passwd

# Поиск заблокированных учётных записей в shadow
sudo grep -E ':(!!|\*):' /etc/shadow
```

### Добавление пользователя вручную

Метод используется для глубокого понимания работы системы или в условиях отсутствия утилит `useradd`/`adduser`.

1. **Добавление записи в /etc/passwd:**

   ```bash
   echo "newuser:x:1001:1001:New User:/home/newuser:/bin/bash" | sudo tee -a /etc/passwd
   ```

2. **Добавление записи в /etc/group:**

   ```bash
   echo "newuser:x:1001:" | sudo tee -a /etc/group
   ```

3. **Генерация хэша и добавление в /etc/shadow:**

   ```bash
   # Генерация хэша SHA-512
   openssl passwd -6 "password"
   # Добавление записи (замените <hash> на результат команды выше)
   echo "newuser:<hash>:19000:0:99999:7:::" | sudo tee -a /etc/shadow
   ```

4. **Создание домашней директории из шаблона /etc/skel:**

   ```bash
   sudo mkdir /home/newuser
   sudo cp -r /etc/skel/. /home/newuser/
   sudo chown -R 1001:1001 /home/newuser
   sudo chmod -R 700 /home/newuser
   ```

### Аудит безопасности

```bash
# Поиск пользователей с пустым паролем
sudo awk -F: '($2 == "") {print $1}' /etc/shadow

# Проверка на наличие лишних пользователей с UID 0 (кроме root)
awk -F: '($3 == 0 && $1 != "root")' /etc/passwd

# Поиск дублирующихся UID
cut -d: -f3 /etc/passwd | sort | uniq -d

# Проверка прав доступа на критические файлы
ls -l /etc/passwd /etc/shadow /etc/group /etc/gshadow
# Рекомендуемые права:
# /etc/passwd: 644 (root:root)
# /etc/shadow: 640 (root:shadow) или 600 (root:root)
```

## Дополнительная информация

### Векторы атак и безопасность

**Эскалация привилегий через /etc/passwd:**
Если злоумышленник получит права на запись в файл `/etc/passwd`, он может:

- Изменить UID своего пользователя на `0`.
- Добавить новую запись с UID `0` и известным ему хэшем пароля.
- Убрать символ `x` во втором поле своей записи, что позволит войти без пароля (если система настроена на поиск хэшей в `/etc/passwd`).

**Безопасность /etc/shadow:**
Никогда не делайте этот файл доступным для чтения обычным пользователям. Хотя пароли захэшированы, они могут быть подвергнуты офлайн-атаке методом перебора (Brute-force) с использованием словарей или радужных таблиц.

### Резервное копирование

Перед внесением любых изменений в эти файлы рекомендуется создавать их резервные копии:

```bash
sudo cp /etc/passwd /etc/passwd.bak
sudo cp /etc/shadow /etc/shadow.bak
sudo cp /etc/group /etc/group.bak
```

### Связанные файлы и параметры

- **`/etc/login.defs`** — содержит глобальные параметры для подсистемы создания пользователей и групп.
  - `ENCRYPT_METHOD` — используемый алгоритм хэширования (рекомендуется `SHA512` или `YESCRYPT`).
  - `UID_MIN`, `UID_MAX` — диапазоны идентификаторов для обычных пользователей.
- **`/etc/default/useradd`** — настройки утилиты `useradd` по умолчанию.
- **[`pam_overview.md`](../../Security/pam_overview.md)** — **PAM (Pluggable Authentication Modules)** — подсистема, отвечающая за процесс аутентификации через данные файлы.
- **[`users_definitions.md`](./users_definitions.md)** — подробнее о различиях между системными и обычными пользователями, а также концепции **UPG (User Private Groups)**.
