# Файлы конфигурации пользователей и групп

## /etc/passwd

Содержит основную информацию о пользователях.

| Поле № | Пример | Описание |
|---|---|---|
| 1 | `daemon` | Имя пользователя |
| 2 | `x` | Пароль (`x` означает, что хэш хранится в `/etc/shadow`) |
| 3 | `1` | UID (User ID) |
| 4 | `1` | GID (Group ID) — идентификатор *первичной* группы |
| 5 | `daemon` | Комментарий (GECOS), часто полное имя |
| 6 | `/usr/sbin` | Домашняя директория |
| 7 | `/usr/sbin/nologin` | Оболочка входа (shell), запрещающая вход |

**Оболочки для блокировки входа:**
- **`/sbin/nologin`**: Выводит сообщение о том, что вход запрещен. Сообщение можно настроить в файле `/etc/nologin.txt`.
- **`/bin/false`**: Просто возвращает код ошибки (false), не выводя сообщения. Используется для сервисных аккаунтов, от которых не требуется интерактивный вход.

## /etc/shadow

Хранит хэши паролей и информацию о сроке их действия. **Доступен для чтения только `root`**.

| Поле № | Пример | Объяснение |
|---|---|---|
| 1 | `magicfun` | Имя пользователя. |
| 2 | `$6$...` или `!` или `*` | Хэш пароля. Формат: `$id$salt$hashed`. `id` (`6`) указывает на алгоритм (SHA-512), `salt` - соль, `hashed` - сам хэш. `!` или `*` означает, что учетная запись заблокирована. |
| 3 | `20215` | Дата последней смены пароля (дней с 01.01.1970). |
| 4 | `0` | Минимальный срок действия пароля (в днях). `0` — можно менять в любое время. |
| 5 | `99999` | Максимальный срок действия пароля (в днях). |
| 6 | `7` | Период предупреждения (в днях) до истечения срока действия пароля. |
| 7 | (пусто) | Период неактивности (в днях), после которого учетная запись будет заблокирована, если пароль истек. |
| 8 | (пусто) | Дата истечения срока действия учетной записи (дней с 01.01.1970). |
| 9 | (пусто) | Зарезервировано для будущего использования. |

## /etc/group

Определяет группы и их членов.

## /etc/gshadow

Хранит защищенную информацию о группах (например, пароли групп, что используется редко).

## /etc/skel

Содержит "скелет" (шаблоны файлов и директорий), которые автоматически копируются в домашнюю директорию нового пользователя при его создании. Это позволяет настроить окружение пользователя по умолчанию (например, `.bashrc`, `.profile`).
