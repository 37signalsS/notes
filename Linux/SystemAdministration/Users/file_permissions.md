# Права доступа к файлам и директориям

Управление доступом к файлам — ключевой аспект безопасности в Linux. Он определяет, кто и что может делать с файлами и директориями.

## Основные понятия

- **Владелец (User, `u`):** Пользователь, который создал файл.
- **Группа (Group, `g`):** Группа, которой принадлежит файл. Позволяет дать одинаковые права нескольким пользователям.
- **Остальные (Others, `o`):** Все остальные, кто не является владельцем и не входит в группу.

## Типы прав

- **`Read (r)` (Чтение):**
    - Для файлов: позволяет просматривать содержимое.
    - Для директорий: позволяет просматривать список файлов (`ls`).
- **`Write (w)` (Запись):**
    - Для файлов: позволяет изменять содержимое.
    - Для директорий: позволяет создавать, удалять и переименовывать файлы в ней.
- **`Execute (x)` (Выполнение):**
    - Для файлов: позволяет запускать файл как программу.
    - Для директорий: позволяет войти в директорию (`cd`).

## Просмотр прав (`ls -l`)

Команда `ls -l` показывает права в виде строки из 10 символов: `d rwx r-x r--`.

- **1-й символ:** тип файла (`d` - директория, `-` - файл).
- **2-4 символы:** права для **владельца** (`rwx`).
- **5-7 символы:** права для **группы** (`r-x`).
- **8-10 символы:** права для **остальных** (`r--`).

## Управление правами: `chmod`

Команда `chmod` (change mode) изменяет права доступа.

### Числовой режим

Каждому праву соответствует число: `r=4`, `w=2`, `x=1`. Права в триаде суммируются.

```bash
# rwxr-xr-x (стандарт для исполняемых файлов и директорий)
sudo chmod 755 script.sh

# rw-r--r-- (стандарт для обычных файлов)
sudo chmod 644 data.txt

# rw------- (максимально приватные права, например, для SSH ключей)
sudo chmod 600 private_key
```

### Символьный режим

Более нагляден для точечных изменений.

```bash
# Добавить право на выполнение для владельца
sudo chmod u+x script.sh

# Убрать право на запись для группы
sudo chmod g-w data.txt

# Установить права: чтение/запись для владельца, только чтение для группы и остальных
sudo chmod u=rw,go=r config.conf
```

## Управление владельцами: `chown`

Команда `chown` (change owner) изменяет владельца и/или группу файла.

```bash
# Сменить владельца файла
sudo chown alice report.txt

# Сменить владельца и группу файла
sudo chown alice:developers report.txt

# Рекурсивно сменить владельца для директории и всего ее содержимого
sudo chown -R alice /home/alice/project
```
