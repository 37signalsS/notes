# Перенос пользователей между системами

Этот метод наиболее безопасен при переносе на "чистую" систему, чтобы избежать конфликтов UID/GID.

1. **Создайте резервные копии** на целевой машине.
2. **Скопируйте файлы конфигурации** с исходной машины:

    ```bash
    # На целевой машине
    scp root@source_machine:/etc/{passwd,shadow,group,gshadow} /tmp/
    # После проверки можно переместить в /etc/
    ```

3. **Скопируйте домашние директории**, сохраняя права:

    ```bash
    # На целевой машине
    rsync -avz root@source_machine:/home/ /home/
    ```
