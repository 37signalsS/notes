# Управление политиками паролей в Linux (chage)

## Определения

- **chage (change age)** — системная утилита, предназначенная для изменения параметров истечения срока действия паролей пользователей и блокировки учётных записей.
- **Срок действия пароля (Password Aging)** — механизм безопасности, принуждающий пользователя регулярно менять пароль для снижения риска его компрометации.
- **Период неактивности (Inactivity Period)** — количество дней после истечения срока действия пароля, в течение которых пользователь всё ещё может его сменить самостоятельно; по истечении этого периода учётная запись блокируется.

## Базовые концепции

Утилита `chage` напрямую модифицирует соответствующие поля в файле `/etc/shadow`. Основные параметры включают:

| Параметр | Описание | Единица измерения |
| :--- | :--- | :--- |
| **Last password change** | Дата последнего изменения пароля. | Дни с 01.01.1970 |
| **Minimum** | Минимальное количество дней между сменами пароля. | Дни |
| **Maximum** | Максимальный срок действия пароля. | Дни |
| **Warning** | Количество дней до истечения пароля, за которые выводится предупреждение. | Дни |
| **Inactive** | Количество дней после истечения пароля до блокировки учётной записи. | Дни |
| **Account expires** | Дата, после которой учётная запись становится недействительной. | Дата или дни с 01.01.1970 |

## Практические сценарии

### Просмотр текущих настроек пользователя

```bash
# Вывод подробной информации о политике пароля
sudo chage -l username

# Пример вывода:
# Last password change                             : Jan 01, 2026
# Password expires                                 : Apr 01, 2026
# Password inactive                                : (never)
# Account expires                                  : (never)
# Minimum number of days between password change   : 0
# Maximum number of days between password change   : 90
# Number of days of warning before password expires: 7
```

### Настройка параметров истечения

```bash
# Установить максимальный срок действия (90 дней)
sudo chage -M 90 username

# Установить минимальный срок между сменами (7 дней)
sudo chage -m 7 username

# Установить период предупреждения (14 дней)
sudo chage -W 14 username

# Установить период неактивности до блокировки (30 дней)
sudo chage -I 30 username

# Установить дату истечения учётной записи
sudo chage -E 2026-12-31 username

# Сделать учётную запись бессрочной
sudo chage -E -1 username

# Установить все параметры одной командой
sudo chage -m 7 -M 90 -W 14 -I 30 -E 2026-12-31 username
```

### Принудительная смена пароля

Применяется для новых пользователей или при подозрении на компрометацию.

```bash
# Заставить пользователя сменить пароль при следующем входе
sudo chage -d 0 username

# Аналог через passwd
sudo passwd --expire username

# Установить дату последней смены на текущий день (сброс счётчика)
sudo chage -d $(date +%Y-%m-%d) username
```

### Глобальная настройка в системе

Для того чтобы новые пользователи автоматически получали определённые политики, необходимо отредактировать файл `/etc/login.defs`.

```bash
# /etc/login.defs
PASS_MAX_DAYS   90    # Максимальный срок
PASS_MIN_DAYS   7     # Минимальный срок
PASS_WARN_AGE   14    # Период предупреждения
```

Применение новых глобальных настроек к существующим пользователям:

```bash
for user in $(awk -F: '$3 >= 1000 {print $1}' /etc/passwd); do
    sudo chage -M 90 -m 7 -W 14 "$user"
done
```

### Аудит и автоматизация

#### Поиск пользователей с бессрочными паролями

```bash
sudo awk -F: '($5 == 99999) {print $1}' /etc/shadow
```

#### Скрипт для уведомления об истечении срока пароля

```bash
#!/bin/bash
# Проверка пользователей, чьи пароли истекают менее чем через 7 дней

for user in $(awk -F: '$3 >= 1000 {print $1}' /etc/passwd); do
    exp_date=$(sudo chage -l "$user" | grep "Password expires" | cut -d: -f2)
    if [[ "$exp_date" != " never" ]]; then
        exp_epoch=$(date -d "$exp_date" +%s)
        now_epoch=$(date +%s)
        diff=$(( (exp_epoch - now_epoch) / 86400 ))
        if [ "$diff" -le 7 ] && [ "$diff" -ge 0 ]; then
            echo "Внимание: пароль пользователя $user истекает через $diff дн."
        fi
    fi
done
```

## Дополнительная информация

### Взаимодействие с PAM

Механизмы `chage` работают на уровне системных вызовов, которые используются модулем **PAM (Pluggable Authentication Modules)** — `pam_unix.so`. При входе пользователя в систему PAM проверяет поля в `/etc/shadow` и, если пароль истёк, запрашивает его смену.

Для более строгих политик сложности паролей (а не только срока их действия) используется модуль `pam_pwquality.so`.

### Распространённые проблемы

| Ошибка | Причина | Решение |
| :--- | :--- | :--- |
| `chage: Permission denied` | Запуск без прав суперпользователя. | Используйте `sudo`. |
| `Password expires: never` | Поле Max установлено в 99999 или -1. | Установите конкретное значение через `-M`. |
| Учётная запись заблокирована внезапно | Истёк период Inactive. | Разблокируйте через `sudo usermod -U username` или измените дату истечения. |
