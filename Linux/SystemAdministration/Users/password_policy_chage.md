# Управление политиками паролей (`chage`)

Команда `chage` (change age) позволяет детально управлять сроком действия паролей и учетных записей.

- **Просмотр текущих политик:** `sudo chage -l username`
- **Установить макс. срок действия пароля (90 дней):** `sudo chage -M 90 username`
- **Заставить сменить пароль при след. входе:** `sudo chage -d 0 username`
- **Установить дату истечения срока действия УЗ:** `sudo chage -E "YYYY-MM-DD" username`
- **Сделать УЗ бессрочной:** `sudo chage -E -1 username`
- **Предупреждать о смене за 7 дней:** `sudo chage -W 7 username`
- **Задать мин. срок между сменами (14 дней):** `sudo chage -m 14 username`
