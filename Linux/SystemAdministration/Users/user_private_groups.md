# Приватные группы пользователей (User Private Groups, UPG)

При создании нового пользователя (например, `useradd username`) без указания группы автоматически создается группа с таким же именем (`username`). Эта группа становится **первичной** для данного пользователя.

- [Управление группами](./group_commands.md)
