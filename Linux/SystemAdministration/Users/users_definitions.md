# Определения

- **Пользователь (User):** Учетная запись, позволяющая человеку или процессу взаимодействовать с системой. Каждому пользователю присваивается уникальный идентификатор (**UID**).
- **Группа (Group):** Механизм для объединения пользователей с целью предоставления им общих прав доступа. Каждой группе присваивается уникальный идентификатор (**GID**).
- **Суперпользователь (root):** Специальный пользователь с UID 0, обладающий неограниченными правами в системе.
- **Первичная группа (Primary Group):** Основная группа пользователя, которая по умолчанию назначается создаваемым им файлам. У пользователя может быть только одна первичная группа.
- **Дополнительные группы (Supplementary Groups):** Группы, в которые пользователь может быть добавлен для получения дополнительных прав.
- **Системные и обычные пользователи:** В Linux принято соглашение о диапазонах UID.
  - **UID 0**: Зарезервирован для `root`.
  - **UID 1-99**: Зарезервированы для статических системных сервисов (daemons).
  - **UID 100-999**: Зарезервированы для динамически назначаемых системных сервисов (pseudo-users).
  - **UID 1000+**: Обычные пользователи для интерактивного входа.
  - **Системные пользователи (UID < 1000):** Зарезервированы для системных служб и демонов. Создание обычного пользователя в этом диапазоне нарушает конвенцию и может привести к конфликтам.
  - **Обычные пользователи (UID >= 1000):** Предназначены для интерактивного входа людей.
