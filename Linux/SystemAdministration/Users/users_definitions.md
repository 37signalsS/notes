# Определения пользователей и групп в Linux

## Определения

- **Пользователь (User):** Учетная запись, позволяющая человеку или процессу взаимодействовать с системой. Каждому пользователю присваивается уникальный идентификатор (**UID**).
- **Группа (Group):** Механизм для объединения пользователей с целью предоставления им общих прав доступа. Каждой группе присваивается уникальный идентификатор (**GID**).
- **Суперпользователь (root):** Специальный пользователь с UID 0, обладающий неограниченными правами в системе.
- **Первичная группа (Primary Group):** Основная группа пользователя, которая по умолчанию назначается создаваемым им файлам. У пользователя может быть только одна первичная группа.
- **Дополнительные группы (Supplementary Groups):** Группы, в которые пользователь может быть добавлен для получения дополнительных прав.
- **Системные пользователи (UID < 1000):** Зарезервированы для системных служб и демонов. Создание обычного пользователя в этом диапазоне нарушает конвенцию и может привести к конфликтам.
- **Обычные пользователи (UID >= 1000):** Предназначены для интерактивного входа людей.

## Базовые концепции

### Диапазоны UID

| Диапазон | Назначение |
| :--- | :--- |
| **UID 0** | `root` — суперпользователь |
| **UID 1-99** | Статические системные сервисы (daemons) |
| **UID 100-999** | Динамически назначаемые системные сервисы (pseudo-users) |
| **UID 1000+** | Обычные пользователи для интерактивного входа |

> **Примечание:** В некоторых дистрибутивах (например, Debian) диапазон системных пользователей может быть расширен до UID 999.

### Повышение привилегий

- **`su` (Switch User):** Полное переключение сессии на другого пользователя. Требует пароль целевого пользователя.
- **`sudo` (Superuser Do):** Выполнение одной команды от имени другого пользователя. Требует пароль текущего пользователя и настройку в `/etc/sudoers`.
- **Группы привилегий:**
  - **`wheel`** — CentOS/RHEL/Fedora
  - **`sudo`** — Debian/Ubuntu

Подробнее см. [Управление привилегиями](../privilege_management.md).

## Практические сценарии

### Проверка информации о пользователе

```bash
# UID, GID и группы пользователя
id username

# Все пользователи в системе
cut -d: -f1 /etc/passwd

# Пользователи с UID >= 1000 (обычные пользователи)
awk -F: '$3 >= 1000 {print $1}' /etc/passwd

# Системные пользователи
awk -F: '$3 < 1000 && $3 != 0 {print $1}' /etc/passwd
```

### Проверка членства в группах

```bash
# Группы пользователя
groups username

# Все пользователи в группе
getent group groupname
```

### Безопасность

- **Принцип наименьших привилегий:** Пользователь должен иметь только те права, которые необходимы для выполнения задач.
- **Конфликты UID/GID:** При миграции пользователей следите за уникальностью идентификаторов.
- **Системные пользователи:** Не используйте диапазон UID < 1000 для обычных пользователей.
