# Определения пользователей и групп в Linux

## Определения

**Пользователь (User)** — учётная запись, позволяющая человеку или процессу взаимодействовать с системой. Каждому пользователю присваивается уникальный числовой идентификатор — **UID (User ID)**.

**Группа (Group)** — механизм объединения пользователей для предоставления общих прав доступа. Каждой группе присваивается уникальный числовой идентификатор — **GID (Group ID)**.

**Суперпользователь (root)** — специальный пользователь с UID 0, обладающий неограниченными правами в системе.

> **Важно (Дублирование UID):** Идентификация в Linux основана на UID, а не на имени пользователя. Система позволяет иметь несколько записей в `/etc/passwd` с UID 0. Все такие пользователи будут обладать правами `root`. Подробнее о создании таких аккаунтов см. в [практических сценариях](./user_commands.md#дублирование-root-создание-пользователя-с-uid-0).

**Первичная группа (Primary Group)** — основная группа пользователя; по умолчанию назначается создаваемым им файлам. У пользователя может быть только одна первичная группа.

**Дополнительные группы (Supplementary Groups)** — группы, в которые пользователь может быть добавлен для получения дополнительных прав.

**Системные пользователи** — пользователи с UID < 1000, зарезервированы для системных служб и демонов. Создание обычного пользователя в этом диапазоне нарушает конвенцию и может привести к конфликтам.

**Обычные пользователи** — пользователи с UID >= 1000, предназначены для интерактивного входа людей.

## Базовые концепции

### Диапазоны UID и GID

| Диапазон | Назначение |
| :--- | :--- |
| **ID 0** | `root` — суперпользователь / группа root |
| **ID 1–99** | Статические системные сервисы и группы |
| **ID 100–999** | Динамические системные сервисы и группы |
| **ID 1000+** | Обычные пользователи и их группы |

> **Примечание:** В некоторых дистрибутивах (например, Debian) диапазон системных пользователей может быть расширен до UID 999.

## Практические сценарии

### Проверка информации о пользователе

```bash
# UID, GID и группы пользователя
id username

# Все пользователи в системе
cut -d: -f1 /etc/passwd

# Пользователи с UID >= 1000 (обычные пользователи)
awk -F: '$3 >= 1000 {print $1}' /etc/passwd

# Системные пользователи
awk -F: '$3 < 1000 && $3 != 0 {print $1}' /etc/passwd
```

### Проверка членства в группах

```bash
# Группы пользователя
groups username

# Все пользователи в группе
getent group groupname
```

## Дополнительная информация

### Безопасность

- **Принцип наименьших привилегий** — пользователь должен иметь только те права, которые необходимы для выполнения задач.
- **Конфликты UID/GID** — при миграции пользователей следите за уникальностью идентификаторов (подробнее: [миграция пользователей](./user_migration.md)).
- **Системные пользователи** — не используйте диапазон UID < 1000 для обычных пользователей.
