# Резервное копирование и восстановление в Linux

В Linux существует множество утилит и подходов для создания резервных копий, от простого копирования файлов до создания полных снимков системы. В этом документе рассматриваются различные инструменты и методики.

---

## Инструменты для создания образов

### genisoimage

**genisoimage** — это инструмент командной строки для создания образов файловой системы ISO 9660. Хотя его основное предназначение — создание загрузочных CD/DVD-ROM, его можно использовать для архивации больших объемов данных в один файл-образ (`.iso`).

Это может быть полезно для создания резервной копии состояния системы или набора файлов, которые затем можно легко хранить или передавать.

**Ключевые особенности:**
- Создает стандартные ISO-образы, совместимые с большинством систем.
- Используется для создания загрузочных дисков.
- Подходит для архивации больших каталогов в один файл.

**Пример использования:**
```bash
# Создать ISO-образ 'backup.iso' из содержимого каталога /path/to/data
genisoimage -o backup.iso -r /path/to/data
```
*Опция `-r` устанавливает корректные права доступа для файлов.*

## Файловые бэкапы

### rsync

**Rsync** — это мощная утилита для быстрой и эффективной синхронизации файлов и каталогов, как локально, так и между удаленными хостами. Передача файлов и синхронизация каталогов — одна из распространенных операций, которая часто осуществляется в автоматическом режиме (например, для создания резервных копий или совместной обработки проектов). Rsync широко используется для создания резервных копий, миграции данных и поддержания актуальности файлов между различными системами. Rsync способна поддерживать коннект по зашифрованным каналам SSH и SSL.

**Ключевые особенности:**
-   **Инкрементальная синхронизация:** Передает только измененные части файлов, что значительно экономит трафик и время.
-   **Удаленная синхронизация:** Работает по сети, используя протоколы SSH или rsync-демон.
-   **Сохранение атрибутов:** Может сохранять права доступа, владельца, группы, временные метки и символические ссылки.
-   **Гибкость:** Множество опций для тонкой настройки поведения.

**Базовая команда:**
```bash
rsync -av --progress /path/to/src/ /path/to/dest/
```
-   `-a` — архивный режим. Сохраняет права, временные метки, символические ссылки.
-   `-v` — подробный вывод.
-   `--progress` — показывает прогресс для каждого файла.

Если Вы копируете по сети на удалённый сервер, добавьте флаг `-z` для сжатия:
```bash
rsync -avz --progress /local/path/ user@server:/remote/path/
```
Если копирование прервалось, просто запустите ту же команду ещё раз — `rsync` пропустит уже скопированные файлы и продолжит с того же места.
