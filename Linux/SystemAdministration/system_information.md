## Версия ядра и операционной системы

```bash
uname -a
```

Альтернативный способ — посмотреть содержимое файла `/proc/version`:
```bash
cat /proc/version
```

## Определение дистрибутива Linux

Чтобы узнать, какой дистрибутив Linux используется, можно посмотреть содержимое специальных файлов в директории `/etc`.

-   **Основной способ (для современных систем):**
    ```sh
    cat /etc/os-release
    ```
    Этот файл содержит детальную информацию в формате `ключ=значение`, включая `NAME` (имя дистрибутива) и `VERSION` (версия).

-   **Альтернативные способы:**
    -   `cat /etc/lsb-release`: Используется в дистрибутивах, следующих стандарту LSB (Linux Standard Base), например, в Ubuntu.
    -   `cat /etc/redhat-release`: Для дистрибутивов на базе Red Hat (CentOS, Fedora).
    -   `cat /etc/debian_version`: Для Debian и его производных.

Узнать версию непосредственно установленного дистрибутива можно из конфигурационных файлов системы:
```bash
cat /etc/os-release
```
Либо через файл `/etc/issue`, который содержит системную информацию для сообщения при авторизации.

## Просмотр информации об оборудовании (Hardware)

На виртуальных серверах информация об оборудовании предоставляется и эмулируется гипервизором.

### Процессор (CPU)

**Модель, количество ядер, поддерживаемые инструкции, режим работы.**

**Модель процессора**
```bash
cat /proc/cpuinfo | grep 'model name'
# или
lscpu
```

**Ядра: физические и логические**
```bash
# Физические ядра на каждом процессоре
grep "cpu cores" /proc/cpuinfo | sort -u
# Общее количество логических ядер
grep -c "processor" /proc/cpuinfo
```
Или через `dmidecode`:
```bash
# Количество физических ядер
sudo dmidecode -t processor | grep "Core Enabled:"
# Количество логических ядер (с учетом Hyper-Threading)
sudo dmidecode -t processor | grep "Thread Count:"
```
*Физические ядра* - это реальные аппаратные компоненты. *Логические ядра* - это число физических ядер, умноженное на количество потоков, которые могут выполняться на каждом ядре (Hyper-Threading).

**Поддерживаемые инструкции**
```bash
cat /proc/cpuinfo | grep 'flags'
# или
lscpu
```

**Режимы работы процессора**
```bash
cat /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor
```
-   `powersave` — режим энергосбережения.
-   `ondemand` — режим, зависящий от текущей нагрузки.
-   `performance` — режим максимальной производительности.

### Память, материнская плата, BIOS

**Типы оперативной памяти (RAM)**
```bash
sudo dmidecode --type memory
# или
sudo dmidecode --type 17
```

**Модель материнской платы**
```bash
sudo dmidecode --type baseboard
```

**Версия BIOS/UEFI**
```bash
sudo dmidecode --type bios
```

### Датчики

**Текущие значения датчиков напряжения, температуры, оборотов вентиляторов.**

**Через `sensors` (требует установки `lm-sensors`)**
```bash
sensors
```

**Через `ipmicfg` (для серверов Supermicro с IPMI)**
```bash
sudo ipmicfg -pminfo
```

### Сетевые адаптеры

**Тип используемого сетевого адаптера и состояние его интерфейсов.**

**Определить адаптер**
```bash
lspci | grep -i net
# или
lshw -class network -short
```

**Состояние интерфейсов**
```bash
ip a
# или
ip link show
```
-   `UP` — интерфейс поднят и готов к работе.
-   `DOWN` — интерфейс отключен.
-   `NO-CARRIER` — нет связи (кабель не подключен).

### Шины и устройства

**Подключённые USB и PCI устройства.**

**PCI устройства**
```bash
lspci -vvv
```

**USB устройства**
```bash
lsusb -vvv
```
