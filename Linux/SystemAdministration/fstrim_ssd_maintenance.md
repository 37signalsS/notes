# fstrim: Обслуживание SSD

## Определения

**`fstrim`** — это утилита Linux для отправки команды TRIM в файловую систему на твердотельном накопителе (SSD). Команда TRIM информирует SSD о том, какие блоки данных больше не используются и могут быть безопасно очищены.

Накопители SSD не всегда "понимают", что файлы были удалены на уровне файловой системы. В результате блоки, содержащие эти "удаленные" данные, могут оставаться помеченными как занятые, что со временем может привести к снижению скорости записи и производительности диска.

## Базовые концепции

В отличие от HDD, где данные перезаписываются, SSD требует явного уведомления об освободившихся блоках. Команда TRIM позволяет контроллеру SSD заблаговременно очищать неиспользуемые блоки, поддерживая оптимальную производительность и продлевая срок службы накопителя.

## Практические сценарии

### Ручное выполнение

Для немедленной очистки неиспользуемых блоков корневого раздела:

```bash
sudo fstrim -v /
```
Команда выведет объем освобожденных данных.

### Автоматическое выполнение с `systemd-timer`

Большинство дистрибутивов Linux включают `systemd-timer` для автоматического еженедельного запуска `fstrim`.
Для активации автоматической очистки:

```bash
sudo systemctl enable fstrim.timer
sudo systemctl start fstrim.timer
```
Это обеспечит поддержание производительности SSD без ручного вмешательства.

## Дополнительная информация

Регулярное использование `fstrim` — это безопасный, простой и эффективный способ поддерживать оптимальную производительность и продлевать срок службы SSD. Автоматическое выполнение через `systemd-timer` является достаточным и рекомендуемым подходом для большинства пользователей.
