# fstrim: Обслуживание SSD

## 1. Определения

**`fstrim`** — это утилита Linux для отправки команды TRIM в файловую систему на твердотельном накопителе (SSD). Команда TRIM информирует SSD о том, какие блоки данных больше не используются и могут быть безопасно очищены.

Накопители SSD не всегда "понимают", что файлы были удалены на уровне файловой системы. В результате блоки, содержащие эти "удаленные" данные, могут оставаться помеченными как занятые, что со временем может привести к снижению скорости записи и производительности диска.

## 2. Базовые концепции

В отличие от традиционных жестких дисков (HDD), где данные просто помечаются как удаленные, а сектора перезаписываются, SSD требует явного уведомления об освободившихся блоках. Без команды TRIM контроллер SSD не знает, какие блоки можно очистить, и вынужден копировать все данные из частично занятых блоков перед записью новых данных, что снижает скорость.

Команда TRIM решает эту проблему, позволяя контроллеру SSD заблаговременно очищать неиспользуемые блоки, тем самым поддерживая производительность накопителя на оптимальном уровне и продлевая его срок службы.

## 3. Практические сценарии

### Ручное выполнение

Вы можете вручную запустить `fstrim` для корневого раздела, чтобы немедленно освободить неиспользуемые блоки:

```bash
sudo fstrim -v /
```
Эта команда выведет информацию о том, сколько байт было освобождено.

### Автоматическое выполнение с `systemd-timer`

Чтобы не выполнять `fstrim` вручную, большинство современных дистрибутивов Linux предоставляют встроенный таймер `systemd`, который автоматически запускает `fstrim` с определенной периодичностью (обычно раз в неделю).

Для включения автоматической очистки достаточно один раз активировать таймер:

```bash
sudo systemctl enable fstrim.timer
sudo systemctl start fstrim.timer
```
После этого очистка будет выполняться автоматически, поддерживая производительность вашего SSD без дополнительных ручных действий.

## 4. Продвинутые детали

Регулярное использование `fstrim` — это безопасный, простой и эффективный способ поддерживать оптимальную производительность и продлевать срок службы SSD. Для большинства пользователей автоматическое выполнение через `systemd-timer` является достаточным и рекомендуемым подходом.
