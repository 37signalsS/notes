# NFS: Базовые концепции

## Определения

**NFS (Network File System)** — протокол распределенной файловой системы, позволяющий пользователям получать доступ к файлам и каталогам на удаленных компьютерах, управляя ими как локальными.

## Ключевые концепции

* **Клиент-серверная модель**:
  * **NFS-сервер**: Экспортирует (предоставляет доступ) свои директории.
  * **NFS-клиент**: Монтирует экспортированные директории в свою файловую систему.
* **RPC (Remote Procedure Call)**: Механизм коммуникации NFS. Служба `rpcbind` информирует клиентов о портах служб NFS. Для NFSv4+ этот механизм менее критичен, так как протокол стремится использовать один порт (2049).
* **`root_squash`**: Важная функция безопасности, при которой запросы от `root` клиента выполняются сервером от имени пользователя `nobody:nogroup`. Это предотвращает получение `root`-прав клиента на файловой системе сервера.

## Версии NFS

| Версия | Особенности | Статус |
| :--- | :--- | :--- |
| **NFSv3** | Stateless, UDP/TCP, нет встроенной безопасности | Устарела, не рекомендуется |
| **NFSv4** | Stateful, только TCP, встроенный security, один порт (2049) | Рекомендуется |
| **NFSv4.1** | Поддержка параллельного NFS (pNFS) для кластеров | Для HPC/кластеров |
| **NFSv4.2** | Server-side copy, sparse files, application I/O hints | Актуальная |

## Маппинг UID/GID

NFS использует числовые UID и GID для разделения привилегий. Для корректной работы в многохостовых средах требуется централизованная система идентификации (например, NIS, [LDAP](../../../Linux/SystemAdministration/users_management.md#LDAP-Lightweight-Directory-Access-Protocol)) для обеспечения согласованного маппинга UID/GID на клиентах и сервере.

Подробнее см. [Управление пользователями в Linux](../../../SystemAdministration/users_management.md).

## Архитектура NFS

```
┌─────────────┐         ┌─────────────┐
│ NFS-клиент  │ ──────► │ NFS-сервер  │
│ 10.0.0.10   │  порт   │ 10.0.0.5    │
│             │  2049   │             │
└─────────────┘         └─────────────┘
      │                        │
      ▼                        ▼
  /mnt/nfs/shared        /srv/nfs/shared
```
