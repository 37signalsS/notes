# NFS: Производительность и оптимизация

## Definitions

**NFS-производительность** — совокупность параметров и практик, направленных на максимизацию пропускной способности и минимизацию задержек при работе с NFS-монтированиями. Ключевые метрики: throughput (МБ/с), IOPS, latency (мс).

## Basic Concepts

### Параметры rsize/wsize

Размер блока данных для операций чтения (`rsize`) и записи (`wsize`). Влияют на объём данных, передаваемых за одну RPC-операцию.

| Опция | Описание | Значение по умолчанию |
| :--- | :--- | :--- |
| `rsize` | Размер блока чтения | 1048576 (1MB) |
| `wsize` | Размер блока записи | 1048576 (1MB) |
| `timeo` | Таймаут в десятых долях секунды | 600 (60 сек) |
| `retrans` | Количество повторных попыток | 3 |
| `noatime` | Отключить обновление времени доступа | Выключено |
| `nodiratime` | Отключить atime для директорий | Выключено |

### Серверные параметры

> **Важно:** На современных системах (Ubuntu 22.04+, ядро 5.x+) параметр `RPCNFSDCOUNT` игнорируется — ядро автоматически масштабирует количество потоков nfsd. Для ручной настройки используется `nfsdthreads` в NFSv4.

**Файл `/etc/default/nfs-kernel-server` (устаревший подход, Debian 11 и старее):**

```bash
# Количество потоков ядра NFS (по умолчанию 8)
# На современных системах игнорируется — ядро управляет автоматически
RPCNFSDCOUNT=16
```

**Современный подход (NFSv4, ядро 6.x+):**

```bash
# Проверить текущие потоки
cat /proc/fs/nfsd/threads

# Установить количество потоков (временно, до перезагрузки)
echo 16 > /proc/fs/nfsd/threads

# Настройка через nfsdthreads (если поддерживается)
# Файл /etc/nfs.conf:
[nfsd]
threads=16
```

## Practical Scenarios

### Монтирование с оптимизированными параметрами

```bash
sudo mount -t nfs4 -o rsize=1048576,wsize=1048576,timeo=600,retrans=3,noatime 10.0.0.5:/srv/nfs/shared /mnt/nfs/shared
```

### Диагностика производительности

```bash
# Статистика NFS на клиенте
nfsstat -c

# Статистика NFS на сервере
nfsstat -s

# Просмотр подключенных клиентов
cat /proc/fs/nfsd/clients/*/info

# Мониторинг I/O в реальном времени
iostat -x 1

# Проверка задержек сети
ping -c 10 <сервер>
```

### Рекомендации по оптимизации

1. **Используйте NFSv4.2** — server-side copy, sparse files, LABELS.
2. **Для баз данных и высоконагруженных приложений** — рассмотрите **iSCSI** вместо NFS.
3. **Включайте `noatime`** — снижает нагрузку на метаданные.
4. **`sync` для критичных данных**, `async` только для кэшируемых/временных.
5. **Размер блоков под workload:**
   - Большие файлы: `rsize=1048576,wsize=1048576`
   - Много мелких файлов: `rsize=32768,wsize=32768`
6. **Выделенная сеть** для NFS-трафика (VLAN, отдельный интерфейс).
7. **Jumbo Frames (MTU 9000)** в изолированной сети хранения.
