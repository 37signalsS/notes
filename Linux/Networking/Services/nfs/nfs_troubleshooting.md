# NFS: Устранение неполадок

## Диагностика подключений

```bash
# Проверка службы на сервере
systemctl status nfs-kernel-server

# Проверка экспортов на сервере
exportfs -v

# Проверка доступных ресурсов на клиенте
showmount -e <IP_сервера>

# Проверка сетевой доступности
ping <IP_сервера>

# Проверка порта 2049
nc -zv <IP_сервера> 2049
```

## Распространённые проблемы

### Монтирование "зависает" или `df` не отвечает

**Причина:** Недоступность NFS-сервера при использовании опции `hard` на клиенте.

**Решение:**

1. Проверьте сетевое соединение и доступность сервера.
2. Убедитесь, что служба `nfs-kernel-server` активна:

   ```bash
   systemctl status nfs-kernel-server
   ```

### Ошибка `Permission denied`

**Причина №1 (Сервер):** Отсутствие IP-адреса клиента в `/etc/exports` или некорректные права доступа.

**Причина №2 (Файрвол):** Блокировка подключений файрволом на сервере.

**Причина №3 (UID/GID mismatch):** Разные UID/GID на клиенте и сервере.

**Решение:**

```bash
# Проверка /etc/exports
cat /etc/exports

# Проверка файрвола
sudo ufw status

# Проверка UID/GID
id
```

Используйте централизованную аутентификацию (LDAP) для согласованного маппинга.

### Ошибка `mount.nfs: Connection timed out`

**Причина:** Проблемы с сетью или файрволом, препятствующие доступу клиента к RPC-портам сервера.

**Решение:**

1. Проверьте `ping` до сервера.
2. Убедитесь в правильности настройки файрвола на сервере.
3. Проверьте, что порт 2049 открыт:

   ```bash
   telnet <IP_сервера> 2049
   ```

### Ошибка Kerberos (`Permission denied`, `Authentication failed`)

**Причина:** Истёк срок действия TGT-билета или рассинхронизация времени.

**Решение:**

```bash
# Проверка билета
klist

# Получение нового билета
kinit user@REALM

# Проверка синхронизации времени
timedatectl status

# Синхронизация времени
sudo systemctl restart systemd-timesyncd
```

## Логи

```bash
# Журнал NFS на сервере (Debian/Ubuntu)
journalctl -u nfs-kernel-server -f

# Журнал NFS на клиенте
journalctl -u nfs-client.target -f

# Общие системные логи
dmesg | grep -i nfs
```
