# DHCP-сервер: Развертывание и настройка

## Определения

**[[DHCP (Dynamic Host Configuration Protocol)|../../../Networking/Protocols/dhcp.md]]** — протокол сетевого управления, используемый в IP-сетях для автоматического назначения IP-адресов и связанных параметров настройки сети устройствам. Позволяет избежать ручной настройки каждого устройства.

**`isc-dhcp-server`** — стандартное программное обеспечение для реализации DHCP-сервера в Linux-системах, особенно в Debian-подобных дистрибутивах.

## Базовые концепции

*   **Назначение:** DHCP-сервер автоматически выдает клиентам IP-адреса из пула, а также маску подсети, шлюз по умолчанию, DNS-серверы.
*   **Статический IP:** DHCP-сервер должен иметь статический IP-адрес для обеспечения доступности.
*   **Файлы конфигурации:** Основные настройки `isc-dhcp-server` находятся в `/etc/dhcp/dhcpd.conf` и `/etc/default/isc-dhcp-server`.
*   **Файл аренды IP-адресов:** Информация об арендованных IP-адресах хранится в `/var/lib/dhcp/dhcpd.leases`.

## Практические сценарии

### 1. Установка `isc-dhcp-server`

```bash
sudo apt update
sudo apt install isc-dhcp-server
```

### 2. Настройка статического IP-адреса для DHCP-сервера

DHCP-серверу необходим статический IP-адрес. Пример настройки в `/etc/network/interfaces` (для Debian/Ubuntu):

```ini
# /etc/network/interfaces
auto enp3s0
iface enp3s0 inet static
    address 192.168.0.100
    netmask 255.255.255.0
```
После изменения сетевых настроек требуется перезапуск сетевой службы или системы.

### 3. Конфигурация интерфейса прослушивания

Укажите сетевой интерфейс, на котором DHCP-сервер будет принимать запросы клиентов.

1.  Откройте `/etc/default/isc-dhcp-server`:
    ```bash
    sudo vim /etc/default/isc-dhcp-server
    ```
2.  Отредактируйте строку `INTERFACESv4`, указав имя интерфейса (например, `enp3s0`):
    ```ini
    INTERFACESv4="enp3s0"
    ```
    Убедитесь, что `ISC_DHCP_SERVER_IPV4="yes"` раскомментировано.

### 4. Основная конфигурация DHCP-сервера (`/etc/dhcp/dhcpd.conf`)

Файл определяет подсети, диапазоны IP-адресов и параметры, выдаваемые клиентам.

1.  Откройте `/etc/dhcp/dhcpd.conf`:
    ```bash
    sudo vim /etc/dhcp/dhcpd.conf
    ```
2.  Пример конфигурации для подсети `192.168.0.0/24`:
    ```ini
    option domain-name "example.com";
    option domain-name-servers 8.8.8.8, 8.8.4.4;

    # Объявление основной подсети
    subnet 192.168.0.0 netmask 255.255.255.0 {
        # Диапазон выдаваемых IP-адресов
        range 192.168.0.10 192.168.0.20;
        # IP-адрес шлюза по умолчанию
        option routers 192.168.0.1;
        # Указание, что этот DHCP-сервер является основным для данной подсети
        authoritative;
        # Время аренды IP-адреса (опционально, можно оставить по умолчанию)
        # default-lease-time 600;
        # max-lease-time 7200;
    }
    ```
3.  **Проверка синтаксиса:**
    ```bash
    sudo dhcpd -t -cf /etc/dhcp/dhcpd.conf
    ```

### 5. Запуск и проверка статуса DHCP-сервера

1.  **Перезапуск службы:**
    ```bash
    sudo systemctl restart isc-dhcp-server
    ```
2.  **Проверка статуса:**
    ```bash
    systemctl status isc-dhcp-server
    ```
    Убедитесь, что служба активна (`active (running)`).

### 6. Проверка на клиентах

1.  На DHCP-клиенте настройте сетевой интерфейс на получение IP по DHCP (например, `iface eth0 inet dhcp` или через NetworkManager/Netplan).
2.  Перезапустите сетевую службу на клиенте или выполните `sudo dhclient -r && sudo dhclient`.
3.  Проверьте полученный IP-адрес:
    ```bash
    ip a
    ```
    Клиент должен получить IP-адрес из настроенного диапазона.
4.  На сервере проверьте файл арендованных IP-адресов:
    ```bash
    cat /var/lib/dhcp/dhcpd.leases
    ```

## Дополнительная информация

*   **`dhcpd.pid`:** При некорректном завершении работы файл `/var/run/dhcpd.pid` может препятствовать запуску службы. При необходимости удалите его вручную (`sudo rm /var/run/dhcpd.pid`).
*   **Проблема с hostname:** Некорректные символы в hostname клиентов могут вызвать проблемы в `dhcpd.leases`. Рекомендуется использовать корректные hostname.
*   **[[Файрвол|../../Settings/linux_firewall_management.md]]**: Настройте файрвол на DHCP-сервере для разрешения входящих UDP-пакетов на порт `67` (DHCP-сервер) и исходящих UDP-пакетов на порт `68` (DHCP-клиент).
*   **`dhcpd.leases` и `dhcpd.leases~`:** `dhcpd.leases` содержит текущие аренды, `dhcpd.leases~` — резервная копия. Сервер может использовать `dhcpd.leases~` для восстановления информации об аренде.
