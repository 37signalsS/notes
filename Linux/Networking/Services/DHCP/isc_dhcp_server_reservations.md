# ISC DHCP-сервер: Резервирование IP и передача маршрутов

> **Важно:** ISC DHCP устарел. Для новых развертываний используйте **[Kea DHCP](./isc_dhcp_server_overview.md#kea-dhcp-современная-альтернатива)**. Конфигурация резервирования в JSON.

> **См. также:** [Статическое назначение DHCP](../../../Networking/Protocols/dhcp.md#способы-назначения-ip-адресов) — теория.

## Резервирование IP-адреса (Static Allocation)
Чтобы устройство (например, сервер или принтер) всегда получало один и тот же IP-адрес, используется резервирование по MAC-адресу.

```ini
# Резервирование IP-адреса для конкретного устройства
host fileserver {
    hardware ethernet 08:00:27:1A:2B:3C; # MAC-адрес устройства
    fixed-address 10.0.10.5;             # IP, который всегда будет выдаваться
}
```

## Передача статических маршрутов
DHCP может передавать клиентам статические маршруты. Это полезно, если из одной подсети нужно обеспечить доступ в другую через специфический шлюз.

```ini
# Пример: DMZ с выдачей статичного маршрута (VLAN 30)
# Позволяет сообщить хостам, как добраться до внутренней сети 172.16.0.0/16
# через внутренний роутер 10.0.30.254
subnet 10.0.30.0 netmask 255.255.255.0 {
    range 10.0.30.10 10.0.30.20;
    option routers 10.0.30.1;
    
    # Опция для передачи статических маршрутов (classless static routes)
    # Формат: <маска-сети>.<IP-сети> <IP-шлюза>
    # 16.172.16 соответствует сети 172.16.0.0/16
    option rfc3442-classless-static-routes 16, 172, 16, 10, 0, 30, 254;
}
```
