# ISC DHCP: Обзор и архитектура

> **Надёжность: 10/10** (Официальная документация + EOL статус)
> **Актуальность: 2026-07** (Статус: End of Life)

> **Важно:** ISC (Internet Systems Consortium) прекратила поддержку DHCP-сервера в 2022 году. Для новых развёртываний **настоятельно рекомендуется** использовать **[Kea DHCP](#kea-dhcp-современная-альтернатива)**. Данный раздел предназначен для обслуживания существующих систем и планирования миграции.

## Определения

**DHCP (Dynamic Host Configuration Protocol — протокол динамической настройки узла)** — сетевой протокол прикладного уровня, используемый для автоматического назначения **IP-адресов (Internet Protocol)** и других параметров конфигурации (маска сети, шлюз, DNS-серверы) узлам в IP-сетях.

**ISC DHCP (Internet Systems Consortium Dynamic Host Configuration Protocol)** — классическая, широко распространенная реализация DHCP-сервера. Состоит из демона `dhcpd`, библиотеки и утилиты `dhclient`.

**Kea DHCP** — современный DHCP-сервер нового поколения от ISC, спроектированный как модульная и высокопроизводительная замена классическому ISC DHCP.

## Основные концепции

### Архитектурные особенности

ISC DHCP является **stateful** (хранящим состояние) приложением. Информация о выданных адресах (leases) сохраняется в текстовой базе данных, что обеспечивает целостность данных после перезагрузки.

**Ключевые компоненты:**
- **Демон `dhcpd`:** Служба, обрабатывающая запросы клиентов.
- **Файл конфигурации (`dhcpd.conf`):** Иерархическая структура параметров (глобальные -> subnet -> host).
- **Файл аренды (`dhcpd.leases`):** Единый источник правды (SSoT) о текущем состоянии назначенных адресов. Сервер обновляет этот файл перед отправкой `DHCPACK` клиенту.

### Технические требования

- **Сетевой уровень:** Статический IP-адрес на сервере.
- **Порты:** 
  - **UDP (User Datagram Protocol) 67:** Приём запросов от клиентов.
  - **UDP 68:** (Для клиента) Приём ответов от сервера.
  - **TCP (Transmission Control Protocol) 647:** Синхронизация между серверами в режиме Failover.
- **Права доступа:** Запуск от имени суперпользователя (root) для работы с сырыми (raw) сокетами.

### Структура системных файлов

| Файл / Директория | Описание | Дистрибутив |
| :--- | :--- | :--- |
| `/etc/dhcp/dhcpd.conf` | Основной конфигурационный файл | Все |
| `/etc/default/isc-dhcp-server` | Настройка интерфейсов и параметров запуска | Debian / Ubuntu |
| `/etc/sysconfig/dhcpd` | Параметры запуска и аргументы демона | RHEL / CentOS / Rocky |
| `/var/lib/dhcp/dhcpd.leases` | База данных арендованных адресов | Debian / Ubuntu |
| `/var/lib/dhcpd/dhcpd.leases` | База данных арендованных адресов | RHEL / Rocky |

## Дополнительная информация

### Kea DHCP — современная альтернатива

Kea DHCP была разработана с учётом недостатков ISC DHCP и современных требований к масштабируемости.

**Ключевые преимущества и отличия:**
- **Модульность:** Возможность подключения функционала через Hook-библиотеки.
- **Базы данных:** Поддержка хранения аренды в **MySQL**, **PostgreSQL** или **Cassandra** вместо текстового файла.
- **REST API:** Позволяет изменять конфигурацию и управлять арендой через **JSON (JavaScript Object Notation)** запросы без перезагрузки демона.
- **Производительность:** Многопоточная архитектура, способная обрабатывать тысячи запросов в секунду.
