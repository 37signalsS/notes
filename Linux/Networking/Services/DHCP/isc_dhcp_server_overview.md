# ISC DHCP-сервер: Обзор и архитектура

> **Важно:** ISC прекратила поддержку DHCP-сервера в 2022 году. Современная альтернатива — **[Kea DHCP](#kea-dhcp-современная-альтернатива)**. Данная документация актуальна для существующих развертываний и миграции на Kea.

Это основной файл, который служит точкой входа для документации по ISC DHCP-серверу.

## Определения

**[DHCP (Dynamic Host Configuration Protocol)](../../../../Networking/Protocols/dhcp.md)** — протокол для автоматической конфигурации сетевых параметров устройств в IP-сетях.

**ISC DHCP** — классическая и наиболее распространенная реализация DHCP-сервера для Linux, разработанная Internet Systems Consortium. Пакет может называться `isc-dhcp-server` (Debian/Ubuntu) или `dhcp-server` (RHEL/CentOS).

> **См. также:** [Протокол DHCP: теория, DORA, безопасность](../../../../Networking/Protocols/dhcp.md) — по концепциям протокола.

## Базовые концепции

* **Назначение:** DHCP-сервер автоматически выдает клиентам IP-адреса из пула, а также маску подсети, шлюз по умолчанию, адреса DNS-серверов и другие дополнительные опции.
* **Статический IP:** DHCP-сервер должен иметь статический IP-адрес для обеспечения доступности.
* **Структура конфигурации:**
  * `/etc/dhcp/dhcpd.conf`: Основной файл конфигурации. Имеет иерархическую структуру: глобальные параметры могут быть переопределены внутри блоков `subnet`.
  * `/etc/dhcp/dhcpd6.conf`: Конфигурация для IPv6.
  * `/etc/default/isc-dhcp-server` (Debian) или `/etc/sysconfig/dhcpd` (RHEL): Указание интерфейсов для прослушивания.
* **Файл аренды:** Информация о выданных IP-адресах и сроках их аренды хранится в `/var/lib/dhcp/dhcpd.leases` (Debian) или `/var/lib/dhcpd/dhcpd.leases` (RHEL).

## Дополнительная информация

## Kea DHCP — современная альтернатива

**Kea DHCP** — официальный современный DHCP-сервер от Internet Systems Consortium (ISC), разработанный как замена устаревшему ISC DHCP. Активно поддерживается и рекомендуется для новых развертываний.

**Ключевые отличия:**

* Пакет: `kea-dhcp-server` (в новых дистрибутивах)
* Конфигурация: полностью совместима с ISC DHCP (JSON-формат)
* Демон: `kead` вместо `dhcpd`
* Файл аренды: тот же формат, прямая миграция
* Поддержка: активные обновления безопасности и новые функции
* REST API для онлайн-конфигурации без перезагрузки

**Миграция:** Переход с ISC DHCP на Kea требует конвертации конфигурации в JSON-формат.

### Файрвол

* На DHCP-сервере должен быть открыт порт **UDP/67** для запросов клиентов
* При использовании failover должен быть открыт порт **TCP/647** для обмена между серверами

### DHCP-клиент

В современных Linux-системах за работу DHCP-клиента обычно отвечает **NetworkManager**, который вызывает `dhclient` или использует встроенные механизмы. Настройки для клиента (например, запрос специфичных опций) производятся через профили NetworkManager (`nmcli`).
