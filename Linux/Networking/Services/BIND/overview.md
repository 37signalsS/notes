# Настройка DNS-сервера BIND: Обзор

## Определения

**BIND (Berkeley Internet Name Domain)** — программное обеспечение для реализации DNS-сервера с полной поддержкой спецификации протокола DNS.

## Базовые концепции

### Роли BIND в инфраструктуре

| Роль | Назначение | Конфигурация |
|------|------------|--------------|
| **Авторитативный сервер** | Хранит официальные записи зоны, отвечает авторитетно | Зоны в `named.conf.local` |
| **Рекурсивный сервер** | Выполняет рекурсивные запросы от клиентов, кэширует ответы | `recursion yes;` |
| **Перенаправляющий (Forwarder)** | Перенаправляет запросы внешним DNS-серверам | `forward only;` + `forwarders {}` |
| **Master-сервер** | Первичный источник данных зоны (файлы редактируются администратором) | `type master;` |
| **Slave-сервер** | Автоматически копирует зону с Master (трансфер зоны) | `type slave;` + `masters {}` |

### Сценарии использования

**Корпоративная сеть:**

- Внутренний авторитативный сервер для локальных зон (`local.lan`, `corp.internal`)
- Перенаправляющий сервер для доступа сотрудников к внешним ресурсам
- Кэширование для снижения внешней нагрузки

**Публичный DNS-сервис:**

- Авторитативные Master/Slave серверы для доменов клиентов
- Anycast-развёртывание для глобальной доступности

**Гибридная конфигурация:**

- Разделение представлений (views) для внутренних и внешних клиентов
- DNSSEC-подпись зон для верификации ответов

## Практические сценарии

### Структура конфигурации BIND

| Файл | Назначение |
|------|------------|
| `/etc/bind/named.conf` | Главный конфиг (включает остальные файлы) |
| `/etc/bind/named.conf.options` | Глобальные настройки (рекурсия, форвардеры, ACL) |
| `/etc/bind/named.conf.local` | Локальные зоны (master/slave) |
| `/etc/bind/named.conf.default-zones` | Стандартные зоны (localhost, root) |
| `/etc/bind/zones/` | Файлы зонных данных |
