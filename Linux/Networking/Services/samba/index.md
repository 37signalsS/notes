# Samba: Обзор

## Определения

**Samba** — программный комплекс с открытым исходным кодом, реализующий протокол **SMB/CIFS** (Server Message Block / Common Internet File System). Позволяет Unix-подобным системам предоставлять общий доступ к файлам и принтерам для клиентов Windows, функционировать как член домена Active Directory (AD Member), а также выступать в роли полнофункционального контроллера домена (AD DC).

**SMB (Server Message Block)** — сетевой протокол прикладного уровня для совместного использования ресурсов. Актуальный стандарт 2026 года — **SMBv3.1.1**, поддерживающий обязательное шифрование AES-256 и защиту от атак типа "человек посередине" (Pre-Authentication Integrity).

**CIFS (Common Internet File System)** — устаревший диалект SMBv1. Использование CIFS/SMBv1 в современных сетях запрещено из-за критических уязвимостей (EternalBlue, WannaCry).

**NetBIOS** — legacy-протокол для разрешения имен и обнаружения ресурсов. В современной инфраструктуре (Samba 4+) полностью заменен на DNS и WSD (Web Services for Devices).

## Базовые концепции

### Архитектура Samba

| Демон | Назначение |
| :--- | :--- |
| **`smbd`** | Файловые ресурсы (Shares), аутентификация, авторизация, блокировки. |
| **`nmbd`** | Разрешение имён NetBIOS (legacy, обычно отключается в AD-средах). |
| **`winbindd`** | Интеграция с Active Directory, маппинг SID ↔ UID/GID, SSO. |
| **`samba`** | Мастер-демон для режима Active Directory Domain Controller (AD DC). |

### Режимы работы

| Режим | Параметр `security` | Описание |
| :--- | :--- | :--- |
| **Standalone** | `user` | Локальная аутентификация через `smbpasswd`. Идеально для простых файловых серверов. |
| **Domain Member** | `ads` | Linux-сервер как член домена Windows. Требует Kerberos и Winbind/SSSD. |
| **Domain Controller** | `ads` | Samba работает как контроллер домена (AD DC), заменяя Windows Server. |

### Версии SMB и безопасность (Стандарты 2026)

| Версия | Статус | Безопасность и возможности |
| :--- | :--- | :--- |
| **SMBv1** | **Запрещён** | Небезопасен. Должен быть отключен на уровне ядра и конфига. |
| **SMBv2.1** | Устарела | Поддержка оппортунистических блокировок (oplocks). |
| **SMBv3.0** | Допустима | Шифрование AES-128-CCM, поддержка кластеров. |
| **SMBv3.1.1** | **Рекомендуется** | Шифрование AES-256-GCM, защита от downgrade-атак. |

> **Конфигурация безопасности 2026:**
> ```ini
> server min protocol = SMB3_11
> server smb encrypt = required
> ntlm auth = ntlmv2-only
> ```

## Практические сценарии

- **Корпоративное файловое хранилище:** замена Windows File Server с сохранением ACL (Access Control Lists) и интеграцией с AD.
- **Интеграция macOS:** оптимизация производительности и поиска через VFS-модуль `fruit`.
- **Hybrid Cloud:** синхронизация локальных шар с облачными хранилищами (Azure Files, AWS FSx) через проксирование.
- **High Availability:** построение отказоустойчивых кластеров с использованием CTDB (Cluster Trivial Database).
- **Time Machine Backup:** использование Linux-сервера как бэкап-цели для Apple устройств.

## Дополнительные сведения

### Популярные VFS (Virtual File System) модули

Модули VFS позволяют расширять функциональность шар без изменения кода ядра Samba.

| Модуль | Назначение |
| :--- | :--- |
| **`fruit`** | Оптимизация для клиентов macOS (метаданные, расширенные атрибуты). |
| **`shadow_copy2`** | Поддержка "Предыдущих версий" Windows на базе снапшотов ZFS/Btrfs/LVM. |
| **`recycle`** | Корзина: перемещение удаленных файлов в указанную директорию вместо удаления. |
| **`full_audit`** | Детальное логирование всех операций пользователей (open, rename, unlink). |
| **`aio_ratelimit`** | (Новое в 2026) Ограничение пропускной способности (I/O) для конкретных шар. |

### Производительность и тюнинг (Modern Samba)

В 2026 году производительность Samba в основном зависит от корректной настройки **Asynchronous I/O (AIO)** и параметров файловой системы.

- **Asynchronous I/O:** для современных SSD/NVMe рекомендуется `aio read size = 1` и `aio write size = 1` для исключения блокирующих вызовов.
- **Sendfile:** параметр `use sendfile = yes` значительно ускоряет передачу больших файлов, уменьшая нагрузку на CPU.
- **XFS/ZFS:** использование файловых систем с поддержкой расширенных атрибутов (`xattr`) критично для производительности метаданных.

### Порты и протоколы

| Порт | Протокол | Назначение |
| :--- | :--- | :--- |
| **445** | TCP | **SMB over TCP** (Основной порт для SMBv2/v3). |
| **139** | TCP | NetBIOS Session Service (Legacy, используется для обратной совместимости). |
| **137/138** | UDP | NetBIOS Name/Datagram Service (Legacy). |

### Ключевые утилиты

- `testparm` — проверка синтаксиса `/etc/samba/smb.conf`.
- `smbstatus` — мониторинг подключений и заблокированных файлов в реальном времени.
- `smbclient` — интерактивный CLI-клиент (аналог ftp для SMB).
- `wbinfo` — проверка связи с доменом через Winbind.
- `net ads` — мощный инструмент для администрирования членства в домене и управления AD.
