# Samba: Базовые концепции

## Определения

**Samba** — программный комплекс, реализующий протокол **SMB/CIFS** (Server Message Block / Common Internet File System). Позволяет Unix-подобным системам (включая Linux) предоставлять общий доступ к файлам и принтерам для клиентов Windows, а также функционировать в качестве члена домена Active Directory.

**NetBIOS** — протокол, используемый Samba для обнаружения и разрешения имен в сетях Windows.

## Компоненты Samba

| Демон | Описание |
| :--- | :--- |
| **`smbd`** | Отвечает за файловые ресурсы, аутентификацию и авторизацию |
| **`nmbd`** | Отвечает за разрешение имён NetBIOS |
| **`winbindd`** | Интеграция с Windows-доменами (Active Directory), позволяет использовать доменных пользователей |

## Версии SMB

| Версия | Особенности | Статус |
| :--- | :--- | :--- |
| **SMBv1 (CIFS)** | Устаревший, нет шифрования, уязвимости (EternalBlue, WannaCry) | **Запрещён** |
| **SMBv2.x** | Улучшенная производительность, поддержка WAN | Устарела |
| **SMBv3.0** | Шифрование (AES-256), Secure Dialect Negotiation | Рекомендуется |
| **SMBv3.1.1** | Улучшенная безопасность, защита от MitM | Актуальная |

## Безопасность протокола SMB

**Уязвимости:**

- **SMBv1**: Критические уязвимости (EternalBlue, WannaCry)
- **Неправильная конфигурация**: Публичные ресурсы без аутентификации

**Рекомендации по безопасности:**

- **Отключить SMBv1** обязательно. Минимальная версия — SMBv2.
- **Использовать SMBv3+** с поддержкой шифрования (`server min protocol = SMB3`).
- **Включить шифрование** для чувствительных данных (`smb encrypt = required`).
- Ограничивать доступ с помощью файрвола (порт **445/tcp**).
- Регулярно обновлять Samba.

## Архитектура Samba

```
┌─────────────┐         ┌─────────────┐
│ SMB-клиент  │ ──────► │ Samba-сервер│
│ (Windows)   │  порт   │ (Linux)     │
│             │  445    │             │
└─────────────┘         └─────────────┘
      │                        │
      ▼                        ▼
  \\server\share          /srv/samba/share
```
