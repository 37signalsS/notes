# ip route: Управление таблицей маршрутизации

## Определения

* **`ip route`** (синоним: `ip r`) — объект утилиты `ip` для управления таблицами маршрутизации в ядре Linux.
* **Таблица маршрутизации (Routing Table)** — база данных правил, используемых ядром для принятия решения о направлении IP-пакетов.
* **Шлюз (Gateway / Next Hop)** — адрес промежуточного сетевого устройства (маршрутизатора), на которое должен быть передан пакет для достижения цели.

## Основные концепции

### Структура и типы таблиц

Linux поддерживает до 255 независимых таблиц маршрутизации. Имена таблиц сопоставляются с ID в файле `/etc/iproute2/rt_tables`.

| ID | Имя | Назначение |
|:---|:---|:---|
| **255** | **local** | Содержит маршруты к локальным и широковещательным адресам хоста. Управляется ядром. |
| **254** | **main** | Основная таблица для большинства системных и пользовательских маршрутов. Используется по умолчанию. |
| **253** | **default** | Таблица для маршрутов по умолчанию (в современных дистрибутивах практически не используется). |
| **1–252** | (custom) | Пользовательские таблицы для **[Policy-Based Routing](../../Policy_Based_Routing/index.md)**. |

### Ключевые атрибуты маршрутов

* **via** — IP-адрес шлюза.
* **dev** — сетевой интерфейс, через который уходит трафик.
* **proto** — протокол, создавший маршрут (`kernel`, `static`, `dhcp`, `zebra` и др.).
* **metric** — числовой приоритет. При наличии нескольких путей к одной цели выбирается маршрут с наименьшей метрикой.
* **scope** — область действия маршрута (например, `global` — везде, `link` — только в этом сегменте сети).
* **src** — предпочитаемый исходный IP (`Source IP`) для исходящих соединений по данному маршруту. Подробнее о механизме выбора: **[Выбор исходного IP](../../SystemAdministration/routing.md#выбор-исходного-ip-source-ip-selection)**.

## Практические сценарии

### Просмотр маршрутов

```bash
# Показать основную таблицу (main)
ip route show

# Показать конкретную таблицу (например, local)
ip route show table local

# Узнать, какой маршрут и какой исходный IP будет выбран для конкретного адреса
ip route get 8.8.8.8
# → 8.8.8.8 via 192.168.1.1 dev eth0 src 192.168.1.10 uid 1000
#   (в поле src указан IP, который будет использован в пакете)
```

### Добавление и изменение маршрутов

```bash
# Добавление маршрута к сети через шлюз
sudo ip route add 10.0.0.0/8 via 192.168.1.1 dev eth0

# Добавление маршрута по умолчанию (Default Gateway)
sudo ip route add default via 192.168.1.1

# Задание явного исходного IP для маршрута по умолчанию
# (полезно, если на интерфейсе несколько IP-адресов)
sudo ip route replace default via 192.168.1.1 src 192.168.1.10

# Добавление маршрута с метрикой
sudo ip route add 10.0.0.0/8 via 192.168.1.254 metric 100

# Замена существующего маршрута
sudo ip route replace default via 192.168.1.254
```

### Удаление маршрутов

```bash
# Удаление конкретного маршрута
sudo ip route del 10.0.0.0/8

# Удаление маршрута по умолчанию
sudo ip route del default
```

### Настройка параметров TCP через маршруты

Некоторые параметры TCP можно оптимизировать для конкретных путей без изменения глобальных `sysctl`.

```bash
# Изменение начального окна перегрузки (initcwnd) для ускорения старта HTTP
sudo ip route change default via 192.168.1.1 initcwnd 30

# Задание MTU для конкретного маршрута
sudo ip route add 10.0.0.0/24 via 192.168.1.1 mtu 1400
```

## Дополнительная информация

### Сохранение настроек

Команды `ip route` применяются немедленно, но не сохраняются после перезагрузки. Методы персистентной настройки зависят от дистрибутива:

* **systemd-networkd**: секция `[Route]` в `.network` файлах.
* **Netplan**: секция `routes:` в YAML-файлах.
* **NetworkManager**: через `nmcli connection modify`.

Подробнее: **[Постоянная настройка сети](../../Settings/Persistent_Network/index.md)**.

### Типичные ошибки

| Ошибка | Причина | Решение |
|:---|:---|:---|
| **RTNETLINK answers: File exists** | Маршрут уже существует | Используйте `replace` вместо `add`. |
| **Network is unreachable** | Нет маршрута к шлюзу или интерфейс выключен | Проверьте `ip address` и `ip link`. |
| **Invalid prefix for "..."** | Ошибка в указании подсети | Проверьте соответствие IP и маски. |
