# iproute2: Обзор

## Определения

* **`iproute2`** — современный набор утилит командной строки для управления сетевым стеком в ядре Linux. Полностью заменяет устаревший пакет `net-tools` (утилиты `ifconfig`, `route`, `arp`).
* **Netlink** — механизм (сокет-интерфейс), используемый `iproute2` для прямого взаимодействия с ядром. Обеспечивает атомарность операций, высокую скорость и доступ к функциям ядра, которые недоступны устаревшим инструментам через `ioctl`.
* **Объект** — логическая единица сетевой конфигурации в `iproute2`. Утилита `ip` оперирует такими объектами, как `link`, `address`, `route`, `neighbour` и другими.

## Основные концепции

### Архитектура и компоненты

Пакет `iproute2` включает в себя ряд специализированных инструментов:

* **`ip`** — универсальный инструмент для управления большинством сетевых объектов (интерфейсы, адреса, маршруты, туннели).
* **`ss`** — утилита для детальной диагностики сокетов (заменяет `netstat`).
* **`tc`** — управление трафиком, очередями (qdisc) и QoS.
* **`bridge`** — настройка сетевых мостов (L2).
* **`devlink`** — управление аппаратными ресурсами сетевых карт (Offload, порты).
* **`mptcp`** — управление путями и параметрами MultiPath TCP.
* **`rdma`** — настройка Remote Direct Memory Access.
* **`nstat` / `lnstat`** — сбор и отображение статистики SNMP и сетевых счетчиков.

### Синтаксис команд

Основной формат вызова утилиты `ip`:

```bash
ip [опции] объект команда [аргументы]
```

**Ключевые опции для диагностики:**

| Опция | Описание |
| :--- | :--- |
| `-br` | Краткий (brief) однострочный вывод. |
| `-j` | Формирование вывода в формате JSON. |
| `-p` | В сочетании с `-j` делает JSON читаемым (pretty print). |
| `-s` | Отображение статистики. Повторное использование (`-s -s`) увеличивает детализацию. |
| `-d` | Детальная (detailed) информация о низкоуровневых параметрах. |
| `-4` / `-6` | Фильтрация по протоколам IPv4 или IPv6. |

## Практические сценарии

### Оперативная диагностика

```bash
# Просмотр статуса интерфейсов и адресов (кратко)
ip -br a

# Определение выбранного маршрута для конкретного IP
ip route get 8.8.8.8

# Просмотр активных соединений и процессов (аналог netstat -tunlp)
ss -tunlp

# Мониторинг всех сетевых событий в реальном времени
ip monitor all
```

### Анализ производительности и ошибок

```bash
# Детальная статистика ошибок и дропов на интерфейсе
ip -s -s link show eth0

# Просмотр SNMP-статистики TCP стека (через nstat)
nstat -az | grep Tcp
```

### Автоматизация через JSON и jq

```bash
# Получить операционное состояние интерфейса eth0
ip -j link show eth0 | jq -r '.[0].operstate'

# Извлечь все IPv4 адреса в виде списка
ip -j -4 addr show | jq -r '.[].addr_info[].local'
```

## Дополнительная информация

### Сохранение конфигурации (Persistence)

Изменения через `iproute2` применяются немедленно в ядре, но **исчезают** после перезагрузки. Для постоянной настройки используйте системные конфигураторы:
- **systemd-networkd**: через файлы `.network` и `.link`.
- **Netplan**: стандарт для Ubuntu и облачных образов.
- **NetworkManager**: стандарт для RHEL/CentOS и Desktop-систем.

Подробнее: **[Постоянная настройка сети](../../Settings/Persistent_Network/index.md)**.

### Установка пакета

| Дистрибутив | Команда установки |
| :--- | :--- |
| **Debian / Ubuntu** | `sudo apt install iproute2` |
| **RHEL / Fedora** | `sudo dnf install iproute` |
| **Arch Linux** | `sudo pacman -S iproute2` |
| **Alpine** | `apk add iproute2` |
