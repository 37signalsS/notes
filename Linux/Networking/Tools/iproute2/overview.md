# iproute2: Обзор

## Определения

* **`iproute2`** — современный набор утилит командной строки для управления сетевым стеком в ядре Linux. Разработан как замена устаревшему пакету `net-tools` (инструменты `ifconfig`, `route`, `arp`).
* **Netlink** — механизм (сокет-интерфейс), используемый `iproute2` для прямого взаимодействия с ядром. Обеспечивает высокую скорость работы и доступ к расширенным функциям ядра, которые недоступны старым инструментам.
* **Объект** — логическая единица управления в `iproute2`. Утилита `ip` работает с различными объектами, такими как `link`, `address`, `route`, `neighbour`, `netns` и другие.

## Основные концепции

### Архитектура и компоненты

* **`ip`** — основная утилита, объединяющая управление большинством сетевых параметров (интерфейсы, адреса, маршруты).
* **`ss`** — инструмент для диагностики сокетов, заменяющий `netstat`.
* **`tc`** — управление трафиком и QoS (Quality of Service).
* **`rtmon`**, **`nstat`**, **`lnstat`** — инструменты мониторинга и сбора статистики.

### Синтаксис команд

Общий формат вызова основной утилиты:

```bash
ip [опции] объект команда [аргументы]
```

**Ключевые опции:**

| Опция | Описание |
|-------|----------|
| `-br` | Краткий вывод (brief), удобен для быстрого обзора. |
| `-j` | Вывод в формате JSON для автоматизации и скриптов. |
| `-s` | Вывод статистики (пакеты, ошибки). Повторное использование (`-s -s`) дает больше деталей. |
| `-d` | Детальная информация о параметрах объекта. |
| `-4` / `-6` | Принудительное использование протоколов IPv4 или IPv6. |

### Ключевые объекты и их назначение

| Объект | Краткая форма | Назначение | SSoT |
|--------|---------------|------------|------|
| **link** | `ip l` | Состояние интерфейсов, MTU, MAC-адреса. | [`ip link`](./ip_link.md) |
| **address** | `ip a` | Управление IP-адресами (IPv4/IPv6). | [`ip address`](./ip_address.md) |
| **route** | `ip r` | Таблицы маршрутизации. | [`ip route`](./ip_route.md) |
| **neighbour** | `ip n` | ARP-кэш и NDP (таблица соседей). | [`ip neighbour`](./ip_neighbour.md) |
| **rule** | `ip rule` | Правила выбора таблиц маршрутизации (PBR). | [`ip rule`](./ip_rule_pbr.md) |
| **netns** | `ip netns` | Изоляция сетевого стека (пространства имен). | [`ip netns`](./ip_netns.md) |
| **tunnel** | `ip tunnel` | Настройка туннелей (GRE, SIT, IPIP). | [`ip tunnel`](./ip_tunnel.md) |
| **xfrm** | `ip x` | Настройка IPsec (SA, SP). | [IPsec](../../../../Networking/Tunnels/ipsec/ipsec.md) |

## Практические сценарии

### Быстрая диагностика системы

```bash
# Проверить состояние всех интерфейсов и назначенные адреса
ip -br a

# Узнать, какой маршрут будет выбран для конкретного адреса
ip route get 8.8.8.8

# Просмотреть активные соединения (аналог netstat -tunlp)
ss -tunlp

# Проверить таблицу ARP
ip neighbour show
```

### Скрипты и автоматизация

Использование JSON-вывода с утилитой `jq`:

```bash
# Получить статус интерфейса eth0
ip -j link show eth0 | jq '.[0].operstate'

# Получить только основной IP-адрес интерфейса
ip -j address show eth0 | jq -r '.[0].addr_info[0].local'
```

### Временный характер настроек

Все изменения, внесенные через утилиты `iproute2`, применяются немедленно в ядре, но **не сохраняются** после перезагрузки. Для постоянной настройки необходимо использовать конфигурационные файлы системы (systemd-networkd, NetworkManager, Netplan).

Подробнее см. в разделе **[Постоянная настройка сети](../../Settings/Persistent_Network/index.md)**.
