# tc netem: Эмуляция сетевых проблем

## Определения

**`tc netem` (Network Emulator)** — модуль `tc` (пакет `iproute2`) для эмуляции сетевых условий: задержки, потери, повреждения, дублирование, изменение порядка пакетов.

**`qdisc` (Queuing Discipline)** — дисциплина очереди ядра Linux, управляющая обработкой, буферизацией и отбрасыванием пакетов. `netem` — одна из таких дисциплин.

## Базовые концепции

### Эмулируемые параметры

| Параметр | Описание | Типичное применение |
|----------|----------|---------------------|
| **delay** | Искусственная задержка | Эмуляция WAN, спутниковых каналов |
| **loss** | Потеря пакетов (%) | Тестирование устойчивости к потерям |
| **corrupt** | Повреждение пакетов | Проверка целостности данных |
| **duplicate** | Дублирование пакетов | Тестирование дедупликации |
| **reorder** | Изменение порядка | Эмуляция многопутевой маршрутизации |
| **rate** | Ограничение скорости | Тестирование при низкой пропускной способности |

### Jitter и Correlation

* **Jitter (разброс)** — отклонение фактической задержки от базовой. Пример: `delay 200ms 40ms` → задержка 160–240 мс.
* **Correlation (корреляция)** — зависимость задержки текущего пакета от предыдущего. Высокая корреляция (50%+) имитирует плавные изменения, характерные для реальных сетей.

## Практические сценарии

### Добавление задержки

```bash
# Базовая задержка 100 мс
sudo tc qdisc add dev eth0 root netem delay 100ms

# Задержка 200 мс с джиттером 40 мс и корреляцией 50%
sudo tc qdisc add dev eth0 root netem delay 200ms 40ms 50%
```

### Потеря пакетов

```bash
# Потеря 70% пакетов
sudo tc qdisc add dev eth0 root netem loss 70%

# Потеря 10% с корреляцией 25%
sudo tc qdisc add dev eth0 root netem loss 10% 25%
```

### Повреждение и дублирование

```bash
# Повреждение 50% пакетов
sudo tc qdisc add dev eth0 root netem corrupt 50%

# Дублирование 40% пакетов
sudo tc qdisc add dev eth0 root netem duplicate 40%
```

### Комбинированные эффекты

```bash
# Задержка 200 мс + потеря 10%
sudo tc qdisc add dev eth0 root netem delay 200ms loss 10%

# Дублирование 40% + задержка 100 мс
sudo tc qdisc add dev eth0 root netem duplicate 40% delay 100ms
```

### Изменение порядка пакетов

```bash
# 30% пакетов приходят с задержкой 50 мс (остальные без задержки)
sudo tc qdisc add dev eth0 root netem delay 50ms 10ms reorder 30% 50%
```

### Ограничение скорости

```bash
# Ограничение до 1 Мбит/с
sudo tc qdisc add dev eth0 root netem rate 1mbit
```

### Просмотр и удаление

```bash
# Просмотр конфигурации
tc qdisc show dev eth0

# Статистика по пакетам
tc -s qdisc show dev eth0

# Удаление netem
sudo tc qdisc del dev eth0 root netem
```

> **Важно:** Если `tc qdisc del` возвращает `No such file or directory` — `netem` не настроен на интерфейсе.
