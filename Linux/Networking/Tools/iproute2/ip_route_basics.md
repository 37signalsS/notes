# ip route: основы маршрутизации в Linux

## Определения

**`ip route`** — команда `iproute2` для управления таблицей маршрутизации ядра Linux.

**Маршрутизация** — процесс определения пути для сетевого трафика на основе IP-адреса назначения.

> **Концепции:** См. [Сетевой уровень OSI](../../../../Networking/OSI_TCP_IP_Model/Network_layer/Concepts/network_layer_overview.md).

---

## Структура маршрута

```
10.0.0.0/8 via 192.168.1.1 dev eth0 proto static metric 100
│            │              │         │        │
│            │              │         │        └─ Приоритет
│            │              │         └─ Источник (static, dhcp, ra)
│            │              └─ Интерфейс
│            └─ Шлюз
└─ Сеть назначения
```

---

## Типы маршрутов

| Тип | Описание | Пример |
|-----|----------|--------|
| **unicast** | Обычный маршрут | `10.0.0.0/8 via 192.168.1.1` |
| **default** | Шлюз по умолчанию | `default via 192.168.1.1` |
| **local** | Локальная сеть/хост | `local 192.168.1.101 dev eth0` |
| **broadcast** | Broadcast-адрес | `broadcast 192.168.12.255 dev eth0` |
| **blackhole** | Отбрасывать пакеты | `blackhole 10.0.0.0/8` |
| **unreachable** | Недостижимо (ICMP error) | `unreachable 10.0.0.0/8` |
| **prohibit** | Запрещено (ICMP forbidden) | `prohibit 10.0.0.0/8` |

## Таблицы маршрутизации

| Таблица | ID | Описание |
|---------|-----|----------|
| **local** | 255 | Локальные маршруты (ядро) |
| **main** | 254 | Основная таблица (по умолчанию) |
| **default** | 253 | Пустая таблица по умолчанию |
| **custom** | 1-252 | Пользовательские (для PBR) |

### local (таблица 255)

Ядро автоматически заносит записи для локальных IP-адресов (чтобы трафик на эти адреса оставался локальным) и для broadcast-адресов.

### main (таблица 254)

Основная таблица, используемая по умолчанию, если в команде не указана другая таблица.

### default (таблица 253)

Изначально пуста, может использоваться для специальных сценариев маршрутизации.

> **PBR:** [Policy-Based Routing](../../Policy_Based_Routing/index.md) — использование множественных таблиц

## proto (источник маршрута)

| Значение | Описание |
| :--- | :--- |
| `kernel` | Добавлен ядром автоматически (при назначении IP) |
| `static` | Добавлен вручную администратором |
| `dhcp` | Получен от DHCP-сервера |
| `ra` | Получен через Router Advertisement (IPv6) |
| `boot` | Получен при загрузке |

---

## scope (область действия)

| Значение | Описание |
| :--- | :--- |
| `global` | Маршрут действителен для всех адресов |
| `link` | Действителен только для этого интерфейса |
| `host` | Действителен только для этого хоста (loopback) |
| `nowhere` | Маршрут никогда не используется |
