# ethtool: Диагностика и управление сетевыми адаптерами

## Определения

* **`ethtool`** — это утилита командной строки для Linux, позволяющая просматривать и изменять параметры физических сетевых интерфейсов (сетевых карт), а также проводить их диагностику.

## Базовые концепции

### Ключевые возможности

* **Просмотр и изменение параметров:** Управление скоростью, дуплексом и автосогласованием.
* **Диагностика:** Просмотр детальной статистики, запуск самотестов, получение информации о драйвере и прошивке.
* **Идентификация:** Возможность заставить светодиодный индикатор сетевой карты мигать для физического обнаружения.

### Дуплекс и автосогласование

* **Полудуплекс (Half-duplex)**: Устройство может либо отправлять, либо получать данные, но не одновременно.
* **Полнодуплекс (Full-duplex)**: Передача и приём происходят одновременно, что значительно повышает эффективность.
* **Автосогласование (Auto-Negotiation)**: Процесс, при котором два соединенных устройства автоматически выбирают наилучший общий режим работы (скорость и дуплекс).

**Дуплексное несоответствие (Duplex Mismatch)** — это серьезная проблема, возникающая, когда одно устройство на линии работает в полнодуплексном режиме, а другое — в полудуплексном. Это приводит к коллизиям, потерям пакетов и резкому падению производительности сети. Обычно происходит, когда на одном конце автосогласование включено, а на другом — принудительно выставлен режим. **Рекомендация:** всегда оставлять автосогласование включенным (`autoneg on`) на обоих концах соединения.

## Практические сценарии

### 1. Установка

* **Debian/Ubuntu**:

    ```bash
    sudo apt-get install ethtool
    ```

* **CentOS/RHEL/Fedora**:

    ```bash
    sudo yum install ethtool
    ```

### 2. Просмотр параметров сетевой карты

Сначала нужно узнать имя сетевого интерфейса.

```bash
ip a
```

Затем можно посмотреть его параметры.

```bash
# Показать основные настройки для интерфейса enp0s3
sudo ethtool enp0s3
```

Вывод покажет скорость, дуплекс, статус автосогласования и состояние соединения (`Link detected: yes/no`).

### 3. Изменение параметров

```bash
# Пример: принудительно установить скорость 1000 Мбит/с и полный дуплекс
sudo ethtool -s enp0s3 speed 1000 duplex full autoneg off

# Вернуть автосогласование (рекомендуется)
sudo ethtool -s enp0s3 autoneg on
```

**Важно:** Настройки, сделанные через `ethtool`, сбрасываются после перезагрузки.

### 4. Просмотр статистики и диагностика

* **Детальная статистика:**

    ```bash
    # Ключ -S показывает счетчики пакетов, байтов, ошибок и дропов
    sudo ethtool -S enp0s3
    ```

    Рост счетчиков `errors`, `dropped`, `rx_crc_errors` или `collisions` указывает на аппаратные проблемы, проблемы с кабелем или дуплексное несоответствие.

* **Идентификация порта:**

    ```bash
    # Заставить индикатор порта мигать в течение 15 секунд
    sudo ethtool -p enp0s3 15
    ```

* **Запуск самотестов:**

    ```bash
    # Запустить онлайн-тесты (не прерывают работу интерфейса в отличие от оффлайн тестов)
    sudo ethtool -t enp0s3 online
    ```

    Результат покажет, прошел ли тест или были обнаружены ошибки.

## Дополнительная информация

### 1. Информация о драйвере и прошивке

Эта информация полезна при отладке проблем совместимости или поиске обновлений.

```bash
# Ключ -i показывает имя драйвера, его версию и версию прошивки
sudo ethtool -i enp0s3
```

**Пример вывода:**

```
driver: e1000e
version: 3.2.6-k
firmware-version: 0.13-3
bus-info: 0000:00:03.0
```

### 2. Сохранение настроек на постоянной основе

Чтобы настройки сохранялись после перезагрузки, их нужно добавить в конфигурационные файлы сети. Способ зависит от дистрибутива.

* **Для RHEL/CentOS (файлы `ifcfg-*`)**:
    Отредактируйте `/etc/sysconfig/network-scripts/ifcfg-enp0s3` и добавьте:

    ```
    ETHTOOL_OPTS="speed 1000 duplex full autoneg on"
    ```

* **Для Debian/Ubuntu (`/etc/network/interfaces`)**:
    Добавьте команду в описание интерфейса:

    ```
    auto enp0s3
    iface enp0s3 inet dhcp
        pre-up /sbin/ethtool -s $IFACE speed 1000 duplex full autoneg on
    ```

* **Для systemd-networkd**:
    В файле `.network` (например, `/etc/systemd/network/10-eth.network`) добавьте секцию `[Link]`:

    ```ini
    [Match]
    Name=enp0s3

    [Link]
    Speed=1000
    Duplex=full
    AutoNegotiation=yes
    ```

Подробнее о настройке см. в [Постоянная настройка сети в Linux](../Settings/persistent_network_configuration.md).
