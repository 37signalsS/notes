# Утилита iproute2

## Определения

*   **`iproute2`** — это набор утилит для управления сетевыми интерфейсами, маршрутизацией и туннелями в ядре Linux, пришедший на смену устаревшим инструментам, таким как `ifconfig`, `route` и `arp`.

## Базовые концепции

`iproute2` предоставляет более мощный и унифицированный интерфейс для конфигурации сети. Основной исполняемый файл — `ip`. Все настройки, сделанные с помощью `ip`, являются временными и будут сброшены после перезагрузки. Для постоянной настройки сети в Linux используются другие методы, описанные в [[Постоянная настройка сети в Linux|../Settings/persistent_network_configuration.md]].

## Практические сценарии

### 1. Основные объекты и команды

Утилита `ip` имеет множество суб-команд (объектов). Наиболее часто используемые:

*   `ip address` (сокр. `ip a`): Управление IP-адресами.
*   `ip link` (сокр. `ip l`): Управление сетевыми устройствами (интерфейсами).
*   `ip route` (сокр. `ip r`): Управление таблицей маршрутизации.
*   `ip neighbour` (сокр. `ip n`): Управление ARP-таблицей и таблицей соседей NDP для IPv6.
*   `ip tunnel`: Управление туннелями.
*   `ip rule`: Управление правилами маршрутизации (policy-based routing).

### 2. Управление интерфейсами (`ip link`)

`ip link` позволяет просматривать и изменять состояние сетевых устройств.

-   **Просмотреть все интерфейсы:**
    ```bash
    ip link show
    # или коротко
    ip l
    ```

-   **Посмотреть статистику и ошибки интерфейсов:**
    Ключ `-s` добавляет подробную информацию о пакетах, ошибках и дропах.
    ```bash
    ip -s link show eth0
    ```
    *Рост счетчиков `errors` или `dropped` указывает на проблемы с сетью (например, поврежденный кабель) или нехватку ресурсов ОС.*

-   **Включить или выключить интерфейс:**
    ```bash
    # Включить
    sudo ip link set eth0 up

    # Выключить
    sudo ip link set eth0 down
    ```
    *Виртуальные интерфейсы (например, туннели) всегда создаются в состоянии `DOWN` и требуют явного включения.*

### 3. Управление адресами (`ip address`)

`ip address` управляет адресами, назначенными на интерфейсы.

-   **Просмотреть все адреса:**
    ```bash
    ip address show
    # или коротко
    ip a
    # или в кратком виде (brief)
    ip -br a
    ```

-   **Добавить или удалить IP-адрес:**
    Команды одинаковы для IPv4 и IPv6.
    ```bash
    # Добавить
    sudo ip address add 192.168.1.10/24 dev eth0

    # Удалить
    sudo ip address del 192.168.1.10/24 dev eth0
    ```

### 4. Управление маршрутизацией (`ip route`)

`ip route` позволяет просматривать и изменять таблицу маршрутизации ядра.

-   **Посмотреть таблицу маршрутизации:**
    ```bash
    ip route show
    # или коротко
    ip r
    ```
    *Ключевая строка в выводе — `default via 192.168.1.1 dev eth0`. Она указывает на **шлюз по умолчанию** (default gateway). Это адрес, на который система отправляет весь трафик для сетей, не указанных явно в таблице.*

-   **Добавить/удалить маршрут:**
    ```bash
    # Добавить маршрут к сети 10.0.0.0/8 через шлюз 192.168.1.1
    sudo ip route add 10.0.0.0/8 via 192.168.1.1

    # Добавить шлюз по умолчанию
    sudo ip route add default via 192.168.1.1
    ```

-   **Узнать, как ядро построит маршрут до конкретного IP:**
    Эта команда — мощный инструмент отладки. Она запрашивает у ядра, какой маршрут будет использован для достижения цели.
    ```bash
    ip route get 8.8.8.8
    ```
    *Вывод `8.8.8.8 via 192.168.1.1 dev eth0 src 192.168.1.10 uid 1000` показывает, что для достижения цели будет использован шлюз `192.168.1.1` на интерфейсе `eth0` с исходящим IP `192.168.1.10`.*

### 5. Управление туннелями (`ip tunnel`)

`iproute2` позволяет создавать различные типы туннелей (GRE, IPIP, VXLAN и др.).

-   **Пример создания GRE-туннеля:**
    ```bash
    # Создание туннеля
    sudo ip tunnel add gre1 mode gre remote 203.0.113.2 local 198.51.100.1 ttl 255

    # Включение интерфейса
    sudo ip link set gre1 up

    # Назначение адреса
    sudo ip address add 10.0.0.1/30 dev gre1
    ```
    *Для создания туннелей также можно использовать более современный синтаксис `ip link add type <type> ...`.*
