# Дисциплины очередей TCP (Queueing Disciplines)

## Определения

**Дисциплина очередей (Queueing Discipline, qdisc)** — механизм ядра Linux, управляющий очередями пакетов на сетевых интерфейсах, определяющий порядок и время отправки пакетов.

## Основные дисциплины

### fq_codel (Fair Queuing Controlled Delay)

* **Назначение:** Снижает латентность при смешанных нагрузках, борется с bufferbloat
* **Статус:** Устанавливается по умолчанию через `net.core.default_qdisc`
* **Принцип:** Комбинирует Fair Queuing с алгоритмом CoDel для контроля задержек

### fq (Fair Queuing)

* **Назначение:** Полезен для точного pacing с BBR при крупных передачах
* **Принцип:** Обеспечивает справедливое распределение пропускной способности между потоками

## Настройка

> Детальная настройка дисциплин выполняется через [`tc`](../Tools/iproute2/tc.md).

```bash
# Установка дисциплины по умолчанию
sysctl -w net.core.default_qdisc=fq_codel

# Для BBR рекомендуется fq
sysctl -w net.core.default_qdisc=fq
```
