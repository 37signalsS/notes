# Дисциплины очередей TCP (Queueing Disciplines)

> **SSoT:** Детальная настройка через `tc` (HTB, фильтры, классы) — в [Linux/Networking/Tools/iproute2/tc.md](../../Tools/iproute2/tc.md)

## Определения

**Дисциплина очередей (Queueing Discipline, qdisc)** — механизм ядра Linux, управляющий очередями пакетов на сетевых интерфейсах, определяющий порядок, приоритизацию и время отправки пакетов.

**Bufferbloat** — проблема избыточной буферизации в сетевых устройствах, приводящая к высокой задержке и джиттеру при загрузке канала.

## Basic Concepts

### Роль qdisc в TCP-стеке

Qdisc находится между сетевым стеком ядра и драйвером сетевой карты (NIC). Он решает, какой пакет отправить следующим, когда NIC готов к передаче.

```
TCP-стек → [qdisc] → Драйвер NIC → Сеть
           ↑
    Порядок отправки пакетов
```

### Взаимодействие с congestion control

Алгоритм управления перегрузкой (CUBIC, BBR) решает **сколько** данных отправить, а qdisc решает **в каком порядке** пакеты покинут интерфейс.

| Congestion Control | Рекомендуемая qdisc | Причина |
| :--- | :--- | :--- |
| **BBR** | `fq` | BBR использует kernel pacing — `fq` обеспечивает точное планирование пакетов |
| **CUBIC** | `fq_codel` | Борьба с bufferbloat при реактивном подходе CUBIC |

### Основные дисциплины

| Дисциплина | Тип | Назначение |
| :--- | :--- | :--- |
| **fq_codel** | Fair Queuing + CoDel | Борьба с bufferbloat, снижение латентности при смешанных нагрузках |
| **fq** | Fair Queuing | Справедливое распределение полосы, pacing для BBR |
| **pfifo_fast** | Prioritized FIFO | По умолчанию (старые ядра), простая очередь с 3 приоритетами |
| **noqueue** | Без очереди | Loopback, виртуальные интерфейсы |
| **mq** | Multi-Queue | Многопроцессорные NIC с несколькими очередями |

### fq_codel vs fq

- **fq_codel:** комбинирует Fair Queuing (изоляция потоков) с CoDel (контроль задержки через отбрасывание пакетов при росте очереди). Оптимален для общего использования.
- **fq:** обеспечивает более точный pacing (планирование отправки), что критично для BBR. Не имеет механизма CoDel для контроля задержек.

## Practical Scenarios

### Проверка текущей дисциплины

```bash
# Дисциплина по умолчанию
sysctl net.core.default_qdisc

# Дисциплины на конкретных интерфейсах
tc qdisc show

# Детально для конкретного интерфейса
tc -s qdisc show dev eth0
```

### Установка дисциплины по умолчанию

**Временно:**

```bash
# Для общего использования (борьба с bufferbloat)
sudo sysctl -w net.core.default_qdisc=fq_codel

# Для BBR (точный pacing)
sudo sysctl -w net.core.default_qdisc=fq
```

**Постоянно** (`/etc/sysctl.d/99-network.conf`):

```ini
net.core.default_qdisc = fq_codel
```

Применение: `sudo sysctl -p /etc/sysctl.d/99-network.conf`

> **Примечание:** `default_qdisc` применяется только к **новым** интерфейсам. Для существующих интерфейсов используйте `tc qdisc replace`.

### Замена дисциплины на активном интерфейсе

```bash
# Заменить на fq_codel
sudo tc qdisc replace dev eth0 root fq_codel

# Заменить на fq
sudo tc qdisc replace dev eth0 root fq

# Вернуть pfifo_fast
sudo tc qdisc replace dev eth0 root pfifo_fast
```

### Выбор qdisc для сценария

| Сценарий | qdisc | Обоснование |
| :--- | :--- | :--- |
| **Домашний роутер** | fq_codel | Борьба с bufferbloat при одновременном стриминге и загрузке |
| **Веб-сервер + BBR** | fq | Точный pacing для BBR, снижение burst |
| **Высокоскоростной канал (>10 Гбит/с)** | mq или mq + fq | Использование всех очередей многопроцессорного NIC |
| **Виртуальный интерфейс (veth)** | noqueue | Минимальные накладные расходы |
| **Сервер с mixed traffic** | fq_codel + HTB | Приоритизация + борьба с bufferbloat |

### Диагностика bufferbloat

```bash
# Мониторинг задержки под нагрузкой
ping -i 0.2 <gateway>

# Загрузить канал и наблюдать рост RTT
# Если RTT растёт в 5-10x → bufferbloat присутствует

# Проверка длины очереди (qlen)
tc -s qdisc show dev eth0 | grep qlen
```

**Симптомы bufferbloat:**

- Низкая задержка в простое, но высокий пинг при загрузке канала
- «Лаги» в видеозвонках при скачивании файлов
- Высокий `qlen` в выводе `tc -s qdisc`
