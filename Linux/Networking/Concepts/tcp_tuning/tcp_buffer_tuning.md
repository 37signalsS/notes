# Оптимизация буферов TCP

## Определения

**TCP буферы** — области памяти ядра, используемые для буферизации входящих (rmem) и исходящих (wmem) данных TCP-соединений.

## Настройка параметров

### Максимальные размеры буферов

```bash
# Максимальный размер буфера приема и передачи для всех типов соединений.
sudo sysctl -w net.core.rmem_max=16777216
sudo sysctl -w net.core.wmem_max=16777216
```

### TCP-специфичные буферы

```bash
# Минимальный, начальный, максимальный размеры для TCP
sudo sysctl -w net.ipv4.tcp_rmem='4096 87380 16777216'
sudo sysctl -w net.ipv4.tcp_wmem='4096 65536 16777216'
```

**Параметры `tcp_rmem` и `tcp_wmem`:**

1. **Минимальный** — минимальный размер буфера
2. **Начальный** — начальный размер буфера при установлении соединения
3. **Максимальный** — максимальный размер буфера
