# PXE: Загрузка по сети

## Определения

*   **PXE (Preboot Execution Environment)** — это среда, позволяющая компьютеру загружаться по сети, используя только сетевую карту, без необходимости в локальном диске с операционной системой. Читается как "пикси".

## Базовые концепции

PXE широко используется для автоматической установки ОС на большом количестве серверов, для запуска систем восстановления или бездисковых рабочих станций.

### Как работает PXE

PXE-код встроен в ПЗУ сетевой карты. Он отвечает за получение исполняемого файла по сети, используя протокол TFTP.

Процесс загрузки выглядит следующим образом:

1.  **Включение компьютера и инициализация:** При включении компьютера происходит подача питания, запускается BIOS/UEFI, который инициализирует сетевую карту через её собственный стек (ЗЧУ).
2.  **DHCP-запрос:** Клиентский компьютер отправляет широковещательный DHCP-запрос для получения сетевых настроек.
3.  **DHCP-ответ:** DHCP-сервер отвечает, предоставляя IP-адрес клиенту, а также информацию о TFTP-сервере (IP-адрес) и имени файла сетевого загрузчика (NBP).
4.  **Загрузка NBP:** Запускается программа сетевой загрузки **NBP (Network Boot Program)**, которая загружается с TFTP-сервера в оперативную память клиента.
5.  **Загрузка образа ОС:** Далее NBP загружает образ операционной системы или установочный образ.
6.  **Дальнейшая загрузка:** (Существующая информация) Загрузчик скачивает свою конфигурацию, ядро и `initrd`. Ядро запускается и, используя `initrd`, монтирует корневую файловую систему по сети (через NFS/iSCSI) или начинает автоматическую установку ОС, скачивая файлы с HTTP/FTP-сервера.

Подробнее о [[процессе загрузки Linux|../../Linux/Core/boot_process.md]].

### Преимущества PXE

PXE позволяет системным администраторам устанавливать операционные системы на компьютеры удалённо, без необходимости использовать физические носители. Это особенно полезно для массовой установки систем в корпоративных сетях и для обслуживания бездисковых рабочих станций.

## Практические сценарии

### Настройка PXE-загрузки в BIOS/UEFI

Для включения PXE-загрузки необходимо выполнить следующие шаги:

1.  **Зайдите в BIOS или UEFI** вашего компьютера.
2.  **Найдите раздел**, связанный с опциями загрузки (например, "Boot", "Advanced" или "Integrated Peripherals"), в зависимости от версии BIOS/UEFI.
3.  **Найдите опцию "Network Boot" или "LAN Boot"** и включите её. Возможно, потребуется установить сетевую карту в качестве первого загрузочного устройства.

**Примечание:** При включённой функции Fast Boot сетевые карты могут загружаться через агент сетевой загрузки, например, Network Atheros Boot Agent.

### Развертывание PXE-сервера: ключевые службы

Для развертывания PXE-сервера необходимо настроить несколько ключевых служб:

1.  **DHCP-сервер:**
    -   **Задача:** Выдать клиенту IP-адрес и сообщить, где находится TFTP-сервер и какой файл загрузчика нужно скачать.
    -   **Ключевые опции DHCP:**
        -   `next-server`: IP-адрес TFTP-сервера.
        -   `filename`: Имя файла загрузчика (например, `pxelinux.0` или `ipxe.efi`).

2.  **TFTP-сервер (Trivial File Transfer Protocol):**
    -   **Задача:** Предоставить клиенту по сети файлы, необходимые для начальной загрузки. TFTP — это очень простой протокол, который может быть реализован в прошивке сетевой карты.
    -   **Содержимое:** На TFTP-сервере размещаются:
        -   Сетевой загрузчик (`pxelinux.0`, `iPXE`).
        -   Файлы конфигурации для загрузчика.
        -   Ядро Linux (`vmlinuz`) и `initrd`.

3.  **Сетевой загрузчик (например, `PXELINUX`):**
    -   **Задача:** После загрузки по TFTP, он отображает меню загрузки (если настроено) и загружает ядро и `initrd` в память клиента.
    -   **Конфигурация:** Обычно находится в директории `pxelinux.cfg/` на TFTP-сервере.

4.  **HTTP/NFS/FTP-сервер (опционально):**
    -   **Задача:** Предоставить основной образ операционной системы и файлы для автоматической установки (например, `Kickstart` для RHEL/CentOS или `Preseed` для Debian/Ubuntu). Подробнее о [[NFS|../Services/nfs.md]].
