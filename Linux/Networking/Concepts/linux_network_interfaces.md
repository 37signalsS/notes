# Сетевые интерфейсы в Linux

## Определения

*   **Сетевой интерфейс** — это программная абстракция в ядре Linux, которая может соответствовать как физическому, так и виртуальному сетевому устройству. Он позволяет операционной системе отправлять и принимать данные по сети.

## Базовые концепции

Сетевые интерфейсы в Linux делятся на два основных типа: физические, которые соответствуют аппаратному обеспечению, и виртуальные, создаваемые программно для различных задач.

### 1. Физические интерфейсы

-   **Примеры:** `eth0`, `enp3s0`, `wlan0`
-   Интерфейсы, напрямую связанные с аппаратным обеспечением (сетевой картой или Wi-Fi адаптером).
-   Они отправляют и принимают данные по физической среде (медь, оптоволокно, радиоволны).
-   У каждого такого интерфейса есть уникальный физический адрес (MAC-адрес).
-   Для управления физическими интерфейсами используется утилита [[iproute2|../Tools/iproute2.md]].

### 2. Виртуальные интерфейсы

Они не привязаны к реальному "железу" и создаются программно для специальных задач.

-   **`loopback` (`lo`)**: Виртуальный интерфейс, который указывает на саму систему. Используется для коммуникации процессов на одной машине через сетевой стек. Всегда имеет IP-адрес `127.0.0.1`.

-   **`bridge` (мост, `br0`)**: Это "виртуальный свитч" 2-го уровня. Он позволяет объединять несколько других интерфейсов (как физических, так и виртуальных) в единый broadcast-домен, чтобы они могли общаться друг с другом, как если бы были подключены к одному физическому коммутатору. Широко используется в виртуализации (KVM, Proxmox) и контейнеризации (Docker).

-   **`veth` (Virtual Ethernet)**: Это "виртуальный патч-корд". Интерфейсы `veth` всегда создаются парами. Все, что отправляется в один конец пары, выходит из другого. Это ключевая технология для контейнеризации, позволяющая соединить сетевое пространство имен контейнера с хост-системой (обычно один конец пары находится в контейнере, а другой — на хосте, подключенный к мосту).

-   **`tun`/`tap`**: Используются для создания сетевых туннелей, чаще всего для VPN (OpenVPN, WireGuard). Они позволяют программам из пространства пользователя (user-space) напрямую отправлять и получать сетевые пакеты.
    -   **`tun`** (tunnelling): Работает на 3-м уровне (IP-пакеты). Создает point-to-point соединение.
    -   **`tap`** (terminal access point): Работает на 2-м уровне (Ethernet-кадры). Позволяет создать виртуальный сетевой адаптер.
