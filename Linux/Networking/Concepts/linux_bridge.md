# Linux Bridge

## Определения

**Linux Bridge (Мост)** — программный коммутатор канального уровня (L2) в ядре Linux, который позволяет объединять несколько сетевых интерфейсов (физических Ethernet-портов, VLAN-интерфейсов, виртуальных интерфейсов VM) в единый логический сегмент. Это создаёт широковещательный домен, в котором все подключенные устройства могут обмениваться кадрами напрямую, как если бы они были подключены к одному физическому коммутатору.

### Основные функции

* **Коммутация L2**: Пересылает кадры между портами на основе MAC-адресов.
* **Виртуализация**: Позволяет виртуальным машинам и контейнерам подключаться к физической сети хоста.
* **Инкапсуляция**: Поддерживает VLAN (IEEE 802.1Q) и другие механизмы инкапсуляции.
* **STP (Spanning Tree Protocol)**: Может быть включен для предотвращения петель в топологиях с избыточными путями.

### Использование

Linux Bridge часто используется в качестве основы для:

* **Гипервизоров**: KVM, QEMU, LXC для предоставления сетевого доступа виртуальным машинам.
* **Контейнерных платформ**: Docker, Kubernetes (через CNI плагины).
* **Создания программных коммутаторов**: В простых сценариях для объединения нескольких физических или виртуальных интерфейсов.
