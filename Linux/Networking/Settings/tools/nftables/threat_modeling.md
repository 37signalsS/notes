# nftables: моделирование угроз и схемы защиты

## Моделирование угроз

**Моделирование угроз** — процесс выявления потенциальных атак и разработки мер защиты. Для межсетевого экранирования рекомендуется стандартный алгоритм:

1. **Формулирование модели угроз** — выявление актуальных угроз для защищаемого узла
2. **Анализ и схема разграничения** — определение, какой трафик разрешать/блокировать
3. **Настройка правил** — реализация схемы в конфигурации файрвола

### Источники моделей угроз

- [MITRE ATT&CK Matrix](https://attack.mitre.org/)
- [Банк данных угроз ФСТЭК России](https://bdu.fstec.ru/)
- Публичные исследования по безопасности

## Типовые угрозы для серверов/рабочих станций

| Угроза | Описание | Меры нейтрализации |
| :--- | :--- | :--- |
| **У1. Эксплуатация уязвимостей** | Атаки на сетевые сервисы через программные/конфигурационные уязвимости | Ограничение входящего трафика по портам и IP (белые/черные списки) |
| **У2.1. DoS через перегрузку** | Превышение критического числа запросов к сервису | Rate limiting, обнаружение и блокировка атакующих IP |
| **У2.2. IP-спуфинг (127.0.0.0/8)** | Подделка обратного адреса на loopback-сеть | Отбрасывание пакетов с 127.0.0.0/8 не с loopback-интерфейса |
| **У3. Брутфорс аутентификации** | Удаленный подбор паролей к сервисам | Fail2ban + rate limiting, ограничение по IP |
| **У4. Вредоносные исходящие** | Трояны, майнеры, утечки телеметрии | Ограничение исходящего трафика (IP, порты, приложения) |
| **У5. Несанкционированные порты** | Вредоносы открывают listening-порты | Запрет входящих подключений к неизвестным сервисам |

## Схемы разграничения трафика (по возрастанию защиты)

### №1. Минимальная защита рабочей станции

**Описание:** Вход: только established/related. Выход: весь разрешен

**От каких угроз защищает:** У1, У2, У3, У5 (У4 игнорируется)

### №2. Минимальная защита сервера

**Описание:** Как №1, но + разрешены порты сервисов + защита от 127.0.0.0/8

**От каких угроз защищает:** У1 (частично), У2.2, У5 (остальные игнорируются)

### №3. Стандартная защита сервера

**Описание:** Как №2, но + исходящий запрещен, кроме established и белых портов

**От каких угроз защищает:** У2.2, У5, частично другие (У2.1 игнорируется)

### №4. Усиленная защита сервера

**Описание:** Как №3, но + rate limiting, белые списки IP, fail2ban, ограничение по IP назначения

**От каких угроз защищает:** Максимальная защита от всех угроз
