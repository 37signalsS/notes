# IPv6 в Linux — Концепции

## Определения

**IPv6 (Internet Protocol version 6)** — основной протокол сетевого уровня в современных дистрибутивах Linux. Поддержка IPv6 встроена в ядро Linux и активирована по умолчанию.

**Основные типы адресов:**

- **Link-Local (`fe80::/10`)** — автоматически назначаются каждому интерфейсу для локальной связи.
- **Unique Local Address (ULA, `fc00::/7`)** — аналог частных (серых) адресов IPv4.
- **Global Unicast (`2000::/3`)** — публичные маршрутизируемые адреса.

Подробное описание протокола и типов адресов см. в **[Обзоре IPv6](../../../../Networking/Protocols/ipv6_overview.md)**.

## Основные концепции

### Особенности реализации в Linux

| Аспект | Описание |
| :--- | :--- |
| **Стек ядра** | Поддержка IPv6 обычно встроена в ядро (`builtin`). |
| **Управление** | Параметры настраиваются через `sysctl` в пространстве `net.ipv6.*`. |
| **Dual Stack** | Linux по умолчанию поддерживает одновременную работу IPv4 и IPv6. |
| **Файрвол** | Для IPv6 используются отдельные цепочки правил (`ip6tables`) или единый `nftables`. |

### Механизмы настройки (sysctl)

Ядро Linux предоставляет гибкое управление поведением IPv6 для каждого интерфейса (`all`, `default`, `<iface>`):

- **`autoconf`**: разрешает автоматическую настройку адресов (SLAAC).
- **`accept_ra`**: разрешает прием объявлений маршрутизатора (Router Advertisements).
- **`disable_ipv6`**: позволяет полностью отключить стек IPv6 на конкретном интерфейсе.

### Privacy Extensions (RFC 4941)

В Linux этот механизм реализуется через генерацию временных случайных адресов для исходящего трафика, что затрудняет отслеживание хоста по идентификатору интерфейса (EUI-64).

**Параметр `use_tempaddr`:**

- `0`: отключено.
- `1`: включено, но предпочтение отдается постоянному адресу.
- `2`: включено, предпочтительны временные адреса для исходящих соединений.

## Практические сценарии

### Управление Privacy Extensions

Проверка текущего статуса:

```bash
sysctl net.ipv6.conf.all.use_tempaddr
```

Включение (рекомендуется значение `2` для клиентских систем):

```bash
# Временно
sudo sysctl -w net.ipv6.conf.all.use_tempaddr=2
sudo sysctl -w net.ipv6.conf.default.use_tempaddr=2

# Постоянно (/etc/sysctl.d/60-ipv6-privacy.conf)
net.ipv6.conf.all.use_tempaddr=2
net.ipv6.conf.default.use_tempaddr=2
```

### Отключение IPv6

В некоторых случаях (совместимость со старым ПО, диагностика) требуется отключить IPv6.

**1. Через sysctl (рекомендуемый способ):**

```bash
# Добавить в /etc/sysctl.d/99-disable-ipv6.conf
net.ipv6.conf.all.disable_ipv6 = 1
net.ipv6.conf.default.disable_ipv6 = 1
net.ipv6.conf.lo.disable_ipv6 = 1
```

**2. Через GRUB (полное отключение на уровне ядра):**
Добавить `ipv6.disable=1` в параметры загрузки `GRUB_CMDLINE_LINUX` в файле `/etc/default/grub`, затем обновить конфигурацию GRUB (`update-grub`).
