# IPv6 в Linux — Концепции

> **Надежность: 10/10** (Подтверждено SSoT и документацией ядра Linux 6.x)

## Определения

**IPv6 (Internet Protocol version 6)** — основной протокол сетевого уровня в современных дистрибутивах Linux. Поддержка IPv6 встроена в ядро Linux и активирована по умолчанию.

**Основные типы адресов:**

- **Link-Local (`fe80::/10`)** — автоматически назначаются каждому интерфейсу для локальной связи. Требуют указания **Scope ID** (интерфейса) для работы.
- **Unique Local Address (ULA, `fc00::/7`)** — аналог частных (серых) адресов IPv4.
- **Global Unicast (`2000::/3`)** — публичные маршрутизируемые адреса.
- **IPv4-mapped IPv6 (`::ffff:0:0/96`)** — механизм представления IPv4-адресов внутри IPv6-стека для совместимости приложений.

**Scope ID (Зональный идентификатор)** — обязательный суффикс для Link-Local адресов (например, `fe80::1%eth0`), указывающий ядру, через какой физический интерфейс следует отправлять пакет, так как один и тот же Link-Local префикс существует на всех интерфейсах.

Подробное описание протокола и типов адресов см. в **[Обзоре IPv6](../../../../Networking/Protocols/ipv6_overview.md)**.

## Основные концепции

### Особенности реализации в Linux

| Аспект | Описание |
| :--- | :--- |
| **Стек ядра** | Поддержка IPv6 встроена в ядро (`builtin`). Модульная загрузка (`modprobe ipv6`) практически не используется в современных дистрибутивах. |
| **Управление** | Основной инструмент — **iproute2** (`ip -6 addr`). Параметры ядра настраиваются через `sysctl` в пространстве `net.ipv6.*`. |
| **Dual Stack** | Linux поддерживает одновременную работу IPv4 и IPv6. Приложения могут использовать один сокет для обоих протоколов через IPv4-mapped адреса. |
| **Файрвол** | Рекомендуется использовать **nftables** (семейство `inet` для общих правил). Устаревший **ip6tables** используется для специфичных задач в старых системах. |

### Механизмы автоконфигурации

Ядро Linux поддерживает три основных способа получения адреса:
1. **SLAAC (Stateless Address Autoconfiguration)** — хост генерирует адрес сам на основе префикса от маршрутизатора (параметр `autoconf`).
2. **DHCPv6** — получение адреса от сервера (Stateful или Stateless).
3. **Static** — ручная настройка через конфигурационные файлы.

### Управление через sysctl

Параметры настраиваются для каждого интерфейса отдельно (`all`, `default`, `<iface>`):

- **`autoconf`**: разрешает генерацию адресов через SLAAC.
- **`accept_ra`**: разрешает прием объявлений маршрутизатора (Router Advertisements).
- **`disable_ipv6`**: полное отключение стека IPv6 на интерфейсе.

### Privacy Extensions (RFC 4941)

Механизм защиты приватности путем генерации временных случайных адресов для исходящего трафика. Это скрывает постоянный идентификатор интерфейса (обычно базирующийся на MAC-адресе EUI-64).

**Параметр `use_tempaddr`:**

- `0`: отключено.
- `1`: включено, но предпочтение отдается постоянному адресу.
- `2`: включено, предпочтительны временные адреса (рекомендуется для десктопов).

## Практические сценарии

### Управление Privacy Extensions

Проверка текущего статуса через **iproute2**:

```bash
ip -6 addr show eth0
# → ищи флаг 'temporary' у адресов
```

Включение через `sysctl`:

```bash
# Временно
sudo sysctl -w net.ipv6.conf.all.use_tempaddr=2
sudo sysctl -w net.ipv6.conf.default.use_tempaddr=2

# Постоянно (/etc/sysctl.d/60-ipv6-privacy.conf)
net.ipv6.conf.all.use_tempaddr=2
net.ipv6.conf.default.use_tempaddr=2
```

### Отключение IPv6

**1. Через sysctl (рекомендуемый способ):**

```bash
# Добавить в /etc/sysctl.d/99-disable-ipv6.conf
net.ipv6.conf.all.disable_ipv6 = 1
net.ipv6.conf.default.disable_ipv6 = 1
net.ipv6.conf.lo.disable_ipv6 = 1
```

**2. Через GRUB (полное отключение на уровне ядра):**
Добавить `ipv6.disable=1` в параметры загрузки `GRUB_CMDLINE_LINUX` в файле `/etc/default/grub`, затем обновить конфигурацию:
- Debian/Ubuntu: `sudo update-grub`
- RHEL/CentOS/Fedora: `sudo grub2-mkconfig -o /boot/grub2/grub.cfg`
