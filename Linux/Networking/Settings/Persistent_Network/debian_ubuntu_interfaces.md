# Debian/Ubuntu: /etc/network/interfaces

**Файл /etc/network/interfaces** — основной конфигурационный файл для пакета `ifupdown`, который используется для настройки сетевых интерфейсов в дистрибутивах Debian, старых версиях Ubuntu и специализированных системах (например, Proxmox). Это императивный способ управления сетью, где параметры каждого интерфейса описываются явно.

## Определения

- **ifupdown** — набор утилит (`ifup`, `ifdown`, `ifquery`) для управления сетевыми интерфейсами на основе конфигурации в `/etc/network/interfaces`.
- **IP (Internet Protocol)** — межсетевой протокол для передачи данных.
- **DHCP (Dynamic Host Configuration Protocol)** — протокол для автоматического получения сетевых настроек (IP-адреса, маски, шлюза).
- **DNS (Domain Name System)** — система доменных имен для преобразования имен хостов в IP-адреса.
- **Loopback (lo)** — виртуальный интерфейс обратной связи (обычно 127.0.0.1), используемый системой для внутреннего взаимодействия.

## Базовые концепции

Конфигурация состоит из строф (stanzas), определяющих поведение интерфейсов.

### Основные директивы

| Директива | Описание |
| :--- | :--- |
| `auto <iface>` | Включает интерфейс автоматически при загрузке системы. |
| `allow-hotplug <iface>` | Включает интерфейс при возникновении события «hotplug» (например, подключение кабеля или обнаружение устройства ядром). |
| `iface <iface> <family> <method>` | Описывает метод настройки интерфейса (например, `inet static` или `inet dhcp`). |

- **Семейства адресов (`family`):** `inet` (IPv4), `inet6` (IPv6).
- **Методы настройки (`method`):** `static` (статический), `dhcp` (автоматический), `loopback` (обратная петля), `manual` (ручной — используется для мостов или когда интерфейс настраивается внешними скриптами).

## Практические сценарии

### 1. Статическая настройка IP-адреса

```ini
# /etc/network/interfaces
auto lo
iface lo inet loopback

# Настройка физического интерфейса eth0
auto eth0
iface eth0 inet static
    address 192.168.1.10/24
    gateway 192.168.1.1
    dns-nameservers 8.8.8.8 1.1.1.1
```

- **`address`**: IP-адрес и маска в формате CIDR (Classless Inter-Domain Routing).
- **`gateway`**: адрес шлюза по умолчанию.
- **`dns-nameservers`**: список DNS-серверов (требует установленного пакета `resolvconf`).

### 2. Настройка через DHCP

```ini
auto eth1
iface eth1 inet dhcp
```

### 3. Использование хуков (Hook Scripts)

Хуки позволяют выполнять произвольные команды на разных этапах жизненного цикла интерфейса.

```ini
iface eth0 inet static
    address 10.10.10.10/24
    gateway 10.10.10.1
    # Выполнить перед поднятием интерфейса
    pre-up /usr/local/bin/check-link.sh
    # Выполнить после поднятия интерфейса
    post-up ip route add 172.16.0.0/16 via 10.10.10.254
    # Выполнить перед опусканием интерфейса
    pre-down /usr/local/bin/save-state.sh
    # Выполнить после опускания интерфейса
    post-down logger "Interface eth0 is down"
```

## Дополнительная информация

### Управление и применение изменений

После редактирования файла изменения необходимо применить.

| Задача | Команда |
| :--- | :--- |
| Перезагрузка всех интерфейсов | `sudo systemctl restart networking` |
| Поднять конкретный интерфейс | `sudo ifup eth0` |
| Опустить конкретный интерфейс | `sudo ifdown eth0` |
| Проверка состояния | `ifquery eth0` |

**Важно:** Команды `ifup` и `ifdown` работают только с интерфейсами, описанными в файле `interfaces`.

### Диагностика

Если интерфейс не поднимается:

1. Проверьте синтаксис: `ifquery --list --allow auto`
2. Проверьте логи: `journalctl -u networking.service`
3. Убедитесь, что интерфейс не управляется другим менеджером (например, NetworkManager).
