# iSCSI (Internet Small Computer System Interface)

Индекс документов по настройке и использованию протокола iSCSI в Linux.

## Определение

**iSCSI (Internet Small Computer System Interface)** — протокол блочного доступа, позволяющий передавать команды SCSI через IP-сети (TCP/IP). Технология позволяет превратить обычную локальную сеть в распределенную систему хранения данных (SAN), где удаленные диски подключаются и работают как локальные блочные устройства.
