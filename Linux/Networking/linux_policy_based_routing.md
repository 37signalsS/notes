# Policy-Based Routing (PBR) в Linux

**Policy-Based Routing (PBR)** – это механизм в Linux, который позволяет создавать гибкие правила маршрутизации трафика, основываясь не только на IP-адресе назначения, но и на других параметрах, таких как порт, протокол или даже владелец процесса.

## Когда это нужно?

- **Разделение трафика по разным каналам:** Например, направлять HTTP/S-трафик через VPN, а SSH и RDP — напрямую.
- **Балансировка нагрузки:** Распределять трафик между несколькими интернет-провайдерами.
- **Изоляция сервисов:** Запрещать контейнерам доступ в интернет, но разрешать обмен данными в локальной сети.

## Настройка PBR в Linux

Процесс настройки включает три основных шага: создание отдельных таблиц маршрутизации, добавление в них маршрутов и определение правил, по которым трафик будет в эти таблицы направляться.

### 1. Создание дополнительных таблиц маршрутов

По умолчанию в Linux используется основная таблица маршрутов `main`. Для PBR необходимо создать дополнительные. Имена таблиц и их числовые идентификаторы добавляются в файл `/etc/iproute2/rt_tables`.

```bash
echo "100 vpn_table" >> /etc/iproute2/rt_tables
echo "200 direct_table" >> /etc/iproute2/rt_tables
```

Здесь `100` и `200` — это уникальные идентификаторы, а `vpn_table` и `direct_table` — человекочитаемые имена.

### 2. Добавление маршрутов в новые таблицы

Предположим, система имеет два сетевых интерфейса:
- `eth0` – основной канал в интернет (шлюз `192.168.1.1`).
- `tun0` – VPN-интерфейс (шлюз `10.8.0.1`).

Добавим маршруты по умолчанию для каждой таблицы:

```bash
# Маршрут для прямого подключения через eth0
ip route add default via 192.168.1.1 dev eth0 table direct_table

# Маршрут для подключения через VPN
ip route add default via 10.8.0.1 dev tun0 table vpn_table
```

### 3. Создание правил для выбора таблицы

Правила (`ip rule`) определяют, какую таблицу маршрутизации использовать для трафика, соответствующего определенным критериям. Часто для маркировки пакетов используется `iptables` (модуль `mangle`).

#### Пример 1: Весь трафик от процесса `firefox` через VPN

1.  **Маркируем пакеты:** С помощью `iptables` помечаем все пакеты, созданные процессом с именем пользователя `firefox`, меткой `1`.
    ```bash
    iptables -t mangle -A OUTPUT -m owner --uid-owner firefox -j MARK --set-mark 1
    ```

2.  **Создаем правило:** Добавляем правило, которое направляет все пакеты с меткой `1` в таблицу `vpn_table`.
    ```bash
    ip rule add fwmark 1 table vpn_table
    ```

#### Пример 2: Весь SSH-трафик (порт 22) напрямую

1.  **Маркируем пакеты:** Помечаем все исходящие TCP-пакеты на порт `22` меткой `2`.
    ```bash
    iptables -t mangle -A OUTPUT -p tcp --dport 22 -j MARK --set-mark 2
    ```

2.  **Создаем правило:** Направляем пакеты с меткой `2` в таблицу `direct_table`.
    ```bash
    ip rule add fwmark 2 table direct_table
    ```

### 4. Проверка настроек

Для проверки текущих правил и содержимого таблиц маршрутизации используются следующие команды:

```bash
# Показать все созданные правила
ip rule show

# Показать маршруты в таблице vpn_table
ip route show table vpn_table

# Показать маршруты в таблице direct_table
ip route show table direct_table
```
