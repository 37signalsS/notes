# Утилита iproute2

`iproute2` — это набор утилит для управления сетевыми интерфейсами, маршрутизацией и туннелями в ядре Linux. Этот пакет пришел на смену устаревшим инструментам, таким как `ifconfig`, `route` и `arp`, предоставляя более мощный и унифицированный интерфейс для конфигурации сети.

Основной исполняемый файл — `ip`.

## Основные команды

Утилита `ip` имеет множество суб-команд для разных объектов. Наиболее часто используемые:

*   `ip address` (или `ip a`): Управление IP-адресами на интерфейсах.
*   `ip link` (или `ip l`): Управление сетевыми интерфейсами (включение/выключение, изменение MTU и т.д.).
*   `ip route` (или `ip r`): Управление таблицей маршрутизации.
*   `ip neighbour` (или `ip n`): Управление ARP-таблицей и таблицей соседей NDP для IPv6.
*   `ip tunnel`: Управление туннелями (IPIP, GRE, SIT).

## Управление интерфейсами (`ip link`)

`ip link` позволяет просматривать и изменять состояние сетевых устройств.

**Просмотреть все интерфейсы:**
```bash
ip link show
# или
ip l
```

**Включить или выключить интерфейс:**
```bash
# Включить
sudo ip link set eth0 up

# Выключить
sudo ip link set eth0 down
```

Ядро Linux всегда создает виртуальные интерфейсы (например, туннели) в выключенном состоянии (`DOWN`), поэтому их всегда необходимо явно включать перед использованием.

## Управление адресами (`ip address`)

**Просмотреть все адреса:**
```bash
ip address show
# или
ip a
```

**Добавить или удалить IP-адрес:**
```bash
# Добавить
sudo ip address add 192.168.1.10/24 dev eth0

# Удалить
sudo ip address del 192.168.1.10/24 dev eth0
```
Команды одинаковы для IPv4 и IPv6.

## Управление туннелями (`ip tunnel` и `ip link`)

`iproute2` предоставляет два семейства команд для настройки туннелей: `ip tunnel` и более новое `ip link`.

*   **`ip tunnel`**: Исторически первая команда для создания туннелей. Она все еще используется, но не поддерживает некоторые новые типы туннелей.
*   **`ip link`**: Более современный и универсальный способ. Для создания туннеля используется команда `ip link add type <type> ...`.

Пример создания туннеля с помощью `ip link`:
```bash
# Создание туннеля типа gre
sudo ip link add gre1 type gre remote 203.0.113.2 local 198.51.100.1

# Включение интерфейса
sudo ip link set gre1 up

# Назначение адреса
sudo ip address add 10.0.0.1/30 dev gre1
```
