# Обзор socat

## Определения

* **socat (SOcket CAT)** — многофункциональная утилита командной строки, предназначенная для перенаправления потоков данных между двумя независимыми каналами (адресами).
* **netcat (nc)** — базовая утилита для работы с сетевыми соединениями (TCP/UDP), используемая для чтения и записи данных в сетевые сокеты.

## Базовые концепции

### Отличие от netcat

В то время как `netcat` ориентирован на простую связь сетевого сокета со стандартными потоками ввода-вывода (stdin/stdout), `socat` позволяет связывать практически любые два типа данных:

* Файлы и устройства (`/dev/ttyS0`, `/dev/null`).
* Сетевые сокеты (`TCP`, `UDP`, `SCTP`, `SSL`).
* Unix domain sockets.
* Псевдотерминалы (`PTY`).
* Вывод программ (`EXEC`, `SYSTEM`).

`socat` поддерживает преобразование данных «на лету» и расширенную настройку параметров (права доступа, таймауты, опции сокетов).

### Основные опции

* `fork` — для каждого нового входящего соединения создается отдельный дочерний процесс, что позволяет обрабатывать несколько подключений одновременно.
* `reuseaddr` — позволяет приложению немедленно повторно использовать адрес (порт), не дожидаясь истечения таймаутов ядра.

## Практические сценарии

### 1. TCP-прокси (Port Forwarding)

Проброс локального порта на удаленный хост. Каждое соединение обрабатывается в отдельном процессе.

```bash
socat TCP-LISTEN:8080,fork,reuseaddr TCP:remote_host:80
```

### 2. SSL-обертка

Добавление поддержки SSL/TLS для сервиса, который изначально ее не поддерживает (например, локальный HTTP-сервер).

```bash
# На стороне сервера (терминация SSL)
socat SSL-LISTEN:443,cert=server.pem,key=server.key,fork,reuseaddr TCP:localhost:8080
```

### 3. Доступ к Unix Domain Socket через TCP

Полезно для удаленной отладки сервисов, использующих локальные сокеты (Docker API, PostgreSQL).

```bash
socat TCP-LISTEN:2375,fork,reuseaddr UNIX-CONNECT:/var/run/docker.sock
```

### 4. Эмуляция Serial-порта через TCP

Позволяет работать с удаленным оборудованием через виртуальный последовательный порт.

```bash
socat PTY,link=/dev/ttyVUSB0,rawer TCP:192.168.1.100:2000
```

* `/dev/ttyVUSB0` — путь к виртуальному устройству.

### 5. Передача файлов с отображением прогресса

Передача файла между хостами напрямую.

```bash
# На приемнике
socat TCP-LISTEN:9999,reuseaddr OPEN:file.tar.gz,create,trunc

# На отправителе
socat OPEN:file.tar.gz TCP:receiver_ip:9999
```
