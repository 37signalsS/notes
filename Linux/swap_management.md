# Управление Swap (файлом подкачки) в Linux

**Swap** (или файл подкачки) — это пространство на диске, которое операционная система использует, когда ей не хватает оперативной памяти (RAM). Если память заполнена, ядро Linux перемещает неактивные страницы памяти (данные) из RAM в swap-пространство, освобождая RAM для более важных задач. Это предотвращает сбои системы из-за нехватки памяти.

Существует два основных способа организации swap:
1.  **Swap-раздел (swap partition)**: Отдельный раздел на диске, предназначенный исключительно для подкачки.
2.  **Swap-файл (swap file)**: Специальный файл, расположенный внутри существующей файловой системы (например, `/swapfile`). Является более гибким решением.

## Swap-раздел vs Swap-файл

| Характеристика      | Swap-раздел                                       | Swap-файл                                           |
| ------------------- | ------------------------------------------------- | --------------------------------------------------- |
| **Производительность** | Традиционно считался быстрее, но на современных SSD разница незначительна. | Практически не уступает разделу по скорости.        |
| **Гибкость**        | **Низкая**. Размер сложно изменить без утилит для работы с разделами. | **Высокая**. Легко создать, удалить или изменить размер на лету. |
| **Использование**     | Классический подход, обязателен для старых систем. | Современный и рекомендуемый подход в большинстве случаев. |
| **Гибернация**      | Необходим для режима гибернации (сохранения состояния RAM на диск). | С современными ядрами Linux гибернация в swap-файл также возможна, но требует более сложной настройки. |

## Создание и активация Swap-файла

Процесс создания swap-файла состоит из нескольких команд:

```bash
# 1. Выделить место для файла (например, 4 ГБ)
sudo fallocate -l 4G /swapfile

# 2. Установить правильные права доступа (только root должен иметь доступ)
sudo chmod 600 /swapfile

# 3. Отформатировать файл как swap-пространство
sudo mkswap /swapfile

# 4. Активировать swap-файл
sudo swapon /swapfile

# 5. Добавить запись в /etc/fstab для автоматического подключения при загрузке
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

## Проверка состояния

```sh
# Показать активные swap-области
swapon --show

# Показать использование памяти и swap
free -h
```

## Тюнинг параметров Swap

Эти параметры настраиваются в файле `/etc/sysctl.conf` для постоянного применения.

### Параметр `swappiness`

`swappiness` — это параметр ядра Linux, который контролирует, насколько агрессивно система будет использовать swap. Значение варьируется от 0 до 100.

-   **`100`**: Максимально агрессивное использование swap. Ядро будет выгружать данные в swap очень активно.
-   **`60`**: Значение по умолчанию для большинства дистрибутивов.
-   **`10`**: Рекомендуемое значение для серверов и десктопов. Система будет использовать swap только тогда, когда это действительно необходимо.
-   **`0`**: Использовать swap только для предотвращения ошибок нехватки памяти, но не для повышения производительности.

**Как проверить текущее значение:**
```sh
cat /proc/sys/vm/swappiness
```

**Как временно изменить значение:**
```sh
sudo sysctl vm.swappiness=10
```

**Как изменить значение навсегда:**
Откройте файл `/etc/sysctl.conf` и добавьте или измените строку:
```
vm.swappiness=10
```
Затем примените изменения: `sudo sysctl -p`.

### Параметр `vfs_cache_pressure`

Этот параметр контролирует, насколько агрессивно ядро будет освобождать память, используемую для кэширования **dentry** (записи каталогов) и **inode** (метаданные файлов).

-   **Значение по умолчанию: `100`**. Ядро быстро освобождает кэш inode/dentry.
-   **Низкое значение (например, `50`):** Ядро будет дольше хранить этот кэш в памяти. Это может ускорить доступ к файлам на системах с большим количеством файлов, но увеличит риск нехватки памяти для процессов.
-   **Высокое значение (более `100`):** Ядро будет очень агрессивно очищать кэш метаданных.

Настройка производится аналогично `swappiness` через `sysctl`:
```bash
sudo sysctl -w vm.vfs_cache_pressure=50
```
