# Настройка Neovim с использованием LazyVim для DevOps

## Определение

**LazyVim** — это современный дистрибутив (wrapper) для Neovim, который предоставляет готовую конфигурацию с предустановленными плагинами для разработки, отладки и работы с инфраструктурой. Он ориентирован на высокую производительность (Lazy loading) и расширяемость через систему "Extras".

## Основные концепции: Vim-мышление

Vim — это не просто редактор, а **язык для редактирования текста**. Команды строятся по принципу `Действие + Объект` (например, "удалить слово", "изменить внутри кавычек"). LazyVim позволяет перенести этот подход в современные DevOps задачи за счет интеграции LSP, инструментов для работы с YAML, Docker, Kubernetes и Git.

### Текстовые объекты (Vim Language)

Комбинируйте действия (`d` - delete, `c` - change, `y` - yank/copy) с объектами:

- `iw` - inner word (слово).
- `i"` - inside quotes (внутри кавычек).
- `a(` - around parentheses (включая скобки).
- `it` - inside tag (внутри HTML/XML тега).
*Пример: `ci"` удалит всё внутри кавычек и перейдет в режим вставки.*

### Подготовка окружения

Для корректного отображения иконок и символов в LazyVim необходимо:

1. **Nerd Fonts:** Установите любой шрифт из серии Nerd Fonts (рекомендуется **JetBrains Mono Nerd Font**).
2. **Терминал:** Рекомендуется использовать современные эмуляторы с поддержкой GPU и лигатур (Kitty, Alacritty, WezTerm).
3. **Зависимости:** Убедитесь, что установлены `git`, `make`, `unzip` и компилятор C (для Tree-sitter).

### Установка

Для чистой установки выполните следующие шаги (предварительно сделайте бэкап существующих конфигов):

```bash
# Бэкап текущих настроек
mv ~/.config/nvim{,.bak}
mv ~/.local/share/nvim{,.bak}
mv ~/.local/state/nvim{,.bak}
mv ~/.cache/nvim{,.bak}

# Клонирование стартового репозитория
git clone https://github.com/LazyVim/starter ~/.config/nvim
# Удаление .git, чтобы использовать свою систему контроля версий
rm -rf ~/.config/nvim/.git
```

### Навигация и поиск

- **Leader Key:** `Space` (Пробел)
- **Поиск файлов (Picker):** `Space Space` (быстрее и эффективнее классического Explorer).
- **Поиск файлов по имени:** `Space f f`.
- **Глобальный поиск (Live Grep):** `Space /` — самый быстрый аналог `Ctrl + Shift + F` в VS Code. Ищет текст по всему проекту.
- **Поиск слова под курсором:** `Space s w` (во всем проекте).
- **Поиск символов в файле:** `Space s s` (функции, ключи YAML). Незаменимо для навигации по длинным конфигам.
- **Поиск символов в проекте:** `Space s S`.
- **Проводник файлов (Explorer):** `Space e` (использует Snacks Explorer или Neotree).
- **Поиск по горячим клавишам:** `Space s k` — позволяет найти любую привязку.
- **Поиск и замена (Search & Replace):** `Space s r` — открывает мощный инструмент `grug-far` для массовых правок.
- **Навигация по буферам (вкладкам):** `Shift h` / `Shift l` или `[` `b` / `]` `b`.
- **Список всех открытых буферов:** `Space b b`.
- **Управление окнами (Windows):** `Space w`.
- **Разделение экрана:** `Space |` (вертикально) и `Space -` (горизонтально).

### Работа с кодом и LSP

- **Code Action:** `Space c a` — исправление ошибок, импорты.
- **Rename:** `Space c r` — переименование во всем проекте.
- **Diagnostics:** `Space c d` — описание ошибки в строке.
- **Hover:** `K` — документация под курсором.
- **Переход к определению:** `g d`.

### Работа с терминалом и окнами

В LazyVim плавающий терминал и окна редактора управляются по-разному:

1. **Плавающий терминал (`Ctrl + /`):**
   - Его **не нужно** закрывать через `:q`. Просто нажмите `Ctrl + /` снова, чтобы скрыть его. Процесс в нем продолжит работать.
   - Если вы нажмете `:q` внутри терминала, вы закроете само окно терминала (иногда завершив процесс).
2. **Переключение фокуса:**
   - Для перемещения между обычными окнами (сплитами) используйте `Ctrl + h/j/k/l`.
   - Если открыт плавающий терминал, он обычно перехватывает весь фокус. Чтобы закрыть файл "на фоне", сначала скройте терминал (`Ctrl + /`), закройте файл и снова откройте терминал.
3. **Закрытие файлов (буферов):**
   - Чтобы закрыть текущий файл, не выходя из Neovim, используйте **`Space b d`** (Buffer Delete).
   - Если вы нажмете `:q`, вы закроете текущее **окно**. Если оно было единственным — Neovim закроется целиком.

### Продвинутая навигация по коду

- `gd` (Go to Definition) — переход к определению функции/переменной.
- `Shift + k` — показать документацию (LSP hover).
- `*` (звездочка) — поиск слова под курсором в текущем файле.
- `zz` — центрировать строку с курсором на экране.
- `f` + `{char}` — прыгнуть вперед к указанному символу в строке.
- `t` + `{char}` — прыгнуть вперед *до* указанного символа.
- `;` — повторить последний прыжок `f` или `t`.
- `,` — повторить прыжок в обратном направлении.
- `[` `d` / `]` `d` — переход к предыдущей/следующей ошибке (Diagnostic).

### История изменений (Undo/Redo)

- `u` — **Undo**: отмена последнего изменения (аналог `Ctrl + z`).
- `Ctrl + r` — **Redo**: возврат отмененного действия (аналог `Ctrl + y` или `Ctrl + Shift + z`).
- **Визуальное дерево (Undo Tree):** В LazyVim для этого часто используется плагин `telescope-undo.nvim`. Если он настроен, вызовите его через `Space s u` (Search Undo).

### Навигация по истории (Jump List)

Если вы переместились в другое место файла (например, к определению функции через `gd`) и хотите вернуться:

- `Ctrl + o` — шаг назад по истории перемещений.
- `Ctrl + i` — шаг вперед по истории перемещений.

### Темы и визуализация

- **Смена темы на лету:** `Space u C` — открывает список всех установленных тем (Tokyo Night, Catppuccin и др.).
- **Интерфейс Lazy:** `Space l` — обновление и управление плагинами.
- **Zen Mode:** `Space u z` — режим фокуса (скрывает лишние элементы).
- **Dimming (Затемнение):** `Space u D` — затемняет неиспользуемый код (фокус на текущей функции).

### Работа с текстом (Editing)

- **Комментирование:**
  - `gcc` — закомментировать/раскомментировать строку.
  - `gc` + движение — закомментировать блок (например, `gc4j` - 4 строки вниз).
  - В визуальном режиме: `gc` — закомментировать выделение.
- **Окружение (Surround):** Используется плагин `mini.surround`.
  - `gz` `a` `iw` `"` — обернуть слово в кавычки.
  - `gz` `d` `"` — удалить кавычки вокруг.
  - `gz` `r` `"` `'` — заменить кавычки на одинарные.

## Практические сценарии для DevOps

### Использование расширений (Extras)

LazyVim предлагает систему Extras для быстрой настройки под конкретные технологии. Вызовите `:LazyExtras` и выберите необходимые:

- **Языки и инструменты:**
  - `lang.go`: Для написания Kubernetes операторов.
  - `lang.yaml`: Критически важен для K8s, Ansible и CI/CD.
  - `lang.markdown`: Улучшает работу с документацией (LSP `marksman`, `render-markdown` для красоты, `markdown-preview` для просмотра в браузере через `Space c p`).
  - `lang.helm`, `lang.docker`, `lang.ansible`, `lang.terraform`.

- **Утилиты:**
  - `util.git`: Интеграция с Git.
  - `coding.copilot`: AI-помощник (требуется авторизация через `:Copilot setup`).
  - `editor.snacks`: Набор современных инструментов.

### Оптимизация и кастомизация

Настройки находятся в `~/.config/nvim/lua/config/`:

1. **Отключение анимаций (для скорости):**
   В файле `lua/config/options.lua` добавьте:

   ```lua
   -- Отключение анимаций Snacks для мгновенного отклика
   vim.g.snacks_animate = false
   ```

2. **Обучение Vim Motions (плагин Hardtime):**
   Если вы хотите быстро избавиться от привычки использовать стрелочки или спамить `hjkl`, установите плагин **hardtime.nvim**. Он блокирует повторяющиеся нажатия, заставляя использовать более эффективные движения (например, `10j`, `w`, `f{char}`).
   Создайте `lua/plugins/training.lua`:

   ```lua
   return {
     "m4xshen/hardtime.nvim",
     dependencies = { "MunifTanjim/nui.nvim", "nvim-lua/plenary.nvim" },
     opts = {}
   }
   ```

3. **Просмотр изображений прямо в терминале:**
   Создайте файл `lua/plugins/snacks.lua`:

   ```lua
   return {
     "folke/snacks.nvim",
     opts = {
       image = { enabled = true },
     },
   }
   ```

4. **Пользовательские горячие клавиши (`lua/config/keymaps.lua`):**

   ```lua
   -- Быстрое сохранение (аналог VS Code)
   vim.keymap.set({ "i", "x", "n", "s" }, "<C-s>", "<cmd>w<cr><ESC>", { desc = "Сохранить файл" })
   -- Выход из режима вставки
   vim.keymap.set("i", "jj", "<Esc>", { desc = "Выход в нормальный режим" })
   ```

### Работа с Git (LazyGit)

Интеграция с **LazyGit** — killer-feature для DevOps:

- Вызов LazyGit: `Space g g`
- Стейджинг, коммиты и работа с ветками через удобный TUI.

## Глобальный поиск: Neovim vs VS Code

В VS Code поиск `Ctrl + Shift + F` по умолчанию может работать в литеральном режиме. В LazyVim поиск через `ripgrep` (rg) по умолчанию использует **регулярные выражения**.

### Почему VS Code может находить "больше"?

1. **Специальные символы (Regex):** Это главная причина вашего случая. Поиск `[TARGET]` в Neovim интерпретируется как поиск *любого одного* символа 'T', 'A', 'R', 'G', 'E', 'T'.
   - **Решение в LazyVim (Snacks Picker):**
     - Нажмите **`Alt + r`** прямо в окне поиска, чтобы переключиться в **Literal** режим (отключить Regex).
     - Или экранируйте: `\[TARGET\]`.
2. **Игнорируемые файлы:** По умолчанию поиск не заходит в файлы из `.gitignore`.
   - Решение: `Space s G` (Grep в корне с учетом игнорируемых).
3. **Регистр:** Используется Smart Case. Если всё в нижнем регистре — поиск нечувствителен. Если есть хоть одна заглавная — поиск ищет точное совпадение регистра.

## Философия перехода с VS Code

1. **Режимы (Modes):** Помните, где вы находитесь. **Normal** (навигация), **Insert** (ввод текста), **Visual** (выделение).
2. **Vim Motions:** Самый сложный этап. Не пытайтесь выучить всё сразу. Начните с `h, j, k, l`. Используйте `w` (слово вперед), `b` (слово назад), `0` (начало строки), `$` (конец строки).
3. **Терминал:** `Ctrl + \` (бэкслеш) открывает встроенный терминал.
4. **Session Restore:** В меню LazyVim (или через `Space s q`) можно восстановить последнюю сессию со всеми открытыми файлами.

## Как эффективно учиться

1. **VimTutor:** Введите в терминале `vimtutor` или в Neovim `:Tutor`. Это 30-минутный интерактивный курс, встроенный в редактор.
2. **Интерактивные игры:**
   - [Vim Adventures](https://vim-adventures.com/) — обучение через RPG-игру.
   - [Vim Golf](https://www.vimgolf.com/) — решение задач по редактированию за минимальное количество нажатий.
3. **Раскладка:** Если вы используете русскую раскладку, команды могут не работать. Рекомендуется использовать английскую для управления или установить плагин для `langmap`.
4. **Практика:** Попробуйте полностью заменить VS Code на один день при работе с YAML или скриптами.

## Дополнительная информация

- **Markdown Preview:** `Space c p` откроет предпросмотр в браузере. Оттуда можно распечатать файл в PDF (даже в темной теме).
- **Scratch Buffer:** `Space n .` — временный буфер для заметок.
- **Форматирование:** Происходит автоматически при сохранении (`Ctrl+s`) при наличии LSP.
