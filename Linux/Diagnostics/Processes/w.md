# `w`

## Определения

**`w`** — стандартная утилита для отображения информации о залогиненных пользователях и их текущих активных процессах. Комбинирует данные `uptime`, `who` и [`ps`](./ps.md).

**Ключевые особенности:**
- Быстрый обзор активных пользовательских сессий
- Информация о времени бездействия (idle)
- Данные о текущих процессах пользователей

## Основные концепции

### Структура вывода

`w` агрегирует информацию из трёх источников:

| Источник | Данные |
| :--- | :--- |
| [`uptime`](#см-также) | Uptime и Load Average |
| [`who`](#см-также) | Пользователи, терминалы, время входа |
| [`ps`](./ps.md) | Текущие активные процессы |

### Пример вывода

```
 10:45:01 up 10 days, 20:21,  2 users,  load average: 0.00, 0.01, 0.05
USER     TTY      FROM             LOGIN@   IDLE   JCPU   PCPU WHAT
user1    pts/0    192.168.1.100    10:30    1.00s  0.02s  0.00s w
user2    pts/1    192.168.1.101    10:40    5.00s  0.01s  0.01s -bash
```

### Столбцы

| Столбец | Описание |
| :--- | :--- |
| `USER` | Имя пользователя |
| `TTY` | Терминал сессии (`pts/X` для SSH, `ttyX` для локальных) |
| `FROM` | IP-адрес или хост подключения |
| `LOGIN@` | Время входа в систему |
| `IDLE` | Время бездействия (с последнего ввода) |
| `JCPU` | Время CPU всех процессов сессии |
| `PCPU` | Время CPU текущего процесса (`WHAT`) |
| `WHAT` | Текущая команда/процесс |

#### Заголовок

**Пример:** `10:45:01 up 10 days, 20:21, 2 users, load average: 0.00, 0.01, 0.05`

| Поле | Описание |
| :--- | :--- |
| `10:45:01` | Текущее время |
| `up 10 days, 20:21` | Uptime системы |
| `2 users` | Количество активных сессий |
| `load average` | Средняя нагрузка (1, 5, 15 мин) — см. [scheduling.md](../../Core/processes/scheduling.md#load-average-la) |

## Практические сценарии

### Базовое использование

```bash
# Показать всех залогиненных пользователей
w

# Информация о конкретном пользователе
w username

# Без заголовка (только таблица)
w -h
```

### Диагностика сессий

#### Поиск неактивных пользователей

```bash
# Пользователи с большим временем бездействия
w | awk 'NR==1 || $4 ~ /:[0-9]{2}/'
```

#### Проверка удалённых подключений

```bash
# Все SSH-подключения
w | grep pts

# Подключения с конкретного IP
w | grep 192.168.1
```

#### Мониторинг активности

```bash
# Непрерывный мониторинг (обновление каждые 2 секунды)
watch -n 2 w
```

### Скриптовая автоматизация

```bash
# Количество активных пользователей
w -h | wc -l

# Получить список пользователей
w -h | awk '{print $1}' | sort -u

# Найти пользователей с определённым процессом
w | grep nginx
```

## Дополнительная информация

### Опции

| Опция | Описание |
| :--- | :--- |
| `-h` | Без заголовка |
| `-u` | Без CPU-времени (быстрее) |
| `-s` | Короткий формат (без JCPU/PCPU) |
| `-f` | С/без поля FROM (в зависимости от версии) |
| `-i` | Без поля FROM (альтернативная опция) |

### Сравнение с аналогами

| Инструмент | Назначение |
| :--- | :--- |
| [`who`](#см-также) | Только список пользователей |
| [`uptime`](#см-также) | Только uptime и нагрузка |
| [`last`](#см-также) | История входов |
| [`users`](#см-также) | Только имена пользователей |
| [`ps -fu <user>`](./ps.md) | Подробная информация о процессах пользователя |
| [`top`](./top.md) / [`htop`](./htop.md) | Интерактивный мониторинг процессов |

### Ограничения

- **Только активные сессии:** Не показывает исторические данные
- **Ограниченная детализация:** Для подробной информации о процессах — [`ps`](./ps.md)
- **Зависит от utmp:** Данные берутся из `/var/run/utmp`
