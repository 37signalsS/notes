# `w`

### Определения

`w` — это стандартная консольная утилита в Unix-поподобных системах, которая предоставляет динамический обзор залогиненных в данный момент пользователей и их текущих активных процессов.

### Основные концепции

`w` является комбинацией вывода трех утилит:

- **`uptime`**: Информация о времени работы системы (uptime) и средней нагрузке (Load Average).
- **`who`**: Данные о залогиненных пользователях (имя пользователя, терминал, IP-адрес, время входа).
- **[`ps`](./ps.md)**: Информация о текущем процессе, запущенном в сессии пользователя.

#### Пример вывода и объяснение столбцов

```
 10:45:01 up 10 days, 20:21,  2 users,  load average: 0.00, 0.01, 0.05
USER     TTY      FROM             LOGIN@   IDLE   JCPU   PCPU WHAT
user1    pts/0    192.168.1.100    10:30    1.00s  0.02s  0.00s w
user2    pts/1    192.168.1.101    10:40    5.00s  0.01s  0.01s -bash
```

**Пояснения к заголовку:**

- **`10:45:01`**: Текущее системное время.
- **`up 10 days, 20:21`**: Время работы системы с момента последней загрузки (uptime).
- **`2 users`**: Общее количество активных пользовательских сессий.
- **`load average: 0.00, 0.01, 0.05`**: Средняя нагрузка на систему за последние 1, 5 и 15 минут. Подробнее см. в [**планировщике и LA**](../Core/processes/scheduling.md#load-average-la).

**Пояснения к столбцам таблицы:**

- **`USER`**: Имя пользователя.
- **`TTY`**: Терминал, через который пользователь подключен (например, `pts/0` для SSH).
- **`FROM`**: IP-адрес хоста, с которого пользователь подключился.
- **`LOGIN@`**: Время входа пользователя в систему.
- **`IDLE`**: Время бездействия пользователя (с момента последнего ввода с терминала).
- **`JCPU` (JCPU time)**: Время, использованное всеми процессами, присоединенными к данному `TTY` (включая фоновые задачи).
- **`PCPU` (PCPU time)**: Время, использованное текущим активным процессом пользователя (`WHAT`).
- **`WHAT`**: Текущая команда или процесс, который выполняется пользователем.

### Практические сценарии

#### Мониторинг активных пользователей

```bash
w
```

### Дополнительная информация

Если требуется более глубокий анализ активности конкретного пользователя или детализация его процессов, рекомендуется использовать специализированные утилиты:

- **[`ps -fu <username>`](./ps.md)**: Для получения полного списка процессов, запущенных конкретным пользователем.
- **[`top`](./top.md)** или **[`htop`](./htop.md)**: Для интерактивного мониторинга процессов и использования ресурсов в реальном времени с возможностью сортировки, фильтрации и управления процессами.
