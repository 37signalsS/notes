# `pidstat`

## Определение

`pidstat` — это утилита командной строки из пакета `sysstat`, предназначенная для мониторинга использования системных ресурсов отдельными процессами Linux. Она предоставляет детальную статистику по CPU, памяти, вводу-выводу (I/O) и другим параметрам для конкретных задач.

## Основные концепции

В отличие от `top` или `htop`, которые показывают общую картину в реальном времени, `pidstat` фокусируется на сборе статистики по процессам с течением времени. Это делает его особенно полезным для:

-   **Отслеживания короткоживущих процессов:** `pidstat` способен фиксировать активность процессов, которые запускаются и завершаются так быстро, что их невозможно заметить в `top`.
-   **Анализа конкретных ресурсов:** Позволяет изолированно изучать потребление CPU, дискового I/O или памяти для одного или нескольких процессов.
-   **Создания отчетов:** Может работать в фоновом режиме, собирая данные с заданным интервалом для последующего анализа.

## Практические сценарии

### Мониторинг использования CPU

```bash
# Показать статистику по CPU для всех процессов с интервалом в 1 секунду
pidstat -u 1
```

### Мониторинг дискового I/O

Это одна из самых частых задач для `pidstat`, так как позволяет точно определить, какой процесс создает нагрузку на диски.

```bash
# Мониторинг I/O для всех активных процессов с интервалом в 1 секунду
pidstat -d 1

# Мониторинг I/O для конкретного процесса (замените <PID> на ID процесса)
pidstat -d -p <PID> 1
```
**Ключевые колонки:**

- `kB_rd/s`: Килобайт прочитано с диска в секунду.
- `kB_wr/s`: Килобайт записано на диск в секунду.
- `kB_ccwr/s`: Килобайт, запись которых на диск была отменена (например, при удалении временных файлов).

### Мониторинг использования памяти

```bash
# Показать статистику по сбоям страниц памяти (page faults) и использованию памяти
pidstat -r 1
```

## Дополнительная информация

### Комплексный мониторинг

```bash
# Одновременно отслеживать CPU (-u), память (-r) и I/O (-d) для процесса с PID 1234
pidstat -urd -p 1234 1
```

### Отчет по потокам (Threads)

```bash
# Показать статистику I/O для процесса и всех его потоков
pidstat -d -t -p <PID> 1
```
