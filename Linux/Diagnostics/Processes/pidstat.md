# `pidstat`

## Определения

**`pidstat`** — утилита из пакета `sysstat` для мониторинга использования системных ресурсов отдельными процессами Linux. Предоставляет детальную статистику по CPU, памяти, I/O и другим параметрам с возможностью сбора данных с заданным интервалом.

**Ключевые особенности:**
- Фокус на отдельных процессах (в отличие от [`top`](./top.md), показывающего общую картину)
- Поддержка исторических данных (сбор с интервалом)
- Выявление короткоживущих процессов
- Гибкая фильтрация по PID, пользователю, ресурсам

**Требования:** Требуется установка пакета `sysstat`.

## Основные концепции

### Отличия от других инструментов

| Инструмент | Назначение | Интерактивность | История |
| :--- | :--- | :--- | :--- |
| [`top`](./top.md) | Общая картина по системе | Да | Нет |
| [`htop`](./htop.md) | Удобный мониторинг процессов | Да | Нет |
| [`ps`](./ps.md) | Снимок процессов | Нет | Нет |
| **`pidstat`** | **Статистика по процессам** | **Ограниченно** | **Да** |
| [`atop`](../Performance/atop.md) | Комплексный мониторинг | Да | Да |

### Режимы работы

1. **Одномоментный снимок:** `pidstat -u` (статистика с момента загрузки)
2. **Непрерывный мониторинг:** `pidstat -u 1` (вывод каждые 1 секунду)
3. **Ограниченная серия:** `pidstat -u 1 5` (5 отчётов с интервалом 1 сек)

### Ключевые метрики

#### CPU (-u)

| Поле | Описание |
| :--- | :--- |
| `PID` | Идентификатор процесса |
| `%usr` | Время в пользовательском режиме |
| `%system` | Время в режиме ядра |
| `%guest` | Время гостевой системы (VM) |
| `%CPU` | Общий процент использования CPU |
| `CPU` | Номер процессора |
| `Command` | Имя команды |

#### I/O (-d)

| Поле | Описание |
| :--- | :--- |
| `PID` | Идентификатор процесса |
| `kB_rd/s` | КБ прочитано с диска в секунду |
| `kB_wr/s` | КБ записано на диск в секунду |
| `kB_ccwr/s` | КБ отменённой записи (cancelled write) |
| `iodelay` | Задержка I/O (в тактах процессора) |
| `Command` | Имя команды |

#### Память (-r)

| Поле | Описание |
| :--- | :--- |
| `PID` | Идентификатор процесса |
| `minflt/s` | Малые отказы страниц в секунду |
| `majflt/s` | Серьёзные отказы страниц в секунду |
| `VSZ` | Виртуальная память (КБ) |
| `%MEM` | Процент использования памяти |
| `Command` | Имя команды |

#### Потоки (-t)

Добавляет информацию о потоках внутри процесса:
- `TGID` — ID группы потоков (PID процесса)
- `TID` — ID потока

Подробно о памяти: [process_memory_metrics.md](../../Core/memory/process_memory_metrics.md).

## Практические сценарии

### Мониторинг CPU

```bash
# Статистика CPU для всех процессов (с момента загрузки)
pidstat -u

# Непрерывный мониторинг с интервалом 1 секунда
pidstat -u 1

# Ограниченная серия: 5 отчётов с интервалом 2 секунды
pidstat -u 2 5

# Мониторинг конкретного PID
pidstat -u -p 1234 1

# Мониторинг всех процессов, кроме pidstat
pidstat -u -I ALL
```

### Мониторинг дискового I/O

```bash
# Базовый мониторинг I/O
pidstat -d 1

# Только для конкретного процесса
pidstat -d -p 1234 1

# С детализацией по потокам
pidstat -d -t -p 1234 1

# Имя команды в выводе
pidstat -d -l 1
```

**Интерпретация:**
- Высокий `kB_wr/s` — активная запись (бэкапы, логи, БД)
- Высокий `kB_ccwr/s` — отменённая запись (временные файлы)
- Высокий `iodelay` — узкое место дисковой подсистемы

### Мониторинг памяти

```bash
# Статистика памяти
pidstat -r 1

# С поиском утечек (рост VSZ и %MEM)
pidstat -r -p 1234 1

# Совместно с CPU
pidstat -ur 1
```

**Интерпретация:**
- Рост `minflt/s` — активное выделение памяти
- Рост `majflt/s` — нехватка RAM, свопинг
- Постоянный рост `VSZ` — возможная утечка памяти

### Комплексный мониторинг

```bash
# CPU + память + I/O для процесса
pidstat -urd -p 1234 1

# Все метрики для всех процессов
pidstat -urdh 1

# С указанием номера CPU
pidstat -u -H 1
```

### Анализ потоков (threads)

```bash
# Статистика по потокам конкретного процесса
pidstat -t -p 1234 1

# Потоки с детализацией I/O
pidstat -d -t -p 1234 1

# Потоки с полным именем команды
pidstat -t -l -p 1234 1
```

### Выявление короткоживущих процессов

```bash
# Запуск с малым интервалом для фиксации кратковременных процессов
pidstat -u 0.5 100

# Логирование для последующего анализа
pidstat -u 1 3600 > /var/log/pidstat_hourly.log
```

### Диагностика проблем

#### Поиск процесса с высоким I/O

```bash
# Запустить мониторинг I/O
pidstat -d 1

# Определить процесс с высоким kB_wr/s или kB_rd/s
# Для детального анализа переключиться на pidstat -d -p <PID> 1
```

Альтернатива: [`iotop`](../Filesystem/iotop.md) для интерактивного режима.

#### Поиск утечки памяти

```bash
# Мониторинг памяти с интервалом 5 секунд
pidstat -r 5

# Искать процессы с постоянным ростом VSZ и %MEM
```

Для точного анализа использовать [`smem`](../Memory/smem.md).

#### Анализ нагрузки на CPU по потокам

```bash
# Для многопоточного приложения (например, Java)
pidstat -t -p $(pgrep -f java) 1
```

Покажет, какие потоки потребляют больше всего CPU.

### Экспорт данных

```bash
# Вывод в CSV для анализа в Excel/Google Sheets
pidstat -u 1 -o - > /tmp/pidstat.csv

# Логирование для последующего анализа
pidstat -urd 1 >> /var/log/pidstat.log &
```

## Дополнительная информация

### Установка

```bash
# Debian/Ubuntu
sudo apt install sysstat

# RHEL/CentOS/Fedora
sudo dnf install sysstat

# Alpine
apk add sysstat

# SUSE
sudo zypper install sysstat
```

### Конфигурация

Пакет `sysstat` может требовать включения сбора статистики:

```bash
# Проверить статус службы сбора данных
systemctl status sysstat

# Включить сбор данных (Debian/Ubuntu)
sudo systemctl enable sysstat
sudo systemctl start sysstat
```

Конфигурация: `/etc/default/sysstat` или `/etc/sysstat/sysstat`.

### Сравнение с аналогами

| Инструмент | Преимущества | Недостатки |
| :--- | :--- | :--- |
| [`top`](./top.md) | Встроен, интерактивный | Нет истории, общая картина |
| [`htop`](./htop.md) | Удобный интерфейс | Нет истории |
| [`ps`](./ps.md) | Снимок для скриптов | Нет динамики |
| [`atop`](../Performance/atop.md) | Комплексный, история | Требует демона |
| [`sar`](../Performance/sar.md) | Системная статистика | Не по процессам |

### Ограничения

- **Требует установки:** Не входит в базовую поставку
- **Ограниченная интерактивность:** Не заменяет `top`/`htop`
- **Требует прав root:** Для полной информации по всем процессам
