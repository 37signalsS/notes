# `htop`

## Определение

`htop` — это кросс-платформенный интерактивный монитор процессов, являющийся более продвинутой и дружелюбной альтернативой стандартной утилите `top`. Он предоставляет цветной интерфейс, полную командную строку процессов, возможность вертикальной и горизонтальной прокрутки, а также интуитивное управление для отправки сигналов процессам.

## Основные концепции

-   **Графические индикаторы**: Загрузка CPU (по каждому ядру), использование физической и swap-памяти отображаются в виде цветных полос.
-   **Древовидный вид**: Позволяет наглядно отслеживать иерархию процессов.
-   **Полные командные строки**: Видно, с какими аргументами был запущен каждый процесс.
-   **Управление мышью**: Поддерживаются клики по элементам интерфейса.

## Практические сценарии

### Основные интерактивные команды

Управление в `htop` осуществляется с помощью функциональных клавиш (F1-F10) и других горячих клавиш:

-   **`t`** или **`F5`**: Вывести процессы в виде дерева, что помогает понять родительско-дочерние связи.
-   **`C`** (Shift+c) / **`M`** (Shift+m) / **`P`** (Shift+p): Сортировать процессы по CPU, памяти (MEM) или приоритету.
-   **`/`** или **`F3`**: Поиск по имени процесса.
-   **`\`** или **`F4`**: Фильтр по имени процесса (отображает только совпадающие). Для сброса фильтра нажмите `Esc`.
-   **`u`** или **`F6`**: Показать процессы, принадлежащие конкретному пользователю.
-   **`k`** или **`F9`**: Послать сигнал выбранному процессу (например, `SIGTERM` или `SIGKILL`).
-   **`l`** (строчная L): Показать файлы, открытые процессом (использует [`lsof`](./lsof.md)).
-   **`e`**: Показать переменные окружения процесса.
-   **`Пробел`**: Выделить/снять выделение с процесса для выполнения массовых действий (например, одновременного "убийства" нескольких процессов).

## Дополнительная информация

### Кастомизация `htop`

`htop` можно настроить под свои нужды через меню **Setup (F2)**. Вы можете добавлять и убирать столбцы, менять цветовую схему, настраивать отображение индикаторов в "шапке".

Конфигурация сохраняется в файле `~/.config/htop/htoprc`.

**Пример команды для быстрой установки конфигурации с созданием бэкапа старой:**

```bash
mkdir -p ~/.config/htop && [ -f ~/.config/htop/htoprc ] && mv ~/.config/htop/htoprc ~/.config/htop/htoprc.bak.$(date +%Y%m%d%H%M%S); curl -fsSL "https://gist.github.com/itcaat/45ea5994d66378fc4bd647cab860a05f/raw" -o ~/.config/htop/htoprc
```
