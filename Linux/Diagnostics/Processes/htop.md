# `htop`

## Определения

**`htop`** — интерактивный монитор процессов с цветным TUI-интерфейсом, расширенная альтернатива [`top`](./top.md). Предоставляет горизонтальную/вертикальную прокрутку, полное отображение командных строк и интуитивное управление сигналами процессов.

## Основные концепции

### Архитектура

`htop` получает данные из `/proc`, аналогично [`top`](./top.md) и [`ps`](./ps.md), но предоставляет более удобный интерфейс агрегации и визуализации.

### Графические индикаторы

В верхней части отображаются метрики системы:
- **CPU**: загрузка по каждому ядру с разбивкой по типам (user, system, nice, idle, iowait, irq)
- **Memory**: использование физической памяти (used, buffers, cached, available)
- **Swap**: использование пространства подкачки

### Столбцы процессов

| Столбец | Описание |
| :--- | :--- |
| `PID` | Идентификатор процесса |
| `USER` | Владелец процесса |
| `PRI` | Приоритет планировщика |
| `NI` | Nice-значение (приоритет пользователя) |
| `VIRT` | Виртуальная память (см. [process_memory_metrics.md](../../Core/memory/process_memory_metrics.md)) |
| `RES` | Резидентная память в RAM |
| `SHR` | Разделяемая память |
| `CPU%` | Процент использования CPU |
| `MEM%` | Процент использования памяти |
| `TIME+` | Суммарное время CPU |
| `COMMAND` | Командная строка процесса |

## Практические сценарии

### Быстрый запуск

```bash
# Базовый запуск
htop

# Запуск от root для просмотра всех процессов
sudo htop

# Запуск с фильтрацией по имени
htop -p nginx

# Запуск с сортировкой по памяти
htop --sort-key=PERCENT_MEM
```

### Интерактивные команды

#### Управление отображением

| Клавиша | Действие |
| :--- | :--- |
| `F5` / `t` | Древовидный вид (tree view) |
| `F2` / `Setup` | Настройка интерфейса |
| `F1` / `Help` | Справка |
| `F10` / `q` | Выход |
| `1` | Развернуть статистику по ядрам CPU |
| `H` | Показать потоки (threads) |

#### Фильтрация и поиск

| Клавиша | Действие |
| :--- | :--- |
| `F3` / `/` | Поиск процесса по имени |
| `F4` / `\` | Фильтр (показывать только совпадения) |
| `F6` / `s` | Сортировка по столбцу |
| `u` | Фильтр по пользователю |

#### Управление процессами

| Клавиша | Действие |
| :--- | :--- |
| `F9` / `k` | Послать сигнал процессу |
| `l` | Показать открытые файлы ([`lsof`](./lsof.md)) |
| `e` | Показать переменные окружения |
| `Пробел` | Выделить процесс для группового действия |
| `+` / `-` | Изменить nice-значение |

### Диагностика проблем

#### Поиск процесса, потребляющего CPU

1. Запустить `htop`
2. Нажать `F6`, выбрать сортировку по `CPU%`
3. Процессы с высоким `%CPU` отобразятся сверху
4. Нажать `l` для просмотра открытых файлов
5. Нажать `F9` для отправки сигнала при необходимости

#### Анализ иерархии процессов

```bash
# В интерактивном режиме нажать F5
```

Отобразит дерево процессов с родительско-дочерними связями. Полезно для понимания, какой сервис породил проблемный процесс.

#### Мониторинг конкретного пользователя

```bash
# В интерактивном режиме нажать 'u', ввести имя пользователя
# Или запустить сразу с фильтром
htop -u www-data
```

### Скриптовая автоматизация

```bash
# Сделать снимок процессов в пакетном режиме
htop -b -n 1 > /tmp/htop_snapshot.txt

# Сохранить топ-10 процессов по памяти
htop -b -n 1 --sort-key=PERCENT_MEM | head -n 10
```

## Дополнительная информация

### Конфигурация

Конфигурация хранится в `~/.config/htop/htoprc`. Настройка через `F2 → Setup`:

- **Meters**: настройка индикаторов в "шапке"
- **Display options**: цвета, обновление, поведение
- **Columns**: выбор и порядок столбцов
- **Colors**: цветовые схемы

**Пример быстрой настройки с бэкапом:**
```bash
mkdir -p ~/.config/htop && \
[ -f ~/.config/htop/htoprc ] && \
mv ~/.config/htop/htoprc ~/.config/htop/htoprc.bak.$(date +%Y%m%d%H%M%S)
# Далее вручную настроить через F2 или скопировать готовый конфиг
```

### Сравнение с аналогами

| Инструмент | Преимущества | Недостатки | Когда использовать |
| :--- | :--- | :--- | :--- |
| [`top`](./top.md) | Встроен в базовую систему, пакетный режим | Менее удобный интерфейс | Системы без `htop`, скрипты |
| [`atop`](../Performance/atop.md) | **Исторические логи**, Dirty Cache, детальный I/O | Сложный интерфейс, требует изучения | **Глубокий анализ инцидентов**, постфактум диагностика |
| [`ps`](./ps.md) | Скриптовая автоматизация, снимки | Не интерактивный | Скрипты, разовые проверки |
| [`systemd-cgtop`](../../Core/systemd/cgtop.md) | Агрегация по cgroups/systemd-сервисам | Только для systemd | Мониторинг systemd-юнитов |


### Ограничения

- **Требует установки**: не входит в базовую поставку некоторых дистрибутивов
- **Ресурсоёмкость**: потребляет больше CPU, чем `top`, при частом обновлении
- **Ограниченная кастомизация**: меньше возможностей настройки вывода, чем у `ps -o`
