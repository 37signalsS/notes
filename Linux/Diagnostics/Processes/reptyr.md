# Утилита `reptyr`

## Определения

**`reptyr`** — специализированная утилита интерфейса командной строки (CLI — Command Line Interface), предназначенная для перехвата запущенного процесса из одной терминальной сессии и его переноса в другую без остановки выполнения.

## Основные концепции

### Назначение инструмента

Типичный сценарий использования возникает, когда длительный процесс (сборка программного обеспечения, миграция базы данных или передача файлов) был запущен в обычной сессии Secure Shell (SSH) без использования терминальных мультиплексоров (`tmux` или `screen`). При разрыве сетевого соединения такой процесс получит сигнал `SIGHUP` и принудительно завершится. `reptyr` позволяет «спасти» выполнение, переместив процесс в стабильную сессию мультиплексора.

### Принцип работы

Утилита использует системный вызов `ptrace` для временной приостановки целевого процесса. В этот момент `reptyr` выполняет перехват файловых дескрипторов, связанных со стандартными потоками ввода-вывода (stdin, stdout, stderr), и перенаправляет их на управляющий терминал новой сессии.

### Требования и безопасность

Для корректной работы требуются права суперпользователя (root) или специфические настройки ядра. В современных дистрибутивах Linux возможность использования `ptrace` для процессов, не являющихся дочерними, ограничена параметром `yama ptrace_scope` в целях безопасности.

**Временное разрешение перехвата:**

```bash
echo 0 | sudo tee /proc/sys/kernel/yama/ptrace_scope
```

Подробнее об ограничениях: [Защита среды выполнения ядра](../Security/Fstec/kernel_runtime_protection.md#уровни-ограничений-ptrace_scope).

**Установка:**

```bash
# Для систем на базе Debian/Ubuntu
sudo apt install reptyr
```

## Практические сценарии

### Перенос работающего процесса в tmux

Рассмотрим пример переноса утилиты `top` из открытого терминала в сессию `tmux`.

1. **Приостановка процесса**: Нажмите `Ctrl+Z` в текущем терминале.
2. **Перевод в фоновый режим**:

   ```bash
   bg
   ```

3. **Определение идентификатора процесса (PID — Process Identifier)**:

   ```bash
   jobs -l
   # [1]+  7972 Stopped (signal)     top
   ```

4. **Отвязка от текущей оболочки (Shell)**:

   ```bash
   disown top
   ```

5. **Запуск и подключение**: Войдите в `tmux` и выполните перехват по PID:

   ```bash
   reptyr 7972
   ```

После выполнения команды интерфейс `top` отобразится в окне мультиплексора.

## Дополнительная информация

### Ограничения и особенности

- **Сложные интерфейсы**: Программы с интенсивным использованием текстового пользовательского интерфейса (TUI — Text User Interface) или специфической графикой могут некорректно восстанавливать отрисовку после переноса.
- **Стабильность**: Инструмент лучше всего работает с классическими консольными утилитами (например, Midnight Commander или стандартные системные мониторы).
- **Смена владельца**: Перенос процессов, запущенных другими пользователями, требует полных привилегий `sudo`.
