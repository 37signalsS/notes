# `ps`

## Определение

`ps` (process status) — это стандартная утилита для создания "снимка" текущих процессов, запущенных в системе.

## Основные концепции

`ps` предоставляет статическую информацию о процессах на момент вызова, в отличие от интерактивных утилит вроде `top`.

- **Стили опций:** `ps` имеет несколько стилей опций, что часто вызывает путаницу:
    - **BSD-стиль:** Опции без дефиса (например, `aux`).
    - **System V-стиль:** Опции с одним дефисом (например, `-ef`).
- **Ключевые поля:** `USER`, `PID`, `PPID` (Parent PID), `%CPU`, `%MEM`, `TTY` (терминал), `STAT` (статус процесса: R, S, D, Z), `START` (время старта), `TIME` (время CPU), `COMMAND` (команда).

## Практические сценарии

### Показать все процессы (BSD-стиль)

Это самый популярный формат, показывающий процессы всех пользователей, включая те, что не привязаны к терминалу.

```bash
ps aux
```
- `a`: Показать процессы всех пользователей.
- `u`: Отобразить в удобном для пользователя формате (с именами).
- `x`: Включить процессы, не привязанные к терминалу.

### Показать все процессы (System V-стиль)

Альтернативный стандартный формат.

```bash
ps -ef
```
- `-e`: Показать все процессы (`every`).
- `-f`: Показать в "полном" формате (`full`), включая `PPID`.

### Поиск конкретного процесса

Обычно `ps` используется в связке с `grep` для поиска.

```bash
# Найти все процессы, связанные с nginx
ps aux | grep nginx
```

### Древовидное отображение

Полезно для отслеживания родительско-дочерних связей.

```bash
ps auxf

# Альтернатива для System V-стиля
ps -ef --forest
```

### Сортировка процессов

```bash
# Показать 10 процессов, потребляющих больше всего памяти
ps aux --sort=-%mem | head -n 11

# Показать 10 процессов, потребляющих больше всего CPU
ps aux --sort=-%cpu | head -n 11
```

## Дополнительная информация

### Вывод в кастомном формате

Флаг `-o` позволяет указать, какие именно колонки выводить.

```bash
# Показать PID, %CPU, %MEM и команду для всех процессов
ps -eo pid,%cpu,%mem,comm
```
Это полезно для написания скриптов.

### `ps` vs `top`/`htop`

Для постоянного мониторинга процессов в реальном времени предпочтительнее использовать интерактивные утилиты, такие как [top](./top.md) или [htop](./htop.md), так как `ps` предоставляет лишь одномоментный срез.
