# `witr`

## Определения

**`witr`** (Why Is That Running) — утилита командной строки для Linux, которая помогает быстро понять, почему запущен тот или иной процесс. Объединяет информацию из `ps`, `ss` и `systemd` для предоставления единой картины о процессе, его родителях и сетевых портах.

**Ключевые особенности:**

- Построение дерева зависимостей процесса
- Автоматическое определение источника запуска (systemd, cron, и т.д.)
- Отображение слушаемых портов
- Предупреждения о потенциальных проблемах безопасности

## Основные концепции

### Архитектура

`witr` агрегирует данные из нескольких источников:

| Источник | Данные |
| :--- | :--- |
| [`ps`](./ps.md) | Информация о процессе |
| [`ss`](../Networking/ss.md) | Сетевые порты |
| `systemd` | Информация о сервисе, дереве зависимостей |
| `/proc` | Время запуска, пользователь, рабочая директория |

### Дерево зависимостей

Ключевая особенность `witr` — построение цепочки вызовов:

```
systemd (pid 1) → nginx (pid 35980) → nginx (pid 35981)
```

Это позволяет мгновенно определить:

- Процесс был запущен вручную или сервисом
- Какой сервис породил процесс
- Иерархию родительско-дочерних процессов

### Предупреждения безопасности

`witr` автоматически выявляет потенциальные проблемы:

- Процесс слушает на публичном интерфейсе
- Процесс запущен из подозрительной директории (например, `/`)
- Процесс запущен от root без необходимости

## Практические сценарии

### Установка

**Требуется:** Rust toolchain (cargo)

```bash
# Установка через cargo
cargo install witr

# Или клонирование репозитория
git clone https://github.com/pranshuparmar/witr.git
cd witr
cargo install --path .
```

**Ссылка на проект:** [https://github.com/pranshuparmar/witr](https://github.com/pranshuparmar/witr)

### Поиск по имени процесса

```bash
# Если несколько процессов совпадают, witr предложит выбрать
witr nginx

# Вывод предложит выбрать конкретный PID:
# [1] nginx (pid 35980)
# [2] nginx (pid 35981)
# Re-run with: witr --pid <pid>
```

### Анализ процесса по PID

```bash
# Основной сценарий — полная сводка о процессе
witr --pid 35981
```

**Пример вывода:**

```

Process     : nginx (pid 35981) {forked}

```

### Поиск процесса по порту

```bash
# Определить, какой процесс использует порт
witr --port 443

# Если несколько процессов, предложит выбрать
witr --port 8080
```

### Диагностика проблем

#### Определение источника запуска процесса

```bash
# Почему запущен этот процесс?
witr --pid <PID>

# Поле "Why It Exists" покажет цепочку:
# systemd → сервис → процесс
```

#### Проверка безопасности сервиса

```bash
# Какие порты слушает сервис?
witr --pid $(pgrep -f nginx)

# Есть ли предупреждения?
# - Публичные интерфейсы
# - Подозрительные рабочие директории
```

#### Анализ перезапусков процесса

```bash
# Информация о перезапусках
witr --pid <PID>

# Поле "Restarts" покажет количество перезапусков
# Полезно для отладки падающих сервисов
```

## Дополнительная информация

### Требования

- **ОС:** Linux с systemd
- **Зависимости:** Rust toolchain (для установки через cargo)
- **Права:** Требуется root для полной информации о чужих процессах

### Сравнение с аналогами

| Инструмент | Преимущества | Недостатки |
| :--- | :--- | :--- |
| [`ps`](./ps.md) | Встроен, подробный вывод | Нет дерева, портов |
| [`pstree`](./pstree.md) | Визуализация иерархии | Нет портов, systemd |
| [`systemctl status`](../../Core/systemd/overview.md) | Информация о сервисе | Только systemd |
| [`ss`](../Networking/ss.md) | Детальная информация о портах | Только сеть |
| **`witr`** | **Агрегация всех источников** | **Требует установки** |

### Ограничения

- **Требует systemd:** Не работает на системах без systemd
- **Требует установки:** Не входит в базовую поставку
- **Молодой проект:** Может содержать баги, ограниченная документация
- **Только Linux:** Не работает на BSD/macOS
