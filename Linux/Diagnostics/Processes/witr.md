# Утилита `witr`

## Определения

**`witr`** (Why Is That Running) — утилита интерфейса командной строки (CLI — Command Line Interface) для Linux, предназначенная для быстрого анализа причин запуска процессов. Она объединяет данные из нескольких системных источников (`ps`, `ss`, `systemd`), предоставляя целостную картину о процессе, его иерархии и сетевой активности.

**Ключевые особенности:**

- Построение цепочки родительских процессов.
- Идентификация источника запуска (службы systemd, планировщик cron и другие).
- Отображение прослушиваемых сетевых портов.
- Выявление потенциальных рисков безопасности.

## Основные концепции

### Источники данных

`witr` выполняет агрегацию информации из следующих компонентов системы:

| Источник | Получаемые данные |
| :--- | :--- |
| [`ps`](./ps.md) | Общие сведения о процессе и его атрибутах |
| [`ss`](../Networking/ss.md) | Информация о сетевых сокетах и портах |
| `systemd` | Связь с системными службами и дерево юнитов |
| `/proc` | Время старта, владелец, рабочая директория и переменные окружения |

### Анализ иерархии процессов

Одной из главных функций утилиты является визуализация дерева зависимостей. Пример цепочки:
`systemd (pid 1) → nginx (pid 35980) → nginx (pid 35981)`

Это позволяет администратору мгновенно определить:

- Был ли процесс запущен интерактивно или автоматизированной службой.
- Какая конкретно служба systemd управляет процессом.
- Структуру подчиненности (родитель-потомок).

### Проверка безопасности

Утилита автоматически анализирует контекст выполнения и выводит предупреждения, если:

- Процесс принимает входящие соединения на публичных сетевых интерфейсах.
- Рабочая директория процесса является подозрительной (например, корень файловой системы `/`).
- Процесс запущен с правами суперпользователя (root) в случаях, когда это может быть избыточным.

## Практические сценарии

### Установка

Для установки требуется инструментарий языка Rust (cargo).

```bash
# Установка из репозитория cargo
cargo install witr

# Установка из исходного кода
git clone https://github.com/pranshuparmar/witr.git
cd witr
cargo install --path .
```

Официальный репозиторий: [https://github.com/pranshuparmar/witr](https://github.com/pranshuparmar/witr)

### Поиск процесса по имени

```bash
# При наличии нескольких совпадений witr предложит интерактивный выбор
witr nginx

# Результат выведет список доступных PID:
# [1] nginx (pid 35980)
# [2] nginx (pid 35981)
```

### Анализ по идентификатору процесса (PID)

Основной режим работы для получения детальной сводки:

```bash
witr --pid 35981
```

**Пример интерпретации вывода:**

- **Target/Process**: имя и PID (Process Identifier) процесса.
- **Why It Exists**: иерархия от `systemd` до целевого процесса.
- **Listening**: список всех IP-адресов и портов, которые слушает процесс.
- **Warnings**: список обнаруженных аномалий или рисков.

### Поиск процесса по сетевому порту

```bash
# Определить, какое приложение занимает конкретный порт
witr --port 443
```

### Диагностика причин запуска

Если в системе обнаружен неизвестный процесс, `witr` помогает быстро восстановить контекст его появления:

1. Выполните `witr --pid <PID>`.
2. Проверьте поле **Why It Exists**.
3. Если процесс запущен через cron или systemd, это будет явно указано в блоке **Source**.

## Дополнительная информация

### Требования и ограничения

- **Операционная система:** Linux с менеджером системных служб systemd.
- **Права доступа:** Для получения полной информации о процессах других пользователей требуются права `sudo`.
- **Зависимости:** Не входит в стандартный набор дистрибутивов, требует предварительной установки.

### Сравнение с аналогами

| Инструмент | Преимущества | Недостатки |
| :--- | :--- | :--- |
| [`ps`](./ps.md) | Универсальность, наличие в любой системе | Не дает информации о портах и связях с systemd |
| `pstree` | Наглядная визуализация иерархии | Отсутствуют данные о сетевой активности |
| [`ss`](../Networking/ss.md) | Подробная статистика сетевого стека | Не показывает дерево процессов |
| **`witr`** | **Комплексный анализ из одной точки** | **Требует Rust и ручной установки** |
