# Сравнение инструментов диагностики дискового I/O

## Определения

- **Block I/O**: Операции на уровне блочного устройства, видимые ядру.

## Основные концепции

### Уровни диагностики

| Уровень | Инструменты | Что показывают |
| :--- | :--- | :--- |
| **Процесс** | `iotop`, `pidstat -d`, `/proc/<pid>/io` | Какие процессы создают нагрузку |
| **Файл** | `fatrace`, `lsof` | Какие файлы читаются/пишутся |
| **Блок** | `biosnoop`, `blktrace` | Каждый I/O запрос к диску |
| **Устройство** | `iostat -xz`, `/proc/diskstats`, `vmstat` | Утилизация и задержки устройства |

### Сравнительная таблица инструментов

| Инструмент | Уровень | Преимущества | Недостатки |
| :--- | :--- | :--- | :--- |
| `iotop` | Процесс | Интерактивный, простой | Пропускает короткие всплески |
| `pidstat -d` | Процесс | История, интервал | Не видит ядерные потоки |
| `fatrace` | Файл | Все файловые операции | Не показывает объём I/O |
| `biosnoop` | Блок | Каждый запрос + latency | Требует bcc-tools |
| `blktrace` | Блок | Полная трассировка | Сложный анализ |
| `/proc/<pid>/io` | Процесс | Кумулятивно, точно | Не в реальном времени |
| `iostat -xz` | Устройство | Утилизация, задержки | Без привязки к процессам |

## Практические сценарии

### Выбор инструмента по ситуации

**«Диск загружен, не знаю чем»:**
1. `iostat -xz 1` → подтверждение проблемы
2. `iotop -o` → поиск процесса
3. `pidstat -d 1` → верификация
4. `biosnoop` → детализация

**«Процесс виден, но что он делает»:**
1. `fatrace` → какие файлы открывает
2. `strace -e trace=file -p <pid>` → системные вызовы
3. `lsof -p <pid>` → открытые дескрипторы

**«Ничего не видно, но диск тормозит»:**
1. `iostat -x` (await, avgqu-sz) → задержки
2. `/proc/meminfo` (Dirty, Writeback) → кэш
3. `blktrace` → низкоуровневая трассировка
4. `lsof +L1` → удалённые файлы

**«Подозрение на аппаратную проблему»:**
1. `dmesg | grep -iE "error|timeout"` → ошибки ядра
2. `smartctl -a /dev/sdX` → SMART-статус
3. `journalctl -k` → логи ядра

### Требования к инструментам

| Инструмент | Пакет | Права | Ядро |
| :--- | :--- | :--- | :--- |
| `iotop` | iotop | root | taskstats |
| `pidstat` | sysstat | обычные | — |
| `iostat` | sysstat | обычные | — |
| `fatrace` | fatrace | root | fanotify |
| `biosnoop` | bpfcc-tools | root | eBPF/BPF |
| `blktrace` | blktrace | root | — |
