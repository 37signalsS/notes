# Расшифровка /proc/diskstats

## Определение

**`/proc/diskstats`** — это интерфейс ядра Linux в виртуальной файловой системе `/proc`, который предоставляет подробную статистику операций ввода-вывода (I/O) для всех блочных устройств в системе. Эти данные являются первоисточником для большинства системных инструментов мониторинга, таких как `iostat`, `sar` и коллекторы Prometheus (node_exporter).

## Основные концепции

### Формат данных

Каждая строка в файле соответствует одному блочному устройству или разделу. Количество полей зависит от версии ядра:
- **До Linux 4.18:** 14 полей.
- **Linux 4.18+:** 18 полей (добавлены операции Discard/TRIM).
- **Linux 5.5+:** 20 полей (добавлены Flush-запросы).

### Расшифровка полей статистики

| Поле | Название | Описание |
| :--- | :--- | :--- |
| 1 | Major number | Основной номер устройства. |
| 2 | Minor number | Второстепенный номер устройства. |
| 3 | Device name | Имя устройства (например, `sda`, `nvme0n1`). |
| 4 | Reads completed | Успешные операции чтения. |
| 5 | Reads merged | Операции чтения, объединенные планировщиком I/O. |
| 6 | Sectors read | Количество прочитанных секторов (стандарт: 512 байт). |
| 7 | Time spent reading (ms) | Общее время на чтение. |
| 8 | Writes completed | Успешные операции записи. |
| 9 | Writes merged | Операции записи, объединенные планировщиком. |
| 10 | Sectors written | Количество записанных секторов. |
| 11 | Time spent writing (ms) | Общее время на запись. |
| 12 | I/O in progress | Текущее количество активных операций I/O. |
| 13 | Time spent doing I/O (ms) | Время, в течение которого устройство было занято. |
| 14 | Weighted I/O time (ms) | Взвешенное время (сумма длин очередей * время). |
| **15** | **Discards completed** | Успешные операции Discard (TRIM). |
| **16** | **Discards merged** | Объединенные операции Discard. |
| **17** | **Sectors discarded** | Количество секторов, помеченных как свободные. |
| **18** | **Time spent discarding** | Время, затраченное на Discard. |
| **19** | **Flush requests completed**| Успешные Flush-запросы (сброс кэша устройства). |
| **20** | **Time spent flushing** | Время, затраченное на Flush-запросы. |

## Практические сценарии

### Получение сырой статистики

Файл полезен для легковесного мониторинга без установки пакета `sysstat`.

```bash
# Просмотр статистики для конкретного SSD (NVMe)
grep -w "nvme0n1" /proc/diskstats
# → result: 259 0 nvme0n1 1234 56 7890 100 2345 67 8901 200 0 150 250 10 0 100 5 2 1
```

### Мониторинг активности в реальном времени

Поле 13 показывает, как долго устройство было занято. Если значение растет на 1000мс каждую секунду — диск утилизирован на 100%.

```bash
# Наблюдение за занятостью диска (поле 13)
watch -d -n1 'cat /proc/diskstats | grep -w sda'
```

### Расчет метрик (IOPS и Throughput)

Поскольку данные кумулятивны, для расчета текущих показателей необходимо взять два снимка с интервалом $\Delta t$.

**Формула IOPS:**
$$\text{Read IOPS} = \frac{\text{Reads}_2 - \text{Reads}_1}{\Delta t}$$

**Пример на AWK (чтение завершенных операций):**

```bash
awk '$3 == "sda" {print "Reads:", $4, "| Writes:", $8}' /proc/diskstats
# → result: Reads: 154203 | Writes: 45012
```

## Дополнительная информация

### Нюансы интерпретации

1. **Размер сектора:** Поле 6 и 10 всегда измеряется в секторах по 512 байт, даже если физический сектор диска (Advanced Format) равен 4096 байт.
2. **Утилизация (%util):** Рассчитывается как `(Поле 13_delta / интервал_мс) * 100%`.
3. **Await:** Среднее время ожидания = `(Поле 7_delta + Поле 11_delta) / (Поле 4_delta + Поле 8_delta)`.
