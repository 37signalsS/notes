# Расшифровка /proc/diskstats

## Определение

**`/proc/diskstats`** — это интерфейс ядра Linux в виртуальной файловой системе `/proc`, который предоставляет подробную статистику операций ввода-вывода (I/O) для всех блочных устройств в системе. Эти данные являются первоисточником для большинства системных инструментов мониторинга, таких как `iostat` и `sar`.

## Основные концепции

### Формат данных

Каждая строка в файле соответствует одному блочному устройству или разделу. Каждая запись содержит 14 полей (в современных ядрах может быть больше, но базовые 14 остаются стандартом).

### Расшифровка полей статистики

| Поле | Название | Описание |
| :--- | :--- | :--- |
| 1 | Major number | Основной (мажорный) номер устройства. |
| 2 | Minor number | Второстепенный (минорный) номер устройства. |
| 3 | Device name | Имя устройства (например, `sda`, `nvme0n1`, `sda1`). |
| 4 | Reads completed | Общее количество успешно завершенных операций чтения. |
| 5 | Reads merged | Количество операций чтения, объединенных планировщиком I/O в одну. |
| 6 | Sectors read | Общее количество прочитанных секторов (обычно 512 байт). |
| 7 | Time spent reading (ms) | Суммарное время, затраченное на все операции чтения (в миллисекундах). |
| 8 | Writes completed | Общее количество успешно завершенных операций записи. |
| 9 | Writes merged | Количество операций записи, объединенных планировщиком I/O. |
| 10 | Sectors written | Общее количество записанных секторов. |
| 11 | Time spent writing (ms) | Суммарное время, затраченное на все операции записи (в миллисекундах). |
| 12 | I/O in progress | Количество операций ввода-вывода, выполняемых в данный момент. |
| 13 | Time spent doing I/O (ms) | Общее время, в течение которого устройство было занято обработкой I/O. |
| 14 | Weighted I/O time (ms) | Взвешенное время I/O, учитывающее длину очереди. |

## Практические сценарии

### Получение сырой статистики

Данный файл полезен для автоматизации и написания кастомных скриптов мониторинга, где нежелательно использовать тяжеловесные внешние утилиты.

```bash
# Просмотр статистики для всех устройств
cat /proc/diskstats

# Фильтрация данных по конкретному диску
grep -w "sda" /proc/diskstats
```

### Анализ производительности в реальном времени

Хотя для реального времени предпочтительнее `iostat`, можно наблюдать за динамикой изменения счетчиков вручную:

```bash
# Наблюдение за изменением счетчиков (поле 13 показывает активность)
watch -n1 'cat /proc/diskstats | grep -w sda'
```

### Использование в скриптах (AWK)

Пример простого извлечения ключевых метрик для диска `sda`:

```bash
awk '$3 == "sda" {print "Reads completed:", $4, "\nWrites completed:", $8, "\nTime spent doing I/O (ms):", $13}' /proc/diskstats
```

## Дополнительная информация

### Интерпретация данных

Значения в `/proc/diskstats` являются кумулятивными (накапливаются с момента загрузки системы или инициализации устройства). Для получения мгновенных показателей (например, IOPS или пропускной способности) необходимо вычислить разницу между двумя снимками (snapshots) и разделить её на интервал времени.
