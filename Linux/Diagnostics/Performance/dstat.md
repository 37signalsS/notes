# `dstat`

## Определение

**`dstat`** — это универсальный инструмент для мониторинга производительности системы в реальном времени. Написанная на Python, утилита объединяет возможности классических инструментов, таких как [`vmstat`](../Memory/vmstat.md), [`iostat`](../Filesystem/iostat.md) и `ifstat`, предоставляя гибкий интерфейс и возможность расширения с помощью плагинов.

**Важное примечание:** Оригинальный проект `dstat` (от Dag Wieers) больше не развивается активно. В современных дистрибутивах (например, RHEL 8+, Fedora) он часто заменяется на **`pcp-dstat`** (часть Performance Co-Pilot) или форк **`dool`**, который поддерживает Python 3.

## Основные концепции

### Универсальность

`dstat` позволяет наблюдать за всеми ресурсами системы одновременно в одном окне. Это исключает необходимость переключения между несколькими утилитами для сопоставления нагрузки на CPU, диск и сеть.

### Модульность и плагины

Система построена на модулях. Помимо стандартных метрик (CPU, диск, сеть, память), доступны плагины для мониторинга специфических параметров:

- Состояние очередей планировщика.
- Статистика конкретных процессов (самые активные по CPU или RAM).
- Метрики приложений (MySQL, Nginx, Postfix).

### Цветовая индикация

Вывод использует цвета для визуального разделения единиц измерения (КБ, МБ, ГБ) и типов данных, что облегчает чтение потока информации.

## Практические сценарии

### Комплексный мониторинг ресурсов

Запуск без параметров выводит базовую информацию: загрузка CPU, активность дисков, трафик сети, paging и системные прерывания.

```bash
dstat
```

### Поиск «виновников» нагрузки

Использование плагинов `top` для идентификации наиболее ресурсоёмких процессов в реальном времени.

```bash
# Процессы, максимально загружающие CPU и I/O
dstat --top-cpu --top-io

# Более детальный поиск (с аргументами процессов)
dstat --top-cpu-adv --top-mem
```

### Диагностика задержек и системных событий

Анализ переключений контекста и прерываний в сочетании с нагрузкой.

```bash
# Статистика CPU, системные вызовы и прерывания
dstat -cy
```

### Фокус на конкретной подсистеме

```bash
# Только статистика дисков с детализацией по каждому устройству
dstat -tdD total,sda,sdb

# Только сетевая активность
dstat -tn
```

## Дополнительная информация

### Сохранение данных для анализа

`dstat` может записывать вывод в формате CSV для последующей обработки в электронных таблицах или построения графиков.

```bash
# Сбор данных каждые 5 секунд, 100 итераций, запись в файл
dstat --output performance_report.csv 5 100
```

### Полезные плагины

- `--socket`: статистика по типам сокетов (TCP, UDP, RAW и т.д.).
- `--tcp`: активные, слушающие и установленные TCP-соединения.
- `--disk-util`: процент занятости диска (аналог `%util` в `iostat`).
- `--freespace`: свободное место на примонтированных файловых системах.
