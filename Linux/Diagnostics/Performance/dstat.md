# `dstat`

## Определение

`dstat` — это многофункциональная утилита для мониторинга производительности системы в реальном времени. Она призвана заменить и объединить возможности таких классических инструментов, как `vmstat`, `iostat` и `ifstat`, предоставляя более гибкий и расширяемый способ сбора данных.

## Основные концепции

Ключевая особенность `dstat` — её модульность. Она позволяет комбинировать различные счётчики и плагины для вывода комплексной статистики в едином, легко читаемом формате.

- **Всё в одном:** Одновременно отображает данные по CPU, дискам, сети, использованию памяти (paging) и системным событиям (прерывания, переключения контекста).
- **Цветовое кодирование:** Вывод раскрашен для лучшего визуального восприятия.
- **Гибкость:** Позволяет легко добавлять или убирать метрики.
- **Плагины:** Имеет множество встроенных и внешних плагинов для отслеживания специфических приложений (например, MySQL, Nginx) или ресурсов.

## Практические сценарии

### Стандартный мониторинг

```bash
# Стандартный вывод: CPU, диск, сеть, paging, система
dstat
```

### Анализ нагрузки на процессор и I/O

```bash
# Показать процесс, который наиболее активно использует CPU
dstat --top-cpu

# Показать процесс, который создает наибольшую нагрузку на ввод-вывод
dstat --top-io

# Комбинированный вариант
dstat --top-cpu-adv --top-io-adv
```

### Фокус на конкретных ресурсах

```bash
# Показать статистику только по дискам
dstat -d

# Показать статистику только по сети
dstat -n
```

## Дополнительная информация

### Использование плагинов

```bash
# Показать статистику по сокетам
dstat --socket

# Показать статистику по TCP
dstat --tcp

# Показать статистику использования памяти с деталями
dstat -g -l -m -s --top-mem
```

### Сохранение в CSV

```bash
# Собирать данные каждые 2 секунды, 10 раз, и сохранить в файл report.csv
dstat --output report.csv 2 10
```
