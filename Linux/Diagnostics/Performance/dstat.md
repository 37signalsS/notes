# `dstat`

## Определение

**`dstat`** — это универсальный инструмент для мониторинга производительности системы в реальном времени. Написанная на Python, утилита объединяет возможности классических инструментов, таких как [`vmstat`](../Memory/vmstat.md), [`iostat`](../Filesystem/iostat.md), `netstat` и `ifstat`. Она предоставляет гибкий интерфейс с цветовой кодировкой и возможностью расширения функционала с помощью плагинов.

## Основные концепции

### Эволюция: dstat, pcp-dstat и dool

Оригинальный проект `dstat` (от Dag Wieers) больше не развивается активно и ориентирован на Python 2. В современных дистрибутивах используются альтернативы:
- **`dool`**: Наиболее точный форк оригинального `dstat`, портированный на Python 3. Рекомендуется как основная замена.
- **`pcp-dstat`**: Часть фреймворка Performance Co-Pilot (PCP). Обладает схожим синтаксисом, но требует запущенного демона `pmcd`.

### Преимущества

1.  **Консолидация:** Позволяет наблюдать за CPU, дисками, сетью и памятью в одном потоке данных, что критично для выявления корреляций между нагрузками.
2.  **Визуализация:** Использует цветовую индикацию для обозначения порядков величин (Б, КБ, МБ), что позволяет мгновенно оценить масштаб нагрузки.
3.  **Отсутствие потерь:** В отличие от `top`, `dstat` выводит данные в виде свитка (rolling log), что позволяет заметить кратковременные всплески (spikes), которые могут исчезнуть при обновлении экрана в интерактивных утилитах.

### Установка

```bash
# Debian / Ubuntu
sudo apt install dool  # Рекомендуется
# или
sudo apt install dstat

# RHEL / CentOS / Fedora
sudo dnf install pcp-system-tools  # Предоставляет pcp-dstat
# или
sudo dnf install dool

# Arch Linux
sudo pacman -S dool
```

## Практические сценарии

### Комплексный мониторинг ресурсов

Запуск без параметров выводит базовый набор: `cpu` (usr, sys, idl, wai, hiq, siq), `disk` (read, writ), `net` (recv, send), `paging` (in, out) и `system` (int, csw).

```bash
dstat 1
# 1 — интервал обновления в секундах
```

### Поиск «виновников» нагрузки

`dstat` включает плагины `top`, которые показывают процесс с максимальным потреблением ресурса в конкретный момент времени.

```bash
# Процессы, максимально нагружающие CPU, память и I/O одновременно
dstat -c --top-cpu --top-mem --top-io
```

### Диагностика сетевых соединений и сокетов

Позволяет увидеть состояние сетевого стека без запуска тяжелых утилит.

```bash
# Статистика TCP-соединений и сокетов
dstat --tcp --socket
# Показывает: lis (listening), act (active), syn, tim (time_wait), clo (closed)
```

### Анализ задержек дисковой подсистемы

Сочетание общей нагрузки на диск с процентом его занятости.

```bash
# Статистика дисков и процент утилизации (аналог %util в iostat)
dstat -d --disk-util
```

### Экспорт данных для пост-анализа

`dstat` идеально подходит для сбора метрик во время проведения нагрузочных тестов.

```bash
# Запись данных в CSV-файл (каждые 10 секунд в течение часа)
dstat --output load_test_results.csv 10 360
```

## Дополнительная информация

### Полезные плагины и флаги

- `-y`, `--sys`: Статистика системных прерываний и переключений контекста.
- `--innodb-buffer`: Метрики буфера InnoDB (для MySQL/MariaDB).
- `--nfs3`, `--nfsd4`: Статистика клиентских и серверных запросов NFS.
- `--vm-adv`: Расширенная статистика виртуальной памяти (dirty pages, writeback).

### Сравнение с аналогами

- **[`sar`](./sar.md)**: Лучше подходит для долгосрочного исторического анализа (хранение за недели/месяцы).
- **[`atop`](./atop.md)**: Предоставляет более детальный интерактивный вид и сохраняет бинарные логи.
- **[`vmstat`](../Memory/vmstat.md)**: Минималистичный инструмент, доступный в любой системе «из коробки», но менее наглядный.
