# `sar`

## Определение

**`sar` (System Activity Reporter)** — системная утилита из пакета `sysstat`, предназначенная для сбора, отчёта и анализа данных о производительности системы. В отличие от инструментов реального времени ([`top`](../Processes/top.md), [`htop`](../Processes/htop.md)), `sar` позволяет анализировать исторические данные, что критично для расследования инцидентов, произошедших в прошлом.

## Основные концепции

`sar` является частью пакета `sysstat`, который также включает утилиты [`iostat`](../Filesystem/iostat.md), [`pidstat`](../Processes/pidstat.md), `mpstat` и другие.

### Режимы работы

1. **Режим реального времени:** Отображение статистики с заданным интервалом (например, `sar 1 5`).
2. **Режим отчёта:** Извлечение данных из бинарных файлов журналов, собранных в фоновом режиме.

### Сбор данных (sadc)

Фоновый процесс **`sadc` (System Activity Data Collector)** собирает системные метрики и сохраняет их в бинарные файлы (обычно в `/var/log/sysstat/` или `/var/log/sa/`). Имена файлов обычно следуют шаблону `saDD`, где `DD` — день месяца.

### Установка и настройка sysstat

Для работы `sar` в режиме отчёта необходимо установить и настроить пакет `sysstat`.

```bash
# Debian / Ubuntu
sudo apt install sysstat

# RHEL / CentOS / Fedora
sudo dnf install sysstat

# Arch Linux
sudo pacman -S sysstat
```

**Включение сбора данных:**

- В **Debian/Ubuntu** необходимо отредактировать `/etc/default/sysstat` и установить `ENABLED="true"`.
- Запустить и включить службу: `sudo systemctl enable --now sysstat`.

## Практические сценарии

### Анализ использования CPU

```bash
# Статистика по CPU в реальном времени (каждую секунду, 5 раз)
sar -u 1 5

# Прочитать сегодняшний отчёт по CPU из лога
sar -u -f /var/log/sysstat/sa$(date +%d)

# Статистика по отдельным ядрам
sar -P ALL 1 1
```

### Анализ оперативной памяти

```bash
# Использование памяти и swap
sar -r 1 5

# Статистика подкачки (swapping)
sar -W 1 5
```

### Анализ дискового ввода-вывода

```bash
# Статистика по блочным устройствам (I/O)
sar -d -p 1 5
# -p (pretty-print) преобразует номера устройств в имена (напр., sda)
```

### Анализ сетевой статистики

```bash
# Статистика по сетевым интерфейсам (трафик, пакеты)
sar -n DEV 1 5

# Анализ ошибок сетевых интерфейсов
sar -n EDEV 1 5

# Статистика по сокетам (TCP, UDP)
sar -n SOCK 1
```

### Выбор временного диапазона

```bash
# Просмотр статистики за конкретный период (из лога)
sar -q -s 10:00:00 -e 12:00:00
```

## Дополнительная информация

### Интеграция с другими инструментами

- **[`atop`](./atop.md):** также ведёт логи. Утилита `atopsar` позволяет генерировать отчёты в стиле `sar` из логов `atop`:

  ```bash
  atopsar -r /var/log/atop/atop_20240101
  ```

- **[`sos report`](../sos_report.md):** при сборе диагностического архива можно включить полный сбор данных `sar` с помощью флага `-k sar.all-sar=on`.

### Настройка периодичности сбора

Периодичность сбора данных `sadc` настраивается через `cron` (файл `/etc/cron.d/sysstat`) или через systemd таймеры в современных дистрибутивах. По умолчанию данные часто собираются каждые 10 минут.
