# `sar`

## Определение

`sar` (System Activity Reporter) — это мощная утилита из пакета `sysstat`, предназначенная для сбора, отчёта и анализа исторических данных о производительности системы. В отличие от инструментов реального времени (`top`, `htop`), `sar` позволяет анализировать, что происходило с системой в прошлом.

## Основные концепции

`sar` работает в двух режимах:

1.  **Режим реального времени:** Отображает статистику производительности с заданным интервалом, как `vmstat` или `iostat`.
2.  **Режим отчёта:** Читает данные из бинарных лог-файлов, которые фоновый процесс `sadc` (System Activity Data Collector) собирает и сохраняет (обычно в `/var/log/sysstat/` или `/var/log/sa/`).

## Практические сценарии

`sar` может отображать статистику практически по всем подсистемам Linux.

### Анализ использования CPU

```bash
# Статистика по CPU в реальном времени (каждую секунду, 5 раз)
sar -u 1 5

# Прочитать сегодняшний отчёт по CPU из лога
sar -u -f /var/log/sysstat/sa$(date +%d)
```

### Анализ сетевой статистики

```bash
# Статистика по сетевым интерфейсам (трафик, пакеты)
# DEV - network devices
sar -n DEV 1 5

# Статистика по TCP, UDP, сокетам
# EDEV - network device errors, SOCK - sockets
sar -n TCP,ETCP,UDP,SOCK 1
```

### Анализ дискового I/O

```bash
# Статистика по блочным устройствам
sar -d 1 5
```

### Анализ использования памяти

```bash
# Статистика по использованию памяти и swap
sar -r 1 5
```

## Дополнительная информация

### `atopsar`

Утилита `atop` также ведёт исторические логи и предоставляет утилиту `atopsar`, которая может генерировать отчёты в стиле `sar` из логов `atop`.

```bash
# Генерация отчета в стиле sar из файла данных atop
atopsar -r /path/to/atop/log
```

### Настройка сбора данных

Сбор данных для `sar` обычно настраивается через `cron`. Файл конфигурации `cron` для `sysstat` (например, `/etc/cron.d/sysstat`) определяет, как часто (`sadc`) собирает данные.

### Выбор временного диапазона

При анализе лог-файлов можно указать временной диапазон с помощью флагов `-s` (start time) и `-e` (end time).

```bash
# Показать статистику CPU за сегодняшний день с 10:00 до 11:00
sar -u -s 10:00:00 -e 11:00:00
```
