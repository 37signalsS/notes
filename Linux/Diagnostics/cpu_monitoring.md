# Мониторинг и профилирование CPU

## mpstat

Выводит статистику по каждому ядру CPU. Полезна для выявления неравномерной нагрузки, когда один поток утилизирует одно ядро на 100%.

---

## pidstat

Утилита для сбора статистики по конкретным процессам, особенно полезная для отслеживания **короткоживущих процессов**, которые сложно заметить в `top`.

---

## Профилирование производительности

### perf

`perf` — мощный инструмент для профилирования системы на уровне ядра, позволяющий глубоко анализировать производительность и выявлять узкие места в работе приложения или всей системы. Он мощнейший инструмент для анализа производительности на уровне ядра и приложений, использующий счетчики производительности процессора.

> **Примечание:** Для работы `perf` могут потребоваться дополнительные пакеты, такие как `linux-tools-generic` и `linux-tools-$(uname -r)`.

**Применение:**
*   Выявление функций, которые потребляют больше всего ресурсов.
*   Анализ производительности ядра при нагрузке.
*   Диагностика узких мест в пользовательских или системных приложениях.

**Основные команды:**

-   **`perf top`**: Показывает, какие функции и символы (в ядре или приложениях) потребляют больше всего CPU в данный момент. Это похоже на `top`, но на уровне функций.

-   **`perf record`**: Записывает профиль работы приложения для последующего анализа. После выполнения команды `perf record` создается файл `perf.data`.
    ```bash
    # Сбор данных производительности
    perf record -F 99 -p <PID> -g
    ```
    *   `-F 99`: устанавливает частоту выборки 99 Гц.
    *   `-p <PID>`: указывает PID процесса, который нужно профилировать.
    *   `-g`: включает сбор данных о вызовах стека (call stack), что необходимо для построения Flame Graphs.

-   **`perf report`**: Анализирует собранные данные из `perf.data` и представляет их в интерактивном режиме. Это откроет интерактивный интерфейс, где вы увидите статистику использования процессора, вызовы функций и многое другое.
