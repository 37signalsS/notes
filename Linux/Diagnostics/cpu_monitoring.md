# Мониторинг и профилирование CPU

## mpstat

Выводит статистику по каждому ядру CPU. Полезна для выявления неравномерной нагрузки, когда один поток утилизирует одно ядро на 100%.

---

## pidstat

Утилита для сбора статистики по конкретным процессам, особенно полезная для отслеживания **короткоживущих процессов**, которые сложно заметить в `top`.

---

## Профилирование производительности

### perf

`perf` — мощнейший инструмент для анализа производительности на уровне ядра и приложений, использующий счетчики производительности процессора.

> **Примечание:** Для работы `perf` могут потребоваться дополнительные пакеты, такие как `linux-tools-generic` и `linux-tools-$(uname -r)`.

**Основные команды:**

-   **`perf top`**: Показывает, какие функции и символы (в ядре или приложениях) потребляют больше всего CPU в данный момент. Это похоже на `top`, но на уровне функций.

-   **`perf record`**: Записывает профиль работы приложения для последующего анализа.
    ```bash
    # Записать профиль работы процесса <PID> со стеком вызовов в течение 10 секунд
    perf record -p <PID> -g -- sleep 10
    ```
    Ключ `-g` включает запись графа вызовов, что необходимо для построения Flame Graphs.

-   **`perf report`**: Анализирует записанный ранее профиль (`perf.data`) и представляет данные в интерактивном режиме.
