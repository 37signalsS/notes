# `ps` — Снимок состояния процессов

## 1. Определение

`ps` (process status) — это стандартная утилита для создания "снимка" текущих процессов, запущенных в системе.

## 2. Основные концепции

`ps` предоставляет статическую информацию о процессах на момент вызова, в отличие от интерактивных утилит вроде `top`. Она крайне гибкая благодаря множеству комбинаций ключей.
- **Форматы вывода:** `ps` поддерживает разные форматы вывода (BSD-style `aux`, System V-style `-ef`). `aux` является наиболее популярным.
- **Ключевые поля:** `USER`, `PID`, `CPU`, `MEM`, `TTY` (терминал), `STAT` (статус процесса: R, S, D, Z), `START` (время старта), `TIME` (время CPU), `COMMAND` (команда).

## 3. Практические сценарии

### Наиболее частый вызов

Показать все процессы всех пользователей, включая те, что без терминала, и отсортировать по потреблению памяти.
```bash
ps aux --sort=-%mem
```
- `a`: Показать процессы всех пользователей.
- `u`: Отобразить в удобном для пользователя формате (с именами).
- `x`: Включить процессы, не привязанные к терминалу.

### Древовидное отображение

Полезно для отслеживания родительско-дочерних связей.
```bash
ps auxf
```

## 4. Продвинутые детали

Для постоянного мониторинга процессов в реальном времени предпочтительнее использовать интерактивные утилиты, такие как [top](./top.md) или [htop](./htop.md), так как `ps` предоставляет лишь одномоментный срез.
