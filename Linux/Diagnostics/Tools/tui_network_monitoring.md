# TUI-утилиты для мониторинга сети

## 1. Определение

TUI (Text-based User Interface) утилиты для мониторинга сети — это инструменты, которые предоставляют интерактивный текстовый интерфейс для наблюдения за сетевым трафиком в реальном времени. Они являются удобной альтернативой командам, которые выдают статический вывод или непрерывный поток текста.

Для установки большинства из них в Debian/Ubuntu-based системах можно использовать команду:
```bash
sudo apt install nload bmon iftop jnettop iptraf-ng
```

## 2. Основные утилиты

### `nload` и `bmon` — Простая визуализация трафика

Эти утилиты решают одну простую задачу: показывают текущую скорость приёма (incoming) и передачи (outgoing) данных на сетевых интерфейсах в виде графиков.

- **`nload`**: Отображает ASCII-графики, очень прост в использовании.
- **`bmon`**: Предоставляет больше деталей, включая статистику по пакетам и ошибкам.

```bash
# Запустить nload (переключение между интерфейсами - стрелки)
nload

# Запустить bmon
bmon
```

### `iftop` — "top" для сетевых соединений

Подобно `top` для процессов, `iftop` слушает трафик на указанном интерфейсе и отображает таблицу активных соединений, отсортированную по объему трафика. Это позволяет быстро определить, какие хосты генерируют наибольшую сетевую нагрузку.

```bash
# Запустить iftop на интерфейсе eth0
sudo iftop -i eth0
```
**Полезные опции в интерактивном режиме:** `n` (вкл/выкл разрешение имен), `s`/`d` (скрыть/показать порт источника/назначения), `p` (вкл/выкл отображение портов).

### `jnettop` — Группировка трафика

`jnettop` также показывает активные соединения, но группирует их по хосту и порту. Это помогает быстро понять, какой сервис на каком хосте больше всего "общается" по сети.

```bash
# Запустить jnettop на интерфейсе eth0
sudo jnettop -i eth0
```

### `iptraf-ng` — Комбайн для анализа

`iptraf-ng` — это мощный интерактивный инструмент с меню, предоставляющий несколько режимов мониторинга:
- Общая статистика по интерфейсам.
- Детальная статистика по протоколам (IP, TCP, UDP, ICMP и др.).
- Мониторинг отдельных TCP/UDP соединений, включая размер пакетов.
- Статистика по размерам пакетов и др.

```bash
# Запустить iptraf-ng
sudo iptraf-ng
```
Навигация осуществляется через меню, что делает его очень удобным для всестороннего анализа "на лету".
