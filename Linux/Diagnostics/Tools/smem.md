# `smem` — Реалистичная оценка потребления памяти

## 1. Определение

`smem` — это продвинутая утилита для анализа использования оперативной памяти в Linux. Её ключевое преимущество перед другими инструментами (`top`, `ps`) заключается в более точном подсчёте памяти, потребляемой процессами, за счёт корректного учёта разделяемых библиотек.

## 2. Основные концепции

Традиционные утилиты часто показывают метрику `RSS` (Resident Set Size), которая включает всю память, занимаемую процессом, в том числе и разделяемые библиотеки. Это приводит к завышенным показателям, так как одна и та же библиотека в памяти учитывается для каждого процесса, который её использует.

`smem` вводит более точные метрики:

-   **USS (Unique Set Size):** Уникальная память процесса. Это объём, который будет освобождён, если процесс завершится. Рост этого показателя — **главный индикатор утечки памяти**.
-   **PSS (Proportional Set Size):** Пропорциональная память. Включает уникальную память процесса (USS) плюс "справедливую" долю разделяемой памяти (например, если библиотеку используют 3 процесса, то каждому засчитывается 1/3 её размера). **Это наиболее реалистичная оценка потребления памяти процессом.**
-   **RSS (Resident Set Size):** Резидентная память. Полный объём физической памяти, занимаемый процессом.

## 3. Практические сценарии

### Общий отчёт по процессам

```bash
# Показать отчёт по всем запущенным процессам, отсортированный по PSS
smem -p
```

### Отчёт с группировкой по пользователям

Полезно для анализа потребления памяти в многопользовательской среде.

```bash
# Показать суммарное потребление памяти для каждого пользователя
smem -u
```

### Системный отчёт

```bash
# Показать общую статистику по системе
smem -w
```

## 4. Продвинутые детали

### Графическое представление

`smem` может генерировать графические диаграммы для наглядного представления данных.

```bash
# Построить круговую диаграмму использования памяти процессами
smem --pie name -c "pss"

# Построить столбчатую диаграмму
smem --bar name -c "pss"
```

### Фильтрация и сортировка

`smem` предоставляет мощные возможности для фильтрации и сортировки вывода.

```bash
# Показать процессы, принадлежащие пользователю www-data, отсортированные по USS
smem -u www-data -s uss
```
