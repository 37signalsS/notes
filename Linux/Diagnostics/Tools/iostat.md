# `iostat` — Статистика дискового I/O

## 1. Определение

`iostat` (input/output statistics) — это утилита из пакета `sysstat`, которая предоставляет детальную численную статистику по операциям ввода-вывода на блочных устройствах (дисках) и разделах. В отличие от [iotop](./iotop.md), который показывает нагрузку по процессам, `iostat` фокусируется на производительности самих устройств.

## 2. Основные концепции

- **Метрики производительности:** `iostat` измеряет ключевые показатели здоровья дисковой подсистемы:
    - **IOPS (`r/s`, `w/s`):** Операции чтения/записи в секунду.
    - **Пропускная способность (`rMB/s`, `wMB/s`):** Скорость обмена данными.
    - **Время отклика (`await`):** Среднее время, которое запрос проводит в очереди и обрабатывается.
    - **Утилизация (`%util`):** Процент времени, когда диск был занят.
- **Время ожидания (`await`):** Критически важная метрика. Высокое значение `await` (например, >20 мс для HDD или >1 мс для SSD) является прямым признаком "тормозов" диска и узкого места в системе.

## 3. Практические сценарии

### Мониторинг в реальном времени

```bash
# Показывает расширенную статистику (-x) по всем дискам (-d)
# с интервалом в 2 секунды
iostat -dx 2
```

### Детальный отчет по конкретному диску

```bash
# Статистика для диска nvme1 каждую секунду, 5 раз,
# в мегабайтах (-m) и с временными метками (-t)
iostat -dxmt 1 5 /dev/nvme1
```

### Диагностика "бутылочного горлышка"

Если `iostat` показывает `%util` близкий к 100% и одновременно высокое значение `await`, это означает, что диск работает на пределе своей производительности и не справляется с нагрузкой. Это классическое "бутылочное горлышко" I/O.

## 4. Продвинутые детали

### Связь с `iowait` и Load Average

Процессы, ожидающие завершения дисковых операций, переходят в состояние `uninterruptible sleep` и вносят вклад в `iowait` (показатель `%wa` в `top` или `vmstat`) и в `Load Average`. Таким образом, высокие значения в `iostat` напрямую коррелируют с ростом этих системных метрик, указывая на то, что именно дисковая подсистема является причиной замедления работы.
