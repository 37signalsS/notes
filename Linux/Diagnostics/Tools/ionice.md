# `ionice` — Управление приоритетом I/O

## 1. Определение

`ionice` — это утилита командной строки, которая позволяет управлять приоритетом операций ввода-вывода (I/O) для процессов в Linux. Она используется для оптимизации дисковых ресурсов, позволяя понизить влияние фоновых задач (например, резервное копирование) на критически важные приложения (например, базы данных).

## 2. Основные концепции

`ionice` работает на основе классов планирования I/O, которые определяют, когда процесс получит доступ к диску.
- **Idle (Класс 3):** Самый низкий приоритет. Процесс выполняет I/O операции только тогда, когда диск полностью свободен. Идеально для фоновых задач, которые не должны влиять на производительность.
- **Best-effort (Класс 2):** Приоритет по умолчанию. Позволяет установить относительный приоритет от 0 (самый высокий) до 7 (самый низкий).
- **Realtime (Класс 1):** Самый высокий приоритет. Процесс получает немедленный доступ к диску, игнорируя другие задачи. **Использовать с большой осторожностью**, так как может вызвать "голодание" других процессов.

## 3. Практические сценарии

### Запуск процесса с низким приоритетом

Это самый частый сценарий, чтобы ресурсоемкая задача не замедляла систему.
```bash
# Запустить rsync с минимальным приоритетом I/O
ionice -c3 rsync -a /source /destination
```

### Изменение приоритета запущенного процесса

Можно изменить приоритет уже работающего процесса по его PID.
```bash
# Установить для процесса с <PID> высокий приоритет Best-effort
sudo ionice -c2 -n0 -p <PID>

# Установить для MySQL самый высокий Realtime приоритет
sudo ionice -c1 -p $(pgrep mysqld)
```

### Проверка текущего приоритета

```bash
# Проверить приоритет I/O для процесса с PID 1234
ionice -p 1234
```

## 4. Продвинутые детали

`ionice` является частью более крупного механизма управления ресурсами в Linux. Для более гранулярного контроля, особенно в контейнеризированных средах, используются **cgroups** (контрольные группы), которые позволяют устанавливать жесткие лимиты на IOPS и пропускную способность для групп процессов, а не только изменять их приоритет.
