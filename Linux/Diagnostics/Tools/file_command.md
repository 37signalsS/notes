# `file` — Определение типа файла

## 1. Определение

Команда `file` в Unix-подобных операционных системах используется для определения типа файла. Она анализирует содержимое файла, а не просто его расширение, что позволяет с высокой точностью определить формат хранения данных и его предназначение, даже если файл имеет неверное расширение или вообще не имеет его.

## 2. Основные концепции

### "Магические числа" (Magic Numbers)

`file` использует базу данных "магических чисел" (magic numbers) — уникальных последовательностей байтов, расположенных в начале файлов различных форматов. Эти сигнатуры, описывающие форматы файлов, хранятся в файле `/etc/magic` или `/usr/share/misc/magic`. Это позволяет утилите надежно определять тип файла, игнорируя его имя или расширение.

## 3. Практические сценарии

### Идентификация неизвестных файлов
Основное применение — быстро узнать природу файла с непонятным содержимым, неверным расширением или без него.
```bash
# Определить тип архива и исполняемого файла
$ file stat-master.zip
stat-master.zip: Zip archive data, at least v1.0 to extract

$ file unins000.exe
unins000.exe: PE32 executable (GUI) Intel 80386, for MS Windows
```

### Использование в скриптах

В скриптах `file` используется для автоматической проверки типа файла перед его обработкой, например, для архивации, конвертации или для проверки на безопасность.

```bash
# Получить только MIME-тип файла без имени
$ file -i -b unins000.exe
application/x-dosexec; charset=binary
```

### Проверка целостности и безопасности

- **Целостность:** Убедиться, что файл соответствует ожидаемому формату.
- **Безопасность:** Выявление потенциально вредоносных исполняемых файлов, маскирующихся под другие типы (например, `.jpg`, который на самом деле является скриптом).

## 4. Продвинутые детали

### Ключевые опции

*   `-b`, `--brief`: Не выводить имена файлов перед их типом. Удобно для скриптов.
*   `-i`, `--mime`: Выводить информацию в формате MIME-типа (например, `application/zip`) и кодировки (`charset=binary`).
*   `-z`, `--compress`: Попытаться заглянуть внутрь сжатых файлов (gzip, bzip2, xz и т.д.), чтобы определить тип содержащихся в них данных.
*   `-s`, `--special-files`: Заставляет `file` читать и пытаться определить тип блочных или символьных специальных файлов вместо того, чтобы просто идентифицировать их как спецфайлы.
*   `-L`, `--dereference`: Следовать по символическим ссылкам и проверять файл, на который они указывают, а не саму ссылку.
