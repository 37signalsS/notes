# `w` — Кто в системе и что делает

## 1. Определение

`w` — это утилита, которая показывает информацию о залогиненных в данный момент пользователях и их активных процессах.

## 2. Основные концепции

`w` является комбинацией вывода трех утилит:
- `uptime`: Показывает время работы системы (uptime) и среднюю нагрузку (Load Average).
- `who`: Показывает, кто из пользователей вошел в систему, откуда и когда.
- `ps`: Показывает, какой процесс запущен в данный момент в сессии пользователя.

## 3. Практические сценарии

### Простой вызов

Запуск без аргументов предоставляет всю основную информацию.
```bash
w
```
**Пример вывода:**
```
 10:45:01 up 10 days, 20:21,  2 users,  load average: 0.00, 0.01, 0.05
USER     TTY      FROM             LOGIN@   IDLE   JCPU   PCPU WHAT
user1    pts/0    192.168.1.100    10:30    1.00s  0.02s  0.00s w
user2    pts/1    192.168.1.101    10:40    5.00s  0.01s  0.01s -bash
```
- `JCPU`: Время, использованное всеми процессами на терминале.
- `PCPU`: Время, использованное текущим процессом (в колонке `WHAT`).
- `WHAT`: Текущая команда, выполняемая пользователем.

## 4. Продвинутые детали

`w` — это быстрый инструмент для обзора. Для детального анализа процессов конкретного пользователя лучше использовать `ps -u <username>` или интерактивные утилиты.
