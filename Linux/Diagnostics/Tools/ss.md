# `ss` — Статистика сокетов

## 1. Определение

`ss` (Socket Statistics) — это современная консольная утилита в Linux для просмотра информации о сетевых сокетах. Она является более быстрой и мощной альтернативой устаревшей команде `netstat`, так как получает информацию напрямую из ядра через интерфейс `netlink`.

## 2. Основные концепции

`ss` позволяет просматривать активные TCP/UDP соединения, слушающие порты и процессы, которые их используют. Её высокая производительность делает её незаменимой на высоконагруженных серверах с большим количеством соединений.

**Ключевые состояния TCP соединений, которые можно увидеть в `ss`:**
- **LISTEN:** Сервер ожидает входящих подключений на порту.
- **SYN-SENT:** Клиент отправил пакет SYN для начала установки соединения.
- **SYN-RECV:** Сервер получил SYN и отправил SYN-ACK.
- **ESTABLISHED:** Соединение установлено, данные могут передаваться.
- **FIN-WAIT-1/2, CLOSE-WAIT, TIME-WAIT:** Различные стадии корректного закрытия соединения.

## 3. Практические сценарии

### Просмотр слушающих портов

Это одна из самых частых задач — узнать, какие сервисы запущены на сервере.

```bash
# Показать все слушающие TCP и UDP порты с именами процессов
sudo ss -tulpn
```
*   **`ss -t`**: Показывает только TCP-сокеты.
*   **`ss -u`**: Показывает только UDP-сокеты.
*   **`ss -a`**: Показывает все сокеты (LISTENING и NOT LISTENING).
*   **`ss -l`**: Показывает только LISTENING сокеты.
*   **`ss -n`**: Не разрешает имена служб и хостов.
*   **`ss -p`**: Показывает процесс, который использует сокет.
*   **`ss -e`**: Показывает расширенную информацию.
*   **`ss -s`**: Выводит сводную статистику по сокетам.

### Фильтрация по состоянию или порту

`ss` поддерживает мощный синтаксис фильтрации.

```bash
# Показать все соединения в состоянии ESTABLISHED
ss -t state established

# Показать все соединения, связанные с портом 80 (как источником, так и назначением)
ss -t '( dport = :80 or sport = :80 )'
```

### Пример из жизни: отслеживание подключения к веб-серверу

1.  На сервере `ss -tl | grep :80` покажет, что веб-сервер находится в состоянии `LISTEN`.
2.  Когда клиент подключается, команда `ss -tnp state established dst :80` покажет новое соединение в состоянии `ESTABLISHED`.
3.  После закрытия страницы в браузере соединение перейдет в состояние `TIME-WAIT` на некоторое время.

## 4. Продвинутые детали

### Сводная статистика

Команда `ss -s` предоставляет общую статистику по всем сокетам, что полезно для быстрой оценки общей сетевой нагрузки.

```bash
$ ss -s
Total: 256 (kernel 304)
TCP:   10 (estab 3, closed 0, orphaned 0, syn-recv 0, time-wait 0/0), ports 0

Transport Total     IP        IPv6
*	  304       -         -
RAW	  1         0         1
UDP	  8         5         3
TCP	  10        7         3
...
```

### Расширенная информация

Флаг `-e` или `-i` предоставляет детальную информацию о TCP соединениях, включая таймеры, `congestion window (cwnd)` и другую внутреннюю информацию TCP стека.

```bash
# Показать детальную информацию об установленных TCP соединениях
ss -tie
```
