# `iotop` — Мониторинг дискового I/O по процессам

## 1. Определение

`iotop` — это интерактивная утилита (подобная `top`), которая показывает нагрузку на дисковый ввод-вывод (I/O) в реальном времени, с разбивкой по процессам или потокам. Она незаменима для быстрого ответа на вопрос: **"Какой процесс сейчас нагружает диск?"**.

## 2. Основные концепции

`iotop` отслеживает, сколько данных каждый процесс читает с диска и пишет на него. Ключевой показатель для диагностики — `IO>`.
- **`IO>`**: Процент времени, который процесс провел в ожидании завершения операций ввода-вывода. Если для какого-либо процесса это значение близко к 100%, значит, он "застрял", ожидая ответа от диска. Это главный симптом "бутылочного горлышка" в подсистеме I/O.
- **`DISK READ/WRITE`**: Фактическая скорость обмена данными с диском для процесса.

## 3. Практические сценарии
### Базовый запуск

Запуск без аргументов показывает все процессы и их дисковую активность.
```bash
sudo iotop
```
*Требуются права `root`, так как утилита обращается к данным ядра.*

### Отображение только активных процессов

Ключ `-o` (`--only`) — самый полезный, так как он отфильтровывает "шум", показывая только те процессы, которые в данный момент выполняют операции I/O.
```bash
sudo iotop -o
```

### Другие полезные опции

- **`-P` (`--processes`):** Отображать только процессы, скрывая отдельные потоки.
- **`-u <user>`:** Отслеживать активность только указанного пользователя.
- **`-p <PID>`:** Мониторить только конкретный процесс.
- **`-k`:** Отображать скорость в килобайтах в секунду (по умолчанию — в удобном для чтения формате).

## 4. Продвинутые детали

### Интерактивное управление

Внутри `iotop` можно управлять отображением:
- **Стрелки влево/вправо**: Изменить колонку для сортировки.
- **`r`**: Инвертировать порядок сортировки.
- **`o`**: Включить/выключить режим отображения только активных процессов (аналог ключа `-o`).
- **`a`**: Переключить между суммарным и средним значением I/O.

### Связь с `iostat`

В то время как `iotop` показывает, *кто* создает нагрузку, [iostat](./iostat.md) показывает, *как* сама дисковая подсистема справляется с этой нагрузкой (утилизация, время отклика). Эти два инструмента отлично дополняют друг друга.
