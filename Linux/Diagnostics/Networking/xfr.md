# xfr

## Definitions

`xfr` — современная альтернатива `iperf3` для измерения пропускной способности сети. Написана на Rust, поддерживает multi-client, MPTCP и QUIC. Предоставляет TUI для мониторинга в реальном времени и встроенное сравнение результатов.

## Basic Concepts

Модель клиент-сервер, аналогичная `iperf3`. Ключевые отличия «из коробки»:

- **TUI:** интерактивный мониторинг метрик в реальном времени
- **Diff:** встроенное сравнение результатов тестов
- **Экспорт метрик:** JSON, Prometheus
- **Multi-client:** сервер принимает несколько одновременных подключений
- **QUIC и MPTCP:** поддержка современных транспортных протоколов

## Practical Scenarios

### Базовое тестирование

```bash
# Сервер (приём трафика)
xfr server

# Клиент (генерация трафика)
xfr client <IP_адрес_сервера>
```

### TUI-мониторинг

```bash
xfr client <IP_адрес_сервера> --tui
```

### Сравнение результатов

```bash
# Сохранить результат
xfr client <IP_адрес_сервера> --json > result1.json

# Сравнить с новым тестом
xfr diff result1.json <(xfr client <IP_адрес_сервера> --json)
```

## Additional Information

### Сравнение с iperf3

| Функция | iperf3 | xfr |
| :--- | :--- | :--- |
| Язык | C | Rust |
| Интерфейс | CLI | CLI + TUI |
| Multi-client | Нет | Да |
| QUIC / MPTCP | Нет | Да |
| Сравнение (diff) | Нет | Встроено |
| Экспорт метрик | JSON | JSON, Prometheus |
