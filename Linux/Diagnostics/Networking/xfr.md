# `xfr` — Альтернатива iperf3

## Определения

`xfr` (Network performance testing tool) — это современная и быстрая альтернатива `iperf3` для измерения пропускной способности сети. Она написана на Rust и предлагает расширенные возможности для мониторинга и отчетности.

## Основные концепции

Как и `iperf3`, `xfr` работает по модели клиент-сервер. Однако она предоставляет более богатый набор функций "из коробки":

* **TUI (Terminal User Interface):** Интерактивный интерфейс для наблюдения за процессом тестирования в реальном времени.
* **Сравнение результатов (diff):** Встроенная возможность сравнивать результаты текущего теста с предыдущими.
* **Экспорт метрик:** Поддержка вывода данных для систем мониторинга (например, Prometheus).
* **Гибкие форматы отчетов:** Поддержка JSON, Markdown и других форматов.

## Практические сценарии

### Базовое тестирование

1. **На стороне сервера:**

    ```bash
    # Запустить xfr в режиме сервера
    xfr server
    ```

2. **На стороне клиента:**

    ```bash
    # Подключиться к серверу и запустить тест
    xfr client <IP_адрес_сервера>
    ```

### Использование TUI

Для визуального наблюдения за нагрузкой и метриками в реальном времени:

```bash
xfr client <IP_адрес_сервера> --tui
```

### Сравнение результатов

`xfr` позволяет сохранять результаты и сравнивать их:

```bash
# Сохранить результат в файл
xfr client <IP_адрес_сервера> --json > result1.json

# Сравнить с новым тестом
xfr diff result1.json <(xfr client <IP_адрес_сервера> --json)
```

## Дополнительная информация

### Основные отличия от iperf3

| Функция | iperf3 | xfr |
| :--- | :--- | :--- |
| **Язык разработки** | C | Rust |
| **Интерфейс** | CLI | CLI + TUI |
| **Сравнение (diff)** | Нет (нужны сторонние скрипты) | Встроено |
| **Экспорт метрик** | JSON | JSON, Prometheus |
| **Направление** | Upload (по умолчанию), Download (`-R`) | Настраиваемо |
