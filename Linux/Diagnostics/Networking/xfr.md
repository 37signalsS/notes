# xfr

## Определения

**`xfr`** — современная альтернатива `iperf3` для измерения пропускной способности сети. Написана на языке Rust, поддерживает многоклиентный режим (multi-client), MPTCP и QUIC. Предоставляет TUI (Text User Interface) для мониторинга в реальном времени и встроенный механизм сравнения результатов.

## Основные концепции

Утилита использует модель клиент-сервер, аналогичную `iperf3`. Ключевые отличия и возможности:

- **TUI:** интерактивный графический мониторинг метрик в реальном времени в консоли.
- **Diff:** встроенное сравнение результатов нескольких тестов.
- **Экспорт метрик:** поддержка форматов JSON и Prometheus.
- **Multi-client:** сервер способен принимать несколько одновременных подключений от разных клиентов.
- **QUIC и MPTCP:** нативная поддержка современных транспортных протоколов.

## Практические сценарии

### Базовое тестирование пропускной способности

```bash
# Запуск сервера (приём трафика)
xfr server
# → Listening on 0.0.0.0:10001 (TCP)

# Запуск клиента (генерация трафика)
xfr client <IP_адрес_сервера>
# → [ID] Interval           Transfer     Bandwidth
# → [0]  0.00-1.00  sec   1.12 GBytes  9.60 Gbits/sec
```

### Мониторинг через TUI

Для визуализации процесса тестирования в реальном времени:

```bash
xfr client <IP_адрес_сервера> --tui
```

### Сравнение результатов тестов

Встроенная функция сравнения позволяет быстро выявить деградацию производительности:

```bash
# Сохранение результата в файл JSON
xfr client <IP_адрес_сервера> --json > result1.json

# Сравнение сохранённого результата с новым тестом
xfr diff result1.json <(xfr client <IP_адрес_сервера> --json)
# → [Diff] result1.json vs current: -2.5% Bandwidth
```

### Тестирование через протокол QUIC

`xfr` позволяет измерять пропускную способность с использованием современных протоколов, которые минимизируют задержки на установку соединения:

```bash
# Запуск клиента с использованием QUIC
xfr client <IP_адрес_сервера> --quic
# → [ID] Interval           Transfer     Bandwidth
# → [0]  0.00-1.00  sec   950 MBytes   7.60 Gbits/sec
```

## Дополнительная информация

### Интерпретация результатов

- **Деградация в Diff:** Отрицательные значения в `xfr diff` (например, `-5%`) указывают на снижение производительности по сравнению с эталонным тестом.
- **TUI vs CLI:** Использование `--tui` полезно для визуального обнаружения всплесков и просадок (jitter) во время теста, которые могут быть незаметны в итоговом среднем значении.
- **QUIC vs TCP:** Сравнение этих протоколов в одинаковых условиях позволяет оценить накладные расходы на шифрование и эффективность механизмов контроля перегрузки.

### Сравнение xfr и iperf3

| Функция | iperf3 | xfr |
| :--- | :--- | :--- |
| **Язык разработки** | C | Rust |
| **Интерфейс** | CLI | CLI + TUI |
| **Multi-client** | Нет | Да |
| **QUIC / MPTCP** | Нет | Да |
| **Сравнение (diff)** | Нет | Встроено |
| **Экспорт метрик** | JSON | JSON, Prometheus |
