# netstat (устаревший)

## Определения

> **Устаревший инструмент:** `netstat` (пакет `net-tools`) не развивается с 2001 года. Современная замена — **[`ss`](./ss.md)** из `iproute2` (прямой доступ к ядру через `netlink`, в 10–100 раз быстрее на >1000 соединений). Используйте `netstat` только для совместимости со старыми скриптами.

**`netstat`** (Network Statistics) — классическая утилита для просмотра сетевых подключений, таблиц маршрутизации и статистики интерфейсов.

## Основные концепции

### Отличия от `ss`

| Критерий | netstat | ss |
| :--- | :--- | :--- |
| Источник данных | `/proc` (обход файлов) | `netlink` (ядро) |
| Производительность | O(n) — медленный при >1000 соединений | O(1) — мгновенно |
| Фильтрация | Только через `grep` | Встроенные BPF-выражения |
| TCP-детали | Базовые | Расширенные (`-ti`: RTT, cwnd, retrans) |
| Поддержка | Прекращена | Активная |

### Основные флаги

| Флаг | Описание |
| :--- | :--- |
| `-t` / `-u` | TCP / UDP сокеты |
| `-l` | Listening-порты |
| `-p` | PID и имя процесса |
| `-n` | Числовые адреса (без DNS) |
| `-a` | Все сокеты |
| `-r` | Таблица маршрутизации |
| `-i` | Статистика интерфейсов |
| `-s` | Статистика протоколов |

## Практические сценарии

### Прослушивающие порты

```bash
netstat -tulpn
```

> **Современная замена:** `ss -tulpn`

### Поиск процесса по порту

```bash
netstat -tulpn | grep :8080
```

> **Современная замена:** `ss -tlnp 'sport = :8080'`

### Таблица маршрутизации

```bash
netstat -rn
```

> **Современная замена:** `ip route show`

### Статистика интерфейсов

```bash
netstat -i
```

> **Современная замена:** `ip -s link show`

## Дополнительная информация

### Миграция на `ss`

| Задача | netstat | ss |
| :--- | :--- | :--- |
| Слушащие порты | `netstat -tulpn` | `ss -tulpn` |
| TCP-соединения | `netstat -tn` | `ss -tn` |
| Статистика TCP | `netstat -st` | `ss -s` |
| Процесс на порту | `netstat -tulpn \| grep :80` | `ss -tlnp 'sport = :80'` |

### История устаревания

- **2001** — начата разработка `iproute2` (включая `ss`)
- **2010** — `net-tools` объявлен устаревшим
- **2015+** — крупные дистрибутивы (RHEL 7+, Ubuntu 16.04+) используют `iproute2` по умолчанию
- **2024** — `net-tools` удалён из репозиториев некоторых дистрибутивов (Fedora 41+)
