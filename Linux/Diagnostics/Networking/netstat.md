# `netstat` (устаревший)

## Определения

> **Предупреждение:** `netstat` является **устаревшим инструментом** с 2001 года. Пакет `net-tools` (включая `netstat`, `ifconfig`, `route`) больше не поддерживается. В современных дистрибутивах Linux используется **`ss` (Socket Statistics)** из пакета `iproute2` — более быстрая и информативная утилита, получающая данные напрямую из ядра через `netlink`.
>
> **Рекомендация:** Используйте [`ss`](./ss.md) для всех задач диагностики сокетов. `netstat` следует применять только для совместимости со старыми скриптами.

**`netstat`** (Network Statistics) — классическая утилита командной строки для просмотра информации о сетевых подключениях, таблицах маршрутизации и статистике интерфейсов. Часть пакета `net-tools`.

## Основные концепции

### Почему `ss` лучше `netstat`

| Критерий | netstat | ss |
| :--- | :--- | :--- |
| **Источник данных** | `/proc` (медленный обход) | `netlink` (прямой доступ к ядру) |
| **Производительность** | Медленный на >1000 соединений | Мгновенный вывод |
| **Детализация** | Базовая информация | Расширенная TCP-статистика (`-ti`) |
| **Поддержка** | Не развивается | Активно развивается |
| **Фильтрация** | Ограниченная (`grep`) | Встроенная (BPF-подобные выражения) |

### Частые флаги (для совместимости)

- `-t` / `-u`: TCP / UDP сокеты
- `-l`: Listening (слушающие) порты
- `-p`: PID и имя процесса
- `-n`: Числовые адреса (без DNS)
- `-a`: Все сокеты
- `-r`: Таблица маршрутизации
- `-i`: Статистика интерфейсов
- `-s`: Статистика протоколов

## Практические сценарии

### Просмотр слушающих портов (устаревший способ)

```bash
# Устаревший способ (медленный на системах с >1000 соединений)
netstat -tulpn
```

> **Современная альтернатива:** `ss -tulpn` — работает в 10-100 раз быстрее на нагруженных системах.

### Поиск процесса по порту

```bash
# Найти процесс на порту 8080
netstat -tulpn | grep :8080
```

> **Современная альтернатива:** `ss -tulpn | grep :8080` или `ss -tlnp 'sport = :8080'`

### Просмотр таблицы маршрутизации

```bash
netstat -rn
```

> **Современная альтернатива:** `ip route show`

### Просмотр статистики интерфейсов

```bash
netstat -i
```

> **Современная альтернатива:** `ip -s link show`

## Дополнительная информация

### Миграция на `ss`

| Задача | netstat | ss |
| :--- | :--- | :--- |
| Все слушающие порты | `netstat -tulpn` | `ss -tulpn` |
| TCP соединения | `netstat -tn` | `ss -tn` |
| Статистика TCP | `netstat -st` | `ss -s` |
| Процесс на порту | `netstat -tulpn \| grep :80` | `ss -tlnp 'sport = :80'` |
| Состояния TCP | `netstat -tan` | `ss -tan` |

### История устаревания

- **2001:** Начата разработка `iproute2` (включая `ss`)
- **2010:** `net-tools` объявлен устаревшим
- **2015+:** Крупные дистрибутивы (RHEL 7+, Ubuntu 16.04+) используют `iproute2` по умолчанию
- **2024:** `net-tools` удалён из репозиториев некоторых дистрибутивов (например, Fedora 41+)
