# TUI-утилиты для мониторинга сети

## Обзор основных утилит

### `nload` и `bmon` — Простая визуализация трафика

Эти утилиты решают одну простую задачу: показывают текущую скорость приёма (incoming) и передачи (outgoing) данных на сетевых интерфейсах в виде ASCII-графиков.

- **`nload`**: Очень прост в использовании, идеально подходит для быстрой оценки общей нагрузки.
- **`bmon`**: Предоставляет больше деталей, включая статистику по пакетам, ошибкам и график за более длительный период.

### `iftop` — "top" для сетевых соединений

Подобно `top` для процессов, `iftop` слушает трафик на указанном интерфейсе и отображает таблицу активных **соединений**, отсортированную по объему трафика. Это позволяет быстро определить, какие хосты генерируют наибольшую сетевую нагрузку.

### `jnettop` — Группировка трафика

`jnettop` также показывает активные соединения, но группирует их **по хосту и порту**. Это помогает быстро понять, какой сервис на каком хосте больше всего "общается" по сети.

### `iptraf-ng` — Комбайн для анализа

`iptraf-ng` — это мощный интерактивный инструмент с TUI-меню, предоставляющий несколько режимов мониторинга: общая и детальная статистика по интерфейсам, статистика по протоколам (IP, TCP, UDP, ICMP), мониторинг соединений и статистика по размерам пакетов.

## Практические сценарии

### Установка

Большинство утилит доступны в стандартных репозиториях Debian/Ubuntu.

```bash
sudo apt install nload bmon iftop jnettop iptraf-ng
```

### Примеры использования

```bash
# Запустить nload (переключение между интерфейсами - стрелки)
nload

# Запустить bmon
bmon

# Запустить iftop на интерфейсе eth0
# Полезные опции в интерактивном режиме: n (разрешение имен), p (порты)
sudo iftop -i eth0

# Запустить jnettop на интерфейсе eth0
sudo jnettop -i eth0

# Запустить iptraf-ng (навигация через меню)
sudo iptraf-ng
```
