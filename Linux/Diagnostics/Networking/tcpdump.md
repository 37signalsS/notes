# tcpdump

## Definitions

`tcpdump` — утилита командной строки для перехвата и анализа сетевого трафика. Работает на уровне ядра через `libpcap`, требует прав `root`. Используется для сетевой диагностики, отладки приложений и анализа безопасности.

## Basic Concepts

### Принцип работы

`tcpdump` подключается к сетевому интерфейсу на уровне ядра (через `libpcap`) и перехватывает все пакеты. Требуются права суперпользователя.

### Ключевые возможности

- **Захват в реальном времени:** вывод пакетов на экран по мере поступления.
- **Мощная фильтрация:** захват по хостам, портам, протоколам (BPF-выражения).
- **Сохранение для анализа:** запись в `.pcap` для последующего анализа в Wireshark или tcpdump.
- **Просмотр содержимого IP-пакетов:** анализ payload и заголовков в HEX и ASCII (флаги `-X`, `-A`).

### Формат вывода

Флаги `-n` / `-nn`:

- `-n`: не разрешать IP в доменные имена (ускоряет вывод)
- `-nn`: не разрешать ни IP, ни порты (максимальная скорость)

### TCP-флаги в выводе tcpdump

| Флаг | Обозначение | Значение |
| :--- | :--- | :--- |
| **SYN** | `[S]` | Начало соединения |
| **ACK** | `[.]` | Подтверждение |
| **PSH** | `[P]` | Просьба протолкнуть данные приложению |
| **FIN** | `[F]` | Завершение соединения |
| **RST** | `[R]` | Сброс соединения |
| **URG** | `[U]` | Срочные данные |
| **ECE** | `[W]` | ECN-Echo, уведомление о перегрузке |
| **CWR** | `[E]` | Congestion Window Reduced, ответ на ECE |

### Связанные инструменты

Для глубокого анализа `.pcap` с графическим интерфейсом — [Wireshark](../../../Networking/ServicesAndTools/Wireshark/definitions.md). Для TUI-анализа в терминале — [termshark](./network_cli_tools.md).

## Practical Scenarios

### Базовый захват трафика

```bash
# Показать список доступных интерфейсов для захвата
sudo tcpdump -D

# Начать захват пакетов на интерфейсе eth0
# -i: указать интерфейс
# -n: не разрешать IP-адреса в доменные имена (ускоряет вывод)
# -nn: не разрешать ни IP, ни порты
sudo tcpdump -i eth0 -nn

# Ограничить количество захваченных пакетов (например, 10)
sudo tcpdump -i eth0 -c 10
```

### Сохранение и чтение трафика

```bash
# Сохранить весь трафик с интерфейса eth0 в файл capture.pcap
sudo tcpdump -i eth0 -w capture.pcap

# Прочитать трафик из файла
tcpdump -r capture.pcap -nn
```

**Важно:** Сохранение в `.pcap` с помощью флага `-w` предпочтительнее, чем перенаправление вывода `>` в текстовый файл.

- `-w`: Записывает "сырые" данные пакетов в бинарный файл, который содержит полную информацию и может быть проанализирован другими утилитами (например, Wireshark).
- `>`: Перенаправляет только форматированный текстовый вывод, который вы видите на экране, теряя при этом часть данных.

### Мощная фильтрация трафика

```bash
# Фильтрация по протоколу (icmp, udp, tcp)
sudo tcpdump -i eth0 icmp

# Фильтрация по хосту (источник или назначение)
sudo tcpdump -i eth0 host 192.168.1.10

# Фильтрация по порту
sudo tcpdump -i eth0 port 80

# Комбинирование фильтров с помощью 'and', 'or', 'not'
# (скобки необходимо экранировать)

# DNS-трафик (обычно UDP, порт 53)
sudo tcpdump -i eth0 udp and port 53

# SSH-трафик с конкретного хоста
sudo tcpdump -i eth0 host 192.168.1.10 and port 22

# Трафик на хост по нескольким портам
sudo tcpdump -i eth0 'host 192.168.1.254 and (port 80 or port 443)'
```

### Мониторинг в реальном времени с ограничением вывода

```bash
# Показать только заголовки пакетов (без payload)
sudo tcpdump -i eth0 -q -n

# Вывод с временными метками
sudo tcpdump -i eth0 -tttt -n

# Остановить захват после определённого количества пакетов
sudo tcpdump -i eth0 -c 5 -w capture.pcap
```

### Анализ проблем с производительностью

```bash
# Захват с метками времени для анализа задержек
sudo tcpdump -i eth0 -tttt 'port 80'

# Показать только проблемные пакеты (RST, FIN)
sudo tcpdump -i eth0 'tcp[tcpflags] & (tcp-rst|tcp-fin) != 0'

# Анализ DNS-запросов с детальной информацией
sudo tcpdump -i eth0 -vvv port 53
```

## Additional Information

### Анализ содержимого пакетов и TCP-соединений

```bash
# Показать содержимое пакетов в HEX и ASCII с максимальной детализацией
# -X: показать содержимое в HEX и ASCII
# -v, -vv, -vvv: уровни детализации (TTL, опции TCP и т.д.)
sudo tcpdump -i eth0 -Xvvv -nn 'port 80 and host example.com'
```

- **HTTP-трафик (незашифрованный):** В ASCII-части вывода можно увидеть HTTP-заголовки (`GET / ...`, `200 OK`).
- **HTTPS-трафик (зашифрованный):** Содержимое пакетов будет нечитаемым, но можно увидеть детали TLS-рукопожатия, например, расширение SNI (Server Name Indication).

### Анализ TCP Handshake (Трехстороннее рукопожатие)

```bash
# Захватить 3 первых пакета при подключении к веб-серверу
sudo tcpdump -i eth0 -c 3 'host example.com and port 80'
```
