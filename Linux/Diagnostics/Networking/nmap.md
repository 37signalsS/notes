# nmap (Network Mapper)

## Определения

**`nmap`** (Network Mapper) — открытая утилита для исследования сетей и аудита безопасности. Предназначена для обнаружения хостов, сканирования портов, определения версий служб и операционных систем, создавая детальную «карту» сетевой инфраструктуры.

## Основные концепции

`nmap` отправляет специально сформированные пакеты (IP-датаграммы) на целевые хосты и анализирует ответы, определяя:

- **Активные хосты:** проверка доступности узлов в сети.
- **Состояние портов:** определение того, какие порты открыты, закрыты или фильтруются.
- **Версии служб:** идентификация приложений и их версий на открытых портах.
- **Операционные системы:** определение типа и версии ОС хоста (TCP/IP fingerprinting).
- **Скриптовый движок NSE:** расширение функционала с помощью готовых Lua-скриптов для автоматизации задач.

### Состояния портов

| Состояние | Описание |
| :--- | :--- |
| **open** | Порт открыт, приложение принимает TCP-соединения или UDP-пакеты. |
| **closed** | Порт доступен, но на нем не запущена служба. |
| **filtered** | Брандмауэр или фильтр блокируют доступ, ответ не получен. |
| **unfiltered** | Порт доступен, но `nmap` не может определить, открыт он или закрыт (в сканировании ACK). |
| **open\|filtered** | Нет ответа, порт может быть открыт или защищен фильтром. |
| **closed\|filtered** | Статус не определен (только для сканирования IP ID idle). |

### Типы сканирования

| Флаг | Описание |
| :--- | :--- |
| `-sS` | SYN-сканирование (полуоткрытое, stealth-режим). |
| `-sT` | TCP Connect (полное трехэтапное рукопожатие, шумное). |
| `-sU` | UDP-сканирование для поиска служб DNS, DHCP, SNMP. |
| `-sV` | Определение версий служб и протоколов. |
| `-O` | Определение операционной системы. |
| `-A` | Агрессивное сканирование: сочетает `-O`, `-sV`, `-sC` и `--traceroute`. |
| `-sn` | Пинг-сканирование (без сканирования портов). |

## Практические сценарии

### Быстрое сканирование хоста

```bash
# Сканирование 1000 наиболее популярных портов
nmap scanme.nmap.org
# → Nmap scan report for scanme.nmap.org (45.33.32.156)
# → PORT     STATE SERVICE
# → 22/tcp   open  ssh
# → 80/tcp   open  http
```

### Сканирование конкретных портов

```bash
# Проверка порта 80
nmap -p 80 192.168.1.1
# → 80/tcp open  http

# Диапазон портов
nmap -p 1-100 192.168.1.1

# Несколько портов
nmap -p 22,80,443,8080 192.168.1.1
```

### Определение версий и ОС

```bash
# Определение версий служб (требует прав root для некоторых типов пакетов)
sudo nmap -sV 192.168.1.1
# → 22/tcp open  ssh     OpenSSH 8.2p1 Ubuntu 4ubuntu0.5

# Определение операционной системы
sudo nmap -O 192.168.1.1
# → Device type: general purpose
# → Running: Linux 4.X|5.X
```

### Сканирование сетей и групп хостов

```bash
# Сканирование подсети /24
nmap 192.168.1.0/24

# Диапазон IP-адресов
nmap 192.168.1.10-50

# Хосты из внешнего файла
nmap -iL targets.txt
```

### Скриптовый движок NSE (Nmap Scripting Engine)

```bash
# Использование набора скриптов по умолчанию
sudo nmap -sC 192.168.1.1

# Проверка на наличие известных уязвимостей
sudo nmap --script vuln 192.168.1.100

# Получение HTTP-заголовков на порту 80
sudo nmap --script http-title -p 80 192.168.1.0/24
```

### Сохранение результатов

```bash
# Сохранение в обычном текстовом формате
nmap -oN report.txt 192.168.1.1

# Сохранение в формате XML (для последующего анализа)
nmap -oX report.xml 192.168.1.1
```

## Дополнительная информация

### Предостережения и этика

- **Производственные среды:** Агрессивные режимы (например, `-A` или `-T5`) могут вызвать сбои в работе старого сетевого оборудования или чувствительных приложений.
- **Легальность:** Всегда получайте разрешение перед сканированием систем, которые вам не принадлежат.
- **Скрытность:** По умолчанию `nmap` легко обнаруживается системами IDS/IPS. Для минимизации шума используйте `-sS` и медленные тайминги (`-T1` или `-T2`).
