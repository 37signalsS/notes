# nmap (Network Mapper)

## Определения

**`nmap`** (Network Mapper) — индустриальный стандарт и мощнейшая утилита с открытым исходным кодом для исследования сетей, сканирования портов и аудита безопасности. Она позволяет обнаруживать активные хосты, определять открытые порты, версии запущенных сервисов и типы операционных систем, формируя полную карту сетевой инфраструктуры.

## Основные концепции

`nmap` работает путем отправки специально сформированных IP-пакетов и анализа ответов от целевых узлов.

- **Обнаружение хостов (Host Discovery):** определение того, какие IP-адреса активны в сети.
- **Сканирование портов:** выявление открытых TCP и UDP портов.
- **Определение версий (Version Detection):** опрос портов для идентификации конкретных приложений и их версий.
- **Определение ОС (OS Fingerprinting):** анализ тонких различий в реализации стека TCP/IP для определения типа и версии операционной системы.
- **NSE (Nmap Scripting Engine):** мощный скриптовый движок на языке Lua для автоматизации задач от сетевого аудита до поиска уязвимостей.

### Состояния портов

Интерпретация ответов `nmap` критически важна для понимания сетевой топологии и настроек брандмауэра:

| Состояние | Описание | Ответ от хоста |
| :--- | :--- | :--- |
| **open** | Порт принимает соединения. Служба активно слушает. | SYN/ACK (TCP) или ответ службы (UDP). |
| **closed** | Порт доступен, но за ним нет слушающей службы. | RST (TCP) или ICMP Port Unreachable (UDP). |
| **filtered** | Пакеты блокируются брандмауэром. Состояние неизвестно. | Нет ответа или ICMP Prohibited (административно запрещено). |
| **unfiltered** | Порт доступен, но состояние (открыт/закрыт) не определено. | Только при ACK-сканировании (`-sA`). |
| **open\|filtered** | Нет ответа; порт либо открыт, либо защищен фильтром. | Типично для UDP или некоторых типов TCP (FIN, Null, Xmas). |

### Режимы сканирования

| Флаг | Тип | Особенности |
| :--- | :--- | :--- |
| `-sS` | **SYN Scan** | "Полуоткрытое" сканирование. Быстрое, не завершает TCP-рукопожатие. Стандарт для Stealth-режима. |
| `-sT` | **Connect Scan** | Использует системный вызов `connect()`. Полное рукопожатие. Оставляет записи в логах приложений. |
| `-sU` | **UDP Scan** | Медленное и менее надежное из-за отсутствия подтверждений. Важно для DNS (53), DHCP (67/68), SNMP (161). |
| `-sA` | **ACK Scan** | Используется для выявления правил фильтрации брандмауэра (Stateful vs Stateless). |
| `-sn` | **Ping Scan** | Отключает сканирование портов. Используется для инвентаризации активных хостов. |

## Практические сценарии

### Выбор целей и исключений

```bash
# Сканирование списка из файла
nmap -iL targets.txt

# Сканирование сети, исключая конкретные IP
nmap 192.168.1.0/24 --exclude 192.168.1.1,192.168.1.254
```

### Выбор портов для сканирования

```bash
# Сканирование конкретных портов
nmap -p 22,80,443 192.168.1.1

# Сканирование диапазона портов
nmap -p 1-1024 192.168.1.1

# Сканирование ВСЕХ портов (65535)
nmap -p- 192.168.1.1

# Сканирование 100 самых популярных портов
nmap --top-ports 100 192.168.1.1

# Быстрое сканирование (100 портов из nmap-services)
nmap -F 192.168.1.1
```

### Инвентаризация сети (Host Discovery)

Быстрый поиск живых хостов в подсети:

```bash
# Обнаружение хостов (ARP-запросы в локальной сети)
nmap -sn 192.168.1.0/24
```

### Детальное сканирование целевого узла

```bash
# Агрессивное сканирование (версии, ОС, скрипты, traceroute)
sudo nmap -A 10.0.0.15

# Определение версий с максимальной интенсивностью (0-9)
nmap -sV --version-intensity 9 10.0.0.15
```

### Скриптовый движок NSE

Категории скриптов: `auth`, `broadcast`, `default`, `discovery`, `dos`, `exploit`, `external`, `fuzzer`, `intrusive`, `malware`, `safe`, `version`, `vuln`.

```bash
# Запуск скриптов по умолчанию
nmap -sC 192.168.1.1

# Поиск уязвимостей
nmap --script vuln 192.168.1.100

# Помощь по конкретному скрипту
nmap --script-help http-enum

# Поиск HTTP-директорий и файлов
nmap --script http-enum 192.168.1.100
```

### Оптимизация и обход защиты

```bash
# Шаблоны таймингов (T0 - параноидальный, T5 - агрессивный)
nmap -T4 192.168.1.1

# Обход фильтрации через подмену источника (Decoy)
nmap -D RND:10 192.168.1.1

# Использование конкретного интерфейса и IP
nmap -e eth0 -S 10.0.0.1 192.168.1.1
```

### Продвинутая диагностика

```bash
# Показать причину состояния порта (почему open или filtered)
nmap --reason 192.168.1.1

# Отслеживание каждого отправленного/полученного пакета
nmap --packet-trace 192.168.1.1
```

### Форматы вывода

```bash
# Сохранение во всех форматах (scan.nmap, scan.xml, scan.gnmap)
nmap -oA scan_result 192.168.1.1

# Вывод в XML для анализа сторонними инструментами
nmap -oX report.xml 192.168.1.1
```

## Дополнительная информация

### Технические нюансы

- **Права Root:** Требуются для операций с Raw Sockets (`-sS`, `-O`, `-sU`, обход FW). Без root используется `-sT` (Connect scan).
- **UDP-сканирование:** Крайне медленное из-за лимитов ICMP-ответов в ОС. Используйте `-sV`, чтобы заставить nmap отправить запрос приложения и подтвердить `open`.
- **Zenmap:** Официальный графический интерфейс (GUI) для Nmap, полезен для визуализации топологии сети.
