# `nmap`

## Определение

`nmap` (Network Mapper) — это мощная утилита с открытым исходным кодом для исследования сетей и проведения аудита безопасности. Она используется для обнаружения хостов и служб в компьютерной сети, создавая таким образом "карту" сети.

## Основные концепции

`nmap` отправляет специально сформированные пакеты на целевые хосты и анализирует ответы. По ответам (или их отсутствию) он определяет:

- Какие хосты активны в сети.
- Какие порты на этих хостах открыты, закрыты или фильтруются.
- Какие службы (приложения) работают на открытых портах.
- Какие операционные системы и их версии установлены на целевых хостах.
- Каким образом осуществляется фильтрация брандмауэром.
- Поиск неавторизованных серверов и сетевых служб.

### Состояния портов

`nmap` может определять различные состояния портов:

- **`open` (открыт)**: Приложение активно принимает TCP-соединения, UDP-дейтаграммы или запросы SCTP.
- **`closed` (закрыт)**: Порт доступен, `nmap` получил ответ, но никакое приложение не прослушивает его.
- **`filtered` (фильтруемый)**: `nmap` не может определить, открыт порт или закрыт, так как фильтрация пакетов (брандмауэром, маршрутизатором или хостом) препятствует достижению "зонда" до порта.
- **`unfiltered` (нефильтруемый)**: Порт доступен, но `nmap` не может определить открыт он или закрыт. Это состояние встречается крайне редко.
- **`open|filtered` (открыт|фильтруемый)**: `nmap` не может определить, открыт ли порт или отфильтрован. Это происходит, когда открытые порты не дают ответа.
- **`closed|filtered` (закрыт|фильтруемый)**: `nmap` не может определить, закрыт ли порт или отфильтрован.

## Практические сценарии

### Быстрое сканирование хоста

```bash
# Просканировать 1000 самых распространенных портов на хосте
nmap scanme.nmap.org
```

### Сканирование конкретного порта

```bash
# Проверить, открыт ли TCP-порт 80 (HTTP) на хосте
nmap -p 80 192.168.1.1

# Проверить диапазон портов
nmap -p 1-100 192.168.1.1
```

### Определение версий служб

```bash
# Просканировать хост и определить версии служб
sudo nmap -sV 192.168.1.1
```

### Сканирование нескольких хостов

Можно сканировать несколько хостов, перечисляя их в команде, используя диапазоны IP-адресов или указывая файл со списком хостов.

```bash
# Сканирование нескольких хостов
nmap host1.example.com host2.example.com 192.168.1.10-20

# Сканирование хостов из файла (каждый хост на новой строке, разделенный пробелами или табуляцией)
nmap -iL /path/to/hosts.txt
```

### Вывод результатов сканирования в файл

`nmap` предоставляет различные форматы вывода для сохранения результатов сканирования.

```bash
# Вывести результаты в обычный текстовый файл
nmap -oN output.txt scanme.nmap.org

# Вывести результаты в XML-формат (удобно для парсинга)
nmap -oX output.xml scanme.nmap.org
```

## Продвинутые детали

### Определение операционной системы

`nmap` может попытаться определить операционную систему на основе анализа TCP/IP стека.

```bash
# Включить определение ОС
sudo nmap -O 192.168.1.1
```

### "Агрессивное" сканирование

Ключ `-A` включает определение ОС (`-O`), версий служб (`-sV`), трассировку (`--traceroute`) и выполнение скриптов (`-sC`). Это дает очень много информации, но является "шумным" и легко обнаруживается системами обнаружения вторжений.

```bash
sudo nmap -A 192.168.1.1
```

### Использование скриптового движка (NSE)

Nmap Scripting Engine (NSE) позволяет выполнять скрипты для автоматизации широкого круга сетевых задач.

```bash
# Запустить стандартный набор скриптов
sudo nmap -sC 192.168.1.1

# Найти все HTTP-серверы в сети и получить их заголовки
sudo nmap --script http-title -p 80 192.168.1.0/24
```

### Сканирование на уязвимости с помощью NSE-скриптов

`nmap` может использовать скрипты для обнаружения известных уязвимостей.

```bash
# Сканирование на наличие уязвимостей (например, SMB) на хосте
sudo nmap --script vuln 192.168.1.100
```

### Проведение атак перебора (Brute-force) с помощью NSE-скриптов

`nmap` также позволяет проводить атаки перебора логинов и паролей для различных служб.

```bash
# Пример SSH-брутфорса с использованием файлов со словарями
sudo nmap --script ssh-brute --script-args userdb=/path/to/users.txt,passdb=/path/to/pass.txt 192.168.1.100
```
