# nmap

## Определения

`nmap` (Network Mapper) — утилита для исследования сетей и аудита безопасности. Обнаруживает хосты, открытые порты, службы и ОС, создавая «карту» сети.

## Основные концепции

`nmap` отправляет специально сформированные пакеты на целевые хосты и анализирует ответы, определяя:

- Активные хосты в сети
- Состояние портов (открыт/закрыт/фильтруется)
- Службы на открытых портах
- Операционные системы (TCP/IP fingerprinting)
- Наличие фильтрации брандмауэром

### Состояния портов

| Состояние | Описание |
| :--- | :--- |
| `open` | Приложение принимает соединения |
| `closed` | Порт доступен, но служба не запущена |
| `filtered` | Брандмауэр блокирует пакеты |
| `unfiltered` | Порт доступен, состояние не определено |
| `open\|filtered` | Открыт или фильтруется (нет ответа) |
| `closed\|filtered` | Закрыт или фильтруется |

### Типы сканирования

| Флаг | Описание |
| :--- | :--- |
| `-sS` | SYN-сканирование (полуоткрытое, stealth) |
| `-sT` | TCP Connect (полное соединение) |
| `-sU` | UDP-сканирование |
| `-sV` | Определение версий служб |
| `-O` | Определение ОС |
| `-A` | Агрессивное: `-O` + `-sV` + `--traceroute` + `-sC` |
| `-sC` / `--script` | NSE-скрипты |

## Практические сценарии

### Быстрое сканирование хоста

```bash
# 1000 самых распространённых портов
nmap scanme.nmap.org
```

### Сканирование конкретного порта

```bash
# TCP-порт 80
nmap -p 80 192.168.1.1

# Диапазон портов
nmap -p 1-100 192.168.1.1

# Несколько портов
nmap -p 22,80,443,8080 192.168.1.1
```

### Определение версий служб

```bash
sudo nmap -sV 192.168.1.1
```

### Сканирование нескольких хостов

```bash
# Перечисление хостов и диапазонов IP
nmap host1.example.com host2.example.com 192.168.1.10-20

# Сканирование подсети /24
nmap 192.168.1.0/24

# Хосты из файла
nmap -iL /path/to/hosts.txt
```

### Вывод результатов в файл

```bash
# Текстовый файл
nmap -oN output.txt scanme.nmap.org

# XML (для парсинга)
nmap -oX output.xml scanme.nmap.org

# Grepable (удобно для grep)
nmap -oG output.txt scanme.nmap.org
```

### Определение операционной системы

```bash
sudo nmap -O 192.168.1.1
```

### Агрессивное сканирование

```bash
# ОС + версии + traceroute + скрипты
sudo nmap -A 192.168.1.1
```

> **Примечание:** Шумное сканирование, легко обнаруживается IDS/IPS.

### Скриптовый движок NSE

```bash
# Стандартный набор скриптов
sudo nmap -sC 192.168.1.1

# Конкретный скрипт
sudo nmap --script http-title -p 80 192.168.1.0/24

# Сканирование на уязвимости
sudo nmap --script vuln 192.168.1.100
```

### Оптимизация скорости

```bash
# Агрессивный тайминг (T4 = быстро, T5 = очень быстро)
nmap -T4 192.168.1.0/24

# Параллельное сканирование портов
nmap --min-parallelism 50 192.168.1.1

# Только хосты, которые включены (без сканирования портов)
nmap -sn 192.168.1.0/24
```

## Дополнительная информация

### Предостережения

- **Производственные среды:** Избегайте `-A` и `--script vuln` без согласования — генерируют значительный трафик и могут вызвать нагрузку на целевые системы.
- **Легальность:** Сканирование сетей без разрешения может нарушать законодательство. Используйте только в авторизованных сетях.
- **Обнаружение:** `nmap` легко детектируется IDS/IPS. Для тестирования на проникновение используйте с осторожностью.
