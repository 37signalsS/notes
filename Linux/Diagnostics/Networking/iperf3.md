# `iperf3`

## Определения

`iperf3` — это утилита для активного измерения максимально достижимой пропускной способности IP-сетей. Она работает в клиент-серверном режиме и позволяет протестировать, какую реальную скорость передачи данных можно получить между двумя хостами.

## Основные концепции

Для проведения теста `iperf3` необходимо запустить на одном хосте в режиме сервера (он будет принимать трафик), а на другом — в режиме клиента (он будет генерировать и отправлять трафик).

`iperf3` измеряет:

- **Пропускную способность (Bandwidth):** Скорость передачи данных в битах/с.
- **Потери пакетов (Lost Datagrams):** Для UDP-тестов.
- **Джиттер (Jitter):** Вариация задержки пакетов.

## Практические сценарии

### Стандартный тест (Upload)

По умолчанию клиент отправляет данные на сервер, измеряя скорость загрузки (upload) со стороны клиента.

1. **На хосте-сервере:**

    ```bash
    iperf3 -s
    ```

2. **На хосте-клиенте:**

    ```bash
    # Запустить тест, подключившись к серверу
    iperf3 -c <IP_адрес_сервера>
    ```

### Тест на скачивание (Download)

С помощью ключа `-R` можно инвертировать направление теста.

```bash
# Клиент запрашивает, а сервер отправляет данные
iperf3 -c <IP_адрес_сервера> -R
```

### Тестирование UDP

Для тестирования трафика, чувствительного к потерям и задержкам (например, VoIP или видео), используется UDP-режим.

```bash
# На сервере
iperf3 -s

# На клиенте, отправить UDP-трафик с пропускной способностью 100 Мбит/с
iperf3 -c <IP_адрес_сервера> -u -b 100M
```

## Дополнительная информация

### Многопоточный тест

Для полного насыщения канала и обхода ограничений одного TCP-соединения можно использовать несколько параллельных потоков.

```bash
# Запустить тест с 10 параллельными потоками
iperf3 -c <IP_адрес_сервера> -P 10
```

### Увеличение длительности теста

Для получения более стабильных и достоверных результатов рекомендуется проводить тест в течение более длительного времени.

```bash
# Проводить тест в течение 60 секунд
iperf3 -c <IP_адрес_сервера> -t 60
```

### JSON-вывод

Для автоматической обработки результатов `iperf3` может выводить данные в формате JSON.

```bash
# Вывести результаты в формате JSON
iperf3 -c <IP_адрес_сервера> -J
```
