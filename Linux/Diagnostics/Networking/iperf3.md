# iperf3

> [iperf.fr](https://iperf.fr/) — официальный сайт с документацией и бинарными сборками.

## Определения

`iperf3` — утилита для активного измерения максимально достижимой пропускной способности IP-сетей. Работает в клиент-серверном режиме, измеряет реальную скорость передачи данных между двумя хостами.

## Основные концепции

Тестирование требует запуска `iperf3` на двух хостах: **сервер** (приём трафика) и **клиент** (генерация трафика).

**Измеряемые метрики:**

| Метрика | Описание | Режим |
| :--- | :--- | :--- |
| Bandwidth | Пропускная способность (бит/с) | TCP, UDP |
| Packet Loss | Потери пакетов | UDP |
| Jitter | Вариация задержки пакетов | UDP |

### Основные аргументы

**Режимы:**
- `-s` — серверный режим (ожидание подключений)
- `-c <адрес>` — клиентский режим (подключение к серверу)

**Параметры теста:**
- `-p <порт>` — порт сервера (по умолчанию `5201`)
- `-t <сек>` — длительность теста (по умолчанию `10`)
- `-i <сек>` — интервал вывода промежуточных результатов
- `-P <n>` — количество параллельных TCP-потоков

**Полезные опции:**
- `-R` — reverse mode: сервер отправляет данные клиенту (проверка download-канала)
- `-f <k/m/g>` — формат вывода: Kbits, Mbits, Gbits
- `-J` — вывод в JSON (для скриптов и автоматизации)
- `-u` — UDP-режим (по умолчанию TCP)
- `-b <скорость>` — целевая пропускная способность в UDP-режиме (например `100M`)

## Практические сценарии

### TCP-тест (Upload)

Клиент отправляет данные на сервер — измеряется upload-скорость.

```bash
# Сервер
iperf3 -s

# Клиент
iperf3 -c <IP_сервера>
```

### Тест с нестандартным портом и промежуточным выводом

```bash
# Сервер на порту 9000
iperf3 -s -p 9000

# Клиент — вывод каждые 2 секунды
iperf3 -c <IP_сервера> -p 9000 -i 2
```

### TCP-тест (Download)

Ключ `-R` инвертирует направление — сервер отправляет данные клиенту.

```bash
iperf3 -c <IP_сервера> -R
```

### UDP-тест

Для оценки качества трафика, чувствительного к потерям (VoIP, видео).

```bash
# Сервер
iperf3 -s

# Клиент — UDP с целевой пропускной способностью 100 Мбит/с
iperf3 -c <IP_сервера> -u -b 100M
```

### Многопоточный тест

Ключ `-P` создаёт параллельные потоки для насыщения канала.

```bash
# 10 параллельных потоков
iperf3 -c <IP_сервера> -P 10
```

### Увеличение длительности

Ключ `-t` задаёт время теста в секундах (по умолчанию 10).

```bash
# Тест 60 секунд для стабильных результатов
iperf3 -c <IP_сервера> -t 60
```

### JSON-вывод

Ключ `-J` выводит результаты в формате JSON для автоматизации.

```bash
iperf3 -c <IP_сервера> -J
```

## Дополнительная информация

### Интерпретация результатов

- **Асимметрия Upload/Download:** Разница в скоростях `-c` и `-R` указывает на асимметричный канал (часто у провайдеров).
- **Один поток vs много:** Один TCP-поток может не насытить канал. Сравните `-P 1` с `-P 10` для выявления ограничений стека TCP.
- **UDP потери:** Высокий Packet Loss при `-u` указывает на перегрузку канала или буферов.
