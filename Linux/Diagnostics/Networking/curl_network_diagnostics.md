# Диагностика сетевых задержек с cURL

## Определения

`curl` — утилита для передачи данных по сетевым протоколам. Опция `-w` (`--write-out`) выводит временные метрики после завершения запроса, позволяя локализовать задержки на каждом этапе HTTP(S)-соединения.

> Полный справочник curl: **[cURL: Универсальный инструмент](../../Networking/Tools/http_clients/curl.md)**

## Основные концепции

**Ключевые временные метрики:**

| Метрика | Описание |
| :--- | :--- |
| `time_namelookup` | Время разрешения DNS-имени |
| `time_connect` | Время установки TCP-соединения |
| `time_appconnect` | Время завершения TLS-рукопожатия (HTTPS) |
| `time_pretransfer` | Время до готовности передачи данных |
| `time_starttransfer` | Время до получения первого байта ответа |
| `time_total` | Общее время выполнения операции |

## Практические сценарии

### Анализ полного времени запроса

```bash
curl -o /dev/null -s -w \
"DNS:     %{time_namelookup}s\n\
TCP:      %{time_connect}s\n\
TLS:      %{time_appconnect}s\n\
Server:   %{time_starttransfer}s\n\
Total:    %{time_total}s\n" \
https://example.com
```

### Изоляция DNS-проблем

```bash
curl --resolve example.com:443:93.184.216.34 https://example.com
```

Сравнение с обычным запросом локализует задержки на этапе DNS. Альтернатива правке `/etc/hosts` — опция `--resolve` применяет IP только для текущего вызова.

## Дополнительная информация

### Интерпретация результатов

| Метрика | Проблема | Направление диагностики |
| :--- | :--- | :--- |
| Высокое `time_namelookup` | Медленный DNS-сервер | **[Диагностика DNS](./dns/overview.md)** |
| Высокое `time_connect` | Задержки TCP, файрвол, перегрузка сети | **[ss](./ss.md)**, **[tcpdump](./tcpdump.md)** |
| Высокое `time_appconnect` | Медленное TLS-рукопожатие (CPU сервера, проблемы с сертификатом) | Проверка сертификата, нагрузка на сервер |
| Высокое `time_starttransfer` | Бэкенд долго обрабатывает запрос (БД, медленный код) | Логи приложения, профилирование бэкенда |
