# Сетевые инструменты CLI и TUI

## Определения

**Сетевые инструменты CLI и TUI** — это специализированные консольные утилиты с текстовым (CLI) или интерактивным псевдографическим (TUI) интерфейсом, предназначенные для мониторинга сетевой активности, анализа трафика и управления соединениями в реальном времени.

Эти инструменты незаменимы при работе на удаленных серверах через SSH, когда использование графических анализаторов (например, Wireshark) невозможно или нецелесообразно.

## Основные концепции

### Классификация инструментов

| Инструмент | Тип | Основное назначение |
| :--- | :--- | :--- |
| **termshark** | TUI | Интерактивный анализ трафика (аналог Wireshark) |
| **snitch** | TUI | Привязка сокетов к процессам, управление процессами |
| **syswatch** | TUI | Комплексный мониторинг CPU, I/O и сети с аналитикой |
| **iftop** | TUI | Анализ нагрузки в разрезе соединений (хост-хост) |
| **nload** | TUI | Визуализация общей нагрузки на интерфейс (графики) |
| **bmon** | TUI | Детальная статистика по интерфейсам и пакетам |
| **iptraf-ng** | TUI | Комплексный мониторинг протоколов и соединений |
| **jnettop** | TUI | Группировка трафика по хостам и портам |

### Описание ключевых утилит

#### termshark

TUI-интерфейс для `tshark` (консольная версия Wireshark). Позволяет анализировать живой трафик или `.pcap`-файлы с использованием привычных фильтров отображения.

**Возможности:**

- Разбор пакетов по уровням (L2-L7).
- Просмотр TCP-потоков (Follow Stream).
- Поддержка большинства протоколов, доступных в Wireshark.

#### snitch

Инструмент, который часто называют «htop для сети». Он позволяет видеть не только активные соединения, но и конкретные процессы, которые их инициировали.

#### syswatch

Современная диагностическая панель, объединяющая функции мониторинга CPU, диска и сети.

**Возможности:**

- **Timeline**: просмотр истории метрик текущей сессии.
- **Insights**: автоматический анализ проблем и их описание.
- **Интеграция**: заменяет собой связку `htop`, `iostat` и `iftop`.

Подробнее см. в [**инструкции по syswatch**](../Performance/syswatch.md).

#### iftop

Инструмент для мониторинга использования полосы пропускания. Он отображает таблицу текущих соединений между парами хостов, сортируя их по объему передаваемых данных.

#### nload и bmon

Утилиты для визуализации нагрузки на сетевые интерфейсы.

- **nload:** фокусируется на входящем и исходящем трафике с простыми ASCII-графиками.
- **bmon:** предоставляет более глубокую статистику, включая количество пакетов, ошибки и возможность просмотра графиков за разные периоды.

#### iptraf-ng

Интерактивный «комбайн», предоставляющий текстовые меню для выбора режима мониторинга: статистика по интерфейсам, протоколам (IP, TCP, UDP, ICMP) или конкретным соединениям.

## Практические сценарии

### Анализ сохраненного дампа трафика (termshark)

Если имеется файл захвата, созданный с помощью `tcpdump`, его можно удобно изучить в терминале:

```bash
termshark -r capture.pcap
# → открывается интерактивное окно с иерархией пакетов
```

### Поиск процесса, создающего сетевую нагрузку (snitch)

Для идентификации приложения, которое занимает канал или держит подозрительный порт:

```bash
sudo snitch
# → открывается список процессов: PID, имя, локальный/удаленный адрес
```

*Горячие клавиши:* `/` — фильтрация, `k` — завершить выбранный процесс.

### Мониторинг общей нагрузки на интерфейс (nload)

Быстрая проверка текущей скорости передачи данных:

```bash
nload eth0
# → отображаются графики Incoming и Outgoing трафика
```

### Выявление самых активных потребителей трафика (iftop)

```bash
sudo iftop -i eth0 -n
# → отображается таблица: Local Host <-> Remote Host | Bandwidth
```

*Флаг `-n` отключает DNS-резолвинг для ускорения работы.*

## Дополнительная информация

### Установка инструментов

В дистрибутивах на базе Debian/Ubuntu большинство классических утилит доступны в официальных репозиториях:

```bash
sudo apt update && sudo apt install nload bmon iftop jnettop iptraf-ng tshark
```

**termshark** и **snitch** могут потребовать установки через менеджеры пакетов языков программирования (Go) или скачивания бинарных файлов:

- [Репозиторий termshark](https://github.com/gcla/termshark)
- [Репозиторий snitch](https://github.com/karol-broda/snitch)
