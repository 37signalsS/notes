# Сетевые инструменты CLI и TUI

## Определения

CLI/TUI-инструменты для интерактивного мониторинга сетевой активности, анализа соединений и управления сокетами в реальном времени.

## Основные концепции

### Классификация

| Инструмент | Тип | Назначение |
| :--- | :--- | :--- |
| **[termshark](#termshark-tui)** | TUI | Глубокий анализ трафика (аналог Wireshark в терминале) |
| **[snitch](#snitch-tui)** | TUI | Сокеты + процессы, kill из интерфейса |
| **[iftop](#iftop)** | CLI/TUI | Трафик по соединениям (как `top` для сети) |
| **[nload](#nload-bmon)** | TUI | Общая нагрузка на интерфейс (ASCII-графики) |
| **[bmon](#nload-bmon)** | TUI | Статистика по пакетам, ошибкам, графики |
| **[iptraf-ng](#iptraf-ng)** | TUI | Комбайн: интерфейсы, протоколы, соединения |
| **[jnettop](#jnettop)** | CLI/TUI | Группировка соединений по хосту/порту |

### termshark (TUI)

TUI-интерфейс для `tshark` с возможностями Wireshark. Требует установленный `tshark` как зависимость.

**Возможности:**

- Анализ `.pcap`/`.pcapng` файлов
- Сниффинг интерфейсов в реальном времени
- Display filters Wireshark
- Просмотр TCP/UDP стримов и conversations

```bash
# Анализ pcap-файла
termshark -r dump.pcap

# Сниффинг интерфейса
sudo termshark -i eth0

# С фильтром захвата
sudo termshark -i eth0 -f "tcp port 80"
```

Установка: `sudo apt install termshark` (Debian/Ubuntu), `brew install termshark` (macOS). [Репозиторий termshark](https://github.com/gcla/termshark).

### snitch (TUI)

«htop для сети» — отображает PID и имя процесса для каждого сокета, разделяет `LISTEN`/`ESTABLISHED`, позволяет завершить процесс из интерфейса.

**Горячие клавиши:** `/` — поиск, `k` — kill процесса, `Enter` — детали соединения.

Установка: `brew install snitch` (macOS), `go install github.com/karol-broda/snitch@latest` (Linux). [Репозиторий snitch](https://github.com/karol-broda/snitch).

### iftop

Отображает таблицу активных соединений, отсортированную по объёму трафика. Показывает, какие хосты генерируют наибольшую нагрузку.

### nload / bmon

Показывают скорость приёма (incoming) и передачи (outgoing) данных в виде ASCII-графиков.

- **nload** — прост в использовании, быстрая оценка общей нагрузки.
- **bmon** — больше деталей: статистика по пакетам, ошибкам, графики за более длительный период.

### iptraf-ng

Мощный интерактивный инструмент с TUI-меню: общая и детальная статистика по интерфейсам, статистика по протоколам (IP, TCP, UDP, ICMP), мониторинг соединений и статистика по размерам пакетов.

### jnettop

Показывает активные соединения, сгруппированные **по хосту и порту** — помогает быстро определить, какой сервис на каком хосте генерирует трафик.

## Практические сценарии

### Поиск процесса по сокету (snitch)

```bash
sudo snitch
```

- `/` — поиск и фильтрация
- `k` — завершить процесс
- `Enter` — просмотр деталей соединения

### Быстрая оценка нагрузки на интерфейс (nload)

```bash
nload eth0
```

Показывает текущую скорость входящего/исходящего трафика на интерфейсе `eth0`.

### Анализ pcap-файла (termshark)

```bash
termshark -r capture.pcap
```

Полноценный анализ захвата трафика в терминале с поддержкой фильтров Wireshark.

## Дополнительная информация

### Установка классических утилит (Debian/Ubuntu)

```bash
sudo apt install nload bmon iftop jnettop iptraf-ng
```
