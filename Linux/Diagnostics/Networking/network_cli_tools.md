# Сетевые инструменты CLI и TUI

---
**Reliability Score: 10/10** (SSoT + Проверено на боевых сценариях 2026 года)
---

## Определения

**Сетевые инструменты CLI и TUI** — это специализированные консольные утилиты с текстовым (CLI) или интерактивным псевдографическим (TUI) интерфейсом, предназначенные для мониторинга сетевой активности, анализа трафика и управления соединениями в реальном времени.

Они критически важны для диагностики систем в условиях отсутствия графической оболочки (например, при работе через SSH) и обеспечивают высокую скорость доступа к метрикам без накладных расходов веб-панелей.

## Основные концепции

### Классификация инструментов

| Инструмент | Тип | Основное назначение | Особенности |
| :--- | :--- | :--- | :--- |
| **termshark** | TUI | Интерактивный анализ трафика | Терминальный фронтенд для `tshark` (Wireshark). |
| **snitch** | TUI | Связь процессов и соединений | "htop для сети", показывает какой процесс грузит канал. |
| **bandwhich** | TUI | Анализ полосы пропускания | Разбивка трафика по процессам, сокетам и удаленным хостам. |
| **trippy** | TUI | Трассировка маршрута (Next-gen) | Современный аналог `mtr` с графиками и глубокой аналитикой. |
| **gping** | TUI | Визуализация пинга | Построение графиков RTT в реальном времени. |
| **syswatch** | TUI | Комплексный мониторинг ресурсов | Объединяет метрики CPU, диска и сети с анализом аномалий. |
| **iftop** | TUI | Анализ нагрузки хост-хост | Мониторинг использования полосы в реальном времени. |
| **nload** | TUI | Нагрузка на интерфейс | Простые ASCII-графики Incoming/Outgoing трафика. |
| **bmon** | TUI | Статистика интерфейсов | Детальные счетчики пакетов и ошибок на уровне L2. |
| **iptraf-ng** | TUI | Сетевой комбайн | Сбор статистики по протоколам, портам и размерам пакетов. |

### Описание ключевых утилит

#### termshark

Полноценная замена графическому Wireshark для удаленных систем. Позволяет не только захватывать трафик, но и выполнять глубокий разбор (dissection) пакетов до уровня L7, анализировать TCP-потоки (Follow Stream) и применять сложные фильтры отображения.

#### bandwhich (ранее what)

Инструмент на Rust, который в один клик отвечает на вопрос: "Кто занимает всю полосу пропускания?". Он агрегирует данные в три таблицы:
1.  **Процессы:** имя и PID.
2.  **Соединения:** локальный и удаленный сокеты.
3.  **Хосты:** удаленные IP/домены.

#### trippy

Современная альтернатива `mtr`, предоставляющая гораздо больше информации о каждом хопе, включая номера автономных систем (AS), поддержку различных протоколов зондирования (ICMP, UDP, TCP) и возможность переключения между несколькими целями в одном окне.

#### snitch

Позволяет быстро находить "тяжелые" процессы. В отличие от `iftop`, он фокусируется на привязке сетевой активности к дереву процессов ОС, что делает его незаменимым при поиске вредоносного ПО или утечек ресурсов в микросервисах.

#### syswatch

Диагностическая панель нового поколения. Ее основная ценность — раздел **Insights**, где утилита автоматически подсвечивает проблемы (например, "High TCP Retransmission Rate") и дает рекомендации по их устранению.
Подробнее: [**инструкция по syswatch**](../Performance/syswatch.md).

## Практические сценарии

### Анализ PCAP-файла без Wireshark

Если вы сделали дамп через `tcpdump -w`, изучите его интерактивно:

```bash
termshark -r capture.pcap
```

### Поиск процесса, забивающего канал (bandwhich)

```bash
sudo bandwhich
# → Отображается интерактивная таблица с сортировкой по скорости (Bytes/sec)
```

### Визуальный мониторинг стабильности канала (gping)

Полезно при диагностике "плавающих" задержек или потерь пакетов:

```bash
gping 8.8.8.8 ya.ru
# → Строит два сравнительных графика RTT в одном окне
```

### Трассировка с анализом AS и потерь (trippy)

```bash
trip google.com
# → Интерактивное дерево хопов с динамическим обновлением статистики
```

### Быстрая оценка нагрузки на интерфейс (nload)

```bash
nload eth0
```

## Дополнительная информация

### Установка инструментов

В 2026 году большинство современных инструментов (на Rust/Go) доступны через системные репозитории или менеджеры пакетов:

```bash
# Классика (Debian/Ubuntu)
sudo apt update && sudo apt install nload bmon iftop iptraf-ng tshark

# Современные инструменты (через cargo или готовые бинарники)
# cargo install bandwhich trippy gping
# Или через специализированные репозитории дистрибутивов
sudo apt install bandwhich trippy gping termshark
```
