# Сетевые инструменты CLI и TUI

## Определения

**Сетевые инструменты CLI и TUI** — это специализированные консольные утилиты с текстовым (CLI) или интерактивным псевдографическим (TUI) интерфейсом, предназначенные для мониторинга сетевой активности, анализа трафика и управления соединениями в реальном времени.

Они критически важны для диагностики систем в условиях отсутствия графической оболочки (например, при работе через SSH) и обеспечивают высокую скорость доступа к метрикам без накладных расходов веб-панелей.

## Основные концепции

### Классификация инструментов

| Инструмент | Тип | Основное назначение | Особенности |
| :--- | :--- | :--- | :--- |
| **termshark** | TUI | Интерактивный анализ трафика | Терминальный фронтенд для `tshark` (Wireshark). |
| **snitch** | TUI | Связь процессов и соединений | Показывает, какой процесс инициировал соединение. |
| **bandwhich** | TUI | Анализ полосы пропускания | Разбивка трафика по процессам, сокетам и удаленным хостам. |
| **trippy** | TUI | Трассировка маршрута (Next-gen) | Аналог `mtr` с графиками и глубокой аналитикой. |
| **gping** | TUI | Визуализация пинга | Построение графиков RTT (Round-Trip Time — время приёма-передачи) в реальном времени. |
| **syswatch** | TUI | Комплексный мониторинг | Объединяет метрики системы с анализом аномалий. |
| **sniffnet** | TUI | Мониторинг трафика | Визуализация статистики по приложениям и странам. |
| **doggo** | CLI | DNS-клиент | Современная и наглядная замена `dig`. |
| **xh** | CLI | HTTP-клиент | Быстрая и дружелюбная альтернатива `curl` (на Rust). |
| **iftop** | TUI | Анализ хост-хост | Мониторинг использования полосы в реальном времени. |
| **nethogs** | TUI | Анализ по процессам | Потребление сети в разрезе PID/приложений. |
| **nload** | TUI | Нагрузка на интерфейс | Простые ASCII-графики Incoming/Outgoing трафика. |
| **slurm** | TUI | Мониторинг интерфейса | Наглядная визуализация нагрузки на конкретный сетевой интерфейс. |
| **bmon** | TUI | Статистика L2 | Детальные счетчики пакетов и ошибок на уровне L2. |
| **tcptrack** | TUI | Отслеживание TCP-сессий | Отображает активные TCP-соединения и их скорость. |
| **iptraf-ng** | TUI | Сетевой комбайн | Сбор статистики по протоколам, портам и размерам пакетов. |

### Описание ключевых утилит

#### termshark

Полноценная замена графическому Wireshark для удаленных систем.
- **Возможности:** захват трафика, глубокий разбор (dissection) до L7, анализ TCP-потоков (Follow Stream).
- **Фильтрация:** поддерживает мощный синтаксис фильтров `tshark/wireshark`.

#### bandwhich (ранее what)

Инструмент на Rust, агрегирующий данные в три таблицы:
1.  **Процессы:** имя и PID (требует `sudo` для привязки к процессам).
2.  **Соединения:** локальный и удаленный сокеты.
3.  **Хосты:** удаленные IP/домены.

#### trippy

Современная альтернатива `mtr`. Предоставляет информацию о хопах, номерах автономных систем (AS), поддерживает ICMP, UDP и TCP зондирование.
Подробнее: [**traceroute и mtr**](./traceroute_mtr.md).

#### sniffnet

Современный монитор трафика с упором на визуализацию. Позволяет быстро увидеть распределение трафика по протоколам (HTTP, TLS, DNS) и географии (страны назначения), что полезно для поиска нежелательной активности.

#### doggo

DNS-утилита с поддержкой DoH (DNS over HTTPS) и DoT (DNS over TLS). Выводит результаты в наглядных таблицах или JSON, упрощая отладку записей.

#### xh

Альтернатива `curl` и `httpie`. Основные преимущества: подсветка синтаксиса "из коробки", автоматическое определение типа контента и удобный синтаксис передачи JSON-данных.

#### syswatch

Диагностическая панель "первого взгляда". Автоматически подсвечивает проблемы в разделе **Insights** (например, "High TCP Retransmission Rate").
Подробнее: [**инструкция по syswatch**](../Performance/syswatch.md).

#### snitch

Позволяет быстро находить "тяжелые" процессы. Он фокусируется на привязке сетевой активности к дереву процессов ОС, что делает его незаменимым при поиске утечек ресурсов или подозрительных соединений.

#### iftop

Аналог `top` для сетевых интерфейсов. Показывает bandwidth между парами хостов в реальном времени, что удобно для быстрого ответа на вопрос «кто ест канал».

```bash
# Базовый запуск
sudo iftop -i eth0

# Без DNS-резолва (быстрее)
sudo iftop -n -i eth0

# Фильтр по порту
sudo iftop -f "port 22" -i eth0
```

**Когда выбирать:** нужно понять, между какими хостами утекает полоса пропускания, и сделать это за одну команду без захвата пакетов.

#### nethogs

Утилита показывает потребление сети по процессам, а не по соединениям. Отвечает на вопрос «какое приложение ест канал», а не «какой хост».

```bash
# Показать все процессы с сетевой активностью
sudo nethogs

# Фильтр по интерфейсу
sudo nethogs eth0
```

**Когда выбирать:** нагрузка не в CPU, а в сети, и нужно найти конкретный процесс-виновника. Работает даже при тысячах соединений, не создавая задержек на парсинге.

## Практические сценарии

### Анализ PCAP-файла без Wireshark (termshark)

Если вы сделали дамп через `tcpdump -w`, изучите его интерактивно:

```bash
termshark -r capture.pcap
```

### Поиск процесса, забивающего канал (bandwhich)

```bash
sudo bandwhich
# → Клавиша 'Tab' переключает фокус между таблицами процессов, соединений и хостов
```

### Мониторинг конкретной TCP-сессии (tcptrack)

Полезно для отслеживания скорости скачивания конкретного файла или работы приложения:

```bash
sudo tcptrack -i eth0
# → Список активных соединений с колонкой 'Rate'
```

### Визуальный мониторинг задержек (gping)

Удобно для выявления кратковременных всплесков или потерь пакетов:

```bash
gping 8.8.8.8 ya.ru
# → Строит сравнительные графики RTT (Round-Trip Time — время приёма-передачи) в одном окне
```
Подробнее о TCP-пинге: [**Альтернативы ping**](../../../Networking/Troubleshooting/ping_alternatives.md).

### Быстрая DNS-проверка с табличным выводом (doggo)

```bash
doggo google.com MX --nameserver 1.1.1.1
```

### Отправка JSON-запроса через xh

```bash
xh POST httpbin.org/post name=gemini status=active
# → Автоматически формирует JSON и добавляет нужные заголовки
```

## Дополнительная информация

### Установка инструментов

В современных дистрибутивах большинство инструментов доступны через системные репозитории:

```bash
# Классика и TUI-комбайны (Debian/Ubuntu)
sudo apt update && sudo apt install nload bmon iftop iptraf-ng tcptrack slurm tshark

# Современные инструменты (часто требуют Cargo или отдельные репозитории)
# cargo install bandwhich trippy gping sniffnet doggo xh
sudo apt install bandwhich trippy gping termshark xh doggo
```
