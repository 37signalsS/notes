# Сетевые инструменты CLI и TUI

## Определения

В этом разделе собраны интерактивные (TUI) и командные (CLI) инструменты для мониторинга сетевой активности, анализа соединений и управления сокетами.

## Основные инструменты

### 1. `termshark` (TUI) — Wireshark в терминале

`termshark` — это TUI-интерфейс для `tshark`, предоставляющий возможности Wireshark прямо в терминале. Работает через движок Wireshark, что обеспечивает полную совместимость с фильтрами и функциями анализа.

* **Назначение:** Глубокий анализ сетевого трафика на удалённых серверах без GUI.
* **Возможности:**
  * Открытие и анализ `.pcap`/`.pcapng` файлов
  * Сниффинг интерфейсов в реальном времени
  * Поддержка display filters из Wireshark
  * Просмотр TCP/UDP стримов
  * Анализ network conversations по протоколам
  * Копирование диапазонов пакетов
* **Установка:**
  ```bash
  # Debian/Ubuntu
  sudo apt install termshark
  
  # macOS (Homebrew)
  brew install termshark
  
  # Arch Linux
  sudo pacman -S termshark
  ```
* **Использование:**
  ```bash
  # Анализ pcap-файла
  termshark -r dump.pcap
  
  # Сниффинг интерфейса в реальном времени
  sudo termshark -i eth0
  
  # С фильтром захвата (как в tcpdump)
  sudo termshark -i eth0 -f "tcp port 80"
  ```
* **Особенности:**
  * Навигация клавишами (стрелки, Tab, Enter)
  * Горячие клавиши аналогичны Wireshark (`/` — поиск, `Ctrl+S` — сохранить)
  * Требует установленный `tshark` (зависимость)
* **[Репозиторий termshark](https://github.com/gcla/termshark)**

### 2. `snitch` (TUI) — "htop для сети"

`snitch` предоставляет наглядный интерфейс для управления сетевыми сокетами и связанными с ними процессами.

* **Назначение:** Быстрый поиск процессов, владеющих портами, и мониторинг их соединений.
* **Особенности:**
  * Отображение PID и имени процесса для каждого сокета.
  * Разделение на `LISTEN` и `ESTABLISHED` соединения.
  * Возможность завершить (kill) процесс прямо из интерфейса.
  * Фильтрация по TCP/UDP, портам и именам.

### 3. `iftop` — "top" для сетевых соединений

Подобно `top` для процессов, `iftop` слушает трафик на указанном интерфейсе и отображает таблицу активных соединений, отсортированную по объему трафика. Это позволяет быстро определить, какие хосты генерируют наибольшую сетевую нагрузку.

### 4. `iptraf-ng` — Комбайн для анализа

Мощный интерактивный инструмент с TUI-меню, предоставляющий несколько режимов мониторинга: общую и детальную статистику по интерфейсам, статистику по протоколам (IP, TCP, UDP, ICMP), мониторинг соединений и статистику по размерам пакетов.

## Практические сценарии

### Использование `snitch`

#### Установка

```bash
# macOS (Homebrew)
brew install snitch

# Linux (Go)
go install github.com/karol-broda/snitch@latest
```

#### Основные действия

Запустите утилиту с правами суперпользователя:

```bash
sudo snitch
```

* **/** (слеш): Поиск и фильтрация.
* **k**: Завершить (kill) выбранный процесс.
* **Enter**: Просмотр деталей соединения.

### Базовая визуализация трафика (`nload`, `bmon`)

Эти утилиты показывают текущую скорость приёма (incoming) и передачи (outgoing) данных на сетевых интерфейсах в виде ASCII-графиков.

* **`nload`**: Очень прост в использовании, идеально подходит для быстрой оценки общей нагрузки.
* **`bmon`**: Предоставляет больше деталей, включая статистику по пакетам, ошибкам и график за более длительный период.

### Группировка трафика (`jnettop`)

`jnettop` показывает активные соединения, но группирует их **по хосту и порту**. Это помогает быстро понять, какой сервис на каком хосте больше всего "общается" по сети.

### Установка классических утилит (Debian/Ubuntu)

```bash
sudo apt install nload bmon iftop jnettop iptraf-ng
```
