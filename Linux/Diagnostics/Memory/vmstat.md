# vmstat — статистика виртуальной памяти

## Определения

`vmstat` (Virtual Memory Statistics) — стандартная утилита командной строки (входит в пакет `procps-ng`), предназначенная для оперативного мониторинга состояния ресурсов системы. Она агрегирует данные о процессах, использовании оперативной памяти, активности подкачки (swap), операциях ввода-вывода (I/O), системных прерываниях и загрузке центрального процессора.

## Основные концепции

### Особенности работы

- **Средние значения:** Первая строка после заголовка в выводе `vmstat` всегда содержит средние значения с момента последней загрузки системы (uptime).
- **Интервальный режим:** Если указан числовой параметр (например, `vmstat 1`), последующие строки будут отражать статистику за этот конкретный интервал времени.
- **Источники данных:** Утилита берет информацию напрямую из интерфейсов ядра в `/proc` (в частности, `/proc/meminfo`, `/proc/stat`, `/proc/vmstat`).

### Расшифровка полей вывода

- **procs (Процессы):**
  - `r` (runnable): Количество процессов, ожидающих процессорного времени (очередь выполнения). Высокие значения указывают на перегрузку CPU.
  - `b` (blocked): Процессы в состоянии "непрерываемого сна" (uninterruptible sleep). Обычно это ожидание дискового I/O или блокировок ядра.
- **memory (Память):**
  - `swpd`: Объем используемой памяти в разделе подкачки (swap).
  - `free`: Объем полностью свободной оперативной памяти.
  - `buff`: Память, выделенная под буферы (метаданные ФС, заголовки).
  - `cache`: Память, используемая под страничный кэш (содержимое файлов).
- **swap (Подкачка):**
  - `si` (swap-in): Скорость чтения данных из swap в RAM (КБ/с).
  - `so` (swap-out): Скорость выгрузки данных из RAM в swap (КБ/с).
- **io (Ввод-вывод):**
  - `bi` (blocks in): Блоков, считанных с диска (блоков/с).
  - `bo` (blocks out): Блоков, записанных на диск (блоков/с).
- **system (Система):**
  - `in`: Количество прерываний (interrupts) в секунду.
  - `cs`: Количество переключений контекста (context switches) в секунду.
- **cpu (Процессор):**
  - `us`: Время выполнения пользовательского кода.
  - `sy`: Время выполнения кода ядра.
  - `id`: Время простоя (idle).
  - `wa`: Время ожидания завершения ввода-вывода (I/O wait).
  - `st`: "Украденное" время (steal time) — время, когда ВМ хотела выполняться, но гипервизор не выделил ресурсы.

## Практические сценарии

### Мониторинг активной и неактивной памяти (-a)

Позволяет понять, какая часть кэша и памяти реально используется процессами, а какая может быть безболезненно вытеснена ядром.

```bash
# Показать активную (active) и неактивную (inactive) память
vmstat -a 1
```

### Диагностика производительности по паттернам

| Симптом | Метрики | Вероятная причина |
| :--- | :--- | :--- |
| **CPU Saturation** | `r` > ядер CPU, `us` + `sy` ≈ 100 | Нехватка вычислительных ресурсов |
| **Memory Thrashing** | Постоянные `si` > 0 и `so` > 0 | Критическая нехватка RAM, активный свопинг |
| **I/O Bottleneck** | `b` > 0, `wa` > 20%, высокие `bi`/`bo` | Медленная дисковая подсистема |
| **Context Switching** | `cs` значительно больше `in` | Слишком много конкурирующих потоков или процессов |

### Просмотр счетчиков событий (-s)

Выводит таблицу всех накопленных системных счетчиков (количество форков, переключений контекста, обращений к диску и т.д.).

```bash
# Сводная таблица счетчиков
vmstat -s
```

### Анализ использования Slab-аллокатора (-m)

Позволяет увидеть, какие структуры данных ядра (кэши объектов) потребляют память. Требует прав **root**.

```bash
# Информация о кэшах ядра
sudo vmstat -m
```

## Дополнительная информация

### Удобство чтения и единицы измерения

- `-S M`: Выводить данные в мегабайтах (вместо КБ).
- `-t`: Добавить временную метку (timestamp) к каждой строке вывода.

### Сравнение с современными инструментами

Хотя `vmstat` остается стандартом, для современных ядер Linux (4.20+) рекомендуется также обращать внимание на **PSI (Pressure Stall Information)**, который показывает реальное время ожидания процессами ресурсов (CPU, Memory, I/O), а не просто наличие очередей.
