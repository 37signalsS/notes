# `vmstat`

## Определения

`vmstat` (Virtual Memory Statistics) — это утилита командной строки, которая предоставляет сводную информацию о процессах, памяти, подкачке (swap), вводе-выводе (I/O), системных прерываниях и активности процессора. Это один из классических инструментов для быстрого обзора состояния системы.

## Основные концепции

`vmstat` выводит данные в виде одной строки с усредненными значениями с момента загрузки системы или с момента предыдущего замера. При запуске с числовым аргументом (например, `vmstat 1`), он переходит в режим периодического обновления, показывая статистику за указанный интервал.

**Ключевые области вывода:**

- **`procs`**: Статистика по процессам.
  - `r`: Количество процессов, ожидающих выполнения (run queue).
  - `b`: Количество процессов в состоянии непрерываемого сна (uninterruptible sleep), обычно ожидающих I/O.
- **`memory`**: Статистика по памяти.
  - `swpd`: Объем используемой виртуальной памяти (swap).
  - `free`: Объем свободной памяти.
  - `buff`: Память, используемая под буферы.
  - `cache`: Память, используемая под кэш страниц.
- **`swap`**: Активность подкачки.
  - `si` (swap-in): Объем памяти, загруженный из swap в RAM (в КБ/с).
  - `so` (swap-out): Объем памяти, выгруженный из RAM в swap (в КБ/с).
- **`io`**: Активность блочных устройств.
  - `bi`: Блоков прочитано с блочных устройств (блоков/с).
  - `bo`: Блоков записано на блочные устройства (блоков/с).
- **`system`**: Системные события.
  - `in`: Количество прерываний в секунду.
  - `cs`: Количество переключений контекста в секунду.
- **`cpu`**: Использование процессорного времени (в процентах).
  - `us`: Пользовательское время.
  - `sy`: Системное (ядро) время.
  - `id`: Время простоя (idle).
  - `wa`: Время ожидания I/O.
  - `st`: "Украденное" время (для виртуальных машин).

## Практические сценарии

### Мониторинг в реальном времени

```bash
# Выводить статистику каждую секунду
vmstat 1

# Выводить статистику каждые 2 секунды, 5 раз
vmstat 2 5
```

### Диагностика нехватки памяти

Постоянно ненулевые значения в колонках `si` и `so` являются главным признаком того, что системе не хватает оперативной памяти и она вынуждена активно использовать swap-раздел.

- **Высокое значение `so` (swap-out):** Система активно выгружает данные из RAM на диск.
- **Высокое значение `si` (swap-in):** Система вынуждена читать ранее выгруженные данные обратно в RAM, что приводит к значительным задержкам.

### Диагностика проблем с I/O

- **Высокое значение `wa` в секции `cpu`:** Процессор простаивает, ожидая завершения операций ввода-вывода.
- **Высокие значения `bi` и `bo`:** Указывают на интенсивный обмен данными с дисками.
- **Большое число в колонке `b` (blocked processes):** Множество процессов "застряли" в ожидании I/O.

## Дополнительная информация

### Отображение в мегабайтах

```bash
vmstat -S M 1
```

### Расширенная статистика

Флаг `-a` (`--active`) показывает активную и неактивную память вместо буферов и кэша.

```bash
vmstat -a 1
```

### Статистика по дискам

Флаг `-d` (`--disk`) выводит детальную статистику по каждому дисковому разделу.

```bash
vmstat -d
```

### Взаимосвязь с другими инструментами

`vmstat` эффективен в связке с другими утилитами диагностики памяти: [`/proc/meminfo`](./proc_meminfo.md) предоставляет детальную статистику на текущий момент, тогда как `vmstat` показывает усреднённую динамику. Если `vmstat` выявил проблему (активный swap), [`pmap`](./pmap.md) помогает найти процесс-виновника, а [`smem`](./smem.md) — точно определить его потребление памяти с учётом PSS/USS.
