# `smem`

## Определения

`smem` — это продвинутая утилита для анализа использования оперативной памяти в Linux. Её ключевое преимущество перед другими инструментами (`top`, `ps`) заключается в более точном подсчёте памяти, потребляемой процессами, за счёт корректного учёта разделяемой памяти.

## Основные концепции

`smem` предоставляет три ключевые метрики потребления памяти процессами:

- **USS (Unique Set Size)** — уникальная память процесса (освободится после его завершения)
- **PSS (Proportional Set Size)** — пропорциональная доля памяти с учётом разделяемых библиотек
- **RSS (Resident Set Size)** — физическая память, занимаемая процессом в RAM

> **Важно:** Подробное описание метрик, их значений и сценариев использования см. в [Метрики потребления памяти процесса](../../Core/memory/process_memory_metrics.md).

## Практические сценарии

### Отчёт по процессам

```bash
# Показать отчёт по всем запущенным процессам, отсортированный по PSS
# Ключ -p включает отображение в процентах
smem -p
```

### Группировка по пользователям и процессам

```bash
# Показать суммарное потребление памяти для каждого пользователя
smem -u

# Показать потребление памяти для конкретного процесса (например, nginx)
smem -P nginx
```

### Системный отчёт

```bash
# Показать общую статистику по системе, включая кэш и память ядра
smem -w
```

### Сортировка и фильтрация

```bash
# Показать процессы, принадлежащие пользователю www-data, отсортированные по USS
smem -u www-data -s uss

# Показать процессы, отсортированные по RSS
smem -s rss
```

## Дополнительная информация

### Графическое представление

`smem` умеет выводить данные в виде диаграмм прямо в консоли.

```bash
# Построить круговую диаграмму использования памяти процессами по PSS
smem --pie name -c "pss"

# Построить столбчатую диаграмму использования памяти по PSS
smem --bar name -c "pss"
```

### Форматирование вывода

#### Флаг `-k` (abbreviate)

Флаг `-k` включает отображение суффиксов единиц измерения (K, M, G) для удобного чтения вместо байтов:

```bash
# Без флага -k (значения в байтах)
smem
#  2054 magi     sleep infinity                 81920     4096    10240   757760

# С флагом -k (значения с суффиксами)
smem -k
#  2054 magi     sleep infinity                 80.0K     4.0K    10.0K   740.0K
```

#### Другие полезные флаги

| Флаг | Описание |
| :--- | :--- |
| `-t`, `--totals` | Показывать итоговые суммы |
| `-p`, `--percent` | Показывать проценты |
| `-r`, `--reverse` | Обратная сортировка |
| `-s SORT`, `--sort=SORT` | Поле для сортировки (`uss`, `pss`, `rss`, `swap`) |
| `-c COLUMNS`, `--columns=COLUMNS` | Указать колонки для отображения |
| `-H`, `--no-header` | Отключить заголовок |
| `-a`, `--autosize` | Автоматический подбор ширины колонок |
| `-n`, `--numeric` | Показывать числовые UID вместо имён пользователей |

#### Специальные опции

| Флаг | Описание |
| :--- | :--- |
| `-K KERNEL`, `--kernel=KERNEL` | Путь к образу ядра для включения его памяти в системный отчёт (`-w`) |
| `-R REALMEM`, `--realmem=REALMEM` | Объём физической RAM для учёта памяти firmware/hardware |
| `-S SOURCE`, `--source=SOURCE` | Альтернативный источник данных (например, дамп от `smemcap`) |

### Работа с правами доступа

#### Без root (обычный пользователь)

```bash
smem
```

- Видны **только процессы текущего пользователя**
- PSS/USS считаются только для доступных процессов
- Процессы других пользователей не отображаются

#### С root (sudo)

```bash
sudo smem
```

- Видны **все процессы в системе**
- Полный доступ к `/proc/<pid>/smaps` для всех процессов
- Точные метрики PSS/USS для всей системы

**Почему требуются права:** `smem` читает файлы `/proc/<pid>/smaps`, которые содержат детальную информацию о памяти и доступны только владельцу процесса или root.

**Примеры с sudo:**

```bash
# Полный системный отчёт
sudo smem -w

# Отчёт по всем пользователям
sudo smem -u

# Фильтрация процессов с полным доступом
sudo smem --processfilter="nginx"
```
