# pmap — карта памяти процесса

## Определения

`pmap` (Process Memory Map) — это утилита командной строки, предназначенная для отображения подробной карты памяти указанного процесса. Она позволяет визуализировать структуру виртуального адресного пространства процесса, включая сегменты кода, данных, стека, кучи и загруженные разделяемые библиотеки.

## Основные концепции

`pmap` агрегирует и форматирует данные из файлов ядра `/proc/<PID>/maps` и `/proc/<PID>/smaps`. Каждый "маппинг" (отображение) в выводе представляет собой непрерывный диапазон виртуальных адресов.

Ключевые атрибуты каждого сегмента:

- **Address:** Начальный виртуальный адрес сегмента.
- **Kbytes:** Размер сегмента в килобайтах.
- **RSS (Resident Set Size):** Объём физической памяти, фактически занимаемый данным сегментом.
- **Dirty:** Объём изменённых страниц в памяти, которые ещё не были синхронизированы с диском (для файловых маппингов).
- **Mode:** Права доступа к сегменту (`r` — чтение, `w` — запись, `x` — исполнение, `s` — разделяемый, `p` — приватный/copy-on-write).
- **Mapping:** Источник сегмента (имя файла библиотеки, исполняемый файл или служебные метки `[anon]`, `[stack]`, `[heap]`).

> **См. также:**
>
> - Подробное описание метрик памяти (RSS, PSS, USS, VSS) — в [Метрики потребления памяти процесса](../../Core/memory/process_memory_metrics.md).
> - Продвинутый анализ памяти с учётом PSS/USS по всей системе — в [`smem`](./smem.md).

## Практические сценарии

### Базовая карта памяти

Позволяет быстро увидеть распределение адресного пространства.

```bash
# Показать базовую карту памяти для процесса
pmap <PID>

# Пример вывода:
# 000055799988a000    148K r-x-- bash
# 0000557999aa5000      4K r---- bash
# ...
# total            14040K
```

### Расширенный формат (-x)

Предоставляет информацию о потреблении физической памяти (RSS) и "грязных" страницах. Это наиболее часто используемый режим для диагностики.

```bash
# Показать расширенную информацию
pmap -x <PID>

# Пример вывода:
# Address           Kbytes     RSS   Dirty Mode  Mapping
# 000055799988a000     148     148       0 r-x-- bash
# ...
# total kB           14040    3456     512
```

### Максимальная детализация (-X)

Выводит детальные метрики, включая PSS (Proportional Set Size), аналогично содержимому `smaps`. Доступно в современных версиях `procps-ng`.

```bash
# Показать максимально подробную информацию
pmap -X <PID>
```

Это позволяет точно оценить вклад процесса в общее потребление памяти системы с учётом разделяемых библиотек.

## Дополнительная информация

### Поиск утечек памяти

`pmap` полезен для первичной диагностики утечек в куче. Если при повторных запусках `pmap -x <PID>` наблюдается постоянный рост размера сегмента `[anon]` (анонимная память) или `[heap]`, это явный признак того, что приложение выделяет память и не освобождает её.

### Анализ зависимостей и библиотек

Утилита наглядно показывает, какие версии разделяемых библиотек (`.so`) реально загружены в память процесса. Это помогает выявить:

- Загрузку неверных версий библиотек.
- Избыточное потребление памяти специфическими плагинами или модулями.

### Взаимодействие с системными метриками

В то время как [`/proc/meminfo`](./proc_meminfo.md) предоставляет глобальную картину состояния памяти сервера, `pmap` служит для "погружения" в конкретный процесс, который был идентифицирован как проблемный с помощью `top` или [`vmstat`](./vmstat.md).
