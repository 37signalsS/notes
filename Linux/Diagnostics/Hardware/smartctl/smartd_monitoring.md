# Автоматический мониторинг дисков с smartd

## Определения

**`smartd`** — демон из пакета `smartmontools` для автоматического мониторинга S.M.A.R.T.-атрибутов накопителей и отправки уведомлений при обнаружении проблем. Конфигурируется через `/etc/smartd.conf`.

Подробнее о концепциях S.M.A.R.T. и ключевых атрибутах см. [smart_concepts](./smart_concepts.md).

## Основные концепции

### Конфигурационный файл

**Путь:** `/etc/smartd.conf`

### Параметры smartd

| Параметр | Описание |
|----------|----------|
| `-H` | Проверка здоровья диска |
| `-f` | Проверка атрибутов failure |
| `-t` | Проверка всех атрибутов |
| `-l error` | Мониторинг журнала ошибок |
| `-l selftest` | Мониторинг журналов самотестирования |
| `-m` | Email для уведомлений |
| `-M onchange` | Отправлять только при изменении статуса |
| `-M daily` | Отправлять ежедневные отчёты |

### Типовые конфигурации

```bash
# Мониторить все диски с отправкой email при проблемах
DEVICESCAN -H -m admin@example.com

# Мониторить конкретный диск с проверкой всех атрибутов
/dev/sda -H -f -t -l error -l selftest -m admin@example.com

# Мониторить NVMe диск
/dev/nvme0n1 -H -m admin@example.com

# Отправка email только при изменении статуса
/dev/sda -H -m admin@example.com -M onchange

# Отправка email при любом событии
/dev/sda -H -m admin@example.com -M daily
```

## Практические сценарии

### Запуск и управление smartd

```bash
# Запуск демона
sudo systemctl enable --now smartd

# Проверка статуса
sudo systemctl status smartd

# Просмотр логов
journalctl -u smartd -f

# Тестовое уведомление
sudo smartctl -t /dev/sda
```

### Диагностика проблем

При ошибках чтения S.M.A.R.T., проблемах с RAID-контроллерами или неполном выводе для NVMe см. [troubleshooting](./troubleshooting.md).

## Дополнительная информация

### Надёжность автоматического мониторинга

`smartd` обеспечивает непрерывный контроль S.M.A.R.T.-атрибутов без ручного вмешательства. Однако S.M.A.R.T. предсказывает ~50-70% отказов — регулярные бэкапы остаются обязательными.

### Связанные инструменты

Ручная проверка здоровья дисков выполняется через [smartctl](./disk_health_check.md). Концепции и атрибуты S.M.A.R.T. описаны в [smart_concepts](./smart_concepts.md). Диагностика сложных проблем — [troubleshooting](./troubleshooting.md).
