# Диагностика дисков с помощью smartctl

## Определения

- **`smartctl`**: Утилита командной строки из пакета `smartmontools`, которая считывает и анализирует данные S.M.A.R.T. с жестких дисков (HDD), твердотельных накопителей (SSD) и NVMe-накопителей. Это основной инструмент для оценки их физического состояния и прогнозирования сбоев.
- **`smartd`**: Демон из пакета `smartmontools`, который автоматически мониторит S.M.A.R.T. атрибуты дисков и отправляет уведомления при обнаружении проблем.
- **S.M.A.R.T. (Self-Monitoring, Analysis, and Reporting Technology)**: Встроенная в накопители система самодиагностики. Она отслеживает множество атрибутов, характеризующих работу диска (например, количество ошибок чтения, переназначенные сектора, температура).
- **NVMe S.M.A.R.T.**: Расширенная спецификация S.M.A.R.T. для NVMe-накопителей с дополнительными метриками (TBW, процент износа, время работы).

## Основные концепции

### Типы накопителей и S.M.A.R.T

| Тип накопителя | Протокол S.M.A.R.T. | Ключевые атрибуты |
|----------------|---------------------|-------------------|
| **HDD (3.5", 2.5")** | ATA/ATAPI S.M.A.R.T. | Reallocated_Sectors, Pending_Sectors, Spin_Retry_Count |
| **SATA SSD** | ATA/ATAPI S.M.A.R.T. | Wear_Leveling, Used_Spare_Block, Total_LBAs_Written |
| **NVMe SSD** | NVMe S.M.A.R.T. | Percentage_Used, Media_Wearout_Indicator, Data_Units_Read |
| **SAS HDD/SSD** | SCSI S.M.A.R.T. | Growndefect, Nonmediumerrors, Programfailcount |

### Ключевые атрибуты для анализа

Высокие или растущие значения следующих атрибутов часто указывают на скорый отказ диска:

#### Для HDD

| Атрибут | ID | Описание | Критичность |
|---------|-----|----------|-------------|
| `Reallocated_Sector_Ct` | 5 | Количество переназначенных секторов | **Высокая** — первый признак деградации |
| `Current_Pending_Sector_Ct` | 197 | Секторы, ожидающие перераспределения | **Высокая** — потенциально плохие сектора |
| `Uncorrectable_Sector_Ct` | 198 | Неисправимые секторы | **Критическая** — необратимые повреждения |
| `Spin_Retry_Count` | 10 | Попытки раскрутки диска | **Высокая** — проблемы с мотором |
| `UDMA_CRC_Error_Count` | 199 | Ошибки интерфейса SATA | **Средняя** — проблемы с кабелем |
| `Power_On_Hours` | 9 | Время работы в часах | Информационный — для оценки возраста |
| `Start_Stop_Count` | 4 | Количество циклов старт/стоп | Информационный |
| `Power_Cycle_Count` | 12 | Количество полных циклов включения | Информационный |

#### Для SSD

| Атрибут | ID | Описание | Критичность |
|---------|-----|----------|-------------|
| `Wear_Leveling_Count` | 177/231 | Степень износа ячеек памяти | **Высокая** —接近 0% = конец срока |
| `Used_Spare_Block` | 179 | Использованные резервные блоки | **Высокая** — резерв исчерпан |
| `Total_LBAs_Written` | 241/242 | Общий объём записанных данных | Информационный — для расчёта TBW |
| `SSD_ProgramFailCount` | 171/173 | Ошибки программирования ячеек | **Высокая** |
| `SSD_EraseFailCount` | 172/174 | Ошибки стирания ячеек | **Высокая** |
| `Power_On_Hours` | 9 | Время работы в часах | Информационный |

#### Для NVMe

| Атрибут | Описание | Критичность |
|---------|----------|-------------|
| `Percentage Used` | Процент использованного ресурса (0-100%) | **Высокая** — 100% = конец срока |
| `Media Wearout Indicator` | Индикатор износа (100-0) | **Высокая** — 0% = конец срока |
| `Available Spare` | Доступный резерв памяти | **Высокая** — 0% = критично |
| `Critical Warning` | Критические предупреждения | **Критическая** |
| `Temperature` | Текущая температура | **Средняя** — перегрев снижает срок |
| `Data Units Read/Written` | Объём прочитанных/записанных данных | Информационный |
| `Power On Hours` | Время работы в часах | Информационный |
| `Power Cycles` | Количество циклов включения | Информационный |

### Интерпретация значений S.M.A.R.T

| Поле | Описание |
|------|----------|
| `VALUE` | Нормализованное значение (обычно 1-253, где 253=отлично, 1=критично) |
| `WORST` | Худшее зафиксированное значение |
| `THRESH` | Пороговое значение, при достижении которого диск считается неисправным |
| `WHEN_FAILED` | Флаг отказа (`-` = ок, `FAILING_NOW` = критично) |
| `RAW_VALUE` | Сырое значение атрибута (интерпретируется производителем) |

**Важно:** `VALUE > THRESH` означает, что диск ещё исправен. При `VALUE <= THRESH` диск считается failing.

## Практические сценарии

### Определение имени диска

```bash
# Список всех дисков
lsblk

# Список SCSI/SATA устройств
lsscsi

# NVMe диски
ls /dev/nvme*
```

**Имена дисков:**

- SATA/SCSI: `/dev/sda`, `/dev/sdb`, `/dev/nvme0n1`
- NVMe: `/dev/nvme0n1`, `/dev/nvme1n1`

### Быстрая проверка здоровья диска

```bash
# Общий статус здоровья (ATA/SATA)
sudo smartctl -H /dev/sda

# Общий статус здоровья (NVMe)
sudo smartctl -H /dev/nvme0n1

# Проверка с автоопределением типа диска
sudo smartctl -a /dev/sda
```

**Возможные результаты:**

- `PASSED` — диск исправен
- `FAILED` — диск неисправен, требуется замена
- `DISK FAILURE IS IMMINENT` — скорый отказ

### Просмотр всех атрибутов S.M.A.R.T

```bash
# Полная информация (ATA/SATA)
sudo smartctl -a /dev/sda

# Полная информация (NVMe)
sudo smartctl -a /dev/nvme0n1

# Только атрибуты
sudo smartctl -A /dev/sda

# С дополнительной информацией о диске
sudo smartctl -i /dev/sda
```

### Запуск тестов самодиагностики

`smartctl` может инициировать встроенные в диск тесты:

| Тип теста | Длительность | Описание |
|-----------|--------------|----------|
| `short` | 2-5 минут | Быстрая проверка электроники и части поверхности |
| `long` | 1-8 часов | Полное сканирование поверхности |
| `conveyance` | 1-5 минут | Тест после транспортировки (не все диски поддерживают) |

```bash
# Запустить короткий тест в фоновом режиме
sudo smartctl -t short /dev/sda

# Запустить длинный тест в фоновом режиме
sudo smartctl -t long /dev/sda

# Посмотреть результаты последнего теста
sudo smartctl -l selftest /dev/sda

# Полная история самопроверок
sudo smartctl -l selftest /dev/sda

# Прервать текущий тест
sudo smartctl -X /dev/sda
```

**Интерпретация результатов самопроверки:**

- `Completed without error` — тест пройден
- `Completed: read failure` — ошибки чтения (bad sectors)
- `Completed: servo failure` — проблемы с сервоприводом
- `Completed: electrical failure` — проблемы с электроникой
- `Aborted by host` — тест прерван пользователем

### Мониторинг ошибок диска

```bash
# Журнал ошибок (ATA)
sudo smartctl -l error /dev/sda

# Журнал ошибок (NVMe)
sudo smartctl -l error /dev/nvme0n1

# Журнал дефектов (grown defects list)
sudo smartctl -l defect /dev/sda

# Статистика по секторам (SATA)
sudo smartctl -l xselftest /dev/sda
```

### Настройка smartd для автоматического мониторинга

**Конфигурационный файл:** `/etc/smartd.conf`

```bash
# Пример конфигурации
# Мониторить все диски с отправкой email при проблемах
DEVICESCAN -H -m admin@example.com

# Мониторить конкретный диск с проверкой всех атрибутов
/dev/sda -H -f -t -l error -l selftest -m admin@example.com

# Мониторить NVMe диск
/dev/nvme0n1 -H -m admin@example.com

# Отправка email только при изменении статуса
/dev/sda -H -m admin@example.com -M onchange

# Отправка email при любом событии
/dev/sda -H -m admin@example.com -M daily
```

### Проверка дисков в RAID-массивах

```bash
# Для аппаратных RAID может потребоваться указание типа контроллера
sudo smartctl -d megaraid,0 -a /dev/sda  # LSI MegaRAID, первый диск
sudo smartctl -d 3ware,0 -a /dev/twe0    # 3ware RAID

# Для soft RAID (mdadm)
sudo smartctl -a /dev/sda  # Проверка физических дисков
```

Подробнее см. [Управление RAID в Linux](../../../FileSystems/raid_management.md).

### Диагностика проблем с производительностью

```bash
# Проверка температуры
sudo smartctl -A /dev/sda | grep -i temperature

# Проверка количества записанных данных (для SSD)
sudo smartctl -A /dev/sda | grep -E "Total_LBAs_Written|Data_Units_Written"

# Проверка износа SSD
sudo smartctl -A /dev/sda | grep -E "Wear_Leveling|Media_Wearout|Percentage_Used"

# Проверка CRC ошибок (проблемы с кабелем SATA)
sudo smartctl -A /dev/sda | grep -i CRC
```

## Диагностика проблем

### Диск не поддерживает S.M.A.R.T

```bash
# Некоторые диски (особенно в RAID или старые) не поддерживают S.M.A.R.T.
# Принудительное включение (может не работать)
sudo smartctl -s on /dev/sda

# Для некоторых RAID-контроллеров требуется указать тип
sudo smartctl -d megaraid,0 -a /dev/sda
```

### Ошибки чтения атрибутов

```bash
# Если smartctl не может прочитать атрибуты
# Проверить поддержку S.M.A.R.T.
sudo smartctl -i /dev/sda

# Проверить логи ядра на ошибки диска
dmesg | grep -i "sd[a-z]"
dmesg | grep -i "I/O error"
```

### NVMe диск показывает неполную информацию

```bash
# Для NVMe дисков используйте специальный формат вывода
sudo smartctl -a /dev/nvme0n1

# Или используйте nvme-cli
sudo nvme smart-log /dev/nvme0n1
sudo nvme health-info /dev/nvme0n1
```

## Дополнительная информация

### Надёжность S.M.A.R.T

| Аспект | Надёжность | Примечания |
|--------|------------|------------|
| **Раннее предупреждение** | Средняя | ~50-70% отказов предсказуемы по S.M.A.R.T. |
| **Reallocated_Sectors** | Высокая | Надёжный индикатор деградации HDD |
| **Wear_Leveling (SSD)** | Высокая | Точно отражает износ флеш-памяти |
| **Temperature** | Средняя | Важно для долгосрочной надёжности |
| **Power_On_Hours** | Высокая | Точные данные о возрасте диска |

**Важно:** S.M.A.R.T. не гарантирует обнаружение всех сбоев. Регулярные бэкапы обязательны.

### Рекомендуемые пороги для замены дисков

| Атрибут | Порог для замены |
|---------|------------------|
| `Reallocated_Sector_Ct` | > 10 и растёт |
| `Current_Pending_Sector_Ct` | > 0 и не уменьшается |
| `UDMA_CRC_Error_Count` | > 100 (проверить кабель) |
| `Wear_Leveling_Count` | < 10% (остаток ресурса) |
| `Percentage Used (NVMe)` | > 90% |
| `Available Spare (NVMe)` | < 10% |
