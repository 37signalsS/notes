# Диагностика дисков с помощью smartctl

## Определения

- **`smartctl`**: Утилита командной строки из пакета `smartmontools`, которая считывает и анализирует данные S.M.A.R.T. с жестких дисков (HDD) и твердотельных накопителей (SSD). Это основной инструмент для оценки их физического состояния и прогнозирования сбоев.
- **S.M.A.R.T. (Self-Monitoring, Analysis, and Reporting Technology)**: Встроенная в накопители система самодиагностики. Она отслеживает множество атрибутов, характеризующих работу диска (например, количество ошибок чтения, переназначенные сектора, температура).

## Основные концепции

### Ключевые атрибуты для анализа

Высокие или растущие значения следующих атрибутов часто указывают на скорый отказ диска:

- **`Reallocated_Sectors_Ct`** (ID 5): Количество переназначенных секторов. Рост этого значения — первый тревожный сигнал, указывающий на то, что диск начал находить и заменять плохие сектора.
- **`Current_Pending_Sector_Ct`** (ID 197): Секторы, ожидающие перераспределения. Это секторы, которые диск обнаружил как потенциально ненадежные и попытается переназначить при следующей записи. Если диск не может их исправить, он может скоро выйти из строя.
- **`Uncorrectable_Sector_Ct`** (ID 198): Неисправимые секторы. Это необратимо поврежденные секторы, которые диск не может ни исправить, ни перенести. Их появление часто предвещает скорую поломку.
- **`UDMA_CRC_Error_Count`** (ID 199) / **`CRC Errors`**: Ошибки интерфейса SATA/NVMe. Указывают на проблемы с кабелем, разъемом или контроллером, а не с самим диском. Тем не менее, могут приводить к потере данных.
- **`Power_On_Hours`** (ID 9): Количество часов, которые диск был включён. Это показывает "возраст" диска. HDD редко живут больше 5-7 лет, SSD – до 3-5 лет при высокой нагрузке.
- **`SSD_Wear_Leveling_Count`** (ID 177) / **`Wear_Leveling_Count`**: Степень износа ячеек памяти у SSD. Если значение (обычно в процентах от 0 до 100) приближается к 100% износа, диск скоро выйдет из строя.

## Практические сценарии

> **Установка:** `sudo apt install smartmontools` или `sudo yum install smartmontools`.

### Быстрая проверка здоровья диска

Команда проверяет общий статус здоровья, который сообщает сам диск.

```bash
# Замените /dev/sda на ваш диск
sudo smartctl -H /dev/sda
```

Ищите строку `SMART overall-health self-assessment test result`. Значение `PASSED` говорит об отсутствии критических проблем на данный момент.

### Просмотр всех атрибутов

```bash
sudo smartctl -a /dev/sda
```

### Запуск тестов самодиагностики

`smartctl` может инициировать встроенные в диск тесты.

- **Короткий тест (`short`):** Быстрая проверка электроники и части дисковой поверхности (длится несколько минут).
- **Длинный тест (`long`):** Полное сканирование всей поверхности диска для выявления сбойных секторов (может длиться несколько часов).

```bash
# Запустить короткий тест в фоновом режиме
sudo smartctl -t short /dev/sda

# Посмотреть результаты последнего теста (через некоторое время)
sudo smartctl -l selftest /dev/sda
```

## Дополнительная информация

- **Интерпретация**: Статус `PASSED` не является гарантией, что диск не выйдет из строя. Важно следить за динамикой критических атрибутов. Резкий рост `Reallocated_Sectors_Ct` — серьезный повод для замены диска.
- **Контекст**: `smartctl` является важным инструментом при обслуживании программных RAID.
  - См. [Управление RAID в Linux](../../FileSystems/raid_management.md)
