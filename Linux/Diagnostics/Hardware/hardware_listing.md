# Инвентаризация оборудования в Linux

## Определения

**`inxi`** — современная и мощная утилита для получения краткой, но информативной сводки обо всей системе (CPU, GPU, RAM, диски, сеть, драйверы). Часто используется для быстрой первичной диагностики.

**`lshw` (List Hardware)** — комплексная утилита, генерирующая детальную иерархическую информацию об аппаратном обеспечении системы на основе данных из `/proc`, `/sys` и DMI.

**`lspci` (List PCI)** — инструмент для отображения всех устройств на шине PCI (видеокарты, сетевые адаптеры, RAID-контроллеры, USB-контроллеры).

**`lsusb` (List USB)** — утилита для вывода информации о USB-контроллерах и подключенных к ним устройствах.

**`lsblk` (List Block Devices)** — стандартный инструмент для просмотра блочных устройств (диски, разделы, LVM).

**`dmidecode`** — инструмент для чтения таблиц DMI (SMBIOS), позволяющий получить серийные номера, модель материнской платы и детализацию по слотам памяти.

## Базовые концепции

### Источники данных

| Утилита | Источник данных | Требует root | Основное назначение |
| :--- | :--- | :--- | :--- |
| **`inxi`** | Смешанный | Нет (для части данных) | Быстрый обзор всей системы |
| **`lshw`** | DMI, sysfs, /proc | Да | Глубокая иерархическая инвентаризация |
| **`lspci`** | `/sys/bus/pci` | Нет | Устройства на шине PCI |
| **`lsusb`** | `/sys/bus/usb` | Нет | Устройства на шине USB |
| **`lsblk`** | `/sys/block`, udev | Нет | Диски и разделы |
| **`dmidecode`** | DMI (BIOS/UEFI) | Да | Низкоуровневые данные (S/N, слоты) |

### Уровни детализации

- **Экспресс-диагностика**: `inxi -Fz`
- **Краткий обзор**: `lshw -short`, `lspci`, `lsusb`, `lsblk`
- **Глубокий анализ**: `lshw`, `lspci -vvv`, `lsusb -v`, `dmidecode`

### Виртуализация и оборудование

На виртуальных машинах (VM) вывод утилит специфичен:
- **`lspci`** показывает виртуальные мосты и устройства (например, `Virtio network device`).
- **`lsblk`** отображает виртуальные диски (`vda`, `xvda`).
- **`dmidecode`** часто возвращает информацию о гипервизоре (например, `Manufacturer: QEMU`, `Product Name: Standard PC`).

## Практические сценарии

### `inxi`: Быстрая сводка системы

```bash
# Полный обзор системы с фильтрацией чувствительных данных (MAC, серийники)
inxi -Fz

# → System:    Host: server1 Kernel: 5.15.0-generic x86_64 bits: 64 Console: pty pts/0 Distro: Ubuntu 22.04
# → CPU:       Info: 8-core model: Intel Core i7-10700 speed: 2900 MHz
# → Graphics:  Device-1: NVIDIA GA104 [GeForce RTX 3070] driver: nvidia v: 510.47.03
```

### `lshw`: Иерархическая инвентаризация

```bash
# Краткая сводка по классам оборудования
sudo lshw -short

# → H/W path       Device     Class          Description
# → ====================================================
# → /0/100/1.1     /dev/fb0   display        GA104 [GeForce RTX 3070]
# → /0/100/1d/0    eth0       network        Ethernet Connection (11) I219-V

# Получение данных в формате JSON для автоматизации
sudo lshw -json -class network
```

### `lspci`: Устройства PCI и драйверы

```bash
# Список устройств с указанием используемого драйвера ядра
lspci -nnk | grep -iA3 vga

# → 01:00.0 VGA compatible controller [0300]: NVIDIA Corporation GA104 [GeForce RTX 3070] [10de:2484]
# →        Subsystem: Gigabyte Technology Co., Ltd Device [1458:404c]
# →        Kernel driver in use: nvidia
# →        Kernel modules: nvidiafb, nvidia

# Обновление локальной базы PCI ID (если устройство отображается как "Unknown")
sudo update-pciids
```

### Инвентаризация оперативной памяти (`dmidecode`)

Используется для проверки физических слотов и характеристик модулей без вскрытия корпуса.

```bash
# Общий объем и количество слотов
sudo dmidecode -t memory | grep -E "Size:|Type:|Speed:|Locator:"

# → Size: 16 GB
# → Type: DDR4
# → Speed: 3200 MT/s
# → Locator: DIMM 0
```

### Инвентаризация дисков и NVMe

Для классических дисков используется `lsblk`, для современных NVMe — специализированная утилита.

```bash
# Дерево блочных устройств с UUID и файловыми системами
lsblk -f

# Детальная информация о NVMe накопителях (пакет nvme-cli)
sudo nvme list

# → Node             SN                   Model               Format  FW Rev
# → /dev/nvme0n1     S59ZNX0R123456       Samsung SSD 980 1TB 512  B L1Q...
```

### Сетевое оборудование (`ethtool`)

Проверка физических параметров линка и возможностей сетевой карты.

```bash
# Проверка физического состояния порта и скорости
sudo ethtool eth0

# → Speed: 1000Mb/s
# → Duplex: Full
# → Link detected: yes
```

## Диагностика проблем

### Поиск отсутствующего оборудования

Если устройство не отображается в `lspci` или `lsusb`:
1. Проверьте сообщения ядра о сбоях инициализации: `dmesg | grep -iE "pci|error|firmware"`.
2. Убедитесь, что устройство не отключено в BIOS/UEFI.
3. Проверьте наличие питания/физического контакта.

### Проблемы с драйверами

Если в `lspci -k` отсутствует строка `Kernel driver in use`:
- Модуль ядра не загружен: `lsmod | grep <имя_модуля>`.
- Отсутствует прошивка (firmware): проверьте `dmesg` на наличие `Direct firmware load for ... failed`.

## Дополнительная информация

### Сравнение форматов вывода

| Формат | Команда | Применение |
| :--- | :--- | :--- |
| **Текстовый** | `lshw -short` | Чтение человеком |

| **XML/HTML** | `sudo lshw -html` | Отчеты для инвентаризации |
