# Инвентаризация оборудования в Linux

## Определения

- **`lshw` (List Hardware)**: Комплексная утилита для получения детальной информации обо всем аппаратном обеспечении системы, включая CPU, память, диски, сетевые карты и многое другое.
- **`lspci` (List PCI)**: Утилита для отображения информации обо всех PCI-шинах в системе и устройствах, подключенных к ним (например, видеокарты, сетевые адаптеры, контроллеры SATA).
- **`lsscsi` (List SCSI)**: Инструмент для вывода списка всех SCSI/SATA устройств, таких как жесткие диски (HDD), твердотельные накопители (SSD) и оптические приводы.
- **`lsusb` (List USB)**: Команда для отображения информации о USB-контроллерах и всех устройствах, подключенных к шинам USB.
- **`lsblk` (List Block Devices)**: Утилита для отображения информации о блочных устройствах (диски, разделы, LVM, RAID).
- **`hwinfo`**: Расширенный инструмент для сбора информации об оборудовании (доступен не во всех дистрибутивах).

## Основные концепции

### Источники данных

| Утилита | Источник данных | Требует root | Основное назначение |
|---------|----------------|--------------|---------------------|
| `lshw` | DMI/SMBIOS, sysfs, /proc | Да (для полной информации) | Комплексная инвентаризация |
| `lspci` | /sys/bus/pci, pciutils | Нет | PCI-устройства |
| `lsusb` | /sys/bus/usb, usbutils | Нет (подробности — да) | USB-устройства |
| `lsscsi` | /sys/class/scsi_device | Нет | SCSI/SATA устройства |
| `lsblk` | /sys/block, udev | Нет | Блочные устройства |
| `dmidecode` | DMI/SMBIOS (BIOS/UEFI) | Да | Низкоуровневая информация |
| `hwinfo` | Различные источники | Да (частично) | Детальная диагностика |

### Уровни детализации

- **Краткий обзор**: `lshw -short`, `lspci`, `lsusb`, `lsblk`
- **Подробная информация**: `lshw`, `lspci -vvv`, `lsusb -v`, `lsscsi -l`
- **Низкоуровневые данные**: `dmidecode`, `hwinfo`

### Виртуализация и оборудование

На виртуальных машинах:
- `lspci` показывает эмулированные PCI-устройства (virtio, vmxnet3)
- `dmidecode` может показывать информацию о виртуальном BIOS
- `lsblk` показывает виртуальные диски (vda, sda от гипервизора)

Подробнее см. [Виртуализация](../../../Virtualization/virtualization_overview.md).

## Практические сценарии

### `lshw`: Комплексный обзор системы

```bash
# Краткая иерархическая сводка по всему оборудованию
sudo lshw -short

# Подробная информация обо всех компонентах
sudo lshw

# Только информация о памяти
sudo lshw -class memory

# Только сетевые интерфейсы
sudo lshw -class network

# Только диски и контроллеры хранения
sudo lshw -class storage

# Экспорт в HTML (для отчётов)
sudo lshw -html > hardware_report.html

# Экспорт в JSON (для автоматизации)
sudo lshw -json > hardware_report.json

# Проверка версии базы данных PCI/USB ID
lshw -version
```

**Ключевые классы оборудования:**
- `memory`: Оперативная память, кэши
- `cpu`: Процессоры
- `network`: Сетевые адаптеры
- `storage`: Контроллеры хранения (SATA, NVMe, RAID)
- `disk`: Физические диски
- `volume`: Разделы
- `display`: Видеокарты
- `usb`: USB-контроллеры
- `pci`: PCI-мосты

### `lspci`: Список устройств на шине PCI

```bash
# Базовый список всех PCI-устройств
lspci

# С информацией о вендоре и устройстве
lspci -v

# Полная информация (регистра, прерывания, память)
lspci -vvv

# Числовой вывод (ID вендора/устройства)
lspci -n

# Числовой вывод с адресами
lspci -nn

# Только сетевые карты
lspci | grep -i net

# Только видеокарты
lspci | grep -i vga

# Поиск конкретного устройства по ID
lspci -d 8086:100e  # Intel устройство с ID 100e

# Дерево PCI-устройств
lspci -t

# Информация о конкретном слоте (00:1f.2)
lspci -s 00:1f.2 -vvv
```

**Формат вывода:** `BB:DD.F Класс: Вендор Устройство (rev XX)`
- `BB` — номер шины (Bus)
- `DD` — номер устройства (Device)
- `F` — функция (Function)

**Распространённые классы:**
- `0600` — Host bridge
- `0100` — SCSI storage controller
- `0106` — SATA controller
- `0200` — Ethernet controller
- `0300` — VGA compatible controller
- `0c03` — USB controller

### `lsscsi`: Список SCSI/SATA устройств

```bash
# Базовый вывод
lsscsi

# Детальная информация с указанием модели и вендора
lsscsi -l

# Только диски
lsscsi --disk

# Только оптические приводы
lsscsi --cd

# Только ленточные накопители
lsscsi --tape

# Информация о путях multipath
lsscsi -m

# Все устройства с хостами
lsscsi -H

# Вывод с размерами дисков
lsscsi -s
```

**Формат вывода:** `[host:channel:target:lun] Тип Устройство`

Пример:
```
[0:0:0:0]    disk    ATA      VBOX HARDDISK     1.0   /dev/sda
[1:0:0:0]    cd/dvd  VBOX     CD-ROM            1.0   /dev/sr0
```

### `lsusb`: Список USB-устройств

```bash
# Краткий список
lsusb

# Подробная информация (требует root для полного доступа)
sudo lsusb -v

# Информация о конкретном устройстве по шине/устройству
lsusb -s 001:002

# Информация о конкретном вендоре/продукте
lsusb -d 8087:0024  # Intel USB hub

# Дерево USB-устройств
lsusb -t

# Только ID вендора и продукта
lsusb | cut -d' ' -f6
```

**Распространённые вендоры:**
- `8087` — Intel
- `046d` — Logitech
- `0781` — SanDisk
- `13fe` — Kingston
- `0951` — Kingston (DataTraveler)

### `lsblk`: Список блочных устройств

```bash
# Базовый вывод
lsblk

# Вывод с размерами
lsblk -o NAME,SIZE

# Вывод с типами устройств и точками монтирования
lsblk -o NAME,TYPE,MOUNTPOINT

# Полный вывод со всеми доступными полями
lsblk -o ALL

# Вывод в виде дерева
lsblk -f  # С информацией о файловых системах

# Только диски (без разделов)
lsblk -nd

# Только разделы
lsblk -d

# Вывод с серийными номерами и моделями
lsblk -o NAME,MODEL,SERIAL,SIZE,TYPE

# Экспорт в JSON
lsblk -J
```

**Типы устройств:**
- `disk`: Физический диск
- `part`: Раздел
- `lvm`: LVM том
- `rom`: Оптический привод
- `raid`: RAID массив

## Диагностика проблем

### Проблемы с распознаванием оборудования

```bash
# PCI устройство не видно
lspci -vvv | grep -A20 "Ethernet"
dmesg | grep -i pci
dmesg | grep -i ethernet

# USB устройство не определяется
lsusb -v
dmesg | tail -50  # Последние сообщения ядра
dmesg | grep -i usb

# Диск не виден в системе
lsscsi
lsblk
dmesg | grep -i sd  # SCSI/SATA диски
dmesg | grep -i nvme  # NVMe диски
```

### Поиск драйверов для оборудования

```bash
# Какой драйвер использует сетевая карта
lspci -k | grep -A3 -i ethernet

# Какой драйвер использует видеокарта
lspci -k | grep -A3 -i vga

# Модули ядра для PCI устройства
lspci -nnk

# Информация о загруженных модулях
lsmod | grep -i e1000  # Пример для Intel NIC
```
