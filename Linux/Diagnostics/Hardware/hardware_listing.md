# Инвентаризация оборудования в Linux

## 1. Определение
Эта заметка описывает набор команд для инвентаризации и получения информации об аппаратных компонентах системы, таких как шины PCI, USB, дисковые устройства и BIOS.

## 2. Основные концепции
- **Источники данных:** Утилиты получают информацию из разных источников. `lshw` и `dmidecode` читают данные из DMI/SMBIOS, предоставляя детальную информацию от производителя. `lspci`, `lsusb`, `lsscsi` опрашивают соответствующие шины и подсистемы ядра.
- **Уровень детализации:** Команды варьируются от высокоуровневого обзора (`lshw -short`) до глубокой детализации по конкретной шине (`lsusb -v`).

## 3. Практические сценарии

### `lshw`: Комплексный обзор системы
Позволяет получить информативное описание всех компонентов сервера.
```bash
# Краткая иерархическая сводка по всему оборудованию
sudo lshw -short
```

### `lspci`: Список устройств на шине PCI
Отображает все PCI-шины и устройства, подключенные к ним (VGA, сетевые карты, SATA-контроллеры).
```bash
lspci
```

### `lsscsi`: Список SCSI/SATA устройств
Быстрый способ проверить все подключенные диски и оптические приводы.
```bash
# Базовый вывод
lsscsi

# Детальная информация
lsscsi -l
```

### `lsusb`: Список USB-устройств
Показывает USB-контроллеры и все подключенные к ним устройства.
```bash
# Краткий список
lsusb

# Подробная информация
lsusb -v
```

### `dmidecode`: Чтение данных из BIOS/DMI
Парсит низкоуровневую информацию из DMI, например, о BIOS.
```bash
# Получить информацию о BIOS
sudo dmidecode -t bios
```

## 4. Продвинутые детали
Хотя эти команды отлично подходят для инвентаризации, для диагностики производительности конкретных устройств (например, дисков или сети) требуются другие инструменты.

- Для дисков: [smartctl](./Tools/smartctl.md) для проверки здоровья, [iostat](./Tools/iostat.md) для статистики I/O.
- Для сети: [ethtool](../Networking/ServicesAndTools/ethtool.md), [ip](../Networking/ServicesAndTools/iproute2.md).
- Для CPU: [lscpu](./cpu_info.md).
