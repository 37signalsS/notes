# Инвентаризация оборудования в Linux

## Определения

- **`lshw` (List Hardware)**: Комплексная утилита для получения детальной информации обо всем аппаратном обеспечении системы, включая CPU, память, диски, сетевые карты и многое другое.
- **`lspci` (List PCI)**: Утилита для отображения информации обо всех PCI-шинах в системе и устройствах, подключенных к ним (например, видеокарты, сетевые адаптеры, контроллеры SATA).
- **`lsscsi` (List SCSI)**: Инструмент для вывода списка всех SCSI/SATA устройств, таких как жесткие диски (HDD), твердотельные накопители (SSD) и оптические приводы.
- **`lsusb` (List USB)**: Команда для отображения информации о USB-контроллерах и всех устройствах, подключенных к шинам USB.

## Основные концепции

- **Источники данных**: Утилиты получают информацию из разных источников. `lshw` и `dmidecode` читают данные из DMI/SMBIOS, предоставляя детальную информацию от производителя. `lspci`, `lsusb`, `lsscsi` опрашивают соответствующие шины и подсистемы ядра, предоставляя взгляд на оборудование со стороны ОС.
- **Уровень детализации**: Команды варьируются от высокоуровневого обзора (`lshw -short`) до глубокой детализации по конкретной шине (`lsusb -v`). `lshw` — самая многофункциональная из них, способная предоставлять как краткую, так и очень подробную информацию.

## Практические сценарии

### `lshw`: Комплексный обзор системы

```bash
# Краткая иерархическая сводка по всему оборудованию
sudo lshw -short
```

### `lspci`: Список устройств на шине PCI

```bash
# Показать все PCI-устройства
lspci
```

### `lsscsi`: Список SCSI/SATA устройств

```bash
# Базовый вывод
lsscsi

# Детальная информация с указанием модели и вендора
lsscsi -l
```

### `lsusb`: Список USB-устройств

```bash
# Краткий список
lsusb

# Подробная информация (может требовать прав суперпользователя)
sudo lsusb -v
```
