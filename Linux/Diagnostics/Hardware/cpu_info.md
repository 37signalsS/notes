# Диагностика и информация о CPU

## 1. Определение

Эта заметка описывает команды для получения подробной информации об архитектуре и характеристиках центрального процессора (CPU) в Linux.

## 2. Основные концепции

- **`/proc/cpuinfo` vs. `lscpu`**: `/proc/cpuinfo` предоставляет "сырую" информацию о каждом логическом ядре. `lscpu` агрегирует эти данные и представляет их в более удобном и читаемом формате, показывая информацию об архитектуре, количестве ядер, потоков, кэшах и т.д.
- **SMBIOS/DMI**: `dmidecode` получает информацию не от ядра, а напрямую из BIOS/UEFI через интерфейс DMI. Это позволяет получить аппаратные детали, которые могут быть не видны ядру, например, максимальную поддерживаемую скорость процессора или информацию о сокете.

## 3. Практические сценарии
### `lscpu`: Быстрый обзор архитектуры CPU
Самый простой и быстрый способ получить сводную информацию о процессоре.
```bash
lscpu
```
**Ключевые поля вывода:**
- `Architecture`: Архитектура (x86_64, aarch64).
- `CPU(s)`: Общее количество логических ядер.
- `Core(s) per socket`: Количество физических ядер на сокет.
- `Socket(s)`: Количество процессорных сокетов.
- `Vendor ID`: Производитель (GenuineIntel, AuthenticAMD).
- `Virtualization`: Поддержка аппаратной виртуализации.
- `L1/L2/L3 cache`: Размеры кэшей.

### `dmidecode`: Аппаратные детали процессора
Используется для получения специфических аппаратных данных из BIOS.
```bash
# Посмотреть информацию о CPU
sudo dmidecode -t processor
```
Эта команда полезна для точной идентификации модели процессора, его максимальной скорости и других низкоуровневых характеристик.
