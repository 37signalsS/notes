# Диагностика и информация о CPU

## Определения

- **`/proc/cpuinfo`**: Псевдофайл в файловой системе `/proc`, предоставляющий необработанную информацию от ядра о каждом логическом процессорном ядре.
- **`lscpu`**: Утилита командной строки, которая собирает и агрегирует данные из `/proc/cpuinfo` и `sysfs`, представляя их в удобном для чтения формате.
- **`dmidecode`**: Инструмент для извлечения низкоуровневой информации об аппаратном обеспечении компьютера из таблиц DMI (Desktop Management Interface).
- **DMI/SMBIOS**: Стандарт, позволяющий операционной системе получать данные напрямую от BIOS/UEFI, включая детальные спецификации компонентов, такие как модель процессора, серийные номера и производитель.

## Основные концепции

- **Разница в источниках**: `lscpu` и `/proc/cpuinfo` получают данные от ядра Linux, отражая то, как ОС "видит" процессор. В отличие от них, `dmidecode` читает информацию напрямую из BIOS/UEFI, что позволяет получить аппаратные детали, которые могут быть не видны ядру (например, максимальная поддерживаемая частота).
- **Уровень детализации**: `/proc/cpuinfo` выводит подробную, но "сырую" информацию для каждого логического ядра отдельно. `lscpu` предоставляет агрегированную и структурированную сводку, которая удобнее для быстрого анализа.

## Практические сценарии

### `lscpu`: Быстрый обзор архитектуры CPU

```bash
lscpu
```
**Ключевые поля вывода:**
- `Architecture`: Архитектура (x86_64, aarch64).
- `CPU(s)`: Общее количество логических ядер.
- `Core(s) per socket`: Количество физических ядер на сокет.
- `Socket(s)`: Количество процессорных сокетов.
- `Vendor ID`: Производитель (GenuineIntel, AuthenticAMD).
- `Virtualization`: Поддержка аппаратной виртуализации.
- `L1/L2/L3 cache`: Размеры кэшей.

### `dmidecode`: Аппаратные детали процессора

Используется для получения специфических аппаратных данных из BIOS.

```bash
# Посмотреть информацию о процессоре
sudo dmidecode -t processor
```
Эта команда полезна для точной идентификации модели, максимальной скорости и других низкоуровневых характеристик.

## Дополнительная информация

- **Надёжность**: Данные из `dmidecode` зависят от того, насколько корректно производитель заполнил таблицы DMI, и могут быть неточными или неполными. Информация от `lscpu` считается более достоверной с точки зрения операционной системы.
