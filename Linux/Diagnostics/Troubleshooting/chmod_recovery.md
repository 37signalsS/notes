# Восстановление `chmod` после снятия прав на исполнение

Это руководство описывает методы восстановления утилиты `chmod` в случае, если с нее были случайно сняты права на исполнение (`chmod -x /bin/chmod`).

### Симптомы

При попытке выполнить любую операцию с `chmod` система возвращает ошибку:

```bash
$ chmod 755 some_file
-bash: /bin/chmod: Permission denied
```

Это происходит потому, что сама утилита `chmod` является исполняемым файлом и требует прав на запуск.

### Методы восстановления

#### Метод 1: Использование Perl / Python (Наиболее вероятный)

Если в системе установлен интерпретатор Perl или Python, можно использовать их встроенные функции для изменения прав доступа к файлам. Эти интерпретаторы выполняют системный вызов `chmod(2)` напрямую, обходя необходимость в внешней утилите.

**Perl:**

```bash
perl -e 'chmod 0755, "/bin/chmod"'
```

**Python (однострочник):**

```bash
python -c 'import os; os.chmod("/bin/chmod", 0o755)'
```

**Python (heredoc — для сложных сценариев):**

```bash
python3 - <<'EOF'
import os
os.chmod("/bin/chmod", 0o755)
EOF
```

#### Метод 2: Использование BusyBox

Если в системе установлен `busybox`, он содержит встроенную реализацию `chmod`.

```bash
busybox chmod 755 /bin/chmod
```

#### Метод 3: Использование динамического компоновщика (Advanced)

Это низкоуровневый метод, который работает в большинстве случаев. Динамический компоновщик (загрузчик) может напрямую запустить исполняемый файл, обходя стандартную проверку прав.

Сначала нужно найти путь к компоновщику. Обычно это `/lib64/ld-linux-x86-64.so.2` или `/lib/ld-linux.so.2`.

```bash
# Для 64-битных систем
/lib64/ld-linux-x86-64.so.2 /bin/chmod 755 /bin/chmod

# Для 32-битных систем
/lib/ld-linux.so.2 /bin/chmod 755 /bin/chmod
```

После выполнения этой команды права на `/bin/chmod` будут восстановлены.

#### Метод 4: Переустановка пакета

Самый чистый способ — переустановить пакет, который содержит утилиту `chmod` (обычно это `coreutils`).

**Для Debian/Ubuntu:**

```bash
sudo apt-get install --reinstall coreutils
```

**Для CentOS/RHEL/Fedora:**

```bash
sudo yum reinstall coreutils
# или
sudo dnf reinstall coreutils
```

#### Метод 5: Загрузка с LiveCD/LiveUSB

Если ни один из вышеперечисленных методов не сработал, можно:

1. Загрузить систему с LiveCD или LiveUSB.
2. Примонтировать корневую файловую систему вашего основного диска:

   ```bash
   mount /dev/sdXN /mnt
   ```

3. Изменить права на файл `chmod` в примонтированной системе:

   ```bash
   chmod 755 /mnt/bin/chmod
   ```

4. Отмонтировать диск и перезагрузиться в основную систему.
