# Диагностика системы: sos report и sosdiff

## Определение

**`sos report`** — универсальный инструмент диагностики для Linux, написанный на языке Python. Предназначен для сбора исчерпывающих диагностических данных из системы без внесения изменений в её конфигурацию. Является стандартом де-факто для служб поддержки (Red Hat, Oracle, Ubuntu) при начале процесса устранения неполадок.

**`sosdiff`** — специализированная утилита (входит в пакет OLED для Oracle Linux) для сравнения двух отчётов `sos report`. Позволяет выявлять различия между "рабочей" и "проблемной" системами, сравнивать конфигурации или отслеживать изменения на одном сервере во времени.

## Базовые концепции

### Назначение и возможности sos report

Инструмент автоматизирует сбор информации из сотен источников:

- Конфигурационные файлы из `/etc`
- Журналы (логи) из `/var/log` и `journald`
- Вывод системных команд (`ip`, `ps`, `df`, `lsmod` и др.)
- Данные о производительности `sar` (из пакета `sysstat`)
- Детальная информация об оборудовании и драйверах
- Состояние структур ядра через интерфейсы `/proc` и `/sys`

### Структура диагностического архива

После распаковки архива (`tar -xf`) создаётся иерархия каталогов, имитирующая корень файловой системы, а также дополнительные служебные папки. Ключевые файлы часто представлены символическими ссылками в корне архива:

- `cmdline` — параметры загрузки ядра
- `dmidecode` — информация о BIOS, CPU и оперативной памяти
- `installed-rpms` / `dpkg-query` — списки установленного ПО
- `lspci` — устройства на шине PCI
- `uname` — версия ядра и архитектура
- `uptime` — время работы и Load Average

**Основные каталоги:**

- `etc/` — копии конфигурационных файлов
- `sos_commands/` — текстовые файлы с выводом выполненных диагностических команд
- `sos_reports/` — отчёты в форматах HTML (для браузера), TXT и JSON
- `var/log/` — системные и прикладные журналы

### Возможности sosdiff (Oracle Linux)

Утилита входит в состав пакета Oracle Linux Enhanced Diagnostics (OLED) и выполняет интеллектуальное сравнение двух архивов, группируя различия по категориям:

- **Пакеты:** различия в версиях и составе установленного ПО.
- **Ядро:** несовпадения в загруженных модулях и параметрах `sysctl`.
- **Сеть:** сравнение конфигурации интерфейсов и маршрутов.
- **Монтирование:** различия в точках монтирования и опциях ФС.

## Практические сценарии

### Установка инструментов

**RHEL / Oracle Linux / CentOS / Fedora:**

```bash
# Oracle Linux 8/9, RHEL 8/9
sudo dnf install sos

# Oracle Linux 6/7, CentOS 7
sudo yum install sos
```

**Ubuntu / Debian:**

```bash
sudo apt update
sudo apt install sosreport
```

### Сбор диагностических данных

Современный синтаксис (sos 4.x+) использует подкоманду `report`.

**Стандартный сбор (максимальная полнота):**

```bash
sudo sos report --batch --all-logs -k sar.all-sar=on
# → /var/tmp/sosreport-hostname-YYYY-MM-DD-xxxxxx.tar.xz
```

**Особенности по версиям и дистрибутивам:**

- **Oracle Linux 9:** может потребоваться явное включение плагина `sar` через `-e sar`.
- **Устаревшие системы (OL 6/7):** используется команда `sosreport` (без пробела).
- **Ограничение по размеру:** если свободного места мало, используйте `--build` для создания отчёта без архивации в `/var/tmp`.

**Ключевые параметры:**

- `--batch` — неинтерактивный режим (автоответ на вопросы об имени хоста).
- `--all-logs` — сбор всех журналов без усечения (важно для глубокого анализа).
- `-k sar.all-sar=on` — сбор истории `sar` за весь период, а не только за последние 24 часа.

### Управление плагинами

Просмотр списка доступных плагинов и их текущего статуса:

```bash
sudo sos report -l
```

Включение конкретных плагинов и передача им опций:

```bash
# Сбор данных только по сети и дискам
sudo sos report -n network,block
```

### Интеграция с sysstat

Для корректного сбора ретроспективных данных о производительности убедитесь, что в системе настроен сбор `sar`. Подробнее см. в [Руководстве по sar](./Performance/sar.md).

### Сравнение отчётов через sosdiff

Инструмент `sosdiff` доступен в Oracle Linux при установке пакета `oled`.

```bash
oled sosdiff report_before/ report_after/
```

**Полезные флаги:**

- `-d, --detail` — детальный вывод изменений.
- `-o, --override` — игнорирование различий в версиях ОС (полезно при миграции).
- `-c, --color` — включение цветовой подсветки.

### Анонимизация и очистка данных (sos clean)

Для удаления чувствительной информации (IP-адреса, пароли, ключи) используется подкоманда `clean`.

**Очистка существующего архива:**

```bash
sudo sos clean /var/tmp/sosreport-file.tar.xz --keywords MyProjectName
# → /var/tmp/sosreport-file-obfuscated.tar.xz
```

**Сбор с одновременной очисткой (sos 4.x+):**

```bash
sudo sos report --clean --batch
```

### Конфигурация по умолчанию

Глобальные настройки можно задать в файле `/etc/sos/sos.conf`:

```ini
[global]
batch = yes

[report]
all-logs = yes
enable-plugins = sar, network

[plugin_options]
sar.all-sar=on
```

## Дополнительная информация

### Анализ содержимого архива

Пример быстрого поиска информации в распакованном отчёте:

```bash
# Проверка параметров ядра
cat proc/cmdline

# Поиск ошибок в логах с привязкой к дате
grep -i "error" var/log/messages | grep "Jul 26"

# Проверка состояния конкретного интерфейса
cat sos_commands/networking/ip_addr | grep -A 5 "eth0"
```

### Сбор данных в кластерных средах (sos collect)

Если проблема затрагивает несколько узлов (например, в Kubernetes или Pacemaker), используйте `sos collect`. Она позволяет запустить сбор данных на группе хостов одновременно и объединить результаты.

```bash
sudo sos collect --nodes=node1,node2,node3 --batch
```

### Рекомендации по эксплуатации

1. **Скорость реакции:** собирайте отчёт немедленно при обнаружении аномалий, пока логи не были перезаписаны (logrotate).
2. **Эталонный слепок:** сохраняйте `sos report` сразу после успешного развёртывания системы для последующего сравнения.
3. **Место на диске:** диагностический архив может занимать несколько гигабайт. Проверяйте наличие места в `/var/tmp`.
4. **Безопасность:** всегда используйте `sos clean` перед отправкой отчётов внешним вендорам или в публичные трекеры.
