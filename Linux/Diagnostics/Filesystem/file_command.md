# file

## Определения

- **`file`:** Универсальная утилита командной строки для определения типа данных внутри файла. В отличие от ОС Windows, `file` в Linux/Unix игнорирует расширение и анализирует фактическую структуру байтов.
- **libmagic:** Библиотека, на которой основана утилита `file`. Она содержит логику сопоставления сигнатур и предоставляет API для других программ (например, файловых менеджеров или веб-серверов).
- **Магические числа (Magic Numbers):** Константы или уникальные последовательности байтов, расположенные в определенных смещениях (обычно в начале) файла.
- **MIME-тип (Multipurpose Internet Mail Extensions):** Стандартизированный идентификатор формата контента, состоящий из типа и подтипа (например, `text/yaml`), используемый для автоматизации обработки данных.

## Основные концепции

Утилита `file` выполняет последовательно три уровня проверок:

1.  **Проверка файловой системы (Filesystem tests):** Анализ результата системного вызова `stat`. Позволяет сразу определить пустой файл, директорию, символьную ссылку, сокет или блочное устройство.
2.  **Проверка магических чисел (Magic tests):** Сравнение содержимого файла с базой данных сигнатур (`/usr/share/misc/magic.mgc`). Это основной этап идентификации бинарных форматов (ELF, PDF, ZIP).
3.  **Текстовые проверки (Language tests):** Если файл не является бинарным, утилита ищет специфические текстовые последовательности (например, `#!`, `<html>`, `---` для YAML), чтобы определить кодировку и язык разметки/программирования.

### База данных сигнатур

- **Системная БД:** Обычно `/usr/share/misc/magic` (исходный текст) и `/usr/share/misc/magic.mgc` (скомпилированная бинарная форма).
- **Пользовательская БД:** Можно расширять правила, создавая файлы в `/etc/magic` или `~/.magic`.

## Практические сценарии

### Идентификация и автоматизация

```bash
# Определение типа без вывода имени файла (идеально для переменных в скриптах)
TYPE=$(file -b --mime-type config.yaml)
# → text/plain (или text/yaml в зависимости от версии БД)

# Массовая проверка файлов из списка
file -f list_of_files.txt

# Вывод информации о кодировке текста
file -i script.py
# → script.py: text/x-python; charset=utf-8
```

### Глубокая диагностика и безопасность

```bash
# Продолжать поиск всех возможных совпадений (не останавливаться на первом)
file -k suspicious_file
# → Помогает выявить "матрешки" или файлы с внедренными данными

# Анализ содержимого внутри сжатых архивов (поддерживает gz, bz2, zip)
file -z backup.tar.gz

# Определение файловой системы на неразмеченном диске
sudo file -s /dev/nvme0n1p1
```

### Работа в macOS (Darwin)

На macOS утилита `file` может возвращать специфические типы, такие как `Mach-O 64-bit executable arm64` для Apple Silicon. База данных магических чисел в macOS также включает специфические сигнатуры для форматов Apple (например, `.dmg`, `.plist`).

## Дополнительная информация

### Ключевые параметры

| Опция | Описание | Пример |
| :--- | :--- | :--- |
| `-b`, `--brief` | Не выводить имя файла перед результатом | `file -b data.bin` |
| `-i`, `--mime` | Показать MIME-тип и кодировку | `file -i index.html` |
| `-f`, `--files-from` | Читать имена файлов из указанного файла | `file -f targets.log` |
| `-k`, `--keep-going` | Показать все найденные совпадения, а не только первое | `file -k polyglot.jpg` |
| `-L`, `--dereference` | Следовать по символьным ссылкам (по умолчанию проверяет саму ссылку) | `file -L /usr/bin/python` |
| `-s`, `--special-files` | Читать специальные файлы (устройства), которые обычно игнорируются | `file -s /dev/sda` |
| `-C`, `--compile` | Скомпилировать файл магических чисел для ускорения работы | `file -C my_magic` |

### Современные MIME-типы и сигнатуры

| MIME-тип | Примечание |
| :--- | :--- |
| `text/yaml` или `text/plain` | Файлы конфигурации (часто зависят от версии `libmagic`) |
| `application/json` | Структурированные данные |
| `application/x-executable` | Бинарные файлы Linux (ELF) |
| `application/x-mach-binary` | Бинарные файлы macOS (Mach-O) |
| `application/vnd.apple.pkpass` | Специфические форматы Apple |

### Ограничения

- **Ложноположительные срабатывания:** Случайные последовательности байтов в текстовых файлах иногда могут быть ошибочно приняты за магические числа редких форматов.
- **Производительность с `-z`:** Распаковка "на лету" для анализа содержимого архивов может быть медленной для очень больших файлов.
- **Точность:** Утилита определяет формат, но не валидирует его (например, поврежденный PDF может быть определен как PDF).
