# `file`

## Определения

- **`file`:** Утилита командной строки для определения типа файла по его фактическому содержимому, а не по расширению. Анализирует так называемые «магические числа» — уникальные последовательности байтов в начале файла.
- **Магические числа (Magic Numbers):** Уникальные сигнатуры форматов файлов, хранящиеся в базе данных `/etc/magic` или `/usr/share/misc/magic`. Позволяют надежно идентифицировать тип данных независимо от имени файла или его расширения.
- **MIME (Multipurpose Internet Mail Extensions):** Стандартный формат указания типа контента (например, `application/zip`, `text/plain`, `application/x-executable`).

## Основные концепции

Утилита `file` выполняет глубокий анализ содержимого файла, что дает следующие возможности:

- **Идентификация без расширения:** Определение типа данных в файлах с отсутствующим или неверным расширением.
- **Безопасность:** Выявление потенциально вредоносных файлов (например, исполняемых файлов, замаскированных под изображения `.jpg`).
- **Проверка целостности:** Подтверждение соответствия файла заявленному формату перед его обработкой.
- **Автоматизация:** Использование в скриптах для корректной маршрутизации файлов на основе их MIME-типов.

### База данных сигнатур

База данных магических чисел обычно располагается по путям `/etc/magic` или `/usr/share/misc/magic`. Она содержит наборы байтов, маски и соответствующие им текстовые описания типов файлов. База обновляется вместе с пакетом утилиты в дистрибутиве Linux.

## Практические сценарии

### Идентификация неизвестных файлов

```bash
# Определение типа архива
$ file archive.zip
# → archive.zip: Zip archive data, at least v1.0 to extract

# Определение исполняемого файла Windows
$ file program.exe
# → program.exe: PE32 executable (GUI) Intel 80386, for MS Windows

# Определение скрипта
$ file script.sh
# → script.sh: POSIX (Portable Operating System Interface) shell script, ASCII (American Standard Code for Information Interchange) text executable

# Распознавание сжатых данных
$ file data.gz
# → data.gz: gzip compressed data, was "data.txt", last modified: ...
```

### Работа с системными и сжатыми объектами

```bash
# Проверка символьной ссылки с разыменованием
$ file -L /bin/sh
# → /bin/sh: symbolic link to dash

# Определение файловой системы на блочном устройстве
$ file -s /dev/sda1
# → /dev/sda1: Linux rev 1.0 ext4 filesystem data, ...

# Просмотр содержимого внутри сжатого архива
$ file -z archive.tar.gz
# → archive.tar.gz: gzip compressed data, from Unix, ... (tar archive)
```

## Дополнительная информация

### Ключевые параметры

| Опция | Описание | Пример |
| :--- | :--- | :--- |
| `-b`, `--brief` | Краткий вывод без имени файла (удобно для скриптов) | `file -b file.txt` |
| `-i`, `--mime` | Вывод MIME-типа и кодировки | `file -i file.pdf` |
| `-z`, `--compress` | Попытка заглянуть внутрь сжатых файлов | `file -z archive.gz` |
| `-s`, `--special-files` | Анализ специальных файлов устройств (блочных/символьных) | `file -s /dev/sda1` |
| `-L`, `--dereference` | Следовать по символьным ссылкам | `file -L /bin/sh` |
| `-c`, `--checking-printout` | Проверка синтаксиса магических правил | `file -c magic` |

### Распространенные MIME-типы

| Тип | Описание |
| :--- | :--- |
| `text/plain` | Обычный текст |
| `text/x-shellscript` | Сценарий оболочки (Shell) |
| `application/pdf` | Документ PDF (Portable Document Format) |
| `application/zip` | Архив ZIP |
| `application/gzip` | Архив GZIP (GNU ZIP) |
| `application/x-executable` | Исполняемый файл ELF (Executable and Linkable Format) |
| `application/x-dosexec` | Исполняемый файл DOS/Windows (PE32) |
| `image/jpeg`, `image/png` | Изображения популярных форматов |
| `application/octet-stream` | Двоичные данные произвольного типа |

### Ограничения утилиты

- **Неизвестные форматы:** Редкие или проприетарные форматы могут определяться как общие двоичные данные (`data`).
- **Зашифрованные данные:** Шифрованные файлы всегда распознаются как случайный поток данных (`data`).
- **Производительность:** Обработка очень больших файлов (>1 ГБ) может занимать значительное время.
- **Кастомные правила:** Для использования собственных магических чисел требуется их предварительная компиляция командой `file -C`.
