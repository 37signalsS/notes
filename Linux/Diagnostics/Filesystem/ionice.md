# `ionice`

## Определения

-   **`ionice`:** Утилита командной строки для управления приоритетом дисковых операций ввода-вывода (I/O) для процессов.
-   **Классы планирования I/O:** Категории, определяющие, когда процесс получит доступ к дисковым ресурсам.
    -   **Idle (Класс 3):** Самый низкий приоритет. Процесс получает доступ к диску, только когда он полностью свободен.
    -   **Best-effort (Класс 2):** Приоритет по умолчанию. Позволяет установить относительный приоритет от 0 (высший) до 7 (низший).
    -   **Realtime (Класс 1):** Наивысший приоритет. Процесс получает немедленный доступ к диску, опережая все остальные.

## Основные концепции

Основная задача `ionice` — предотвратить ситуацию, когда ресурсоемкие, но некритичные фоновые задачи (например, резервное копирование, индексация файлов) замедляют работу важных приложений (например, баз данных или веб-серверов), активно использующих диск.

Путем назначения различных классов планирования `ionice` позволяет ядру Linux принимать более взвешенные решения о том, какому процессу предоставить доступ к диску в первую очередь.

## Практические сценарии

### Запуск процесса с низким приоритетом

```bash
# Запустить rsync с минимальным приоритетом I/O (класс Idle)
ionice -c3 rsync -a /source /destination
```

### Изменение приоритета запущенного процесса

```bash
# Установить для процесса с <PID> высокий приоритет в классе Best-effort
sudo ionice -c2 -n0 -p <PID>

# Установить для MySQL самый высокий Realtime приоритет (использовать с осторожностью!)
sudo ionice -c1 -p $(pgrep mysqld)
```

### Проверка текущего приоритета

```bash
# Проверить приоритет I/O для процесса с PID 1234
ionice -p 1234
```

## Дополнительная информация

`ionice` является простым инструментом для управления приоритетами. Для более гранулярного контроля, особенно в контейнеризированных средах, используются **cgroups** (контрольные группы). Cgroups позволяют не только изменять приоритет, но и устанавливать жесткие лимиты на IOPS и пропускную способность для групп процессов.
