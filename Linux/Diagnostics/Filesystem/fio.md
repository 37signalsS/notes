# `fio`

## Определения

- **`fio` (Flexible I/O Tester):** Мощная утилита для бенчмаркинга и стресс-тестирования систем хранения данных (I/O). Позволяет эмулировать различные типы дисковой нагрузки и измерять ключевые метрики производительности.
- **BW (Bandwidth):** Пропускная способность, измеряется в мегабайтах в секунду (MB/s).
- **IOPS:** Операции ввода-вывода в секунду.
- **Latency (lat):** Задержки на выполнение операций.
- **Паттерны нагрузки:** Типы доступа к данным, симулируемые `fio` (последовательный/случайный, чтение/запись).
- **Механизмы I/O (`ioengine`):** Интерфейсы для взаимодействия с подсистемой ввода-вывода (например, `sync`, `libaio`, `io_uring`).

## Основные концепции

`fio` позволяет точно имитировать реальные сценарии использования диска, будь то нагрузка от базы данных (случайное чтение малых блоков), файлового сервера (последовательная запись больших блоков) или другой специфической задачи.

Выбор правильных паттернов нагрузки, механизмов I/O и других параметров позволяет получить репрезентативные данные о поведении системы хранения данных. Например, `libaio` и `io_uring` обеспечивают асинхронный ввод-вывод, что критично для тестирования современных высокопроизводительных хранилищ, тогда как `sync` подходит для более простых, синхронных операций.

Интерпретация результатов `fio` дает конкретные, измеримые показатели (например, "1500 IOPS при random read 4K с задержкой 15 ms"), что является более ценной информацией, чем субъективная оценка "диск медленный".

## Практические сценарии

### Базовый тест последовательной записи

```bash
# Записать 1GB данных блоками по 1MB в файл testfile
fio --name=seq_write --rw=write --bs=1M --size=1G --filename=./testfile
```

### Тест случайного чтения (типично для БД)

```bash
# Прочитать 1GB данных случайными блоками по 4KB
fio --name=rand_read --rw=randread --bs=4k --size=1G --filename=./testfile
```

### Смешанная нагрузка с несколькими потоками

```bash
# Эмулировать нагрузку с 4 потоками и глубиной очереди 32
fio --name=multithread --rw=randrw --bs=4k --numjobs=4 --iodepth=32 --size=1G --filename=./testfile --group_reporting
```

## Дополнительная информация

### Ключевые параметры для кастомизации

- `--rw`: Режим операции (`read`, `write`, `randread`, `randwrite`, `randrw`).
- `--bs`: Размер блока (например, `4k`, `1M`).
- `--size`: Общий объем данных для операции.
- `--numjobs`: Количество параллельных задач (потоков).
- `--ioengine`: Механизм I/O (`libaio`, `sync`, `io_uring`).
- `--iodepth`: Глубина очереди запросов для асинхронных движков.
