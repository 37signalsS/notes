# Диагностика файловых систем и дискового пространства

## 1. Определение

Эта заметка описывает базовые утилиты для анализа использования дискового пространства и просмотра смонтированных файловых систем в Linux.

## 2. Основные концепции

- **Файловая система vs. Дисковое пространство:** Файловая система — это структура для организации файлов на диске. Диагностика включает как проверку самой структуры (точки монтирования), так и анализ занятого/свободного пространства.
- **`df` (disk free) vs. `du` (disk usage):** `df` показывает сводную информацию о пространстве на уровне всей файловой системы, читая данные из суперблока. Это быстро. `du` рекурсивно обходит каталоги и подсчитывает реальный размер файлов, что медленнее, но точнее для конкретных директорий.
- **Inodes (индексные дескрипторы):** Каждому файлу и каталогу соответствует inode. Если на диске заканчиваются свободные inodes, новые файлы создавать нельзя, даже если есть свободное место.

## 3. Практические сценарии

### `mount`: Просмотр смонтированных систем
Утилита `mount` без аргументов показывает, какие файловые системы и куда примонтированы.
```bash
# Показать все точки монтирования
mount | column -t
```

### `df`: Анализ свободного пространства
Показывает использование дискового пространства на уровне файловых систем.
```bash
# Показать свободное место в человекочитаемом формате (GB, MB)
df -h

# Показать использование inode (важно для диагностики)
df -i
```
Если `df -i` показывает использование 100%, это означает, что исчерпаны индексные дескрипторы.

### `du`: Анализ занятого пространства
Подсчитывает, сколько места занимают конкретные файлы и директории.
```bash
# Узнать общий размер текущей директории
du -sh .

# Найти самые "тяжелые" директории внутри /var (на 1 уровень вглубь)
# sort -rh сортирует результат по убыванию
sudo du -h --max-depth=1 /var | sort -rh
```

## 4. Продвинутые детали
Для более глубокого анализа производительности дисков (I/O) используются специализированные инструменты, такие как [iostat](./Tools/iostat.md) и [iotop](./Tools/iotop.md), которые показывают статистику операций ввода-вывода, а не только занятое пространство.
