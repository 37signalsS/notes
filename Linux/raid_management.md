# Управление программным RAID с помощью mdadm

`mdadm` — это стандартная утилита в Linux для создания и управления программными RAID-массивами. Программный RAID позволяет объединять несколько дисков в один логический массив без необходимости в специальном RAID-контроллере.

## Уровни RAID

RAID — технология объединения нескольких дисков в один логический массив для повышения производительности или отказоустойчивости.

-   **RAID 0 (Striping)**: Максимальная производительность, нет отказоустойчивости.
-   **RAID 1 (Mirroring)**: Полная отказоустойчивость (зеркалирование), но теряется 50% ёмкости.
-   **RAID 5 (Striping with Parity)**: Баланс между скоростью и надёжностью. Выдерживает отказ одного диска. Минимум 3 диска.
-   **RAID 6 (Striping with Double Parity)**: Повышенная надёжность. Выдерживает отказ двух дисков. Минимум 4 диска.
-   **RAID 10 (1+0)**: Комбинация зеркалирования и чередования. Высокая скорость и надёжность. Минимум 4 диска.

## Создание и настройка

Процесс создания RAID-массива включает в себя несколько шагов:

1.  **Подготовка дисков:** Убедитесь, что у вас есть необходимое количество дисков или разделов, и они не содержат важных данных.

2.  **Создание массива:** Используйте команду `mdadm --create`.

    **Пример создания RAID 1 (зеркало) из двух дисков:**
    ```bash
    # /dev/md0 — имя будущего массива
    # --level=1 — уровень RAID (зеркало)
    # --raid-devices=2 — количество устройств в массиве
    # /dev/sdb и /dev/sdc — диски-участники
    sudo mdadm --create /dev/md0 --level=1 --raid-devices=2 /dev/sdb /dev/sdc
    ```

3.  **Сохранение конфигурации:** Чтобы массив автоматически собирался при загрузке, сохраните его конфигурацию в файл `mdadm.conf`.
    ```bash
    # Эта команда просканирует существующие массивы и добавит их в файл конфигурации
    sudo mdadm --detail --scan | sudo tee -a /etc/mdadm/mdadm.conf
    ```

4.  **Создание файловой системы:** После создания массива на нём можно создать файловую систему, как на обычном диске.
    ```bash
    sudo mkfs.ext4 /dev/md0
    ```

5.  **Монтирование:** Смонтируйте массив и добавьте его в `/etc/fstab` для автоматического монтирования при загрузке.

## Мониторинг

Для мониторинга состояния программного RAID-массива используйте:
```bash
# Показывает детальную информацию о конкретном массиве
sudo mdadm --detail /dev/md0

# Краткая информация о всех активных массивах (часто используется в скриптах)
cat /proc/mdstat
```
