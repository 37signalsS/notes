# Виртуальная файловая система /proc (procfs)

## Определения

- **procfs:** Виртуальная файловая система в Linux, монтируемая в каталог `/proc`. Она предоставляет интерфейс к структурам данных ядра в реальном времени, позволяя получать информацию о состоянии системы и запущенных процессах, а также изменять параметры ядра.
- **PID (Process Identifier — идентификатор процесса):** Уникальный числовой номер, присваиваемый ядром каждому запущенному процессу.
- **Всё есть файл:** Принцип Unix-систем, согласно которому доступ к системным ресурсам и информации ядра осуществляется через стандартные операции работы с файлами (`read`, `write`).

## Основные концепции

### Механизм взаимодействия

Содержимое `/proc` не хранится на физическом диске, а генерируется ядром "на лету" при обращении к файлам. Это обеспечивает абсолютную актуальность данных, но требует понимания того, что информация существует только в оперативной памяти (**RAM**).

### Структура каталога /proc

Иерархия `/proc` разделена на две основные части:

1. **Каталоги процессов (`/proc/[PID]/`):** Содержат информацию о каждом конкретном процессе.
2. **Системные файлы:** Расположены в корне `/proc` и подкаталогах (например, `/proc/sys/`), предоставляют общую статистику системы и интерфейс настройки ядра.

### Информация о процессах (/proc/[PID]/)

Для каждого процесса ядро экспортирует набор файлов, описывающих его состояние:

- `cmdline`: Полная командная строка запуска.
- `environ`: Переменные окружения процесса.
- `exe`: Символическая ссылка на исполняемый файл.
- `fd/`: Каталог с дескрипторами всех открытых процессом файлов и сокетов.
- `status`: Человекочитаемая сводка (потребление памяти, права, состояние).
- `maps`: Карта распределения адресного пространства памяти.
- `io`: Статистика ввода-вывода (I/O) процесса.

## Практические сценарии

### Исследование работающего процесса

Просмотр параметров запуска и окружения процесса (например, с PID 1234):

```bash
# Получить переменные окружения (разделены нулевым байтом, меняем на перевод строки)
cat /proc/1234/environ | tr '\0' '\n'

# Узнать, откуда запущен бинарный файл
ls -l /proc/1234/exe
```

### Восстановление удаленных файлов

Если файл был удален командой `rm`, но процесс всё еще удерживает его открытым, данные остаются на диске. Их можно скопировать через файловый дескриптор:

1. Найти номер дескриптора (например, через `lsof | grep deleted`).
2. Скопировать данные:

   ```bash
   # Где 7 — номер дескриптора удаленного файла
   cp /proc/1234/fd/7 /tmp/restored_file.txt
   ```

### Изменение параметров ядра (sysctl)

Каталог `/proc/sys/` позволяет изменять настройки ядра без перезагрузки. Это является основой работы утилиты `sysctl`.

```bash
# Включение пересылки трафика (IP Forwarding)
echo 1 | sudo tee /proc/sys/net/ipv4/ip_forward
```

Подробнее: **[Настройка параметров ядра (sysctl)](../Core/kernel/sysctl.md)**.

### Освобождение места при открытых дескрипторах

Если диск переполнен из-за лог-файла, который нельзя удалить (так как процесс не закроет дескриптор), файл можно обнулить:

```bash
# Обнуление удаленного, но удерживаемого файла через дескриптор
: > /proc/1234/fd/4
```

Подробнее: **[Устранение нехватки места на диске](./disk_space_troubleshooting.md)**.

## Дополнительная информация

### Ключевые системные файлы

- **[/proc/cpuinfo](../Diagnostics/Hardware/cpu_info.md):** Детальные характеристики процессоров.
- **[/proc/meminfo](../Diagnostics/Memory/proc_meminfo.md):** Подробная статистика использования оперативной памяти.
- **[/proc/devices](./virtual_fs_dev.md):** Список зарегистрированных символьных и блочных устройств.
- **[/proc/pressure/](../Core/kernel/psi.md):** Статистика давления на ресурсы (**PSI**, Pressure Stall Information).
- **`/proc/mounts`:** Список смонтированных файловых систем (ссылка на актуальную таблицу монтирования).
