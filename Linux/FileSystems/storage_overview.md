# Управление хранилищами в Linux: Обзор

## Определения

- **Блочное устройство (Block Device):** Низкоуровневое представление накопителя (HDD, SSD, NVMe, раздел диска, LVM-том), с которым ядро взаимодействует, оперируя блоками данных. Подробнее см. в [device_types.md](Linux/FileSystems/device_types.md).
- **Раздел (Partition):** Часть физического диска, размеченная с помощью таблицы разделов (MBR или GPT). Каждый раздел может рассматриваться как отдельное блочное устройство. Подробнее см. в [partitions_and_filesystems.md](Linux/FileSystems/partitions_and_filesystems.md).
- **Файловая система (Filesystem):** Структура данных (`ext4`, `XFS`), которая позволяет ОС хранить, организовывать и находить файлы на блочном устройстве. Подробнее см. в [partitions_and_filesystems.md](Linux/FileSystems/partitions_and_filesystems.md).
- **Монтирование (Mounting):** Процесс подключения файловой системы к определённому каталогу в общей структуре каталогов Linux. Подробнее см. в [mounting.md](./mounting/index.md).

## Основные концепции

Управление хранилищами в Linux представляет собой многоуровневую систему, где каждый слой выполняет свою задачу:

1. **Физический диск:** Аппаратное устройство (`/dev/sda`).
2. **Таблица разделов:** Структура данных на диске (GPT/MBR), которая делит его на разделы.
3. **Раздел:** Логическая область диска (`/dev/sda1`), которая выступает как самостоятельное блочное устройство.
4. **Слои виртуализации (опционально):** Технологии вроде **LVM**, **RAID** или **LUKS** могут объединять или преобразовывать блочные устройства.
5. **Файловая система:** Структура, созданная поверх блочного устройства для хранения файлов.
6. **Точка монтирования:** Каталог в файловой системе, через который осуществляется доступ к данным.

## Практические сценарии

### Подготовка и использование нового диска

1. **Найти диск** с помощью `lsblk`.
2. **(Опционально) Создать разделы** с помощью `fdisk` или `parted`.
3. **Создать файловую систему (форматирование):**
    *ВНИМАНИЕ: Эта команда уничтожит все данные на устройстве.*

    ```bash
    sudo mkfs.ext4 /dev/sdb1
    ```

4. **Выполнить временное монтирование:**

    ```bash
    sudo mkdir /data
    sudo mount /dev/sdb1 /data
    ```

5. **Настроить автоматическое монтирование:** Для постоянного монтирования при загрузке системы используется файл `/etc/fstab`.
    - **См. подробнее:** [Монтирование файловых систем и /etc/fstab](./mounting.md)

### Шифрование диска с помощью LUKS

**LUKS (Linux Unified Key Setup)** — стандарт для шифрования блочных устройств.

1. **Инициализация LUKS:**

    ```bash
    sudo cryptsetup luksFormat /dev/sdb1
    ```

2. **Открытие (расшифровка) тома:** Создает виртуальное блочное устройство в `/dev/mapper/`.

    ```bash
    sudo cryptsetup luksOpen /dev/sdb1 my_encrypted_volume
    ```

3. **Работа с расшифрованным томом:** Далее с устройством `/dev/mapper/my_encrypted_volume` можно работать как с обычным: создать на нем файловую систему и смонтировать.

## Дополнительная информация

- **LVM (Logical Volume Manager):** Объединение дисков в пулы, динамическое изменение размеров и создание снимков.
  - **Подробности:** [LVM (Logical Volume Manager)](./lvm.md)

- **RAID (Redundant Array of Independent Disks):** Объединение дисков в массив для повышения производительности и/или отказоустойчивости.
  - **Подробности:** [Управление программным RAID с помощью mdadm](./raid_management.md)
