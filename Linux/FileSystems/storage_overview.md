# Обзор управления хранилищами в Linux

Управление дисковым пространством в Linux — это многоуровневый процесс, который включает в себя работу с физическими устройствами, их логическое объединение и представление в виде файловых систем, доступных пользователю.

## 1. Определения и основные концепции

1.  **Блочное устройство (Block Device):** Низкоуровневое представление физического или виртуального накопителя (HDD, SSD, NVMe, раздел диска, LVM-том). Ядро Linux взаимодействует с ним, оперируя блоками данных.

2.  **Раздел (Partition):** Часть физического диска, размеченная с помощью таблицы разделов (MBR или GPT). Каждый раздел может рассматриваться как отдельное блочное устройство.

3.  **Файловая система (Filesystem):** Структура данных, которая позволяет операционной системе хранить, организовывать и находить файлы на блочном устройстве. Примеры: `ext4`, `XFS`, `Btrfs`.

4.  **Монтирование (Mounting):** Процесс подключения файловой системы, находящейся на блочном устройстве, к определённому каталогу в общей структуре каталогов Linux (например, к `/data`).

## 2. Базовые практические сценарии

### 2.1. Подготовка и монтирование нового диска

Это фундаментальная последовательность действий для введения нового накопителя в эксплуатацию.

1.  **Определение диска:**
    Найти блочное устройство с помощью `lsblk`.
    ```bash
    lsblk
    ```

2.  **Создание файловой системы (Форматирование):**
    **ВНИМАНИЕ:** Эта команда уничтожит все данные на устройстве.
    ```bash
    # Форматирование в ext4 с меткой 'data'
    sudo mkfs.ext4 -L data /dev/sdb
    ```

3.  **Монтирование:**
    ```bash
    sudo mkdir /data
    sudo mount /dev/sdb /data
    ```

4.  **Настройка автоматического монтирования (`/etc/fstab`):**
    Для надежности используется уникальный идентификатор **UUID**.
    ```bash
    # 1. Получить UUID
    sudo blkid /dev/sdb

    # 2. Добавить запись в /etc/fstab
    # UUID=<ваш_uuid>  /data  ext4  defaults  0  2
    ```

### 2.2. Шифрование диска с помощью LUKS

**LUKS (Linux Unified Key Setup)** — стандарт для шифрования дисков, обеспечивающий защиту данных.

1.  **Инициализация LUKS на разделе:**
    ```bash
    sudo cryptsetup luksFormat /dev/sdb1
    ```

2.  **Открытие (расшифровка) тома:**
    Это создаст виртуальное блочное устройство в `/dev/mapper/`.
    ```bash
    sudo cryptsetup luksOpen /dev/sdb1 my_encrypted_volume
    ```

3.  **Форматирование и монтирование:**
    Теперь с расшифрованным томом можно работать как с обычным устройством.
    ```bash
    sudo mkfs.ext4 /dev/mapper/my_encrypted_volume
    sudo mkdir /mnt/encrypted_data
    sudo mount /dev/mapper/my_encrypted_volume /mnt/encrypted_data
    ```

## 3. Продвинутые технологии хранения

Для более гибкого и надёжного управления хранилищами используются технологии, которые абстрагируют физические устройства от логического представления.

-   **LVM (Logical Volume Manager):** Позволяет объединять диски в пулы, динамически изменять размеры томов и создавать снимки. Является стандартом де-факто для гибкого управления пространством на серверах.
    -   **Подробности в заметке:** [LVM (Logical Volume Manager)](./lvm.md)

-   **RAID (Redundant Array of Independent Disks):** Технология объединения нескольких дисков в массив для повышения производительности (RAID 0), отказоустойчивости (RAID 1, 5, 6) или и того, и другого (RAID 10).
    -   **Подробности в заметке:** [Управление программным RAID с помощью mdadm](./raid_management.md)
