# Проверка и восстановление целостности ФС (fsck)

### Определения

**`fsck` (File System Check)** — это стандартная утилита в Unix-подобных системах для проверки целостности файловой системы и исправления обнаруженных в ней ошибок.

### Основные концепции

-   **Запуск на размонтированном разделе:** `fsck` всегда должна запускаться на **размонтированной** файловой системе. Попытка запустить проверку на смонтированном разделе может привести к дальнейшему повреждению данных.
-   **Автоматическая проверка:** Система обычно автоматически запускает `fsck` при загрузке, если файловая система была помечена как "грязная" (например, после аварийного выключения питания).

### Практические сценарии

#### Стандартное использование

Принудительная проверка файловой системы (например, ext2/3/4) на разделе `/dev/sdXN`.
```bash
# Ключ -f (force) заставляет fsck проверить файловую систему, даже если она помечена как "чистая".
sudo fsck -f /dev/sdXN
```

#### Особенности для файловой системы XFS

Стандартная утилита `fsck` не работает для XFS. Вместо нее используется специализированная команда `xfs_repair`.
```bash
# Для проверки и восстановления целостности XFS
sudo xfs_repair /dev/sdXN
```
`fsck.xfs` существует, но является лишь оберткой и не выполняет реального исправления.
