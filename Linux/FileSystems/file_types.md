# Типы файлов в Linux

## Определения

В Linux, согласно принципу "всё есть файл", даже устройства и каналы взаимодействия между процессами представлены в файловой системе. Тип файла определяет его назначение и способ взаимодействия с ним. Узнать тип файла можно по первому символу в выводе команды `ls -l`.

## Основные типы файлов

| Символ | Тип файла | Описание и примеры |
| :--- | :--- | :--- |
| **`-`** | **Обычный файл (Regular File)** | Наиболее распространенный тип. Содержит данные, такие как текст, изображения или исполняемый код программы. |
| **`d`** | **Каталог (Directory)** | Специальный файл, который содержит список других файлов и каталогов, а также ссылки на их `inode`. |
| **`l`** | **Символическая ссылка (Symbolic Link)** | Файл-указатель, который ссылается на другой файл или каталог по его имени. Подробнее см. в [Cсылки, Inode и Dentry](./links_inodes_dentries.md). |
| **`b`** | **Блочное устройство (Block Device)** | Файл, представляющий устройство, которое передает данные блоками (например, жесткие диски `/dev/sda`, SSD). Подробнее см. в [Типы устройств](./device_types.md). |
| **`c`** | **Символьное устройство (Character Device)** | Файл, представляющий устройство, которое передает данные посимвольно (например, терминалы `/dev/tty`, последовательные порты). Подробнее см. в [Типы устройств](./device_types.md). |
| **`s`** | **Сокет (Socket)** | Файл, используемый для межпроцессного взаимодействия (IPC), позволяющий обмениваться данными между процессами на одной или разных машинах. |
| **`p`** | **Именованный канал (Named Pipe / FIFO)** | Файл, который действует как канал "первым вошел — первым вышел" (First-In, First-Out) для однонаправленной связи между процессами. |

## Практические сценарии

### Как определить тип файла

Используйте команду `ls -l` для просмотра подробной информации о файле, где первый символ в строке указывает на его тип.

```bash
# ls -l /dev/sda /dev/tty /etc/hosts /var/log /tmp/mysql.sock
brw-rw---- 1 root disk 8, 0 фев 25 10:00 /dev/sda     # Блочное устройство
crw-rw-rw- 1 root tty  4, 0 фев 25 10:00 /dev/tty     # Символьное устройство
-rw-r--r-- 1 root root 158 фев 25 10:00 /etc/hosts   # Обычный файл
lrwxrwxrwx 1 root root  25 фев 25 10:00 /var/log -> /path/to/logs # Символическая ссылка
srwxrwxrwx 1 mysql mysql 0 фев 25 10:00 /tmp/mysql.sock # Сокет
```
