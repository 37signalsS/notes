# Типы файлов в Linux

## Определения

- **Тип файла:** Свойство объекта в файловой системе, определяющее его структуру, назначение и набор допустимых операций ввода-вывода. Тип файла кодируется в поле режима (**mode**) индексного дескриптора (**Inode**).
- **Всё есть файл (Everything is a file):** Фундаментальная концепция архитектуры Unix/Linux, при которой доступ к аппаратным ресурсам, потокам данных и системным интерфейсам осуществляется через стандартные системные вызовы работы с файлами (`open`, `read`, `write`, `close`).

## Основные концепции

В Linux существует 7 стандартных типов файлов. Их можно идентифицировать по первому символу строки разрешений в выводе команды `ls -l` или с помощью системных вызовов (поле `st_mode` структуры `stat`).

### Классификация типов файлов

| Символ | Тип файла | Английское название | Описание |
| :---: | :--- | :--- | :--- |
| **`-`** | **Обычный файл** | Regular File | Последовательность байтов. Сюда относятся текстовые документы, исполняемые бинарные файлы (ELF), изображения, архивы. |
| **`d`** | **Каталог** | Directory | Специальный файл, содержащий список имен объектов и сопоставленные им номера Inode. |
| **`l`** | **Символическая ссылка** | Symbolic Link | Файл, содержащий путь к другому объекту. Подробнее: [Inode и ссылки](./links_inodes_dentries.md). |
| **`b`** | **Блочное устройство** | Block Device | Интерфейс к оборудованию, обменивающемуся данными блоками фиксированного размера (диски, RAID-массивы). |
| **`c`** | **Символьное устройство** | Character Device | Интерфейс к оборудованию с побайтовой передачей данных (терминалы, клавиатуры, `/dev/null`). |
| **`p`** | **Именованный канал** | Named Pipe (FIFO) | Объект для межпроцессного взаимодействия (IPC), работающий по принципу очереди «первым пришел — первым ушел». |
| **`s`** | **Сокет** | Unix Domain Socket | Точка связи для двунаправленной передачи данных между процессами на одной машине. |

### Метаданные и диагностика

Тип файла является статическим свойством и не зависит от расширения. Ядро определяет тип по значению битов в структуре Inode.

1. **Команда `ls -l`**: Самый простой способ визуальной проверки типа.
2. **Команда `stat`**: Предоставляет полную информацию из Inode, включая тип в текстовом и восьмеричном виде.
3. **Команда `file`**: Определяет тип контента обычных файлов путем анализа «магических чисел» (Magic Numbers).

## Практические сценарии

### Идентификация через `stat`

Команда `stat` показывает тип файла в поле «File:»:

```bash
stat /etc/passwd
# → File: /etc/passwd
# → Size: 2575 Blocks: 8 IO Block: 4096 regular file
```

### Поиск файлов по типу

Утилита `find` позволяет эффективно фильтровать объекты по их типу:

```bash
# Найти все символические ссылки в /etc
sudo find /etc -type l

# Найти все сокеты в системе
sudo find / -type s 2>/dev/null

# Найти все блочные устройства
find /dev -type b
```

### Создание специальных объектов

Создание FIFO и сокетов (обычно сокеты создаются программно):

```bash
# Создание именованного канала
mkfifo /tmp/test_pipe

# Создание символической ссылки
ln -s /etc/hostname ~/my_host
```

## Устранение неполадок

- **«Битые» ссылки (Dangling Links):** Символическая ссылка типа `l` может указывать на несуществующий путь. При попытке обращения возникнет ошибка «No such file or directory», хотя файл ссылки существует.
- **Ошибки типов в Docker/контейнерах:** Некоторые типы файлов (например, устройства `/dev/fuse`) требуют специальных привилегий или проброса внутрь контейнера для корректной работы.
