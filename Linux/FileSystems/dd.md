# Утилита dd

## Определения

- **`dd` (Dataset Definition):** Низкоуровневая утилита командной строки для Unix-подобных систем, предназначенная для копирования и преобразования данных поблочно. Благодаря прямому доступу к устройствам позволяет выполнять операции, недоступные обычным средствам копирования файлов.
- **Поблочное копирование:** Метод передачи данных, при котором информация считывается и записывается фиксированными порциями (блоками) определённого размера.
- **Образ диска (Image):** Файл, содержащий полную копию структуры и данных носителя (сектор за сектором).

## Основные концепции

Утилита `dd` работает с потоками данных, последовательно считывая их из источника и записывая в место назначения.

### Ключевые параметры

- **`if=<source>` (Input File):** Путь к источнику данных. Это может быть обычный файл или файл устройства (например, `/dev/sda`). По умолчанию используется `stdin`.
- **`of=<destination>` (Output File):** Путь к месту назначения. Если файл не существует, он будет создан; если существует — перезаписан. По умолчанию используется `stdout`.
- **`bs=<size>` (Block Size):** Размер блока для чтения и записи. Рекомендуется использовать значения кратные степени двойки (например, `bs=4M` для 4 мегабайт) для повышения производительности **I/O (Input/Output)**.
- **`count=<n>`:** Количество блоков, которые необходимо скопировать. Используется для создания файлов фиксированного размера или копирования части данных.
- **`status=<level>`:** Управляет выводом информации в консоль. Флаг `status=progress` включает отображение индикатора выполнения и скорости копирования в реальном времени.

## Практические сценарии

### 1. Создание и восстановление образов

Создание полной копии диска или раздела:

```bash
# Создать образ диска /dev/sda в файл sda.img
sudo dd if=/dev/sda of=/path/to/sda.img bs=4M status=progress
```

Восстановление данных из образа:

```bash
# Записать содержимое образа обратно на физическое устройство
sudo dd if=/path/to/sda.img of=/dev/sdb bs=4M status=progress
```

> **Внимание:** Команда полностью уничтожает существующие данные на целевом устройстве (`of`).

### 2. Безопасное удаление данных

Заполнение диска нулями или случайными данными для предотвращения восстановления:

```bash
# Затирка диска нулями
sudo dd if=/dev/zero of=/dev/sda bs=4M status=progress

# Затирка случайными данными (более надежно)
sudo dd if=/dev/urandom of=/dev/sda bs=4M status=progress
```

### 3. Тестирование производительности

Измерение скорости работы дисковой подсистемы:

```bash
# Тест скорости записи файла объемом 1 ГБ (Gigabyte) в обход кэша ОС
dd if=/dev/zero of=testfile bs=1G count=1 oflag=direct

# Тест скорости чтения созданного файла
dd if=testfile of=/dev/null bs=1G
```

### 4. Создание файлов заданного размера

Применяется для создания файлов подкачки (**Swap**) или контейнеров для **LVM (Logical Volume Manager)**:

```bash
# Создать пустой файл размером 2 ГБ
dd if=/dev/zero of=storage.img bs=1G count=2
```

### 5. Генерация нагрузки на CPU

Симуляция высокой активности **CPU (Central Processing Unit)** для тестирования мониторинга:

```bash
# Чтение данных из быстрого источника в "пустоту" загружает одно ядро на 100%
dd if=/dev/zero of=/dev/null
```

## Дополнительная информация

- **Безопасность:** Для гарантированного уничтожения данных рекомендуется использовать утилиту `shred`.
- **Альтернативы:** Для восстановления данных с поврежденных носителей лучше подходит `ddrescue`, так как она умеет пропускать битые сектора.
