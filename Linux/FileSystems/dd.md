# dd

## Определения

**`dd` (dataset definition)** — это низкоуровневая утилита командной строки в Unix-подобных системах, предназначенная для копирования и преобразования данных поблочно. Из-за своей мощи и прямого доступа к устройствам её иногда в шутку называют "disk destroyer", так как одна ошибка в команде может привести к полной потере данных.

## Основные концепции

`dd` работает с потоками данных, читая их из источника (`if`) и записывая в назначение (`of`).

- **`if=<source>`**: Входной файл (input file). Источник, откуда будут читаться данные. По умолчанию — `stdin`.
- **`of=<destination>`**: Выходной файл (output file). Назначение, куда будут записываться данные. По умолчанию — `stdout`.
- **`bs=<bytes>`**: Размер блока (block size). Устанавливает размер одного блока для чтения и записи. Например, `bs=4M` означает 4 мегабайта. Оптимальный размер блока может сильно влиять на производительность.
- **`count=<n>`**: Количество блоков. Копировать только `n` блоков указанного размера.
- **`status=<level>`**: Уровень вывода информации. `status=progress` показывает индикатор выполнения в реальном времени.

## Практические сценарии

### 1. Создание образа диска или раздела

Это один из самых частых сценариев использования.

```bash
# Создать полный образ диска /dev/sda в файл sda.img
sudo dd if=/dev/sda of=/path/to/sda.img bs=4M status=progress
```

### 2. Восстановление диска из образа

```bash
# Записать образ sda.img на диск /dev/sdb
sudo dd if=/path/to/sda.img of=/dev/sdb bs=4M status=progress
```
**Внимание!** Эта команда полностью перезапишет все данные на `/dev/sdb`.

### 3. Полная очистка диска (затирание данных)

`dd` можно использовать для безопасного удаления данных путем перезаписи диска нулями или случайными данными.

```bash
# Записать нулями весь диск. Данные будут уничтожены.
sudo dd if=/dev/zero of=/dev/sda bs=4M status=progress

# Записать случайными данными для большей безопасности
sudo dd if=/dev/urandom of=/dev/sda bs=4M status=progress
```

### 4. Тестирование производительности диска

Можно измерить скорость записи и чтения.

```bash
# Тест скорости записи: пишем файл размером 1ГБ
dd if=/dev/zero of=testfile bs=1G count=1 oflag=direct

# Тест скорости чтения
dd if=testfile of=/dev/null bs=1G
```
`oflag=direct` используется для обхода кэша и измерения "чистой" скорости диска.

### 5. Создание файла-образа (swap, LVM и др.)

`dd` отлично подходит для быстрого создания файлов заданного размера.

```bash
# Создать пустой файл размером 2 ГБ
dd if=/dev/zero of=swapfile bs=1G count=2
```

### 6. Генерация системной нагрузки для стресс-тестирования

Хотя `dd` — это утилита для работы с вводом-выводом, её можно использовать для создания высокой нагрузки на CPU.

```bash
# Генерировать нагрузку на одно ядро CPU
dd if=/dev/zero of=/dev/null
```
- **Как это работает:** Команда непрерывно читает нули из `/dev/zero` (очень быстрый псевдо-источник) и отправляет их в `/dev/null` ("черную дыру"). Фактической записи на диск не происходит, но процесс копирования данных в памяти полностью загружает одно ядро процессора.
- **Применение:** Это простой способ симулировать 100% загрузку CPU на одном ядре для тестирования систем мониторинга, автоскейлинга или для проверки реакции системы на перегрузку. Для загрузки нескольких ядер можно запустить несколько таких команд параллельно.
