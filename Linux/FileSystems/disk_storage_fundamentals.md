# Основы хранения данных

## Определения

- **Блок (Block):** Минимальная адресуемая единица данных, которой оперирует файловая система.
- **Сектор (Sector):** Минимальная адресуемая единица хранения данных на физическом диске.
- **HDD (Hard Disk Drive):** Накопитель на магнитных дисках с вращающимися пластинами.
- **SSD (Solid-State Drive):** Накопитель на основе флеш-памяти без подвижных частей.

## Основные концепции

### Эволюция носителей информации

- **Магнитные ленты:** Используются для долгосрочного хранения и бэкапов (LTO). Последовательный доступ.
- **HDD:** Медленный произвольный доступ из-за механических частей.
- **SSD:** Высокая скорость произвольного доступа, ограниченный ресурс циклов перезаписи.

### Низкоуровневая адресация диска

- **CHS (Cylinder-Head-Sector):** Устаревший метод физической адресации по координатам.
- **LBA (Logical Block Addressing):** Современный метод, где каждый сектор имеет уникальный последовательный номер. Контроллер диска преобразует логический адрес в физический.

### Современные размеры секторов

- **512n (Native):** Логический и физический секторы по 512 байт.
- **512e (Emulation):** Физический сектор 4 КБ, логический 512 байт (для обратной совместимости). Наиболее распространен.
- **4Kn (4K Native):** Логический и физический секторы по 4 КБ. Обеспечивает лучшую производительность.

### Фрагментация

- **Суть:** Файл записывается в несмежные блоки на диске.
- **Влияние на HDD:** Значительно замедляет доступ из-за перемещения головок.
- **Влияние на SSD:** Менее критично, но может влиять на ресурс ячеек.

## Практические сценарии

### Проблема выравнивания разделов (Partition Alignment)

- **Проблема:** При использовании дисков 512e, если раздел начинается с адреса, не кратного 4 КБ, одна операция записи файловой системы (4 КБ) может потребовать чтения и записи двух физических 4К-блоков диска (Read-Modify-Write), что снижает производительность.
- **Решение:** Современные утилиты разметки (`parted`, `fdisk`) автоматически выравнивают разделы по границам мегабайта.

### Дефрагментация

- **HDD:** Рекомендуется для поддержания производительности.
- **SSD:** **Не рекомендуется**, так как не дает значительного прироста скорости, но расходует ограниченный ресурс ячеек памяти.
