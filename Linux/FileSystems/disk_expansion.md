# Расширение дискового пространства в Linux

## Определения

- **Расширение (Expansion):** Процесс увеличения доступной емкости запоминающего устройства. В Linux это многоэтапная операция, затрагивающая разные уровни абстракции (физический диск → таблица разделов → логические тома → файловая система).
- **Файловая система (ФС):** Способ организации данных на носителе. Расширение ФС позволяет ОС использовать новое пространство внутри раздела или логического тома.
- **growpart:** Утилита для автоматического расширения раздела диска до максимально возможного размера без потери данных и размонтирования.
- **Rescan:** Операция принудительного уведомления ядра Linux об изменении размера физического или виртуального диска (актуально для облачных сред и виртуализации).

## Основные концепции

### Иерархия уровней расширения

Расширение всегда выполняется "снизу вверх":

1. **Уровень диска:** Увеличение объема физического накопителя или виртуального диска в гипервизоре.
2. **Уровень разделов:** Изменение границ раздела в таблице разделов (MBR или **GPT (GUID Partition Table)**).
3. **Уровень LVM (опционально):** Расширение физического тома (**PV (Physical Volume)**), группы томов (**VG (Volume Group)**) и логического тома (**LV (Logical Volume)**).
4. **Уровень файловой системы:** Финальный этап, на котором ФС адаптирует свои структуры под новый размер "контейнера".

### Приоритет безопасности

Любые манипуляции с разделами несут риск потери данных.

- **Рекомендация:** Всегда создавайте резервную копию (**Snapshot** или **Backup**) перед началом работ.
- **Инструменты диагностики:** Используйте `lsblk`, `df -h` и `fdisk -l` для верификации текущего состояния на каждом этапе.

## Практические сценарии

### Шаг 0: Принудительное обновление информации о диске (Rescan)

Если диск был увеличен в гипервизоре или облачной панели "на горячую", ядро может не увидеть новый объем сразу.

```bash
# Обновление информации для конкретного диска (например, sda)
echo 1 | sudo tee /sys/class/block/sda/device/rescan
```

### Сценарий 1: Исправление GPT Backup Header

При расширении диска с разметкой GPT резервная копия таблицы разделов остается в старом конце диска, что блокирует расширение.

```bash
# Использование gdisk для перемещения структур данных в новый конец диска
sudo gdisk /dev/sda
# В меню gdisk:
# x — expert mode
# e — relocate backup data structures to the end of the disk
# w — save changes and exit
```

### Сценарий 2: Расширение раздела через growpart (рекомендуемый)

Самый безопасный способ расширения разделов "на лету" (online).

**1. Установка (при необходимости):**

- **Debian/Ubuntu:** `sudo apt install cloud-guest-utils`
- **RHEL/CentOS:** `sudo yum install cloud-utils-growpart`

**2. Расширение раздела и ФС:**

```bash
# Расширить раздел 1 на диске sda
sudo growpart /dev/sda 1

# Расширить ФС ext4
sudo resize2fs /dev/sda1

# Расширить ФС XFS (указывается точка монтирования)
sudo xfs_growfs /
```

### Сценарий 3: Особенности расширения в LVM

Для систем с **LVM (Logical Volume Manager)** добавляется этап адаптации физического тома.

1. **Расширение раздела:** `sudo growpart /dev/sda 3`
2. **Адаптация PV:** `sudo pvresize /dev/sda3`
3. **Расширение LV и ФС:**

   ```bash
   # Флаг -r автоматически вызывает нужную утилиту изменения размера ФС
   sudo lvextend -l +100%FREE -r /dev/mapper/vg_name-lv_name
   ```

Подробности в материале: **[Изменение размеров LVM](./LVM/operations/lvm_resize.md)**.

### Сценарий 4: Ручное расширение через fdisk (рискованный способ)

Применяется, если другие инструменты недоступны. Основан на пересоздании раздела с тем же начальным сектором.

1. Запустить `fdisk /dev/sda`.
2. Командой `p` зафиксировать **Start sector** расширяемого раздела.
3. Командой `d` удалить раздел.
4. Командой `n` создать раздел заново:
   - Указать тот же номер.
   - **Обязательно указать тот же Start sector.**
   - Конечный сектор — по умолчанию (до конца диска).
5. При запросе "Remove signature?" ответить **N** (No).
6. Командой `w` сохранить изменения.
7. Применить изменения в ядре: `sudo partprobe /dev/sda`.
8. Расширить ФС: `resize2fs /dev/sda1`.
