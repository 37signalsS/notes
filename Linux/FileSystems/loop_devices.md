# Петлевые устройства (Loop Devices)

## Определения

- **Loop Device (Петлевое устройство):** Псевдоустройство в ядре Linux, которое позволяет связать обычный файл с виртуальным блочным устройством (например, `/dev/loop0`). Это дает возможность работать с файлом-образом так же, как с физическим диском: форматировать его, монтировать или шифровать.
- **losetup:** Системная утилита, предназначенная для управления ассоциациями между файлами и петлевыми устройствами.

## Основные концепции

### Принцип работы

Драйвер петлевых устройств транслирует все операции ввода-вывода (**I/O**, Input/Output), направленные на устройство `/dev/loopX`, в соответствующие операции чтения и записи привязанного файла на диске. Этот процесс прозрачен для операционной системы и приложений: они "видят" стандартное блочное устройство, не зная, что за ним стоит файл.

### Способы назначения

1. **Автоматическое:** Ядро само находит первый свободный номер устройства при использовании флага `-o loop` в команде `mount`.
2. **Ручное:** Пользователь явно указывает устройство через `losetup`. Это необходимо для предварительной настройки (например, указания смещения внутри образа или лимита размера) перед монтированием.

## Практические сценарии

### 1. Управление через losetup

Базовые операции по привязке и отсоединению:

```bash
# Найти первое свободное устройство и привязать к нему файл
sudo losetup -f /path/to/disk.img

# Привязать файл к конкретному устройству
sudo losetup /dev/loop0 /path/to/disk.img

# Просмотреть список всех активных петлевых устройств
losetup -a

# Отсоединить файл от устройства
sudo losetup -d /dev/loop0
```

### 2. Работа с ISO-образами

Монтирование образа диска (**ISO**, International Organization for Standardization) для доступа к его содержимому:

```bash
# Автоматическое создание петлевого устройства и монтирование
sudo mount -o loop /path/to/image.iso /mnt/iso
```

### 3. Создание виртуального диска

Процесс создания и подготовки нового файла-образа:

```bash
# 1. Создать пустой файл размером 1 ГБ (Gigabyte)
fallocate -l 1G virtual_disk.img

# 2. Создать файловую систему внутри файла
mkfs.ext4 virtual_disk.img

# 3. Смонтировать как петлевое устройство
sudo mount -o loop virtual_disk.img /mnt/vdisk
```

### 4. Монтирование образов с разделами

Если файл-образ содержит таблицу разделов (например, полный бэкап **SD**-карты), можно использовать автоматическое сканирование разделов:

```bash
# -P: сканировать таблицу разделов внутри файла
# --show: вывести имя назначенного устройства
sudo losetup -P -f --show /path/to/full_image.img
# → результат: /dev/loop0

# Теперь разделы доступны как отдельные устройства (например, /dev/loop0p1)
sudo mount /dev/loop0p1 /mnt/partition1
```

### 5. Использование в шифровании (LUKS)

Петлевые устройства часто используются для создания зашифрованных контейнеров через **LUKS** (Linux Unified Key Setup):

```bash
# Привязать файл и инициализировать зашифрованный слой
sudo losetup /dev/loop0 secret.img
sudo cryptsetup luksFormat /dev/loop0
```

Подробнее о шифровании — в материале **[Управление хранилищами: Обзор](./storage_overview.md#шифрование-диска-с-помощью-luks)**.
