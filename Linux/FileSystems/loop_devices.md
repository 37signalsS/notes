# Loop Devices (Петлевые устройства)

## Определения

**Loop device** (петлевое устройство, также известное как `vnd` – vnode disk или `lofi` – loop file interface) — это псевдоустройство в Unix-подобных операционных системах, которое делает обычный компьютерный файл доступным в качестве блочного устройства.

Перед использованием петлевое устройство должно быть ассоциировано (подключено) к существующему файлу в файловой системе. Эта ассоциация позволяет использовать файл так, как если бы это был специальный блочный файл (например, `/dev/sda`). Если файл содержит целую файловую систему (например, образ диска), он может быть смонтирован как обычное дисковое устройство.

## Основные концепции

Ядро Linux предоставляет специальный драйвер, который позволяет связать файл с виртуальным блочным устройством вида `/dev/loopX` (где X — это номер). После связывания этот `/dev/loopX` можно использовать как обычный диск — создавать на нем файловую систему, монтировать, копировать файлы и т.д. Все операции чтения/записи к `/dev/loopX` транслируются ядром в соответствующие операции с файлом-образом.

## Практические сценарии

### Области применения

* **Автономное управление образами файловых систем:** Удобный метод для работы с образами дисков (например, ISO-образы CD/DVD или образы для установочных систем).
* **Установка операционной системы в файл:** Позволяет установить ОС в файл, расположенный в существующей файловой системе, без необходимости переразбиения физического диска.
* **Изоляция и инкапсуляция данных:** Дает возможность имитировать съемные носители или инкапсулировать зашифрованную файловую систему внутри обычного файла.
* **Создание виртуальных дисков:** Часто используется для создания виртуальных дисков для тестов, разработки или безопасного хранения данных.

### Примеры использования

#### Монтирование ISO-образа

Это наиболее частый сценарий использования, позволяющий получить доступ к содержимому ISO-файла без его записи на физический диск.

```bash
# Создаем точку монтирования
mkdir -p /mnt/iso

# Монтируем образ с помощью опции -o loop
sudo mount -o loop /path/to/image.iso /mnt/iso
```

Здесь `/path/to/image.iso` — это файл, содержащий файловую систему ISO 9660, а `/mnt/iso` — точка монтирования, куда будет доступно содержимое образа.

#### Создание и монтирование файла-образа

Этот метод позволяет создать "виртуальный диск" в виде файла.

```bash
# Создаем директорию для монтирования
mkdir -p /mnt/virtual_disk

# Создаем пустой файл-образ размером 1 ГБ
fallocate -l 1G /opt/disk.img

# Форматируем файл-образ в файловую систему ext4
# Система запросит подтверждение, так как /opt/disk.img не является блочным устройством
mkfs.ext4 /opt/disk.img

# Монтируем файл-образ через loop device
sudo mount -o loop /opt/disk.img /mnt/virtual_disk

# Проверяем результат
df -h /mnt/virtual_disk
```

Теперь директория `/mnt/virtual_disk` работает как обычный раздел, но все данные физически хранятся в файле `/opt/disk.img`.
