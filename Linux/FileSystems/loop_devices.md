# Loop Devices (Петлевые устройства)

**Loop device** (петлевое устройство, также известное как `vnd` – vnode disk или `lofi` – loop file interface) в Unix-подобных операционных системах является псевдоустройством, которое делает обычный компьютерный файл доступным в качестве блочного устройства.

Перед использованием петлевое устройство должно быть ассоциировано (подключено) к существующему файлу в файловой системе. Эта ассоциация предоставляет пользователю интерфейс прикладного программирования (API), который позволяет использовать файл так, как если бы это был специальный блочный файл (подобно файлу дискового устройства).

Таким образом, если файл содержит целую файловую систему (например, образ CD/DVD в формате ISO или образ дискеты), этот файл может быть смонтирован как обычное дисковое устройство. Файлы внутри этой вложенной файловой системы становятся доступными в указанной точке монтирования.

## Применение Loop Devices

Петлевое подключение имеет несколько важных применений:

*   **Автономное управление и редактирование образов файловых систем:** Это удобный метод для работы с образами дисков, которые в дальнейшем используются для нормальной работы системы (например, образы CD/DVD или установочные системы).
*   **Установка операционной системы в файл:** Можно установить операционную систему в файл, расположенный в существующей файловой системе, без необходимости переразбиения физического диска.
*   **Постоянное разделение данных:** Позволяет имитировать съемные носители на более быстром жестком диске или инкапсулировать зашифрованную файловую систему внутри обычного файла.
*   **Создание виртуальных дисков:** Часто используется для создания виртуальных дисков (например, для тестов, разработки или безопасного хранения данных) без выделения отдельного физического раздела.

## Как это работает

Ядро Linux предоставляет специальный драйвер, который позволяет связать файл с виртуальным блочным устройством `/dev/loopX` (где X — это число). После связывания этот `/dev/loopX` можно использовать как обычный диск — создавать на нем файловую систему, монтировать, копировать файлы и т.д. Все операции чтения/записи к `/dev/loopX` будут транслироваться в соответствующие операции с файлом-образом.

## Примеры использования

1.  **Монтирование ISO-образа:**
    ```bash
    sudo mount -o loop /path/to/image.iso /mnt/iso
    ```
    Здесь `/path/to/image.iso` — это файл, содержащий файловую систему ISO 9660, а `/mnt/iso` — точка монтирования, куда будет доступно содержимое образа.

2.  **Создание и монтирование файла-образа для файловой системы:**
    ```bash
    # Создание пустого файла размером 1 ГБ
    fallocate -l 1G /path/to/disk.img
    
    # Форматирование файла как ext4 файловой системы
    mkfs.ext4 /path/to/disk.img
    
    # Монтирование файла-образа через loop device
    sudo mount -o loop /path/to/disk.img /mnt/virtual_disk
    ```
    Теперь `/mnt/virtual_disk` работает как обычный раздел, но все данные хранятся в файле `/path/to/disk.img`.
