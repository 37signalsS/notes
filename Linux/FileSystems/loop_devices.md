# Петлевые устройства (Loop Devices)

## Определения

- **Loop Device (Петлевое устройство):** Псевдоустройство в ядре Linux (модуль `loop`), которое позволяет представить обычный файл как блочное устройство. Это позволяет монтировать образы дисков, создавать зашифрованные контейнеры или тестировать файловые системы без выделения физического накопителя.
- **losetup:** Основная системная утилита для управления связями между файлами и петлевыми устройствами (`/dev/loopX`).

## Основные концепции

### Принцип работы

Драйвер петлевого устройства выступает в роли транслятора: он перехватывает блочные запросы ввода-вывода (I/O) к устройству `/dev/loopX` и преобразует их в операции чтения/записи конкретных смещений внутри ассоциированного файла.

### Оптимизация производительности (Direct I/O)

По умолчанию операции с петлевыми устройствами проходят через системный **Page Cache** хоста. Это может привести к «двойному кэшированию» (кэширование на уровне файла-образа и внутри смонтированной ФС).
- **Флаг `--direct-io[=on|off]`:** Позволяет петлевому устройству обращаться к файлу-образу напрямую, минуя кэш хоста. Это снижает нагрузку на CPU и память при интенсивном I/O.

### Виды файлов-образов

1.  **Обычные файлы:** Создаются через `fallocate` (сразу резервируют место).
2.  **Разреженные файлы (Sparse Files):** Занимают место только по мере записи данных. Создаются через `truncate` или `dd`.

## Практические сценарии

### 1. Расширенная диагностика и вывод

Для автоматизации в скриптах рекомендуется использовать форматированный вывод.

```bash
# Список всех устройств в формате JSON
losetup -a --json

# Поиск первого свободного устройства без его захвата
losetup -f
```

### 2. Создание и монтирование разреженного диска

```bash
# 1. Создать "пустой" файл на 10 ГБ (реально занимает 0 байт)
truncate -s 10G my_disk.img

# 2. Привязать с включенным Direct I/O
sudo losetup --direct-io=on -f my_disk.img

# 3. Найти имя созданного устройства
DEV=$(losetup -j my_disk.img --raw | awk '{print $1}')

# 4. Форматирование и монтирование
sudo mkfs.xfs "$DEV"
sudo mount "$DEV" /mnt/test
```

### 3. Монтирование образов с разделами

Если образ содержит таблицу разделов (например, дамп SD-карты), используйте флаг `-P` (**Partscan**).

```bash
# Привязать и просканировать разделы
sudo losetup -P -f --show full_system.img
# -> Выведет: /dev/loop0

# Теперь разделы видны как /dev/loop0p1, /dev/loop0p2 и т.д.
ls /dev/loop0*
```

### 4. Отсоединение всех неиспользуемых устройств

```bash
# Безопасное отсоединение всех занятых файлов (кроме смонтированных)
sudo losetup -D
```

## Безопасность и ограничения

- **Только чтение:** Для защиты целостности эталонных образов монтируйте их с флагом `-r` или используйте `losetup -r`.
- **Лимиты:** Количество доступных устройств `/dev/loopX` регулируется параметром ядра `max_loop`. В современных ядрах устройства создаются динамически по мере необходимости.
- **Безопасное удаление:** Перед удалением файла-образа всегда выполняйте `umount` и `losetup -d`. Удаление файла при активной привязке может привести к ошибкам в ядре.
