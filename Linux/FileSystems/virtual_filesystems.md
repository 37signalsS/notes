# Виртуальные и псевдофайловые системы Linux

## Определения

- **VFS (Virtual File System):** Слой абстракции в ядре Linux, предоставляющий единый API для работы с различными типами файловых систем. Благодаря VFS приложения используют стандартные системные вызовы (`open`, `read`, `write`) независимо от типа ФС.

- **Псевдофайловая система:** Тип ФС, которая не управляет данными на физическом устройстве. Содержимое генерируется ядром "на лету" и хранится в оперативной памяти.

- **Tmpfs (Temporary File System):** Псевдофайловая система, хранящая данные в виртуальной памяти (RAM + swap). Данные не сохраняются после перезагрузки.

- **Cgroupfs (Control Group File System):** Псевдофайловая система — пользовательский интерфейс для контрольных групп ядра Linux.

## Основные концепции

### Как работают псевдофайловые системы

Ядро Linux перехватывает запросы к файлам псевдо-ФС, собирает информацию из внутренних структур данных и возвращает её как содержимое файла. Это позволяет использовать стандартные утилиты (`cat`, `echo`, `ls`) для взаимодействия с ядром.

### Tmpfs: хранение в памяти

- **Виртуальная память:** В отличие от `ramfs` (только RAM), `tmpfs` использует swap при нехватке ОЗУ.
- **Динамический размер:** Потребляет память по мере необходимости, не резервирует весь размер сразу.
- **Скорость:** Доступ к данным на порядки быстрее, чем к диску.

### Cgroupfs: управление ресурсами

- **Файловый интерфейс:** Монтируется в `/sys/fs/cgroup`, представляет иерархию контрольных групп как дерево каталогов.
- **Управление через файлы:** Запись в файлы задаёт лимиты ресурсов (CPU, память, I/O).
- **Контроллеры:** Различные подсистемы (`cpu`, `memory`, `io`) предоставляют свои наборы файлов.

## Практические сценарии

### Области применения Tmpfs

| Точка монтирования | Назначение |
| :--- | :--- |
| `/dev/shm` | Разделяемая память POSIX для межпроцессного взаимодействия |
| `/run` | Временные данные процессов (PID-файлы, сокеты) |
| `/tmp` | Временные файлы (во многих дистрибутивах) |

### Примеры использования Cgroupfs

- **Systemd:** Использует cgroups для управления службами — каждый сервис в своей группе.
- **Контейнеризация:** Docker, Podman, Kubernetes ограничивают ресурсы контейнеров через cgroups.

  ```bash
  # Docker: ограничение памяти
  docker run --memory=1g container_name
  ```

  Эта команда записывает значение в соответствующий файл `cgroupfs`.

### Монтирование tmpfs вручную

```bash
# Смонтировать tmpfs размером 512 МБ
sudo mount -t tmpfs -o size=512M tmpfs /mnt/my_tmpfs

# В /etc/fstab для автоматического монтирования
tmpfs /mnt/my_tmpfs tmpfs defaults,size=512M 0 0
```

## Дополнительная информация

### Ramfs vs Tmpfs

| Характеристика | Ramfs | Tmpfs |
| :--- | :--- | :--- |
| **Хранение** | Только RAM | RAM + swap |
| **Размер** | Динамический, без лимита | Можно задать лимит |
| **Выгрузка в swap** | Нет | Да |
| **Стабильность** | Может исчерпать RAM | Более гибкая |
