# FUSE (Filesystem in Userspace)

## Определения

**FUSE (Filesystem in Userspace)** — это интерфейс ядра Linux, который позволяет создавать файловые системы, работающие в пространстве пользователя (userspace), без необходимости написания и компиляции модулей ядра.

## Основные концепции

### Принцип работы

Инфраструктура FUSE состоит из модуля ядра и пользовательской библиотеки (libfuse). Модуль ядра выступает в роли "моста":

1. Приложение отправляет запрос к файловой системе (например, `ls` или `read`).
2. Ядро через VFS (Virtual File System) передает запрос модулю FUSE.
3. Модуль FUSE перенаправляет запрос пользовательскому процессу (демону), который реализует логику ФС.
4. Демон обрабатывает запрос и возвращает ответ ядру, которое передает его исходному приложению.

### Преимущества и недостатки

**Преимущества:**

* **Изоляция и стабильность:** Ошибки в коде файловой системы не приводят к критическому сбою ядра (Kernel Panic). При падении демона размонтируется только конкретная точка монтирования.
* **Гибкость:** Файловые системы можно реализовывать на любых языках программирования (C, Go, Python, Rust).
* **Безопасность:** Позволяет непривилегированным пользователям монтировать свои файловые системы.

**Недостатки:**

* **Производительность:** Каждый системный вызов требует многократного переключения контекста между ядром и пространством пользователя, что вносит задержки (overhead) по сравнению с нативными модулями ядра.

### Примеры применения

* **Сетевые ресурсы:** SSHFS, CephFS (FUSE-клиент).
* **Облачные хранилища:** Rclone mount (S3, Google Drive).
* **Контейнеризация:** `fuse-overlayfs` используется для управления слоями в rootless-контейнерах (см. [Podman rootless](../../Podman/podman_rootless.md)).
* **Специфические форматы:** NTFS-3G (драйвер NTFS), монтирование архивов, виртуальные ФС поверх API.

## Практические сценарии

### Монтирование удаленной директории через SSHFS

Инструмент `sshfs` позволяет работать с удаленными файлами так, будто они находятся на локальном диске.

1. **Установка:**

   ```bash
   sudo apt install sshfs
   ```

2. **Монтирование:**

   ```bash
   mkdir ~/remote_data
   sshfs user@remote-host:/path/to/dir ~/remote_data
   ```

3. **Размонтирование:**

   ```bash
   fusermount -u ~/remote_data
   ```

Подробные примеры и опции описаны в [Инструментах командной строки SSH](../Security/ssh/ssh_cli_tools.md#sshfs---монтирование-удалённой-фс).

### Работа с облачными хранилищами через Rclone

Rclone позволяет монтировать практически любое облачное хранилище как локальный диск.

1. **Монтирование:**

   ```bash
   # Предварительно настроенный конфиг с именем "remote_s3"
   mkdir ~/cloud_storage
   rclone mount remote_s3:bucket_name ~/cloud_storage --vfs-cache-mode writes &
   ```

2. **Проверка:**

   ```bash
   df -h | grep rclone
   ```
