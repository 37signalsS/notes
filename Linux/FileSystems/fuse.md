# FUSE (Filesystem in Userspace)

### Определения

**FUSE (Filesystem in Userspace)** — это интерфейс ядра Linux, который позволяет создавать файловые системы, работающие в пространстве пользователя (userspace), без необходимости писать код для ядра. Это значительно упрощает разработку и повышает безопасность.

### Основные концепции

#### Принцип работы FUSE

Модуль ядра FUSE действует как "мост". Он перенаправляет все запросы к виртуальной файловой системе от ядра к пользовательской программе-демону. Этот демон, работающий в userspace, реализует всю логику файловой системы: обработку операций чтения, записи, создания директорий и т.д.

#### Преимущества FUSE

-   **Изоляция и безопасность:** Поскольку логика файловой системы выполняется в пространстве пользователя, ошибка в ней не может привести к падению всей системы (Kernel Panic), в отличие от ошибки в нативном драйвере ядра.
-   **Гибкость и простота разработки:** Разрабатывать файловую систему на любом языке программирования в userspace гораздо проще и быстрее, чем писать сложный модуль ядра на C.
-   **Разнообразие применений:** FUSE позволяет реализовать файловые системы поверх практически любых источников данных:
    -   **Сетевые протоколы:** Например, `sshfs` для монтирования удаленных директорий через SSH.
    -   **Облачные хранилища:** `rclone` монтирует различные облачные сервисы (Google Drive, Dropbox, S3) как локальные папки.
    -   **Архивы:** Монтирование `zip` или `tar` архива как файловой системы без полной распаковки.
    -   **Базы данных и API:** Представление данных из баз данных или веб-API в виде обычных файлов и директорий.
    -   **Шифрование:** `EncFS` или `gocryptfs` создают зашифрованную файловую систему поверх существующей директории.

### Практические сценарии

#### Монтирование удаленных директорий с `sshfs`

`sshfs` позволяет монтировать директории с удаленного сервера по протоколу SSH.
```bash
# Установить sshfs (пример для Debian/Ubuntu)
sudo apt install sshfs

# Создать точку монтирования
mkdir ~/remote_server

# Смонтировать домашнюю директорию удаленного пользователя
sshfs user@remote-host:/home/user ~/remote_server

# Отмонтировать
fusermount -u ~/remote_server
```

#### Монтирование облачных хранилищ с `rclone`

`rclone` — это мощная утилита командной строки для синхронизации файлов с облачными хранилищами и монтирования их через FUSE.
```bash
# После настройки rclone (`rclone config` для добавления учетных данных)

# Создать точку монтирования
mkdir ~/gdrive

# Смонтировать облачное хранилище (например, Google Drive)
rclone mount "MyGoogleDrive:" ~/gdrive --daemon

# Отмонтировать
fusermount -u ~/gdrive
```
