# FUSE (Filesystem in Userspace)

**FUSE (Filesystem in Userspace)** — это интерфейс ядра Linux, который позволяет создавать файловые системы, работающие в пространстве пользователя, без необходимости писать код для ядра. Это значительно упрощает разработку и повышает безопасность.

**Как это работает:**
Модуль ядра FUSE действует как "мост". Он перенаправляет запросы к виртуальной файловой системе от ядра к пользовательской программе-демону, которая и реализует всю логику (чтение, запись, создание директорий).

### Преимущества FUSE

-   **Изоляция и безопасность:** Поскольку код файловой системы работает в пространстве пользователя, ошибка в нем не приведет к падению всей системы (Kernel Panic), в отличие от ошибки в нативном драйвере ядра.
-   **Гибкость и простота:** Разрабатывать файловую систему на любом языке программирования в userspace гораздо проще, чем писать модуль ядра на C.
-   **Разнообразие применений:** FUSE позволяет реализовать файловые системы поверх чего угодно:
    -   **Сетевые протоколы:** `sshfs` монтирует удаленную директорию через SSH.
    -   **Облачные хранилища:** `rclone` может монтировать Google Drive, Dropbox, S3 и десятки других облачных сервисов как локальную папку.
    -   **Архивы:** Монтирование `zip` или `tar` архива как файловой системы без его полной распаковки.
    -   **Базы данных и API:** Представление данных из базы данных или веб-API в виде файлов и директорий.
    -   **Шифрование:** `EncFS` или `gocryptfs` создают зашифрованную файловую систему поверх существующей директории.

### Примеры использования

-   **`sshfs`:** Монтирование удаленной файловой системы.
    ```bash
    # Установить sshfs
    sudo apt install sshfs
    # Смонтировать домашнюю директорию удаленного пользователя
    mkdir ~/remote_server
    sshfs user@remote-host:/home/user ~/remote_server
    ```

-   **`rclone`:** Монтирование облачного хранилища.
    ```bash
    # После настройки rclone (`rclone config`)
    mkdir ~/gdrive
    rclone mount "MyGoogleDrive:" ~/gdrive --daemon
    ```
