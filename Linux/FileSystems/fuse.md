# FUSE (Filesystem in Userspace)

## Определения

- **FUSE (Filesystem in Userspace):** Интерфейс ядра Linux, позволяющий создавать файловые системы, полностью работающие в пространстве пользователя (userspace), без необходимости разработки кода для ядра.

## Основные концепции

### Принцип работы

Модуль ядра FUSE выступает в роли "моста", перенаправляя все запросы к файловой системе от ядра к пользовательскому демону. Этот демон, работающий в userspace, реализует всю логику файловой системы, обрабатывая операции чтения, записи, создания директорий и т.д.

### Преимущества

- **Изоляция и безопасность:** Ошибки в логике файловой системы userspace не приводят к падению всей системы (Kernel Panic), повышая стабильность.
- **Гибкость и простота разработки:** Файловые системы FUSE могут быть реализованы на любом языке программирования, значительно упрощая и ускоряя разработку по сравнению с модулями ядра.
- **Разнообразие применений:** FUSE позволяет создавать файловые системы поверх широкого спектра источников данных:
  - **Сетевые протоколы:** Например, `sshfs` для монтирования удаленных директорий через SSH.
  - **Облачные хранилища:** `rclone` монтирует облачные сервисы (Google Drive, Dropbox, S3) как локальные папки.
  - **Архивы:** Монтирование `zip` или `tar` архивов как файловой системы без полной распаковки.
  - **Базы данных и API:** Представление данных из баз данных или веб-API в виде обычных файлов и директорий.
  - **Шифрование:** `EncFS` или `gocryptfs` для создания зашифрованных файловых систем.

## Практические сценарии

### Монтирование удаленных директорий с `sshfs`

`sshfs` позволяет монтировать директории с удаленного сервера по протоколу SSH, представляя их как локальную файловую систему.

1. **Установка `sshfs`** (пример для Debian/Ubuntu):

    ```bash
    sudo apt install sshfs
    ```

2. **Создание точки монтирования:**

    ```bash
    mkdir ~/remote_server
    ```

3. **Монтирование директории:**

    ```bash
    sshfs user@remote-host:/home/user ~/remote_server
    ```

4. **Отмонтирование:**

    ```bash
    fusermount -u ~/remote_server
    ```

    Подробнее об использовании `sshfs` см. в [Практическое использование SSH](../Security/ssh/ssh_usage_and_tunnels.md#передача-файлов-и-работа-с-файловой-системой).

### Монтирование облачных хранилищ с `rclone`

`rclone` — это мощная утилита для синхронизации с облачными хранилищами и их монтирования через FUSE.

1. **Настройка `rclone`:** Выполните `rclone config` для добавления учетных данных облачного хранилища (например, Google Drive).
2. **Создание точки монтирования:**

    ```bash
    mkdir ~/gdrive
    ```

3. **Монтирование облачного хранилища:**

    ```bash
    rclone mount "MyGoogleDrive:" ~/gdrive --daemon
    ```

4. **Отмонтирование:**

    ```bash
    fusermount -u ~/gdrive
    ```

## Дополнительная информация

- FUSE является основой для многих современных файловых систем, которые расширяют функциональность Linux, позволяя интегрировать практически любой источник данных в виде локальной файловой системы.
- При разработке файловых систем с использованием FUSE важно обеспечить корректную обработку ошибок и учитывать вопросы производительности, так как каждый запрос проходит через userspace.
