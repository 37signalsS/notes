# Логическое восстановление данных

## Определения

- **Логическое восстановление данных:** Процесс извлечения и восстановления файлов или файловых систем, потерянных из-за программных ошибок, случайного удаления, форматирования или повреждения файловой системы, при отсутствии физических повреждений носителя.

## Основные концепции

- **Первое правило:** Ничего не писать на раздел, где был удалённый файл. Каждая операция записи увеличивает риск того, что блоки данных, ранее занимаемые удалённым файлом, будут перезаписаны новыми данными.
- **Действия при потере данных:**
  - На продакшн-сервере: немедленно остановить все процессы, активно пишущие на диск.
  - Размонтировать файловую систему (`umount`) или перевести её в режим "только чтение":

    ```bash
    mount -o remount,ro /dev/sdb1
    ```

- **Приоритет сохранения данных:** Всегда восстанавливайте данные на **другой** физический носитель.

## Практические сценарии

### 1. Восстановление файла, открытого процессом

Если файл был удалён, но процесс всё ещё удерживает его дескриптор, данные остаются на диске.

1. Найти процесс и дескриптор файла:

   ```bash
   lsof | grep deleted
   ```

2. Скопировать содержимое файла из файловой системы `/proc`:

   ```bash
   cp /proc/<PID>/fd/<FD> /tmp/recovered_file
   ```

*Это самый надёжный способ, так как данные гарантированно целые.*

### 2. Восстановление через TestDisk (разделы и файлы)

**TestDisk** — интерактивная утилита для восстановления разделов и файлов, если точный путь неизвестен.

1. Запуск: `sudo testdisk /dev/sdb1`
2. Навигация в меню: `Analyse` → `Quick Search`.
3. Найти удалённые файлы (обычно выделены красным), скопировать их на другой диск.

### 3. Восстановление через extundelete (для ext3/ext4)

Специализированная утилита, которая ищет удалённые файлы в журнале файловой системы.

```bash
# Восстановить конкретный файл по пути
extundelete /dev/sdb1 --restore-file /path/to/deleted/file

# Восстановить всё удалённое в директории
extundelete /dev/sdb1 --restore-directory /path/to/dir
```

### 4. Создание образа диска (dd)

Если простые методы не помогли, необходимо снять образ раздела для дальнейших попыток восстановления, чтобы не повредить оригинал.

```bash
dd if=/dev/sdb1 of=/mnt/backup/disk.img bs=4M status=progress
```

*Дальнейшее восстановление следует проводить, работая с файлом образа `disk.img`.*

### 5. Восстановление по сигнатурам (PhotoRec)

**PhotoRec** восстанавливает файлы по их внутренним сигнатурам, игнорируя повреждения метаданных ФС. Эффективен для восстановления медиафайлов и документов с отформатированных носителей.

## Дополнительная информация

- **Btrfs:** Используйте `btrfs restore` для извлечения файлов с повреждённых ФС.
- **XFS:** Возможности `xfs_repair` по восстановлению именно *удалённых* файлов крайне ограничены.
