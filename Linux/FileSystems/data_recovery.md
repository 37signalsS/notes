# Логическое восстановление данных

**Важно:** При потере данных первое, что нужно сделать, — это отмонтировать файловую систему (`umount`) или смонтировать её в режиме "только чтение" (`mount -o remount,ro`), чтобы предотвратить перезапись удалённых данных.

### Инструменты для восстановления

-   **`TestDisk`**: Мощная утилита для восстановления потерянных разделов и исправления загрузочных секторов.
-   **`PhotoRec`**: Идёт в комплекте с `TestDisk`. Восстанавливает файлы по их сигнатурам, игнорируя файловую систему. Эффективен для восстановления фотографий, документов и архивов с отформатированных носителей.

-   **Для Ext3/Ext4:**
    -   `extundelete`: Ищет удалённые файлы в журнале файловой системы.
    -   `ext4magic`: Более продвинутый инструмент для восстановления.

-   **Для XFS:**
    -   `xfs_repair`: В первую очередь, это инструмент для проверки и исправления метаданных. Возможности восстановления удалённых файлов ограничены.

-   **Для Btrfs:**
    -   `btrfs restore`: Специализированная утилита для извлечения файлов с повреждённой или немонтируемой файловой системы Btrfs.
