# Дисковые квоты

## Определения

- **Дисковая квота (Disk Quota):** Механизм ограничения объема дискового пространства или количества файлов для отдельных пользователей или групп. Используется для предотвращения монополизации ресурсов и обеспечения стабильности системы.
- **Мягкий лимит (Soft Limit):** Порог, при достижении которого пользователю выводится предупреждение, но запись данных продолжается до истечения льготного периода.
- **Жесткий лимит (Hard Limit):** Абсолютный предел, при достижении которого любая попытка записи данных или создания файлов блокируется немедленно.
- **Льготный период (Grace Period):** Время, в течение которого пользователь может превышать мягкий лимит. По истечении этого времени мягкий лимит превращается в жесткий.
- **Индексный дескриптор (Inode):** Структура данных ФС (Файловой Системы), описывающая файл или каталог. Ограничение по **inodes** предотвращает переполнение таблицы дескрипторов ФС.

## Основные концепции

### Типы квот

1. **Квоты на пространство (Block Quotas):** Ограничивают суммарный объем данных в килобайтах или блоках.
2. **Квоты на количество файлов (Inode Quotas):** Ограничивают общее количество создаваемых объектов (файлов, каталогов, ссылок). Актуально для предотвращения атак типа "отказ в обслуживании" путем создания миллионов пустых файлов.

### Принципы работы

- Квоты применяются к конкретной точке монтирования ФС.
- База данных квот хранится в файлах `aquota.user` и `aquota.group` в корне соответствующего раздела.
- Пользователь `root` обладает иммунитетом к квотам.
- В современных ФС (например, **XFS**) квоты являются частью метаданных самой ФС и управляются более эффективно.

## Практические сценарии

### Настройка квот для Ext4

1. **Подготовка `/etc/fstab`:** Добавьте параметры `usrquota` и `grpquota`.

   ```bash
   /dev/sdb1  /home  ext4  defaults,usrquota,grpquota  0  2
   ```

2. **Активация параметров:**

   ```bash
   mount -o remount /home
   ```

3. **Инициализация БД квот:**

   ```bash
   # -u (user), -g (group), -c (create), -v (verbose)
   quotacheck -ugcv /home
   ```

4. **Включение квот:**

   ```bash
   quotaon -v /home
   ```

### Управление лимитами

- **Интерактивное редактирование:**

  ```bash
  # Открывает редактор для установки лимитов конкретного пользователя
  edquota -u <username>
  ```

- **Установка в командной строке (для скриптов):**

  ```bash
  # setquota <user> <soft_block> <hard_block> <soft_inode> <hard_inode> <mount_point>
  setquota -u user1 500M 600M 10000 11000 /home
  ```

### Просмотр и диагностика

- **Проверка квот текущего пользователя:**

  ```bash
  quota -v
  ```

- **Сводный отчет по разделу:**

  ```bash
  repquota -s /home
  ```

### Особенности XFS

В **XFS** квоты включаются при монтировании и управляются через утилиту `xfs_quota`.

```bash
# Просмотр квот в XFS
xfs_quota -x -c 'report -h' /mnt/data
```

### Примечания

- При использовании **NFS** квоты настраиваются на стороне сервера.
- Квоты могут конфликтовать с системами автоматического бэкапа, если они запускаются от имени пользователя с ограниченными лимитами.
