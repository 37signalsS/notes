# Дисковые квоты (Disk Quotas)

## Что такое дисковые квоты?

**Дисковая квота** — это механизм в операционных системах, который позволяет системному администратору ограничивать объем дискового пространства или количество файлов, которые может использовать отдельный пользователь или группа пользователей.

Основная цель квот — справедливое распределение дисковых ресурсов и предотвращение ситуации, когда один пользователь занимает всё доступное место на общем диске (например, в `/home`).

## Сценарий: "No space left on device" при наличии свободного места

Классическая ситуация, в которой проявляется работа квот:

1.  **Проблема:** Обычный пользователь пытается создать файл и получает ошибку `no space left on device` (нет места на устройстве).
2.  **Проверка:** Команда `df -h` показывает, что на диске еще много свободного места.
3.  **Исключение:** При этом пользователь `root` может без проблем создавать и записывать файлы в том же месте.

**Причина:**
Такая ситуация возникает, когда пользователь **превысил свою персональную дисковую квоту**, установленную администратором. Система блокирует создание новых файлов или запись данных для этого пользователя, даже если на физическом разделе есть свободное пространство. Пользователь `root` не подчиняется ограничениям квот, поэтому может продолжать работу.

## Типы квот

Квоты могут быть установлены по двум параметрам:

1.  **Квота на пространство (block quota):** Ограничивает суммарный объем дискового пространства (в килобайтах или блоках), которое могут занимать файлы пользователя.
2.  **Квота на количество файлов (inode quota):** Ограничивает общее количество файлов и каталогов (то есть количество используемых **inodes**), которые может создать пользователь. Это защищает от ситуаций, когда пользователь создает миллионы мелких файлов, исчерпывая все доступные inodes на файловой системе, что также делает невозможным создание новых файлов для других.

Для каждого типа квот устанавливаются два уровня ограничений:
*   **Мягкий лимит (Soft Limit):** Порог, при превышении которого система выдает пользователю предупреждение. Начинается отсчет **льготного периода (grace period)**, в течение которого пользователь должен освободить место.
*   **Жесткий лимит (Hard Limit):** Абсолютный предел. Как только пользователь достигает этого лимита, система немедленно блокирует создание новых файлов или запись данных.

## Основные команды для управления квотами

*   **`quota`**: Показывает текущие дисковые квоты и использование для пользователя.
    ```bash
    # Посмотреть свою квоту
    quota -v
    
    # Посмотреть квоту конкретного пользователя (от root)
    quota -v <username>
    ```

*   **`repquota`**: Генерирует сводный отчет об использовании квот для указанной файловой системы.
    ```bash
    # Показать отчет для всех файловых систем с квотами
    repquota -a
    ```

*   **`edquota`**: Редактирует квоты для пользователя или группы в текстовом редакторе.
    ```bash
    # Редактировать квоту пользователя
    sudo edquota -u <username>
    ```

*   **`setquota`**: Устанавливает квоты из командной строки, что удобно для скриптов.

## Включение квот

Чтобы квоты заработали, их нужно включить на уровне файловой системы. В общих чертах процесс выглядит так:
1.  Добавить опции `usrquota` и/или `grpquota` в `/etc/fstab` для нужного раздела.
2.  Перемонтировать файловую систему.
3.  Создать файлы квот (`aquota.user`, `aquota.group`) с помощью `quotacheck`.
4.  Включить квотирование командой `quotaon`.
