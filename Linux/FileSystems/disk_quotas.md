# Дисковые квоты (Disk Quotas)

## Определения

-   **Дисковая квота:** Механизм ограничения объема дискового пространства или количества файлов, используемых пользователем или группой. Цель — справедливое распределение ресурсов и предотвращение монополизации дискового пространства.

## Основные концепции

### Типы квот

1.  **Квота на пространство (Block Quota):** Ограничивает суммарный объем дискового пространства (в блоках или килобайтах).
2.  **Квота на количество файлов (Inode Quota):** Ограничивает общее количество файлов и каталогов ([inodes](../../FileSystems/links_inodes_dentries.md#Inode-Индексный-дескриптор)). Защищает от исчерпания inodes файловой системы.

### Уровни ограничений

-   **Мягкий лимит (Soft Limit):** Порог, при превышении которого выдается предупреждение и запускается **льготный период (Grace Period)**. В течение этого периода пользователь должен уменьшить использование ресурсов.
-   **Жесткий лимит (Hard Limit):** Абсолютный предел. При достижении этого лимита дальнейшая запись данных или создание файлов немедленно блокируется.

## Практические сценарии

### Сценарий: "No space left on device" при наличии свободного места

-   **Проблема:** Пользователь получает ошибку `No space left on device`, хотя `df -h` показывает свободное место.
-   **Причина:** Пользователь превысил свои дисковые квоты (Soft или Hard Limit). Пользователь `root` не подчиняется квотам.

### Основные команды управления квотами

-   **`quota`**: Просмотр собственных квот или квот другого пользователя (с правами root).
    ```bash
    quota -v             # Показать свою квоту
    quota -v <username>  # Показать квоту пользователя (от root)
    ```
-   **`repquota`**: Сводный отчет об использовании квот для файловой системы.
    ```bash
    repquota -a          # Отчет для всех файловых систем с квотами
    ```
-   **`edquota`**: Редактирование квот пользователя или группы в текстовом редакторе.
    ```bash
    sudo edquota -u <username> # Редактировать квоту пользователя
    sudo edquota -g <groupname> # Редактировать квоту группы
    ```
-   **`setquota`**: Установка квот из командной строки. Удобно для скриптов.

### Включение дисковых квот

1.  **Изменение `/etc/fstab`:** Добавьте опции `usrquota` (для пользователей) и/или `grpquota` (для групп) в строку монтирования нужного раздела.
    ```
    # Пример для раздела /dev/sda1, монтируемого в /home
    UUID=... /home ext4 defaults,usrquota,grpquota 0 2
    ```
2.  **Перемонтирование файловой системы:**
    ```bash
    sudo mount -o remount /home
    ```
3.  **Инициализация файлов квот:** Создайте базу данных квот.
    ```bash
    sudo quotacheck -ug /home
    ```
4.  **Активация квотирования:**
    ```bash
    sudo quotaon -ug /home
    ```

## Дополнительная информация

-   Квоты обычно применяются к локальным файловым системам (Ext4, XFS и т.д.). Для сетевых файловых систем (NFS) квоты управляются на сервере NFS.
-   Для эффективного использования квот необходимо регулярное отслеживание и настройка лимитов в соответствии с потребностями пользователей и доступными ресурсами.
-   Перед включением квот всегда рекомендуется выполнить полное резервное копирование данных.
