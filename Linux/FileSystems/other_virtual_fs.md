# Псевдофайловые системы Tmpfs и Cgroupfs

## Определения

### Tmpfs

**Tmpfs (Temporary File System)** — это псевдофайловая система, которая хранит все свои файлы в виртуальной памяти (включая оперативную память и, при необходимости, [пространство подкачки (swap)](../Core/memory/swap_management.md)). Она выглядит как обычная монтируемая файловая система, но данные в ней не сохраняются между перезагрузками, так как не записываются на постоянное запоминающее устройство.

### Cgroupfs

**Cgroupfs (Control Group File System)** — это псевдофайловая система, которая служит пользовательским интерфейсом для [контрольных групп (cgroups)](../Core/cgroups.md) ядра Linux. Она предоставляет механизм для организации процессов в иерархические группы и управления их ресурсами (ЦП, память, дисковый ввод-вывод, сеть и т.д.).

## Основные концепции

### Как работает Tmpfs?

- **Хранение в памяти**: В отличие от `ramfs` (которая использует только ОЗУ и не может быть выгружена в swap), `tmpfs` использует [виртуальную память](../Core/memory/virtual_vs_physical_memory.md). Это означает, что при нехватке оперативной памяти страницы `tmpfs` могут быть выгружены в [раздел подкачки (swap)](../Core/memory/swap_management.md).
- **Динамический размер**: Размер `tmpfs` по умолчанию составляет половину от общего объема ОЗУ, но он может быть задан при монтировании. Важно, что `tmpfs` потребляет память только по мере необходимости (по мере создания файлов), а не резервирует весь указанный размер сразу.
- **Скорость**: Поскольку данные находятся в ОЗУ, доступ к ним осуществляется на порядки быстрее, чем к данным на диске.

### Как работает Cgroupfs?

- **Файловый интерфейс**: `cgroupfs` монтируется (обычно в `/sys/fs/cgroup`) и представляет иерархию [контрольных групп (cgroups)](../Core/cgroups.md) в виде дерева каталогов.
- **Управление через файлы**: Внутри каждого каталога, представляющего группу, находятся псевдофайлы, которые позволяют читать статистику и задавать лимиты ресурсов. Например, записав значение в файл `memory.limit_in_bytes`, можно ограничить потребление памяти для всех процессов в данной группе.
- **Контроллеры**: Различные подсистемы `cgroups` (контроллеры `cpu`, `memory`, `io` и др.) предоставляют свои наборы файлов для управления соответствующими ресурсами.

## Практические сценарии

### Примеры использования Tmpfs

`tmpfs` активно используется системой для временных данных, доступ к которым должен быть максимально быстрым:

- **`/dev/shm`**: Используется для реализации стандарта [разделяемой памяти POSIX](other_virtual_fs.md). Процессы могут создавать файлы в этой директории для быстрого обмена данными.
- **`/run`**: Хранит временные данные (runtime data), которые требуются запущенным процессам, например, PID-файлы и сокеты. Содержимое этой директории не должно сохраняться после перезагрузки.
- **`/tmp`**: Во многих современных дистрибутивах `/tmp` также монтируется как `tmpfs` для ускорения работы с временными файлами и автоматической очистки при перезагрузке.

### Примеры использования Cgroupfs

`cgroupfs` является фундаментальной технологией для системных менеджеров и систем [контейнеризации](../Virtualization/virtualization_overview.md#контейнеризация).

- **Systemd**: [systemd](../Core/systemd/overview.md) использует [cgroups](../Core/cgroups.md) для управления жизненным циклом и ресурсами системных служб. Каждый сервис запускается в своей собственной контрольной группе.
- **Контейнеризация (Docker, Podman, Kubernetes)**: Контейнеры изолируются и ограничиваются с помощью [cgroups](../Core/cgroups.md). Когда вы задаете лимит памяти или ЦП для контейнера (например, `docker run --memory=1g`), [Docker](../../Docker/docker_overview.md) фактически записывает это значение в соответствующий файл в иерархии `cgroupfs`. [Kubernetes](../../Kubernetes/kubernetes_overview.md) также широко использует `cgroups` для управления ресурсами подов.

## Дополнительная информация

- **`ramfs` vs `tmpfs`**: `ramfs` использует только RAM и не может использовать swap. `tmpfs` может использовать swap, что делает её более гибкой, но потенциально медленнее, чем `ramfs` в условиях нехватки RAM.
- **`/sys/fs/cgroup`**: Стандартная точка монтирования для `cgroupfs` в Linux.
