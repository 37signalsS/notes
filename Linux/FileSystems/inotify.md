# Мониторинг событий файловой системы (inotify)

## Определения

- **`inotify`:** Подсистема ядра Linux, предоставляющая API для отслеживания событий файловой системы в реальном времени (создание, удаление, изменение, перемещение файлов и директорий).

## Основные концепции

Для работы с `inotify` из командной строки используется пакет **`inotify-tools`**, включающий две основные утилиты:

- **`inotifywait`:** Блокирующая утилита, ожидающая указанного события и завершающая работу. Идеальна для автоматизации в скриптах.
- **`inotifywatch`:** Собирает и выводит статистику о событиях файловой системы за определённый период.

## Практические сценарии

### Ожидание одного события

`inotifywait` позволяет выполнять действия после фиксации изменения в отслеживаемой директории.

```bash
# Ожидать любого события в директории /tmp, затем завершить работу
inotifywait /tmp
echo "Событие в /tmp зафиксировано."
```

### Непрерывный мониторинг

Ключ `-m` (`--monitor`) обеспечивает непрерывную работу `inotifywait`, а `-r` (`--recursive`) включает отслеживание событий во всех вложенных директориях.

```bash
# Непрерывно мониторить директорию /var/www и все её поддиректории
inotifywait -m -r /var/www
```

### Форматированный вывод событий

Для использования в скриптах рекомендуется форматированный вывод с разделителями:

```bash
# Вывод в формате: время событие файл
inotifywait -m -r --format '%T %e %w%f' --timefmt '%Y-%m-%d %H:%M:%S' /var/www
```

### Отслеживание конкретных событий

```bash
# Мониторить только создание и удаление файлов
inotifywait -m -e create -e delete /tmp
```

### Управление лимитами `inotify`

Ядро ограничивает количество одновременно отслеживаемых объектов (`watches`), чтобы предотвратить исчерпание ресурсов. Приложения, активно использующие `inotify` (редакторы кода, системы синхронизации), могут достигать этого лимита, что проявляется ошибкой `inotify: too many open files` или `No space left on device`.

**Просмотр текущего лимита:**

```bash
sysctl fs.inotify.max_user_watches
```

**Временное изменение лимита** (до перезагрузки):

```bash
sudo sysctl -w fs.inotify.max_user_watches=524288
```

**Постоянное изменение лимита:**

Добавьте строку в `/etc/sysctl.conf` или создайте файл `/etc/sysctl.d/99-inotify.conf`:

```ini
fs.inotify.max_user_watches=524288
```

Затем примените изменения:

```bash
sudo sysctl -p /etc/sysctl.d/99-inotify.conf
```

Подробнее о настройке параметров ядра — в [Настройке параметров ядра (sysctl)](../../Linux/Core/kernel/sysctl.md).

## Дополнительная информация

Подсистема `inotify` является фундаментом для многих инструментов разработки и систем синхронизации файлов. Для более детального аудита событий файловой системы (кто, когда и какие операции выполнял) используется подсистема [auditd](../SystemAdministration/Logging/auditd.md). Лимит `max_user_watches` относится к системным [лимитах ресурсов](../Core/processes/limits_hierarchy.md), а использование file watchers в инструментах сборки описано в [Build tools](../Development/build_tools.md).
