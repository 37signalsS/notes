# Мониторинг событий ФС (`inotify`)

`inotify` — это подсистема ядра Linux, которая позволяет приложениям отслеживать события в файловой системе в реальном времени (например, создание, удаление, изменение файлов).

**Утилиты для работы с `inotify`:**
-   **`inotifywait`**: Ожидает определённого события и завершает работу. Удобно для использования в скриптах.
    ```bash
    # Ждать любого события в директории /tmp и выйти
    inotifywait /tmp
    ```
-   **`inotifywatch`**: Собирает статистику о событиях в файловой системе.

**Пример с `inotifywait`:**
```bash
# Мониторить директорию /var/www в реальном времени (-m) и рекурсивно (-r)
inotifywait -m -r /var/www
```

**Лимиты `inotify`:**
Существует ограничение на количество "наблюдателей" (watches), которое может создать один пользователь. Если вы видите ошибку "Too many open files" при использовании `inotify`, возможно, нужно увеличить этот лимит:
```bash
# Посмотреть текущий лимит
sysctl fs.inotify.max_user_watches

# Установить новый лимит
sudo sysctl -w fs.inotify.max_user_watches=524288
```
