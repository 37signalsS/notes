# Мониторинг событий файловой системы — inotify

## Определения

- **inotify** — подсистема ядра Linux, предоставляющая API (Application Programming Interface) для отслеживания событий файловой системы в реальном времени. Позволяет приложениям получать уведомления о создании, удалении, изменении и перемещении файлов или директорий.

## Основные концепции

### Инструментарий

Для взаимодействия с подсистемой из командной строки используется пакет **inotify-tools**, включающий две основные утилиты:

- **inotifywait** — блокирующая утилита, которая ожидает наступления события и завершает работу. Оптимальна для использования в сценариях автоматизации.
- **inotifywatch** — инструмент для сбора и вывода статистики событий файловой системы за определённый период.

### Системные ограничения

Ядро ограничивает количество одновременно отслеживаемых объектов (watches) для предотвращения исчерпания оперативной памяти. При достижении лимита приложения могут выдавать ошибки `inotify: too many open files` или `No space left on device`.

**Просмотр текущего лимита:**

```bash
sysctl fs.inotify.max_user_watches
```

**Временное изменение лимита:**

```bash
sudo sysctl -w fs.inotify.max_user_watches=524288
```

**Постоянное изменение лимита:**

Создайте файл `/etc/sysctl.d/99-inotify.conf`:

```ini
fs.inotify.max_user_watches=524288
```

Примените изменения:

```bash
sudo sysctl -p /etc/sysctl.d/99-inotify.conf
```

Подробнее о настройке параметров ядра — в [Настройке параметров ядра (sysctl)](../Core/kernel/sysctl.md).

## Практические сценарии

### Ожидание одного события

`inotifywait` позволяет выполнять действия сразу после фиксации изменения.

```bash
# Ожидание любого события в директории /tmp
inotifywait /tmp
echo "Событие зафиксировано"
```

### Непрерывный мониторинг

Параметр `-m` (`--monitor`) обеспечивает непрерывную работу, а `-r` (`--recursive`) включает рекурсивное отслеживание вложенных директорий.

```bash
# Мониторинг директории /var/www и всех поддиректорий
inotifywait -m -r /var/www
```

### Форматированный вывод

Для обработки событий в скриптах рекомендуется использовать специфический формат вывода:

```bash
# Формат: дата_время событие путь_к_файлу
inotifywait -m -r --format '%T %e %w%f' --timefmt '%Y-%m-%d %H:%M:%S' /var/www
```

### Фильтрация событий

```bash
# Отслеживание только создания и удаления файлов
inotifywait -m -e create -e delete /tmp
```

## Дополнительная информация

Подсистема inotify является базой для многих инструментов синхронизации и сборки программного обеспечения. Для глубокого аудита безопасности (идентификация пользователя, совершившего действие) рекомендуется использовать [auditd](../SystemAdministration/Logging/auditd.md).
