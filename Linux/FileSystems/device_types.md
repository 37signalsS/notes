# Типы устройств в Linux: блочные и символьные

### Определения

#### Блочное устройство (Block Device)

**Блочное устройство** — это уровень абстракции для устройства хранения информации, которое оперирует данными в виде блоков фиксированного размера. Доступ к каждому блоку осуществляется независимо от других (произвольный доступ). Этот тип устройств используется, когда необходима передача больших объемов данных.

#### Символьное устройство (Character Device)

**Символьное устройство** — это тип устройства, которое оперирует данными последовательно, символ за символом (или байт за байтом). Используется для более медленных устройств, где обмен данными происходит небольшими порциями и не требует частых операций поиска.

### Основные концепции

#### Блочные устройства

*   **Примеры:** Жесткие диски (HDD, SSD), RAM-диски, CD/DVD-приводы, разделы дисков.
*   **Единица передачи данных:** Данные передаются **блоками**. Размер блока, как правило, является степенью двойки (например, 512 байт, 1024 байта, 4096 байт).
*   **Доступ:** Доступ осуществляется через специальные файлы-интерфейсы в каталоге `/dev`. На блочных устройствах, как правило, размещаются файловые системы.
*   **Взаимодействие с ядром:** Системные вызовы не идут напрямую к драйверу. Взаимодействие обеспечивается через подсистемы ядра:
    1.  **Система управления файлами:** Принимает запросы от приложений.
    2.  **Подсистема блочного устройства:** Управляет буферами, кэширует недавно прочитанные блоки и упорядочивает операции чтения/записи для повышения производительности.
*   **Основное применение:** Монтирование файловых систем.

#### Символьные устройства

*   **Примеры:** Мышь, клавиатура, последовательные порты (`/dev/ttyS0`), терминалы (`/dev/tty`), псевдо-устройства (`/dev/null`).
*   **Единица передачи данных:** Данные передаются **последовательно, побайтно**.
*   **Взаимодействие с ядром:** Системные вызовы от приложений поступают **напрямую к драйверу** соответствующего устройства.

### Практические сценарии

#### Элементарные операции с блочными устройствами
*   Чтение и запись блоков данных.
*   Создание разделов.
*   Форматирование (создание файловой системы).
*   Монтирование.

**Просмотр блочных устройств:**
```bash
lsblk
```

#### Элементарные операции с символьными устройствами

*   Чтение и запись потока байтов.
*   Настройка параметров устройства (например, скорость последовательного порта).
