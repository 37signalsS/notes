# Типы устройств в Linux: блочные и символьные

Блочные и символьные устройства — это два из нескольких [типов файлов в Linux](./file_types.md). Они представляют собой интерфейсы для взаимодействия с аппаратным обеспечением.

## Определения

- **Блочное устройство (Block Device):** Устройство хранения данных, которое оперирует информацией в виде блоков фиксированного размера, обеспечивая произвольный доступ. Применяется для высокопроизводительных операций ввода-вывода с большими объемами данных.
- **Символьное устройство (Character Device):** Устройство, которое передает данные последовательно, байт за байтом. Используется для устройств, где обмен данными происходит небольшими порциями и не требует произвольного доступа.

## Основные концепции

### Блочные устройства

- **Примеры:** Жесткие диски (HDD, SSD), RAM-диски, разделы дисков.
- **Единица передачи данных:** Блоки (как правило, 512 байт, 1024 байта, 4096 байт).
- **Доступ:** Произвольный. Данные доступны через специальные файлы в каталоге `/dev`.
- **Взаимодействие с ядром:** Системные вызовы обрабатываются через подсистемы ядра (например, подсистема блочного устройства, управляющая буферами и кэшированием), что оптимизирует производительность.

### Символьные устройства

- **Примеры:** Мышь, клавиатура, последовательные порты (`/dev/ttyS0`), терминалы (`/dev/tty`), псевдо-устройства (`/dev/null`).
- **Единица передачи данных:** Последовательный поток байтов.
- **Доступ:** Последовательный.
- **Взаимодействие с ядром:** Системные вызовы направляются напрямую к драйверу соответствующего устройства, минуя промежуточные подсистемы.

## Практические сценарии

### Работа с блочными устройствами

- Просмотр блочных устройств в системе:

    ```bash
    lsblk
    ```

- Создание разделов (например, с `fdisk` или `parted`).
- Форматирование (создание файловой системы, например, `mkfs.ext4 /dev/sda1`).
- Монтирование файловых систем (например, `mount /dev/sda1 /mnt/data`).

### Работа с символьными устройствами

- Чтение данных из символьного устройства:

    ```bash
    cat /dev/urandom | head -c 10 # Получить 10 случайных байт
    ```

- Запись данных в символьное устройство:

    ```bash
    echo "Hello" > /dev/ttyS0 # Отправить "Hello" на последовательный порт
    ```

- Использование псевдо-устройств, таких как `/dev/null` для подавления вывода:

    ```bash
    command > /dev/null 2>&1
    ```

## Дополнительная информация

- Все устройства в Linux представлены в виде файлов в виртуальной файловой системе `/dev` (см. [Виртуальная файловая система /dev](virtual_fs_dev.md)).
- **MAJOR и MINOR нумерация:**
  - **MAJOR number:** Идентифицирует драйвер устройства в ядре. Все устройства, управляемые одним драйвером, имеют одинаковый Major.
  - **MINOR number:** Идентифицирует конкретное физическое устройство или раздел, управляемый этим драйвером.
  - **Просмотр соответствия драйверов:** Файл `/proc/devices` содержит список всех зарегистрированных Major-номеров для символьных и блочных устройств.

    ```bash
    cat /proc/partitions # Показывает Major/Minor для разделов
    cat /proc/devices    # Показывает Major для драйверов
    ```

  - **Просмотр в /dev:** Команда `ls -l` выводит номера вместо размера файла.
- **Работа с терминалами (/dev/pts/X):**
  Терминалы являются символьными устройствами. Можно отправить сообщение пользователю на другой терминал, записав данные в его файл устройства:

  ```bash
  echo "Hello from agent" > /dev/pts/0
  ```

- **Команда `mknod`:** Используется для ручного создания специальных файлов устройств.
  - **Когда используется:** В средах `chroot`, при создании `initramfs`, или если `udev` недоступен/неправильно настроен.
  - **Пример:** `sudo mknod /dev/sdb1 b 8 17` (создает блочное устройство `b` с Major 8 и Minor 17).
- `udev` динамически управляет созданием и удалением файлов устройств в `/dev` (см. [Udev: подсистема динамического управления устройствами](../Core/udev.md)).
- **См. также:** [Типы файлов в Linux](./file_types.md) (блочные `b` и символьные `c` файлы устройств), [Loop devices](./loop_devices.md) (петлевые устройства для работы с образами), [Псевдо-устройства](./virtual_fs_dev.md#Специальные-псевдо-устройства) (`/dev/null`, `/dev/zero`, `/dev/random`).
