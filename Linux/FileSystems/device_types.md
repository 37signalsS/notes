# Типы устройств в Linux: блочные и символьные

## Определения

- **Блочное устройство (Block Device):** Устройство хранения данных, которое оперирует информацией в виде блоков фиксированного размера и поддерживает произвольный доступ (возможность чтения/записи в любом месте без последовательного перебора).
- **Символьное устройство (Character Device):** Устройство, которое передает данные последовательно, байт за байтом. Не поддерживает произвольный доступ и работает как поток данных.
- **Старший номер устройства (Major Number):** Идентификатор в ядре Linux, который указывает, какой драйвер управляет данным устройством.
- **Младший номер устройства (Minor Number):** Идентификатор, используемый драйвером для различения конкретных физических устройств или их логических разделов.

## Основные концепции

### Блочные устройства

Блочные устройства предназначены для высокопроизводительного обмена большими объемами данных.

- **Примеры:** **HDD (Hard Disk Drive)**, **SSD (Solid-State Drive)**, **NVMe (Non-Volatile Memory Express)**, разделы дисков, **RAM**-диски.
- **Единица передачи:** Блоки (традиционно 512 байт, современные стандарты используют 4096 байт).
- **Кэширование:** Ядро Linux использует буферный кэш для блочных устройств, что позволяет оптимизировать операции **I/O (Input/Output)**, объединяя мелкие запросы в крупные блоки.
- **Интерфейс:** В выводе `ls -l` помечаются буквой `b`.

### Символьные устройства

Символьные устройства работают с данными как с непрерывным потоком, где важен порядок поступления байтов.

- **Примеры:** Клавиатура, мышь, последовательные порты (`/dev/ttyS0`), терминалы (`/dev/tty`), генераторы случайных чисел (`/dev/urandom`).
- **Передача данных:** Прямая передача байтов между драйвером и приложением, обычно без промежуточного кэширования ядром (хотя драйвер может иметь собственный буфер).
- **Интерфейс:** В выводе `ls -l` помечаются буквой `c`.

### Нумерация Major и Minor

Связь между файлом в `/dev` и драйвером устройства осуществляется через номера Major и Minor.

- **Major:** Группирует устройства по драйверу. Например, все диски, управляемые драйвером `sd`, имеют Major 8.
- **Minor:** Разделяет устройства внутри группы. Для диска `/dev/sda` Minor будет 0, для первого раздела `/dev/sda1` — 1 и так далее.
- **Просмотр:** Список зарегистрированных Major-номеров доступен в `/proc/devices`.

## Практические сценарии

### Идентификация устройств в системе

Просмотр иерархии блочных устройств:

```bash
lsblk
```

Просмотр Major и Minor номеров в каталоге `/dev`:

```bash
# Номера выводятся вместо размера файла
ls -l /dev/sda /dev/tty
# brw-rw---- 1 root disk 8, 0 ... /dev/sda (Major 8, Minor 0)
# crw-rw-rw- 1 root tty  5, 0 ... /dev/tty (Major 5, Minor 0)
```

### Взаимодействие с устройствами

Чтение случайных данных из символьного устройства:

```bash
# Получить 10 байт из генератора псевдослучайных чисел
cat /dev/urandom | head -c 10
```

Перенаправление вывода в "пустое" символьное устройство:

```bash
# Подавление стандартного вывода и ошибок
command > /dev/null 2>&1
```

### Ручное создание файлов устройств

Утилита `mknod` используется для создания специальных файлов, если они не были созданы автоматически (например, в среде **chroot**):

```bash
# Создание блочного устройства (b) с Major 8 и Minor 16
sudo mknod /dev/sdb b 8 16
```
