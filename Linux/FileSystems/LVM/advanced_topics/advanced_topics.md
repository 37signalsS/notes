# LVM: Расширенные темы

## Определения

**Расширенные темы LVM** — комплексные вопросы эксплуатации системы логических томов, включающие взаимодействие с процессом загрузки ОС, глубокую диагностику метаданных, фильтрацию устройств и тюнинг производительности.

**initramfs (Initial RAM Filesystem)** — временная файловая система, используемая ядром при загрузке для активации драйверов и утилит (включая LVM), необходимых для поиска и монтирования корневого раздела.

**MDA (Metadata Area)** — зарезервированная область в начале физического тома (PV), где хранится описание структуры группы томов (VG) в текстовом формате.

**LVM Filter** — правило в конфигурационном файле `lvm.conf`, определяющее, какие блочные устройства LVM должен сканировать, а какие — игнорировать.

## Базовые концепции

### Взаимодействие с процессом загрузки

Для успешной загрузки системы с корнем на LVM необходимо наличие утилит LVM в `initramfs` и корректная конфигурация загрузчика.

#### Ограничение размещения /boot
Рекомендуется выносить каталог `/boot` на отдельный стандартный раздел (не LVM).
- **Причина:** Хотя современные GRUB умеют читать LVM, это усложняет восстановление при повреждении метаданных LVM.
- **Стандартная схема:**
  - `/dev/sda1` (512 МБ – 1 ГБ, ext4/XFS) — точка монтирования `/boot`.
  - `/dev/sda2` (LVM PV) — все остальные разделы (`/`, `/home`, `swap`).

#### Событийная активация (systemd)
LVM интегрируется с `systemd` через следующие службы:
- `lvm2-pvscan@.service`: Выполняет автоматическое сканирование PV при обнаружении устройства ядром.
- `lvm2-monitor.service`: Следит за состоянием томов и снимков через демон `dmeventd`.

### Фильтрация устройств (lvm.conf)

По умолчанию LVM сканирует все блочные устройства в `/dev/`. В сложных средах (Multipath, iSCSI, Docker) это может привести к ошибкам дублирования или замедлению работы.

**Типы фильтров:**
- `filter`: Список регулярных выражений для путей устройств (например, `["a|/dev/sd.*|", "r|.*|"]`).
- `global_filter`: Применяется ко всем утилитам, включая `pvscan` и `vgscan`.

### Тюнинг и производительность

- **Alignment (Выравнивание):** LVM автоматически выравнивает данные по границам экстентов (PE). Важно следить, чтобы начало PV соответствовало физическому сектору диска (актуально для RAID и SSD).
- **Read-ahead:** Для высоконагруженных систем чтения можно увеличить параметр `readahead` для конкретного LV (`lvchange -r <size>`).

## Практические сценарии

### Сценарий 1: Настройка фильтров устройств

Предотвращение сканирования локальных дисков при использовании Multipath или исключение loop-устройств Docker.

**Редактирование `/etc/lvm/lvm.conf`:**
```ini
devices {
    # a - allow (разрешить), r - reject (запретить)
    # Пример: разрешить только диски sda и sdb, игнорировать всё остальное
    filter = [ "a|/dev/sda.*|", "a|/dev/sdb.*|", "r|.*|" ]
}
```
*После изменения фильтра выполните `sudo vgscan` для обновления кэша.*

### Сценарий 2: Восстановление загрузки (Rebuild initramfs)

Если система не находит VG при загрузке (ошибка `Volume group not found`).

#### Для Debian / Ubuntu
```bash
# Добавление модуля (если он не включен автоматически)
echo "lvm2" | sudo tee -a /etc/initramfs-tools/modules

# Обновление образа для текущего ядра
sudo update-initramfs -u
# → update-initramfs: Generating /boot/initrd.img-6.x.x-generic
```

#### Для RHEL / Rocky / Fedora (dracut)
```bash
# Принудительное включение модуля
sudo dracut --force --add lvm --regenerate-all
```

#### Для Arch Linux (mkinitcpio)
В файле `/etc/mkinitcpio.conf` убедитесь, что `lvm2` стоит перед `filesystems`:
`HOOKS=(base udev autodetect modconf block lvm2 filesystems keyboard fsck)`
```bash
sudo mkinitcpio -P
```

### Сценарий 3: Диагностика целостности метаданных

Используется при подозрении на повреждение диска или некорректное завершение операций LVM.

```bash
# Проверка физического тома на ошибки метаданных
sudo pvck /dev/sdb1

# Проверка консистентности всей группы томов
sudo vgck my_vg

# Просмотр истории изменений метаданных
sudo vgcfgrestore --list my_vg
# → File: /etc/lvm/archive/my_vg_00001-12345.vg
```
