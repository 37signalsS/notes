# LVM: Тонкие тома (Thin Provisioning)

## Определения

**Тонкое провизионирование (Thin Provisioning)** — это метод, позволяющий создавать логические тома с "виртуальным" размером, превышающим доступное физическое пространство. Место выделяется динамически, по мере записи данных.

**Тонкий пул (Thin Pool)** — специальный LV, который служит контейнером с реальным дисковым пространством.

**Тонкий том (Thin Volume)** — LV с виртуальным размером, созданный внутри пула. При создании не занимает места.

## Основные концепции

### Отличия от традиционных томов

| Характеристика | Традиционный LV | Тонкий том |
| :--- | :--- | :--- |
| Размер при создании | Фиксированный | Виртуальный (может превышать физический) |
| Выделение места | Сразу при создании | По требованию (при записи данных) |
| Переподписка | Невозможна | Возможна (виртуальный > физический) |

### Преимущества

* Эффективное использование дискового пространства
* Возможность "переподписки" (over-commit)
* Упрощение планирования емкости

### Недостатки

* Риск переполнения пула
* Сложность мониторинга
* Производительность может снизиться при интенсивной записи

## Практический сценарий: Создание и управление

### Создание тонкого пула

```bash
# Создать пул my_thin_pool размером 100 ГБ
lvcreate -L 100G --thinpool my_thin_pool my_vg
```

### Создание тонкого тома

```bash
# Создать том my_thin_lv с виртуальным размером 1 ТБ
lvcreate -V 1T --thin -n my_thin_lv my_vg/my_thin_pool
```

### Мониторинг

Важно следить за заполнением пула, иначе запись во все тонкие тома прекратится.

```bash
# Просмотр состояния (включая метаданные)
lvs -o+thin_pool,thin_count,thin_provisioned,data_percent

# Расширение пула
lvextend -L +50G my_vg/my_thin_pool
```

### Автоматическое расширение

Можно настроить автоматическое расширение пула при достижении порога:

```bash
# Установить политику автоматического расширения (до 100% от текущего размера)
lvchange --poolmetadatasize +1G my_vg/my_thin_pool
```

> **Внимание:** При переполнении тонкого пула запись на все связанные тома прекращается. Рекомендуется настроить мониторинг.
