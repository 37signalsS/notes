# Замена физического диска в LVM

## Определения

`pvmove` — команда для миграции данных между физическими томами без остановки работы системы.

## Процесс замены физического диска

`pvmove` позволяет заменять физический диск в группе томов без остановки работы системы.

### 1. Подготовьте новый диск

Подключите, создайте раздел и инициализируйте его как PV (`pvcreate /dev/sdd1`).

### 2. Добавьте новый диск в VG

Добав PV в ту же группу томьте новыйов (`vgextend my_vg /dev/sdd1`).

### 3. Переместите данные

Команда `pvmove` мигрирует все данные со старого диска на другие свободные диски в той же VG.

```bash
# Переместить все данные с /dev/sdc1
pvmove /dev/sdc1
```

Этот процесс может занять длительное время.

### 4. Удалите старый диск из VG

```bash
vgreduce my_vg /dev/sdc1
```

### 5. Очистите LVM-метки

```bash
pvremove /dev/sdc1
```

Теперь старый диск можно физически извлекать.
