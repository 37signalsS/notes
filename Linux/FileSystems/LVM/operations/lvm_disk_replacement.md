# Замена физического диска в LVM

## Определения

`pvmove` — команда для миграции данных между физическими томами (PV) в пределах одной группы томов (VG) без остановки работы системы.

## Базовые концепции

Замена физического диска в LVM выполняется без простоя благодаря механизму `pvmove`, который перемещает данные на уровне физических экстентов (PE). Процесс работает на уровне VG — данные мигрируют на любой свободный PV в той же группе томов.

**Ключевые принципы:**

- Новый диск должен быть в **той же VG**, что и старый
- Требуется достаточно свободного места для размещения всех данных со старого диска
- `pvmove` работает в фоне — процесс может занять часы при больших объёмах данных
- Команда поддерживает мониторинг через `pvmove --status` или `lvs`
- Прерывание `pvmove` не критично — операцию можно возобновить

## Практические сценарии

### Пошаговая замена физического диска

**Шаг 1: Подготовьте новый диск**

Подключите диск, создайте раздел и инициализируйте как PV:

```bash
pvcreate /dev/sdd1
```

**Шаг 2: Добавьте новый диск в VG**

```bash
vgextend my_vg /dev/sdd1
```

**Шаг 3: Переместите данные**

Миграция всех данных со старого диска на свободное пространство в VG:

```bash
# Переместить все данные с /dev/sdc1
pvmove /dev/sdc1

# Мониторинг прогресса (в отдельном терминале)
pvmove --status
# или
lvs -o+move_pv,move_pe
```

Процесс может занять длительное время — не прерывайте без необходимости. При обрыве `pvmove` возобновится автоматически при повторном запуске.

**Шаг 4: Удалите старый диск из VG**

После завершения миграции убедитесь, что старый PV пуст:

```bash
pvs  # Free = Size на /dev/sdc1
vgreduce my_vg /dev/sdc1
```

**Шаг 5: Очистите LVM-метки**

```bash
pvremove /dev/sdc1
```

Теперь диск можно физически извлекать.

### Аварийная ситуация: зависание pvmove

Если миграция зависла или работает медленно:

```bash
# Проверить статус
pvmove --status

# Не прерывайте! Дождитесь завершения
# При необходимости — дождитесь и перезагрузите систему
```

Прерывание `pvmove` безопасно для данных, но требует повторного запуска.
