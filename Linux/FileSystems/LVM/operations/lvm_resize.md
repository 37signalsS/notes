# Изменение размеров LVM

## Определения

**Расширение (extend)** — увеличение размера логического тома (LV) и файловой системы без остановки работы.

**Уменьшение (reduce)** — уменьшение размера LV и ФС. Рискованная операция, требующая офлайн-режима для ext-ФС.

**pvresize** — команда для обновления размера физического тома после изменения размера раздела диска.

## Базовые концепции

### Общие принципы

- **Расширение** — безопасная операция, выполняется "на лету"
- **Уменьшение** — рискованная операция, требует резервных копий
- Флаг `-r` в `lvextend`/`lvreduce` автоматически расширяет/уменьшает ФС вместе с LV
- Размер ФС и LV должны быть согласованы: ФС ≤ LV

### Поддержка файловыми системами

| ФС | Расширение | Уменьшение | Особенности |
| :--- | :--- | :--- | :--- |
| **ext2/3/4** | `resize2fs` (онлайн) | `resize2fs` (офлайн) | Требует `e2fsck -f` перед уменьшением |
| **XFS** | `xfs_growfs` (онлайн) | **Не поддерживается** | Единственная операция — расширение |

## Практические сценарии

### Сценарий 1: Расширение LV и ФС

**Шаг 1: Проверка свободного места в VG**

```bash
vgs  # Столбец VFree — свободное место
```

**Шаг 2: При необходимости — расширение VG**

Если в VG закончилось место, добавьте новый PV:

```bash
pvcreate /dev/sdd1
vgextend my_vg /dev/sdd1
```

**Шаг 3: Расширение LV + ФС одной командой**

```bash
# Добавить 5 ГБ
lvextend -L +5G -r /dev/my_vg/my_lv

# Или использовать всё свободное место
lvextend -l 100%FREE -r /dev/my_vg/my_lv
```

Флаг `-r` автоматически вызывает `resize2fs` (ext4) или `xfs_growfs` (XFS).

**Шаг 4: Ручное расширение ФС (без флага -r)**

```bash
# ext2/3/4
resize2fs /dev/my_vg/my_lv

# XFS (указывается точка монтирования!)
xfs_growfs /mnt/mountpoint
```

### Сценарий 2: Уменьшение LV (только ext2/3/4)

**Внимание: всегда создавайте резервную копию перед уменьшением!**

**Шаг 1: Отмонтируйте том**

```bash
umount /data
```

**Шаг 2: Проверьте ФС на ошибки**

```bash
e2fsck -f /dev/my_vg/my_lv
```

**Шаг 3: Уменьшите ФС** до размера *чуть меньше* целевого LV

```bash
# Уменьшить ФС до 14G (целевой LV = 15G)
resize2fs /dev/my_vg/my_lv 14G
```

**Шаг 4: Уменьшите LV**

```bash
lvreduce -L 15G /dev/my_vg/my_lv
```

**Шаг 5: Расширьте ФС до полного размера LV**

```bash
resize2fs /dev/my_vg/my_lv
```

**Шаг 6: Смонтируйте обратно**

```bash
mount /dev/my_vg/my_lv /data
```

> **Для XFS:** Уменьшение невозможно. Единственный путь — создать новый LV меньшего размера и перенести данные.

### Сценарий 3: Расширение LVM после увеличения диска

Когда диск увеличен на уровне гипервизора (или облака), необходимо последовательно расширить раздел, PV, LV и ФС.

**Шаг 1: Обновление информации о диске (Rescan)**

Если новый размер диска не виден в `lsblk`, принудительно обновите его:
```bash
echo 1 > /sys/class/block/sda/device/rescan
```

**Шаг 2: Расширение раздела с помощью growpart**

Самый простой способ расширить раздел без размонтирования:
```bash
sudo growpart /dev/sda 2  # Расширить раздел 2 на диске /dev/sda
```

**Шаг 3: Расширение PV**

```bash
sudo pvresize /dev/sda2
sudo pvs  # Проверить новый размер
```

**Шаг 4: Расширение LV и ФС**

```bash
sudo lvextend -l +100%FREE -r /dev/my_vg/my_lv
```

Подробнее об инструментах расширения см. в общем руководстве [Расширение дискового пространства в Linux](../../disk_expansion.md).
