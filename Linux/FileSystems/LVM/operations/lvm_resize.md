# Изменение размеров LVM

## Определения

Расширение (extend) — увеличение размера логического тома и файловой системы.

Уменьшение (reduce) — уменьшение размера логического тома и файловой системы.

## Расширение логического тома (LV)

Это безопасная операция, которую можно выполнять "на лету".

### Расширение группы томов (VG)

Если в VG закончилось место, ее можно расширить, добавив новый PV.

```bash
# 1. Инициализировать новый диск как PV
pvcreate /dev/sdd1
# 2. Добавить PV в существующую VG
vgextend my_vg /dev/sdd1
```

### Расширение логического тома (LV)

```bash
# Добавить 5 ГБ к существующему LV
lvextend -L +5G /dev/my_vg/my_lv
```

### Расширение файловой системы

Файловая система должна "увидеть" новое пространство.

- Для **ext2/3/4**: `resize2fs /dev/my_vg/my_lv`
- Для **XFS**: `xfs_growfs /path/to/mountpoint`

**Удобный способ:** Использовать флаг `-r`, чтобы расширить LV и ФС одной командой.

```bash
lvextend -L +5G -r /dev/my_vg/my_lv
```

## Уменьшение логического тома (LV)

**Внимание: Это рискованная операция. Всегда делайте резервные копии!**

### Ограничения ФС

- **XFS:** Не поддерживает уменьшение.
- **ext2/3/4:** Поддерживает, но **только в офлайн-режиме** (том должен быть отмонтирован).

### Безопасный подход для ext2/3/4

1. `umount /data` — **Отмонтировать том.**
2. `e2fsck -f /dev/my_vg/my_lv` — **Проверить ФС.**
3. `resize2fs /dev/my_vg/my_lv 14G` — **Уменьшить ФС** до размера *чуть меньше* целевого размера LV.
4. `lvreduce -L 15G /dev/my_vg/my_lv` — **Уменьшить LV.**
5. `resize2fs /dev/my_vg/my_lv` — **Расширить ФС**, чтобы занять все доступное место на LV.
6. `mount /dev/my_vg/my_lv /data` — **Смонтировать обратно.**

## Расширение LVM после увеличения раздела диска

Когда раздел диска (например, `/dev/sda2`) был увеличен на уровне гипервизора или таблицы разделов, необходимо расширить физический том LVM, чтобы он "увидел" новое пространство.

### 1. Определение стека технологий

Для понимания структуры LVM используйте следующие команды (двигаясь сверху вниз):
- `lsblk` — показывает блочные устройства и их иерархию (диск -> раздел -> PV -> LV -> ФС).
- `lvs` (или `lvdisplay`) — показывает логические тома и их группу томов.
- `vgs` (или `vgdisplay`) — показывает группы томов и свободное место в них.
- `pvs` (или `pvdisplay`) — показывает физические тома и их размеры.

### 2. Расширение физического тома (PV)

После увеличения размера раздела (например, через `fdisk`), расширьте PV командой `pvresize`:

```bash
# Расширение PV на весь доступный размер раздела
sudo pvresize /dev/sda2

# Проверка результата
sudo pvs
```

> **Примечание:** Группа томов (VG) автоматически увеличится после расширения PV, дополнительные команды для VG не требуются.

### 3. Расширение логического тома и файловой системы

После расширения VG, расширьте LV и файловую систему одной командой:

```bash
# Расширить LV на все свободное место в VG
sudo lvextend -l +100%FREE -r /dev/my_vg/my_lv
```

Подробнее о командах расширения ФС:
- Для **ext2/3/4**: `resize2fs /dev/my_vg/my_lv`
- Для **XFS**: `xfs_growfs /mount/point`
