# Просмотр информации LVM

## Команды просмотра

| Команда | Описание |
| :--- | :--- |
| `pvs` или `pvdisplay` | Показывает информацию о физических томах (PV). |
| `vgs` или `vgdisplay` | Показывает информацию о группах томов (VG). |
| `lvs` или `lvdisplay` | Показывает информацию о логических томах (LV). |

## Структура стека технологий

Для понимания структуры LVM используйте следующие команды (двигаясь сверху вниз):
- `lsblk` — показывает блочные устройства и их иерархию (диск -> раздел -> PV -> LV -> ФС).
- `lvs` (или `lvdisplay`) — показывает логические тома и их группу томов.
- `vgs` (или `vgdisplay`) — показывает группы томов и свободное место в них.
- `pvs` (или `pvdisplay`) — показывает физические тома и их размеры.
