# Просмотр информации LVM

## Определения

**Краткий вывод (pvs/vgs/lvs)** — компактный однострочный формат на каждый объект. Используется для быстрого обзора и скриптов.

**Полный вывод (pvdisplay/vgdisplay/lvdisplay)** — развёрнутый формат с детальной информацией о каждом объекте. Используется для глубокой диагностики.

## Базовые концепции

### Иерархия команд просмотра

LVM предоставляет два уровня утилит для каждого типа объекта:

| Объект | Кратко | Подробно | Назначение |
| :--- | :--- | :--- | :--- |
| PV | `pvs` | `pvdisplay` | Физические диски/разделы |
| VG | `vgs` | `vgdisplay` | Группы томов |
| LV | `lvs` | `lvdisplay` | Логические тома |

### Диагностика структуры LVM

Для понимания полной структуры двигайтесь **сверху вниз**:

1. `lsblk` — блочные устройства и иерархия: диск → раздел → PV → LV → ФС
2. `pvs` — физические тома и их размеры
3. `vgs` — группы томов и свободное место
4. `lvs` — логические тома и использование

## Практические сценарии

### Сценарий 1: Быстрая проверка состояния VG

```bash
vgs
```

**Ключевые столбцы:**

| Столбец | Описание |
| :--- | :--- |
| `VG` | Имя группы томов |
| `#PV` | Количество физических томов |
| `#LV` | Количество логических томов |
| `VSize` | Общий размер VG |
| `VFree` | Свободное место (критично для расширения) |

### Сценарий 2: Проверка свободного места в PV

```bash
pvs
```

| Столбец | Описание |
| :--- | :--- |
| `PV` | Устройство (например, `/dev/sda2`) |
| `VG` | Группа томов, к которой принадлежит PV |
| `PSize` | Размер PV |
| `PFree` | Свободное место внутри PV |

### Сценарий 3: Детальная информация о LV

```bash
lvs
```

| Столбец | Описание |
| :--- | :--- |
| `LV` | Имя логического тома |
| `VG` | Группа томов |
| `LSize` | Размер LV |
| `Data%` | Процент использования (для тонких томов) |
| `Snap%` | Процент использования снимка |

### Сценарий 4: Подробная диагностика одного объекта

```bash
# Подробно о конкретном PV
pvdisplay /dev/sda2

# Подробно о конкретной VG
vgdisplay my_vg

# Подробно о конкретном LV
lvdisplay /dev/my_vg/my_lv
```

### Сценарий 5: Пользовательский вывод

Команды `pvs`, `vgs`, `lvs` поддерживают кастомизацию через флаг `-o`:

```bash
# LV + размер пула и процент данных
lvs -o+thin_pool,data_percent

# PV + метаданные
pvs -o+pv_mda_size

# VG + размер PE (Physical Extent)
vgs -o+vg_extent_size
```

### Сценарий 6: Сканирование всех LVM-объектов

```bash
vgscan   # Найти все VG на системе
lvscan   # Найти все LV и их статус (ACTIVE/INACTIVE)
pvscan   # Найти все PV
```

Полезно после подключения новых дисков или восстановления.
