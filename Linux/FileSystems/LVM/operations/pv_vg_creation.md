# Создание PV, VG и LV

## Определения

**PV (Physical Volume — физический том)** — диск, раздел или блочное устройство, инициализированное для использования в LVM. Содержит метаданные LVM.

**VG (Volume Group — группа томов)** — виртуальный пул хранения, объединяющий один или несколько PV. Группа томов представляет собой единое адресное пространство.

**LV (Logical Volume — логический том)** — виртуальный блочный прибор, создаваемый внутри VG. На нем размещается файловая система.

**PE (Physical Extent — физический экстент)** — минимальный блок данных в LVM (по умолчанию 4 МБ). Все операции выделения места кратны размеру PE.

## Базовые концепции

### Иерархия уровней LVM

Процесс абстракции дискового пространства проходит через следующие этапы:
`Физический носитель → Physical Volume (PV) → Volume Group (VG) → Logical Volume (LV) → Файловая система`

### Ключевые принципы инициализации

- **Очистка метаданных:** Перед созданием PV рекомендуется выполнить `wipefs`, чтобы удалить старые сигнатуры RAID или ФС.
- **Размер Physical Extent (PE):** Задается при создании VG (параметр `-s`). Больший размер PE может быть полезен для повышения производительности при работе с очень большими томами (десятки ТБ).
- **Адресация LV:** Доступ к томам осуществляется через `/dev/<VG_NAME>/<LV_NAME>`.

### Основные утилиты

| Операция | Команда | Описание |
| :--- | :--- | :--- |
| **Инициализация PV** | `sudo pvcreate /dev/sdb1` | Подготовка устройства к работе в LVM. |
| **Создание VG** | `sudo vgcreate -s 8M data_vg /dev/sdb1` | Создание пула с кастомным размером PE (8 МБ). |
| **Создание LV (размер)** | `sudo lvcreate -L 10G -n my_lv data_vg` | Выделение тома фиксированного размера. |
| **Создание LV (чередование)** | `sudo lvcreate -i 2 -I 64k -L 20G -n stripe_lv data_vg` | Создание Striped LV на двух дисках. |

## Практические сценарии

### Сценарий 1: Подготовка нового диска с разделением на LV

**Шаг 1: Идентификация диска**
```bash
lsblk
# → sdb           8:16   0   20G  0 disk
```

**Шаг 2: Создание разделов**
Рекомендуемый тип раздела — `8e` (Linux LVM).
```bash
sudo fdisk /dev/sdb
# → n (новый), p (основной), t (тип), 8e (LVM), w (записать)
```

**Шаг 3: Инициализация физических томов (PV)**
```bash
sudo wipefs --all /dev/sdb1
sudo pvcreate /dev/sdb1
# → Physical volume "/dev/sdb1" successfully created.
```

**Шаг 4: Создание группы томов (VG)**
```bash
sudo vgcreate vg_data /dev/sdb1
# → Volume group "vg_data" successfully created
```

**Шаг 5: Создание логических томов (LV)**
```bash
# Создание тома для БД (10 ГБ)
sudo lvcreate -n lv_db -L 10G vg_data
# → Logical volume "lv_db" created.

# Использование всего оставшегося места
sudo lvcreate -n lv_app -l 100%FREE vg_data
# → Logical volume "lv_app" created.
```

**Шаг 6: Создание файловой системы и монтирование**
```bash
sudo mkfs.xfs /dev/vg_data/lv_db
sudo mkdir -p /mnt/db
sudo mount /dev/vg_data/lv_db /mnt/db
```

### Сценарий 2: Создание LVM на базе нескольких дисков (RAID 0/Striping)

Для повышения производительности чтения/записи можно использовать чередование (striping) при создании LV. Требуется как минимум два PV в группе томов.

```bash
# Инициализация двух дисков
sudo pvcreate /dev/sdc /dev/sdd

# Создание одной VG на двух дисках
sudo vgcreate vg_perf /dev/sdc /dev/sdd

# Создание LV с чередованием по 2 дискам (-i 2)
sudo lvcreate -i 2 -L 40G -n lv_high_perf vg_perf
# → Logical volume "lv_high_perf" created.
```
