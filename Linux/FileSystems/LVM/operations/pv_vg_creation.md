# Создание PV, VG и LV

## Определения

Физический том (Physical Volume, PV) — блочное устройство, инициализированное для использования в LVM.

Группа томов (Volume Group, VG) — пул пространства, объединяющий один или несколько физических томов.

Логический том (Logical Volume, LV) — виртуальный том, выделенный из группы томов.

## Практический сценарий: Разметка нового диска с помощью LVM

Этот сценарий демонстрирует полный процесс от подключения нового диска до его настройки и постоянного монтирования в системе с использованием LVM.

### 1. Обнаружение нового диска

После подключения физического или виртуального диска, найдите его в системе с помощью `lsblk`. Новый диск обычно не имеет разделов (PART) и точек монтирования (MOUNTPOINT).

```bash
$ lsblk
NAME                  MAJ:MIN RM   SIZE RO TYPE MOUNTPOINT
sda                     8:0    0    20G  0 disk
├─sda1                  8:1    0     1M  0 part
├─sda2                  8:2    0     2G  0 part /boot
└─sda3                  8:3    0    18G  0 part /
sdb                     8:16   0    10G  0 disk  <-- Наш новый диск
```

### 2. Создание разделов

Используйте `fdisk` для создания разделов на новом диске.

```bash
sudo fdisk /dev/sdb
```

В интерактивном режиме `fdisk`:
- `n` — создать новый раздел (new).
- `p` — основной раздел (primary).
- `1` — номер раздела.
- `Enter` (для первого сектора) — принять значение по умолчанию.
- `+5G` — указать размер раздела (например, 5 ГБ).
- `n` -> `p` -> `2` -> `Enter` -> `Enter` — создать второй раздел, используя все оставшееся место.
- `t` -> `1` -> `8e` — изменить тип первого раздела на "Linux LVM".
- `t` -> `2` -> `8e` — изменить тип второго раздела на "Linux LVM".
- `p` — проверить (print) созданную таблицу разделов.
- `w` — записать изменения и выйти (write).

После выхода из `fdisk`, `lsblk` покажет созданные разделы:
```bash
$ lsblk
...
sdb                     8:16   0    10G  0 disk
├─sdb1                  8:17   0     5G  0 part
└─sdb2                  8:18   0     5G  0 part
```

### 3. Создание LVM-структуры

#### Создание физических томов (PV)

Создайте физические тома (PV) из новых разделов:

> **Важно:** Если диск или раздел уже использовался ранее (имеет сигнатуры), используйте `wipefs` для очистки метаданных, иначе LVM может отказаться работать с диском.

```bash
sudo wipefs --all /dev/sdb1
sudo pvcreate /dev/sdb1 /dev/sdb2
```

#### Создание группы томов (VG)

Создайте группу томов (VG), например, `data_vg`, из одного или нескольких PV:

```bash
sudo vgcreate data_vg /dev/sdb1 /dev/sdb2
# Вывод: Volume group "data_vg" successfully created
```

#### Создание логических томов (LV)

Создайте логические тома (LV) из пространства VG. Создадим два LV: `logs_lv` и `data_lv`.

```bash
sudo lvcreate -n logs_lv -L 5G data_vg
# Вывод: Logical volume "logs_lv" created.

sudo lvcreate -n data_lv -l 100%FREE data_vg
# Вывод: Logical volume "data_lv" created.
```

### 4. Форматирование и монтирование

#### Форматирование

Отформатируйте новые логические тома в нужную файловую систему, например, `ext4`:

```bash
sudo mkfs.ext4 /dev/data_vg/logs_lv
sudo mkfs.ext4 /dev/data_vg/data_lv
```

#### Монтирование

Создайте точки монтирования и примонтируйте тома:

```bash
sudo mkdir -p /mnt/data
sudo mount /dev/data_vg/logs_lv /var/log
sudo mount /dev/data_vg/data_lv /mnt/data
```

### 5. Настройка постоянного монтирования

Чтобы монтирование сохранялось после перезагрузки, добавьте записи в `/etc/fstab`.

#### Узнайте UUID

Узнайте UUID ваших логических томов с помощью `blkid`:

```bash
$ sudo blkid
...
/dev/mapper/data_vg-logs_lv: UUID="a1b2c3d4-..." TYPE="ext4"
/dev/mapper/data_vg-data_lv: UUID="e5f6g7h8-..." TYPE="ext4"
```

#### Добавьте записи в /etc/fstab

Добавьте следующие строки в конец файла `/etc/fstab`, используя полученные UUID:

```
# /etc/fstab

# монтирование для логов
UUID=a1b2c3d4-...    /var/log    ext4    defaults    0    2

# монтирование для данных
UUID=e5f6g7h8-...    /mnt/data   ext4    defaults    0    2
```

#### Проверка монтирования

Проверьте и примонтируйте все, что указано в `fstab`:
```bash
sudo mount -a
```

После этих шагов система будет использовать новые LVM-тома для `/var/log` и `/mnt/data`, и они будут автоматически монтироваться при каждой загрузке.

## Базовые операции создания

### Создание физического тома (PV)

Помечаем диск или раздел как готовый для LVM.

```bash
pvcreate /dev/sdb1
```

### Создание группы томов (VG)

Объединяем один или несколько PV в единый пул.

```bash
# Из одного диска
vgcreate my_vg /dev/sdb1

# Из нескольких дисков
vgcreate my_vg /dev/sdb1 /dev/sdc1
```

### Создание логического тома (LV)

"Нарезаем" том из пространства VG.

```bash
# Создать LV размером 10 ГБ
lvcreate -L 10G -n my_lv my_vg

# Создать LV, используя весь оставшийся объем VG
lvcreate -l 100%FREE -n my_lv my_vg
```

### Форматирование и монтирование LV

Путь к тому: `/dev/<имя_VG>/<имя_LV>` или `/dev/mapper/<имя_VG>-<имя_LV>`.

> **Рекомендация:** В `/etc/fstab` лучше использовать путь вида `/dev/mapper/<имя_VG>-<имя_LV>`, так как это обеспечивает лучшую совместимость и стабильность (является символической ссылкой на реальное устройство в `/dev/dm-*`).

```bash
mkfs.ext4 /dev/my_vg/my_lv
mkdir /data
mount /dev/my_vg/my_lv /data
```
