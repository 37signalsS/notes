# LVM: Операции Управления

## Практические сценарии

### Просмотр информации

| Команда | Описание |
| :--- | :--- |
| `pvs` или `pvdisplay` | Показывает информацию о физических томах (PV). |
| `vgs` или `vgdisplay` | Показывает информацию о группах томов (VG). |
| `lvs` или `lvdisplay` | Показывает информацию о логических томах (LV). |

### Создание и настройка

1. **Создание физического тома (PV):** Помечаем диск или раздел как готовый для LVM.

    ```bash
    pvcreate /dev/sdb1
    ```

2. **Создание группы томов (VG):** Объединяем один или несколько PV в единый пул.

    ```bash
    # Из одного диска
    vgcreate my_vg /dev/sdb1

    # Из нескольких дисков
    vgcreate my_vg /dev/sdb1 /dev/sdc1
    ```

3. **Создание логического тома (LV):** "Нарезаем" том из пространства VG.

    ```bash
    # Создать LV размером 10 ГБ
    lvcreate -L 10G -n my_lv my_vg

    # Создать LV, используя весь оставшийся объем VG
    lvcreate -l 100%FREE -n my_lv my_vg
    ```

4. **Форматирование и монтирование LV:**
    Путь к тому: `/dev/<имя_VG>/<имя_LV>` или `/dev/mapper/<имя_VG>-<имя_LV>`.

    ```bash
    mkfs.ext4 /dev/my_vg/my_lv
    mkdir /data
    mount /dev/my_vg/my_lv /data
    ```

### Изменение размеров

#### Расширение логического тома (LV)

Это безопасная операция, которую можно выполнять "на лету".

1. **Расширение группы томов (VG):** Если в VG закончилось место, ее можно расширить, добавив новый PV.

    ```bash
    # 1. Инициализировать новый диск как PV
    pvcreate /dev/sdd1
    # 2. Добавить PV в существующую VG
    vgextend my_vg /dev/sdd1
    ```

2. **Расширение логического тома (LV):**

    ```bash
    # Добавить 5 ГБ к существующему LV
    lvextend -L +5G /dev/my_vg/my_lv
    ```

3. **Расширение файловой системы:** Файловая система должна "увидеть" новое пространство.
    * Для **ext2/3/4**: `resize2fs /dev/my_vg/my_lv`
    * Для **XFS**: `xfs_growfs /path/to/mountpoint`

    **Удобный способ:** Использовать флаг `-r`, чтобы расширить LV и ФС одной командой.

    ```bash
    lvextend -L +5G -r /dev/my_vg/my_lv
    ```

#### Уменьшение логического тома (LV)

**Внимание: Это рискованная операция. Всегда делайте резервные копии!**

* **Ограничения ФС:**
  * **XFS:** Не поддерживает уменьшение.
  * **ext2/3/4:** Поддерживает, но **только в офлайн-режиме** (том должен быть отмонтирован).

* **Безопасный подход для ext2/3/4:**
    1. `umount /data` — **Отмонтировать том.**
    2. `e2fsck -f /dev/my_vg/my_lv` — **Проверить ФС.**
    3. `resize2fs /dev/my_vg/my_lv 14G` — **Уменьшить ФС** до размера *чуть меньше* целевого размера LV.
    4. `lvreduce -L 15G /dev/my_vg/my_lv` — **Уменьшить LV.**
    5. `resize2fs /dev/my_vg/my_lv` — **Расширить ФС**, чтобы занять все доступное место на LV.
    6. `mount /dev/my_vg/my_lv /data` — **Смонтировать обратно.**

### Замена физического диска в VG

`pvmove` позволяет заменять физический диск в группе томов без остановки работы системы.

**Процесс замены:**

1. **Подготовьте новый диск:** Подключите, создайте раздел и инициализируйте его как PV (`pvcreate /dev/sdd1`).
2. **Добавьте новый диск в VG:** Добавьте новый PV в ту же группу томов (`vgextend my_vg /dev/sdd1`).
3. **Переместите данные:** Команда `pvmove` мигрирует все данные со старого диска на другие свободные диски в той же VG.

    ```bash
    # Переместить все данные с /dev/sdc1
    pvmove /dev/sdc1
    ```

    Этот процесс может занять длительное время.
4. **Удалите старый диск из VG:**

    ```bash
    vgreduce my_vg /dev/sdc1
    ```

5. **Очистите LVM-метки:**

    ```bash
    pvremove /dev/sdc1
    ```

    Теперь старый диск можно физически извлекать.

### Полный жизненный цикл LVM

1. **Подготовка диска и создание PV:**
    * Добавьте новый диск (`/dev/sdc`).
    * Создайте на нем раздел (`/dev/sdc1`) и пометьте его для LVM (`parted`, `set 1 lvm on`).
    * Инициализируйте PV:

        ```bash
        sudo pvcreate /dev/sdc1
        ```

2. **Создание VG и LV:**

    ```bash
    sudo vgcreate my_vg /dev/sdc1
    sudo lvcreate -L 1G -n my_test_lv my_vg
    ```

3. **Форматирование и монтирование:**

    ```bash
    sudo mkfs.ext4 /dev/my_vg/my_test_lv
    sudo mkdir /mnt/test
    sudo mount /dev/my_vg/my_test_lv /mnt/test
    ```

    *(Не забудьте про [`/etc/fstab`](../mounting/fstab.md#структура-и-синтаксис-файла-etcfstab) для постоянного монтирования)*.

4. **Расширение "на лету":**
    * Добавьте еще один диск/раздел (`/dev/sdd1`) в VG: `pvcreate /dev/sdd1`, `vgextend my_vg /dev/sdd1`.
    * Расширьте LV и файловую систему одной командой:

        ```bash
        sudo lvextend -L +500M -r /dev/my_vg/my_test_lv
        ```

5. **Полное удаление (в обратном порядке):**

    ```bash
    sudo umount /mnt/test
    sudo lvremove /dev/my_vg/my_test_lv
    sudo vgreduce my_vg /dev/sdc1
    sudo vgreduce my_vg /dev/sdd1
    sudo pvremove /dev/sdc1 /dev/sdd1
    ```
