# Внутреннее устройство файловых систем

### Определения

**Page Cache (кэш страниц)** — это основной механизм дискового кэша в Linux. Это область в оперативной памяти (RAM), где хранятся копии данных с диска (страницы файлов), к которым недавно обращались.

**Суперблок (Superblock)** — это ключевая структура метаданных, которая описывает состояние файловой системы: её размер, количество блоков, расположение таблицы inode'ов и другую служебную информацию.

### Основные концепции

#### Принцип работы Page Cache

Поскольку устройства ввода-вывода являются самым медленным компонентом системы, Linux использует всю свободную оперативную память для кэширования дисковых операций.

-   **При чтении:** Когда процесс впервые читает файл, его данные копируются с диска в Page Cache. Все последующие чтения этого файла будут происходить напрямую из быстрой оперативной памяти, минуя медленный диск.
-   **При записи:** Данные сначала записываются в Page Cache (это очень быстрая операция), и только потом ядро в фоновом режиме "сбрасывает" их на диск.

Кэш не удаляется из памяти, пока она не потребуется для более важных задач. Это объясняет, почему в выводе утилиты `free -m` колонка `buff/cache` почти всегда занята.

#### Содержимое суперблока

Суперблок критически важен для монтирования и работы файловой системы. Он хранит:
-   Тип и размер файловой системы.
-   Размер блока.
-   Количество свободных и занятых блоков и inode'ов.
-   Точку монтирования и статус ("чистая" или "грязная").

Из-за его важности файловая система хранит несколько резервных копий суперблока.

### Практические сценарии

#### Наблюдение за Page Cache

Увидеть, сколько памяти используется под Page Cache, можно с помощью утилиты `free`:
```bash
free -m
```
Значение в колонке `buff/cache` показывает объем памяти, выделенный под кэш страниц и другие буферы ядра.

#### Просмотр информации о суперблоке

Для файловых систем Ext2/3/4 информацию из суперблока можно прочитать с помощью `dumpe2fs`:
```sh
sudo dumpe2fs /dev/sda1 | grep -i superblock
```
Эта команда покажет расположение основного суперблока и его резервных копий.
