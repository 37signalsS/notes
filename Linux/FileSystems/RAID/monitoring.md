# Мониторинг RAID-массивов

## Определения

**Мониторинг RAID (Redundant Array of Independent Disks / Избыточный массив независимых дисков)** — непрерывное отслеживание состояния массива, дисков-участников и процессов восстановления (rebuild/reshape).

**S.M.A.R.T. (Self-Monitoring, Analysis and Reporting Technology)** — встроенная в накопители система самодиагностики для оценки физического состояния дисков.

## Основные концепции

### Источники информации

| Источник | Команда | Описание |
| :--- | :--- | :--- |
| `/proc/mdstat` | `cat /proc/mdstat` | Быстрый статус всех массивов (ядро) |
| `mdadm --detail` | `mdadm --detail /dev/mdX` | Детальная информация о массиве |
| `mdadm --examine` | `mdadm --examine /dev/sdX` | Информация о суперблоке (метаданных) диска |
| SMART | `smartctl -a /dev/sdX` | Здоровье физических дисков через `smartmontools` |

## Практические сценарии

### Быстрая проверка состояния

```bash
# Статус всех массивов в реальном времени
watch -n 1 cat /proc/mdstat
```

**Расшифровка вывода:**

```
md0 : active raid1 sdb1[1] sda1[0]
      1048576 blocks super 1.2 [2/2] [UU]
```

| Символ | Значение |
| :--- | :--- |
| `[UU]` | Все диски в RAID 1 исправны |
| `[UUU]` | Все 3 диска в RAID 5 исправны |
| `[_U]` | Один диск в RAID 1 сбойный (degraded) |
| `[U_U]` | Один диск в RAID 5 сбойный |
| `[>..........]` | Идёт rebuild/resync (прогресс восстановления) |
| `recovery = 45.2%` | Процент завершения восстановления |

### Детальная информация о массиве

```bash
sudo mdadm --detail /dev/md0
```

**Ключевые поля статуса (State):**

| Статус | Значение |
| :--- | :--- |
| `active, clean` | Нормальное состояние, данные согласованы |
| `active, degraded` | Массив работает, но есть сбойные диски |
| `inactive` | Массив не активен (требует сборки) |
| `resyncing` | Идёт начальная синхронизация |
| `recovering` | Идёт восстановление (rebuild) после замены диска |

### Проверка метаданных на диске

```bash
# Проверка метаданных RAID на конкретном разделе
sudo mdadm --examine /dev/sda1
```

**Что проверять:**

* **UUID (Universally Unique Identifier):** должен быть идентичен у всех дисков одного массива.
* **Events:** счётчик обновлений метаданных (диск с меньшим числом событий может быть устаревшим).
* **State:** текущая роль диска в массиве (`Active`, `Spare`, `Failed`).

### Проверка SMART дисков в RAID

Для программного RAID (`mdadm`) диски видны операционной системе напрямую, поэтому стандартные команды `smartctl` работают без дополнительных ключей.

```bash
# Проверка здоровья физического диска
sudo smartctl -a /dev/sda
```

Подробнее: [Проверка дисков в RAID](../../Diagnostics/Hardware/smartctl/index.md#проверка-дисков-в-raid-массивах).

### Настройка уведомлений о сбоях

Для автоматического мониторинга используется демон `mdadm`, который может отправлять email или выполнять скрипты при сбоях.

**Конфигурация:** `/etc/mdadm/mdadm.conf`

```bash
# Адрес для отправки уведомлений
MAILADDR admin@example.com

# Программа-обработчик событий
PROGRAM /usr/local/bin/raid_alert.sh
```

**Запуск службы мониторинга:**

```bash
# Включение и запуск стандартной службы (Debian/Ubuntu)
sudo systemctl enable --now mdadm
```

### Диагностика и обслуживание

#### Массив в режиме degraded

Если массив потерял диск, необходимо определить сбойное устройство:

```bash
# Поиск устройств со статусом failed или faulty
sudo mdadm --detail /dev/md0 | grep -E "failed|faulty"
```

#### Проверка консистентности (Scrubbing)

Рекомендуется периодически проверять массив на наличие нечитаемых секторов и несоответствий чётности.

```bash
# Запуск проверки (не деструктивно)
echo check | sudo tee /sys/block/md0/md/sync_action

# Проверка прогресса
cat /sys/block/md0/md/sync_completed

# Исправление найденных ошибок
echo repair | sudo tee /sys/block/md0/md/sync_action
```
