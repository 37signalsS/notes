# Управление RAID 5

## Определения

**RAID 5 (Redundant Array of Independent Disks Level 5 / Избыточный массив независимых дисков уровня 5)** — уровень RAID с чередованием данных и распределённой чётностью. Обеспечивает баланс между полезной ёмкостью и отказоустойчивостью.

**URE (Unrecoverable Read Error / Некорректируемая ошибка чтения)** — критическая ошибка при чтении данных с диска, которая может привести к потере массива при восстановлении (rebuild).

> **Внимание:** RAID 5 считается устаревшим для накопителей объёмом более 1 ТБ. Рекомендуется использовать RAID 6 или RAID 10 для обеспечения надёжности в современных системах.

## Основные концепции

### Особенности RAID 5

| Параметр | Значение |
| :--- | :--- |
| Минимальное количество дисков | 3 |
| Отказоустойчивость | 1 диск |
| Полезная ёмкость | (N-1) × размер минимального диска |
| Штраф на запись | 4 операции (read-modify-write) |

### Ограничения и риски

Для дисков объёмом 2 ТБ и более вероятность возникновения URE при восстановлении массива достигает 40%. Время процесса восстановления для диска объёмом 8 ТБ может составлять от 12 до 24 часов, в течение которых массив остаётся уязвимым к отказу второго диска.

## Практические сценарии

### Создание массива RAID 5

```bash
# Создание массива из 3 дисков
sudo mdadm --create --verbose /dev/md0 --level=5 --raid-devices=3 /dev/vdb /dev/vdc /dev/vdd

# Фиксация конфигурации для автоматической сборки
sudo mdadm --detail --scan | sudo tee -a /etc/mdadm/mdadm.conf
sudo update-initramfs -u
```

Базовые шаги подготовки накопителей идентичны процедурам для [RAID 1](./raid1-management.md).

### Работа при сбоях

#### Имитация отказа накопителя

```bash
# Пометка диска как неисправного
sudo mdadm /dev/md0 --fail /dev/vdb

# Проверка состояния массива
cat /proc/mdstat
sudo mdadm --detail /dev/md0
```

#### Замена неисправного диска

```bash
# 1. Удаление сбойного диска из состава массива
sudo mdadm /dev/md0 --remove /dev/vdb

# 2. Добавление нового диска (процесс восстановления начнется автоматически)
sudo mdadm /dev/md0 --add /dev/vde
```

**Мониторинг процесса восстановления:** см. [Мониторинг RAID-массивов](./monitoring.md#быстрая-проверка-состояния).

### Изменение конфигурации массива (Grow)

RAID 5 поддерживает расширение количества дисков в режиме реального времени с перераспределением данных (reshape).

#### Добавление диска и расширение

```bash
# 1. Добавление нового диска как запасного (spare)
sudo mdadm /dev/md0 --add /dev/vdb

# 2. Увеличение количества активных дисков в массиве
sudo mdadm --grow /dev/md0 --raid-devices=4
```

**Мониторинг процесса перераспределения (reshape):** см. [Мониторинг RAID-массивов](./monitoring.md#быстрая-проверка-состояния).

#### Расширение файловой системы

После завершения перераспределения данных необходимо расширить файловую систему:

```bash
# Для файловой системы ext4
sudo resize2fs /dev/md0

# Для файловой системы XFS
sudo xfs_growfs /mnt/raid5
```

### Конвертация в RAID 6

Для повышения надёжности при увеличении количества дисков (более 4-х) рекомендуется переходить на RAID 6.

```bash
# Добавление диска и изменение уровня RAID
sudo mdadm --grow /dev/md0 --level=6 --raid-devices=4
```

**Мониторинг процесса конвертации:** см. [Мониторинг RAID-массивов](./monitoring.md#быстрая-проверка-состояния).
