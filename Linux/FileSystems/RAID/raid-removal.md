# Удаление RAID-массива

## Определения

**Удаление RAID (Redundant Array of Independent Disks / Избыточный массив независимых дисков)** — процесс деактивации виртуального устройства и очистки физических накопителей от метаданных. Операция является необратимой и приводит к потере доступа к данным через устройство RAID.

**Очистка суперблока (Metadata Clearing)** — удаление служебных заголовков RAID с физических дисков. Без этого шага ОС может попытаться автоматически собрать массив при следующей загрузке, даже если он был остановлен.

## Основные концепции

### Ключевые инструменты и операции

| Команда | Назначение | Особенности |
| :--- | :--- | :--- |
| **`mdadm --stop`** | Остановка массива | Требует, чтобы устройство не было смонтировано и не использовалось другими подсистемами (LVM). |
| **`mdadm --zero-superblock`** | Стирание метаданных | Применяется к физическим разделам или дискам, входившим в массив. |
| **`wipefs --all`** | Полная очистка подписей | Удаляет все сигнатур (RAID, LVM, файловые системы), подготавливая диск к новому использованию. |
| **`lsof` / `fuser`** | Поиск блокирующих процессов | Используется, если массив не останавливается из-за состояния "busy". |

## Практические сценарии

### Полный демонтаж массива из системы

Процедура должна выполняться строго последовательно, «сверху вниз» по стеку хранения.

#### 1. Размонтирование и очистка зависимостей

Перед остановкой RAID необходимо освободить устройство от всех вышележащих слоев.

1.  **Завершение работы приложений:** Закройте все процессы, использующие массив.
2.  **Размонтирование:**
    ```bash
    sudo umount /dev/md0
    ```
3.  **Очистка LVM (если использовался):**
    Если поверх RAID были созданы физические тома (PV), их нужно удалить:
    ```bash
    sudo pvremove /dev/md0
    ```
4.  **Удаление из fstab:**
    Обязательно удалите или закомментируйте строку с RAID в `/etc/fstab`, иначе система может не загрузиться.

#### 2. Остановка массива

Если устройство занято, определите процесс:
```bash
sudo lsof /dev/md0
# или
sudo fuser -v /dev/md0
```

Остановите массив:
```bash
sudo mdadm --stop /dev/md0
```

#### 3. Уничтожение метаданных

После остановки `/dev/md0` перестает существовать, и операции проводятся над физическими устройствами (например, `/dev/sdb1` и `/dev/sdc1`).

```bash
# Очистка суперблока RAID
sudo mdadm --zero-superblock /dev/sdb1 /dev/sdc1

# Рекомендуется также очистить все остальные подписи
sudo wipefs --all /dev/sdb1
sudo wipefs --all /dev/sdc1
```

#### 4. Финализация конфигурации

Если этого не сделать, система будет выдавать ошибки при загрузке или пытаться собрать несуществующий массив.

1.  **Обновление mdadm.conf:** Удалите соответствующую строку `ARRAY` из `/etc/mdadm/mdadm.conf`.
2.  **Обновление initramfs:**
    ```bash
    sudo update-initramfs -u
    ```

---

### Удаление диска из состава массива

Применяется для замены неисправного накопителя или при плановом уменьшении объема.

1.  **Пометка как сбойного:**
    ```bash
    sudo mdadm /dev/md0 --fail /dev/sdb1
    ```
2.  **Удаление из массива:**
    ```bash
    sudo mdadm /dev/md0 --remove /dev/sdb1
    ```
3.  **Очистка извлеченного диска:**
    ```bash
    sudo mdadm --zero-superblock /dev/sdb1
    ```
