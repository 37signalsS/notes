# Удаление RAID-массива

## Определения

**Удаление RAID (Redundant Array of Independent Disks / Избыточный массив независимых дисков)** — процесс деактивации и демонтажа программного массива. Операция может подразумевать как простое прекращение работы массива с сохранением данных на дисках, так и полную очистку накопителей от метаданных и файловых систем.

**Очистка метаданных (суперблока)** — процедура удаления служебной информации RAID с физических дисков или разделов, что предотвращает автоматическую сборку массива при загрузке системы.

## Основные концепции

### Ключевые операции

| Операция | Команда | Назначение |
| :--- | :--- | :--- |
| Остановка массива | `mdadm --stop` | Перевод устройства `/dev/mdX` в неактивное состояние |
| Очистка метаданных | `mdadm --zero-superblock` | Стирание подписей RAID с блочного устройства |
| Полная очистка подписей | `wipefs --all` | Удаление всех сигнатур (Файловых систем, LVM, RAID) |

### Меры предосторожности

Удаление метаданных делает данные массива недоступными через устройство RAID, но не перезаписывает сами блоки данных. Для гарантированного уничтожения информации следует использовать специализированные утилиты (например, `shred`).

## Практические сценарии

### Полное удаление массива из системы

Процедура выполняется последовательно для корректного освобождения ресурсов ОС (Операционной системы).

#### 1. Размонтирование файловой системы

```bash
# Размонтирование точки монтирования
sudo umount /dev/md0

# Удаление записи из конфигурации монтирования
sudo nano /etc/fstab  # удалить строку, содержащую UUID или /dev/md0
```

**UUID (Universally Unique Identifier / Универсальный уникальный идентификатор)** позволяет однозначно идентифицировать массив.

#### 2. Остановка работы массива

```bash
# Деактивация виртуального устройства
sudo mdadm --stop /dev/md0
```

#### 3. Удаление метаданных RAID с накопителей

Необходимо выполнить для каждого диска или раздела, входившего в состав массива.

```bash
# Для разделов
sudo mdadm --zero-superblock /dev/sdb1 /dev/sdc1

# Для целых дисков
sudo mdadm --zero-superblock /dev/sdb /dev/sdc
```

**Проверка результата:**

```bash
sudo mdadm --examine /dev/sdb1
# Ожидаемый результат: "No md superblock detected"
```

#### 4. Очистка конфигурационных файлов

```bash
# Удаление упоминаний массива из mdadm.conf
sudo nano /etc/mdadm/mdadm.conf

# Обновление образа initramfs (временной файловой системы ядра)
sudo update-initramfs -u
```

---

### Удаление отдельного диска из активного массива

Сценарий применяется при замене диска или уменьшении размера массива (если это поддерживается уровнем RAID).

```bash
# 1. Пометка диска как неисправного
sudo mdadm /dev/md0 --fail /dev/sdb1

# 2. Исключение диска из состава массива
sudo mdadm /dev/md0 --remove /dev/sdb1

# 3. Очистка метаданных на извлеченном диске
sudo mdadm --zero-superblock /dev/sdb1
```

> **Примечание:** После этих действий массив перейдет в состояние `degraded` (деградированный), если не был предусмотрен диск горячей замены (hot spare).
