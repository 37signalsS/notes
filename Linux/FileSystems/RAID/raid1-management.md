# Управление RAID 1 (Зеркалирование)

## Определения

**RAID 1 (Redundant Array of Independent Disks Level 1)** — технология объединения накопителей, при которой данные идентично записываются на два или более диска. Массив остается работоспособным до тех пор, пока исправен хотя бы один диск из зеркальной пары.

**Зеркалирование (Mirroring)** — процесс синхронной записи одних и тех же данных на разные физические устройства для обеспечения избыточности.

## Основные концепции

### Выбор метаданных для загрузочных разделов
При создании массива для раздела `/boot` критически важно использовать версию метаданных **1.0**.
*   **Почему:** В версии 1.0 суперблок находится в конце раздела. Это позволяет BIOS/UEFI и загрузчику GRUB видеть данные на разделе как на обычном диске еще до инициализации модуля `md` ядром.

### Отказоустойчивость загрузки
Наличие RAID 1 для системного раздела не гарантирует загрузку при отказе одного диска, если загрузчик (GRUB) установлен только на один из них. Необходимо выполнять установку на каждое физическое устройство в зеркале.

## Практические сценарии

### Создание RAID 1

#### 1. Подготовка накопителей
Рекомендуется использовать разделы (GPT), оставляя небольшой объем в конце диска неразмеченным (например, 100 МБ) для компенсации разницы в физическом объеме дисков от разных производителей.

```bash
# Создание таблицы разделов GPT
sudo parted /dev/sdb mklabel gpt
# Создание раздела (оставив место в конце)
sudo parted /dev/sdb mkpart primary ext4 1M 100%
sudo parted /dev/sdb set 1 raid on
```

#### 2. Очистка старых метаданных
Перед сборкой необходимо убедиться в отсутствии остатков старых конфигураций.

```bash
# Проверка наличия метаданных
sudo mdadm --examine /dev/sdb1
# Удаление сигнатур файловых систем и LVM
sudo wipefs --all /dev/sdb1
# Удаление суперблока RAID
sudo mdadm --zero-superblock /dev/sdb1
```

#### 3. Создание массива
Для обычных данных:
```bash
sudo mdadm --create /dev/md0 --level=1 --raid-devices=2 /dev/sdb1 /dev/sdc1
```

Для загрузочного раздела (`/boot`):
```bash
sudo mdadm --create /dev/md0 --level=1 --metadata=1.0 --raid-devices=2 /dev/sdb1 /dev/sdc1
```

#### 4. Обеспечение загрузки (GRUB)
Установите GRUB на оба физических диска зеркала:
```bash
sudo grub-install /dev/sdb
sudo grub-install /dev/sdc
```

#### 5. Сохранение конфигурации
```bash
# Фиксация структуры массива
sudo mdadm --detail --scan | sudo tee -a /etc/mdadm/mdadm.conf
# Обновление initramfs
sudo update-initramfs -u
```

### Обслуживание и масштабирование

#### Добавление дополнительного зеркала (Трехстороннее зеркало)
Если требуется повысить надежность, RAID 1 можно расширить с 2 до 3 (или более) дисков.

```bash
# 1. Добавление диска как Spare
sudo mdadm /dev/md0 --add /dev/sdd1
# 2. Расширение количества активных устройств (начнется синхронизация)
sudo mdadm --grow /dev/md0 --raid-devices=3
```

#### Увеличение объема массива (Grow)
Сценарий: замена обоих дисков в RAID 1 на более емкие.

1.  **Замените диски по очереди**, дождавшись полной синхронизации после каждой замены (`cat /proc/mdstat`).
2.  **Расширение массива:**
    ```bash
    # Массив займет всё доступное пространство на новых дисках
    sudo mdadm --grow /dev/md0 --size=max
    ```
3.  **Расширение файловой системы:**
    ```bash
    sudo resize2fs /dev/md0  # для ext4
    # или
    sudo xfs_growfs /mnt/raid1  # для XFS
    ```

#### Проверка целостности (Scrubbing)
Рекомендуется выполнять периодически для выявления расхождений в данных между дисками.
```bash
# Запуск проверки
echo check | sudo tee /sys/block/md0/md/sync_action
# Проверка результата (mismatch_cnt должен быть 0)
cat /sys/block/md0/md/mismatch_cnt
```

### Обработка сбоев

При отказе диска массив переходит в режим `degraded`.

1.  **Идентификация сбойного диска:**
    ```bash
    sudo mdadm --detail /dev/md0 | grep "failed"
    ```
2.  **Удаление из массива:**
    ```bash
    sudo mdadm /dev/md0 --remove /dev/sdb1
    ```
3.  **Добавление нового диска:**
    ```bash
    sudo mdadm /dev/md0 --add /dev/sde1
    ```
