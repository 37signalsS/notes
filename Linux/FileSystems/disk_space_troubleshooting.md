# Устранение нехватки места на диске

## Аварийное освобождение места (ext-файловые системы)

### Ситуация

Работа системы практически остановлена. Диск заполнен на 100%, что мешает выполнению даже базовых команд (например, автодополнению в `bash`), так как они не могут создать временные файлы.

### Решение

Файловые системы `ext2/3/4` по умолчанию резервируют 5% дисковых блоков для пользователя `root`. Это сделано для того, чтобы `root` мог войти в систему и провести очистку, даже когда диск заполнен для обычных пользователей.

В экстренной ситуации можно временно обнулить этот резерв, чтобы немедленно получить доступ к зарезервированному пространству.

```bash
# Установить процент зарезервированных блоков в 0
# Замените /dev/sdX на ваш раздел, например /dev/sda1
sudo tune2fs -m 0 /dev/sdX
```

Это изменение применяется мгновенно и даст вам несколько гигабайт свободного места для проведения очистки.

### Важное предупреждение

После устранения проблемы и очистки диска **обязательно верните значение резерва обратно на 5%**.

```bash
sudo tune2fs -m 5 /dev/sdX
```

Отсутствие резерва повышает риск сильной фрагментации файловой системы и может помешать `root` исправить проблемы с диском в будущем.
