# Восстановление GUID Partition Table (GPT)

## Определения

- **GPT (GUID Partition Table):** Современный стандарт разметки диска, пришедший на смену MBR.
- **Primary GPT:** Основная таблица разделов, расположенная в начале диска.
- **Secondary (Backup) GPT:** Резервная копия основной таблицы разделов, расположенная в конце диска.

## Основные концепции

- **Преимущества:** GPT обладает значительными преимуществами перед устаревшим MBR, включая поддержку дисков объемом более 2 ТБ, практически неограниченное количество разделов и повышенную надежность за счет дублирования таблицы разделов. Подробное сравнение приведено в статье о [разделах и файловых системах](./partitions_and_filesystems.md).
- **Резервное копирование:** Ключевая особенность GPT — наличие Secondary GPT, которая позволяет восстановить поврежденную Primary GPT.
- **Работа с дисками переменного размера:** При увеличении физического размера диска (например, на ВМ), Secondary GPT не смещается автоматически. Для использования нового пространства необходимо с помощью утилит разметки пересоздать Secondary GPT в новом конце диска.

## Практические сценарии

### 1. Восстановление с помощью `gdisk`

`gdisk` — стандартная утилита для работы с GPT. Она автоматически обнаруживает повреждения Primary GPT и предлагает восстановить её из Secondary GPT.

**Сценарий:** Primary GPT повреждена, Secondary GPT в порядке.

1. Запустите `gdisk` для проблемного диска:

    ```bash
    gdisk /dev/sda
    ```

2. `gdisk` обнаружит несоответствие и предложит использовать резервную копию для восстановления.
3. Для ручного восстановления используйте команду `r` (recovery & transformation options), а затем `c` (load backup partition table).
4. Сохраните изменения командой `w`. `gdisk` перезапишет поврежденную Primary GPT данными из Secondary GPT.

### 2. Увеличение размера диска с GPT

При увеличении размера виртуального диска `gdisk` позволяет корректно переместить Secondary GPT.

1. Запустите `gdisk /dev/sda`.
2. Измените или создайте раздел, чтобы он занимал новое пространство.
3. При сохранении изменений (`w`) `gdisk` автоматически переместит Secondary GPT в конец диска.
    > **Важно:** `gdisk` не позволит изменить размер раздела за пределы существующей Secondary GPT без её предварительного пересоздания.

### 3. Резервное копирование и восстановление с помощью `dd`

> **Внимание:** Этот метод является низкоуровневым и потенциально опасным. Рекомендуется использовать `gdisk` в большинстве случаев.

**Создание резервной копии GPT:**
Заголовок и таблица разделов GPT занимают больше 512 байт. 34 сектора (17 КБ) обычно достаточно.

```bash
# Копирование первых 17 КБ диска
dd if=/dev/sda of=gpt_backup.img bs=512 count=34
```

**Восстановление GPT из резервной копии:**
Эта команда полностью перезапишет таблицу разделов в начале диска.

```bash
dd if=gpt_backup.img of=/dev/sda bs=512 count=34
```
