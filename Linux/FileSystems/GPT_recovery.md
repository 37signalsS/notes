# Восстановление GUID Partition Table (GPT)

## Определения

-   **GPT (GUID Partition Table):** Глобальная таблица разделов GUID. Более современный стандарт разметки диска, пришедший на смену MBR.
-   **Primary GPT:** Основная таблица разделов GPT, расположенная в начале диска.
-   **Secondary (Backup) GPT:** Вторичная (резервная) таблица разделов GPT, расположенная в конце диска. Содержит точную копию Primary GPT.

## Основные концепции

-   **Преимущества перед MBR:**
    -   Поддержка дисков размером более 2 ТБ.
    -   Практически неограниченное количество разделов (по умолчанию многие утилиты предлагают 128).
    -   Механизм резервного копирования: наличие Secondary GPT позволяет восстановить поврежденную Primary GPT.
    -   Отсутствие концепции "расширенных" и "логических" разделов, что упрощает разметку.
-   **Размер:** GPT занимает значительно больше места, чем MBR (минимум 1024 байта для заголовков и доп.данных).
-   **Увеличение размера диска:** При увеличении физического размера диска (например, на виртуальной машине), Primary GPT может быть обновлена, но Secondary GPT, находящаяся в конце диска, не смещается автоматически. Для использования всего нового пространства необходимо удалить старую Secondary GPT и позволить утилите разметки создать новую в конце расширенного диска.

## Практические сценарии

### 1. Резервное копирование и восстановление GPT с помощью `dd`

**Создание резервной копии GPT (включая заголовки и таблицу разделов):**
> **Примечание:** Для GPT необходимо скопировать больше, чем 512 байт, так как структура сложнее. Точный размер зависит от количества разделов, но для минимальной структуры можно взять несколько килобайт.
```bash
# Пример: копирование первых 17 КБ диска (обычно достаточно для заголовка и таблицы разделов по умолчанию)
dd if=/dev/sda of=gpt_header_backup.img bs=512 count=34
```

**Восстановление GPT из резервной копии:**
> **Внимание:** Эта команда полностью перезапишет начало диска. Используйте с осторожностью.
```bash
dd if=gpt_header_backup.img of=/dev/sda bs=512 count=34
```

### 2. Восстановление GPT с помощью `gdisk` (из Secondary GPT)

`gdisk` — утилита для работы с разделами GPT. Она способна автоматически обнаруживать повреждения Primary GPT и восстанавливать её из Secondary GPT.

**Сценарий:** Primary GPT повреждена, но Secondary GPT цела.

1.  **Запустите `gdisk` для проблемного диска:**
    ```bash
    gdisk /dev/sda
    ```

2.  `gdisk` автоматически попытается обнаружить и исправить несоответствия. Если Primary GPT повреждена, а Secondary GPT цела, `gdisk` предложит восстановить Primary GPT. Пример сообщения:
    ```
    Problem: The secondary header is invalid, but the primary header is good.
    ...
    Do you want to use the primary GPT? (Y/N): Y
    ```
    или
    ```
    Problem: The primary GPT table is corrupt, but the secondary is fine.
    ...
    Warning! Main and backup partition tables are inconsistent!
    ```
    В этом случае `gdisk` обычно предлагает восстановить основную таблицу из резервной.

3.  **Используйте команду `r` (recovery & transformation options) в интерактивном режиме `gdisk`.**
    ```
    Command (? for help): r
    ```

4.  **Выберите `p` (print the partition table) для просмотра текущего состояния.**

5.  **Выберите `c` (load backup partition table) для загрузки резервной таблицы.**

6.  **После восстановления выйдите из режима `r` и сохраните изменения (`w`).** `gdisk` перезапишет Primary GPT данными из Secondary GPT.

### 3. Увеличение размера диска с GPT

Если вы увеличили размер виртуального диска, содержащего GPT, `gdisk` поможет скорректировать Secondary GPT.

1.  **Удалите старую Secondary GPT:** Перед увеличением логического раздела (если он занимает всё доступное место) необходимо "переместить" Secondary GPT. Для этого `gdisk` при сохранении может потребовать подтверждения об удалении старой резервной копии и создании новой.

2.  **Запустите `gdisk`:**
    ```bash
    gdisk /dev/sda
    ```

3.  **Создайте или измените раздел** так, чтобы он занимал новое доступное пространство.

4.  **При сохранении изменений (`w`) `gdisk` автоматически разместит новую Secondary GPT** в конце диска.
    > **Важно:** `gdisk` не даст увеличить раздел за пределы существующей Secondary GPT без её предварительного смещения (удаления и воссоздания).

## Дополнительная информация

-   Все действия с `gdisk` должны выполняться с крайней осторожностью, так как неправильные команды могут привести к потере данных.
-   Перед любыми операциями по восстановлению или изменению структуры разделов рекомендуется выполнить полное резервное копирование диска.
