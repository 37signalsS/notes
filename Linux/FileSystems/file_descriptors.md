# Файловые дескрипторы

### Определения

**Файловый дескриптор** — это целое неотрицательное число, которое ядро использует для идентификации открытого файла или другого ресурса ввода-вывода (например, сокета или канала).

### Основные концепции

#### Стандартные потоки

По умолчанию каждый процесс в Linux при запуске получает три стандартных файловых дескриптора:

-   `0` – `stdin` (стандартный ввод)
-   `1` – `stdout` (стандартный вывод)
-   `2` – `stderr` (стандартный вывод ошибок)

#### Утечка файловых дескрипторов

Утечка файловых дескрипторов происходит, когда процесс многократно открывает файлы или сокеты, но не закрывает их, со временем исчерпывая доступный лимит. Это может привести к ошибке "Too many open files" и отказу приложения в обслуживании.

### Практические сценарии

#### Просмотр и мониторинг

-   **`lsof` (List Open Files):** Показывает все файлы, открытые процессами. Основной инструмент для отладки.

    ```bash
    # Показать все открытые файлы для процесса с указанным PID
    sudo lsof -p <PID>
    
    # Посчитать количество открытых файлов для процесса
    sudo lsof -p <PID> | wc -l
    ```

-   **Просмотр через `/proc`:** Директория `/proc/<PID>/fd/` содержит символические ссылки на все файлы, открытые процессом.

    ```bash
    # Посчитать количество открытых дескрипторов для процесса
    ls -l /proc/<PID>/fd/ | wc -l
    ```

-   **`ulimit`:** Позволяет просматривать и устанавливать лимиты ресурсов для текущей сессии пользователя.

    ```bash
    # Показать текущий лимит на количество открытых файловых дескрипторов
    ulimit -n
    ```

-   **`cat /proc/sys/fs/file-nr`:** Показывает общесистемную информацию о файловых дескрипторах.

    ```bash
    # Вывод содержит три значения:
    # 1. Общее количество выделенных файловых дескрипторов.
    # 2. Количество свободных выделенных файловых дескрипторов.
    # 3. Максимальное количество файловых дескрипторов в системе.
    cat /proc/sys/fs/file-nr
    ```

-   **`fuser`:** Показывает, какие процессы используют указанный файл или файловую систему.

    ```bash
    # Найти процесс, использующий файл
    fuser -v /path/to/your/file
    ```
