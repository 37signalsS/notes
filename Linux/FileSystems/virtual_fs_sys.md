# Виртуальная файловая система /sys

## Определения

### sysfs (Виртуальная файловая система /sys)

`sysfs` — это виртуальная файловая система в Linux, которая монтируется в каталог `/sys`. Она предоставляет структурированный доступ к информации об устройствах и драйверах с точки зрения ядра и отображает иерархию объектов ядра.

В отличие от `/proc`, который исторически был "свалкой" разнородной информации, `/sys` имеет более строгую и логичную структуру "один объект — один каталог".

## Основные концепции

### Структура и назначение

Основная задача `sysfs` — экспорт информации о топологии системы и состоянии устройств и драйверов. Каждый объект в ядре (например, блочное устройство, сетевая карта, USB-устройство) представлен в виде отдельного каталога. Атрибуты этого объекта представлены в виде файлов внутри этого каталога.

* Файлы в `/sys` обычно содержат одно значение.
* Чтение файла позволяет узнать значение атрибута.
* Запись в файл (если это разрешено) позволяет изменить атрибут.

### Ключевые каталоги sysfs

* `/sys/block`: Содержит по каталогу для каждого блочного устройства в системе (например, `sda`, `nvme0n1`).
* `/sys/class`: Группирует устройства по их "классам". Например, в `/sys/class/net` будут все сетевые интерфейсы, а в `/sys/class/power_supply` — информация о батареях и источниках питания.
* `/sys/bus`: Представляет устройства с точки зрения шин, к которым они подключены (например, `pci`, `usb`, `scsi`).
* `/sys/devices`: Содержит основное дерево всех устройств в системе, отражающее их физическую иерархию. Каталоги в `block`, `class` и `bus` являются символическими ссылками на каталоги в `devices`.
* `/sys/module`: Содержит информацию о загруженных в ядро модулях, позволяя просматривать их параметры и, в некоторых случаях, изменять их на лету.

## Практические сценарии

### 1. Определение типа диска (SSD или HDD)

Можно определить, является ли диск твердотельным (SSD) или вращающимся (HDD), проверив значение в файле `rotational`.

```bash
# Для диска sda
cat /sys/block/sda/queue/rotational
```

* **`0`**: Диск не вращается (SSD, NVMe).
* **`1`**: Диск вращается (HDD).

### 2. Пересканирование SCSI/SATA устройства

`sysfs` позволяет запустить пересканирование SCSI/SATA устройств без перезагрузки, что полезно после изменения размера диска на уровне гипервизора или СХД.

```bash
# Заставить устройство sdb пересканировать свой размер
echo 1 > /sys/block/sdb/device/rescan

# Или пересканировать всю шину SCSI для хоста host0
echo "- - -" > /sys/class/scsi_host/host0/scan
```

### 3. Определение, работает ли система в виртуальной машине

Файлы в `/sys/class/dmi/id/` содержат информацию из DMI/SMBIOS, что позволяет идентифицировать "железо", даже если утилиты вроде `dmidecode` отсутствуют.

```bash
cat /sys/class/dmi/id/product_name
# Пример вывода: "KVM", "VirtualBox", "VMware Virtual Platform"

cat /sys/class/dmi/id/sys_vendor
# Пример вывода: "QEMU", "innotek GmbH", "VMware, Inc."
```

### 4. Просмотр и изменение параметров модулей ядра

В каталоге `/sys/module` можно найти параметры для каждого загруженного модуля.

```bash
# Посмотреть доступные параметры для модуля zfs
ls /sys/module/zfs/parameters/

# Прочитать значение конкретного параметра
cat /sys/module/zfs/parameters/zfs_arc_max
```

Это позволяет получить актуальные значения параметров модуля, что не всегда возможно с помощью `modinfo`.
