# Виртуальная файловая система /sys (sysfs)

## Определения

- **sysfs:** Виртуальная файловая система в ядре Linux, монтируемая в каталог `/sys`. Она экспортирует информацию о системных объектах (устройствах, драйверах, шинах) и их взаимосвязях в пространство пользователя.
- **Объект ядра (Kobject):** Базовая структура в ядре, представляющая собой элемент иерархии (каталог в `/sys`).
- **Атрибут:** Файл внутри каталога объекта ядра, представляющий конкретный параметр или состояние объекта (например, `size` или `status`).

## Основные концепции

### Назначение и структура

Основная задача `sysfs` — отображение физической топологии системы и управление атрибутами оборудования. В отличие от `/proc`, который ориентирован на процессы и общую статистику, `/sys` имеет строгую структуру: один файл — одно значение.

#### Ключевые каталоги

- **`/sys/devices`:** Главное дерево всех объектов устройств. Отражает реальную физическую иерархию (как устройства подключены друг к другу). Остальные каталоги обычно содержат символические ссылки на объекты в этом дереве.
- **`/sys/bus`:** Устройства, сгруппированные по типу шины (**PCI**, **USB**, **SCSI**). Содержит два подкаталога: `devices` (ссылки на устройства) и `drivers` (загруженные драйверы этой шины).
- **`/sys/class`:** Устройства, сгруппированные по функциональному классу (например, `net` для сетевых карт, `block` для дисков, `power_supply` для батарей).
- **`/sys/block`:** Устаревший, но всё ещё поддерживаемый каталог со ссылками на все блочные устройства.
- **`/sys/module`:** Информация обо всех загруженных модулях ядра и их текущих параметрах.
- **`/sys/fs`:** Параметры и информация о смонтированных файловых системах.

### Взаимодействие с атрибутами

- **Чтение:** Команда `cat` позволяет получить текущее состояние оборудования (например, скорость вентилятора или температуру).
- **Запись:** Команда `echo` (от имени `root`) позволяет изменять параметры "на лету" без перезагрузки системы.

## Практические сценарии

### Идентификация аппаратных характеристик

Определение типа накопителя (**SSD** или **HDD**):

```bash
# Значение 0 — диск не вращается (SSD/NVMe), 1 — вращается (HDD)
cat /sys/block/sda/queue/rotational
```

Проверка режима работы процессора (**CPU Governor**):

```bash
# Просмотр режима для всех ядер
cat /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor
```

### Управление оборудованием

Принудительное пересканирование шины **SCSI (Small Computer System Interface)** после расширения диска в гипервизоре:

```bash
# Обновление размера конкретного диска
echo 1 | sudo tee /sys/class/block/sdb/device/rescan
```

Управление индикацией (**LED**) на корпусе или клавиатуре:

```bash
# Включить индикатор (если поддерживается драйвером)
echo 1 | sudo tee /sys/class/leds/input3::capslock/brightness
```

### Диагностика виртуализации

Определение производителя и продукта через **DMI (Desktop Management Interface)**:

```bash
# Выявит "QEMU", "VirtualBox" или "VMware"
cat /sys/class/dmi/id/sys_vendor
cat /sys/class/dmi/id/product_name
```

### Просмотр параметров модулей

Проверка текущего значения параметра модуля ядра:

```bash
# Например, для модуля kvm
ls /sys/module/kvm/parameters/
cat /sys/module/kvm/parameters/ignore_msrs
```
