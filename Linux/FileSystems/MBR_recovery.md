# Восстановление Master Boot Record (MBR)

## Определения

-   **MBR (Master Boot Record):** Главная загрузочная запись. Первые 512 байт диска, содержащие загрузчик (446 байт) и таблицу разделов (4x16 байт).

## Основные концепции

-   **Критичность:** Повреждение MBR делает невозможным загрузку ОС и доступ к разделам. Однако данные в самих разделах остаются нетронутыми.
-   **Ограничения:** MBR имеет ограничения по размеру диска и количеству разделов. Детальное сравнение с GPT и ограничения MBR приведены в статье о [разделах и файловых системах](./partitions_and_filesystems.md).
-   **Восстановление:** Для восстановления критически важно знать точные начальные секторы каждого раздела.

## Практические сценарии

### 1. Резервное копирование и восстановление MBR

Резервная копия первых 512 байт диска (MBR) позволяет быстро восстановить таблицу разделов.

**Создание резервной копии:**
```bash
dd if=/dev/sda of=mbr_backup.img bs=512 count=1
```

**Восстановление из резервной копии:**
> **Внимание:** Эта команда полностью перезапишет текущую MBR на диске `/dev/sda`.
```bash
dd if=mbr_backup.img of=/dev/sda bs=512 count=1
```

### 2. Ручное восстановление удаленных разделов с помощью `fdisk`

Если резервной копии нет, но разделы были простыми (только основные), можно пересоздать таблицу разделов с помощью `fdisk`.

**Сценарий:** Разделы были случайно удалены из таблицы MBR.

1.  Запустите `fdisk` для нужного диска:
    ```bash
    fdisk /dev/sda
    ```
2.  Создайте новый раздел (`n`), указывая тот же тип, номер и, самое главное, **тот же начальный сектор**, который был у раздела.
3.  Повторите процедуру для всех восстанавливаемых разделов.
4.  Сохраните изменения (`w`).
5.  Проинформируйте ядро об изменениях в таблице разделов:
    ```bash
    partprobe /dev/sda
    ```
    Или перезагрузите систему.

После этих действий файловые системы на восстановленных разделах должны стать доступными.

## Дополнительная информация

-   Восстановление расширенных и логических разделов сложнее, так как их структура хранится за пределами основной MBR.
-   Если точное положение разделов неизвестно, можно использовать утилиты для сканирования диска, например `testdisk` (см. также [Логическое восстановление данных](../data_recovery.md)).
-   Все операции по изменению таблицы разделов являются потенциально деструктивными. Всегда выполняйте резервное копирование важных данных перед началом работ.
