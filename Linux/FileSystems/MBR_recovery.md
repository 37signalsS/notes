# Восстановление Master Boot Record (MBR)

## Определения

-   **MBR (Master Boot Record):** Главная загрузочная запись. Первые 512 байт на диске с таблицей разделов MBR. Содержит загрузчик (446 байт) и таблицу разделов (4x16 байт).

## Основные концепции

-   **Критичность:** Повреждение MBR делает невозможным загрузку ОС и доступ к разделам стандартными средствами. Однако данные в самих разделах остаются нетронутыми.
-   **Ограничения:** MBR поддерживает до 4-х основных разделов (или 3 основных и 1 расширенный) и диски объемом до 2 ТБ (при размере сектора 512 байт).
-   **Восстановление:** Ключевым фактором для восстановления является точное знание начального сектора каждого раздела.

## Практические сценарии

### 1. Резервное копирование и восстановление MBR

Резервная копия MBR (первые 512 байт диска) позволяет быстро восстановить таблицу разделов.

**Создание резервной копии:**
```bash
dd if=/dev/sda of=mbr_backup.img bs=512 count=1
```

**Восстановление из резервной копии:**
> **Внимание:** Эта команда перезапишет текущую MBR на диске `/dev/sda`.
```bash
dd if=mbr_backup.img of=/dev/sda bs=512 count=1
```

### 2. Ручное восстановление удаленных разделов

Если резервной копии нет, но структура разделов была простой (только основные разделы), можно пересоздать таблицу разделов с помощью `fdisk`.

**Сценарий:** Разделы были случайно удалены из таблицы MBR.

1.  **Запустите `fdisk` для нужного диска:**
    ```bash
    fdisk /dev/sda
    ```

2.  **Создайте новый раздел (`n`).** Укажите тот же тип (primary), номер и, самое главное, **тот же начальный сектор**, который был у раздела. Размер может быть таким же или больше.

3.  **Повторите** для всех удаленных разделов, которые необходимо восстановить.

4.  **Сохраните изменения (`w`).**

5.  **Проинформируйте ядро** об изменениях в таблице разделов:
    ```bash
    partprobe /dev/sda
    ```
    Или перезагрузите систему.

После этого файловые системы на восстановленных разделах должны быть доступны для монтирования, так как сами данные не были затронуты.

## Дополнительная информация

-   Восстановление расширенных (extended) и логических (logical) разделов сложнее, так как их структура хранится не только в MBR.
-   Если точное положение разделов неизвестно, их можно попытаться найти утилитами вроде `testdisk`.
