# Definitions

**Команды монтирования** — это утилиты командной строки, предназначенные для управления подключением (монтированием) и отключением (размонтированием) файловых систем в иерархию каталогов Linux.

# Basic Concepts

## mount: Подключение файловых систем

Команда `mount` присоединяет файловую систему, находящуюся на устройстве (например, разделе диска), к указанному каталогу (точке монтирования).

* **Синтаксис**: `mount [опции] <устройство> <точка_монтирования>`
* **Идентификация устройства**: Рекомендуется использовать `UUID` или `PARTUUID` для монтирования, так как они уникальны и не меняются при перезагрузке, в отличие от имени устройства (`/dev/sdX`).
* **Типы файловых систем**: Команда автоматически определяет тип ФС, но можно указать явно через `-t <тип>`.

## umount: Отключение файловых систем

Команда `umount` отключает файловую систему от точки монтирования.

* **Синтаксис**: `umount [опции] <точка_монтирования | устройство>`
* **Принудительное размонтирование**: В случаях, когда ресурс занят другим процессом, можно использовать специальные флаги:
  * `-l` (`--lazy`): "Ленивое" размонтирование. Файловая система отключается от иерархии, как только перестает быть занятой.
  * `-f` (`--force`): Принудительное размонтирование. Используется с осторожностью, в основном для недоступных сетевых файловых систем (NFS).
  * `-R` (`--recursive`): Рекурсивное размонтирование всех точек монтирования внутри указанной.

## mount -a: Монтирование по fstab

Команда `mount -a` (`--all`) монтирует все файловые системы, перечисленные в файле `/etc/fstab`, которые не имеют опции `noauto` и еще не смонтированы.

## findmnt: Современная альтернатива

Утилита `findmnt` предоставляет более удобный вывод и дополнительные возможности по сравнению с `mount`:

* **Древовидный вывод**: `findmnt --tree`
* **Проверка точки монтирования**: `findmnt /mnt/data`
* **Верификация fstab**: `findmnt --verify --verbose`

# Practical Scenarios

```bash
# Посмотреть все смонтированные файловые системы
mount
df -hT

# Современный способ с findmnt
findmnt --tree
findmnt -l  # с исходными устройствами

# Монтирование раздела по UUID (предпочтительный способ)
sudo mount UUID="a1b2c3d4-e5f6-7890" /mnt/data

# Монтирование по имени устройства (менее надежно)
sudo mount /dev/sdb1 /mnt/data

# Монтирование с указанием типа ФС
sudo mount -t ext4 /dev/sdb1 /mnt/data

# Монтирование только для чтения
sudo mount -o ro /dev/sdb1 /mnt/data

# Перемонтирование с изменением опций (без размонтирования)
# Подробное описание — [remount.md](./remount.md)
sudo mount -o remount,rw /mnt/data

# Размонтирование
sudo umount /mnt/data

# "Ленивое" размонтирование, если ресурс занят
sudo umount -l /mnt/data

# Рекурсивное размонтирование (все вложенные точки)
sudo umount -R /mnt/data

# Применить все изменения из /etc/fstab без перезагрузки
sudo mount -a

# Проверка fstab перед перезагрузкой
findmnt --verify --verbose
```

# Additional Information

* Для автоматизации монтирования при загрузке системы используется файл [`/etc/fstab`](./fstab.md). Команда `mount -a` напрямую зависит от его содержимого.
* Общий обзор всех способов монтирования представлен в [главном файле раздела](./index.md).
