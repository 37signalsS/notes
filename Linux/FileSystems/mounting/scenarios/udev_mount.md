# Определения

**Udev** — подсистема Linux для динамического управления устройствами в `/dev`. Правила `udev` позволяют выполнять команды при событиях устройств (add, remove, change).

# Основные концепции

Для монтирования используются:
* `ACTION=="add"` — событие подключения устройства
* `ACTION=="remove"` — событие отключения устройства
* `RUN+="/bin/mount ..."` — команда монтирования

> **Предупреждение:** `udev` — мощный, но сложный инструмент. Для простых случаев монтирования разделов предпочтительнее использовать [**`/etc/fstab`**](../fstab.md) или [**Systemd mount units**](./systemd_mount.md). Используйте udev только для специфичных сценариев (автоматическое монтирование съёмных носителей по серийному номеру).

# Практический сценарий

### 1. Создание точки монтирования

```bash
sudo mkdir -p /mnt/my-usb
```

### 2. Поиск уникальных атрибутов диска

1. Подключите USB-диск.
2. Найдите его имя (например, `/dev/sdb1`) с помощью `lsblk`.
3. Используйте `udevadm`, чтобы найти уникальный атрибут, например, серийный номер.

    ```bash
    udevadm info -a -n /dev/sdb1 | grep 'serial'
    # Пример вывода:
    #     ATTRS{serial}=="ABC12345"
    ```

Подробнее о поиске атрибутов: [Udev: подсистема динамического управления устройствами](../../../Core/udev.md#практические-сценарии).

### 3. Создание файла правил

Создайте файл `/etc/udev/rules.d/99-usb-mount.rules`. Имя файла важно: правила обрабатываются в алфавитном порядке, поэтому префикс `99-` гарантирует, что правило будет применено одним из последних.

```ini
# /etc/udev/rules.d/99-usb-mount.rules

# Правило для монтирования
ACTION=="add", SUBSYSTEM=="block", ATTRS{serial}=="ABC12345", RUN+="/bin/mount /dev/%k /mnt/my-usb"

# Правило для размонтирования
ACTION=="remove", SUBSYSTEM=="block", ATTRS{serial}=="ABC12345", RUN+="/bin/umount /mnt/my-usb"
```

* `%k` — это плейсхолдер, который `udev` заменит на имя устройства (например, `sdb1`).

### 4. Перезагрузка правил

Примените новые правила без перезагрузки системы.

```bash
sudo udevadm control --reload-rules && sudo udevadm trigger
```

Теперь при подключении USB-диска с указанным серийным номером он будет автоматически смонтирован в `/mnt/my-usb`, а при отключении — размонтирован.

### 5. Отладка правил

```bash
# Мониторинг событий udev в реальном времени
udevadm monitor --udev --property

# Тестирование правила на устройстве
udevadm test /sys/class/block/sdb1

# Проверка применённых правил
udevadm info -a -n /dev/sdb1
```

Подробнее: [Udev: подсистема динамического управления устройствами](../../../Core/udev.md#управление-правилами).
