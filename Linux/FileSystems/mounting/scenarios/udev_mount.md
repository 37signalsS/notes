# Определения

**Udev** — это подсистема Linux, отвечающая за управление устройствами в каталоге `/dev`. Она динамически создает и удаляет файлы устройств при их подключении или отключении от системы.

**Правила Udev** — это файлы конфигурации, которые позволяют выполнять заданные действия (например, запуск скрипта или команды) в ответ на события устройств. Монтирование на основе правил `udev` — это низкоуровневый способ автоматизации, часто используемый для специфических устройств (например, USB-дисков с определенным серийным номером).

# Основные концепции

## Структура правила

Правила хранятся в файлах с расширением `.rules` в каталоге `/etc/udev/rules.d/`. Каждое правило состоит из двух частей:

1. **Условия сопоставления (Match Keys)**: Набор пар `ключ=="значение"`, которые должны совпасть с атрибутами устройства. Основные ключи:
    * `ACTION`: Тип события (например, `add`, `remove`).
    * `SUBSYSTEM`: Подсистема, к которой относится устройство (например, `block` для дисков).
    * `KERNEL`: Имя устройства в ядре (например, `sd*`, `sda1`).
    * `ATTRS{ключ}`: Системный атрибут устройства из sysfs (например, `ATTRS{serial}` для серийного номера).

2. **Действия (Action Keys)**: Команды, которые выполняются, если условия совпали.
    * `RUN+="/путь/к/команде"`: Запускает программу.
    * `TAG+="..."`: Добавляет тег к устройству (например, `systemd`).

## Использование в монтировании

Правило `udev` может отслеживать событие `add` для блочного устройства и запускать команду `mount`. Для размонтирования можно создать отдельное правило для события `remove`.

# Практический сценарий: Автомонтирование USB-диска по серийному номеру

### 1. Создание точки монтирования

```bash
sudo mkdir -p /mnt/my-usb
```

### 2. Поиск уникальных атрибутов диска

1. Подключите USB-диск.
2. Найдите его имя (например, `/dev/sdb1`) с помощью `lsblk`.
3. Используйте `udevadm`, чтобы найти уникальный атрибут, например, серийный номер.

    ```bash
    udevadm info -a -n /dev/sdb1 | grep 'serial'
    # Пример вывода:
    #     ATTRS{serial}=="ABC12345"
    ```

### 3. Создание файла правил

Создайте файл `/etc/udev/rules.d/99-usb-mount.rules`. Имя файла важно: правила обрабатываются в алфавитном порядке, поэтому префикс `99-` гарантирует, что правило будет применено одним из последних.

```ini
# /etc/udev/rules.d/99-usb-mount.rules

# Правило для монтирования
ACTION=="add", SUBSYSTEM=="block", ATTRS{serial}=="ABC12345", RUN+="/bin/mount /dev/%k /mnt/my-usb"

# Правило для размонтирования
ACTION=="remove", SUBSYSTEM=="block", ATTRS{serial}=="ABC12345", RUN+="/bin/umount /mnt/my-usb"
```

* `%k` — это плейсхолдер, который `udev` заменит на имя устройства (например, `sdb1`).

### 4. Перезагрузка правил

Примените новые правила без перезагрузки системы.

```bash
sudo udevadm control --reload-rules && sudo udevadm trigger
```

Теперь при подключении USB-диска с указанным серийным номером он будет автоматически смонтирован в `/mnt/my-usb`, а при отключении — размонтирован.
