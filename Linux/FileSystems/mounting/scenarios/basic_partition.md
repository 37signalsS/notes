# Определения

**Сценарий базовой разметки (Basic partition scenario)** — полный цикл добавления нового физического или виртуального диска в систему: от инициализации таблицы разделов до настройки автоматического монтирования при загрузке через файл конфигурации `/etc/fstab` (file systems table).

# Основные концепции

Процесс подготовки нового накопителя состоит из нескольких ключевых этапов:

1. **Разметка диска (Partitioning)**: Создание на диске одного или нескольких разделов. Используются стандарты MBR (Master Boot Record) или GPT (GUID Partition Table).
2. **Форматирование (Formatting)**: Создание на разделе файловой системы (ФС), которая будет управлять хранением данных.
3. **Монтирование (Mounting)**: Подключение отформатированного раздела к каталогу в основной иерархии ФС.
4. **Автоматизация**: Добавление записи в `/etc/fstab` для постоянного монтирования раздела при загрузке ОС (Операционной Системы).

Подробная теория и описание инструментов доступны в материале: **[Разделы и файловые системы в Linux](../partitions_and_filesystems.md)**.

## Выбор инструмента разметки

| Инструмент | Тип диска | Рекомендация |
| :--- | :--- | :--- |
| `fdisk` | MBR/GPT | Универсальный инструмент с текстовым интерфейсом |
| `parted` | GPT | Рекомендуется для дисков более 2 ТБ (Терабайт), удобен для скриптов |
| `gdisk` | GPT | Специализированная утилита для GPT |

## Выбор файловой системы

| ФС | Назначение | Особенности |
| :--- | :--- | :--- |
| `ext4` (Fourth Extended Filesystem) | Универсальная | Зрелая, надёжная, стандарт для большинства дистрибутивов |
| `XFS` (Extents File System) | Большие файлы и разделы | Высокая производительность, масштабируемость |
| `Btrfs` (B-tree File System) | Снимки, RAID (Redundant Array of Independent Disks) | Поддержка снапшотов и встроенного управления томами |

# Практические сценарии

## Сценарий: Добавление нового диска

### 1. Определение имени диска

Найдите имя нового накопителя с помощью `lsblk`. Новый диск обычно отображается без разделов и точек монтирования (например, `/dev/sdc`).

```bash
lsblk
```

### 2. Создание раздела на диске

**Вариант A: Использование `fdisk` (универсальный способ)**

Замените `/dev/sdX` на фактическое имя вашего диска.

```bash
sudo fdisk /dev/sdX
```

Команды внутри `fdisk`:

* `n` — создать новый раздел.
* `p` — выбрать основной раздел (primary).
* `1` — номер раздела.
* Примите значения по умолчанию для секторов, чтобы использовать весь объем.
* `w` — записать изменения и выйти.

**Вариант B: Использование `parted` (для GPT и больших дисков)**

```bash
sudo parted /dev/sdX mklabel gpt
sudo parted /dev/sdX mkpart primary ext4 0% 100%
```

### 3. Форматирование раздела

После разметки появится новое устройство раздела, например `/dev/sdX1`.

**Для ext4:**

```bash
sudo mkfs.ext4 /dev/sdX1
```

**Для XFS:**

```bash
sudo mkfs.xfs /dev/sdX1
```

Подробнее о параметрах форматирования: [Создание файловой системы (mkfs)](../partitions_and_filesystems.md#создание-файловой-системы-mkfs).

### 4. Создание точки монтирования

```bash
sudo mkdir /data
```

### 5. Настройка автоматического монтирования

1. **Узнайте UUID** (Universally Unique Identifier) нового раздела. Это исключает ошибки при изменении порядка подключения дисков.

    ```bash
    sudo blkid /dev/sdX1
    ```

2. **Добавьте запись в `/etc/fstab`**. Замените `UUID_ЗНАЧЕНИЕ` на результат выполнения предыдущей команды.

    ```bash
    # Для ext4
    echo 'UUID=UUID_ЗНАЧЕНИЕ /data ext4 defaults,noatime,nofail 0 2' | sudo tee -a /etc/fstab
    
    # Для XFS (fsck не требуется, поле pass = 0)
    echo 'UUID=UUID_ЗНАЧЕНИЕ /data xfs defaults,noatime,nofail 0 0' | sudo tee -a /etc/fstab
    ```

3. **Смонтируйте и проверьте корректность:**

    ```bash
    sudo mount -a
    findmnt --verify --verbose
    df -hT /data
    ```
