# Определения

Этот документ описывает полный сценарий добавления нового физического или виртуального диска в систему: от разметки до автоматического монтирования при загрузке через `/etc/fstab`.

# Основные концепции

Процесс состоит из нескольких ключевых этапов:

1. **Разметка диска (Partitioning)**: Создание на диске одного или нескольких разделов, которые операционная система сможет использовать.
2. **Форматирование (Formatting)**: Создание на разделе файловой системы (например, `ext4`, `xfs`), которая будет управлять хранением файлов.
3. **Монтирование (Mounting)**: Подключение отформатированного раздела к каталогу в основной файловой системе, чтобы сделать его доступным.
4. **Автоматизация**: Добавление записи в `/etc/fstab` для постоянного монтирования раздела при каждой загрузке системы.

# Практический сценарий: Добавление нового диска

### 1. Определение имени диска

Сначала найдите имя нового диска с помощью `lsblk`. Новый диск, скорее всего, не будет иметь разделов и точек монтирования (например, `sdc`).

```bash
lsblk
```

### 2. Создание раздела на диске

Используйте `fdisk` для создания нового раздела. Замените `/dev/sdX` на имя вашего диска.

```bash
sudo fdisk /dev/sdX
```

Внутри `fdisk` используйте следующие команды:

* `n` — создать новый раздел.
* `p` — выбрать основной раздел (primary).
* `1` — номер раздела.
* Примите значения по умолчанию для первого и последнего секторов, чтобы использовать весь диск.
* `w` — записать изменения и выйти.

После этого появится новый раздел, например `/dev/sdX1`.

### 3. Форматирование раздела

Создайте на новом разделе файловую систему `ext4`.

```bash
sudo mkfs.ext4 /dev/sdX1
```

### 4. Создание точки монтирования

Создайте каталог, к которому будет примонтирован новый раздел.

```bash
sudo mkdir /data
```

### 5. Настройка автоматического монтирования

1. **Узнайте UUID** нового раздела. Это самый надежный способ идентификации.

    ```bash
    sudo blkid /dev/sdX1
    ```

2. **Добавьте запись в `/etc/fstab`**. Откройте файл в текстовом редакторе или используйте `echo`. Замените `UUID_ВАШЕГО_РАЗДЕЛА` на реальный UUID.

    ```bash
    echo 'UUID=UUID_ВАШЕГО_РАЗДЕЛА /data ext4 defaults,nofail 0 2' | sudo tee -a /etc/fstab
    ```

3. **Смонтируйте все разделы из `fstab`**.

    ```bash
    sudo mount -a
    ```

4. **Проверьте результат**. Убедитесь, что раздел примонтирован.

    ```bash
    df -hT /data
    ```
