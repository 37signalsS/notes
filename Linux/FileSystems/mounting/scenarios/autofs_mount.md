# Определения

**Autofs** — это сервис в Linux, который обеспечивает монтирование файловых систем по требованию. Он автоматически монтирует ресурс (например, сетевую папку или локальный раздел) при первом обращении к нему и отмонтирует после заданного периода бездействия.

# Основные концепции

Работа `autofs` управляется двумя типами файлов:

1. **Главный файл конфигурации (`/etc/auto.master`)**: В этом файле определяются "корневые" точки монтирования и указываются файлы карт, которые описывают, что именно монтировать.
2. **Файлы карт (например, `/etc/auto.direct`)**: В файлах карт перечисляются конкретные точки монтирования, их опции и источники (устройства или сетевые ресурсы).

# Практический сценарий: Настройка Autofs

Ниже приведен пошаговый сценарий настройки `autofs` для автоматического монтирования локального раздела.

### 1. Установка

```bash
sudo apt update
sudo apt install autofs
```

### 2. Конфигурация `/etc/auto.master`

Добавьте в конец файла `/etc/auto.master` строку, связывающую файловую карту с точкой монтирования. Использование `/-` позволяет задавать абсолютные пути в файле карты.

```text
# /etc/auto.master
#
# <точка монтирования> <файл карты>     <опции>
/-                      /etc/auto.direct --timeout=60
```

*`--timeout=60`* означает, что ресурс будет отмонтирован после 60 секунд бездействия.

### 3. Создание файла карты `/etc/auto.direct`

Создайте файл карты и добавьте в него описание ресурса для монтирования.

```text
# /etc/auto.direct
#
# <полный_путь>  <опции_монтирования>  <источник>
/mnt/data         -fstype=ext4,rw       :/dev/disk/by-uuid/a1b2c3d4-e5f6-7890
```

**Важно:** Обратите внимание на синтаксис:

* Опции монтирования (`-fstype=...`) начинаются с дефиса.
* Источник (`:/dev/...`) начинается с двоеточия.

### 4. Перезапуск сервиса

Чтобы применить изменения, перезапустите сервис `autofs` и добавьте его в автозагрузку.

```bash
sudo systemctl enable --now autofs
# или для применения изменений без остановки сервиса
sudo systemctl restart autofs
```

Теперь при первой попытке доступа к `/mnt/data` сервис `autofs` автоматически смонтирует указанный раздел.

### 5. Практический сценарий: Автоматическое монтирование домашних директорий по NFS

Данный сценарий востребован в корпоративных средах, где пользователи работают на разных компьютерах и их домашние директории должны быть доступны на любом рабочем месте. Вместо статического прописывания всех пользователей в fstab используется AutoFS с подстановочными символами.

#### Настройка AutoFS для NFS

**1. Установка (если не установлен):**

```bash
# RHEL/CentOS
sudo yum install -y autofs

# Debian/Ubuntu
sudo apt install -y autofs
```

**2. Настройка `/etc/auto.master`:**

Добавьте строку, указывающую на файл карты для домашних директорий:

```text
# /etc/auto.master
/home /etc/auto.home --timeout=300
```

*Опция `--timeout=300` означает, что директория будет отмонтирована после 5 минут (300 секунд) бездействия.*

**3. Настройка `/etc/auto.home`:**

Здесь используются подстановочные символы:
- `*` — любой username
- `&` — подставляет имя директории (совпадает с именем пользователя)

```text
# /etc/auto.home
* -rw,sync,soft,intr server.example.com:/home/&
```

**4. Применение конфигурации:**

```bash
sudo systemctl restart autofs
```

**5. Проверка:**

При обращении к `/home/username` AutoFS автоматически смонтирует `server.example.com:/home/username`.

#### Интеграция с FreeIPA/LDAP

В реальных инфраструктурах пользователи хранятся не локально, а на сервере идентификации (FreeIPA, LDAP). AutoFS дополняет эту схему:

1. **FreeIPA** (или LDAP + Kerberos) обеспечивает аутентификацию и авторизацию пользователей.
2. **NFS** хранит домашние директории на центральном сервере.
3. **AutoFS** монтирует домашнюю директорию пользователя при первом обращении (логин или доступ к `/home/<username>`).

Настройка клиента FreeIPA:

```bash
# Установка клиента
sudo yum install -y freeipa-client

# Настройка (интерактивно или с параметрами)
sudo ipa-client-install --enable-dns-updates
```

После настройки FreeIPA клиент получает список пользователей с сервера, а AutoFS обеспечивает монтирование их домашних директорий.
