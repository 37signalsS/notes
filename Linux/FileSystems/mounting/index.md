# Определения

**Монтирование (Mounting)** — это процесс, при котором операционная система делает файловую систему, находящуюся на устройстве (например, разделе диска или сетевом ресурсе), доступной в определённой точке общего дерева каталогов. Эта точка называется **точкой монтирования (mount point)**.

Этот файл является главным источником информации (SSoT) по теме монтирования и содержит ссылки на все связанные документы.

# Основные концепции

Существует несколько подходов к монтированию файловых систем в Linux, от ручного до полностью автоматизированного.

1. **Ручное монтирование**: С помощью утилиты `mount`, описанной в файле [**`commands.md`**](./commands.md). Этот способ используется для временного подключения устройств.

2. **Статическое монтирование при загрузке (`/etc/fstab`)**: Традиционный и самый распространенный способ автоматического монтирования. Все параметры жестко задаются в файле [**`/etc/fstab`**](./fstab.md).

3. **Монтирование по требованию (`autofs`)**: Сервис `autofs` монтирует файловую систему только при первом обращении к ней и отключает после периода бездействия. Идеально для сетевых ресурсов.

4. **Монтирование через `systemd`**: Современный подход, использующий `.mount` и `.automount` юниты. Предоставляет больше гибкости и возможностей для управления зависимостями (например, монтировать сетевой диск только после поднятия сети).

5. **Монтирование на основе событий (`udev`)**: `udev` позволяет выполнять монтирование при физическом подключении устройства (например, USB-флешки).
