# Определения

**Монтирование (Mounting)** — процесс подключения файловой системы (с раздела диска, сетевого ресурса или иного устройства) к определённой точке дерева каталогов Linux, называемой **точкой монтирования (mount point)**. После монтирования содержимое файловой системы становится доступным по указанному пути.

# Основные концепции

## Методы монтирования

В Linux существует несколько подходов к монтированию файловых систем — от ручного до полностью автоматизированного.

| Метод | Сценарий использования | Сложность | Рекомендация |
| :--- | :--- | :--- | :--- |
| **Ручное (`mount`)** | Временное подключение | Низкая | Для тестирования |
| **`/etc/fstab`** | Постоянное монтирование при загрузке | Низкая | Для локальных ФС |
| **Systemd mount** | Сложные зависимости, сетевые ресурсы | Средняя | Альтернатива fstab для NFS/CIFS |
| **Systemd automount** | Ленивое монтирование по требованию | Средняя | Альтернатива autofs |
| **Autofs** | NFS, LDAP, NIS, корпоративные среды | Высокая | Для динамического монтирования |
| **Udev** | Съёмные носители по событию подключения | Высокая | Специфичные случаи |

## Описание методов

1. **Ручное монтирование** — утилита `mount` (подробнее в [commands.md](./commands.md)). Используется для временного подключения устройств без перезагрузки.

2. **Статическое монтирование (`/etc/fstab`)** — традиционный способ автоматического монтирования при загрузке. Параметры задаются в файле [fstab.md](./fstab.md).

3. **Монтирование по требованию (`autofs`)** — сервис монтирует ФС при первом обращении к точке монтирования и отключает после периода бездействия. Подходит для сетевых ресурсов (NFS, CIFS). Описание — в [scenarios/autofs_mount.md](./scenarios/autofs_mount.md).

4. **Монтирование через `systemd`** — современный подход с использованием `.mount` и `.automount` юнитов. Обеспечивает гибкое управление зависимостями (например, монтировать сетевой диск после поднятия сети). Описание — в [scenarios/systemd_mount.md](./scenarios/systemd_mount.md).

5. **Монтирование на основе событий (`udev`)** — автоматическое подключение при физическом подключении устройства (например, USB-флешки). Описание — в [scenarios/udev_mount.md](./scenarios/udev_mount.md).

## Выбор метода

| Сценарий | Рекомендуемый метод |
| :--- | :--- |
| Локальный диск для постоянного использования | `/etc/fstab` |
| Сетевой ресурс (NFS/CIFS) | `systemd mount` или `autofs` |
| Ленивое монтирование (по требованию) | `systemd automount` или `autofs` |
| Съёмный носитель по серийному номеру | `udev` |
| Корпоративная среда (LDAP, NIS) | `autofs` |

## Изменение параметров смонтированных ФС

Операция **перемонтирования (remount)** позволяет изменить опции уже смонтированной файловой системы без её размонтирования. Подробное описание — в [remount.md](./remount.md).

```bash
# Пример: перемонтировать в rw без размонтирования
sudo mount -o remount,rw /mnt/data
```
