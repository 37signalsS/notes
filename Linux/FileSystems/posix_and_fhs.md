# Стандарт POSIX и его роль в Linux

**POSIX (Portable Operating System Interface)** — это набор стандартов, разработанный IEEE, который определяет, как операционные системы должны выглядеть и вести себя с точки зрения программиста. Его главная цель — обеспечить **совместимость исходного кода** между различными Unix-подобными операционными системами.

**Ключевые аспекты, которые определяет POSIX:**

1.  **Интерфейс командной строки (Shell):** Стандартизирует команды (`ls`, `cp`, `grep`), синтаксис и переменные окружения.
2.  **Системные вызовы (API):** Определяет стандартный набор функций на языке C для взаимодействия с ядром (например, `open()`, `read()`, `write()`, `fork()`).
3.  **Файловая система:** Описывает базовую структуру каталогов, права доступа к файлам (rwx) и концепцию "всё есть файл".
4.  **Процессы и потоки:** Стандартизирует управление процессами, сигналами и потоками (pthreads).

**Почему это важно для Linux?**

Хотя Linux не является сертифицированной POSIX-системой "из коробки" (сертификация стоит дорого), он **в значительной степени совместим с POSIX**. Это означает, что программы, написанные с соблюдением стандартов POSIX, могут быть легко скомпилированы и запущены на Linux, macOS, BSD и других Unix-системах с минимальными изменениями или без них.

**Linux Standard Base (LSB) и Filesystem Hierarchy Standard (FHS)**

-   **LSB (Linux Standard Base):** Это более специфичный стандарт, который расширяет POSIX и направлен на обеспечение бинарной совместимости между различными дистрибутивами Linux. Он определяет такие вещи, как структура файловой системы, основные библиотеки и команды.
-   **FHS (Filesystem Hierarchy Standard):** Является частью LSB и подробно описывает, в каких каталогах должны располагаться те или иные типы файлов (например, `/bin` для исполняемых файлов, `/etc` для конфигураций). Это обеспечивает предсказуемость и порядок в системе.

## Стандартная иерархия каталогов (FHS)

В отличие от операционных систем, использующих буквенные обозначения для дисков (например, C:, D: в Windows), в Linux существует единый корневой каталог (`/`), от которого строится вся файловая система. Все остальные каталоги и файловые системы монтируются в подкаталоги корневого каталога. Это обеспечивает унифицированный и предсказуемый путь к любому файлу в системе.

-   `/`: **Корневой каталог (Root Directory)**. Это вершина иерархии файловой системы. Все остальные каталоги и файлы находятся внутри него.
-   `/bin`: **Основные исполняемые файлы (Binaries)**. Содержит базовые команды и утилиты, необходимые для работы системы и доступные всем пользователям (например, `ls`, `cp`, `mv`). Эти бинарные файлы часто являются частью операционной системы.
-   `/usr/bin`: **Исполняемые файлы пользователей**. Содержит большинство пользовательских команд и утилит, которые не являются критически важными для загрузки системы. В некоторых дистрибутивах `/bin` может быть символической ссылкой на `/usr/bin`.
-   `/boot`: **Файлы загрузки**. Содержит ядро Linux, файлы `initrd` (initial RAM disk) и файлы загрузчика (например, GRUB). Этот каталог критически важен для старта системы. Если `/boot` вынесен на отдельный раздел, его можно размонтировать после успешной загрузки системы, так как он больше не требуется для её работы.
-   `/dev`: **Файлы устройств (Devices)**. Представляет аппаратные компоненты системы в виде файлов. Это виртуальная файловая система (tmpfs), данные которой хранятся в оперативной памяти и динамически обновляются.
-   `/etc`: **Конфигурационные файлы (Editable Text Configuration)**. Содержит файлы конфигурации для всей системы и установленных приложений. Это один из наиболее часто используемых каталогов для системных администраторов. При установке нового программного обеспечения в `/etc` часто создается подкаталог с его именем для хранения настроек.
-   `/home`: **Домашние каталоги пользователей (Home)**. Содержит домашние каталоги для обычных пользователей системы. Каждый пользователь обычно имеет свой подкаталог (например, `/home/username`), где хранятся его личные файлы и настройки.
-   `/lib`: **Библиотеки (Libraries)**. Содержит основные общие библиотеки, необходимые для работы исполняемых файлов из `/bin` и `/sbin`.
-   `/lib64`: **64-битные библиотеки**. Аналогично `/lib`, но для 64-битных систем, содержит 64-битные версии общих библиотек.
-   `/lost+found`: **Потерянные и найденные файлы**. Каталог, создаваемый файловыми системами (например, ext4) для хранения фрагментов файлов, восстановленных после проверки целостности (`fsck`). Не является "корзиной" для удаленных файлов.
-   `/srv`: **Данные сервисов (Service Data)**. Содержит данные, специфичные для сервисов, предоставляемых системой. Например, данные для веб-сервера или FTP-сервера. Часто используется для ручного создания каталогов для данных приложений.
-   `/snap`: **Пакеты Snap**. Каталог, используемый пакетным менеджером Snap для хранения установленных Snap-пакетов. Если Snap не используется, этот каталог может отсутствовать или быть пустым.
-   `/media`: **Съемные носители (Media)**. Точки монтирования для автоматически подключаемых съемных носителей, таких как CD/DVD-ROM, USB-флешки и внешние жесткие диски.
-   `/mnt`: **Точки монтирования (Mount)**. Предназначен для временного монтирования файловых систем вручную. Обычно используется для одноразового доступа к файловым системам.
-   `/opt`: **Опциональное программное обеспечение (Optional)**. Предназначен для установки стороннего, опционального программного обеспечения, которое не является частью стандартной дистрибуции. Часто используется для программ, скомпилированных из исходных кодов или распакованных вручную. По умолчанию этот каталог обычно пуст.
-   `/proc`: **Информация о процессах (Processes)**. Виртуальная файловая система (tmpfs), предоставляющая доступ к информации о запущенных процессах и ядре. Данные хранятся в оперативной памяти.
-   `/root`: **Домашний каталог пользователя root**. Это домашний каталог суперпользователя (root). Он отделен от `/home` для обеспечения доступности даже в случае проблем с монтированием раздела `/home`, что критически важно для восстановления системы.
-   `/sbin`: **Системные исполняемые файлы (System Binaries)**. Содержит исполняемые файлы, предназначенные для системного администрирования и обслуживания системы (например, `fdisk`, `mkfs`, `ifconfig`). Эти команды обычно доступны только пользователю root или через `sudo`.
-   `/sys`: **Параметры ядра (System)**. Виртуальная файловая система (tmpfs), предоставляющая интерфейс к драйверам ядра и его параметрам. Данные хранятся в оперативной памяти.
-   `/tmp`: **Временные файлы (Temporary)**. Каталог для временного хранения файлов. По умолчанию хранится на диске, но может быть настроен как tmpfs (в оперативной памяти). Рекомендуется выносить на отдельный раздел для предотвращения заполнения корневой файловой системы.
-   `/usr`: **Иерархия пользовательских системных ресурсов (Unix System Resources)**. Содержит большинство пользовательских программ, утилит, библиотек, документации и других данных, которые не являются критически важными для загрузки системы. Включает подкаталоги, такие как `/usr/bin`, `/usr/sbin`, `/usr/lib`, `/usr/local` (для программ, установленных локально администратором, например, `/usr/local/etc` для их конфигураций).
-   `/var`: **Переменные данные (Variable)**. Содержит данные, которые часто изменяются во время нормальной работы системы. К ним относятся файлы журналов (`/var/log`), спулы (например, для печати или почты), временные файлы, кэши и файлы баз данных (`/var/lib`). Из-за своей динамической природы `/var` часто рекомендуется выносить на отдельный раздел для предотвращения заполнения корневой файловой системы и упрощения резервного копирования.
