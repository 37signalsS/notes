# POSIX и FHS — стандарты файловой системы

## Определения

- **POSIX (Portable Operating System Interface)** — набор стандартов, описывающий принципы функционирования Unix-подобных операционных систем. Основная цель — обеспечение **совместимости исходного кода** программ между различными системами (Linux, macOS, Berkeley Software Distribution (BSD)). Стандарт определяет системные вызовы (Application Programming Interface (API)), интерфейс командной строки, права доступа и базовую структуру файловой системы. Linux следует этим стандартам в значительной степени, хотя формально не всегда сертифицирован.

- **FHS (Filesystem Hierarchy Standard)** — стандарт, определяющий структуру каталогов в Linux и других Unix-подобных системах. Предписывает назначение каталогов и расположение файлов, что обеспечивает предсказуемость структуры (например, `/etc` для конфигураций).

- **LSB (Linux Standard Base)** — стандарт для дистрибутивов Linux, направленный на обеспечение **бинарной совместимости**. FHS является составной частью LSB.

## Основные концепции

- **Принцип "Всё есть файл"**: в Unix-подобных системах большинство объектов, включая оборудование (диски `/dev/sda`, терминалы `/dev/tty1`), сетевые сокеты и системную информацию ([`/proc`](./virtual_fs_proc.md)), представлены в виде файлов. Это позволяет использовать стандартные утилиты (`read`, `write`, `cat`) для взаимодействия с ними.

- **Единое корневое дерево**: в отличие от систем с буквами дисков, в Linux вся файловая система организована как единая иерархия, начинающаяся с корня (`/`). Любые устройства или сетевые ресурсы монтируются в существующие каталоги этого дерева. Например, раздел для данных пользователей монтируется в `/home`, становясь частью общей структуры.

## Практические сценарии

### Иерархия каталогов (стандарт FHS)

- `/`: **Корень (Root)**. Вершина всей иерархии файловой системы.
- `/bin`: **Основные команды**. Критически важные утилиты для всех пользователей (`ls`, `cp`, `mv`). В современных системах — ссылка на `/usr/bin`.
- `/sbin`: **Системные команды**. Утилиты администрирования (`fdisk`, `mkfs`), обычно требующие прав суперпользователя. Часто ссылка на `/usr/sbin`.
- `/boot`: **Загрузочные файлы**. Ядро Linux, образ `initramfs` и конфигурация загрузчика.
- `/dev`: **[Файлы устройств](./virtual_fs_dev.md)**. Интерфейс к аппаратному обеспечению.
- `/etc`: **Конфигурации**. Системные и программные конфигурационные файлы.
- `/home`: **Домашние каталоги**. Личные данные пользователей.
- `/root`: **Домашний каталог root**. Отделен от `/home` для обеспечения доступа при недоступности других разделов.
- `/lib`, `/lib64`: **Библиотеки**. Системные библиотеки для программ из `/bin` и `/sbin`.
- `/opt`: **Опциональное ПО**. Для сторонних пакетов, не входящих в дистрибутив.
- `/srv`: **Данные сервисов**. Данные для предоставляемых системой сервисов (например, веб-сервера).
- `/tmp`: **Временные файлы**. Очищаются при перезагрузке, часто монтируются в ОЗУ.
- `/usr`: **Пользовательские ресурсы**. Содержит большинство программ, библиотек и документации.
- `/var`: **Переменные данные**. Логи, кэш, очереди и базы данных.
- `/proc`: **[Информация о процессах](./virtual_fs_proc.md)**. Виртуальная ФС с данными о ядре и процессах в реальном времени.
- `/sys`: **[Информация об устройствах](./virtual_fs_sys.md)**. Структурированный доступ к параметрам ядра и оборудования.
- `/mnt`, `/media`: **Точки монтирования**. `/mnt` для временных ручных монтирований, `/media` для автоматического монтирования съемных носителей.
- `/lost+found`: **Восстановленные файлы**. Данные, найденные утилитой `fsck` после сбоев.

## Дополнительная информация

В современных дистрибутивах применяется **UsrMerge** — перенос содержимого `/bin`, `/sbin`, `/lib` в `/usr`, что упрощает управление системой. Каталоги `/dev`, `/proc`, `/sys` и часто `/tmp` являются виртуальными и хранятся в оперативной памяти (`tmpfs`).
