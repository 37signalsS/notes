# Восстановление пароля root в Linux

Если вы потеряли пароль от пользователя `root`, его можно сбросить, получив доступ к системе в однопользовательском режиме или с помощью `init`-шелла. Этот процесс требует физического доступа к машине или консоли управления.

### Перезагрузка и вход в меню GRUB

1.  Перезагрузите компьютер.
2.  Когда появится меню загрузчика GRUB, нажмите клавишу `e`, чтобы отредактировать параметры загрузки для выбранной записи (обычно первой).

### Редактирование параметров загрузки ядра

1.  Вы увидите текстовый редактор с конфигурацией загрузки. Найдите строку, которая начинается с `linux` или `linuxefi`. Эта строка определяет ядро для загрузки и его параметры.

2.  Переместите курсор в конец этой строки.

3.  Добавьте один из следующих параметров:
    *   **`init=/bin/bash`** (или `init=/bin/sh`)
        *   **Что делает:** Указывает ядру запустить `/bin/bash` в качестве первого процесса (PID 1) вместо `systemd` или `init`. В результате вы сразу получите корневую оболочку.
        *   **Когда использовать:** Универсальный метод, работает на большинстве систем.

    *   **`rd.break`** (для систем с `systemd`, таких как RHEL 7+, AlmaLinux/Rocky Linux и Ubuntu 18.04+. **Важно:** стандартная поддержка Ubuntu 18.04 прекращена. CentOS 7 также достиг EOL, рекомендуется использовать современные RHEL-подобные дистрибутивы)
        *   **Что делает:** Останавливает процесс загрузки на раннем этапе, до того как `systemd` передаст управление реальной корневой файловой системе. Вы попадете в `emergency mode`.
        *   **Когда использовать:** Предпочтительный метод для современных систем, использующих `initramfs`.

### Запуск с измененными параметрами

-   После добавления параметра нажмите `Ctrl+X` или `F10`, чтобы загрузить систему с измененными параметрами.

### Сброс пароля

Теперь вы находитесь в корневой оболочке с правами `root`. Дальнейшие действия зависят от того, какой параметр вы использовали.

#### Вариант А: Если вы использовали `init=/bin/bash`

1.  Корневая файловая система (`/`) смонтирована в режиме "только для чтения" (`ro`). Ее нужно перемонтировать в режим "чтение-запись" (`rw`):
    ```bash
    mount -o remount,rw /
    ```

2.  Измените пароль пользователя `root`:
    ```bash
    passwd
    ```
    Система попросит вас ввести и подтвердить новый пароль.

3.  (Только для систем с SELinux) Если у вас включен SELinux (например, в CentOS/RHEL), создайте пустой файл `.autorelabel` в корне, чтобы система выполнила перемаркировку файлов при следующей загрузке.
    ```bash
    touch /.autorelabel
    ```

4.  Перезагрузите систему. Так как `systemd` не запущен, обычная команда `reboot` может не сработать. Используйте одну из этих команд для принудительной перезагрузки:
    ```bash
    exec /sbin/init 6
    # или, в крайнем случае
    reboot -f
    ```

#### Вариант Б: Если вы использовали `rd.break`

1.  Корневая файловая система находится в `/sysroot` и смонтирована в режиме "только для чтения" (`ro`). Перемонтируйте ее в режим "чтение-запись" (`rw`):
    ```bash
    mount -o remount,rw /sysroot
    ```

2.  Переключитесь в `chroot`-окружение, чтобы корневой директорией стала `/sysroot`:
    ```bash
    chroot /sysroot
    ```

3.  Теперь вы можете изменить пароль:
    ```bash
    passwd
    ```

4.  (Только для систем с SELinux) Создайте файл для перемаркировки:
    ```bash
    touch /.autorelabel
    ```

5.  Выйдите из `chroot`-окружения:
    ```bash
    exit
    ```

6.  Перезагрузите систему:
    ```bash
    reboot
    ```
