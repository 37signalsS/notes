# Обзор управления пакетами в Linux: RPM и DEB

## Определения

Ниже приведены основные термины, используемые в экосистеме управления программным обеспечением в дистрибутивах Linux.

**Пакет (Package)** — архив специального формата, содержащий файлы программного обеспечения, метаданные (версия, зависимости, контрольные суммы), а также скрипты для автоматизации установки и удаления.

**Низкоуровневая утилита** — инструмент для прямой работы с файлами пакетов: `rpm` для формата RPM (Red Hat Package Manager) или `dpkg` для формата DEB (Debian Package). Позволяет устанавливать и удалять конкретные файлы, но не умеет автоматически разрешать зависимости.

**Высокоуровневая утилита** — надстройка, упрощающая управление программным обеспечением: `dnf` (Dandified YUM) / `yum` (Yellowdog Updater, Modified) для RPM или `apt` (Advanced Package Tool) для DEB. Работает с репозиториями, автоматически скачивает необходимые зависимости и управляет системными обновлениями.

**Репозиторий (Repository)** — хранилище пакетов и их метаданных, организованное по определенным стандартам. Позволяет пакетным менеджерам находить и устанавливать актуальные версии ПО.

**Зависимость (Dependency)** — внешний программный компонент (библиотека или другая программа), без которого установка или работа данного пакета невозможна.

**Транзакция (Transaction)** — атомарная последовательность действий по изменению состава ПО в системе. Если в процессе установки возникнет критическая ошибка, транзакция может быть отменена для сохранения стабильности системы.

## Основные концепции

### Сравнение систем пакетов

| Характеристика | RPM (Red Hat Package Manager) | DEB (Debian Package) |
| :--- | :--- | :--- |
| **Ключевые дистрибутивы** | Fedora, RHEL (Red Hat Enterprise Linux), CentOS, openSUSE | Debian, Ubuntu, Linux Mint |
| **Расширение файлов** | `.rpm` | `.deb` |
| **Низкоуровневая утилита** | `rpm` | `dpkg` |
| **Высокоуровневая утилита** | `dnf`, `yum` | `apt`, `apt-get` |
| **Системная база данных** | `/var/lib/rpm/` | `/var/lib/dpkg/` |

### Принцип работы высокоуровневых менеджеров

1. **Анализ дерева зависимостей**: Определение всех необходимых компонентов для целевого пакета.
2. **Поиск в источниках**: Поиск пакетов в настроенных репозиториях с учетом приоритетов (например, через механизм [Apt Pinning](./deb_apt_pinning.md)).
3. **Планирование транзакции**: Составление списка действий и проверка на наличие конфликтов версий.
4. **Подтверждение**: Вывод информации об объеме загрузки и требуемом дисковом пространстве для пользователя.
5. **Исполнение**: Загрузка файлов и вызов низкоуровневых утилит для распаковки и размещения файлов.
6. **Регистрация**: Обновление локальной базы данных установленного ПО.

### Технологические особенности APT (Advanced Package Tool)

#### Решатель зависимостей Solver3 (начиная с APT 3.2+)

Solver3 представляет собой современный алгоритм разрешения конфликтов:

- **Эффективный backtracking**: Улучшенный механизм отката при поиске альтернативных путей разрешения зависимостей.
- **Интеллектуальный выбор**: Оптимизированная логика подбора кандидатов при глобальном обновлении системы.
- **Диагностика**: Инструменты `apt why` и `apt why-not` позволяют понять логику решений менеджера.

#### Варианты микроархитектуры CPU (Central Processing Unit)

Поддержка специфических расширений процессоров для повышения производительности (начиная с версии APT 3.2+):

- **Уровни x86-64-v2, v3, v4**: Автоматический выбор пакетов, оптимизированных под инструкции SSE4 (Streaming SIMD Extensions 4), AVX (Advanced Vector Extensions) и AVX-512.
- **Механизм**: Реализуется через поле `Architecture-Variants` в конфигурации APT.

## Практические сценарии

### Выбор дистрибутива под задачу

| Сценарий использования | Рекомендуемый дистрибутив | Причина выбора |
| :--- | :--- | :--- |
| **Продакшен-серверы** | Debian Stable, RHEL, AlmaLinux | Максимальная стабильность, длительный цикл поддержки. |
| **Рабочая станция разработчика** | Ubuntu LTS (Long Term Support), Fedora | Баланс между свежим ПО и надежностью. |
| **Изучение новых технологий** | Fedora, Arch Linux | Самые актуальные версии ядер и библиотек. |

### Таблица соответствия команд

| Операция | DEB (apt) | RPM (dnf) |
| :--- | :--- | :--- |
| **Обновление индексов** | `apt update` | `dnf check-update` |
| **Полное обновление ОС** | `apt upgrade` | `dnf upgrade` |
| **Установка программы** | `apt install <name>` | `dnf install <name>` |
| **Удаление программы** | `apt remove <name>` | `dnf remove <name>` |
| **Поиск по ключевому слову** | `apt search <query>` | `dnf search <query>` |
