## Дополнительная информация

### Расчёт необходимого дискового пространства

| Дистрибутив | Полный размер | Частичное (main only) |
| :--- | :--- | :--- |
| **Ubuntu 22.04** | ~200 GB | ~50 GB |
| **Debian 12** | ~400 GB | ~80 GB |

**Рекомендации:**

- Используйте отдельный раздел или диск для хранения зеркала.
- Настройте мониторинг свободного места.
- Планируйте рост объёма данных при добавлении новых версий дистрибутивов.

### Оптимизация зеркалирования

#### Фильтрация пакетов (apt-mirror)

В файле `mirror.list` можно ограничить список загружаемых данных:

```bash
# Зеркалирование только определённых архитектур
set archs amd64

# Исключение пакетов по регулярному выражению (пример)
# FILTER = ^(.*/)?(kernel|linux-image).*$
```

#### Инкрементальная синхронизация

`apt-mirror` по умолчанию загружает только изменённые файлы.

```bash
# Принудительная проверка всех файлов
apt-mirror --force-check

# Очистка устаревших версий пакетов (удаление файлов, отсутствующих в upstream)
apt-mirror --clean
```

### Мониторинг и логирование

```bash
# Просмотр лога синхронизации в реальном времени
tail -f /var/spool/apt-mirror/var/log

# Проверка времени последнего успешного запуска
ls -la /var/spool/apt-mirror/var/last-run
```

**Пример скрипта для уведомлений об ошибках:**

```bash
#!/bin/bash
if ! /usr/bin/apt-mirror > /var/log/apt-mirror.log 2>&1; then
    echo "Ошибка синхронизации APT зеркала. Подробности в /var/log/apt-mirror.log" | \
    mail -s "APT Mirror Sync Failed" admin@example.com
fi
```

### Проблемы и решения

| Проблема | Причина | Решение |
| :--- | :--- | :--- |
| **Недостаточно места** | Большой размер репозитория | Очистить старые пакеты (`--clean`), увеличить диск. |
| **404 ошибки** | Изменения в структуре upstream | Обновить URL (Uniform Resource Locator) адреса в `mirror.list`. |
| **Ошибки GPG на клиентах** | Отсутствуют публичные ключи | Импортировать ключи GPG (GNU Privacy Guard) репозитория на клиентские машины. |
| **Медленная загрузка** | Ограничение пропускной способности | Увеличить количество потоков `nthreads`. |
