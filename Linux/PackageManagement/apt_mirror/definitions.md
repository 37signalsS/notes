# Зеркалирование APT: Определения

## Definitions

**Локальное зеркало (Local Mirror)** — полная или частичная копия удалённого репозитория пакетов (например, Ubuntu, Debian), размещённая в локальной сети или на изолированном сервере. Служит для экономии WAN-трафика, ускорения доставки пакетов и работы в air-gapped средах.

**Репозиторий-источник (Upstream Repository)** — официальный или доверенный удалённый репозиторий, с которого синхронизируется локальное зеркало. Примеры: `archive.ubuntu.com`, `security.ubuntu.com`, `deb.debian.org`, `ppa.launchpad.net`.

**Синхронизация** — процесс обновления локального зеркала до актуального состояния репозитория-источника. Бывает первичной (полное копирование) и инкрементальной (только delta-изменения).

**APT (Advanced Package Tool)** — система управления пакетами в Debian/Ubuntu, использующая репозитории для установки, обновления и удаления ПО. Основные команды: `apt update`, `apt upgrade`, `apt install`.

**Индексы репозитория** — метаданные APT: `Packages`, `Sources`, `Release`, `InRelease`, `Packages.gz`. Содержат информацию о доступных пакетах, версиях, зависимостях и контрольных сумтах.

**Компоненты репозитория (Components)** — логические секции внутри репозитория:

- `main` — свободное ПО, официально поддерживаемое дистрибутивом
- `restricted` — проприетарные драйверы и firmware
- `universe` — сообщество поддерживаемые пакеты
- `multiverse` — ПО с ограниченной лицензией

**Архитектура (Architecture)** — целевая платформа пакетов: `amd64`, `arm64`, `i386`, `source` (исходный код). Зеркалирование может включать одну или несколько архитектур.

**Пулы пакетов (Pool)** — единое хранилище `.deb`-файлов в репозитории, на которое ссыляются индексные файлы. Структура: `pool/main/<first-letter>/<package-name>/`.

## Basic Concepts

### Отличия зеркалирования от приватного репозитория

| Критерий | Зеркалирование | Приватный репозиторий |
| :--- | :--- | :--- |
| **Цель** | Копирование внешних upstream-репо | Публикация внутренних пакетов |
| **Инструменты** | `apt-mirror`, `debmirror` | `reprepro` |
| **GPG-подпись** | Не требуется | Обязательна |
| **Направление** | Извне → внутрь | Изнутри → наружу |

### Ключевые файлы APT-репозитория

| Файл | Назначение |
| :--- | :--- |
| `dists/<codename>/Release` | Метаданные дистрибутива: версии, компоненты, хэши |
| `dists/<codename>/main/binary-<arch>/Packages.gz` | Сжатый индекс бинарных пакетов |
| `pool/` | Хранилище `.deb`-файлов |
| `dists/<codename>/InRelease` | Подписанный Release-файл (APT Secure) |

### Экосистема Debian/Ubuntu

- **Debian** — стабильный, консервативный дистрибутив. Репозитории: `deb.debian.org`, `security.debian.org`
- **Ubuntu** — производный от Debian, фиксированный цикл релизов. Репозитории: `archive.ubuntu.com`, `security.ubuntu.com`
- **PPA (Personal Package Archive)** — пользовательские репозитории на `launchpad.net`
- **Совместимость** — Ubuntu-пакеты не всегда совместимы с Debian и наоборот
