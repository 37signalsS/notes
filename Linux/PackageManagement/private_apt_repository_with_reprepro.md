# Создание приватного Apt-репозитория с помощью reprepro

`reprepro` — это утилита для создания и управления репозиториями `.deb` пакетов для Debian, Ubuntu и их производных. Это мощный инструмент для организации доставки вашего собственного ПО или для создания зеркала существующих пакетов.

## 1. Установка и первоначальная настройка

Установим `reprepro` и создадим структуру директорий для нашего репозитория.

```bash
sudo apt-get update
sudo apt-get install reprepro

# Создаем директорию для репозитория
mkdir -p my-repo/conf
```

## 2. Создание GPG-ключа для подписи репозитория

Apt-репозитории должны быть подписаны GPG-ключом, чтобы клиенты могли доверять пакетам.

```bash
# Генерируем новый ключ
gpg --gen-key
```

Следуйте инструкциям на экране. Рекомендуется выбрать:
*   Тип ключа: `RSA and RSA`
*   Размер ключа: `4096`
*   Срок действия: на ваше усмотрение (например, `0` для бессрочного).

После создания ключа, узнайте его ID:

```bash
gpg --list-secret-keys --keyid-format LONG
```

Вывод будет примерно таким:
```
sec   rsa4096/AABBCCDD11223344 2025-11-13 [SC]
      XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
uid                 [ultimate] Your Name <your.email@example.com>
```
Здесь `AABBCCDD11223344` — это ID вашего ключа.

Экспортируем публичную часть ключа. Этот файл (`repo.key`) нужно будет распространить на клиентские машины.

```bash
# Экспортируем публичную часть ключа. Этот файл (`repo.key`) нужно будет распространить на клиентские машины.
# Замените <ID_ВАШЕГО_GPG_КЛЮЧА> на реальный ID, полученный на предыдущем шаге.
gpg --export -a "<ID_ВАШЕГО_GPG_КЛЮЧА>" > my-repo/repo.key
```

## 3. Конфигурация репозитория

Основной конфигурационный файл `reprepro` — это `conf/distributions`. Он описывает дистрибутивы (например, `focal`, `buster`), компоненты (`main`, `contrib`) и архитектуры (`amd64`, `arm64`), которые будет обслуживать репозиторий.

Создадим файл `my-repo/conf/distributions`:

```
# Имя репозитория, которое будет видно клиентам
Origin: Rebrain
# Описание
Label: Rebrain APT Repository
# Кодовое имя дистрибутива (например, Ubuntu 20.04)
Codename: focal
# Архитектуры
Architectures: amd64
# Компоненты
Components: main
# Описание
Description: Rebrain private package repository
# Указываем ID GPG-ключа для подписи
SignWith: <ID_ВАШЕГО_GPG_КЛЮЧА>
```

*   `Origin`, `Label`: Имена, которые помогут идентифицировать репозиторий на клиенте (например, для [настройки приоритетов](./apt_pinning_and_priorities.md)).
*   `Codename`: Кодовое имя релиза ОС, для которого предназначены пакеты (например, `focal` для Ubuntu 20.04, `buster` для Debian 10).
*   `SignWith`: ID GPG-ключа, созданного на предыдущем шаге.

## 4. Добавление пакетов

Теперь можно добавить в репозиторий `.deb` пакет.

```bash
# Переходим в директорию репозитория
cd my-repo

# Добавляем пакет в дистрибутив 'focal'
reprepro includedeb focal /path/to/your/package_1.0_amd64.deb
```
`reprepro` попросит ввести пароль от GPG-ключа для подписи метаданных репозитория.

После выполнения команды `reprepro` автоматически создаст необходимую структуру директорий (`dists`, `pool`) и обновит метаданные.

## 5. Публикация репозитория через Nginx

Репозиторий представляет собой набор статических файлов, поэтому его легко опубликовать с помощью любого веб-сервера.

Пример конфигурации Nginx:

```nginx
server {
    listen 80;
    server_name repo.your.domain;

    root /path/to/your/my-repo;

    location / {
        # Включаем листинг директорий для удобства просмотра
        autoindex on;
    }
}
```

*   `root`: Укажите полный путь к директории вашего репозитория (`my-repo`).

Для защиты репозитория можно использовать [аутентификацию по клиентским SSL-сертификатам](../../WebServers/Nginx/ssl_client_certificate_authentication.md).

## 6. Настройка клиента

Чтобы клиент мог использовать ваш репозиторий:

1.  **Скопируйте публичный GPG-ключ (`repo.key`)** на клиентскую машину и добавьте его в доверенные:
    ```bash
    sudo cp repo.key /etc/apt/trusted.gpg.d/my-repo.asc
    ```

2.  **Создайте файл списка источников:**
    ```bash
    # /etc/apt/sources.list.d/my-repo.list
    deb [arch=amd64] http://repo.your.domain focal main
    ```

3.  **Обновите список пакетов:**
    ```bash
    sudo apt-get update
    ```

Теперь вы можете устанавливать пакеты из вашего приватного репозитория.
