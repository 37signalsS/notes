# Управление репозиториями в Ubuntu

**Репозиторий** — это централизованное хранилище программного обеспечения, откуда система управления пакетами APT (Advanced Package Tool) загружает и устанавливает пакеты.

**Пакет** — это готовый к установке программный продукт, упакованный в архив. Пакеты содержат не только само приложение, но и метаданные, необходимые для управления зависимостями, разрешения конфликтов и автоматизации установки/удаления.

Файл `/etc/apt/sources.list` и файлы в директории `/etc/apt/sources.list.d/` определяют, откуда система управления пакетами APT будет загружать пакеты.

Каждая строка в `sources.list` имеет следующую структуру:

```
<type> <url> <distribution> <component_1> <component_2> ...
```

-   **`type`**: Тип архива.
    -   `deb`: бинарные пакеты (скомпилированные приложения).
    -   `deb-src`: исходные коды пакетов.
-   **`url`**: Базовый URL репозитория.
-   **`distribution`**: Имя выпуска (кодовое имя) или класс выпуска (например, `focal`, `jammy`).
-   **`component`**: Компоненты репозитория.
    -   `main`: Основные, полностью свободные пакеты, поддерживаемые Canonical.
    -   `restricted`: Проприетарные драйверы устройств.
    -   `universe`: Свободное ПО, поддерживаемое сообществом.
    -   `multiverse`: Проприетарное ПО, не поддерживаемое Canonical.

По умолчанию в Ubuntu `sources.list` содержит записи для `main`, `restricted`, `universe`, `multiverse`, а также для `updates` и `security` компонентов, которые отвечают за обычные обновления и обновления безопасности соответственно.

## Добавление сторонних репозиториев

При добавлении сторонних репозиториев крайне важно добавить соответствующий GPG-ключ, которым подписаны пакеты. Это гарантирует, что система доверяет источнику пакетов и предотвращает установку поддельных или вредоносных пакетов. GPG-ключ позволяет системе проверить подлинность пакетов, убедившись, что они получены именно от заявленного разработчика и не были изменены.

### Пример 1: Репозиторий Nginx

Для установки более свежей версии Nginx, чем доступна в стандартных репозиториях Ubuntu, можно добавить официальный репозиторий Nginx.

1.  **Установка зависимостей и импорт GPG-ключа:**

    ```bash
    sudo apt update
    sudo apt install -y curl gnupg2 ca-certificates lsb-release ubuntu-keyring
    curl -fsSL https://nginx.org/keys/nginx_signing.key | sudo gpg --dearmor -o /usr/share/keyrings/nginx-archive-keyring.gpg
    ```

2.  **Добавление репозитория Nginx:**

    Создайте файл `/etc/apt/sources.list.d/nginx.list` со следующим содержимым (для Ubuntu Focal Fossa):

    ```bash
    echo "deb [signed-by=/usr/share/keyrings/nginx-archive-keyring.gpg] https://nginx.org/packages/ubuntu `lsb_release -cs` nginx" | sudo tee /etc/apt/sources.list.d/nginx.list
    echo "deb-src [signed-by=/usr/share/keyrings/nginx-archive-keyring.gpg] https://nginx.org/packages/ubuntu `lsb_release -cs` nginx" | sudo tee -a /etc/apt/sources.list.d/nginx.list
    ```
    *Примечание: `lsb_release -cs` автоматически подставит кодовое имя вашего дистрибутива (например, `focal`).*

3.  **Обновление списка пакетов и установка Nginx:**

    ```bash
    sudo apt update
    sudo apt install nginx -y
    ```

    Если вы хотите использовать `mainline` версию Nginx (более свежая, но потенциально менее стабильная), замените `nginx` на `nginx-mainline` в строках репозитория.

### Пример 2: Репозиторий Oracle MySQL (через `.deb` пакет)

Некоторые производители предоставляют `.deb` пакет, который автоматически настраивает репозиторий и импортирует GPG-ключ.

1.  **Загрузка `.deb` пакета конфигурации репозитория:**

    Перейдите на официальную страницу загрузки MySQL APT Repository (например, `https://dev.mysql.com/downloads/repo/apt/`) и скопируйте ссылку на нужный `.deb` пакет.

    ```bash
    wget https://dev.mysql.com/get/mysql-apt-config_0.8.22-1_all.deb
    ```

2.  **Установка `.deb` пакета:**

    ```bash
    sudo dpkg -i mysql-apt-config_0.8.22-1_all.deb
    ```
    Во время установки вам будет предложено выбрать версию MySQL и компоненты, которые вы хотите включить в репозиторий.

3.  **Обновление списка пакетов и установка MySQL:**

    ```bash
    sudo apt update
    sudo apt install mysql-server -y
    ```

    Для перенастройки выбранных опций репозитория после установки можно использовать команду:
    ```bash
    sudo dpkg-reconfigure mysql-apt-config
    ```

## Проверка источников пакетов с помощью `apt policy`

Команда `apt policy <package_name>` позволяет узнать, из каких репозиториев доступен пакет, его текущую установленную версию и приоритеты различных источников.

Приоритеты играют ключевую роль, когда один и тот же пакет доступен из нескольких репозиториев. Система APT выбирает пакет из источника с наивысшим приоритетом. Если приоритеты одинаковы, предпочтение отдается более новой версии. Это позволяет, например, использовать более свежие версии ПО от разработчика, даже если в стандартных репозиториях Ubuntu есть более старая версия того же пакета.

```bash
apt policy nginx
```

Пример вывода:
```
nginx:
  Установлен: 1.20.2-1~focal
  Кандидат:   1.20.2-1~focal
  Таблица версий:
 *** 1.20.2-1~focal 500
        500 https://nginx.org/packages/ubuntu focal/nginx amd64 Packages
     1.18.0-0ubuntu1.4 500
        500 http://archive.ubuntu.com/ubuntu focal-updates/main amd64 Packages
     1.18.0-0ubuntu1 500
        500 http://archive.ubuntu.com/ubuntu focal/main amd64 Packages
```
В данном примере видно, что установленная версия `1.20.2` получена из репозитория `nginx.org`, который имеет приоритет `500`. Также доступны более старые версии из стандартных репозиториев Ubuntu. Чем выше значение приоритета, тем более вероятно, что пакет будет выбран из этого источника.
