# Управление приоритетами пакетов в Apt (Pinning)

## Определения

**Pinning (Приоритизация пакетов)** — механизм Apt для гибкого управления выбором источника и версии пакета. Приоритет — числовое значение, присваиваемое каждой версии пакета, определяющее его предпочтительность при установке. Apt всегда выбирает версию с наивысшим приоритетом.

## Основные понятия

### Принцип выбора пакета Apt

По умолчанию Apt устанавливает пакет с максимальной версией. При равных версиях приоритет отдается репозиторию, объявленному первым. Механизм pinning изменяет это поведение, позволяя вручную назначать приоритеты.

### Просмотр приоритетов

Команда `apt-cache policy` отображает приоритеты настроенных репозиториев и установленных пакетов.

```bash
apt-cache policy
```

Для просмотра приоритетов конкретного пакета:

```bash
apt-cache policy nginx
```

Вывод включает доступные версии, их репозитории, присвоенные приоритеты и "кандидата на установку" — версию, которую Apt выберет при `apt-get install`.

### Стандартные значения приоритетов

* `> 1000`: Безусловная установка, допустим downgrade.
* `990 - 1000`: Приоритет для целевого релиза.
* `500 - 989`: Стандартный приоритет для обычных репозиториев.
* `100 - 499`: Приоритет для установленных версий и пакетов из `backports`.
* `1 - 99`: Низкий приоритет, не для автоматической установки.
* `< 0`: Запрет установки.

## Практические сценарии

### Настройка приоритетов

Приоритеты конфигурируются в файлах директории `/etc/apt/preferences.d/`. Эти файлы дополняют [источники репозиториев (`sources.list`)](../../Linux/PackageManagement/deb_repositories_sources_list.md). Рекомендуется использовать отдельный файл для каждого правила.

Пример: создание `/etc/apt/preferences.d/my-repo-prefs`.

#### Пример 1: Приоритизация всего репозитория

Для предпочтения всех пакетов из определенного репозитория, даже если их версии ниже.

```
# /etc/apt/preferences.d/my-repo-prefs
Package: *
Pin: origin "My Private Repo"
Pin-Priority: 990
```

* `Package: *`: Правило для всех пакетов.
* `Pin: origin "My Private Repo"`: Идентификатор репозитория (узнать можно из `apt-cache policy`).
* `Pin-Priority: 990`: Высокий приоритет.

#### Пример 2: Приоритизация конкретного пакета

Для "замораживания" версии определенного пакета из конкретного репозитория.

```
# /etc/apt/preferences.d/my-repo-prefs
Package: nginx
Pin: origin "My Private Repo"
Pin-Priority: 1001
```

Приоритет `1001` гарантирует установку `nginx` из указанного репозитория, даже если это приведет к понижению версии.

#### Пример 3: Запрет установки пакета из репозитория

```
# /etc/apt/preferences.d/block-nginx
Package: nginx
Pin: origin "nginx.org"
Pin-Priority: -1
```

Это правило блокирует установку `nginx` из репозитория с `Origin` "nginx.org".

## Дополнительная информация

### Применение изменений

После создания или модификации файлов в `/etc/apt/preferences.d/` необходимо обновить кэш Apt:

```bash
sudo apt-get update
```

Затем проверьте результат с `apt-cache policy <package-name>` для подтверждения соответствия правил.
