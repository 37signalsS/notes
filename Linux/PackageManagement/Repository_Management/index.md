# Управление репозиториями DNF

## Определения

Ниже приведены основные термины, описывающие структуру и механизмы работы хранилищ программного обеспечения в дистрибутивах на базе RPM (Red Hat Package Manager).

**Репозиторий DNF (Dandified YUM)** — сервер или локальный каталог, содержащий пакеты формата RPM и метаданные в формате, совместимом с пакетными менеджерами DNF и YUM (Yellowdog Updater, Modified). Конфигурация осуществляется через файлы в директории `/etc/yum.repos.d/`.

**GPG-ключ репозитория** — публичный криптографический ключ GPG (GNU Privacy Guard), используемый для проверки цифровой подписи пакетов. Это гарантирует, что программное обеспечение не было изменено и было подписано доверенным источником.

**Metalink / Mirrorlist** — механизмы динамического выбора зеркал (серверов) для загрузки пакетов. Обеспечивают высокую доступность, отказоустойчивость и автоматическую балансировку нагрузки между серверами.

## Основные концепции

### Структура .repo файла

Файлы конфигурации репозиториев используют формат INI (Initialization file) и должны иметь расширение `.repo`. Они располагаются в директории `/etc/yum.repos.d/`.

```ini
[repo_id]                    # Уникальный идентификатор репозитория
name=Human-Readable Name     # Человекочитаемое описание
baseurl=http://...           # Прямой URL (Uniform Resource Locator) хранилища
mirrorlist=http://...        # URL списка доступных зеркал
metalink=https://...         # URL metalink-файла (рекомендуется для Fedora)
enabled=1                    # Состояние: 1 — включён, 0 — выключен
gpgcheck=1                   # Проверка GPG-подписи каждого пакета
gpgkey=file:///...           # Путь к файлу публичного ключа GPG
repo_gpgcheck=0              # Проверка подписи самих метаданных репозитория
priority=50                  # Приоритет (меньше значение — выше приоритет)
cost=1000                    # Стоимость (используется для выбора между равнозначными зеркалами)
includepkgs=pkg1,pkg2        # Ограничение: устанавливать только указанные пакеты
exclude=pkga,pkgb            # Исключение: игнорировать указанные пакеты
```

### Приоритеты и стоимость репозиториев

Для тонкой настройки выбора пакетов при наличии одинаковых имен в разных источниках используются следующие параметры:

| Параметр | Диапазон | Назначение |
| :--- | :--- | :--- |
| `priority` | 1 – 99 | Порядковый приоритет (1 — наивысший). Требует плагин `dnf-plugin-priorities`. |
| `cost` | 1+ | Относительная "цена" доступа (меньшее значение предпочтительнее при выборе зеркала). |
| `enabled` | 0 / 1 | Флаг активности репозитория по умолчанию. |

### Переменные в URL репозиториев

DNF поддерживает динамическую подстановку значений, что позволяет использовать универсальные пути для разных архитектур и версий ОС (Операционной Системы).

| Переменная | Описание | Пример значения |
| :--- | :--- | :--- |
| `$releasever` | Версия дистрибутива | `9`, `40`, `rawhide` |
| `$basearch` | Базовая архитектура системы | `x86_64`, `aarch64` |
| `$arch` | Конкретная архитектура CPU | `x86_64`, `noarch` |
| `$contentdir` | Путь к директории контента | `centos`, `fedora` |
