# Управление репозиториями DNF

## Определения

**Репозиторий DNF** — сервер или локальный каталог, содержащий RPM-пакеты и метаданные в формате, совместимом с DNF/YUM. Конфигурируется через файлы в `/etc/yum.repos.d/`.

**GPG-ключ репозитория** — криптографический ключ для проверки подлинности пакетов. Гарантирует, что пакеты не были изменены и подписаны доверенным источником.

**Metalink/Mirrorlist** — механизм динамического выбора зеркала для загрузки пакетов, обеспечивающий отказоустойчивость и балансировку нагрузки.

## Основные понятия

### Структура .repo файла

Файлы репозиториев имеют формат INI с расширением `.repo` в директории `/etc/yum.repos.d/`. Полный список директив — в [конфигурации DNF](../dnf_commands/basic_concepts.md).

```ini
[repo_id]                    # Уникальный идентификатор
name=Human-Readable Name     # Человекочитаемое имя
baseurl=http://...           # Прямой URL
mirrorlist=http://...        # URL списка зеркал
metalink=https://...         # URL metalink (предпочтительно для Fedora)
enabled=1                    # 1 — включён, 0 — выключен
gpgcheck=1                   # Проверка GPG-подписи пакетов
gpgkey=file:///...           # Путь к публичному GPG-ключу
repo_gpgcheck=0              # Проверка подписи метаданных
priority=50                  # Приоритет (меньше = выше, требует плагин priorities)
cost=1000                    # Стоимость (для выбора между зеркалами)
includepkgs=pkg1,pkg2        # Только указанные пакеты
exclude=pkga,pkgb            # Исключить пакеты
```

### Приоритеты репозиториев

| Параметр | Значение | Назначение |
| :--- | :--- | :--- |
| `priority` | 1–99 | Приоритет репозитория (1 — наивысший) |
| `cost` | 1+ | Относительная стоимость пакета (меньше = лучше) |
| `enabled` | 0/1 | Включён ли по умолчанию |

**Требование:** плагин `dnf-plugin-priorities` (или `yum-plugin-priorities` для старых версий).

### Переменные в URL

| Переменная | Значение | Пример |
| :--- | :--- | :--- |
| `$releasever` | Версия дистрибутива | `8`, `9`, `38` |
| `$basearch` | Базовая архитектура | `x86_64`, `aarch64` |
| `$arch` | Архитектура | `x86_64`, `noarch` |
| `$contentdir` | Директория контента | `centos`, `fedora` |
