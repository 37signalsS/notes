## Основные концепции

### Этапы сборки

Процесс создания пакета обычно включает следующие стадии:

1. **Получение исходных текстов** — загрузка исходного кода и необходимых патчей.
2. **Подготовка окружения** — установка зависимостей, необходимых для компиляции и сборки.
3. **Настройка правил сборки** — модификация управляющих файлов (`debian/rules` для DEB или `.spec` для RPM).
4. **Сборка** — непосредственная компиляция кода и упаковка в бинарный формат.
5. **Проверка (Linting)** — автоматизированное тестирование собранного пакета на соответствие стандартам дистрибутива.
6. **Подпись** — криптографическая подпись пакета GPG (GNU Privacy Guard) ключом для обеспечения доверия.

### Инструменты сборки

#### Система DEB (Debian Package)

| Инструменты | Назначение |
| :--- | :--- |
| `dpkg-dev`, `debhelper`, `devscripts` | Базовый набор утилит для сборки в Debian/Ubuntu. |
| `pbuilder`, `sbuild`, `cowbuilder` | Инструменты для создания чистого изолированного окружения. |
| `debuild`, `dch`, `debchange` | Автоматизация сборки и управление журналом изменений (changelog). |

#### Система RPM (Red Hat Package Manager)

| Инструменты | Назначение |
| :--- | :--- |
| `rpm-build`, `rpmdevtools` | Базовые инструменты для создания RPM-пакетов. |
| `mock` | Создание чистого окружения для сборки (аналог `pbuilder`). |
| `rpmlint` | Утилита для проверки RPM-пакетов на наличие ошибок и соответствие стандартам. |

### Архитектура управляющих файлов

#### Структура директории debian

Директория `debian/` является сердцем исходного пакета DEB:

- `changelog` — история изменений и текущая версия пакета.
- `control` — метаданные, описание и зависимости.
- `rules` — сценарий сборки (на базе Makefile).
- `copyright` — информация о лицензировании.
- `patches/` — набор патчей, управляемых через `quilt`.

#### Структура Spec-файла (RPM)

Файл `.spec` определяет все аспекты жизненного цикла пакета RPM:

- **Метаданные**: `Name`, `Version`, `Release`, `Summary`, `License`.
- **Зависимости**: `BuildRequires` (для сборки) и `Requires` (для работы).
- **Секции**:
  - `%prep` — распаковка и подготовка исходников.
  - `%build` — компиляция кода.
  - `%install` — установка файлов в фиктивный корень сборки.
  - `%files` — список файлов, которые войдут в итоговый пакет.
  - `%changelog` — история изменений.
