# Сборка пакетов: Определения

## Определения

**Сборка пакета (Package Building)** — процесс преобразования исходного кода программы в бинарный пакет (`.deb` или `.rpm`) с использованием системы сборки дистрибутива.

**Исходный пакет (Source Package)** — архив, содержащий исходный код, патчи, метаданные и инструкции для сборки бинарного пакета. Форматы: `.dsc` + `.orig.tar.gz` + `.debian.tar.xz` (DEB), `.src.rpm` (RPM).

**Бинарный пакет (Binary Package)** — скомпилированный и упакованный файл программы, готовый к установке: `.deb` (DEB) или `.rpm` (RPM). Содержит исполняемые файлы, библиотеки, документацию и конфигурационные файлы.

**Спецификация (Spec File)** — файл `.spec`, описывающий метаданные, зависимости, инструкции сборки и установки для RPM-пакета. Включает секции `%prep`, `%build`, `%install`, `%files`.

**Debian Directory** — директория `debian/` в исходном коде, содержащая файлы управления для сборки DEB-пакета: `control`, `rules`, `changelog`, `copyright`, скрипты (`preinst`, `postinst`, `prerm`, `postrm`).

**Changelog** — файл истории изменений пакета, определяющий версию и описывающий изменения в каждой версии. Формат версии DEB: `upstream_version-debian_revision` (например, `1.2.3-4ubuntu5`).

**Чистое окружение (Clean Build Environment)** — изолированная среда для сборки, гарантирующая отсутствие скрытых зависимостей и воспроизводимость результатов. Инструменты: `pbuilder`, `sbuild`, `cowbuilder` (DEB); `mock` (RPM).

**Зависимости сборки (Build Dependencies)** — пакеты, необходимые для компиляции и сборки пакета. Указываются в `Build-Depends` (DEB, файл `debian/control`) или `BuildRequires` (RPM, spec-файл).

**Патч (Patch)** — файл с изменениями исходного кода, применяемый в процессе сборки. В DEB-системах управляется через `quilt` и хранится в `debian/patches/`. В RPM — указывается в spec-файле через директиву `PatchN:`.

**Воспроизводимость сборки (Reproducible Build)** — свойство сборки, при котором одинаковый исходный код всегда создаёт идентичные бинарные пакеты независимо от окружения и времени сборки.
