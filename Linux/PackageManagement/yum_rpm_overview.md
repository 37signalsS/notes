# YUM и RPM: Управление Пакетами в CentOS

## Обзор

В операционной системе CentOS для управления программным обеспечением используются пакетные менеджеры RPM и YUM. Они значительно упрощают установку, обновление и удаление программ, а также управление их зависимостями.

## RPM (Red Hat Package Manager)

RPM является низкоуровневым пакетным менеджером, используемым в дистрибутивах на базе Red Hat, включая CentOS.

*   **Функциональность:**
    *   Установка пакетов с локального диска.
    *   Просмотр информации об установленных пакетах.
    *   Удаление пакетов.
*   **Пример команды:**
    ```bash
    rpm -qa # Показывает список всех установленных пакетов
    # Пример подсчета всех пакетов:
    # rpm -qa | wc -l
    # (Например, 370 пакетов)
    ```
*   **Особенности:** Каждый пакет RPM представляет собой архив, содержащий исполняемые файлы и метаданные. Отслеживание версий и зависимостей вручную с помощью только RPM является сложной задачей, так как каждый пакет может включать множество файлов.

## YUM (Yellowdog Updater, Modified)

YUM — это высокоуровневый пакетный менеджер, который является надстройкой над RPM. Он предназначен для работы с репозиториями пакетов, автоматизируя разрешение зависимостей и упрощая процесс установки.

*   **Функциональность:**
    *   Установка пакетов из удаленных репозиториев.
    *   Автоматическое разрешение и установка зависимостей.
    *   Обновление системы и отдельных пакетов.
    *   Поиск пакетов.
*   **Пример команды:**
    ```bash
    yum install httpd # Устанавливает пакет Apache (httpd) и все его зависимости
    ```
*   **Взаимодействие с RPM:** YUM загружает необходимые пакеты из репозиториев и передает их RPM для непосредственной установки в систему.

## Пакеты и Репозитории

*   **Пакет:** По сути, это архив, который включает в себя исполняемый файл программы, а также метаданные и информацию о том, что ей необходимо для работы (зависимости).
*   **Репозиторий:** Хранилище пакетов, которое, как правило, содержит не только сами пакеты, но и все необходимые зависимости для них. Это позволяет пакетному менеджеру автоматически находить и устанавливать все компоненты, требуемые для корректной работы программы.

### Установка пакетов и зависимости

Установка программного обеспечения в Linux с использованием пакетных менеджеров значительно упрощена. Пакетный менеджер (например, `YUM` в CentOS) работает с репозиториями, которые содержат не только сами пакеты, но и все необходимые зависимости.

Когда вы даете команду на установку пакета, высокоуровневый менеджер (YUM/DNF) выполняет следующие действия:
1.  Анализирует метаданные запрашиваемого пакета, чтобы определить список его зависимостей (других пакетов, необходимых для его работы).
2.  Ищет эти зависимости в настроенных репозиториях.
3.  Составляет полный список пакетов для установки (основной пакет + все его зависимости).
4.  Показывает пользователю этот список, а также информацию об общем объеме загружаемых данных и дисковом пространстве, которое будет занято после установки.
5.  После подтверждения, загружает `.rpm` файлы и передает их низкоуровневому менеджеру `RPM` для непосредственной установки в систему.

**Пример установки Apache (пакет `httpd`) в CentOS:**

```bash
yum install httpd
```

При выполнении этой команды `YUM` автоматически определит, что пакет `httpd` требует дополнительные зависимости (например, `httpd-tools`). Он найдет их в репозитории и предложит установить все необходимые компоненты, указав общий размер загружаемых данных и объем, который будет занят на диске после установки. Например, в выводе будет указано: "я скачаю 2,8 мегабайта, а в итоге, когда я все это распакую, у вас на диске будет занято 9,5 мегабайт".

`YUM` выступает в роли высокоуровневой надстройки, которая взаимодействует с репозиториями, разрешает зависимости и затем передает пакеты низкоуровневому менеджеру `RPM` для непосредственной установки в систему.

Использование YUM и RPM обеспечивает простоту и надежность установки программного обеспечения в среде Linux, особенно в CentOS, за счет централизованного управления пакетами и автоматического разрешения зависимостей.
