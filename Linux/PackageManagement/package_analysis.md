# Анализ и получение пакетов в Linux

## Определения

Ниже приведены основные термины, используемые при исследовании структуры и содержимого программного обеспечения в дистрибутивах Linux.

**Анализ пакета** — процесс изучения метаданных, содержимого, зависимостей и скриптов пакета без его обязательной установки в систему.

**Виртуальный пакет (Virtual Package)** — имя, которое не соответствует физическому пакету, но «предоставляется» другими пакетами (например, пакет `mail-transport-agent` предоставляется через `postfix` или `exim4`).

**Возможность (Capability/Provides)** — в системе RPM это именованная функция или файл, который пакет предоставляет другим компонентам для разрешения зависимостей.

**Метаданные пакета** — структурированная информация о пакете: версия, зависимости, краткое и полное описание, сопровождающий (maintainer), размер и целевая архитектура процессора.

**Scriptlets (Скрипты пакета)** — вспомогательные сценарии, исполняемые менеджером пакетов на различных этапах жизненного цикла (до или после установки/удаления).

## Основные концепции

### Структура пакетов

#### DEB (Debian Package)

Архив формата `ar` (Unix archiver), содержащий три обязательных компонента:

- `debian-binary` — текстовый файл с версией формата пакета (обычно `2.0`).
- `control.tar.gz` — метаданные и управляющие скрипты. В современных дистрибутивах может использовать сжатие `.xz` или `.zstd`.
- `data.tar.gz` — основной архив с файлами. Современные стандарты (Debian 12+, Ubuntu 22.04+) часто используют `data.tar.zstd` для ускорения распаковки.

#### RPM (Red Hat Package Manager)

Бинарный файл, состоящий из четырех основных секций:

- **Lead** — устаревший заголовок для совместимости с `file`.
- **Подпись (Signature)** — криптографическая подпись GPG для подтверждения подлинности.
- **Заголовок (Header)** — содержит все метаданные: зависимости, версии, описания.
- **Тело (Payload)** — архив в формате `cpio`, сжатый `gzip`, `xz` или `zstd`.

### Жизненный цикл скриптов

| Скрипт | Выполняется | Назначение |
| :--- | :--- | :--- |
| `preinst` / `%pre` | Перед установкой | Проверка системных условий, создание необходимых пользователей. |
| `postinst` / `%post` | После установки | Регистрация сервисов в `systemd`, генерация сертификатов. |
| `prerm` / `%preun` | Перед удалением | Остановка активных демонов, сохранение критических данных. |
| `postrm` / `%postun` | После удаления | Очистка временных файлов, удаление символических ссылок. |

## Практические сценарии

### Получение файлов пакетов без установки

#### Системы на базе APT (Debian, Ubuntu)

```bash
# Скачать только файл пакета (.deb) в текущую директорию
apt-get download <package_name>

# Скачать пакет со всеми зависимостями в локальный кэш (/var/cache/apt/archives/)
# Полезно для подготовки офлайн-установки
apt-get install --download-only <package_name>

# Поиск пакета, которому принадлежит существующий файл в системе
dpkg -S /etc/nginx/nginx.conf
# → result: nginx-common: /etc/nginx/nginx.conf

# Поиск пакета по имени файла, даже если пакет не установлен (требует apt-file)
sudo apt-get update && sudo apt-get install apt-file && apt-file update
apt-file search bin/htop
```

#### Системы на базе DNF (RHEL, Fedora)

```bash
# Скачать RPM-файл без установки в текущую директорию
dnf download <package_name>

# Скачать пакет и его зависимости в указанную директорию
dnf install --downloadonly --destdir=/tmp/packages <package_name>

# Поиск пакета, предоставляющего конкретную возможность или файл
dnf provides /usr/sbin/nginx
dnf provides 'python3-module(requests)'
```

### Глубокий анализ зависимостей

#### Анализ в DEB-системах

```bash
# Анализ цепочки зависимостей (почему пакет нужен в системе)
# Доступно в APT 3.0+ (Debian Trixie, Ubuntu 24.10)
apt why <package_name>

# Для старых систем используйте aptitude
aptitude why <package_name>

# Рекурсивный список всех зависимостей (требует apt-rdepends)
apt-rdepends <package_name>
```

#### Анализ в RPM-системах

```bash
# Просмотр дерева зависимостей пакета в репозитории
dnf deplist <package_name>

# Мощный инструмент для запросов к репозиторию (repoquery)
# Показать пакеты, которые зависят от данного (reverse dependencies)
dnf repoquery --whoneeds <package_name>

# Показать, что именно предоставляет пакет (capabilities)
dnf repoquery --provides <package_name>
```

### Исследование метаданных и содержимого архивов

#### Инструментарий DEB (dpkg-deb)

```bash
# Просмотр метаданных (control файл) не установленного пакета
dpkg-deb --info <package_name.deb>

# Список всех файлов внутри архива
dpkg-deb --contents <package_name.deb>

# Просмотр всех метаданных установленного пакета
dpkg-query -s <package_name>

# Пользовательский формат вывода (например, только имя и версия)
dpkg-query -W -f='${Package} ${Version}\n' nginx
```

#### Инструментарий RPM (rpm)

```bash
# Информация из RPM-файла (p — package file)
rpm -qip <package_name.rpm>

# Список файлов внутри RPM-файла
rpm -qlp <package_name.rpm>

# Просмотр встроенных скриптов (scriptlets)
rpm -qp --scripts <package_name.rpm>

# Проверка того, какие файлы считаются конфигурационными
rpm -qcp <package_name.rpm>
```

### Ручная распаковка (Extraction)

```bash
# Распаковка DEB через dpkg-deb (извлекает файлы данных)
dpkg-deb -x <package_name.deb> ./output_dir

# Распаковка DEB вручную (извлечение всех tar-архивов)
ar x <package_name.deb>

# Распаковка RPM через связку с cpio
rpm2cpio <package_name.rpm> | cpio -idmv
```

### Проверка целостности (Integrity)

```bash
# DEB: Проверка контрольных сумм установленных файлов (требует debsums)
sudo debsums -s nginx
# → result: (пусто, если всё в порядке; список измененных файлов при ошибке)

# RPM: Встроенная мощная проверка всех атрибутов файлов (права, MD5, размер)
rpm -V <package_name>
# → result: S.5....T.  /etc/nginx/nginx.conf (S — размер, 5 — MD5, T — время изменены)
```

## Дополнительная информация

### Выбор инструмента: Низкий уровень vs Высокий уровень

| Уровень | Инструменты | Когда использовать |
| :--- | :--- | :--- |
| **Низкий** | `dpkg`, `rpm`, `dpkg-deb` | Работа с локальными файлами, диагностика базы данных, извлечение файлов. Не разрешают зависимости. |
| **Высокий** | `apt`, `dnf`, `apt-get` | Установка из репозиториев, автоматическое разрешение зависимостей, системное обновление. |

### Ресурсы для поиска пакетов онлайн

- **pkgs.org** — универсальный агрегатор пакетов для множества дистрибутивов.
- **Debian**: [packages.debian.org](https://packages.debian.org/)
- **Ubuntu**: [packages.ubuntu.com](https://packages.ubuntu.com/)
- **Fedora**: [packages.fedoraproject.org](https://packages.fedoraproject.org/)
