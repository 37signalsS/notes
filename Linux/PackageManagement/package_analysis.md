# Анализ файлов пакетов

## Практические сценарии

### DEB-based системы (`.deb`)

Структура `.deb` пакета включает: конфигурационные файлы, управляющую информацию (метаданные), контрольные суммы, постустановочные/предудаляющие/постудаляющие скрипты.

* **Метаданные из файла пакета:** `dpkg --info <package_name.deb>`
* **Содержимое файла пакета:** `dpkg --contents <package_name.deb>`
* **Метаданные установленного пакета:** `dpkg -s <package_name>`
* **Список файлов установленного пакета:** `dpkg -L <package_name>`

### RPM-based системы (`.rpm`)

* **Метаданные из файла пакета:** `rpm -qip <package_name.rpm>`
* **Содержимое файла пакета:** `rpm -qlp <package_name.rpm>`
* **Метаданные установленного пакета:** `rpm -qi <package_name>`
* **Список файлов установленного пакета:** `rpm -ql <package_name>`
* **Показать скрипты внутри пакета:** `rpm -qp --scripts <package_name.rpm>`
* **Показать все установленные пакеты:** `rpm -qa`

## Структура RPM-пакета

RPM-пакет — это архив, который распаковывается в корневую файловую систему при установке. Внутри содержится:
* Файлы программы (бинарные файлы, конфигурации, библиотеки)
* Скрипты, выполняемые при установке/удалении
* Метаданные (версия, зависимости, описание)

### Скрипты в пакете (scriptlets)

- `preinstall`: Выполняется перед установкой
- `postinstall`: Выполняется после установки
- `preuninstall`: Выполняется перед удалением
- `postuninstall`: Выполняется после удаления

## Информация об установленных пакетах

```bash
# Посмотреть все установленные пакеты
rpm -qa

# Информация об установленном пакете
rpm -qi <package_name>

# Список файлов в пакете
rpm -ql <package_name>

# К какому пакету принадлежит файл (уже установленный)
rpm -qf /path/to/file

# Скрипты внутри rpm-файла
rpm -qp --scripts package.rpm
```
