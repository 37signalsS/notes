# Приватный Apt-репозиторий с reprepro: Дополнительная информация

## Определения

**Управление GPG-ключами** — процессы создания, продления, отзыва и защиты ключей, используемых для криптографической подписи метаданных репозитория.

**Альтернативы reprepro** — инструменты для создания и управления APT-репозиториями с другими возможностями и архитектурой (aptly, debmirror, simple-repo).

## Основные понятия

### Управление ключами

GPG-ключи требуют периодического обслуживания для обеспечения безопасности репозитория.

**Проверка срока действия ключа:**

```bash
gpg --list-keys --with-colons | grep -E "^pub|^fpr"
```

**Продление срока действия ключа:**

```bash
gpg --edit-key ABCDEF1234567890
> expire
> save
```

**Отзыв ключа (при компрометации):**

```bash
gpg --gen-revoke ABCDEF1234567890
```

### Безопасность репозитория

1. **Хранение секретного ключа** — ограничьте доступ к `~/.gnupg/` (chmod 700)
2. **Отдельный ключ для репозитория** — не используйте личный ключ
3. **Регулярное обновление ключа** — смена каждые 2-3 года
4. **Мониторинг доступа** — отслеживание несанкционированных попыток доступа
5. **HTTPS для публикации** — защита трафика от MitM-атак

### Отладка и диагностика

| Команда | Назначение |
| :--- | :--- |
| `reprepro -V check` | Проверка конфигурации |
| `reprepro show <codename> <pkg>` | Информация о пакете |
| `reprepro list <codename>` | Все пакеты в дистрибутиве |
| `reprepro export <codename>` | Экспорт метаданных |
| `reprepro verify` | Проверка целостности репозитория |

## Практические сценарии

### Сценарий: Выбор инструмента для управления репозиторием

| Инструмент | Преимущества | Недостатки |
| :--- | :--- | :--- |
| **aptly** | Современный, REST API, снапшоты | Сложнее в настройке |
| **debmirror** | Зеркалирование существующих репо | Не для собственных пакетов |
| **simple-repo** | Минималистичный | Нет подписи, ограниченный функционал |

**Выбор:** `reprepro` подходит для большинства задач создания приватных репозиториев. `aptly` предпочтительнее при необходимости снапшотов и API.
