## Основные концепции

### Переменные окружения DNF

Переменные окружения позволяют изменять поведение пакетного менеджера DNF (Dandified YUM) без редактирования конфигурационных файлов.

| Переменная | Назначение |
| :--- | :--- |
| `DNF_CONF_FILE` | Переопределяет путь к основному файлу конфигурации (по умолчанию `/etc/dnf/dnf.conf`). |
| `DNF_PLUGIN_PATH` | Указывает дополнительные пути для поиска плагинов DNF. |
| `RELEASEVER` | Содержит версию дистрибутива, которая подставляется в переменные `$releasever` внутри файлов репозиториев (`.repo`). |

### Плагины DNF

Плагины расширяют возможности DNF, добавляя новые команды или изменяя процесс обработки транзакций. Большинство плагинов написаны на языке Python.

| Плагин | Назначение |
| :--- | :--- |
| `dnf-plugins-core` | Набор базовых плагинов, включающий `config-manager`, `needs-restarting`, `copr` и другие. |
| `dnf-plugin-versionlock` | Позволяет фиксировать (*замораживать*) конкретные версии пакетов, предотвращая их автоматическое обновление. |
| `dnf-plugin-post-transaction-actions` | Выполняет заданные действия (скрипты или команды) сразу после завершения транзакции. |
| `dnf-plugin-debuginfo-install` | Автоматизирует установку пакетов с отладочной информацией (`debuginfo`) для анализа сбоев. |

## Практические сценарии

### Блокировка версий пакетов (versionlock)

Для предотвращения нежелательного обновления критически важных компонентов (например, ядра или базы данных) используется плагин `versionlock`.

```bash
# Установка набора базовых плагинов
sudo dnf install dnf-plugins-core

# Блокировка текущей версии пакета
sudo dnf versionlock add <package_name>

# Просмотр списка заблокированных пакетов
sudo dnf versionlock list

# Удаление блокировки для конкретного пакета
sudo dnf versionlock delete <package_name>

# Снятие всех установленных блокировок
sudo dnf versionlock clear
```

### Сравнение синтаксиса DNF и YUM

DNF сохраняет высокую степень обратной совместимости с YUM (Yellowdog Updater, Modified), однако в некоторых командах синтаксис был изменён для обеспечения большей логичности.

| Операция | Команда YUM | Команда DNF | Примечание |
| :--- | :--- | :--- | :--- |
| **Установка** | `yum install` | `dnf install` | Полная совместимость. |
| **Обновление** | `yum update` | `dnf upgrade` | В DNF `update` является синонимом `upgrade`. |
| **Поиск файлов** | `yum provides` | `dnf provides` | Полная совместимость. |
| **Группы пакетов** | `yum groupinstall` | `dnf group install` | В DNF рекомендуется явное использование подкоманды `group`. |
| **Модульность** | — | `dnf module` | Новая функциональность, отсутствующая в классическом YUM. |
