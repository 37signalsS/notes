## Основные концепции

### Преимущества DNF перед YUM

Пакетный менеджер DNF (Dandified YUM) пришёл на смену YUM (Yellowdog Updater, Modified) в дистрибутивах Fedora 22 и RHEL 8 (Red Hat Enterprise Linux) благодаря ряду архитектурных улучшений:

- **Разрешение зависимостей** — использование современного алгоритма на базе библиотеки `libsolv`, обеспечивающего высокую скорость и точность.
- **Модульность** — поддержка параллельных версий ПО через механизмы Fedora Modularity и RHEL Application Streams.
- **Производительность** — оптимизированное потребление памяти и "ленивая" загрузка метаданных репозиториев.
- **История транзакций** — ведение детального журнала операций с возможностью безопасного отката (*rollback*) к предыдущим состояниям.
- **Расширяемость** — гибкая система плагинов на языке Python, позволяющая легко добавлять новые функции.

### Конфигурационные файлы

| Файл | Назначение |
| :--- | :--- |
| `/etc/dnf/dnf.conf` | Глобальные настройки пакетного менеджера. |
| `/etc/yum.repos.d/` | Настройки репозиториев (файлы с расширением `.repo`). |
| `/var/cache/dnf/` | Локальное хранилище скачанных метаданных и RPM-пакетов. |
| `/var/log/dnf.log*` | Журнал работы и ошибок выполнения команд. |
| `/var/log/dnf.history` | База данных истории транзакций. |

### Структура файла dnf.conf

Основная конфигурация разделена на секции. Секция `[main]` содержит общие параметры работы:

```ini
[main]
gpgcheck=1              # Проверка цифровых подписей GPG (GNU Privacy Guard)
installonly_limit=3     # Максимальное количество одновременно установленных версий ядра
clean_requirements_on_remove=true  # Автоматическое удаление зависимостей при удалении пакета
best=True               # Всегда пытаться установить последнюю доступную версию
skip_if_unavailable=False  # Остановка выполнения при недоступности одного из репозиториев
```
