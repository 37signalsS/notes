# DNF: Определения

## Определения

**DNF (Dandified YUM)** — современный высокоуровневый пакетный менеджер для RPM-based дистрибутивов (Fedora, RHEL 8+, CentOS, AlmaLinux, Rocky Linux). Написан на Python с использованием библиотек `libsolv` и `hawkey`. Является заменой устаревшего `yum`, сохраняя обратную совместимость (команда `yum` — символическая ссылка на `dnf`).

**Модуль (Module)** — механизм управления параллельными версиями ПО и их зависимостями (например, несколько версий Python, Node.js, PostgreSQL одновременно).

**Транзакция (Transaction)** — атомарная операция установки, удаления или обновления пакетов, которая может быть отменена или повторена.

**Репозиторий (Repository)** — удалённое или локальное хранилище RPM-пакетов с метаданными для разрешения зависимостей.

**Пакет (Package)** — базовая единица установки ПО в формате RPM, содержащая файлы, метаданные и зависимости.

**Зависимость (Dependency)** — другой пакет, необходимый для работы устанавливаемого пакета. Разрешается автоматически.

**Плагин (Plugin)** — расширение DNF на Python, добавляющее функциональность (блокировка версий, управление репозиториями, анализ).

**Stream** — версия ПО внутри модуля (например, `nodejs:18`, `nodejs:20`). Позволяет выбирать между параллельными версиями.

**Профиль (Profile)** — предопределённый набор пакетов внутри модуля для конкретной роли (например, `development`, `minimal`, `default`).

**GPG-ключ** — криптографический ключ для проверки подписей пакетов и репозиториев. Гарантирует целостность и аутентичность.

**AppStream** — репозиторий с приложениями и языковыми модулями, поддерживающий несколько версий ПО (введён в RHEL 8+).

**BaseOS** — репозиторий базовой системы с минимальным набором пакетов, обеспечивающих работу ОС.
