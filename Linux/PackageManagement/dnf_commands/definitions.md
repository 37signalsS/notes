# DNF: Определения

## Определения

Ниже приведены определения терминов, специфичных для пакетного менеджера DNF и дистрибутивов семейства Red Hat. Базовые понятия пакетного управления (пакет, зависимость, транзакция, репозиторий) описаны в **[общем обзоре пакетных менеджеров](../linux_package_management_overview.md)**.

**DNF (Dandified YUM)** — современный высокоуровневый пакетный менеджер для RPM-based дистрибутивов (Fedora, RHEL 8+, CentOS, AlmaLinux, Rocky Linux). Написан на Python с использованием библиотек `libsolv` и `hawkey`. Является заменой устаревшего `yum`, сохраняя обратную совместимость (команда `yum` — символическая ссылка на `dnf`).

**RPM (Red Hat Package Manager)** — формат пакетов и одноимённая низкоуровневая утилита для управления ими. Пакеты RPM содержат скомпилированные файлы, метаданные и инструкции для пакетного менеджера.

**Модуль (Module)** — механизм управления параллельными версиями ПО и их зависимостями в рамках одного репозитория. Позволяет устанавливать разные версии одного и того же приложения (например, PostgreSQL 12 и PostgreSQL 15) в одной системе, но не одновременно.

**Stream** — конкретная версия ПО внутри модуля (например, `nodejs:18`, `nodejs:20`). Пользователь может выбрать нужный stream для установки.

**Профиль (Profile)** — предопределённый набор пакетов внутри модуля, оптимизированный под конкретную задачу (например, `development`, `minimal`, `default`, `client`, `server`).

**GPG-ключ (GNU Privacy Guard)** — криптографический ключ, используемый для проверки цифровой подписи пакетов и метаданных репозитория. Гарантирует, что пакет не был изменён и получен из доверенного источника.

**AppStream** — репозиторий в дистрибутивах RHEL 8+ и их производных, содержащий приложения, языки программирования и инструменты, которые могут иметь несколько версий (через механизм модулей).

**BaseOS** — репозиторий, содержащий минимальный набор пакетов, необходимых для работы ядра и базовой операционной системы. Пакеты в BaseOS обеспечивают жизненный цикл ОС и имеют длительную поддержку.

**Плагин (Plugin)** — расширение DNF, написанное на Python, которое добавляет новую функциональность (например, `dnf-plugin-spacewalk` для интеграции с Red Hat Satellite или `dnf-plugin-versionlock` для фиксации версий пакетов).

## Основные концепции

### Модульность и AppStream

Механизм модулей решает проблему "стабильности против актуальности". Традиционные репозитории предлагают одну версию пакета на весь жизненный цикл дистрибутива. AppStream позволяет переключаться между разными версиями ПО без ожидания следующего релиза ОС.

### Транзакции и история

DNF рассматривает каждую операцию (установку, удаление, обновление) как атомарную транзакцию. Вся история операций сохраняется в базе данных, что позволяет просматривать прошлые действия и выполнять откат (*rollback*) изменений.
