# Управление репозиториями в Debian и Ubuntu (sources.list)

## Определения

Ниже приведены основные термины, используемые при настройке источников программного обеспечения в системах на базе DEB (Debian Package).

**APT-репозиторий** — сервер или локальный каталог, хранящий пакеты и метаданные в стандартизированной структуре. Позволяет системе APT (Advanced Package Tool) находить, устанавливать и обновлять программное обеспечение.

**sources.list** — основной конфигурационный файл (`/etc/apt/sources.list`) и файлы в директории `/etc/apt/sources.list.d/`, указывающие системе, по каким URL (Uniform Resource Locator) искать пакеты.

**GPG-ключ (GNU Privacy Guard)** — криптографический ключ для проверки цифровой подписи репозитория. Гарантирует подлинность пакетов и защиту от атак типа MitM (Man-in-the-Middle — «человек посередине»).

**Компонент репозитория** — логическая категория пакетов внутри дистрибутива, разделяющая программное обеспечение по типу лицензии и уровню официальной поддержки.

**PPA (Personal Package Archive)** — персональный архив пакетов, специализированный тип репозитория для дистрибутива Ubuntu, размещаемый на платформе Launchpad.

## Основные концепции

### Форматы файлов источников

#### Традиционный формат (One-line)

Записи в файлах с расширением `.list` представляют собой одну строку следующего вида:

```bash
<тип> [опции] <url> <дистрибутив> <компонент_1> <компонент_2> ...
```

#### Современный формат (DEB822)

Используется в Debian 12 (Bookworm) и выше, а также в Ubuntu 24.04 (Noble Numbat) и новее. Представляет собой структурированные блоки в файлах с расширением `.sources`:

```ini
Types: deb
URIs: https://packages.example.com/repo
Suites: stable
Components: main
Architectures: amd64
Signed-By: /etc/apt/keyrings/example.gpg
```

Начиная с версии APT 3.2, этот формат поддерживает расширенные поля фильтрации пакетов.

### Компоненты репозиториев

#### Debian

- **main** — полностью свободное программное обеспечение.
- **contrib** — свободное ПО, зависящее от несвободных компонентов.
- **non-free** — проприетарное программное обеспечение.
- **non-free-firmware** — несвободные прошивки для оборудования (выделены в отдельный компонент начиная с Debian 12).

#### Ubuntu

- **main** — свободное программное обеспечение, официально поддерживаемое компанией Canonical.
- **restricted** — проприетарные драйверы и компоненты.
- **universe** — свободное ПО, поддерживаемое сообществом.
- **multiverse** — несвободное программное обеспечение без официальной поддержки.

### Управление ключами GPG

Современные стандарты безопасности требуют хранения ключей в директории `/etc/apt/keyrings/` в бинарном формате и явной привязки ключа к конкретному репозиторию через опцию `signed-by`. Использование устаревшей команды `apt-key add` признано небезопасным и не рекомендуется.

## Практические сценарии

### Настройка стороннего репозитория (на примере Nginx)

1. **Импорт GPG-ключа**:

    ```bash
    sudo mkdir -p /etc/apt/keyrings
    curl -fsSL https://nginx.org/keys/nginx_signing.key | \
        sudo gpg --dearmor -o /etc/apt/keyrings/nginx-archive-keyring.gpg
    ```

2. **Добавление репозитория с привязкой к ключу**:

    ```bash
    echo "deb [signed-by=/etc/apt/keyrings/nginx-archive-keyring.gpg] \
        https://nginx.org/packages/ubuntu $(lsb_release -cs) nginx" | \
        sudo tee /etc/apt/sources.list.d/nginx.list
    ```

3. **Обновление и установка**:

    ```bash
    sudo apt update && sudo apt install nginx
    ```

### Использование PPA на Ubuntu

```bash
# Добавление репозитория через специализированную утилиту
sudo add-apt-repository ppa:ondrej/nginx
sudo apt update && sudo apt install nginx
```

### Настройка локального зеркала

Для работы во внутренней сети или в изолированных контурах используется локальное зеркало. Подробные инструкции по настройке серверной части приведены в документе **[Зеркалирование APT](./apt_mirror/practical_scenarios.md)**.

## Дополнительная информация

### Диагностика источников через `apt policy`

Команда позволяет просмотреть приоритеты репозиториев и доступные версии пакетов:

```bash
# Показать информацию о приоритетах и версиях для конкретного пакета
apt policy <имя_пакета>

# Просмотреть общий список подключенных репозиториев и их приоритеты
apt policy
```

### Безопасность и рекомендации

- Всегда используйте протокол **HTTPS** (Hypertext Transfer Protocol Secure) для доступа к репозиториям.
- Избегайте добавления непроверенных сторонних источников в производственные системы.
- Для управления приоритетами и предотвращения конфликтов версий используйте механизм **[Apt Pinning](./deb_apt_pinning.md)**.
