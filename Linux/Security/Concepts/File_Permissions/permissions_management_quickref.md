# Управление правами файлов: Краткая справка

## Определения

**Управление правами** — практическая деятельность по настройке доступа к ресурсам файловой системы с использованием стандартных и расширенных механизмов Linux.

**Umask (User File-Creation Mask)** — маска, определяющая права доступа, которые **не будут** установлены для новых файлов и директорий в текущей сессии.

## Базовые концепции

### Правила изменения прав

| Действие | Кто может | Команда |
| :--- | :--- | :--- |
| Изменить права (`chmod`) | Владелец файла или `root` | `chmod` |
| Сменить владельца (`chown`) | Только `root` | `chown` |
| Сменить группу (`chgrp`) | Владелец (если состоит в группе) или `root` | `chgrp`, `chown` |

Теоретические основы моделей доступа (DAC/MAC) и их ограничения описаны в [обзоре прав доступа](./overview_definitions.md).

## Практические сценарии

### Просмотр прав и метаданных

```bash
# Базовая информация (права, владелец, группа, размер)
ls -l <file>

# Информация с числовыми UID/GID
ls -ln <file>

# Полная метаинформация из inode (atime, mtime, cime, ссылки)
stat <file>
```

### Изменение прав (chmod)

```bash
# Символьный режим (u - user, g - group, o - others, a - all)
chmod u+x,go-w script.sh

# Числовой режим (r=4, w=2, x=1)
chmod 755 script.sh       # rwxr-xr-x
chmod 600 secret.txt      # rw-------

# Рекурсивное изменение (применять осторожно!)
chmod -R 755 /path/to/directory
```

### Смена владельца и группы (chown)

```bash
# Смена владельца
sudo chown alice file.txt

# Смена группы
sudo chgrp developers file.txt

# Владелец и группа одновременно
sudo chown alice:developers file.txt

# Владелец + его основная группа
sudo chown bob: file.txt

# Рекурсивная смена
sudo chown -R alice:developers /srv/app
```

### Настройка umask

При создании объектов ядро использует базовые права (`666` для файлов, `777` для директорий) и вычитает из них значение `umask`.

| Umask | Файлы | Директории | Сценарий |
| :--- | :--- | :--- | :--- |
| `0022` | `644` | `755` | Стандарт (владелец — всё, остальные — чтение) |
| `0027` | `640` | `750` | Групповой доступ, остальные исключены |
| `0077` | `600` | `700` | Приватный доступ (только владелец) |

```bash
# Текущее значение
umask

# Установка для текущей сессии
umask 0027

# Постоянная настройка (добавить в ~/.bashrc или /etc/login.defs)
# UMASK 027
```

### Специальные права

Краткие примеры установки. Подробная теория и безопасность: [специальные права доступа](./special_permissions.md).

```bash
# SUID: выполнение от имени владельца
chmod u+s /path/to/binary

# SGID: наследование группы (для директорий)
chmod g+s /path/to/shared_dir

# Sticky Bit: запрет удаления чужих файлов
chmod +t /path/to/tmp_dir
```

### ACL и Атрибуты

Краткие примеры. Подробно: [ACL, атрибуты и временные метки](./acl_immutable_timestamps.md).

```bash
# ACL: назначить права конкретному пользователю
setfacl -m u:alice:rw- file.txt

# Атрибуты: сделать файл неизменяемым (даже для root)
sudo chattr +i file.txt
```
