# Ограничения и Управление Правами Файлов в Linux

### 8. Ограничения стандартной модели прав (DAC)

* **Трудоемкость настройки:** Управление правами для большого количества пользователей и сложных сценариев становится громоздким и подверженным ошибкам.
* **Проблема распространения прав:** Пользователь, имеющий доступ на чтение файла, может скопировать его содержимое и передать кому угодно, обходя исходные ограничения. Система DAC не контролирует дальнейшее распространение информации.
* **Централизация на пользователе:** Права привязаны к пользователю. Если учетная запись пользователя скомпрометирована, злоумышленник получает доступ ко всем его ресурсам. Модели MAC, напротив, фокусируются на ограничении самих процессов.

## Практические сценарии

### 1. Просмотр прав и метаданных

* **Просмотр прав и владельца:**

    ```bash
    ls -l <file>
    ```

* **Просмотр с числовыми UID/GID:** Полезно, если имена не сопоставлены.

    ```bash
    ls -ln <file>
    ```

* **Просмотр расширенных атрибутов:**

    ```bash
    lsattr <file>
    ```

* **Просмотр ACL:**

    ```bash
    getfacl <file>
    ```

    Подробнее об ACL см. **[ACL, Атрибуты и Временные Метки Файлов](./acl_immutable_timestamps.md)**.

* **Просмотр всей метаинформации из inode:**

    ```bash
    stat <file>
    ```

### 2. Управление правами и владельцами

> **Кто может изменять:** Права (`chmod`) и владельцев (`chown`) может менять только **владелец** файла или **суперпользователь (root)**. Обычный пользователь **не может** сменить владельца своих файлов, даже если он является их владельцем.
>
> **Нюансы смены группы:** Сменить группу (`chgrp`) может владелец файла (если он состоит в этой группе) или root. Сменить владельца может только root.

* **Изменение прав (`chmod`):**

    ```bash
    # Символьный режим (u,g,o,a | +,-,= | r,w,x)
    chmod u+x,go-w script.sh

    # Числовой режим
    chmod 755 script.sh       # rwxr-xr-x
    chmod 600 secret.txt      # rw-------

    # Ключ -c (changes) выводит сообщение только при успешном изменении прав
    chmod -c 744 my_file.txt
    # Вывод: режим 'my_file.txt' из 0644 (rw-r--r--) изменен на 0744 (rwxr--r--)
    ```

* **Смена владельца и группы (`chown`, `chgrp`):**

    ```bash
    # Смена владельца (только root)
    sudo chown alice file.txt

    # Смена группы (владелец файла или root)
    sudo chgrp developers file.txt

    # Смена владельца и группы одновременно (только root)
    sudo chown alice:developers file.txt

    # Смена владельца и установка его основной группы (только root)
    sudo chown bob: file.txt # Владелец bob, группа - основная группа bob

    # Рекурсивная смена владельца и группы (только root)
    sudo chown -R alice:developers /srv/app
    ```

### 3. Управление `umask`

* **Просмотр текущей маски:**

    ```bash
    umask     # Восьмеричное представление (e.g., 0022)
    umask -S  # Символьное (u=rwx,g=rx,o=rx)
    ```

* **Установка маски для текущей сессии:**

    ```bash
    umask 0077
    ```

* **Постоянная настройка umask:**
  * **Для пользователя:** Добавить `umask 0077` в конец файла `~/.bashrc`.
  * **Глобально:** Изменить параметр `UMASK` в файле `/etc/login.defs`.

### 4. Управление специальными правами

* **Установка SUID:**

    ```bash
    chmod u+s /usr/bin/binary
    chmod 4755 /usr/bin/binary
    ```

* **Установка SGID (на директорию):**

    ```bash
    chmod g+s /shared/directory
    chmod 2775 /shared/directory
    ```

* **Установка Sticky Bit:**

    ```bash
    chmod +t /tmp/public_dir
    chmod 1777 /tmp/public_dir
    ```

### 5. Управление ACL

> Развёрнутая информация об ACL доступна в файле **[ACL, Атрибуты и Временные Метки Файлов](./acl_immutable_timestamps.md)**.

Краткая справка:

* **Добавить/изменить правило (`-m`):**

    ```bash
    setfacl -m u:alice:rw- /path/to/file
    setfacl -m g:testers:r-- /path/to/file
    ```

* **Удалить правило (`-x`):**

    ```bash
    setfacl -x u:alice /path/to/file
    ```

* **Удалить все расширенные правила ACL (`-b`):**

    ```bash
    setfacl -b /path/to/file
    ```

* **Установить ACL по умолчанию для директории (`-d`):**

    ```bash
    # Все новые файлы в /shared получат эти права
    setfacl -m d:u:bob:rw-,d:g:project:rw- /shared
    ```

### 6. Управление атрибутами (`chattr`)

* **Установить флаг неизменяемости:**

    ```bash
    sudo chattr +i /etc/hosts
    sudo chattr +i -R /etc/critical_configs/
    ```

* **Снять флаг неизменяемости:**

    ```bash
    sudo chattr -i /etc/hosts
    ```
