# Дополнительная информация о правах доступа в Linux

## Дополнительная информация

* **Inode:** Вся метаинформация о файле, включая права доступа, хранится в его **inode**. Подробнее см. в [Inode (Индексный дескриптор)](../../../FileSystems/links_inodes_dentries.md#Inode-Индексный-дескриптор).
* **Пользователи и группы:** Система прав тесно связана с концепцией пользователей и групп. См. [Управление пользователями и группами](../../../SystemAdministration/users_management.md).
* **Копирование:** Утилита `cp` по умолчанию создает файлы с правами, определенными `umask`. Чтобы сохранить исходные права и атрибуты, используйте флаг `cp -p` или `cp -a`.
