# ACL, Атрибуты и Временные Метки Файлов в Linux

## Определения

**Списки контроля доступа (ACL)** — расширенный механизм прав, который позволяет назначать разрешения для любого произвольного пользователя или группы, дополняя стандартную модель «владелец-группа-остальные».

**Атрибуты файлов** — флаги на уровне файловой системы, управляющие поведением ядра при операциях с файлами. Ключевой атрибут безопасности — `immutable` (`i`).

**Временные метки** — метаинформация inode о времени событий файла (доступ, модификация, изменение статуса).

## Основные концепции

### Проверка поддержки ACL

Перед использованием ACL необходимо убедиться, что файловая система поддерживает и имеет включенную поддержку ACL:

```bash
# Проверка монтирования с опцией acl
mount | grep acl

# Если ACL не включен — перемонтировать с поддержкой
mount -o remount,acl /home
```

> **Примечание:** Современные файловые системы (ext4, xfs) часто имеют ACL включенными по умолчанию.

### Списки контроля доступа (ACL)

ACL — это расширенный механизм прав, который позволяет назначать разрешения для любого пользователя или группы, дополняя стандартные права. Если для файла установлены расширенные права, в выводе `ls -l` появится знак `+`.

* **ACL по умолчанию (Default ACL):** Особая возможность ACL для директорий. Все новые файлы и поддиректории, созданные внутри неё, будут автоматически наследовать эти права.
* **Маска (Mask):** Маска в ACL определяет **максимально возможные права** для всех именованных пользователей и групп. Она работает как ограничитель. Например, если пользователю `alice` даны права `rw-`, а маска `r--`, то эффективные права `alice` будут только `r--`.

#### Пример вывода getfacl

```bash
getfacl myfile.txt
# file: myfile.txt
# owner: user1
# group: users
user::rw-
user:john:r--
group::r--
mask::r--
other::---
```

### Атрибут неизменяемости (`immutable`)

Файл или директория с флагом `i` становятся "неприкосновенными". Их нельзя удалить, переименовать, изменить или создавать на них жёсткие ссылки. Даже пользователь `root` не сможет выполнить эти действия, пока флаг не будет снят.

**Управление атрибутами (`chattr`, `lsattr`):**

| Команда | Описание | Пример |
| :--- | :--- | :--- |
| `chattr +i <файл>` | Установить флаг immutable | `chattr +i /etc/passwd` |
| `chattr -i <файл>` | Снять флаг immutable | `chattr -i /etc/passwd` |
| `lsattr <файл>` | Просмотр атрибутов | `lsattr /etc/passwd` |

**Распространённые атрибуты:**

| Атрибут | Название | Эффект |
| :--- | :--- | :--- |
| `i` | immutable | Запрет на изменение, удаление, переименование |
| `a` | append-only | Разрешено только дозаписывание в конец файла |
| `A` | noatime | Не обновлять `atime` при доступе |
| `d` | nodump | Исключить из резервного копирования (`dump`) |

**Сценарии применения:**

1. **Защита критических файлов:**
   ```bash
   # Защитить /etc/passwd от изменений
   sudo chattr +i /etc/passwd
   sudo chattr +i /etc/shadow
   
   # Проверка
   lsattr /etc/passwd  # ----i---------e----- /etc/passwd
   
   # Попытка изменения завершится ошибкой:
   echo "test" >> /etc/passwd
   # bash: /etc/passwd: Operation not permitted
   ```

2. **Защита логов от модификации:**
   ```bash
   # Разрешить только дозапись (защита от удаления записей)
   sudo chattr +a /var/log/auth.log
   ```

3. **Временное снятие защиты:**
   ```bash
   # Для легитимных изменений снять флаг
   sudo chattr -i /etc/passwd
   # Внести изменения...
   sudo chattr +i /etc/passwd
   ```

> **Предостережение:** Флаг `immutable` не является заменой правильного контроля доступа. Это дополнительный слой защиты. Не устанавливайте `+i` на файлы, которые должны регулярно изменяться (например, логи сервисов без атрибута `a`).

## Практические сценарии

### Управление ACL

> **Требования:** Для работы с ACL необходим пакет `acl` (`getfacl`, `setfacl`). Файловая система должна быть смонтирована с опцией `acl`.

#### Просмотр ACL

```bash
# Просмотр текущих ACL для файла или директории
getfacl myfile.txt
getfacl /path/to/directory
```

#### Добавление и изменение ACL-прав (setfacl)

```bash
# Разрешить пользователю john запись (rw) в файл
setfacl -m u:john:rw myfile.txt

# Разрешить группе developers выполнение (x)
setfacl -m g:developers:x myfile.txt

# Дать всем (other) полный доступ (rwx)
setfacl -m o::rwx myfile.txt

# Назначить по умолчанию права для всех новых файлов в папке
setfacl -d -m u:john:rwx project/
```

#### Удаление ACL-прав

```bash
# Удалить ACL для конкретного пользователя
setfacl -x u:john myfile.txt

# Очистить все ACL-права файла
setfacl -b myfile.txt
```

### Временные метки файла (`stat`)

Команда `stat` предоставляет подробную метаинформацию о файле из его inode.

* **`Access` (atime):** Время **последнего доступа** к файлу (чтения). В современных системах обновляется с задержкой (опция `relatime`) повышения производительности.
* **`Modify` (mtime):** Время **последней модификации содержимого** файла. Это та дата, которую показывает `ls -l`.
* **`Change` (ctime):** Время **последнего изменения метаданных** (статуса) файла: прав (`chmod`), владельца (`chown`), имени (`mv`). `ctime` обновляется всегда, когда меняется `mtime`.
* **`Birth`:** Время "рождения" файла. Поддерживается не всеми файловыми системами.
