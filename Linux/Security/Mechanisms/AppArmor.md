# AppArmor

**AppArmor** — это инструмент, который может помочь администраторам ограничить права пользователей, определив конкретные профили для пользователей и связанных с ними процессов. Он реализует систему принудительного контроля доступа (Mandatory Access Control, MAC) на основе путей к файлам.

Следуя шагам, описанным в статье, администраторы могут создавать профили AppArmor, анализировать их и вводить ограничения на разрешения пользователей. В конечном счете, внедрение этих методов приводит к созданию более безопасной и эффективной системы Linux.
