## Определения

**KASLR (Kernel Address Space Layout Randomization)** — это механизм безопасности ядра Linux, который при каждой загрузке системы размещает код самого ядра, его модули и ключевые структуры данных по случайным адресам в виртуальной памяти.

## Основные понятия

**Цель KASLR** — усложнить эксплуатацию уязвимостей ядра. Многие атаки, такие как **возвратно-ориентированное программирование (ROP)**, требуют знания точных адресов функций в памяти ядра. KASLR делает эти адреса непредсказуемыми: при каждой загрузке ядро выбирает случайное смещение, размещая свой код и данные по новому базовому адресу.

KASLR является прямым аналогом механизма **ASLR (Address Space Layout Randomization)**, но перенесенным с уровня пользовательских приложений на уровень ядра операционной системы.

**Ограничения и обход:** KASLR значительно повышает сложность атаки, но не устраняет уязвимости. Злоумышленники могут попытаться обойти KASLR, используя другие уязвимости, которые приводят к утечке информации (information leak) и позволяют вычислить базовое смещение.

## Практические сценарии

**1. Проверка статуса KASLR:**

*   **Сравнение адресов после перезагрузки (надежный метод):**
    1.  Посмотрите адрес символа ядра: `sudo cat /proc/kallsyms | grep 'T _stext'`
    2.  Перезагрузите систему.
    3.  Выполните ту же команду снова. Если адрес изменился, KASLR работает.
*   **Проверка параметров загрузки ядра:**
    Проверьте `/proc/cmdline`. Если присутствует `nokaslr`, механизм отключен. Отсутствие этого параметра обычно означает, что KASLR включен по умолчанию.

**2. Управление KASLR (через параметры загрузки):**
Осуществляется через параметры, передаваемые ядру при загрузке (в конфигурации GRUB).
*   **Отключение KASLR:** Добавьте параметр `nokaslr` к строке загрузки ядра (полезно для отладки).
*   **Принудительное включение KASLR:** Добавьте параметр `kaslr` (требуется редко, так как включен по умолчанию).

Для внесения изменений отредактируйте `/etc/default/grub`, добавив параметр в `GRUB_CMDLINE_LINUX_DEFAULT`, затем обновите конфигурацию GRUB (`sudo update-grub` или `sudo grub2-mkconfig`).

## Дополнительная информация

*   **Статус по умолчанию:** KASLR включен по умолчанию в большинстве современных дистрибутивов Linux (начиная примерно с ядра 3.14).
*   **Контекст:** KASLR является одним из ключевых механизмов защиты от эксплуатации уязвимостей, описанных в общем обзоре [механизмов безопасности Linux](../Linux_Security_Mechanisms_Overview.md).
