# Контроль прав доступа к файлам (FSTEC)

## Настройка прав на файлы учетных записей

Необходимо установить правильные права доступа на системные файлы, содержащие информацию о пользователях и группах. Подробнее о правах можно прочитать в [документе о правах доступа](../Concepts/File_Permissions/overview_definitions.md).

* **`/etc/passwd` и `/etc/group`**: Эти файлы должны быть доступны для чтения всем пользователям, но запись должна быть разрешена только для `root`.

  ```bash
  chmod 644 /etc/passwd
  chmod 644 /etc/group
  ```

* **`/etc/shadow`**: Этот файл содержит хэши паролей и должен быть доступен для чтения и записи только `root`, а также для чтения группе `shadow` (или `root`). Остальным пользователям доступ должен быть закрыт.

  ```bash
  chmod 640 /etc/shadow
  ```

## Контроль целостности и прав доступа к системным файлам

Для предотвращения несанкционированного изменения системных файлов и сервисов, необходимо строго контролировать права доступа.

### Ограничение прав для новых файлов (umask)

Подробную информацию о настройке `umask` для ограничения прав на создаваемые по умолчанию файлы см. в документе [о правах доступа](../Concepts/File_Permissions/overview_definitions.md#3-маска-прав-по-умолчанию-umask).

### Права на системные файлы и каталоги

* **Конфигурационные файлы**: Должны быть защищены от записи кем-либо, кроме `root`. Право на выполнение должно быть снято (`chmod 644`).
* **Исполняемые файлы и библиотеки**: Должны быть защищены от записи. Право на выполнение должно быть только у владельца (и, если необходимо, у группы), но не у всех подряд (`chmod 750`).

## Аудит и устранение небезопасных прав

### Поиск файлов с небезопасными правами

Регулярно проводите аудит системных каталогов на наличие файлов, которые имеют права на запись для группы или для всех.

```bash
# Поиск файлов, доступных для записи всем (world-writable)
find /etc /usr/sbin /usr/bin /sbin /bin -type f -perm -0002

# Поиск файлов, доступных для записи группе (group-writable)
find /etc /usr/sbin /usr/bin /sbin /bin -type f -perm -0020
```

### Устранение уязвимостей

При обнаружении файла с избыточными правами на запись, необходимо их удалить, особенно если у файла есть право на выполнение.

```bash
# Убрать права на запись и выполнение для группы и остальных
chmod go-wx /path/to/some-script
```

## Защита компонентов времени выполнения

Ключевые компоненты системы (стартовые скрипты, библиотеки, модули ядра) должны быть защищены от несанкционированного изменения, и их владельцем должен быть `root`.

* **Systemd units (`.service`)**: Рекомендуемые права: `644` (`rw-r--r--`).
* **SysVinit скрипты (`/etc/init.d/`)**: Рекомендуемые права: `750` (`rwxr-x---`).
* **Файлы библиотек (`.so`)**: Рекомендуемые права: `644` (`rw-r--r--`).
* **Модули ядра (`.ko`)**: Рекомендуемые права: `644` (`rw-r--r--`).

## Аудит SUID и GUID битов

Файлы с битами SUID/GUID выполняются с правами владельца/группы, что может быть опасно. Необходимо регулярно сканировать систему на наличие таких файлов и удалять бит у нелегитимных программ. Подробнее о SUID/GUID см. в [документе о правах доступа](../Concepts/File_Permissions/special_permissions.md).

### Поиск и обезвреживание

```bash
# Поиск файлов с битом SUID
find / -type f -perm -4000

# Поиск файлов с битом GUID
find / -type f -perm -2000

# Удаление SUID/GUID бита
chmod u-s /path/to/file
chmod g-s /path/to/file
```

**Важно:** Не удаляйте биты у стандартных системных утилит (`passwd`, `su`, `mount`), которые легитимно их используют.
