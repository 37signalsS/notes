# Конфигурация клиента SSH (`~/.ssh/config`)

Для удобства работы с часто используемыми SSH-соединениями можно настроить алиасы и параметры в файле `~/.ssh/config`. Это позволяет сократить длинные команды и автоматизировать подключение.

Файл `~/.ssh/config` имеет следующую структуру:

```ini
# Блок для конкретного хоста (алиаса)
Host work
  HostName spb-mx-i3.extrt.int.company.net
  User ivanov_i
  Port 2222
  IdentityFile ~/.ssh/id_work
  Compression yes

# Другой хост
Host home
  HostName myhome.dyndns.org
  User vasya
  PasswordAuthentication no
  IdentityFile ~/.ssh/id_rsa_home

# Настройки по умолчанию для всех хостов
Host *
  # Пользователь по умолчанию для всех подключений, если не указан явно для конкретного хоста.
  User root
  # Включает перенаправление X11. Полезно для запуска графических приложений на удаленном сервере.
  # Отключаем X11 forwarding, потому что это обычное текстовое подключение.
  ForwardX11 no
  # Отправляет "keep alive" сообщения каждые 60 секунд, чтобы соединение не разрывалось из-за бездействия.
  ServerAliveInterval 60
  # Включает сжатие данных, что может быть полезно для медленных соединений, уменьшая объем передаваемого трафика.
  Compression yes
  # Отключает все интерактивные запросы (пароли, подтверждение хостов), используеться только в связке с ssh-ключами.
  # Крайне полезно для скриптов и автоматизации.
  # При необходимости аутентификации, которая требует интерактива(ввод пароля), соединение просто завершится с ошибкой, а не "зависнет".
  BatchMode yes
  # Уровень логирования для клиента SSH. Полезно для отладки проблем с подключением.
  # Возможные значения: QUIET, FATAL, ERROR, INFO, VERBOSE, DEBUG, DEBUG1, DEBUG2, DEBUG3.
  # LogLevel INFO
```
> **Примечание:** Для простых алиасов можно также использовать файл `~/.bashrc` (например, `alias ssh_test='ssh -C -p 6022 user@host'`), но `~/.ssh/config` предоставляет гораздо более гибкие и мощные возможности для управления SSH-соединениями.

### Права доступа

Для корректной работы SSH-клиента и из соображений безопасности, директория `~/.ssh` и файлы внутри нее должны иметь строгие права доступа.
- Директория `~/.ssh` должна иметь права `700` (только владелец может читать, писать и исполнять).
- Файл конфигурации `~/.ssh/config` должен иметь права `600` (только владелец может читать и писать).
- Приватные ключи (например, `~/.ssh/id_ed25519`) должны иметь права `600`.

```bash
chmod 700 ~/.ssh
chmod 600 ~/.ssh/config
chmod 600 ~/.ssh/id_*
```
