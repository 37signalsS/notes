# Контроль доступа SSH

## Основные концепции

### Ограничение доступа пользователей

Рекомендуется использовать "белый список" (whitelist), явно разрешая доступ только определённым пользователям или группам.

- `AllowUsers user1 user2@host`: Разрешает вход только указанным пользователям. Можно ограничить доступ по IP или хосту.
- `AllowGroups sshusers`: Разрешает вход только пользователям, входящим в группу `sshusers`.

**Важно:** Директивы `Allow` имеют приоритет над `Deny`. Рекомендуется использовать только `AllowUsers` или `AllowGroups`, чтобы избежать путаницы.

### Ограничение доступа по IP-адресу с помощью [TCP Wrappers](../../Networking/ServicesAndTools/tcp_wrappers.md)

### Смена стандартного порта

- `Port 22`: По умолчанию SSH слушает порт `22`. **Настоятельно рекомендуется изменить стандартный порт** на нестандартный (например, `15134`, `2239`), чтобы уменьшить количество автоматизированных атак от ботов.
