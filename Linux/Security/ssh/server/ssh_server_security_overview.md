# Безопасность SSH-сервера (sshd)

## Определения

**Безопасность SSH-сервера** — это комплекс мер, направленных на защиту службы `sshd` (SSH daemon) от несанкционированного доступа, атак и других угроз. `sshd` является основной службой для удаленного управления системами на базе Linux, что делает её критически важной целью для злоумышленников. Правильная настройка `sshd` является фундаментальным аспектом обеспечения безопасности всей системы.
