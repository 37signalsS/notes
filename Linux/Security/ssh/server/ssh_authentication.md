# Методы аутентификации SSH

## Основные концепции

### Файл конфигурации `/etc/ssh/sshd_config`

Это главный файл, определяющий поведение SSH-сервера. Ниже приведены ключевые директивы безопасности, касающиеся аутентификации.

-   **Настройка методов аутентификации**
    -   `PasswordAuthentication no`: Отключает аутентификацию по паролю.
    -   **Запрет входа для `root`:**
        -   `PermitRootLogin no`: Полностью запрещает прямой вход от имени `root`. Это заставляет злоумышленника сначала получить доступ к учетной записи обычного пользователя, а затем повышать привилегии.
        -   `PermitRootLogin yes`: **(КРАЙНЕ НЕБЕЗОПАСНО!)** Разрешает прямой вход для `root` по паролю или ключу. **Настоятельно не рекомендуется для production-систем.** Использовать только в крайних случаях и только с аутентификацией по ключу, предварительно убедившись, что другой доступ к системе невозможен.
        -   `prohibit-password`: Альтернативный вариант, который разрешает вход `root` только по SSH-ключу. Менее безопасен, чем `no`.
    -   **Ограничение попыток входа:**
        -   `MaxAuthTries 3`: Уменьшает количество попыток аутентификации, что замедляет атаки перебора (brute-force).
    -   `PermitEmptyPasswords no`: Запрещает вход с пустыми паролями.
    -   `PubkeyAuthentication yes`: Убеждается, что аутентификация по ключам включена.
    -   `ChallengeResponseAuthentication no`: Отключает интерактивные методы аутентификации "вызов-ответ".
    -   `GSSAPIAuthentication no`, `KerberosAuthentication no`: Отключает аутентификацию через Kerberos/GSSAPI, если она не используется, для уменьшения векторов атак.

### Контроль прав доступа

Для безопасной работы SSH требует строгих прав на файлы и каталоги. Неправильные разрешения могут привести к отказу в аутентификации по ключу.

-   **Общее правило:** Конфиденциальные файлы (приватные ключи) должны быть доступны для чтения и записи только их владельцу (`600`), а содержащие их каталоги — только для просмотра и изменения владельцем (`700`).

| Путь                                  | Права | Владелец       | Описание                                                                                                                                                                                                           |
| ------------------------------------- | ----- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `~/.ssh` (на клиенте и сервере)       | `700` | Пользователь   | Каталог с конфигурацией и ключами.                                                                                                                                                                                 |
| `~/.ssh/authorized_keys` (на сервере) | `600` | Пользователь   | Файл с публичными ключами, которым разрешен доступ.                                                                                                                                                                |
| `~/.ssh/id_*` (на клиенте)            | `600` | Пользователь   | Приватные ключи пользователя. **Их утечка компрометирует доступ!**                                                                                                                                                   |
| `~/.ssh/id_*.pub` (на клиенте)        | `644` | Пользователь   | Публичные ключи, не содержат секретной информации.                                                                                                                                                                 |
| `~/.ssh/config` (на клиенте)          | `600` | Пользователь   | Файл конфигурации клиента SSH.                                                                                                                                                                                     |
| `/etc/ssh/ssh_host_*_key` (на сервере) | `600` | `root:root`    | Приватные ключи хоста.                                                                                                                                                                                             |
| `/etc/ssh/ssh_host_*_key.pub` (на сервере)|`644`| `root:root`    | Публичные ключи хоста.                                                                                                                                                                                             |

> **Важно:** Если права на `~/.ssh` или `~/.ssh/authorized_keys` слишком открыты (например, `775` или `664`), `sshd` отклонит аутентификацию по ключу, записав в лог ошибку, например: `Authentication refused: bad ownership or modes for directory /home/user/.ssh`.
