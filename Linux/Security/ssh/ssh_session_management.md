# Управление SSH-сессиями с помощью Screen и Tmux

При работе с удаленными серверами по SSH часто возникает проблема: если соединение прерывается, все запущенные в терминале процессы завершаются. Терминальные мультиплексоры, такие как `screen` и `tmux`, решают эту проблему, позволяя создавать персистентные сессии, которые продолжают работать в фоновом режиме даже после отключения от сервера.

## Screen

`screen` — это классический полноэкранный оконный менеджер, который позволяет запускать несколько виртуальных терминалов (сессий) внутри одного физического.

### Основные команды `screen`

*   **Запуск новой сессии:**
    ```bash
    screen
    ```
    Это создаст новую сессию `screen` и переключит вас в нее.

*   **Запуск именованной сессии:**
    ```bash
    screen -S my_session_name
    ```
    Полезно, если у вас несколько сессий, чтобы легче их идентифицировать.

*   **Отключение от сессии (`detach`):**
    Нажмите `Ctrl+A`, затем `D`.
    Ваша текущая SSH-сессия отключится от `screen`, но процессы внутри `screen` продолжат выполняться на удаленном сервере.

*   **Просмотр списка запущенных сессий:**
    ```bash
    screen -ls
    ```
    Вы увидите список всех активных `screen` сессий:
    ```
    There are screens on:
            12345.my_session_name   (Attached)
            67890.pts-0.hostname    (Detached)
    2 Sockets in /run/screen/S-user.
    ```

*   **Подключение к отключенной сессии (`attach`):**
    Если есть только одна отключенная сессия:
    ```bash
    screen -r
    ```
    Если есть несколько, используйте ID или имя:
    ```bash
    screen -r 67890             # по ID
    screen -r my_session_name   # по имени
    ```

*   **Завершение сессии:**
    Находясь внутри сессии `screen`, наберите `exit` или нажмите `Ctrl+D`. Если это последний терминал в сессии, `screen` завершится.
    Чтобы "убить" сессию извне:
    ```bash
    screen -X -S 67890 quit             # Завершить сессию по ID
    screen -X -S my_session_name quit   # Завершить сессию по имени
    ```

### Преимущества `screen` при работе с SSH:

*   **Устойчивость к разрывам соединения:** Если ваше SSH-соединение прервется, процессы внутри `screen` продолжат работу. Вы можете переподключиться и восстановить сессию.
*   **Многозадачность:** Позволяет работать с несколькими командными строками на одном сервере, переключаясь между ними.
*   **Совместная работа:** Несколько пользователей могут подключиться к одной `screen` сессии (в режиме `multiuser`) для демонстраций или совместной отладки.
