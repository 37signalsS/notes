# Управление персистентными сессиями SSH

## Определения

**Терминальный мультиплексор** — это программа, которая позволяет создавать и управлять несколькими независимыми терминальными сессиями в рамках одного окна или одного SSH-соединения. Она выступает в роли "оконного менеджера" для командной строки.

**Персистентная сессия (Persistent Session)** — это терминальная сессия, которая продолжает выполняться на сервере даже после того, как клиент (пользователь) отключился от неё. Это позволяет сохранять запущенные процессы и состояние работы при разрывах сетевого соединения. `screen` и `tmux` являются основными инструментами для создания таких сессий.

## Основные концепции

### Проблема разрыва SSH-соединения

При стандартном SSH-подключении все процессы, запущенные в командной строке, являются дочерними по отношению к процессу SSH-сессии. Если соединение прерывается (из-за проблем с сетью, закрытия ноутбука или таймаута), родительский процесс уничтожается, что, в свою очередь, приводит к завершению всех запущенных в нём задач (например, долгого копирования файлов, сборки проекта или работы скрипта).

### Решение с помощью мультиплексоров

Терминальные мультиплексоры, такие как `screen` и `tmux`, решают эту проблему, создавая сессию, которая работает на сервере независимо от SSH-подключения.

1. Вы подключаетесь к серверу по SSH.
2. Внутри SSH-сессии вы запускаете мультиплексор (`screen` или `tmux`), который создает новую, отдельную сессию прямо на сервере.
3. Все команды вы выполняете уже *внутри* этой сессии мультиплексора.
4. Вы можете "отключиться" (`detach`) от сессии мультиплексора, оставив её работать в фоновом режиме, и закрыть SSH-соединение.
5. Позже вы можете снова подключиться к серверу по SSH и "присоединиться" (`attach`) к ранее созданной сессии, чтобы продолжить работу с того же места, где остановились.

## Практические сценарии

### Использование `GNU Screen`

* **Запуск новой именованной сессии:**

    ```bash
    screen -S my_session_name
    ```

* **Отключение от текущей сессии (`detach`):**
    Нажмите `Ctrl+A`, а затем `D`.
* **Просмотр списка запущенных сессий:**

    ```bash
    screen -ls
    ```

    ```
    There are screens on:
            12345.my_session_name   (Detached)
    1 Socket in /run/screen/S-user.
    ```

* **Подключение к отключенной сессии (`attach`):**

    ```bash
    # Если сессия одна, можно просто выполнить:
    screen -r
    # Или указать имя/ID:
    screen -r my_session_name
    ```

* **Завершение сессии:**
    Находясь внутри сессии, выполните команду `exit`. Если это был последний открытый терминал в сессии, она завершится.
    Для принудительного завершения сессии извне:

    ```bash
    screen -X -S my_session_name quit
    ```

### Использование `tmux`

`tmux` — более современный и гибкий терминальный мультиплексор, ставший стандартом для многих разработчиков и системных администраторов. Он предлагает такие функции, как вертикальное разделение панелей, лучшую скриптуемость и более интуитивное управление.

**Базовые команды tmux:**

```bash
# Запуск новой сессии с именем
tmux new -s my_session

# Отключение от сессии (detach)
# Нажмите Ctrl+B, затем D

# Просмотр списка сессий
tmux ls

# Подключение к существующей сессии (attach)
tmux attach -t my_session

# Завершение сессии изнутри
exit
```
