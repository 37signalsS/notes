# SSH (Secure Shell): Обзор

## Определения

**SSH (Secure Shell)** — это сетевой протокол прикладного уровня, предназначенный для безопасного удалённого управления операционной системой и туннелирования TCP-соединений. В отличие от небезопасных протоколов вроде Telnet, SSH шифрует весь трафик, включая пароли, что обеспечивает конфиденциальность и целостность данных при их передаче по незащищенным сетям. Для надежной доставки данных протокол использует TCP на транспортном уровне.

## Основные концепции

Ключевой аспект работы SSH — это процесс установки безопасного соединения (handshake), который происходит в несколько этапов:

1.  **Установка TCP-соединения:** Клиент инициирует TCP-соединение с сервером на указанный порт (по умолчанию 22).
2.  **Обмен версиями протокола:** Клиент и сервер сообщают друг другу поддерживаемые версии протокола SSH и выбирают общую для взаимодействия.
3.  **Согласование алгоритмов:** Стороны договариваются о наборе криптографических алгоритмов для:
    -   **Шифрования:** (например, AES-256-GCM, ChaCha20) для защиты данных.
    -   **Проверки целостности (MAC):** (например, HMAC-SHA2) для гарантии, что данные не были изменены в пути.
    -   **Ключевого обмена:** (например, Diffie-Hellman, ECDH, Curve25519) для безопасной генерации общего секрета.
    -   **Аутентификации хоста:** (например, RSA, ED25519) для проверки подлинности сервера.
4.  **Обмен ключами сессии и аутентификация хоста:** С помощью согласованного алгоритма обмена ключами генерируется общий секретный ключ сессии, который будет использоваться для шифрования всего дальнейшего трафика. На этом же этапе сервер предоставляет свой ключ хоста, чтобы клиент мог проверить его подлинность (обычно сверяя с записями в файле `~/.ssh/known_hosts`) и избежать атак "человек посередине" (man-in-the-middle).
5.  **Аутентификация пользователя:** После установки зашифрованного канала клиент должен доказать серверу свое право на доступ, используя один из согласованных методов, например, пароль или криптографический ключ.

## Практические сценарии

Протокол SSH обеспечивает надежную основу для множества операций. Для эффективной работы с ним рекомендуется изучить следующие аспекты, подробно описанные в отдельных заметках:
- **[Аутентификация](./ssh_authentication.md):** Понимание различных методов подтверждения личности, в первую очередь по ключам.
- **[Базовое использование и туннелирование](./ssh_usage_and_tunnels.md):** Выполнение команд, копирование файлов и создание защищенных каналов (проброс портов).
- **[Конфигурация клиента](./ssh_client_config.md):** Упрощение и автоматизация подключений через файл `~/.ssh/config`.
- **[Защита сервера](./ssh_server_security.md):** Настройка `sshd` для повышения безопасности.
