# Инструменты командной строки SSH

## Definitions

**SSH CLI tools** — набор утилит командной строки, использующих протокол SSH для безопасной передачи файлов, синхронизации данных и удалённого управления.

Основные инструменты:

- **`scp`** — разовое копирование файлов поверх SSH.
- **`rsync`** — инкрементальная синхронизация с передачей только дельт.
- **`sftp`** — интерактивный протокол управления файлами поверх SSH.
- **`sshfs`** — монтирование удалённой файловой системы локально через FUSE.

Дополнительные инструменты:

- **`mosh`** — устойчивый к нестабильным сетям терминальный доступ (UDP + SSH).
- **`lazyssh`** — TUI-менеджер для управления множеством SSH-подключений.
- **`xxh`** — запуск локальной оболочки на удалённом хосте через SSH.

## Basic Concepts

### Протоколы и механизмы

| Инструмент | Протокол | Транспорт | Основной сценарий |
| :--- | :--- | :--- | :--- |
| `scp` | SSH | TCP | Разовое копирование файлов |
| `rsync` | SSH / собственный | TCP | Синхронизация с дельтами |
| `sftp` | SSH | TCP | Интерактивное управление файлами |
| `sshfs` | SFTP + FUSE | TCP | Локальное монтирование удалённой ФС |
| `mosh` | SSP + SSH (аутентификация) | UDP | Терминальный доступ в нестабильных сетях |

### Принцип работы rsync

`rsync` экономит трафик за счёт передачи только изменённых блоков:

1. Разбивает файлы на блоки фиксированного размера.
2. Вычисляет контрольные суммы (rolling checksum + хэш) для каждого блока.
3. Сравнивает блоки источника и назначения.
4. Передаёт только отличающиеся блоки.

### Важность слеша в rsync

- `rsync source/ dest` — копирует **содержимое** директории `source` в `dest`.
- `rsync source dest` — копирует **саму директорию** `source` в `dest`.

### Принцип работы mosh

`mosh` использует SSH для начальной аутентификации, затем переключается на UDP-канал с протоколом SSP (State Synchronization Protocol):

1. Клиент подключается через SSH для аутентификации.
2. После успешной аутентификации `mosh` поднимает свой канал по UDP.
3. SSH-соединение закрывается, дальнейшая работа идёт через UDP.

**SSP** синхронизирует состояние экрана, а не передаёт байты. При потере пакетов промежуточные кадры пропускаются — аналогично видеостримингу. Каждый UDP-датаграмм шифруется AES-128-OCB3.

## Practical Scenarios

### scp — копирование файлов

```bash
# Копирование локального файла на удалённый сервер
scp /path/to/local/file.txt user@server:/remote/path/

# Рекурсивное копирование директории с нестандартным портом
scp -P 2222 -r /local/dir user@server:/remote/dir

# Копирование между двумя удалёнными серверами
scp user1@server1:/file.txt user2@server2:/dest/

# Копирование с сжатием для медленных сетей
scp -C -r /large_dir user@server:/path/

# Использование globbing на удалённой стороне
scp user@server:/remote/path/*.log /local/dir/
```

### rsync — синхронизация файлов

**rsync** — утилита для эффективной синхронизации файлов и каталогов. Главное преимущество перед `scp` — использование дельта-алгоритма (передача только изменений) и возможность зеркалирования директорий.

Подробное руководство, описание всех флагов и практические примеры: **[rsync — синхронизация файлов](../../SystemAdministration/rsync.md)**.

### sftp — интерактивная работа с файлами

```bash
# Подключение
sftp user@server

# Основные команды:
# ls, cd, pwd     — навигация
# get, put        — скачать/загрузить
# get -r, put -r  — рекурсивно для директорий
# mkdir, rmdir    — создать/удалить директорию
# rm              — удалить файл
# bye, quit       — выход
```

### sshfs — монтирование удалённой ФС

```bash
# Создать точку монтирования
mkdir ~/remote_server

# Смонтировать
sshfs user@server:/remote/path ~/remote_server

# Отмонтировать
fusermount -u ~/remote_server
```

### mosh — мобильная оболочка

```bash
# Установка (Debian/Ubuntu)
apt install mosh

# Подключение
mosh user@host

# С указанием порта SSH
mosh --port=2222 user@host
```

**Ограничения mosh:**

| Ограничение | Решение |
| :--- | :--- |
| Нет скроллбэка | Использовать `tmux` или `screen` внутри сессии |
| Нет port forwarding, agent forwarding, X11 | Для туннелей использовать SSH |
| Не работает через Tor (TCP-only) | Архитектурное ограничение |
| Только терминал, без передачи файлов | Использовать `scp`/`rsync` отдельно |

## Additional Information

### Сравнение инструментов

| Характеристика | `scp` | `sftp` | `rsync` |
| :--- | :--- | :--- | :--- |
| **Назначение** | Разовое копирование | Интерактивная работа с файлами | Синхронизация/инкрементальное копирование |
| **Delta-передача** | Нет | Нет | Да |
| **Удаление файлов** | Нет | Да (`rm`) | Да (`--delete`) |
| **Лучший сценарий** | Быстрое копирование небольших файлов | Навигация по удалённой ФС | Регулярные бэкапы, синхронизация больших директорий |

### lazyssh

TUI-менеджер для SSH с дашбордом мониторинга, быстрым подключением к серверам из списка и управлением сессиями через горячие клавиши. [GitHub](https://github.com/adembc/lazyssh).

### xxh

Позволяет запускать локально установленную оболочку (zsh, fish) на удалённом хосте через SSH без предварительной установки на сервере. [GitHub](https://github.com/xxh/xxh).
