# Инструменты командной строки SSH

## Передача файлов и работа с файловой системой

### `scp` (Secure Copy)

Простая утилита для копирования файлов.

```bash
# Копирование локального файла на сервер
scp /path/to/local/file.txt user@server:/remote/path/

# Рекурсивное копирование директории с нестандартным портом (-P)
scp -P 2222 -r /local/dir user@server:/remote/dir

# Копирование файла с локальной машины на удаленную с указанием нестандартного порта
scp -P 2239 /path/to/local/new_file.txt root@192.168.150.148:/root/

# Копирование файла с удаленной машины на локальную с указанием нестандартного порта
scp -P 2239 root@192.168.150.148:/root/one.txt /path/to/local/

# Копирование с уданую (челенной на удаленрез локальную машину)
scp user1@server1:/file.txt user2@server2:/dest/

# Копирование с сжатием (-C) для ускорения передачи по медленной сети
scp -C -r /large_dir user@server:/path/

# Использование globbing (шаблонов) на удаленной стороне
scp user@server:/remote/path/*.log /local/dir/
```

### `rsync` (Remote Sync)

Более мощная утилита для синхронизации. Передает только измененные части файлов, что эффективнее при повторных операциях.

```bash
# Синхронизация локальной директории с удаленной с сжатием и прогрессом
rsync -avz --progress /local/dir/ user@server:/remote/dir/

# Важные ключи:
# -a (--archive): архивный режим = -rlptgoD (рекурсивно, ссылки, права, время, группы, владельцы, устройства)
# -v (--verbose): подробный вывод
# -z (--compress): сжать данные перед передачей
# --progress: показать прогресс передачи
# --delete: удалить файлы в назначении, которых нет в источнике
# -n (--dry-run): тестовый прогресс без реальных изменений
```

**Важность слеша:**
- `rsync source/ dest` — копирует **содержимое** директории source в dest
- `rsync source dest` — копирует **саму директорию** source в dest

### `sftp` (SSH File Transfer Protocol)

Интерактивный протокол для работы с файлами поверх SSH. В отличие от FTP, работает на одном порту (22) и использует шифрование по умолчанию.

```bash
# Подключение к удаленному серверу
sftp user@server

# Основные команды в интерактивном режиме:
# ls, cd, pwd     # навигация
# get, put        # скачать/загрузить файл
# get -r, put -r  # рекурсивно для директорий
# mkdir, rmdir    # создать/удалить директорию
# rm              # удалить файл
# bye, quit       # выход
```

**Графические клиенты:**
- Linux: Nautilus (файловый менеджер) — подключение через `sftp://user@server`
- Windows: WinSCP, FileZilla

### Сравнение SCP, SFTP и RSYNC

| Характеристика | `scp` | `sftp` | `rsync` |
| :--- | :--- | :--- | :--- |
| **Назначение** | Разовое копирование | Интерактивная работа с файлами | Синхронизация/инкрементальное копирование |
| **Основной режим** | Командная строка | Интерактивный/командная строка | Командная строка |
| **ПередачаDelta** | Всегда копирует файл целиком | Всегда копирует файл целиком | Только изменения (дельты) |
| **Удаление файлов** | Нет | Нет | Да (`--delete`) |
| **Лучший сценарий** | Быстрое копирование небольших файлов | Навигация по удаленной ФС, управление файлами | Регулярные бэкапы, синхронизация больших директорий |

### `sshfs` (SSH File System)

Монтирует удаленную файловую систему локально, используя [FUSE](../../FileSystems/fuse.md), позволяя работать с файлами так, будто они находятся на вашем компьютере.

```bash
# Создать точку монтирования
mkdir ~/remote_server
# Смонтировать
sshfs user@server:/remote/path ~/remote_server
# Отмонтировать
fusermount -u ~/remote_server
```

### Сравнение `scp` и `rsync`

| Критерий | `scp` | `rsync` |
| :--- | :--- | :--- |
| **Простота** | Очень прост для базового копирования | Немного сложнее, больше опций |
| **Эффективность** | Всегда копирует файл целиком | Копирует только измененные блоки данных |
| **Возможности**| Только копирование | Синхронизация, исключение файлов, удаление |
| **Лучший сценарий** | Разовое копирование небольших файлов | Регулярная синхронизация, бэкапы, передача больших файлов |

## Интерактивные TUI-менеджеры

### `lazyssh`

**`lazyssh`** — это TUI (Text-based User Interface) менеджер для SSH, который предоставляет интерактивную оболочку для управления множеством серверов.

- **Ключевые возможности**:
  - Быстрое подключение к серверам из списка.
  - Дашборд для мониторинга статуса серверов.
  - Упрощенное управление файлами (копирование между клиентом и сервером).
  - Управление сессиями и навигация с помощью горячих клавиш.

- **[GitHub-репозиторий](https://github.com/adembc/lazyssh)

## Другие CLI инструменты

### `xxh` (eXecute SHell)

**`xxh`** — инструмент, позволяющий запускать локально установленную оболочку (shell) на удаленном хосте через SSH, без необходимости ее предварительной установки или конфигурации на удаленном сервере.

- **Ключевые возможности**:
  - Использование предпочитаемой локальной оболочки (например, zsh, fish) на любом удаленном сервере.
  - Сохранение привычной конфигурации и плагинов оболочки при работе на удаленных системах.
  - Упрощение кросс-системной работы без необходимости синхронизации настроек оболочки.

- **[GitHub-репозиторий](https://github.com/xxh/xxh)
