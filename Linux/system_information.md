## Версия ядра и операционной системы

```bash
uname -a
```

Альтернативный способ — посмотреть содержимое файла `/proc/version`:
```bash
cat /proc/version
```

## Определение дистрибутива Linux

Чтобы узнать, какой дистрибутив Linux используется, можно посмотреть содержимое специальных файлов в директории `/etc`.

-   **Основной способ (для современных систем):**
    ```sh
    cat /etc/os-release
    ```
    Этот файл содержит детальную информацию в формате `ключ=значение`, включая `NAME` (имя дистрибутива) и `VERSION` (версия).

-   **Альтернативные способы:**
    -   `cat /etc/lsb-release`: Используется в дистрибутивах, следующих стандарту LSB (Linux Standard Base), например, в Ubuntu.
    -   `cat /etc/redhat-release`: Для дистрибутивов на базе Red Hat (CentOS, Fedora).
    -   `cat /etc/debian_version`: Для Debian и его производных.

Узнать версию непосредственно установленного дистрибутива можно из конфигурационных файлов системы:
```bash
cat /etc/os-release
```
Либо через файл `/etc/issue`, который содержит системную информацию для сообщения при авторизации.

## Оборудование

На виртуальных серверах информация об оборудовании предоставляется гипервизором.

Краткую информацию об оборудовании можно посмотреть следующим образом (может потребоваться установка `apt-get install lshw`):

```bash
lshw -short
```

Просмотр данных процессора:
```bash
lscpu
```

Просмотр блочных устройств (диски и разделы):
```bash
lsblk -a
```

Если утилиты `lshw`, `lscpu`, `lsblk` недоступны, можно обратиться напрямую к файлам в директории `/proc`:

```bash
# Информация о процессоре
cat /proc/cpuinfo

# Информация о дисках
fdisk -l
```

Также можно использовать `dmidecode` для вывода информации о железе, зашитой в BIOS:

```bash
dmidecode -t system
```
