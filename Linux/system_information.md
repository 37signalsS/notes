## Версия ядра и операционной системы

```bash
uname -a
```

Альтернативный способ — посмотреть содержимое файла `/proc/version`:
```bash
cat /proc/version
```

Узнать версию непосредственно установленного дистрибутива можно из конфигурационных файлов системы:
```bash
cat /etc/os-release
```
Либо через файл `/etc/issue`, который содержит системную информацию для сообщения при авторизации.

## Оборудование

На виртуальных серверах информация об оборудовании предоставляется гипервизором.

Краткую информацию об оборудовании можно посмотреть следующим образом (может потребоваться установка `apt-get install lshw`):

```bash
lshw -short
```

Просмотр данных процессора:
```bash
lscpu
```

Просмотр блочных устройств (диски и разделы):
```bash
lsblk -a
```

Если утилиты `lshw`, `lscpu`, `lsblk` недоступны, можно обратиться напрямую к файлам в директории `/proc`:

```bash
# Информация о процессоре
cat /proc/cpuinfo

# Информация о дисках
fdisk -l
```

Также можно использовать `dmidecode` для вывода информации о железе, зашитой в BIOS:

```bash
dmidecode -t system
```

## Диагностика производительности системы

Для быстрой оценки состояния системы можно использовать следующие утилиты.

- `w`: Показывает время работы системы (uptime), список залогиненных пользователей и их текущие процессы. Комбинирует в себе `who`, `uptime` и `ps -a`.

- `iftop`: Утилита для мониторинга сетевой активности в реальном времени. Показывает использование сетевого интерфейса процессами. (Требует установки: `apt-get install iftop`)

- `atop`: Продвинутый монитор производительности, который отображает активность процессора, памяти, дисков и сети. Может вести запись для последующего анализа.
    - `atop -r`: Чтение и анализ ранее сохраненного отчета `atop`.
    - `atopsar -r`: Генерация отчета в стиле `sar` из файла данных `atop`.
