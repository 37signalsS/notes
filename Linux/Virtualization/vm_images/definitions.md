# Образы ВМ — Определения

В данном файле приведены определения ключевых терминов, связанных с образами виртуальных машин (ВМ), форматами дисков и механизмами управления хранилищем. Концепции организации и сравнение форматов представлены в [Образы ВМ — Основные концепции](./basic_concepts.md).

## Определения

**Образ ВМ (VM Image)** — файл или логическое устройство, содержащее полную копию операционной системы (ОС), конфигурационных файлов и данных приложений виртуальной машины.

**Дисковый образ (Disk Image)** — виртуальный жесткий диск ВМ, представленный в виде файла в файловой системе хоста. Примеры форматов: `raw`, `qcow2`, `vmdk`.

**Block Device Passthrough** — метод предоставления ВМ прямого доступа к физическому или логическому блочному устройству хоста (диск, раздел, LVM-том), минуя уровень файловой системы хоста для повышения производительности.

**Thin Provisioning** — технология «тонкого» выделения ресурсов, при которой дисковое пространство на физическом носителе резервируется только по мере фактической записи данных гостевой ОС.

**Разреженный файл (Sparse File)** — тип компьютерного файла, в котором последовательности нулевых байтов заменяются метаданными, что позволяет файлу занимать на диске меньше места, чем его номинальный размер.

**Снапшот (Snapshot)** — моментальный снимок состояния диска ВМ на определенный момент времени, позволяющий вернуться к сохраненной точке в случае сбоя или неудачного обновления.

**Copy-on-Write (CoW)** — стратегия оптимизации записи, при которой изменения вносятся не в основной образ, а в отдельный файл (дельта-диск). Чтение неизмененных данных происходит из базового образа.

**Базовый образ (Backing File)** — файл образа, используемый в качестве основы (только для чтения) для одного или нескольких зависимых дисков (снапшотов).

**Цепочка образов (Backing Chain)** — иерархическая структура файлов, где каждый последующий файл хранит только изменения относительно предыдущего (базовый образ → снапшот 1 → снапшот 2).

**Внутренний снапшот (Internal Snapshot)** — снимок состояния, который хранится внутри самого файла образа (характерно для формата `qcow2`).

**Внешний снапшот (External Snapshot)** — снимок, создаваемый как отдельный файл, использующий оригинальный образ в качестве `backing file`.

**Золотой образ (Golden Image)** — настроенный эталонный шаблон ОС с предустановленным ПО, используемый для быстрого развертывания множества идентичных виртуальных машин.

**OVF (Open Virtualization Format)** — открытый стандарт упаковки и распространения виртуальных машин, включающий дескриптор (XML), образы дисков и файлы метаданных.

**OVA (Open Virtualization Appliance)** — формат архива (обычно tar), объединяющий все компоненты OVF-пакета в один файл для удобства передачи.

**qemu-img** — универсальная CLI-утилита для создания, конвертации, изменения размера и проверки целостности образов дисков в средах QEMU/KVM.

**qemu-nbd** — инструмент для монтирования образов дисков (например, `qcow2`) к хостовой системе через сетевое блочное устройство (Network Block Device), позволяющий редактировать содержимое диска без запуска ВМ.

## Базовые концепции

Краткий обзор ключевых архитектурных решений. Подробности см. в [Основных концепциях](./basic_concepts.md).

### Сравнение подходов к хранению

- **Файловые образы:** Гибкость, портативность, поддержка снапшотов. Рекомендуется для большинства задач.
- **Passthrough:** Максимальная производительность I/O. Рекомендуется для высоконагруженных БД.

### Жизненный цикл снапшота

1. Создание точки восстановления перед опасной операцией.
2. Работа в режиме CoW (запись изменений в дельту).
3. Удаление снапшота (слияние данных с базой) или откат (удаление дельты).

## Практические сценарии

Примеры использования основных инструментов. Детальные инструкции в [Практических сценариях](./practical_scenarios.md).

### Проверка информации об образе

```bash
qemu-img info disk.qcow2
# → показывает формат, размер, использование на диске и цепочку backing file
```

### Монтирование образа для восстановления

```bash
# Подключение через nbd
sudo qemu-nbd --connect=/dev/nbd0 disk.qcow2
# → позволяет монтировать разделы диска ВМ в /mnt хоста
```
