## Определения

| Термин | Описание |
| :--- | :--- |
| **Образ ВМ (VM Image)** | Файл или блочное устройство с полной копией ОС, приложений и данных ВМ |
| **Гипервизор** | ПО для создания и управления ВМ (KVM, VMware, Hyper-V, VirtualBox), см. [Виртуализация overview](../virtualization_overview.md) |
| **Block Device Passthrough** | Проброс физического/логического блочного устройства хоста напрямую в ВМ, минуя файловую систему хоста |
| **Disk Image** | Виртуальный диск ВМ, хранящийся как файл в ФС хоста (raw, qcow2, vmdk, vhd, vdi) |
| **Thin Provisioning** | Стратегия выделения дискового пространства по факту записи, а не на полный заявленный размер |
| **Sparse File** | Разреженный файл — файл, в котором неинициализированные блоки не занимают место на диске |
| **Снапшот (Snapshot)** | Снимок состояния виртуального диска на определённый момент времени |
| **CoW (Copy-on-Write)** | Стратегия записи: данные считываются из базового образа, изменения пишутся в отдельный файл (delta-disk) |
| **Backing File** | Базовый образ, на который ссылается снапшот/дельта-диск для чтения неизменённых блоков |
| **Internal Snapshot** | Снапшот, хранящийся внутри того же файла образа (qcow2); требует выделения места в том же файле |
| **External Snapshot** | Снапшот в виде отдельного файла с цепочкой backing file; позволяет использовать базовый образ read-only |
| **Golden Image (Золотой образ)** | Базовый шаблонный образ ОС с предустановленным ПО, используемый для клонирования множества ВМ |
| **OVF (Open Virtualization Format)** | Открытый стандарт DMTF для упаковки ВМ: XML-дескриптор + диски + манифест целостности |
| **OVA (Open Virtualization Appliance)** | TAR-архив, содержащий OVF-пакет целиком (один файл для распространения) |
| **Backing Chain** | Цепочка образов: базовый образ → снапшот 1 → снапшот 2 → ... → активный диск ВМ |
| **Cluster Size (qcow2)** | Минимальный блок выделения данных в qcow2-образе; влияет на производительность и размер файла |
| **qemu-img** | Утилита управления образами QEMU: создание, конвертация, снапшоты, изменение размера |
| **qemu-nbd** | Утилита монтирования qcow2-образов через NBD (Network Block Device) для доступа к содержимому с хоста |
| **Live Snapshot** | Снапшот, созданный без остановки ВМ; требует поддержки гипервизором и гостевых агентных утилит |

> **Подробнее:** сравнение форматов, выбор стратегии хранилища, best practices снапшотов — в [basic_concepts.md](./basic_concepts.md).
