# Установка и предварительная настройка KVM

## Определения

**KVM (Kernel-based Virtual Machine)** — модуль ядра Linux, превращающий его в гипервизор 1-го типа. Подробнее: [KVM Overview](./overview.md).

**QEMU** — эмулятор, который в связке с KVM выполняет роль менеджера виртуальных машин. Подробнее: [KVM Architecture](./overview.md#архитектура-qemu--kvm).

**libvirt** — набор инструментов (API, демон `libvirtd`, утилиты `virsh`, `virt-install`) для управления виртуальными машинами. Подробнее: [KVM Management](./management.md).

## Базовые концепции

### Требования к системе

Перед установкой необходимо убедиться в соблюдении следующих условий:

| Требование | Описание | Проверка |
| :--- | :--- | :--- |
| **Аппаратная виртуализация** | Поддержка Intel VT-x или AMD-V процессором | `egrep -c '(vmx\|svm)' /proc/cpuinfo` |
| **Включена в BIOS/UEFI** | Функция виртуализации должна быть активирована | `sudo kvm-ok` |
| **Модули ядра** | `kvm_intel` или `kvm_amd` + `kvm` | `lsmod \| grep kvm` |
| **Права доступа** | Пользователь в группе `libvirt` | `groups $USER` |

### Компоненты стека KVM

Полноценная установка включает следующие пакеты:

| Пакет | Назначение |
| :--- | :--- |
| `qemu-kvm` | Основной пакет KVM (гипервизор) |
| `qemu` | Эмулятор устройств (диски, сеть, видео) |
| `libvirt-daemon` | Демон `libvirtd` для управления ВМ |
| `libvirt-clients` | Утилиты `virsh`, `virt-install` |
| `bridge-utils` | Управление сетевыми мостами |
| `virt-manager` | Графический интерфейс (опционально) |

### Сетевая инфраструктура

При установке KVM автоматически создаётся сетевой мост `virbr0` (NAT-режим). ВМ получают доступ к внешней сети через хост. Для прямого доступа ВМ к физической сети требуется настройка отдельного моста (`br0`). Подробнее: [Linux Networking](../../Networking/Concepts/linux_network_interfaces.md#bridge-мост).

## Практические сценарии

### Шаг 1: Проверка поддержки аппаратной виртуализации

**Способ 1 — через `/proc/cpuinfo`:**

```bash
egrep -c '(vmx|svm)' /proc/cpuinfo
```

Результат `> 0` означает поддержку виртуализации:

- `vmx` — Intel VT-x
- `svm` — AMD-V

**Способ 2 — через утилиту `kvm-ok` (рекомендуется):**

```bash
sudo apt install cpu-checker
sudo kvm-ok
```

Пример корректного вывода:

```
INFO: /dev/kvm exists
KVM acceleration can be used
```

Если виртуализация отключена в BIOS/UEFI, появится сообщение об ошибке.

### Шаг 2: Установка компонентов KVM

Установка полного стека для управления ВМ:

```bash
sudo apt install -y qemu qemu-kvm libvirt-daemon libvirt-clients bridge-utils virt-manager
```

**Примечание:** Для серверных установок без GUI пакет `virt-manager` можно исключить.

### Шаг 3: Настройка пользователя и служб

**Добавление пользователя в группу `libvirt`:**

```bash
sudo gpasswd -a $USER libvirt
```

**Важно:** После выполнения команды необходимо перелогиниться (или выполнить `newgrp libvirt`), чтобы изменения вступили в силу.

**Проверка и активация демона `libvirtd`:**

```bash
sudo systemctl status libvirtd
sudo systemctl enable --now libvirtd
```

Флаг `--now` запускает демон немедленно, без перезагрузки.

### Шаг 4: Проверка установки

**Проверка загрузки модулей ядра:**

```bash
lsmod | grep -i kvm
```

Ожидаемый вывод:

- `kvm_intel` (или `kvm_amd`)
- `kvm` (базовый модуль)

**Проверка сетевых интерфейсов:**

```bash
ip link
```

Должен присутствовать интерфейс `virbr0` — мост по умолчанию для NAT-сети.

**Проверка доступности libvirt:**

```bash
virsh list --all
```

Команда должна выполняться без ошибок (даже если список ВМ пуст).
