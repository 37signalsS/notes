# Вложенная виртуализация (Nested Virtualization)

**Вложенная виртуализация** — это функция, которая позволяет запускать гипервизор внутри виртуальной машины (ВМ). Иными словами, это возможность создавать виртуальные машины внутри других виртуальных машин.

### Иерархия уровней

-   **L0 (Level 0):** Физический хост (сервер или ПК). На этом уровне работает основной гипервизор (например, KVM, VMware ESXi, Hyper-V).
-   **L1 (Level 1):** Гостевая ВМ, запущенная на гипервизоре L0. Эта ВМ сама выступает в роли хоста и запускает собственный гипервизор.
-   **L2 (Level 2):** Вложенная ВМ, запущенная на гипервизоре, который работает внутри гостевой ВМ (L1).

```
+--------------------------------------------------+
| Физический хост (L0)                             |
| +----------------------------------------------+ |
| | Гипервизор L0 (например, KVM)                | |
| +----------------------------------------------+ |
| |                                              | |
| |  +-----------------------------------------+ | |
| |  | Гостевая ВМ (L1)                        | | |
| |  | +-------------------------------------+ | | |
| |  | | Гостевая ОС (L1) + Гипервизор L1    | | | |
| |  | +-------------------------------------+ | | |
| |  | |                                     | | | |
| |  | |  +--------------------------------+ | | | |
| |  | |  | Вложенная ВМ (L2)              | | | | |
| |  | |  | +----------------------------+ | | | | |
| |  | |  | | Гостевая ОС (L2)           | | | | | |
| |  | |  | +----------------------------+ | | | | |
| |  | |  +--------------------------------+ | | | |
| |  | +-------------------------------------+ | | |
| |  +-----------------------------------------+ | |
| +--------------------------------------------------+
```

### Требования

Для работы вложенной виртуализации необходима **аппаратная поддержка** со стороны центрального процессора (CPU) на физическом хосте (L0):

-   **Intel:** **VT-x** и **EPT (Extended Page Tables)**.
-   **AMD:** **AMD-V** и **RVI (Rapid Virtualization Indexing)**.

Эта функция должна быть включена в BIOS/UEFI физического хоста.

### Включение в KVM

Для включения вложенной виртуализации в KVM (наиболее распространенный гипервизор в Linux), необходимо включить соответствующую опцию в модуле ядра.

1.  **Проверка поддержки:**
    ```bash
    cat /sys/module/kvm_intel/parameters/nested
    # или для AMD
    cat /sys/module/kvm_amd/parameters/nested
    ```
    Если вывод `Y` или `1`, функция включена. Если `N` или `0` — выключена.

2.  **Включение (временное, до перезагрузки):**
    ```bash
    # Для Intel
    sudo modprobe -r kvm_intel
    sudo modprobe kvm_intel nested=1

    # Для AMD
    sudo modprobe -r kvm_amd
    sudo modprobe kvm_amd nested=1
    ```

3.  **Включение (постоянное):**
    Создайте файл `/etc/modprobe.d/kvm.conf` со следующим содержанием:
    ```
    # Для Intel
    options kvm_intel nested=1

    # Для AMD
    options kvm_amd nested=1
    ```
    После этого необходимо обновить initramfs и перезагрузиться.

### Сценарии использования

1.  **Разработка и тестирование:** Разработчики гипервизоров, облачных платформ (OpenStack, Kubernetes с KubeVirt) и ОС могут тестировать свои продукты без доступа к большому парку физических серверов.
2.  **Облачные вычисления:** Крупные облачные провайдеры (Google Cloud, AWS, Azure) используют вложенную виртуализацию, чтобы предоставить клиентам возможность запускать собственные ВМ с кастомными гипервизорами.
3.  **Безопасность (Sandbox):** Запуск недоверенного или потенциально вредоносного ПО в дополнительном слое изоляции (ВМ внутри ВМ).
4.  **Обучение и симуляция:** Создание сложных сетевых и системных лабораторных стендов на одном физическом компьютере.

### Ограничения и производительность

-   **Производительность:** Вложенная виртуализация несет дополнительные накладные расходы. Производительность L2-машины всегда будет ниже, чем L1, особенно в части операций ввода-вывода (I/O). Разница может достигать 10-30% и более в зависимости от нагрузки.
-   **Сложность:** Настройка и отладка многоуровневых виртуализированных сред сложнее.
-   **Ограничения Live-миграции:** Миграция вложенных ВМ (L2) может быть затруднена или не поддерживаться.
