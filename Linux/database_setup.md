## Установка MariaDB

*   **Ubuntu и Debian:**
    ```bash
    apt -y install mariadb-server mariadb-client
    ```
*   **CentOS:**
    ```bash
    yum -y install mariadb mariadb-server
    ```

```bash
systemctl status mariadb
```

### Начальная настройка безопасности

Для редактирования параметров безопасности запустите встроенный инструмент настройки:

```bash
mysql_secure_installation
```

C его помощью вы сможете отключить небезопасные опции. Рекомендуется подтвердить все параметры:

*   Новый пароль `root` для сервера баз данных.
*   Удаление анонимных пользователей.
*   Отключение удалённого доступа для пользователя `root`.
*   Удаление тестовой базы данных и доступов к ней.
*   Перезагрузка таблиц для применения новых параметров.

## Установка MySQL

    ```bash
    apt -y install mysql-server
    ```

    ```bash
    systemctl status mysqld
    ```

### Начальная настройка безопасности

Запустите автонастройку безопасности:

```bash
mysql_secure_installation
```

Список настраиваемых параметров по порядку:

*   Активация модуля проверки надёжности паролей.
*   Выбор уровня надёжности (0 — слабый / 1 — средний/ 2 — сильный).
*   Ввод и подтверждение нового пароля для `root`-пользователя MySQL.
*   Удаление анонимных пользователей.
*   Отключение удалённого подключения к БД для `root`-пользователя MySQL.
*   Удаление открытой тестовой базы данных.
*   Перезагрузка таблиц привилегий для применения новых настроек.

## Оптимизация производительности MySQL/MariaDB

### Анализ с помощью MySQLTuner

`mysqltuner` — это скрипт для анализа конфигурации и состояния MySQL/MariaDB, который предоставляет рекомендации по оптимизации.

**Установка:**
- **Debian/Ubuntu:** `sudo apt-get -y install mysqltuner`
- **CentOS:** `sudo yum -y install mysqltuner`

**Запуск:**
```bash
mysqltuner
# или с параметрами
mysqltuner --user root --pass YOUR_PASSWORD
```

Скрипт выведет отчет с секцией `Recommendations` и переменными для корректировки (`Variables to adjust`).

### Конфигурационный файл

Основной конфигурационный файл находится по пути `/etc/mysql/my.cnf` или `/etc/mysql/mariadb.conf.d/50-server.cnf`.

**Важно:** Перед внесением изменений всегда создавайте резервную копию конфигурационного файла.

После внесения изменений перезапустите службу:
```bash
sudo systemctl restart mysql.service # или mariadb.service
```

### Ключевые параметры для тюнинга

- `key_buffer_size`: Размер буфера для индексов таблиц MyISAM. Рекомендуется не более 25% системной памяти при использовании MyISAM.
- `max_allowed_packet`: Максимальный размер одного пакета. Увеличивайте, если работаете с большими `BLOB` полями.
- `thread_cache_size`: Количество потоков, которые сервер кэширует для переиспользования. Помогает при большом количестве новых подключений.
- `max_connections`: Максимальное количество одновременных подключений.
- `query_cache_size`: (Устарело в новых версиях) Размер кэша для запросов. Обычно не рекомендуется использовать и выставлять в `0`.

### Индексы

Индексы — ключевой инструмент для ускорения `SELECT` запросов.

**Синтаксис создания простого индекса:**
```sql
CREATE INDEX index_name ON table_name(column_name);
```

**Синтаксис создания составного индекса:**
```sql
CREATE INDEX index_name ON table_name(column1, column2);
```

**Кластерные индексы:** В InnoDB первичный ключ (`PRIMARY KEY`) является кластерным индексом. Это значит, что данные таблицы физически хранятся в порядке этого индекса, что обеспечивает очень быстрый доступ по первичному ключу.

### Смена движка таблицы

Для использования преимуществ InnoDB (транзакции, внешние ключи) можно изменить движок таблицы:

```sql
ALTER TABLE table_name ENGINE = InnoDB;
```
