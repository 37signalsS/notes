# Перенаправление ввода-вывода в Shell

## Определения

- **Перенаправление (Redirection)**: Механизм shell для изменения стандартных источников ввода и вывода команд.
- **Стандартные потоки (Standard Streams)**: Три потока данных, доступные каждой программе по умолчанию:
  - **`stdin` (стандартный ввод, дескриптор `0`)**: источник данных (по умолчанию — клавиатура).
  - **`stdout` (стандартный вывод, дескриптор `1`)**: основной результат (по умолчанию — терминал).
  - **`stderr` (стандартный вывод ошибок, дескриптор `2`)**: сообщения об ошибках (по умолчанию — терминал).
- **Файловый дескриптор (File Descriptor)**: Неотрицательное целое число, используемое ядром для идентификации открытого файла или потока.

---

## Базовые концепции

### Перенаправление `stdout`

- `команда > файл` — перезапись файла.
- `команда >> файл` — дописывание в конец файла.

```bash
ls -l > output.txt
echo "Новая строка" >> output.txt
```

### Перенаправление `stderr`

- `команда 2> файл` — перенаправление ошибок (дескриптор `2`).

```bash
ls /nonexistent 2> errors.log
```

### Объединение `stdout` и `stderr`

- `команда > файл 2>&1` — `stderr` туда же, куда `stdout`. Порядок важен.
- `команда &> файл` — современный эквивалент `> файл 2>&1`.

```bash
make &> build.log
```

### Перенаправление `stdin`

- `команда < файл` — чтение из файла вместо клавиатуры.

```bash
sort < names.txt
```

### `/dev/null`

Специальный файл, отбрасывающий все записанное. Используется для подавления вывода.

```bash
команда > /dev/null 2>&1
```

## Практические сценарии

### Фатальная ошибка: `grep "pattern" file > file`

Перенаправление (`>`) обрабатывается оболочкой **до** запуска команды:

1. Shell очищает `file`.
2. `grep` запускается — файл уже пуст.
3. **Результат: потеря данных.**

**Решения:**

- **Временный файл**:

  ```bash
  grep "pattern" a.txt > a.tmp && mv a.tmp a.txt
  ```

- **`sponge` (пакет `moreutils`)**:

  ```bash
  grep "pattern" a.txt | sponge a.txt
  ```

- **Утилиты с `-i` (редактирование на месте)**:

  ```bash
  sed -i '/pattern/!d' a.txt
  ```
