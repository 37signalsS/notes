# Конвейеры и операторы Shell

## Определения

- **Pipeline (Конвейер)** — механизм Shell для связывания нескольких команд, при котором стандартный поток вывода (`stdout`) одной команды передается непосредственно на стандартный поток ввода (`stdin`) следующей. Оператор: `|`.
- **Unix Philosophy (Философия Unix)** — подход к проектированию ПО, основанный на создании небольших программ, которые «делают одну вещь, но делают её хорошо» и могут эффективно взаимодействовать через текстовые потоки.
- **xargs** — утилита для преобразования данных из стандартного ввода в аргументы командной строки для других программ.

## Базовые концепции

### Принцип работы конвейера

1. Первая команда отправляет результат своей работы в поток `stdout`.
2. Оператор `|` перехватывает этот поток и перенаправляет его в `stdin` второй команды.
3. Важно помнить: каждая команда в конвейере выполняется в отдельном **дочернем процессе** (Subshell). Это означает, что изменения переменных окружения внутри конвейера не сохраняются в родительской оболочке.

Подробнее о процессах: [Логика обработки команд](./bash_command_execution.md#группировка-команд).

### Перенаправление потока ошибок: `|&`

Стандартный оператор `|` передает только `stdout`. В Bash 4+ доступен оператор `|&`, который передает и `stdout`, и `stderr` (эквивалент `2>&1 |`).

```bash
# Обычный конвейер не увидит ошибку в grep
cat non_existent.txt | grep "No such file"

# Конвейер с stderr обработает сообщение об ошибке
cat non_existent.txt |& grep "No such file"
```

### Инспектирование потока: `tee`

Утилита `tee` позволяет разветвить поток: данные записываются в один или несколько файлов и одновременно передаются дальше по конвейеру в `stdout`.

```bash
# Сохранить полный список процессов и отфильтровать только nginx
ps aux | tee all_processes.txt | grep "nginx"
```

## Практические сценарии

### Анализ использования дискового пространства

Поиск 10 самых объемных директорий в текущей папке:

```bash
du -sh * | sort -hr | head -n 10
```

### Поиск и удаление файлов через `xargs`

Безопасное удаление временных файлов (флаг `-print0` и `-0` предотвращают проблемы с именами, содержащими пробелы):

```bash
find . -name "*.tmp" -print0 | xargs -0 rm -f
```

### Массовая обработка пользователей

Получение списка имен всех пользователей системы и проверка их ID:

```bash
awk -F: '{print $1}' /etc/passwd | while read user; do id "$user"; done
```

## Дополнительная информация

### Выбор между конвейером и циклами

- Используйте **конвейеры** для быстрой трансформации текстовых данных (фильтрация, сортировка, подсчет).
- Используйте **циклы** (`while read`), если логика обработки требует выполнения сложных условий или нескольких команд для каждой строки.
