# Конвейеры (Pipelines)

## Определения

- **Конвейер (Pipeline)**: Механизм shell для связывания команд, при котором `stdout` одной команды передается на `stdin` следующей. Оператор: `|` (pipe).
- **Философия Unix**: Программы должны делать одно дело хорошо, работать вместе и использовать текстовые потоки как универсальный интерфейс.

---

## Базовые концепции

### Принцип работы

1. Команда отправляет результат на `stdout`.
2. `|` передает вывод на `stdin` следующей команды.
3. Каждая команда в конвейере выполняется в **отдельном subshell** — переменные не разделяются. Подробнее: [Группировка команд](bash_command_execution.md#группировка-команд--и--).

### Перенаправление `stdout` и `stderr` в конвейер: `|&`

- `|` — передает только `stdout`.
- `|&` (Bash 4+) — передает `stdout` и `stderr` (эквивалент `2>&1 |`).

```bash
cat non_existent_file.txt | grep "No such file"      # Вывода нет
cat non_existent_file.txt |& grep "No such file"     # Ошибка попала в grep
```

### Инспектирование конвейера: `tee`

`tee` читает `stdin` и записывает одновременно в `stdout` и файл.

```bash
ps aux | tee process_list.txt | grep "nginx"
ls -l | tee -a output.txt   # -a — дописывание
```

## Практические сценарии

### Подсчет запущенных процессов

```bash
ps aux | wc -l
```

### Анализ прав доступа

```bash
ls -l | grep -v '^total' | cut -c 2-10 | sort | uniq -c | sort -nr
```

**Разбор:**

1. `ls -l` → список файлов.
2. `grep -v '^total'` → убрать строку `total`.
3. `cut -c 2-10` → вырезать права (`rwxr-xr-x`).
4. `sort` → сортировка для `uniq`.
5. `uniq -c` → подсчёт повторов.
6. `sort -nr` → сортировка по убыванию.

### Получение информации о пользователях

```bash
awk -F: '{print $1}' /etc/passwd | while read user; do id "$user"; done
```

`awk` извлекает имена → `while read` построчно читает → `id` для каждого.

## Дополнительная информация

### Конвейеры и `xargs`

Команды вроде `rm`, `cp` не читают `stdin`. `xargs` преобразует поток в аргументы:

```bash
find . -name "*.tmp" | xargs rm
```
