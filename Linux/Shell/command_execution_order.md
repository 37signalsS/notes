# Порядок поиска и выполнения команд в Shell

### Определения

*   **Порядок выполнения команд** — это последовательность шагов, которые командная оболочка (shell) предпринимает для нахождения и запуска команды, введенной пользователем.
*   **Псевдоним (Alias)** — пользовательское короткое имя для более длинной или сложной команды.
*   **Встроенная команда (Built-in)** — команда, являющаяся частью самой оболочки, выполняемая без запуска отдельного процесса.
*   **Хеш-таблица (Hash table)** — внутренний кэш оболочки, хранящий пути к исполняемым файлам, которые были найдены ранее. Это ускоряет последующие вызовы тех же команд.
*   **Переменная `$PATH`** — переменная окружения, содержащая список директорий, в которых оболочка ищет исполняемые файлы.

### Основные концепции

Оболочка ищет команду в строго определенном порядке. Как только команда найдена, поиск прекращается, и команда выполняется.

1.  **Псевдонимы (Aliases):** Сначала проверяется, не является ли введенное имя псевдонимом.
2.  **Ключевые слова (Keywords):** Проверяется, не является ли команда ключевым словом оболочки (например, `if`, `for`, `while`).
3.  **Встроенные команды (Built-ins):** Далее проверяется, не является ли команда встроенной (`cd`, `echo`, `read`).
4.  **Хеш-таблица (Hash):** Оболочка проверяет свой кэш путей к командам.
5.  **Переменная `$PATH`:** Если команда до сих пор не найдена, оболочка последовательно перебирает директории из переменной `$PATH` в поисках исполняемого файла с таким именем.
6.  **Ошибка:** Если ни один из шагов не дал результата, выводится ошибка `command not found`.

### Практические сценарии

*   **Создание и использование псевдонима:**
    ```bash
    # Создаем псевдоним
    alias ll='ls -lha'
    # Теперь 'll' будет выполняться как 'ls -lha'
    ll
    ```

*   **Использование встроенной команды:**
    ```bash
    # Команда 'cd' встроена в оболочку и выполняется ей напрямую
    cd /tmp
    ```

*   **Поиск по `$PATH` и хеширование:**
    ```bash
    # Первый вызов 'htop'. Оболочка ищет его в директориях из $PATH
    htop
    # Второй вызов. Оболочка находит 'htop' в хеш-таблице, что быстрее
    htop
    # Посмотреть текущую хеш-таблицу
    hash
    ```

*   **Команда не найдена:**
    ```bash
    # Если ввести несуществующую команду
    nonexistentcommand
    # Вывод:
    # nonexistentcommand: command not found
    ```

### Дополнительная информация

Ключевое различие между **внутренними (встроенными)** и **внешними** командами заключается в том, что внутренние выполняются самой оболочкой, а для внешних создается новый дочерний процесс. Это делает встроенные команды более быстрыми и позволяет им изменять состояние самой оболочки (например, `cd` меняет текущую директорию). Внешние команды — это самостоятельные исполняемые файлы (например, `/bin/ls`).
