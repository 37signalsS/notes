# Консольные редакторы и утилиты

## Определения

- **TUI (Terminal User Interface)**: текстовый пользовательский интерфейс — интерактивные элементы (меню, списки, окна), работающие внутри терминала без использования графического сервера (X11/Wayland).
- **CLI Editor**: текстовый редактор, работающий непосредственно в командной строке (Vim, Nano).
- **Терминальный мультиплексор**: инструмент, позволяющий разделять одно окно терминала на несколько панелей и окон, а также сохранять сессии активными после отключения пользователя (например, Tmux).
- **Fuzzy Search (Нечеткий поиск)**: метод поиска, позволяющий находить результаты по частичным и неточным совпадениям (например, Fzf).

## Базовые концепции

### Текстовые редакторы

#### Vim / Neovim
Профессиональный модальный редактор. `Neovim` — современный форк с расширенными возможностями API и поддержкой Lua.

**Основные режимы:**
- **Normal**: навигация и команды (вход через `Esc`).
- **Insert**: ввод текста (вход через `i`).
- **Visual**: выделение текста (вход через `v`).
- **Command-Line**: выполнение команд (вход через `:`).

**Базовые команды (Normal mode):**
| Действие | Клавиши |
| :--- | :--- |
| Навигация | `h`, `j`, `k`, `l` (влево, вниз, вверх, вправо) |
| Поиск | `/шаблон` (вниз), `?шаблон` (вверх), `n` (далее) |
| Редактирование | `x` (удалить символ), `dd` (удалить строку), `u` (отмена) |
| Работа с файлом | `:w` (сохранить), `:q!` (выход без сохранения), `:wq` (сохранить и выйти) |

#### Nano
Простой редактор, подходящий для быстрых правок без обучения.
- `Ctrl + O`: Сохранить.
- `Ctrl + X`: Выход.
- `Ctrl + W`: Поиск.

### Современные инструменты (Rust-стек)

Эти утилиты являются более быстрыми и функциональными альтернативами стандартным командам GNU.

#### fzf (Fuzzy Finder)
Интерактивный фильтр для командной строки.
- Позволяет искать файлы, историю команд или процессы в реальном времени.
- Пример: `cat $(fzf)` — выбрать файл и вывести его содержимое.

#### bat (Улучшенный cat)
- Синтаксическая подсветка для сотен языков.
- Интеграция с Git (показывает изменения в строках).
- Автоматический пейджинг (использует `less`, если текст не помещается).

#### eza (Улучшенный ls)
- Отображение иконок и цветов.
- Встроенная поддержка Git (статус файлов в колонке).
- Режим дерева (`--tree`).

#### zoxide (Умный cd)
- Запоминает часто посещаемые директории.
- Команда `z path` позволяет мгновенно переместиться в нужную папку по части имени.

### Терминальные мультиплексоры

#### Tmux
Позволяет запускать фоновые сессии и разделять экран.
- **Префикс по умолчанию:** `Ctrl + B`.
- `Префикс, %` / `Префикс, "`: Разделить окно вертикально / горизонтально.
- `Префикс, D`: Отключиться от сессии (она продолжит работать).
- `tmux attach`: Вернуться в последнюю сессию.

Подробнее об управлении сессиями: [Управление сессиями SSH](../Security/ssh/ssh_session_management.md).

### Справочные утилиты

#### tldr
Упрощенные man-страницы с практическими примерами.
- Пример: `tldr docker` покажет 5-10 самых частых команд Docker.

#### cheat.sh (cht.sh)
Доступ к подсказкам по командам и языкам программирования через `curl`.
- Пример: `curl cht.sh/python/read+json` — пример чтения JSON на Python.

## Практические сценарии

### Безопасное редактирование системных файлов
Использование `sudo vim` является небезопасным (редактор получает полный root-доступ). Рекомендуется использовать `sudoedit`:
```bash
# Редактор открывается с правами пользователя, изменения применяются к системному файлу после сохранения
export SUDO_EDITOR=vim
sudoedit /etc/nginx/nginx.conf
```
Подробнее: [Управление привилегиями](../SystemAdministration/privilege_management.md).

### Быстрое удаление процесса через fzf
```bash
kill -9 $(ps -ef | fzf | awk '{print $2}')
```

### Редактирование длинной команды в Vim
Если команда в терминале стала слишком длинной, нажмите `Ctrl + X, Ctrl + E`. Текущая строка откроется в `$EDITOR`. После сохранения и закрытия редактора команда выполнится.

## Дополнительная информация

### Настройка переменных окружения
Для того чтобы программы знали, какой редактор использовать, добавьте в `~/.bashrc`:
```bash
export EDITOR='vim'
export VISUAL='vim'
```
