# Инструменты и горячие клавиши командной строки

## Определения

- **TUI (Terminal User Interface)**: Текстовый пользовательский интерфейс в терминале — интерактивные элементы (меню, списки) без графического сервера.
- **Горячие клавиши (Hotkeys)**: Сочетания клавиш для быстрого редактирования командной строки и управления процессами.

---

## Базовые концепции

### Vim (CLI Editor)

Стандартный редактор Unix-систем. Установлен по умолчанию (в отличие от nano).

#### Режимы

- **Normal** — навигация и команды. `Escape` возвращает в этот режим.
- **Insert** — ввод текста.
- **Command-Line** — команды (`:`, `/`, `!`).

#### Переход в Insert

| Клавиша | Действие |
| :--- | :--- |
| `i` | Ввод перед курсором |
| `I` | Ввод с начала строки |
| `a` | Ввод после курсора |
| `A` | Ввод с конца строки |
| `o` | Новая строка ниже |
| `O` | Новая строка выше |

#### Навигация (Normal)

| Клавиша | Действие |
| :--- | :--- |
| `h`, `j`, `k`, `l` | Влево, вниз, вверх, вправо |
| `w` / `b` | Начало следующего / предыдущего слова |
| `e` | Конец слова |
| `gg` / `G` | Начало / конец файла |

#### Редактирование (Normal)

| Клавиша | Действие |
| :--- | :--- |
| `x` | Удалить символ |
| `dd` | Удалить строку |
| `yy` | Копировать строку |
| `p` / `P` | Вставить после / перед курсором |
| `u` | Отменить действие |

#### Визуальный режим и поиск

| Клавиша | Действие |
| :--- | :--- |
| `v` / `V` | Выделение посимвольное / построчное |
| `/pattern` | Поиск вниз |
| `n` | Следующее вхождение |
| `:%s/old/new/g` | Заменить все вхождения |

#### Сохранение и выход (Command-Line)

| Клавиша | Действие |
| :--- | :--- |
| `:w` | Сохранить |
| `:q` | Выйти (без изменений) |
| `:q!` | Выйти без сохранения |
| `:wq` / `:x` | Сохранить и выйти |
| `ZZ` | Сохранить и выйти (из Normal) |

### Nano (CLI Editor)

`^` = **Ctrl**, `M` = **Meta** (Alt/Esc).

| Клавиша | Действие |
| :--- | :--- |
| `Ctrl+G` | Справка |
| `Ctrl+O` | Сохранить |
| `Ctrl+X` | Выйти |
| `Ctrl+W` | Поиск |
| `Alt+W` | Следующее вхождение |
| `Ctrl+K` / `Ctrl+U` | Вырезать / вставить строку |
| `Alt+U` | Отменить |
| `Ctrl+A` / `Ctrl+E` | Начало / конец строки |
| `Ctrl+←` / `Ctrl+→` | Предыдущее / следующее слово |

**Переход к строке:** `Ctrl+W` → `Ctrl+T` → номер строки.

**Нумерация строк постоянно:** добавить `set linenumbers` в `~/.nanorc`.

### cli-stash (TUI)

Утилита для сохранения и быстрого поиска shell-команд.

- **Интеграция с историей:** добавление команд из истории (`Ctrl+A`).
- **Нечеткий поиск:** поиск по частичным совпадениям.
- **Прямая вставка:** выбранная команда подставляется в приглашение терминала.

**Установка:**

```bash
go install github.com/itcaat/cli-stash@latest   # Go
brew install itcaat/tap/cli-stash               # macOS
```

**Использование:**

1. Запустить `cli-stash`.
2. `Ctrl+A` — поиск в истории.
3. Выбрать и сохранить в «избранное».

### Горячие клавиши Shell

#### Управление процессами

| Клавиша | Действие |
| :--- | :--- |
| `Ctrl+C` | Завершить процесс (SIGINT) |
| `Ctrl+Z` | Приостановить процесс (SIGTSTP) → `fg` для возврата |
| `Ctrl+D` | Закрыть оболочку (EOF) |
| `Ctrl+L` | Очистить экран (`clear`) |

#### Навигация по строке

| Клавиша | Действие |
| :--- | :--- |
| `Ctrl+A` / `Home` | Начало строки |
| `Ctrl+E` / `End` | Конец строки |
| `Alt+B` / `Ctrl+←` | Слово влево |
| `Alt+F` / `Ctrl+→` | Слово вправо |
| `Ctrl+B` / `Ctrl+F` | Символ влево / вправо |
| `Ctrl+XX` | Переключение между началом и курсором |

#### Редактирование

| Клавиша | Действие |
| :--- | :--- |
| `Ctrl+D` | Удалить символ под курсором |
| `Ctrl+W` | Вырезать слово перед курсором |
| `Ctrl+K` | Вырезать от курсора до конца |
| `Ctrl+U` | Вырезать от курсора до начала |
| `Ctrl+Y` | Вставить вырезанный текст |
| `Ctrl+T` | Поменять символы перед курсором |
| `Alt+T` | Поменять текущее и предыдущее слова |
| `Alt+U` / `Alt+L` | Верхний / нижний регистр до конца слова |
| `Alt+C` | Заглавная первая буква слова |
| `Ctrl+_` | Отменить действие |
| `Ctrl+X; Ctrl+E` | Открыть `$EDITOR` для редактирования команды |

#### История команд

| Клавиша | Действие |
| :--- | :--- |
| `Ctrl+P` / `↑` | Предыдущая команда |
| `Ctrl+N` / `↓` | Следующая команда |
| `Ctrl+R` | Поиск по истории (инкрементальный) |
| `Ctrl+O` | Запустить найденную команду и перейти к следующей |
| `Ctrl+G` | Выйти из поиска |
| `Alt+R` | Отменить изменения в команде из истории |

#### Прочее

- **`sudo !!`** — запустить последнюю команду с `sudo`.
- **Пробел перед командой** — не сохранять в истории Bash.

## Практические сценарии

### Быстрый запуск последней команды с sudo

```bash
$ systemctl restart nginx
Permission denied
$ sudo !!
sudo systemctl restart nginx
```

### Поиск по истории через Ctrl+R

`Ctrl+R` → ввод фрагмента команды → `Enter` для запуска, `Ctrl+O` для запуска и перехода к следующей, `Ctrl+G` для выхода.

### Редактирование сложной команды в редакторе

`Ctrl+X; Ctrl+E` открывает `$EDITOR` (vim/nano) с текущей командой для удобного редактирования многострочных конструкций.

### Скрытие команды из истории

```bash
export SECRET_KEY=my_secret  # пробел в начале — команда не попадёт в историю
```
