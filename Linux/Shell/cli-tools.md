# Консольные редакторы и утилиты

## Определения

- **TUI (Terminal User Interface)** — текстовый пользовательский интерфейс, использующий псевдографику для создания интерактивных элементов (меню, окон, списков) внутри терминала.
- **CLI Editor** — текстовый редактор, работающий непосредственно в командной оболочке (Vim, Nano).
- **Терминальный мультиплексор** — инструмент для управления несколькими терминальными сессиями в одном окне и сохранения их активности при отключении пользователя (Tmux, Screen).
- **Fuzzy Search (Нечеткий поиск)** — алгоритм поиска, позволяющий находить результаты по неполным или неточным совпадениям (Fzf).

## Базовые концепции

### Текстовые редакторы

#### Vim / Neovim
Модальный редактор с высокой степенью кастомизации. `Neovim` является современным форком с поддержкой Lua-плагинов и расширенным API.

**Основные режимы:**
- **Normal**: навигация и команды (переход через `Esc`).
- **Insert**: прямой ввод текста (переход через `i`).
- **Visual**: выделение блоков текста (переход через `v`).
- **Command-Line**: выполнение команд (переход через `:`).

**Базовые команды (режим Normal):**
| Действие | Клавиши |
| :--- | :--- |
| Навигация | `h`, `j`, `k`, `l` (влево, вниз, вверх, вправо) |
| Поиск | `/шаблон` (вниз), `?шаблон` (вверх), `n` (следующее совпадение) |
| Правка | `x` (удалить символ), `dd` (удалить строку), `u` (отмена действия) |
| Файловые операции | `:w` (сохранить), `:q!` (выход без сохранения), `:wq` (сохранить и выйти) |

#### Nano
Минималистичный редактор, не требующий обучения.
- `Ctrl + O`: Сохранить изменения.
- `Ctrl + X`: Выйти из редактора.
- `Ctrl + W`: Поиск по тексту.

### Современные инструменты (Rust/Go стек)

Современные альтернативы классическим утилитам GNU, обладающие большей скоростью и удобством.

#### Системный мониторинг и ресурсы
- **btop**: Высокопроизводительный монитор ресурсов (CPU, RAM, Disk, Network) с графиками и поддержкой мыши. Современная замена `htop`.
- **duf**: Утилита для просмотра свободного места на дисках с цветовой индикацией и группировкой по типам ФС. Замена `df`.
- **ncdu**: Интерактивный анализатор использования дискового пространства на базе ncurses. Замена `du`.

#### Файловая система и навигация
- **eza**: Улучшенная версия `ls`. Поддерживает иконки, цвета, отображение статуса Git и древовидный вид (`--tree`).
- **fd**: Быстрый и интуитивно понятный инструмент поиска файлов. Игнорирует `.gitignore` по умолчанию. Замена `find`.
- **zoxide**: "Умный" переход по директориям (`cd`), который запоминает часто посещаемые пути и позволяет перемещаться к ним по части имени.

#### Просмотр и поиск текста
- **bat**: Замена `cat` с синтаксической подсветкой, интеграцией с Git и автоматическим пейджингом (использует `less` для длинных текстов).
- **fzf**: Интерактивный потоковый фильтр. Позволяет быстро выбирать файлы, процессы или команды из истории.
- **ripgrep (rg)**: Экстремально быстрый поиск текста в файлах. См. детально в [grep.md](./grep.md).

#### Работа с сетью и API
- **xh / httpie**: Удобные HTTP-клиенты для тестирования API. Автоматически форматируют и подсвечивают JSON.

### Терминальные мультиплексоры

#### Screen

`GNU Screen` — классический терминальный мультиплексор, позволяющий создавать отсоединённые сессии, переживающие разрыв SSH. В 2026 году в большинстве сценариев предпочтительнее `tmux` (см. ниже), но `screen` остаётся удобным для простых detached-задач с логированием.

```bash
# Запуск отсоединённой именованной сессии с логом
screen -L -Logfile /tmp/job.log -dmS deploy bash -c './deploy.sh'

# Вернуться к сессии
screen -r deploy

# Список активных сессий
screen -ls
```

#### Tmux
Позволяет разделять экран на панели и сохранять сессии при обрыве связи.
- **Префикс (Prefix):** `Ctrl + B` (по умолчанию).
- `Prefix, %` / `Prefix, "`: Разделить панель вертикально / горизонтально.
- `Prefix, d`: Отключиться (detach) от сессии, оставив процессы работать.
- `tmux attach`: Подписаться к последней активной сессии.

Детальное руководство по мультиплексорам: [Управление сессиями SSH](../Security/ssh/ssh_session_management.md).

## Практические сценарии

### Безопасное редактирование через sudoedit
Использование `sudo vim` небезопасно, так как плагины редактора могут выполнить произвольный код с правами root. `sudoedit` копирует файл во временную директорию, редактирует его с правами пользователя и затем возвращает изменения.

```bash
# Настройка редактора по умолчанию
export SUDO_EDITOR=vim
# Безопасное редактирование системного конфига
sudoedit /etc/fstab
```

### Интерактивная работа с fzf
```bash
# Быстрый переход в директорию (fzf + cd)
cd $(find . -type d | fzf)

# Умное удаление процесса
ps -ef | fzf --multi | awk '{print $2}' | xargs kill -9
```

### Редактирование команды в полноценном редакторе
Если команда в строке ввода стала слишком сложной, нажмите `Ctrl + X, Ctrl + E`. Bash откроет её в `$EDITOR`. После сохранения и закрытия файла команда будет немедленно выполнена.

## Дополнительная информация

### Конфигурация окружения
Для корректной работы большинства утилит необходимо задать основной редактор в `~/.bashrc` или `~/.zshrc`:
```bash
export EDITOR='vim'
export VISUAL='vim'
```
