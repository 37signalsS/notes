# Консольные редакторы и утилиты

## Определения

- **TUI (Terminal User Interface)**: текстовый пользовательский интерфейс — интерактивные элементы (меню, списки, окна), работающие внутри терминала без использования графического сервера (X11/Wayland).
- **CLI Editor**: текстовый редактор, работающий непосредственно в командной строке (Vim, Nano).

---

## Базовые концепции

### Vim (CLI Editor)

Профессиональный модальный редактор, установленный практически во всех Unix-подобных системах.

#### Основные режимы

- **Normal (Обычный)**: навигация и ввод команд. Возврат в этот режим — `Esc`.
- **Insert (Вставка)**: ввод текста.
- **Visual (Визуальный)**: выделение текста.
- **Command-Line (Командный)**: выполнение команд (`:`, `/`).

#### Навигация и редактирование (Normal mode)

| Действие | Клавиши |
| :--- | :--- |
| Влево, вниз, вверх, вправо | `h`, `j`, `k`, `l` |
| Начало / конец слова | `w` / `e` |
| Начало / конец файла | `gg` / `G` |
| Удалить символ / строку | `x` / `dd` |
| Копировать / вставить | `yy` / `p` |
| Отмена / Возврат | `u` / `Ctrl + r` |
| Поиск вниз / вверх | `/pattern` / `?pattern` |

#### Сохранение и выход

| Команда | Действие |
| :--- | :--- |
| `:w` | Сохранить |
| `:q!` | Выйти без сохранения |
| `:wq` или `ZZ` | Сохранить и выйти |

### Nano (CLI Editor)

Простой и интуитивно понятный редактор для базовых правок.

| Комбинация | Действие |
| :--- | :--- |
| `Ctrl + O` | Сохранить файл |
| `Ctrl + X` | Выйти из редактора |
| `Ctrl + W` | Поиск текста |
| `Ctrl + K` / `Ctrl + U` | Вырезать / вставить строку |

### tldr (CLI Utility)

Упрощенные и понятные страницы помощи (man pages), ориентированные на практические примеры использования команд.

- **Практичность**: вместо полной технической документации выводит 5–10 самых популярных сценариев использования.
- **Установка**: `snap install tldr` или через системные пакетные менеджеры.
- **Пример**: `tldr pwd` — покажет основные флаги и примеры для команды вывода текущей директории.

### cli-stash (TUI Utility)

Утилита для сохранения, каталогизации и быстрого поиска часто используемых shell-команд.

- **Fuzzy search**: поиск команд по частичным совпадениям.
- **History integration**: возможность быстро добавить команду из истории в «избранное».

### Tmux (Terminal Multiplexer)

Инструмент для управления сессиями терминала, позволяющий разделять окно на несколько панелей и сохранять процессы запущенными даже после отключения от сервера.

- **Sessions**: позволяют отключаться (`detach`) и подключаться (`attach`) к запущенным процессам.
- **Windows / Panes**: разделение рабочего пространства на логические части.

## Практические сценарии

### Быстрое редактирование конфигурации через sudo

Для редактирования системных файлов (например, `/etc/hosts`) используйте `vim` или `nano`:

```bash
sudo vim /etc/hosts
```

### Редактирование длинной команды в редакторе

Если вы начали вводить сложную команду и поняли, что в терминале это неудобно, нажмите `Ctrl + X; Ctrl + E`. Оболочка откроет текущую строку в вашем основном редакторе (`$EDITOR`). После сохранения и выхода команда будет выполнена автоматически.

### Поиск и вставка команд через cli-stash

1. Запустите `cli-stash`.
2. Используйте поиск для выбора нужной команды.
3. Нажмите `Enter`, и команда подставится в приглашение терминала.

## Дополнительная информация

### Выбор редактора по умолчанию

Для установки основного редактора в системе добавьте в `~/.bashrc` или `~/.zshrc`:

```bash
export EDITOR='vim'
```
