# Инструменты и Горячие Клавиши Командной Строки

## Определения

**TUI (Terminal User Interface)** — это текстовый пользовательский интерфейс, который работает внутри терминала, предоставляя интерактивные элементы управления (меню, кнопки, списки) без использования графического сервера (GUI).

**Горячие клавиши (Hotkeys)** — сочетания клавиш, предназначенные для быстрого выполнения команд редактирования и управления процессами в командной строке.

## Основные инструменты

### 1. `cli-stash` (TUI)

`cli-stash` — это утилита для сохранения часто используемых или сложных shell-команд в "избранном".

* **Назначение:** Хранение и быстрый поиск команд (docker, kubectl, ffmpeg) для вставки в терминал.
* **Особенности:**
  * **Интеграция с историей:** Позволяет добавлять команды напрямую из истории оболочки (Ctrl+A).
  * **Нечеткий поиск:** Позволяет находить команды по частичным совпадениям.
  * **Прямая вставка:** Выбранная команда подставляется сразу в приглашение текущего терминала.

### 2. Vim (CLI Editor)

Vim — это мощный текстовый редактор, работающий в командной строке, поддерживающий различные режимы работы.

* **Нормальный режим (Normal Mode):** Основной режим для навигации.
* **Режим вставки (Insert Mode):** Для набора текста.
* **Визуальный режим (Visual Mode):** Для выделения текста.
* **Командный режим (Command-Line Mode):** Для выполнения команд (`:`).

## Горячие клавиши Shell

### Управление Процессами и Редактирование

* **Ctrl + C:** завершить текущий процесс (SIGINT).
* **Ctrl + Z:** приостановить текущий процесс (SIGTSTP). Для возврата используйте `fg`.
* **Ctrl + D:** закрыть оболочку (послать маркер EOF).
* **Ctrl + A / Home:** перейти к началу строки.
* **Ctrl + E / End:** перейти в конец строки.
* **Alt + B / Ctrl + ←:** перейти на слово влево.
* **Alt + F / Ctrl + →:** перейти на слово вправо.
* **Ctrl + B:** перемещение на один символ влево.
* **Ctrl + F:** перемещение на один символ вправо.
* **Ctrl + XX:** переключение между началом строки и текущей позицией курсора.
* **Ctrl + D:** удалить символ под курсором.
* **Alt + T:** поменять текущее и предыдущее слова.
* **Ctrl + T:** поменять местами два символа перед курсором.
* **Ctrl + _:** отменить последнее действие.
* **Ctrl + x; Ctrl + e**: открывает `$EDITOR` для редактирования текущей команды.
* **Ctrl + W:** вырезать слово перед курсором.
* **Ctrl + K:** вырезать текст от курсора до конца строки.
* **Ctrl + U:** вырезать текст от курсора до начала строки.
* **Ctrl + Y:** вставить последний вырезанный текст.
* **Alt + U:** перевод текста до конца слова в верхний регистр.
* **Alt + L:** перевод текста до конца слова в нижний регистр.
* **Alt + C:** ввод первой заглавной буквы в слове.
* **Ctrl + P / ↑:** перейти к предыдущей команде в истории.
* **Ctrl + N / ↓:** перейти к следующей команде в истории.
* **Ctrl + R:** поиск по истории команд (инкрементальный поиск).
* **Ctrl + O:** запустить найденную команду и перейти к следующей.
* **Ctrl + G:** выйти из режима поиска в истории.
* **Alt + R:** отменить изменения в команде из истории.
* **sudo !!**: запустить последнюю выполненную команду с правами суперпользователя.
* **Пробел перед командой**: предотвращает сохранение команды в истории Bash.
* **Ctrl + L:** очистить экран (аналог `clear`).

## Работа в Vim

### Навигация и Редактирование

* `h`, `j`, `k`, `l`: Перемещение влево, вниз, вверх, вправо.
* `w`: Переместиться на начало следующего слова.
* `b`: Переместиться на начало предыдущего слова.
* `e`: Переместиться в конец текущего слова.
* `gg`: В начало файла.
* `G`: В конец файла.
* `i`: Перейти в режим вставки **перед** курсором.
* `a`: Перейти в режим вставки **после** курсором.
* `o`: Вставить новую строку **ниже** текущей и перейти в режим вставки.
* `dd`: Удалить (вырезать) текущую строку.
* `yy`: Скопировать текущую строку.
* `p`: Вставить **после** курсора.
* `u`: Отменить последнее действие.
* `:wq` или `:x`: Сохранить и выйти.
* `:q!`: Выйти без сохранения.

### Выделение и Поиск

* `v`: Включить визуальный режим (символьный).
* `V` (Shift+v): Включить визуальный режим (построчный).
* `/pattern`: Искать `pattern` от курсора вниз.
* `n`: Найти следующее вхождение.
* `:%s/old/new/g`: Заменить все вхождения `old` на `new`.

## Практические сценарии

### Настройка и использование `cli-stash`

#### Установка

```bash
# Go install
go install github.com/itcaat/cli-stash@latest
# macOS (Homebrew)
brew install itcaat/tap/cli-stash
```

#### Использование

1. Запустите `cli-stash`.
2. Нажмите **Ctrl+A** для поиска в истории шелла.
3. Выберите нужную команду и сохраните её в "избранное".
4. В будущем просто выбирайте команду из списка для вставки в CLI.
