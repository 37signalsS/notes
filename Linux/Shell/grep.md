# Поиск текста с помощью grep

## Определения

- **`grep` (Global Regular Expression Print)**: Утилита для поиска по шаблону. Читает входные данные (файл или поток) и выводит строки, совпадающие с регулярным выражением.
- **Шаблон (Pattern)**: Строка или регулярное выражение, используемое для поиска.

---

## Базовые концепции

### Ключи grep

| Ключ | Длинный ключ | Описание |
| :--- | :--- | :--- |
| `-i` | `--ignore-case` | Игнорировать регистр |
| `-v` | `--invert-match` | Инвертировать поиск: строки **без** шаблона |
| `-r`, `-R` | `--recursive` | Рекурсивный поиск в директории |
| `-l` | `--files-with-matches` | Вывести только имена файлов с совпадениями |
| `-L` | `--files-without-match` | Вывести только имена файлов **без** совпадений |
| `-c` | `--count` | Количество строк с совпадениями |
| `-n` | `--line-number` | Номер строки перед каждым совпадением |
| `-w` | `--word-regexp` | Поиск точного совпадения слова (окруженного пробелами/пунктуацией) |
| `-x` | `--line-regexp` | Поиск точного совпадения всей строки |
| `-E` | `--extended-regexp` | Расширенный синтаксис регулярных выражений (ERE) |
| `-F` | `--fixed-strings` | Точный поиск строки (не regex). Ускоряет поиск |
| `-P` | `--perl-regexp` | Синтаксис регулярных выражений Perl (PCRE) |
| `-q` | `--quiet` | Тихий режим. Только [код выхода](exit_codes.md): `0` (найдено), `1` (нет) |
| `-A N` | `--after-context=N` | `N` строк **после** совпадения |
| `-B N` | `--before-context=N` | `N` строк **до** совпадения |
| `-C N` | `--context=N` | `N` строк **вокруг** совпадения |
| `-o` | `--only-matching` | Только совпавшая часть строки |
| `-h` | `--no-filename` | Не выводить имена файлов при поиске в нескольких файлах |
| `-H` | `--with-filename` | Всегда выводить имена файлов |
| `-f file` | `--file=file` | Читать шаблоны из указанного файла |
| `-m N` | `--max-count=N` | Остановить поиск после `N` совпадений |

## Практические сценарии

### Простой поиск в файле

```bash
grep "/bin/bash" /etc/passwd
```

### Поиск без учёта регистра

```bash
grep -i "error" /var/log/syslog /var/log/messages
```

### Поиск нескольких шаблонов (ИЛИ)

```bash
# Использование -E (ERE) и вертикальной черты
grep -E "error|critical|warning" /var/log/syslog

# Использование нескольких флагов -e
grep -e "error" -e "critical" /var/log/syslog
```

### Поиск точного слова или строки

```bash
# Найти "bin", но не "sbin" или "binary"
grep -w "bin" /etc/passwd

# Найти строку, состоящую только из "root"
grep -x "root" my_file.txt
```

### Рекурсивный поиск с исключениями

```bash
# Рекурсивный поиск слова "TODO" во всех файлах, кроме .log
grep -r --exclude="*.log" "TODO" .

# Исключение целых директорий (например, .git)
grep -r --exclude-dir=".git" "pattern" .
```

### Проверка условий в скриптах (`grep -q`)

```bash
# Проверить наличие пользователя
if grep -q "^root:" /etc/passwd; then
    echo "Пользователь root существует."
fi

# Добавить строку, только если её ещё нет
LINE="127.0.0.1 myhost"
FILE="/etc/hosts"
if ! grep -qFx "$LINE" "$FILE"; then
    echo "$LINE" | sudo tee -a "$FILE"
fi
```

### Поиск специальных символов

Символы regex (`[`, `]`, `.`, `*`, `+`, `?`, `|`, `(`, `)`) экранируются обратным слэшем:

```bash
# Поиск токена [27] в логе
grep '\[27\]' my_log_file.txt
```

### Поиск в сжатых файлах (`zgrep`)

Утилита `zgrep` позволяет искать текст в файлах, сжатых `gzip`, не распаковывая их вручную.

```bash
zgrep -i "error" /var/log/syslog.2.gz
```

## Дополнительная информация

### Режимы регулярных выражений

- **BRE (Basic Regular Expressions)**: базовый режим по умолчанию. Символы `?`, `+`, `{}`, `|`, `()` требуют `\` для активации.
- **ERE (Extended Regular Expressions)**: расширенный режим, активируется флагом `-E` (или `egrep`). Спецсимволы работают без экранирования.
- **PCRE (Perl Compatible Regular Expressions)**: режим совместимости с Perl, флаг `-P`. Поддерживает look-arounds, non-greedy matching.

### Опасность `grep file > file`

Перенаправление (`>`) обрабатывается оболочкой **до** запуска команды. Если вы попытаетесь записать результат поиска в тот же файл, из которого читаете, оболочка сначала обнулит его.

```bash
# ОШИБКА — файл my_file.txt будет стерт!
grep "pattern" my_file.txt > my_file.txt
```

**Безопасные решения:**

1. **Временный файл**:

    ```bash
    grep "pattern" a.txt > a.tmp && mv a.tmp a.txt
    ```

2. **Утилита `sponge`** (пакет `moreutils`):

    ```bash
    grep "pattern" a.txt | sponge a.txt
    ```

3. **Использование `sed -i`** (редактирование на месте):

    ```bash
    sed -i '/pattern/!d' a.txt
    ```

Подробнее о механизме: [Перенаправление ввода/вывода](io_redirection.md).
