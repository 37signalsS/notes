# Логика обработки и выполнения команд в Shell

## Определения

- **Жизненный цикл команды (Command Lifecycle)** — последовательность этапов, которые проходит строка ввода от парсинга до завершения процесса.
- **Подстановка (Expansion)** — замена специальных символов (`*`, `$`, `$( )`) на их значения перед выполнением команды.
- **Разбиение на слова (Word Splitting)** — процесс разделения результата подстановок на отдельные аргументы на основе переменной `$IFS`.
- **Префиксное присваивание (Variable Assignment)** — задание переменных окружения непосредственно перед командой (`VAR=val cmd`), влияющее только на этот вызов.
- **Хеш-таблица (Hash Table)** — внутренний кеш Shell, хранящий пути к исполняемым файлам для ускорения поиска в `$PATH`.

---

## Жизненный цикл выполнения команды

Когда вы нажимаете `Enter`, Bash обрабатывает строку в строго определенном порядке. Нарушение этого порядка — частая причина ошибок в скриптах.

1.  **Токенизация**: Разбиение строки на слова и операторы (`|`, `&&`, `;`, `&`).
2.  **Генерация строк (Brace Expansion)**: Обработка `{a,b}`. Выполняется первой, так как не зависит от значений переменных.
3.  **Подстановка тильды (Tilde Expansion)**: Замена `~` на путь к `$HOME`.
4.  **Подстановка параметров и переменных**: Замена `$VAR` и `${VAR}`.
5.  **Арифметическая подстановка**: Вычисление `$(( expression ))`.
6.  **Подстановка команд**: Обработка `$(command)` или `` `command` ``. Выполняется путем запуска подоболочки.
7.  **Разбиение на слова (Word Splitting)**: Применяется к результатам этапов 4, 5 и 6, если они **не** заключены в двойные кавычки.
8.  **Подстановка имен файлов (Globbing)**: Обработка `*`, `?`, `[ ]`.
9.  **Удаление кавычек (Quote Removal)**: Убираются внешние кавычки (`'`, `"`), защищавшие текст на предыдущих этапах.
10. **Перенаправления**: Настройка дескрипторов файлов (`<`, `>`, `>>`).
11. **Выполнение**: Определение типа команды и её запуск.

## Приоритет поиска и управления командами

### Порядок поиска (Command Lookup)
Если команда введена без пути (не содержит `/`), Bash ищет её в следующем порядке:
1.  **Алиасы (Aliases)**: Только в интерактивных оболочках.
2.  **Ключевые слова (Keywords)**: Резервированные слова (`if`, `then`, `function`).
3.  **Функции (Functions)**: Определенные пользователем в текущей сессии.
4.  **Встроенные команды (Built-ins)**: Команды внутри бинарного файла самого Bash (`cd`, `echo`, `read`).
5.  **Внешние команды (External)**: Поиск в директориях переменной `$PATH`. Путь кешируется в `hash`.

### Инструменты диагностики
- **`type -a <cmd>`**: Показывает все доступные версии команды (алиас, функция, файл). Рекомендуется вместо `which`.
- **`command -v <cmd>`**: Возвращает путь к команде или её имя, если она встроена. Удобно для скриптов.

### Обход приоритетов
- **`\command`**: Обратный слэш перед именем отключает алиасы.
- **`command <cmd>`**: Игнорирует алиасы и функции.
- **`builtin <cmd>`**: Форсирует использование встроенной команды.

## Продвинутые механизмы выполнения

### Команда exec
Заменяет текущий процесс оболочки новым процессом. Текущий скрипт или Shell **завершается**, и управление передается новой программе без создания дочернего процесса.
```bash
# Текущий Shell заменяется на htop
exec htop
```

### Команда eval
Заставляет оболочку выполнить строку дважды: сначала провести все подстановки, а затем выполнить получившуюся строку как команду. **Опасно** при работе с пользовательским вводом.
```bash
VAR="ls -l"
eval $VAR  # Корректно выполнит ls -l
```

### Подстановка процессов (Process Substitution)
Создает временный именованный канал (pipe) и передает его путь как аргумент.
- **`<(cmd)`**: Позволяет читать вывод `cmd` как файл.
- **`>(cmd)`**: Позволяет записывать в `cmd` как в файл.

## Управляющие операторы и группировка

### Логические связи
- **`&&`**: Выполнить следующую, только если предыдущая успешна (`exit 0`).
- **`||`**: Выполнить следующую, только если предыдущая завершилась с ошибкой.

### Группировка
- **`( commands )`**: Запуск в **Subshell**. Создает копию процесса. Переменные и `cd` внутри не влияют на родителя.
- **`{ commands; }`**: Запуск в текущей оболочке. Влияет на состояние текущего Shell.

## Практические сценарии

### Изоляция окружения для одной команды
```bash
# Установка переменной только для этого вызова приложения
LOG_LEVEL=debug ./my_app
# LOG_LEVEL здесь снова не определена
```

### Сравнение удаленных и локальных файлов
```bash
diff <(ssh server "cat /etc/config") /etc/config
```

### Проверка наличия команды в скрипте
```bash
if command -v docker &>/dev/null; then
    docker ps
else
    echo "Docker не установлен"
fi
```

## Дополнительная информация

### Безопасность и PATH
Переменная `$PATH` просматривается слева направо. Наличие `.` (текущей директории) в начале `$PATH` является критической уязвимостью, так как позволяет выполнить вредоносный файл вместо системной утилиты.
