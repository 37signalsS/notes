# Коды возврата в Shell

## Определения

**Код возврата (Exit Code, Exit Status)** — целочисленное значение в диапазоне от **0** до **255**, возвращаемое процессом родительской оболочке или операционной системе при завершении работы. Это фундаментальный механизм межпроцессного взаимодействия для передачи результата выполнения.

- **Переменная `$?`** — специальный параметр оболочки, который хранит код возврата последней выполненной команды (или конвейера). Значение обновляется немедленно после выполнения любой операции, включая проверки `[` или команды вывода `echo`.
- **PIPESTATUS** — внутренний массив Bash, содержащий коды возврата всех команд в последнем выполненном конвейере (pipeline).

## Базовые концепции

### Интерпретация значений

- **`0`** — **Успех (Success)**. Команда выполнена корректно.
- **`1–255`** — **Ошибка (Failure)**. Любое ненулевое значение сигнализирует о сбое. Конкретное число часто указывает на тип возникшей проблемы.

### Механизм переполнения и 8-битное ограничение

Коды возврата в Unix ограничены 8 битами. Если процесс вызывает `exit` со значением больше 255, результат вычисляется по формуле `N % 256`.
- `exit 256` → вернет **0** (может быть ошибочно воспринято как успех).
- `exit 257` → вернет **1**.
- `exit -1` → вернет **255** (циклическое смещение).

### Сохранение кода возврата

Так как `$?` меняется после каждой команды, для анализа кода конкретной операции его необходимо сохранить в переменную сразу после вызова.

```bash
# Пример корректного сохранения
ls /nonexistent_file
rc=$?
# Теперь переменную rc можно анализировать многократно
if [ $rc -ne 0 ]; then
    echo "Ошибка! Код возврата: $rc"
fi
```

### Коды выхода и системные сигналы (128 + N)

Если процесс завершается принудительно под воздействием сигнала, оболочка устанавливает код возврата по формуле **128 + номер_сигнала**.

| Сигнал | Номер | Код выхода | Причина |
| :--- | :--- | :--- | :--- |
| **SIGINT** | 2 | **130** | Прервано пользователем (`Ctrl+C`). |
| **SIGKILL** | 9 | **137** | Принудительно убито (`kill -9`) или OOM Killer. |
| **SIGTERM** | 15 | **143** | Запрос на мягкое завершение (стандарт для `docker stop`). |

### Таблица общепринятых и зарезервированных кодов

| Код | Значение | Описание |
| :--- | :--- | :--- |
| **0** | Успех | Команда завершена без ошибок. |
| **1** | Общая ошибка | Неспецифический сбой (деление на ноль, ошибки выполнения скрипта). |
| **2** | Неправильное использование | Ошибки синтаксиса или неверные аргументы встроенных команд Bash. |
| **64–78** | sysexits.h | Стандартизированные коды для системных утилит (например, 64 — ошибка параметров, 77 — нет прав). |
| **126** | Невыполнимая команда | Файл найден, но права на исполнение отсутствуют (`Permission denied`) или это директория. |
| **127** | Команда не найдена | Опечатка в имени или файл отсутствует в путях `$PATH`. |
| **128** | Неверный аргумент выхода | Передан `exit` с нечисловым аргументом. |
| **130** | SIGINT | Завершение через прерывание (128 + 2). |
| **137** | SIGKILL | Принудительное завершение, часто нехватка памяти (128 + 9). |

## Продвинутая работа с кодами возврата

### Конвейеры и массив PIPESTATUS

По умолчанию `$?` хранит код только **последней** команды в конвейере.

```bash
# Пример обманчивого успеха
cat nonexistent_file | sort
echo $? # → 0 (так как sort отработал успешно)
```

В Bash для доступа к кодам всех команд используется массив `${PIPESTATUS[@]}`:

```bash
cat nonexistent_file | sort
# Сохраняем массив сразу, так как он обновится при следующей команде
results=("${PIPESTATUS[@]}")
echo "cat: ${results[0]}, sort: ${results[1]}"
```

### Стабильность скриптов: set -e и pipefail

- `set -e` (errexit): Оболочка прекращает выполнение скрипта при любой ошибке (кроме проверок в `if`, `while` и логических И/ИЛИ).
- `set -o pipefail`: Кодом возврата конвейера станет код самой правой команды, завершившейся с ошибкой (а не просто последней).

Рекомендуемый заголовок: `set -euo pipefail`.

### Разница между exit и return

- **`exit N`**: Завершает работу текущей оболочки (скрипта или сабшелла). Если вызвано в `( ... )`, основной скрипт продолжит работу.
- **`return N`**: Завершает выполнение функции или скрипта, вызванного через `source`, возвращая код в вызывающую среду, но не завершая процесс.

### Команды-заглушки: true и false

- `true` (или `:`): всегда возвращает **0**.
- `false`: всегда возвращает **1**.

## Практические сценарии

### Проверки в скриптах

```bash
# Идемпотентная проверка наличия пользователя
if grep -q "^admin:" /etc/passwd; then
    echo "Пользователь существует"
else
    echo "Пользователь не найден"
fi
```

### Контроль качества в CI/CD

```bash
# Запуск тестов
npm test
if [ $? -ne 0 ]; then
    echo "Тесты провалены! Прекращение сборки."
    exit 1
fi
```

### Логические операторы (&& и ||)

- `cmd1 && cmd2` — выполнить `cmd2`, если `cmd1` успешна (**0**).
- `cmd1 || cmd2` — выполнить `cmd2`, если `cmd1` завершилась ошибкой (**не 0**).
