# Коды возврата в Shell

## Определения

- **Код возврата (Exit Code, Exit Status)**: Целочисленное значение (0–255), возвращаемое процессом при завершении. Информирует систему о результате выполнения программы.
- **Переменная `$?`**: Специальная переменная shell, хранящая код возврата последней выполненной команды. Перезаписывается после каждой новой команды.

---

## Базовые концепции

### Интерпретация кодов

- **`0`** — успех.
- **`1–255`** — ошибка. Конкретное значение может указывать на причину.

### Сохранение кода возврата

`$?` перезаписывается после **каждой** команды. Для последующего использования значение необходимо немедленно сохранить:

```bash
some_command
LAST_EXIT_CODE=$?
echo "$LAST_EXIT_CODE"
```

### Таблица общепринятых кодов

| Код | Значение | Описание |
| :--- | :--- | :--- |
| `0` | Успех | Команда выполнена без ошибок |
| `1` | Общая ошибка | Неуказанная проблема |
| `2` | Неправильное использование | Ошибочные аргументы командной строки |
| `125` | Ошибка запуска (Docker) | `docker run` не смог запустить контейнер |
| `126` | Невыполнимая команда | Команда найдена, но нет прав (`chmod +x`) или неверный формат |
| `127` | Команда не найдена | Опечатка или отсутствие исполняемого файла в `$PATH` |
| `130` (128+2) | SIGINT | Прерывание (`Ctrl+C`) |
| `137` (128+9) | SIGKILL | Принудительное завершение. Частые причины: `OOMKilled`, `kill -9` |
| `139` (128+11) | SIGSEGV | Ошибка сегментации (C/C++, нативные расширения) |
| `143` (128+15) | SIGTERM | «Вежливое» завершение. Приложение не обработало SIGTERM |

Коды **>128** указывают на завершение по сигналу: `128 + номер_сигнала`.

## Практические сценарии

### Проверка успешного выполнения

```bash
ls /etc/hosts
echo $?  # 0
```

### Проверка ошибочного выполнения

```bash
ls /не/существует
echo $?  # 2 (или другое ненулевое значение)
```

### Ветвление логики в скриптах

```bash
grep "user" /etc/passwd
if [ $? -eq 0 ]; then
    echo "Пользователь найден."
else
    echo "Пользователь не найден."
fi
```

### Сохранение кода возврата

```bash
ls /не/существует
LAST_EXIT_CODE=$?

echo "Код завершения ls: $LAST_EXIT_CODE"
echo "Код завершения echo: $?"  # 0
```

### Проверка в конвейерах CI/CD

```bash
trivy image --severity HIGH,CRITICAL --exit-code 1 myapp:1.2.3
# Exit code 1 → CI/CD шаг завершится с ошибкой при обнаружении уязвимостей
```
