# Коды возврата в Shell

## Определения

* **Код возврата (Exit Code, Exit Status)** — это целочисленное значение в диапазоне от 0 до 255, которое возвращает каждый процесс или команда после своего завершения. Он информирует систему о том, как завершилась программа.
* **Переменная `$?`** — специальная переменная в shell, которая хранит код возврата последней выполненной команды.

## Основные концепции

* **`0` (Успех):** Команда завершилась успешно, без ошибок.
* **`1-255` (Ошибка):** В процессе выполнения команды произошла ошибка. Конкретное число может указывать на причину.

Значение переменной `$?` перезаписывается после выполнения **каждой** новой команды. Если нужно сохранить код возврата для последующего использования, его необходимо немедленно присвоить другой переменной.

## Практические сценарии

* **Проверка успешного выполнения:**

    ```bash
    ls /etc/hosts
    # /etc/hosts
    
    echo $?
    # 0
    ```

* **Проверка ошибочного выполнения:**

    ```bash
    ls /не/существует
    # ls: cannot access '/не/существует': No such file or directory
    
    echo $?
    # 2 (или другое ненулевое значение)
    ```

* **Использование в скриптах для ветвления логики:**

    ```bash
    grep "user" /etc/passwd
    
    if [ $? -eq 0 ]; then
      echo "Пользователь найден."
    else
      echo "Пользователь не найден или произошла ошибка."
    fi
    ```

* **Сохранение кода возврата:**

    ```bash
    ls /не/существует
    LAST_EXIT_CODE=$?
    
    # Теперь можно выполнять другие команды, не боясь потерять исходный код
    echo "Команда 'ls' завершилась с кодом: $LAST_EXIT_CODE"
    
    echo "А код возврата последней команды 'echo' равен: $?" # Будет 0
    ```

## Дополнительная информация

Существуют общепринятые, хотя и не строго обязательные, значения кодов возврата:

* **1:** Общая ошибка (например, `let a=1/0`).
* **2:** Некорректное использование (ошибка в аргументах встроенной команды shell).
* **126:** Команда найдена, но не может быть выполнена (проблема с правами доступа).
* **127:** Команда не найдена.
* **130 (128 + 2):** Скрипт завершен по `Ctrl+C` (сигнал `SIGINT`). Коды выше 128 указывают на завершение по сигналу.
