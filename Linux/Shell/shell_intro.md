# Введение в командную строку: Терминал, Оболочка, CLI

## Определения

* **Эмулятор терминала (Terminal Emulator):**
    Это **графическое приложение** (окно), которое вы запускаете. Его основная задача — обрабатывать ввод с клавиатуры, отображать текстовый вывод и предоставлять интерфейс для взаимодействия с командной оболочкой.

* **Командная оболочка (Shell):**
    Это **программа-интерпретатор команд**, которая работает *внутри* эмулятора терминала. Оболочка принимает ваши команды, интерпретирует их и передает инструкции ядру операционной системы. Она также управляет переменными, скриптами и процессами.

* **Интерфейс командной строки (Command Line Interface, CLI):**
    Это сам **текстовый интерфейс** для взаимодействия с оболочкой, состоящий из строк для ввода команд и вывода результатов. Важной его частью является **приглашение (prompt)**, которое сигнализирует о готовности к вводу (например, `user@hostname:~$`).

## Основные концепции

#### Взаимосвязь компонентов

1. Вы открываете **Эмулятор терминала** (например, GNOME Terminal).
2. Терминал запускает **Оболочку** (например, `bash`).
3. Оболочка предоставляет вам **Командную строку** для ввода команд.

## Практические сценарии

#### Как узнать свою текущую оболочку?

```bash
echo $SHELL
# /bin/bash

# Или, для большинства интерактивных оболочек:
echo $0
# bash
```

## Дополнительная информация: режимы работы и файлы конфигурации

Оболочки работают в разных режимах, что влияет на то, какие файлы конфигурации (`startup files`) они загружают. Понимание этого ключительно для правильной настройки окружения.

* **Интерактивная login-оболочка (Interactive login shell):**
  - **Что это:** Сессия, которую вы получаете при входе в систему через консоль или SSH.
  - **Файлы конфигурации (Bash):** Сначала выполняется `/etc/profile` (для системных настроек), а затем первый найденный из `~/.bash_profile`, `~/.bash_login`, `~/.profile`.
  - **Назначение:** Установка переменных окружения, которые должны быть доступны во всей сессии пользователя.

* **Интерактивная non-login-оболочка (Interactive non-login shell):**
  - **Что это:** Сессия, которую вы получаете, открывая новое окно терминала в графическом интерфейсе.
  - **Файлы конфигурации (Bash):** Выполняется `~/.bashrc`.
  - **Назначение:** Определение алиасов, функций и настроек `prompt`, которые нужны только для интерактивной работы.

* **Неинтерактивная оболочка (Non-interactive shell):**
  - **Что это:** Оболочка, которая выполняет скрипт.
  - **Файлы конфигурации (Bash):** Обычно никакие из перечисленных файлов не загружаются, чтобы обеспечить предсказуемую и чистую среду выполнения. Переменные окружения наследуются от родительского процесса, который запустил скрипт.
