# Введение в командную строку: Terminal, Shell, CLI

## Определения

- **Terminal Emulator (Эмулятор терминала)** — графическое приложение (например, Alacritty, iTerm2, GNOME Terminal), которое предоставляет окно для ввода команд и отображения текстового вывода. Оно имитирует поведение старых аппаратных терминалов.
- **Shell (Командная оболочка)** — программа-интерпретатор, которая принимает команды от пользователя, разбирает их и передает ядру операционной системы для выполнения. Оболочка также управляет переменными окружения, скриптами и процессами.
- **CLI (Command Line Interface)** — текстовый интерфейс взаимодействия пользователя с программным обеспечением.
- **TTY / PTY (Teletype / Pseudo-Teletype)**:
  - **TTY**: Исторически — физическое печатающее устройство. В современном Linux — виртуальная консоль (например, доступная по `Ctrl+Alt+F1`).
  - **PTY**: "Псевдо-терминал", используемый эмуляторами терминала и SSH-сессиями для взаимодействия с оболочкой.
- **Prompt (Приглашение)** — строка текста, выводимая оболочкой, когда она готова принять новую команду (например, `user@host:~$`).

## Базовые концепции

### Типы командных оболочек

| Оболочка | Описание | Применение |
| :--- | :--- | :--- |
| **sh** | Bourne Shell. Основа синтаксиса большинства оболочек. | Минималистичный стандарт POSIX. |
| **bash** | Bourne Again Shell. Самая популярная оболочка в Linux. | Стандарт для интерактивной работы и скриптов. |
| **dash** | Debian Almquist Shell. Маленькая и быстрая. | Используется как `/bin/sh` в Debian/Ubuntu для ускорения загрузки. |
| **zsh** | Z Shell. Совместима с Bash, но имеет богатый функционал. | Выбор по умолчанию в macOS и для продвинутых пользователей. |
| **fish** | Friendly Interactive Shell. Не совместима с POSIX. | Фокус на интерактивность "из коробки" (подсветка, подсказки). |

### Стандартные потоки данных

Каждая программа, запущенная в оболочке, автоматически получает три открытых потока данных:
1. **stdin (fd 0)** — стандартный ввод (обычно клавиатура).
2. **stdout (fd 1)** — стандартный вывод (обычно экран).
3. **stderr (fd 2)** — стандартный поток ошибок (также экран, но отделен от основного вывода).

Подробнее о манипуляции потоками: [Перенаправление ввода-вывода](./io_redirection.md).

### Встроенные и внешние команды

- **Built-ins (Встроенные)**: Являются частью самой программы Shell (например, `cd`, `pwd`, `echo`, `export`). Они выполняются мгновенно без создания нового процесса.
- **External (Внешние)**: Отдельные программы, лежащие в файловой системе (например, `ls`, `grep`, `awk`). Shell ищет их в директориях, указанных в переменной `$PATH`.

Подробная логика поиска и приоритеты: [Логика обработки команд](./bash_command_execution.md).

### Работа со справочной информацией

1. **man (Manual pages)**: Полноценные руководства. `man <command>`.
2. **help (Built-in help)**: Справка по встроенным командам Bash. `help <command>`.
3. **apropos**: Поиск команд по описанию. `apropos "partition"`.
4. **tldr**: Лаконичные примеры использования ([подробнее в cli-tools](./cli-tools.md)).

## Практические сценарии

### Определение текущего окружения

```bash
# Узнать путь к текущей оболочке
echo $SHELL

# Узнать имя текущего процесса (обычно оболочки)
echo $0

# Проверить тип команды (встроенная или внешняя)
type cd   # → cd is a shell builtin
type ls   # → ls is aliased to `ls --color=auto`
type -P ls # → /usr/bin/ls (найти путь к бинарному файлу)
```

### Безопасная проверка наличия команды

Вместо `which` (который может вести себя по-разному в разных дистрибутивах), рекомендуется использовать встроенную команду `command`:

```bash
# Проверить наличие утилиты в скрипте
if command -v git &> /dev/null; then
    echo "Git установлен"
fi
```

### Переключение между оболочками

Если в системе установлено несколько оболочек, между ними можно переключаться:

```bash
# Временный переход в zsh
zsh

# Смена оболочки по умолчанию для текущего пользователя (требует пароль)
chsh -s /bin/zsh
```

## Дополнительная информация

### Режимы сессий и конфигурационные файлы

То, какие файлы конфигурации будут загружены, зависит от типа сессии:

1. **Interactive Login**: Запускается при входе (SSH, TTY).
   - Читает: `/etc/profile` → `~/.bash_profile` (или `~/.profile`).
2. **Interactive Non-login**: Новое окно терминала в GUI.
   - Читает: `/etc/bash.bashrc` (зависит от дистрибутива) → `~/.bashrc`.
3. **Non-interactive**: Выполнение скрипта.
   - Использует переменную `$BASH_ENV`.
