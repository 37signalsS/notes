# Введение в командную строку: Терминал, Оболочка, CLI

### Определения

*   **Эмулятор терминала (Terminal Emulator):**
    Это **графическое приложение** (окно), которое вы запускаете. Его основная задача — обрабатывать ввод с клавиатуры, отображать текстовый вывод и предоставлять интерфейс для взаимодействия с командной оболочкой.

*   **Командная оболочка (Shell):**
    Это **программа-интерпретатор команд**, которая работает *внутри* эмулятора терминала. Оболочка принимает ваши команды, интерпретирует их и передает инструкции ядру операционной системы. Она также управляет переменными, скриптами и процессами.

*   **Интерфейс командной строки (Command Line Interface, CLI):**
    Это сам **текстовый интерфейс** для взаимодействия с оболочкой, состоящий из строк для ввода команд и вывода результатов. Важной его частью является **приглашение (prompt)**, которое сигнализирует о готовности к вводу (например, `user@hostname:~$`).

### Основные концепции

#### Взаимосвязь компонентов

1.  Вы открываете **Эмулятор терминала** (например, GNOME Terminal).
2.  Терминал запускает **Оболочку** (например, `bash`).
3.  Оболочка предоставляет вам **Командную строку** для ввода команд.

### Практические сценарии

#### Как узнать свою текущую оболочку?

Выполните одну из этих команд:
```bash
echo $SHELL
# /bin/bash

# Или, для большинства интерактивных оболочек:
echo $0
# bash
```

### Дополнительная информация

Оболочки могут работать в двух режимах:

*   **Интерактивный режим:** Когда вы напрямую вводите команды в терминале и получаете ответ. В этом режиме оболочка загружает файлы конфигурации, такие как `.bashrc` или `.zshrc`.
*   **Неинтерактивный режим:** Когда оболочка выполняет команды из файла (скрипта). В этом режиме обычно загружаются другие файлы конфигурации (например, `.bash_profile`) или не загружаются вовсе, чтобы обеспечить предсказуемую и чистую среду выполнения.
