# Переменные оболочки: локальные, окружения и специальные

## Определения

- **Shell Variable (Переменная оболочки)** — именованная область памяти в текущем сеансе Shell, предназначенная для хранения строковых данных.
- **Local Variable (Локальная переменная)** — переменная, доступная только в текущем процессе оболочки. Не наследуется дочерними процессами.
- **Environment Variable (Переменная окружения)** — глобальная переменная, доступная текущему процессу и всем его потомкам. Формирует контекст выполнения (окружение) для программ.
- **Special Variable (Специальная переменная)** — встроенная переменная Shell, имеющая фиксированное имя (обычно один символ) и специфическое назначение (аргументы, статусы выполнения и т.д.).
- **Parameter Expansion** — механизм Shell для извлечения и модификации значений переменных «на лету».

## Основные концепции

### Локальные переменные против Переменных окружения

| Характеристика | Локальная переменная | Переменная окружения |
| :--- | :--- | :--- |
| **Объявление** | `VAR="value"` | `export VAR="value"` |
| **Видимость** | Только текущий Shell | Текущий + дочерние процессы |
| **Наследование** | Нет | Да |
| **Регистр (соглашение)** | Обычно `lowercase` | Обычно `UPPERCASE` |

### Специальные переменные Shell

Эти переменные создаются и обновляются оболочкой автоматически:

| Переменная | Описание |
| :--- | :--- |
| **`$?`** | Код возврата последней выполненной команды ([подробнее](./exit_codes.md)). |
| **`$$`** | PID (Process ID) текущего экземпляра оболочки. |
| **`$!`** | PID последнего процесса, запущенного в фоновом режиме. |
| **`$0`** | Имя исполняемого скрипта или самой оболочки. |
| **`$1, $2...`** | Позиционные параметры (аргументы командной строки). |
| **`$#`** | Количество переданных аргументов. |
| **`$*`** | Все аргументы одной строкой (разделенные первым символом `IFS`). |
| **`$@`** | Все аргументы как отдельные слова (безопасно для итерации в кавычках `"$@"`). |

### Parameter Expansion: манипуляция значениями

Базовый синтаксис `${VAR}` позволяет выполнять проверки и подстановки:

| Синтаксис | Описание |
| :--- | :--- |
| **`${VAR:-default}`** | Использовать `default`, если `VAR` не установлена или пуста. |
| **`${VAR:=default}`** | Присвоить `default` переменной `VAR`, если она не установлена. |
| **`${VAR:?message}`** | Вывести ошибку `message` и завершить скрипт, если `VAR` не установлена. |
| **`${VAR:+alt}`** | Использовать `alt`, если `VAR` установлена и не пуста. |

## Практические сценарии

### Настройка системного окружения

```bash
# Добавление пути в переменную PATH для текущего сеанса
export PATH="/usr/local/go/bin:$PATH"

# Проверка результата
echo $PATH
```

### Передача конфигурации приложению

Многие современные приложения (например, в Docker-контейнерах) настраиваются исключительно через переменные окружения.

```bash
# Задание параметров подключения к БД
export DB_HOST="localhost"
export DB_PORT=5432

./my_app_binary
```

### Проверка обязательных параметров в скриптах

```bash
#!/bin/bash

# Завершить работу, если API_KEY не задан
: "${API_KEY?Ошибка: переменная API_KEY должна быть установлена}"

echo "Используем ключ: $API_KEY"
```

### "Чистый" запуск команды

Использование утилиты `env` позволяет запустить программу без наследования текущих переменных окружения (или с их заменой).

```bash
# Запуск с очищенным окружением, только с указанным PATH
env -i PATH=/usr/bin:/bin bash -c 'env'
```

## Дополнительная информация

### Различия "$*" и "$@"

Эти специальные переменные ведут себя по-разному при использовании в кавычках:

- **`"$*"`** — разворачивается в **одну строку**, где все аргументы разделены первым символом переменной `IFS` (обычно пробел).
- **`"$@"`** — разворачивается в **список строк**, где каждый аргумент представлен как отдельное слово. Это наиболее безопасный способ итерации по аргументам, сохраняющий пробелы внутри них.

```bash
# Пример: ./script.sh "arg 1" "arg 2"
for arg in "$*"; do echo "$arg"; done   # Результат: "arg 1 arg 2" (одна итерация)
for arg in "$@"; do echo "$arg"; done   # Результат: "arg 1" и "arg 2" (две итерации)
```

### Управление переменными

| Команда | Назначение |
| :--- | :--- |
| **`set`** | Вывод всех переменных (включая локальные) и функций оболочки. |
| **`env`** | Вывод всех экспортированных переменных окружения. |
| **`unset VAR`** | Удаление переменной из текущего сеанса. |
| **`readonly VAR`** | Запрет на изменение значения переменной. |

### Места хранения конфигурации (dotfiles)

Переменные, которые должны быть доступны постоянно, прописываются в файлах инициализации:

- **`/etc/environment`** — системные переменные для всех пользователей (не поддерживает скрипты).
- **`~/.bashrc`** — настройки для каждого нового интерактивного окна терминала.
- **`~/.bash_profile`** (или `~/.profile`) — настройки для **login shell** (выполняются один раз при входе).
