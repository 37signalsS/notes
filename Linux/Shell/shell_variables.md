# Переменные оболочки: локальные, окружения и специальные

## Определения

- **Shell Variable (Переменная оболочки)** — именованная область памяти в текущем сеансе Shell, предназначенная для хранения строковых данных или массивов.
- **Local Variable (Локальная переменная)** — переменная, доступная только в текущем процессе оболочки. Не наследуется дочерними процессами.
- **Environment Variable (Переменная окружения)** — переменная, экспортированная в окружение текущего процесса (`export`) и доступная всем его потомкам.
- **Массив (Array)** — структура данных для хранения нескольких значений. Бывают индексированные (числовые индексы) и ассоциативные (ключ-значение).
- **Parameter Expansion** — встроенный механизм оболочки для извлечения, манипуляции и проверки значений переменных без вызова внешних утилит (например, `sed` или `awk`).
- **Nameref** — ссылочная переменная (`declare -n`), которая указывает на имя другой переменной, позволяя изменять её значение косвенно.

## Базовые концепции

### Типы переменных и область видимости

| Тип | Команда | Наследование | Описание |
| :--- | :--- | :--- | :--- |
| **Локальная** | `VAR="val"` | Нет | Доступна только в текущем экземпляре Shell. |
| **Функциональная** | `local VAR="val"` | Нет | Доступна только внутри функции (Bash/Zsh). |
| **Окружения** | `export VAR="val"` | Да | Доступна текущему Shell и всем дочерним процессам. |

### Управление переменными: env, set, unset

- **`env`**: Выводит список всех переменных окружения.
- **`printenv`**: Аналог `env`, позволяет вывести значение конкретной переменной (`printenv PATH`).
- **`set`**: Выводит все переменные (окружения и локальные) и функции оболочки. Также используется для установки флагов оболочки (`set -e`).
- **`unset VAR`**: Удаляет переменную или функцию из текущей сессии.
- **`export -n VAR`**: Убирает флаг экспорта; переменная становится локальной.

### Атрибуты и команда declare

Команда `declare` (или `typeset`) задает тип и поведение переменной:

- `declare -i VAR`: Целое число. Присваивание строки вызовет арифметическое вычисление.
- `declare -r VAR`: Только для чтения (Read-only). Нельзя изменить или `unset`.
- `declare -x VAR`: Экспортировать в окружение.
- `declare -u VAR`: Автоматический перевод в ВЕРХНИЙ регистр.
- `declare -l VAR`: Автоматический перевод в нижний регистр.
- `declare -a / -A`: Индексированный / ассоциативный массивы.

### Специальные и встроенные переменные

Обновляются оболочкой автоматически:

| Переменная | Описание |
| :--- | :--- |
| **`$?`** | Код возврата последней команды ([подробнее](./exit_codes.md)). |
| **`$$`** | PID текущего процесса оболочки. |
| **`$!`** | PID последнего фонового процесса. |
| **`$0`** | Имя скрипта или оболочки. |
| **`$1, $2...`** | Позиционные параметры (аргументы скрипта). |
| **`$#`** | Количество переданных аргументов. |
| **`$-`** | Текущие флаги оболочки (например, `himBH`). |
| **`$_`** | Последний аргумент предыдущей команды. |
| **`$IFS`** | Разделитель полей (Internal Field Separator). По умолчанию: пробел, табуляция, новая строка. |
| **`$PATH`** | Список директорий для поиска исполняемых файлов. |

## Массивы в Bash

### Индексированные массивы

```bash
# Инициализация
declare -a APPS=("nginx" "redis" "postgres")
APPS+=("memcached") # Добавление

# Доступ
echo "${APPS[0]}"    # → nginx
echo "${APPS[@]}"    # → все элементы
echo "${#APPS[@]}"   # → 4 (длина массива)
echo "${!APPS[@]}"   # → 0 1 2 3 (индексы)

# Слайсинг (извлечение подмножества)
echo "${APPS[@]:1:2}" # → redis postgres
```

### Ассоциативные массивы (Bash 4.0+)

```bash
declare -A HOSTS
HOSTS=( ["srv1"]="10.0.0.1" ["srv2"]="10.0.0.2" )

echo "${HOSTS[srv1]}" # → 10.0.0.1
```

## Parameter Expansion: манипуляция данными

Эффективная обработка строк средствами Shell.

| Синтаксис | Назначение |
| :--- | :--- |
| **`${VAR:-def}`** | Использовать `def`, если `VAR` пуста или не задана. |
| **`${VAR:=def}`** | Присвоить `def`, если `VAR` пуста (не работает для позиционных параметров). |
| **`${VAR:+alt}`** | Использовать `alt`, если `VAR` **не** пуста. |
| **`${VAR:?err}`** | Вывести `err` и выйти, если `VAR` пуста. |
| **`${#VAR}`** | Длина строки. |
| **`${VAR:off:len}`** | Извлечение подстроки. |
| **`${VAR#pat}`** / **`${VAR##pat}`** | Удалить кратчайший / длиннейший префикс. |
| **`${VAR%pat}`** / **`${VAR%%pat}`** | Удалить кратчайший / длиннейший суффикс. |
| **`${VAR/pat/str}`** | Заменить первое вхождение `pat` на `str`. |
| **`${VAR//pat/str}`** | Заменить все вхождения. |
| **`${VAR^}`** / **`${VAR^^}`** | В верхний регистр (первая буква / всё). |
| **`${VAR,}`** / **`${VAR,,}`** | В нижний регистр (первая буква / всё). |
| **`${VAR@Q}`** | Значение переменной, экранированное для повторного ввода (Quoted). |

## Практические сценарии

### Динамические переменные (Nameref)

Позволяет передавать массивы или изменять переменные внутри функций "по ссылке".

```bash
#!/bin/bash
function update_config() {
    declare -n target=$1
    target="new_configuration_value"
}

MY_CONF="old"
update_config MY_CONF
echo "$MY_CONF" # → new_configuration_value
```

### Парсинг путей и расширений

```bash
FILE="/var/log/nginx/access.log.gz"

echo "${FILE##*/}"   # → access.log.gz (basename)
echo "${FILE%/*}"    # → /var/log/nginx (dirname)
echo "${FILE%%.*}"   # → /var/log/nginx/access (путь без всех расширений)
echo "${FILE#*.}"    # → log.gz (только расширения)
```

### Безопасное использование переменных в скриптах

```bash
# Прекратить работу, если переменная не задана
: "${DB_URL:?Ошибка: DB_URL не определена}"

# Установка значения по умолчанию для опционального параметра
LOG_LEVEL="${LOG_LEVEL:-INFO}"
```

## Дополнительная информация

### Жизненный цикл переменных (Dotfiles)

1.  **`/etc/environment`**: Статические пары `KEY=VALUE`, загружаемые PAM при входе (не скрипт!).
2.  **`~/.bash_profile`** / **`~/.profile`**: Выполняются один раз при логине (Login Shell). Место для `export PATH`.
3.  **`~/.bashrc`**: Выполняется для каждого нового окна терминала (Interactive Non-login Shell). Место для алиасов и функций.

### Различия "$*" и "$@"

Имеют значение только в двойных кавычках:
- **`"$*"`**: Все аргументы как **одна строка**, разделенная первым символом `$IFS`.
- **`"$@"`**: Каждый аргумент как **отдельное слово**. Рекомендуется для циклов `for`.
