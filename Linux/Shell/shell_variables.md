# Переменные оболочки: локальные, окружения и специальные

## Определения

- **Shell Variable (Переменная оболочки)** — именованная область памяти в текущем сеансе Shell, предназначенная для хранения строковых данных или массивов.
- **Local Variable (Локальная переменная)** — переменная, доступная только в текущем процессе оболочки. Не наследуется дочерними процессами. В функциях может быть ограничена областью видимости функции через `local`.
- **Environment Variable (Переменная окружения)** — глобальная переменная, экспортированная в окружение текущего процесса и доступная всем его потомкам.
- **Массив (Array)** — структура данных, позволяющая хранить несколько значений под одним именем. Поддерживаются индексированные (числовые индексы) и ассоциативные (строковые ключи) массивы.
- **Parameter Expansion** — механизм оболочки для извлечения, модификации и проверки значений переменных непосредственно в командной строке или скрипте.

## Базовые концепции

### Типы переменных и область видимости

| Тип | Объявление | Область видимости |
| :--- | :--- | :--- |
| **Локальная** | `VAR="value"` | Текущий Shell |
| **Локальная в функции** | `local VAR="value"` | Только внутри функции |
| **Окружения** | `export VAR="value"` | Текущий + дочерние процессы |

### Атрибуты и команда declare

Команда `declare` (или `typeset`) позволяет задавать специфические свойства переменным:

- `declare -i VAR`: Объявляет переменную как целое число. Арифметические операции выполняются автоматически при присваивании.
- `declare -r VAR`: Только для чтения (аналог `readonly`). Нельзя изменить или удалить.
- `declare -x VAR`: Экспортирует переменную в окружение (аналог `export`).
- `declare -u VAR`: При присваивании автоматически переводит текст в ВЕРХНИЙ регистр.
- `declare -l VAR`: При присваивании автоматически переводит текст в нижний регистр.
- `declare -n VAR`: **Nameref** (ссылка по имени). Позволяет обращаться к другой переменной через это имя.

### Специальные и встроенные переменные

Эти переменные обновляются оболочкой автоматически:

| Переменная | Описание |
| :--- | :--- |
| **`$?`** | Код возврата последней команды ([подробнее](./exit_codes.md)). |
| **`$$`** | PID текущего процесса оболочки. |
| **`$!`** | PID последнего фонового процесса. |
| **`$0`** | Имя скрипта или оболочки. |
| **`$1, $2...`** | Позиционные параметры (аргументы). |
| **`$#`** | Количество аргументов. |
| **`$*` / `$@`** | Все аргументы (разница описана в «Дополнительной информации»). |
| **`$PWD`** / **`$OLDPWD`** | Текущая и предыдущая рабочая директория. |
| **`$HOME`** | Домашняя директория пользователя. |
| **`$RANDOM`** | Генерирует случайное число (0–32767). |
| **`$SECONDS`** | Количество секунд с момента запуска оболочки. |
| **`$REPLY`** | Значение по умолчанию для команды `read`. |

## Массивы в Bash

### Индексированные массивы

```bash
# Объявление и инициализация
declare -a MY_ARRAY=("val1" "val2" "val3")
MY_ARRAY[0]="start"

# Доступ к элементам
echo "${MY_ARRAY[0]}"    # → start
echo "${MY_ARRAY[@]}"    # → все элементы
echo "${#MY_ARRAY[@]}"   # → количество элементов

# Добавление элемента
MY_ARRAY+=("new_val")
```

### Ассоциативные массивы (Bash 4.0+)

```bash
# Обязательное объявление через -A
declare -A CONF
CONF=( ["host"]="localhost" ["port"]="8080" )

echo "${CONF[host]}"     # → localhost
echo "${!CONF[@]}"       # → список всех ключей (индексов)
```

## Parameter Expansion: манипуляция значениями

Механизм `${VAR}` позволяет выполнять сложные трансформации строк без вызова внешних утилит.

| Синтаксис | Назначение |
| :--- | :--- |
| **`${VAR:-default}`** | Использовать `default`, если `VAR` пуста или не задана. |
| **`${VAR:=default}`** | Присвоить `default` переменной `VAR`, если она пуста. |
| **`${VAR:?error}`** | Вывести `error` и завершить работу, если `VAR` не задана. |
| **`${#VAR}`** | Длина строки в символах. |
| **`${VAR:offset:len}`** | Извлечение подстроки (с позиции `offset` длиной `len`). |
| **`${VAR#pattern}`** | Удаление кратчайшего префикса по шаблону. |
| **`${VAR##pattern}`** | Удаление длиннейшего префикса по шаблону. |
| **`${VAR%pattern}`** | Удаление кратчайшего суффикса по шаблону. |
| **`${VAR%%pattern}`** | Удаление длиннейшего суффикса по шаблону. |
| **`${VAR/pat/str}`** | Замена первого вхождения `pat` на `str`. |
| **`${VAR//pat/str}`** | Замена всех вхождений `pat` на `str`. |
| **`${!VAR}`** | **Косвенная подстановка**: значение переменной, чье имя хранится в `VAR`. |
| **`${!PREFIX*}`** | Список имен всех переменных, начинающихся на `PREFIX`. |

## Практические сценарии

### Использование Nameref для передачи переменных в функции

```bash
#!/bin/bash
function update_var() {
    declare -n ref=$1  # создаем ссылку на имя, переданное в аргументе
    ref="updated_value"
}

my_data="original"
update_var my_data
echo "$my_data"  # → updated_value
```

### Обработка путей к файлам

```bash
full_path="/etc/nginx/nginx.conf"
filename="${full_path##*/}"      # → nginx.conf
dir="${full_path%/*}"            # → /etc/nginx
ext="${full_path##*.}"           # → conf
base="${filename%.*}"            # → nginx
```

### Настройка окружения с проверкой

```bash
# Установка порта по умолчанию, если не задан
: "${APP_PORT:=8080}"
export APP_PORT

# Проверка обязательного секрета
: "${DB_PASSWORD?Ошибка: база данных требует пароль}"
```

## Дополнительная информация

### Различия "$*" и "$@"

Разница проявляется только при использовании в двойных кавычках:

- **`"$*"`** — все аргументы склеиваются в **одну строку**, разделенную первым символом `IFS` (обычно пробелом).
- **`"$@"`** — каждый аргумент остается **отдельным словом**. Это стандарт для циклов и передачи аргументов дальше, так как сохраняет пробелы внутри значений.

### Разделитель полей IFS (Internal Field Separator)

Переменная `IFS` определяет символы, по которым оболочка разбивает строку на слова (Word Splitting).
- Значение по умолчанию: ` \t\n` (пробел, табуляция, новая строка).
- Переопределение `IFS` часто используется для разбора CSV или `/etc/passwd`.

### Места хранения (Dotfiles)

1.  **`/etc/environment`**: Системные переменные (ключ=значение, без логики).
2.  **`~/.bashrc`**: Настройки для каждого интерактивного терминала (алиасы, функции, PS1).
3.  **`~/.bash_profile`** / **`~/.profile`**: Выполняются один раз при логине (настройка PATH, экспорт переменных).
