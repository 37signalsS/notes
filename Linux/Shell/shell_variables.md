# Переменные оболочки: локальные и окружения

## Определения

*   **Переменная оболочки (Shell Variable)** — именованное хранилище данных (строк) в текущем сеансе оболочки для параметризации команд и скриптов.
*   **Локальная переменная** — доступна только в процессе оболочки, где объявлена. Дочерние процессы не наследуют автоматически.
*   **Переменная окружения (Environment Variable)** — доступна в текущем процессе и во **всех дочерних процессах**, формирующих "среду" для программ.
*   **Область видимости (Scope)** — контекст, в котором переменная доступна.
*   **Parameter Expansion** — механизм bash для работы со значениями переменных "на лету".

## Основные концепции

### Локальная vs Переменная окружения

| Аспект | Локальная переменная | Переменная окружения |
|--------|---------------------|---------------------|
| **Объявление** | `VAR="value"` | `export VAR="value"` |
| **Видимость** | Только текущий процесс | Текущий + дочерние процессы |
| **Наследование** | Нет | Да |
| **Типичное использование** | Временные значения в скрипте | Конфигурация приложений |

### Объявление и использование

**Локальная переменная:**

```bash
# Объявляем локальную переменную
MY_LOCAL_VAR="Hello from local"

# В текущей оболочке она доступна
echo "В текущей оболочке: $MY_LOCAL_VAR"
# Вывод: В текущей оболочке: Hello from local

# Запускаем новый bash-процесс (дочерний) и пытаемся прочитать переменную
bash -c 'echo "В дочернем процессе: $MY_LOCAL_VAR"'
# Вывод: В дочернем процессе:
# (пустая строка, переменная недоступна)
```

**Переменная окружения:**

```bash
# Объявляем и экспортируем переменную
export MY_ENV_VAR="Hello from environment"

# В текущей оболочке она доступна
echo "В текущей оболочке: $MY_ENV_VAR"
# Вывод: В текущей оболочке: Hello from environment

# Запускаем новый bash-процесс (дочерний) и пытаемся прочитать переменную
bash -c 'echo "В дочернем процессе: $MY_ENV_VAR"'
# Вывод: В дочернем процессе: Hello from environment
```

### Parameter Expansion

Механизмы работы со значениями переменных:

| Синтаксис | Описание | Пример |
|-----------|----------|--------|
| `${VAR:-default}` | Значение по умолчанию (без изменения VAR) | `${REGION:-us-east-1}` |
| `${VAR:=default}` | Присвоить значение по умолчанию | `${PATH:=/bin}` |
| `${VAR:?message}` | Проверка существования (ошибка если пусто) | `${REQUIRED?Not set}` |
| `${VAR:+alternative}` | Альтернатива если VAR установлена | `${DEBUG:+--verbose}` |

> Подробнее об экранировании переменных см. в [Quoting](./quoting.md).

## Практические сценарии

### Временное изменение PATH

```bash
# Добавить /usr/local/go/bin в PATH для текущего сеанса
export PATH="/usr/local/go/bin:$PATH"

# Проверить новое значение
echo $PATH
```

### Конфигурация приложений через окружение

```bash
# Задать порт для веб-сервера
export APP_PORT=8080
./my_web_app  # Приложение читает APP_PORT
```

### Значения по умолчанию

```bash
# Если REGION не задана, используется 'us-east-1'
echo "Регион: ${REGION:-us-east-1}"

# Обязательная переменная (скрипт завершится с ошибкой)
: "${REQUIRED_VAR?Переменная REQUIRED_VAR не установлена}"
```

### Работа с переменными

```bash
# Удаление переменной
unset MY_VAR

# Защита от изменений
readonly MY_CONST="value"
MY_CONST="new"  # Ошибка: readonly variable

# Пометка для экспорта
export MY_VAR  # Экспорт существующей переменной
```

### "Чистая" среда

```bash
# Запуск команды без наследования окружения
env -i PATH=/usr/bin:/bin bash -c 'env'
```

## Дополнительная информация

### Команды для работы с переменными

| Команда | Описание |
|---------|----------|
| `set` | Все переменные оболочки, функции и опции |
| `env` / `printenv` | Только переменные окружения |
| `declare` | Переменные с атрибутами (`declare -x` — экспортированные) |
| `unset` | Удаление переменной |
| `readonly` | Создание переменной только для чтения |

### Часто используемые переменные окружения

| Переменная | Назначение |
|------------|------------|
| `PATH` | Путь поиска исполняемых файлов |
| `HOME` | Домашний каталог текущего пользователя |
| `USER` / `LOGNAME` | Имя текущего пользователя |
| `SHELL` | Путь к текущей командной оболочке |
| `LANG` / `LC_*` | Локаль системы |
| `PS1` | Строка приглашения командной строки |
| `TERM` | Тип терминала |
| `EDITOR` / `VISUAL` | Редактор по умолчанию |
| `PWD` / `OLDPWD` | Текущий / предыдущий каталог |

### Где задавать переменные

| Файл/механизм | Когда применяется | Примеры переменных |
|---------------|-------------------|-------------------|
| `/etc/environment` | Ко всем пользователям (PAM) | `LANG`, `HTTP_PROXY` |
| `/etc/profile.d/*.sh` | Login shell для всех | `PATH`, `JAVA_HOME` |
| `~/.profile`, `~/.bash_profile` | Login shell пользователя | `PATH`, `EDITOR` |
| `~/.bashrc` | Интерактивные bash-сессии | Алиасы, `PS1` |
| `~/.zshrc` | Интерактивные zsh | `PATH`, функции |
| `systemd --user` | Пользовательские сервисы | `systemctl --user import-environment VAR` |

### Особенности

*   **Регистр:** Имена переменных чувствительны к регистру (`VAR` ≠ `var`).
*   **Соглашение:** Переменные окружения — UPPERCASE (`PATH`), локальные — lowercase (`my_var`).
*   **Типы:** Все переменные окружения — строки. Массивы требуют сериализации.
