# Регулярные выражения (Regular Expressions)

## Определения

* **Регулярное выражение (regex, regexp)** — формальный язык для описания шаблонов поиска и манипуляции текстом. Позволяет находить, заменять, валидировать и извлекать подстроки на основе заданных правил.
* **BRE (Basic Regular Expressions)** — базовый стандарт POSIX (Portable Operating System Interface). Мета-символы `()`, `{}`, `|`, `+` требуют экранирования для интерпретации их специального значения.
* **ERE (Extended Regular Expressions)** — расширенный стандарт POSIX. Мета-символы `()`, `{}`, `|`, `+` работают как управляющие без экранирования.
* **PCRE (Perl Compatible Regular Expressions)** — диалект регулярных выражений, совместимый с языком Perl. Поддерживает расширенные функции: lookahead/lookbehind (просмотр вперед/назад), нежадные квантификаторы, именованные группы захвата.

## Базовые концепции

### Специальные символы и экранирование

Многие символы в регулярных выражениях имеют специальное (управляющее) значение (например, `$`, `*`, `?`, `.`, `\`, `/`). Для использования их как обычных текстовых литералов необходимо применять **экранирование** — добавление обратного слэша (`\`) перед символом.

> **Важно:** экранирование в regex отличается от [экранирования в Shell](./quoting.md). Это разные механизмы, обрабатываемые разными программами (Shell обрабатывает строку до передачи её утилите, которая затем интерпретирует regex).

### Якорные символы

Якоря привязывают шаблон к определённой позиции в строке, не соответствуя при этом никаким символам сами по себе.

* `^` (карет) — привязка к **началу** строки.
* `$` (доллар) — привязка к **концу** строки.

### Различия в обработке между утилитами

Поведение некоторых спецсимволов может варьироваться в зависимости от используемой утилиты (`grep`, `sed`, `awk`).

Например, символ `^` при поиске его как литерала:

* В `sed` его часто не требуется экранировать, если он не в начале шаблона.
* В `awk` его необходимо экранировать (`\^`), иначе он может быть интерпретирован как якорь начала строки.

### Точка и классы символов

#### Символ точки (`.`)

Точка соответствует **любому одиночному символу**, кроме символа новой строки.

* Шаблон `п.т` найдет "пат", "пот", "пэт", но не "пт".

#### Квадратные скобки (`[]`)

Позволяют указать набор символов, один из которых должен находиться на данной позиции.

* `[abc]` — соответствует `a`, `b` или `c`.
* `[0-9]` — диапазон цифр.
* `[а-я]` — диапазон строчных букв кириллицы.
* Регистр имеет значение: `[A-Z]` не эквивалентно `[a-z]`.

#### Отрицание в наборе (`[^]`)

Символ `^` в начале квадратных скобок инвертирует смысл набора. Шаблон соответствует **любому символу, кроме указанных**.

* `[^0-9]` — любой символ, не являющийся цифрой.

#### Именованные классы символов (POSIX)

Стандартизированные классы, записываемые в формате `[:class:]` внутри квадратных скобок `[ ]`.

* `[[:alpha:]]` — любая буква.
* `[[:digit:]]` — любая цифра.
* `[[:alnum:]]` — буква или цифра.
* `[[:space:]]` — любой пробельный символ.

### Квантификаторы

Указывают количество повторений предшествующего элемента.

* `*` — ноль или более раз.
* `?` — ноль или один раз.
* `+` — один или более раз.
* `{n}` — ровно `n` раз.
* `{n,}` — не менее `n` раз.
* `{n,m}` — от `n` до `m` раз включительно.

### Группировка и чередование

#### Группировка (`()`)

Позволяет объединить часть шаблона в единый блок. К группе можно применять квантификаторы или использовать её для захвата значения.

* Шаблон `(сис)?админ` найдет "админ" или "сисадмин".

#### Чередование (`|`)

Работает как логическое "ИЛИ", позволяя выбрать один из нескольких вариантов.

* Шаблон `сисадмин|программист` найдет строки, содержащие любое из этих слов.

## Практические сценарии

### Удаление пустых строк

Шаблон `^$` соответствует строке, в которой начало сразу переходит в конец (пустая строка).

```bash
# Вывод всех строк, кроме пустых (на примере awk)
awk '!/^$/' file.txt
```

### Валидация формата email

Пример регулярного выражения для базовой проверки email-адреса:

```regex
^([a-zA-Z0-9_.-+]+)@([a-zA-Z0-9_.-]+)\.([a-zA-Z]{2,5})$
```

**Разбор компонентов:**

* `^` и `$` — гарантируют, что вся строка целиком соответствует шаблону.
* `([a-zA-Z0-9_.-+]+)` — имя пользователя (буквы, цифры, точки, дефисы, плюсы).
* `@` — обязательный символ разделителя.
* `([a-zA-Z0-9_.-]+)` — доменное имя.
* `\.` — экранированная точка (разделитель домена верхнего уровня).
* `([a-zA-Z]{2,5})` — домен верхнего уровня (от 2 до 5 букв).

### Поиск в логах с помощью grep

Использование различных диалектов в `grep`:

```bash
# BRE (по умолчанию): требуется экранирование для '+'
grep 'error\+' log.txt

# ERE: '+' работает без экранирования
grep -E 'error+' log.txt

# PCRE: поддержка нежадных квантификаторов и lookahead
grep -P '(?<=status=)\d+' log.txt
```

## Дополнительная информация

### Сокращенные обозначения (диалект Perl)

Многие современные утилиты (включая `grep -P`) поддерживают короткие записи классов символов.

| Сокращение | Описание | Аналог POSIX |
| :--- | :--- | :--- |
| `\d` | Любая цифра | `[[:digit:]]` |
| `\D` | Любой символ, кроме цифры | `[^[:digit:]]` |
| `\w` | Символ слова (буква, цифра, `_`) | `[[:alnum:]_]` |
| `\W` | Не символ слова | `[^[:alnum:]_]` |
| `\s` | Пробельный символ | `[[:space:]]` |
| `\S` | Не пробельный символ | `[^[:space:]]` |
