# Регулярные выражения (Regular Expressions)

## Определения

- **Регулярное выражение (RegEx, RegExp)** — формальный язык для описания шаблонов поиска, валидации и манипуляции текстом.
- **Движок (Engine)** — программный модуль (библиотека), интерпретирующий регулярное выражение и выполняющий сопоставление с текстом.
- **BRE (Basic Regular Expressions)** — базовый стандарт POSIX. Метасимволы `()`, `{}`, `|`, `+` по умолчанию воспринимаются как литералы и требуют экранирования (`\(\)`, `\{\}`, `\|`, `\+`) для спецфункций.
- **ERE (Extended Regular Expressions)** — расширенный стандарт POSIX. Метасимволы работают как управляющие без экранирования.
- **PCRE (Perl Compatible Regular Expressions)** — наиболее мощный диалект, поддерживающий Lookaround (проверки), ленивые квантификаторы, именованные группы и расширенные классы символов (`\d`, `\w`).

## Основные концепции

### Взаимодействие с Shell

Regex — это строка, передаваемая программе (`grep`, `sed`, `awk`). Shell интерпретирует кавычки и переменные **до** того, как Regex-движок увидит строку.

**Золотое правило:** Всегда заключайте сложные Regex в **одинарные кавычки** (`' '`), чтобы защитить спецсимволы от интерпретации самой оболочкой.

```bash
# Shell увидит $ как переменную, если не использовать одинарные кавычки
grep 'end$' file.txt
```

### Диалекты и стандарты (SSoT)

| Функция | BRE (`grep`, `sed`) | ERE (`grep -E`, `awk`) | PCRE (`grep -P`) |
| :--- | :--- | :--- | :--- |
| **Группировка** | `\( \)` | `( )` | `( )` |
| **Чередование (ИЛИ)** | `\|` (не везде) | `|` | `|` |
| **Квантификатор `+`, `?`** | `\+`, `\?` | `+`, `?` | `+`, `?` |
| **Интервалы `{n,m}`** | `\{n,m\}` | `{n,m}` | `{n,m}` |
| **Ленивость `*?`** | Нет | Нет | Да |
| **Lookaround** | Нет | Нет | Да |

### Якоря и границы слова

Якоря определяют позицию, а не конкретный символ.

- **`^`** — начало строки.
- **`$`** — конец строки.
- **`\b`** (Word Boundary) — граница слова (стык буквенно-цифрового символа и любого другого).
- **`\B`** — позиция, НЕ являющаяся границей слова.
- **`^$`** — пустая строка.
- **`^[[:space:]]*$`** — пустая строка или строка только из пробелов.

### Квантификаторы и жадность

Квантификаторы управляют количеством повторений. По умолчанию они **жадные (greedy)** — стремятся захватить как можно более длинную подстроку.

- **`*`**: 0 или более.
- **`+`**: 1 или более.
- **`?`**: 0 или 1.
- **`{n}`**: ровно n раз.
- **`*?` / `+?`**: **ленивые (lazy)** версии (только в PCRE). Находят кратчайшее совпадение.

### Классы символов и POSIX выражения

#### Квадратные скобки `[]`
- `[abc]` — любой из символов a, b или c.
- `[^abc]` — любой символ, КРОМЕ a, b и c.
- `[a-z0-9]` — диапазоны символов.

#### POSIX Bracket Expressions
Используются для переносимости (например, если локаль влияет на алфавитный порядок).

| POSIX Класс | Описание | Эквивалент (обычно) |
| :--- | :--- | :--- |
| **`[[:alnum:]]`** | Буквы и цифры | `[a-zA-Z0-9]` |
| **`[[:alpha:]]`** | Только буквы | `[a-zA-Z]` |
| **`[[:digit:]]`** | Цифры | `[0-9]` или `\d` |
| **`[[:lower:]]`** | Строчные буквы | `[a-z]` |
| **`[[:upper:]]`** | Заглавные буквы | `[A-Z]` |
| **`[[:space:]]`** | Пробельные символы | `[ \t\n\r\f\v]` или `\s` |
| **`[[:punct:]]`** | Знаки пунктуации | `[!"#$%&'()*+,-./:;<=>?@[\]^_`{|}~]` |

### Группировка и обратные ссылки (Backreferences)

Группы `( )` позволяют применять квантификаторы к целым выражениям и обращаться к найденному тексту через `\1`, `\2` и т.д.

```bash
# Поиск повторяющихся слов в строке (PCRE)
echo "test test" | grep -P '(\b\w+\b) \1'
```

## Практические сценарии

### Очистка конфигурационных файлов
Удаление всех комментариев и пустых строк (BRE/ERE).

```bash
# d — команда удаления в sed
sed -E '/^[[:space:]]*(#|;|$)/d' config.ini
```

### Парсинг логов: извлечение IP и статуса
Использование групп для извлечения конкретных данных.

```bash
# Извлечение IP и HTTP кода (PCRE)
grep -Po '^(\d{1,3}\.){3}\d{1,3}.*? \K\d{3}' access.log
```
*Примечание: `\K` в PCRE сбрасывает совпадение до этой точки (используется как Lookbehind).*

### Валидация сложных условий (Lookahead)
Найти строки, которые содержат "error", но НЕ содержат "ignore".

```bash
grep -P '^(?=.*error)(?!.*ignore).*$' app.log
```
