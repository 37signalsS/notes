# Регулярные выражения (Regular Expressions)

## Определения

- **Регулярное выражение (RegEx, RegExp)** — формальный язык для описания шаблонов поиска и манипуляции текстом. Позволяет находить, заменять, валидировать и извлекать подстроки на основе заданных правил.
- **BRE (Basic Regular Expressions)** — базовый стандарт POSIX. Метасимволы `()`, `{}`, `|`, `+` требуют экранирования (`\(\)`, `\{\}`, `\|`, `\+`) для интерпретации их специального значения. Используется в `grep` (по умолчанию), `sed`.
- **ERE (Extended Regular Expressions)** — расширенный стандарт POSIX. Метасимволы работают как управляющие без экранирования. Используется в `grep -E`, `awk`, `egrep`.
- **PCRE (Perl Compatible Regular Expressions)** — наиболее мощный диалект (Perl-совместимый). Поддерживает просмотр вперед/назад (Lookaround), ленивые квантификаторы, именованные группы. Используется в `grep -P`, `git grep -P`, многих языках программирования.

## Основные концепции

### Специальные символы и экранирование

Символы, имеющие управляющее значение (`$`, `*`, `+`, `.`, `?`, `[`, `]`, `(`, `)`, `|`, `\`, `/`), называются метасимволами. Для их поиска как обычного текста используется экранирование обратным слэшем (`\`).

> **Важно:** Экранирование в Regex — это механизм *программы* (grep, sed), а не оболочки. Shell обрабатывает кавычки и переменные **до** того, как строка попадет в Regex-движок. См. [Экранирование в Shell](./quoting.md).

### Якоря и границы

Якоря не соответствуют символам, а указывают на позицию в тексте.

- **`^`** — начало строки.
- **`$`** — конец строки.
- **`\b`** (Word Boundary) — граница слова (позиция между символом слова `\w` и не-символом слова или краем строки).
- **`\B`** — позиция, не являющаяся границей слова.

```bash
# Поиск слова "bin", исключая "sbin" или "binary"
echo "sbin bin binary" | grep -o '\bbin\b'
# → bin
```

### Квантификаторы и жадность

Квантификаторы определяют, сколько раз должен повториться предшествующий элемент.

| Квантификатор | Описание | Примечание |
| :--- | :--- | :--- |
| **`*`** | 0 или более | Жадный (greedy) |
| **`+`** | 1 или более | Жадный |
| **`?`** | 0 или 1 | Жадный |
| **`{n}`** | Ровно `n` | |
| **`{n,}`** | `n` или более | |
| **`{n,m}`** | От `n` до `m` | |
| **`*?`, `+?`** | Ленивые аналоги | PCRE: находят кратчайшее совпадение |

**Пример жадности:**
Строка: `<b>текст</b> и еще <b>текст</b>`
- Шаблон `<b>.*</b>`: найдет всю строку от первого до последнего тега (жадность).
- Шаблон `<b>.*?</b>`: найдет отдельно каждое вхождение `<b>текст</b>` (лень, PCRE).

### Классы символов

- **`[abc]`** — один любой из указанных символов.
- **`[^abc]`** — один любой символ, **кроме** указанных.
- **`[0-9]`**, **`[a-z]`** — диапазоны.
- **`.`** (точка) — любой один символ, кроме новой строки `\n`.

#### Стандартные классы (POSIX и Perl)

| Класс | Описание | Аналог POSIX |
| :--- | :--- | :--- |
| **`\d`** | Цифра | `[[:digit:]]` |
| **`\w`** | Буква, цифра или `_` | `[[:alnum:]_]` |
| **`\s`** | Пробел, табуляция | `[[:space:]]` |
| **`\D`, `\W`, `\S`** | Отрицание вышеперечисленных | `[^...]` |

### Группировка и обратные ссылки

Группировка `()` позволяет применять квантификаторы к блоку и "запоминать" совпадение для последующего использования через `\1`, `\2` и т.д.

```bash
# Поиск повторяющихся слов
echo "hello hello world" | grep -P '(\b\w+\b) \1'
# → hello hello
```

### Проверки (Lookaround, только PCRE)

Позволяют искать шаблон, основываясь на том, что находится до или после него, не включая эти части в результат совпадения.

- **`(?=pattern)`** — опережающая проверка (Lookahead).
- **`(?<=pattern)`** — ретроспективная проверка (Lookbehind).

```bash
# Найти число, перед которым стоит "id="
echo "user_id=123" | grep -Po '(?<=id=)\d+'
# → 123
```

## Сравнение диалектов (SSoT)

| Функция | BRE (`grep`) | ERE (`grep -E`) | PCRE (`grep -P`) |
| :--- | :--- | :--- | :--- |
| Группировка | `\( \)` | `( )` | `( )` |
| Чередование (ИЛИ) | `\|` | `|` | `|` |
| Квантификатор `+`, `?` | `\+`, `\?` | `+`, `?` | `+`, `?` |
| Интервалы `{n,m}` | `\{n,m\}` | `{n,m}` | `{n,m}` |
| Ленивость `*?` | Нет | Нет | Да |
| Lookaround | Нет | Нет | Да |
| Классы `\d`, `\s` | Нет (зависит от версии) | Обычно да | Да |

## Практические сценарии

### Валидация IP-адреса (базовая)

```regex
^([0-9]{1,3}\.){3}[0-9]{1,3}$
```

### Извлечение даты из лога (формат ISO 8601)

```bash
# Поиск строк, начинающихся с даты 2023-10-24
grep -E '^2023-10-24' access.log
```

### Поиск сложных паролей (Lookahead)

Требование: минимум 8 символов, хотя бы одна цифра и одна заглавная буква.

```regex
^(?=.*[0-9])(?=.*[A-Z]).{8,}$
```

### Удаление комментариев из конфигурации

```bash
# Удалить строки, начинающиеся с # или ; (включая пробелы перед ними)
sed -E '/^[[:space:]]*[#;]/d' config.conf
```
