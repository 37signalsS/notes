# Регулярные выражения (Regular Expressions)

## Определения

**Регулярное выражение** — это последовательность символов, которая определяет шаблон поиска. Они используются для поиска, замены и валидации строк.

## Основные Концепты

### 1. Специальные символы и экранирование

Многие символы в регулярных выражениях имеют специальное значение (например, `$`, `*`, `?`, `.` `\`, `/`). Чтобы использовать их как обычные символы, их необходимо **экранировать**, добавив перед ними обратный слэш (`\`).

**Пример с `awk`:**

Для поиска строки, содержащей символ `$`, его нужно экранировать:

```bash
awk '/\\$/' my_file.txt
```

То же самое касается и других спецсимволов, например, прямого слэша `/` в `sed` или `awk`, который часто используется как разделитель.

```bash
awk '/\\//' my_file.txt
```

### 2. Якорные символы

Якорные символы привязывают шаблон к определённой позиции в строке.

- `^` (карет) — привязка к **началу** строки.
- `$` (доллар) — привязка к **концу** строки.

**Пример:**

Допустим, файл `names.txt` содержит:

```
Петя хороший сисадмин
Хороший сисадмин это Петя
```

- Найти строки, **начинающиеся** на "Петя":

    ```bash
    awk '/^Петя/' names.txt
    # Вывод: Петя хороший сисадмин
    ```

- Найти строки, **заканчивающиеся** на "Петя":

    ```bash
    awk '/Петя$/' names.txt
    # Вывод: Хороший сисадмин это Петя
    ```

- Найти строки, которые **в точности** соответствуют "Петя хороший сисадмин":

    ```bash
    awk '/^Петя хороший сисадмин$/' names.txt
    ```

### 3. Различия в обработке между утилитами (`sed` vs `awk`)

Поведение некоторых спецсимволов может отличаться в разных утилитах.

Например, символ `^` при поиске его как литерала:

- В `sed` его не нужно экранировать.
- В `awk` его необходимо экранировать (`\^`), иначе он будет интерпретирован как якорный символ.

### 4. Символ `.` и классы символов

#### 4.1. Символ `.` (точка)

Точка `.` — это метасимвол, который соответствует **любому одиночному символу**, за исключением символа новой строки.

**Пример:**
Шаблон `п.т` найдет "пат", "пот", "пэт", но не "пт".

```bash
# Пример с awk: найти строки, где есть "пет" и любой следующий символ
awk '/пет./' my_file.txt
# Возможный вывод: "петя", "пета", "петер"
```

#### 4.2. Квадратные скобки `[]`

Квадратные скобки позволяют указать **набор символов**, любой из которых может находиться на данной позиции.

- `[abc]` — соответствует `a`, `b` или `c`.
- `[0-9]` — **диапазон**, соответствует любой цифре от 0 до 9.
- `[а-я]` — **диапазон**, соответствует любой строчной букве русского алфавита.
- Регистр имеет значение: `[A-Z]` не то же самое, что `[a-z]`.

**Пример:**
Найти строки, где после "д" идет "о", "и" или "р".

```bash
awk '/д[оир]/' my_file.txt
# Возможный вывод: "директория", "дракон"
```

#### 4.3. Отрицание `[^]`

Символ `^` в начале набора в квадратных скобках инвертирует его значение. Шаблон будет соответствовать **любому символу, кроме указанных**.

- `[^abc]` — соответствует любому символу, кроме `a`, `b` или `c`.
- `[^0-9]` — соответствует любому символу, не являющемуся цифрой.

**Пример:**
Найти строки, где после "пет" идет любой символ, кроме "я".

```bash
awk '/пет[^я]/' my_text.txt
# Возможный вывод: "петю" (но не "петя")
```

#### 4.4. Именованные классы символов (POSIX)

Для удобства существуют предопределённые именованные классы. Они записываются в формате `[:class:]` и должны использоваться внутри квадратных скобок `[ ]`.

- `[[:alpha:]]` — любая буква (`[A-Za-z]`).
- `[[:digit:]]` — любая цифра (`[0-9]`).
- `[[:alnum:]]` — любая буква или цифра.
- `[[:space:]]` — любой пробельный символ (пробел, таб, и т.д.).
- `[[:upper:]]` — любая буква в верхнем регистре.
- `[[:lower:]]` — любая буква в нижнем регистре.
- `[[:punct:]]` — любой знак пунктуации.

**Пример:**
Найти последовательность "две цифры и одна буква".

```bash
echo "12a" | awk '/[[:digit:]][[:digit:]][[:alpha:]]/'
# Вывод: 12a
```

### 5. Квантификаторы (указание количества повторений)

Квантификаторы позволяют указать, сколько раз должен встречаться предшествующий символ, группа или класс символов.

- `*` (звёздочка) — ноль или более раз.
- `?` (вопросительный знак) — ноль или один раз.
- `+` (плюс) — один или более раз.
- `{n}` — ровно `n` раз.
- `{n,}` — не менее `n` раз.
- `{n,m}` — от `n` до `m` раз включительно.

**Примеры:**

- Шаблон `п.*р` найдет "петр", "пир", "программист" (любые символы между "п" и "р").
- Шаблон `админ?` найдет "адми" и "админ".
- Шаблон `сис.+` найдет "система", "сисадмин" (любая строка, начинающаяся с "сис" и имеющая хотя бы один символ после).
- Шаблон `[0-9]{3}` найдет любую последовательность из трёх цифр.

### 6. Группировка и чередование

#### 6.1. Группировка `()`

Круглые скобки `()` позволяют сгруппировать часть шаблона в единый элемент. К этому элементу можно применять квантификаторы.

**Пример:**
Шаблон `(сис)?админ` будет искать "админ" или "сисадмин". Здесь `?` относится ко всей группе `(сис)`.

#### 6.2. Чередование `|` (Логическое ИЛИ)

Вертикальная черта `|` работает как оператор "ИЛИ" и позволяет указать несколько альтернативных вариантов.

**Пример:**
Шаблон `сисадмин|программист` найдет строки, содержащие "сисадмин" или "программист".

## Практические сценарии

### Фильтрация пустых строк

С помощью якорных символов можно легко удалять пустые строки из вывода. Шаблон `^$` соответствует строке, у которой начало (`^`) сразу же сменяется концом (`$`), то есть пустой строке.

**Пример с `awk`:**

Используя оператор отрицания `!`, можно вывести все строки, **не** соответствующие шаблону.

```bash
# Файл a.txt
line 1

line 3
```

```bash
awk '!/^$/' a.txt
```

**Результат:**

```
line 1
line 3
```

Это произошло потому, что:

1. Шаблон `/^$/` нашел все пустые строки.
2. Оператор `!` инвертировал результат, и `awk` распечатал только те строки, которые не соответствуют шаблону (т.е. непустые).

### Валидация email-адресов

Регулярные выражения позволяют проверять строки на соответствие сложному формату, например, email-адресу.

**Пример регулярного выражения для email-адреса:**

```regex
^([a-zA-Z0-9_.-+]+)@([a-zA-Z0-9_.-]+)\.([a-zA-Z]{2,5})$
```

**Разбор компонентов:**

- `^` — Начало строки. Указывает, что совпадение должно начинаться с самого начала текста.
- `(`...`)` — Группировка. Позволяет объединять части регулярного выражения. Каждая такая группа называется "захватывающей" (capturing group) и может быть извлечена отдельно.
- `[a-zA-Z0-9_.-+]` — Класс символов для **имени пользователя (логина)**.
  - `a-zA-Z` — Любая латинская буква (в нижнем или верхнем регистре).
  - `0-9` — Любая цифра.
  - `_` — Символ нижнего подчеркивания.
  - `.` — Точка (экранировать не нужно внутри `[]`).
  - `-` — Дефис (экранировать не нужно внутри `[]`, если он не первый или последний).
  - `+` — Знак плюс (экранировать не нужно внутри `[]`).
- `+` (после класса символов) — Квантификатор: класс символов должен повторяться один или более раз. Это означает, что имя пользователя не может быть пустым.
- `@` — Символ "собака". Соответствует сам себе.
- `([a-zA-Z0-9_.-]+)` — Класс символов для **доменного имени (без домена верхнего уровня)**. Аналогичен классу для имени пользователя, но без знака `+`. Также должен повторяться один или более раз.
- `\.` — Экранированная точка. Разделяет доменное имя и домен верхнего уровня. Точка (`.`) является специальным символом в регулярных выражениях (соответствует любому символу), поэтому для поиска самой точки её необходимо экранировать обратным слэшем `\`.
- `([a-zA-Z]{2,5})` — Класс символов для **домена верхнего уровня (TLD)**.
  - `a-zA-Z` — Только латинские буквы (нижний или верхний регистр).
  - `{2,5}` — Квантификатор: TLD должен состоять минимум из 2 и максимум из 5 символов (например, `ru`, `com`, `info`, `name`).
- `$` — Конец строки. Указывает, что совпадение должно заканчиваться в самом конце текста.

Это регулярное выражение является достаточно полным для базовой проверки формата email, но не охватывает все крайние случаи и международные стандарты (например, Punycode).

## Дополнительная информация

- Регулярные выражения являются мощным инструментом, широко применяемым в `grep`, `sed`, `awk`, `bash`, а также в большинстве языков программирования.
- Существуют разные "диалекты" регулярных выражений (BRE, ERE, PCRE), которые могут иметь небольшие различия в синтаксисе и функциональности.
