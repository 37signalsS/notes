# tmux — терминальный мультиплексор

**Актуально для:** tmux 3.4+

`tmux` (terminal multiplexer) — утилита для разделения терминала на окна и панели, а также сохранения сессий при обрыве соединения. В 2026 году считается современной заменой `screen` благодаря лучшей поддержке цветов, UTF-8 и clipboard.

## Определения

- **Сессия (session):** Верхний уровень иерархии. Может содержать несколько окон.
- **Окно (window):** Аналог вкладки в браузере. Может содержать несколько панелей.
- **Панель (pane):** Индивидуальный терминал внутри окна.
- **Префикс (prefix):** Клавиатурная комбинация, активирующая режим ввода команд tmux. По умолчанию `Ctrl + B`.

## Практические сценарии

### Управление сессиями

```bash
# Создать новую именованную сессию
tmux new-session -s work

# Подключиться к существующей сессии
tmux attach-session -t work

# Список активных сессий
tmux ls

# Отключиться от сессии (оставив процессы работать)
# <prefix> d

# Завершить сессию и все её окна
tmux kill-session -t work
```

### Разделение и навигация по панелям

```bash
# Разделить текущую панель на левую и правую (горизонтально)
# <prefix> %

# Разделить текущую панель на верхнюю и нижнюю (вертикально)
# <prefix> "

# Переместить фокус на соседнюю панель
# <prefix> <стрелки>

# Изменить размер панели на 5 строк вниз
tmux resize-pane -D 5
```

### Управление окнами

```bash
# Создать новое окно в текущей сессии
# <prefix> c

# Переименовать текущее окно
# <prefix> ,

# Перейти в окно по номеру
# <prefix> 0-9
```

### Режим копирования

```bash
# Войти в режим прокрутки/копирования
# <prefix> [

# Навигация стрелками или vi-клавишами (в зависимости от конфигурации)
# Для выхода: q или Esc
```

### Синхронизация панелей

```bash
# Отправлять ввод во все панели одновременно (операции на нескольких серверах)
tmux setw synchronize-panes on
```

### Автоматизация

```bash
# Выполнить команду во всех панелях текущей сессии
tmux list-panes -s -F '#{session_name}:#{window_index}.#{pane_index}' | \
  xargs -I{} tmux send-keys -t {} 'uptime' Enter

# Создать фоновую сессию и подать команду (выживает разрыв SSH)
tmux new-session -d -s work && tmux send-keys -t work 'tail -f /var/log/app.log' Enter

# Сохранить последние 3000 строк панели в файл
tmux capture-pane -p -S -3000 -t work > /tmp/pane.log
```

## Дополнительная информация

### Схожие утилиты

- **`screen`:** Классический мультиплексор. Поддерживается широко, но менее гибок. [Справка по screen](./cli-tools.md).
- **`mosh`:** Mobile shell — для ненадёжных соединений с автоматическим восстановлением после смены IP.
