# Конструкции для написания скриптов на Bash

## Определения

- **Управляющие конструкции (Control Structures)**: Блоки кода для управления ходом выполнения скрипта — условные операторы (`if`, `case`) и циклы (`for`, `while`).
- **Позиционные параметры и специальные переменные**: Автоматически создаваемые оболочкой переменные для доступа к аргументам скрипта и среде выполнения.

---

## Базовые концепции

### 1. Позиционные параметры и специальные переменные

- **Позиционные параметры**: `$0` — имя скрипта, `$1`, `$2`, ... — аргументы.
- **Специальные переменные**:
  - `$#` — количество аргументов.
  - `$*` — все аргументы **одной строкой**.
  - `$@` — все аргументы **отдельными строками** (предпочтительно для итерации).
  - `$?` — [код возврата](exit_codes.md) последней команды.
  - `$$` — PID текущего скрипта. Подробнее: [fork()/exec()](../Core/processes/basic_concepts.md).
  - `$!` — PID последнего фонового процесса.

См. также: [Переменные оболочки](shell_variables.md), [Кавычки](quoting.md).

### 2. Условные операторы

#### `if / else / elif`

```bash
if условие1; then
    # если условие1 истинно
elif условие2; then
    # если условие2 истинно
else
    # если ни одно не истинно
fi
```

**Способы проверки:**

1. **`[ ]` (одинарные скобки)** — команда `test`, переносимый стандарт.
   - `-f "file"` — файл существует; `-d "dir"` — директория существует.
   - `-z "$VAR"` — переменная пуста; `"$A" = "$B"` — строки равны.
   - `"$A" -eq "$B"` — числа равны.

2. **`[[ ]]` (двойные скобки)** — расширение Bash, **рекомендуется**.
   - Логические операторы: `[[ -f "f" && -r "f" ]]`.
   - Шаблоны: `[[ "$VAR" == *.txt ]]`.
   - Регулярные выражения: `[[ "$VAR" =~ [0-9]+ ]]`.

#### `case`

Альтернатива `if/elif/else` для проверки одной переменной на несколько шаблонов.

```bash
case "$переменная" in
    "шаблон1")
        # для шаблона 1
        ;;
    "шаблон2" | "шаблон3")
        # для шаблона 2 или 3
        ;;
    *)
        # по умолчанию
        ;;
esac
```

### 3. Циклы

#### `for`

```bash
# Итерация по элементам
for item in 1 2 3; do
    echo "Элемент: $item"
done

# C-подобный цикл
for (( i=0; i<5; i++ )); do
    echo "Итерация: $i"
done
```

#### `while`

```bash
count=0
while [ $count -lt 5 ]; do
    echo "Счетчик: $count"
    count=$((count + 1))
done
```

## Практические сценарии

### Проверка прав root

```bash
if [ "$(id -u)" -ne 0 ]; then
    echo "Требуются права root." >&2
    exit 1
fi
```

### Обработка аргументов с `case`

```bash
#!/bin/bash
case "$1" in
    "start")  echo "Запускаем сервис..." ;;
    "stop")   echo "Останавливаем сервис..." ;;
    "status") echo "Проверяем статус..." ;;
    *)
        echo "Ошибка: неизвестная команда '$1'." >&2
        echo "Используйте: $0 {start|stop|status}" >&2
        exit 1
        ;;
esac
```

### Итерация по файлам `.log`

```bash
#!/bin/bash
for logfile in *.log; do
    if [[ -f "$logfile" && -s "$logfile" ]]; then
        echo "Архивируем $logfile..."
        tar -czf "$logfile.tar.gz" "$logfile"
    else
        echo "Пропускаем $logfile (не существует или пуст)."
    fi
done
```

## Дополнительная информация

### `"$*"` vs `"$@"`

- `"$*"` — все аргументы **одной строкой**, разделённые `$IFS`.
- `"$@"` — каждый аргумент **отдельной строкой** (безопасно для итерации).

```bash
# ./test.sh "arg 1" "arg 2"
for arg in "$*"; do echo "$arg"; done   # "arg 1 arg 2" (одна строка)
for arg in "$@"; do echo "$arg"; done   # "arg 1" \n "arg 2" (отдельно)
```

**Правило:** всегда используйте `"$@"` для итерации по аргументам. `$*` или `$@` без кавычек приводят к word splitting.

### `while read` в пайплайнах: Subshell

В конструкции `command | while read var; do ... done` цикл `while` выполняется в subshell — изменения переменных не видны в родительской оболочке.

```bash
counter=0
echo "1" | while read line; do
    counter=$((counter + 1))
done
echo "$counter"  # 0 — изменения потеряны
```

**Решения:** перенаправление ввода (`while read line < file.txt; do ... done`) или process substitution (`while read line; do ... done < <(command)`).
