# Конструкции для написания скриптов на Bash

## Определения

- **Управляющие конструкции (Control Structures)** — блоки кода, определяющие логику и порядок выполнения скрипта: условия (`if`, `case`) и циклы (`for`, `while`, `until`).
- **Код возврата (Exit Code)** — числовое значение, возвращаемое командой после завершения (0 — успех, не 0 — ошибка). Подробнее: [Коды возврата](./exit_codes.md).

---

## Базовые концепции

### 1. Позиционные параметры и специальные переменные

Bash автоматически создает набор переменных для доступа к аргументам скрипта и информации о среде выполнения.

- **`$0`** — имя скрипта.
- **`$1, $2...`** — аргументы командной строки.
- **`$#`** — количество переданных аргументов.
- **`$@`** — все аргументы как отдельные слова.
- **`$?`** — результат выполнения последней команды.

Полный список и правила использования (включая различия `"$*"` и `"$@"`) см. в разделе: [Специальные переменные Shell](./shell_variables.md#специальные-переменные-shell).

### 2. Арифметика в Bash

В Bash все переменные по умолчанию являются строками. Для выполнения арифметических операций используются специальные конструкции:

- **`(( ))`** — арифметическое вычисление (рекомендуется). Возвращает 0 (успех), если результат не равен 0.
- **`let`** — встроенная команда для присваивания арифметических значений.
- **`expr`** — внешняя утилита (устарело, требует пробелов).

```bash
# Использование (( ))
(( a = 5 + 3 ))
(( a++ ))
if (( a > 5 )); then echo "Больше 5"; fi

# Использование let
let "b = 10 / 2"
let b++
```

### 3. Условные операторы

#### Оператор `if / else / elif`

Позволяет выполнять блоки кода в зависимости от результата проверки условия.

```bash
if условие1; then
    # если условие1 истинно
elif условие2; then
    # если условие2 истинно
else
    # если ни одно условие не выполнено
fi
```

**Инструменты проверки:**

1. **`[ ]` (одинарные скобки)** — вызов команды `test`. Требует пробелов внутри скобок.
   - Сравнение чисел: `-eq`, `-ne`, `-gt`, `-ge`, `-lt`, `-le`.
   - Сравнение строк: `==`, `!=`, `>`, `<`.
   - Файлы: `-f` (файл), `-d` (директория), `-e` (существует), `-r` (доступ на чтение).
2. **`[[ ]]` (двойные скобки)** — расширенная конструкция Bash (**рекомендуется**).
   - Поддерживает регулярные выражения: `[[ "$VAR" =~ [0-9]+ ]]`.
   - Поддерживает шаблоны (globbing): `[[ "$VAR" == *.txt ]]`.
   - Не требует кавычек вокруг переменных для защиты от word splitting.

**Пустой блок**: Если в ветке `if` не нужно ничего выполнять, используется команда-заглушка `:` (no-op).

```bash
if [[ $skip -eq 1 ]]; then
    : # ничего не делаем
else
    do_something
fi
```

#### Оператор `case`

Эффективная замена множественным `if/elif`, когда проверяется одна переменная на соответствие шаблонам.

```bash
case "$variable" in
    "pattern1")
        # команды для pattern1
        ;;
    "pattern2" | "pattern3")
        # команды для pattern2 или pattern3
        ;;
    *)
        # действие по умолчанию (аналог else)
        ;;
esac
```

### 4. Циклы

#### Цикл `for`

Используется для итерации по списку элементов или выполнения действий заданное количество раз.

```bash
# Итерация по списку
for item in apple orange banana; do
    echo "Fruit: $item"
done

# C-style цикл
for (( i=0; i<5; i++ )); do
    echo "Iteration: $i"
done
```

#### Цикл `while` и `until`

- **`while`**: выполняется, пока условие **истинно**.
- **`until`**: выполняется, пока условие **ложно** (до наступления истинности).

```bash
# While
count=0
while [[ $count -lt 5 ]]; do
    echo "Count: $count"
    ((count++))
done

# Until
until [[ $finished -eq 1 ]]; do
    check_status
done
```

#### Управление циклами

- **`break`** — немедленный выход из цикла.
- **`continue`** — переход к следующей итерации цикла.

#### Бесконечные циклы

```bash
while true; do ...; done
while :; do ...; done
for (( ; ; )); do ...; done
```

### 5. Функции

Функции в Bash позволяют группировать код для повторного использования.

**Особенности:**

- Должны быть определены **до** их первого вызова в скрипте.
- Используют те же позиционные параметры (`$1`, `$2`), что и скрипт, но локально.
- Возвращают только **код возврата** (через `return` или статус последней команды).

```bash
# Определение функции
greet() {
    local name="$1"  # локальная переменная
    echo "Hello, $name"
    return 0
}

# Вызов функции
greet "Alice"
```

### 6. Массивы

Bash поддерживает одномерные индексированные и ассоциативные массивы.

```bash
# Объявление и инициализация
apps=("docker" "git" "bash")

# Доступ по индексу (с нуля)
echo ${apps[0]}

# Все элементы
echo ${apps[@]}

# Список индексов
echo ${!apps[@]}

# Добавление элемента
apps+=("vim")
```

## Практические сценарии

### Проверка прав суперпользователя (root)

```bash
if [[ $EUID -ne 0 ]]; then
   echo "Этот скрипт должен быть запущен от имени root" >&2
   exit 1
fi
```

### Обработка аргументов командной строки

```bash
#!/bin/bash
case "$1" in
    "start")
        systemctl start my_service
        ;;
    "stop")
        systemctl stop my_service
        ;;
    *)
        echo "Использование: $0 {start|stop}"
        exit 1
        ;;
esac
```

## Дополнительная информация

### Влияние конвейеров на область видимости переменных

При использовании `while read` в конвейере (`command | while read ...`), цикл запускается в **дочерней оболочке** (Subshell). Изменения переменных внутри такого цикла не сохраняются в основной оболочке.

**Пример проблемы:**

```bash
count=0
ls | while read file; do
    ((count++))
done
echo "$count" # Выведет 0, так как count изменился в subshell
```

**Решение (Process Substitution):**

```bash
count=0
while read file; do
    ((count++))
done < <(ls)
echo "$count" # Выведет корректное число
```

Подробнее о механизмах выполнения см. в: [Выполнение скриптов Bash](./bash_scripting_execution.md).
