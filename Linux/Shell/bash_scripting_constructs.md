# Конструкции для написания скриптов на Bash

## Определения

- **Шебанг (Shebang)** — первая строка скрипта (`#!`), указывающая системе путь к интерпретатору, который должен выполнить данный файл (например, `#!/bin/bash`).
- **Управляющие конструкции (Control Structures)** — блоки кода, определяющие логику и порядок выполнения скрипта: условия (`if`, `case`, `select`) и циклы (`for`, `while`, `until`).
- **Область видимости (Scope)** — контекст доступности переменных. В Bash по умолчанию все переменные глобальны, если не указано иное. Ключевое слово `local` ограничивает видимость переменной внутри функции.
- **Код возврата (Exit Code)** — целое число (0–255), возвращаемое командой или скриптом. **0** всегда означает успех, любое другое значение — ошибку.

## Базовые концепции

### 1. Условные операторы и тесты

#### Конструкция `if / elif / else`

```bash
if [[ $VAR == "value" ]]; then
    echo "Равно"
elif [[ $VAR =~ ^[0-9]+$ ]]; then
    echo "Это число (RegEx)"
else
    echo "Другое"
fi
```

#### Сравнение `[[ ... ]]` и `[ ... ]`

Рекомендуется всегда использовать **`[[ ... ]]`** (расширенный тест Bash), так как он:
- Не требует кавычек вокруг переменных (защищен от Word Splitting).
- Поддерживает логические операторы `&&` и `||` внутри скобок.
- Поддерживает сопоставление по маске (globbing) и регулярные выражения (`=~`).
- Обычный `[ ... ]` (команда `test`) медленнее и требует строгого экранирования.

#### Оператор `case` (аналог switch)

```bash
case "$1" in
    start|up)   echo "Запуск...";;
    stop|down)  echo "Остановка...";;
    *)          echo "Использование: $0 {start|stop}"; exit 1;;
esac
```

### 2. Циклы и итерация

#### Цикл `for`

```bash
# Итерация по списку/массиву
for item in "${ARRAY[@]}"; do
    echo "Элемент: $item"
done

# C-style цикл для счетчиков
for (( i=0; i<10; i++ )); do
    echo "Счетчик: $i"
done
```

#### Цикл `while` и `until`
- **`while`**: выполняется, пока условие истинно.
- **`until`**: выполняется, пока условие ложно.

### 3. Функции

Функции должны быть определены до их вызова. Они принимают аргументы как `$1, $2...` и имеют собственный код возврата (`return`).

```bash
# Определение функции
log_message() {
    local level="$1"  # всегда используйте local для безопасности
    shift             # сдвигаем аргументы, чтобы $@ содержал только текст сообщения
    printf "[%s] [%s] %s\n" "$(date +%T)" "$level" "$*"
}

# Вызов
log_message "INFO" "Скрипт запущен успешно"
```

## Практические сценарии

### Обработка аргументов командной строки

Для простых флагов используйте встроенную команду `getopts`. Для сложных длинных параметров (`--file`) используется цикл `while` с `case`.

```bash
# Использование getopts для флагов -a, -b со значением
while getopts "ab:" opt; do
    case $opt in
        a) echo "Флаг -a установлен";;
        b) echo "Значение -b: $OPTARG";;
        *) exit 1;;
    esac
done
```

### Построчное чтение файла (безопасный метод)

Использование `read -r` предотвращает интерпретацию обратных слэшей.

```bash
while read -r line; do
    [[ -z "$line" || "$line" == #* ]] && continue # пропуск пустых и комментариев
    echo "Обработка: $line"
done < "config.txt"
```

### Интерактивное меню (`select`)

```bash
PS3="Выберите действие: "
options=("Статус" "Перезагрузка" "Выход")
select opt in "${options[@]}"; do
    case $opt in
        "Статус")       systemctl status nginx; break;;
        "Перезагрузка") systemctl restart nginx; break;;
        "Выход")        exit 0;;
    esac
done
```

## Дополнительная информация

### Безопасный режим (Strict Mode)

Добавляйте этот блок в начало каждого скрипта для повышения надежности:

```bash
#!/bin/bash
set -euo pipefail
# -e: выход при любой ошибке
# -u: выход при обращении к неустановленной переменной
# -o pipefail: ошибка в конвейере считается ошибкой всей цепочки
```

### Отладка и трассировка

1. **`set -x`**: выводит каждую команду перед выполнением (трассировка).
2. **`set -n`**: проверка синтаксиса без выполнения кода.
3. **Кастомизация трассировки**: измените переменную `PS4`, чтобы добавить время или номер строки в лог отладки:
   `export PS4='+(${BASH_SOURCE}:${LINENO}): ${FUNCNAME[0]:+${FUNCNAME[0]}(): }'`
