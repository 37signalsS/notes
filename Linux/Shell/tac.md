# tac

## Определения

**tac** (анаграмма `cat`) — стандартная утилита в Unix-подобных системах, предназначенная для вывода содержимого файлов или стандартного ввода в обратном порядке (строка за строкой). В отличие от `cat`, которая выводит строки от первой до последней, `tac` начинает с последней строки и заканчивает первой.

## Базовые концепции

Основной принцип работы `tac` — использование разделителя (по умолчанию это символ новой строки `\n`) для определения границ записей и последующий их вывод в обратном порядке.

### Аргументы и опции

- `-b, --before`: прикрепляет разделитель перед записью, а не после неё.
- `-r, --regex`: интерпретирует разделитель как регулярное выражение.
- `-s, --separator=STRING`: использует указанную строку `STRING` в качестве разделителя вместо символа новой строки.

### Сравнение с базовыми утилитами

| Утилита | Направление вывода | Единица обработки |
| :--- | :--- | :--- |
| `cat` | Прямое (с начала) | Поток / Строки |
| `tac` | Обратное (с конца) | Строки (записи) |
| `rev` | Обратное (с конца) | Символы внутри строки |

## Практические сценарии

### Анализ лог-файлов

`tac` часто используется для быстрого просмотра последних событий в логах, когда нужно видеть хронологию "от новых к старым".

```bash
# Вывод системного лога в обратном порядке
tac /var/log/syslog | less

# Поиск последнего вхождения ошибки
tac /var/log/nginx/error.log | grep -m 1 "error"
```

### Обработка данных с кастомными разделителями

Если файл содержит записи, разделенные не переносом строки, а другим символом или строкой, можно использовать флаг `-s`.

```bash
# Реверс записей, разделенных запятой
echo "1,2,3,4" | tac -s ","
# → 43,2,1, (зависит от наличия финального разделителя)
```

### Использование регулярных выражений в качестве разделителя

Полезно для файлов, где границы записей определяются шаблоном.

```bash
# Реверс блоков, начинающихся с "DATE:"
tac -r -s "^DATE:" file.txt
```

### Комбинация tac и rev

Для полного реверса файла (и строк, и символов в них):

```bash
# Реверс порядка строк и символов в каждой строке
tac file.txt | rev
```

## Дополнительная информация

### Производительность

`tac` работает эффективно даже с большими файлами, так как он не загружает весь файл в оперативную память целиком, а считывает его с конца, используя временные файлы при необходимости (в зависимости от реализации).
