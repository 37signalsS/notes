# tac

## Определения

**tac** (`cat` наоборот) — утилита для вывода файла строками в обратном порядке. Полезна при анализе плотных логов, когда нужно начать с последних записей.

## Базовое использование

```bash
# Вывести файл задом наперёд
tac /var/log/syslog

# Чтение через pipe
journalctl -u nginx -b | tac
```

## Сравнение с аналогами

| Задача | Команда |
|--------|---------|
| Вывести файл целиком | `cat file` |
| Вывести файл задом наперёд | `tac file` |
| Последние N строк | `tail -n N file` |
| Последние N строк и следить за новыми | `tail -n N -f file` |
