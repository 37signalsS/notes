# tac

## Определения

**tac** (обратное написание `cat`) — стандартная утилита в Unix-подобных системах, предназначенная для вывода содержимого файлов или данных из стандартного потока ввода (`stdin`) в обратном порядке. В отличие от `cat`, которая выводит строки последовательно от первой к последней, `tac` обрабатывает файл с конца, выводя сначала последнюю строку (или запись), затем предпоследнюю и так далее до начала.

## Базовые концепции

Основной принцип работы `tac` заключается в поиске разделителей (по умолчанию — символ новой строки `\n`) и инверсии порядка следования блоков данных, ограниченных этими разделителями.

### Механизм обработки и производительность

- **Регулярные файлы:** Если входные данные являются обычным файлом, `tac` считывает его с конца, используя системный вызов `lseek`. Это позволяет эффективно обрабатывать файлы любого размера без необходимости загружать их целиком в оперативную память.
- **Потоки (Pipes и Sockets):** Если данные поступают через конвейер (pipe), `tac` не может перемещаться по ним произвольно. В этом случае утилита сначала считывает весь поток и сохраняет его во временный файл (обычно в `/tmp`), после чего выводит содержимое этого временного файла в обратном порядке.
- **Память:** Благодаря использованию временных файлов для неперемещаемых потоков, `tac` стабилен при работе с объемами данных, превышающими объем доступной RAM.

### Аргументы и опции

- `-b, --before`: прикрепляет разделитель перед записью (перед текстом), а не после неё.
- `-r, --regex`: интерпретирует строку разделителя как регулярное выражение.
- `-s, --separator=STRING`: использует указанную строку `STRING` в качестве разделителя вместо стандартного `\n`.

### Сравнение с аналогичными инструментами

| Утилита | Направление | Объект инверсии | Особенности |
| :--- | :--- | :--- | :--- |
| `cat` | Прямое | Поток строк | Базовый вывод |
| `tac` | Обратное | Строки (записи) | GNU coreutils стандарт |
| `rev` | Обратное | Символы внутри строки | Инвертирует каждую строку посимвольно |
| `tail -r` | Обратное | Строки | Специфично для BSD/macOS; часто отсутствует в GNU |

## Практические сценарии

### Анализ журналов (логов)

Использование `tac` позволяет видеть самые свежие события вверху вывода, что удобно для быстрой диагностики без использования `less` в режиме следования.

```bash
# Вывод последних событий системного лога в обратном порядке
tac /var/log/syslog | head -n 20

# Поиск последнего вхождения ошибки с контекстом
# (grep покажет ошибку первой, так как поиск идет с конца)
tac /var/log/nginx/error.log | grep -m 1 -A 5 "error"
```

### Обработка данных с кастомными разделителями

Если файл содержит записи, разделенные специфическим символом (например, нулевым байтом или запятой), `tac` может инвертировать их порядок.

```bash
# Реверс записей, разделенных запятой
echo -n "1,2,3,4" | tac -s ","
# → 43,2,1 (результат зависит от наличия терминатора в конце)
```

### Инверсия многострочных блоков текста

Если лог-файл содержит многострочные записи (например, Java Stack Trace), начинающиеся с определенного шаблона (дата или заголовок), можно использовать регулярные выражения для реверса именно этих блоков целиком.

```bash
# Реверс блоков, начинающихся с "DATE:"
# Параметр -b гарантирует, что разделитель останется в начале блока
tac -r -b -s "^DATE:.*" app.log
```

### Полная инверсия файла (строки и символы)

Комбинация с `rev` позволяет полностью "зеркально" отразить содержимое файла.

```bash
# Инверсия порядка строк и порядка символов в каждой из них
tac input.txt | rev
```

## Дополнительная информация

### Альтернативные способы инверсии

Если `tac` отсутствует в системе (редкий случай для Linux, но возможный в минимальных контейнерах), можно использовать `sed` или `awk`:

```bash
# Инверсия через sed (требует памяти для всего файла)
sed '1!G;h;$!d' file.txt

# Инверсия через awk
awk '{a[NR]=$0} END {for (i=NR; i>0; i--) print a[i]}' file.txt
```
