# Горячие клавиши и шорткаты Shell

## Определения → Базовые концепции → Практические сценарии → Дополнительная информация

## Определения

**Горячие клавиши (Shortcuts)** — комбинации клавиш, предназначенные для ускорения работы в командной оболочке (Bash/Zsh) и терминале. 

**Readline** — библиотека, используемая Bash и многими другими CLI-инструментами для редактирования командной строки. Большинство шорткатов определяются именно её настройками (Emacs или Vi mode).

## Базовые концепции

### Управление процессами и сигналами

| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| **`Ctrl + C`** | `SIGINT` | Прервать выполнение текущего процесса |
| **`Ctrl + Z`** | `SIGTSTP` | Приостановить процесс и отправить в фон (suspend) |
| **`Ctrl + D`** | `EOF` | Закрыть текущий сеанс shell или отправить сигнал конца файла |
| **`Ctrl + \`** | `SIGQUIT` | Прервать процесс и создать coredump |

### Навигация по строке

| Комбинация | Действие |
| :--- | :--- |
| **`Ctrl + A`** | Перейти в начало строки |
| **`Ctrl + E`** | Перейти в конец строки |
| **`Alt + B`** | Вернуться на одно слово назад |
| **`Alt + F`** | Перейти на одно слово вперёд |
| **`Ctrl + L`** | Очистить экран (аналог `clear`) |

### Редактирование текста

| Комбинация | Действие |
| :--- | :--- |
| **`Ctrl + U`** | Удалить всё от курсора до начала строки |
| **`Ctrl + K`** | Удалить всё от курсора до конца строки |
| **`Ctrl + W`** | Удалить слово перед курсором |
| **`Ctrl + Y`** | Вставить (yank) последний удалённый фрагмент |
| **`Ctrl + T`** | Поменять местами два символа перед курсором |
| **`Alt + T`** | Поменять местами два слова перед курсором |

### Работа с историей

| Комбинация | Действие |
| :--- | :--- |
| **`Ctrl + R`** | Обратный инкрементальный поиск по истории |
| **`Ctrl + G`** | Выйти из режима поиска в истории |
| **`Alt + .`** | Вставить последний аргумент предыдущей команды |
| **`!!`** | Выполнить последнюю команду целиком |
| **`!$`** | Последний аргумент последней команды |

## Практические сценарии

### Сценарий 1: Быстрое исправление опечатки в длинной команде
Вместо того чтобы зажимать стрелку «влево», используйте `Ctrl + A` для прыжка в начало или `Alt + B` для перемещения по словам.

### Сценарий 2: Повтор команды с sudo
Если вы забыли `sudo`, не нужно переписывать всё заново:
```bash
sudo !!
```

### Сценарий 3: Использование аргумента предыдущей команды
Вы создали директорию и хотите в неё зайти:
```bash
mkdir -p /very/long/path/to/directory
cd !$
```

### Сценарий 4: Поиск сложной команды в истории
Нажмите `Ctrl + R` и начните вводить часть команды (например, `docker run`). Нажимайте `Ctrl + R` повторно для циклического поиска назад.

## Дополнительная информация

### Настройка режима редактирования
По умолчанию используется режим **Emacs**. Если вы предпочитаете **Vi**, добавьте в `~/.bashrc`:
```bash
set -o vi
```

### Кастомные шорткаты
Настройки хранятся в файле `~/.inputrc`. Пример добавления поиска по истории стрелками:
```bash
"\e[A": history-search-backward
"\e[B": history-search-forward
```
