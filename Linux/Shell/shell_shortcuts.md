# Горячие клавиши и шорткаты Shell

## Определения

- **Горячие клавиши (Shortcuts)** — комбинации клавиш, предназначенные для ускорения ввода, редактирования команд и управления процессами в командной оболочке (Bash, Zsh) и эмуляторах терминала.
- **Readline** — библиотека, используемая Bash (и многими другими CLI-инструментами) для редактирования командной строки. Она определяет поведение большинства шорткатов.
- **ZLE (Zsh Line Editor)** — встроенный редактор строк в Zsh, который по умолчанию имитирует поведение Readline, но предоставляет больше возможностей для кастомизации.

## Базовые концепции

### Управление процессами и терминалом

| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| **`Ctrl + C`** | `SIGINT` | Прервать выполнение текущего процесса. |
| **`Ctrl + Z`** | `SIGTSTP` | Приостановить процесс и отправить в фон (используйте `fg` для возврата). |
| **`Ctrl + D`** | `EOF` | Закрыть текущую сессию (exit) или сигнализировать о конце ввода. |
| **`Ctrl + L`** | `clear` | Очистить экран (аналог команды `clear`). |
| **`Ctrl + S`** | `XOFF` | Приостановить вывод в терминал (заморозка экрана). |
| **`Ctrl + Q`** | `XON` | Возобновить вывод в терминал (разморозка после `Ctrl + S`). |
| **`Ctrl + \`** | `SIGQUIT` | Принудительно завершить процесс с созданием дампа памяти (coredump). |

### Навигация по командной строке

| Комбинация | Действие |
| :--- | :--- |
| **`Ctrl + A`** | Перейти в начало строки. |
| **`Ctrl + E`** | Перейти в конец строки. |
| **`Alt + B`** | Перейти на одно слово назад (назад). |
| **`Alt + F`** | Перейти на одно слово вперед (вперед). |
| **`Ctrl + XX`** | Прыжок между текущей позицией курсора и началом строки. |

### Редактирование текста

| Комбинация | Действие |
| :--- | :--- |
| **`Ctrl + U`** | Удалить текст от курсора до начала строки. |
| **`Ctrl + K`** | Удалить текст от курсора до конца строки. |
| **`Ctrl + W`** | Удалить слово перед курсором (по границе пробела). |
| **`Alt + Backspace`** | Удалить слово перед курсором (по границе спецсимволов). |
| **`Ctrl + Y`** | Вставить (yank) последний удаленный фрагмент текста. |
| **`Ctrl + _`** или **`Ctrl + X, Ctrl + U`** | Отменить последнее действие (Undo). |
| **`Alt + C`** | Сделать заглавной первую букву текущего слова. |
| **`Alt + U`** | Перевести слово после курсора в ВЕРХНИЙ регистр. |
| **`Alt + L`** | Перевести слово после курсора в нижний регистр. |
| **`Alt + #`** | Закомментировать текущую строку и переместить её в историю. |
| **`Ctrl + X, Ctrl + E`** | Открыть текущую команду в `$EDITOR` (Vim/Nano) для редактирования. |

### Работа с историей и подстановками

| Комбинация | Действие |
| :--- | :--- |
| **`Ctrl + R`** | Инкрементальный поиск по истории (назад). |
| **`Ctrl + S`** | Инкрементальный поиск по истории (вперед) — может требовать отключения `XOFF`. |
| **`Alt + .`** | Вставить последний аргумент предыдущей команды. |
| **`!!`** | Повторить последнюю команду целиком. |
| **`!$`** | Последний аргумент последней команды (аналог `Alt + .`). |
| **`!^`** | Первый аргумент последней команды. |
| **`!*`** | Все аргументы последней команды (без самой команды). |
| **`!:n`** | n-ый аргумент последней команды. |

## Практические сценарии

### Использование sudo для последней команды
Частая ситуация: вы ввели длинную команду, но забыли `sudo`.
```bash
$ apt update
# Ошибка: Permission denied
$ sudo !!
# Выполнит: sudo apt update
```

### Манипуляция аргументами
Предположим, вы создали директорию и хотите сразу в неё перейти:
```bash
$ mkdir -p /var/log/myapp/configs
$ cd !$
# Выполнит: cd /var/log/myapp/configs
```

### "Разморозка" терминала
Если вы случайно нажали `Ctrl + S`, терминал перестанет реагировать на ввод. Не закрывайте окно — просто нажмите `Ctrl + Q`, чтобы возобновить работу.

### Редактирование сложных циклов
Если вы начали писать сложный цикл `for` или `if` и запутались:
1. Нажмите `Ctrl + X, Ctrl + E`.
2. Bash откроет ваш любимый редактор (Vim/Nano).
3. Отредактируйте код, сохраните и выйдите.
4. Оболочка тут же выполнит этот код.

## Дополнительная информация

### Режимы Emacs и Vi
По умолчанию Readline работает в режиме **Emacs** (описан выше). Если вы предпочитаете навигацию как в Vim, переключите режим в `~/.bashrc` (для Bash) или `~/.zshrc` (для Zsh):

```bash
# Для Bash
set -o vi

# Для Zsh
bindkey -v
```

### Настройка в .inputrc
Для Bash настройки шорткатов хранятся в `/etc/inputrc` или `~/.inputrc`. Вы можете добавить свои бинды, например, поиск по истории с помощью стрелок:
```bash
"\e[A": history-search-backward
"\e[B": history-search-forward
```
