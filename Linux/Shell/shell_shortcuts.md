# Горячие клавиши и шорткаты Shell

## Определения

- **Горячие клавиши (Shortcuts)** — комбинации клавиш, предназначенные для ускорения работы в командной оболочке (Bash, Zsh) и терминале.
- **Readline** — библиотека, используемая Bash и многими другими CLI (Command Line Interface) инструментами для редактирования командной строки. Большинство шорткатов определяются её настройками (режимы Emacs или Vi).

## Базовые концепции

### Управление процессами и сигналами

| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| **`Ctrl + C`** | `SIGINT (Signal Interrupt)` | Прервать выполнение текущего процесса |
| **`Ctrl + Z`** | `SIGTSTP (Signal Terminal Stop)` | Приостановить процесс и отправить в фон (suspend) |
| **`Ctrl + D`** | `EOF (End Of File)` | Закрыть текущий сеанс Shell или отправить сигнал конца файла |
| **`Ctrl + L`** | `clear` | Очистить экран терминала |
| **`Ctrl + \`** | `SIGQUIT (Signal Quit)` | Прервать процесс и создать coredump (снимок памяти) |

### Навигация по строке

| Комбинация | Действие |
| :--- | :--- |
| **`Ctrl + A`** / `Home` | Перейти в начало строки |
| **`Ctrl + E`** / `End` | Перейти в конец строки |
| **`Alt + B`** / `Ctrl + ←` | Вернуться на одно слово назад |
| **`Alt + F`** / `Ctrl + →` | Перейти на одно слово вперёд |
| **`Ctrl + B`** / `Ctrl + F` | Перейти на один символ влево / вправо |
| **`Ctrl + XX`** | Переключение между началом строки и текущей позицией курсора |

### Редактирование текста

| Комбинация | Действие |
| :--- | :--- |
| **`Ctrl + U`** | Удалить всё от курсора до начала строки |
| **`Ctrl + K`** | Удалить всё от курсора до конца строки |
| **`Ctrl + W`** | Удалить слово перед курсором |
| **`Ctrl + D`** | Удалить символ под курсором |
| **`Ctrl + Y`** | Вставить (yank) последний удалённый фрагмент |
| **`Ctrl + T`** | Поменять местами два символа перед курсором |
| **`Alt + T`** | Поменять местами два слова перед курсором |
| **`Alt + U`** / **`Alt + L`** | Перевести слово после курсора в верхний / нижний регистр |
| **`Alt + C`** | Сделать заглавной первую букву текущего слова |
| **`Ctrl + _`** | Отменить последнее действие (Undo) |
| **`Ctrl + X; Ctrl + E`** | Открыть текущую команду в `$EDITOR` (Vim, Nano) для редактирования |

### Работа с историей

| Комбинация | Действие |
| :--- | :--- |
| **`Ctrl + R`** | Обратный инкрементальный поиск по истории |
| **`Ctrl + G`** | Выйти из режима поиска в истории |
| **`Ctrl + P`** / `↑` | Предыдущая команда |
| **`Ctrl + N`** / `↓` | Следующая команда |
| **`Ctrl + O`** | Запустить найденную команду и перейти к следующей из истории |
| **`Alt + R`** | Отменить изменения в команде, извлеченной из истории |
| **`Alt + .`** | Вставить последний аргумент предыдущей команды |
| **`!!`** | Выполнить последнюю команду целиком |
| **`!$`** | Последний аргумент последней команды |

## Практические сценарии

### Быстрое исправление длинной команды

Используйте `Ctrl + A` для прыжка в начало или `Alt + B` для перемещения по словам. Если команда слишком сложная (например, многострочный цикл), нажмите `Ctrl + X; Ctrl + E`, чтобы отредактировать её в полноценном текстовом редакторе.

### Повтор команды с sudo

Если команда завершилась с ошибкой доступа из-за отсутствия привилегий, используйте конструкцию `!!`:

```bash
$ apt update
E: Could not open lock file...
$ sudo !!
sudo apt update
```

### Скрытие команды из истории

Пробел перед командой предотвращает её сохранение в истории Bash (при условии настройки `HISTCONTROL=ignorespace` или `ignoreboth`):

```bash
 export SECRET_TOKEN="very-secret-value"  # пробел в начале строки
```

## Дополнительная информация

### Режимы редактирования Readline

По умолчанию в большинстве дистрибутивов используется режим **Emacs**. Для переключения в режим **Vi** (управление как в редакторе Vim) добавьте в `~/.bashrc`:

```bash
set -o vi
```

### Пользовательские шорткаты

Настройки библиотеки Readline хранятся в файле `~/.inputrc`. Пример добавления поиска по истории с помощью клавиш управления курсором:

```bash
"\e[A": history-search-backward
"\e[B": history-search-forward
```
