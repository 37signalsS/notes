# vim — текстовый редактор VI

**Актуально для:** Vim 9.1+

## Определения

**Vim** (Vi IMproved) — расширенный текстовый редактор vi с поддержкой плагинов, макросов, синтаксиса и программирования. Режимный редактор: команды вводятся в виде последовательностей клавиш без необходимости выхода в меню.

## Базовые концепции

### Режимы

| Режим | Клавиша | Описание |
| :--- | :--- | :--- |
| **Normal** | `Esc` | Командный режим (по умолчанию) |
| **Insert** | `i`, `a`, `o` | Вставка текста |
| **Visual** | `v`, `V`, `Ctrl+v` | Выделение текста |
| **Command-line** | `:` | Ввод команд (`:wq`, `:s/...`) |
| **Search** | `/`, `?` | Поиск по паттерну |

### Механика записи макросов

Макросы позволяют автоматизировать повторяющиеся правки:

```vim
qa       " Запись в регистр 'a'
...      " выполняемые команды
q        " остановка записи
@a       " воспроизведение макроса
10@a     " воспроизведение 10 раз
```

## Практические сценарии

### Сохранение и выход

```vim
:wq    " Сохранить и выйти (write + quit)
:q!    " Выйти без сохранения (quit + force)
:w     " Только сохранить
:w file.txt  " Сохранить как
:x     " Сохранить и выйти (только если изменено)
```

### Глобальная замена

```vim
:%s/old/new/g       " Заменить все вхождения во всём файле
:%s/old/new/gc      " С подтверждением каждой замены
:%s/old/new/gi      " Без учёта регистра
:%s/old/new/gn      " Только посчитать совпадения
```

- `%` — диапазон «все строки»
- `s` — substitute
- `g` — global (все в строке)
- `c` — confirm
- `i` — ignore case

### Открытие файла на строке

```bash
vim +42 file.txt
```

Или изнутри vim: `:42` и затем `Enter`.

### Поиск

```vim
/pattern    " Искать вперёд
?pattern    " Искать назад
n           " Следующее совпадение
N           " Предыдущее совпадение
```

Опции поиска:
- `:set ignorecase` — без учёта регистра
- `:set hlsearch` — подсвечивать совпадения
- `:set incsearch` — поиск во время ввода

### Удаление строк по паттерну

```vim
:g/^#/d        " Удалить все строки, начинающиеся с #
:g/pattern/d   " Удалить все строки, содержащие pattern
:g!/pattern/d  " Удалить строки, НЕ содержащие pattern
:v/pattern/d   " Сокращение от :g!
```

### Форматирование и отступы

```vim
gg=G    " Переформатировать весь файл (gg — в начало, = — выровнять, G — до конца)
>>      " Увеличить отступ текущей строки
<<      " Уменьшить отступ
~       " Переключить регистр символа
```

### Навигация по файлу

| Команда | Описание |
| :--- | :--- |
| `gg` | В начало файла |
| `G` | В конец файла |
| `Ctrl+d` / `Ctrl+u` | Полудовжный прокрут (вниз/вверх) |
| `w` / `b` | Следующее/предыдущее слово |
| `0` / `$` | Начало/конец строки |
| `:line` | Перейти на строку (например, `:42`) |

### Работа с окнами и вкладками

```vim
:vsplit file.txt   " Вертикальное разделение окна
:split file.txt    " Горизонтальное разделение
:tabnew            " Создать вкладку
Ctrl+w + стрелка   " Переключение между окнами
```

### Полезные опции

```vim
:set number          " Показать номера строк
:set relativenumber    " Относительные номера
:set nonumber        " Скрыть номера
:set paste           " Не переводить ввод (избегает проблем с отступами в paste-mode)
:set list            " Показать табы и концы строк
```

### Поиск и замена с регулярными выражениями

```vim
:%s/^\s*//g       " Удалить начальные пробелы и табы
:g/^\s*$/d         " Удалить пустые строки
:%s/\t/    /g     " Заменить табы на пробелы
```

## Дополнительная информация

- **Миграция с vi:** Vim полностью обратим с vi, но добавляет множество расширений (поддержка UTF-8, цветовых схем, плагинов).
- **Аналоги:** `nvim` (Neovim) — современная переработка с лучшей производительностью и встроенной поддержкой Lua-плагинов.
