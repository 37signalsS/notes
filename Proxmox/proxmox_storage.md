# Хранилища (Storage) и Ceph в Proxmox

## Определения

**Storage в Proxmox** — подсистема управления хранилищами, позволяющая подключать локальные диски, сетевые шары (SMB/NFS) и блочные устройства (iSCSI, Ceph) для размещения дисков виртуальных машин, бэкапов и ISO-образов.

## Основные концепции

### Типы хранилищ

В Proxmox хранилища делятся на локальные и общие (Shared):

- **Local Directory / ext4**: Используется для хранения файлов (ISO, бэкапы, шаблоны), а также виртуальных дисков в виде файлов `.raw` или `.qcow2`.
- **LVM-Thin**: Оптимизированный тип локального хранилища, создаваемый по умолчанию при установке. Поддерживает снапшоты, но не поддерживает кластерную репликацию (Storage Replication). Хорошо подходит для дисков ВМ, но не для файлов (ISO/бэкапы).
- **ZFS**: Продвинутая файловая система, поддерживающая компрессию, дедупликацию и снапшоты. Обязательна для работы встроенной функции Storage Replication между нодами кластера. Требует много оперативной памяти.
- **Shared Storage (SMB / NFS)**: Сетевые хранилища. Виртуальные диски хранятся централизованно. Позволяют выполнять HA без репликации данных.

### Ceph Storage в Proxmox
**Ceph** — распределенная система хранения данных. Proxmox позволяет разворачивать гиперконвергентный кластер прямо через GUI.
- **MON (Monitors)**: Карта состояния кластера (нужно 3 или 5).
- **MGR (Managers)**: Метрики и управление.
- **OSD (Object Storage Daemon)**: Служба для каждого физического диска. **Критически важна** отдельная быстрая сеть (10 Gbps+) для трафика репликации OSD.
- **MDS (Metadata Server)**: Необходим для работы **CephFS** — общей файловой системы поверх Ceph для хранения ISO, шаблонов и бэкапов.
- **Pools**: Группировка дисков с заданным уровнем репликации (обычно 3 копии).


## Практические сценарии

### Миграция хранилища (Move Storage)
В Proxmox можно прозрачно переносить виртуальный диск запущенной виртуальной машины между различными типами хранилищ: например, из локального пула `local-lvm` на сетевую шару `NFS` или в отказоустойчивый пул `Ceph`. Опция доступна в меню `Hardware -> Hard Disk -> Disk Action -> Move Storage`.
