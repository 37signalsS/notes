# Proxmox Backup Server (PBS)

## Определения

**Proxmox Backup Server (PBS)** — специализированная платформа корпоративного уровня для инкрементального дедуплицированного резервного копирования виртуальных машин (VM), контейнеров (LXC) и физических хостов.

**Datastore** — логическое хранилище, представляющее собой директорию на файловой системе, где размещаются дедуплицированные блоки данных (**chunks**) и метаданные.

**Namespace (Пространство имен)** — механизм иерархического разделения данных внутри одного Datastore. Позволяет изолировать бэкапы разных клиентов или отделов, применяя к ним индивидуальные политики прав и хранения.

## Основные концепции

### Преимущества дедупликации

PBS использует **инкрементальность на уровне блоков** и **глобальную дедупликацию**:
- **Chunking**: Исходный поток данных разбивается на фрагменты (чанки) среднего размера 4 МБ.
- **SHA-256**: Каждый чанк идентифицируется уникальным хешем. Если такой хеш уже есть в хранилище, он не записывается повторно.
- **Экономия**: Позволяет хранить сотни версий одной ВМ, занимая объем, близкий к одной полной копии плюс дельта изменений.

### Шифрование и безопасность

- **Client-side Encryption**: Данные шифруются в PVE перед отправкой. PBS получает только зашифрованные блоки.
- **Ransomware Protection**: Поддержка режима **Immutable Backups** (неизменяемые бэкапы) и строгая проверка целостности данных.

### Сценарии Offsite-хранения

- **Sync Jobs**: Автоматическая синхронизация данных между двумя PBS серверами (например, из локального офиса в облако).
- **Tape Backup**: Нативная поддержка ленточных библиотек (LTO) для реализации правила "3-2-1". Поддержка **Media Pools** и инвентаризации лент.

## Практические сценарии

### Подключение PBS к Proxmox VE через CLI

```bash
# Добавление хранилища PBS в кластер PVE
pvesm add pbs local-backup \
    --server 10.0.0.50 \
    --datastore pool-01 \
    --username backup-user@pbs \
    --password "secret-pass" \
    --fingerprint "AA:BB:CC:..."
# → update storage: 'local-backup'
```

### Настройка Namespace через CLI (на стороне PBS)

```bash
# Создание пространства имен для отдела разработки
proxmox-backup-manager datastore namespace create pool-01 dev-team
# → Successfully created namespace 'dev-team'
```

### Резервное копирование физического Linux-сервера

```bash
# Установка клиента и выполнение бэкапа
proxmox-backup-client backup root.pxar:/ --repository backup@pbs@10.0.0.50:pool-01
# → Uploading "root.pxar"
# → Backup finished.
```

## Обслуживание и диагностика

### Жизненный цикл данных (Maintenance)

1. **Prune**: Удаление индексов старых бэкапов (логическое удаление).
2. **Garbage Collection (GC)**: Физическое удаление чанков, на которые больше нет ссылок. Рекомендуется запускать раз в неделю.
3. **Verify**: Проверка целостности данных для предотвращения "bit rot".

**Запуск GC:**
```bash
proxmox-backup-manager datastore garbage-collection pool-01
# → Start garbage collection on "pool-01"
# → Removed 12500 chunks (5.2 GB)
```

### Проверка состояния дисков и хранилищ
```bash
proxmox-backup-manager datastore status pool-01
# → {
# →   "total": 1000200000000,
# →   "used": 450000000000,
# →   "avail": 550200000000
# → }
```
