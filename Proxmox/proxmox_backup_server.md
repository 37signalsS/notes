# Proxmox Backup Server (PBS)

## Определения

**Proxmox Backup Server (PBS)** — это специализированная платформа корпоративного уровня для резервного копирования и восстановления виртуальных машин (VM), контейнеров (LXC) и физических хостов.

**Datastore (Хранилище данных)** — логическая единица хранения в PBS, представляющая собой директорию на файловой системе, где размещаются дедуплицированные блоки данных (chunks) и метаданные бэкапов.

**Chunk (Чанк)** — минимальная единица данных (обычно фиксированного или переменного размера до 4 МБ), на которые разбивается исходный поток данных перед сохранением.

## Основные концепции

### Преимущества PBS перед классическим VZDump

В отличие от стандартного механизма `vzdump` в Proxmox Virtual Environment (PVE), который создает полные архивы, PBS использует инкрементальный подход:

- **Инкрементальность на уровне блоков**: Сохраняются только измененные блоки данных. Это позволяет делать бэкапы каждые 15-30 минут с минимальной нагрузкой на сеть и дисковую подсистему.
- **Глобальная дедупликация**: Одинаковые блоки данных от разных виртуальных машин сохраняются в рамках одного Datastore только один раз, что экономит до 90% дискового пространства.
- **Шифрование на стороне клиента**: Данные шифруются алгоритмом AES-256 (GCM mode) в PVE перед отправкой по сети. Ключи шифрования хранятся в PVE.
- **Live Restore (Живое восстановление)**: Позволяет запустить виртуальную машину практически мгновенно, подгружая необходимые данные с PBS в фоновом режиме, пока идет процесс полного восстановления диска.

### Механизм хранения данных

PBS хранит данные в виде набора файлов в структуре директорий:

- **.chunks/**: Директория с фактическими данными, именованными по их SHA-256 хешу.
- **index.json**: Файл, описывающий структуру бэкапа и ссылки на чанки.
- **blob.json**: Хранилище метаданных (конфигурация ВМ, логи).

## Практические сценарии

### Подключение PBS к Proxmox VE через CLI

Для подключения хранилища к кластеру PVE необходимо использовать утилиту `pvesm` (Proxmox Storage Manager).

```bash
# Добавление хранилища PBS
pvesm add pbs my-pbs-storage \
    --server 192.168.1.50 \
    --datastore backup-pool \
    --username backup-user@pbs \
    --password "your-secret-password" \
    --fingerprint "AA:BB:CC..."
```

### Резервное копирование физического хоста

PBS позволяет бэкапить не только виртуальную инфраструктуру, но и обычные серверы с помощью `proxmox-backup-client`.

```bash
# Установка переменной для авторизации
export PBS_PASSWORD="your-password"

# Создание бэкапа директории /etc и /home
proxmox-backup-client backup root.pxar:/etc home.pxar:/home \
    --repository backup-user@pbs@192.168.1.50:backup-pool
# → Uploading "root.pxar"
# → Uploading "home.pxar"
# → Backup finished.
```

### Обслуживание и верификация (Maintenance)

Регулярное обслуживание критично для очистки места и проверки целостности:

1. **Prune (Усечение)**: Удаление старых версий бэкапов согласно политике (Retention).
2. **Garbage Collection (GC)**: Физическое удаление чанков с диска, на которые больше нет ссылок после Prune.
3. **Verify (Верификация)**: Пересчет контрольных сумм всех чанков для обнаружения повреждений (bit rot).

**Запуск сборки мусора через CLI на сервере PBS:**

```bash
proxmox-backup-manager datastore garbage-collection backup-pool
# → Start garbage collection on "backup-pool"
# → Removed 12050 chunks (4.5 GB)
```
