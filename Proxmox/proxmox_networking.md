# Сетевые технологии Proxmox

## Определения

Сетевая подсистема Proxmox базируется на стандартных инструментах Linux, расширенных возможностями SDN (Software-Defined Networking). По умолчанию конфигурация управляется через графический интерфейс и сохраняется в файле `/etc/network/interfaces`.

## Основные концепции

### Linux Bridge (Мост)
**Bridge** — стандартный и самый распространенный тип сетевого интерфейса в Proxmox. Действует как программный коммутатор Layer 2 (L2). 
При установке гипервизора автоматически создается интерфейс `vmbr0`, привязанный к физическому порту сервера. Виртуальные машины и контейнеры подключаются к этому мосту, получают IP-адреса из физической сети хоста и ведут себя как независимые устройства.

### Software-Defined Networking (SDN)
Начиная с версии 8.1, в Proxmox интегрирована встроенная поддержка программно-определяемых сетей (SDN), позволяющая строить виртуальные сетевые топологии поверх физической инфраструктуры.
- **Изоляция и безопасность**: SDN позволяет создавать изолированные зоны (Zones) и подсети (VNETs) для разделения трафика разных проектов или клиентов (тенантов) без изменения настроек физических коммутаторов.
- **Типы зон**: Поддерживаются Simple (локально на ноде), VLAN, QinQ, VxLAN (для L2 поверх L3) и EVPN.
- **Преимущества**: Упрощает масштабирование сети в кластере и позволяет автоматизировать управление сетевыми ресурсами через API.

### SDN Fabrics (Open Fabric)
В Proxmox VE 9 появилась встроенная поддержка **Fabrics** (Open Fabric) в модуле SDN.
- Это технология, которая автоматически настраивает маршрутизацию между нодами в кластере и динамически подстраивается под изменения физической топологии.
- Позволяет легко развернуть Mesh-сеть между физическими хостами, используя доступные сетевые интерфейсы. Настройка производится в `Datacenter -> SDN -> Fabrics`.
- Идеально подходит для создания высокоскоростной внутренней "задней" сети (например, для Ceph Storage Network OSD трафика), так как маршруты балансируются напрямую между узлами без сложной настройки протоколов динамической маршрутизации.
