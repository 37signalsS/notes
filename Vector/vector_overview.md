# Vector

Vector — это высокопроизводительный конвейер для сбора, обработки и отправки логов, метрик и событий. Он написан на языке Rust, что обеспечивает высокую производительность и безопасность при работе с памятью.

## Основные характеристики

- **Производительность:** Значительно быстрее и менее ресурсоемок по сравнению с альтернативами вроде Logstash или Fluentd.
- **Надежность:** Гарантирует доставку данных (at-least-once delivery).
- **Единый инструмент:** Может выполнять роль как легковесного агента (замена Filebeat/Fluent Bit), так и агрегатора (замена Logstash/Fluentd).

## Архитектура

Архитектура Vector концептуально похожа на Logstash и состоит из трех компонентов:

1.  **Sources (Источники):** Определяют, откуда Vector будет получать данные (например, файлы, сокеты, Kafka, HTTP).
2.  **Transforms (Преобразования):** Позволяют модифицировать, фильтровать и обогащать данные в процессе их передачи.
3.  **Sinks (Приемники):** Определяют, куда Vector будет отправлять обработанные данные (например, Elasticsearch, Loki, Kafka, ClickHouse).

## Конфигурация

- Vector использует формат **TOML** (`vector.toml`) для конфигурации, который является более строгим и читаемым по сравнению с кастомным форматом Logstash.
- Конфигурация состоит из секций `[sources]`, `[transforms]`, и `[sinks]`, которые связываются между собой через параметры `inputs`.

### Пример преобразования

Vector использует язык **VRL (Vector Remap Language)** для сложных преобразований данных. Это мощный и безопасный язык, специально разработанный для обработки событий.

```toml
[transforms.my_transform]
  type = "remap"
  inputs = ["my_source"]
  source = '''
  # Преобразование VRL
  .message = "processed: " + .message
  .new_field = "hello world"
  '''
```

## Сравнение с Logstash

- **Производительность:** Vector на порядок превосходит Logstash по скорости обработки данных и требует в несколько раз меньше CPU и RAM при одинаковой нагрузке.
- **Функциональность:** Logstash имеет более зрелую экосистему и значительно большее количество готовых плагинов для различных интеграций. Функционал Vector активно развивается, но пока уступает Logstash в широте покрытия.
- **Язык и Ресурсы:** Vector написан на Rust, что дает ему преимущество в производительности и управлении ресурсами. Logstash, работая на JVM, более требователен к памяти и CPU.

**Вывод:** Vector является отличным выбором для высоконагруженных систем, где критически важны производительность и эффективное использование ресурсов. Он подходит как для роли агента на конечных узлах, так и для централизованного агрегатора, особенно если не требуются экзотические интеграции, доступные только в Logstash.

Для более детального сравнения см. заметку **[Сравнение Logstash и Vector](../Logstash/logstash_vs_vector.md)**.
