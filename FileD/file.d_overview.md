# file.d

`file.d` — это высокопроизводительный инструмент для сбора логов и построения конвейеров данных (чтения, обработки и вывода событий), который позиционируется как быстрая альтернатива таким инструментам, как `Filebeat`, `Fluentd` и `Vector`. Изначально разработанный для чтения из файлов, он также поддерживает множество плагинов ввода/действия/вывода.

**Ключевые возможности:**

* **Скорость:** Заявлено, что `file.d` работает более чем в 10 раз быстрее по сравнению с аналогичными инструментами.
* **Предсказуемость:** Использует пул для ограничения потребления памяти.
* **Надежность:** Гарантирует отсутствие потери данных благодаря механизму фиксации (commit mechanism).
* **Гибкость развертывания:** Поддерживает контейнерные среды, облачные решения и нативный Kubernetes.
* **Простота конфигурации:** Настраивается с помощью файлов YAML.
* **Совместимость с Prometheus:** Позволяет преобразовывать события в метрики на любом этапе конвейера.
* **Удобство использования с хранилищами секретов:** Позволяет безопасно хранить конфиденциальную информацию и использовать ее для любых параметров конвейера.
* **Проверен в производстве:** Используется для сбора журналов из кластеров Kubernetes с общим количеством ядер ЦП более 3000.

Список поддерживаемых плагинов для ввода, преобразования и вывода доступен в репозитории проекта: [https://github.com/ozontech/file.d](https://github.com/ozontech/file.d)

## Сравнение с Vector

| Характеристика | file.d | Vector |
| :--- | :--- | :--- |
| **Язык** | Go | Rust |
| **Производительность** | Очень высокая (10× быстрее аналогов) | Очень высокая (5–10× быстрее Logstash) |
| **Язык трансформации** | Lua, Go-плагины | VRL (Vector Remap Language) |
| **Экосистема** | Малая (российский проект) | Большая (международное сообщество) |
| **Конфигурация** | YAML | TOML/YAML/JSON |

**Когда выбирать file.d:**

* Простые сценарии сбора и отправки логов
* Предпочтение Go-экосистеме

**Когда выбирать Vector:**

* Сложные трансформации данных (VRL мощнее Lua)
* Требуется богатая экосистема интеграций
* Международная поддержка и сообщество

> Подробнее о Vector см. в **[Vector Overview](../Vector/vector_overview.md#сравнение-с-аналогами)**.
