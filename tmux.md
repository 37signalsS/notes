# Tmux: Терминальный Мультиплексор

## 1. Определения

**Tmux** (Terminal Multiplexer) — это мощный инструмент для командной строки, который позволяет пользователям запускать несколько независимых терминальных сессий в одном окне, отключаться от них и повторно подключаться позже, сохраняя при этом все запущенные процессы. Это делает его незаменимым для системных администраторов, разработчиков и всех, кто работает с командной строкой.

**Ключевые сущности Tmux:**

* **Сессия (Session):** Контейнер верхнего уровня, который может содержать одно или несколько окон. Сессии можно отключать (detach) и подключать (attach), что позволяет сохранять рабочее окружение даже после закрытия терминала или потери соединения.
* **Окно (Window):** Эквивалент вкладок в обычных терминалах. Каждое окно отображает один или несколько разделенных панелей.
* **Панель (Pane):** Отдельная область внутри окна, в которой выполняется своя командная оболочка. Окна могут быть разделены на несколько панелей как по горизонтали, так и по вертикали.
* **Клиент (Client):** Сам терминал, из которого вы подключаетесь к сессии Tmux.

## 2. Основные концепции

### Зачем использовать Tmux?

* **Сохранение сессий:** Позволяет отключаться от удаленных серверов или закрывать локальный терминал, не прерывая запущенные процессы. При повторном подключении вы найдете все в том же состоянии.
* **Множественные терминалы:** Организуйте работу с несколькими командными строками, редакторами и скриптами в одном окне, легко переключаясь между ними.
* **Разделение экрана:** Делите окно на несколько панелей для одновременного просмотра вывода разных команд или работы над разными частями проекта.
* **Совместная работа:** Несколько пользователей могут подключиться к одной и той же сессии Tmux, что удобно для совместного отладки или обучения.

## 3. Настройка Tmux

Настройка Tmux производится через файл `~/.tmux.conf`. Если его нет, создайте его.

### Префикс (Prefix Key)

По умолчанию префиксная клавиша Tmux — `Ctrl+b`. Все команды Tmux начинаются с этой комбинации. Однако многие пользователи предпочитают изменять ее на более удобную.

**Изменение префикса на `Ctrl+a`:**

```tmux.conf
# Установка префикса на Ctrl+a
set -g prefix C-a
# Отвязка Ctrl+b от старых команд
unbind C-b
# Привязка Ctrl+a как префикса
bind C-a send-prefix
```

Или, как предлагается в одном из источников, использование `Alt` клавиши, для этого необходимо использовать `bind -n` для привязок без префикса, но в таком случае нужно учитывать, что `Alt` может быть перехвачен терминалом.

### Основные настройки

```tmux.conf
# Включить поддержку 256 цветов
set -g default-terminal "screen-256color"

# Увеличить историю буфера для каждой панели
set -g history-limit 5000 # или любое удобное значение

# Сделать индексацию окон и панелей с 1, а не с 0 (более интуитивно)
set -g base-index 1
set -g pane-base-index 1

# Разрешить переиндексацию окон при закрытии (окна всегда будут иметь последовательные номера)
set -g renumber-windows on

# Включить поддержку мыши для переключения панелей, изменения размеров, прокрутки
set -g mouse on

# Уменьшить задержку после нажатия Esc (полезно для Vim)
set -s escape-time 0

# Установить более интуитивные клавиши для разделения окон
# Разделение по вертикали (Ctrl+b + |)
bind | split-window -h
# Разделение по горизонтали (Ctrl+b + -)
bind - split-window -v

# Перезагрузка конфига Tmux (Ctrl+b + r)
bind r source-file ~/.tmux.conf \; display-message "Tmux config reloaded!"

# Переключение между панелями как в Vim (Ctrl+b + h/j/k/l)
bind h select-pane -L
bind j select-pane -D
bind k select-pane -U
bind l select-pane -R

# Изменение размеров панелей
bind -r H resize-pane -L 5
bind -r J resize-pane -D 5
bind -r K resize-pane -U 5
bind -r L resize-pane -R 5

# Быстрое переключение между последними окнами (Ctrl+b + q)
bind q last-window

# Копирование в буфер обмена (по умолчанию Shift+Mouse Drag, затем Ctrl+Shift+C)
# Для интеграции с системным буфером обмена (нужны xclip/wl-copy на Linux):
# bind -T copy-mode-vi y send-keys -X copy-pipe-and-cancel "xclip -in -selection clipboard"
# bind -T copy-mode-vi MouseDragEnd1Pane send-keys -X copy-pipe-and-cancel "xclip -in -selection clipboard"
```

## 4. Плагины

Плагины значительно расширяют функциональность Tmux. Для управления плагинами рекомендуется использовать **Tmux Plugin Manager (tpm)**.

### Установка tpm

1. Клонируйте репозиторий tpm:

    ```bash
    git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
    ```

2. Добавьте следующие строки в конец вашего `~/.tmux.conf`:

    ```tmux.conf
    # Список плагинов
    set -g @plugin 'tmux-plugins/tpm'
    set -g @plugin 'tmux-plugins/tmux-sensible' # Основные настройки

    # Другие плагины (добавим позже)
    # set -g @plugin 'tmux-plugins/tmux-resurrect'
    # set -g @plugin 'tmux-plugins/tmux-continuum'
    # set -g @plugin 'tmux-plugins/tmux-themepack'
    # set -g @plugin 'tmux-plugins/tmux-session-manager'
    # set -g @plugin 'christoomey/vim-tmux-navigator'

    # Инициализация tpm (должна быть в самом конце файла)
    run '~/.tmux/plugins/tpm/tpm'
    ```

3. Перезагрузите Tmux (если он запущен) или запустите новый сеанс.
4. Нажмите `Prefix + I` (по умолчанию `Ctrl+b + I`) для установки добавленных плагинов.

### Рекомендуемые плагины

* **tmux-sensible:** Набор разумных настроек по умолчанию для Tmux.

    ```tmux.conf
    set -g @plugin 'tmux-plugins/tmux-sensible'
    ```

* **tmux-resurrect:** Сохраняет и восстанавливает сессии Tmux после перезагрузки системы.

    ```tmux.conf
    set -g @plugin 'tmux-plugins/tmux-resurrect'
    ```

* **tmux-continuum:** Автоматическое сохранение сессий (работает в связке с `tmux-resurrect`).

    ```tmux.conf
    set -g @plugin 'tmux-plugins/tmux-continuum'
    # Настройка автосохранения каждые 15 минут
    set -g @continuum-restore 'on'
    set -g @continuum-save-interval '15'
    ```

* **tmux-themepack:** Красивые темы для статус-бара Tmux.

    ```tmux.conf
    set -g @plugin 'tmux-plugins/tmux-themepack'
    # Выберите тему, например 'powerline/double/cyan'
    set -g @themepack-option 'powerline/double/cyan'
    ```

* **tmux-session-manager:** Удобное управление сессиями, включая нечеткий поиск.

    ```tmux.conf
    set -g @plugin 'tmux-plugins/tmux-session-manager'
    # Горячая клавиша для вызова менеджера сессий (по умолчанию Ctrl+b + o)
    # bind o run-shell "tmux-session-manager" # пример
    ```

* **vim-tmux-navigator (christoomey/vim-tmux-navigator):** Позволяет бесшовно переключаться между панелями Tmux и буферами Vim/NeoVim с помощью одной и той же комбинации клавиш (Ctrl+h/j/k/l).

    ```tmux.conf
    set -g @plugin 'christoomey/vim-tmux-navigator'
    # Для работы этого плагина также требуется соответствующая настройка в файле конфигурации Vim/NeoVim.
    ```

После добавления плагинов в `.tmux.conf` нажмите `Prefix + I` для их установки.

## 5. Практические сценарии

### Управление сессиями

* **Запуск новой сессии:**

    ```bash
    tmux new -s my_session
    ```

    (или просто `tmux` для сессии с именем по умолчанию)
* **Отключение от сессии (Detach):** `Prefix + d`
* **Подключение к последней сессии (Attach):**

    ```bash
    tmux attach
    # или
    tmux a
    ```

* **Подключение к именованной сессии:**

    ```bash
    tmux attach -t my_session
    # или
    tmux a -t my_session
    ```

* **Список всех сессий:**

    ```bash
    tmux ls
    ```

* **Переименование текущей сессии:** `Prefix + $`
* **Переключение между сессиями:** `Prefix + s` (показать список), затем используйте стрелки для выбора и Enter. С `tmux-session-manager` можно использовать `Prefix + o` (или другую настроенную клавишу) для быстрого поиска и переключения.

### Управление окнами

* **Создание нового окна:** `Prefix + c`
* **Переименование текущего окна:** `Prefix + ,`
* **Переключение между окнами:**
  * `Prefix + <номер_окна>` (например, `Prefix + 1`)
  * `Prefix + p` (предыдущее окно)
  * `Prefix + n` (следующее окно)
  * `Prefix + w` (показать список окон)

### Управление панелями

* **Разделение текущей панели:**
  * Вертикально: `Prefix + |` (или `Prefix + %` по умолчанию)
  * Горизонтально: `Prefix + -` (или `Prefix + "` по умолчанию)
* **Переключение между панелями:** `Prefix + <стрелка_направления>` (или настроенные `Prefix + h/j/k/l`)
* **Изменение размера панели:** `Prefix + Ctrl + <стрелка_направления>` или `Prefix + H/J/K/L` (если настроены)
* **Закрытие текущей панели:** `Ctrl+d` (как закрытие обычного терминала) или `Prefix + x` (с подтверждением).
* **Развернуть/свернуть панель (Zoom):** `Prefix + z`
* **Перемещение панели:** `Prefix + {` (влево), `Prefix + }` (вправо)

### Режим копирования (Copy Mode)

Позволяет прокручивать вывод терминала и копировать текст.

* **Вход в режим копирования:** `Prefix + [`
* **Навигация:** Стрелки, PageUp/PageDown, или Vim-подобные клавиши (h/j/k/l).
* **Выделение:** `Space` для начала выделения, `Enter` для копирования (в буфер Tmux).

  Управление конфигурацией и сессиями:

* Alt + r: Перезагрузить конфиг tmux (~/.config/tmux/tmux.conf).
* Alt + s: Показать дерево сессий, окон и панелей для быстрой навигации.
* Alt + d: Отключиться от текущей сессии.
* Alt + Q: Закрыть всю сессию (спросит подтверждение).

  Окна и панели:

* Alt + Enter: Создать новое окно.
* Alt + q: Закрыть текущее окно.
* Alt + c: Закрыть текущую панель.
* Alt + h: Разделить окно по вертикали (создаст панель снизу).
* Alt + v: Разделить окно по горизонтали (создаст панель справа).
* Alt + 1...9: Быстрое переключение между окнами по их номеру.
* Alt + ←/→/↑/↓: Перемещение между панелями.

  Изменение размера панелей:

* Alt + Shift + ←: Увеличить размер панели влево.
* Alt + Shift + →: Увеличить размер панели вправо.
* Alt + Shift + ↑: Увеличить размер панели вверх.
* Alt + Shift + ↓: Увеличить размер панели вниз.

  Копирование и поиск (режим `vi`):

* Alt + /: Войти в режим копирования и начать поиск текста вниз.
* Alt + ?: Войти в режим копирования и начать поиск текста вверх.
* В режиме копирования, v: Начать выделение текста.
* В режиме копирования, y: Скопировать выделенный текст в системный буфер обмена.

  1. Основные стандартные хоткеи (с префиксом Ctrl + b)

* Ctrl+b d: Отключиться от текущей сессии (detach).
* Ctrl+b w: Показать интерактивный список окон.
* Ctrl+b c: Создать новое окно (вы уже используете Alt+Enter).
* Ctrl+b ,: Переименовать текущее окно.
* Ctrl+b %: Разделить панель по вертикали (как Alt+v).
* Ctrl+b ": Разделить панель по горизонтали (как Alt+h).
* Ctrl+b z: "Зазумить" текущую панель на весь экран. Повторное нажатие вернет все как было.
* Ctrl+b x: Убить текущую панель (с подтверждением).

  1. Сценарии использования

  Сценарий 1: "Вечная" рабочая среда

  Вы работаете над проектом на удаленном сервере.

   1. Подключаетесь к серверу по SSH.
   2. Запускаете tmux new -s project_name.
   3. Открываете в панелях все, что нужно: vim в одной, git в другой, запущенный сервер в третьей.
   4. Вам нужно отключиться. Нажимаете Alt + d (или Ctrl+b d). Вы отключаетесь от сессии, но все процессы (vim, сервер) продолжают работать на сервере.
   5. Когда вы снова подключаетесь к серверу, просто вводите tmux attach -t project_name и мгновенно возвращаетесь в свою рабочую среду.

  Сценарий 2: Разработка и мониторинг

  Вы пишете код и хотите видеть результат в реальном времени.

   1. Открываете vim или другой редактор в левой панели.
   2. Нажимаете Alt + v, чтобы создать панель справа.
   3. В правой панели запускаете тестовый фреймворк в режиме "watch" или сервер разработки (например, npm run dev).
   4. Вы меняете код слева, а справа сразу видите результат пересборки или обновления тестов.
   5. Нужен терминал для git? Жмете Alt + h, и у вас появляется еще одна панель снизу, не мешая первым двум.

  Сценарий 3: Копирование вывода команды

  Вам нужно скопировать ошибку или длинный путь из терминала.

   1. Нажимаете Ctrl + b [ чтобы войти в режим копирования (vi-mode).
   2. Стрелками или h/j/k/l добираетесь до нужного места.
   3. Нажимаете v, чтобы начать выделение.
   4. Двигаете курсор, чтобы выделить нужный блок текста.
   5. Нажимаете y, и текст копируется в буфер обмена вашей основной системы.

   6. Ваши плагины

* tmux-plugins/tpm: Менеджер плагинов. Вы уже использовали его для установки. Ctrl+b I для установки новых, Ctrl+b U для обновления существующих.
* catppuccin/tmux: Красивая цветовая схема. Она уже работает.
* tmux-plugins/tmux-resurrect: Сохраняет ваши сессии, окна и панели после перезагрузки компьютера.
  * Ctrl+b + Ctrl+s: Сохранить окружение.
  * Ctrl+b + Ctrl+r: Восстановить окружение.
* tmux-plugins/tmux-continuum: Дополнение к resurrect. Автоматически сохраняет ваше окружение каждые 15 минут (согласно вашей настройке), так что вам даже не нужно думать о ручном сохранении.
