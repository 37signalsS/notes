# Горячие клавиши macOS

Этот файл содержит систематизированный список полезных сочетаний клавиш для macOS, составленный на основе практических руководств и опыта DevOps-инженеров.

## 1. Базовые сочетания клавиш

| Сочетание | Описание |
|:----------|:---------|
| `Command + C` | Копировать |
| `Command + V` | Вставить |
| `Command + X` | Вырезать (работает для текста, в Finder не вырезает файлы напрямую) |
| `Command + Option + V` | Переместить (эквивалент "вырезать и вставить" для файлов в Finder) |
| `Command + Z` | Отменить последнее действие |
| `Command + Shift + Z` | Повторить отмененное действие (Redo) |
| `Command + A` | Выделить все |
| `Command + F` | Поиск |
| `Command + S` | Сохранить |
| `Command + P` | Печать |
| `Command + ,` (запятая) | Открыть настройки активного приложения |

## 2. Работа с файлами и Finder

| Сочетание | Описание |
|:----------|:---------|
| `Space` (Пробел) | Быстрый просмотр (Quick Look) выбранного файла |
| `Command + I` | Показать информацию о файле (Get Info) |
| `Command + Ctrl + I` | Инспектор: показывает одно общее окно информации для всех выбранных файлов (вместо множества отдельных окон) |
| `Command + Option + P` | Показать или скрыть строку пути (Path Bar) внизу окна |
| `Command + Option + S` | Показать или скрыть боковую панель (Sidebar) |
| `Command + /` | Показать или скрыть строку состояния (Status Bar) |
| `Command + J` | Открыть параметры вида (View Options) для текущей папки |
| `Command + Up Arrow` | Перейти в родительскую папку |
| `Command + Down Arrow` | Открыть выбранный файл или войти в папку |
| `Option + Стрелка вправо` | В режиме списка (List View) разворачивает выбранную папку и **все** вложенные в нее подпапки |
| `Command + Option + C` | Скопировать путь к выбранному файлу или папке в виде текста |
| `Command + Option + Перетаскивание` | Создать псевдоним (Alias) для объекта при перемещении |

## 3. Окна и приложения

| Сочетание | Описание |
|:----------|:---------|
| `Command + Tab` | Переключение между запущенными приложениями |
| `Command + Tab`, затем `Q` | Не отпуская `Command`, можно закрыть выбранное в переключателе приложение |
| `Command + Tab`, затем `H` | Не отпуская `Command`, можно скрыть выбранное в переключателе приложение |
| `Command + ~` (тильда) | Переключение между окнами одного и того же приложения |
| `Command + Q` | Полностью закрыть приложение (Quit) |
| `Command + W` | Закрыть текущее окно или вкладку |
| `Command + M` | Свернуть текущее окно (Minimize) |
| `Command + H` | Скрыть окна текущего приложения (Hide) |
| `Command + Option + H` | Скрыть окна всех приложений, кроме активного |
| `Command + Option + Escape` | Окно принудительного завершения программ (аналог Ctrl+Alt+Delete) |
| `Fn + F` | Переход в полноэкранный режим и выход из него |
| `Option + Click` на зеленую кнопку окна | Масштабировать окно на весь экран (без перехода в Full Screen Mode) |

## 4. Скриншоты и запись экрана

| Сочетание | Описание |
|:----------|:---------|
| `Command + Shift + 3` | Снимок всего экрана |
| `Command + Shift + 4` | Снимок выбранной области |
| `Command + Shift + 4`, затем `Space` | Сделать снимок конкретного окна (курсор превратится в камеру) |
| `Command + Shift + 5` | Меню скриншотов и записи экрана (настройки, таймер, выбор области) |

## 5. Работа с текстом и редактированием

| Сочетание | Описание |
|:----------|:---------|
| `Command + Стрелка влево/вправо` | Перейти в начало или конец текущей строки |
| `Command + Стрелка вверх/вниз` | Перейти в начало или конец документа |
| `Option + Стрелка влево/вправо` | Переместить курсор на одно слово вперед или назад |
| `Option + Delete` | Удалить слово слева от курсора |
| `Shift + Команды перемещения` | Выделить текст во время перемещения курсора |
| `Fn + Delete` | Удаление символа справа от курсора (Delete Forward) |
| `Command + Option + Shift + V` | Вставить текст без сохранения исходного форматирования |
| `Option + Escape` | Показать список вариантов для автозавершения слова (работает во многих редакторах) |
| `Ctrl + Command + D` | Быстрый поиск определения слова в словаре (Look Up) |
| `Option + Shift + -` (дефис) | Вставить длинное тире (—) |
| `Option + -` (дефис) | Вставить среднее тире или минус (–) |
| `Option + Shift + K` | Напечатать символ Apple () |
| `Ctrl + Command + Space` | Панель выбора эмодзи и символов |

## 6. Браузер и вкладки (Safari, Chrome)

| Сочетание | Описание |
|:----------|:---------|
| `Command + T` | Новая вкладка |
| `Command + Shift + T` | Восстановить последнюю закрытую вкладку |
| `Command + Shift + [` или `]` | Переключение между вкладками (влево/вправо) |
| `Command + (1–9)` | Перейти на вкладку с соответствующим номером |
| `Command + L` | Быстрый переход в адресную строку |
| `Command + R` | Обновить страницу |
| `Command + Option + R` | Полная перезагрузка страницы (без кэша) |
| `Command + Shift + R` | Режим чтения (если поддерживается страницей) |
| `Command + Shift + I` | Отправить текущую страницу по электронной почте |

## 7. Системные и дополнительные возможности

| Сочетание | Описание |
|:----------|:---------|
| `Command + Space` | Поиск Spotlight |
| `Command + Option + D` | Показать или скрыть панель Dock |
| `Shift + Command + /` (слэш) | Открыть меню "Справка" (Help) и активировать строку поиска по пунктам меню |
| `Option + Click` на иконку звука | Выбор источников ввода и вывода аудио в статус-баре |
| `Option + Click` на иконку Wi-Fi | Подробная техническая информация о сети (IP, BSSID, уровень сигнала, канал) |
| `Option + Click` на иконку Центра уведомлений | Включить или выключить режим "Не беспокоить" (DND) |
| `Command + Click` на заголовок окна | Показать иерархию папок до текущего местоположения |
| `Command` (удерживать) | Позволяет перетаскивать иконки в статус-баре для изменения их порядка |
| `Command + Перетаскивание` из статус-бара | Удалить иконку из статус-бара |
| `Option + Click` на полосу прокрутки | Мгновенный переход к месту клика (вместо прокрутки на страницу) |
| `Ctrl + Command + Q` | Заблокировать экран |
