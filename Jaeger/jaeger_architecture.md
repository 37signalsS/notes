# Архитектура Jaeger

## Назначение и общий контекст

Jaeger — распределённая система трассировки, предназначенная для наблюдаемости межсервисных взаимодействий. Архитектура Jaeger разделяет сбор, транспорт, хранение и визуализацию трасс, чтобы независимо масштабировать каждый слой и подстраиваться под разные требования к задержкам, объёму данных и стоимости.

## Ключевые компоненты и их роли

| Компонент | Назначение | Масштабирование и особенности |
| --- | --- | --- |
| Клиентская инструментализация (чаще через OpenTelemetry SDK) | Создаёт спаны, контекст и метаданные | Внедряется в код; поддерживает head-based sampling |
| Agent (классический Jaeger) или OpenTelemetry Collector | Локальный приём и буферизация, преобразование протоколов | Агент как DaemonSet/sidecar; Collector централизуется и упрощает маршрутизацию |
| Collector (Jaeger Collector) | Принимает батчи трасс, нормализует и записывает в хранилище | Статлесс, масштабируется горизонтально за Load Balancer |
| Kafka + Ingester (опционально) | Декаплинг приёмки и записи в хранилище, сглаживание пиков | Позволяет выдерживать всплески; Ingester читает из Kafka и пишет в сторедж |
| Storage (Elasticsearch, Cassandra, Badger) | Долговременное хранение спанов и индексов | Выбор зависит от объёма, задержек и стоимости; Badger для разработчиков |
| Query | API для чтения трасс и агрегатов | Статлесс, читающий слой над хранилищем |
| UI | Веб-интерфейс для поиска и анализа трасс | Отдаётся сервисом Query; кеширование уменьшает нагрузку |

## Поток данных

*   Приложение формирует спаны и контекст и отправляет их локальному агенту или в OpenTelemetry Collector по OTLP/HTTP или OTLP/gRPC.
*   Агент/Collector по сети передаёт батчи в Jaeger Collector (gRPC/HTTP).
*   Collector применяет валидации, метаданные о сервисах и пишет напрямую в хранилище или в Kafka.
*   Ingester (при наличии Kafka) считывает сообщения и записывает в хранилище с управляемой скоростью.
*   Query получает запросы от UI, формирует выборки и возвращает трассы, зависимости и статистику.

Схематически:
Application → Agent/OTel Collector → Jaeger Collector → [Kafka → Ingester] → Storage → Query/UI

## Варианты развёртывания

*   **All-in-one**: единый бинарник для локальной разработки и демо.
*   **Продакшен**: раздельные сервисы, балансировка на входе Collector, асинхронная очередь через Kafka при высоком трафике.
*   **Kubernetes**: Agent как DaemonSet на каждом узле или sidecar; всё чаще — OpenTelemetry Collector как Deployment/DaemonSet, экспортирующий в Jaeger Collector.

## Сэмплирование

*   **Head-based** (на стороне SDK/агента): фиксированная вероятность, per-operation, rate limiting. Уменьшает трафик с источника.
*   **Remote sampling**: политика сэмплинга доставляется клиентам централизованно.
*   **Tail-based**: решение о сэмплинге принимается после наблюдения всей трассы (обычно в OpenTelemetry Collector). Позволяет сохранять редкие или ошибочные трассы, но требует больше ресурсов.

## Хранилище и индексы

*   **Elasticsearch**: быстрый поиск и гибкая индексация, удобен для высоких RPS на чтение.
*   **Cassandra**: горизонтально масштабируемая запись, предсказуемая пропускная способность.
*   **Badger**: локальное встраиваемое хранилище для небольших окружений.

Практики включают управление TTL, шаблоны индексов, шардирование и выделенные кластеры под горячие/холодные данные.

## Надёжность и производительность

*   Батчинг и очереди в агенте/Collector уменьшают накладные расходы.
*   Kafka буферизует пики и отделяет SLA приёмки от SLA записи.
*   Горизонтальное масштабирование Collector/Query, ограничение размеров спана, сжатие и контроль кардинальности тегов.
*   Периодические задачи анализа зависимостей формируют граф сервисов для UI и аналитики.

## Минимальный пример через OpenTelemetry Collector

```yaml
receivers:
  otlp:
    protocols:
      http:
      grpc:

processors:
  batch:

exporters:
  jaeger:
    endpoint: jaeger-collector:14250
    tls:
      insecure: true

service:
  pipelines:
    traces:
      receivers: [otlp]
      processors: [batch]
      exporters: [jaeger]
```
