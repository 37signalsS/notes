# MAC-адрес (Media Access Control)

## Определения

**MAC-адрес** — это уникальный идентификатор, который назначается сетевому интерфейсу (сетевой карте) для связи на канальном уровне ([Layer 2](../OSI_TCP_IP_Model/osi_model.md)) в сегменте сети. Он используется в таких технологиях, как [Ethernet](../Protocols/ethernet.md) и Wi-Fi, для доставки кадров (frames) конкретному устройству в локальной сети.

В стандарте IEEE 802, канальный уровень разделен на два подуровня:
*   **LLC (Logical Link Control):** Отвечает за взаимодействие с сетевым уровнем.
*   **MAC (Media Access Control):** Отвечает за управление доступом к среде и использует MAC-адреса для адресации.

MAC-адреса регламентированы стандартами IEEE 802.

## Основные концепции

### Структура и формат

- **Длина:** 6 байт (48 бит).
- **Формат записи:** Шесть групп по две шестнадцатеричные цифры, разделенные двоеточиями (`:`) или дефисами (`-`).
  - Пример: `00:1A:2B:3C:4D:5E` или `00-1A-2B-3C-4D-5E`.

### Типы MAC-адресов

1.  **Индивидуальный (Unicast):**
    -   Адрес, который идентифицирует один конкретный сетевой адаптер.
    -   Кадр, отправленный на unicast-адрес, доставляется только одному устройству в сети.
    -   Первый бит старшего байта равен `0`.

2.  **Групповой (Multicast):**
    -   Адрес, который используется для отправки данных группе устройств.
    -   Кадр, отправленный на multicast-адрес, получают все устройства, которые подписаны на эту группу.
    -   Первый бит старшего байта равен `1`.
    -   Пример: `01:00:5E:00:00:01`.

3.  **Широковещательный (Broadcast):**
    -   Специальный адрес для отправки данных всем устройствам в одном сегменте сети.
    -   Кадр, отправленный на broadcast-адрес, получают все устройства в сети.
    -   Адрес состоит из всех битовых единиц.
    -   Шестнадцатеричное представление: `FF:FF:FF:FF:FF:FF`.

### Уникальность и назначение адресов

Крайне важно, чтобы MAC-адреса были уникальны в пределах одного сегмента сети. Если в сети появятся два устройства с одинаковыми MAC-адресами, возникнет конфликт, который может привести к сбоям в работе одного или обоих устройств.

Существует два способа назначения MAC-адресов:

#### 1. Централизованное назначение (аппаратный адрес)

Это способ по умолчанию. MAC-адрес "прошивается" производителем оборудования в сетевой адаптер на заводе. Для обеспечения глобальной уникальности используется иерархическая схема:

-   **Первые 3 байта (24 бита):** **OUI (Organizationally Unique Identifier)** — уникальный идентификатор организации, который выдается производителю комитетом IEEE. По OUI можно определить производителя устройства.
    -   Примеры OUI: `00-1B-63` (Cisco), `00-0A-95` (IBM), `E8-03-9A` (Intel).
-   **Последние 3 байта (24 бита):** Назначаются производителем по своему усмотрению. Производитель должен гарантировать, что он не выпустит два адаптера с одинаковым OUI и одинаковой второй частью адреса.

#### 2. Локальное назначение (программный адрес)

Сетевой администратор может вручную изменить MAC-адрес сетевого адаптера. В этом случае ответственность за обеспечение уникальности адресов в сети ложится на администратора.

**Как отличить централизованный адрес от локального?**

Для этого используется **второй бит** старшего байта MAC-адреса:
-   `0`: Адрес назначен централизованно (аппаратный).
-   `1`: Адрес назначен локально (программный).

## Практические сценарии

### Как посмотреть MAC-адрес

#### Windows
- **Командная строка:**
  ```cmd
  ipconfig /all
  ```
  (Искать "Физический адрес")
- **Графический интерфейс:** В свойствах сетевого подключения.

#### Linux
- **Команда `ip` (современный способ):**
  ```bash
  ip link show
  ```
  или
  ```bash
  ip a
  ```
  (Искать `link/ether`)
- **Команда `ifconfig` (устаревший способ):**
  ```bash
  ifconfig
  ```
  (Искать `ether` или `HWaddr`)
