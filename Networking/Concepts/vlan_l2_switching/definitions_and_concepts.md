# L2 Switching и VLAN: Определения и концепции

## Определения

**Коммутатор (Switch)** — устройство канального уровня (L2), пересылающее кадры между устройствами на основе [MAC-адресов](../mac_address.md).

**Broadcast-домен** — сегмент сети, где все устройства получают широковещательные пакеты друг друга. По умолчанию один коммутатор = один broadcast-домен.

**Широковещательный домен (Broadcast Domain)** — группа доменов коллизий, соединённых устройствами второго уровня (коммутаторами). Это участок сети, в котором все узлы могут передавать данные друг другу с помощью широковещательного пакета на канальном уровне модели OSI. Широковещательный пакет имеет MAC-адрес назначения `FF:FF:FF:FF:FF:FF` и доставляется всем устройствам в пределах домена.

**VLAN** — технология логического разделения broadcast-доменов. Подробное описание протокола 802.1Q см. в **[VLAN (протокол)](../../Protocols/vlan.md)**.

## Базовые концепции

### Принцип работы коммутатора

Подробное описание алгоритма работы коммутатора, таблицы коммутации и практические примеры см. в **[Канальный уровень → Коммутатор](../../OSI_TCP_IP_Model/data_link_layer.md#коммутатор-switch)**.

Коммутатор работает с **таблицей MAC-адресов** (MAC address table, CAM table) для принятия решений о пересылке кадров в пределах [VLAN](../../Protocols/vlan.md). Формат кадра 802.1Q описан в **[VLAN 802.1Q Frame](../../Protocols/VLAN/vlan_8021q_frame.md)**, предотвращение петель — в **[STP](../../Protocols/stp.md)**.

**Пример таблицы MAC-адресов с VLAN:**

```
MAC Address       VLAN    Port
--------------    ----    ----
00:1A:2B:3C:4D:5E 10      Gi0/1
00:1A:2B:3C:4D:5F 10      Gi0/2
00:1A:2B:3C:4D:60 20      Gi0/3
```

### Сегментация сети с помощью VLAN

**Зачем делить сеть на VLAN:**

| Причина | Описание |
|---------|----------|
| **Изоляция** | Устройства в разных VLAN не видят друг друга на L2 |
| **Безопасность** | Критичные сервисы (серверы, управление) в отдельном VLAN |
| **Производительность** | Broadcast-трафик не распространяется за пределы VLAN |
| **Гибкость** | Группировка по отделам/проектам, а не физическому расположению |

**Пример сегментации:**

```
                    [Core Switch]
                         |
        +----------------+----------------+
        |                |                |
   [VLAN 10]        [VLAN 20]        [VLAN 30]
   Users            Servers          Management
   192.168.10.0/24  192.168.20.0/24  192.168.30.0/24
```

Подробнее о стратегиях сегментации см. **[Сетевая сегментация и микросегментация](../network_segmentation_and_microsegmentation.md)**. Основы адресации L2 — в **[MAC-адреса](../mac_address.md)**.
