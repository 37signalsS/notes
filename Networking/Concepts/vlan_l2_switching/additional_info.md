# L2 Switching и VLAN: Дополнительная информация

## Маркировка кабелей и портов

**Правильная маркировка кабелей критична для поддержки VLAN:**

### Стандарты маркировки

- **Двусторонняя маркировка:** Оба конца кабеля маркируются
- **Формат:** `Откуда → Куда` (например, `SW1-P24 → SRV3-eth0`)
- **VLAN информация:** На коммутаторе указать VLAN ID на порту

### Пример маркировки

```
Порт коммутатора:
  Gi0/1  [VLAN 10]  →  SRV1-eth0  (Users)
  Gi0/2  [VLAN 20]  →  SRV1-eth1  (Servers)
  Gi0/24 [TRUNK]    →  SW2-Gi0/1

Кабель:
  [SW1-P24] ====== [SW2-P1]
  CAT6A, 2024-03-15
```

## Best Practices

### Проектирование VLAN

1. **Планирование адресации:**
   - Одна подсеть = один VLAN
   - Резервирование адресов для роста

2. **Документирование:**
   - Таблица VLAN с назначением и подсетями
   - Схема связей между коммутаторами

3. **Безопасность:**
   - Отдельный VLAN для управления инфраструктурой
   - Изоляция гостевого доступа
   - Private VLAN для дополнительной изоляции

### Конфигурация коммутаторов

1. **Trunk-порты:**
   - Явно указывать разрешённые VLAN
   - Отключать неиспользуемые порты

2. **Access-порты:**
   - Назначать только необходимые VLAN
   - Использовать port security

3. **Native VLAN:**
   - Изменять с VLAN 1 на отдельный служебный VLAN
   - Не передавать пользовательский трафик
