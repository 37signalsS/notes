# Настройка и использование SR-IOV

## Настройка SR-IOV

```bash
# 1. Включить SR-IOV в BIOS

# 2. Загрузить модуль ядра
modprobe vfio-pci

# 3. Включить SR-IOV на NIC (пример Intel)
echo 4 > /sys/class/net/eth0/device/sriov_numvfs

# 4. Проверка созданных VF
lspci | grep Eth

# 5. Привязка VF к VFIO (для passthrough)
devbind.py --bind=vfio-pci 0000:04:10.0

# 6. Назначение VM в libvirt
<hostdev mode='subsystem' type='pci' managed='yes'>
  <source>
    <address domain='0x0000' bus='0x04' slot='0x10' function='0x0'/>
  </source>
</hostdev>
```

## Сравнение DPDK и SR-IOV

| Критерий | DPDK | SR-IOV |
|----------|------|--------|
| **Уровень** | Software (userspace) | Hardware (NIC) |
| **Требования** | Любой NIC + Hugepages | Поддержка SR-IOV в NIC |
| **Производительность** | Очень высокая | Максимальная (близка к bare metal) |
| **Гибкость** | Высокая (software-defined) | Ограничена возможностями NIC |
| **Live Migration** | Поддерживается | Не поддерживается |
| **Сложность** | Высокая | Средняя |

## Комбинирование DPDK + SR-IOV

```
┌─────────────────────────────────────────────────────────────┐
│                    Container/Pod                            │
│  ┌─────────────────────────────────────────────────────┐    │
│  │              DPDK Application                       │    │
│  │         (Обработка пакетов userspace)               │    │
│  └─────────────────────┬───────────────────────────────┘    │
└────────────────────────┼────────────────────────────────────┘
                         │
┌────────────────────────▼────────────────────────────────────┐
│              VF (Virtual Function)                          │
│         Прямой доступ через PCI passthrough                 │
└───────────────────────┬─────────────────────────────────────┘
                        │
┌───────────────────────▼─────────────────────────────────────┐
│              ФИЗИЧЕСКИЙ NIC (SR-IOV)                        │
└─────────────────────────────────────────────────────────────┘

Результат: Максимальная производительность!
```

**Преимущества комбинации:**
- VF предоставляет bare-metal доступ к NIC
- DPDK обрабатывает пакеты с максимальной эффективностью
- Идеально для Cloud-Native Network Functions (CNF)
