# Обзор DPDK (Data Plane Development Kit)

### Определения

- **DPDK (Data Plane Development Kit)**: Набор библиотек и userspace-драйверов для высокопроизводительной обработки сетевых пакетов. DPDK позволяет обходить сетевой стек ядра операционной системы, предоставляя приложениям прямой доступ к оборудованию (NIC).
- **Userspace-обработка**: Выполнение задач, традиционно находящихся в ядре (как обработка пакетов), в пространстве пользователя, чтобы избежать дорогостоящих системных вызовов и переключений контекста.

---

### Основные концепции

#### Проблема стандартного сетевого стека

Традиционная обработка пакета в ядре Linux связана с существенными накладными расходами:

- **Системные вызовы**: Каждая операция чтения/записи требует переключения контекста `userspace ↔ kernel`.
- **Копирование данных**: Пакеты копируются из буферов ядра в буферы приложения.
- **Обработка прерываний**: Сетевая карта генерирует прерывание для каждого полученного пакета, что создает большую нагрузку на CPU.

В результате производительность ограничивается ~1-2 миллионами пакетов в секунду (Mpps) на одно ядро CPU.

#### Архитектура DPDK: Обход ядра

DPDK решает эти проблемы, реализуя следующий подход:

1. **Poll Mode Drivers (PMD)**: Вместо прерываний, DPDK постоянно опрашивает (polls) сетевую карту на предмет новых пакетов. Это устраняет прерывания и обеспечивает предсказуемость.
2. **Прямой доступ к памяти (DMA)**: Приложения получают прямой доступ к буферам сетевой карты через механизм `UIO` или `VFIO`.
3. **Оптимизированное управление памятью**: Использование `HugePages` и пулов памяти (`mempool`) снижает задержки доступа к памяти.

```
┌──────────────────────────────────────┐
│         Приложение (Userspace)       │
│      (Прямая обработка пакетов)      │
├──────────────────────────────────────┤
│           Библиотеки DPDK            │
│ (EAL, PMD, Mempool, Lock-free-очереди)│
├──────────────────────────────────────┤
│         UIO/VFIO + Hugepages         │
└─────────┬───────────────────┬────────┘
          │                   │
┌─────────▼─────────┐  ┌──────▼──────┐
│  Сетевой адаптер  │  │   Ядро ОС   │
│ (Прямой доступ)   │  │ (НЕ ИСПОЛЬЗУЕТСЯ)│
└───────────────────┘  └─────────────┘
```

### Практические сценарии

DPDK является фундаментальной технологией для создания высокопроизводительных сетевых функций (NFV), таких как:

- Виртуальные маршрутизаторы (vRouter).
- Балансировщики нагрузки.
- Системы обнаружения и предотвращения вторжений (IDS/IPS).
- Компоненты мобильных сетей 4G/5G.

> Примеры конфигурации и кода см. в [Практические сценарии DPDK и SR-IOV](scenarios.md).
