# DPDK и SR-IOV: Обзор

## Определения

**DPDK (Data Plane Development Kit)** — это набор библиотек и драйверов для быстрой обработки пакетов в userspace, обходя стек ядра Linux. Обеспечивает производительность до миллионов пакетов в секунду на одном ядре CPU.

**SR-IOV (Single Root I/O Virtualization)** — это технология аппаратной виртуализации сетевых адаптеров, позволяющая одному физическому NIC представляться как несколько виртуальных (VF — Virtual Functions) для прямого назначения ВМ или контейнерам.

## DPDK (Data Plane Development Kit)

### Проблема стандартного сетевого стека Linux

```
┌─────────────────────────────────────────────────────────────┐
│                    ПРИЛОЖЕНИЕ (userspace)                   │
└───────────────────────┬─────────────────────────────────────┘
                        │ Системные вызовы (read/write/send/recv)
┌───────────────────────▼─────────────────────────────────────┐
│                      СТЕК TCP/IP (ядро)                     │
│  - Socket layer                                             │
│  - TCP/UDP layer                                            │
│  - IP layer                                                 │
└───────────────────────┬─────────────────────────────────────┘
                        │
┌───────────────────────▼─────────────────────────────────────┐
│                    ДРАЙВЕР СЕТЕВОЙ КАРТЫ                    │
└───────────────────────┬─────────────────────────────────────┘
                        │
┌───────────────────────▼─────────────────────────────────────┐
│                    СЕТЕВОЙ АДАПТЕР (NIC)                    │
└─────────────────────────────────────────────────────────────┘
```

**Накладные расходы стандартного стека:**
- Переключение контекста userspace ↔ kernel
- Копирование данных между kernel и userspace
- Прерывания (interrupts) для каждого пакета
- **Результат:** ~1-2 Mpps на ядро

### Архитектура DPDK

```
┌─────────────────────────────────────────────────────────────┐
│                    ПРИЛОЖЕНИЕ DPDK                          │
│  - Обработка пакетов в userspace                            │
│  - Прямой доступ к памяти NIC                               │
└───────────────────────┬─────────────────────────────────────┘
                        │
┌───────────────────────▼─────────────────────────────────────┐
│                    DPDK LIBRARIES                           │
│  - EAL (Environment Abstraction Layer)                      │
│  - Mempool (управление памятью)                             │
│  - Ring (lock-free очереди)                                 │
│  - PMD (Poll Mode Drivers)                                  │
└───────────────────────┬─────────────────────────────────────┘
                        │
┌───────────────────────▼─────────────────────────────────────┐
│         UIO/VFIO (Userspace I/O) + Hugepages                │
└───────────────────────┬─────────────────────────────────────┘
                        │
┌───────────────────────▼─────────────────────────────────────┐
│                    СЕТЕВОЙ АДАПТЕР (NIC)                    │
│         Прямой доступ из userspace!                         │
└─────────────────────────────────────────────────────────────┘
```

### Ключевые компоненты DPDK

| Компонент | Назначение |
|-----------|------------|
| **EAL** | Абстракция от ОС, управление памятью, потоками |
| **Mempool** | Пул фиксированных буферов для пакетов |
| **Ring** | Lock-free кольцевые буферы (очереди) |
| **PMD** | Poll Mode Drivers — драйверы в userspace |
| **MBuf** | Структура для хранения пакетов |
