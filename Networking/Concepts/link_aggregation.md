# Агрегация каналов (Link Aggregation)

**Агрегация каналов** (также известная как `Bonding`, `Teaming` или `Link Aggregation`) — это технология, позволяющая объединить несколько физических сетевых интерфейсов в один логический. Это делается для достижения двух основных целей:

1.  **Отказоустойчивость (Fault Tolerance):** Если один из физических каналов выходит из строя, трафик автоматически перенаправляется через оставшиеся рабочие каналы, обеспечивая непрерывность соединения.
2.  **Увеличение пропускной способности (Bandwidth Aggregation):** Суммирование пропускной способности нескольких каналов для увеличения общей скорости передачи данных.

## Режимы работы в Linux (Bonding)

Модуль `bonding` в ядре Linux поддерживает несколько режимов работы, которые определяют, как трафик распределяется между объединенными интерфейсами.

-   `mode=0` (**balance-rr**, Round-robin):
    -   **Принцип:** Пакеты поочередно отправляются через каждый интерфейс в группе.
    -   **Преимущества:** Обеспечивает балансировку нагрузки.
    -   **Недостатки:** Может приводить к нарушению порядка доставки пакетов.

-   `mode=1` (**active-backup**):
    -   **Принцип:** Один интерфейс активен, остальные находятся в режиме ожидания. Если активный интерфейс падает, один из резервных занимает его место.
    -   **Преимущества:** Идеально для простой отказоустойчивости.
    -   **Недостатки:** Не увеличивает пропускную способность, так как используется только один канал.

-   `mode=2` (**balance-xor**):
    -   **Принцип:** Выбор интерфейса для отправки пакета осуществляется на основе XOR-операции над MAC-адресами отправителя и получателя.
    -   **Преимущества:** Обеспечивает балансировку и отказоустойчивость.

-   `mode=3` (**broadcast**):
    -   **Принцип:** Все пакеты отправляются через все интерфейсы в группе.
    -   **Преимущества:** Максимальная отказоустойчивость.
    -   **Недостатки:** Непрактично, не балансирует нагрузку.

-   `mode=4` (**802.3ad**, LACP - Link Aggregation Control Protocol):
    -   **Принцип:** Динамическая агрегация каналов. Создает группы агрегации с одинаковыми скоростями и настройками дуплекса.
    -   **Преимущества:** Отраслевой стандарт, обеспечивает отличную балансировку и отказоустойчивость.
    -   **Требование:** Нужна поддержка со стороны сетевого коммутатора.

-   `mode=5` (**balance-tlb**, Adaptive Transmit Load Balancing):
    -   **Принцип:** Исходящий трафик распределяется в зависимости от текущей нагрузки на каждом интерфейсе. Входящий трафик принимается только одним интерфейсом.
    -   **Требование:** Не требует специальной настройки коммутатора.

-   `mode=6` (**balance-alb**, Adaptive Load Balancing):
    -   **Принцип:** Включает в себя `balance-tlb` и дополнительно балансировку входящего трафика (через ARP-ответы).
    -   **Требование:** Не требует специальной настройки коммутатора.

## Настройка

Настройка `bonding` обычно выполняется через системные конфигурационные файлы сети (например, в `/etc/network/interfaces` для Debian/Ubuntu или через `nmcli`/`nmtui` для систем с NetworkManager).
