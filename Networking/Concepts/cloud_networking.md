# Облачная сеть и хранилище — Основные понятия

Файл содержит обзор ключевых компонентов облачной инфраструктуры: сетей, типов хранилищ и географического распределения.

## Облачная сеть (VPC)

**VPC (Virtual Private Cloud)** — логически изолированная виртуальная сеть внутри облака провайдера.

- **Программное управление:** все настройки сети (подсети, таблицы маршрутизации, шлюзы) доступны через API.
- **Изоляция:** трафик между VPC разных клиентов полностью изолирован на уровне гипервизора и сетевых протоколов (например, VXLAN).
- **Security Groups:** облачные файерволлы, работающие на уровне виртуальных интерфейсов машин, а не внутри ОС.

## Типы облачных хранилищ

| Тип | Название | Характеристики | Примеры использования |
| :--- | :--- | :--- | :--- |
| **Блочное** | Block Storage / Диски | Эмулирует физический диск (HDD/SSD). Привязан к одной ВМ. Высокая скорость I/O. | Системные диски ОС, базы данных. |
| **Объектное** | Object Storage (S3) | Хранение файлов как объектов с метаданными. Доступ по HTTP. Бесконечно масштабируемо. | Бэкапы, статика сайтов, медиафайлы, логи. |
| **Файловое** | File Storage (NFS/SMB) | Сетевая папка, к которой могут подключаться несколько машин одновременно. | Общие конфиги, медиа-архивы для группы серверов. |

## Географическая структура

Для обеспечения отказоустойчивости и минимальных задержек ресурсы распределяются географически:

1. **Регион (Region):** Географическая область (например, Москва, Франкфурт). Состоит из нескольких зон доступности.
2. **Зона доступности (Availability Zone / AZ):** Один или несколько дата-центров, физически удаленных друг от друга, с независимым электропитанием и каналами связи.

**Практика отказоустойчивости:** Развертывание приложения минимум в двух зонах доступности позволяет пережить выход из строя целого дата-центра.

## Стоимость трафика (Egress)

Важный аспект облачной экономики:
- **Входящий трафик (Ingress):** обычно бесплатен.
- **Исходящий трафик (Egress):** выгрузка данных из облака в интернет — платная и зачастую дорогая услуга.
- **Внутренний трафик:** передача данных между зонами доступности внутри одного региона часто тарифицируется, но дешевле внешнего трафика.
