# Сетевые порты

## Определения

**Порт** — это числовое значение (от 0 до 65535), которое используется на [транспортном уровне (L4)](../OSI_TCP_IP_Model/osi_tcp_ip_models.md) для идентификации конкретного процесса или службы на устройстве.

Пара `IP-адрес:Порт` однозначно идентифицирует конечную точку сетевого соединения, которая называется **[сокет (socket)](./socket_api.md)**.

## Основные концепции

Когда компьютер обменивается данными по сети, он использует [IP-адрес](./ip_address.md) для определения устройства-получателя и **номер порта** для указания, какому именно приложению на этом устройстве предназначены данные.

Порты делятся на три диапазона в соответствии с рекомендациями IANA (Internet Assigned Numbers Authority):

1.  **Системные (Well-Known Ports):** 0–1023
2.  **Зарегистрированные (Registered Ports):** 1024–49151
3.  **Динамические (Dynamic/Private Ports):** 49152–65535

## Практика

### 1. Системные порты (0–1023)
*   **Назначение:** Зарезервированы для стандартных, хорошо известных системных служб и протоколов.
*   **Особенность:** Для использования (прослушивания) этих портов в большинстве ОС требуются права суперпользователя (root).
*   **Примеры:**
    *   `22`: SSH
    *   `25`: SMTP
    *   `53`: [DNS](../Protocols/dns_protocol.md)
    *   `80`: [HTTP](../Protocols/http_protocol.md)
    *   `443`: [HTTPS](../Protocols/tls_protocol.md)

### 2. Зарегистрированные порты (1024–49151)
*   **Назначение:** Предназначены для приложений, которые устанавливаются пользователями. Компании могут официально зарегистрировать порт в IANA для своего приложения.
*   **Примеры:**
    *   `1433`: Microsoft SQL Server
    *   `3306`: MySQL
    *   `5432`: PostgreSQL
    *   `8080`, `8000`: Часто используются как альтернативные порты для веб-серверов.

### 3. Динамические порты (49152–65535)
*   **Назначение:** Используются для временных (эфемерных) соединений.
*   **Принцип работы:** Когда клиент подключается к серверу (например, на порт 443), он выбирает для себя случайный свободный порт из этого диапазона для **исходящего** соединения.
