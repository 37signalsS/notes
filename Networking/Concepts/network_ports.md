# Сетевые порты

**Порт** — это числовое значение (от 0 до 65535), которое используется на [транспортном уровне (L4)](../OSI_TCP_IP_Model/osi_tcp_ip_models.md) для идентификации конкретного процесса или службы, работающей на устройстве.

Когда компьютер обменивается данными по сети, он использует [IP-адрес](./ip_address.md) для определения устройства-получателя и **номер порта** для указания, какому именно приложению на этом устройстве предназначены данные.

Пара `IP-адрес:Порт` однозначно идентифицирует конечную точку сетевого соединения, которая называется **[сокет (socket)](./socket_api.md)**.

## Диапазоны портов

Порты делятся на три диапазона в соответствии с рекомендациями IANA (Internet Assigned Numbers Authority):

### 1. Системные (или общеизвестные) порты (Well-Known Ports): 0–1023
*   **Назначение:** Зарезервированы для стандартных, хорошо известных системных служб и протоколов.
*   **Особенность:** Для использования (прослушивания) этих портов в большинстве операционных систем требуются права суперпользователя (root).
*   **Примеры:**
    *   `22`: SSH (Secure Shell)
    *   `25`: SMTP (Simple Mail Transfer Protocol)
    *   `53`: [DNS (Domain Name System)](../Protocols/dns_protocol.md)
    *   `80`: [HTTP (HyperText Transfer Protocol)](../Protocols/http_protocol.md)    *   `443`: [HTTPS (HTTP Secure)](../Protocols/tls_protocol.md)

### 2. Зарегистрированные (или пользовательские) порты (Registered/User Ports): 1024–49151
*   **Назначение:** Предназначены для приложений и служб, которые устанавливаются пользователями или сторонним программным обеспечением. Компании могут официально зарегистрировать порт для своего приложения в IANA, чтобы избежать конфликтов.
*   **Примеры:**
    *   `1433`: Microsoft SQL Server
    *   `3306`: MySQL
    *   `5432`: PostgreSQL
    *   `8080`, `8000`: Часто используются как альтернативные порты для веб-серверов во время разработки.

### 3. Динамические (или частные) порты (Dynamic/Private/Ephemeral Ports): 49152–65535
*   **Назначение:** Используются для временных (эфемерных) соединений.
*   **Принцип работы:** Когда ваш компьютер (клиент) подключается к веб-серверу (например, на порт 443), он выбирает для себя случайный свободный порт из этого диапазона для **исходящего** соединения. Это позволяет установить множество одновременных соединений с одним и тем же сервером.
*   **Особенность:** Эти порты не закрепляются за какой-либо службой на постоянной основе и свободны для использования любым приложением.
