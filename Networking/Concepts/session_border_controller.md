# Session Border Controller (SBC)

## Определения

**SBC (Session Border Controller)** — сетевое устройство (или программный модуль), размещаемое на границе сети для управления сессиями VoIP. Обеспечивает безопасность, межсетевое взаимодействие и трансляцию сигнальных и медиа-потоков между разнородными сетями и устройствами.

SBC работает на прикладном уровне (L7) модели OSI, анализируя и модифицируя SIP/SDP и RTP-трафик.

## Основные концепции

### Архитектура B2BUA

SBC функционирует как **B2BUA (Back-to-Back User Agent)** — разрывает каждую сигнальную сессию на два независимых «плеча»:

- Со стороны отправителя SBC выступает как **UAS (User Agent Server)** — принимает запрос.
- Со стороны получателя SBC выступает как **UAC (User Agent Client)** — инициирует новый запрос.

Это позволяет контроллеру полностью контролировать обе половины вызова, модифицировать заголовки и медиа-параметры независимо.

### Основные функции

| Функция | Описание |
| :--- | :--- |
| **Безопасность** | Защита от DDoS, флуда, подмены SIP-заголовков; контроль доступа через ACL (Access Control List) |
| **Межсетевое взаимодействие** | Соединение несовместимых сигнальных протоколов и медиа-кодеков; трансляция адресов (NAT traversal) |
| **Транскодинг** | Преобразование медиа-потоков (RTP) между кодеками, когда две стороны не могут согласовать параметры в SDP |
| **Шифрование** | TLS для сигнального трафика (SIP) и SRTP для медиа-потоков |
| **Фильтрация SDP** | Модификация полей SDP (Session Description Protocol) — подавление нежелательных кодеков, ограничение полосы |

### Анализ трафика

SBC выполняет глубокий анализ (Deep Packet Inspection) SIP-пакетов:

- Проверка заголовков SIP на корректность.
- Валидация полей SDP в теле сообщения.
- Выявление искажённых или подозрительных пакетов до их передачи во внутреннюю сеть.

## Практические сценарии

### Корпоративная телефония

SBC устанавливается на границе сети предприятия и позволяет:
- Подключить IP-АТС к SIP-провайдеру с трансляцией протоколов.
- Организовать безопасный доступ удалённых сотрудников через TLS/SRTP.
- Ограничить список разрешённых кодеков (например, только G.711 и G.729).

### Оператор связи

На стороне провайдера SBC:
- Агрегирует трафик от множества клиентов.
- Реализует политики QoS и биллинга.
- Защищает опорную сеть от атак из внешних сетей.
