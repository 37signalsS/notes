# Классификация сетей

## Определения

* **Классификация сетей**: Разделение сетевых технологий на категории по различным признакам, таким как метод передачи данных, топология, географический охват и т.д. Понимание этих классификаций помогает в проектировании, управлении и устранении неполадок в сетевых инфраструктурах.

## Основные концепции

Сетевые технологии классифицируются по трём основным признакам.

### 1. По типу коммутации

Определяет способ передачи данных между отправителем и получателем.

#### Сети с коммутацией каналов (Circuit Switching)

Перед передачей данных устанавливается выделенный непрерывный канал, резервируемый на всё время соединения.

| Характеристика | Описание |
| :--- | :--- |
| Пропускная способность | Гарантирована, зарезервирована на всё время соединения |
| Задержки | Минимальны после установления канала |
| Использование ресурсов | Неэффективно — канал занят даже в периоды простоя |
| Отказоустойчивость | Низкая — сбой промежуточного узла разрывает соединение |

#### Сети с коммутацией пакетов (Packet Switching)

Данные разбиваются на независимые пакеты, каждый из которых маршрутизируется самостоятельно.

| Характеристика | Описание |
| :--- | :--- |
| Пропускная способность | Не гарантирована — возможны задержки и потери при перегрузках |
| Задержки | Зависят от загрузки маршрутизаторов |
| Использование ресурсов | Эффективно — канал совместно используется множеством пользователей |
| Отказоустойчивость | Высокая — пакеты перенаправляются по альтернативным маршрутам |

### 2. По технологии передачи данных

Определяет способ разделения среды передачи данных между устройствами.

#### Широковещательные сети (Broadcast Networks)

Данные одного устройства доступны всем устройствам в общей среде.

| Характеристика | Описание |
| :--- | :--- |
| Простота | Легко добавлять новые устройства |
| Безопасность | Низкая — трафик виден всем |
| Коллизии | Требуются механизмы управления доступом (CSMA/CD, CSMA/CA) |

**Примеры:** Классический [Ethernet с CSMA/CD](../Protocols/ethernet.md#метод-доступа-к-среде-в-классическом-ethernet-csmacd), Wi-Fi.

#### Сети точка-точка (Point-to-Point Networks)

Прямое соединение между двумя устройствами. Для связи с удалёнными узлами используется цепочка таких соединений и маршрутизация.

| Характеристика | Описание |
| :--- | :--- |
| Пропускная способность | Полная, без разделения с другими |
| Безопасность | Высокая — данные идут напрямую |
| Сложность | Требует маршрутизации в крупных сетях |
| Адресация | Оптимально маска `/31` ([RFC 3021](../Protocols/IP_addressing/special_masks.md#маска-31-point-to-point-линки)) — оба адреса подсети используются |

### 3. По географическому масштабу

| Тип | Расшифровка | Охват | Примеры |
| :--- | :--- | :--- | :--- |
| PAN | Personal Area Network | Несколько метров | Bluetooth (наушники, мышь) |
| LAN | Local Area Network | Здание, кампус | Сеть офиса, дома ([Ethernet](../Protocols/ethernet.md)) |
| MAN | Metropolitan Area Network | Город | Сети городских провайдеров |
| WAN | Wide Area Network | Страна, континент | Магистральные сети операторов |
| Интернет | Internetwork | Глобально | Объединение сетей worldwide |

## Практические сценарии

### Коммутация каналов vs пакетов в современных системах

- **Коммутация каналов:** Традиционная телефонная сеть (PSTN), выделенные линии (E1/T1, SDH). Канал гарантирован, но негибок.
- **Коммутация пакетов:** Все IP-сети, включая Интернет. Гибкая маршрутизация, эффективное использование ресурсов.

### Выбор типа сети при проектировании

- **Broadcast-сети** (Ethernet-коммутатор, Wi-Fi-точка доступа) — подходят для LAN, где устройства находятся в одном L2-домене.
- **Point-to-Point** (оптоволоконные линки, PPP/GRE/IPsec-туннели) — для WAN-соединений, линков между маршрутизаторами. Маска `/31` экономит адресное пространство.

### Диагностические ориентиры

- Задержки и потери пакетов → проблема коммутации пакетов (перегрузка маршрутизаторов).
- Разрывы соединения → проблема коммутации каналов (сбой промежуточного узла).
- Коллизии в Ethernet → перегрузка broadcast-домена, требуется сегментация (VLAN).
