# Классификация сетей

Сетевые технологии разнообразны, и их можно классифицировать по различным признакам. Данная заметка описывает три основных подхода к классификации сетей.

## 1. По типу коммутации

Этот тип классификации определяет, как данные передаются через сеть между отправителем и получателем.

### Сети с коммутацией каналов (Circuit Switching)
-   **Принцип:** Перед началом передачи данных между отправителем и получателем устанавливается выделенный, непрерывный канал связи. Все данные передаются только по этому каналу.
-   **Пример:** Традиционная телефонная сеть. Когда вы звоните кому-либо, между вашим телефоном и телефоном абонента устанавливается физический или логический канал.
-   **Особенности:**
    -   **Гарантированная пропускная способность:** После установления канала, пропускная способность резервируется и гарантируется.
    -   **Отсутствие задержек:** Нет задержек на маршрутизацию после установления соединения.
    -   **Неэффективное использование ресурсов:** Канал резервируется на все время соединения, даже если данные не передаются (периоды молчания).
    -   **Низкая отказоустойчивость:** При выходе из строя любого промежуточного узла в установленном канале, соединение разрывается.

### Сети с коммутацией пакетов (Packet Switching)
-   **Принцип:** Данные разбиваются на небольшие независимые блоки — **пакеты**. Каждый пакет содержит адрес назначения и может передаваться через сеть независимо от других пакетов, по разным маршрутам.
-   **Пример:** Все современные компьютерные сети, включая Интернет.
-   **Особенности:**
    -   **Отказоустойчивость:** При выходе из строя промежуточных узлов, пакеты могут быть перенаправлены по альтернативным маршрутам.
    -   **Эффективное использование ресурсов:** Ресурсы канала используются совместно множеством пользователей, так как пакеты передаются только по мере необходимости.
    -   **Нагрузка на маршрутизацию:** Каждый промежуточный узел (маршрутизатор) должен принимать решение о маршрутизации для каждого пакета, что требует вычислительных ресурсов и вносит задержки.
    -   **Отсутствие гарантированной пропускной способности:** В общем случае, пропускная способность не гарантируется, могут возникать задержки и потери пакетов из-за перегрузок.

## 2. По технологии передачи данных

Эта классификация определяет, как устройства делят общую среду передачи данных.

### Широковещательные сети (Broadcast Networks)
-   **Принцип:** Данные, отправленные одним устройством, доступны для приема всем другим устройствам, подключенным к той же среде.
-   **Пример:** Классический [Ethernet с методом CSMA/CD](./ethernet_csma_cd.md), [Wi-Fi](./data_link_layer_basics.md).
-   **Особенности:**
    -   **Простота реализации:** Легко подключать новые устройства.
    -   **Низкая безопасность:** Весь трафик виден всем.
    -   **Проблемы с коллизиями:** Требуется механизм управления доступом к среде для предотвращения конфликтов.

### Сети точка-точка (Point-to-Point Networks)
-   **Принцип:** Данные передаются непосредственно от одного устройства к другому. Если данные должны дойти до более удаленного узла, они передаются через цепочку таких соединений.
-   **Пример:** Коммутируемый Ethernet (современный Ethernet с использованием коммутаторов), оптоволоконные линии связи.
-   **Особенности:**
    -   **Высокая пропускная способность:** Нет необходимости делить канал.
    -   **Высокая безопасность:** Данные передаются напрямую получателю.
    -   **Сложность управления:** Для крупных сетей требуется маршрутизация.

## 3. По протяженности сети (Географический масштаб)

Эта классификация определяет физический охват сети.

-   **PAN (Personal Area Network — персональная сеть):**
    -   **Охват:** Несколько метров (например, 1 метр).
    -   **Пример:** [Bluetooth-соединение](./bluetooth.md) между смартфоном и наушниками, беспроводная мышь.
-   **LAN (Local Area Network — локальная сеть):**
    -   **Охват:** В пределах одного здания или нескольких близко расположенных зданий (от нескольких метров до нескольких километров).
    -   **Пример:** Сеть в офисе, доме, университетском кампусе.
    -   **Технологии:** [Ethernet](./data_link_layer_basics.md), [Wi-Fi](./data_link_layer_basics.md).
-   **MAN (Metropolitan Area Network — городская сеть):**
    -   **Охват:** В пределах города.
    -   **Пример:** Сети городских провайдеров, предоставляющие интернет, ТВ и телефонию по одному соединению.
-   **WAN (Wide Area Network — глобальная сеть):**
    -   **Охват:** В пределах страны или континента.
    -   **Пример:** Магистральные сети операторов связи (например, Ростелеком, ТрансТелеКом).
-   **Интернет (Internetwork):**
    -   **Охват:** Объединение множества сетей по всему миру.
    -   **Пример:** Глобальная сеть Интернет.

В рамках данного курса основное внимание уделяется:
-   Сетям с коммутацией пакетов (телефонные сети не рассматриваются).
-   Широковещательным сетям (классический Ethernet, Wi-Fi) и сетям точка-точка (коммутируемый Ethernet).
-   Локальным сетям (LAN) и технологиям их реализации.
-   Объединению сетей (Internetwork) с использованием стека протоколов TCP/IP.
