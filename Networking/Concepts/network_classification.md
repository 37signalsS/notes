# Классификация сетей

## Определения

* **Классификация сетей:** Систематизация сетевых технологий по ключевым архитектурным и эксплуатационным признакам. Позволяет инженерам выбирать оптимальные стеки технологий для конкретных задач — от подключения носимых устройств до построения глобальных облачных магистралей.

---

## Основные концепции

Сетевые технологии классифицируются по нескольким фундаментальным осям.

### 1. По типу коммутации

Определяет способ передачи данных между отправителем и получателем.

#### Коммутация каналов (Circuit Switching)
Перед передачей устанавливается выделенный физический или логический путь, который резервируется на всё время сессии.
- **Плюсы:** Гарантированная полоса пропускания, отсутствие джиттера (вариации задержки).
- **Минусы:** Неэффективное использование ресурсов (канал занят даже в тишине), долгое установление связи.
- **Примеры:** PSTN (телефония), ISDN, выделенные линии SDH/OTN.

#### Коммутация пакетов (Packet Switching)
Данные делятся на пакеты, которые передаются независимо через общую сеть.
- **Дейтаграммный способ:** Каждый пакет маршрутизируется отдельно (IP-сети). Максимальная отказоустойчивость и эффективность использования полосы.
- **Виртуальный канал:** Пакеты следуют по заранее проложенному логическому пути (MPLS, ATM). Сочетает гибкость пакетов с предсказуемостью каналов.

### 2. По технологии передачи данных

#### Широковещательные сети (Broadcast Networks)
Единый канал связи разделяется всеми узлами сегмента. Сообщение одного узла «слышат» все остальные.
- **Механизмы доступа:** CSMA/CD (Ethernet) или CSMA/CA (Wi-Fi) для предотвращения коллизий.
- **Особенности:** Требует сегментации через [VLAN](./vlan_l2_switching/definitions_and_concepts.md) для ограничения широковещательного шторма.

#### Сети точка-точка (Point-to-Point Networks)
Прямое соединение двух узлов. 
- **Эффективность:** Использование маски `/31` ([RFC 3021](../Protocols/IP_addressing/special_masks.md#маска-31-point-to-point-линки)) позволяет использовать оба доступных адреса для хостов, экономя пространство IPv4.
- **Примеры:** Магистральные линки маршрутизаторов, туннели (GRE, IPsec, WireGuard).

### 3. По географическому масштабу

| Тип | Название | Охват | Примеры / Технологии |
| :--- | :--- | :--- | :--- |
| **BAN** | Body Area Network | < 1 м | Носимые датчики, медицинские импланты (Bluetooth Low Energy) |
| **PAN** | Personal Area Network | ~10 м | Bluetooth, Zigbee, NFC (связь смартфона с часами/наушниками) |
| **LAN** | Local Area Network | До 1-2 км | Офис, дом ([Ethernet](../Protocols/ethernet.md), Wi-Fi 6E/7) |
| **CAN** | Campus Area Network | До 5-10 км | Университет, завод, военная база (объединение нескольких LAN) |
| **MAN** | Metropolitan Area Network | Город | Metro Ethernet, оптические кольца DWDM провайдеров |
| **WAN** | Wide Area Network | Регион / Страна | Магистрали ISP, Интернет, MPLS-сети корпораций |
| **GAN** | Global Area Network | Весь мир | Глобальные спутниковые системы (Starlink), Интернет в целом |

### 4. Специализированные и современные типы

#### SAN (Storage Area Network)
Высокоскоростная сеть для подключения систем хранения данных (СХД). Работает независимо от LAN для исключения конкуренции за полосу.
- **Протоколы:** Fibre Channel (FC), iSCSI, а также современный **NVMe over Fabrics (NVMe-oF)**, обеспечивающий минимальные задержки для Flash-массивов через RDMA (RoCE).

#### SD-WAN (Software-Defined WAN)
Оверлейная технология управления WAN-соединениями, отделяющая плоскость управления (Control Plane) от плоскости данных (Data Plane).
- **Принцип:** Динамический выбор пути (Path Steering) на основе качества линка (Latency, Packet Loss) между MPLS, LTE/5G и обычным ШПД.

#### Overlay и Underlay
Современный стандарт построения сетей ЦОД и облаков.
- **Underlay:** Физическая инфраструктура (кабели, коммутаторы, маршрутизаторы), обеспечивающая базовую IP-связность. Обычно строится на базе протоколов BGP или IS-IS (топология Clos/Leaf-Spine).
- **Overlay:** Логическая сеть, построенная поверх Underlay с помощью инкапсуляции. Позволяет создавать изолированные L2/L3 сегменты для тысяч арендаторов (tenants).
    - **Технологии:** VXLAN (стандарт для ЦОД), GENEVE, **HBONE** (используется в Istio Ambient Mesh для инкапсуляции трафика в HTTP/2 CONNECT).

## Практические сценарии

### Выбор архитектуры для современного ЦОД
В 2026 году классикой является использование **Underlay** на базе BGP-unnumbered и **Overlay** на базе VXLAN с контроллером (EVPN). Это позволяет масштабировать сеть до десятков тысяч узлов без проблем с STP.

### Изоляция трафика СХД
Для предотвращения деградации производительности БД из-за обычного пользовательского трафика, трафик iSCSI выносится в отдельную **SAN** (физически или логически через выделенные адаптеры и VLAN с поддержкой Jumbo Frames).

### Экономия IPv4 на магистралях
При настройке P2P-линков между маршрутизаторами (например, в Underlay) использование `/31` является обязательным стандартом. Это экономит 50% адресов по сравнению с устаревшим подходом `/30`.

### Диагностика: шторм в широковещательной сети
**Симптом:** Резкий рост нагрузки на CPU всех коммутаторов в сегменте LAN.
**Причина:** Отсутствие сегментации или петля в Broadcast-домене.
**Решение:** Разделение на мелкие [VLAN](./vlan_l2_switching/definitions_and_concepts.md), настройка Storm Control и использование современных альтернатив STP (например, MC-LAG или переход к L3 на доступе).
