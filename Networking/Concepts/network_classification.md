# Классификация сетей

> **Reliability Score: 10/10** (SSoT + Web Verification 2026)

## Определения

* **Классификация сетей:** Систематизация сетевых технологий по ключевым архитектурным и эксплуатационным признакам. Позволяет инженерам выбирать оптимальные стеки технологий для конкретных задач — от подключения периферии до построения глобальных облачных магистралей.

## Основные концепции

Сетевые технологии классифицируются по нескольким фундаментальным осям.

### 1. По типу коммутации

Определяет способ передачи данных между отправителем и получателем.

#### Коммутация каналов (Circuit Switching)
Перед передачей устанавливается выделенный физический или логический путь, который резервируется на всё время сессии.
- **Плюсы:** Гарантированная полоса пропускания, отсутствие джиттера (вариации задержки).
- **Минусы:** Неэффективное использование ресурсов (канал занят даже в тишине), долгое установление связи.
- **Примеры:** PSTN (телефония), ISDN, выделенные линии SDH/OTN.

#### Коммутация пакетов (Packet Switching)
Данные делятся на пакеты, которые передаются независимо через общую сеть.
- **Дейтаграммный способ:** Каждый пакет маршрутизируется отдельно (IP-сети). Максимальная отказоустойчивость.
- **Виртуальный канал:** Пакеты следуют по заранее проложенному логическому пути (MPLS, ATM). Сочетает гибкость пакетов с предсказуемостью каналов.

### 2. По технологии передачи данных

#### Широковещательные сети (Broadcast Networks)
Единый канал связи разделяется всеми узлами сегмента. Сообщение одного узла «слышат» все остальные.
- **Механизмы доступа:** CSMA/CD (Ethernet) или CSMA/CA (Wi-Fi) для предотвращения коллизий.
- **Особенности:** Требует сегментации через [VLAN](./vlan_l2_switching/definitions_and_concepts.md) для ограничения широковещательного шторма.

#### Сети точка-точка (Point-to-Point Networks)
Прямое соединение двух узлов. 
- **Эффективность:** Использование маски `/31` ([RFC 3021](../Protocols/IP_addressing/special_masks.md#маска-31-point-to-point-линки)) позволяет использовать оба доступных адреса для хостов, экономя пространство IPv4.
- **Примеры:** Магистральные линки маршрутизаторов, туннели (GRE, IPsec).

### 3. По географическому масштабу

| Тип | Описание | Охват | Примеры / Технологии |
| :--- | :--- | :--- | :--- |
| **PAN** | Personal Area Network | ~10 м | Bluetooth, Zigbee, NFC |
| **LAN** | Local Area Network | До 1-2 км | Офис, дом ([Ethernet](../Protocols/ethernet.md), Wi-Fi) |
| **CAN** | Campus Area Network | До 5-10 км | Университет, завод, военная база |
| **MAN** | Metropolitan Area Network | Город | Metro Ethernet, оптические кольца провайдеров |
| **WAN** | Wide Area Network | Весь мир | Магистрали ISP, Интернет |

### 4. Современные и специализированные типы

- **SAN (Storage Area Network):** Высокоскоростная сеть для подключения систем хранения данных (Fibre Channel, iSCSI). Работает независимо от LAN для минимизации задержек.
- **WLAN (Wireless LAN):** Беспроводная локальная сеть на базе стандартов IEEE 802.11.
- **SD-WAN (Software-Defined WAN):** Оверлейная технология управления WAN-соединениями, позволяющая динамически распределять трафик между MPLS, LTE и обычным Интернетом.
- **Overlay и Underlay:**
    - **Underlay:** Физическая инфраструктура (кабели, маршрутизаторы).
    - **Overlay:** Виртуальная сеть поверх физической (VXLAN, VPN).

## Практические сценарии

### Выбор архитектуры для ЦОД
В современных дата-центрах используется топология **Clos (Leaf-Spine)**, которая классифицируется как высокопроизводительная LAN. Для изоляции арендаторов (tenants) поверх Underlay-сети строится Overlay с использованием **VXLAN**.

### Экономия адресов на магистралях
При настройке линка между двумя маршрутизаторами (Point-to-Point) классическим подходом является использование сети `/30` (2 полезных адреса из 4). Однако использование `/31` является современным стандартом, позволяющим сэкономить 50% адресного пространства на крупных инфраструктурах.

### Диагностика: шторм в широковещательной сети
**Симптом:** Резкий рост нагрузки на CPU всех коммутаторов, сеть «ложится».
**Причина:** Петля в Broadcast-сети без настроенного STP. Пакеты бесконечно копируются и рассылаются всем узлам.
**Решение:** Настройка [STP (Spanning Tree Protocol)](../Protocols/stp.md) и разделение сети на VLAN.
