# MPLS (Multiprotocol Label Switching)

## Определения

**MPLS (Multiprotocol Label Switching)** — технология высокопроизводительной передачи данных, работающая на уровне L2.5 (между канальным и сетевым уровнями). Вместо маршрутизации по IP-адресу пакеты направляются по коротким меткам (labels), что повышает скорость и упрощает управление трафиком.

**LSR (Label Switching Router)** — маршрутизатор, выполняющий коммутацию по меткам. Различают ingress, transit и egress LSR.

**LSP (Label Switched Path)** — путь, по которому пакет проходит через MPLS-сеть.

**FEC (Forwarding Equivalence Class)** — группа пакетов, обрабатываемых одинаково (одна метка).

> **См. также:** [VXLAN](./vxlan.md) — альтернативная технология оверлейных сетей, [Туннели: обзор](./tunneling_overview.md)

## Основные концепции

### Принцип работы

1. На входном (ingress) LSR пакет получает метку на основе IP-префикса (FEC).
2. Промежуточные (transit) LSR коммутируют пакет по метке без анализа IP-заголовка.
3. Выходной (egress) LSR удаляет метку и передаёт обычный IP-пакет получателю.

### MPLS vs VXLAN

| Характеристика | MPLS | VXLAN |
| :--- | :--- | :--- |
| **Уровень** | L2.5 | L3 (overlay поверх UDP/IP) |
| **Производительность** | Высокая, низкая задержка | Небольшой оверхед на инкапсуляцию (~50 байт) |
| **Идентификатор сегмента** | Label (20 бит) | VNI (24 бита) |
| **Гибкость** | Ниже, требуется LDP/RSVP | Выше, работает на обычном IP |
| **Применение** | Провайдерские сети, магистрали | Дата-центры, виртуальные машины, контейнеры |

**Когда выбирать:** MPLS — для магистралей и операторских сетей; VXLAN — для облачных дата-центров и динамических инфраструктур.

## Практические сценарии

### Базовая настройка MPLS на Linux

```bash
# Загрузка модуля MPLS
modprobe mpls_router

# Включение входящей обработки MPLS на интерфейсе
echo 1 > /proc/sys/net/mpls/conf/eth0/input

# Создание MPLS-интерфейса
ip link add name mpls0 type mpls
ip addr add 192.168.100.1/24 dev mpls0
ip link set mpls0 up

# Добавление метки (на другом хосте — аналогично, с другим IP)
mpls label add 100 dev eth0
```

**Проверка MPLS-маршрутов:**

```bash
ip -f mpls route
ping 192.168.100.2
```
