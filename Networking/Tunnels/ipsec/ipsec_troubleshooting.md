# IPsec: диагностика KAME/racoon

> **Основной документ:** [ipsec.md](./ipsec.md).

Данный файл содержит историческую документацию по диагностике устаревшей реализации IPsec через стек KAME/racoon.

> **Устаревшая реализация:** Для диагностики современных систем (strongSwan) используйте **[раздел диагностики в основном документе](./ipsec.md#диагностика-и-устранение-неполадок)**.

---

## Определения

**Quick Mode (Фаза 2 IKE)** — процесс согласования параметров IPsec SA внутри защищённого ISAKMP-туннеля.

**SAD (Security Association Database)** — база данных в ядре, содержащая информацию об активных SA. Проверяется командой `setkey -D`.

**SPD (Security Policy Database)** — база данных политик безопасности, определяющая правила перехвата трафика для защиты. Проверяется командой `setkey -DP`.

---

## Основные концепции

### Инструменты диагностики KAME

| Утилита | Назначение |
|---------|------------|
| `racoonctl show-sa isakmp` | Проверка SA фазы 1 (ISAKMP) |
| `racoonctl show-sa esp` | Проверка SA фазы 2 (ESP/AH) |
| `setkey -D` | Просмотр SAD из ядра |
| `setkey -DP` | Просмотр SPD из ядра |
| `tcpdump` | Анализ трафика IKE (UDP 500/4500) и ESP (proto 50) |

## Практические сценарии

### Порядок диагностики

1. **Сетевая связность:** проверить `ping` между внешними IP шлюзов.
2. **Активация туннеля:** отправить тестовый пакет (`ping -I local_ip remote_ip`).
3. **Проверка Фазы 1:** `racoonctl show-sa isakmp`. Ожидается статус `established`.
4. **Проверка Фазы 2:** `racoonctl show-sa esp`. Ожидается статус `mature`.
5. **Анализ трафика:** `tcpdump -i ethX host <remote_ip>`.

### Анализ трафика (tcpdump)

**Пример успешного установления:**

```text

18:01:06.439 IP 10.0.255.1.500 > 10.0.1.1.500: isakmp: phase 1 R ident
18:01:07.412 IP 10.0.1.1.500 > 10.0.255.1.500: isakmp: phase 2 I oakley-quick
18:01:08.467 IP 10.0.1.1 > 10.0.255.1: ESP(spi=0x7aabfa82,seq=0x1), length 116
```

## Дополнительная информация

### Типовые проблемы и решения

| Проблема | Возможная причина | Решение |
|----------|-------------------|---------|
| Туннель не поднимается | Нет "интересного" трафика | Отправить пинг, соответствующий SPD |
| `No route to host` | Проблема с ARP для /32 маски | Добавить статическую ARP-запись |
| Ошибка Фазы 1 | Неверный PSK или ID | Проверить `/etc/racoon/psk.txt` |
| Ошибка Фазы 2 | Несоответствие политик (SPD) | Проверить `spdadd` в `/etc/ipsec-tools.conf` |
