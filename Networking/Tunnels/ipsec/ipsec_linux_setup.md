# IPsec: настройка KAME/racoon на Linux

> **Основной документ:** [ipsec.md](./ipsec.md).

Данный файл содержит историческую документацию по устаревшей реализации IPsec через стек KAME/racoon.

> **ВНИМАНИЕ — УСТАРЕВШАЯ ТЕХНОЛОГИЯ:** Стек KAME/racoon не поддерживается и не обновляется с начала 2010-х годов. Он содержит критические ограничения безопасности (отсутствие поддержки IKEv2, использование слабых алгоритмов). Для новых инсталляций **ОБЯЗАТЕЛЬНО** используйте **[strongSwan](./ipsec.md)** или **LibreSwan**.

---

## Определения

**KAME** — проект по реализации стека IPv6 и IPsec для BSD, части которого были портированы в ядро Linux. 

**Утилиты управления:**
- **racoon:** Демон (IKE-демон) для согласования ключей и управления ассоциациями безопасности (SA) по протоколу IKEv1.
- **setkey:** Утилита для ручного управления базами данных SA (SAD) и политик безопасности (SPD) в ядре.

---

## Основные концепции

### Компоненты стека

| Компонент | Назначение |
|-----------|------------|
| **racoon** | Управление ISAKMP-туннелем (только IKEv1) |
| **setkey** | Прямое управление политиками (SPD) и состояниями (SAD) |
| **ipsec-tools** | Пакет, объединяющий эти инструменты (часто отсутствует в современных репозиториях) |

### Ключевые файлы конфигурации

| Файл | Назначение |
|------|------------|
| `/etc/racoon.conf` | Настройки обмена ключами (Фаза 1 и Фаза 2) |
| `/etc/racoon/psk.txt` | Файл с общими ключами (Pre-Shared Keys) |
| `/etc/ipsec-tools.conf` | Конфигурация политик безопасности для `setkey` |

## Практические сценарии

### Полная конфигурация KAME/racoon (Site-to-Site)

**Сценарий:** Защищённый туннель между двумя узлами.
- **Внешние IP:** `10.0.1.1` (Local) и `10.0.255.1` (Remote)
- **Защищаемые ресурсы:** `192.168.1.1` и `192.168.255.1`

#### 1. Установка

```bash
# Пакет может быть недоступен в современных дистрибутивах (Debian 11+, Ubuntu 20.04+)
apt-get install racoon ipsec-tools
```

#### 2. Настройка политик (`/etc/ipsec-tools.conf`)

Этот файл определяет, какой именно трафик должен перехватываться ядром для защиты.

```bash
flush;
spdflush;

# Исходящий трафик: от локального сервиса к удаленному
spdadd 192.168.1.1/32 192.168.255.1/32 any -P out ipsec
    esp/tunnel/10.0.1.1-10.0.255.1/require;

# Входящий трафик: от удаленного сервиса к локальному
spdadd 192.168.255.1/32 192.168.1.1/32 any -P in ipsec
    esp/tunnel/10.0.255.1-10.0.1.1/require;
```

#### 3. Настройка демона ключей (`/etc/racoon.conf`)

```bash
path pre_shared_key "/etc/racoon/psk.txt";
log notify; # Уровень логирования

listen {
    isakmp 10.0.1.1 [500];
    strict_address;
}

# Фаза 1: Согласование IKE_SA
remote 10.0.255.1 {
    exchange_mode main;
    proposal {
        encryption_algorithm 3des; # ВНИМАНИЕ: Небезопасно!
        hash_algorithm sha1;      # ВНИМАНИЕ: Небезопасно!
        authentication_method pre_shared_key;
        dh_group 2;               # modp1024 (устарело)
    }
}

# Фаза 2: Согласование IPsec_SA
sainfo address 192.168.1.1 any address 192.168.255.1 any {
    pfs_group 2;
    encryption_algorithm 3des;
    authentication_algorithm hmac_sha1;
    compression_algorithm deflate;
}
```

#### 4. Настройка секретов (`/etc/racoon/psk.txt`)

```text
10.0.255.1    SECRET_KEY_HERE
```
*Важно: Права на файл должны быть `600` (`chmod 600 /etc/racoon/psk.txt`).*

## Управление и диагностика

```bash
# 1. Применение политик (SPD)
setkey -f /etc/ipsec-tools.conf

# 2. Проверка текущих политик
setkey -DP

# 3. Проверка активных ассоциаций (SAD)
setkey -D

# 4. Запуск демона
service racoon start
```

### Типовые проблемы

- **Несоответствие алгоритмов:** Racoon очень чувствителен к порядку и набору алгоритмов в Фазе 1 и 2.
- **NAT:** Racoon плохо справляется с NAT-T без специфических патчей и настроек.
- **MTU:** KAME не умеет автоматически корректировать MSS, что часто приводит к зависанию TCP-сессий.

## Дополнительная информация

### Критические недостатки

1. **Отсутствие IKEv2:** Не поддерживает современный стандарт обмена ключами.
2. **Слабая криптография:** Основные реализации жестко завязаны на 3DES и SHA-1, которые дискредитированы.
3. **Отсутствие поддержки интерфейсов:** Не поддерживает современные XFRM-интерфейсы и VTI.
