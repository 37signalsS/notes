# Пинг без ICMP: как проверить доступность, если всё закрыто

Когда вы работаете с инфраструктурой, где ICMP-запросы блокируются (например, корпоративные фаерволы, жесткие политики безопасности или хостинг-провайдеры), привычный `ping` перестаёт быть полезным. Однако проверка доступности хоста или сервиса по-прежнему необходима.

## Альтернативы ICMP-пингу:

### 1. TCP ping через `nmap`, `nc` (netcat) или `telnet`

Эти инструменты позволяют проверить доступность определенного TCP-порта на удаленном хосте. Если порт открыт и сервис отвечает, это подтверждает доступность хоста.

**Использование `nc` (netcat):**
```bash
# Проверка доступности порта 22 (SSH) на 192.168.0.1
nc -zv 192.168.0.1 22
```

**Использование `nmap`:**
```bash
# Проверка доступности порта 80 на 192.168.0.1
nmap -p 80 192.168.0.1
```

**Использование `telnet`:**
```bash
# Проверка доступности порта 80 на example.com (после выполнения команды нужно ввести Ctrl+])
telnet example.com 80
```

### 2. `curl` или `wget` для HTTP(S) сервисов

Если на удаленном хосте запущен веб-сервер (HTTP/HTTPS), можно проверить его доступность, запросив страницу.

**Использование `curl`:**
```bash
# Проверка статуса HTTP-ответа и заголовков, показывая только первую строку ответа
curl -Is http://example.com | head -n 1
```

**Использование `wget`:**
```bash
# Проверка доступности URL без сохранения файла
wget --spider http://example.com
```

### 3. `hping3` — мощный инструмент для кастомных проверок

`hping3` позволяет отправлять произвольные TCP/UDP/ICMP пакеты, управлять флагами, портами и заголовками. Это дает большой контроль для детальной проверки доступности.

```bash
# Отправка TCP SYN пакета на порт 80 example.com
hping3 -S -p 80 example.com
```

### 4. `fping` — массовый пинг (с возможностью без ICMP)

`fping` предназначен для быстрого пингования множества хостов. Хотя по умолчанию он использует ICMP, существуют режимы и флаги, позволяющие использовать другие протоколы.

```bash
# Пингование хостов с использованием TCP (требуется fping с поддержкой TCP)
# fping -p 80 -t 500 -a <хост1> <хост2> ...
# (Функционал TCP-пинга может зависеть от версии и сборки fping)
```

### 5. PowerShell `Test-NetConnection` (для Windows-серверов)

В средах Windows PowerShell предоставляет встроенную команду `Test-NetConnection`, которая может проверять доступность TCP-портов.

```powershell
# Проверка доступности порта 443 на example.com
Test-NetConnection -ComputerName example.com -Port 443
```
