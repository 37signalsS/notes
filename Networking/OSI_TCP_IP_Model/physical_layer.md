# Физический уровень (L1)

## Определения

**Физический уровень** — первый, нижний уровень [модели OSI](./osi_model.md). Отвечает за передачу неструктурированного потока бит по физической среде. Определяет физические, электрические и механические характеристики среды, но не анализирует смысл информации.

На этом уровне данные отсутствуют — здесь только физика:

* Электрические сигналы в медном кабеле.
* Световые импульсы в оптоволокне.
* Радиоволны в Wi-Fi.

* **PDU (Protocol Data Unit):** Бит
* **Адресация:** Отсутствует (передача в физическую среду)

## Базовые концепции

### Основные функции

| Функция | Описание |
| :--- | :--- |
| **Представление битов** | Преобразование 0/1 в электрические, световые, радиосигналы |
| **Передача сигналов** | Физическое перемещение сигналов от отправителя к получателю |
| **Восстановление битов** | Обратное преобразование сигналов в биты на приёме |
| **Синхронизация** | Обеспечение временной синхронизации передатчика и приёмника |
| **Защита от помех** | Использование экранирования, скручивания пар, фильтрации |

### Параметры сигналов

| Параметр | Описание | Применение |
| :--- | :--- | :--- |
| **Амплитуда** | Уровень напряжения сигнала | Кодирование данных в аналоговых системах |
| **Частота** | Количество колебаний в секунду | Определение несущей частоты, модуляция |
| **Фаза** | Смещение сигнала во времени | Фазовая модуляция (QPSK, QAM) |
| **Модуляция** | Изменение параметров несущей для кодирования данных | AM, FM, PM, QAM, OFDM |

### Характеристики канала связи

| Характеристика | Описание | Единицы |
| :--- | :--- | :--- |
| **Пропускная способность (Bandwidth)** | Объём данных за единицу времени | бит/с, Мбит/с, Гбит/с |
| **Задержка (Latency)** | Время доставки сообщения | мс, мкс |
| **Частота ошибок (Error Rate)** | Процент искажённых битов | BER (Bit Error Rate) |

> **Важно:** Сетевая скорость измеряется в **битах** (bps), скорость загрузки файлов — в **байтах** (B/s). 1 байт = 8 бит. Пример: 100 Мбит/с ≈ 12.5 МБ/с.

### Типы каналов по направлению передачи

| Тип | Описание | Пример |
| :--- | :--- | :--- |
| **Симплексный (Simplex)** | Только в одном направлении | ТВ-вещание, радио |
| **Полудуплексный (Half-Duplex)** | В обе стороны, поочерёдно | Рация, Wi-Fi |
| **Дуплексный (Full-Duplex)** | Одновременно в обе стороны | Телефон, Ethernet |

### Кодирование информации

| Тип | Описание | Применение |
| :--- | :--- | :--- |
| **Цифровое кодирование** | Дискретные уровни напряжения для 0/1 | Проводные сети (Ethernet) |
| **Аналоговое кодирование (Модуляция)** | Изменение амплитуды/частоты/фазы несущей | Wi-Fi, сотовая связь, модемы |

## Практические сценарии

### Среды передачи данных

#### Проводные среды

| Среда | Описание | Применение |
| :--- | :--- | :--- |
| **Витая пара (Twisted Pair)** | Скрученные медные пары для уменьшения помех | Локальные сети (Ethernet) |
| **Оптический кабель (Fiber Optic)** | Световые импульсы по стекловолокну | Магистральные каналы, ЦОД |
| **Коаксиальный кабель** | Центральный проводник в экране | Телевидение, исторически Ethernet |

| Категория | Макс. скорость | Макс. длина | Применение |

### Оборудование физического уровня

| Устройство | Функция | Применение |
| :--- | :--- | :--- |
| **Концентратор (Hub)** | Повторение сигнала на все порты | Устарело, вытеснено коммутаторами |
| **Повторитель (Repeater)** | Усиление и восстановление сигнала | Увеличение длины сегмента |
| **Трансиверы** | Преобразование сред (электрика ↔ оптика) | SFP, SFP+, QSFP модули |
| **Кабели** | Физическая среда передачи | Витая пара, оптоволокно, коаксиал |

> **Концентратор (Hub)** — устройство L1, создающее **общую шину**. Все устройства видят весь трафик, что приводит к коллизиям и низкой безопасности. Полностью вытеснен коммутаторами.

#### Принцип работы хаба

Хаб (концентратор) работает на физическом уровне модели OSI и представляет собой небольшую коробку с портами для подключения сетевых устройств.

**Алгоритм работы:**

1. Получив сигнал на любой из портов, хаб повторяет (ретранслирует) его во **все остальные** активные порты.
2. Хаб не анализирует MAC-адреса и не принимает решений о маршрутизации — это простое устройство повторения сигнала.

**Пример работы в сети из 3 хостов:**

```
[Host 1] ----\
              \
[Host 2] ---- [Hub]
              /
[Host 3] ----/
```

Если **Host 1** отправляет пакет для **Host 2**:

* Хаб получает пакет от Host 1
* Ретранслирует пакет на **все** порты (Host 2 и Host 3)
* **Host 2** принимает пакет (совпадение MAC-адреса)
* **Host 3** отбрасывает пакет (MAC-адрес не совпадает)

**Следствия:**

* Все хосты в сети на базе хаба находятся в **одном домене коллизий**
* При одновременной передаче двумя хостами возникает **коллизия**
* Низкая безопасность: любой хост может перейти в promiscuous mode и перехватывать весь трафик

### Стандарты Ethernet (физический уровень)

| Стандарт | Среда | Скорость | Макс. длина |
| :--- | :--- | :--- | :--- |
| **10BASE-T** | Витая пара Cat3/Cat5 | 10 Мбит/с | 100 м |
| **100BASE-TX** | Витая пара Cat5 | 100 Мбит/с | 100 м |
| **1000BASE-T** | Витая пара Cat5e/Cat6 | 1 Гбит/с | 100 м |
| **10GBASE-T** | Витая пара Cat6a/Cat7 | 10 Гбит/с | 100 м |
| **1000BASE-SX** | Многомодовое волокно | 1 Гбит/с | 550 м |
| **1000BASE-LX** | Одномодовое волокно | 1 Гбит/с | 5 км |
| **10GBASE-SR** | Многомодовое волокно | 10 Гбит/с | 400 м |
| **10GBASE-LR** | Одномодовое волокно | 10 Гбит/с | 10 км |

**Обозначения:**

* **10/100/1000/10000** — скорость в Мбит/с
* **BASE** — базовая полоса (baseband)
* **T** — витая пара (Twisted pair)
* **S/L** — короткая/длинная волна (Short/Long) для оптики

### Стандарты Wi-Fi

| Стандарт | Поколение | Диапазон | Макс. скорость (PHY) | Год |
| :--- | :--- | :--- | :--- | :--- |
| **802.11ac** | Wi-Fi 5 | 5 ГГц | 6.9 Гбит/с | 2014 |
| **802.11ax** | Wi-Fi 6/6E | 2.4/5/6 ГГц | 9.6 Гбит/с | 2019 |
| **802.11be** | Wi-Fi 7 | 2.4/5/6 ГГц | 46 Гбит/с | 2024 |

> **Примечание:** IEEE 802.11be утверждён в сентябре 2024, сертификация Wi-Fi Alliance — с января 2024.
