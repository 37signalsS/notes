# Физический уровень (L1)

## Определения

**Физический уровень (Physical Layer, L1)** — первый, нижний уровень модели **OSI (Open Systems Interconnection)**. Отвечает за передачу неструктурированного потока бит по физической среде. Определяет физические, электрические и механические характеристики среды, но не анализирует смысл передаваемой информации.

На этом уровне данные как логическая структура отсутствуют — здесь оперируют физическими явлениями:
* Электрические сигналы в медном кабеле.
* Световые импульсы в оптоволокне.
* Радиоволны в беспроводных сетях.

* **PDU (Protocol Data Unit):** Бит.
* **Адресация:** Отсутствует (передача осуществляется непосредственно в физическую среду).

## Базовые концепции

### Основные функции

| Функция | Описание |
| :--- | :--- |
| **Представление битов** | Преобразование логических 0 и 1 в физические сигналы (электрические, световые, радио) |
| **Передача сигналов** | Физическое перемещение сигналов от отправителя к получателю по среде |
| **Восстановление битов** | Обратное преобразование принятых физических сигналов в биты |
| **Синхронизация** | Обеспечение временной согласованности передатчика и приёмника |
| **Защита от помех** | Использование экранирования, скручивания пар проводников, фильтрации сигналов |

### Параметры сигналов

| Параметр | Описание | Применение |
| :--- | :--- | :--- |
| **Амплитуда** | Максимальное значение отклонения сигнала от среднего уровня | Кодирование данных в аналоговых системах |
| **Частота** | Количество полных циклов колебания сигнала в секунду | Определение несущей частоты, модуляция |
| **Фаза** | Смещение сигнала во времени относительно начала координат | Фазовая модуляция |
| **Модуляция** | Процесс изменения параметров несущего сигнала для кодирования данных | AM, FM, PM, QAM, OFDM |

**Методы модуляции:**
* **AM (Amplitude Modulation):** Амплитудная модуляция.
* **FM (Frequency Modulation):** Частотная модуляция.
* **PM (Phase Modulation):** Фазовая модуляция.
* **QAM (Quadrature Amplitude Modulation):** Квадратурная амплитудная модуляция.
* **OFDM (Orthogonal Frequency-Division Multiplexing):** Ортогональное частотное разделение каналов с мультиплексированием.

### Характеристики канала связи

| Характеристика | Описание | Единицы измерения |
| :--- | :--- | :--- |
| **Пропускная способность (Bandwidth)** | Максимальный объём данных, передаваемый за единицу времени | бит/с (bps), Мбит/с, Гбит/с |
| **Задержка (Latency)** | Время, затрачиваемое на доставку сообщения от источника к получателю | мс, мкс |
| **Частота ошибок (Error Rate)** | Отношение количества искажённых битов к общему количеству переданных | BER (Bit Error Rate) |

**Важное различие:** Сетевая скорость измеряется в **битах** в секунду (bps), а скорость загрузки файлов в прикладном ПО — часто в **байтах** в секунду (B/s). 1 байт = 8 бит.

### Типы каналов по направлению передачи

| Тип | Описание | Пример |
| :--- | :--- | :--- |
| **Симплексный (Simplex)** | Передача возможна только в одном направлении | Телевизионное вещание, радио |
| **Полудуплексный (Half-Duplex)** | Передача в обе стороны, но поочерёдно в каждый момент времени | Рация, Wi-Fi |
| **Дуплексный (Full-Duplex)** | Одновременная передача и приём данных в обоих направлениях | Телефонная связь, современный Ethernet |

### Кодирование информации

* **Цифровое кодирование:** Использование дискретных уровней напряжения или тока для представления 0 и 1. Применяется в проводных сетях (Ethernet).
* **Аналоговое кодирование (Модуляция):** Изменение параметров несущего аналогового сигнала (амплитуды, частоты или фазы). Применяется в Wi-Fi, сотовой связи, модемах.

## Практические сценарии

### Среды передачи данных

#### Проводные среды

| Среда | Описание | Применение |
| :--- | :--- | :--- |
| **Витая пара (Twisted Pair)** | Медные провода, скрученные попарно для минимизации электромагнитных помех | Локальные сети (Ethernet) |
| **Оптический кабель (Fiber Optic)** | Передача световых импульсов по чистому стеклу или пластику | Магистральные каналы, ЦОД (Центр Обработки Данных) |
| **Коаксиальный кабель** | Центральный проводник, окружённый изоляцией и экраном | Кабельное телевидение, старые стандарты Ethernet |

#### Категории витой пары (Cat — Category)

| Категория | Макс. скорость | Макс. длина | Применение |
| :--- | :--- | :--- | :--- |
| **Cat5e** | 1 Гбит/с | 100 м | Стандарт для большинства офисных и домашних ЛВС |
| **Cat6** | 10 Гбит/с | 55 м | Улучшенная защита от перекрёстных помех |
| **Cat6a** | 10 Гбит/с | 100 м | Современный стандарт для 10G сетей |
| **Cat7/Cat8** | До 40 Гбит/с | 30–50 м | Высокопроизводительные серверные стойки в ЦОД |

#### Беспроводные среды

| Среда | Диапазон частот | Применение |
| :--- | :--- | :--- |
| **Радиоволны (Wi-Fi)** | 2.4 / 5 / 6 ГГц | Беспроводные локальные сети (WLAN) |
| **Сотовая связь** | 700 МГц – 6 ГГц | Мобильный интернет (4G LTE, 5G) |
| **Bluetooth** | 2.4 ГГц | Персональные сети (PAN) |

### Оборудование физического уровня

| Устройство | Функция | Применение |
| :--- | :--- | :--- |
| **Концентратор (Hub)** | Простая ретрансляция входного сигнала на все остальные порты | Устаревшее оборудование, вытеснено коммутаторами |
| **Повторитель (Repeater)** | Усиление и восстановление формы сигнала для борьбы с затуханием | Увеличение допустимой длины кабельного сегмента |
| **Трансиверы** | Преобразование сигналов между различными средами (например, медь ↔ оптика) | Модули SFP (Small Form-factor Pluggable), QSFP |
| **Сетевые кабели** | Непосредственная физическая среда для прохождения сигналов | Витая пара, оптоволоконные патч-корды |

#### Особенности работы концентратора (Hub)

Концентратор является устройством L1 и создаёт **общую шину** (shared medium). Все подключённые к нему устройства находятся в одном **домене коллизий**.
1. При получении сигнала на один порт, хаб копирует его на **все** остальные порты.
2. Он не анализирует MAC-адреса (Media Access Control) и не принимает решений о фильтрации трафика.
3. Низкая безопасность: любое устройство в сети может перехватывать чужой трафик.
4. Низкая эффективность: одновременная передача двумя узлами приводит к коллизии (наложению сигналов).

### Стандарты Ethernet (физический уровень)

| Стандарт | Среда передачи | Скорость | Макс. длина сегмента |
| :--- | :--- | :--- | :--- |
| **10BASE-T** | Витая пара Cat3/Cat5 | 10 Мбит/с | 100 м |
| **100BASE-TX** | Витая пара Cat5 | 100 Мбит/с | 100 м |
| **1000BASE-T** | Витая пара Cat5e/Cat6 | 1 Гбит/с | 100 м |
| **10GBASE-T** | Витая пара Cat6a/Cat7 | 10 Гбит/с | 100 м |
| **1000BASE-SX** | Многомодовое оптоволокно (Short wavelength) | 1 Гбит/с | До 550 м |
| **1000BASE-LX** | Одномодовое оптоволокно (Long wavelength) | 1 Гбит/с | До 5 км |

### Стандарты Wi-Fi

Разрабатываются институтом **IEEE (Institute of Electrical and Electronics Engineers)** в рамках группы 802.11.

| Стандарт | Маркетинговое имя | Диапазон | Максимальная скорость (PHY) |
| :--- | :--- | :--- | :--- |
| **802.11ac** | Wi-Fi 5 | 5 ГГц | До 6.9 Гбит/с |
| **802.11ax** | Wi-Fi 6 / 6E | 2.4 / 5 / 6 ГГц | До 9.6 Гбит/с |
| **802.11be** | Wi-Fi 7 | 2.4 / 5 / 6 ГГц | До 46 Гбит/с |
