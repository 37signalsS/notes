# Физический уровень (L1)

## Определения

**Физический уровень (Physical Layer, L1)** — первый и самый нижний уровень эталонной модели **OSI (Open Systems Interconnection)**. Он отвечает за передачу неструктурированного потока бит по физической среде передачи данных. На этом уровне определяются электрические, механические, процедурные и функциональные характеристики, необходимые для активации, поддержания и деактивации физических соединений.

На уровне L1 данные как логическая структура (кадры, пакеты) отсутствуют. Здесь оперируют физическими сигналами:
- **Электрические импульсы:** Медный кабель (витая пара, коаксиал).
- **Световые импульсы:** Оптоволокно (многомод, одномод).
- **Радиоволны:** Беспроводные сети (Wi-Fi, 5G, спутниковая связь).

- **PDU (Protocol Data Unit):** Бит (Bit).
- **Адресация:** Отсутствует. Передача осуществляется непосредственно в среду («на провод»).

## Базовые концепции

### Основные функции

| Функция | Описание |
| :--- | :--- |
| **Кодирование и модуляция** | Преобразование логических 0 и 1 в физические сигналы (NRZ, Manchester, PAM4, QAM). |
| **Линейное кодирование** | Обеспечение самосинхронизации приёмника и отсутствия постоянной составляющей тока (например, 8b/10b, 64b/66b). |
| **Синхронизация бит** | Согласование тактовой частоты передатчика и приёмника для корректного распознавания каждого бита. |
| **Передача сигналов** | Физическое перемещение энергии по среде (электроны, фотоны, электромагнитные волны). |
| **Определение топологии** | Описание физического расположения узлов и их соединений (шина, звезда, кольцо, ячеистая сеть). |
| **Механические характеристики** | Спецификации разъемов (RJ-45, LC, MPO/MTP) и типов используемых кабелей. |

### Параметры и характеристики канала

| Параметр | Описание |
| :--- | :--- |
| **Пропускная способность (Bandwidth)** | Максимальный теоретический объем бит, который среда может передать за секунду (bps). |
| **Затухание (Attenuation)** | Снижение мощности сигнала при прохождении через среду, ограничивающее предельную длину сегмента. |
| **Отношение сигнал/шум (SNR)** | Определяет максимально возможную скорость передачи при заданном уровне шума (теорема Шеннона). |
| **Дисперсия** | Искажение светового импульса в оптоволокне из-за разной скорости распространения мод (межмодовая) или длин волн (хроматическая). |
| **FEC (Forward Error Correction)** | Упреждающая коррекция ошибок. Математический метод восстановления поврежденных бит на приёмной стороне, критически важный для скоростей 25G+. |

### Режимы передачи данных

- **Симплекс (Simplex):** Только в одну сторону (например, традиционное радиовещание).
- **Полудуплекс (Half-Duplex):** В обе стороны, но поочередно (классический Wi-Fi, Ethernet с использованием концентраторов/хабов).
- **Полный дуплекс (Full-Duplex):** Одновременно в обе стороны (современный коммутируемый Ethernet).

## Среды передачи и стандарты

### Медные кабели (Витая пара)

Основной стандарт для построения LAN — **TIA/EIA-568**.

| Категория | Макс. скорость | Частота | Применение |
| :--- | :--- | :--- | :--- |
| **Cat 5e** | 1 Гбит/с | 100 МГц | Самый распространенный стандарт для офисных сетей. |
| **Cat 6** | 10 Гбит/с (до 55м) | 250 МГц | Улучшенная изоляция пар, использование в современных офисах. |
| **Cat 6a** | 10 Гбит/с (100м) | 500 МГц | Стандарт для серверных и ЦОД (10GBASE-T). |
| **Cat 8.1/8.2** | 25/40 Гбит/с (30м) | 2000 МГц | Сверхскоростные соединения внутри серверных стоек. |

### Оптоволоконные кабели

| Тип | Класс | Скорость/Расстояние | Особенности |
| :--- | :--- | :--- | :--- |
| **Многомод (MMF)** | **OM4 / OM5** | До 100 Гбит/с (до 150м) | Использует VCSEL лазеры (850 нм). Оптимально для коротких линков в ЦОД. |
| **Одномод (SMF)** | **OS2** | До 400+ Гбит/с (до 40+ км) | Тонкая сердцевина (9 мкм), лазеры высокой мощности. Для магистралей и WAN. |

**Важное замечание по разъемам:**
- **UPC (Ultra Physical Contact):** Синие разъемы, плоская полировка. Высокое обратное отражение.
- **APC (Angled Physical Contact):** Зеленые разъемы, полировка под углом 8°. Минимальное обратное отражение. Несовместимы с UPC напрямую!

### Беспроводные технологии

| Технология | Стандарт | Диапазон | Особенности L1 |
| :--- | :--- | :--- | :--- |
| **Wi-Fi 6/6E** | 802.11ax | 2.4 / 5 / 6 ГГц | Модуляция **1024-QAM**, использование **OFDMA**. |
| **Wi-Fi 7** | 802.11be | 2.4 / 5 / 6 ГГц | Модуляция **4096-QAM**, полоса канала до **320 МГц**. |
| **5G NR** | 3GPP Rel. 15+ | < 6 ГГц / mmWave | **Massive MIMO**, Beamforming, гибкая нумерология поднесущих. |

## Оборудование физического уровня

- **Трансиверы (SFP+, SFP28, QSFP-DD):** Сменные модули для преобразования электрического сигнала в оптический и наоборот.
- **Сетевая карта (NIC):** Содержит контроллер и микросхему **PHY**, реализующую физическое кодирование.
- **Повторитель (Repeater):** Усиливает или регенерирует сигнал для увеличения дистанции (редко в чистом виде).
- **Медиаконвертер:** Преобразует один тип физической среды в другой (например, медь RJ-45 ↔ оптика LC).
- **Концентратор (Hub):** Устаревшее устройство, ретранслирующее сигнал на все порты (общий домен коллизий).

## Современные технологии физического уровня

### InfiniBand
Стандарт для высокопроизводительных вычислений (HPC) и кластеров машинного обучения.
- **HDR (200G)** и **NDR (400G)**: Используют агрегацию нескольких физических линий.
- Обеспечивает экстремально низкие задержки (latency) за счет оптимизированного стека, где L1 тесно интегрирован с механизмами RDMA.

### PAM4 (Pulse Amplitude Modulation 4-level)
Метод кодирования, заменивший NRZ в сетях со скоростями 50G, 100G, 400G и выше.
- Передает **4 уровня амплитуды** сигнала, что позволяет упаковать **2 бита в один символ (бод)**.
- Это удваивает скорость передачи при той же тактовой частоте, но снижает устойчивость к шуму, что делает использование **FEC** обязательным.

## Практическая диагностика (SRE/DevOps)

Для инженера диагностика L1 — это проверка «физики» линка до начала анализа пакетов.

### Мониторинг параметров SFP (DOM/DDM)
Функция **Digital Optical Monitoring** позволяет видеть физическое состояние канала:
- **TX/RX Power:** Уровень мощности сигнала в dBm. Слишком низкий RX указывает на грязный разъем или повреждение волокна.
- **Bias Current:** Ток смещения лазера. Резкий рост может означать скорую деградацию трансивера.

### Команды в Linux
```bash
# Проверка физического состояния интерфейса (Link detected)
ethtool eth0

# Просмотр статистики PHY (CRC errors, FEC corrected/uncorrected blocks)
ethtool -S eth0

# Считывание диагностических данных с SFP-модуля (DOM)
ethtool -m eth0
```
