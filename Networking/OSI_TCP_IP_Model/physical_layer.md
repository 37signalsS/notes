# Физический уровень (L1)

## Определения

**Физический уровень (Physical Layer, L1)** — первый, самый нижний уровень эталонной модели **OSI (Open Systems Interconnection)**. Он отвечает за передачу неструктурированного потока бит по физической среде передачи данных. На этом уровне определяются электрические, механические, процедурные и функциональные характеристики активации, поддержания и деактивации физического канала.

На уровне L1 данные как логическая структура отсутствуют. Здесь оперируют физическими сигналами:
- Электрические импульсы (медный кабель).
- Световые импульсы (оптоволокно).
- Радиоволны (беспроводные сети).

- **PDU (Protocol Data Unit):** Бит (Bit).
- **Адресация:** Отсутствует. Передача осуществляется непосредственно в среду («на провод»).

## Базовые концепции

### Основные функции

| Функция | Описание |
| :--- | :--- |
| **Кодирование и модуляция** | Преобразование логических 0 и 1 в физические сигналы (NRZ, Manchester, PAM4, QAM) |
| **Синхронизация бит** | Обеспечение временной согласованности передатчика и приёмника для корректного считывания бит |
| **Передача сигналов** | Физическое перемещение энергии по среде (ток, свет, волна) |
| **Определение топологии** | Описание физического расположения узлов и соединений (шина, звезда, кольцо) |
| **Механические характеристики** | Спецификации разъемов (RJ-45, LC/UPC, MPO) и типов кабелей |

### Параметры и характеристики канала

| Параметр | Описание |
| :--- | :--- |
| **Пропускная способность (Bandwidth)** | Максимальный объем бит, который среда может передать за секунду (bps) |
| **Затухание (Attenuation)** | Потеря мощности сигнала при прохождении через среду, ограничивающая длину кабеля |
| **Отношение сигнал/шум (SNR)** | Ключевой параметр, определяющий максимально возможную скорость передачи (теорема Шеннона) |
| **Дисперсия** | Искажение светового импульса в оптоволокне из-за разной скорости распространения мод или длин волн |

### Режимы передачи данных

- **Симплекс (Simplex):** Только в одну сторону (например, радиовещание).
- **Полудуплекс (Half-Duplex):** В обе стороны, но поочередно (например, классический Wi-Fi, Ethernet с хабами).
- **Полный дуплекс (Full-Duplex):** Одновременно в обе стороны (например, современный Ethernet на коммутаторах).

## Среды передачи и стандарты

### Медные кабели (Витая пара)

Используются в локальных сетях (LAN). Основной стандарт — **TIA/EIA-568**.

| Категория | Макс. скорость | Частота | Применение |
| :--- | :--- | :--- | :--- |
| **Cat 5e** | 1 Гбит/с | 100 МГц | Самый массовый стандарт для офисов |
| **Cat 6** | 10 Гбит/с (до 55м) | 250 МГц | Улучшенная изоляция пар |
| **Cat 6a** | 10 Гбит/с (100м) | 500 МГц | Стандарт для современных ЦОД (10GBASE-T) |
| **Cat 8.1/8.2** | 25/40 Гбит/с (30м) | 2000 МГц | Высокоскоростные соединения внутри серверных стоек |

### Оптоволоконные кабели

Используются для магистральных каналов и в высокопроизводительных сетях.

| Тип | Класс | Скорость/Расстояние | Особенности |
| :--- | :--- | :--- | :--- |
| **Многомод (MMF)** | **OM4 / OM5** | До 100 Гбит/с (до 150м) | Использует LED или VCSEL лазеры. Дешевле в реализации. |
| **Одномод (SMF)** | **OS2** | До 400+ Гбит/с (до 40+ км) | Тонкая сердцевина, лазеры высокой мощности. Для глобальных сетей (WAN). |

### Беспроводные технологии

| Технология | Стандарт | Диапазон | Особенности L1 |
| :--- | :--- | :--- | :--- |
| **Wi-Fi 6/6E** | 802.11ax | 2.4 / 5 / 6 ГГц | Модуляция **1024-QAM**, технология **OFDMA** |
| **Wi-Fi 7** | 802.11be | 2.4 / 5 / 6 ГГц | Модуляция **4096-QAM**, ширина канала **320 МГц** |
| **5G NR** | 3GPP Rel. 15+ | < 6 ГГц / mmWave | **Massive MIMO**, Beamforming (формирование луча) |

## Оборудование физического уровня

| Устройство | Роль на уровне L1 |
| :--- | :--- |
| **Трансиверы (SFP/SFP28/QSFP-DD)** | Преобразование электрических сигналов в световые (и наоборот) |
| **Повторитель (Repeater)** | Регенерация сигнала для увеличения дальности передачи |
| **Концентратор (Hub)** | Ретрансляция электрического сигнала на все порты (устарело) |
| **Медиаконвертер** | Сопряжение различных сред (например, медь ↔ оптика) |
| **Сетевая карта (NIC)** | На уровне L1 реализует трансивер (PHY) для работы с физическим портом |

## Современные технологии физического уровня

### InfiniBand
Специализированная технология для высокопроизводительных вычислений (HPC) и ИИ-кластеров.
- Использует стандарты **HDR (200G)** и **NDR (400G)**.
- Обеспечивает экстремально низкие задержки на физическом уровне за счет оптимизированного кодирования.

### PAM4 (Pulse Amplitude Modulation 4-level)
Метод кодирования, пришедший на смену классическому NRZ в сетях 50G, 100G и 400G.
- Передает **2 бита** за один такт (4 уровня сигнала вместо 2).
- Позволяет удвоить пропускную способность без увеличения тактовой частоты, но требует сложной коррекции ошибок (FEC).
