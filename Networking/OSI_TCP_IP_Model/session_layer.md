# Сеансовый уровень (L5)

## Определения

**Сеансовый уровень (L5, Session Layer)** — пятый уровень [модели OSI](./osi_model.md), отвечающий за установление, управление и завершение сеансов связи между приложениями.

- **PDU (Protocol Data Unit):** Данные (Data)
- **Адресация:** Отсутствует (использует адреса транспортного уровня)

## Базовые концепции

### Статус в современных сетях

> **Важно:** В [модели TCP/IP](./tcp_ip_model.md) сеансовый уровень как отдельная единица отсутствует. Его функции реализуются на прикладном уровне или через системные библиотеки и API.

Ключевая задача — управление диалогом между конечными устройствами.

| Функция | Описание |
| :--- | :--- |
| **Управление сеансами** | Создание, поддержание и штатное завершение соединений |
| **Управление диалогом** | Определение очередности передачи данных (дуплекс/полудуплекс) |
| **Синхронизация** | Установка контрольных точек для возобновления передачи после сбоя |
| **Управление маркерами** | Предотвращение одновременного выполнения критических операций несколькими узлами |

## Практические сценарии

### Реализации в современных системах

| Технология | Описание | Пример использования |
| :--- | :--- | :--- |
| **NetBIOS** | Legacy-протокол и API для установления сеанса | Сети Microsoft (разрешение имен, сессии) |
| **RPC** | Remote Procedure Call — удалённый вызов процедур | Распределённые системы, [gRPC](../ServicesAndTools/grpc_overview.md) |
| **Sockets API** | Интерфейс программирования для управления сеансами | Системные вызовы `connect()`, `accept()` |
| **SSH** | Протокол удалённого доступа с управлением сессией | Шифрованное управление хостами |
| **TLS Session** | Механизм возобновления сессий (resumption) | Оптимизация HTTPS-соединений |

### Пример: возобновление загрузки файла

1. Клиент начинает загрузку файла по FTP.
2. На 50% соединение обрывается (сбой на физическом или сетевом уровне).
3. Благодаря контрольной точке (checkpoint), установленной на L5:
4. Загрузка возобновляется с 50%, а не с начала.
5. Реализуется через протоколы прикладного уровня (например, FTP с командой `REST`).
