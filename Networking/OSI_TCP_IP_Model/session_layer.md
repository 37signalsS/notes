# Сеансовый уровень (L5)

**Сеансовый уровень** — это пятый уровень [[osi_tcp_ip_models|модели OSI]], который отвечает за установление, управление и завершение сеансов связи между приложениями.

## Основные концепции

На практике этот уровень используется редко, и его функции часто реализуются на прикладном уровне. В модели [[tcp_ip_model|TCP/IP]] этот уровень как отдельная единица отсутствует.

### Ключевые задачи

1.  **Управление сеансами:** Создание, поддержание и разрыв соединений (сеансов) между двумя системами.
2.  **Управление диалогом:** Определение, чья очередь передавать данные в данный момент (в полудуплексном режиме).
3.  **Синхронизация:** Установка "контрольных точек" в потоке данных, чтобы в случае сбоя можно было возобновить передачу с последней успешной точки, а не начинать все заново.

### Примеры протоколов

*   **NetBIOS (Network Basic Input/Output System):** Использовался в ранних сетях Microsoft.
*   **RPC (Remote Procedure Call):** Протоколы для удаленного вызова процедур.
*   **Sockets API:** Хотя это интерфейс, он предоставляет функции для управления сеансами.
