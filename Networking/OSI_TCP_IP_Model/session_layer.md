# Сеансовый уровень (L5)

## Определения

**Сеансовый уровень (L5)** — пятый уровень [модели OSI](./osi_model.md), отвечающий за установление, управление и завершение сеансов связи между приложениями.

- **PDU (Protocol Data Unit):** Данные (Data)
- **Адресация:** Отсутствует (использует адреса транспортного уровня)

### Статус в современных сетях

> **Важно:** В [модели TCP/IP](./tcp_ip_model.md) сеансовый уровень как отдельная единица отсутствует. Его функции реализуются на прикладном уровне или через библиотеки/API.

## Базовые концепции

Ключевая задача — управление диалогом между конечными устройствами.

| Функция | Описание |
| :--- | :--- |
| **Управление сеансами** | Создание, поддержание, завершение соединений |
| **Управление диалогом** | Определение очереди передачи (полудуплекс) |
| **Синхронизация** | Контрольные точки для возобновления после сбоя |
| **Управление маркерами** | Предотвращение одновременных критических операций |

## Практические сценарии

### Реализации в современных системах

| Технология | Описание | Пример использования |
| :--- | :--- | :--- |
| **NetBIOS** | Сетевой API для установления сеанса | Ранние сети Microsoft |
| **RPC** | Удалённый вызов процедур | Распределённые системы |
| **Sockets API** | Функции управления сеансами | `connect()`, `listen()`, `accept()` |
| **SSH** | Удалённый доступ с управлением сессией | `ssh user@host` |
| **TLS Session** | Возобновление TLS-сессий | HTTPS с session resumption |

### Пример: возобновление загрузки файла

1. Клиент начинает загрузку файла по FTP
2. На 50% соединение обрывается
3. Благодаря контрольной точке (checkpoint) на L5
4. Загрузка возобновляется с 50%, а не с начала
5. Протокол: FTP с командой `REST` (restart)
