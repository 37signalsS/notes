# Сеансовый уровень (L5)

## Определения

**Сеансовый уровень (L5)** — это пятый уровень [модели OSI](./osi_model.md), отвечающий за установление, управление и завершение сеансов связи между приложениями.

- **PDU (Protocol Data Unit):** Данные (Data)

## Основные концепции

Ключевая задача сеансового уровня — управление диалогом между конечными устройствами. На практике этот уровень используется редко, и его функции часто реализуются на прикладном уровне. В модели [TCP/IP](./tcp_ip_model.md) он как отдельная единица отсутствует.

**Основные функции:**
- **Управление сеансами:** Создание, поддержание и разрыв соединений (сеансов).
- **Управление диалогом:** Определение, чья очередь передавать данные в данный момент (в полудуплексном режиме).
- **Синхронизация:** Установка "контрольных точек" в потоке данных. Это позволяет возобновить передачу с последней успешной точки в случае сбоя, а не начинать заново.
- **Управление маркерами (tokens):** Предотвращение одновременного выполнения критических операций двумя сторонами.

## Практические сценарии

Функциональность сеансового уровня реализуется через следующие протоколы и API:

- **NetBIOS (Network Basic Input/Output System):** Использовался в ранних сетях Microsoft для установления сеанса.
- **RPC (Remote Procedure Call):** Протоколы, позволяющие программе вызывать процедуру на удаленной машине.
- **Sockets API:** Хотя Sockets являются интерфейсом, они предоставляют функции для управления сеансами (например, `connect()`, `listen()`, `accept()`).
