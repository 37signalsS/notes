# Канальный уровень (L2)

## Определения

**Канальный уровень (Data Link Layer, L2)** — второй уровень эталонной [модели OSI](./osi_model.md), обеспечивающий надежную передачу данных между узлами в пределах одного сегмента сети (локальной сети). Он преобразует физическую среду передачи в логическую линию связи, свободную от ошибок для вышестоящих уровней.

- **PDU (Protocol Data Unit):** Кадр (Frame).
- **Адресация:** [MAC-адреса](../Concepts/mac_address.md) (Media Access Control).

**Кадр (Frame)** — логическая единица данных L2. Состоит из заголовка (адреса, служебные поля), полезной нагрузки (пакет L3) и трейлера (концевика), содержащего контрольную сумму **FCS** (Frame Check Sequence) для обнаружения ошибок.

## Базовые концепции

### Подуровни (IEEE 802)

Стандарт IEEE 802 разделяет канальный уровень на два подуровня для обеспечения гибкости и независимости от физической среды:

| Подуровень | Описание |
| :--- | :--- |
| **LLC (Logical Link Control)** | Верхний подуровень. Отвечает за взаимодействие с сетевым уровнем, мультиплексирование протоколов (через поля SAP или SNAP) и контроль потока. |
| **MAC (Media Access Control)** | Нижний подуровень. Отвечает за физическую адресацию, формирование кадров и управление доступом к разделяемой среде (CSMA/CD, CSMA/CA). |

### Ключевые функции

- **Формирование кадров (Framing):** Инкапсуляция пакетов сетевого уровня. Определение границ кадра с помощью преамбулы и межкадрового интервала (IFG).
- **Физическая адресация:** Доставка кадра конкретному получателю в сегменте на основе уникальных MAC-адресов.
- **Обнаружение ошибок:** Проверка целостности данных с помощью циклического избыточного кода (**CRC/FCS**). Битые кадры отбрасываются на уровне оборудования.
- **Управление доступом (Medium Access):** Определение правил использования общей среды передачи (например, предотвращение коллизий в Ethernet).

### Разделение доменов

| Тип домена | Описание | Оборудование |
| :--- | :--- | :--- |
| **Домен коллизий** | Сегмент, где возможны столкновения сигналов при одновременной передаче. | Хабы (весь хаб — 1 домен), Коммутаторы (каждый порт — отдельный домен). |
| **Широковещательный домен** | Область, в которой широковещательные кадры (Broadcast) доставляются всем узлам. | Коммутаторы (по умолчанию 1 домен), [VLAN](../Protocols/vlan.md) (разделяют на несколько). |

## Современные технологии и оборудование

### Коммутация (L2 Switching)

Коммутатор (Switch) — это многопортовый мост, который принимает решение о пересылке кадров на основе **таблицы MAC-адресов** (CAM-таблицы).
- **Механизмы:** Learning (обучение), Forwarding (пересылка), Flooding (рассылка при отсутствии адреса в таблице), Aging (старение записей).
- **Методы коммутации:** Store-and-Forward (полная проверка CRC), Cut-Through (минимальная задержка), Adaptive.
- Подробнее: **[Определения и концепции L2 Switching](../Concepts/vlan_l2_switching/definitions_and_concepts.md)**.

### Агрегация каналов (EtherChannel / Bonding / LACP)

Технология объединения нескольких физических каналов в один логический для повышения отказоустойчивости и пропускной способности.
- **Протокол:** LACP (Link Aggregation Control Protocol, 802.3ad).
- **Режимы в Linux:** Balance-RR, Active-Backup, 802.3ad (LACP).

### Устранение петель (STP)

Протокол **STP (Spanning Tree Protocol, 802.1D)** предотвращает бесконечную циркуляцию кадров в сетях с избыточными связями путем блокировки «лишних» портов. Современные версии: RSTP (802.1w), MSTP (802.1s).

### Виртуализация сетевого интерфейса

В современных высоконагруженных системах и облаках функции L2 реализуются на новом уровне:
- **SR-IOV (Single Root I/O Virtualization):** Позволяет физической сетевой карте (PF) создавать виртуальные интерфейсы (VF), которые пробрасываются напрямую в ВМ, минуя стек гипервизора.
- **DPDK / XDP:** Технологии обработки кадров в пространстве пользователя или на уровне драйвера (eBPF), позволяющие достичь скоростей 100G+ за счет обхода стандартного сетевого стека ядра.
- **Виртуальные коммутаторы:** [Linux Bridge](../../Linux/Networking/Concepts/linux_bridge.md), [Open vSwitch (OVS)](../../Networking/ServicesAndTools/open_vswitch.md).

## Безопасность на канальном уровне

L2 является наиболее уязвимым уровнем, так как атаки здесь часто невидимы для L3-файрволов.
- **Port Security:** Ограничение количества или конкретных MAC-адресов на порту коммутатора.
- **DHCP Snooping:** Защита от поддельных DHCP-серверов.
- **Dynamic ARP Inspection (DAI):** Проверка соответствия IP-MAC для предотвращения ARP-спуфинга.
