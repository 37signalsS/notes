# Канальный уровень (L2)

## Определения

**Канальный уровень (Data Link Layer, L2)** — второй уровень эталонной [модели OSI](./osi_model.md), обеспечивающий надежную передачу данных между узлами в пределах одного сегмента сети (локальной сети). Он отвечает за преобразование физических сигналов, полученных с L1, в логические блоки данных и управление доступом к среде передачи.

- **PDU (Protocol Data Unit):** Кадр (Frame).
- **Адресация:** [MAC-адреса](../Concepts/mac_address.md) (Media Access Control). Длина — 48 бит (6 байт).

**Кадр (Frame)** — логическая единица данных L2. Типовой кадр Ethernet состоит из:
1.  **Заголовка (Header):** Преамбула, MAC-адреса отправителя и получателя, тип/длина (EtherType).
2.  **Полезной нагрузки (Payload):** Пакет сетевого уровня (обычно IPv4 или IPv6).
3.  **Трейлера (Trailer):** Контрольная сумма **FCS** (Frame Check Sequence), вычисляемая с помощью алгоритма CRC для проверки целостности.

## Базовые концепции

### Подуровни (IEEE 802)

Стандарт IEEE 802 разделяет канальный уровень на два подуровня:

| Подуровень | Описание |
| :--- | :--- |
| **LLC (Logical Link Control, 802.2)** | Верхний подуровень. Обеспечивает интерфейс для сетевого уровня (L3), выполняет мультиплексирование протоколов и контроль потока. |
| **MAC (Media Access Control)** | Нижний подуровень. Управляет физической адресацией, формирует кадры и контролирует доступ к среде (CSMA/CD для Ethernet, CSMA/CA для Wi-Fi). |

### Типы кадров Ethernet

1.  **Ethernet II (DIX):** Самый распространенный формат в сетях TCP/IP. Использует поле `EtherType` для указания протокола верхнего уровня (например, `0x0800` для IPv4).
2.  **IEEE 802.3 (LLC/SNAP):** Используется в некоторых служебных протоколах (например, STP, CDP). Содержит дополнительные поля заголовка для управления логическим каналом.

### Ключевые функции

- **Формирование кадров (Framing):** Инкапсуляция пакетов L3 в кадры L2 с четкими границами.
- **Физическая адресация:** Использование MAC-адресов для доставки внутри одного широковещательного домена.
- **Контроль доступа к среде:** Предотвращение или обработка коллизий (столкновений сигналов) в разделяемых средах.
- **Обнаружение ошибок:** Проверка контрольной суммы FCS. Если кадр поврежден, он отбрасывается (L2 по умолчанию не гарантирует доставку и не запрашивает повтор).

### Разделение доменов

- **Домен коллизий (Collision Domain):** Сегмент, где устройства конкурируют за среду. Коммутаторы разделяют домены коллизий: каждый порт — это отдельный домен.
- **Широковещательный домен (Broadcast Domain):** Область, в которой широковещательный кадр доставляется всем узлам. Разделяется маршрутизаторами (L3) или логически с помощью [VLAN](../Protocols/vlan.md).

## Современные технологии и оборудование

### Коммутация (L2 Switching)

Коммутатор (Switch) — интеллектуальное устройство, работающее на основе **таблицы MAC-адресов** (CAM-таблицы).
- **Процесс:** При получении кадра коммутатор записывает MAC отправителя (Learning) и пересылает кадр на нужный порт (Forwarding). Если адрес неизвестен, кадр рассылается на все порты (Flooding).
- **Методы:**
  - **Store-and-Forward:** Читает весь кадр, проверяет CRC (надежно, но медленнее).
  - **Cut-Through:** Начинает пересылку сразу после чтения адреса получателя (минимальная задержка).

### VLAN и тегирование (802.1Q)

Технология [VLAN](../Protocols/vlan.md) позволяет создавать несколько логических сетей на одной физической базе. Для передачи информации о VLAN между коммутаторами используется тег **IEEE 802.1Q** (4 байта), вставляемый в Ethernet-кадр:
- **VID (VLAN ID):** 12 бит (до 4094 сетей).
- **PCP (Priority Code Point):** 3 бита для QoS (CoS — Class of Service).

### Агрегация каналов (LACP)

Технология **802.3ad (LACP)** позволяет объединить несколько физических линков в один логический (Bonding/EtherChannel). Это увеличивает пропускную способность и обеспечивает отказоустойчивость (при обрыве одного кабеля связь сохраняется).

### ARP: Мост между L2 и L3

Протокол **[ARP](../Protocols/arp.md)** (Address Resolution Protocol) работает на стыке уровней (часто называют L2.5). Он позволяет узнать MAC-адрес устройства, зная его IP. Без ARP инкапсуляция IP-пакета в Ethernet-кадр невозможна.

### L2 Multicast и IGMP Snooping

По умолчанию коммутаторы рассылают мультикаст-трафик как широковещательный (на все порты). Механизм **IGMP Snooping** заставляет коммутатор «подслушивать» запросы узлов и отправлять мультикаст-группы только тем, кто на них подписан.

## Безопасность на канальном уровне

L2 уязвим для специфических атак:
- **MAC Flooding:** Переполнение CAM-таблицы коммутатора для перевода его в режим хаба. Защита: `Port Security`.
- **ARP Spoofing:** Подмена MAC-адреса шлюза. Защита: `Dynamic ARP Inspection (DAI)`.
- **DHCP Starvation:** Исчерпание пула IP-адресов. Защита: `DHCP Snooping`.

## Практическая диагностика (Linux)

Основные инструменты для анализа L2-состояния:

```bash
# Просмотр состояния интерфейсов и MAC-адресов
ip link show

# Просмотр таблицы MAC-адресов (на мосту/коммутаторе)
bridge fdb show

# Просмотр соседей (ARP-таблица)
ip neigh show

# Статистика ошибок (дропы, коллизии)
ethtool -S eth0
```
