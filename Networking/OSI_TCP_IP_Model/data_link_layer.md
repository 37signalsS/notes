# Канальный уровень (Data Link Layer)

## Определения

**Канальный уровень** — это второй уровень [модели OSI](./osi_model.md), который отвечает за передачу данных между двумя непосредственно подключенными узлами в одной локальной сети. В отличие от физического уровня, который оперирует битами, канальный уровень работает с **кадрами (frames)**.

**Кадр (Frame)** — это единица данных канального уровня, в которую упаковываются пакеты сетевого уровня. Кадр содержит служебную информацию, такую как MAC-адреса отправителя и получателя, а также данные для проверки целостности.

## Основные понятия

### Задачи канального уровня

1.  **Формирование кадров (Framing):** Упаковка пакетов, полученных от сетевого уровня, в кадры. Это включает добавление заголовка и концевика, что позволяет определить начало и конец сообщения в потоке бит.
2.  **Адресация:** Использование физических адресов (например, [MAC-адресов](../Concepts/mac_address.md)) для идентификации отправителя и получателя в пределах одного сегмента сети.
3.  **Управление доступом к среде (Media Access Control, MAC):** Регулирование доступа к общей среде передачи данных, чтобы избежать конфликтов (коллизий), когда несколько устройств пытаются передавать данные одновременно.
4.  **Обнаружение и коррекция ошибок:** Проверка целостности полученных кадров с помощью контрольной суммы (например, CRC) и, в некоторых технологиях, исправление ошибок.

### Технологии и протоколы

*   **Технологии:** Самой распространенной технологией для построения проводных локальных сетей является [Ethernet](../Protocols/ethernet.md). Другие примеры включают Wi-Fi, PPP (Point-to-Point Protocol) и [VLAN](../Protocols/vlan.md).
*   **Протоколы:** Ключевым протоколом, работающим на стыке канального и сетевого уровней, является [ARP](../Protocols/arp.md), который сопоставляет IP-адреса с MAC-адресами.

## Практические сценарии

*   **Коммутатор (Switch):**
    *   **Назначение**: Интеллектуальное устройство, соединяющее несколько узлов в одной **локальной сети (LAN)**. Является основой современной технологии **коммутируемого Ethernet**.
    *   **Уровень OSI**: Работает на **Канальном уровне (L2)**, оперируя [MAC-адресами](../Concepts/mac_address.md).
    *   **Принцип работы (Алгоритм прозрачного моста):**
        1.  **Таблица коммутации (MAC-таблица):** Внутри коммутатора находится таблица, которая сопоставляет MAC-адреса устройств с портами коммутатора, к которым они подключены.
        2.  **Обратное обучение (Backward Learning):** Коммутатор строит свою MAC-таблицу в процессе работы. Он просматривает каждый входящий кадр, считывает **MAC-адрес отправителя** и запоминает, на каком порту этот адрес был обнаружен.
        3.  **Пересылка:** Когда на коммутатор поступает кадр, он считывает **MAC-адрес получателя** и ищет его в своей таблице.
            *   **Если адрес найден:** Кадр отправляется только на тот порт, который указан в таблице.
            *   **Если адрес не найден (или это широковещательный адрес `FF:FF:FF:FF:FF:FF`):** Коммутатор отправляет кадр на **все порты**, кроме того, с которого кадр пришел (этот процесс называется **flooding**).
    *   **Преимущества:**
        *   **Высокая производительность:** Соединения "точка-точка" в полнодуплексном режиме устраняют коллизии, кардинально повышая эффективность сети.
        *   **Высокая безопасность:** Кадры доставляются только целевому получателю.
*   **Мост (Bridge):** Устройство, соединяющее два или более сегмента сети на канальном уровне. Современные коммутаторы являются, по сути, многопортовыми мостами.
*   **Сетевая карта (NIC - Network Interface Card):** Плата, устанавливаемая в компьютер, которая обеспечивает физическое подключение к сети и реализует функции канального уровня.
