# Уровень представления (L6)

## Определения

**Уровень представления (Presentation Layer)** — шестой уровень эталонной модели **OSI (Open Systems Interconnection)**, отвечающий за преобразование данных в формат, понятный для приложений. Обеспечивает "общий язык" для коммуникации, абстрагируя приложения от синтаксических различий.

- **PDU (Protocol Data Unit)** — единица данных протокола: Данные (Data).
- **Адресация:** Отсутствует (использует адреса сеансового или транспортного уровней).

## Базовые концепции

### Статус в современных сетях

В практической модели **TCP/IP (Transmission Control Protocol/Internet Protocol)** уровень представления не выделен как отдельный слой. Его функции интегрированы в прикладной уровень или реализуются через внешние библиотеки. Например, функции **TLS (Transport Layer Security)** часто реализуются библиотекой OpenSSL.

Уровень представления функционирует как "переводчик" в сетевом стеке.

| Функция | Описание | Примеры |
| :--- | :--- | :--- |
| **Представление данных** | Согласование формата, синтаксиса и семантики | ASCII, UTF-8, Big-endian/Little-endian |
| **Сжатие (Compression)** | Уменьшение объёма передаваемых данных | gzip, deflate, JPEG, MPEG |
| **Шифрование (Encryption)** | Обеспечение конфиденциальности данных | TLS/SSL, AES, RSA |

**Основные термины:**
* **ASCII (American Standard Code for Information Interchange):** Американский стандартный код для обмена информацией.
* **UTF (Unicode Transformation Format):** Формат преобразования Юникода.
* **TLS (Transport Layer Security):** Протокол защиты транспортного уровня.
* **SSL (Secure Sockets Layer):** Уровень защищённых сокетов (предшественник TLS).
* **AES (Advanced Encryption Standard):** Расширенный стандарт шифрования.
* **RSA (Rivest-Shamir-Adleman):** Криптографический алгоритм с открытым ключом.

### Процесс преобразования

```
Приложение (данные в специфическом формате)
         ↓
Уровень представления (кодирование, шифрование, сжатие)
         ↓
Универсальный сетевой формат для передачи
         ↓
Получатель (декодирование, расшифровка, декомпрессия)
         ↓
Приложение (данные в специфическом формате)
```

## Практические сценарии

### Сценарий 1: Безопасное веб-соединение (HTTPS)

При использовании **HTTPS (HyperText Transfer Protocol Secure)** уровень представления выполняет критические задачи:
1. Согласование алгоритмов шифрования между клиентом и сервером.
2. Проверка сертификатов и обмен ключами.
3. Шифрование прикладных данных перед их передачей на транспортный уровень.

### Сценарий 2: Передача медиаконтента

Приложение отправляет изображение в формате **JPEG (Joint Photographic Experts Group)**. Уровень представления гарантирует, что принимающая сторона сможет корректно интерпретировать битовую последовательность как изображение, независимо от архитектуры процессора или операционной системы. Аналогично это работает для видео в формате **MPEG (Moving Picture Experts Group)**.

### Сценарий 3: Сериализация данных

При взаимодействии микросервисов данные часто преобразуются в текстовые форматы, такие как **JSON (JavaScript Object Notation)** или **XML (eXtensible Markup Language)**. Это позволяет системам, написанным на разных языках программирования, обмениваться сложными структурами данных. Для повышения производительности могут использоваться бинарные форматы, например, Protocol Buffers.

## Дополнительная информация

### Сравнение с другими уровнями

| Уровень | PDU | Основные функции |
| :--- | :--- | :--- |
| **Прикладной (L7)** | Данные | Интерфейс пользователя, логика приложения |
| **Представления (L6)** | Данные | Форматирование, шифрование, сжатие |
| **Сеансовый (L5)** | Данные | Управление диалогом и сессиями |
