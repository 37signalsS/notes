# Уровень представления (L6)

**Уровень представления** (Presentation Layer) — это шестой уровень [[osi_tcp_ip_models|модели OSI]]. Его главная задача — преобразовывать данные в понятный для приложений формат, обеспечивая "общий язык" для коммуникации.

## Основные концепции

Этот уровень работает как "переводчик" для сети. Он берет данные от прикладного уровня и преобразует их в стандартный формат для передачи. На принимающей стороне он выполняет обратное преобразование.

В модели [[tcp_ip_model|TCP/IP]] этот уровень не выделен отдельно, и его функции (например, шифрование с помощью TLS) часто относят к прикладному уровню.

### Ключевые задачи

1.  **Представление данных:** Определение и согласование формата, синтаксиса и семантики передаваемых данных. Например:
    *   **Кодировка символов:** ASCII, UTF-8.
    *   **Порядок байтов:** Big-endian или Little-endian.
2.  **Сжатие (Compression):** Уменьшение объема данных для ускорения передачи.
3.  **Шифрование и дешифрование (Encryption/Decryption):** Обеспечение конфиденциальности данных.

### Примеры протоколов и стандартов

*   **[SSL/TLS](../Protocols/tls_protocol.md):** Хотя этот протокол часто ассоциируется с транспортным и прикладным уровнями, его функция шифрования является классическим примером задачи уровня представления.
*   **ASCII, EBCDIC:** Стандарты кодирования символов.
*   **JPEG, MPEG, GIF:** Стандарты для представления изображений и видео.
