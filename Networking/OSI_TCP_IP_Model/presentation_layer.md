# Уровень представления (L6)

## Определения

**Уровень представления (Presentation Layer)** — шестой уровень [модели OSI](./osi_model.md), отвечающий за преобразование данных в формат, понятный для приложений. Обеспечивает "общий язык" для коммуникации, абстрагируя приложения от синтаксических различий.

- **PDU (Protocol Data Unit):** Данные (Data)
- **Адресация:** Отсутствует (использует адреса сеансового/транспортного уровня)

## Базовые концепции

### Статус в современных сетях

> **Важно:** В [модели TCP/IP](./tcp_ip_model.md) уровень представления не выделен отдельно. Его функции (шифрование, сжатие, кодирование) интегрированы в прикладной уровень или реализуются через библиотеки (например, OpenSSL для TLS).

Уровень представления функционирует как "переводчик" в сети.

| Функция | Описание | Примеры |
| :--- | :--- | :--- |
| **Представление данных** | Согласование формата, синтаксиса, семантики | ASCII, UTF-8, Big-endian/Little-endian |
| **Сжатие (Compression)** | Уменьшение объёма данных | gzip, deflate, JPEG, MPEG |
| **Шифрование (Encryption)** | Конфиденциальность данных | TLS/SSL, AES, RSA |

### Процесс преобразования

```
Приложение (данные в своём формате)
         ↓
Уровень представления (кодирование/шифрование/сжатие)
         ↓
Универсальный формат для передачи
         ↓
Получатель (декодирование/расшифровка/ decompression)
         ↓
Приложение (данные в своём формате)
```

## Практические сценарии

### Сценарий 1: Безопасное веб-соединение (HTTPS)

1. Браузер запрашивает `https://example.com`
2. Сервер отправляет SSL/TLS-сертификат
3. **Уровень представления** выполняет:
   - Согласование алгоритма шифрования
   - Обмен ключами
   - Шифрование данных
4. Далее данные передаются в зашифрованном виде

### Сценарий 2: Передача изображения

1. Приложение отправляет изображение JPEG
2. **Уровень представления**:
   - Проверяет формат (JPEG)
   - При необходимости сжимает
   - Преобразует в сетевой формат
3. Получатель декодирует JPEG и отображает

### Сценарий 3: Текстовая коммуникация

| Проблема | Решение на L6 |
| :--- | :--- |
| Разные кодировки (CP1251 vs UTF-8) | Согласование UTF-8 |
| Разный порядок байтов | Преобразование endian |
| Специальные символы | Unicode-кодирование |

### Распространённые протоколы и форматы

| Категория | Примеры |
| :--- | :--- |
| **Шифрование** | TLS/SSL, SSH, [IPsec](../Tunnels/ipsec/ipsec.md) |
| **Сжатие** | gzip, zlib, LZ77 |
| **Кодировки текста** | ASCII, UTF-8, UTF-16, EBCDIC |
| **Медиаформаты** | JPEG, PNG, MPEG, GIF, MP3 |
| **Серийнаязация** | JSON, XML, ASN.1, Protocol Buffers |
