# Сетевой уровень (L3) — Обзор

## Определения

**Сетевой уровень (L3)** — третий уровень [модели OSI](../../osi_model.md), главная задача которого — построение крупных **составных сетей (internetworks)** из множества разнородных сетей, каждая из которых может быть построена на своей технологии канального уровня (Ethernet, Wi-Fi, сотовые сети и т.д.).

**PDU (Protocol Data Unit)** сетевого уровня — **пакет (Packet)**.

* **Адресация:** [IP-адреса](../../../Protocols/ip.md) (логические адреса, 32 бита IPv4 / 128 бит IPv6)

## Базовые концепции

### Необходимость сетевого уровня: ограничения L2

MAC-адрес уникален для каждого сетевого адаптера и позволяет идентифицировать устройство на [канальном уровне (L2)](../../data_link_layer.md) в пределах одной локальной сети. Однако для построения глобальных сетей MAC-адресации недостаточно:

1. **Локальная область действия:** MAC-адреса "плоские" и не содержат информации о топологии. Устройства общаются по MAC только в пределах одного широковещательного домена.
2. **Проблема масштабируемости:**
   * **Размер таблиц коммутации:** в глобальной сети с миллиардами устройств таблица MAC-адресов была бы невозможна для хранения и поиска
   * **Широковещательный шторм:** неизвестный MAC-адрес вызывает рассылку на все порты; в масштабах Интернета это привело бы к коллапсу
3. **Разнородность технологий:** Ethernet, Wi-Fi и другие L2-технологии отличаются адресацией, MTU и принципами работы
4. **Отсутствие множественных путей:** L2 не допускает петель; протокол [STP](../../../Protocols/stp.md) отключает резервные каналы, что неэффективно в глобальной сети

### IP-адрес как решение

**IP-адрес** — **логический, иерархический адрес**, который:

* Позволяет объединять разнородные локальные сети в единую глобальную сеть
* Предоставляет информацию о местоположении устройства для [маршрутизации](#маршрутизация-routing)
* Позволяет маршрутизаторам оперировать блоками адресов (подсетями), а не отдельными устройствами
* Отделяет логическую адресацию от физической

### Ключевые функции сетевого уровня

1. **Объединение сетей (Internetworking):** единая система связи между сетями с разными технологиями
2. **Глобальная адресация:** система логических [IP-адресов](../../../Protocols/ip.md), не зависящих от физических адресов канального уровня
3. **Маршрутизация (Routing):** определение оптимального пути для доставки пакетов через **маршрутизаторы**
   * Сетевой уровень позволяет иметь **несколько активных путей** между узлами
   * Маршрутизаторы обмениваются информацией о топологии (OSPF, BGP)
4. **Агрегация адресов:** маршрутизаторы оперируют **подсетями** (Network ID + Host ID), а не отдельными хостами
5. **Фрагментация:** разбивка пакетов на части для передачи через сети с меньшим MTU
6. **Отбрасывание пакетов:** пакеты с неизвестным путём не рассылаются, а отбрасываются
7. **Ограничение времени жизни (TTL):** счётчик уменьшается на каждом маршрутизаторе; при достижении нуля пакет уничтожается

## Практические сценарии

### Принцип работы маршрутизации

1. Чтобы отправить пакет получателю в другой сети, узел передаёт его по цепочке маршрутизаторов
2. На каждом шаге происходит:
   * Спуск на канальный уровень для физической доставки следующему маршрутизатору
   * Подъём на сетевой уровень для принятия решения о следующем шаге
3. Процесс повторяется до достижения целевой сети

Подробнее см. [Практические сценарии маршрутизации](./routing_scenarios.md).
