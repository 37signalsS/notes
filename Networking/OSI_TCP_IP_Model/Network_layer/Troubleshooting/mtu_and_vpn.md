# MTU и VPN

## Определения

**MTU (Maximum Transmission Unit)** — максимальный размер пакета (включая IP-заголовок), который может быть передан через сетевой интерфейс без фрагментации. Стандартное значение для Ethernet — **1500 байт**.

## Базовые концепции

### Почему VPN ломает MTU

VPN создает туннель, который инкапсулирует исходные IP-пакеты в новые пакеты с дополнительными заголовками:

| Тип VPN | Дополнительный оверхед | Эффективный MTU |
|---------|------------------------|-----------------|
| **IPsec (ESP)** | ~56-73 байта | ~1427-1444 байта |
| **WireGuard** | ~60 байт (IP+UDP+WireGuard) | ~1440 байт |
| **OpenVPN (UDP)** | ~69 байт | ~1431 байт |
| **GRE** | ~24 байта | ~1476 байт |

Когда исходный пакет (1500 байт) попадает в VPN-туннель, суммарный размер превышает MTU внешнего интерфейса. Это приводит к:

1. **Фрагментации** — пакет разбивается на части (если DF-флаг не установлен)
2. **Drops** — пакет отбрасывается (если DF-флаг установлен и фрагментация запрещена)
3. **Проблемам с PMTUD** — ICMP-сообщения "Fragmentation Needed" могут блокироваться файрволами

## Практические сценарии

### Симптомы проблем с MTU в VPN

- Мелкие пакеты (SSH, ping) работают, большие (HTTPS, SCP) — нет
- Соединение "зависает" при передаче данных
- Нестабильная работа только через VPN

### Диагностика MTU

Для определения максимального размера пакета без фрагментации используется [`ping` с флагом DF](../../../../Linux/Diagnostics/Networking/ping.md#тестирование-mtu):

```bash
# Проверка MTU через VPN (пример для WireGuard)
ping -M do -s 1472 vpn.endpoint.com
```

- **`-M do`** — запрет фрагментации (Don't Fragment)
- **`-s 1472`** — размер payload (1472 + 28 байт заголовков ICMP/IP = 1500)

Если ping не проходит — уменьшайте значение до нахождения максимального работающего размера.

### Решения

1. **Уменьшение MTU на VPN-интерфейсе:**

   ```bash
   ip link set dev wg0 mtu 1420
   ```

2. **TCP MSS Clamping** на маршрутизаторе/VPN-шлюзе — ограничение размера TCP-сегмента в SYN-пакетах

3. **Включение PMTUD** и пропуск ICMP "Fragmentation Needed" через файрвол
