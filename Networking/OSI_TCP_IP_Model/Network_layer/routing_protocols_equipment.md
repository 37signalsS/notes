# Протоколы и оборудование сетевого уровня (L3)

## Определения

**Маршрутизация (Routing)** — процесс выбора оптимального пути для передачи IP-пакета от источника к получателю через промежуточные узлы (хопы).

**Маршрутизатор (Router)** — специализированное устройство сетевого уровня, объединяющее разнородные сети и принимающее решение о пересылке на основе **таблицы маршрутизации (RIB)** и **таблицы продвижения (FIB)**.

## Базовые протоколы сетевого уровня

Помимо протоколов выбора пути, стек L3 включает служебные протоколы для обеспечения связности:

| Протокол | Назначение |
| :--- | :--- |
| **[IP (Internet Protocol)](../../Protocols/IP_addressing/ip_overview.md)** | Глобальная адресация и доставка пакетов. |
| **[ICMP (Internet Control Message Protocol)](../../Protocols/ICMP/icmp_overview.md)** | Диагностика и сообщения об ошибках (Unreachable, TTL Exceeded). |
| **[ARP (Address Resolution Protocol)](../../Protocols/arp.md)** | Связка IP (L3) и MAC (L2) в широковещательных сегментах. |
| **[DHCP (Dynamic Host Configuration Protocol)](../../Protocols/DHCP/dhcp_overview.md)** | Автоматизация настройки сетевых параметров. |

## Типы и протоколы маршрутизации

### 1. Статическая маршрутизация
Маршруты задаются администратором вручную.
- **Преимущества:** Минимальная нагрузка на CPU, полный контроль, высокая безопасность.
- **Недостатки:** Плохая масштабируемость, отсутствие адаптации к сбоям (нужны внешние проверки типа IP SLA).
- **Применение:** Default Gateway, сети с одним выходом (stub networks).

### 2. Динамическая маршрутизация (IGP и EGP)

Протоколы динамической маршрутизации позволяют роутерам автоматически обмениваться топологией.

#### IGP (Interior Gateway Protocols) — внутри Автономной Системы (AS)
| Протокол | Тип алгоритма | Метрика | Особенности |
| :--- | :--- | :--- | :--- |
| **[OSPF](./../../Protocols/ospf.md)** | Link-State | Cost (10^8/Bandwidth) | Иерархическая структура (Areas). Быстрая сходимость. Стандарт для Enterprise-сетей. |
| **IS-IS** | Link-State | Metric (Default 10) | Работает напрямую над L2. Масштабируемее OSPF, стандарт в сетях провайдеров и для SRv6. |
| **EIGRP** | Advanced Dist. Vector | Задержка + Полоса | Проприетарный (Cisco), высокая скорость переключения (Feasible Successor). |

#### EGP (Exterior Gateway Protocols) — между Автономными Системами
| Протокол | Тип алгоритма | Характеристики |
| :--- | :--- | :--- |
| **[BGP (Border Gateway Protocol)](../../Protocols/bgp.md)** | Path-Vector | Базируется на политиках (AS Path, Local Pref). Основа глобального Интернета. |

## Архитектура и оборудование L3

### Типы устройств

1.  **Маршрутизатор (Router):** Ориентирован на сложные функции L3, поддержку множества протоколов и WAN-интерфейсов.
2.  **L3-коммутатор (Multilayer Switch):** Совмещает L2-коммутацию и L3-маршрутизацию. Большинство операций выполняется аппаратно (ASIC), что обеспечивает огромную скорость при ограниченном наборе L3-функций.
3.  **Виртуальный маршрутизатор (vRouter):** ПО, запущенное в ВМ или контейнере (например, VyOS, FRRouting, Cisco 8000V). Широко используется в облаках.
4.  **Whitebox Switch:** Стандартное железо (bare-metal) с открытой ОС (SONiC, Cumulus Linux). Позволяет отделить софт от железа.

### Аппаратная архитектура
В современных высокопроизводительных роутерах (2026+) разделяются три плана (planes):

-   **Management Plane:** Уровень управления (SSH, SNMP, Netconf/Restconf).
-   **Control Plane:** Логика протоколов (BGP, OSPF). Работает на CPU. Формирует таблицу RIB (Routing Information Base).
-   **Data Plane (Forwarding Plane):** Непосредственная пересылка пакетов. Реализуется на специализированных чипах (**ASIC**) или сетевых процессорах (**NPU**). Использует таблицу FIB (Forwarding Information Base).

## Практические концепции

### Default-Free Zone (DFZ)
Совокупность маршрутизаторов в Интернете, которые имеют полную таблицу маршрутов (Full View) и не используют маршрут по умолчанию. 
- На июль 2026 года размер Full View составляет **~1 000 000+ префиксов IPv4** и **~220 000+ IPv6**.
- Для работы в DFZ роутеры должны иметь большой объем памяти (TCAM) для хранения FIB.

### EVPN (Ethernet VPN)
Современный стандарт для построения L2/L3 сетей поверх IP-фабрики (обычно через VXLAN).
- Использует **MP-BGP** для передачи информации о MAC и IP адресах.
- Позволяет строить масштабируемые ЦОД с поддержкой мобильности виртуальных машин.
