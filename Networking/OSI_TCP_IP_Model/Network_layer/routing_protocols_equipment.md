# Протоколы и оборудование сетевого уровня (L3)

## Определения

- **Маршрутизация:** Процесс определения оптимального пути для передачи данных (пакетов) между различными сетевыми сегментами.
- **Маршрутизатор (Роутер):** Устройство сетевого уровня (L3), основное назначение которого — объединение нескольких сетей в единую составную сеть (internetwork) и пересылка пакетов между ними.

## Базовые концепции

### Ключевые протоколы сетевого уровня

Помимо протоколов маршрутизации, сетевой уровень использует ряд других протоколов для своей работы:

| Протокол | Назначение |
| :--- | :--- |
| **[IP (Internet Protocol)](../../Protocols/IP_addressing/ip_overview.md)** | Передача данных и глобальная адресация пакетов. |
| **[ICMP (Internet Control Message Protocol)](../../Protocols/ICMP/icmp_overview.md)** | Служебные и диагностические сообщения, информирующие о проблемах в сети. |
| **[ARP (Address Resolution Protocol)](../../Protocols/arp.md)** | Сопоставление логических IP-адресов (L3) с физическими MAC-адресами (L2). |
| **[DHCP (Dynamic Host Configuration Protocol)](../../Protocols/DHCP/dhcp_overview.md)** | Автоматическое назначение IP-адресов и других сетевых параметров хостам. |

### Типы маршрутизации

Методы, используемые маршрутизаторами для построения таблиц маршрутизации:

| Тип маршрутизации | Описание | Применение |
| :--- | :--- | :--- |
| **Статическая** | Маршруты конфигурируются администратором вручную. | Небольшие сети, маршруты по умолчанию, изолированные (stub) сети. |
| **Динамическая** | Маршрутизаторы автоматически обмениваются информацией о сетях и строят таблицы маршрутизации, адаптируясь к изменениям топологии. | Крупные и сложные сети с высокой избыточностью. |

### Протоколы динамической маршрутизации (ДРП)

ДРП делятся на протоколы внутренних шлюзов (IGP) — для работы внутри одной автономной системы (AS), и протоколы внешних шлюзов (EGP) — для связи между AS.

| Протокол | Тип (IGP/EGP) | Алгоритм / Метрика | Особенности и применение |
| :--- | :--- | :--- | :--- |
| **RIP (Routing Information Protocol)** | IGP | Distance Vector / Хопы | Один из старейших протоколов. Основан на количестве "прыжков" (hops) до цели (макс. 15). Медленная сходимость, малоэффективен в современных крупных сетях. |
| **OSPF (Open Shortest Path First)** | IGP | Link State / Стоимость (пропускная способность) | Строит полную карту сети. Использует алгоритм Дейкстры для выбора кратчайшего пути на основе "стоимости" канала. Быстро реагирует на изменения топологии. Основной протокол для внутренних сетей. |
| **[BGP (Border Gateway Protocol)](../../Protocols/bgp.md)** | EGP | Path Vector / Политики | Протокол, на котором основан весь Интернет. Соединяет различные автономные системы. Выбор пути основан на комплексных политиках (бизнес-отношениях), а не только на метрике. |
| **EIGRP (Enhanced Interior Gateway Routing Protocol)** | IGP | Advanced Distance Vector | Гибридный протокол, разработанный Cisco. Сочетает скорость сходимости Link State с простотой Distance Vector. |

## Оборудование сетевого уровня

### Маршрутизатор (Роутер)

**Назначение:** Основная роль маршрутизатора — пересылка пакетов между разными IP-сетями.

**Принцип работы:**

1. Маршрутизатор получает IP-пакет на один из своих интерфейсов.
2. Анализирует IP-адрес назначения пакета.
3. Сверяется со своей **таблицей маршрутизации**, чтобы найти наилучший путь до сети назначения.
4. Пересылает пакет на соответствующий исходящий интерфейс, обычно после уменьшения значения TTL.

**Отличие от коммутатора:**

- **Коммутатор** (L2) соединяет устройства **внутри одной** локальной сети, используя MAC-адреса.
- **Маршрутизатор** (L3) соединяет **разные** IP-сети, используя IP-адреса.

### L3-коммутатор

**Гибридное устройство**, которое сочетает функциональность коммутатора и маршрутизатора:

- **Функции коммутатора:** Обеспечивает быструю коммутацию на L2 в пределах VLAN.
- **Функции маршрутизатора:** Выполняет маршрутизацию между VLAN/подсетями на L3, часто с аппаратным ускорением.

**Применение:** Используется в кампусных сетях для высокопроизводительной маршрутизации между VLAN.

## Практические сценарии

### Default-Free Zone (DFZ)

**Default-Free Zone (DFZ)** — это совокупность магистральных маршрутизаторов в интернете, которые содержат полные таблицы маршрутизации до всех известных сетей и **не используют маршрут по умолчанию** для пересылки трафика. Это обеспечивает полную связность и отказоустойчивость.

#### Проблема использования маршрута по умолчанию в сложных сетях

Маршрут по умолчанию (`0.0.0.0/0`) направляет весь трафик, для которого нет более специфичного маршрута, в одно заранее определенное направление. Это упрощает конфигурацию в небольших сетях, но может привести к проблемам в сложных многосвязанных топологиях:

- Маршрутизатор, имеющий только маршрут по умолчанию, не способен принимать решения о маршрутизации, если у него несколько исходящих путей.
- Возникают ситуации, когда пакеты могут доходить до цели, но обратный трафик теряется, потому что промежуточные маршрутизаторы не знают, куда отправлять ответы.

#### Пример сети с маршрутом по умолчанию

Рассмотрим простую сеть:

```text
Хост 1 (10.0.0.1/24) -- [Маршрутизатор 1] -- (192.168.1.0/24) -- [Маршрутизатор 2] -- (172.16.12.0/24) -- [Маршрутизатор 3] -- Хост 2 (169.254.1.1/24)
```

Если на `Маршрутизаторе 2` установлен только маршрут по умолчанию, направленный на `Маршрутизатор 3`, а `Маршрутизатор 3` не знает о сети `10.0.0.0/24`, то пакеты от Хоста 1 дойдут до Хоста 2, но обратно — нет.

#### Решения для обеспечения полной связности в DFZ

**1. Полная таблица маршрутизации:** Каждый маршрутизатор в DFZ хранит подробные маршруты до всех достижимых сетей. Это требует больших вычислительных ресурсов и памяти.
**2. Комбинация статических/динамических маршрутов:** Использование протоколов динамической маршрутизации (например, BGP) для обмена информацией о сетях, что позволяет строить эффективные таблицы без ручного конфигурирования каждого маршрута.

В интернете роль DFZ выполняют магистральные маршрутизаторы крупных провайдеров (Tier-1), которые используют [BGP](../../Protocols/bgp.md) для обмена информацией о более чем 900 000 префиксах (на 2024 год).
