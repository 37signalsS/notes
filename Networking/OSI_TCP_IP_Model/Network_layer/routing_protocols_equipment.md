# Протоколы и оборудование сетевого уровня (L3)

## Определения

**Маршрутизация (Routing)** — процесс выбора оптимального пути для передачи IP-пакета от источника к получателю через промежуточные узлы (хопы) на основе логической адресации.

**Маршрутизатор (Router)** — интеллектуальное устройство сетевого уровня, объединяющее разнородные сети (L2-домены) и принимающее решение о пересылке пакетов на основе динамических или статических правил.

**Административная дистанция (Administrative Distance, AD)** — мера «доверия» к источнику маршрутной информации. Если один и тот же префикс получен из разных источников (например, OSPF и BGP), маршрутизатор выберет тот, у которого AD ниже.

## Базовые концепции

### Базовые протоколы сетевого уровня

Для обеспечения функционирования L3, помимо самих протоколов маршрутизации, используются вспомогательные службы:

| Протокол | Назначение | SSoT |
| :--- | :--- | :--- |
| **[IP (Internet Protocol)](../../Protocols/IP_addressing/ip_overview.md)** | Глобальная адресация и доставка пакетов. | [Обзор IP](../../Protocols/IP_addressing/ip_overview.md) |
| **[ICMP (Control Message)](../../Protocols/ICMP/icmp_overview.md)** | Диагностика и сообщения об ошибках (Unreachable, TTL Exceeded). | [Обзор ICMP](../../Protocols/ICMP/icmp_overview.md) |
| **[ARP (Address Resolution)](../../Protocols/arp.md)** | Связка IP (L3) и MAC (L2) в широковещательных сегментах. | [Обзор ARP](../../Protocols/arp.md) |
| **[DHCP (Host Configuration)](../../Protocols/DHCP/dhcp_overview.md)** | Автоматизация настройки сетевых параметров узлов. | [Обзор DHCP](../../Protocols/DHCP/dhcp_overview.md) |

### Типы маршрутизации

1.  **Статическая маршрутизация:** Маршруты прописываются администратором вручную (`ip route ...`).
    - *Применение:* Default Gateway на хостах, тупиковые сети (Stub), резервные каналы (Floating Static).
2.  **Динамическая маршрутизация:** Автоматический обмен информацией о топологии между роутерами.

#### IGP (Interior Gateway Protocols) — внутри одной организации (AS)
- **[OSPF](../../Protocols/ospf.md):** Алгоритм Link-State (SPF). Стандарт для корпоративных сетей. Быстрая сходимость.
- **IS-IS:** Аналог OSPF, работающий напрямую над L2. Основной протокол в сетях провайдеров для построения IP-фабрик.
- **EIGRP:** Гибридный протокол (Cisco), оптимизированный для быстрой реакции на изменения.

#### EGP (Exterior Gateway Protocols) — между автономными системами
- **[BGP (Border Gateway Protocol)](../../Protocols/bgp.md):** Протокол вектора пути (Path-Vector). Единственный протокол, на котором держится глобальный Интернет. Управляется политиками (Attributes), а не просто метриками.

## Архитектура и оборудование L3

### Уровни обработки (Planes)

Современные маршрутизаторы (2026+) строго разделяют ресурсы для стабильности:
1.  **Management Plane:** Доступ для администратора (SSH, API, SNMP).
2.  **Control Plane:** Работа протоколов маршрутизации. Здесь CPU вычисляет пути и строит таблицу **RIB (Routing Information Base)** — общую базу всех известных маршрутов.
3.  **Data Plane (Forwarding Plane):** Непосредственная пересылка пакетов. Использует таблицу **FIB (Forwarding Information Base)** — «выжимку» из RIB, оптимизированную для максимально быстрого поиска.

**Важный нюанс:** Наличие маршрута в RIB не гарантирует прохождение пакета. Если между Control Plane и Data Plane возникает рассинхронизация (например, при сложных изменениях BGP, ECMP или PBR), запись в FIB может отсутствовать или указывать на неверный next-hop. Диагностика требует проверки обеих таблиц:
- **RIB:** `show ip route <prefix>` (решение процесса маршрутизации).
- **FIB:** `show ip cef <destination>` (реальное решение forwarding).

### Аппаратное ускорение

-   **ASIC (Application-Specific Integrated Circuit):** Специализированные чипы, выполняющие поиск в FIB на аппаратной скорости порта (Wire-speed).
-   **TCAM (Ternary Content-Addressable Memory):** Сверхбыстрая память, позволяющая выполнять поиск по маске (**Longest Prefix Match**) за один такт. Количество записей в TCAM определяет масштаб сети, которую может обслуживать устройство.
-   **NPU (Network Processor):** Программируемые чипы, занимающие промежуточное положение между CPU и ASIC (гибкость софта + скорость железа).

### Типы оборудования

-   **Классический роутер:** Максимальный набор функций (VPN, QoS, глубокая инспекция), но часто ниже плотность портов.
-   **L3-коммутатор (Layer 3 Switch):** Коммутатор, умеющий маршрутизировать трафик между VLAN на аппаратной скорости. Дешевле роутера на порт, но ограничен в функциях WAN и размере таблиц.
-   **Whitebox Switch:** Стандартное железо без ОС. Инженер сам выбирает сетевую ОС (SONiC, FreeRtr), что позволяет избежать vendor lock-in.
-   **vRouter (Виртуальный роутер):** Инстанс в облаке (FRRouting, VyOS). Позволяет строить сложные топологии внутри виртуальной инфраструктуры.

## Практические концепции (2026+)

### Default-Free Zone (DFZ)
Область Интернета, где роутеры (Core) не используют маршрут по умолчанию. Они хранят **Full View** — полную таблицу всех публичных префиксов мира (~1.2M записей в 2026г).

### Segment Routing (SRv6)
Новая парадигма управления трафиком. Маршрут задается непосредственно в заголовке пакета IPv6 в виде списка сегментов. Это заменяет сложный MPLS и позволяет Control Plane быть полностью централизованным (SDN).

### EVPN (Ethernet VPN)
Протокол управления для Overlay-сетей (VXLAN). Использует BGP для передачи информации не только об IP, но и о MAC-адресах, обеспечивая бесшовную мобильность нагрузок в ЦОД.
