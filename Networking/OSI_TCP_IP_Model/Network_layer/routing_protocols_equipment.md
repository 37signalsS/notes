# Протоколы и оборудование сетевого уровня

## Определения

**Маршрутизация** — процесс определения оптимального пути для передачи данных между сетями.

**Маршрутизатор** — устройство сетевого уровня, предназначенное для объединения нескольких сетей в единую составную сеть (internetwork).

## Базовые концепции

### Ключевые протоколы сетевого уровня

| Протокол | Назначение |
|----------|------------|

### Типы маршрутизации

| Тип | Описание | Применение |
|-----|----------|------------|
| **Статическая** | Маршруты конфигурируются администратором вручную | Малые сети, дефолтные маршруты, stub-сети |
| **Динамическая** | Автоматический выбор маршрута на основе изменяющихся условий | Крупные сети с избыточной топологией |

### Протоколы динамической маршрутизации

| Протокол | Тип | Алгоритм | Применение |
|----------|-----|----------|------------|
| **OSPF** | IGP (Interior Gateway Protocol) | Link State (состояние каналов) | Крупные корпоративные сети |
| **RIP** | IGP | Distance Vector (вектор расстояния) | Малые сети (устаревший) |
| **[BGP](../../Protocols/bgp.md)** | EGP (Exterior Gateway Protocol) | Path Vector | Интернет, крупные провайдеры |
| **EIGRP** | IGP | Advanced Distance Vector (Cisco) | Сети Cisco |

## Практические сценарии

### Оборудование сетевого уровня

#### Маршрутизатор (Роутер)

**Назначение:** объединение нескольких сетей в единую составную сеть.

**Принцип работы:**

1. Получает пакет на интерфейс
2. Анализирует IP-адрес назначения
3. Сверяется с **таблицей маршрутизации**
4. Отправляет пакет на соответствующий интерфейс

**Отличие от коммутатора:**

- Коммутатор соединяет узлы *внутри* одной сети (L2, MAC-адреса)
- Маршрутизатор связывает *разные* сети (L3, IP-адреса)

#### L3-коммутатор

**Гибридное устройство**, сочетающее:

- Функции коммутатора: быстрая коммутация на L2 в пределах VLAN
- Функции маршрутизатора: маршрутизация между VLAN/подсетями на L3

**Применение:**

- Маршрутизация между VLAN в кампусных сетях
- Высокая производительность за счёт аппаратной маршрутизации
