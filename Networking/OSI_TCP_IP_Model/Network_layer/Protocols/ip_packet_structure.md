# Структура IP-пакета (IPv4)

IP-пакет (дейтаграмма) состоит из двух основных частей: **заголовка (Header)** и **полезной нагрузки (Payload)**. Заголовок содержит служебную информацию, необходимую для маршрутизации и обработки пакета. Минимальный размер заголовка IPv4 составляет 20 байт, максимальный — 60 байт (с учетом опций).

| Поле               | Длина (бит) | Описание                                                                                                                                                                                                                                                                 |
| :----------------- | :---------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Version**        | 4           | Версия IP-протокола (например, `4` для IPv4).                                                                                                                                                                                                                          |
| **IHL (Internet Header Length)** | 4           | Длина заголовка IP-пакета в 32-битных словах. Минимальное значение `5` (20 байт).                                                                                                                                                                             |
| **DSCP (Differentiated Services Code Point) / ECN (Explicit Congestion Notification)** | 8           | Ранее Type of Service (ToS). Используется для маркировки пакетов с целью обеспечения качества обслуживания (QoS) и уведомления о перегрузке.                                                                       |
| **Total Length**   | 16          | Общая длина IP-пакета (заголовок + данные) в байтах. Максимальное значение — 65 535 байт.                                                                                                                                                                                |
| **Identification** | 16          | Уникальный идентификатор для фрагментированных пакетов. Все фрагменты одного исходного IP-пакета имеют одинаковый ID.                                                                                                                                                  |
| **Flags**          | 3           | Флаги, управляющие фрагментацией:<br>- `DF` (Don't Fragment): Запрещает фрагментацию. Если пакет не может быть передан без фрагментации, он отбрасывается.<br>- `MF` (More Fragments): Указывает, что за данным фрагментом следуют другие. Последний фрагмент имеет `MF=0`. |
| **Fragment Offset** | 13          | Смещение фрагмента в исходном IP-пакете, измеряется в 8-байтных блоках. Используется для сборки фрагментов в правильном порядке.                                                                                                                                           |
| **Time To Live (TTL)** | 8           | Количество переходов (хопов), которое пакет может совершить до того, как будет отброшен. Защищает от зацикливания пакетов.                                                                                                                                            |
| **Protocol**       | 8           | Указывает протокол следующего уровня (например, `6` для TCP, `17` для UDP, `1` для ICMP).                                                                                                                                                                                 |
| **Header Checksum** | 16          | Контрольная сумма только для заголовка IP-пакета. Пересчитывается на каждом маршрутизаторе, так как TTL меняется.                                                                                                                                                           |
| **Source IP Address** | 32          | IP-адрес отправителя пакета.                                                                                                                                                                                                                                         |
| **Destination IP Address** | 32          | IP-адрес получателя пакета.                                                                                                                                                                                                                                          |
| **Options**        | Переменная | Дополнительные параметры (например, запись маршрута, временные метки). Используются редко.                                                                                                                                                                                 |
| **Padding**        | Переменная | Заполняющие биты, чтобы заголовок был кратен 32 битам.                                                                                                                                                                                                                     |
