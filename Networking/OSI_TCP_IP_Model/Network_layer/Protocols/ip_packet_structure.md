# Структура IP-пакета (IPv4)

## Определения

**IP-пакет (дейтаграмма)** — единица данных сетевого уровня, состоящая из **заголовка (Header)** и **полезной нагрузки (Payload)**.

**MTU (Maximum Transmission Unit)** — максимальный размер пакета, который может быть передан без фрагментации.

## Базовые концепции

### Общая структура

```
+------------------+---------------------+
|    Заголовок     |  Полезная нагрузка  |
| (20-60 байт)     |  (до 65535 байт)    |
+------------------+---------------------+
```

- **Минимальный размер заголовка:** 20 байт
- **Максимальный размер заголовка:** 60 байт (с опциями)
- **Максимальный размер пакета:** 65 535 байт

### Поля заголовка IPv4

| Поле | Длина (бит) | Описание |
|------|-------------|----------|
| **Version** | 4 | Версия IP-протокола (`4` для IPv4) |
| **IHL (Internet Header Length)** | 4 | Длина заголовка в 32-битных словах (мин. `5` = 20 байт) |
| **DSCP/ECN** | 8 | Quality of Service (DSCP) и Explicit Congestion Notification |
| **Total Length** | 16 | Общая длина пакета в байтах (макс. 65 535) |
| **Identification** | 16 | Идентификатор для фрагментированных пакетов |
| **Flags** | 3 | Флаги фрагментации: `DF` (Don't Fragment), `MF` (More Fragments) |
| **Fragment Offset** | 13 | Смещение фрагмента (в 8-байтных блоках) |
| **TTL (Time To Live)** | 8 | Количество переходов (уменьшается на каждом хопе) |
| **Protocol** | 8 | Протокол следующего уровня: `6`=TCP, `17`=UDP, `1`=ICMP |
| **Header Checksum** | 16 | Контрольная сумма заголовка (пересчитывается на каждом маршрутизаторе) |
| **Source IP Address** | 32 | IP-адрес отправителя |
| **Destination IP Address** | 32 | IP-адрес получателя |
| **Options** | Переменная | Дополнительные параметры (редко используются) |
| **Padding** | Переменная | Заполнение до кратности 32 битам |

## Практические сценарии

### Поля для фрагментации

Поля, используемые при фрагментации (подробнее см. [Фрагментация IP-пакетов](./ip_fragmentation.md)):

- **Identification:** все фрагменты одного пакета имеют одинаковый ID
- **Flags (MF):** установлен во всех фрагментах, кроме последнего
- **Fragment Offset:** позиция фрагмента относительно начала исходного пакета

### TTL и диагностика

**TTL** используется для диагностики пути пакета:

```bash
# traceroute отправляет пакеты с возрастающим TTL
traceroute example.com
```

Каждый маршрутизатор уменьшает TTL на 1 и при достижении 0 отправляет ICMP Time Exceeded.

## Дополнительная информация

### Сравнение IPv4 и IPv6

| Характеристика | IPv4 | IPv6 |
|----------------|------|------|
| **Размер заголовка** | 20-60 байт | 40 байт (фиксированный) |
| **Checksum** | Есть | Нет (перенесён на L2/L4) |
| **Фрагментация** | В заголовке | В расширении (Extension Header) |
| **Опции** | В заголовке | В Extension Headers |
