# Меж-VLAN маршрутизация (Inter-VLAN Routing)

## Определения

**Меж-VLAN маршрутизация (Inter-VLAN Routing)** — процесс передачи трафика между логически изолированными сетями (VLAN) через устройство третьего уровня модели OSI (L3) — маршрутизатор или L3-коммутатор.

**SVI (Switch Virtual Interface)** — виртуальный интерфейс L3-коммутатора, связанный с конкретным VLAN. Выполняет роль шлюза по умолчанию для устройств внутри этого VLAN.

**ROAS (Router-on-a-Stick)** — метод маршрутизации между VLAN с использованием одного физического интерфейса маршрутизатора, разделенного на виртуальные сабинтерфейсы (sub-interfaces).

**Reliability Score:** 10 (SSoT + Industry standards verified)

## Основные концепции

### Зачем нужна маршрутизация между VLAN?
VLAN обеспечивают изоляцию на канальном уровне (L2). Устройства в разных VLAN находятся в разных широковещательных доменах и не могут взаимодействовать напрямую. Для связи между ними пакеты должны быть переданы на сетевой уровень (L3), где принимается решение о маршрутизации на основе IP-адресов.

### Методы реализации

| Метод | Оборудование | Особенности | Масштабируемость |
| :--- | :--- | :--- | :--- |
| **Отдельные интерфейсы** | Маршрутизатор + L2-Switch | Физический порт на каждый VLAN | Низкая (ограничена портами) |
| **Router-on-a-Stick** | Маршрутизатор + L2-Switch | Один Trunk-порт, сабинтерфейсы | Средняя (ограничена CPU/BW порта) |
| **L3-Switch (SVI)** | L3-коммутатор | Маршрутизация на аппаратной скорости (ASIC) | Высокая |

## Практические сценарии

### 1. Router-on-a-Stick (ROAS)
Используется в небольших сетях, где нет L3-коммутатора.

**Принцип работы:**
1. Пакет из VLAN 10 поступает на коммутатор.
2. Коммутатор отправляет его через Trunk-порт на маршрутизатор, добавляя тег 802.1Q.
3. Маршрутизатор принимает пакет на сабинтерфейсе (например, `Gi0/0.10`), снимает тег, проверяет таблицу маршрутизации.
4. Маршрутизатор инкапсулирует пакет с новым тегом (VLAN 20) и отправляет обратно через тот же Trunk-порт.

**Конфигурация Cisco IOS:**
```cisco
interface GigabitEthernet0/0.10
 description *** Gateway for VLAN 10 ***
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0

interface GigabitEthernet0/0.20
 description *** Gateway for VLAN 20 ***
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
```

### 2. Маршрутизация на L3-коммутаторе (SVI)
Современный стандарт для корпоративных сетей. Маршрутизация происходит внутри коммутатора «на лету» (wire-speed).

**Принцип работы:**
Для каждого VLAN создается логический интерфейс `interface Vlan <ID>`, который становится шлюзом для этого сегмента.

**Конфигурация Cisco IOS:**
```cisco
# Включение функций маршрутизации
ip routing

interface Vlan 10
 description *** Gateway for VLAN 10 ***
 ip address 192.168.10.1 255.255.255.0
 no shutdown

interface Vlan 20
 description *** Gateway for VLAN 20 ***
 ip address 192.168.20.1 255.255.255.0
 no shutdown
```

## Безопасность и фильтрация

### Использование ACL (Access Control Lists)
Поскольку меж-VLAN маршрутизация объединяет сегменты, необходимо контролировать доступ:
- Изоляция гостевой сети от корпоративной.
- Ограничение доступа к серверному сегменту (только по нужным портам).

**Пример ACL на SVI (Cisco):**
```cisco
ip access-list extended BLOCK_GUEST
 deny ip 192.168.20.0 0.0.0.255 192.168.10.0 0.0.0.255
 permit ip any any

interface Vlan 20
 ip access-group BLOCK_GUEST in
```

### VRF (Virtual Routing and Forwarding)
Для полной изоляции трафика (например, разных арендаторов) на одном физическом устройстве используются VRF — независимые таблицы маршрутизации.
- **SSoT:** Подробнее см. **[VRF в сетевых технологиях](../../../Linux/Networking/vrf.md)**.

## Диагностика и устранение неисправностей

### Типичные проблемы
1. **Mismatch тегирования:** На маршрутизаторе настроен сабинтерфейс `.10`, а на коммутаторе порт не в Trunk-режиме или VLAN 10 не разрешен.
2. **Отсутствие `ip routing`:** На L3-коммутаторе интерфейсы SVI подняты, но маршрутизация не включена глобально.
3. **Неверный Gateway:** Хосты в VLAN имеют шлюз, отличный от адреса SVI/Sub-interface.

### Команды проверки
```cisco
# Просмотр таблицы маршрутизации
show ip route

# Проверка состояния SVI
show ip interface brief | include Vlan

# Проверка сабинтерфейсов
show vlans
```
