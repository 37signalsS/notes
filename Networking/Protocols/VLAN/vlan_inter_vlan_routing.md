# Меж-VLAN маршрутизация (Inter-VLAN Routing)

## Определения

**Меж-VLAN маршрутизация (Inter-VLAN Routing)** — процесс передачи трафика между устройствами в разных VLAN через L3-устройство (маршрутизатор или L3-коммутатор).

**Ключевая особенность:** Устройства в разных VLAN не могут взаимодействовать напрямую на L2. Требуется маршрутизация на сетевом уровне.

## Базовые концепции

### Назначение

VLAN разделяют один физический широковещательный домен на несколько изолированных. Например, в сети на 1000 хостов:

- Бухгалтерия (VLAN 10)
- Серверная (VLAN 20)
- Разработка (VLAN 30)
- Тестирование (VLAN 40)

**Без VLAN** — единый broadcast-домен вызывает:

- Лавину ARP-запросов на все хосты
- Проблемы безопасности (любой хост видит чужой трафик)

**С VLAN** — изоляция на L2, но для взаимодействия отделов требуется L3-маршрутизация.

### Принцип работы

Маршрутизатор/L3-коммутатор имеет интерфейсы (физические или логические) в каждом VLAN. При получении пакета от устройства в VLAN A с адресом получателя в VLAN B:

1. Разбирает IP-заголовок на входном интерфейсе
2. Консультируется с таблицей маршрутизации
3. Отправляет пакет через выходной интерфейс VLAN B

### Терминология

Запись «VLAN 10» является сокращением от «VLAN Id = 10» и общепринята в документации.

## Практические сценарии

### Схема 1: Отдельные физические интерфейсы

Каждому VLAN соответствует отдельный физический порт маршрутизатора.

**Топология:**

```
[Хост 1: 192.168.1.0/24, VLAN 10] ──(порт 1)── [Маршрутизатор] ──(порт 2)── [Хост 2: 10.0.0.0/24, VLAN 20]
                                             (192.168.1.1)            (10.0.0.1)
```

**Процесс передачи:**

1. Хост 1 отправляет пакет → коммутатор (VLAN 10) → маршрутизатор (порт 192.168.1.1)
2. Маршрутизатор разбирает IP-заголовок, определяет, что получатель (10.0.0.2) не его
3. По таблице маршрутизации отправляет пакет через интерфейс 10.0.0.1
4. Пакет попадает на порт коммутатора с VLAN 20 → коммутация в пределах VLAN 20 → хост 2

**Недостаток:** Один физический порт на каждый VLAN — не масштабируется.

---

### Схема 2: Router-on-a-Stick (ROAS)

**ROAS (Router-on-a-Stick)** — маршрутизация между VLAN через один физический интерфейс с использованием сабинтерфейсов.

**Сабинтерфейс (sub-interface)** — виртуальный L3-интерфейс, отправляющий и принимающий кадры с тегом 802.1Q.

**Топология:**

```
[Хост 1: 192.168.1.0/24, VLAN 10] ──(access)── [Коммутатор] ══(trunk)══ [Маршрутизатор]
                                                                          (1 физический порт)
                                                                           ├─ eth0.10: 192.168.1.1/24 (VLAN 10)
                                                                           └─ eth0.20: 10.0.0.1/24 (VLAN 20)
[Хост 2: 10.0.0.0/24, VLAN 20] ──(access)── [Коммутатор]
```

**Конфигурация коммутатора:**

- Порт к маршрутизатору: **Trunk** — пропускает несколько VLAN с тегами 802.1Q
- Остальные порты: **Access** — один VLAN, трафик нетегированный

**Процесс передачи:**

1. Хост 1 отправляет пакет → access-порт (VLAN 10)
2. Коммутатор отправляет пакет через trunk-порт, добавляя тег 802.1Q (VLAN Id = 10)
3. Маршрутизатор принимает пакет с тегом:
   - Обрабатывается сабинтерфейсом eth0.10 (настроен на VLAN 10)
   - Разбирает IP-заголовок, определяет получателя 10.0.0.2
   - По таблице маршрутизации отправляет через eth0.20
   - Добавляет тег 802.1Q (VLAN Id = 20)
4. Пакет с VLAN Id = 20 возвращается на trunk-порт коммутатора → коммутация в VLAN 20 → хост 2

**Преимущества ROAS:**

- Экономия портов (один физический порт вместо нескольких)
- Гибкость — добавление VLAN без новых подключений
- Масштабируемость — до 4094 VLAN на один интерфейс

#### Конфигурация Cisco

```cisco
! Сабинтерфейс для VLAN 10
interface GigabitEthernet0/0.10
 encapsulation dot1Q 10
 ip address 192.168.1.1 255.255.255.0

! Сабинтерфейс для VLAN 20
interface GigabitEthernet0/0.20
 encapsulation dot1Q 20
 ip address 10.0.0.1 255.255.255.0
```

#### Настройка в Linux

```bash
# Включить IP forwarding
sysctl -w net.ipv4.ip_forward=1

# Создать VLAN-интерфейсы
ip link add link eth0 name eth0.10 type vlan id 10
ip link add link eth0 name eth0.20 type vlan id 20

# Назначить IP
ip addr add 192.168.1.1/24 dev eth0.10
ip addr add 10.0.0.1/24 dev eth0.20

# Поднять интерфейсы
ip link set eth0.10 up
ip link set eth0.20 up

# NAT для выхода в интернет (опционально)
iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
```
