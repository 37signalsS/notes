# Формат кадра 802.1Q и тегирование VLAN

## Definitions

**IEEE 802.1Q** — стандарт канального уровня (L2), определяющий процедуру добавления 4-байтового тега в Ethernet-кадр для принадлежности к VLAN.

**VLAN tag** — 4-байтовый заголовок, вставляемый между полями Src MAC и EtherType/Length стандартного Ethernet-кадра. Содержит информацию о VLAN ID и приоритете.

**Терминация** — процесс удаления VLAN-тега из кадра перед отправкой нетегированному конечному устройству (access-порт).

## Basic Concepts

### Структура кадра 802.1Q

Стандартный Ethernet-кадр модифицируется добавлением 4-байтового тега:

```
| Dest MAC (6) | Src MAC (6) | TPID 0x8100 (2) | TCI (2) | EtherType (2) | Data (46-1500) | FCS (4) |
```

Поля тега:

| Поле | Размер | Описание |
|------|--------|----------|
| **TPID (Tag Protocol Identifier)** | 2 байта | `0x8100` — указывает на тегированный кадр. Размещается на месте поля Тип/Длина стандартного Ethernet-кадра, позволяет принимающей стороне определить заголовок 802.1Q |
| **TCI (Tag Control Information)** | 2 байта | Управляющая информация, включает PCP, DEI, VID |
| &nbsp;&nbsp;— PCP (Priority Code Point) | 3 бита | Приоритет для [QoS](../../Concepts/qos.md) (0–7) по IEEE 802.1p; 0 — наименьший, 7 — наивысший |
| &nbsp;&nbsp;— DEI (Drop Eligible Indicator) | 1 бит | Индикатор допустимости отбрасывания при перегрузке |
| &nbsp;&nbsp;— VID (VLAN Identifier) | 12 бит | ID VLAN (1–4094; 0 и 4095 зарезервированы) |

**Ключевая особенность:** Поле VID позволяет прямо в кадре передать информацию о принадлежности к конкретному VLAN.

**MTU:** Тег увеличивает максимальный размер кадра с 1518 до 1522 байт.

### Принцип тегирования

1. **Вход кадра:** Кадр от конечного устройства поступает на access-порт коммутатора
2. **Добавление тега:** Коммутатор добавляет 4-байтовый тег с VLAN ID
3. **Передача по trunk:** Тегированный кадр передаётся другому коммутатору
4. **Чтение тега:** Принимающий коммутатор читает VID и направляет кадр в соответствующий VLAN
5. **Терминация:** Перед отправкой конечному устройству тег удаляется

## Practical Scenarios

### Передача пакета через trunk-соединение

**Топология:**

```
[Хост 1] --(Access, VLAN 10)--> [Коммутатор 1] <==Trunk==> [Коммутатор 2] --(Access, VLAN 10)--> [Хост 2]
```

Процесс передачи пакета от хоста 1 к хосту 2:

1. **Коммутатор 1 получает пакет** от хоста 1, определяет VLAN ID = 10 по настройке access-порта
2. **Коммутация внутри VLAN 10:** Пакет коммутируется только в порты VLAN 10; по таблице MAC-адресов отправляется в порт к коммутатору 2
3. **Добавление тега:** Trunk-порт добавляет тег 802.1Q с VID = 10
4. **Коммутатор 2 получает пакет** на trunk-порт, извлекает VID = 10, коммутирует только в порты VLAN 10
5. **Терминация:** Access-порт хоста 2 удаляет тег перед отправкой пакета

**Конфигурация (Cisco):**

```cisco
interface GigabitEthernet0/1
 switchport mode access
 switchport access vlan 10

interface GigabitEthernet0/24
 switchport mode trunk
 switchport trunk allowed vlan 10,20
```

## Additional Information

### Расширения стандарта

| Стандарт | Описание |
|----------|----------|
