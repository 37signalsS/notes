# Формат кадра 802.1Q и тегирование VLAN

## Определения

**IEEE 802.1Q** — отраслевой стандарт канального уровня (L2), определяющий метод инкапсуляции (тегирования) Ethernet-кадров для их разделения на логические сети (VLAN).

**VLAN tag (тег)** — 4-байтовый заголовок, вставляемый в Ethernet-кадр. Позволяет передавать информацию о VLAN ID и приоритете трафика (CoS) по магистральным каналам (Trunk).

**Терминация (Untagging)** — процесс удаления VLAN-тега из кадра перед его отправкой на устройство, не поддерживающее тегирование (например, на access-порт коммутатора).

**Reliability Score:** 10 (SSoT + IEEE Standard verified)

## Базовые концепции

### Структура кадра 802.1Q

Стандартный Ethernet II кадр модифицируется путем вставки 4-байтового тега между полем **Source MAC** и полем **EtherType/Length**.

**Схема кадра:**

```text
| Dest MAC (6) | Src MAC (6) | TPID (2) | TCI (2) | EtherType (2) | Data (46-1500) | FCS (4) |
                              └────────┬─────────┘
                                   VLAN Tag
```

#### Поля тега (VLAN Tag)

| Поле | Размер | Описание |
| :--- | :--- | :--- |
| **TPID (Tag Protocol Identifier)** | 16 бит | Идентификатор протокола тегирования. Стандартное значение — `0x8100`. |
| **TCI (Tag Control Information)** | 16 бит | Управляющая информация, состоящая из трех подполей (PCP, DEI, VID). |

**Детальная структура TCI (16 бит):**

| Подполе | Биты | Описание |
| :--- | :--- | :--- |
| **PCP** (Priority Code Point) | 3 бита | Определяет приоритет кадра (0–7) согласно **IEEE 802.1p**. Используется для [QoS](../../Concepts/qos.md). |
| **DEI** (Drop Eligible Indicator) | 1 бит | Индикатор допустимости отбрасывания. При перегрузке сети кадры с DEI=1 отбрасываются первыми. |
| **VID** (VLAN Identifier) | 12 бит | Идентификатор VLAN. Указывает, какой сети принадлежит кадр. |

#### Идентификаторы VLAN (VID)

Диапазон VID составляет 12 бит (0–4095).

| VID | Статус | Описание |
| :--- | :--- | :--- |
| **0** | Зарезервирован | Используется для кадров, содержащих только приоритет (PCP), без привязки к конкретному VLAN (Priority Tagging). |
| **1** | Default | Стандартный VLAN по умолчанию на большинстве оборудования. Часто используется как Native VLAN. |
| **2–4094** | User-defined | Доступные для настройки пользовательские VLAN. |
| **4095** | Зарезервирован | Зарезервирован для системных целей (часто используется как wildcard в фильтрах). |

### Влияние на размер кадра (MTU)

Добавление тега увеличивает размер Ethernet-кадра на 4 байта.

- **Standard Ethernet:** 1518 байт (без учета преамбулы).
- **802.1Q Tagged:** 1522 байта (**Baby Giant Frame**).

Большинство современных сетевых карт (NIC) и коммутаторов автоматически поддерживают кадры размером 1522 байта (MRU — Maximum Receive Unit). Однако на устаревшем оборудовании может потребоваться ручное увеличение MTU до 1504/1508 байт или включение поддержки Jumbo Frames.

### Типы TPID

Хотя `0x8100` является стандартным, существуют и другие значения для специальных случаев:

- **0x8100:** Стандартный тег 802.1Q (C-tag — Customer Tag).
- **0x88a8:** Тег 802.1ad (S-tag — Service Tag) для технологий Q-in-Q.
- **0x9100 / 0x9200:** Устаревшие или вендор-специфичные значения (например, старые коммутаторы Juniper или Riverstone).

## Практические сценарии

### Алгоритм прохождения кадра через коммутатор

1. **Ingress (Вход):** Кадр поступает на access-порт (VLAN 10). Коммутатор "навешивает" тег с VID 10.
2. **Switching:** Коммутатор ищет порт назначения в своей таблице MAC-адресов, ограниченной рамками VLAN 10.
3. **Egress (Выход) через Trunk:** Если выходной порт является магистральным (trunk), кадр отправляется с тегом `VID=10`.
4. **Egress (Выход) через Access:** Если выходной порт — access-порт VLAN 10, коммутатор удаляет тег (терминирует) и передает чистый Ethernet-кадр конечному устройству.

### Инспекция тегов с помощью tcpdump

Для ручной проверки полей 802.1Q можно использовать `tcpdump` с выводом в шестнадцатеричном формате.

```bash
# Захват кадров с выводом Ethernet-заголовков (-e) и данных в HEX (-X)
sudo tcpdump -i eth0 -nn -e -c 1 vlan 10
```

**Пример разбора вывода:**
```text
10:00:01.123 ethertype 802.1Q (0x8100), length 64: vlan 10, p 7, ethertype IPv4, ...
0x0000:  0015 5d01 0203 0015 5d01 0204 8100 e00a 0800 ...
                                       ^    ^    ^
                                       |    |    EtherType (IPv4)
                                       |    TCI (PCP=7, DEI=0, VID=10 -> 0xe00a)
                                       TPID (802.1Q)
```

## Дополнительная информация

### Сравнение с QinQ (802.1ad)

При использовании **Q-in-Q** в кадр добавляется второй тег. Это увеличивает размер кадра еще на 4 байта (итого 1526 байт).

| Структура | Описание |
| :--- | :--- |
| `[S-Tag][C-Tag][Data]` | Два последовательных тега 802.1Q. |

Подробнее см.: **[VLAN — обзор](../vlan.md#qinq-vlan-stacking--double-tagging)**.
