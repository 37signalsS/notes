# HTTP: Базовые концепции

## Определения

HTTP (Hypertext Transfer Protocol) — протокол передачи гипертекста, который является основой Всемирной паутины (World Wide Web). Он определяет правила, по которым веб-клиенты (например, браузеры) и веб-серверы взаимодействуют для обмена информацией.

## Базовые концепции

### Модель "Запрос-Ответ"

Протокол HTTP работает по модели "запрос-ответ":

* **Клиент** (веб-браузер) отправляет запрос на сервер.
* **Сервер** обрабатывает запрос и отправляет ответ.

Сервер не может инициировать взаимодействие. HTTP использует протокол [TCP](../TCP/overview.md) на транспортном уровне, что гарантирует надежную доставку. Веб-серверы обычно используют порт **80** для HTTP и **443** для HTTPS.

### Stateless-протокол (Протокол без сохранения состояния)

**HTTP является stateless-протоколом.** Это означает, что сервер не хранит никакой информации о предыдущих запросах от клиента. Каждый запрос рассматривается как независимая транзакция и должен содержать всю информацию, необходимую для его выполнения.

* **Преимущества:**
  * **Масштабируемость:** Любой сервер в кластере может обработать запрос клиента, так как нет привязки к состоянию сессии на конкретном сервере. Это упрощает горизонтальное масштабирование.
  * **Надежность:** Отказ одного сервера не влияет на сессию пользователя, так как следующий запрос может быть успешно обработан другим сервером.
  * **Простота:** Отсутствие управления состоянием упрощает дизайн сервера.

* **Недостатки:**
  * **Избыточность:** Клиенту может потребоваться отправлять повторяющуюся информацию (например, данные аутентификации) с каждым запросом.

Для обхода этого ограничения и создания "сессий" используются такие механизмы, как [Cookies](http_authentication.md#cookies) или токены в заголовках (`Authorization`).

### Структура HTTP-сообщения

**Минимальный HTTP-запрос (HTTP/1.1)**

1. **Стартовая строка (Request Line):** `GET / HTTP/1.1` (Метод, URI, Версия).
2. **Заголовок `Host`:** `Host: example.com` (Обязателен в HTTP/1.1).
3. **Пустая строка (CRLF):** Сигнал окончания заголовков.

**Минимальный HTTP-ответ (HTTP/1.1)**

1. **Строка состояния (Status Line):** `HTTP/1.1 200 OK` (Версия, Код, Пояснение).
2. **Заголовки:** `Content-Length: 1234` (Обязателен для ответа с телом).
3. **Пустая строка (CRLF):** Разделяет заголовки и тело.
4. **Тело ответа (Response Body):** Сами данные.
