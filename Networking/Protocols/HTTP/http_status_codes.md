# HTTP Коды ответа

## Категории кодов ответа HTTP

| Код | Категория | Описание |
|---|---|---|
| 100 | Информационный | Continue - продолжить запрос |
| 101 | Информационный | Switching Protocols - смена протокола |
| 102 | Информационный | Processing - запрос обрабатывается |
| 103 | Информационный | Early Hints - предварительные подсказки |
| 200 | Успешный | OK - успешный запрос |
| 201 | Успешный | Created - ресурс создан |
| 202 | Успешный | Accepted - запрос принят |
| 204 | Успешный | No Content - нет содержимого |
| 206 | Успешный | Partial Content - частичное содержимое |
| 301 | Перенаправление | Moved Permanently - постоянное перенаправление |
| 302 | Перенаправление | Found - временное перенаправление |
| 304 | Перенаправление | Not Modified - ресурс не изменён |
| 307 | Перенаправление | Temporary Redirect - временное без изменения метода |
| 308 | Перенаправление | Permanent Redirect - постоянное без изменения метода |
| 400 | Ошибка клиента | Bad Request - плохой запрос |
| 401 | Ошибка клиента | Unauthorized - неавторизован |
| 403 | Ошибка клиента | Forbidden - доступ запрещён |
| 404 | Ошибка клиента | Not Found - не найдено |
| 405 | Ошибка клиента | Method Not Allowed - метод не поддерживается |
| 429 | Ошибка клиента | Too Many Requests - слишком много запросов |
| 500 | Ошибка сервера | Internal Server Error - внутренняя ошибка |
| 502 | Ошибка сервера | Bad Gateway - плохой шлюз |
| 503 | Ошибка сервера | Service Unavailable - служба недоступна |
| 504 | Ошибка сервера | Gateway Timeout - таймаут шлюза |

## Категории кодов

### 1xx — Информационные
Запрос получен, продолжается обработка.

### 2xx — Успешные
Запрос успешно получен, понят и обработан.

### 3xx — Перенаправления
Требуется дополнительное действие для завершения запроса.

### 4xx — Ошибки клиента
Ошибка по вине клиента (неверный запрос, отсутствие прав).

### 5xx — Ошибки сервера
Сервер не смог выполнить корректный запрос по своей вине.
