# BGP (Border Gateway Protocol): Обзор

## Определения

**BGP (Border Gateway Protocol)** — это основной протокол внешнего шлюза (EGP), используемый для маршрутизации в сети Интернет. Он отвечает за обмен информацией о доступности маршрутов между автономными системами (AS).

**Автономная система (AS)** — это группа IP-сетей, управляемых одним или несколькими операторами связи, имеющая единую и четко определенную политику маршрутизации. Каждая AS имеет уникальный номер (ASN).

## Базовые концепции

### Типы BGP

BGP бывает двух основных типов в зависимости от того, между какими автономными системами устанавливается пиринг:

*   **eBGP (external BGP)**: Используется для маршрутизации между различными автономными системами. Это основной механизм обмена маршрутной информацией между интернет-провайдерами и крупными организациями.
*   **iBGP (internal BGP)**: Работает внутри одной автономной системы, передавая BGP-маршруты между маршрутизаторами в этой сети. Это позволяет обеспечить согласованность маршрутной информации внутри AS.

### Атрибуты BGP (Constants)

BGP использует множество атрибутов для выбора наилучшего пути к целевой сети. Наиболее важные из них включают:

*   **Local Preference**: Приоритетный маршрут внутри AS. Чем выше значение, тем более предпочтителен маршрут.
*   **AS Path**: Список автономных систем, через которые проходит маршрут. Более короткий путь обычно предпочтительнее.
*   **MED (Multi-Exit Discriminator)**: Подсказка соседней AS о предпочтительном точке входа в текущую AS. Меньшее значение MED обычно предпочтительнее.
*   **Origin**: Указывает источник маршрута (например, из IGP, EGP или неполный). Порядок предпочтения: IGP < EGP < Incomplete.
*   **Community**: Дополнительные метки, используемые для упрощения политики маршрутизации и обмена информацией между BGP-соседями.
*   **Weight** (только Cisco): Локальный параметр, используемый для выбора лучшего маршрута, если доступно несколько путей к одной цели. Чем больше значение, тем лучше (влияет только на локальный маршрутизатор).

## Практические сценарии

### Платформы для BGP-пирингов

BGP-пиринги могут быть настроены как на аппаратных, так и на программных решениях:

#### Аппаратные маршрутизаторы

*   **Cisco (IOS, IOS-XE, IOS-XR, NX-OS)**: Классическое решение для крупных сетей и провайдеров.
*   **Juniper (Junos OS)**: Мощное решение, часто используемое в дата-центрах и сетях операторов связи.
*   **Arista (EOS)**: Высокопроизводительные маршрутизаторы для центров обработки данных.
*   **Huawei (VRP)**: Популярно в крупных корпоративных сетях, особенно в Азии.

#### Программные решения (Soft-router)

*   **FRRouting (FRR)**: Open-source пакет маршрутизации, поддерживающий BGP, OSPF, IS-IS и другие протоколы. Широко используется.
*   **BIRD**: Легковесный BGP-демон для Linux, часто используемый в точках обмена трафиком (IXP).
*   **GoBGP**: BGP-демон, написанный на Go, с акцентом на производительность и масштабируемость.
*   **VyOS**: Операционная система на базе Linux, предоставляющая функционал маршрутизатора с поддержкой BGP.
*   **MikroTik (RouterOS)**: Бюджетное, но функциональное решение, популярное для малых и средних сетей.
