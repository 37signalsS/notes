### Транспортный уровень (L4)

#### TCP-handshake (тройное рукопожатие)

Установка TCP-соединения — это процесс, который гарантирует, что обе стороны готовы к обмену данными.

1.  **Шаг 1: `SYN` (Synchronize)**
    *   **Кто:** Клиент отправляет серверу.
    *   **Что происходит:** Клиент инициирует соединение, отправляя сегмент с флагом `SYN`. В этом сегменте он также передаёт свой начальный порядковый номер (`Sequence Number`, `seq=x`), который является случайным числом. Этот номер нужен для отслеживания потока данных.

2.  **Шаг 2: `SYN-ACK` (Synchronize-Acknowledgment)**
    *   **Кто:** Сервер отвечает клиенту.
    *   **Что происходит:** Если сервер готов принять соединение, он отправляет сегмент с двумя флагами:
        *   `SYN`: Сервер передаёт свой собственный начальный порядковый номер (`seq=y`).
        *   `ACK`: Сервер подтверждает получение пакета от клиента, увеличивая его порядковый номер на единицу (`Acknowledgment Number`, `ack=x+1`).

3.  **Шаг 3: `ACK` (Acknowledgment)**
    *   **Кто:** Клиент отправляет серверу.
    *   **Что происходит:** Клиент подтверждает получение `SYN-ACK` от сервера. Он отправляет сегмент с флагом `ACK`, в котором номер подтверждения равен порядковому номеру сервера + 1 (`ack=y+1`).

После этого шага соединение считается установленным, и обе стороны могут начать передачу данных.

**Схематично это выглядит так:**

```text
   Клиент                                     Сервер
     |                                            |
     |  SYN (seq=x) ----------------------------> |
     |                                            |
     |  <---------------------------- SYN-ACK (seq=y, ack=x+1)
     |                                            |
     |  ACK (seq=x+1, ack=y+1) -----------------> |
     |                                            |
```

#### Наблюдение в Wireshark

При анализе трафика в Wireshark или с помощью `tcpdump` шаги рукопожатия легко отслеживаются по TCP-флагам, которые отображаются в квадратных скобках:

*   **`[S]`**: Пакет `SYN` от клиента.
*   **`[S.]`**: Пакет `SYN-ACK` от сервера (точка `.` обозначает ACK).
*   **`[.]`**: Пакет `ACK` от клиента.

После этого начинается обмен данными, который обычно имеет флаг `[P]` (PSH/Push) вместе с `[.]` (ACK).

Если соединение не может быть установлено (например, порт закрыт), сервер отвечает пакетом с флагом **`[RST]`** (Reset), немедленно сбрасывая попытку подключения. Это также видно в Wireshark и является явным индикатором того, что удаленный хост отклонил соединение.
