# Протокол DNS (Domain Name System)

## Определения

**DNS (Domain Name System)** — это распределенная система с повсеместным кэшированием, обеспечивающая её эффективность и отказоустойчивость. На уровне IP-протокола компьютеры идентифицируются по числовым IP-адресам (например, `192.0.2.1`). DNS служит "телефонной книгой" интернета, преобразуя доменные имена (например, `habr.com`) в IP-адреса и обратно.

* **Авторитетный (Authoritative Answer):** Ответ, полученный напрямую от DNS-сервера, ответственного за доменную зону. Считается точным и актуальным. Флаг `AA` установлен.
* **Неавторитетный (Non-Authoritative Answer):** Ответ, предоставленный DNS-резолвером из кэша. Быстрее, но может быть устаревшим (до истечения TTL).

**TTL (Time To Live)** — параметр в секундах, указывающий, как долго DNS-резолвер может кэшировать DNS-запись. По истечении этого времени резолвер обязан запросить "свежую" запись у авторитативного сервера.

### Типы DNS-серверов

* **Авторитативный DNS-сервер**: Отвечает исключительно за предоставление ответов для своих доменных зон. Не выполняет рекурсивные запросы к другим DNS-серверам и не кэширует их результаты.
* **Рекурсивный DNS-сервер (резолвер)**: Принимает рекурсивные запросы от клиентов и выполняет всю работу по поиску ответа, последовательно опрашивая другие DNS-серверы. Кэширует ответы для ускорения последующих запросов.

### Транспортные протоколы (UDP/TCP)

По умолчанию DNS использует **UDP/53** для скорости. **TCP/53** используется в следующих случаях:

1. **Ответ превышает 512 байт** (или лимит EDNS): сервер отправляет усеченный ответ (флаг **TC**), и клиент повторяет запрос через TCP.
2. **Трансфер зоны (AXFR/IXFR):** Синхронизация записей между master и slave серверами всегда идет через TCP.
3. **DNS over TLS (DoT):** Шифрование DNS-трафика происходит поверх TCP-соединения.

## Практические сценарии

### Конфигурация DNS-клиента

Настройка DNS-клиента в ОС (например, Linux) включает управление порядком и способом разрешения доменных имен. Основные способы: DHCP, ручная настройка (публичные DNS-серверы), локальные службы-резолверы.

Подробности настройки для Linux (включая `/etc/nsswitch.conf`, `/etc/hosts`, `/etc/resolv.conf`, `resolvectl`) см. в: [Настройка и диагностика DNS-клиента в Linux](../../../Linux/Networking/Concepts/dns_client.md).
