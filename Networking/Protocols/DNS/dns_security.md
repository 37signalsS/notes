# Безопасность DNS

## Определения

**DNSSEC (Domain Name System Security Extensions)** — расширение DNS, добавляющее криптографические подписи для проверки подлинности и целостности ответов. Защищает от атак типа "отравление кэша".

**DoH (DNS over HTTPS)** — протокол шифрования DNS-трафика через HTTPS (порт 443). DNS-запросы маскируются под обычный веб-трафик.

**DoT (DNS over TLS)** — протокол шифрования DNS-трафика через TLS (порт 853). Выделенный порт для защищённых DNS-запросов.

**Cache Poisoning (Отравление кэша)** — атака, при которой злоумышленник внедряет поддельные DNS-записи в кэш резолвера, перенаправляя пользователей на фишинговые сайты.

## Основные концепции

### Проблемы безопасности стандартного DNS

| Уязвимость | Описание | Риск |
|------------|----------|------|
| **Передача в открытом виде** | DNS-запросы/ответы не шифруются | Перехват, анализ, модификация (MitM) |
| **Отравление кэша** | Поддельные ответы кэшируются резолвером | Массовое перенаправление на фишинговые сайты |
| **DNS-туннелирование** | Передача данных через DNS-запросы | Утечка данных, обход файрволов |
| **DDoS-атаки** | Флуд DNS-серверов запросами | Отказ в обслуживании |

### Защищённые версии DNS

| Протокол | Порт | Преимущества | Недостатки |
|----------|------|--------------|------------|
| **DNSSEC** | 53 (UDP/TCP) | Проверка подлинности, защита от подмены | Не шифрует трафик, сложная настройка |
| **DoH** | 443 (HTTPS) | Шифрование, маскировка под веб-трафик | Сложнее мониторинг, блокировка |
| **DoT** | 853 (TLS) | Шифрование, выделенный порт | Видимость факта использования DNS |

## Практические сценарии

### Включение DNSSEC

Для проверки поддержки DNSSEC доменом:

```bash
dig +dnssec example.com
# Наличие записей RRSIG в ответе означает поддержку DNSSEC
```

Для включения валидации на резолвере (BIND):

```conf
options {
    dnssec-validation auto;
};
```

### Настройка DoH/DoT клиента

**systemd-resolved (DoT):**

```ini
# /etc/systemd/resolved.conf
[Resolve]
DNS=1.1.1.1
DNSOverTLS=yes
```

### Диагностика DNSSEC

```bash
# Проверка цепочки доверия
delv example.com

# Проверка подписей
dig +multi +noall +answer DNSKEY example.com
dig +multi +noall +answer DS example.com
```
