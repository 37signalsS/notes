# Checksum (Контрольная сумма) в TCP

## Определения

**Checksum** — механизм контроля целостности данных в TCP.

**Назначение:** обнаружение ошибок в заголовке и данных.

## Особенности TCP Checksum

* **Обязательно для TCP** (в отличие от UDP, где опционально в IPv4)
* Включает **pseudo-header** (IP-адреса, протокол, длина)
* Если ошибка — сегмент отбрасывается без ACK
* Вычисляется отправителем, проверяется получателем

## Pseudo-header

**Назначение:** защита от неправильной доставки (не тот адрес/порт).

**Структура pseudo-header (IPv4):**

```
 0      7 8     15 16    23 24    31
+--------+--------+--------+--------+
|          Source Address           |
+--------+--------+--------+--------+
|        Destination Address        |
+--------+--------+--------+--------+
|  Zero  |Protocol|       Length    |
+--------+--------+--------+--------+
```

**Поля:**

| Поле | Размер | Описание |
| :--- | :--- | :--- |
| Source Address | 32 бита | IP-адрес отправителя |
| Destination Address | 32 бита | IP-адрес получателя |
| Zero | 8 бит | Нули (зарезервировано) |
| Protocol | 8 бит | Номер протокола (6 для TCP) |
| Length | 16 бит | Длина TCP-сегмента (заголовок + данные) |

**Важно:** pseudo-header используется только для вычисления checksum, не передается в сети.

## Алгоритм вычисления

### Отправитель

1. Обнулить поле checksum в заголовке TCP
2. Добавить pseudo-header
3. Добавить TCP-заголовок и данные
4. Дополнить нулями до границы 16 бит (если нечетное количество)
5. Разбить на 16-битные слова
6. Сложить все слова с переносом (one's complement sum)
7. Инвертировать результат (one's complement)
8. Записать в поле checksum

### Получатель

1. Добавить pseudo-header
2. Добавить TCP-заголовок и данные
3. Разбить на 16-битные слова
4. Сложить все слова с переносом
5. Инвертировать результат
6. Если результат 0xFFFF — ошибок нет, иначе — ошибка

## Обработка ошибок

**При обнаружении ошибки:**

1. Сегмент отбрасывается без ACK
2. Отправитель не получает подтверждение
3. Срабатывает тайм-аут (RTO)
4. Происходит **ретрансмиссия**

**Подробнее:** [Retransmission](./retransmission.md)

## Проверка checksum

```bash
# Проверка через tcpdump
tcpdump -i eth0 -nn 'tcp' -v

# Пример вывода с ошибкой checksum:
# IP (tos 0x0, ttl 64, id 12345, offset 0, flags [DF], proto TCP (6), length 60)
#     192.168.1.10.54321 > 93.184.216.34.80: Flags [S], cksum 0x1234 (incorrect -> 0x5678), ...
```

**Примечание:** некоторые сетевые карты выносят вычисление checksum на аппаратный уровень (checksum offload), что может приводить к отображению неверных checksum в tcpdump.

## Offload

**Checksum Offload** — вычисление checksum на сетевой карте (NIC).

**Преимущества:**

* Снижение нагрузки на CPU
* Увеличение пропускной способности

**Проверка:**

```bash
ethtool -k eth0 | grep checksum
```

**Отключение (для отладки):**

```bash
ethtool -K eth0 tx-checksumming off rx-checksumming off
```
