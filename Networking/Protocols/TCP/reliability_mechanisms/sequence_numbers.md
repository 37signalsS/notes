# Sequence Numbers в TCP

## Определения

**Sequence Numbers** — механизм нумерации байт в TCP для обеспечения упорядоченной доставки данных.

**Принцип:** TCP нумерует **байты**, а не сегменты.

## Initial Sequence Number (ISN)

**ISN (Initial Sequence Number)** — случайное 32-битное число, выбираемое при установке соединения.

**Назначение:**

* Защищает от старых дубликатов сегментов
* Усложняет предсказание последовательности (защита от spoofing)
* Обменивается в [handshake](./connection/connection_management.md#установка-соединения-tcp-handshake)

**Пример установки соединения:**

```
Отправитель                         Получатель
     |                                    |
     |  SYN, seq=1000 ------------------> |  ISN клиента = 1000
     |  <---------------- SYN, seq=2000 --|  ISN сервера = 2000
     |  ACK, ack=2001 ------------------> |  Ожидается байт 2001
     |                                    |
```

## Назначение Sequence Numbers

### 1. Восстановление порядка (Reordering)

Пакеты могут приходить не по порядку из-за маршрутизации. Sequence Numbers позволяют получателю восстановить правильный порядок.

```
Отправлено: [1-1000] [1001-2000] [2001-3000]
Получено:   [1-1000] [2001-3000] [1001-2000]  (перепутаны)
Действие:   буферизация [2001-3000], ожидание [1001-2000]
Результат:  передача приложению в порядке [1-1000][1001-2000][2001-3000]
```

### 2. Обнаружение дубликатов

Если сегмент с теми же Sequence Numbers уже получен, дубликат отбрасывается.

```
Отправлено: [1-1000]
Получено:   [1-1000] (первый раз) → принят
Получено:   [1-1000] (второй раз) → отброшен (дубликат)
```

### 3. Точное подтверждение полученных данных

ACK указывает следующий ожидаемый байт, что позволяет точно подтвердить полученные данные.

```
Отправлено: [1001-2000] [2001-3000]
Получено:   [1001-2000] [2001-3000] (все)
ACK:        ack=3001 (ожидается байт 3001)
```

## Пример передачи данных

```
Отправитель                         Получатель
     |                                    |
     |  Данные [1001-2000], seq=1001 ---> |  Байты 1001-2000
     |  Данные [2001-3000], seq=2001 ---> |  Байты 2001-3000
     |  <---------------- ACK, ack=3001 --|  Ожидается байт 3001
```

## 32-битное пространство

**Размер:** 2^32 = 4 294 967 296 байт (~4 ГБ)

**Проблема:** при высокой пропускной способности Sequence Numbers могут «завернуться».

**Решение:** опция **Timestamps** (RFC 7323) для защиты от старых дубликатов.
