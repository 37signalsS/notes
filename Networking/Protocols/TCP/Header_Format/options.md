# Опции TCP и ECN

## Определения

**Опции TCP** — дополнительные поля заголовка для расширения функциональности (MSS, Window Scale, SACK, Timestamps).

**ECN (Explicit Congestion Notification)** — явное уведомление о перегрузке без потери пакетов.

> **Навигация:** [Главная Header Format](./index.md) | [Практика](./practical.md)

---

## Basic Concepts

### Опции (Options)

Опции выравниваются по 32-битной границе (добавляются PAD-байты).

#### Максимальный размер сегмента (Maximum Segment Size, MSS)

| Параметр | Значение |
| :--- | :--- |
| **Kind** | 2 |
| **Длина** | 4 байта |
| **Использование** | Только в SYN-пакетах handshake |

**Расчет:**

```
MSS = MTU - IP Header - TCP Header
MSS = 1500 - 20 - 20 = 1460 байт (стандартный Ethernet)
```

**Важно:** MSS не включает заголовки — только данные.

---

#### Масштаб окна (Window Scale)

| Параметр | Значение |
| :--- | :--- |
| **Kind** | 3 |
| **Длина** | 3 байта |
| **Shift** | 0–14 бит |

**Назначение:** увеличение окна beyond 64 КБ

**Формула:**

```
Реальное окно = Window Size × 2^Shift
Максимум: 65535 × 2^14 ≈ 1 ГБ
```

**Использование:** только в SYN-пакетах. Обе стороны должны поддержать опцию.

**Проблема без Window Scale:**

- При RTT = 100 мс и окне 64 КБ максимальная пропускная способность:

  ```
  64 КБ / 0.1 с = 640 КБ/с ≈ 5 Мбит/с
  ```

- Для каналов >100 Мбит/с требуется window scaling.

---

#### Выборочное подтверждение (Selective Acknowledgment, SACK)

| Параметр | Значение |
| :--- | :--- |
| **Kind (SACK permitted)** | 4 |
| **Kind (SACK)** | 5 |
| **Длина** | Переменная |

**Назначение:** подтверждение отдельных блоков данных при потере сегментов

**Проблема без SACK:**

```
Отправлено: [1-1000] [1001-2000] [2001-3000] [3001-4000]
Потерян: [1001-2000]
Без SACK: ACK = 1001 (кумулятивно), отправитель не знает о полученных 2001-4000
С SACK: ACK = 1001 + SACK blocks: [2001-4000]
```

**Эффект:** отправитель ретранслирует только потерянный сегмент.

См. также: [Механизмы надежности](./reliability_mechanisms.md#выборочное-подтверждение-sack)

---

#### Метки времени (Timestamps)

| Параметр | Значение |
| :--- | :--- |
| **Kind** | 8 |
| **Длина** | 10 байт |
| **Поля** | TSval (4 байта), TSecr (4 байта) |

**Назначение:**

- Точное измерение **RTT (Round-Trip Time)**
- Защита от старых дубликатов (**PAWS — Protection Against Wrapped Sequence numbers**)

**Использование:**

- Каждый сегмент содержит текущую метку (TSval)
- ACK содержит эхо метки (TSecr)
- RTT = текущее время - TSecr

---

### ECN (Explicit Congestion Notification)

**Механизм:** явное уведомление о перегрузке без потери пакетов

**Флаги:**

- **ECE (ECN-Echo):** получатель сообщает о перегрузке
- **CWR (Congestion Window Reduced):** отправитель подтверждает уменьшение окна

**Преимущество:** снижение перегрузки до потери пакетов.

Требует поддержки обоими узлами и маршрутизаторами.
