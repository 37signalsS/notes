# SMTP: Simple Mail Transfer Protocol

## 1. Определения

**SMTP (Simple Mail Transfer Protocol)** — протокол прикладного уровня, предназначенный для передачи электронной почты в сетях TCP/IP.

**Ключевые характеристики:**

- Использует [TCP](../Protocols/TCP/overview.md) в качестве транспортного протокола.
- Стандартные порты:
    - **25** — основной порт для обмена почтой между серверами (MTA to MTA).
    - **465** — SMTPS (SMTP over SSL), устаревший, но всё ещё используемый.
    - **587** — Submission порт для отправки почты клиентами (MUA to MSA) с использованием STARTTLS.
- Работает на текстовых командах (`HELO`, `MAIL FROM`, `RCPT TO`, `DATA`, `QUIT`).

## 2. Основные концепции

### Сценарий доставки сообщения через SMTP

Процесс доставки почты включает несколько ключевых этапов и ролей:

1. **Отправка (MUA → MSA):** Пользователь нажимает «Отправить» в почтовом клиенте (**MUA** — Mail User Agent, например, Outlook или Thunderbird). Клиент подключается к **MSA** (Mail Submission Agent) своего почтового провайдера по порту 587.
2. **Маршрутизация (MSA → MTA):** Сервер провайдера проверяет права отправителя и передаёт письмо на свой **MTA** (Mail Transfer Agent).
3. **Передача между серверами (MTA → MTA):** MTA отправителя определяет адрес MTA получателя через [DNS (MX-записи)](./DNS/dns_records.md). Между серверами устанавливается SMTP-соединение по порту 25, и письмо пересылается.
4. **Приём и локальная доставка (MTA → MDA):** MTA получателя принимает письмо и передаёт его **MDA** (Mail Delivery Agent), который сохраняет его в почтовый ящик пользователя на диске.
5. **Чтение (MDA → MUA):** Получатель забирает письмо из ящика с помощью своего клиента (MUA) по протоколам [POP3 или IMAP](../../Anki/linux_cards.csv) (SMTP не используется для получения почты клиентом).

## 3. Практические сценарии

### Тестирование SMTP через telnet

```bash
telnet smtp.example.com 25
# → 220 smtp.example.com ESMTP
HELO client.example.com
# → 250 Hello
MAIL FROM:<sender@example.com>
# → 250 OK
RCPT TO:<recipient@example.com>
# → 250 OK
DATA
# → 354 End data with <CR><LF>.<CR><LF>
Subject: Test email
Hello, this is a test!
.
# → 250 OK: queued as 12345
QUIT
# → 221 Bye
```

## 4. Дополнительная информация

- **STARTTLS:** Механизм обновления открытого соединения до шифрованного (TLS).
- **Безопасность:** Для предотвращения спама и подделки адресов используются механизмы SPF, DKIM и DMARC. Подробнее: **[Безопасность почты](../../Zabbix/zabbix_best_practices.md)**.
