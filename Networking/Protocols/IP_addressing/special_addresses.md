# Специальные и частные IP-адреса

## IANA (Internet Assigned Numbers Authority)

**IANA** — организация, отвечающая за распределение IP-адресов и поддержку стандартов IPv4/IPv6. IANA выделяет диапазоны адресов региональным регистратурам (RIR), а также резервирует специальные диапазоны для конкретных целей.

Все специальные диапазоны адресов документированы в **RFC** (Request for Comments) — стандартах интернета.

## Специальные IP-адреса

| Адрес / Диапазон | Название | Описание и назначение |
| :--- | :--- | :--- |
| **`127.0.0.1`** | **Loopback / localhost** | Адрес "для себя", всегда указывающий на собственный компьютер. Трафик на `127.0.0.1` не покидает пределы машины. Полная сеть loopback: `127.0.0.0/8`. Подробнее: [Сетевые интерфейсы в Linux](../../Linux/Networking/Concepts/linux_network_interfaces.md#2-виртуальные-интерфейсы). |
| **`0.0.0.0`** | **Unspecified Address** | Немаршрутизируемый мета-адрес для обозначения "любого" или "всех" IP-адресов. Используется серверами для приема соединений на всех сетевых интерфейсах. |
| **`0.0.0.0/8`** | **This network** | Используется только как адрес источника, когда устройство ещё не знает свой IP (например, при DHCP-запросе). |
| **`0.0.0.0/0`** | **Default Route** | Маршрут по умолчанию — используется для всех сетей, для которых нет явного маршрута. Подробнее: [Маршрутизация в Linux](../../Linux/SystemAdministration/routing.md#4-маршрут-по-умолчанию-default-gateway). |
| **`169.254.0.0/16`** | **Link-local (APIPA)** | Автоматическая конфигурация при отсутствии DHCP-сервера. Адреса назначаются случайно из этого диапазона. |

## Частные (приватные) сети (RFC 1918)

Эти диапазоны предназначены для локальных сетей (LAN) и не маршрутизируются в интернете. Для доступа в интернет с таких адресов используется [NAT](../Concepts/nat.md).

Также известны как **"серые IP-сети"** или **"серые IP-адреса"** — в отличие от "белых" (публичных) IP-адресов, используемых в интернете.

### Диапазоны частных сетей

| Диапазон | Класс | Количество хостов |
|----------|-------|-------------------|
| `10.0.0.0/8` (`10.0.0.0` - `10.255.255.255`) | A | ~16,7 млн |
| `172.16.0.0/12` (`172.16.0.0` - `172.31.255.255`) | B | ~1 млн |
| `192.168.0.0/16` (`192.168.0.0` - `192.168.255.255`) | C | ~65 тыс. |

### Особенности

- IP-адреса из этих сетей не могут быть использованы в сети Интернет напрямую
- Могут свободно использоваться в частных нуждах: дома, в офисе, кафе, гостиницах и т.д.
- Один и тот же частный IP (например, `192.168.1.1`) может одновременно использоваться миллионами устройств по всему миру за разными NAT
- При выходе в интернет частный IP подменяется на публичный IP маршрутизатора (NAT/masquerading)

## Другие зарезервированные диапазоны

### Адреса для документации и примеров (RFC 5737)

Используются в документации, примерах конфигураций и тестировании:

- `192.0.2.0/24` (TEST-NET-1)
- `198.51.100.0/24` (TEST-NET-2)
- `203.0.113.0/24` (TEST-NET-3)

### Многоадресная рассылка (Multicast)

**Диапазон:** `224.0.0.0/4` (`224.0.0.0` - `239.255.255.255`)

Используется для групповой рассылки пакетов нескольким получателям одновременно.

**Подробнее:** [MAC-адреса](../Concepts/mac_address.md#2-групповой-multicast)

### Carrier-Grade NAT (RFC 6598)

**Диапазон:** `100.64.0.0/10` (`100.64.0.0` - `100.127.255.255`)

Используется провайдерами для NAT на уровне оператора связи.
