# IP-адресация — Обзор

## Definitions

**IP-адрес (Internet Protocol Address)** — уникальный числовой идентификатор устройства в компьютерной сети, работающей по протоколу IP. Используется на [сетевом уровне (L3)](../../OSI_TCP_IP_Model/Network_layer/Concepts/network_layer_overview.md) для маршрутизации пакетов и доставки конечному узлу.

**Ключевая особенность:** В отличие от [MAC-адресов](../../Concepts/mac_address.md), которые жестко привязаны к физическому оборудованию, IP-адреса являются логическими и могут назначаться динамически.

## Basic Concepts

### Типы адресов в подсети

В рамках одной подсети существуют три фундаментальных типа адресов:

| Тип | Описание | Можно назначать устройствам |
|-----|----------|---------------------------|
| **Адрес сети (Network Address)** | Идентификатор всей сети или подсети. Используется маршрутизаторами для построения таблиц маршрутизации. Первый адрес в диапазоне с нулевыми битами в хостовой части. | ❌ Нет |
| **Адрес хоста (Host Address)** | Уникальный IP-адрес, назначенный сетевому интерфейсу конкретного устройства (компьютера, сервера, принтера). Рабочие адреса для обмена данными. | ✅ Да |
| **Широковещательный адрес (Broadcast Address)** | Специальный адрес для отправки сообщения **всем** устройствам в пределах одной подсети. Последний адрес в диапазоне с единичными битами в хостовой части. | ❌ Нет |

### Версии протокола

### IPv4

- **Длина адреса:** 4 байта (32 бита)
- **Формат записи:** Четыре октета, разделённых точкой (например, `192.168.1.10`)
- **Статус:** Наиболее распространенная версия, но адресное пространство практически исчерпано

### IPv6

- **Длина адреса:** 16 байт (128 бит)
- **Формат записи:** Восьмь групп по 4 шестнадцатеричных цифры, разделённых двоеточием
- **Статус:** Создана для решения проблемы нехватки IPv4-адресов

### Определение версии на канальном уровне

Информация о версии IP-протокола определяется на уровне заголовка Ethernet-кадра:

| Тип EtherType | Значение | Описание |
| :--- | :--- | :--- |
| **IPv4** | `0x0800` | Внутри Ethernet-кадра передается IPv4-пакет |
| **IPv6** | `0x86DD` | Внутри Ethernet-кадра передается IPv6-пакет |

**Вывод:** Поле `Version` в заголовке IP является избыточным, так как тип инкапсулированного протокола определяется в поле **EtherType/Length** заголовка Ethernet-кадра.

### Структура IPv4-адреса

Длина IPv4-адреса составляет 32 бита, или 4 байта. Для удобства работы с такими адресами их делят на четыре части по восемь бит. Каждая такая часть называется **октет**.

**Форма записи:** Четыре октета, разделённых точкой (например, `192.168.1.10`).

### Компоненты IP-адреса

IP-адрес логически делится на две части для обеспечения масштабируемости сетей:

1. **Номер подсети (Network ID):** Старшие биты, одинаковые для всех устройств в одной подсети. Маршрутизаторы оперируют именно этими адресами.
2. **Номер хоста (Host ID):** Младшие биты, уникальные для каждого устройства в пределах подсети.

### Маска подсети (Subnet Mask)

Маска подсети — это 32-битное число, которое используется для разделения IP-адреса на сетевую и хостовую части.

**Структура:** Единицы в маске соответствуют сетевой части адреса, нули — хостовой.

**Назначение:** Определить, какие биты в IP-адресе относятся к сети, а какие — к хосту.

#### Форматы записи маски

| Формат | Пример | Описание |
|--------|--------|----------|
| **Десятичный (Dotted-Decimal)** | `255.255.255.0` | Традиционная запись |
| **Префиксный (CIDR)** | `/24` | Современный формат. Число после слэша означает количество бит, отведенных под сетевую часть |

### Time To Live (TTL)

**Time To Live (TTL)** — 8-битный счётчик в заголовке IP-пакета, предотвращающий бесконечное "блуждание" пакетов в сети из-за петель маршрутизации.

**Механизм:** Каждый маршрутизатор уменьшает TTL на единицу. При достижении нуля пакет уничтожается, отправителю возвращается [ICMP Time Exceeded](../ICMP/icmp_time_exceeded.md).

## Practical Scenarios

### Диагностика сетевых маршрутов (traceroute)

Утилита `traceroute` использует TTL для обнаружения маршрутизаторов на пути пакета. Отправляются пакеты с TTL=1, TTL=2, TTL=3 и т.д. Каждый маршрутизатор, уменьшая TTL до нуля, возвращает ICMP Time Exceeded — так определяется его IP-адрес.

### Разделение сетей на подсети (subnetting)

При проектировании сети `192.168.1.0/24` можно разделить на несколько подсетей с помощью маски. Например, `/26` даёт 4 подсети по 62 хоста каждая. Подробный расчет: [Расчет подсетей](./subnetting_calculation.md).

### Изоляция тестовых сред

Частные диапазоны [RFC 1918](./special_addresses.md) (например, `10.0.0.0/8`) используются для внутренних сетей без выхода в интернет. Разные отделы компании могут использовать разные подсети (`10.1.0.0/16` — разработка, `10.2.0.0/16` — продакшн) с изоляцией через [firewall rules](../../Concepts/firewall_rules_best_practices.md).
