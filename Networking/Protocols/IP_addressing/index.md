# IP-адресация (Internet Protocol Addressing)

## Definitions

**IP-адрес (Internet Protocol Address)** — уникальный числовой идентификатор устройства в компьютерной сети, используемый для маршрутизации пакетов на сетевом уровне (L3).

**Ключевые особенности:**

- Логический адрес (в отличие от MAC-адреса)
- Может назначаться динамически
- Два основных стандарта: IPv4 (32 бита) и IPv6 (128 бит)

## Basic Concepts

### Типы адресов в подсети

- **Адрес сети (Network Address)** — идентификатор подсети, первый адрес в диапазоне с нулевыми битами в хостовой части. Нельзя назначать устройствам.
- **Адрес хоста (Host Address)** — уникальный адрес устройства в подсети.
- **Broadcast** — адрес для рассылки всем устройствам в подсети, последний адрес в диапазоне с единичными битами в хостовой части. Нельзя назначать устройствам.

### Маска подсети и CIDR

**Маска подсети (Subnet Mask)** — 32-битное число для разделения IP-адреса на сетевую и хостовую части. Единицы в маске соответствуют сетевой части, нули — хостовой.

**CIDR (Classless Inter-Domain Routing)** — бесклассовая адресация с записью маски в префиксном формате (например, `/24`).

### Специальные маски

- **`/32`** — хост-маршрут (конкретный IP-адрес)
- **`/31`** — point-to-point соединения (RFC 3021, оба адреса доступны)

## Practical Scenarios

### Расчет параметров подсети

Для определения адреса сети, broadcast и диапазона хостов используется операция логического И (AND) между IP-адресом и маской подсети.

**Пример:** IP `192.168.1.130/26`

- Адрес сети: `192.168.1.128`
- Broadcast: `192.168.1.191`
- Доступные хосты: `192.168.1.129` — `192.168.1.190` (62 адреса)

### Проверка принадлежности к одной сети

Два IP-адреса находятся в одной подсети, если после применения маски подсети к обоим адресам результат (адрес сети) совпадает.
