# IP-адресация

## Определения

**IP-адрес (Internet Protocol Address)** — уникальный числовой идентификатор устройства в компьютерной сети, используемый для маршрутизации пакетов на сетевом уровне (L3).

**Ключевые особенности:**

- **Логический адрес:** В отличие от физического MAC-адреса, IP-адрес является логическим и может изменяться.
- **Динамичность:** Может назначаться автоматически (через DHCP) или вручную.
- **Масштабируемость:** Позволяет объединять устройства в иерархические структуры (подсети).

## Основные концепции

### Версии IP-протокола

Существуют два актуальных стандарта адресации:

| Характеристика | IPv4 | IPv6 |
| :--- | :--- | :--- |
| **Размер адреса** | 32 бита (4 байта) | 128 бит (16 байт) |
| **Количество адресов** | ~4,3 млрд ($2^{32}$) | ~$3,4 \times 10^{38}$ ($2^{128}$) |
| **Формат записи** | Десятичный (например, `192.168.1.1`) | Шестнадцатеричный (например, `2001:db8::1`) |
| **Статус** | Дефицит адресов, использование NAT | Стандарт современного интернета |

Подробнее: **[Обзор IPv4](./ip_overview.md)** и **[Протокол IPv6](../ipv6_overview.md)**.

### Типы адресов по области видимости

1. **Публичные (белые) адреса:** Уникальны в глобальной сети Интернет. Необходимы для прямой доступности узла извне.
2. **Приватные (серые) адреса:** Используются во внутренних сетях (LAN). Описаны в **RFC 1918**. Не маршрутизируются в интернете без [NAT](../Concepts/nat.md).

### Типы адресов в подсети

- **Адрес сети (Network Address):** Идентификатор подсети (первый адрес). Не назначается хостам.
- **Адрес хоста (Host Address):** Уникальный адрес конкретного интерфейса.
- **Широковещательный адрес (Broadcast):** Адрес для рассылки всем в подсети (последний адрес в IPv4).

### Маска подсети и CIDR

**Маска подсети (Subnet Mask)** — 32-битное число, разделяющее IP на сетевую и хостовую части.
**CIDR (Classless Inter-Domain Routing)** — современный формат записи маски через префикс (например, `/24`), пришедший на смену классовой адресации.

### Специальные маски

- **`/32`:** Указывает на конкретный хост (хост-маршрут).
- **`/31`:** Используется для соединений "точка-точка" (RFC 3021), позволяя эффективно использовать адреса (доступны оба адреса в диапазоне).

## Практические сценарии

### Расчет параметров подсети

Для определения адреса сети и диапазона доступных хостов выполняется побитовая операция «И» (AND) между IP и маской.

**Пример: IP `192.168.1.130/26`**

- **Магическое число:** $256 - 192 = 64$ (шаг сети).
- **Адрес сети:** `192.168.1.128` (ближайшее кратное 64 число, меньшее 130).
- **Broadcast:** `192.168.1.191` (адрес перед следующей сетью `192.168.1.192`).
- **Диапазон хостов:** `192.168.1.129` – `192.168.1.190` (62 адреса).

Подробные примеры и методы расчета: **[Методы расчета подсетей](./subnetting_calculation.md)**.

### Проверка связности L2

Два узла находятся в одном L2-сегменте (могут общаться напрямую без роутера), если после применения маски к их IP-адресам результат (адрес сети) совпадает.

### RFC и стандарты

- **RFC 791:** Спецификация IPv4.
- **RFC 8200:** Спецификация IPv6 (заменил RFC 2460).
- **RFC 1918:** Распределение адресов для частных сетей.
- **RFC 3021:** Использование префиксов `/31` на линках Point-to-Point.
- **RFC 4632:** Спецификация CIDR.
