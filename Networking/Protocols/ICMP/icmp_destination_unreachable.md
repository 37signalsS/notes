# ICMP Destination Unreachable (Цель недоступна)

**Reliability Score: 10/10** (SSoT + Проверено по RFC 792/4443)

## Определения

**Destination Unreachable (Тип 3 для IPv4, Тип 1 для IPv6)** — служебное сообщение протокола ICMP, уведомляющее отправителя о невозможности доставки IP-пакета до конечного узла или конкретного приложения.

**Основные параметры:**
- **IPv4:** Тип 3.
- **IPv6:** Тип 1.
- **Код:** 0–15 (детализация конкретной причины отказа в доставке).

## Основные концепции

### Назначение

Сообщения о недостижимости критически важны для стабильности сети:
1.  **Оптимизация ресурсов:** позволяют стеку протоколов (TCP/UDP) немедленно прекратить бесперспективные повторные передачи, не дожидаясь таймаутов.
2.  **Диагностика:** помогают точно локализовать место разрыва связи (маршрутизатор или хост) и причину (нет маршрута, порт закрыт, запрещено фильтром).
3.  **Path MTU Discovery (PMTUD):** в IPv4 используется специальный код (Type 3 Code 4) для уведомления о необходимости фрагментации.

### Источники сообщений

| Источник | Генерируемые причины |
| :--- | :--- |
| **Маршрутизатор** | Нет пути к сети, хост не отвечает на ARP/NDP, пакет слишком велик, доступ запрещен правилами (ACL). |
| **Хост назначения** | Нужный протокол не поддерживается, порт (приложение) не прослушивается. |

### Таблица основных кодов (v4 vs v6)

| Описание причины | Код IPv4 (Type 3) | Код IPv6 (Type 1) | Примечание |
| :--- | :--- | :--- | :--- |
| **No Route to Destination** | 0 (Net Unr.) | 0 (No route) | Маршрутизатор не знает, куда слать пакет. |
| **Host/Address Unreachable** | 1 (Host Unr.) | 3 (Address Unr.) | Ошибка разрешения L2 (ARP/NDP) или узел выключен. |
| **Protocol Unreachable** | 2 | — | В IPv6 заменено на ICMPv6 Type 4 (Parameter Problem). |
| **Port Unreachable** | 3 | 4 | UDP-порт закрыт. Для TCP используется флаг RST. |
| **Fragmentation Needed** | 4 | **Type 2** | **Важно:** В IPv6 это отдельный тип (Packet Too Big). |
| **Communication Prohibited** | 9, 10, 13 | 1 | Пакет отброшен брандмауэром или ACL. |

## Практические сценарии

### Недостижимость сети (IPv4 Code 0 / IPv6 Code 0)

**Сценарий:** Ошибка в таблице маршрутизации или падение аплинка.
1. Пакет приходит на маршрутизатор.
2. Маршрутизатор не находит подходящего маршрута (даже `default gateway`).
3. Маршрутизатор отбрасывает пакет и отправляет отправителю ICMP Destination Unreachable.
4. **Реакция:** Приложение получает ошибку "No route to host".

### Порт закрыт (IPv4 Code 3 / IPv6 Code 4)

**Сценарий:** Попытка обращения к UDP-сервису, который не запущен.
1. Пакет успешно доставляется на целевой хост.
2. Ядро ОС видит, что на указанном порту нет слушающего сокета.
3. ОС отправляет ICMP Port Unreachable.
4. **Диагностика:** Используется утилитами `nmap` или `nc` для сканирования UDP-портов.

### Требуется фрагментация (IPv4 Type 3 Code 4)

**Сценарий:** "Черные дыры" в туннелях (VPN/PPPoE).
1. Хост отправляет пакет с флагом DF (Don't Fragment).
2. Маршрутизатор видит, что MTU следующего линка меньше размера пакета.
3. Маршрутизатор отбрасывает пакет и шлет ICMP Type 3 Code 4, указывая свой MTU.
4. **Проблема:** Если этот ICMP пакет заблокирован файрволом, возникает "Black Hole" — SSH-сессия или HTTP-запрос "зависают" после передачи первых данных.
