# Безопасность DHCP: Атаки и защита

## Определения

Протокол DHCP уязвим для двух основных типов атак:

- **DHCP Starvation** — DoS-атака, исчерпывающая пул IP-адресов сервера поддельными MAC-адресами
- **Rogue DHCP (DHCP Spoofing)** — развёртывание поддельного DHCP-сервера для выдачи клиентам неверных сетевых параметров (шлюз, DNS)

## Основные концепции

### DHCP Starvation (Истощение пула)

**Механизм:**
1. Сервер резервирует IP при получении `DHCPDISCOVER`, запоминая MAC клиента
2. Злоумышленник отправляет множество `DHCPDISCOVER` с поддельными MAC
3. Пул исчерпывается — легитимные клиенты не получают IP

**Последствия:** отказ в обслуживании (DoS) для новых устройств в сети.

### Rogue DHCP Server (Поддельный сервер)

**Механизм:**
1. Клиент отправляет `DHCPDISCOVER`
2. Все серверы отвечают `DHCPOFFER`
3. Клиент принимает первый полученный ответ
4. Злоумышленник настраивает сервер на максимально быструю отправку

**Варианты атаки:**

| Тип | Описание |
|-----|----------|
| **DoS** | Выдача нерабочих сетевых параметров (неверный шлюз, DNS) |
| **Man-in-the-Middle** | Шлюз по умолчанию — сервер атакующего, трафик перехватывается |
| **Перехват DNS** | DNS-запросы перенаправляются на подконтрольный сервер |

**Признаки атаки:**
- Клиенты получают IP из другой подсети
- Невозможность выхода в интернет или доступа к локальным ресурсам
- Несколько `DHCPOFFER` от разных серверов на один `DHCPDISCOVER` (видно в Wireshark)

### Механизмы защиты L2-коммутаторов

#### DHCP Snooping

Коммутатор отслеживает DHCP-трафик и классифицирует порты:

| Тип порта | Описание |
|-----------|----------|
| **Trusted** | Порты легитимных DHCP-серверов/аплинков. Разрешены все DHCP-сообщения |
| **Untrusted** | Порты пользователей. Блокируются входящие `DHCPOFFER`, `DHCPACK`, `DHCPNAK` |

`DHCPOFFER`/`DHCPACK` от сервера на untrusted-порту блокируется коммутатором.

#### Port Security

Ограничение количества MAC-адресов на одном порту.

```cisco
interface GigabitEthernet0/1
 switchport port-security
 switchport port-security maximum 2
 switchport port-security violation shutdown
```

#### Dynamic ARP Inspection (DAI)

Проверяет ARP-сообщения на основе базы DHCP Snooping. Предотвращает ARP-спуфинг.

## Практические сценарии

### Обнаружение и отключение Rogue DHCP-сервера

**1. Сетевой анализ:**
- Wireshark/tcpdump — захват DHCP-трафика, идентификация IP/MAC всех отвечающих серверов
- `dhcp-discover` (Linux), Rogue Detector — активное сканирование

**2. Поиск порта на коммутаторе:**
- По MAC-адресу rogue-сервера найти порт в таблице MAC-адресов коммутатора
- Проверить логи управляемого коммутатора

**3. Блокировка:**
- Административно отключить порт или физически отключить устройство
- Если устройство легитимно (например, роутер пользователя), перенастроить

### Рекомендации по безопасности

1. Включить **DHCP Snooping** на всех коммутаторах доступа
2. Настроить **trusted-порты** только для легитимных DHCP-серверов
3. Ограничить MAC-адреса на пользовательских портах (**Port Security**)
4. Мониторить логи DHCP-сервера на аномальную активность
5. Использовать **авторитативный сервер** в каждой подсети
6. Применять **802.1X** для аутентификации устройств перед допуском в сеть

> **Публичные сети:** в кафе, аэропортах, отелях риск Rogue DHCP и MitM значительно выше.
