# DHCP Relay (Ретранслятор DHCP)

## Определения

**DHCP Relay (ретранслятор DHCP)** — механизм, позволяющий DHCP-клиентам и серверам находиться в разных сегментах сети.

**Проблема:** Маршрутизаторы не передают широковещательные сообщения между подсетями, поэтому для доставки DHCP-запросов используется ретранслятор.

## Сценарий использования

В организации несколько офисов, каждый в своей IP-подсети за маршрутизатором. Вместо развертывания DHCP-сервера в каждом офисе, настраивается один центральный сервер, а на маршрутизаторах включается DHCP Relay.

## Принцип работы

### 1. Клиент отправляет DHCP DISCOVER

- Хост подключается к сети и отправляет широковещательное сообщение `DHCPDISCOVER`
- Сообщение не выходит за пределы локального широковещательного домена

### 2. DHCP Relay получает сообщение

- Ретранслятор (обычно на маршрутизаторе) перехватывает широковещательный запрос
- Добавляет свой IP-адрес в поле `giaddr` (gateway IP address)
- Увеличивает поле `hops` (счетчик прыжков)
- Отправляет `DHCPDISCOVER` напрямую на DHCP-сервер (unicast)

### 3. DHCP-сервер обрабатывает запрос

- Использует поле `giaddr` для определения подсети клиента
- Выбирает свободный IP-адрес из пула, соответствующего подсети
- Формирует сообщение `DHCPOFFER`
- Отправляет ответ напрямую на ретранслятор (используя `giaddr`)

### 4. DHCP Relay пересылает ответ

- Получает `DHCPOFFER` от сервера
- Пересылает сообщение клиенту в локальную подсеть

Аналогичным образом ретранслятор обрабатывает сообщения `DHCPREQUEST` и `DHCPACK`.

## Ключевые поля

| Поле | Описание |
|------|----------|
| `giaddr` | IP-адрес ретранслятора, указывает серверу на подсеть клиента |
| `hops` | Счетчик пройденных ретрансляторов (защита от петель) |

## Настройка

На маршрутизаторе указывается IP-адрес DHCP-сервера, на который необходимо ретранслировать сообщения.

**Пример (Cisco):**
```cisco
interface Vlan10
 ip helper-address 10.0.0.100
```

**Пример (Linux, dhcp-relay):**
```bash
# Установка пакета
apt-get install isc-dhcp-relay

# Конфигурация /etc/default/isc-dhcp-relay
SERVERS="10.0.0.100"
INTERFACES="eth0 eth1"
```

## Ограничения

- **Максимальное количество ретрансляторов:** Ограничено полем `hops` (максимум 16)
- **Задержка:** Каждый ретранслятор добавляет задержку к процессу DORA
- **Безопасность:** Требуется доверие между ретранслятором и сервером
