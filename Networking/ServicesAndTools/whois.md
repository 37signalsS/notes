# whois — проверка информации о домене

## Определения

**whois** — протокол и утилита для получения информации о доменных именах, IP-адресах и автономных системах. whois позволяет узнать владельца домена, дату регистрации, контакты администратора и другие метаданные.

## Основные концепции

### Для чего используется whois

1. **Проверка доступности домена:** Узнать, свободен ли домен для регистрации
2. **Определение владельца:** Получить контактные данные владельца домена
3. **Проверка даты регистрации:** Узнать, когда домен был зарегистрирован
4. **Выявление мошеннических сайтов:** Определить подозрительные домены по дате регистрации
5. **Диагностика DNS-проблем:** Найти DNS-серверы домена

### Типы информации в whois

**Стандартные поля:**
- **Domain Name:** Имя домена
- **Registrar:** Регистратор домена
- **Creation Date:** Дата регистрации домена
- **Updated Date:** Дата последнего обновления
- **Registry Expiry Date:** Дата истечения регистрации
- **Name Server:** DNS-серверы домена
- **DNSSEC:** Подпись DNSSEC
- **Registrant Contact:** Данные владельца (могут быть скрыты)

## Практические сценарии

### Сценарий 1: Проверка сайта мошенников

**Проблема:** Вы нашли подозрительный сайт и хотите проверить его надёжность.

**Пример:** Поиск "Скачать Google Chrome" приводит на сайт `vicsoftware.net`.

**Шаги проверки:**

1. **Откройте whois-сервис:**
   - https://www.reg.ru/whois/
   - https://whois.domaintools.com/
   - https://whois.icann.ru/

2. **Введите название домена:**
   ```
   vicsoftware.net
   ```

3. **Изучите результат:**
   ```
   Domain Name: VICSOFTWARE.NET
   Registry Domain ID: 2948181039_DOMAIN_NET-VRSN
   Registrar WHOIS Server: whois.namesilo.com
   Registrar URL: http://www.namesilo.com
   Updated Date: 2026-01-06T10:22:04Z
   Creation Date: 2025-01-06T13:08:10Z  ← Дата создания
   Registry Expiry Date: 2027-01-06T13:08:10Z
   ...
   ```

4. **Анализ:**
   - **Creation Date:** 6 января 2025 (домен создан недавно)
   - **Вывод:** Подозрительно — сайт предлагает скачать бесплатный браузер, но домен зарегистрирован вчера

5. **Рекомендация:** Не скачивайте файлы с недавно зарегистрированных доменов — это могут быть мошенники.

**Признаки подозрительного домена:**
- ✅ Домен зарегистрирован менее года назад
- ✅ Предлагает платные услуги для бесплатных продуктов
- ✅ Нет контактной информации владельца
- ✅ DNSSEC не настроен
- ✅ Регистратор в офшорной зоне

### Сценарий 2: Проверка возраста домена для SEO

**Проблема:** Вы хотите купить домен для SEO-проекта и проверяете его историю.

**Команда:**
```bash
whois example.com
```

**Анализ:**
- Старые домены (>5 лет) имеют больший вес в поисковиках
- Проверьте, не был ли домен в спам-базах
- Узнайте, сколько раз домен перерегистрировался

### Сценарий 3: Поиск контактов владельца

**Проблема:** Вы хотите связаться с владельцем домена для покупки.

**Команда:**
```bash
whois example.com
```

**Результат:**
```
Registrant Contact:
  Name: John Doe
  Email: admin@example.com
  Phone: +1.5555555555
```

**Примечание:** Многие владельцы используют защиту приватности (WHOIS privacy), которая скрывает контактные данные.

**Использование:**
```bash
# Проверка домена
whois example.com

# Проверка IP-адреса
whois 8.8.8.8

#指定 сервер
whois -h whois.ripe.net example.com
```

## Интерпретация результатов

### Критические поля для анализа

| Поле | На что обращать внимание |
| :--- | :--- |
| **Creation Date** | Чем новее домен, тем выше риск мошенничества |
| **Updated Date** | Частые изменения могут указывать на смену владельца |
| **Registry Expiry Date** | Скоро истекает — домен может быть выкуплен |
| **Registrar** | Известный регистратор = больше доверия |
| **Name Server** | Свои DNS = серьёзный проект, чужие = возможно, хостинг |
| **DNSSEC** | Включён = лучше безопасность |

## Ограничения whois

1. **Защита приватности:** Многие владельцы скрывают данные через WHOIS privacy
2. **GDPR:** В Европе ограничили доступ к персональным данным
3. **Неполные данные:** Некоторые регистраторы предоставляют минимум информации
4. **Кэширование:** Данные могут быть неактуальными (до 24 часов)
