# whois — протокол и утилита

## Определения

**whois** — протокол и утилита командной строки для получения регистрационной информации о доменных именах, IP-адресах и автономных системах (AS). Позволяет узнать владельца домена, дату регистрации, контакты администратора, DNS-серверы и другие метаданные.

Протокол работает поверх TCP, порт **43**.

## Основные концепции

### Типы информации в whois

**Стандартные поля:**

| Поле | Описание |
| :--- | :--- |
| `Domain Name` | Имя домена |
| `Registrar` | Регистратор домена |
| `Creation Date` | Дата регистрации |
| `Updated Date` | Дата последнего обновления |
| `Registry Expiry Date` | Дата истечения регистрации |
| `Name Server` | DNS-серверы домена |
| `DNSSEC` | Статус подписи DNSSEC |
| `Registrant Contact` | Данные владельца (могут быть скрыты через WHOIS privacy) |

### Для чего используется whois

- **Проверка доступности домена** — свободен ли домен для регистрации
- **Определение владельца** — контактные данные registrant, admin, tech
- **Проверка даты регистрации** — возраст домена, история перерегистраций
- **Выявление подозрительных доменов** — недавно зарегистрированные домены с признаками фишинга
- **Диагностика DNS-проблем** — поиск DNS-серверов домена
- **SEO-анализ** — оценка истории и возраста домена перед покупкой

### Ограничения whois

- **WHOIS privacy:** Многие владельцы скрывают данные через сервисы защиты приватности
- **GDPR:** В Европе ограничена публикация персональных данных в whois
- **Неполные данные:** Некоторые регистраторы предоставляют минимум информации
- **Кэширование:** Данные могут быть неактуальными (до 24 часов)

## Практические сценарии

### Базовые команды

```bash
# Проверка домена
whois example.com

# Проверка IP-адреса
whois 8.8.8.8

# Указать конкретный whois-сервер
whois -h whois.ripe.net example.com
```

### Проверка подозрительного домена

**Сценарий:** Поиск «Скачать Google Chrome» приводит на сайт `vicsoftware.net`.

**Шаги:**

```bash
whois vicsoftware.net
```

**Результат:**

```
Domain Name: VICSOFTWARE.NET
Registrar WHOIS Server: whois.namesilo.com
Creation Date: 2025-01-06T13:08:10Z
Registry Expiry Date: 2027-01-06T13:08:10Z
```

**Анализ:**

- `Creation Date` — 6 января 2025 (домен зарегистрирован недавно)
- Предлагает бесплатный браузер, но домен свежий — высокий риск мошенничества

**Признаки подозрительного домена:**

- Домен зарегистрирован менее года назад
- Предлагает платные услуги для бесплатных продуктов
- Нет контактной информации владельца
- DNSSEC не настроен
- Регистратор в офшорной зоне

Для онлайн-проверки можно использовать веб-сервисы: [reg.ru/whois](https://www.reg.ru/whois/), [whois.domaintools.com](https://whois.domaintools.com/), [whois.icann.org](https://whois.icann.org/).

### Проверка возраста домена для SEO

```bash
whois example.com
```

**Критерии анализа:**

- Старые домены (>5 лет) имеют больший вес в поисковых системах
- Проверить историю нахождения в спам-базах
- Узнать частоту перерегистраций

### Поиск контактов владельца

```bash
whois example.com
```

Многие владельцы используют WHOIS privacy, скрывающий реальные контактные данные. В этом случае в поле `Registrant Contact` будут указаны данные сервиса приватности.

### Интерпретация критических полей

| Поле | На что обращать внимание |
| :--- | :--- |
| `Creation Date` | Чем новее домен, тем выше риск мошенничества |
| `Updated Date` | Частые изменения могут указывать на смену владельца |
| `Registry Expiry Date` | Скорое истечение — домен может стать свободен |
| `Registrar` | Известный регистратор = больше доверия |
| `Name Server` | Собственные DNS = серьёзный проект, чужие = возможно, хостинг |
| `DNSSEC` | Включён = выше безопасность |
