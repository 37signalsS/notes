# Использование Postman для работы с API

## Что такое Postman?

Postman — это платформа для разработки API, которая упрощает каждый шаг жизненного цикла API и позволяет быстрее создавать лучшие API.

*   **Доступность:** Postman можно использовать бесплатно, но также есть платные подписки.
*   **Установка:** Доступны версии для Windows, Mac и Linux.
*   **Веб-версия:** Можно использовать веб-версию Postman, предварительно зарегистрировавшись.

## Отправка запросов в Postman

### Интерфейс Postman

Основное окно Postman позволяет отправлять запросы.

1.  **Выбор метода HTTP:** В левой части окна можно выбрать метод HTTP, который будет использоваться при отправке запроса (по умолчанию установлен `GET`, который используется чаще всего; также можно выбрать `POST`, `PUT`, `PATCH` и другие методы).
2.  **Строка запроса:** Сюда вставляется URL-адрес API.
3.  **Заголовки (Headers):** Postman автоматически добавляет несколько стандартных заголовков.
4.  **Ответ (Response):** В правой/нижней части отображается ответ от сервера.

### Пример 1: Использование API Geolocation

Рассмотрим отправку запроса к Geolocation API.

1.  **Базовый URL:** `https://api.geolocation.com/` (пример).
2.  **Отправка запроса:** Вставляем базовый URL в строку запроса Postman и нажимаем кнопку `Send`.
3.  **Анализ ответа:**
    *   **Статус:** `200 OK` (статус выполнения запроса).
    *   **Статистика:** Информация о времени выполнения запроса и объеме переданных/полученных данных.
    *   **Заголовки ответа:** Например, `Content-Type: application/json` (указывает формат данных в ответе).
    *   **Тело ответа (Body):** Данные в формате JSON.

### Работа с параметрами запроса

Postman позволяет легко добавлять параметры запроса.

1.  **Вкладка "Params":** Для параметров запроса (query parameters) есть специальная таблица "Key" (ключ) и "Value" (значение).
2.  **Пример параметра `lang` (язык ответа):**
    *   `Key`: `lang`
    *   `Value`: `ru` (русский язык)
    *   После ввода параметров они автоматически добавляются в строку URL.
    *   Отправляем запрос, и в ответе видим, что некоторые строки переведены на русский язык (например, "страна: Россия", "регион: Москва"), хотя некоторые поля могут оставаться на английском.
3.  **Пример параметра `fields` (выбор полей):**
    *   Можно указать, какие именно поля нужно получить, а не выводить все поля.
    *   `Key`: `fields`
    *   `Value`: `region_name,company_name`
    *   В результате получаем ответ, содержащий только запрошенные поля.

### Пример 2: Использование API HeadHunter

Работу с новым API всегда начинаем с изучения документации.

1.  **Базовый URL:** `https://api.hh.ru/`
2.  **Поиск вакансий:** Для поиска вакансий используется метод `GET` на эндпоинт `/vacancies`.
3.  **Добавление параметров поиска:**
    *   **Параметр `text`:** Используется для поиска строки в полях вакансии.
        *   `Key`: `text`
        *   `Value`: `сетевой инженер`
        *   Отправляем запрос. В ответе получаем список вакансий, где ключевые слова ищутся во всех полях.
    *   **Параметр `search_field`:** Ограничивает область поиска определёнными полями.
        *   `Key`: `search_field`
        *   `Value`: `name` (поиск только в названии вакансии)
        *   Отправляем запрос. Результат будет более релевантным, так как поиск ограничен названием вакансии.
4.  **Получение подробной информации о вакансии:**
    *   Для получения детальной информации по конкретной вакансии используется эндпоинт `/vacancies/{vacancy_id}`, где `{vacancy_id}` — это идентификатор вакансии.
    *   Вставляем URL в Postman, заменяем `{vacancy_id}` на реальный ID вакансии и отправляем запрос.
    *   В ответе получаем подробное описание вакансии, включая название, город и полное описание в формате HTML. Postman позволяет просмотреть HTML-описание во вкладке `Preview`.

### Выводы о Postman

Postman — это бесплатная и одна из самых популярных программ для работы с API. Её графический интерфейс делает работу с API значительно удобнее, чем использование браузера или терминала.
