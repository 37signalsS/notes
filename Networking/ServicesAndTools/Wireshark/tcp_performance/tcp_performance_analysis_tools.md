# Графики Wireshark для анализа TCP

## Определения

**TCP Stream Graphs** — набор визуализаций в Wireshark, строящих графики на основе анализа TCP-потока (последовательности, RTT, throughput, окно).

**IO Graphs** — универсальный график общего трафика с возможностью фильтрации по анализатору Wireshark (ретрансмиты, Zero Window, DupACK).

---

## Basic Concepts

### Доступные графики TCP Stream Graphs

Все графики доступны через меню: `Statistics → TCP Stream Graphs`.

| График | Описание |
| :--- | :--- |
| **Time-Sequence (Stevens)** | Последовательность пакетов во времени |
| **Round Trip Time** | Время от отправки до подтверждения (ACK) |
| **Throughput** | Скорость передачи данных (байт/сек) |
| **Window Scaling** | Изменение размера TCP-окна |

### IO Graphs

Доступен через: `Statistics → IO Graphs`. Позволяет накладывать фильтры анализаатора TCP для визуализации ошибок поверх общего трафика.

**Основные фильтры:**

- `tcp.analysis.retransmission` — ретрансмиты
- `tcp.analysis.zero_window` — Zero Window события
- `tcp.analysis.dup_ack` — Duplicate ACK

**Масштабирование:**

- Axis Factor: ×10 или ×100 для видимости малых значений
- Interval: 100ms для детализации

## Practical Scenarios

### Time-Sequence (Stevens)

**Назначение:** Визуализация последовательности пакетов во времени.

**Интерпретация:**

- Наклонная линия вверх — нормальная передача
- Горизонтальная линия — пауза в передаче
- Вертикальные скачки — ретрансмиты

**Пример использования:** [Диагностика проблем сервера](./tcp_server_performance_issues.md) — поиск пауз на стороне сервера.

### Round Trip Time Graph

**Назначение:** Анализ задержек между отправкой и подтверждением.

**Интерпретация:**

- Стабильный низкий RTT (микросекунды) — клиент/сервер работает быстро
- Высокий RTT (миллисекунды) — проблема на стороне получателя
- Резкие скачки — потери пакетов или перегрузка сети

**Пример использования:** [Диагностика проблем сервера](./tcp_server_performance_issues.md) — подтверждение, что проблема не на клиенте.

### Throughput

**Назначение:** Мониторинг скорости передачи данных.

**Интерпретация:**

- Пилообразный график — нормальная работа TCP congestion control
- Провалы до 0 — потери пакетов или тайм-ауты
- Стабильная низкая линия — ограничение пропускной способности

**Пример использования:** [Потери в сети и offloading](./tcp_network_losses_and_offloading.md) — стабильный throughput при ложных ретрансмитах.

### Window Scaling

**Назначение:** Отслеживание изменения размера TCP-окна.

**Интерпретация:**

- Плавное уменьшение — получатель не успевает обрабатывать
- Резкое падение до 0 — Zero Window (буфер заполнен)
- Восстановление — буфер освободился

**Пример использования:** [Диагностика проблем клиента](./tcp_client_performance_issues.md) — заполнение буфера клиента.

### IO Graphs — визуализация потерь

**Назначение:** Общий обзор трафика и ошибок поверх него.

**Настройка:**

1. `Statistics → IO Graphs`
2. Добавить график с фильтром `tcp.analysis.retransmission`
3. Установить Axis Factor ×10 для видимости малых значений
4. Interval: 100ms

**Интерпретация:**

- Красная линия (ретрансмиты) поверх чёрной (весь трафик)
- Регулярные пики ошибок — систематические потери
- Единичные всплески — случайные потери
