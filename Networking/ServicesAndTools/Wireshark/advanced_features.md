# Wireshark: Дополнительные Возможности и Настройки

## Дополнительная информация

### Справочник по фильтрам

Важно помнить, что синтаксис **фильтров захвата** и **фильтров отображения** отличается. Фильтры захвата (Capture Filters) используют синтаксис `tcpdump` (например, `host 192.168.1.1` или `port 80`), тогда как фильтры отображения (Display Filters) требуют использования оператора сравнения (`==`) для большинства полей (например, `ip.addr == 192.168.1.1` или `tcp.port == 80`).

#### Фильтры захвата (`-f "..."`)
*Синтаксис `tcpdump`. Применяются при запуске захвата.*
| Сценарий | Фильтр |
|---|---|
| Трафик от/к хосту | `host 192.168.1.1` |
| Трафик к хосту | `dst host 8.8.8.8` |
| Трафик с порта 443 | `port 443` |
| Только TCP или UDP | `tcp or udp` |
| DNS трафик (порт 53) | `udp port 53` |
| Трафик из подсети | `net 192.168.1.0/24` |
| Исключить SSH | `not port 22` |

#### Фильтры отображения (`-Y "..."` или в GUI)
*Более мощный и гибкий синтаксис. Применяются к уже захваченным данным.*
| Действие | Фильтр |
|---|---|
| По IP-адресу (источник или назначение) | `ip.addr == 10.10.42.1` |
| По исходному IP | `ip.src == 10.10.42.1` |
| По протоколу | `http or dns or icmp` |
| По TCP порту | `tcp.port == 25` |
| Флаг TCP SYN | `tcp.flags.syn == 1 && tcp.flags.ack == 0` |
| HTTP Host | `http.host == "example.com"` |
| Широковещательный трафик | `eth.dst == ff:ff:ff:ff:ff:ff` |

### Цветовая маркировка (Coloring Rules)
Wireshark использует цвета для выделения трафика, что помогает быстро находить проблемы.
*   **Светло-голубой**: TCP трафик.
*   **Светло-зеленый**: HTTP трафик.
*   **Темно-синий**: DNS трафик.
*   **Черный**: Пакеты с ошибками (например, неверная контрольная сумма TCP).
*   **Красный**: Проблемный TCP-трафик (например, повторные передачи).
Правила настраиваются в меню `View -> Coloring Rules...`.

### Горячие клавиши Wireshark GUI
| Клавиша | Действие |
|---|---|
| `Ctrl+E` | Начать/Остановить захват |
| `Ctrl+R` | Перезапустить захват |
| `Ctrl+O` | Открыть файл |
| `Ctrl+S` | Сохранить файл |
| `Ctrl+F` | Найти пакет |

### Визуализация и комментарии

*   **Граф потоков (Flow Graph)**: В меню `Statistics -> Flow Graph` Wireshark может построить графическое представление взаимодействия в выбранном потоке (например, TCP). Это очень удобно для визуального понимания последовательности запросов и ответов, а также для документирования. Графы могут быть экспортированы в различные форматы.
*   **Раскраска диалогов (Colorize Conversation)**: Для выделения определенных взаимодействий можно раскрасить все пакеты, относящиеся к конкретному диалогу (например, между двумя IP-адресами). Кликните правой кнопкой мыши по любому пакету в диалоге, выберите `Colorize Conversation` и задайте правила. Правила раскраски настраиваются в `View -> Coloring Rules...`.
*   **Добавление комментариев к пакетам**: Кликните правой кнопкой мыши по пакету, выберите `Packet Comment -> Add Packet Comment`. Это позволяет добавлять текстовые заметки к отдельным пакетам, что очень удобно для фиксации выводов или подозрительных моментов при долгом анализе. Комментарии можно отображать в отдельном столбце.

### Дешифрование TLS-трафика
Wireshark может дешифровать TLS-трафик, что критически важно для анализа HTTPS, WebSockets over TLS и других защищенных протоколов.

#### Методы дешифрования:
1.  **С помощью приватного ключа сервера**: Если у вас есть приватный ключ сервера, используемый для TLS-соединения, его можно указать в `Edit -> Preferences -> Protocols -> TLS`. Добавьте запись с IP-адресом сервера, портом и путем к файлу ключа. Этот метод эффективен для трафика, где вы контролируете серверную часть.
2.  **С помощью `(Pre)-Master-Secret log filename` (рекомендуемый для клиентского трафика)**: Современные браузеры (Firefox, Chrome) и приложения, построенные на их движках (Electron-приложения, такие как Slack, Mattermost, клиенты ChatGPT), могут быть настроены на запись своих TLS-сессионных ключей в специальный файл. Wireshark может использовать этот файл для автоматического дешифрования трафика.
    *   **Настройка Wireshark**: В `Edit -> Preferences -> Protocols -> TLS` укажите путь к файлу в поле `(Pre)-Master-Secret log filename`.
    *   **Запуск браузера/приложения**: Используйте `Tools -> TLS Key Log File -> Launch` в Wireshark. Это запустит браузер со специальными переменными окружения, которые заставят его записывать ключи в указанный файл.
    *   **Применимость**: Этот метод позволяет дешифровать трафик, инициированный вашим браузером или Electron-приложениями, включая WebSockets, что дает возможность увидеть сообщения, передаваемые по защищенному соединению.
