# Инструменты для сетевых расчётов

## Определения

**Инструменты для сетевых расчётов** — специализированное программное обеспечение для автоматизации вычислений параметров IP-сетей. Они позволяют мгновенно получить адрес сети, широковещательный адрес, диапазон доступных хостов и маску подсети на основе заданного IP-адреса и префикса.

Для изучения теоретических основ IP-адресации и методов ручного расчёта см. **[расчёт параметров подсети](../../Protocols/IP_addressing/subnetting_calculation.md)**.

## Основные концепции

### ipcalc

`ipcalc` — классическая утилита командной строки для Linux, предназначенная для расчёта параметров сетей IPv4. Она поддерживает как десятичную запись маски, так и нотацию CIDR.

**Основные возможности:**

- Расчёт адреса сети, broadcast и wildcard-маски.
- Определение диапазона доступных хостов.
- Визуализация структуры адреса в двоичном формате.
- Проверка типа адреса (сетевой, хостовый или широковещательный).

### sipcalc

`sipcalc` — более мощная альтернатива `ipcalc`, поддерживающая как **IPv4**, так и **IPv6**. Она выводит информацию в структурированном виде и удобна для парсинга в скриптах.

### Модуль ipaddress (Python)

Для автоматизации сетевых расчётов в DevOps-сценариях (например, в Ansible или кастомных скриптах на Python) стандартом является встроенный модуль `ipaddress`. Он позволяет работать с объектами сетей и адресов, выполнять итерации по хостам и проверять вхождения адресов в подсети.

### Онлайн-сервисы

Для быстрой проверки без доступа к терминалу используются веб-инструменты:

- [jodies.de/ipcalc](http://jodies.de/ipcalc) — онлайн-аналог консольного `ipcalc`.
- [subnetonline.com](https://www.subnetonline.com/) — калькулятор подсетей с расширенной визуализацией.

## Практические сценарии

### Расчёт параметров подсети через ipcalc

Команда для расчёта сети `192.168.0.5/30`:

```bash
ipcalc 192.168.0.5/30
```

**Пример вывода:**

```text
Address:   192.168.0.5          11000000.10101000.00000000.00000101
Netmask:   255.255.255.252 = 30 11111111.11111111.11111111.11111100
Wildcard:  0.0.0.3              00000000.00000000.00000000.00000011
=>
Network:   192.168.0.4/30       11000000.10101000.00000000.00000100
HostMin:   192.168.0.5          11000000.10101000.00000000.00000101
HostMax:   192.168.0.6          11000000.10101000.00000000.00000110
Broadcast: 192.168.0.7          11000000.10101000.00000000.00000111
Hosts/Net: 2                     Class C, Private Internet
```

**Интерпретация полей:**

- `Wildcard`: [обратная маска](../../Protocols/IP_addressing/special_masks.md), необходимая для настройки ACL и протоколов маршрутизации (например, OSPF).
- `Network`: [адрес сети](../../Protocols/IP_addressing/subnetting_calculation.md#шаг-3-расчет-адреса-сети-network-address).
- `Broadcast`: [широковещательный адрес](../../Protocols/IP_addressing/subnetting_calculation.md#шаг-4-расчет-широковещательного-адреса-broadcast-address).
- `Hosts/Net`: количество полезных адресов (исключая Network и Broadcast).

### Автоматизация на Python (ipaddress)

Пример скрипта для получения всех хостов подсети:

```python
import ipaddress

net = ipaddress.ip_network('192.168.1.0/29')
print(f"Маска: {net.netmask}")
print(f"Первый хост: {net[1]}")
print(f"Последний хост: {net[-2]}")

# Итерация по всем доступным хостам
for host in net.hosts():
    print(host)
```

### Проверка IPv6 через sipcalc

```bash
sipcalc 2001:db8::1/64
```

## Дополнительная информация

### Выбор инструмента

- **ipcalc**: лучшее решение для быстрой проверки IPv4-адресов в терминале и визуализации двоичной структуры.
- **sipcalc**: предпочтителен при работе с IPv6 или если нужен компактный структурированный вывод.
- **Python ipaddress**: обязателен при написании скриптов автоматизации и обработки больших списков сетей.
