# Инструменты для сетевых расчетов

## ipcalc

`ipcalc` — это утилита командной строки для расчета информации о IP-адресах и сетях. Она помогает быстро определить параметры сети на основе IP-адреса и маски подсети (в формате CIDR или стандартной нотации).

### Пример использования

Запрос на расчет для IP-адреса `192.168.0.5` в сети с префиксом `/30`:

```bash
$ ipcalc 192.168.0.5/30
Address:   192.168.0.5          11000000.10101000.00000000.00000101
Netmask:   255.255.255.252 = 30 11111111.11111111.11111111.11111100
Wildcard:  0.0.0.3              00000000.00000000.00000000.00000011
=>
Network:   192.168.0.4/30       11000000.10101000.00000000.00000100
HostMin:   192.168.0.5          11000000.10101000.00000000.00000101
HostMax:   192.168.0.6          11000000.10101000.00000000.00000110
Broadcast: 192.168.0.7          11000000.10101000.00000000.00000111
Hosts/Net: 2                     Class C, Private Internet
```

### Объяснение вывода

*   **Address:** Указанный IP-адрес в десятичном и двоичном формате.
*   **Netmask:** Маска подсети, определяющая, какая часть IP-адреса относится к сети, а какая — к хостам. `= 30` — это нотация CIDR.
*   **Wildcard:** Обратная маска (wildcard mask), используется в списках контроля доступа (ACL) на сетевом оборудовании.
*   **Network:** Адрес сети. Это самый первый IP-адрес в диапазоне, он не назначается хостам.
*   **HostMin:** Первый доступный IP-адрес в подсети, который можно назначить хосту. В сетях `/30` и `/31` это часто адрес шлюза.
*   **HostMax:** Последний доступный IP-адрес в подсети для назначения хосту.
*   **Broadcast:** Широковещательный адрес. Используется для отправки данных всем хостам в данной подсети.
*   **Hosts/Net:** Количество доступных хостов в подсети. В сети `/30` доступно всего 2 хоста, что часто используется для point-to-point соединений (например, между двумя роутерами).

Таким образом, если дан IP-адрес одного устройства `192.168.0.5`, то шлюзом по умолчанию (gateway) с большой вероятностью будет второй доступный адрес в этой подсети — `192.168.0.6`.
