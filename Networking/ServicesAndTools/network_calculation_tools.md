# Инструменты для сетевых расчетов

## Определения

Инструменты для сетевых расчетов предназначены для автоматизации вычислений параметров IP-сетей: адрес сети, широковещательный адрес, диапазон хостов, количество подсетей и другие.

## ipcalc

### Основные концепции

`ipcalc` — это утилита командной строки для Linux, предназначенная для выполнения различных расчетов, связанных с IP-адресами и сетями. Она позволяет быстро получать ключевую информацию о подсети на основе заданного IP-адреса и маски подсети.

`ipcalc` значительно упрощает задачи сетевого инженера, автоматизируя вычисление параметров IP-сетей. Утилита работает как с традиционной десятичной записью маски, так и с более современной нотацией [CIDR](../../Networking/Protocols/ip.md).

Для общего понимания концепций IP-адресации, масок подсети и CIDR, рекомендуется ознакомиться с [основами IP-адресации](../../Networking/Protocols/ip.md).

### Практические сценарии

#### Пример использования

Запрос на расчет для IP-адреса `192.168.0.5` в сети с префиксом `/30`:

```bash
$ ipcalc 192.168.0.5/30
Address:   192.168.0.5          11000000.10101000.00000000.00000101
Netmask:   255.255.255.252 = 30 11111111.11111111.11111111.11111100
Wildcard:  0.0.0.3              00000000.00000000.00000000.00000011
=>
Network:   192.168.0.4/30       11000000.10101000.00000000.00000100
HostMin:   192.168.0.5          11000000.10101000.00000000.00000101
HostMax:   192.168.0.6          11000000.10101000.00000000.00000110
Broadcast: 192.168.0.7          11000000.10101000.00000000.00000111
Hosts/Net: 2                     Class C, Private Internet
```

### Объяснение вывода `ipcalc`

* **`Address`:** Указанный IP-адрес в десятичном и двоичном формате.
* **`Netmask`:** Маска подсети, определяющая, какая часть IP-адреса относится к сети, а какая — к хостам. Формат `= 30` является нотацией [CIDR](../../Networking/Protocols/ip.md#cidr-бесклассовая-междоменная-маршрутизация).
* **`Wildcard`:** [Обратная маска (wildcard mask)](../../Networking/Protocols/ip.md#wildcard-mask), используется, например, в списках контроля доступа (ACL) на сетевом оборудовании.
* **`Network`:** [Адрес сети](../../Networking/Protocols/ip.md#адрес-сети-network-address). Это самый первый IP-адрес в диапазоне подсети, который идентифицирует саму сеть. Он не назначается хостам.
* **`HostMin`:** Первый доступный [IP-адрес](../../Networking/Protocols/ip.md) в подсети, который можно назначить хосту.
* **`HostMax`:** Последний доступный [IP-адрес](../../Networking/Protocols/ip.md) в подсети для назначения хосту.
* **`Broadcast`:** [Широковещательный адрес](../../Networking/Protocols/ip.md#широковещательный-адрес-broadcast-address). Используется для отправки данных всем хостам в данной подсети.
* **`Hosts/Net`:** Количество доступных хостов в подсети. В сети `/30` доступно всего 2 хоста, что часто используется для point-to-point соединений (например, между двумя роутерами).

Таким образом, для примера с `192.168.0.5/30`, если это IP-адрес одного устройства, то шлюзом по умолчанию (gateway) с большой вероятностью будет второй доступный адрес в этой подсети — `192.168.0.6`.

### Дополнительные команды ipcalc

```bash
# Проверка, является ли адрес сетью, хостом или широковещательным
ipcalc -c 192.168.1.0/24      # network
ipcalc -c 192.168.1.5/24      # host
ipcalc -c 192.168.1.255/24    # broadcast

# Генерация диапазона адресов
ipcalc -r 192.168.1.0/24

# Проверка, находится ли хост в определенной сети
ipcalc -n 192.168.1.5 255.255.255.0
```

## Альтернативные инструменты

### sipcalc

Усовершенствованная версия ipcalc с поддержкой IPv6 и дополнительными функциями.

```bash
# Установка
sudo apt install sipcalc

# Пример использования (IPv4)
$ sipcalc 192.168.1.100/26
- [ipv4 : 192.168.1.100/26]
Network range:    192.168.1.64 - 192.168.1.127
Prefix length:    26
Network address:  192.168.1.64/26
Netmask:          255.255.255.192
Wildcard:         0.0.0.63
Hosts / Net:      62
First host:       192.168.1.65
Last host:        192.168.1.126
Broadcast:        192.168.1.127

# Пример использования (IPv6)
$ sipcalc 2001:db8::1/64
```
