# Инструменты для сетевых расчётов

## Определения

**Инструменты для сетевых расчётов** — специализированный инструментарий (CLI-утилиты, библиотеки, веб-сервисы) для автоматизации вычислений параметров IP-сетей. Они позволяют мгновенно преобразовывать маски, рассчитывать границы подсетей, количество доступных хостов и агрегировать диапазоны адресов.

Для изучения теоретических основ IP-адресации и методов ручного расчёта см. **[расчёт параметров подсети](../../Networking/Protocols/IP_addressing/subnetting_calculation.md)**.

## Основные концепции

### ipcalc и ipcalc-ng

`ipcalc` — классическая утилита для быстрого расчёта параметров IPv4. В современных дистрибутивах (Fedora, RHEL 9+) часто заменена на **ipcalc-ng**, которая поддерживает IPv6 и имеет расширенные возможности (например, вывод в формате JSON).

**Основные возможности:**
- Расчёт сетевого адреса, широковещательного адреса (broadcast) и wildcard-маски.
- Определение диапазона HostMin/HostMax.
- Визуализация структуры адреса в двоичном виде.
- Проверка вхождения IP в подсеть.

### sipcalc

`sipcalc` — продвинутая альтернатива, изначально созданная с полноценной поддержкой **IPv6**. Она выводит информацию в более структурированном виде, что удобно для использования в конвейерах (pipelines) командной строки.

### prips и grepcidr

Инструменты для массовой обработки адресов в автоматизации:
*   **prips**: Развёртывает CIDR-нотацию или диапазон в полный список IP-адресов. Незаменим для циклов `for` в bash-скриптах.
*   **grepcidr**: Высокопроизводительная утилита для фильтрации списков IP-адресов на основе соответствия заданным сетям (аналог `grep`, понимающий CIDR).

### Модуль ipaddress (Python)

Стандарт де-факто для сетевой автоматизации в DevOps (скрипты, кастомные модули Ansible). Библиотека позволяет работать с IP-объектами как с полноценными структурами данных, а не просто строками.

**Ключевые возможности:**
- Валидация корректности адресов и сетей.
- Арифметика IP (сложение, вычитание, инкремент).
- Проверка пересечений подсетей (overlaps).
- Суммирование (агрегация) списка сетей в минимально возможный набор.

## Практические сценарии

### Расчёт параметров через ipcalc

Команда для анализа сети `172.16.10.0/26`:

```bash
ipcalc 172.16.10.0/26
```

**Ожидаемый результат:**
```text
Address:   172.16.10.0          10101100.00010000.00001010.00 000000
Netmask:   255.255.255.192 = 26 11111111.11111111.11111111.11 000000
Wildcard:  0.0.0.63             00000000.00000000.00000000.00 111111
=>
Network:   172.16.10.0/26       10101100.00010000.00001010.00 000000
HostMin:   172.16.10.1          10101100.00010000.00001010.00 000001
HostMax:   172.16.10.62         10101100.00010000.00001010.00 111110
Broadcast: 172.16.10.63         10101100.00010000.00001010.00 111111
Hosts/Net: 62                    Class B, Private Internet
```

### Генерация списка IP-адресов (prips)

Сценарий: запуск сканирования или пинга по всем хостам подсети.

```bash
# Вывести все IP из сети /29
prips 192.168.1.0/29
# → 192.168.1.0
# → 192.168.1.1
# ...
# → 192.168.1.7
```

### Фильтрация логов по подсети (grepcidr)

Сценарий: найти все записи в логе веб-сервера, принадлежащие офисной сети.

```bash
grepcidr "192.168.50.0/24" access.log
```

### Продвинутая автоматизация на Python

Проверка пересечения сетей и суммирование диапазонов:

```python
import ipaddress

# 1. Проверка пересечения (Overlaps)
net1 = ipaddress.ip_network('10.0.0.0/24')
net2 = ipaddress.ip_network('10.0.0.128/25')
print(f"Пересекаются: {net1.overlaps(net2)}") # → True

# 2. Агрегация (Summarization)
networks = [
    ipaddress.ip_network('192.168.1.0/24'),
    ipaddress.ip_network('192.168.0.0/24')
]
summarized = list(ipaddress.collapse_addresses(networks))
print(f"Суммированная сеть: {summarized[0]}") # → 192.168.0.0/23
```

## Дополнительная информация

### Выбор инструмента

| Задача | Инструмент |
| :--- | :--- |
| Быстрая проверка IPv4 в консоли | `ipcalc` |
| Работа с IPv6 | `sipcalc` или `ipcalc-ng` |
| Генерация списка IP для циклов | `prips` |
| Фильтрация текста/логов по CIDR | `grepcidr` |
| Сложная логика, CI/CD пайплайны | **Python `ipaddress`** |

### Онлайн-сервисы

Для визуального планирования сетей удобно использовать:
- [jodies.de/ipcalc](http://jodies.de/ipcalc) — классический веб-калькулятор.
- [subnetonline.com](https://www.subnetonline.com/) — инструменты для расчёта IPv4/IPv6.
