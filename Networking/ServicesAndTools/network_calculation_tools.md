# Инструменты для сетевых расчётов

## Definitions

**Инструменты для сетевых расчётов** — утилиты для автоматизации вычислений параметров IP-сетей: адрес сети, широковещательный адрес, диапазон хостов, маска подсети, количество подсетей.

Для понимания концепций IP-адресации, масок подсети и методов расчёта см. [расчёт параметров подсети](../../Protocols/IP_addressing/subnetting_calculation.md).

## Basic Concepts

### ipcalc

`ipcalc` — утилита командной строки для Linux, выполняющая расчёты, связанные с IP-адресами и сетями. Работает с десятичной записью маски и нотацией [CIDR](../../Protocols/IP_addressing/special_masks.md#cidr-бесклассовая-междоменная-маршрутизация).

**Основные возможности:**

- Расчёт адреса сети, broadcast, wildcard-маски
- Определение диапазона доступных хостов
- Проверка типа адреса (network/host/broadcast)
- Генерация диапазона адресов

### sipcalc

`sipcalc` — расширенная версия ipcalc с поддержкой **IPv6** и дополнительными функциями. Выводит информацию в структурированном формате, поддерживает оба стека одновременно.

### Онлайн-инструменты

Для быстрых расчётов без CLI существуют веб-версии: [jodies.de/ipcalc](http://jodies.de/ipcalc) (онлайн-версия ipcalc) и [subnetonline.com](https://www.subnetonline.com/) (калькулятор подсетей с визуализацией).

## Practical Scenarios

### Базовый расчёт подсети (ipcalc)

Расчёт для `192.168.0.5/30`:

```bash
$ ipcalc 192.168.0.5/30
Address:   192.168.0.5          11000000.10101000.00000000.00000101
Netmask:   255.255.255.252 = 30 11111111.11111111.11111111.11111100
Wildcard:  0.0.0.3              00000000.00000000.00000000.00000011
=>
Network:   192.168.0.4/30       11000000.10101000.00000000.00000100
HostMin:   192.168.0.5          11000000.10101000.00000000.00000101
HostMax:   192.168.0.6          11000000.10101000.00000000.00000110
Broadcast: 192.168.0.7          11000000.10101000.00000000.00000111
Hosts/Net: 2                     Class C, Private Internet
```

**Расшифровка вывода:**

| Поле | Описание |
| :--- | :--- |
| `Address` | Указанный IP-адрес в десятичном и двоичном формате |
| `Netmask` | Маска подсети; `= 30` — нотация CIDR |
| `Wildcard` | [Обратная маска](../../Protocols/IP_addressing/special_masks.md), используется в ACL |
| `Network` | [Адрес сети](../../Protocols/IP_addressing/subnetting_calculation.md#шаг-3-расчет-адреса-сети-network-address) — первый IP в диапазоне, идентифицирует сеть |
| `HostMin` | Первый доступный IP для назначения хосту |
| `HostMax` | Последний доступный IP для назначения хосту |
| `Broadcast` | [Широковещательный адрес](../../Protocols/IP_addressing/subnetting_calculation.md#шаг-4-расчет-широковещательного-адреса-broadcast-address) для отправки всем хостам |
| `Hosts/Net` | Количество доступных хостов; `/30` = 2 хоста (point-to-point) |

> **Примечание:** Для point-to-point соединений существует маска `/31` (RFC 3021), использующая оба адреса. Подробнее — в [специальных масках](../../Protocols/IP_addressing/special_masks.md#маска-31-point-to-point-линки).

### Дополнительные команды ipcalc

```bash
# Проверка типа адреса
ipcalc -c 192.168.1.0/24      # network
ipcalc -c 192.168.1.5/24      # host
ipcalc -c 192.168.1.255/24    # broadcast

# Генерация диапазона адресов
ipcalc -r 192.168.1.0/24

# Проверка принадлежности хоста к сети
ipcalc -n 192.168.1.5 255.255.255.0
```

### Расчёт IPv6-подсети (sipcalc)

```bash
# Установка
sudo apt install sipcalc

# IPv4
$ sipcalc 192.168.1.100/26
- [ipv4 : 192.168.1.100/26]
Network range:    192.168.1.64 - 192.168.1.127
Prefix length:    26
Network address:  192.168.1.64/26
Netmask:          255.255.255.192
Wildcard:         0.0.0.63
Hosts / Net:      62
First host:       192.168.1.65
Last host:        192.168.1.126
Broadcast:        192.168.1.127

# IPv6
$ sipcalc 2001:db8::1/64
```

## Additional Information

### Интерпретация результатов для point-to-point линков

В примере `192.168.0.5/30` доступны 2 хоста: `192.168.0.5` и `192.168.0.6`. Если `192.168.0.5` — адрес одного устройства, то шлюзом (gateway) с высокой вероятностью будет `192.168.0.6`.
