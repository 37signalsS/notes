# SNMP (Simple Network Management Protocol)

## Определения

**SNMP (Simple Network Management Protocol)** — стандартный протокол прикладного уровня для управления и мониторинга сетевых устройств (маршрутизаторов, коммутаторов, серверов, принтеров) в IP-сетях.

**MIB (Management Information Base)** — иерархическая база данных, описывающая структуру данных управления устройством. Каждому объекту в MIB соответствует уникальный идентификатор OID.

**OID (Object Identifier)** — числовой идентификатор (например, `1.3.6.1.2.1.1.1.0`), указывающий на конкретный параметр в дереве MIB (например, описание системы).

## Базовые концепции

### Компоненты SNMP

1.  **SNMP Manager (NMS — Network Management System):** Система, которая опрашивает устройства и собирает данные (например, Zabbix, Prometheus с SNMP Exporter, Nagios).
2.  **SNMP Agent:** Программное обеспечение, запущенное на управляемом устройстве. Оно собирает данные локально и передает их менеджеру по запросу.
3.  **Managed Device:** Само устройство, на котором запущен агент.

### Версии протокола

| Версия | Безопасность | Особенности |
| :--- | :--- | :--- |
| **v1** | Низкая (Community String) | Первая версия, отсутствие защиты, только 32-битные счетчики. |
| **v2c** | Низкая (Community String) | Самая распространенная. Добавлены 64-битные счетчики и команда `GetBulk`. |
| **v3** | Высокая (User/Password/Encryption) | Добавлена аутентификация и шифрование (MD5/SHA, DES/AES). Рекомендуется для использования. |

### Основные операции

-   **Get:** Запрос конкретного значения параметра по его OID.
-   **GetNext:** Запрос следующего значения в дереве MIB (используется для обхода таблиц).
-   **GetBulk:** (v2/v3) Запрос сразу нескольких значений для ускорения обмена данными.
-   **Set:** Установка (изменение) значения параметра на устройстве (например, выключение порта).
-   **Trap:** Неинициированное сообщение от агента менеджеру о событии (например, «порт упал»).
-   **Inform:** Подтверждаемый Trap (менеджер должен подтвердить получение).

## Практические сценарии

### Использование портов

-   **UDP 161:** Порт агента (для запросов Manager → Agent).
-   **UDP 162:** Порт менеджера (для получения Trap/Inform от Agent → Manager).

### Популярные утилиты (snmpwalk, snmpget)

В Linux используются инструменты из пакета `net-snmp-utils`.

```bash
# Установка в Debian/Ubuntu
sudo apt install snmp snmp-mibs-downloader

# Получение описания системы (v2c)
snmpget -v2c -c public <IP_ADDRESS> 1.3.6.1.2.1.1.1.0

# Обход всего дерева MIB
snmpwalk -v2c -c public <IP_ADDRESS> 1.3.6.1.2.1
```

## Дополнительная информация

### Для чего используется SNMP?

1.  **Мониторинг производительности:** Сбор статистики по загрузке CPU, памяти, трафику на интерфейсах.
2.  **Инвентаризация:** Получение серийных номеров, версий прошивок и имен устройств.
3.  **Оповещение о сбоях:** Моментальное получение уведомлений (Traps) о критических событиях (перегрев, отказ питания, падение линка).
4.  **Удаленная конфигурация:** (Используется редко из-за рисков безопасности) Изменение параметров через `Set`.
