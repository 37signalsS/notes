# Namespace

**Namespace** (пространство имен) — это механизм для изоляции групп ресурсов внутри одного кластера Kubernetes. Он позволяет разделить один физический кластер на несколько виртуальных кластеров.

### Основные цели использования:

*   **Организация ресурсов:** Группировка ресурсов по проектам, командам или средам (например, `development`, `staging`, `production`).
*   **Предотвращение конфликтов имен:** Имена ресурсов должны быть уникальны в пределах одного пространства имен, но не во всем кластере.
*   **Управление доступом:** Применение политик RBAC (Role-Based Access Control) к конкретным пространствам имен, чтобы ограничить права пользователей.
*   **Квотирование ресурсов:** Установка квот на использование ресурсов (CPU, память, количество объектов) для каждого пространства имен.

---

### Стандартные пространства имен

При создании кластера Kubernetes создает несколько стандартных пространств имен:

*   `default`: Пространство имен по умолчанию для объектов, у которых оно не указано.
*   `kube-system`: Для объектов, созданных системой Kubernetes (например, компоненты control plane).
*   `kube-public`: Общедоступное пространство, читаемое всеми пользователями (даже неаутентифицированными). Используется редко.
*   `kube-node-lease`: Для объектов Lease, которые отслеживают доступность узлов.

---

### Работа с пространствами имен

#### Создание

```bash
# С помощью команды
kubectl create namespace my-namespace

# С помощью манифеста
cat <<EOF | kubectl apply -f -
apiVersion: v1
kind: Namespace
metadata:
  name: my-namespace
EOF
```

#### Указание пространства имен при работе с объектами

```bash
# Применить манифест к определенному пространству имен
kubectl apply -f my-pod.yaml -n my-namespace

# Получить поды из конкретного пространства имен
kubectl get pods -n my-namespace

# Получить поды из всех пространств имен
kubectl get pods --all-namespaces
# или
kubectl get pods -A
```

#### Переключение текущего контекста

Чтобы не указывать флаг `-n` каждый раз, можно изменить текущий контекст:

```bash
kubectl config set-context --current --namespace=my-namespace
```
