# Настройка синхронизации Obsidian с помощью Git и GitHub

Это руководство описывает, как настроить бесплатную и надёжную синхронизацию хранилища Obsidian между несколькими устройствами (ПК и мобильными) с использованием приватного репозитория на GitHub.

## Шаг 1: Создание приватного репозитория на GitHub

1.  **Авторизуйтесь** на [github.com](https://github.com).
2.  **Создайте новый репозиторий**, перейдя по ссылке [github.com/new](https://github.com/new).
3.  **Заполните форму**:
    *   **Repository name**: Придумайте имя (например, `obsidian-vault`).
    *   **Description**: Краткое описание (необязательно).
    *   **Privacy**: Выберите **Private**. Это гарантирует, что никто, кроме вас, не сможет получить доступ к вашим заметкам.
    *   **Initialize this repository with**: Поставьте галочку напротив `Add a README file`. Репозиторий не должен быть пустым.
4.  Нажмите **Create repository**.

5.  **Создайте файл `.gitignore`**, чтобы исключить из синхронизации системные файлы Obsidian:
    *   В созданном репозитории нажмите `Add file` -> `Create new file`.
    *   Назовите файл `.gitignore`.
    *   Вставьте в него следующий код:
        ```gitignore
        # Исключаем кеш, плагины и настройки рабочей области Obsidian
        .obsidian/
        ```
    *   Нажмите **Commit new file**.

## Шаг 2: Создание токена доступа (Personal Access Token)

Токен нужен, чтобы плагин Obsidian Git мог получить доступ к вашему репозиторию.

1.  Перейдите в настройки для разработчиков: [github.com/settings/tokens/new](https://github.com/settings/tokens/new).
2.  Выберите **Tokens (classic)**.
3.  Нажмите **Generate new token** -> **Generate new token (classic)**.
4.  **Заполните форму**:
    *   **Note**: Дайте токену понятное имя (например, `obsidian-sync-token`).
    *   **Expiration**: Установите срок действия. `No expiration` удобно, но менее безопасно. Рекомендуется выбрать **90 days** или **1 year** и обновить токен по истечении срока.
    *   **Select scopes**: Поставьте галочку напротив **`repo`**. Это даст токену права на чтение и запись в ваши репозитории.
5.  Нажмите **Generate token**.

> **⚠️ Важно!** Скопируйте и сохраните сгенерированный токен в надёжном месте (например, в менеджере паролей). GitHub покажет его только один раз.

## Шаг 3: Настройка на основном устройстве (ПК)

1.  **Установите Git**, если его нет. Проверить можно командой `git --version` в терминале. Если Git не найден, скачайте его с [git-scm.com/downloads](https://git-scm.com/downloads).

2.  **Настройте Git**, указав ваше имя и email (если не делали этого ранее):
    ```sh
    git config --global user.name "Your Name"
    git config --global user.email "your.email@example.com"
    ```

3.  **Клонируйте репозиторий**:
    *   Скопируйте HTTPS-ссылку на ваш репозиторий (кнопка `Code` -> `HTTPS`).
    *   Откройте терминал в папке, где вы хотите хранить хранилища Obsidian (например, `~/Documents/Obsidian`).
    *   Выполните команду:
        ```sh
        git clone https://github.com/<USERNAME>/<REPO_NAME>.git
        ```
        Пример: `git clone https://github.com/37signalsS/obsidian-vault.git`
    *   Git запросит ваше имя пользователя и пароль. В качестве пароля **вставьте ваш сохранённый токен доступа**.

4.  **Откройте хранилище в Obsidian**:
    *   Запустите Obsidian и выберите `Open folder as vault`.
    *   Укажите путь к папке, которую вы только что клонировали.

## Шаг 4: Установка и настройка плагина Obsidian Git

Этот плагин будет автоматически синхронизировать ваши изменения на всех устройствах.

1.  В Obsidian перейдите в `Settings` -> `Community plugins` -> `Browse`.
2.  Найдите и установите плагин **Obsidian Git**.
3.  **Включите плагин** после установки.
4.  Откройте **настройки плагина** (`Settings` -> `Obsidian Git`) и установите следующие параметры:

    *   **Vault backup interval (minutes)**: Установите `5` или `10`. Ежеминутная синхронизация (`1`) избыточна и может создавать лишнюю нагрузку.
    *   **Auto backup after stopping file edits**: `Включено`.
    *   **Pull updates on startup**: `Включено`. При запуске Obsidian будет автоматически загружать последние изменения.
    *   **Disable notifications**: `Включено`, чтобы избежать постоянных уведомлений о синхронизации.

## Шаг 5: Настройка на других устройствах (ПК и мобильные)

Процесс почти идентичен для всех устройств, где установлен Obsidian.

1.  **На ПК**: Повторите **Шаг 3** и **Шаг 4**.

2.  **На мобильных устройствах (Android/iOS)**:
    *   Установите и настройте **Obsidian Git** так же, как на ПК (Шаг 4).
    *   **Клонирование**: Вместо `git clone` в терминале, используйте палитру команд Obsidian:
        1.  Откройте палитру команд (`Ctrl+P` на ПК или смахните вниз на мобильном).
        2.  Найдите и выполните команду `Obsidian Git: Clone an existing remote repo`.
        3.  Вставьте HTTPS-ссылку на ваш репозиторий (без токена).
        4.  Плагин запросит данные для аутентификации. Введите ваш логин GitHub и **токен доступа**.
        5.  Укажите, куда на устройстве сохранить хранилище.

Теперь все ваши устройства будут автоматически синхронизироваться через GitHub, обеспечивая единую версию ваших заметок везде.
