## Шаг 1: Создание приватного репозитория на Github

1.  Авторизуйтесь на [github.com](https://github.com).
2.  Перейдите по ссылке [github.com/new](https://github.com/new) и укажите:
    *   Имя репозитория.
    *   Тип: **приватный**.
    *   Опционально: добавьте файл `README.md` (репозиторий не должен быть пустым).
3.  Нажмите кнопку "Create repository".
4.  В корне репозитория создайте файл `.gitignore` со следующим содержимым:

    ```
    .obsidian
    ```
# Шаг 2: Создание токена доступа

1.  Перейдите по ссылке [github.com/settings/tokens/new](https://github.com/settings/tokens/new) и укажите:
    *   Имя токена.
    *   Срок действия: **No Expiration** (бессрочный).
    *   Область действия (Scope): **repo**.
2.  Нажмите "Generate token".
3.  **Сохраните созданный токен.** Github покажет его только один раз. В случае утери придется создавать новый.

<details>
<summary>Для параноиков: создание токена с ограниченным доступом</summary>

Созданный по инструкции выше токен дает доступ ко всем вашим репозиториям. Если это некомфортно, есть два решения:

1.  **Создать "продвинутый" токен (Fine-grained token):**
    *   Выдать права только на конкретный репозиторий: `Repository permissions -> Contents: Read and Write`.
    *   Указать срок жизни токена (максимум 1 год, что неудобно из-за необходимости обновления).
2.  **Создать отдельный Github-аккаунт** специально для Obsidian и использовать на нем обычный токен.

## Шаг 3: Синхронизация с ПК (Windows, Linux, Mac)

### 3а: Клонирование репозитория

1.  **Убедитесь, что у вас установлен Git.**
    *   В терминале выполните команду `git --version`. Если появится номер версии, все в порядке.
    *   Если команда не найдена, установите Git с официального сайта [git-scm.com/downloads](https://git-scm.com/downloads).
    *   Выполните первоначальную настройку, указав ваше имя и email:
        ```sh
        git config --global user.email "ВАШ-EMAIL"
        git config --global user.name "ВАШЕ-ИМЯ"
        ```

2.  **Создайте папку для хранилищ Obsidian.** Например, `C:/OBSIDIAN` в Windows или `~/OBSIDIAN` в Linux.

3.  **Соберите HTTPS-ссылку для клонирования:**
    *   Формат: `https://<TOKEN>@github.com/<USERNAME>/<REPO>.git`
    *   Пример: `https://ghp_..._TOKEN...@github.com/my-account/my-obsidian-vault.git`

4.  **Выполните клонирование.**
    *   Откройте терминал, перейдите в созданную папку (`cd C:/OBSIDIAN`) и выполните команду:
        ```sh
        git clone https://<TOKEN>@github.com/<USERNAME>/<REPO>.git
        ```

> В результате в папке `OBSIDIAN` появится директория `my-obsidian-vault` с файлами из вашего репозитория.

### 3b: Настройка Obsidian и плагина Git

1.  В Obsidian откройте скачанную папку `my-obsidian-vault` как новое хранилище (`Open folder as vault`).
2.  Теперь можно наполнять хранилище заметками.

> **UPDATE:** В новых версиях плагина Obsidian-git термин "Backup" заменен на "Commit-and-sync".

1.  В настройках Obsidian (`Settings -> Community plugins`) найдите и установите плагин **Obsidian Git**.
2.  В настройках самого плагина установите:
    *   **Vault Backup Interval (minutes):** `1` (или другое значение по желанию).
    *   **Auto Backup after stopping file edits:** `ВКЛ`.
    *   **Pull updates on startup:** `ВКЛ`.
    *   **Disable notifications:** `ВКЛ` (чтобы не получать ежеминутные уведомления).

Теперь все изменения в хранилище будут автоматически отправляться в Github через минуту после окончания редактирования, а также подгружаться при запуске Obsidian.

> Если не хочется ждать, можно принудительно синхронизировать изменения через палитру команд (`CTRL+P`), введя "Git: Create backup".

## Шаг 4: Синхронизация с мобильным устройством (Android, iOS)

На мобильных устройствах используется другой плагин.

1.  Откройте мобильное приложение Obsidian.
2.  Создайте **новое пустое** хранилище.
3.  Внутри этого хранилища установите community-плагин **Fit**.
4.  В настройках плагина Fit:
    *   Вставьте ваш токен доступа из Шага 2.
    *   Нажмите **Authenticate user**.
    *   **Github repository name:** выберите ваш репозиторий из списка.
    *   **Branch name:** выберите `main`.
    *   **Auto sync:** выберите `Muted`.
    *   **Auto check interval:** установите `1` минуту.

Настройка завершена. Теперь мобильный клиент также будет синхронизироваться с Github.

### Недостатки плагина Fit

*   Плагин Fit не выполняет автоматическую синхронизацию при старте приложения. Чтобы подтянуть свежие изменения, нужно нажать на иконку с котиком ("Fit Sync").
*   При удалении папки на ПК, на мобильном устройстве файлы из нее удалятся, но сама пустая папка может остаться, и ее придется удалять вручную.
