# **Решение проблем с WireGuard**

---

### **Проблема: VPN "падает" после смены IP-адреса сервера**

**Симптомы:**

- У вас есть VPS-сервер с настроенным WireGuard.
- Интернет-провайдер предоставляет серверу динамический IP-адрес.
- После того как IP-адрес сервера меняется, VPN-туннель перестаёт работать, и клиенты не могут подключиться.

**Причина:**

WireGuard кэширует IP-адрес, на котором он слушает входящие подключения. Если публичный IP-адрес сервера меняется, WireGuard продолжает "слушать" на старом IP, и трафик от клиентов до него не доходит.

**Решение — автоматическая переинициализация WireGuard**

Нужно создать простой скрипт и systemd-таймер, который будет периодически "перезапускать" службу WireGuard, заставляя её перепривязываться к новому IP-адресу.

**1. Создайте скрипт `/usr/local/bin/wg-rebind.sh`**

Этот скрипт заставляет WireGuard переинициализировать свой слушающий сокет.

```bash
#!/bin/bash
#
# Скрипт для переинициализации WireGuard.
# Это заставляет WireGuard перепривязать свой сокет для прослушивания,
# что необходимо после смены IP-адреса на сервере.

# Имя вашего WireGuard-интерфейса
IFACE="wg0"
# Порт, который слушает WireGuard
PORT="51820"

# Переустанавливаем порт для прослушивания.
# Это действие заставляет WireGuard перепривязать сокет и "увидеть" новый IP-адрес.
wg set "$IFACE" listen-port "$PORT"
```

**2. Сделайте скрипт исполняемым**

```sh
sudo chmod +x /usr/local/bin/wg-rebind.sh
```

**3. Создайте systemd-сервис**

Создайте файл `/etc/systemd/system/wg-rebind.service`:

```ini
[Unit]
Description=Rebind WireGuard after IP change
# Запускаться после того, как сеть будет доступна
After=network-online.target
Wants=network-online.target

[Service]
Type=oneshot
ExecStart=/usr/local/bin/wg-rebind.sh
```

**4. Создайте systemd-таймер**

Создайте файл `/etc/systemd/system/wg-rebind.timer`, который будет запускать сервис каждые 5 минут.

```ini
[Unit]
Description=Run wg-rebind.sh every 5 minutes

[Timer]
# Запустить через 1 минуту после загрузки системы
OnBootSec=1min
# Запускать каждые 5 минут
OnUnitActiveSec=5min

[Install]
WantedBy=timers.target
```

**5. Активируйте и запустите таймер**

```sh
# Перезагрузить конфигурацию systemd
sudo systemctl daemon-reload
# Включить и запустить таймер
sudo systemctl enable --now wg-rebind.timer
```

**Вывод:**

Теперь systemd будет автоматически выполнять ваш скрипт каждые 5 минут. Если IP-адрес сервера изменится, WireGuard быстро "подхватит" новый адрес, и VPN-соединение восстановится без ручного вмешательства.

⚠️ **Важно:** Если вы используете файрвол или ваш хостинг-провайдер требует ручной настройки правил, не забудьте обновить их для нового IP-адреса, чтобы разрешить трафик на порт WireGuard.
