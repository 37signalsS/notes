# Краткое руководство по Tailscale и Headscale

Это руководство поможет вам быстро настроить и управлять VPN-сетью на базе Tailscale и собственного сервера Headscale.

## 1. Клиентские устройства

### 1.1. Регистрация нового устройства

Процесс состоит из двух шагов: получение ключа на клиентском устройстве и его регистрация на сервере Headscale.

**Шаг 1: Получение ключа на клиенте**

*   **Linux:**
    Выполните в терминале команду, указав адрес вашего сервера Headscale.
    ```bash
    # Замените <server_url> на адрес вашего сервера (https://headscale.magicfun.nnstd.dev)
    sudo tailscale up --login-server <server_url>
    ```
    Скопируйте ключ (`mkey...`), который появится в выводе.

*   **Windows / macOS / Android:**
    1.  В настройках приложения найдите опцию для использования альтернативного сервера (`Use alternative coordination server`).
    2.  Введите адрес вашего сервера Headscale: `<server_url>`.
    3.  Нажмите `Log in` или `Подключиться`. В браузере откроется страница с ключом аутентификации.
    4.  Скопируйте этот ключ (`mkey...`).

**Шаг 2: Регистрация ключа на сервере**

Подключитесь к вашему серверу Headscale (например, по SSH) и выполните команду:

```bash
# Замените <user> на имя пользователя (например, misha)
# Замените <key> на ключ, полученный на шаге 1
headscale nodes register --user <user> --key <key>
```

После успешного выполнения команды устройство автоматически подключится к VPN-сети.

### 1.2. Настройка Exit Node

Чтобы маршрутизировать весь трафик устройства через другой узел в вашей сети (exit node):

*   **Linux (командная строка):**
    ```bash
    # Замените <exit-node-name> на имя узла (например, kaguya)
    sudo tailscale set --exit-node-allow-lan-access=true --exit-node=<exit-node-name>
    ```
    Для отключения:
    ```bash
    sudo tailscale set --exit-node=""
    ```

*   **Windows / macOS / Android (графический интерфейс):**
    В настройках приложения найдите раздел "Exit Node" и выберите нужный узел из списка.

## 2. Управление сервером Headscale

Все команды выполняются на сервере, где установлен Headscale.

### 2.1. Управление пользователями

*   **Создание нового пользователя:**
    ```bash
    # Замените <username> на имя нового пользователя
    headscale users create <username>
    ```

### 2.2. Управление узлами (устройствами)

*   **Просмотр списка всех узлов:**
    ```bash
    headscale nodes list
    ```

*   **Удаление неактивного узла:**
    ```bash
    # Замените <ID> на номер узла из списка
    headscale nodes delete --identifier <ID>
    ```

### 2.3. Управление доступом (ACL)

Правила доступа между устройствами настраиваются в файле `acl.hujson` (или `acl.json`) на сервере.

**Пример `acl.hujson`:**

```hujson
{
  // Группы пользователей для удобного управления доступом.
  "groups": {
    "group:admins": ["user1@example.com", "misha"],
    "group:services": ["autogroup:self"],
  },

  // Определения хостов для статических IP или псевдонимов.
  "hosts": {
    "monitoring": "100.64.0.1",
    "kaguya-exit-node": "100.64.0.2",
  },

  // Основной раздел с правилами доступа.
  "acls": [
    // Администраторы имеют доступ ко всем устройствам.
    {
      "action": "accept",
      "src": ["group:admins"],
      "dst": ["*:*"],
    },
    // Разрешить всем в сети использовать exit-node.
    {
      "action": "accept",
      "src": ["autogroup:members"],
      "dst": ["kaguya-exit-node:*"],
    },
  ],

  // Тесты для проверки правил ACL (опционально).
  "tests": [
    {
      "src": "misha",
      "accept": ["monitoring:80"],
      "deny": ["100.64.0.3:22"],
    },
  ],
}
```

**Важно:** После внесения изменений в файл ACL перезапустите Headscale для их применения.

```bash
# Пример для Docker Compose
docker compose restart headscale

# Пример для systemd
sudo systemctl restart headscale
```
