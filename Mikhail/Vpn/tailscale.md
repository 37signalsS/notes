## Настройка Tailscale на Linux

**1. Подключение к Headscale (координационному серверу):**

```sh
sudo tailscale up --login-server https://headscale.magicfun.nnstd.dev
```

**2. Регистрация узла на сервере:**

После выполнения предыдущей команды, в терминале появится ключ. Его нужно использовать на сервере, где развернут Headscale.

```sh
# Замените <key> на ключ, полученный на предыдущем шаге
headscale nodes register --user misha --key <key>
```

**3. Настройка Exit Node (опционально):**

Для маршрутизации всего трафика через один из узлов сети (например, `kaguya`), выполните на клиентском устройстве:

```sh
# Замените kaguya на имя вашего exit-node
sudo tailscale set --exit-node-allow-lan-access=true --exit-node=kaguya
```

## Настройка Tailscale на Android

1.  В настройках приложения выберите пункт `Use alternative coordination server`.
2.  Введите адрес вашего сервера Headscale: `https://headscale.magicfun.nnstd.dev`
3.  Нажмите `Log in`. Браузер откроет страницу для аутентификации.
4.  Скопируйте ключ (mkey), который отобразится на странице.
5.  Зарегистрируйте устройство на сервере Headscale, используя скопированный ключ, как описано в шаге 2 для Linux.
6.  Вернитесь в приложение, оно должно автоматически подключиться.

## Управление узлами в Headscale

**Просмотр списка всех узлов:**

```sh
headscale nodes ls
```

**Удаление неактивного узла:**

```sh
# Замените <ID> на номер подключения из списка выше
headscale nodes delete -i <ID>
```

## Управление пользователями в Headscale

**Создание нового пользователя:**

```sh
# Замените <username> на имя нового пользователя
headscale users create <username>
```

**Добавление пользователя в группу доступа:**

Для предоставления доступа новому пользователю, необходимо отредактировать файл `acl.json` на сервере Headscale, добавив пользователя в соответствующую группу.

**Пример `acl.json`:**

```json
{
  "groups": {
    "group:admins": [
      "user1@example.com",
      "user2@example.com",
      "<username>" // Добавьте нового пользователя сюда
    ]
  },
  // ... другие правила
}
```

После сохранения изменений в `acl.json`, перезапустите Headscale для применения правил:

```sh
docker compose restart
```
