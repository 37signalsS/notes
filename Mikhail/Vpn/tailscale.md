# Инструкция по работе с Tailscale и Headscale

## 1. Регистрация нового устройства

На устройстве, которое вы хотите добавить в сеть, выполните команду подключения. В ответ вы получите ключ для регистрации.

*   **Для Linux (в терминале):**
    ```bash
    sudo tailscale up --login-server https://headscale.magicfun.nnstd.dev
    ```
*   **Для Android/Windows/macOS:**
    1.  В настройках приложения укажите альтернативный сервер: `https://headscale.magicfun.nnstd.dev`.
    2.  Нажмите `Log in`. В браузере откроется страница с ключом аутентификации (`mkey...`).
    3.  Скопируйте этот ключ.

**Шаг 2: Регистрация ключа на сервере Headscale**

Подключитесь к вашему серверу Headscale и выполните команду, используя ключ, полученный на предыдущем шаге.

```bash
# Замените <user> на имя пользователя (например, misha)
# Замените <key> на ключ, полученный от клиента
headscale nodes register --user <user> --key <key>
```

После успешной регистрации устройство автоматически подключится к VPN-сети.

## 2. Настройка клиентов

### 2.1. Linux

#### Маршрутизация трафика (Exit Node)

Чтобы направить весь трафик с клиентского устройства через другой узел сети (exit node), выполните команду:

```bash
# Замените <exit-node-name> на имя узла (например, kaguya)
sudo tailscale set --exit-node-allow-lan-access=true --exit-node=<exit-node-name>
```

Для отключения exit node:
```bash
sudo tailscale set --exit-node=""
```

## Настройка Tailscale на Android

1.  В настройках приложения выберите пункт `Use alternative coordination server`.
2.  Введите адрес вашего сервера Headscale: `https://headscale.magicfun.nnstd.dev`
3.  Нажмите `Log in`. Браузер откроет страницу для аутентификации.
4.  Скопируйте ключ (mkey), который отобразится на странице.
5.  Зарегистрируйте устройство на сервере Headscale, используя скопированный ключ, как описано в шаге 2 для Linux.
6.  Вернитесь в приложение, оно должно автоматически подключиться.

### 3.1. Управление узлами (Nodes)

**Просмотр списка всех узлов:**
```bash
headscale nodes ls
```

**Удаление неактивного узла:**
```bash
# Замените <ID> на номер узла из списка
headscale nodes delete -i <ID>
```

### 3.2. Управление пользователями (Users)

**Создание нового пользователя:**
```bash
# Замените <username> на имя нового пользователя
headscale users create <username>
```

### 3.3. Управление доступом (ACL)

Для предоставления доступа новому пользователю или изменения прав необходимо отредактировать файл `acl.json` на сервере Headscale.

**Пример `acl.json`:**

```json
{
  "groups": {
    "group:admins": [
      "user1@example.com",
      "user2@example.com",
      "<username>" // Добавьте нового пользователя сюда
    ]
  },
  // ... другие правила 
}
```

**Важно:** После внесения изменений в `acl.json` необходимо перезапустить Headscale для их применения.

```bash
# Если используется Docker Compose
docker compose restart

# Или перезапустите сервис systemd, если применимо
systemctl restart headscale
```
