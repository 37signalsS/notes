# Docker Swarm

**Docker Swarm** — это встроенная в Docker система оркестрации, которая позволяет объединить несколько хостов в единый виртуальный хост, или кластер. Swarm управляет развертыванием, масштабированием, сетевым взаимодействием и безопасностью контейнеризованных приложений.

---

### **Масштабирование сервисов**

Для горизонтального масштабирования сервиса (увеличения или уменьшения количества реплик) используется команда `docker service scale`.

```sh
# Установить количество реплик сервиса myservice равным 5
docker service scale myservice=5
```
