Клиент-серверная архитектура

Docker Daemon(управляет всем на основании пользовательских запросов)
- серверная часть
- работает на хост машине
- скачивает образы и запускает их них контейнеры
- создает сеть между контейнерами 
- собирает логи контейнеров 
- создает новый образ

Docker CLI
- консольная утилита для работы с Docker Daemon
- может работать не только локально, но и по сети

Image
- храниться в Docker registry 
- имеют hash, name and tag
- имеют слои
- создаются на основе Dockerfile

Dockerfile
- инструкция для создания образа
- каждая новая команда - новый слой(если слой уже создавался в другом контейнере то он будет переиспользован из кэша а не создан с 0)

Container

Docker registry
