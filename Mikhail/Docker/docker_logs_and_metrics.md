# Метрики Docker

## Метрики Docker демона

Чтобы включить метрики в Docker демоне, нужно добавить следующие параметры в конфигурационный файл `daemon.json`:

```json
{
  "experimental": true,
  "metrics-addr": "0.0.0.0:9100"
}
```

После этого можно получать метрики, обратившись по адресу:

```bash
curl 127.0.0.1:9100/metrics
```

## Внешние экспортеры

Когда встроенных метрик недостаточно, можно использовать внешние экспортеры:

*   [draganm/missing-container-metrics](https://github.com/draganm/missing-container-metrics)
*   [google/cadvisor](https://github.com/google/cadvisor)


## Метрики приложений

Для получения метрик от приложений, запущенных в контейнерах, достаточно опубликовать соответствующий порт:

```bash
docker run -p 8080:8080 -p 9090:9090 my-app
```

Хорошей практикой является отдача метрик на эндпоинт `/metrics`.

---

### **Мониторинг ресурсов**

- Инфа о использовании ресурсов всех запущенных контейнеров
```sh
docker stats
```

- Инфа о использовании ресурсов запущенного контейнеров
```sh
docker stats <container_id>
```

- Показывает однократный снимок статистики по ресурсам (CPU, память, сеть) всех контейнеров.
```sh
docker stats --no-stream
```

- Cколько пространства на диске занимают образы, контейнеры, сети и тома в Docker
```sh
docker system df
```

---

### **Логирование**

- Смотрим логи
```sh
docker logs --tail 30 <container_id>
```

- Смотреть логи в реальном времени
```sh
docker logs -f <container_name>
```


## Docker Stats и cgroups

Команда `docker stats` показывает текущее потребление ресурсов контейнерами.

Метрики также доступны в псевдофайлах cgroups:

*   `/sys/fs/cgroup/memory/docker/<longid>/memory.stat`
*   `/sys/fs/cgroup/cpu/docker/<longid>/cpuacct.stat`

## cAdvisor

cAdvisor (Container Advisor) от Google предоставляет детальную информацию о ресурсах и производительности контейнеров в удобном виде.

## ctop

`ctop` - это утилита командной строки, похожая на `top`, но предназначенная для мониторинга метрик контейнеров в реальном времени.
