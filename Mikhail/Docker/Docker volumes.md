
Что предлагает Docker для хранения данных

- docker volumes:  
  Это просто файл на диске (`/var/lib/docker/volumes/`), доступ только через контейнер. Один том может использоваться несколькими контейнерами. Docker при удалении контейнера не удаляет volumes.

- Подключение каталога с хоста в контейнер (bind mount)
  Обычное монтирование. Если Docker запущен с root-правами — могут возникнуть проблемы с доступом и правами к файлам.

- Монтирование tmpfs
  Размещается в оперативной памяти. Высокая скорость. 100% вероятность потерять данные при остановке контейнера.

- Другие варианты: NFS, Ceph, S3


Пример монтирования при запуске (src — на хосте, dst — в контейнере, имя volumes = то, что написано в src)

```sh
docker run --name webserver \
--mount type=bind,src=/src/www,dst=/avar/www,readonly \
-p 80:80 -d nginx:1.17

Создать volumes:

``` sh
docker volumes creat имя
```

Удалить volumes:

``` sh
docker volumes rm имя
```

 Узнать где храниться volumes:
 
``` sh
docker inspect имя_volumes
```

При монтировании лучше всего указывать абсолютные пути

Можно при старте добавлять несколько --mount

Можно добавить --volumes-from имя_контейнера дабы перенести в новый контейнер все mount другого контейнера

С хоста в volumes не лазить, только через контейнер
