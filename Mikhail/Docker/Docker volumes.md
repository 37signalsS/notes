# **Docker Volumes**

Docker предлагает несколько способов для хранения данных, чтобы они не терялись после остановки или удаления контейнера.

---

### **Способы хранения данных**

1.  **Docker Volumes (Тома)**
    - **Что это:** Специальная директория на хосте (обычно в `/var/lib/docker/volumes/`), полностью управляемая Docker.
    - **Преимущества:**
        - Безопасность: Доступ к данным осуществляется только через контейнер.
        - Персистентность: Docker не удаляет тома при удалении контейнера.
        - Переносимость: Один том может использоваться несколькими контейнерами.

2.  **Bind Mounts (Монтирование каталога с хоста)**
    - **Что это:** Прямое монтирование файла или директории с хостовой системы в контейнер.
    - **Недостатки:**
        - Проблемы с правами: Если Docker запущен с root-правами, могут возникнуть конфликты прав доступа к файлам.
        - Зависимость от хоста: Структура файлов на хосте напрямую влияет на контейнер.

3.  **tmpfs Mounts (Монтирование в память)**
    - **Что это:** Данные хранятся в оперативной памяти хоста.
    - **Преимущества:** Высокая скорость доступа.
    - **Недостатки:** Данные полностью теряются при остановке контейнера.

4.  **Другие варианты**
    - Существуют плагины для использования сетевых хранилищ, таких как NFS, Ceph или S3.

---

### **Основные команды для управления томами**

- **Создать том:**
  ```sh
docker volume create <имя_тома>
  ```

- **Удалить том:**
  ```sh
docker volume rm <имя_тома>
  ```

- **Посмотреть информацию о томе (включая путь на хосте):**
  ```sh
docker volume inspect <имя_тома>
  ```

---

### **Примеры и лучшие практики**

- **Монтирование `bind mount` при запуске контейнера:**
  В этом примере мы монтируем директорию `/src/www` с хоста в `/var/www` в контейнере в режиме "только для чтения".
  ```sh
docker run --name webserver \
    --mount type=bind,src=/src/www,dst=/var/www,readonly \
    -p 80:80 -d nginx:1.17
  ```

- **Использование `--volumes-from` (устарело):**
  Можно было перенести все тома из одного контейнера в другой с помощью флага `--volumes-from <имя_контейнера>`. В современных версиях Docker рекомендуется использовать именованные тома и подключать их к нескольким контейнерам.

- **Рекомендации:**
    - **Абсолютные пути:** При монтировании всегда указывайте абсолютные пути.
    - **Доступ к томам:** Не изменяйте данные в томах напрямую с хоста. Управляйте ими через контейнеры.
    - **Несколько монтирований:** К одному контейнеру можно подключить несколько томов, используя несколько флагов `--mount` или `--volume`.
