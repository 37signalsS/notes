# Заметки по работе с Google Gemini CLI

## Контекст проекта

Для эффективной работы с Gemini CLI рекомендуется создать файл `Gemini.md` в корне проекта. Этот файл должен содержать:

-   **Начальный промпт (Initial Prompt)**: Определяет роль и задачи Gemini в рамках проекта.
-   **Ключевые инструкции**: Любые другие важные указания для Gemini.

## Основные команды и возможности

### Управление сессиями

-   **Сохранение чата**:

    ```
    /chat save <имя_сессии>
    ```

### Работа с файлами

-   **Анализ проекта**: Перед началом работы попросите Gemini проанализировать текущий проект.
-   **Работа с изображениями**: Gemini может анализировать изображения. Укажите путь к файлу относительно директории, в которой запущен CLI.

### Работа со ссылками

-   Gemini может обрабатывать информацию по ссылкам. Просто передайте URL в запросе.
    -   Пример: `Проанализируй статью: https://example.com`
