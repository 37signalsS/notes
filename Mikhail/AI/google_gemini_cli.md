# Google Gemini CLI

## Основные возможности и рабочие процессы

### Работа с файлами

-   **Анализ проекта**: Перед началом работы над задачами, рекомендуется попросить Gemini проанализировать текущий проект.

-   **Сохранение контекста**: Результаты анализа и ключевые инструкции для Gemini следует сохранять в файл `Gemini.md` в корне проекта. Этот файл будет служить основным источником контекста для всех последующих запросов.
    -   В `Gemini.md` можно включить начальный промпт (initial prompt) для определения роли и задач Gemini в рамках проекта.
-   **Работа с изображениями**: Gemini может анализировать изображения. Для этого необходимо указать путь к файлу изображения относительно директории, в которой запущен CLI.

### Работа со ссылками

-   Gemini может обрабатывать информацию по ссылкам. Просто передайте URL в запросе.
    -   [Видео про установку Gemini](https://www.youtube.com/watch?v=SRasGkyiLFk&list=WL&index=3&t=158s)

### Управление сессиями

-   **Сохранение чата**: Для сохранения текущей сессии чата можно использовать команду:
    ```
    /chat save <имя_сессии>
    ```
