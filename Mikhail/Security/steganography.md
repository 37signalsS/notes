# CryptoFrame — Видеостеганография
- **Ссылка:** [github.com/x011/CryptoFrame](https://github.com/x011/CryptoFrame)

CryptoFrame - это инструмент, который шифрует текст и скрывает его в видеофайле, используя стеганографию. В отличие от SecretPixel, который работает с изображениями, CryptoFrame предназначен для видео и использует 7 слоев шифрования.

## Метод работы

CryptoFrame использует метод **Least Significant Bit (LSB)** — запись информации в наименее значимый бит.

1.  Видео состоит из кадров, которые состоят из пикселей.
2.  Цвет каждого пикселя кодируется в формате RGB (красный, зеленый, синий).
3.  Значение каждого цветового канала представлено в битах. Скрываемый текст также преобразуется в биты.
4.  Метод LSB заменяет последний, наименее значимый бит в значении цвета пикселя на бит скрываемого сообщения. Это изменение настолько минимально, что визуально незаметно.

Биты скрытых данных распределяются по разным пикселям и кадрам, что усложняет их обнаружение. Из-за этого CryptoFrame работает с любыми форматами видео на входе, но на выходе создает видео, сжатое **только кодеками без потерь** (lossless). Это гарантирует, что скрытые данные не будут повреждены или утеряны в процессе сжатия.

## Технические детали

- **Исходный код:** Открытый, на Python.
- **Платформы:** Linux, Windows, macOS (везде, где есть Python 3+).
- **Зависимости:** 6 зависимостей, включая OpenSSL.
- **Входные форматы видео:** AVI, MKV, MOV, MP4, OGG, WMV, WEBM.
- **Выходные форматы видео:** AVI, MOV, MKV.
- **Кодеки на выходе (lossless):**
    - `FFV1`: Меньший размер, хорошая поддержка.
    - `HFYU`: Больший размер.
- **Шифрование:**
    - **Данные:** AES-256-CBC.
    - **Ключ AES:** Шифруется с помощью RSA-4096. Требуется генерация пары ключей и установка парольной фразы.
