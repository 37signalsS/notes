### **В чем разница между одинарными и двойными кавычками в Linux?**

1. **Одинарные кавычки (`'`):**

- Всё, что заключено в одинарные кавычки, интерпретируется **буквально** .

- Специальные символы (например, `$`, `\`, `` ` ``) внутри одинарных кавычек **не обрабатываются** и выводятся как есть.

```sh
echo '$HOME is not expanded'
```

$HOME is not expanded

2. **Двойные кавычки (`"`):**

- Двойные кавычки позволяют использовать **интерполяцию** (подстановку значений).
    
- Переменные (`$variable`), обратные кавычки (`` `command` ``) и escape-последовательности (`\n`, `\t`) внутри двойных кавычек **обрабатываются** .

```sh
echo "Your home directory is $HOME"
```

Your home directory is /home/username

# **Grep**

Поиск без учета регистра:

```sh
grep -i  "error"
```

Показывает две строки до и три после каждой ошибки для контекста

```sh
grep -A3 -B2 "error"
```

Для поиска, присутствует ли ключевое слово в файле в текущем каталоге:

```sh
grep -win <keyword> ./*.txt 
```

--color - выделить совпадения цветом; -w - поиск только целых слов, найдет sh, но не найдет bash; -r - рекурсивый поиск по всем файлам в указанной директории; -E - использование регулярных выражений; -v - исключить определенный строки из вывода 

```sh
grep --color -Ewri '(exploit|backdoor|malware|virus|trojan|hack|rootkit|192.20.1.2|:9204|/dev/tcp|sh|ptrace|Landlock|error|fail|warn)' /var/log/*.log dmesg.txt | grep -v 'No such file or directory'
```

# **Hotkeys**

Ctrl + A — переход к началу строки.
Ctrl + E — переход в конец строки.
Ctrl + U — удаление от курсора до начала строки.
Ctrl + K — удаление от курсора до конца строки.
Ctrl + W — удаление слова перед курсором.
Ctrl <> - переход по словам 
cd - - переход в предыдущую папку
