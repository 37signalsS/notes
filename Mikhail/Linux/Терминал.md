# Работа в терминале Linux

## Кавычки: одинарные vs двойные

### 1. Одинарные кавычки (`'`)

Всё, что заключено в одинарные кавычки, интерпретируется **буквально**. Специальные символы, такие как `, `\`, `` ` ``, не обрабатываются.

```sh
echo 'Переменная $HOME не будет раскрыта'
```
Вывод:
```text
Переменная $HOME не будет раскрыта
```

### 2. Двойные кавычки (`"`)

Двойные кавычки позволяют оболочке **интерпретировать** специальные символы. Это называется подстановкой (interpolation).

-   Переменные (`$VAR`) заменяются их значениями.
-   Конструкции `` `команда` `` или `$(команда)` заменяются результатом выполнения команды.

```sh
echo "Ваш домашний каталог: $HOME"
```
Вывод:
```text
Ваш домашний каталог: /home/username
```

## Переменные: локальные и окружения

Основное различие между `VAR="VALUE"` и `export VAR="VALUE"` заключается в **области видимости** переменной.

- **`VAR="VALUE"` (Локальная переменная):**
  - Создает переменную, доступную **только в текущем экземпляре оболочки**.
  - Дочерние процессы, запущенные из этой оболочки, не унаследуют эту переменную.

- **`export VAR="VALUE"` (Переменная окружения):**
  - Создает переменную и делает её частью окружения.
  - Переменная становится доступной не только в текущей оболочке, но и **во всех дочерних процессах**.

## Операторы управления командами

-   **`&` (Фоновый режим):** Запускает команду в фоновом режиме, не блокируя терминал.
    ```sh
sleep 10 &
    ```
-   **`;` (Последовательное выполнение):** Выполняет команды одну за другой, независимо от успеха предыдущей.
    ```sh
echo "Первая"; echo "Вторая"
    ```
-   **`&&` (Логическое И):** Вторая команда выполняется только в том случае, если первая завершилась успешно (код выхода 0).
    ```sh
mkdir -p temp_dir && cd temp_dir
    ```
-   **`||` (Логическое ИЛИ):** Вторая команда выполняется только в том случае, если первая завершилась с ошибкой (код выхода не 0).
    ```sh
ping -c 1 nonexistent-host || echo "Хост недоступен"
    ```
-   **`|` (Канал, pipe):** Перенаправляет стандартный вывод (`stdout`) одной команды на стандартный ввод (`stdin`) другой.
    ```sh
ps aux | grep "nginx"
    ```
-   **`|&` (Канал для stdout и stderr):** Перенаправляет и `stdout`, и `stderr`.

## Перенаправление ввода/вывода

-   **`>` (Перезапись файла):** Перенаправляет `stdout` в файл, перезаписывая его содержимое.
    ```sh
echo "Hello" > file.txt
    ```
-   **`>>` (Добавление в файл):** Перенаправляет `stdout` в файл, добавляя вывод в конец.
    ```sh
echo "World" >> file.txt
    ```
-   **`<` (Ввод из файла):** Использует содержимое файла как `stdin` для команды.
    ```sh
sort < file.txt
    ```
-   **`2>` (Перенаправление ошибок):** Перенаправляет `stderr` (дескриптор 2) в файл.
    ```sh
ls /nonexistent_dir 2> errors.txt
    ```
-   **`&>` (Перенаправление всего вывода):** Перенаправляет `stdout` и `stderr` в один файл.
    ```sh
ls / /nonexistent_dir &> output_and_errors.txt
    ```

## Полезные утилиты

### `grep`

`grep` — утилита для поиска текста по шаблону.

-   `-i`: Поиск без учёта регистра.
-   `-w`: Поиск только целых слов.
-   `-r` или `-R`: Рекурсивный поиск по всем файлам в директории.
-   `-v`: Инвертировать поиск (показать строки, которые *не* совпадают).
-   `-E`: Использовать расширенные регулярные выражения.
-   `-A<N>`: Показать `N` строк **после** совпадения.
-   `-B<N>`: Показать `N` строк **до** совпадения.
-   `--color`: Выделить совпадения цветом.

**Пример:** Рекурсивный поиск по логам подозрительных слов, исключая определённые сообщения.
```sh
grep --color -Ewri '(exploit|backdoor|malware|error|fail)' /var/log/ | grep -v 'No such file'
```

## Горячие клавиши (Hotkeys)

-   `Ctrl + A`: Переместить курсор в начало строки.
-   `Ctrl + E`: Переместить курсор в конец строки.
-   `Ctrl + U`: Удалить всё от курсора до начала строки.
-   `Ctrl + K`: Удалить всё от курсора до конца строки.
-   `Ctrl + W`: Удалить слово слева от курсора.
-   `Alt + B` или `Ctrl + LeftArrow`: Переместиться на слово назад.
-   `Alt + F` или `Ctrl + RightArrow`: Переместиться на слово вперёд.
-   `Ctrl + L`: Очистить экран терминала.
-   `Ctrl + R`: Поиск по истории команд.
-   `cd -`: Вернуться в предыдущую рабочую директорию.
