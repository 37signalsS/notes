### **В чем разница между одинарными и двойными кавычками в Linux?**

1. **Одинарные кавычки (`'`):**

- Всё, что заключено в одинарные кавычки, интерпретируется **буквально** .

- Специальные символы (например, `$`, `\`, `` ` ``) внутри одинарных кавычек **не обрабатываются** и выводятся как есть.

```
echo '$HOME is not expanded'
```

$HOME is not expanded

2. **Двойные кавычки (`"`):**

- Двойные кавычки позволяют использовать **интерполяцию** (подстановку значений).
    
- Переменные (`$variable`), обратные кавычки (`` `command` ``) и escape-последовательности (`\n`, `\t`) внутри двойных кавычек **обрабатываются** .

```
echo "Your home directory is $HOME"
```

Your home directory is /home/username

# **Grep**

Поиск без учета регистра:

```sh
grep -i  "error"
```

Показывает две строки до и три после каждой ошибки для контекста

```sh
grep -A3 -B2 "error"
```

Для поиска, присутствует ли ключевое слово в файле в текущем каталоге:

```sh
grep -win <keyword> ./*.txt 
```
