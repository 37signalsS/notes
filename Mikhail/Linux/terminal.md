# Работа в терминале Linux

## Кавычки: одинарные vs двойные

### 1. Одинарные кавычки (`'`) 

Всё, что заключено в одинарные кавычки, интерпретируется **буквально**. Специальные символы, такие как `$`, `\`, ``` ` ```, не обрабатываются.

```sh
 echo 'Переменная $HOME не будет раскрыта'
```
Вывод:
```text
Переменная $HOME не будет раскрыта
```

### 2. Двойные кавычки (`"`) 

Двойные кавычки позволяют оболочке **интерпретировать** специальные символы. Это называется подстановкой (interpolation).

-   Переменные (`$VAR`) заменяются их значениями.
-   Конструкции `` `команда` `` или `$(команда)` заменяются результатом выполнения команды.

```sh
 echo "Ваш домашний каталог: $HOME"
```
Вывод:
```text
Ваш домашний каталог: /home/username
```

## Переменные: локальные и окружения

Основное различие между `VAR="VALUE"` и `export VAR="VALUE"` заключается в **области видимости** переменной.

- **`VAR="VALUE"` (Локальная переменная):**
  - Создает переменную, доступную **только в текущем экземпляре оболочки**.
  - Дочерние процессы, запущенные из этой оболочки, не унаследуют эту переменную.

- **`export VAR="VALUE"` (Переменная окружения):**
  - Создает переменную и делает её частью окружения.
  - Переменная становится доступной не только в текущей оболочке, но и **во всех дочерних процессах**.

## Операторы управления командами

-   **`&` (Фоновый режим):** Запускает команду в фоновом режиме, не блокируя терминал.
    ```sh
    sleep 10 &
    ```
-   **`;` (Последовательное выполнение):** Выполняет команды одну за другой, независимо от успеха предыдущей.
    ```sh
    echo "Первая"; echo "Вторая"
    ```
-   **`&&` (Логическое И):** Вторая команда выполняется только в том случае, если первая завершилась успешно (код выхода 0).
    ```sh
    mkdir -p temp_dir && cd temp_dir
    ```
-   **`||` (Логическое ИЛИ):** Вторая команда выполняется только в том случае, если первая завершилась с ошибкой (код выхода не 0).
    ```sh
    ping -c 1 nonexistent-host || echo "Хост недоступен"
    ```
-   **`|` (Канал, pipe):** Перенаправляет стандартный вывод (`stdout`) одной команды на стандартный ввод (`stdin`) другой.
    ```sh
    ps aux | grep "nginx"
    ```
-   **`|&` (Канал для stdout и stderr):** Перенаправляет и `stdout`, и `stderr`.

## Перенаправление ввода/вывода

-   **`>` (Перезапись файла):** Перенаправляет `stdout` в файл, перезаписывая его содержимое.
    ```sh
    echo "Hello" > file.txt
    ```
-   **`>>` (Добавление в файл):** Перенаправляет `stdout` в файл, добавляя вывод в конец.
    ```sh
    echo "World" >> file.txt
    ```
-   **`<` (Ввод из файла):** Использует содержимое файла как `stdin` для команды.
    ```sh
    sort < file.txt
    ```
-   **`2>` (Перенаправление ошибок):** Перенаправляет `stderr` (дескриптор 2) в файл.
    ```sh
    ls /nonexistent_dir 2> errors.txt
    ```
-   **`&>` (Перенаправление всего вывода):** Перенаправляет `stdout` и `stderr` в один файл.
    ```sh
    ls / /nonexistent_dir &> output_and_errors.txt
    ```

## Полезные утилиты

### `grep`

`grep` — утилита для поиска текста по шаблону.

-   `-i`: Поиск без учёта регистра.
-   `-w`: Поиск только целых слов.
-   `-r` или `-R`: Рекурсивный поиск по всем файлам в директории.
-   `-v`: Инвертировать поиск (показать строки, которые *не* совпадают).
-   `-E`: Использовать расширенные регулярные выражения.
-   `-A<N>`: Показать `N` строк **после** совпадения.
-   `-B<N>`: Показать `N` строк **до** совпадения.
-   `--color`: Выделить совпадения цветом.

**Пример:** Рекурсивный поиск по логам подозрительных слов, исключая определённые сообщения.
```sh
 grep --color -Ewri '(exploit|backdoor|malware|error|fail)' /var/log/ | grep -v 'No such file'
```

## Vim

Vim - мощный текстовый редактор с несколькими режимами работы.

### Режимы

-   **Нормальный режим (Normal Mode):** Основной режим для навигации и манипуляций текстом. Включается по умолчанию или по нажатию `Esc` / `Ctrl + c` / `Ctrl + [`.
-   **Режим вставки (Insert Mode):** Режим для набора текста. Включается командами `i`, `a`, `o` и др.
-   **Визуальный режим (Visual Mode):** Режим для выделения текста. Включается `v` (символьное), `V` (построчное), `Ctrl+v` (блочное).
-   **Командный режим (Command-Line Mode):** Режим для выполнения команд, начинающихся с `: `.

### Навигация

-   `h`, `j`, `k`, `l`: Перемещение влево, вниз, вверх, вправо.
-   `w`: Переместиться на начало следующего слова.
-   `b`: Переместиться на начало предыдущего слова.
-   `e`: Переместиться в конец текущего слова.
-   `gg`: В начало файла.
-   `G`: В конец файла.
-   `<N>G` или `:<N>`: Переместиться на строку с номером `N` (например, `20G`).
-   `^`: В начало строки (на первый непустой символ).
-   `0`: В самое начало строки (на первый символ).
-   `$`: В конец строки.
-   `H`, `M`, `L`: Переместиться на верх, середину, низ экрана.

### Редактирование

-   `i`: Перейти в режим вставки **перед** курсором.
-   `a`: Перейти в режим вставки **после** курсором.
-   `o`: Вставить новую строку **ниже** текущей и перейти в режим вставки.
-   `O`: Вставить новую строку **выше** текущей и перейти в режим вставки.
-   `dd`: Удалить (вырезать) текущую строку.
-   `dw`: Удалить (вырезать) слово.
-   `d$`: Удалить (вырезать) от курсора до конца строки.
-   `yy`: Скопировать текущую строку.
-   `yw`: Скопировать слово.
-   `p`: Вставить **после** курсора.
-   `P`: Вставить **перед** курсором.
-   `u`: Отменить последнее действие.
-   `Ctrl + r`: Вернуть отмененное действие (redo).
-   `x`: Удалить символ под курсором.
-   `r`: Заменить один символ под курсором.
-   `cw`: Заменить слово.
-   `J`: Объединить текущую строку со следующей.

### Визуальный режим и выделение

-   `v`: Включить визуальный режим (символьный).
-   `V` (Shift+v): Включить визуальный режим (построчный).
-   `Ctrl + v`: Включить визуальный режим (блочный).
-   `viw`: Выделить слово под курсором (inner word).
-   `vaw`: Выделить слово и пробел после него (a word).
-   `>`: Сдвинуть выделенный блок вправо (отступ).
-   `<`: Сдвинуть выделенный блок влево.
-   `=`: Автоматически выровнять выделенный код.

### Поиск и замена

-   `/pattern`: Искать `pattern` от курсора вниз.
-   `?pattern`: Искать `pattern` от курсора вверх.
-   `n`: Найти следующее вхождение.
-   `N`: Найти предыдущее вхождение.
-   `*`: Искать слово под курсором (вперед).
-   `#`: Искать слово под курсором (назад).
-   `:%s/old/new/g`: Заменить все (`g`) вхождения `old` на `new` во всем файле (`%`).
-   `:%s/old/new/gc`: То же, но с подтверждением (`c`) каждой замены.

### Работа с файлами (Командный режим)

-   `:w`: Сохранить изменения.
-   `:q`: Выйти.
-   `:wq` или `:x`: Сохранить и выйти.
-   `:q!`: Выйти без сохранения.

## Горячие клавиши терминала Linux

### Перемещение курсора:
*   **Ctrl+a** - перейти в начало строки.
*   **Ctrl+e** - перейти в конец строки.
*   **Alt+b** - перейти влево на одно слово.
*   **Alt+f** - перейти в право на одно слово.
*   **Ctrl+b** - перейти влево на один символ.
*   **Ctrl+f** - перейти вправо на один символ.
*   **Ctrl+xx** - перейти в конец или в начало строки.

### Редактирование:
*   **Ctrl+u** - вырезать строку до позиции курсора.
*   **Alt+Del** - удалить слово перед курсором.
*   **Alt+d** - удалить слово после курсора.
*   **Ctrl+d** - удалить символ под курсором.
*   **Ctrl+h** - удалить символ под курсором.
*   **Ctrl+w** - вырезать слово под курсором.
*   **Ctrl+k** - вырезать строку от позиции курсора до конца строки
*   **Alt+t** - поменять текущее слово с предыдущим.
*   **Ctrl+t** - поменять местами два символа перед курсором.
*   **Esc+t** - поменять местами два слова перед курсором.
*   **Ctrl+y** - вставить то, что было вырезано.
*   **Alt+u** - сделать верхний регистр символов от позиции курсора до конца текущего слова.
*   **Alt+l** - сделать нижний регистр символов от позиции курсора до конца слова.
*   **Alt+c** - перевести символ под курсором в верхний регистр и перейти к концу слова.
*   **Alt+r** - вернуть строку в исходное состояние.
*   **Ctrl+_** - отменить последнее действие со строкой.
*   **Alt+Shift+#** - закомментировать текущую строку (команда не выполнится, но сохранится в истории).

### 1. Эмулятор терминала (Terminal Emulator)

Это **графическое приложение**, то есть окно, которое вы открываете, чтобы начать работу. Его единственная задача — предоставить вам интерфейс для взаимодействия с оболочкой (шеллом), обрабатывать ввод с клавиатуры и отображать текстовый вывод.

### 2. Шел / Оболочка (Shell)

Это **программа-интерпретатор**, которая работает *внутри* эмулятора терминала. Именно она принимает ваши команды, "понимает" их и говорит ядру операционной системы, что нужно сделать. Она также отвечает за переменные окружения (`$PATH`), скрипты (например, `.bashrc`) и управление процессами.

### 3. Командная строка (Command Line)

Это и есть сам **текстовый интерфейс** для ввода команд, который предоставляет вам шелл. Если точнее, это одна строка, в которой вы печатаете команду. Она обычно начинается с приглашения (prompt), например `user@hostname:~$`.
