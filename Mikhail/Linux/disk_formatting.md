# Форматирование и автоматическое монтирование диска в Linux

Это руководство описывает процесс форматирования диска и его настройки для автоматического монтирования при загрузке системы. Мы рассмотрим наиболее надёжный способ монтирования через **UUID**.

## Шаг 1: Определение диска

Сначала найдите диск, который вы хотите отформатировать. Используйте команду `lsblk`, чтобы увидеть список всех блочных устройств.

```bash
lsblk
```

Найдите в списке нужный диск (например, `/dev/sdb`). Будьте внимательны, чтобы не выбрать системный диск.

## Шаг 2: Форматирование диска

**ВНИМАНИЕ:** Следующая команда уничтожит все данные на указанном диске. Убедитесь, что вы выбрали правильное устройство.

Отформатируем диск в файловую систему `ext4`. Мы также зададим метку (`LABEL`) с помощью флага `-L`, что может быть полезно для идентификации.

```bash
mkfs.ext4 -L data /dev/sdb
```

*   `-L data`: Задаёт метку `data`. Вы можете выбрать любую другую.
*   `/dev/sdb`: Устройство, которое вы форматируете.
*   Если нужна другая файловая система (например, XFS), используйте `mkfs.xfs`.

## Шаг 3: Создание точки монтирования

Создайте каталог, куда будет монтироваться диск.

```bash
sudo mkdir /data
```

## Шаг 4: Настройка автоматического монтирования через `/etc/fstab`

Чтобы диск монтировался автоматически при каждой загрузке системы, нужно добавить запись в файл `/etc/fstab`. Самый надёжный способ — использовать **UUID** диска, так как он уникален и не меняется, в отличие от имени устройства (`/dev/sdb`).

### 4.1. Получение UUID

Узнайте UUID вашего нового отформатированного раздела:

```bash
blkid /dev/sdb
```
Или так:
```bash
lsblk -f
```

Вывод будет примерно таким:
```
/dev/sdb: LABEL="data" UUID="4f5d3a1c-8b32-4e9a-9c4d-7f1b8e6d2a0a" TYPE="ext4"
```
Скопируйте значение `UUID`.

### 4.2. Редактирование `/etc/fstab`

Откройте `/etc/fstab` в текстовом редакторе с правами суперпользователя:

```bash
sudo vim /etc/fstab
```

Добавьте в конец файла следующую строку, подставив ваш `UUID` и точку монтирования:

```
UUID=4f5d3a1c-8b32-4e9a-9c4d-7f1b8e6d2a0a  /data  ext4  defaults,noatime  0  2
```

**Объяснение опций:**
*   `UUID=...`: Идентификатор вашего диска.
*   `/data`: Точка монтирования.
*   `ext4`: Файловая система.
*   `defaults`: Набор стандартных опций монтирования (включает `rw`, `suid`, `dev`, `exec`, `auto`, `nouser`, `async`).
*   `noatime`: Отключает обновление времени доступа к файлам, что немного повышает производительность диска.
*   `0`: Отключает проверку утилитой `dump`.
*   `2`: Устанавливает приоритет проверки файловой системы утилитой `fsck` (1 — для корневой ФС, 2 — для всех остальных).

> **Почему не использовать `/dev/sdb` или `LABEL`?**
> *   **/dev/sdb**: Имя может измениться после перезагрузки или подключения новых дисков. **Ненадёжно.**
> *   **LABEL=data**: Удобнее для чтения, но менее уникально, чем UUID. Если вы подключите другой диск с такой же меткой, возникнет конфликт. **Хороший вариант, но UUID лучше.**
> *   **UUID**: Гарантирует, что будет смонтирован именно тот диск, который вы указали. **Рекомендуемый способ.**

## Шаг 5: Проверка монтирования

Чтобы применить изменения без перезагрузки, выполните команду:

```bash
sudo mount -a
```

Эта команда смонтирует все устройства, описанные в `/etc/fstab`. Если ошибок нет, проверьте, что диск смонтирован в нужную точку:

```bash
df -hT /data
```
или
```bash
lsblk
```

Вы должны увидеть ваш диск, смонтированный в `/data`.

## Управление программным RAID с помощью `mdadm`

`mdadm` — это стандартная утилита в Linux для создания и управления программными RAID-массивами. Программный RAID позволяет объединять несколько дисков в один логический массив без необходимости в специальном RAID-контроллере.

### Создание RAID-массива

Процесс создания RAID-массива включает в себя несколько шагов:

1.  **Подготовка дисков:** Убедитесь, что у вас есть необходимое количество дисков или разделов, и они не содержат важных данных.

2.  **Создание массива:** Используйте команду `mdadm --create`.

    **Пример создания RAID 1 (зеркало) из двух дисков:**
    ```bash
    # /dev/md0 — имя будущего массива
    # --level=1 — уровень RAID (зеркало)
    # --raid-devices=2 — количество устройств в массиве
    # /dev/sdb и /dev/sdc — диски-участники
    sudo mdadm --create /dev/md0 --level=1 --raid-devices=2 /dev/sdb /dev/sdc
    ```

3.  **Сохранение конфигурации:** Чтобы массив автоматически собирался при загрузке, сохраните его конфигурацию в файл `mdadm.conf`.
    ```bash
    # Эта команда просканирует существующие массивы и добавит их в файл конфигурации
    sudo mdadm --detail --scan | sudo tee -a /etc/mdadm/mdadm.conf
    ```

4.  **Создание файловой системы:** После создания массива на нём можно создать файловую систему, как на обычном диске.
    ```bash
    sudo mkfs.ext4 /dev/md0
    ```

5.  **Монтирование:** Смонтируйте массив и добавьте его в `/etc/fstab` для автоматического монтирования при загрузке.

### Проверка состояния RAID

Для мониторинга состояния программного RAID-массива используйте:
```bash
# Показывает детальную информацию о конкретном массиве
sudo mdadm --detail /dev/md0

# Краткая информация о всех активных массивах (часто используется в скриптах)
cat /proc/mdstat
```

## Проверка состояния дисков с помощью `smartctl`

**S.M.A.R.T. (Self-Monitoring, Analysis, and Reporting Technology)** — это технология самодиагностики, встроенная в большинство современных жёстких дисков (HDD) и твердотельных накопителей (SSD). Утилита `smartctl` из пакета `smartmontools` позволяет считывать эти данные для оценки состояния диска и прогнозирования возможных сбоев.

### Использование `smartctl`

1.  **Установка:**
    ```bash
    sudo apt-get install smartmontools # Debian/Ubuntu
    sudo yum install smartmontools     # CentOS/RHEL
    ```

2.  **Просмотр общей информации о здоровье диска:**
    ```bash
    # Замените /dev/sda на ваш диск
    sudo smartctl -H /dev/sda
    ```
    В выводе ищите строку `SMART overall-health self-assessment test result`. Значение `PASSED` говорит о том, что диск считает себя исправным.

3.  **Просмотр всех S.M.A.R.T. атрибутов:**
    ```bash
    sudo smartctl -a /dev/sda
    ```
    Эта команда выводит подробную таблицу с атрибутами, такими как:
    -   `Reallocated_Sector_Ct`: Количество переназначенных секторов. Рост этого значения — плохой знак.
    -   `Temperature_Celsius`: Текущая температура диска.
    -   `Power_On_Hours`: Количество часов, которые диск был включён.
    -   `UDMA_CRC_Error_Count`: Ошибки передачи данных по интерфейсу. Могут указывать на проблемы с кабелем.
