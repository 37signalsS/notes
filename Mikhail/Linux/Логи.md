- Посмотреть конец лог файла:

``` sh
tail -f -n50 /var/log/syslog
```

(-f в реальном времени, -n50 последние 50 строк)

- Посмотреть начало лог файла

``` sh
head -n50 /var/log/syslog
```

- Просмотр всего лог файла(можно перемещаться вверх-вниз). +F - просмотр в режиме реального времени, -N - выводить номера строк, &слово - отображать строки соответствующие шалону, &!слово - отображать строки не соответствующие шаблону.

= - количество строк в текущем отображении, общее количество строк в файле, процент прокрутки файла

```sh
less /var/log/syslog
```

- История попыток входа на сервер и команд на повышение привилегий:

``` sh
cat /var/log/auth.log 
```

- Логи только сервиса nginx в реальном времени(-f)

``` sh
journalctl -xeu nginx -f
```

--since "1 hour ago" - логи на последний час

-p <номер> - только сообщения о выбранном событии

Уровни(номера) логирования в systemd (по journalctl -p):
0 (emerg) – Аварийная ситуация
1 (alert) – Тревога
2 (crit) – Критическая ошибка
3 (err) – Ошибка (ERROR)
4 (warning) – Предупреждение
5 (notice) – Уведомление
6 (info) – Информация
7 (debug) – Отладочные сообщения
