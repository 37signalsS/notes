# **SSH-туннелирование**

SSH-туннелирование — это метод создания зашифрованного канала через SSH, который позволяет перенаправлять сетевой трафик между локальной машиной и удаленным сервером. Это полезно для:
- Обхода ограничений файрвола.
- Безопасного доступа к внутренним сервисам.
- Тестирования приложений на локальной машине через удаленный сервер.

### Основные типы SSH-туннелирования:

1. Локальный проброс портов (Local Port Forwarding):
   - Позволяет перенаправить трафик с локального порта на удаленный сервер.

```
 ssh -L <локальный_порт>:<удаленный_хост>:<удаленный_порт> user@ssh_server
```

- 8080 — локальный порт.
- example.com:80 — удаленный хост и порт.
- После подключения можно открыть http://localhost:8080 в браузере, чтобы получить доступ к example.com.

2. Удаленный проброс портов (Remote Port Forwarding):
   - Позволяет перенаправить трафик с удаленного сервера на локальную машину.

```
 ssh -R <удаленный_порт>:<локальный_хост>:<локальный_порт> user@ssh_server
```

- 8080 — порт на удаленном сервере.
- localhost:3000 — локальный хост и порт.
- Теперь можно открыть http://ssh_server:8080, чтобы получить доступ к локальному приложению на порту 3000.
