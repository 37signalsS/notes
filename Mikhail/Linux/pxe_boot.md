# PXE: Загрузка по сети

**PXE (Preboot Execution Environment)** — это стандарт, который позволяет компьютеру загружаться, используя только свою сетевую карту, без необходимости в локальном диске с операционной системой.

Это широко используется для автоматической установки ОС на большом количестве серверов, для запуска систем восстановления или бездисковых рабочих станций.

## Компоненты PXE-сервера

Для развертывания PXE-сервера необходимо настроить несколько ключевых служб:

1.  **DHCP-сервер:**
    -   **Задача:** Выдать клиенту IP-адрес и сообщить, где находится TFTP-сервер и какой файл загрузчика нужно скачать.
    -   **Ключевые опции DHCP:**
        -   `next-server`: IP-адрес TFTP-сервера.
        -   `filename`: Имя файла загрузчика (например, `pxelinux.0` или `ipxe.efi`).

2.  **TFTP-сервер (Trivial File Transfer Protocol):**
    -   **Задача:** Предоставить клиенту по сети файлы, необходимые для начальной загрузки. TFTP — это очень простой протокол, который может быть реализован в прошивке сетевой карты.
    -   **Содержимое:** На TFTP-сервере размещаются:
        -   Сетевой загрузчик (`pxelinux.0`, `iPXE`).
        -   Файлы конфигурации для загрузчика.
        -   Ядро Linux (`vmlinuz`) и `initrd`.

3.  **Сетевой загрузчик (например, `PXELINUX`):**
    -   **Задача:** После загрузки по TFTP, он отображает меню загрузки (если настроено) и загружает ядро и `initrd` в память клиента.
    -   **Конфигурация:** Обычно находится в директории `pxelinux.cfg/` на TFTP-сервере.

4.  **HTTP/NFS/FTP-сервер (опционально):**
    -   **Задача:** Предоставить основной образ операционной системы и файлы для автоматической установки (например, `Kickstart` для RHEL/CentOS или `Preseed` для Debian/Ubuntu).

## Процесс загрузки по PXE

1.  Клиентский компьютер включается, и его сетевая карта отправляет широковещательный DHCP-запрос.
2.  DHCP-сервер отвечает, предоставляя IP-адрес и информацию о TFTP-сервере.
3.  Клиент скачивает с TFTP-сервера загрузчик (например, `pxelinux.0`).
4.  Загрузчик скачивает свою конфигурацию, ядро и `initrd`.
5.  Ядро запускается и, используя `initrd`, монтирует корневую файловую систему по сети (через NFS/iSCSI) или начинает автоматическую установку ОС, скачивая файлы с HTTP/FTP-сервера.
