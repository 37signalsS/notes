# Пространства имён (Namespaces) в Linux

**Пространства имён (Namespaces)** — это одна из фундаментальных технологий ядра Linux, которая обеспечивает изоляцию и виртуализацию системных ресурсов. Она позволяет создавать для группы процессов "свой собственный мир", в котором они видят только те ресурсы, которые принадлежат их пространству имён.

Именно `namespaces` вместе с `cgroups` лежат в основе технологии контейнеризации (Docker, Podman, Kubernetes).

## Основные типы пространств имён

Существует несколько типов пространств имён, каждый из которых отвечает за изоляцию определённого ресурса:

1.  **Mount (mnt):**
    -   **Изолирует:** Точки монтирования файловых систем.
    -   **Как работает:** Процессы в одном `mnt` namespace могут иметь свой собственный, уникальный набор смонтированных файловых систем, невидимый для других процессов. Это позволяет контейнерам иметь свою собственную корневую файловую систему (`/`).

2.  **PID (Process ID):**
    -   **Изолирует:** Идентификаторы процессов (PID).
    -   **Как работает:** Внутри нового PID namespace нумерация процессов начинается с 1. Первый процесс в этом пространстве имён становится "своим `init`" для всех последующих процессов. Снаружи, в родительском пространстве имён, эти процессы имеют обычные, уникальные для всей системы PID.

3.  **Network (net):**
    -   **Изолирует:** Сетевой стек.
    -   **Как работает:** Процесс получает свой собственный набор сетевых интерфейсов (включая `lo`), свою таблицу маршрутизации, правила `iptables` и порты. Это позволяет каждому контейнеру иметь свой собственный IP-адрес и сетевые настройки.

4.  **User:**
    -   **Изолирует:** Идентификаторы пользователей и групп (UID, GID).
    -   **Как работает:** Позволяет процессу иметь права суперпользователя (`root`, UID 0) внутри своего пространства имён, оставаясь при этом обычным непривилегированным процессом для основной системы. Это ключевой механизм безопасности, предотвращающий эскалацию привилегий из контейнера на хост.

5.  **IPC (Inter-Process Communication):**
    -   **Изолирует:** Механизмы межпроцессного взаимодействия, такие как семафоры, очереди сообщений и разделяемая память (System V IPC).

6.  **UTS (UNIX Timesharing System):**
    -   **Изолирует:** Имя хоста и доменное имя (`hostname`, `domainname`).
    -   **Как работает:** Позволяет каждому контейнеру иметь своё собственное уникальное имя хоста.
