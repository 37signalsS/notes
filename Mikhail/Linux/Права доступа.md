# **Файл  /etc/sudoers** 

Для пользователя `root` есть настройки `ALL=(ALL:ALL) ALL`, которые означают:

- **Первое `ALL`** — данное правило применяется ко всем хостам.
- **Второе `ALL`** — указанный пользователь может запускать команды от лица всех пользователей.
- **Третье `ALL`** — указанный пользователь может запускать команды от лица всех групп.
- **Четвёртое `ALL`** — данные правила применяются всем командам.

Через команду `sudo -l` выводится список разрешённых команд для пользователя.

# **Sudo and su**

Смена пользователя на любого:

```sh 
su <имя_пользователя>
```

```sh
sudo -i
```
- **Что делает** :
    - Запускает интерактивную сессию от имени root, аналогичную `su -`, но
    - Использует ваш пароль .33333
    - Полностью меняет окружение на root
- **Как работает** :
    - Требует, чтобы ваш пользователь был в группе `sudo` (или `wheel` в некоторых дистрибутивах).
    - Запрашивает ваш пароль (а не root).

```sh
sudo -s
```
- **Что делает** :
    - Запускает shell от имени root, **не меняя окружение** (переменные среды остаются ваши).
    - Меняются только права доступа (UID и GID становятся root).
- **Как работает** :
    - Запрашивает ваш пароль.
    - Окружение (например, переменные `HOME`, `PATH`) остаётся от текущего пользователя.

# **Если вы хотите добавить пользователя в группу, которая уже имеет доступ**

```sh
sudo chgrp -R new_group /var/www/html
```

После этого все пользователи, входящие в группу `new_group`, будут иметь права, соответствующие первой цифре(пользователь) chmod.

# **Добавление пользователя в группу**

Узнать в каких группах состоит пользователь:

```sh
groups <имя_пользователя>
```

Если вы хотите добавить пользователя в существующую группу:

```sh
sudo usermod -aG group_name username
```

# **Chown**

Используется для выдачи прав пользователя/группы пользователю или группе которые предварительно установлены при помощи chmod к файлу или директории пользователю или группе

Выдача прав пользователю alice

```sh
chown alice file.txt
```

Выдача прав группе developers

``` sh
chown :developers file.txt
```

Выдача прав пользователю alice из группы developers

``` sh
chown alice:developers file.txt
```

# **Chmod**

Числовая аннотация команды chmod для изменения доступа к файлами и директориям:

| Бинарный | Восьмеричный    | Права доступа             | Представление |
|----------|-----------------|---------------------------|---------------|
| `000`    | `0 (0+0+0)`     | Нет доступа               | `---`         |
| `001`    | `1 (0+0+1)`     | Выполнение                | `--x`         |
| `010`    | `2 (0+2+0)`     | Запись                    | `-w-`         |
| `011`    | `3 (0+2+1)`     | Запись + Выполнение       | `-wx`         |
| `100`    | `4 (4+0+0)`     | Чтение                    | `r--`         |
| `101`    | `5 (4+0+1)`     | Чтение + Выполнение       | `r-x`         |
| `110`    | `6 (4+2+0)`     | Чтение + Запись           | `rw-`         |
| `111`    | `7 (4+2+1)`     | Чтение + Запись + Выполнение | `rwx`     |
 
```sh 
-rwxrw-r-x
```
Первый символ (-): Тип файла (например, - для обычного файла).
Следующие три символа (rwx): Права владельца.
Следующие три символа (rw-): Права группы.
Последние три символа (r-x): Права других пользователей.

# **Особые права в Linux**

Права групп  

    SUID (Set User ID) : Устанавливается на исполняемые файлы. 
        Позволяет выполнять файл с правами владельца файла.
        Отображается как s в позиции выполнения владельца.
        Устанавливается командой: chmod u+s имя_файла.
         

    SGID (Set Group ID) : 
        Устанавливается на исполняемые файлы или директории.
        Для файлов: выполняются с правами группы-владельца.
        Для директорий: новые файлы наследуют группу директории.
        Устанавливается командой: chmod g+s имя_файла.
         

    Sticky bit : 
        Обычно используется для директорий.
        Предотвращает удаление файлов другими пользователями.
        Только владелец файла, владелец директории или пользователь root может удалить файл.
        Устанавливается командой: chmod +t директория.

-rwsr-xr-x  root root 59976 May 6 2022 /bin/passwd

Обычные пользователи могут запускать passwd с правами root, чтобы изменить свой пароль в /etc/passwd.

-rwxr-sr-x  root crontab 39568 May 6 2022 /usr/bin/crontab

Пользователи могут запускать crontab с правами группы crontab, чтобы изменять свои задания cron.

drwxrwxrwt  root root 36 Feb 2 17:21 /tmp

Файлы в /tmp могут быть удалены только их владельцем, владельцем директории (root) или пользователем root.
  
Установка SUID : 

    Команда: chmod u+s filename
    Восьмеричный код: chmod 4755 filename
     

Установка SGID : 

    Команда: chmod g+s filename
    Восьмеричный код: chmod 2755 filename
     

Установка Sticky бита : 

    Команда: chmod +t directory
    Восьмеричный код: chmod 1777 directory
     

Установка нескольких битов : 

    Команда: chmod ug+s, +t directory
    Восьмеричный код: chmod 7755 directory
