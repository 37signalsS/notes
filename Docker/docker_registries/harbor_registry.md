# Harbor: частный Docker-реестр

## Обзор

Harbor - это открытый проект [CNCF](../../Kubernetes/cncf_overview.md) с функциями сканирования уязвимостей, репликации и управления доступом. Он предоставляет надежное решение для хранения и распространения Docker-образов в корпоративной среде.

## Особенности Harbor

- **Сканирование уязвимостей**: Интегрированный сканер безопасности для выявления уязвимостей в образах
- **Репликация**: Возможность репликации образов между различными экземплярами Harbor
- **Управление доступом**: Поддержка ролевой модели доступа (RBAC)
- **Подпись образов**: Поддержка подписи образов для обеспечения целостности
- **Веб-интерфейс**: Удобный веб-интерфейс для управления образами и проектами

## Установка Harbor

### Требования

- Docker Engine >= 17.03
- Docker Compose >= 1.10.0
- Минимум 4 ГБ оперативной памяти
- Минимум 4 ГБ свободного места на диске

### Установка с помощью офлайн-инсталлятора

1. Скачайте офлайн-инсталлятор с официального сайта Harbor
2. Распакуйте архив:
   ```bash
   tar -xzf harbor-offline-installer-*.tgz
   ```

3. Скопируйте шаблон конфигурации:
   ```bash
   cp harbor.yml.tmpl harbor.yml
   ```

4. Отредактируйте файл `harbor.yml`, указав:
   - `hostname`: доменное имя, по которому будет доступен Harbor
   - `port`: порты, на которых будет работать Harbor (по умолчанию 80 и 443)
   - `certificate path` и `private key path`: пути к TLS-сертификату и его закрытому ключу

5. Запустите установку:
   ```bash
   sudo ./install.sh
   ```

## Настройка Harbor

### Конфигурационный файл

Файл `harbor.yml` содержит основные настройки Harbor:

```yaml
hostname: reg.yourdomain.com
http:
  port: 80
https:
  port: 443
  certificate: /path/to/your/certificate
  private_key: /path/to/your/private/key
harbor_admin_password: <пароль_администратора>
database:
  password: <пароль_базы_данных>
data_volume: /data
clair:
  updaters_interval: 12
```

### Аутентификация

Harbor поддерживает несколько методов аутентификации:

- **DB_AUTH**: Аутентификация встроенной базой данных
- **LDAP**: Аутентификация через LDAP/AD
- **UAA**: Аутентификация через Cloud Foundry UAA

## Использование Harbor

### Аутентификация в Harbor

Для работы с Harbor необходимо сначала аутентифицироваться:

```bash
docker login <ваш_домен_харбора>
```

Например:
```bash
docker login reg.yourdomain.com
# Введите логин и пароль
# Логин: admin
# Пароль: Harbor12345 (по умолчанию)
```

### Публикация образа в Harbor

1. Сначала нужно "затегировать" (tag) образ с адресом вашего Harbor-реестра:
   ```bash
   docker tag <локальный_образ> <ваш_домен_харбора>/<проект>/<имя_образа>:<тег>
   ```
   
   Пример:
   ```bash
   docker tag my-go-app:latest reg.yourdomain.com/library/my-go-app:latest
   ```

2. Затем можно запушить образ в реестр:
   ```bash
   docker push <ваш_домен_харбора>/<проект>/<имя_образа>:<тег>
   ```
   
   Пример:
   ```bash
   docker push reg.yourdomain.com/library/my-go-app:latest
   ```

### Получение образа из Harbor

После аутентификации можно использовать образы из Harbor так же, как и из Docker Hub:

```bash
docker pull <ваш_домен_харбора>/<проект>/<имя_образа>:<тег>
```

Пример:
```bash
docker pull reg.yourdomain.com/library/my-go-app:latest
```

## Управление проектами

В Harbor образы организованы в проекты. Проекты могут быть:

- **Публичными**: Доступны для всех без аутентификации
- **Приватными**: Доступны только авторизованным пользователям

### Создание проекта

1. Войдите в веб-интерфейс Harbor
2. Нажмите "New Project"
3. Укажите имя проекта
4. Выберите тип (публичный или приватный)
5. Установите квоты при необходимости

## Безопасность в Harbor

Harbor включает в себя несколько уровней безопасности:

- **Сканирование образов**: Автоматическое сканирование на уязвимости
- **Подпись образов**: Проверка целостности образов
- **Управление доступом**: Поддержка RBAC для тонкой настройки прав доступа
- **Уведомления**: Возможность настройки уведомлений о событиях безопасности

## Мониторинг и логирование

Harbor предоставляет встроенные возможности мониторинга и логирования:

- **Метрики**: Интеграция с Prometheus для сбора метрик
- **Логи**: Подробные логи всех операций
- **Аудит**: Журнал аудита для отслеживания всех действий пользователей
