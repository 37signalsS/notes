# Интеграция Docker с Prometheus

## Определения

**Интеграция Docker с Prometheus** — процесс настройки экспорта метрик Docker в формате Prometheus для централизованного сбора, хранения и анализа данных о работе демона Docker (Docker Engine), контейнеров и запущенных в них приложений.

## Основные концепции

Для полноценного мониторинга Docker-хоста требуется сбор данных на трех уровнях:

1.  **Метрики Docker Engine** — статистика работы демона (количество контейнеров и образов, ошибки сборки).
2.  **Метрики контейнеров** — детальные данные о потреблении ресурсов каждым контейнером: CPU (Центральный процессор), память (RAM), сеть, I/O (Ввод-вывод).
3.  **Метрики приложений** — внутренние показатели сервисов: количество обработанных запросов, время ответа API (Интерфейс программирования приложений), активные пользователи.

Для каждого уровня используется специализированный инструмент или метод сбора.

## Практические сценарии

### Сбор метрик Docker Engine

Docker Engine (версии 20.10 и выше) поддерживает нативный экспорт метрик в формате Prometheus.

**Назначение:** Мониторинг общего состояния и производительности демона Docker.

**Настройка:** Необходимо добавить параметр `metrics-addr` в файл конфигурации `/etc/docker/daemon.json` и перезапустить службу Docker.

```json
{
  "metrics-addr": "0.0.0.0:9323",
  "experimental": true
}
```

Метрики будут доступны по адресу `http://<host-ip>:9323/metrics`.

*Примечание:* Указание адреса `0.0.0.0` открывает доступ к метрикам из внешней сети. Для ограничения доступа только локальной машиной используйте `127.0.0.1:9323`.

### Сбор метрик контейнеров через cAdvisor

Для получения детальной статистики по каждому контейнеру используется инструмент **[cAdvisor (Container Advisor)](../../Prometheus/Exporters/cadvisor.md)**.

**Назначение:** Сбор, агрегация и экспорт данных о потреблении ресурсов (CPU, память, сеть, диск) всеми контейнерами на хосте.

cAdvisor рекомендуется запускать как отдельный Docker-контейнер. Подробные инструкции по установке и настройке приведены в основной статье: **[cAdvisor](../../Prometheus/Exporters/cadvisor.md)**.

### Сбор метрик приложений

Этот уровень требует инструментирования кода приложения с использованием клиентских библиотек Prometheus.

**Принцип работы:** Приложение самостоятельно экспортирует специфичные метрики бизнес-логики через HTTP-эндпоинт (Протокол передачи гипертекста), обычно `/metrics`.

**Настройка:** Порт приложения, на котором отдаются метрики, должен быть доступен для скрейпера (сборщика) Prometheus.

## Дополнительная информация

### Взаимодействие с Node Exporter

Для получения полной картины состояния системы рекомендуется использовать cAdvisor в связке с **[Node Exporter](../../Prometheus/Exporters/node_exporter.md)**:

*   **cAdvisor** — фокусируется на метриках внутри контейнеров.
*   **Node Exporter** — собирает метрики хост-системы (общая загрузка процессора, использование физических дисков, состояние сетевых интерфейсов хоста).
