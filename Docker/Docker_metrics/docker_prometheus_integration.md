# Интеграция Docker с Prometheus

## Определения

**Интеграция Docker с Prometheus** — настройка экспорта метрик Docker в формате Prometheus для централизованного сбора, хранения и анализа данных о работе демона Docker, контейнеров и приложений.

## Основные концепции

Полноценный мониторинг Docker-хоста требует сбора метрик с трёх уровней:

1. **Метрики Docker Engine** — статистика работы демона Docker (количество контейнеров, образов, ошибки сборки)
2. **Метрики контейнеров** — детальные данные о потреблении CPU, памяти, сети, I/O каждым контейнером
3. **Метрики приложений** — внутренние показатели сервисов (обработанные запросы, время ответа API, активные пользователи)

Каждый уровень требует своего инструмента сбора.

## Практические сценарии

### 1. Сбор метрик Docker Engine

Docker Engine (v20.10+) нативно экспортирует метрики в формате Prometheus.

**Назначение:** мониторинг состояния и производительности демона Docker.

**Настройка:** добавить параметр `metrics-addr` в `/etc/docker/daemon.json` и перезапустить Docker:

```json
{
  "metrics-addr": "0.0.0.0:9323",
  "experimental": true
}
```

Метрики доступны по адресу `http://<host-ip>:9323/metrics`.

> **Примечание:** Порт `0.0.0.0` открывает доступ из внешней сети. Для локального доступа используйте `127.0.0.1:9323`.

### 2. Сбор метрик контейнеров: cAdvisor

Для сбора детальных метрик каждого контейнера используется **[cAdvisor (Container Advisor)](../../Prometheus/Exporters/cadvisor.md)** от Google.

**Назначение:** сбор, агрегация и экспорт детальной статистики потребления CPU, памяти, сети и диска для всех контейнеров на хосте.

**Запуск:** cAdvisor удобно запускать как Docker-контейнер:

```yaml
# Пример для docker-compose.yml
services:
  cadvisor:
    image: ghcr.io/google/cadvisor:v0.56.2
    container_name: cadvisor
    ports:
      - "8080:8080"
    volumes:
      - /:/rootfs:ro
      - /var/run:/var/run:rw
      - /sys:/sys:ro
      - /var/lib/docker/:/var/lib/docker:ro
    restart: unless-stopped
```

> **Важно:** Начиная с v0.56.0, cAdvisor мигрировал с `gcr.io/cadvisor/cadvisor` на `ghcr.io/google/cadvisor`. Версия v0.56.0+ требует Docker 25.0+.

Метрики доступны по адресу `http://<host-ip>:8080/metrics`.

### 3. Сбор метрик приложений

Требует инструментирования приложения клиентскими библиотеками Prometheus.

**Принцип работы:** приложение отдаёт специфичные метрики (бизнес-логика, производительность) по HTTP-эндпоинту `/metrics`.

**Настройка:** порт с метриками должен быть доступен для скрейпера Prometheus.

## Дополнительная информация

### Связка с Node Exporter

Для полной картины мониторинга **[cAdvisor](../../Prometheus/Exporters/cadvisor.md)** (метрики контейнеров) используется в связке с **[node-exporter](../../Prometheus/Exporters/node_exporter.md)** (метрики хост-системы):

- **cAdvisor** — метрики внутри контейнеров (CPU, память, сеть каждого контейнера)
- **node-exporter** — метрики хоста (загрузка CPU, использование диска, состояние сети)

При недостатке стандартных метрик cAdvisor можно использовать **[draganm/missing-container-metrics](https://github.com/draganm/missing-container-metrics)** для экспорта специфичных данных.
