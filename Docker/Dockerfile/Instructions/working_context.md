# Инструкции Dockerfile: Рабочий Контекст

### Рабочий контекст

#### `WORKDIR`

Устанавливает текущий рабочий каталог для всех последующих инструкций `RUN`, `CMD`, `ENTRYPOINT`, `COPY` и `ADD`. Если каталог не существует, он будет создан.

#### `SHELL`

Выбор оболочки по умолчанию для выполнения команд в инструкциях `RUN`, `CMD` и `ENTRYPOINT` в формате shell.
