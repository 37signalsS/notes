# Инструкции Dockerfile: Обзор

## Определения

**Инструкции Dockerfile** — команды в файле `Dockerfile` для пошаговой сборки Docker-образа. Каждая инструкция создаёт новый слой, что позволяет Docker кэшировать результаты и оптимизировать повторные сборки.

## Практические сценарии

### Минимальный Dockerfile

```dockerfile
FROM alpine:3.20
LABEL maintainer="developer@example.com"
CMD ["echo", "Hello World"]
```

### Типовой Dockerfile приложения

```dockerfile
FROM python:3.11-slim
LABEL version="1.0" description="My Python App"

WORKDIR /app
ENV PYTHONUNBUFFERED=1

COPY requirements.txt .
RUN pip install -r requirements.txt

COPY . .
EXPOSE 8000
USER appuser

HEALTHCHECK --interval=30s --timeout=3s \
  CMD curl -f http://localhost:8000/health || exit 1

CMD ["python", "app.py"]
```
