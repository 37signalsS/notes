# Инструкции Dockerfile: Копирование Файлов

## Определения

**Инструкция `COPY`** — копирует файлы и директории из контекста сборки в файловую систему образа.

**Инструкция `ADD`** — расширенная версия `COPY` с дополнительными возможностями (загрузка по URL, автоматическая распаковка архивов).

**Контекст сборки** — набор файлов и директорий, передаваемых демону Docker перед сборкой.

## Основные концепции

### `COPY` vs `ADD`

| Функция | COPY | ADD |
| :--- | :--- | :--- |
| Копирование файлов из контекста | ✅ | ✅ |
| Загрузка файлов по URL | ❌ | ✅ |
| Автоматическая распаковка архивов (tar, gzip, bzip2, xz) | ❌ | ✅ |

> ⚠️ **Лучшая практика:** Официальная документация Docker рекомендует **использовать `COPY`**, если не требуется функциональность `ADD`. Для загрузки и распаковки файлов лучше использовать явные команды в `RUN`.

### Практические примеры

**COPY — простое копирование:**

```dockerfile
COPY ./app.py /app/
COPY package*.json /app/
```

**ADD — загрузка по URL (не рекомендуется, используйте RUN + curl):**

```dockerfile
# Не рекомендуется
ADD http://example.com/file.tar.gz /tmp/

# Рекомендуется
RUN curl -SL http://example.com/file.tar.gz | tar -xz -C /tmp/
```

**ADD — распаковка архива:**

```dockerfile
# Не рекомендуется
ADD archive.tar.gz /app/

# Рекомендуется
RUN tar -xzf archive.tar.gz -C /app/ && rm archive.tar.gz
```

## Практические сценарии

### Эффективное копирование зависимостей

```dockerfile
# Копируем только файл зависимостей (редко меняется)
COPY package*.json ./
# Устанавливаем зависимости
RUN npm install
# Копируем остальной код (часто меняется)
COPY . .
```

### Копирование с исключением ненужных файлов

```dockerfile
COPY . .
# Удаляем ненужные файлы в том же слое
RUN rm -rf .git README.md tests/ && \
    # Очищаем кэш
    npm cache clean --force
```
