# Инструкции Dockerfile: Данные и Хранилища

## Определения

**Том (Volume)** — механизм для персистентного хранения данных, генерируемых контейнером. Данные сохраняются независимо от жизненного цикла контейнера.

**Инструкция `VOLUME`** — директива в Dockerfile, объявляющая точку монтирования для внешнего тома.

## Основные концепции

### `VOLUME`

Директива `VOLUME` в Dockerfile позволяет указать путь внутри контейнера, который должен быть внешним томом. Это декларативная инструкция.

**Синтаксис:**

```dockerfile
VOLUME /path/to/directory/inside/container
```

Или для нескольких точек монтирования:

```dockerfile
VOLUME ["/path1", "/path2"]
```

**Типы томов:**

| Тип | Описание | Когда использовать |
| :--- | :--- | :--- |
| Анонимный том | Создаётся Docker автоматически при запуске контейнера | Временное хранение, логи |
| Именованный том | Создаётся и управляется пользователем (`docker volume create`) | Персистентные данные (БД, загрузки) |
| Bind mount | Монтирование директории хоста | Разработка, конфигурации |

**Важно:** Директива `VOLUME` создаёт **анонимные тома**. Это отличается от `bind mount` (например, `-v /host/path:/container/path` в `docker run`).

### Отличие от bind mount

| Характеристика | VOLUME (в Dockerfile) | Bind mount (`-v`) |
| :--- | :--- | :--- |
| Управление | Docker управляет автоматически | Пользователь управляет |
| Расположение | В директории Docker | Любая директория хоста |
| Переносимость | Переносится между хостами | Привязан к хосту |

## Практические сценарии

### Сценарий 1: Логи веб-сервера

```dockerfile
FROM nginx:alpine
VOLUME /var/log/nginx
```

Docker создаст анонимный том и автоматически примонтирует его к `/var/log/nginx`. Данные в таком томе переживут смерть и воскрешение контейнера.

### Сценарий 2: Пользовательские файлы и кэш

```dockerfile
FROM node:20-alpine
WORKDIR /app
VOLUME ["/app/uploads", "/app/cache"]
```

### Сценарий 3: Использование с Docker Compose

В Docker Compose директива `VOLUME` из Dockerfile работает как значение по умолчанию:

```yaml
services:
  app:
    build: .
    volumes:
      - my_named_volume:/app/data  # Переопределяет VOLUME из Dockerfile
volumes:
  my_named_volume:
```

## Дополнительная информация

- Данные в томах не являются частью записываемого слоя контейнера
- При использовании `docker export` данные томов не включаются в экспорт
