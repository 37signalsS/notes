# Инструкции Dockerfile: Сеть и Порты

## Определения

**EXPOSE** — инструкция Dockerfile, информирующая Docker о том, что контейнер прослушивает указанные сетевые порты во время выполнения.

## Основные концепции

### Декларативная природа EXPOSE

`EXPOSE` — это исключительно **декларативная** инструкция. Она **не открывает** и **не публикует** порты. Инструкция выполняет две функции:

1. **Документация:** Служит подсказкой для пользователя, который будет запускать образ, о том, какие порты предназначены для публикации.
2. **Автоматическая публикация:** При использовании флага `-P` (публикация всех *exposed* портов) в команде `docker run`, Docker использует эту информацию для автоматического проброса портов на случайные порты хоста.

**Синтаксис:**

```dockerfile
EXPOSE 80
EXPOSE 443
EXPOSE 8080/tcp
EXPOSE 53/udp
```

Можно указать протокол (`tcp` по умолчанию или `udp`).

## Практические сценарии

### Публикация портов при запуске

| Метод | Команда | Результат |
| :--- | :--- | :--- |
| Не публиковать | `docker run my-image` | Порт не доступен снаружи |
| Проброс на случайный порт | `docker run -P my-image` | Docker выбирает свободный порт на хосте |
| Проброс на конкретный порт | `docker run -p 8080:80 my-image` | Порт 80 контейнера доступен на `localhost:8080` |

**Пример Dockerfile:**

```dockerfile
FROM nginx:alpine
EXPOSE 80
EXPOSE 443
CMD ["nginx", "-g", "daemon off;"]
```

При запуске `docker run -P my-nginx` порты 80 и 443 будут автоматически проброшены на случайные порты хоста.

## Дополнительная информация

- Для постоянного проброса портов используйте флаг `-p` в `docker run` или секцию `ports` в `docker-compose.yml`
- `EXPOSE` не заменяет настройку сетевых драйверов Docker — это лишь метаданные для документации и автоматизации
