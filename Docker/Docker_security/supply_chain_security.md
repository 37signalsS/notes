# Безопасность цепочки поставок (Supply Chain Security)

## Определения

**Безопасность цепочки поставок ПО (Software Supply Chain Security)** — это комплекс мер, направленных на защиту программных артефактов (таких как Docker-образы), их зависимостей и процессов сборки/доставки от умышленных или случайных уязвимостей. Цель — гарантировать, что в production используется только доверенное, проверенное и неизменённое программное обеспечение.

## Основные концепции

Безопасность цепочки поставок для Docker-образов включает несколько ключевых направлений:

*   **Гарантия происхождения и целостности:** Проверка того, что образ был создан доверенным источником и не был изменен по пути. Основной механизм — цифровая подпись.
*   **Статический анализ уязвимостей (SAST):** Сканирование Docker-образов и их зависимостей на наличие известных уязвимостей (CVE) до их запуска.
*   **Динамический анализ поведения (Runtime Security):** Мониторинг запущенных контейнеров для обнаружения аномальной или вредоносной активности в реальном времени.
*   **Аудит конфигураций и содержимого:** Проверка конфигурации самого Docker и анализ слоев образа для выявления небезопасных практик и уменьшения поверхности атаки.
*   **Анализ Infrastructure as Code (IaC):** Проверка файлов, описывающих инфраструктуру (включая `Dockerfile`), на предмет уязвимостей и ошибок конфигурации.

## Практические сценарии: Инструменты и примеры

### 1. Подписание образов

-   **Docker Content Trust (DCT):** Встроенный, но устаревший механизм на основе Notary. Требует сложной настройки и отдельного сервера. Для активации используется `export DOCKER_CONTENT_TRUST=1`.
-   **Sigstore/Cosign:** Современный стандарт де-факто для подписи OCI-артефактов. Прост в использовании, не требует отдельных серверов и поддерживает "безключевую" подпись, что идеально для CI/CD. Подробное описание, примеры и принцип работы находятся в основном документе **[Sigstore: Безопасность цепочки поставок ПО](../../Security/Tools/sigstore.md)**.

### 2. Статический анализ образов (SAST)

-   **Trivy:** Популярный и простой сканер уязвимостей.
    ```bash
    # Сканирование образа на критические и высокие уязвимости
    trivy image --severity HIGH,CRITICAL python:3.13-slim
    # Сканирование Dockerfile на плохие практики
    trivy config /path/to/your/Dockerfile
    ```
-   **Grype:** Альтернатива от Anchore. Удобен для интеграции в CI/CD.
    ```bash
    # Завершить выполнение с ошибкой, если найдены уязвимости уровня "high" или выше
    grype python:3.13-slim --fail-on high
    ```
-   **Clair:** Серверный сканер, часто интегрируется с Docker-реестрами (Harbor, Quay) для анализа образов при их загрузке.
-   **Docker Scout:** Встроенный инструмент Docker для анализа уязвимостей.
    ```bash
    docker scout quickview ваш-образ:тег
    ```
-   **GitHub Dependabot:** Автоматически отслеживает и предлагает обновить уязвимые базовые образы в `Dockerfile`.
-   **Copacetic:** Инструмент для "горячего" исправления уязвимостей в образах без полной пересборки на основе отчета сканера.
    ```bash
    # 1. Сканируем и получаем отчет
    trivy image --format json --output report.json my-app:1.0
    # 2. Исправляем образ на основе отчета
    copa patch -i my-app:1.0 -r report.json -t my-app:1.0-patched
    ```

### 3. Динамический анализ (Runtime Security)

-   **Falco:** Стандарт де-факто для мониторинга безопасности во время выполнения. `Falco` отслеживает системные вызовы (`syscalls`) через eBPF, обнаруживает подозрительное поведение (например, запуск shell в контейнере, запись в `/etc`) и генерирует оповещения. Подробнее см. в основном документе **[Falco: Мониторинг безопасности во время выполнения (Runtime Security)](../../Security/Tools/falco.md)**.

### 4. Аудит конфигураций и образов

-   **Dive:** Инструмент для послойного анализа Docker-образа. Помогает найти и устранить "раздутые" слои, уменьшая размер и поверхность атаки.
    ```sh
    dive my-app:1.0.0
    ```
-   **Docker Bench Security:** Скрипт, проверяющий конфигурацию Docker на соответствие лучшим практикам безопасности от CIS (Center for Internet Security).
    ```sh
    git clone https://github.com/docker/docker-bench-security.git
    cd docker-bench-security
    sudo sh docker-bench-security.sh
    ```

### 5. Анализ IaC

-   **KICS (Keeping Infrastructure as Code Secure):** Статический анализатор для файлов IaC (Terraform, Kubernetes, **Docker**, Ansible), который находит уязвимости и неправильные конфигурации.
