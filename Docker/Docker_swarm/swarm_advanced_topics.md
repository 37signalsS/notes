# Docker Swarm: Продвинутые темы

## Определения

* Этот документ рассматривает продвинутые аспекты [Docker Swarm Mode](../docker_swarm_overview.md).

## Базовые концепции

### Безопасность Docker Swarm

* **TLS-шифрование:** Весь трафик между узлами Swarm по умолчанию шифруется с использованием TLS, обеспечивая безопасную коммуникацию.
* **Токены присоединения:** Специальные токены используются для безопасного добавления новых узлов (менеджеров или рабочих) в существующий Swarm.
* **Ролевая модель (RBAC):** Docker Swarm не имеет встроенной системы RBAC, аналогичной Kubernetes. Контроль доступа обычно реализуется на уровне хоста через защиту Docker Engine API.

## Практические сценарии

### Сосуществование с автономными контейнерами

* **Гибкость:** Активация Swarm Mode не затрагивает существующие автономные контейнеры или приложения Docker Compose. Они продолжают работать в штатном режиме.
* **Постепенная миграция:** Такой подход позволяет постепенно переводить приложения на рельсы Swarm (в виде сервисов или стеков), не требуя одномоментного переключения всей инфраструктуры и допуская параллельную работу старых и новых компонентов.
