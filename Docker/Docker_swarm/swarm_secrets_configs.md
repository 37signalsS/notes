# Docker Swarm: Секреты и Конфигурации

## Определения

* **Секреты (Secrets):** Встроенный механизм Docker Swarm для безопасного хранения и управления чувствительными данными (пароли, токены, SSH-ключи). Секреты хранятся в зашифрованной Raft-базе данных кластера и передаются только тем контейнерам сервисов, которым они явно назначены.

* **Конфигурации (Configs):** Аналогичный секретам механизм, предназначенный для централизованного управления нечувствительными данными, такими как конфигурационные файлы приложений.

## Базовые концепции

* **Доступ внутри контейнера:** И секреты, и конфигурации монтируются в контейнер как файлы в оперативной памяти (in-memory filesystem).
  * Секреты по умолчанию доступны по пути `/run/secrets/<имя_секрета>`.
  * Конфигурации по умолчанию доступны по пути `/<имя_конфига>`.
  * **Важно:** Если приложение ожидает конфигурацию в виде переменной окружения, потребуется скрипт-обертка, который прочитает файл и экспортирует его содержимое как переменную.

* **Неизменяемость (Immutability):** После создания ни секрет, ни конфигурацию нельзя отредактировать. Для обновления данных необходимо создать новый объект и обновить сервис, чтобы он использовал новую версию.

## Практические сценарии

### Управление Секретами

* **Создать секрет (из файла или stdin):**

    ```sh
    # Из файла
    docker secret create my_secret_file /path/to/secret.txt

    # Из stdin
    echo "my_super_secret_password" | docker secret create my_secret_password -
    ```

* **Просмотреть список секретов:**

    ```sh
    docker secret ls
    ```

* **Использовать секрет в сервисе:**

    ```sh
    docker service create --name my-app --secret my_secret_password my-image
    ```

* **Удалить секрет:**

    ```sh
    docker secret rm my_secret_password
    ```

### Управление Конфигурациями

* **Создать конфигурацию:**

    ```sh
    docker config create my_config_file ./app_config.yaml
    ```

* **Просмотреть список конфигураций:**

    ```sh
    docker config ls
    ```

* **Использовать конфигурацию в сервисе:**

    ```sh
    # Файл будет доступен как /my_config_file
    docker service create --name my-app --config my_config_file my-image
    ```

* **Удалить конфигурацию:**

    ```sh
    docker config rm my_config_file
    ```
