# Сеть в Docker Swarm

**Docker Swarm** для обеспечения связи между контейнерами, запущенными на разных узлах кластера, активно использует **оверлейные сети (overlay networks)**. Эта технология построена на инкапсуляции трафика, часто с использованием протокола **[VXLAN](../../Networking/Tunnels/vxlan.md)**, что позволяет создавать виртуальную сеть второго уровня (Layer 2) поверх существующей сетевой инфраструктуры третьего уровня (Layer 3). Таким образом, контейнеры, расположенные на разных физических хостах, могут обмениваться данными, как если бы они находились в одной локальной сети.

## Определения

*   **Оверлейная сеть (Overlay Network):** Виртуальная сеть, которая "накладывается" поверх существующей физической сети. В Docker Swarm она позволяет контейнерам на разных хостах общаться так, будто они находятся в одной локальной сети. Подробнее см. **[драйвер overlay](../../Docker/Docker_network/drivers/overlay.md)**.
*   **`ingress`:** Системная `overlay`-сеть, управляемая Swarm. Отвечает за прием внешнего трафика и его маршрутизацию на опубликованные порты сервисов с помощью механизма **[Routing Mesh](swarm_core_concepts.md)**.
*   **`docker_gwbridge`:** Сеть-шлюз (типа `bridge`), которая создается на каждом узле Swarm и обеспечивает контейнерам доступ во внешние сети (например, в интернет).

## Базовые концепции

### Особенности оверлейных сетей Swarm

*   **Простота управления:** Оверлейные сети автоматически создаются и управляются Docker Swarm, что упрощает конфигурацию.
*   **Изоляция трафика:** Сетевой трафик между различными сервисами изолирован, обеспечивая безопасность и предотвращая конфликты.
*   **Встроенная DNS-балансировка:** Swarm предоставляет встроенную DNS-балансировку нагрузки для сервисов, распределяя запросы между их репликами.

### Системные сети в Swarm

Помимо пользовательских `overlay`-сетей, в Swarm-кластере по умолчанию существуют две важные системные сети, определенные выше: `ingress` и `docker_gwbridge`.

## Практические сценарии

### Создание пользовательской оверлейной сети

```sh
docker network create --driver overlay --attachable --opt encrypted my-overlay-network
```
*   `--attachable`: Позволяет автономным контейнерам (не являющимся частью Swarm-сервисов) подключаться к этой сети.
*   `--opt encrypted`: Включает IPsec-шифрование трафика внутри сети, что повышает безопасность, но может незначительно повлиять на производительность.

### Использование сети в сервисе Swarm

Для того чтобы сервис использовал созданную или существующую сеть, её необходимо указать при его создании:

```sh
docker service create --name my-service --network my-overlay-network --replicas 3 my-image
```
