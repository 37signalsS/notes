# Инструменты для работы с Docker (TUI и CLI)

## Определения

**TUI (Terminal User Interface)** для Docker позволяют управлять контейнерами, образами, сетями и томами в интерактивном режиме прямо из консоли, что часто быстрее и удобнее, чем использование стандартного CLI или тяжеловесных веб-интерфейсов.

## Основные инструменты

### 1. `lazydocker`

`lazydocker` — один из самых популярных TUI-инструментов для управления Docker и Docker Compose.

* **Назначение:** Мониторинг и управление локальной Docker-инфраструктурой.
* **Особенности:**
  * Просмотр состояния контейнеров, логов и статистики потребления ресурсов (CPU, Memory) в реальном времени.
  * Быстрое выполнение команд (restart, stop, remove) горячими клавишами.
  * Визуализация Docker Compose проектов.
  * Просмотр конфигурации образов и слоев.
  * Очистка неиспользуемых ресурсов (prune).

### 2. `oxker`

Более легковесная альтернатива `lazydocker`, написанная на Rust. Сфокусирована на производительности и минимализме.

* **Назначение:** Быстрый просмотр статуса контейнеров и управление ими.
* **Особенности:** Высокая скорость работы, поддержка логов и базовых операций управления.

## Практические сценарии

### Использование `lazydocker`

#### Установка

```bash
# Через curl (официальный скрипт)
curl https://raw.githubusercontent.com/jesseduffield/lazydocker/master/scripts/install_update_linux.sh | bash

# Или через go
go install github.com/jesseduffield/lazydocker@latest
```

#### Основные горячие клавиши

* **Стрелки / hjkl:** Навигация по панелям и спискам.
* **Enter:** Переключиться на панель логов/деталей.
* **b:** Открыть меню действий для выбранного контейнера.
* **s:** Остановить контейнер.
* **r:** Перезапустить контейнер.
* **d:** Удалить контейнер (с подтверждением).
* **x:** Выполнить произвольную команду внутри контейнера (exec).
* **q:** Выход.
