# Управление слоями Docker

## Объединение слоев (`--squash`)

Флаг `docker build --squash` объединяет все слои, созданные в `Dockerfile`, в один новый слой.

- **Плюс:** Может незначительно уменьшить размер финального образа
- **Минус:** Уничтожает кэш для объединенных слоев

## Схлопывание слоев с помощью `docker-squash`

Более гибкой альтернативой является внешняя утилита **`docker-squash`**.

1. **Установка:**

    ```bash
    pip install docker-squash==1.2.2
    ```

2. **Использование:**

    ```bash
    # Схлопнуть последние 2 слоя
    docker-squash -f 2 my-image:1.1.0 -t my-image:squashed

    # Схлопнуть все слои, начиная с определенного
    docker-squash -from 5a5295c74599 my-image:1.1.0 -t my-image:squashed
    ```

**Преимущества перед `docker build --squash`:**
- **Сохранение кэша:** Не затрагивает базовые слои
- **Гибкость:** Позволяет точно указать, какие слои объединить
- **Работа с существующими образами:** Можно оптимизировать образы без Dockerfile
