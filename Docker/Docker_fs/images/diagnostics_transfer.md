# Диагностика и перенос образов Docker

## Диагностика слоёв

Посмотреть, как образ разбит на слои:

```bash
docker history --no-trunc <image>
```

Получение сведений о драйвере и путях overlay2:

```bash
docker inspect <container> \
  --format '{{ json .GraphDriver }}' | jq .
```

## Перенос образов (save/load, export/import)

### `docker save` и `docker load`: Работа с образами

Эти команды работают с **образами**, сохраняя всю их структуру, включая слои, историю и метаданные.

- **`docker save`**: Создает `.tar`-архив из одного или нескольких образов.

  ```sh
  docker save -o my_images.tar my-image:1.1.0 another-image:1.1
  ```

- **`docker load`**: Загружает образы из `.tar`-архива.

  ```sh
  docker load -i my_images.tar
  ```

### `docker export` и `docker import`: Работа с файловой системой

Эти команды работают с **файловой системой контейнера**, создавая "плоский" (flattened) архив.

- **`docker export`**: Создает `.tar`-архив файловой системы контейнера.

  ```sh
  docker export my-container > my_container.tar
  ```

- **`docker import`**: Создает **новый** образ из `.tar`-архива.

  ```sh
  cat my_container.tar | docker import - my-new-image:1.1.0
  ```

### Ключевые различия

| Критерий | `save`/`load` | `export`/`import` |
| :--- | :--- | :--- |
| **Объект** | **Образ (Image)** | **Файловая система контейнера** |
| **Слои** | **Сохраняются** | Теряются (объединяются) |
| **История** | Сохраняется | Теряется |
| **Метаданные** | Сохраняются | Теряются |
| **Назначение** | Перенос/бекап образов | Создание "чистого" базового образа |
