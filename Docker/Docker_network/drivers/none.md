# Сетевой драйвер none

## Определения

**Драйвер none** — это сетевой драйвер Docker, который полностью отключает сетевой стек для контейнера. Контейнер, запущенный с этим драйвером, не имеет внешних сетевых интерфейсов и полностью изолирован от сетей хоста и других контейнеров.

## Основные концепции

### Механизм работы

При запуске контейнера с опцией `--network none` Docker создает для него изолированное сетевое пространство имен (network namespace). В отличие от других драйверов, Docker не выполняет настройку сетевых интерфейсов:

- Внешние сетевые интерфейсы не создаются.
- IP-адрес (Internet Protocol) не назначается.
- Таблицы маршрутизации остаются пустыми (за исключением локального интерфейса).

Внутри контейнера доступен только интерфейс `lo` (loopback), предназначенный для взаимодействия процессов в рамках одного и того же контейнера.

### Сценарии использования

- **Полная изоляция:** Выполнение batch-заданий и вычислений, требующих доступа только к данным в подключенных **[томах](../../Docker_fs/docker_volumes.md)**.
- **Повышенная безопасность:** Гарантированное отсутствие сетевого доступа для критически важных процессов.
- **Собственная настройка сети:** Использование сторонних инструментов управления сетью или CNI (Container Network Interface) плагинов для ручной конфигурации сетевого пространства имен контейнера.

## Практические сценарии

### Проверка сетевой изоляции контейнера

1. **Запуск контейнера:**

    ```bash
    docker run -d --name isolated-container --network none alpine sleep 3600
    # → Контейнер запущен в режиме полной сетевой изоляции
    ```

2. **Просмотр доступных интерфейсов:**

    ```bash
    docker exec isolated-container ip addr
    # → 1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536 qdisc noqueue state UNKNOWN qlen 1000
    # →     link/loopback 00:00:00:00:00:00 brd 00:00:00:00:00:00
    # →     inet 127.0.0.1/8 scope host lo
    ```

3. **Проверка отсутствия связи с внешней сетью:**

    ```bash
    docker exec isolated-container ping -c 1 8.8.8.8
    # → ping: bad address '8.8.8.8' или "Network is unreachable"
    ```

## Дополнительная информация

При использовании драйвера `none` контейнер лишается возможности использовать встроенный DNS-сервер Docker для связи с другими контейнерами. Любые сетевые взаимодействия возможны только при ручной настройке интерфейсов через пространство имен контейнера в Linux.
