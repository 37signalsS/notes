# Драйвер сети: none

## Определения

**None-режим** — это сетевой драйвер Docker, который предоставляет контейнеру полную сетевую изоляцию. При его использовании контейнеру не присваиваются сетевые интерфейсы, и сеть полностью отключается.

## Базовые концепции

Принцип работы драйвера `none` заключается в том, что Docker не настраивает никакой сетевой стек для контейнера. Контейнер запускается без доступа к какой-либо сети, как к внешней, так и к внутренней (другим контейнерам на том же хосте).

## Практические сценарии

*   **Полная изоляция**: Используется для задач, где требуется максимально жесткая сетевая изоляция и контейнеру не нужен доступ к сети.
*   **Тонкая ручная настройка**: Подходит для продвинутых сценариев, когда сетевая конфигурация внутри контейнера будет настроена вручную после запуска (например, с использованием `nsenter` для входа в сетевое пространство имен).

**Пример использования:**

```bash
docker run -it --network none alpine ip addr
```

Эта команда запустит контейнер `alpine` без сетевых интерфейсов. Команда `ip addr` внутри контейнера покажет только loopback-интерфейс (`lo`).

## Дополнительная информация

Драйвер `none` крайне редко используется в повседневной работе, но может быть полезен для специфических задач, связанных с безопасностью или отладкой сетевых конфигураций.
