## Сетевые драйверы Docker

**По умолчанию существуют/создаются три вида сетей в докере: bridge, none, host**

| Драйвер   | Изоляция                | Производительность  | Основной сценарий использования                                              |
| :-------- | :---------------------- | :------------------ | :--------------------------------------------------------------------------- |
| `bridge`  | Высокая (своя подсеть)  | Хорошая (через NAT) | **Сеть по умолчанию.** Изолированные контейнеры на одном хосте.              |
| `host`    | Отсутствует             | Максимальная        | Когда нужна высокая производительность и не важна изоляция.                  |
| `none`    | Полная                  | N/A                 | Для контейнеров, которым не требуется сеть (например, для пакетных заданий). |
| `overlay` | Высокая (между хостами) | Хорошая             | **Docker Swarm.** Для связи контейнеров, запущенных на разных хостах.        |
| `macvlan` | Средняя (на уровне L2)  | Высокая             | Интеграция контейнеров в физическую сеть как полноценных устройств.          |
