## Сетевые драйверы Docker

**По умолчанию существуют/создаются три вида сетей в докере: bridge, none, host**

| Драйвер   | Изоляция                | Производительность  | Основной сценарий использования                                              |
| :-------- | :---------------------- | :------------------ | :--------------------------------------------------------------------------- |
| `bridge`  | Высокая (своя подсеть)  | Хорошая (через NAT) | **Сеть по умолчанию.** Изолированные контейнеры на одном хосте, локальная разработка. |
| `host`    | Отсутствует             | Максимальная        | Для контейнеров, которым требуется высокая производительность и доступ к сети хоста напрямую (например, мониторинг, логгинг). |
| `none`    | Полная                  | N/A                 | Для задач, где требуется полная изоляция и отсутствие сетевого взаимодействия. |
| `overlay` | Высокая (между хостами) | Хорошая             | **Docker Swarm.** Для связи контейнеров, запущенных на разных хостах в распределенных микросервисных системах. |
| `macvlan` | Средняя (на уровне L2)  | Высокая             | Контейнеры становятся полноценными участниками физической сети, получая свой MAC-адрес и IP. |
| `ipvlan`  | Средняя (на уровне L3)  | Высокая             | Похоже на Macvlan, но с более простым управлением IP-адресами на уровне L3, подходит для масштабных систем с жёсткими требованиями к маршрутизации. |
