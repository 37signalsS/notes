# Управление сетями Docker: CLI

### Определения

- **Сеть Docker (Docker Network)**: Виртуальная сеть, обеспечивающая изоляцию и коммуникацию между контейнерами, а также связь с внешним миром. Docker предоставляет различные драйверы сетей (`bridge`, `host`, `overlay`, `macvlan`, `none`) для разных сценариев использования.

### Основные понятия: Команды CLI

| Команда | Описание |
| :--- | :--- |
| `docker network ls` | Показать все сети. |
| `docker network create <имя>` | Создать новую сеть (по умолчанию используется драйвер `bridge`). |
| `docker network create --driver <драйвер> --subnet <подсеть> --gateway <шлюз> <имя>` | Создать сеть с указанием драйвера, подсети и шлюза. |
| `docker network inspect <имя>` | Показать детальную информацию о сети, включая подключенные контейнеры и их IP-адреса. |
| `docker network connect <сеть> <контейнер>` | Подключить работающий контейнер к дополнительной сети. |
| `docker network disconnect <сеть> <контейнер>` | Отключить контейнер от сети. |
| `docker network prune` | Удалить все неиспользуемые сети (сети, к которым не подключен ни один контейнер). |
| `docker run --network <сеть> ...` | Запустить контейнер, сразу подключив его к указанной сети. |
