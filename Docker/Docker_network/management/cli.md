## Управление сетями: Основные команды

| Команда | Описание |
| :--- | :--- |
| `docker network ls` | Показать все сети. |
| `docker network create <имя>` | Создать новую сеть (по умолчанию `bridge`). |
| `docker network create --driver bridge --subnet=... --gateway=... <имя>` | Создать сеть с указанием драйвера, подсети и шлюза. |
| `docker network inspect <имя>` | Показать детальную информацию о сети, включая подключенные контейнеры. |
| `docker network connect <сеть> <контейнер>` | Подключить работающий контейнер к сети. |
| `docker network disconnect <сеть> <контейнер>` | Отключить контейнер от сети. |
| `docker run --network <сеть> ...` | Запустить контейнер, сразу подключив его к указанной сети. |
