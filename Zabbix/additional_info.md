# Zabbix — дополнительная техническая информация

## Определения

* **Процесс запуска Zabbix Server** — последовательность инициализации внутренних компонентов системы при старте службы, включающая загрузку параметров конфигурации, синхронизацию с базой данных и активацию рабочих процессов.
* **Инкрементальная загрузка конфигурации** — механизм обновления кэша конфигурации Zabbix Server, при котором в память загружаются только измененные в базе данных объекты, что снижает нагрузку на СУБД.

---

## Основные концепции

### Последовательность запуска сервера

При старте службы Zabbix Server выполняет следующие этапы инициализации:

1. **Чтение конфигурации:** загрузка параметров из файла `zabbix_server.conf`.
2. **Аллокация памяти:** создание и инициализация разделяемых сегментов памяти (Shared Memory) для кэшей.
3. **Проверка схемы БД:** верификация соответствия версии базы данных текущему бинарному файлу сервера.
4. **Запуск HA-менеджера:** активация процессов обеспечения высокой доступности (если настроено).
5. **Первичная загрузка кэша:** наполнение оперативной памяти данными о хостах, элементах и триггерах из базы данных.
6. **Активация воркеров:** запуск процессов сбора (`pollers`), приема (`trappers`) и синхронизации данных (`history syncers`).

### Оптимизация кэша конфигурации (Zabbix 7.0+)

Начиная с версии 7.0, процесс обновления кэша конфигурации был значительно оптимизирован. Вместо полной перезагрузки всех данных раз в минуту (как это было в более ранних версиях), сервер выполняет инкрементальное обновление каждые 10 секунд по умолчанию. Это позволяет быстрее применять изменения, внесенные через веб-интерфейс, и снижает пиковые нагрузки на центральный процессор и дисковую подсистему БД.

## Практические сценарии

### Анализ процесса запуска через логи

Для диагностики проблем при старте сервера рекомендуется использовать лог-файл (обычно `/var/log/zabbix/zabbix_server.log`).

Основные сообщения об успешном прохождении этапов:

* `Starting Zabbix Server. Zabbix 7.0.0 (revision ...).` — начало запуска.
* `using configuration file: /etc/zabbix/zabbix_server.conf` — файл прочитан.
* `current database version (main/optional): 07000000/07000000` — версия БД корректна.
* `server #0 started [main process]` — сервер успешно запущен.

Если процесс прерывается на этапе проверки БД, необходимо убедиться в корректности выполненного импорта схемы при установке (см. раздел **[Установка и настройка](./installation.md)**).

## Дополнительная информация

### Рекомендации по настройке ресурсов

При большом количестве объектов мониторинга необходимо корректировать параметры в `zabbix_server.conf`:

* `CacheSize` — размер кэша конфигурации.
* `HistoryCacheSize` — размер кэша для хранения сырых данных перед записью в БД.
* `ValueCacheSize` — размер кэша для вычисления триггеров.

Подробные инструкции по тюнингу производительности приведены в разделе **[Тюнинг и устранение неисправностей](./zabbix_troubleshooting_and_performance_tuning.md)**.
