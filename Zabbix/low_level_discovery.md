# Zabbix: Низкоуровневое обнаружение (LLD)

## Пример JSON для LLD файловых систем

```json
{
  "data": [
    { "{#FSNAME}": "/", "{#FSTYPE}": "ext4" },
    { "{#FSNAME}": "/boot", "{#FSTYPE}": "ext4" },
    { "{#FSNAME}": "/var/log", "{#FSTYPE}": "xfs" }
  ]
}
```

На основе этих данных Zabbix создаст проверки для каждой файловой системы, используя прототипы, например, `Free disk space on {#FSNAME}` с ключом `vfs.fs.size[{#FSNAME},pfree]`.

---

## Принцип работы LLD

1. **Правило обнаружения (LLD Rule)** внутри шаблона выполняет проверку, которая возвращает **JSON-объект** со списком обнаруженных ресурсов.

2. **Прототипы (`Prototypes`)** элементов данных, триггеров и графиков используют специальные макросы из полученного JSON.

3. **Создание реальных объектов:** Zabbix автоматически создаёт настоящие элементы данных, триггеры и графики для каждого обнаруженного ресурса, подставляя значения из JSON в прототипы.

Если какой-то объект (например, файловая система) исчезает из JSON при следующей проверке, Zabbix автоматически удаляет связанные с ним метрики и триггеры.
