# Zabbix: Мониторинг баз данных (Database Monitoring)

## Definitions

**Мониторинг СУБД в Zabbix** — процесс сбора, анализа и визуализации метрик производительности, доступности и состояния баз данных с использованием Zabbix. Цель — своевременное выявление проблем, оптимизация производительности и обеспечение непрерывной работы БД.

**Уровни мониторинга СУБД:**

- **Инфраструктурный** — CPU, память, диски, сеть на сервере БД.
- **Экземпляр БД** — внутренние метрики СУБД (I/O, блокировки, репликация, свободное место в дата-файлах).
- **SQL-синтаксис** — статистика оптимизатора, выявление неоптимальных запросов.
- **Сессии** — активные соединения, сессии с высокой нагрузкой.

## Basic Concepts

### Подходы к мониторингу

Мониторинг СУБД должен охватывать все четыре уровня. Необходимость детализации зависит от конкретной СУБД. Например, Oracle редко падает «сам по себе» — проблемы обычно вызваны нехваткой дискового пространства, использованием swap или сбоями резервного копирования, что заметно на инфраструктурном уровне.

### Методы сбора данных в Zabbix

Zabbix предлагает несколько способов мониторинга баз данных.

#### ODBC

Универсальный драйвер ODBC для прямого подключения Zabbix Server/Proxy к СУБД.

- **Преимущества:** Готовые ODBC-шаблоны для различных СУБД (MySQL, PostgreSQL, Oracle). Удобно для локальных конфигураций.
- **Недостатки:** Требует прямого соединения с СУБД. В географически распределённой инфраструктуре может потребоваться проброс портов и настройка файрволов, что создаёт риски безопасности.

#### UserParameter (Zabbix Agent)

Кастомные параметры (`UserParameter`) в конфигурации Zabbix Agent, ссылающиеся на внешние скрипты.

- **Преимущества:** Гибкость (любые кастомные метрики), безопасность (агент подключается через `localhost`, БД не доступна извне), поддержка любых языков scripting, пассивный и активный режимы.
- **Недостатки:** Требуется самостоятельная разработка и поддержка скриптов, неоптимальные скрипты создают нагрузку на сервер, специфичность под каждую СУБД.

#### Модули и внешние агенты

Специализированные модули (`zabbix.spg.sql` для PostgreSQL) или сторонние агенты (Mamonsu, Zabbix DBA для MySQL).

- **Преимущества:** Готовые решения для расширенного мониторинга.
- **Недостатки:** Модули могут не поддерживать последние версии Zabbix, некоторые требуют ручной компиляции, сильная зависимость от сторонних разработчиков.

#### Zabbix Agent 2

Новая версия агента на Go с модульной архитектурой и плагинами.

- **Преимущества:** Встроенные плагины для PostgreSQL, MySQL, Oracle, Redis. Эффективный мониторинг через специализированные плагины, кроссплатформенность, упрощённая разработка (Go вместо C).
- **Примеры:** [Мониторинг PostgreSQL](./zabbix_postgresql_monitoring.md), [Мониторинг MySQL](../Databases/MySQL/monitoring.md).

#### Zabbix Agent DBMON

Специализированный форк Zabbix Agent для мониторинга широкого перечня СУБД «из коробки» (MySQL, PostgreSQL, Oracle, MS SQL Server).

- **Преимущества:** Упрощённое развёртывание, минимизация ручных настроек.
- **Установка:** Замена бинарника стандартного Zabbix Agent на скомпилированный бинарник DBMON (без компиляции всего агента из исходников).

## Practical Scenarios

### Выбор подхода по СУБД

| СУБД | Рекомендуемый подход | Документация |
|------|---------------------|--------------|
| PostgreSQL | Zabbix Agent 2 с плагином | [Мониторинг PostgreSQL](./zabbix_postgresql_monitoring.md) |
| MySQL/MariaDB | Zabbix Agent + UserParameter | [Мониторинг MySQL](../Databases/MySQL/monitoring.md) |
| Oracle | Zabbix Agent DBMON / ODBC | — |
| Redis | Zabbix Agent 2 с плагином | — |
| ClickHouse | UserParameter / HTTP-запросы | — |

### Рекомендации

1. **PostgreSQL** — использовать **Zabbix Agent 2** со специализированным плагином как наиболее современный и функциональный подход.
2. **MySQL** — рекомендуется **UserParameter** с безопасной аутентификацией через `~/.my.cnf`.
3. **Oracle и коммерческие СУБД** — **Zabbix Agent DBMON** или мониторинг через **ODBC**.
4. **Лучшие практики** по настройке триггеров, оповещений и общие рекомендации: [Лучшие практики настройки Zabbix](./zabbix_best_practices.md).
