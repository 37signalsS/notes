# Zabbix — лучшие практики настройки

> Основные понятия и архитектура системы описаны в разделе **[Определения и основные концепции](./definitions_and_concepts.md)**.

---

## Определения

* **Гистерезис (Hysteresis)** — механизм предотвращения «дребезжания» триггера (постоянного переключения между состояниями Problem и OK) путем установки различных пороговых значений для активации и восстановления.
* **Зависимости триггеров (Trigger Dependencies)** — иерархическая связь между триггерами, позволяющая подавлять оповещения от зависимых объектов, если проблема вызвана корневой причиной (например, недоступностью вышестоящего коммутатора).
* **Уровни серьезности (Severity Levels)** — классификация проблем по степени влияния на бизнес-процессы (Information, Warning, Average, High, Disaster). Используется для фильтрации и маршрутизации оповещений.
* **Усталость от оповещений (Alert Fatigue)** — эффект потери концентрации и игнорирования уведомлений персоналом из-за чрезмерного количества некритичных или ложных срабатываний системы мониторинга.

---

## Основные концепции

Эффективная система мониторинга строится на принципах наблюдаемости, где каждое оповещение требует действия. Если на событие нет реакции, триггер должен быть пересмотрен или отключен.

Ключевые принципы:

* **Информативность:** оповещение должно содержать достаточно контекста для понимания сути проблемы.
* **Минимизация шума:** использование фильтров, гистерезиса и зависимостей для исключения ложных тревог.
* **Масштабируемость:** применение шаблонов и низкоуровневого обнаружения (LLD) для автоматизации настройки.

## Практические сценарии

### Настройка триггеров

#### Снижение количества ложных срабатываний

1. **Чувствительность:** избегайте триггеров на мгновенные пики. Используйте функции времени или количества проверок (например, `last(#3)` или `max(5m)`).
2. **Гистерезис:** применяйте разные условия для входа и выхода из состояния проблемы. Пример:
   * Проблема: `{host:system.cpu.util.avg(5m)}>90`
   * Восстановление: `{host:system.cpu.util.avg(10m)}<80`
3. **Функции трендов:** для анализа больших периодов (недели, месяцы) используйте `trendavg`, `trendmax`. Это значительно снижает нагрузку на базу данных по сравнению с обычными функциями истории. Подробнее: **[Тюнинг производительности](./zabbix_troubleshooting_and_performance_tuning.md)**.

#### Использование зависимостей

Настраивайте зависимости для минимизации «шторма» уведомлений. Если сервер находится за прокси-сервером или коммутатором, триггеры доступности сервера должны зависеть от доступности сетевого узла.

### Стратегия оповещений

| Канал | Применение | Рекомендации |
| :--- | :--- | :--- |
| **Telegram / Чат-системы** | Оперативное информирование | Использование ботов и групп для командного взаимодействия. |
| **Email** | Отчетность и некритичные события | Требует корректной настройки SMTP и SPF/DKIM для исключения попадания в спам. |
| **Service Desk (Jira/ITSM)** | Инцидент-менеджмент | Автоматическое создание заявок для уровней High и Disaster. |
| **SMS / Звонки** | Критические аварии | Только для уровня Disaster в нерабочее время. |

### Веб-мониторинг

| Метод | Описание | Когда использовать |
| :--- | :--- | :--- |
| **Browser Checks** | Выполнение JavaScript через Selenium. | Рекомендуемый подход для современных SPA и сложных сценариев с авторизацией. |
| **Web Scenarios** | Проверка HTTP-кодов и содержимого (curl-based). | Базовые проверки доступности простых API или статических сайтов. |

### Мониторинг самодиагностики

Обязательным условием надежной системы является мониторинг компонентов самого Zabbix:

* **Здоровье сервера:** загрузка процессов (`pollers`, `syncers`), утилизация кэшей (`Value cache`, `History cache`).
* **База данных:** скорость выполнения запросов, размер таблиц, состояние партиций.
* **Инфраструктура:** доступность Zabbix Proxy, нагрузка на веб-сервер и PHP-FPM.

Для глубокого анализа внутренних метрик используйте встроенный шаблон `Zabbix server health` и рекомендации из раздела **[Тюнинг и диагностика](./zabbix_troubleshooting_and_performance_tuning.md)**.
