# Wazuh

## 1. Определения

**Wazuh** ([wazuh/wazuh](https://github.com/wazuh/wazuh)) — это бесплатная платформа с открытым исходным кодом для предотвращения, обнаружения и реагирования на угрозы, объединяющая возможности XDR (eXtended Detection and Response) и SIEM (Security Information and Event Management).

## 2. Основные концепции

* **SIEM и XDR**: Централизованный сбор, анализ логов и расширенное обнаружение угроз.
* **Обнаружение вторжений (HIDS)**: Мониторинг системы на наличие вредоносного ПО, руткитов и аномалий.
* **Мониторинг целостности файлов (FIM)**: Отслеживание изменений в критически важных файлах.
* **Обнаружение уязвимостей**: Автоматическое сканирование на наличие известных уязвимостей (CVE).
* **Соответствие стандартам**: Помогает в соблюдении PCI DSS, GDPR и других нормативов.

### Компоненты

* **Wazuh Agent**: Устанавливается на конечные точки для сбора данных.
* **Wazuh Server**: Анализирует данные от агентов.
* **Wazuh Indexer**: Индексирует и хранит сгенерированные данные и алерты (форк OpenSearch).
* **Wazuh Dashboard**: Веб-интерфейс для визуализации данных и управления алертами (форк OpenSearch Dashboards).

## 3. Практические сценарии

Wazuh применяется для решения широкого круга задач по обеспечению безопасности:

* **Мониторинг целостности файлов (FIM)**: Отслеживание изменений в критических системных файлах, например, `/etc/passwd` или файлах веб-сервера. Отличается от разовых проверок ([AIDE, debsums, rpm](../../Linux/Security/Concepts/file-integrity-checking.md)) непрерывным мониторингом в реальном времени.
* **Обнаружение уязвимостей**: Агент собирает список установленного ПО, а сервер коррелирует его с базами данных CVE, выявляя уязвимые компоненты.
* **Анализ логов**: Сбор и анализ логов с конечных точек, сетевых устройств и приложений для обнаружения аномалий.
* **Безопасность контейнеров**: Мониторинг событий в Docker и Kubernetes для обнаружения угроз в контейнеризированных средах.
* **Соответствие стандартам**: Wazuh содержит готовые наборы правил и отчеты для соответствия стандартам PCI DSS, GDPR, CIS и др.

## 4. Продвинутые детали

### Активное реагирование (Active Response)

Ключевая возможность Wazuh — автоматическое выполнение действий в ответ на определенные события. Это позволяет не только обнаруживать, но и блокировать угрозы в реальном времени.

**Примеры активного реагирования:**

* **Блокировка IP-адреса**: При обнаружении множества неудачных попыток входа по SSH (brute-force), Wazuh может автоматически заблокировать атакующий IP-адрес с помощью `iptables` или `firewalld`.
* **Изоляция хоста**: Временно изолировать скомпрометированный хост от сети, чтобы предотвратить распространение угрозы.
* **Остановка вредоносного процесса**: Автоматически завершить процесс, который был идентифицирован как вредоносный по сигнатурам YARA.
* **Отключение пользователя**: Заблокировать учетную запись пользователя после серии подозрительных действий.

### Интеграция с внешними системами

Wazuh может быть интегрирован с другими платформами для расширения своих возможностей:

* **YARA**: Использование правил YARA для сканирования файловой системы на наличие вредоносного ПО.
* **VirusTotal**: Автоматическая проверка хешей подозрительных файлов через API VirusTotal.
* **Slack/TheHive**: Отправка уведомлений и создание инцидентов во внешних системах для дальнейшего расследования.
