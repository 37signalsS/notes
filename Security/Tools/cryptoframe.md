# CryptoFrame: Стеганография зашифрованных данных в видео

## Definitions

**CryptoFrame** ([github.com/x011/CryptoFrame](https://github.com/x011/CryptoFrame)) — инструмент, который шифрует текст и скрывает его в видеофайле методом LSB-стеганографии. Комбинирует многослойное шифрование (AES-256-CBC + RSA-4096) со стеганографией для одновременной защиты содержимого и сокрытия факта передачи сообщения.

## Basic Concepts

### Принцип работы: LSB-стеганография в видео

**LSB (Least Significant Bit)** — запись информации в наименее значимый бит пикселей кадров видео:

1. Видео разбивается на кадры (пиксели RGB)
2. Скрываемый текст преобразуется в биты
3. LSB каждого пикселя заменяется на бит сообщения

Биты распределяются по разным пикселям и кадрам, что затрудняет статистический анализ и обнаружение.

### Криптография

| Слой | Алгоритм | Назначение |
| :--- | :--- | :--- |
| **Данные** | 7 × AES-256-CBC | Многослойное шифрование содержимого |
| **Ключ AES** | RSA-4096 | Шифрование ключа симметричного шифра |

Даже при обнаружении факта стеганографии извлечение содержимого без RSA-ключа практически невозможно.

### Требование lossless-кодеков

Критическое ограничение: выходное видео **обязательно** сжимается только кодеками без потерь:

| Тип | Кодеки | Влияние на LSB |
| :--- | :--- | :--- |
| **Lossless** | FFV1, HFYU | Сохраняют LSB-данные целиком |
| **Lossy** | H.264, H.265, VP9 | Удаляют младшие биты → потеря скрытых данных |

**Компромисс:** lossless-видео значительно больше по размеру, что может вызвать подозрения при передаче.

## Practical Scenarios

### Тайная пересылка сообщений

Встраивание зашифрованных сообщений в видеофайлы для скрытой коммуникации. Получатель знает алгоритм извлечения и RSA-ключ.

```bash
# Примерный пайплайн (синтаксис зависит от версии)
cryptoframe encode -i input_video.mp4 -m "secret message" -k public_key.pem -o output.mkv
cryptoframe decode -i output.mkv -k private_key.pem
```

### CTF-соревнования

Стандартный сценарий — найти скрытое сообщение в видеофайле:

- Анализ метаданных (`ffprobe`, `mediainfo`)
- Извлечение кадров и LSB-анализ
- Определение кодека (lossless — индикатор возможной стеганографии)

### Поддерживаемые платформы и форматы

- **Платформы:** Linux, Windows, macOS (Python 3+)
- **Входные форматы:** AVI, MKV, MOV, MP4 и др.
- **Выходные форматы:** AVI, MOV, MKV (только lossless)

## Additional Information

### Объём скрытых данных

Видеофайлы значительно превышают изображения по объёму, что позволяет встраивать большие сообщения. Распределение по кадрам увеличивает устойчивость к обнаружению по сравнению со статичными изображениями.

### Ограничения и риски

- **Размер файла:** lossless-видео в разы больше lossy — аномальный размер может привлечь внимание
- **Статистический анализ:** RS-анализ, гистограммный анализ могут выявить LSB-модификации
- **Не защищает от lossy-транскодирования:** любая конвертация в H.264/H.265 уничтожит скрытые данные
- **Малоактивный проект:** репозиторий обновляется нерегулярно; для production-использования рекомендуется аудит кода
