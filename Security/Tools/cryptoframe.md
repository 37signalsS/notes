# CryptoFrame

## 1. Определения

**CryptoFrame** ([github.com/x011/CryptoFrame](https://github.com/x011/CryptoFrame)) - это инструмент, который шифрует текст и скрывает его в видеофайле, используя стеганографию.

## 2. Основные концепции

CryptoFrame использует метод **Least Significant Bit (LSB)** — запись информации в наименее значимый бит пикселей в кадрах видео.

- **Процесс:**
    1. Видео разбивается на кадры, состоящие из пикселей (RGB).
    2. Скрываемый текст преобразуется в биты.
    3. Метод LSB заменяет последний, наименее значимый бит в значении цвета пикселя на бит скрываемого сообщения.
- **Надежность:** Биты скрытых данных распределяются по разным пикселям и кадрам. Чтобы избежать потери данных, на выходе создается видео, сжатое **только кодеками без потерь** (lossless), такими как `FFV1` или `HFYU`.
- **Шифрование:**
  - **Данные:** 7 слоев AES-256-CBC.
  - **Ключ AES:** Шифруется с помощью RSA-4096.

## 3. Практические сценарии

Инструмент может использоваться для тайной пересылки зашифрованных сообщений внутри видеофайлов.

- **Платформы:** Linux, Windows, macOS (Python 3+).
- **Входные форматы:** AVI, MKV, MOV, MP4, и др.
- **Выходные форматы:** AVI, MOV, MKV (только lossless).

## 4. Продвинутые детали

### Особенности стеганографии в видео

Применение LSB-стеганографии к видеофайлам имеет свои особенности:

- **Объем данных:** Видеофайлы, как правило, намного больше изображений, что позволяет скрывать значительные объемы данных.
- **Движение и изменения:** Динамика видеоряда может маскировать незначительные изменения, внесенные LSB, делая их еще менее заметными для человеческого глаза по сравнению со статичными изображениями.
- **Временной аспект:** Возможность распределять скрытые данные по большому количеству кадров затрудняет статистический анализ и увеличивает сложность обнаружения.

### Значение lossless кодеков

Критически важным аспектом CryptoFrame является использование **только кодеков без потерь (lossless)**, таких как `FFV1` или `HFYU`. Это обусловлено тем, что большинство популярных видеокодеков (например, H.264, H.265) являются **кодеками с потерями (lossy)**.

- **Lossy-кодеки:** При сжатии они удаляют часть информации, которая считается наименее значимой для человеческого восприятия. Это включает в себя младшие биты пикселей, что делает LSB-стеганографию неэффективной и приводит к потере скрытых данных.
- **Lossless-кодеки:** Сохраняют всю исходную информацию, что гарантирует целостность внедренных LSB-данных после кодирования. Однако, видеофайлы, сжатые такими кодеками, обычно значительно больше по размеру, чем сжатые lossy-кодеками, что может вызвать подозрения и затруднить передачу.

### Многослойное шифрование

Использование 7 слоев AES-256-CBC с ключом, зашифрованным RSA-4096, обеспечивает высокий уровень криптографической стойкости скрываемого сообщения. Это означает, что даже если сам факт стеганографии будет обнаружен, извлечение содержимого без знания ключей будет крайне затруднительным.
