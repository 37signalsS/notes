# Aces: Утилита и библиотека для кодирования данных

**Aces** — это утилита командной строки и библиотека, разработанная на Go, которая позволяет кодировать любые данные в набор символов по вашему выбору. Это предоставляет гибкий способ скрывать или представлять информацию в нестандартных форматах, делая ее истинное значение известным только вам.

## Возможности

*   **Произвольный набор символов:** Вы можете использовать любой набор символов для кодирования, включая буквы, цифры, специальные символы или даже эмодзи.
*   **Гибкие форматы:** Поддерживаются стандартные форматы (шестнадцатеричный, восьмеричный, двоичный), а также возможность создавать собственные форматы кодирования.
*   **Пример использования:** Например, строку «Foo Bar» можно закодировать комбинацией символов «HhAa», что приведет к последовательности, такой как `hHhAhAaahAaaHAHHhHHAhAHhhaHA`, значение которой известно только вам.
*   **Использование как библиотеки:** Aces также предоставляет библиотеку для Go, которую можно интегрировать в другие приложения для кодирования и декодирования данных программным путем.
