# Aces: Утилита и библиотека для кодирования данных

## Definitions

**Aces** ([github.com/quackduck/aces](https://github.com/quackduck/aces)) — утилита командной строки и Go-библиотека для кодирования произвольных данных в пользовательский набор символов. Предоставляет гибкий механизм обфускации и представления информации в нестандартных форматах без использования криптографии.

## Basic Concepts

- **Произвольный charset:** Кодирование в любой набор символов — буквы, цифры, спецсимволы, эмодзи, Unicode-блоки.
- **Стандартные форматы:** Поддержка hex, octal, binary режимов кодирования.
- **Библиотека для Go:** Программное использование через [pkg.go.dev/github.com/quackduck/aces](https://pkg.go.dev/github.com/quackduck/aces).
- **CLI-утилита:** Установка через `go install github.com/quackduck/aces@latest`.

## Practical Scenarios

### Базовое использование

```bash
# Кодирование строки "Foo Bar" в набор символов "HhAa"
echo -n "Foo Bar" | aces encode HhAa
# Результат: hHhAhAaahAaaHAHHhHHAhAHhhaHA

# Декодирование
echo "hHhAhAaahAaaHAHHhHHAhAHhhaHA" | aces decode HhAa
```

### Обфускация секретов

Скрытие API-ключей, токенов или конфигурационных данных в логах или конфигурационных файлах без использования шифрования:

```bash
# Кодирование секретного ключа в эмодзи
echo -n "sk-1234567890abcdef" | aces encode "🔐🔑🔒🛡️"
```

### Обход текстовых фильтров

Перекодирование данных в символы, не попадающие под регулярные выражения систем обнаружения:

```bash
# Использование Unicode-символов, похожих на латиницу
echo -n "sensitive-data" | aces encode "αβγδεζηθ"
```

## Additional Information

### Применение в security-практиках

**Обфускация:** Трансформация данных в малопонятный формат без криптографии. Закодированные данные выглядят как случайный набор символов для неподготовленного наблюдателя.

**Маскировка данных:** Слияние чувствительной информации с обычным текстом для снижения заметности в автоматических системах анализа.

**Ограниченные каналы связи:** Создание пользовательского "алфавита" для протоколов с фильтрацией "подозрительных" символов.

### Гибкость charset-наборов

- **Повышенная скрытность:** Уникальный charset, известный только участникам обмена, усложняет криптоанализ.
- **Стилизация:** Данные могут имитировать текст на определённом языке, случайные последовательности или графические элементы (через Unicode-блоки).
- **Стойкость к фильтрам:** Выбор символов вне стандартных regex-паттернов обходит системы обнаружения.

### Ограничения и рекомендации

⚠️ **Aces не обеспечивает криптографическую стойкость.** Это инструмент обфускации и маскировки. Для конфиденциальной информации обязательно комбинировать с шифрованием ([SOPS](./sops_overview.md), [age](https://github.com/FiloSottile/age)).

### Связанные инструменты

- [CryptoFrame](./cryptoframe.md) — стеганография зашифрованных данных в видео
- [SecretPixel](./secretpixel.md) — стеганография в изображениях
- [Stegbrute](./stegbrute.md) — инструмент для стеганографии
- [File Hider](./file_hider.md) — скрытие файлов в других файлах

### Предостережения

- Aces подходит для обфускации, но **не заменяет шифрование**.
- Закодированные данные обратимы без ключа — любой, кто знает charset, может декодировать.
- Для production-сред используйте в комбинации с криптографическими инструментами.
