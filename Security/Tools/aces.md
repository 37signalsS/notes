# Aces: Утилита и библиотека для кодирования данных

## Определения

**Aces** ([github.com/quackduck/aces](https://github.com/quackduck/aces)) — утилита командной строки и библиотека на языке Go, предназначенная для кодирования произвольных данных с использованием пользовательских наборов символов (charset). Инструмент реализует алгоритм преобразования систем счисления (base-N encoding), где N — количество символов в предоставленном алфавите.

Это решение используется для гибкой обфускации, маскировки данных в текстовых потоках и представления информации в нестандартных форматах без применения криптографических преобразований.

## Основные концепции

- **Произвольный алфавит (Charset):** Возможность кодирования в любой набор символов — от классических букв и цифр до эмодзи, Unicode-иероглифов и невидимых символов.
- **Масштабируемость Base-N:** Длина выходной последовательности напрямую зависит от размера используемого алфавита. Чем больше символов в наборе, тем компактнее результат.
- **Интеграция с Go:** Библиотека предоставляет простые методы `Encode` и `Decode`, позволяя встраивать механизм кодирования непосредственно в приложения.
- **CLI-инструмент:** Легковесная утилита для использования в пайплайнах Bash и автоматизации.

## Практические сценарии

### Базовое использование через CLI

Установка:
```bash
go install github.com/quackduck/aces@latest
```

Кодирование строки с использованием кастомного алфавита:
```bash
# Кодирование строки "DevOps" в алфавит "01" (двоичное представление)
echo -n "DevOps" | aces encode "01"
# Результат: 010001000110010101110110010011110111000001110011

# Декодирование обратно в текст
echo "010001000110010101110110010011110111000001110011" | aces decode "01"
```

### Маскировка данных под обычный текст

Использование набора символов, визуально похожих на стандартный текст, для обхода простейших фильтров или снижения заметности:

```bash
# Кодирование пароля в набор кириллических символов, похожих на латиницу
echo -n "P@ssw0rd123" | aces encode "АВЕКМНОРСТУХ"
```

### Использование в качестве Go-библиотеки

Пример интеграции в программный код:

```go
package main

import (
	"fmt"
	"github.com/quackduck/aces"
)

func main() {
	charset := "αβγδεζηθ"
	data := []byte("secret signal")

	// Кодирование
	encoded := aces.Encode(data, charset)
	fmt.Printf("Encoded: %s\n", encoded)

	// Декодирование
	decoded, err := aces.Decode(encoded, charset)
	if err != nil {
		panic(err)
	}
	fmt.Printf("Decoded: %s\n", string(decoded))
}
```

## Дополнительная информация

### Сравнение с шифрованием

Важно понимать архитектурное различие:
- **Шифрование:** Защищает данные от несанкционированного доступа с помощью ключа. Без ключа чтение невозможно.
- **Обфускация (Aces):** Скрывает смысл данных, меняя их представление. Если наблюдатель знает или может угадать используемый алфавит (charset), данные легко декодируются.

Aces не обеспечивает конфиденциальность против активного криптоанализа. Для защиты чувствительных данных используйте [SOPS](./sops_overview.md) или системные средства шифрования.

### Технические ограничения

1.  **Длина алфавита:** Минимальная длина алфавита для работы Aces — 2 символа.
2.  **Уникальность символов:** Все символы в строке `charset` должны быть уникальными. При наличии дубликатов результат декодирования будет некорректным.
3.  **Нагрузка на память:** При работе с экстремально большими объемами данных через библиотеку следует учитывать потребление ресурсов на этапе преобразования систем счисления.
