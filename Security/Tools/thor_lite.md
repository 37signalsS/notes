# THOR Lite: Сканер для поиска признаков взлома и вредоносного ПО

## Определения

**THOR Lite** ([Nextron Systems](https://www.nextron-systems.com/thor-lite/)) — это бесплатная версия профессионального форензик-сканера THOR, предназначенная для сообщества и малого бизнеса. Инструмент используется для поиска индикаторов компрометации (IOC), вредоносного ПО и следов хакерской активности в операционных системах Windows, Linux и macOS.

В 2026 году THOR Lite остается одним из ключевых инструментов для первичного реагирования на инциденты (**Incident Response**) и оценки компрометации (**Compromise Assessment**), используя открытые наборы сигнатур и механизмы YARA.

## Основные концепции

### Механизмы обнаружения

Сканирование в THOR Lite базируется на нескольких уровнях анализа:

*   **Сигнатуры YARA:** Поиск сложных паттернов в файлах и памяти. Используется база **Open Source** сигнатур (YARA Forge и наработки Nextron для сообщества).
*   **IOC-сканирование:** Проверка по спискам известных индикаторов (хеши MD5/SHA1/SHA256, имена файлов, IP-адреса, домены).
*   **Модуль Autoruns:** Анализ механизмов закрепления в системе (Persistence) для выявления подозрительных служб и автозагрузки.
*   **CPU Throttling:** Встроенная функция ограничения нагрузки на процессор для минимизации влияния сканирования на производительность системы.

### Лицензирование и требования

*   **Лицензия:** Бесплатна для внутреннего использования, государственных органов и образовательных целей.
*   **Получение:** Требуется регистрация на сайте Nextron (подписка на рассылку) для получения ссылки на загрузку и файла лицензии (`.lic`).
*   **Файл лицензии:** Сканер не запустится без файла `.lic`, который должен находиться в той же директории или быть указан через флаг `--licensepath`.
*   **Обновления:** Для загрузки актуальных сигнатур и версий сканера используется утилита `thor-util`.

## Практические сценарии

### Подготовка и обновление

Перед использованием необходимо обновить базу сигнатур:

```bash
# Обновление сканера и сигнатур (требуется лицензия)
./thor-util-linux update
```

### Базовое сканирование системы

Основной сценарий для полной проверки хоста:

```bash
# Запуск полного сканирования (Full Scan)
sudo ./thor-lite-linux --fullscan
```

Результаты выводятся в консоль и сохраняются в директорию `logs`.

### Сканирование конкретной области

Если требуется проверить только веб-директорию или подозрительный раздел:

```bash
# Сканирование пути с высоким уровнем интенсивности
sudo ./thor-lite-linux --path /var/www/html --scan-level high
```

### Использование пользовательских IOC

Вы можете добавить собственные индикаторы компрометации, полученные из отчетов об угрозах (Threat Intelligence):

```bash
# Сканирование с подключением пользовательского файла IOC
sudo ./thor-lite-linux --ioc-file my_custom_iocs.txt
```

### Вывод результатов в JSON

Для интеграции с системами сбора логов (SIEM, ELK) удобно использовать формат JSON:

```bash
# Запуск сканирования с сохранением отчета в JSON
sudo ./thor-lite-linux --fullscan --output json > scan_report.json
```

## Дополнительная информация

### Отличия от THOR Enterprise (APT Scanner)

THOR Lite является функционально ограниченной версией коммерческого продукта.

| Характеристика | THOR Lite | THOR Enterprise |
| :--- | :--- | :--- |
| **Сигнатуры** | Open Source (YARA Forge) | Приватные базы (30,000+ правил) |
| **IOC / Паттерны** | Базовые | 10,000+ эксклюзивных индикаторов |
| **Модули** | Базовые (ФС, Процессы) | 25+ модулей (Registry, Eventlog, ShimCache) |
| **Эвристика** | Ограничена | Продвинутый движок обнаружения Zero-day |
| **Управление** | Локальное | Централизованное (ASGARD) |
| **Сценарии** | Ручной запуск | Remote Scan, Thunderstorm (Web Service) |

### THOR Cloud Lite (2026)

В середине 2026 года Nextron представила **THOR Cloud Lite** — облегченную версию с управлением через облачную панель. Это позволяет централизованно просматривать отчеты сканирования с разных узлов без развертывания сложной инфраструктуры ASGARD.
