# THOR Lite

## 1. Определения

**THOR Lite** ([Nextron Systems](https://www.nextron-systems.com/thor-lite/)) — это мультиплатформенный сканер от компании Nextron Systems, предназначенный для поиска признаков взлома и вредоносного ПО.

## 2. Основные концепции

Сканирование в THOR Lite происходит на основе сигнатур и индикаторов компрометации (IOC). Он проверяет систему на наличие:

- Сигнатур **YARA**.
- Хешей вредоносных файлов.
- Подозрительных имён файлов.
- Ключей реестра, связанных с вредоносами.
- Сетевых индикаторов (IP-адреса, домены).

Это инструмент для быстрой проверки системы на уже известные угрозы.

THOR Lite используется для оперативного сканирования систем с целью обнаружения активных угроз или следов прошлых компрометаций.

### Базовое сканирование

```bash
# Запуск полного сканирования системы
thor-lite --fullscan
```

Эта команда запустит сканирование всех поддерживаемых областей системы (файловая система, процессы, реестр и т.д.) на основе встроенных сигнатур.

### Сканирование конкретной директории

```bash
# Сканирование определенной директории на наличие вредоносного ПО
thor-lite --path /var/www/html --scan-level high
```

Полезно для проверки веб-серверов или других критичных директорий.

### Использование внешних IOC

THOR Lite может использовать внешние списки индикаторов компрометации (IOC) для расширения обнаружения.

```bash
# Сканирование с использованием IOC из файла
thor-lite --ioc-file my_custom_iocs.txt
```

### Отчеты

Результаты сканирования обычно выводятся в консоль, а также могут быть сохранены в файл для дальнейшего анализа.

```bash
# Сохранение отчета в JSON формате
thor-lite --fullscan --output json > report.json
```

## 4. Продвинутые детали

### Принципы сигнатурного анализа

THOR Lite использует базу сигнатур, которая включает:

- **YARA-правила:** Для поиска сложных паттернов в файлах и памяти. YARA позволяет создавать правила для идентификации семейств вредоносного ПО на основе текстовых или бинарных строк, логических условий и регулярных выражений.
- **Хеши:** MD5, SHA1, SHA256 хеши известных вредоносных файлов для быстрого обнаружения.
- **Индикаторы на основе текстовых строк:** Поиск конкретных строк (например, URL командных центров, имен файлов, записей реестра), связанных с вредоносной активностью.

### Отличия от полной версии THOR (THOR APT Scanner)

THOR Lite является урезанной версией коммерческого продукта THOR APT Scanner, который предлагает гораздо более широкий функционал:

- **База сигнатур:** Полная версия имеет значительно более объемную и часто обновляемую базу сигнатур, включая приватные IOC.
- **Эвристический анализ:** THOR APT Scanner включает продвинутые эвристические движки для обнаружения неизвестных угроз (zero-day).
- **Расширенный функционал:** Включает анализ памяти, обнаружение руткитов, логирование сети, интеграцию с SIEM-системами и многое другое, чего нет в Lite-версии.
- **Поддержка:** Коммерческая версия поставляется с полноценной технической поддержкой и регулярными обновлениями.

THOR Lite полезен как быстрый инструмент для первичной проверки, но для глубокого и комплексного анализа безопасности рекомендуется использовать полноценные коммерческие решения.
