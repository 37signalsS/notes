# ghostscan: Linux Rootkit & Hidden Threat Scanner

## Definitions

**ghostscan** ([h2337/ghostscan](https://github.com/h2337/ghostscan)) — сканер безопасности для Linux на Rust для помощи в реагировании на инциденты (incident response). Выявляет скрытые руткиты, eBPF-угрозы и «призрачные» процессы (ghost processes), скрытые от стандартных утилит мониторинга.

## Basic Concepts

ghostscan собирает системную информацию из множества источников и сравнивает данные для обнаружения аномалий.

### Источники данных

- Ядро Linux: `/proc`, `/sys`
- eBPF: `bpffs`
- `systemd`, `cron`
- Сетевые сокеты

### Технологии

- **Язык:** Rust
- **Ключевая технология:** eBPF для глубокого сканирования
- **Зависимости:** `bpftool`, `nft`, `ss`, `journalctl`, `auditctl`
- **Требования:** права `root` для доступа к ядру

## Practical Scenarios

### Сборка и запуск сканирования

```bash
# Сборка из исходного кода (требуется Rust/Cargo)
git clone https://github.com/h2337/ghostscan.git
cd ghostscan
cargo build --release

# Запуск сканирования
sudo ./target/release/ghostscan
```

Инструмент выводит отчёт о подозрительных активностях: скрытые процессы, аномальные хуки ядра, несанкционированные BPF-программы.

## Additional Information

### Механизмы обнаружения на базе eBPF

- **Скрытые процессы:** Сравнение `/proc` с данными напрямую из структур ядра через eBPF. Расхождения указывают на скрытые процессы.
- **Хуки ядра:** Проверка перехватов в критических функциях ядра (например, `ftrace`), используемых вредоносным ПО для сокрытия.
- **Аномальные kprobes:** Поиск проб ядра, прикреплённых к чувствительным функциям, не принадлежащих легитимным инструментам.
- **Скрытые BPF-программы:** Обнаружение программ, закреплённых (pinned) вне стандартной директории `bpffs`.

### Сравнение с другими инструментами

- **[Falco](./falco.md):** Runtime-мониторинг и оповещение о подозрительной активности в реальном времени. ghostscan — сканирование по требованию для incident response.
- **chkrootkit/rkhunter:** Классические сканеры руткитов. ghostscan использует eBPF для обнаружения современных угроз, скрытых от традиционных утилит.
