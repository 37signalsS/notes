# ghostscan: Сканер руткитов и скрытых угроз Linux

## Определения

**ghostscan** ([h2337/ghostscan](https://github.com/h2337/ghostscan)) — специализированный сканер безопасности для Linux, написанный на Rust, предназначенный для использования в процессе реагирования на инциденты (**Incident Response**). Основная задача инструмента — выявление скрытых руткитов, eBPF-имплантов и «призрачных» процессов (**ghost processes**), которые намеренно скрываются от стандартных утилит мониторинга (`ps`, `top`, `lsof`).

## Основные концепции

ghostscan реализует метод кросс-верификации: он собирает системную информацию из множества источников и сравнивает данные для обнаружения расхождений (аномалий), характерных для работы вредоносного ПО уровня ядра.

### Механизмы обнаружения на базе eBPF

Использование eBPF позволяет сканеру получать данные напрямую из структур ядра, минуя стандартные интерфейсы, которые могут быть перехвачены руткитом.

- **Детекция скрытых процессов:** ghostscan сравнивает список процессов из `/proc` со списком, полученным через итерацию по структурам `task_struct` ядра с помощью eBPF. Любое расхождение указывает на процесс, скрытый через манипуляцию с системными вызовами или структурами VFS.
- **Анализ хуков ядра:** Проверка критических функций ядра (например, `ftrace`, `kprobes`) на наличие несанкционированных перехватов. Руткиты часто используют `kprobes` для модификации поведения системы «на лету».
- **Инспекция eBPF-программ:** Обнаружение «прикрепленных» (pinned) программ в `bpffs`, которые не отображаются в стандартных списках или имеют аномальные точки входа.
- **Скрытые сетевые сокеты:** Сравнение вывода `ss` / `/proc/net` с данными прямого трассирования стека TCP/UDP.

### Технологический стек

- **Язык:** Rust (обеспечивает безопасность памяти и высокую производительность).
- **Зависимости:** `bpftool` (для работы с BPF-объектами), `auditctl` (анализ правил аудита), `ss` (сетевая диагностика).
- **Требования:** Права `root` и поддержка ядром BTF (**BPF Type Format**) для корректной работы eBPF-зондов.

## Практические сценарии

### Сборка и запуск в изолированной среде

Для обеспечения достоверности результатов рекомендуется запускать сканер из доверенной сборки (статического бинарника).

```bash
# Сборка из исходного кода
git clone https://github.com/h2337/ghostscan.git
cd ghostscan
cargo build --release

# Запуск полного сканирования системы
sudo ./target/release/ghostscan
```

### Интерпретация результатов

| Находка | Значение | Действие |
| :--- | :--- | :--- |
| **Hidden PID detected** | Процесс существует в ядре, но скрыт от `/proc` | Немедленная изоляция хоста, дамп памяти процесса через `gcore`. |
| **Unexpected kprobe hook** | Перехват функции (например, `sys_read`) | Проверка принадлежности к инструментам мониторинга (Falco, Sysdig). |
| **Anomalous BPF program** | BPF-код, не принадлежащий системе | Анализ байт-кода через `bpftool prog dump xlated`. |

### Использование в Incident Response

1.  **Снимок состояния:** Запуск ghostscan сразу после обнаружения подозрительной активности.
2.  **Сравнение с эталоном:** Использование ghostscan на «чистом» золотом образе и сравнение списков хуков ядра.
3.  **Поиск eBPF-руткитов:** В 2025–2026 годах атаки через eBPF (например, захват SSH-сессий) становятся массовыми; ghostscan является одним из немногих инструментов, способных обнаружить такие импланты.

## Меры защиты и предотвращение

1.  **Ограничение eBPF:** Установка `kernel.unprivileged_bpf_disabled = 1` для предотвращения загрузки BPF-кода обычными пользователями.
2.  **Подпись модулей ядра:** Использование `CONFIG_MODULE_SIG_FORCE` для предотвращения загрузки неподписанных LKM-руткитов.
3.  **Мониторинг в реальном времени:** Использование [Falco](./falco.md) для мгновенного оповещения о попытках установки хуков, которые ghostscan может найти только постфактум.
4.  **Runtime Security:** Использование LSM-модулей (SELinux, AppArmor) для блокировки доступа к `/sys/fs/bpf` неавторизованным процессам.

## Дополнительная информация

### Сравнение с аналогами

- **[Falco](./falco.md):** Фокусируется на потоковом анализе событий (Event Streaming). ghostscan — это моментальный снимок (Snapshot) и глубокий аудит состояния ядра.
- **chkrootkit / rkhunter:** Классические инструменты, основанные на сигнатурах файлов и простых проверках. Они практически бесполезны против современных eBPF-руткитов, от которых защищает ghostscan.
- **[bpftool](../../Linux/Core/kernel/ebpf.md):** Низкоуровневая утилита. ghostscan надстраивает над ней логику обнаружения аномалий и сравнения данных.
