# ghostscan

## 1. Определения

**ghostscan** ([h2337/ghostscan](https://github.com/h2337/ghostscan)) — это современный сканер безопасности для Linux, написанный на Rust. Он предназначен для помощи в реагировании на инциденты (incident response).

## 2. Основные концепции

*   **Обнаружение скрытых угроз**: Помогает выявлять скрытые руткиты, продвинутые угрозы с использованием eBPF и "призрачные" процессы (процессы, скрытые от стандартных утилит мониторинга).
*   **Сбор данных**: Собирает системную информацию из множества источников для комплексного анализа:
    *   Ядро Linux (`/proc`, `/sys`)
    *   eBPF (`bpffs`)
    *   `systemd`
    *   `cron`
    *   Сетевые сокеты

*   **Язык**: Rust
*   **Ключевая технология**: eBPF для глубокого сканирования и обнаружения аномалий.
*   **Интеграции**: Взаимодействует с системными утилитами, такими как `bpftool`, `nft`, `ss`, `journalctl`, `auditctl`.

## 3. Практические сценарии

### Базовое сканирование системы
Основной сценарий использования `ghostscan` — это запуск полного сканирования системы для обнаружения аномалий. Поскольку инструмент требует глубокого доступа к ядру, его необходимо запускать с правами `root`.

1.  **Сборка из исходного кода:**
    ```bash
    # Требуется установленный Rust/Cargo
    git clone https://github.com/h2337/ghostscan.git
    cd ghostscan
    cargo build --release
    ```
2.  **Запуск сканирования:**
    ```bash
    sudo ./target/release/ghostscan
    ```
    `ghostscan` выведет отчет о найденных подозрительных активностях, таких как скрытые процессы или аномальные хуки ядра.

## 4. Продвинутые детали

### Механизмы обнаружения на базе eBPF
`ghostscan` использует eBPF для получения низкоуровневой информации о системе, недоступной для традиционных утилит, что позволяет ему обнаруживать продвинутые руткиты.

- **Обнаружение скрытых процессов**: Сравнивает список процессов, полученный из `/proc`, со списком, полученным напрямую из структур ядра через eBPF. Расхождения могут указывать на процессы, скрытые вредоносным ПО.
- **Анализ хуков ядра**: Проверяет наличие перехватов (хуков) в критически важных функциях ядра (например, `ftrace`). Вредоносное ПО часто использует такие хуки для сокрытия своей активности.
- **Поиск аномальных kprobes**: Ищет отладочные пробы ядра (`kprobes`), которые прикреплены к чувствительным системным функциям, но не принадлежат известным легитимным инструментам.
- **Выявление скрытых BPF-программ**: Обнаруживает BPF-программы, которые "прикреплены" (pinned) вне стандартной директории `bpffs`, что является подозрительным поведением.
