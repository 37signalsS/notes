# Ciphey: Автоматический инструмент дешифрования

> **⚠️ Актуальность:** Ciphey практически не обновляется. Команда разработчиков переключилась на [Ares](https://github.com/bee-san/Ares) — переписанную на Rust версию следующего поколения. Для новых проектов рекомендуется рассмотреть Ares.

## Definitions

**Ciphey** ([github.com/Ciphey/Ciphey](https://github.com/Ciphey/Ciphey)) — полностью автоматизированный инструмент дешифрования, декодирования и взлома, использующий обработку естественного языка (NLP) и искусственный интеллект для автоматического определения и расшифровки зашифрованных или закодированных текстов без необходимости вручную перебирать методы.

## Basic Concepts

### Архитектура: AuSearch + Language Checker

Ciphey использует двухступенчатый подход:

1. **AuSearch (Automated Search)** — AI-движок обнаружения шифра:
   - **Частотный анализ** — для классических шифров (Цезарь, Виженер) анализируется частота символов
   - **Детекция паттернов** — поиск характерных структур (например, `==` в конце Base64)
   - **Оценка энтропии** — высокая энтропия указывает на зашифрованные данные или сжатие
   - **Вероятностные модели** — строит модель для каждого возможного шифра/кодирования

2. **Language Checker** — модуль проверки осмысленности результата:
   - **Словарные проверки** — сравнение с большим словарём
   - **N-граммный анализ** — оценка вероятности последовательностей символов
   - **Статистика естественного языка** — анализ распределения букв, слов, фраз

### Поддерживаемые шифры и кодировки

| Категория | Примеры |
| :--- | :--- |
| **Кодировки** | Base64, Base32, Hex, Binary |
| **Классические шифры** | Caesar, ROT13, Vigenere, Atbash, Substitution |
| **Современные** | XOR, AES (при известном ключе) |
| **Хеши** | MD5, SHA1, SHA256 и др. (поиск исходного текста по известным словарям) |

Полный список — в [документации Ciphey](https://github.com/Ciphey/Ciphey/wiki).

## Practical Scenarios

### Базовое использование

```bash
# Дешифрование текста напрямую
ciphey --text "encrypted_string_here"

# Дешифрование содержимого файла
ciphey --file encrypted_file.txt
```

### CTF-соревнования

Ciphey эффективен для быстрого анализа неизвестных строк в CTF-задачах по криптографии и стеганографии:

```bash
# Пайплайн: извлечение строки → дешифрование
echo "U2VjcmV0IG1lc3NhZ2U=" | ciphey -t -
```

### Анализ артефактов вредоносного ПО

Используется для автоматического распознавания закодированных строк в:

- Логах и дампах трафика
- Конфигурационных файлах малвари
- Obfuscated-скриптах

### Интеграция в пайплайны

Ciphey можно вызывать из скриптов автоматизации благодаря поддержке stdin/stdout и JSON-вывода:

```bash
# JSON-вывод для парсинга
ciphey --text "encoded_data" --json
```

## Additional Information

### Ограничения

- **Не предназначен для стойкой криптографии** — эффективен против классических шифров и кодировок, но не ломает AES-256 без ключа
- **Хеши** — пытается найти исходный текст только если он встречается в словарях (не brute-force)
- **Ложные срабатывания** — возможны на коротких входных данных; Language Checker минимизирует, но не исключает полностью

### Экосистема

- **Ares** ([github.com/bee-san/Ares](https://github.com/bee-san/Ares)) — преемник Ciphey, переписанный на Rust. Значительно быстрее, с улучшенным детектором шифров. Находится в активной разработке.
