# Ciphey: Автоматический инструмент дешифрования

## 1. Определения

**Ciphey** ([github.com/Ciphey/Ciphey](https://github.com/Ciphey/Ciphey)) — это полностью автоматизированный инструмент дешифрования, декодирования и взлома, который использует обработку естественного языка и искусственный интеллект (AI) для автоматического определения и расшифровки зашифрованных текстов.

## 2. Основные концепции

* **Использование AI (AuSearch):** Ciphey включает специально разработанный модуль искусственного интеллекта (AuSearch) с интерфейсом обнаружения шифров. Этот модуль способен приблизительно определить, каким способом был зашифрован или закодирован текст.
* **Проверка языка:** После предварительного определения шифра, настраиваемый интерфейс проверки языка помогает извлечь из приблизительного текста истинный, читаемый текст.
* **Автоматизация:** Инструмент нацелен на полную автоматизацию процесса, избавляя пользователя от необходимости вручную перебирать различные методы дешифрования.
* Подробности можно найти в [документации](https://github.com/Ciphey/Ciphey/wiki).

Ciphey значительно упрощает процесс анализа зашифрованных или закодированных данных, особенно в CTF-соревнованиях или при анализе подозрительных строк.

### Базовое использование

Самый простой способ использования Ciphey — передать ему текст напрямую или из файла.

```bash
# Дешифровать текст напрямую
ciphey --text "encrypted_string_here"

# Дешифровать содержимое файла
ciphey --file encrypted_file.txt
```

### Поддержка различных кодировок и шифров

Ciphey может автоматически распознавать и дешифровать множество форматов, включая (но не ограничиваясь ими):

* Base64, Base32, Hex
* Цезарь (Caesar cipher), ROT13
* Виженер (Vigenere cipher)
* Шифр подстановки (Substitution cipher)
* Атбаш (Atbash)
* Различные виды хешей (MD5, SHA1 и т.д.) - хотя для хешей он будет пытаться найти исходный текст, если хеш известен.

### Интеграция с другими инструментами

Ciphey можно использовать в связке с другими инструментами, например, для анализа трафика, логов или артефактов вредоносного ПО, где встречаются закодированные строки.

## 4. Продвинутые детали

### AuSearch: AI-движок Ciphey

AuSearch (Automated Search) — это сердце Ciphey. Он использует несколько техник для определения типа шифрования или кодирования:

* **Частотный анализ:** Для классических шифров (например, Цезарь, Виженер) анализируется частота появления символов.
* **Детекция паттернов:** Поиск характерных структур, которые указывают на определенные кодировки (например, "==" в конце Base64).
* **Оценка энтропии:** Высокая энтропия может указывать на зашифрованные данные или сжатие.
* **Вероятностные модели:** AuSearch строит вероятностную модель для каждого возможного шифра/кодирования и пытается найти наиболее подходящий.

### Проверка языка

После того как AuSearch предлагает потенциальные методы дешифрования, Ciphey использует модули проверки языка для определения, является ли полученный текст осмысленным. Это включает:

* **Словарные проверки:** Сравнение полученных слов с большим словарем.
* **N-граммный анализ:** Оценка вероятности появления последовательностей символов в данном языке.
* **Статистика естественного языка:** Анализ распределения букв, слов и фраз.

Этот двухступенчатый подход (определение шифра -> проверка языка) позволяет Ciphey эффективно работать с неизвестными входными данными и минимизировать количество ложных срабатываний.
