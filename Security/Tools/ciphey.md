# Ciphey: Автоматизированный инструмент дешифрования и декодирования

## Определение

**Ciphey** ([github.com/Ciphey/Ciphey](https://github.com/Ciphey/Ciphey)) — это интеллектуальный инструмент с открытым исходным кодом, предназначенный для автоматического дешифрования, декодирования и взлома текстовых данных. Он использует методы обработки естественного языка (NLP) и искусственного интеллекта для автоматического определения типа шифра или кодировки, исключая необходимость ручного перебора методов.

Инструмент особенно полезен в ситуациях, когда тип кодирования неизвестен, что типично для CTF-соревнований и первичного анализа вредоносного ПО.

Примечание: На текущий момент (2026 год) проект Ciphey находится в режиме поддержки. Основная разработка команды перенесена на **Ares** — высокопроизводительный аналог на языке Rust.

## Основные концепции

### Архитектура: AuSearch и Language Checker

Ciphey реализует двухфазный процесс анализа входных данных:

1.  **AuSearch (Automated Search):** Движок поиска, основанный на статистических моделях.
    *   **Частотный анализ:** Оценка распределения символов для выявления классических шифров (Цезарь, Виженер).
    *   **Детекция паттернов:** Поиск специфических маркеров (например, суффиксы `==` для Base64 или префиксы `0x` для Hex).
    *   **Энтропийный анализ:** Оценка сложности данных. Высокая энтропия помогает отличить сжатые/зашифрованные данные от обычного текста.
    *   **Вероятностное дерево:** AuSearch строит дерево возможных преобразований и приоритизирует наиболее вероятные ветки.

2.  **Language Checker:** Модуль верификации результата.
    *   **Словарный поиск:** Проверка полученного текста на наличие слов из встроенных баз данных (поддерживается множество языков).
    *   **N-граммный анализ:** Статистическая проверка вероятности последовательностей символов, характерных для естественных языков.
    *   **Heuristic Analysis:** Использование эвристик для подтверждения осмысленности расшифрованного текста.

### Поддерживаемые форматы

| Категория | Поддерживаемые алгоритмы |
| :--- | :--- |
| **Кодировки** | Base64, Base32, Base85, Hex, Binary, Morse Code |
| **Классические шифры** | Caesar, ROT13, Vigenere, Atbash, Affine, Substitution |
| **Современные (базовые)** | XOR (с коротким ключом), ASCII-сдвиги |
| **Хеши (поиск)** | MD5, SHA1, SHA256 (поиск по радужным таблицам и онлайн-базам) |

## Практические сценарии

### Базовый анализ строки

Для запуска анализа достаточно передать строку. Ciphey автоматически применит цепочку декодирования (например, Base64 -> Caesar -> Plaintext):

```bash
ciphey -t "V2hhdCBpcyB0aGlzPyA="
```

### Анализ файлов и автоматизация

Работа с файлами и интеграция в Bash-пайплайны:

```bash
# Анализ содержимого файла
ciphey -f encrypted_payload.txt

# Использование в конвейере с выводом только результата
echo "SGVsbG8gd29ybGQ=" | ciphey --t -q
```

### Применение в кибербезопасности

1.  **CTF (Capture The Flag):** Быстрое решение задач категории Crypto и Stegano, где требуется декодировать многократно обфусцированные строки.
2.  **Malware Analysis:** Автоматическое декодирование команд C2-сервера или конфигураций вредоносного ПО, скрытых с помощью простых преобразований.
3.  **Digital Forensics:** Анализ подозрительных строк в дампах памяти или логах прокси-серверов.

## Дополнительная информация

### Ограничения и точность

-   **Стойкая криптография:** Ciphey не предназначен для взлома современных алгоритмов (AES, RSA) без ключа. Его цель — идентификация и устранение «слабого» кодирования.
-   **Длина данных:** Для корректной работы модуля NLP требуется достаточный объем текста. Очень короткие строки (менее 10-15 символов) могут приводить к ложноположительным результатам.
-   **Производительность:** Из-за использования Python и сложных нейронных сетей Ciphey может быть медленным на больших объемах данных.

### Сравнение с аналогичными инструментами

| Инструмент | Преимущества | Недостатки |
| :--- | :--- | :--- |
| **Ciphey** | Полная автоматизация, поддержка NLP | Медленный, на базе Python |
