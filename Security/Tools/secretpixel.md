# SecretPixel

## 1. Определения

**SecretPixel** ([github.com/x011/SecretPixel](https://github.com/x011/SecretPixel)) — это инструмент для скрытия файлов внутри изображений с использованием стеганографии.

## 2. Основные концепции

Инструмент использует метод **LSB (Least Significant Bit)**, но с важным дополнением — **начальным значением (seed)** для псевдослучайного распределения.

- **Процесс:**
    1.  **Сжатие и шифрование**: Скрываемый файл сжимается (zlib) и шифруется (AES-256).
    2.  **Генерация позиций**: Генератор псевдослучайных чисел с заданным `seed` создает последовательность позиций пикселей в изображении.
    3.  **Внедрение LSB**: Биты зашифрованного файла записываются в наименее значимые биты (LSB) цветовых каналов (RGB) пикселей в псевдослучайном порядке.

Использование `seed` значительно усложняет обнаружение скрытых данных статистическими методами.

- **Шифрование:**
    - **Данные:** AES-256.
    - **Ключ AES:** Шифруется с помощью RSA.

## 3. Практические сценарии

- **Платформы:** Кроссплатформенный (Python).
- **Форматы изображений:** PNG, BMP, TGA, TIFF (форматы без потерь).

## 4. Продвинутые детали

### Усовершенствования метода LSB
Использование `seed` для генерации псевдослучайного распределения позиций пикселей является значительным улучшением по сравнению с простым последовательным внедрением LSB. Это усложняет обнаружение скрытых данных, так как статистический анализ, ищущий изменения в младших битах по порядку, будет менее эффективен. Однако, если злоумышленник знает `seed` или может его подобрать, это преимущество теряется.

### Обнаружение стеганографии (Стеганализ)
Несмотря на усовершенствования, стеганография на основе LSB (даже с `seed`) все еще подвержена обнаружению с помощью методов стеганализа:
- **Статистические атаки:** Существуют специализированные статистические алгоритмы (например, RS-анализ, гистограммный анализ), которые могут выявить аномалии в распределении цветов/яркости, вызванные заменой LSB, даже если биты распределены псевдослучайно.
- **Анализ шума:** Внедрение скрытых данных увеличивает "шум" в изображении. Специализированные алгоритмы могут обнаруживать эту повышенную энтропию.
- **Машинное обучение:** Современные методы стеганализа используют машинное обучение для тренировки моделей на больших наборах данных, содержащих как обычные, так и стеганографические изображения, для выявления скрытых паттернов.

Важно понимать, что ни один метод стеганографии не является абсолютно неуязвимым для обнаружения, особенно если злоумышленник располагает достаточными вычислительными ресурсами и знаниями.
