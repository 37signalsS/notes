# SecretPixel — стеганография зашифрованных данных в изображениях

## 1. Определения

**SecretPixel** ([github.com/x011/SecretPixel](https://github.com/x011/SecretPixel)) — это консольный инструмент на Python для скрытого хранения файлов внутри изображений. В отличие от базовых утилит стеганографии, SecretPixel комбинирует многослойное шифрование (RSA + AES-256) с псевдослучайным распределением данных, что значительно усложняет обнаружение и несанкционированное извлечение информации.

## 2. Основные концепции

### Алгоритм внедрения (Seeded LSB)
Инструмент использует метод **LSB (Least Significant Bit — наименее значимый бит)**, но с критически важным дополнением:
- **Псевдослучайное распределение:** Вместо последовательной записи битов в пиксели (что легко обнаруживается инструментами типа `zsteg`), SecretPixel использует генератор псевдослучайных чисел с **начальным значением (seed)**.
- **Маскировка:** Биты распределяются по нелинейной траектории, что делает изменения в младших битах статистически похожими на естественный шум сенсора камеры или артефакты оцифровки.

### Цепочка обработки данных
1.  **Сжатие:** Исходный файл сжимается с помощью `zlib` для уменьшения объема внедряемых данных.
2.  **Шифрование данных:** Генерируется случайный сессионный ключ AES-256, которым шифруется сжатый файл.
3.  **Шифрование ключа:** Сессионный ключ AES шифруется с помощью **RSA-4096** (публичного ключа получателя). Это гарантирует, что извлечь данные сможет только владелец приватного ключа.
4.  **Внедрение:** Зашифрованный пакет записывается в LSB цветовых каналов (RGB) пикселей, выбранных согласно `seed`.

### Поддерживаемые контейнеры
Поддерживаются только форматы без потерь (lossless), так как сжатие с потерями (JPEG) уничтожает данные в младших битах:
- **PNG**, **BMP**, **TGA**, **TIFF**.

## 3. Практические сценарии

### Установка
Для работы требуется Python 3.7+ и библиотека `Pillow`.

```bash
git clone https://github.com/x011/SecretPixel.git
cd SecretPixel
pip install -r requirements.txt
```

### Генерация ключей RSA
Перед использованием необходимо создать пару ключей (публичный для отправителя, приватный для получателя).

```bash
python gen_keys.py
# Будут созданы файлы public.pem и private.pem
```

### Скрытие файла (Hide)
Для внедрения данных требуется изображение-контейнер, файл с секретом и публичный ключ.

```bash
python secretpixel.py hide \
  -i original_image.png \
  -f secret_document.pdf \
  -p public.pem \
  -o stego_result.png
```
- `-i`: Исходное изображение.
- `-f`: Файл, который нужно скрыть.
- `-p`: Публичный ключ RSA.
- `-o`: Итоговое изображение со скрытыми данными.

### Извлечение файла (Unhide)
Для извлечения требуется изображение с данными и приватный ключ.

```bash
python secretpixel.py unhide \
  -i stego_result.png \
  -k private.pem
```
- `-i`: Изображение с внедренными данными.
- `-k`: Приватный ключ RSA.

## 4. Дополнительная информация

### Устойчивость к стеганализу
SecretPixel спроектирован для противодействия автоматизированным методам анализа:
- **Визуальные атаки:** Изменения в 1-2 битах LSB незаметны для человеческого глаза даже при сильном увеличении.
- **Статистический анализ:** Благодаря шифрованию AES, внедренные данные имеют высокую энтропию и выглядят как случайный шум. Псевдослучайное распределение (seed) делает неэффективным стандартный RS-анализ, который ищет закономерности в последовательных пикселях.

### Ограничения и риски
- **Вместимость:** Объем скрываемого файла ограничен разрешением изображения (количеством доступных пикселей).
- **Чувствительность к обработке:** Любое изменение изображения-результата (изменение размера, обрезка, повторное сохранение в JPEG) приведет к необратимой порче скрытых данных.
- **Целостность:** Инструмент не имеет встроенных механизмов коррекции ошибок; повреждение даже нескольких ключевых битов может сделать расшифровку AES невозможной.

### Сравнение методов
| Характеристика | Стандартный LSB | SecretPixel |
| :--- | :--- | :--- |
| **Порядок внедрения** | Последовательный | Псевдослучайный (Seeded) |
| **Шифрование** | Отсутствует / Симметричное | Асимметричное (RSA + AES) |
| **Сжатие** | Нет | zlib |
| **Обнаружение утилитой `zsteg`** | Легко | Затруднено |
