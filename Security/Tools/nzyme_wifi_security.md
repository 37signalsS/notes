# nzyme: Wi-Fi Security Monitoring System

## Definitions

**nzyme** — открытая система мониторинга и защиты беспроводных сетей (Wireless Intrusion Detection System, WIDS). Использует Wi-Fi-адаптеры в режиме мониторинга для обнаружения подозрительной активности, атак и неавторизованных точек доступа. Проект: [nzyme.org](https://www.nzyme.org/), исходный код: [github.com/nzymedefense/nzyme](https://github.com/nzymedefense/nzyme), документация: [docs.nzyme.org](https://www.nzyme.org/docs/intro/). Последняя стабильная версия: v2.0.0-alpha.16 (апрель 2025).

## Basic Concepts

Nzyme захватывает беспроводные кадры (802.11) через Wi-Fi-адаптеры в режиме мониторинга. Каждый кадр анализируется на предмет угроз; при обнаружении генерируется оповещение, сопутствующая информация записывается для последующего анализа.

**Обнаружение угроз:** сканирование эфира для выявления атак — мошеннические точки доступа (Rogue AP), деаутентификация клиентов и иные векторы атак на Wi-Fi.

**Физическое обнаружение:** отслеживание уровня сигнала (RSSI) от атакующих устройств для их физической локализации.

**Интеграция с Graylog:** отправка данных и событий в Graylog для долгосрочного хранения, анализа и форензики.

**Гибкая система оповещений:** предупреждения на основе сигнатурного анализа, обнаружения аномалий и honeypot-ловушек.

**Соответствие стандартам:** поддержка выполнения требований PCI-DSS, CIS, NIST, ISO/IEC 27001.

## Practical Scenarios

### Attack Detection

**Deauthentication/Disassociation Flood:** массовая отправка кадров деаутентификации для отключения клиентов от легитимной точки доступа. Nzyme обнаруживает аномальное количество таких кадров.

**Rogue Access Point:** обнаружение точек доступа, отсутствующих в списке доверенных.

**Evil Twin:** идентификация точки доступа, имитирующей легитимную сеть (идентичный SSID, иной BSSID или характеристики).

**SSID Spam:** выявление попыток создания большого количества фейковых SSID в эфире.

### Attacker Device Identification

Nzyme содержит базу сигнатур для распознавания хакерского оборудования: WiFi Pineapple, Pwnagotchi, Flipper Zero, O.MG Cable.

## Additional Information

### Physical Localization

Nzyme отслеживает мощность сигнала (RSSI) от любого Wi-Fi-устройства. Анализ изменения RSSI при перемещении сенсора (тапа) позволяет определить примерное физическое местоположение целевого устройства. Критически важно для нейтрализации неавторизованных точек доступа и вредоносных устройств.

### Integrations and Alerts

События и оповещения отправляются во внешние системы для анализа и реагирования:

- **Graylog / SIEM:** централизованное хранение, корреляция и анализ логов.
- **Prometheus:** интеграция в систему мониторинга.
- **SMTP:** отправка оповещений по электронной почте.
- **Пользовательские скрипты:** вызов собственных скриптов в ответ на события.
