# nzyme: Система мониторинга безопасности Wi-Fi

## Определения

**nzyme** — открытая распределенная система мониторинга и защиты беспроводных сетей (Wireless Intrusion Detection System, WIDS). Инструмент предназначен для обнаружения атак на уровне 802.11, выявления неавторизованных точек доступа и физической локализации злоумышленников. В версии v2 проект перешел на модульную архитектуру и использование реляционных баз данных для хранения состояния.

Официальные ресурсы:

*   Документация: [docs.nzyme.org](https://www.nzyme.org/docs/intro/)
*   GitHub: [github.com/nzymedefense/nzyme](https://github.com/nzymedefense/nzyme)

## Основные концепции

### Архитектура (v2+)

Система разделена на два основных компонента, что позволяет масштабировать мониторинг на большие территории:

1.  **nzyme-core (Сервер):** Центральный узел, отвечающий за обработку данных, анализ угроз, управление оповещениями и предоставление веб-интерфейса. Требует Java 17+ и PostgreSQL в качестве основного хранилища.
2.  **nzyme-tap (Сенсор):** Легковесный агент, устанавливаемый на устройства с Wi-Fi-адаптерами (например, Raspberry Pi). Переводит адаптер в режим мониторинга (monitor mode), захватывает кадры 802.11 и передает их в Core по зашифрованному каналу.

### Механизмы обнаружения

*   **Сигнатурный анализ:** Сравнение характеристик кадров с известными паттернами атак и инструментов (WiFi Pineapple, Flipper Zero).
*   **Контроль окружения:** Сопоставление обнаруженных сетей со списком разрешенных SSID и BSSID. Любое отклонение (изменение канала, мощности или флагов безопасности) вызывает тревогу.
*   **Обнаружение аномалий:** Анализ поведения клиентов и точек доступа, выявление необычных всплесков трафика управления (management frames).

### Требования к оборудованию

Для работы сенсоров необходимы адаптеры с поддержкой режима мониторинга и захвата кадров (monitor mode & packet injection). Популярные чипсеты: Atheros AR9271, Ralink RT3070, Realtek RTL8812AU.

## Практические сценарии

### Обнаружение атак на доступность и целостность

*   **Deauthentication/Disassociation Flood:** Выявление атак, направленных на принудительное отключение клиентов. Nzyme фиксирует всплески кадров деаутентификации, которые часто предшествуют созданию Evil Twin.
*   **PMKID Timeout/Attack:** Обнаружение попыток перехвата хешей PMKID, используемых для взлома паролей WPA/WPA2 без участия клиента.
*   **Beacon Flooding:** Фильтрация и обнаружение сотен поддельных SSID, генерируемых инструментами типа mdk4 для перегрузки списков сетей у пользователей.

### Борьба с неавторизованными устройствами

*   **Rogue Access Point:** Идентификация точек доступа, подключенных к корпоративной проводной сети без разрешения.
*   **Evil Twin / Karma Attack:** Обнаружение фальшивых точек доступа с легитимными SSID, но отличающимися параметрами (например, отсутствие поддержки специфических расширений 802.11 или другой BSSID).
*   **Идентификация инструментов:** Автоматическое распознавание специфических отпечатков (fingerprints) хакерских устройств, таких как Pwnagotchi или O.MG Cable.

## Дополнительная информация

### Физическая локализация (RSSI Tracking)

Nzyme агрегирует данные об уровне сигнала (RSSI) от различных сенсоров (taps).
*   **Триангуляция:** При наличии трех и более сенсоров система может вычислить примерные координаты источника сигнала на плане помещения.
*   **Поиск "на ощупь":** Использование мобильного сенсора для отслеживания изменения RSSI в реальном времени, что позволяет оператору физически подойти к атакующему устройству.

### Интеграции и оповещения

Nzyme v2 значительно расширил возможности взаимодействия с внешними системами:
*   **PostgreSQL:** Прямой доступ к данным для построения аналитики (например, через Grafana).
*   **Graylog / SIEM:** Отправка структурированных логов через GELF для долгосрочного хранения и корреляции с событиями на хостах.
*   **Webhooks:** Возможность вызова внешних API при срабатывании определенных правил.
*   **Prometheus:** Экспорт метрик о состоянии сенсоров и количестве обнаруженных угроз.
