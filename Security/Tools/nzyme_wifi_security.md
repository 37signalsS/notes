# nzyme: Система защиты Wi-Fi

## 1. Определения

**nzyme** ([nzyme.org](https://www.nzyme.org/)) — это открытая система для мониторинга и защиты беспроводных сетей (Wireless Intrusion Detection System, WIDS). Она использует Wi-Fi адаптеры в режиме мониторинга для обнаружения подозрительной активности, атак и неавторизованных точек доступа.

- **GitHub:** [github.com/nzymedefense/nzyme](https://github.com/nzymedefense/nzyme)
- **Документация:** [docs.nzyme.org](https://www.nzyme.org/docs/intro/)

## 2. Основные концепции

Nzyme захватывает беспроводные кадры (802.11) с помощью стандартных Wi-Fi адаптеров, работающих в режиме мониторинга. Каждый кадр анализируется на предмет угроз. В случае обнаружения подозрительной активности генерируется оповещение, а вся сопутствующая информация записывается для последующего анализа.

- **Обнаружение угроз:** Nzyme сканирует эфир для выявления атак, таких как создание мошеннических точек доступа (Rogue AP), деаутентификация клиентов и другие известные векторы атак на Wi-Fi.
- **Физическое обнаружение:** Система позволяет отслеживать уровень сигнала от атакующих устройств, что помогает в их физической локализации.
- **Интеграция с Graylog:** Все собранные данные и события могут быть отправлены в систему управления логами Graylog для долгосрочного хранения, анализа и проведения расследований (форензики).
- **Гибкая система оповещений:** Поддерживает несколько типов предупреждений, основанных на сигнатурном анализе, обнаружении аномалий или использовании "ловушек" (honeypots).
- **Соответствие стандартам:** Помогает в выполнении требований стандартов безопасности, таких как PCI-DSS, CIS, NIST и ISO/IEC 27001.

## 3. Практические сценарии

Nzyme обнаруживает широкий спектр угроз в беспроводных сетях.

### Обнаружение атак

- **Deauthentication/Disassociation Flood**: Массовая отправка кадров деаутентификации для отключения клиентов от легитимной точки доступа. Nzyme обнаруживает аномальное количество таких кадров.
- **Rogue Access Point (Вредоносная точка доступа)**: Обнаружение точек доступа, которые не входят в список доверенных.
- **"Evil Twin" (Злой двойник)**: Идентификация точки доступа, которая имитирует легитимную сеть (тот же SSID), но имеет другой BSSID или характеристики.
- **SSID Spam**: Обнаружение попыток "замусорить" эфир большим количеством фейковых SSID.

### Идентификация атакующих устройств

Nzyme имеет базу сигнатур для распознавания популярного хакерского оборудования, такого как:

- WiFi Pineapple
- Pwnagotchi
- Flipper Zero
- O.MG Cable

## 4. Продвинутые детали

### Физическая локализация

Nzyme может отслеживать мощность сигнала (RSSI) от любого Wi-Fi устройства. Анализируя изменение мощности сигнала при перемещении сенсора (тапа) nzyme, можно определить примерное физическое местоположение искомого устройства. Это критически важно для нейтрализации неавторизованных точек доступа или других вредоносных устройств.

### Интеграция и оповещения

Все события и оповещения могут быть отправлены во внешние системы для дальнейшего анализа и реагирования:

- **Graylog / SIEM**: Для централизованного хранения, корреляции и анализа логов.
- **Prometheus**: Для интеграции в систему мониторинга.
- **SMTP**: Для отправки оповещений по электронной почте.
- **Пользовательские скрипты**: Возможность вызывать собственные скрипты в ответ на определенные события.
