# what (pyWhat): Идентификация и анализ данных

## Определения

**what** (также известный как **pyWhat**, [github.com/bee-san/pyWhat](https://github.com/bee-san/pyWhat)) — инструмент командной строки для автоматической идентификации типов данных, форматов файлов и чувствительной информации. Он анализирует переданные строки или файлы, сопоставляя их с обширной базой паттернов, включая идентификаторы облачных провайдеров, хеши, ключи API и артефакты криминалистического анализа.

## Основные концепции

### Механизмы идентификации

Инструмент использует многоуровневый подход к анализу:

1.  **Регулярные выражения (Regex):** Основной движок, содержащий тысячи паттернов для распознавания структурированных строк (email, IP, UUID, криптокошельки).
2.  **Магические числа (Magic Numbers):** Анализ первых байтов файлов для определения их формата, даже если расширение отсутствует или изменено.
3.  **Энтропийный анализ:** Оценка степени хаотичности данных для выявления зашифрованных блоков или сжатых архивов.
4.  **Контекстная эвристика:** Проверка взаимосвязей между найденными элементами для повышения точности (например, подтверждение типа ключа по его длине и характерному префиксу).

### Отличия от утилиты file

В отличие от стандартной Unix-утилиты `file`, которая фокусируется преимущественно на типах файлов (ELF, JPEG, ASCII), `pyWhat` предназначен для извлечения смысла из содержимого:
- Находит API-ключи внутри текстовых файлов.
- Идентифицирует конкретные типы хешей (SHA-256 vs Bitcoin address).
- Распознает токены облачных платформ (AWS Access Key ID).

## Практические сценарии

### Анализ строк и секретов

Быстрая идентификация типа данных без ручного поиска по документации:

```bash
# Идентификация хеша
what "f7e5f0edfbe920f2f0e5f3e3eeebfcede8ea0a"

# Идентификация AWS ключа
what "AKIAIOSFODNN7EXAMPLE"
```

### Рекурсивный аудит директорий

Поиск чувствительной информации в исходном коде или логах:

```bash
# Рекурсивный поиск во всех файлах текущей папки
what -r .
```

### Анализ сетевых дампов и бинарных файлов

Инструмент поддерживает разбор специфических форматов:

```bash
# Анализ pcap-файла на наличие артефактов
what traffic.pcap
```

## Дополнительная информация

### Применение в DevOps и SRE

1.  **Предотвращение утечек (Secrets Detection):** Интеграция в CI/CD пайплайны для проверки коммитов на наличие жестко заданных API-ключей AWS, GCP, Azure или Slack-токенов.
2.  **Триаж инцидентов:** Быстрый анализ подозрительных строк в логах или дампов памяти при расследовании компрометации.
3.  **Инвентаризация:** Идентификация используемых форматов данных в легаси-системах.

### Интеграция с другими инструментами

- **[Ciphey](./ciphey.md):** `pyWhat` часто используется в паре с Ciphey. Если Ciphey отвечает за автоматическое декодирование и дешифрование, то `pyWhat` помогает определить, что именно было получено на выходе.
- **[Capa](./capa.md):** Для анализа исполняемых файлов (бинарный анализ), в то время как `pyWhat` эффективнее для анализа строк и данных внутри этих файлов.

### Ограничения

- **Ложноположительные срабатывания:** Из-за использования Regex инструмент может ошибочно идентифицировать случайные строки как ключи или хеши.
- **Отсутствие валидации:** `pyWhat` сообщает, что строка *похожа* на API-ключ, но не проверяет его валидность (для этого требуются специализированные инструменты вроде `trufflehog`).
