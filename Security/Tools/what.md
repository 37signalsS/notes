# what (pyWhat): Инструмент для идентификации данных

## 1. Определения

**what** (также известный как `pyWhat`, [github.com/bee-san/pyWhat](https://github.com/bee-san/pyWhat)) — это утилита командной строки, предназначенная для автоматического определения типа и содержания предоставленных данных.

## 2. Основные концепции

* **Автоматическое определение:** Основная задача `what` — определить, "что есть что". Он способен анализировать как текстовые строки, так и файлы.
* **Идентификация различных типов данных:** `what` может легко идентифицировать:
  * Электронные письма
  * IP-адреса
  * Различные форматы данных (например, шестнадцатеричные строки)
  * Содержимое файлов (например, `.pcap` файлы)

## 3. Практические сценарии

Пример использования для анализа строки:

```bash
what "f7e5f0edfbe920f2f0e5f3e3eeebfcede8ea0a"
```

Инструмент проанализирует строку и сообщит, что она собой представляет.

Для использования достаточно передать `what` текст или путь к файлу.

## 4. Продвинутые детали

### Механизмы работы

`pyWhat` использует комбинацию регулярных выражений, анализа энтропии, эвристических правил и, возможно, встроенных баз данных для распознавания различных типов данных.

* **Регулярные выражения (Regex):** Основной метод для идентификации структурированных данных, таких как email-адреса, IP-адреса, UUID, URL и т.д.
* **Энтропийный анализ:** Используется для оценки случайности данных. Высокая энтропия может указывать на зашифрованные, сжатые или закодированные данные (например, Base64).
* **Эвристика:** Набор правил, основанных на знании типичных форматов и структур данных, например, определенных магических чисел для файлов или характерных последовательностей для определенных типов токенов.

### Применение в безопасности и форензике

`pyWhat` может быть крайне полезен в задачах кибербезопасности и цифровой форензики:

* **Быстрый анализ дампов памяти или файлов логов:** Помогает быстро выявить чувствительную информацию или интересные паттерны.
* **Идентификация закодированных или зашифрованных данных:** Может подсказать тип кодирования или наличие шифрованных блоков, что является первым шагом в их дальнейшем анализе.
* **Поиск IOC (Indicators of Compromise):** Автоматически выявлять IP-адреса, доменные имена или хеши файлов, связанные с известными угрозами.
* **CTF-соревнования:** Быстро определить тип задачи или кодировки.
