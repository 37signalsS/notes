# Lynis

## 1. Определения

**Lynis** ([CISOfy/lynis](https://github.com/CISOfy/lynis)) — это инструмент для проверки безопасности и соответствия стандартам в Linux-системах. Он выполняет сотни тестов для выявления уязвимостей и проблем конфигурации.

- **Сайт:** https://cisofy.com/lynis/

## 2. Основные концепции

Lynis проводит аудит системы по множеству категорий для предоставления комплексной оценки безопасности.

#### Что проверяет:
*   Настройки ядра и системные параметры
*   Права доступа и аутентификация
*   Конфигурации сетевых служб
*   Наличие обновлений безопасности
*   Соответствие стандартам CIS, NIST, HIPAA
*   Логирование и мониторинг

#### Анализ результатов:

После запуска Lynis предоставляет:
*   Оценку безопасности (hardening index) от 0 до 100.
*   Предупреждения (warnings) — критичные проблемы.
*   Советы (suggestions) — рекомендации по улучшению.
*   Обнаруженное ПО — установленные пакеты и версии.

## 3. Практические сценарии

#### Основное использование:

*   **Базовый аудит:**
    ```bash
    # Запуск с правами root
    sudo lynis audit system
    ```

*   **Проверка конкретной группы тестов:**
    ```bash
    # Проверка раздела SSH
    sudo lynis audit system --tests-from-group ssh
    ```

*   **Расширенная проверка:**
    ```bash
    # Детальный отчёт с сохранением результатов
    sudo lynis audit system --quick --nocolors --report-file /tmp/lynis-report.txt
    ```

*   **Проверка на соответствие стандарту:**
    ```bash
    # Проверка на соответствие стандарту CIS
    sudo lynis audit system --profile cis
    ```

## 4. Продвинутые детали

### Автоматизация с помощью Cron
Lynis можно запускать по расписанию для регулярного аудита. При запуске через `cron` рекомендуется использовать опцию `--cronjob`. Она включает тихий режим (`-Q` или `--quick`) и проверку всех категорий (`-c`), а также форматирует вывод без специальных символов.

**Пример записи в crontab для ежедневного сканирования:**
```bash
# Запускать аудит каждый день в 22:30
30 22 * * * /path/to/lynis --cronjob audit system > /var/log/lynis-scan.log
```

### Пользовательские профили
Вместо того чтобы передавать множество параметров при каждом запуске, можно определить их в файле профиля (`.prf`). Это позволяет создавать шаблоны для разных типов систем (например, веб-сервер, сервер БД).

1.  Скопируйте `default.prf` в `my-custom.prf`.
2.  Внесите изменения в `my-custom.prf`.
3.  Запустите Lynis с вашим профилем:
    ```bash
    lynis audit system --profile my-custom.prf
    ```

### Просмотр всех доступных тестов
Команда `show tests` выведет список всех идентификаторов тестов, которые можно использовать для выборочной проверки.
```bash
lynis show tests
```
