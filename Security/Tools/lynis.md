# Lynis: Аудит безопасности и харденинг Linux

## Определения

**Lynis** ([CISOfy/lynis](https://github.com/CISOfy/lynis)) — это проверенный временем инструмент с открытым исходным кодом для аудита безопасности, тестирования на соответствие стандартам (compliance) и укрепления защиты (hardening) систем на базе Unix/Linux. 

В отличие от сканеров уязвимостей, которые ищут известные CVE во внешних портах, Lynis выполняет глубокое сканирование «изнутри» хоста, анализируя конфигурации системы, настройки ядра, права доступа и установленное ПО.

## Основные концепции

### Области аудита

Lynis проводит модульное тестирование системы, охватывая следующие уровни:
- **Системные параметры:** Загрузчик (GRUB), параметры ядра (sysctl), наличие обновлений безопасности.
- **Аутентификация:** Политики паролей, права на домашние директории, настройки PAM.
- **Сеть:** Конфигурация файрвола (iptables/nftables), настройки SSH, DNS-резолвинг.
- **Хранение данных:** Монтирование файловых систем (noexec, nosuid), квоты, зашифрованные разделы.
- **Логирование:** Конфигурация syslog/journald, аудит через auditd.
- **Контейнеризация:** Обнаружение Docker, Kubernetes и базовый аудит их конфигураций на хосте.

### Механизм анализа и отчетность

По завершении сканирования Lynis генерирует три типа данных:
1. **Hardening Index:** Числовой показатель (0–100), отражающий общий уровень защищенности системы.
2. **Warnings (Предупреждения):** Критические проблемы, требующие немедленного устранения (например, незащищенный доступ к root).
3. **Suggestions (Рекомендации):** Советы по улучшению конфигурации, которые повышают Hardening Index.

Результаты сохраняются в лог-файл (`lynis.log`) и файл отчета (`lynis-report.dat`), который можно использовать для интеграции с внешними системами мониторинга.

## Практические сценарии

### Полный аудит системы

Стандартный запуск для получения общего отчета о состоянии хоста:

```bash
sudo lynis audit system
```

### Аудит конкретных компонентов

Для экономии времени или проверки после внесения изменений можно запускать группы тестов:

```bash
# Проверка только настроек SSH
sudo lynis audit system --tests-from-group ssh

# Проверка файловой системы и разделов монтирования
sudo lynis audit system --tests-from-group storage
```

### Использование профилей для соответствия стандартам

Lynis поддерживает профили (`.prf`), позволяющие автоматизировать проверку на соответствие стандартам (например, CIS):

```bash
# Запуск с профилем CIS (если установлен соответствующий плагин/профиль)
sudo lynis audit system --profile cis.prf
```

### Интеграция в CI/CD и автоматизация

Для регулярного мониторинга Lynis запускается через планировщик с параметрами для автоматизации:

```bash
# --cronjob: тихий режим, отсутствие цветового форматирования в выводе
30 02 * * * /usr/local/bin/lynis audit system --cronjob > /var/log/lynis_daily.log
```

## Дополнительная информация

### Расширение функционала (Плагины)

Lynis поддерживает систему плагинов, которые позволяют проводить специфические тесты:
- **Плагины для БД:** Проверка MySQL/PostgreSQL на наличие небезопасных настроек.
- **Плагины для веба:** Аудит конфигураций Apache/Nginx.
- **Собственные плагины:** Возможность написания кастомных проверок на языке shell script.

### Интеграция с централизованными системами

Данные из `lynis-report.dat` могут быть преобразованы в JSON или отправлены напрямую в SIEM:
- **ELK/OpenSearch:** Парсинг отчетов для построения дашбордов безопасности.
- **Wazuh:** Интеграция Lynis как внешнего источника данных для SCA (Security Configuration Assessment).
