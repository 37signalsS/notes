# traitor

## 1. Определения

**traitor** ([liamg/traitor](https://github.com/liamg/traitor)) — это инструмент, написанный на Go, для автоматического поиска и использования известных уязвимостей с целью повышения привилегий в ОС Linux.

## 2. Основные концепции

`traitor` сканирует систему на наличие уязвимых мест и автоматически пытается их эксплуатировать для получения root-доступа.

### Векторы атак:
*   Большинство техник из **GTFOBins** (использование системных утилит с SUID-битом).
*   Записываемый сокет Docker (`docker.sock`).
*   Известные уязвимости ядра и системных служб, включая:
    *   **CVE-2022-0847 (Dirty Pipe)**
    *   **CVE-2021-4034 (PwnKit)**

## 3. Практические сценарии

`traitor` — это инструмент для пентестеров и специалистов по безопасности, который позволяет быстро проверить систему на наличие очевидных векторов повышения привилегий.

### Только поиск уязвимостей
Запуск без параметров сканирует систему и выводит список найденных уязвимостей, но не пытается их эксплуатировать.
```bash
traitor
```

### Поиск и автоматическая эксплуатация
Флаг `-a` (или `--any`) заставляет `traitor` искать все уязвимости и последовательно пытаться эксплуатировать каждую из них до получения root-доступа.
```bash
traitor -a
```

### Эксплуатация конкретной уязвимости
Можно указать `traitor` попытаться использовать только один конкретный эксплойт.
```bash
# Попытка эксплуатации уязвимости "Dirty Pipe"
traitor -e cve:CVE-2022-0847

# Попытка эксплуатации через сокет Docker
traitor -e docker:writable-socket
```

## 4. Продвинутые детали

### Ограничения
`traitor` не является заменой для ручного анализа. Он ищет только самые известные и легко автоматизируемые уязвимости. Сложные, многоступенчатые или специфичные для окружения векторы атак требуют ручного исследования.

### Интерактивный режим
Инструмент работает в интерактивном режиме. В случае успешной эксплуатации он предоставляет пользователю корневую оболочку (`root shell`) прямо в текущем терминале.
