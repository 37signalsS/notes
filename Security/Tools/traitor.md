# Traitor: Автоматизация повышения привилегий в Linux

## Определения

**Traitor** ([github.com/liamg/traitor](https://github.com/liamg/traitor)) — это высокопроизводительный инструмент с открытым исходным кодом, написанный на языке Go, предназначенный для автоматического поиска и эксплуатации уязвимостей с целью получения прав суперпользователя (root) в операционных системах Linux.

Инструмент автоматизирует процесс, который обычно выполняется вручную пентестерами, объединяя в себе сканер конфигураций, проверку прав доступа и набор встроенных эксплойтов. Основная ценность Traitor заключается в его автономности: он скомпилирован в статически связанный бинарный файл, который не требует внешних зависимостей или библиотек на целевой системе.

## Основные концепции

### Механизм работы

Traitor функционирует как «активный» сканер. Он не просто сообщает о наличии потенциальной проблемы, но и предоставляет механизмы для её немедленного использования. Внутренняя логика включает:
1.  **Анализ метаданных:** Проверка версий ядра и системных служб.
2.  **Аудит разрешений:** Поиск файлов с SUID/SGID битами, анализ конфигураций `sudoers` и возможностей Linux (Capabilities).
3.  **Встроенные модули эксплуатации:** Реализация известных CVE и техник GTFOBins непосредственно в коде инструмента.

### Векторы атак и модули эксплуатации

Traitor включает модули для эксплуатации следующих критических уязвимостей и конфигурационных ошибок:

#### 1. Уязвимости ядра (Kernel CVEs)
*   **CVE-2022-0847 (Dirty Pipe):** Позволяет перезаписывать данные в файлах, доступных только для чтения (например, внедрение нового пользователя в `/etc/passwd`), путем манипуляции с кэшем страниц через неинициализированные флаги в пайпах.
*   **CVE-2021-4034 (PwnKit):** Уязвимость повреждения памяти в `pkexec` (Polkit), позволяющая любому непривилегированному пользователю получить root-права независимо от архитектуры.
*   **CVE-2021-3560:** Ошибка логики в Polkit, позволяющая отправлять команды через D-Bus для создания нового администратора, обходя авторизацию.

#### 2. Техники GTFOBins
Инструмент автоматически распознает бинарные файлы, которые могут быть использованы для «побега» из ограниченной оболочки:
*   **SUID-бинарники:** Использование утилит типа `find`, `vim`, `nano`, `bash`, если у них установлен бит смены владельца на root.
*   **sudo-права:** Автоматический запуск разрешенных команд без пароля, которые ведут к получению shell.

#### 3. Контейнеризация и Docker
*   **Writable Docker Socket:** Если пользователь имеет доступ на запись в `/var/run/docker.sock`, Traitor может запустить привилегированный контейнер, примонтировать к нему `/` хоста и изменить `/etc/shadow` или добавить SSH-ключ для root.

## Практические сценарии

### Системный аудит (Enumeration)

Запуск без флагов выполняет поиск всех векторов повышения привилегий без попытки их использования. Это безопасно для «живых» систем.

```bash
# Запуск сканирования
./traitor
```
Результаты классифицируются по степени уверенности (Confidence): `Low`, `Medium`, `High`.

### Полная автоматическая эксплуатация

Флаг `--any` (или `-a`) заставляет инструмент перебирать все найденные уязвимости и последовательно пытаться получить root-оболочку.

```bash
# Автоматический взлом до первого успеха
./traitor -a
```

### Таргетированная эксплуатация конкретной уязвимости

Если вы заранее знаете наиболее вероятный вектор, можно указать конкретный модуль:

```bash
# Эксплуатация Dirty Pipe для модификации системных файлов
./traitor --exploit cve:CVE-2022-0847

# Эксплуатация PwnKit (Polkit)
./traitor --exploit cve:CVE-2021-4034

# Использование уязвимого сокета Docker
./traitor --exploit docker:writable-socket
```

## Продвинутые детали

### Интерактивный режим и Root Shell

В случае успешной эксплуатации Traitor автоматически перехватывает ввод-вывод и предоставляет полноценную интерактивную оболочку `root shell` прямо в текущем терминале. Это исключает необходимость настройки дополнительных reverse shell соединений.

### Сравнение с аналогичными инструментами

| Характеристика | Traitor | LinPEAS (PEASS-ng) | BeRoot |
| :--- | :--- | :--- | :--- |
| **Природа** | Активный эксплойтер | Пассивный сканер | Пассивный сканер |
| **Зависимости** | Нет (Static Go Binary) | Shell / Python | Python |
| **База CVE** | Фокус на High-Impact | Максимально широкая | Общие мисконфиги |
| **Автоматизация** | Встроена (Exploit) | Требует ручной работы | Требует ручной работы |

### Ограничения (2025–2026)

*   **Актуальность CVE:** Оригинальный Traitor не включает новейшие уязвимости 2024–2026 годов (например, CVE-2024-1086 в Netfilter). В таких случаях рекомендуется использовать его как «быстрый фильтр» для старых систем.
*   **Сложные цепочки:** Инструмент не умеет строить многошаговые цепочки атак, требующие взаимодействия нескольких утилит.
*   **Детекция:** Попытки эксплуатации (особенно Kernel CVE) могут быть зафиксированы системами EDR или вызвать нестабильность ядра (Kernel Panic).
