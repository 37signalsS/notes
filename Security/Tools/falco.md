# Falco: Мониторинг безопасности во время выполнения (Runtime Security)

## 1. Определения

**Falco** (https://falco.org/) — это open-source решение для мониторинга безопасности во время выполнения задач на хостах, контейнерах, Kubernetes и в облачных средах. Falco отслеживает поведение процессов на уровне ядра Linux, позволяя выявлять подозрительную активность в контейнерах и кластерах Kubernetes в реальном времени.

Это решение поддерживается Cloud Native Computing Foundation (CNCF) и является де-факто стандартом для обнаружения угроз безопасности во время выполнения в облачных средах.

## 2. Основные концепции

Falco работает, перехватывая системные вызовы ядра Linux с помощью модуля ядра или технологии eBPF. Эти системные вызовы затем сравниваются с набором правил для выявления аномалий или нежелательного поведения.

### Механизм работы:
*   **Перехват системных вызовов:** Falco использует `eBPF` (Extended Berkeley Packet Filter) или собственный модуль ядра для мониторинга активности системных вызовов в реальном времени. Это позволяет ему "видеть" всё, что происходит на уровне ядра.
*   **Система правил:** Перехваченные события обрабатываются с помощью гибкой системы правил. Правила определяются в формате YAML и описывают, какое поведение считается подозрительным или опасным (например, запуск `shell` внутри контейнера, изменение критических файлов, доступ к сетевым ресурсам).

### Основной функционал:
*   Мониторинг системных вызовов ядра с помощью eBPF или собственного модуля.
*   Обнаружение нежелательных действий: запуск `shell` внутри контейнеров, изменения прав доступа, доступ к критическим файлам, выполнение сетевых запросов из неожиданных мест.
*   Гибкая система правил на YAML: можно использовать готовые (например, CIS-совместимые) или писать свои, адаптированные под специфические нужды.
*   Интеграция с Kubernetes (мониторинг активности `kube-apiserver`), AWS CloudTrail, GitHub и другими сервисами для обогащения контекста событий.
*   Возможность отправки событий в внешние системы оповещения (Slack, Prometheus, Grafana, SIEM-системы и др.) через инструмент-компаньон Falcosidekick.

### Преимущества:
Falco помогает строить безопасные и прозрачные среды, автоматизировать контроль соответствия и быстро реагировать на угрозы. Его runtime-мониторинг является критически важным слоем защиты, который дополняет статический анализ и аудит конфигураций.

### Сравнение с другими инструментами безопасности

*   **[Kubesec](../Kubernetes/Security/kubesec.md) / [Kyverno](../Kubernetes/Security/kyverno.md):** Эти инструменты фокусируются на проверке манифестов и применении политик *до* или *во время* развертывания (Admission Control). Falco работает *после* развертывания, обеспечивая *runtime-мониторинг*.
*   **[kube-bench](../Kubernetes/Security/kube-bench.md):** Проводит аудит *статической конфигурации кластера* на соответствие CIS Benchmark. Falco обнаруживает *динамические угрозы* в работающем кластере.
*   **[Sigstore](./sigstore.md):** Обеспечивает безопасность *цепочки поставок ПО* путем подписи и проверки артефактов. Falco отвечает за *безопасность этих артефактов во время их выполнения*.

Falco, как инструмент runtime-безопасности, является неотъемлемой частью комплексной стратегии защиты облачных и контейнерных сред.
