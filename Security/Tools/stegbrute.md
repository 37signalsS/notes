# stegbrute: Быстрый перебор паролей для Steghide

## Определения

**stegbrute** ([github.com/R4yGM/stegbrute](https://github.com/R4yGM/stegbrute)) — это высокопроизводительный инструмент с открытым исходным кодом, написанный на языке Rust, предназначенный для проведения атак методом перебора (Brute-force) на файлы, содержащие скрытые данные с помощью утилиты `steghide`.

В отличие от стандартных скриптов-оберток, `stegbrute` использует многопоточность Rust для достижения максимальной скорости перебора на современных многоядерных процессорах.

## Основные концепции

### Принцип работы

Инструмент автоматизирует процесс последовательного тестирования паролей из заданного словаря (`wordlist`) для извлечения скрытого контента из контейнера.

- **Зависимость:** Для работы инструмента необходимо наличие установленного бинарного файла `steghide` в системном пути (`PATH`).
- **Стеганографический алгоритм:** Работает только с файлами, обработанными алгоритмами `steghide` (использует графы для встраивания данных).
- **Производительность:** Благодаря реализации на Rust, инструмент значительно быстрее аналогов на Python или Bash при обработке словарей большого объема (например, `rockyou.txt`).

### Поддерживаемые форматы контейнеров

`stegbrute` поддерживает все форматы, с которыми работает базовая утилита `steghide`:
- **Изображения:** `.jpg`, `.jpeg`, `.bmp`
- **Аудио:** `.wav`, `.au`

## Практические сценарии

### Установка

**Через Cargo (рекомендуется):**
```bash
cargo install stegbrute
```

**Через Docker:**
```bash
docker pull r4ygm/stegbrute
```

### Базовое использование

Для успешного извлечения данных требуется файл-контейнер и словарь паролей.

```bash
# Простой запуск с указанием файла и словаря
stegbrute -f container.jpg -w /usr/share/wordlists/rockyou.txt

# Запуск с использованием определенного количества потоков (по умолчанию используются все ядра)
stegbrute -f secret.wav -w wordlist.txt -t 4
```

### Опции командной строки

| Опция | Описание |
| :--- | :--- |
| `-f, --file` | Путь к файлу-контейнеру (изображение или аудио). |
| `-w, --wordlist` | Путь к словарю для перебора. |
| `-t, --threads` | Количество потоков (по умолчанию — количество логических ядер CPU). |
| `-v, --verbose` | Вывод каждой попытки (снижает скорость работы). |
| `-x, --extract` | Автоматическое сохранение извлеченного контента в файл. |

### Использование в CTF (Capture The Flag)

В задачах категории "Stegano" `stegbrute` часто является первым инструментом выбора после `binwalk` и `exiftool`, если предполагается использование пароля для `steghide`.

```bash
# Поиск пароля и автоматическое извлечение данных
stegbrute -f challenge.jpg -w rockyou.txt -x extracted_flag.txt
```

## Меры защиты и противодействие

Стеганография сама по себе является методом сокрытия факта передачи данных, однако слабый пароль делает её уязвимой к автоматизированному анализу.

1.  **Использование сложных паролей:** Пароли длиной более 12 символов с использованием разных регистров и спецсимволов делают словарные атаки неэффективными.
2.  **Защита от стеганализа:** Используйте современные инструменты, такие как **OutGuess**, которые минимизируют статистические искажения в контейнере.
3.  **Шифрование перед встраиванием:** Всегда шифруйте данные (например, через AES) перед тем, как прятать их с помощью стеганографии. Даже если пароль к `steghide` будет подобран, злоумышленник получит зашифрованный блок.

## Дополнительная информация

### Ограничения

- **Зависимость от steghide:** Если утилита `steghide` не установлена или недоступна, инструмент не сможет функционировать.
- **Специфичность:** Инструмент не предназначен для перебора паролей к архивам (`zip`, `rar`) или другим методам стеганографии (например, LSB в PNG).
