# stegbrute

## 1. Определения

**stegbrute** ([github.com/R4yGM/stegbrute](https://github.com/R4yGM/stegbrute)) — это быстрый инструмент, написанный на Rust, для подбора паролей к данным, скрытым с помощью утилиты `steghide`.

## 2. Основные концепции

Инструмент автоматизирует процесс перебора паролей из словаря (`wordlist`) для извлечения данных, скрытых с помощью `steghide`.

- **Зависимость**: `steghide` должна быть установлена в системе.
- **Процесс**: `stegbrute` поочередно использует каждый пароль из словаря, вызывая `steghide` для попытки извлечения данных.
- **Многопоточность**: Поддерживает многопоточный режим для ускорения перебора.

## 3. Практические сценарии

`stegbrute` часто используется в CTF-соревнованиях для решения задач на стеганографию, где требуется подобрать пароль.

- **Поддерживаемые форматы**: JPEG, BMP, WAV, AU (форматы, которые поддерживает `steghide`).

## 4. Продвинутые детали

- **Установка**: Может быть установлен через `cargo`, `docker` или из скомпилированного бинарного файла.
