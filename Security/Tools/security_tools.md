## ghostscan [h2337/ghostscan](https://github.com/h2337/ghostscan)

**ghostscan** — это современный сканер безопасности для Linux, написанный на Rust. Он предназначен для помощи в реагировании на инциденты (incident response).

*   **Обнаружение скрытых угроз**: Помогает выявлять скрытые руткиты, продвинутые угрозы с использованием eBPF и "призрачные" процессы (процессы, скрытые от стандартных утилит мониторинга).
*   **Сбор данных**: Собирает системную информацию из множества источников для комплексного анализа:
    *   Ядро Linux (`/proc`, `/sys`)
    *   eBPF (`bpffs`)
    *   `systemd`
    *   `cron`
    *   Сетевые сокеты

*   **Язык**: Rust
*   **Ключевая технология**: eBPF для глубокого сканирования и обнаружения аномалий.
*   **Интеграции**: Взаимодействует с системными утилитами, такими как `bpftool`, `nft`, `ss`, `journalctl`, `auditctl`.


## Capa [fireeye/capa](https://github.com/fireeye/capa)

**Capa** — это инструмент от Mandiant (ранее FireEye) для выявления возможностей исполняемых файлов. Он помогает аналитикам быстро понять, что делает та или иная программа.

*   **Идентификация возможностей**: Определяет, что программа может делать (например, устанавливать службу, использовать HTTP, являться бэкдором).
*   **Статический и динамический анализ**: Анализирует исполняемые файлы (PE, ELF, .NET) и может обрабатывать отчеты из песочниц (динамический анализ).
*   **Сопоставление с ATT&CK**: Связывает обнаруженные возможности с тактиками и техниками из матрицы MITRE ATT&CK.

*   **Язык**: Python.
*   **Ключевая технология**: Анализ на основе правил. Правила пишутся в формате, похожем на YAML, и легко расширяются.
*   **Интеграции**: Имеет плагины для IDA Pro и Ghidra, что позволяет проводить анализ непосредственно в среде реверс-инжиниринга.


## Lynis [CISOfy/lynis](https://github.com/CISOfy/lynis)

**Lynis** — это инструмент для аудита безопасности и усиления защиты систем на базе UNIX.

*   **Соответствие стандартам**: Помогает в тестировании на соответствие стандартам, таким как ISO27001, PCI-DSS, HIPAA.
*   **Усиление защиты (Hardening)**: Предоставляет рекомендации по усилению защиты системы.
*   **Отчетность**: Генерирует подробные отчеты с найденными проблемами и предложениями по их устранению.


## Wazuh [wazuh/wazuh](https://github.com/wazuh/wazuh)

**Wazuh** — это бесплатная платформа с открытым исходным кодом для предотвращения, обнаружения и реагирования на угрозы, объединяющая возможности XDR и SIEM.

*   **SIEM и XDR**: Централизованный сбор, анализ логов и расширенное обнаружение угроз.
*   **Обнаружение вторжений**: Мониторинг системы на наличие вредоносного ПО, руткитов и аномалий.
*   **Мониторинг целостности файлов (FIM)**: Отслеживание изменений в критически важных файлах.
*   **Обнаружение уязвимостей**: Автоматическое сканирование на наличие известных уязвимостей (CVE).
*   **Соответствие стандартам**: Помогает в соблюдении PCI DSS, GDPR и других нормативов.
*   **Компоненты**: Состоит из Wazuh Agent (устанавливается на конечные точки), Wazuh Server, Wazuh Indexer и Wazuh Dashboard.

## THOR Lite [Nextron Systems](https://www.nextron-systems.com/thor-lite/)

**THOR Lite** — это мультиплатформенный сканер от Nextron Systems. Сканирование  происходит на основе сигнатур (YARA) и индикаторов компрометации (IOC).

## traitor [liamg/traitor](https://github.com/liamg/traitor)

**traitor** — это инструмент для автоматического поиска и эксплуатации уязвимостей с целью повышения привилегий в Linux.

*   **Автоматический эксплойт**: Ищет и пытается применить известные эксплойты для повышения привилегий.

*   **Язык**: Go.
*   **Векторы атак**:
    *   Большинство техник из [GTFOBins](#gtfobins).
    *   Записываемый сокет Docker (`docker.sock`).
    *   Известные CVE, включая CVE-2022-0847 (Dirty Pipe) и CVE-2021-4034 (PwnKit).


## GTFOBins [GTFOBins](https://gtfobins.github.io/)

**GTFOBins** — это курируемый список бинарных файлов Unix, которые могут быть использованы для обхода локальных ограничений безопасности.

*   **Повышение привилегий**: Демонстрирует, как легитимные системные утилиты могут быть использованы для получения root-доступа.
*   **Пост-эксплуатация**: Содержит техники для выполнения команд, создания обратных шеллов, передачи файлов и других действий после первоначального проникновения.


## Kubernetes Goat [madhuakula/kubernetes-goat](https://github.com/madhuakula/kubernetes-goat)

**Kubernetes Goat** — это не инструмент, а интерактивная обучающая среда ("Vulnerable by Design") для изучения безопасности Kubernetes.
