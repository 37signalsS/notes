# Инструменты безопасности

Данный документ является центральным индексом инструментов безопасности, описанных в базе знаний. Он структурирован по функциональным областям для удобства навигации и аудита.

## Сканеры уязвимостей и аудит систем

- **[OpenVAS (GVM)](./openvas_installation_and_usage.md)**: Полнофункциональный фреймворк для сканирования уязвимостей и управления ими на уровне инфраструктуры.
- **[Lynis](./lynis.md)**: Инструмент для глубокого аудита безопасности и проверки соответствия стандартам (compliance) в Unix-подобных системах.
- **[THOR Lite](./thor_lite.md)**: Сканер для поиска признаков компрометации (IOC) и вредоносного ПО на основе сигнатур и эвристики.
- **[Trivy](../../Docker/Docker_security/vulnerability_scanning.md)**: Универсальный сканер для поиска уязвимостей в образах контейнеров, файловых системах, репозиториях Git и IaC-манифестах.
- **[Grype](../../Docker/Docker_security/vulnerability_scanning.md)**: Специализированный сканер уязвимостей для образов контейнеров и файловых систем.

## Безопасность цепочки поставок (Supply Chain Security)

- **[Sigstore](./sigstore.md)**: Комплексное решение для безопасной подписи и проверки программных артефактов (образов, бинарных файлов).
- **[Cosign](../../Security/Supply_Chain_Security/artifact_signing.md)**: Инструмент для подписи контейнерных образов, аттестаций и метаданных в OCI-реестрах.
- **[Syft](../../Security/Supply_Chain_Security/overview.md)**: Утилита для генерации состава программного обеспечения (SBOM) из образов контейнеров и файловых систем.

## Безопасность во время выполнения (Runtime Security)

- **[Falco](./falco.md)**: Система мониторинга безопасности в режиме реального времени для хостов и контейнеров, анализирующая системные вызовы.
- **[Wazuh](./wazuh.md)**: Платформа класса XDR и SIEM, объединяющая функции HIDS, мониторинга логов и реагирования на инциденты.

## Анализ вредоносного ПО и реверс-инжиниринг

- **[Capa](./capa.md)**: Инструмент для автоматического выявления возможностей исполняемых файлов (детектирование поведения программы).
- **[Ciphey](./ciphey.md)**: Автоматизированная утилита для дешифрования и декодирования данных без знания ключа или алгоритма.
- **[what (pyWhat)](./what.md)**: Инструмент для идентификации типа данных, хешей, криптографических ключей и других цифровых артефактов.

## Реагирование на инциденты и форензика

- **[ghostscan](./ghostscan.md)**: Сканер для Linux, ориентированный на выявление скрытых угроз и помощь в первичной форензике при инцидентах.
- **[Проверка целостности бинарников](../../Linux/Security/Concepts/file-integrity-checking.md)**: Методы и инструменты (`rpm -Va`, `debsums`, AIDE) для обнаружения подмены системных компонентов.

## Повышение привилегий и эксплуатация

- **[traitor](./traitor.md)**: Инструмент для автоматизированного поиска и эксплуатации путей повышения привилегий в Linux (GTFOBins, уязвимости ядра).
- **[GTFOBins](./gtfobins.md)**: Справочник по использованию легитимных Unix-бинарников для обхода ограничений безопасности.
- **[Hydra](./hydra.md)**: Онлайн-инструмент для проведения атак методом перебора (brute-force) на сетевые протоколы.
- ** John the Ripper (JtR)](./jtr.md)**: Оффлайн-взломщик паролей, поддерживающий сотни типов хешей.

## Управление идентификацией и доступом (IAM)

- **[Keycloak: Обзор](./keycloak_overview.md)**: Система управления идентификацией и доступом (Identity and Access Management) с поддержкой SSO.
- **[Keycloak: LDAP Федерация](./keycloak_ldap_federation.md)**: Интеграция Keycloak с существующими каталогами пользователей.

## Криптография и управление секретами

- **[Vault](../../Vault/overview.md)**: Централизованная платформа для управления секретами, ключами шифрования и динамического выпуска сертификатов.
- **[GPG и OpenPGP](../../Linux/Security/Tools/gpg_and_openpgp.md)**: Свободная реализация стандарта OpenPGP (RFC 4880/9580) для шифрования, подписи и управления ключами.
- **[SOPS](./sops_overview.md)**: Редактор для шифрования данных внутри файлов (YAML, JSON, .env) c поддержкой PGP и `age`.
- **[Betterleaks](./betterleaks.md)**: Сканер секретов (наследник Gitleaks) — локальные файлы, Git-история, GitHub, GitLab, Hugging Face, S3 с валидацией найденных credentials.
- **[Sealed Secrets](../../Kubernetes/Security/sealed_secrets_overview.md)**: Инструмент Kubernetes для шифрования секретов в Git, которые могут быть расшифрованы только контроллером в кластере.
- **[Диагностика SSL/TLS сертификатов](./ssl_certificate_diagnostics.md)**: Практическое руководство по отладке цепочек доверия и верификации сертификатов через OpenSSL.
- **[Управление CA с помощью OpenSSL](./openssl_ca/single_tier/overview.md)**: Инструкции по созданию и эксплуатации собственного удостоверяющего центра.
- **[Aces](./aces.md)**: Библиотека и утилита для кодирования данных в произвольные наборы символов.

## Безопасность сетевой инфраструктуры

- **[nzyme](./nzyme_wifi_security.md)**: Система обнаружения вторжений в беспроводные сети (WIDS) и мониторинга Wi-Fi безопасности.

## Стеганография и сокрытие данных

- **[CryptoFrame](./cryptoframe.md)**: Методы сокрытия зашифрованной информации внутри видеопотоков.
- **[SecretPixel](./secretpixel.md)**: Внедрение зашифрованных данных в изображения с использованием LSB и псевдослучайного распределения.
- **[stegbrute](./stegbrute.md)**: Инструмент для перебора паролей к скрытым данным, внедренным через `steghide`.
- **[File_Hider](./file_hider.md)**: Утилита для внедрения одного файла в другой с использованием маркеров конца файла.
