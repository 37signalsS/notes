# Инструменты безопасности

Это главный индекс инструментов безопасности, описанных в данной базе знаний.

## Сканеры уязвимостей и аудита

-   **[OpenVAS (GVM)](./openvas_installation_and_usage.md)**: Мощный фреймворк для сканирования и управления уязвимостями.
-   **[Lynis](./lynis.md)**: Инструмент для проверки безопасности и соответствия стандартам в Linux-системах.
-   **[THOR Lite](./thor_lite.md)**: Мультиплатформенный сканер для поиска признаков взлома и вредоносного ПО на основе сигнатур.

## Анализ вредоносного ПО и реверс-инжиниринг

-   **[Capa](./capa.md)**: Инструмент для выявления возможностей исполняемых файлов (что делает программа).
-   **[Ciphey](./ciphey.md)**: Полностью автоматизированный инструмент дешифрования и декодирования.
-   **[what (pyWhat)](./what.md)**: Утилита для автоматического определения типа и содержания данных.

## Реагирование на инциденты и форензика

-   **[ghostscan](./ghostscan.md)**: Сканер для Linux, предназначенный для помощи в реагировании на инциденты и выявления скрытых угроз.

## Безопасность во время выполнения (Runtime Security)

-   **[Falco](./falco.md)**: Open-source решение для мониторинга безопасности во время выполнения на хостах и в контейнерах.
-   **[Wazuh](./wazuh.md)**: Платформа XDR и SIEM для предотвращения, обнаружения и реагирования на угрозы.

## Повышение привилегий

-   **[traitor](./traitor.md)**: Инструмент для автоматического поиска и эксплуатации уязвимостей с целью повышения привилегий в Linux.
-   **[GTFOBins](./gtfobins.md)**: База знаний о том, как использовать легитимные бинарные файлы Unix для обхода ограничений.

## Инструменты для атак

-   **[Hydra](./hydra.md):** Универсальный онлайн-инструмент для подбора паролей к различным сервисам.
-   **[John the Ripper (JtR)](./jtr.md):** Мощный оффлайн-инструмент для взлома паролей по их хешам.

## Безопасность Wi-Fi

-   **[nzyme](./nzyme_wifi_security.md)**: Открытая система для мониторинга и защиты беспроводных сетей (Wireless Intrusion Detection System).

## Криптография и управление секретами

-   **[Vault](../../Vault/overview.md)**: Централизованное хранилище для управления секретами.
-   **[SOPS](./sops_overview.md)**: Редактор для шифрования файлов (YAML, JSON) и их безопасного хранения в Git.
-   **[Sealed Secrets](./sealed_secrets_overview.md)**: Инструмент для безопасного хранения секретов Kubernetes в Git.
-   **[Управление CA с помощью OpenSSL](./openssl_ca/single_tier/overview.md)**: Руководство по созданию и управлению собственным центром сертификации.
-   **[Sigstore](./sigstore.md)**: Решение для безопасной подписи и проверки программных артефактов (образов, бинарников).
-   **[Aces](./aces.md)**: Утилита и библиотека для кодирования данных в произвольный набор символов.

## Стеганография

-   **[CryptoFrame](./cryptoframe.md)**: Скрытие данных в видеофайлах.
-   **[SecretPixel](./secretpixel.md)**: Скрытие данных в изображениях.
-   **[stegbrute](./stegbrute.md)**: Подбор паролей к данным, скрытым с помощью `steghide`.
-   **[File_Hider](./file_hider.md)**: Внедрение одного файла в другой с использованием маркеров.
