# John the Ripper (JtR)

## 1. Определения

**John the Ripper (JtR)** — это популярный и мощный инструмент для **офлайн-аудита** и восстановления паролей. Он предназначен для взлома паролей по их хешам, полученным из различных систем. JtR поддерживает огромное количество форматов хешей и работает на большинстве операционных систем.

## 2. Основные концепции

JtR работает, принимая на вход файл с хешами паролей и пытаясь подобрать соответствующий пароль в открытом виде с помощью различных режимов атаки.

### Режимы работы

1. **Wordlist mode (Словарная атака)**: Самый распространенный режим. JtR использует предоставленный файл-словарь (`wordlist`) и проверяет каждое слово в качестве пароля.
2. **Single crack mode (Одиночный режим)**: Использует информацию из имени пользователя (логина) для генерации вероятных паролей. Например, для пользователя `testuser` он может проверить `testuser`, `testuser123`, `restuset` и т.д.
3. **Incremental mode (Инкрементальный режим)**: Классический [брутфорс](../Concepts/brute_force_attacks.md), при котором JtR перебирает все возможные комбинации символов до нахождения пароля. Это самый медленный, но и самый исчерпывающий режим.
4. **External mode (Внешний режим)**: Позволяет определять собственные методы генерации паролей с помощью скриптов.

### Файл `john.pot`

Все успешно взломанные пароли JtR сохраняет в файл `~/.john/john.pot`. Перед каждой новой атакой он проверяет этот файл, чтобы не тратить время на уже известные хеши.

## 3. Практические сценарии

### Взлом хешей из `/etc/shadow`

1. **Подготовка файла с хешами:**
    Для атаки на хеши пользователей Linux необходимо объединить файлы `/etc/passwd` и `/etc/shadow`. Для этого используется утилита `unshadow`.

    ```bash
    unshadow /etc/passwd /etc/shadow > hashes.txt
    ```

2. **Запуск атаки:**
    Передайте полученный файл в JtR.

    ```bash
    # John автоматически определит тип хеша и начнет атаку
    john hashes.txt
    ```

    Чтобы использовать конкретный словарь:

    ```bash
    john --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt
    ```

### Взлом хеша из строки

```bash
# Пример с хешем MD5
echo "8743b52063cd84097a65d1633f5c74f5" > md5_hash.txt
john --format=raw-md5 md5_hash.txt
```

### Взлом пароля ZIP-архива

1. **Извлечение хеша из архива:**
    Используйте утилиту `zip2john`.

    ```bash
    zip2john my_archive.zip > zip_hash.txt
    ```

2. **Запуск атаки на хеш:**

    ```bash
    john zip_hash.txt
    ```

### Просмотр взломанных паролей

```bash
john --show hashes.txt
```

## 4. Продвинутые детали

### Правила (Rules)

JtR позволяет применять **правила** к словам из словаря для создания более сложных вариаций. Например, правило может добавлять цифры в конец слова, заменять буквы на похожие символы (`a` -> `@`, `s` -> `$`) или менять регистр. Это значительно повышает эффективность словарной атаки.

```bash
# Применить стандартные правила к словарю
john --wordlist=pass.list --rules hashes.txt
```

Правила можно комбинировать и создавать собственные в файле `john.conf`.

### Jumbo John

Существует расширенная версия, **"Jumbo John"**, которая поддерживает гораздо больше форматов хешей, использует GPU для ускорения перебора (через OpenCL) и включает множество дополнительных утилит (`ssh2john`, `pdf2john` и т.д.). Для серьезной работы рекомендуется использовать именно Jumbo-версию.
