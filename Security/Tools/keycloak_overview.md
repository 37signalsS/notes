# Keycloak

## Определения

**Keycloak** — это open-source продукт для управления идентификацией и доступом (Identity and Access Management, IAM), который обеспечивает централизованную аутентификацию и авторизацию для приложений и сервисов.

## Основные концепции

### Аутентификация и Авторизация (AuthN/AuthZ)

Keycloak разделяет процессы:

- **Аутентификация (Authentication, AuthN):** Проверка подлинности пользователя (кто ты?).
- **Авторизация (Authorization, AuthZ):** Предоставление прав доступа к ресурсам (что тебе разрешено?).

### Аналоги

Keycloak является альтернативой для:

- **Microsoft Active Directory:** В отличие от AD, ориентированного на Windows-инфраструктуру, Keycloak является кросс-платформенным решением, часто используемым в стеке Linux/macOS.
- **Okta, Auth0:** Облачные IAM-провайдеры.

### Поддерживаемые протоколы

Keycloak поддерживает стандартные протоколы, что обеспечивает широкую совместимость:

- **OpenID Connect (OIDC):** Слой идентификации поверх OAuth 2.0.
- **OAuth 2.0:** Фреймворк для делегирования авторизации.
- **SAML 2.0:** Стандарт для обмена данными аутентификации и авторизации.

## Практические сценарии

### Централизованный вход (Single Sign-On, SSO)

Пользователи могут входить в несколько приложений, используя одну учетную запись Keycloak.

### Управление доступом

Администраторы могут настраивать детальные политики доступа (roles, groups, policies) для пользователей и сервисов.

### Федерация удостоверений (Identity Federation)

Keycloak может выступать в качестве посредника для внешних провайдеров идентификации, таких как Google, GitHub или корпоративный LDAP/Active Directory. См. [Keycloak и LDAP Федерация](./keycloak_ldap_federation.md).
