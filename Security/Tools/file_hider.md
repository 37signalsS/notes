# File_Hider

## 1. Определения

**File_Hider** ([github.com/x011/File_Hider](https://github.com/x011/File_Hider)) — это инструмент, который внедряет один файл внутрь другого (файла-хоста), используя специальные маркеры для последующего извлечения.

## 2. Основные концепции

File_Hider не использует классические методы стеганографии, такие как LSB.

- **Процесс:**
    1.  **Сжатие и шифрование**: Файл, который нужно скрыть, сжимается и проходит 7 слоев шифрования AES-256.
    2.  **Шифрование ключа**: Сессионный ключ AES шифруется с помощью открытого ключа RSA.
    3.  **Внедрение**: Зашифрованный контент кодируется в Base64 и встраивается в файл-хост между специальными маркерами.

Этот метод позволяет использовать любые типы файлов в качестве хоста и скрываемого файла.

## 3. Практические сценарии

- **Платформы:** Linux, Windows.
- **Зависимости:** Python 3, Tkinter, PyCryptodome, OpenSSL.

## 4. Продвинутые детали

File_Hider отличается от традиционных методов стеганографии (например, LSB) тем, что он не пытается сделать скрытые данные визуально или аудиально незаметными. Вместо этого он сосредоточен на создании "логической" невидимости путем внедрения зашифрованного и закодированного файла в другой файл, используя уникальные маркеры.

### Отличия от классической стеганографии:
- **Независимость от типа контейнера:** Классическая стеганография часто сильно зависит от специфических свойств медиафайлов (изображения, аудио), используя их избыточность. File_Hider может использовать любой файл как контейнер, поскольку он просто добавляет данные между маркерами, не модифицируя существующие биты контейнера.
- **Обнаружение:** Методы классической стеганографии могут быть обнаружены статистическим анализом контейнера. File_Hider полагается на то, что зашифрованный и Base64-кодированный блок данных между маркерами может быть интерпретирован как часть хост-файла или быть проигнорирован обычными парсерами. Однако наличие самих маркеров может быть сигнатурой для обнаружения.
- **Безопасность:** Шифрование AES-256 обеспечивает конфиденциальность скрываемых данных, а RSA-шифрование ключа AES добавляет дополнительный уровень защиты. Однако, если маркеры будут известны или легко обнаружимы, сам факт скрытия данных может быть установлен.

### Применение:
Этот метод подходит для сценариев, где требуется скрыть небольшой объем данных внутри файла, который предположительно не будет тщательно анализироваться на предмет постороннего содержимого, или где сами маркеры не вызовут подозрений.
