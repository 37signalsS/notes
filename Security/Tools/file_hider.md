# File Hider

## Definitions

**File Hider** ([github.com/x011/File_Hider](https://github.com/x011/File_Hider)) — инструмент для внедрения одного файла внутрь другого (файла-хоста) с использованием специальных маркеров для последующего извлечения.

Относится к категории инструментов [стеганографии](../Concepts/steganography.md), но не использует классические методы (LSB, DCT) — вместо этого применяет подход «логической невидимости» через встраивание зашифрованных данных между уникальными маркерами.

## Basic Concepts

### Архитектура внедрения

1. **Сжатие и шифрование** — скрываемый файл сжимается и проходит 7 слоёв шифрования AES-256-CBC.
2. **Шифрование ключа** — сессионный ключ AES шифруется асимметричным алгоритмом RSA.
3. **Кодирование и внедрение** — зашифрованный контент кодируется в Base64 и встраивается в файл-хост между специальными маркерами.

### Ключевые особенности

- **Независимость от типа контейнера** — может использовать любой файл как хост (не модифицирует существующие биты контейнера).
- **Универсальность форматов** — поддерживает любые типы файлов в качестве хоста и скрываемого файла.
- **Многослойная защита** — комбинация AES-256 (данные) + RSA (ключ).

## Practical Scenarios

### Использование

- **Платформы:** Linux, Windows.
- **Зависимости:** Python 3, Tkinter, PyCryptodome, OpenSSL.
- **Применение:** скрытие небольших объёмов данных в файлах, которые не предполагают тщательного анализа.

## Additional Information

### Отличия от классической стеганографии

| Характеристика | Классическая стеганография | File Hider |
|---|---|---|
| **Метод** | LSB, DCT, модификация битов контейнера | Встраивание между маркерами без изменения существующих данных |
| **Типы контейнеров** | Изображения, аудио, видео (требуют избыточности) | Любые файлы |
| **Обнаружение** | Статистический анализ (RS, гистограммы) | Сигнатурный анализ (поиск маркеров) |
| **Визуальная незаметность** | Да (минимальные искажения) | Нет (данные видны как Base64-блок) |

### Риски и ограничения

- **Обнаружение по маркерам** — наличие уникальных маркеров может служить сигнатурой для детектирования.
- **Интерпретация парсерами** — некоторые приложения могут корректно обработать файл-хост с внедрёнными данными, другие — выдать ошибку.
- **Объём данных** — подходит только для небольших файлов (Base64 увеличивает размер на ~33%).
