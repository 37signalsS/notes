# Sigstore: Безопасность цепочки поставок ПО

## 1. Определения

**Sigstore** (https://www.sigstore.dev/) — это open-source решение, разработанное для безопасной подписи и проверки программных артефактов, таких как образы контейнеров, бинарники и SBOM (Software Bill of Materials). Целью Sigstore является упрощение процесса криптографической подписи программного обеспечения и предоставление прозрачного, доступного для аудита механизма для защиты цепочек поставок ПО.

Sigstore поддерживается OpenSSF (Open Source Security Foundation) и устраняет сложности, связанные с традиционным управлением ключами, благодаря "keyless" подходу и публичному журналу прозрачности.

## 2. Основные концепции

Sigstore предоставляет набор интегрированных сервисов и инструментов для работы с цифровыми подписями:

*   **Fulcio (Keyless-подпись):** Сервис, который выдает краткосрочные сертификаты на основе аутентификации пользователя через OpenID Connect (OIDC). Это позволяет разработчикам подписывать артефакты, не управляя долгосрочными ключами вручную. Подписи создаются на основе удостоверения разработчика.
*   **Rekor (Публичный журнал прозрачности):** Неизменяемый и публичный журнал транзакций, который хранит записи обо всех подписях, сделанных через Sigstore. Любой желающий может проаудировать записи, чтобы убедиться, что артефакт был подписан и не был изменен.
*   **Cosign (CLI-утилита):** Инструмент командной строки для непосредственной подписи и проверки программных артефактов. Он поддерживает подпись образов контейнеров (в том числе в OCI-реестрах), Helm-чартов, файлов и других бинарников.

### Основной функционал:
*   Keyless-подпись через Fulcio (использует OIDC для выдачи краткосрочных сертификатов).
*   Прозрачность с Rekor (неизменяемый лог для аудита подписей).
*   Cosign для подписи и проверки артефактов (контейнеры, Helm-чарты, файлы).
*   Поддержка CI/CD-интеграций (GitHub Actions, Tekton и другие).
*   Бесплатный публичный сервис для open-source проектов.

### Преимущества:
Sigstore делает подпись ПО удобной и безопасной, устраняя сложности управления ключами и предоставляя проверяемый публичный журнал для обеспечения целостности и происхождения программных артефактов.
