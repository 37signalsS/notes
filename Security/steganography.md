## CryptoFrame — Видеостеганография
- **Ссылка:** [github.com/x011/CryptoFrame](https://github.com/x011/CryptoFrame)

CryptoFrame - это инструмент, который шифрует текст и скрывает его в видеофайле, используя стеганографию. В отличие от SecretPixel, который работает с изображениями, CryptoFrame предназначен для видео и использует 7 слоев шифрования.

CryptoFrame использует метод **Least Significant Bit (LSB)** — запись информации в наименее значимый бит.

1.  Видео состоит из кадров, которые состоят из пикселей.
2.  Цвет каждого пикселя кодируется в формате RGB (красный, зеленый, синий).
3.  Значение каждого цветового канала представлено в битах. Скрываемый текст также преобразуется в биты.
4.  Метод LSB заменяет последний, наименее значимый бит в значении цвета пикселя на бит скрываемого сообщения. Это изменение настолько минимально, что визуально незаметно.

Биты скрытых данных распределяются по разным пикселям и кадрам, что усложняет их обнаружение. Из-за этого CryptoFrame работает с любыми форматами видео на входе, но на выходе создает видео, сжатое **только кодеками без потерь** (lossless). Это гарантирует, что скрытые данные не будут повреждены или утеряны в процессе сжатия.

- **Платформы:** Linux, Windows, macOS (везде, где есть Python 3+).
- **Зависимости:** 6 зависимостей, включая OpenSSL.
- **Входные форматы видео:** AVI, MKV, MOV, MP4, OGG, WMV, WEBM.
- **Выходные форматы видео:** AVI, MOV, MKV.
- **Кодеки на выходе (lossless):**
    - `FFV1`: Меньший размер, хорошая поддержка.
    - `HFYU`: Больший размер.
- **Шифрование:**
    - **Данные:** AES-256-CBC.
    - **Ключ AES:** Шифруется с помощью RSA-4096. Требуется генерация пары ключей и установка парольной фразы.

## SecretPixel — Стеганография для изображений
- **Ссылка:** [github.com/x011/SecretPixel](https://github.com/x011/SecretPixel)

Инструмент использует метод **LSB (Least Significant Bit)**, но с важным дополнением — **начальным значением (seed)**.

1.  **Сжатие и шифрование**: Скрываемый файл сжимается (zlib) и шифруется (AES-256).
2.  **Генерация позиций**: Генератор псевдослучайных чисел с заданным `seed` создает последовательность позиций пикселей в изображении.
3.  **Внедрение LSB**: Биты зашифрованного файла записываются в наименее значимые биты (LSB) цветовых каналов (RGB) пикселей в псевдослучайном порядке, который определяется на шаге 2.

Использование `seed` распределяет скрытые данные по всему изображению, а не последовательно, что значительно усложняет их обнаружение статистическими методами.

- **Платформы:** Кроссплатформенный (Python).
- **Зависимости:** PyCryptodome, Pillow.
- **Форматы изображений:** PNG, BMP, TGA, TIFF.
- **Шифрование:**
    - **Данные:** AES-256.
    - **Ключ AES:** Шифруется с помощью RSA.

## stegbrute — Брутфорс для стеганографии
- **Ссылка:** [github.com/R4yGM/stegbrute](https://github.com/R4yGM/stegbrute)

**stegbrute** — это быстрый инструмент для подбора паролей к данным, скрытым с помощью стеганографии. Он написан на Rust и часто используется в CTF-соревнованиях.

Инструмент автоматизирует процесс перебора паролей из словаря (`wordlist`) для извлечения данных, скрытых с помощью утилиты `steghide`.

- **Зависимость**: `steghide` должна быть установлена в системе.
- **Процесс**: `stegbrute` поочередно использует каждый пароль из словаря, вызывая `steghide` для попытки извлечения данных.
- **Многопоточность**: Поддерживает многопоточный режим для ускорения перебора.

- **Язык**: Rust.
- **Поддерживаемые форматы**: JPEG, BMP, WAV, AU (форматы, которые поддерживает `steghide`).
- **Установка**: Может быть установлен через `cargo`, `docker` или из скомпилированного бинарного файла.

## File_Hider — Стеганография для файлов
- **Ссылка:** [github.com/x011/File_Hider](https://github.com/x011/File_Hider)

File_Hider не использует классические методы стеганографии, такие как LSB. Вместо этого он внедряет зашифрованный и сжатый файл (payload) внутрь другого файла (host file), добавляя специальные маркеры для последующего извлечения.

1.  **Сжатие и шифрование**: Файл, который нужно скрыть, сжимается и проходит 7 слоев шифрования AES-256 с разными ключами и векторами инициализации (IV).
2.  **Шифрование ключа**: Сессионный ключ AES шифруется с помощью открытого ключа RSA. Это гарантирует, что только владелец закрытого ключа сможет расшифровать данные.
3.  **Внедрение**: Зашифрованный контент кодируется в Base64 и встраивается в файл-хост.

Этот метод позволяет использовать любые типы файлов в качестве хоста и скрываемого файла.

- **Платформы:** Linux, Windows (есть `.exe`).
- **Зависимости:** Python 3, Tkinter, PyCryptodome, OpenSSL (для генерации ключей).
- **Шифрование:**
    - **Данные:** 7 слоев AES-256.
    - **Ключ AES:** Шифруется с помощью RSA.
