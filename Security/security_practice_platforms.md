# Платформы для практики кибербезопасности

*   **[Hack The Box (HTB)](https://www.hackthebox.com)** — ведущая платформа для Red Team. Предлагает виртуальные машины (Boxes) с реальными сценариями, а также **HTB Academy** для структурированного обучения. В 2026 году активно развивает направление **HTB Enterprise** для корпоративного обучения.
*   **[TryHackMe (THM)](https://tryhackme.com/)** — наиболее подходящая платформа для новичков. Содержит интерактивные комнаты (Rooms) с пошаговыми инструкциями. Охватывает как основы сетей и Linux, так и современные векторы атак на Active Directory и Web.
*   **[CyberCamp](https://cybercamp.su/)** — русскоязычная платформа, ориентированная на проведение соревнований и обучение. Популярна в академической и корпоративной среде РФ.
*   **[CyberDefenders](https://cyberdefenders.org/)** — специализируется на задачах для Blue Team и SOC. Предлагает сценарии по форензике (анализ дампов памяти, дисков), анализу сетевого трафика и расследованию инцидентов на базе реальных кейсов.
*   **[Blue Team Labs Online (BTLO)](https://blueteamlabs.online/)** — платформа для практики защитных навыков: анализ артефактов вредоносного ПО, работа с SIEM и укрепление конфигураций серверов.
*   **[Kubernetes Goat](https://github.com/madhuakula/kubernetes-goat)** — интерактивная лаборатория с намеренно уязвимым кластером Kubernetes. Позволяет на практике изучить такие угрозы, как побег из контейнера, компрометация API-сервера и атаки через Sidecar-контейнеры.
*   **[iximiuz Labs](https://labs.iximiuz.com/)** — высокотехнологичная платформа для глубокого изучения внутреннего устройства Linux, Docker, Networking и Kubernetes через интерактивные сценарии в браузере.
*   **[Killercoda](https://killercoda.com/)** — облачная песочница с готовыми сценариями по Kubernetes и Linux. Широко используется для подготовки к экзаменам CKA/CKS.
*   **[CloudGoat](https://github.com/RhinoSecurityLabs/cloudgoat)** — (Rhino Security Labs) уязвимая инфраструктура в AWS/GCP для отработки навыков поиска небезопасных конфигураций (Misconfigurations) и эксплуатации IAM-ролей.
*   **[OverTheWire](https://overthewire.org/wargames/)** — классический набор wargames. Серия **Bandit** является обязательной для освоения командной строки Linux. Другие уровни (Leviathan, Narnia) фокусируются на эксплуатации уязвимостей в C-коде.
*   **[pwn.college](https://pwn.college/)** — образовательный проект ASU, предлагающий глубокое погружение в системную безопасность: от ассемблера и шелл-кодов до эксплуатации сложных уязвимостей в ядре Linux.
*   **[Root-Me](https://www.root-me.org/)** — французская платформа с огромным количеством задач по всем категориям ИБ, включая специфические разделы по VoIP и сетевым протоколам.
