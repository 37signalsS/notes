# Платформы для практики кибербезопасности

### CyberCamp

**[CyberCamp](https://cybercamp.su/)** — это платформа, предлагающая задачи и конкурсы по кибербезопасности, часто используемая для обучения и соревнований в русскоязычном сегменте.

### CyberDefenders

**[CyberDefenders](https://cyberdefenders.org/)** — платформа, специализирующаяся на Blue Team (защите) и SOC (Security Operations Center) задачах. Предоставляет реалистичные сценарии для отработки навыков анализа инцидентов и реагирования на них.

### TryHackMe

**[TryHackMe](https://tryhackme.com/)** — популярная платформа для обучения кибербезопасности с интерактивными лабораториями, руководствами и задачами. Подходит как для новичков, так и для более опытных специалистов, охватывая широкий спектр тем от основ до продвинутых техник.

### Hack The Box

**[Hack The Box](https://www.hackthebox.com)** — одна из ведущих платформ для тренировки навыков Red Team (атаки). Предлагает множество виртуальных машин для взлома, реальные сценарии и соревнования, помогая развивать навыки пентестинга и поиска уязвимостей.

### Kubernetes Goat

**[Kubernetes Goat](https://github.com/madhuakula/kubernetes-goat)** — это специально созданная "уязвимая" среда Kubernetes, разработанная для изучения и практики безопасности контейнерных сред. Это интерактивная обучающая среда для изучения безопасности Kubernetes.

### OverTheWire

**[OverTheWire](https://overthewire.org/wargames/)** — предоставляет набор "военных игр" (wargames), которые помогают улучшить навыки в области безопасности, начиная с основ командной строки Linux и заканчивая более сложными криптографическими и эксплойтами.

### pwn.college

**[pwn.college](https://pwn.college/welcome/welcome/)** — образовательная платформа, ориентированная на изучение низкоуровневой безопасности, эксплойтов и обратной инженерии. Предлагает курсы и задачи для глубокого понимания работы систем и уязвимостей.
