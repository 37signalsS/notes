# Атаки методом перебора (Brute-force)

## Определения

**Атака методом перебора (Brute-force)** — метод несанкционированного доступа к защищённым данным (паролям, криптографическим ключам, хешам) путём систематического перебора всех возможных комбинаций символов до нахождения корректного значения.

**Математическая сложность:** определяется формулой `S = N^L`, где:

- `N` — размер используемого алфавита символов.
- `L` — длина пароля/ключа.
Время взлома растёт экспоненциально при увеличении длины или расширении алфавита.

## Основные концепции

### Типы атак

| Тип | Описание | Особенности |
| :--- | :--- | :--- |
| **Полный перебор** | Исчерпывающий поиск по всему пространству ключей. | Гарантирует результат, но требует огромных вычислительных ресурсов. |
| **Словарная атака** | Перебор по списку наиболее вероятных паролей (утечки, популярные слова). | Намного быстрее полного перебора; эффективна против слабых паролей. |
| **Гибридная атака** | Сочетание словаря с мутациями (добавление цифр, спецсимволов, замена букв: `a` → `@`). | Позволяет находить «усложнённые» пользователями пароли. |
| **Параллельный перебор** | Распределение нагрузки между множеством узлов (GPU-кластеры, ботнеты). | Сокращает время взлома пропорционально количеству вычислителей. |
| **Timing Attack** | Анализ времени отклика системы для определения частичной корректности данных. | Позволяет узнать, существует ли пользователь в системе, по разнице во времени обработки запроса. |

### Математика стойкости паролей

Количество возможных комбинаций в зависимости от длины и алфавита:

| Длина | a-z (26) | a-Z (52) | a-Z0-9 (62) | Полный набор (94) |
| :--- | :--- | :--- | :--- | :--- |
| **8** | 2.1 × 10¹¹ | 5.3 × 10¹³ | 2.2 × 10¹⁴ | 6.6 × 10¹⁵ |
| **12** | 9.5 × 10¹⁷ | 9.5 × 10²⁰ | 4.7 × 10²¹ | 4.8 × 10²² |
| **16** | 4.4 × 10²⁴ | 1.9 × 10²⁸ | 7.9 × 10²⁸ | 3.5 × 10³⁰ |

## Практические сценарии

### Инструменты перебора

- **[Hydra](../Tools/hydra.md):** инструмент для онлайн-атак на сетевые протоколы (SSH, HTTP, FTP, RDP).
- **[John the Ripper](../Tools/jtr.md):** мощный инструмент для офлайн-взлома хешей паролей из дампов БД и системных файлов.
- **[Hashcat](https://hashcat.net/hashcat/):** самый быстрый инструмент для перебора хешей с использованием мощностей GPU.

### Методы защиты и контрмеры

1. **Rate Limiting:** ограничение количества попыток входа с одного IP-адреса.
   - [fail2ban](../../Linux/Security/Tools/fail2ban.md) — автоматическая блокировка по логам.
   - Модули Nginx (`limit_req`) и API Gateway.
2. **Account Lockout:** временная блокировка учётной записи после нескольких неудачных попыток.
3. **[MFA / 2FA](./mfa_totp.md):** многофакторная аутентификация делает подбор пароля бессмысленным для доступа.
4. **Усложнение паролей:** использование длинных (от 16 символов) паролей или фраз.
5. **Аутентификация по ключам:** замена паролей на криптографические ключи ([SSH-ключи](../../Linux/Security/ssh/server/ssh_authentication.md)).
6. **Constant-time comparison:** программная защита от Timing Attacks путём обеспечения одинакового времени выполнения функций сравнения независимо от результата.

## Дополнительная информация

### Безопасное хранение паролей

Для защиты от офлайн-перебора (в случае утечки базы данных) необходимо использовать медленные хеш-функции с «солью» (Salt) и параметром сложности (Work Factor):

- **Argon2** (рекомендовано)
- **bcrypt**
- **scrypt**

Подробнее см. [Хеширование паролей в Linux](../../Linux/SystemAdministration/Users/password_hashing.md).
