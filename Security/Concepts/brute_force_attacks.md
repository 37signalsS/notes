# Атаки методом перебора (Brute-force Attacks)

## 1. Определения

**Атаки методом перебора (брутфорс, brute-force)** — это попытки взлома учетных данных (паролей, ключей) путем систематического перебора всех возможных комбинаций символов до тех пор, пока не будет найдена правильная. Эффективность этих атак напрямую зависит от сложности и длины подбираемого значения.

## 2. Основные концепции

Существуют различные типы атак методом перебора:

### Полный перебор (Exhaustive Search)

Это наиболее прямолинейный и ресурсоемкий метод, при котором перебираются все возможные комбинации символов. Его сложность растет **экспоненциально** с увеличением длины пароля и размера алфавита символов (`N^L`).

### Словарные атаки (Dictionary Attacks)

Оптимизированный метод, который использует заранее подготовленные "словари" с наиболее вероятными паролями: слова, имена, даты, популярные последовательности (`123456`, `qwerty`).

### Параллельные атаки (Parallel Brute-force)

Задача по перебору распределяется между множеством устройств (например, ботнетом), что значительно сокращает общее время, необходимое для взлома.

### Временные атаки (Timing Attacks)

Атаки, использующие разницу во времени отклика системы для определения корректности части данных. Например, если проверка существующего логина занимает чуть больше времени, чем несуществующего, это можно использовать для перебора логинов.

## 3. Практические сценарии

### Инструменты для брутфорса

- **[Hydra](../Tools/hydra.md):** Универсальный онлайн-инструмент для подбора паролей к различным сервисам (SSH, FTP, HTTP).
- **[John the Ripper (JtR)](../Tools/jtr.md):** Мощный оффлайн-инструмент для взлома паролей по их хешам.

### Пример временной атаки

1. Атакующий отправляет запрос с логином `user1`. Система отвечает за **15 мс**.
2. Атакующий отправляет запрос с логином `admin`. Система отвечает за **50 мс**.
3. Вывод: разница во времени ответа указывает на то, что пользователь `admin`, скорее всего, существует, и система перешла к более длительной операции проверки пароля.

## 4. Дополнительная информация

### Защита от Brute-force атак

- **Использование сложных и длинных паролей:** Увеличивает время, необходимое для полного перебора.
- **Ограничение количества попыток:** Блокировка IP-адреса или учетной записи после N неудачных попыток входа. (См. [fail2ban](../../Linux/Security/Tools/fail2ban.md)).
- **[Многофакторная аутентификация (MFA)](./mfa_totp.md):** Требует дополнительного подтверждения (TOTP, биометрия, токен), даже если пароль подобран.
- **Аутентификация по ключам:** Использование [SSH-ключей](../../Linux/Security/ssh/ssh_session_management.md) вместо паролей.
- **Изменение стандартных портов:** Снижает количество автоматических атак на стандартные порты (например, 22 для SSH).
- **Капча (CAPTCHA):** Требует от пользователя доказать, что он не робот.
