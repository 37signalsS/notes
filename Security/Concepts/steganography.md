# Стеганография

## Определение

**Стеганография** — метод скрытой передачи или хранения информации путем её встраивания в другие, не вызывающие подозрений объекты (контейнеры). В отличие от криптографии, которая защищает содержимое сообщения, стеганография скрывает сам факт существования тайного обмена данными.

**Ключевые термины:**
- **Container (Контейнер):** исходный объект (изображение, аудио, видео, текст, сетевой пакет), в который встраивается скрытая информация.
- **Stego-container (Стегоконтейнер):** объект, содержащий скрытое сообщение.
- **Steganographic Key (Стеганографический ключ):** секретный параметр, определяющий алгоритм распределения данных внутри контейнера.
- **Payload (Полезная нагрузка):** скрываемая информация.

## Основные концепции

### Методы встраивания в медиафайлы

| Метод | Описание | Применение |
| :--- | :--- | :--- |
| **LSB** (Least Significant Bit) | Замена наименее значимых битов данных (пикселей, сэмплов) битами сообщения. | BMP, WAV, Lossless видео. |
| **Transform Domain** | Встраивание в коэффициенты математических преобразований (DCT, DWT, Fourier). | JPEG, MP3, MPEG. |
| **Spread Spectrum** | Распределение сигнала сообщения по широкому диапазону частот контейнера. | Водяные знаки, устойчивые к помехам. |

### Современные и специфические подходы

- **Blockchain Steganography:** использование метаданных транзакций (например, поле `OP_RETURN` в Bitcoin или параметры смарт-контрактов) для хранения скрытых записей.
- **Generative Steganography (ИИ):** использование нейросетей (GAN, Diffusion models) для генерации контейнера "с нуля" на основе скрытого сообщения. В этом случае контейнер не подвергается модификации, он изначально создается как носитель.
- **Network Steganography:** использование полей протоколов TCP/IP (TTL, Sequence Numbers, Timestamps) или временных интервалов между пакетами (Jitter) для скрытой передачи.

## Практические сценарии

### Защита авторских прав (Watermarking)
Встраивание невидимых идентификаторов в изображения или видео для отслеживания цепочки распространения контента и доказательства владения.

### Предотвращение утечек (DLP)
Автоматическое нанесение скрытых меток на документы при их выгрузке из корпоративных систем. Позволяет идентифицировать источник утечки даже по фотографии распечатанного документа.

### CTF и кибербезопасность
Анализ подозрительных объектов на наличие скрытых деструктивных модулей или паролей.
Инструменты для анализа:
- **Binwalk:** поиск внедренных файлов и сигнатур.
- **StegSolve:** визуальный анализ цветовых плоскостей.
- **StegVeritas:** автоматизированный набор инструментов для поиска скрытых данных.

### Скрытая коммуникация
Использование в условиях жесткой цензуры или для координации действий (например, встраивание команд управления ботнетом в обычные изображения в соцсетях).

## Дополнительная информация

### Стеганоанализ (Обнаружение)

Стеганоанализ направлен на выявление факта наличия скрытых данных, даже если их невозможно извлечь.

- **Statistical Analysis:** поиск аномалий в распределении значений (RS-анализ, Chi-square attack). Эффективен против простых методов типа LSB.
- **Deep Learning Steganalysis:** использование сверточных нейросетей (CNN), обученных на огромных массивах данных, для обнаружения микроскопических изменений текстур и шумов. Современные архитектуры (например, Yedroudj-Net) превосходят классические статистические методы.

### Сравнение с криптографией

| Характеристика | Криптография | Стеганография |
| :--- | :--- | :--- |
| **Цель** | Скрыть смысл сообщения. | Скрыть факт наличия сообщения. |
| **Заметность** | Высокая (шифротекст выглядит как шум). | Низкая (объект выглядит обыденно). |
| **Стойкость** | Зависит от сложности ключа. | Зависит от незаметности метода. |

**Best Practice:** совместное использование — шифрование данных перед их стеганографическим встраиванием.

### Инструменты управления

- **steghide:** классическая утилита для встраивания в JPEG/BMP/WAV.
- **stegpy:** встраивание в изображения и аудио с использованием Python.
- **OutGuess:** стеганографическая система с упором на противодействие статистическому анализу.
- [stegbrute](../Tools/stegbrute.md): инструмент для автоматизированного подбора паролей к контейнерам `steghide`.
