# MFA (Multi-Factor Authentication) и TOTP (Time-Based One-Time Password)

## 1. Определения

### MFA (Multi-Factor Authentication)

**MFA (Многофакторная аутентификация)** — метод подтверждения личности пользователя, требующий **два или более факторов** из разных категорий:

| Фактор | Что это | Примеры |
|--------|---------|---------|
| **Знание** | Что-то, что знает пользователь | Пароль, PIN-код, ответ на секретный вопрос |
| **Владение** | Что-то, чем владеет пользователь | Смартфон, USB-токен (YubiKey), смарт-карта |
| **Сущность** | Что-то, чем является пользователь | Отпечаток пальца, скан лица, голос, сетчатка |
| **Местоположение** | Где находится пользователь | IP-адрес, GPS-координаты |

### TOTP (Time-Based One-Time Password)

**TOTP (Одноразовый пароль на основе времени)** — алгоритм генерации временных кодов (RFC 6238), основанный на:

- **Секретном ключе** (shared secret) — известен серверу и клиенту
- **Текущем времени** — обычно 30-секундные интервалы
- **HMAC-SHA1** — для генерации кода

Формула: `TOTP = Truncate(HMAC-SHA1(K, T))`, где:

- `K` — секретный ключ
- `T` — временная метка (timestamp // 30)

## 2. Основные концепции

### Как работает TOTP

1. **Начальная настройка:**
   - Сервер генерирует секретный ключ
   - Ключ передаётся пользователю через QR-код или текст
   - Пользователь добавляет ключ в приложение-аутентификатор

2. **Генерация кода:**
   - Приложение берёт текущее Unix timestamp
   - Делит на 30 секунд → получает временной интервал
   - Применяет HMAC-SHA1 к ключу и интервалу
   - Усекает результат до 6-8 цифр

3. **Проверка:**
   - Сервер вычисляет код для текущего и соседних интервалов
   - Сравнивает с введённым пользователем
   - При совпадении — аутентификация успешна

### Различия MFA-методов

| Метод | Тип | Преимущества | Недостатки |
|-------|-----|--------------|------------|
| **TOTP (Google Authenticator, Authy)** | Владение | Оффлайн, нет зависимости от сети | Требует синхронизации времени |
| **SMS/Email коды** | Владение | Простота использования | Уязвимы к перехвату (SIM-swapping) |
| **Push-уведомления** | Владение | Удобство, нет ввода кода | Требует интернета на устройстве |
| **U2F/FIDO2 (YubiKey)** | Владение | Высочайшая безопасность | Стоимость, риск потери |
| **Биометрия** | Сущность | Удобство | Невозможность смены при компрометации |

## 3. Практические сценарии

### Настройка TOTP для приложения

```python
# Пример на Python с использованием pyotp
import pyotp

# Генерация секретного ключа
secret = pyotp.random_base32()

# Создание URI для QR-кода
totp = pyotp.TOTP(secret)
uri = totp.provisioning_uri(
    name="user@example.com",
    issuer_name="MyApp"
)
# uri → генерирует QR-код для Google Authenticator

# Проверка кода
is_valid = totp.verify(user_input_code)
```

### Рекомендации по внедрению

1. **Резервные коды:**
   - Генерируйте 10 одноразовых резервных кодов
   - Показывайте только один раз при настройке
   - Храните хеши, а не plaintext

2. **Grace period:**
   - Принимайте предыдущий код (T-1) на случай рассинхронизации
   - Ограничьте время жизни кода

3. **Резервный метод:**
   - Предлагайте альтернативу при потере устройства
   - Но не через SMS (уязвимость)

## 4. Дополнительная информация

### Безопасность TOTP

- **Оффлайн-генерация:** Код создаётся локально, не требует связи с сервером
- **Нет повторного использования:** Код действителен только в текущем окне
- **Защита от фишинга:** Код привязан к конкретному сервису через секрет

### Уязвимости и митигация

| Угроза | Митигация |
|--------|-----------|
| Фишинг TOTP-кода | Использование WebAuthn/FIDO2 вместо TOTP |
| Кража секретного ключа | Хранение ключей в HSM или зашифрованном виде |
| Рассинхронизация времени | Допуск ±1 временного окна при проверке |
| SIM-swapping | Не использовать SMS как фактор MFA |

### Инструменты

- **Приложения-аутентификаторы:** Google Authenticator, Authy, Microsoft Authenticator, 1Password
- **Библиотеки:** `pyotp` (Python), `speakeasy` (Node.js), `google-authenticator` (Go)
- **Токены:** YubiKey, FIDO2/WebAuthn ключи

### Связанные концепции

- **2FA (Two-Factor Authentication)** — подмножество MFA с ровно двумя факторами
- **HOTP (HMAC-based One-Time Password)** — аналог TOTP, но с счётчиком вместо времени
- **WebAuthn/FIDO2** — современная альтернатива TOTP с криптографической защитой
