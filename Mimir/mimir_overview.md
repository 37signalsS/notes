# Grafana Mimir

**Grafana Mimir** — это горизонтально масштабируемое, высокодоступное и мульти-тенантное решение для долгосрочного хранения метрик, совместимое с [Prometheus](../Prometheus/overview.md). Mimir является частью стека LGTM (Loki, Grafana, Tempo, Mimir) от Grafana Labs.

Mimir позволяет агрегировать метрики из множества кластеров Prometheus и предоставляет единую точку для их запроса, решая проблемы масштабирования и долгосрочного хранения, присущие стандартному Prometheus.

## Архитектура

Архитектура Mimir, как и у других компонентов стека Grafana ([Loki](../Loki/loki_overview.md), [Tempo](../Tempo/tempo_overview.md)), основана на микросервисах и использует объектное хранилище (S3, GCS, MinIO) для данных. Это обеспечивает высокую масштабируемость и отказоустойчивость.

Основные компоненты:

*   **Distributor (Диспетчер):** Принимает метрики от Prometheus через `remote_write` API. Валидирует данные и направляет их на инжестеры.
*   **Ingester (Инжестер):** Получает данные от диспетчера, хранит их в памяти в виде временных рядов и периодически "сбрасывает" сжатые блоки данных (TSDB blocks) в объектное хранилище.
*   **Querier (Запросчик):** Обрабатывает запросы на языке PromQL. Он запрашивает самые свежие данные у инжестеров, а исторические данные — у компонента `store-gateway`.
*   **Query Frontend:** Опциональный компонент для ускорения запросов. Кэширует результаты, разбивает большие запросы и может ставить их в очередь, чтобы избежать перегрузки запросчиков.
*   **Store-Gateway:** "Шлюз" к объектному хранилищу. Он сканирует бакеты на наличие новых блоков данных, загружает метаданные и предоставляет их запросчикам для выполнения исторических запросов.
*   **Compactor (Уплотнитель):** Оптимизирует блоки данных в объектном хранилище, объединяя их и удаляя устаревшие данные. Это ускоряет запросы и экономит место.
*   **Ruler:** Отвечает за выполнение правил записи (recording rules) и алертов (alerting rules) в формате Prometheus.
*   **Alertmanager:** Принимает алерты от Ruler, дедуплицирует их, группирует и отправляет в настроенные каналы уведомлений (Slack, PagerDuty и т.д.).

## Преимущества перед стандартным Prometheus

*   **Горизонтальная масштабируемость:** Все компоненты Mimir можно масштабировать независимо друг от друга.
*   **Долгосрочное хранение:** Использует дешевые объектные хранилища для хранения метрик за длительные периоды (годы).
*   **Высокая доступность:** Репликация данных между компонентами обеспечивает отказоустойчивость.
*   **Глобальный обзор:** Позволяет выполнять запросы к метрикам со всех ваших Prometheus-серверов в одном месте.
