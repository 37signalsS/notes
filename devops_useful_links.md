# Полезные ссылки по DevOps и SRE

- **Cloud Native Landscape (CNCF)**
  Динамическая карта всех проектов экосистемы Cloud Native. Позволяет ориентироваться в огромном количестве инструментов.
  - [https://landscape.cncf.io/](https://landscape.cncf.io/)

## Обучающие платформы и лаборатории

- **KodeKloud**
  Платформа с упором на практические лабораторные работы в браузере. Курсы по Docker, Kubernetes, Terraform, Ansible и др.
  - [https://kodekloud.com/](https://kodekloud.com/)

- **Killercoda**
  Бесплатные интерактивные сценарии по Kubernetes, Linux и инструментам DevOps. Отличная площадка для экспериментов.
  - [https://killercoda.com/](https://killercoda.com/)

- **LabEx**
  Большая коллекция интерактивных лабораторных работ по Linux, программированию и DevOps-инструментам.
  - [https://labex.io/ru](https://labex.io/ru)

- **SadServers**
  Симулятор для отработки навыков устранения неисправностей (Troubleshooting) в Linux-системах в условиях, приближенных к реальным.
  - [https://sadservers.com/](https://sadservers.com/)

- **SREGA.me**
  Тренировки и задачи в формате Capture the Flag (CTF) для системных инженеров.
  - [https://srega.me/](https://srega.me/)

- **Packt Library**
  Цифровая библиотека с доступом к тысячам книг и видеокурсов по ИТ-технологиям.
  - [https://www.packtpub.com/](https://www.packtpub.com/)

## Сертификация

- **CNCF Certifications (CKA, CKAD, CKS, KCNA)**
  Официальные сертификации по Kubernetes и Cloud Native технологиям от Linux Foundation.
  - [https://training.linuxfoundation.org/certification/](https://training.linuxfoundation.org/certification/)

- **HashiCorp Certified (Terraform, Vault, Consul)**
  Сертификации по самым популярным инструментам IaC и управления секретами.
  - [https://www.hashicorp.com/certification](https://www.hashicorp.com/certification)

- **Cloud Provider Certifications (AWS, Azure, GCP)**
  Профессиональные треки от крупнейших облачных провайдеров.
  - AWS: [AWS Training](https://aws.amazon.com/training/)
  - Azure: [Microsoft Learn](https://learn.microsoft.com/en-us/credentials/browse/)
  - GCP: [Google Cloud Training](https://cloud.google.com/training)

## Новости и дайджесты

- **DevOps Weekly**
  Еженедельный дайджест новостей, статей и новых инструментов.
  - [https://www.devopsweekly.com/](https://www.devopsweekly.com/)

- **SRE Weekly**
  Подборка новостей и статей, сфокусированных на надежности и эксплуатации систем.
  - [https://sreweekly.com/](https://sreweekly.com/)

- **KubeWeekly**
  Официальный дайджест от CNCF о новостях экосистемы Kubernetes.
  - [https://www.cncf.io/kubeweekly/](https://www.cncf.io/kubeweekly/)
