# Балансировка нагрузки в Nginx: Дополнительная информация и сравнения

## Definitions

* **`.htaccess`** — распределённый конфигурационный файл Apache, позволяющий управлять настройками на уровне отдельных директорий. Nginx не поддерживает `.htaccess` — вся конфигурация централизована. Подробнее: [Файлы `.htaccess` в Apache](../../../Apache/apache_overview.md#файлы-htaccess).

## Basic Concepts

### Рекомендации по организации конфигурации Nginx

* **Расширения `.conf`:** Для Apache файлы в `sites-available` должны иметь расширение `.conf`, иначе `a2ensite` и Apache могут их игнорировать. Для Nginx это не строгое требование, но рекомендуемая практика.
* **Директории Nginx:** В современных версиях Nginx:
  - `/etc/nginx/conf.d/` — глобальные настройки (включая `upstream`-блоки)
  - `/etc/nginx/sites-enabled/` — конфигурации конкретных сайтов/серверов (`server`-блоки)

### Сравнение подходов к конфигурации: Apache vs. Nginx

| Параметр | Apache | Nginx |
|:---------|:-------|:------|
| Конфигурация на уровне директорий | `.htaccess` — да | Нет |
| Производительность | Снижена из-за чтения `.htaccess` при каждом запросе | Максимальная — конфигурация загружается в память при старте |
| Гибкость для пользователя | Высокая (shared-hosting) | Требует доступа к серверу |
| Изоляция ошибок | Ошибка в `.htaccess` ломает только один сайт | Ошибка в конфиге не применится при `nginx -t` |

Подробное описание: [Файлы `.htaccess` в Apache](../../../Apache/apache_overview.md#файлы-htaccess).

## Practical Scenarios

### Сравнение Nginx с HAProxy

Nginx — универсальный веб-сервер с функцией балансировщика, HAProxy — специализированный балансировщик нагрузки.

| Критерий | Nginx (Open Source) | HAProxy |
|:---------|:--------------------|:--------|
| Алгоритмы балансировки | Базовые (round-robin, least_conn, ip_hash) | Широкий набор: `url_param`, `hdr`, `rdp-cookie`, `uri`, `source` и др. |
| Health checks | Пассивные (реакция на ошибки) | Активные и пассивные |
| Привязка сессий | Сторонний модуль или Nginx Plus/Angie | Встроенная, гибкая |
| Производительность | Высокая | Оптимизирован специально для балансировки |
| Универсальность | Веб-сервер + прокси + балансировщик | Специализированный балансировщик |

**Nginx Plus** (платная версия) предлагает уникальные функции: балансировку по скорости ответа сервера, динамическую реконфигурацию бэкендов, расширенный мониторинг.

### Рекомендации по выбору

| Сценарий | Рекомендуемое решение |
|:---------|:----------------------|
| Один администратор, нужен универсальный инструмент (веб-сервер + реверс-прокси + балансировщик) | Nginx |
| Высоконагруженная система, максимальная гибкость балансировки | HAProxy |
| Shared-hosting с гибкостью `.htaccess` | Связка Apache (бэкенд) + Nginx (фронтенд для статики) |
| Балансировка по скорости ответа, динамическое обновление бэкендов | Nginx Plus |

Подробнее о HAProxy: [Обзор HAProxy](../../../haproxy_overview.md).
