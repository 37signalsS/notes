# PageSpeed Insights

## Два типа данных

### 1. Field Data (Полевые данные, CrUX)

Агрегированные данные от реальных пользователей Chrome за последние 28 дней. **Это самые важные и точные данные**, так как они показывают реальный опыт пользователей и влияют на ранжирование.

### 2. Lab Data (Лабораторные данные)

Результат одного синтетического запуска Lighthouse с серверов Google. Результаты могут быть нестабильны из-за неконтролируемой точки тестирования, и на них следует смотреть с осторожностью.
