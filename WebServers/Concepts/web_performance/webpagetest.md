# WebPageTest — инструмент синтетического тестирования производительности

---
**Reliability Score: 10/10** (SSoT + Проверено по обновлениям Catchpoint/WPT 2026)
---

## Определения

**WebPageTest** — профессиональный инструмент для синтетического (лабораторного) тестирования производительности, обеспечивающий глубокую диагностику в контролируемой среде. С 2025 года полностью интегрирован в платформу **Catchpoint Internet Performance Monitoring (IPM)**.

**SPOF (Single Point of Failure — единая точка отказа)** — ресурс или домен (обычно сторонний: CDN, аналитика, рекламный скрипт), недоступность которого полностью блокирует отрисовку или функциональность страницы.

**No-Code Experiments** — функционал WebPageTest, позволяющий имитировать изменения на странице (удаление скриптов, оптимизация изображений, изменение приоритетов) для проверки их влияния на скорость без физического изменения исходного кода.

## Основные концепции

### Распределённая архитектура

WebPageTest использует сеть реальных устройств и браузеров, расположенных по всему миру. В отличие от эмуляции в браузере, инструмент позволяет имитировать **реальные сетевые потери пакетов** и задержки (jitter), что критично для мобильного веба и HTTP/3.

### Ключевые возможности

* **Мультипротокольный анализ:** Полная поддержка и визуализация **HTTP/3 (QUIC)** в водопадных диаграммах. Выявление проблем с рукопожатием 0-RTT и ALPN.
* **Opportunities & Experiments:** Автоматическое обнаружение проблем (как в Lighthouse) и возможность запустить "эксперимент" для проверки гипотезы исправления в один клик.
* **Визуальный анализ:**
    * **Waterfall (Водопадная диаграмма):** Детальный график загрузки с выделением фаз DNS, TCP, TLS и TTFB.
    * **Filmstrip (Раскадровка):** Покадровая визуализация с возможностью сравнения "Side-by-Side" (например, до и после оптимизации или в режиме SPOF).
* **Синтетическая автоматизация:**
    * **Scheduled Tests:** Планирование регулярных запусков для отслеживания трендов Core Web Vitals (LCP, INP, CLS).
    * **Performance Budgets:** Установка жестких лимитов на размер бандлов или время загрузки.
* **Scripting:** Мощный язык сценариев для тестирования сложных пользовательских путей (авторизация, добавление в корзину).

## Практические сценарии

### Сценарий: Глубокая диагностика Core Web Vitals

1. Выберите локацию, максимально близкую к пользователям, и профиль сети (например, **4G / 9 Mbps**).
2. Запустите тест с **9 прогонами** (рекомендуется для исключения статистических выбросов в 2026 году).
3. В отчете откройте **Web Vitals View**: проанализируйте фазы LCP (Resource Load Delay, Render Delay).
4. Используйте **Filmstrip**, чтобы найти точный кадр, на котором появляется LCP-элемент.

### Сценарий: Тестирование единой точки отказа (SPOF)

1. Перейдите в раздел **Advanced Settings** → вкладка **Block**.
2. Укажите домен критической зависимости (например, `cdn.common-lib.com`).
3. Запустите сравнение с базовым тестом.
4. Если в режиме блокировки страница остается пустой более 3 секунд — выявлена критическая точка отказа.
5. **Решение:** Перенести ресурс на собственный домен или добавить атрибуты `defer`/`async`.

### Сценарий: Автоматизация в CI/CD (GitHub Actions)

1. Установите официальный экшен `webpagetest/github-action`.
2. Настройте проверку при каждом Pull Request:
   ```yaml
   - name: WebPageTest Performance Audit
     uses: webpagetest/github-action@v2
     with:
       apiKey: ${{ secrets.WPT_API_KEY }}
       url: ${{ env.PREVIEW_URL }}
       budget: budget.json
   ```
3. Если изменения кода приводят к нарушению бюджета (например, LCP увеличился более чем на 200мс), билд будет помечен как упавший.

## Дополнительная информация

### Особенности интерпретации результатов

В 2026 году WebPageTest активно использует **AI-инсайты** для интерпретации Waterfall. При анализе следует обращать внимание на "длинные хвосты" (Tail Latency) и загрузку процессора (Main Thread Activity), которые напрямую влияют на метрику **INP**.

### Сравнение с альтернативами

| Характеристика | [Chrome DevTools](./chrome_devtools.md) | [PageSpeed Insights](./pagespeed_insights.md) | **WebPageTest** |
| :--- | :--- | :--- | :--- |
| **Среда** | Локальная | Облачная (Google) | Глобально распределенная |
| **Точность сети** | Эмуляция (Throttle) | Эмуляция | Реальные ограничения / Packet Loss |
| **Тестирование гипотез** | Ручное | Нет | Автоматические Experiments |
| **SPOF анализ** | Базовый | Нет | Продвинутый (Side-by-Side) |
