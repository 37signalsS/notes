# Лучшие практики оптимизации производительности

## Распространённые проблемы

### Блокирующие ресурсы в `<head>`

Каждый CSS и синхронный JS откладывает начало отрисовки.

### Большое количество или объем JS

Длительное выполнение JavaScript блокирует основной поток, делая страницу неинтерактивной.

### Неоптимизированные изображения

Старые форматы и отсутствие сжатия увеличивают время загрузки.

### Динамические элементы (слайдеры)

Могут "обманывать" инструменты тестирования, завышая LCP, так как каждый новый слайд воспринимается как изменение контента.

### Отсутствие Lazy Loading

Загрузка всех изображений, даже тех, что находятся за пределами видимой области, замедляет первоначальную загрузку (`loading="lazy"` в помощь).

### Сторонние скрипты (счетчики, аналитика, реклама)

Могут значительно влиять на производительность. Их код часто раздут и требует много ресурсов. Например, Google Tag Manager может быть "злым" с точки зрения влияния на интерактивность.

## Осторожность с CDN и автоматическими сервисами

* Загрузка критичных ресурсов с медленных CDN или использование сервисов "ускорения в один клик" (включая некоторые функции популярных CDN, например, Cloudflare) может замедлить сайт.
* Часто автоматические сервисы применяют общие, неоптимальные методики.
* **Никогда не доверяйте маркетинговым заявлениям.** Эффективность любого инструмента или сервиса необходимо проверять с помощью детального тестирования (например, через WebPageTest), сравнивая метрики "до" и "после" внедрения.
