# Компрессия контента на веб-сервере

Сжатие текстового контента (HTML, CSS, JS, SVG) — один из самых эффективных способов уменьшения объема данных.

## Алгоритмы

* **Gzip:** Старый, но широко поддерживаемый.
* **Brotli:** Современный, обеспечивает лучшее сжатие (особенно для статики).
* **ZSTD (Zstandard):** Очень высокая скорость сжатия/распаковки, идеален для динамической компрессии.

## Типы компрессии

* **Статическая:** Файлы сжимаются заранее (во время сборки). Идеальный вариант для статических ресурсов.
* **Динамическая:** Контент сжимается "на лету" при каждом запросе.

## Сравнение производительности (динамическое сжатие)

| Алгоритм | Уровень сжатия | Размер файла (КБ) | RPS (запросов/сек) | Примечания |
| :--- | :--- | :--- | :--- | :--- |
| Gzip | 1 | 159 | 130 | Медленнее ZSTD, хуже сжатие, чем Brotli |
| Gzip | 4 | 135 | 100 | Умеренный баланс, но уступает современным |
| Brotli | 3 | 125 | 125 | Хорошее сжатие, приемлемая скорость |
| Brotli | 11 | 94 | 1 | Максимальное сжатие, очень медленно (только для статики) |
| ZSTD | 1 | 140 | 240 | Самый быстрый для динамики, хорошее сжатие |
| ZSTD | 3 | 132 | 215 | Отличный баланс скорости и сжатия для динамики |

## Рекомендации

* Для **статического контента** используйте **Brotli** с максимальной степенью сжатия.
* Для **динамического контента** используйте **ZSTD** на низких уровнях сжатия.
* **Gzip** как запасной вариант.
