# Настройка TLS в Angie

## Определения

**Настройка TLS в Angie** — процесс конфигурации шифрования TLS/SSL для защиты данных, передаваемых между сервером Angie и клиентом. Angie является форком Nginx, поэтому архитектура и большинство механизмов шифрования в них идентичны.

## Основные концепции

Angie наследует TLS-архитектуру Nginx, включая директивы управления сертификатами, протоколами и шифрами. Основным руководством по общей архитектуре TLS, механизмам OCSP Stapling, HSTS и mTLS является документация Nginx:

> **[Оптимальная настройка TLS/SSL в Nginx](../Nginx/Security/TLS_SSL/nginx_tls_ssl_overview.md)**

В данном документе рассматриваются только особенности, характерные для Angie.

### Отличия Angie в области TLS

| Возможность | Nginx | Angie |
|:------------|:------|:------|
| HTTP/3 (QUIC) | Требует сборку с `--with-http_v3_module` | Встроенная поддержка, директива `http3 on` |
| ACME-модуль | Внешний (Certbot, acme.sh) | Встроенный модуль `acme` |
| Лицензирование | Open Source / Plus | Бесплатно + коммерческая лицензия |
| TLS-директивы | Полная совместимость | Полная совместимость |

## Практические сценарии

### Сценарий: Настройка HTTP/3 (QUIC)

Angie обеспечивает нативную поддержку HTTP/3. Конфигурация требует открытия UDP-порта и анонсирования поддержки через заголовок `Alt-Svc`:

```nginx
server {
    # TCP-порт для HTTP/2 и TLS
    listen 443 ssl http2;
    # UDP-порт для QUIC (HTTP/3)
    listen 443 quic reuseport;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    # Включение HTTP/3
    http3 on;

    # Анонсирование поддержки HTTP/3
    add_header Alt-Svc 'h3=":443"; ma=86400';
}
```

**Ключевые директивы:**

- `listen 443 quic reuseport` — прослушивание UDP-порта 443 для QUIC.
- `http3 on` — активация поддержки HTTP/3.
- `Alt-Svc` — заголовок, сообщающий клиенту о доступности HTTP/3.

Подробное описание работы протоколов: [Конфигурация HTTP/2 и HTTP/3 в Nginx](../Nginx/Performance/nginx_http_versions.md).

### Сценарий: Автоматизация сертификатов (ACME)

В отличие от Nginx, Angie содержит встроенный модуль для автоматического получения и обновления сертификатов (например, Let's Encrypt), что избавляет от необходимости использовать Certbot.

Полная конфигурация модуля: [Автоматические TLS-сертификаты в Angie: модуль ACME](./angie_acme_module.md).

### Оптимизация отдачи статики (Kernel TLS)

Механизм Kernel TLS (kTLS) в Angie идентичен Nginx. Он позволяет перенести операции шифрования в ядро ОС для повышения производительности при отдаче статических файлов через `sendfile`.

Настройка и требования: [Оптимизация производительности Nginx — Kernel TLS](../Nginx/Performance/nginx_performance_tuning.md#kernel-tls-ktls).

### Использование DNS-записи HTTPS

Для информирования клиентов о поддержке современных протоколов (H2, H3) рекомендуется использовать специальные DNS-записи.

Описание и примеры: [DNS-записи HTTPS/SVCB](../../Networking/Protocols/DNS/dns_records.md).
