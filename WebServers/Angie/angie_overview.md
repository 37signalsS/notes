# Обзор Angie

## Определения

**Angie** — это эффективный, мощный и масштабируемый веб-сервер, форк Nginx. Создан основной командой разработчиков, покинувшей компанию F5 (владелец Nginx) и основавшей собственную компанию «Веб-сервер». Полностью совместим с Nginx и расширяет его функциональность, предлагая новые возможности и более динамичное развитие.

## Основные концепции

### История и развитие

- **2002–2019:** Создание и развитие Nginx, поглощение компанией F5.
- **2022:** После ухода F5 с российского рынка основная команда разработчиков создаёт форк Angie на базе кода **Nginx 1.23.1** для независимого развития.
- **Октябрь 2022:** Первый публичный релиз Angie.
- **Текущее состояние:** Angie активно развивается, инкорпорируя изменения из Nginx и `free-nginx` (ещё один форк); по числу разработчиков и темпам внедрения новых функций опережает оригинальный проект.

### Модель версионирования

Angie упростил модель версионирования по сравнению с Nginx:

- **Основа:** Angie базируется на последней `mainline` версии Nginx.
- **Релизы:** Новые версии выходят раз в несколько месяцев, все считаются стабильными. Отсутствует разделение на `stable` и `mainline` ветки.
- **Проверка версии:**

  ```bash
  $ angie -v
  angie version: angie 1.8.2
  nginx version: nginx/1.27.3
  ```

### Экосистема продуктов

- **Angie (Open Source):** Бесплатная версия с расширенной функциональностью, включая многие возможности, доступные только в платном Nginx Plus.
- **Angie Pro:** Коммерческая версия с дополнительными функциями (активные health checks, продвинутая балансировка) и технической поддержкой.
- **Anig:** Коммерческий Ingress-контроллер для Kubernetes.

## Практические сценарии

### Мониторинг

- JSON API с доступом к сотням метрик в реальном времени.
- Веб-консоль (Console Lite) для визуального мониторинга.
- Встроенный эндпоинт `/p8s` для интеграции с Prometheus и Grafana.

См. [Мониторинг Angie](./angie_monitoring.md).

### Балансировка нагрузки

- `sticky sessions` — привязка сессии клиента к определённому бэкенду.
- `slow_start` и `drain` — плавный ввод и вывод серверов из балансировки.
- Проксирование по HTTP/3 к бэкендам.

См. [Балансировка нагрузки HTTP(S)](./angie_http_load_balancing.md).

### Автоматизация TLS-сертификатов (ACME)

Встроенный ACME-клиент для автоматического получения и продления сертификатов Let's Encrypt.

См. [Настройка ACME](./angie_acme_module.md).

### Установка модулей

Десятки популярных модулей (Brotli, ModSecurity и др.) доступны из официального репозитория без ручной компиляции.

См. [Установка Angie](./angie_installation.md).

## Дополнительная информация

### Поддержка и миграция

- **Поддержка:** открытый Telegram-чат для связи с разработчиками, коммерческая поддержка в РФ.
