# Обзор Angie

## Определения

**Angie** — это высокопроизводительный, надежный и масштабируемый веб-сервер, являющийся форком [Nginx](../Nginx/Core/nginx_overview.md). Продукт разработан российской компанией ООО «Веб-сервер» командой инженеров, ранее создававших оригинальный Nginx. 

Angie является **drop-in** заменой Nginx: он полностью сохраняет конфигурационный синтаксис, пути и логику работы, при этом значительно расширяя возможности мониторинга, балансировки нагрузки и безопасности, которые в оригинальном проекте доступны только в коммерческой версии Nginx Plus.

## Базовые концепции

### История и импортозамещение

*   **2022 год:** Основание компании ООО «Веб-сервер» и создание форка на базе Nginx 1.23.1. Основная цель — обеспечить независимое развитие продукта и поддержку пользователей в РФ.
*   **Реестр российского ПО:** Программный комплекс Angie (включая версии PRO и Ingress) официально включен в Единый реестр российских программ (запись № 17604).
*   **Совместимость:** Поддерживает сертификацию и работу с отечественными ОС (Astra Linux, РЕД ОС, Альт Линукс).

### Преимущества перед Nginx (Open Source)

Angie переносит многие функции «Enterprise»-уровня в свободную версию:
*   **Нативный мониторинг:** Встроенный REST API и экспорт метрик в формате Prometheus без сторонних экспортеров.
*   **Расширенная балансировка:** Поддержка сессионной привязки (`sticky`) и балансировки по времени ответа (`least_time`).
*   **Современные протоколы:** Нативная поддержка HTTP/3 (QUIC) как для клиентов, так и для проксирования на бэкенды.
*   **MQTT-проксирование:** Специализированные механизмы балансировки для IoT-устройств.

### Модель версионирования

Angie отказался от разделения на ветки `stable` и `mainline`. Каждый публичный релиз является стабильным и рекомендуется для продуктивной среды.
*   **Релизный цикл:** Новые версии выходят примерно раз в квартал.
*   **Проверка версии:**
    ```bash
    $ angie -v
    angie version: angie/1.8.2 (nginx/1.27.3)
    ```

## Практические сценарии

### Мониторинг и наблюдаемость

В отличие от стандартного `stub_status`, Angie предоставляет детальную статистику в JSON через модуль `api`.
*   **Visual Console:** Легковесный веб-интерфейс для контроля состояния апстримов и соединений.
*   **Prometheus:** Нативный эндпоинт `/p8s` для прямого сбора метрик.
Подробнее: [Мониторинг Angie — основные концепции](./angie_monitoring/angie_monitoring_concepts.md).

### Управление трафиком (L7)

*   **Sticky Sessions:** Привязка клиента к конкретному серверу в `upstream` по куки или параметру.
*   **Slow Start:** Постепенное наращивание нагрузки на сервер после его ввода в строй.
*   **HTTP/3 (QUIC):** Полноценная поддержка протокола с возможностью независимой настройки версий для клиента и бэкенда.
Подробнее: [Балансировка нагрузки HTTP в Angie](./angie_http_load_balancing.md).

### Безопасность и автоматизация

*   **Модуль ACME:** Встроенный клиент для автоматического получения и продления сертификатов Let's Encrypt и других удостоверяющих центров.
*   **DNS-over-HTTPS (DoH):** Возможность работы в качестве DoH-сервера или проксирования таких запросов.
Подробнее: [Автоматические TLS-сертификаты в Angie: модуль ACME](./angie_acme_module.md).
