# Обзор Angie

## Определения

**Angie** — это эффективный, мощный и масштабируемый веб-сервер, который является форком Nginx. Он был создан основной командой разработчиков, которые покинули компанию F5 (владелец Nginx) и основали собственную компанию "Веб-сервер". Angie не только полностью совместим с Nginx, но и расширяет его функциональность, предлагая новые возможности и более динамичное развитие.

## Основные концепции

### История и развитие

- **2002-2019:** Создание и развитие Nginx, поглощение компанией F5.
- **2022:** После ухода F5 с российского рынка, основная команда разработчиков Nginx создает форк Angie на основе кода **Nginx 1.23.1** для независимого развития.
- **Октябрь 2022:** Первый публичный релиз Angie.
- **Сегодня:** Angie активно развивается, инкорпорируя изменения из Nginx и `free-nginx` (еще один форк), и по числу разработчиков и темпам внедрения новых функций опережает оригинальный проект.

### Модель версионирования

Angie упростил модель версионирования по сравнению с Nginx:

- **Основа:** Angie всегда базируется на последней `mainline` версии Nginx.
- **Релизы:** Новые версии выходят раз в несколько месяцев, и все они считаются стабильными. Отсутствует путаница между `stable` и `mainline` ветками.
- **Проверка версии:** Команда `angie -V` покажет версию Angie и Nginx, на которой он основан.

    ```bash
    $ angie -v
    angie version: angie 1.8.2
    nginx version: nginx/1.27.3
    ```

## Ключевые возможности и сценарии использования

Многие функции, эксклюзивные для платной версии Nginx Plus, в Angie доступны бесплатно.

### 1. Расширенный мониторинг

- **API в формате JSON:** Удобный доступ к сотням метрик.
- **Веб-консоль (Console Lite):** Веб-интерфейс для мониторинга в реальном времени.
- **Prometheus Exporter:** Встроенный эндпоинт (`/p8s`) для интеграции с Grafana.
- *См. [Мониторинг Angie](./angie_monitoring.md).*

### 2. Продвинутая балансировка нагрузки

- **`sticky sessions`:** Привязка сессий клиента к определенному бэкенду.
- **`slow_start` и `drain`:** Плавный ввод и вывод серверов из балансировки.
- **Проксирование по HTTP/3 к бэкендам.**
- *См. [Балансировка нагрузки HTTP(S)](./angie_http_load_balancing.md).*

### 3. Удобство использования

- **Автоматизация SSL (ACME):** Встроенный клиент для Let's Encrypt. См. [Настройка ACME](./angie_acme_module.md).
- **Готовые пакеты модулей:** Десятки популярных модулей (Brotli, ModSecurity и др.) доступны из репозитория без ручной компиляции. См. [Установка Angie](./angie_installation.md).
- **Упрощенная конфигурация:** Возможность объединения блоков `location`.

## Дополнительная информация

### Поддержка и миграция

- **Поддержка:** Существует открытый Telegram-чат для прямого контакта с разработчиками, а также коммерческая поддержка в РФ.
- **Миграция:** Пакеты Angie не конфликтуют с Nginx, что позволяет установить его параллельно для безопасного тестирования и переноса конфигурации. Подробнее в [руководстве по миграции](./migration_from_nginx.md).

### Экосистема продуктов

- **Angie (Open Source):** Бесплатная версия с расширенной функциональностью.
- **Angie Pro:** Коммерческая версия с дополнительными функциями (активные хелсчеки, продвинутая балансировка) и поддержкой.
- **Anig:** Коммерческий Ingress-контроллер для Kubernetes.
