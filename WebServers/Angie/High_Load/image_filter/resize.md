# Модуль image_filter в Angie: изменение размеров

## Определения

**Resize** — функция изменения размеров изображений с сохранением пропорций.

## Основные концепции

### Параметры resize

## Практические сценарии

### Сценарий 4: Изменение размеров

**Параметры resize:**

```nginx
# Конкретные размеры
image_filter resize 100 100;  # 100x100px

# Только ширина (высота автоматически)
image_filter resize 200 -;    # 200px по ширине

# Только высота (ширина автоматически)
image_filter resize - 150;    # 150px по высоте
```

**Важно:**
- Пропорции сохраняются всегда
- Апскейл (увеличение) не производится — выдается оригинал
- Sharpen рекомендуется при уменьшении (значения 1-3)
