# Модуль image_filter в Angie: изменение размеров

## Определения

**Resize** — операция изменения размеров изображений с сохранением исходных пропорций. Выполняется директивой `image_filter resize` в контексте `location`.

## Базовые концепции

### Принцип работы

Директива `image_filter resize <width> <height>` задаёт целевые размеры изображения. Angie автоматически сохраняет пропорции — изображение вписывается в указанный прямоугольник без искажений.

### Параметры

| Параметр | Описание | Пример |
|:---------|:---------|:-------|
| `<width>` | Целевая ширина в пикселях или `-` (авто) | `200` или `-` |
| `<height>` | Целевая высота в пикселях или `-` (авто) | `150` или `-` |

**Правила:**

- Минимум один параметр должен быть числом (нельзя `image_filter resize - -`)
- Пропорции сохраняются всегда — изображение вписывается в заданные границы
- Апскейл (увеличение) не производится — если оригинал меньше указанных размеров, выдаётся оригинал
- Рекомендуется использовать совместно с `image_filter_sharpen` для повышения резкости при уменьшении

## Практические сценарии

### Конкретные размеры (ширина и высота)

```nginx
location ~* ^/img/(\d+)x(\d+)(/.+\.jpe?g)$ {
    image_filter resize $1 $2;
    image_filter_jpeg_quality 80;
    image_filter_sharpen 1;
}
# → Запрос /img/100x100/photo.jpg вернёт изображение, вписанное в 100x100px
```

### Только ширина (высота автоматически)

```nginx
location ~* ^/img/(\d+)(/.+\.jpe?g)$ {
    image_filter resize $1 -;
    image_filter_jpeg_quality 80;
}
# → Запрос /img/200/photo.jpg вернёт изображение шириной 200px, высота рассчитается пропорционально
```

### Только высота (ширина автоматически)

```nginx
location ~* ^/img/h(\d+)(/.+\.jpe?g)$ {
    image_filter resize - $1;
    image_filter_jpeg_quality 80;
}
# → Запрос /img/h150/photo.jpg вернёт изображение высотой 150px, ширина рассчитается пропорционально
```

## Практические сценарии

### Обрезка (Crop)

Операция `image_filter crop` обрезает изображение по центру. Если вы уменьшаете высоту, обрезка происходит равномерно сверху и снизу (центрирование).

```nginx
location ~* ^/img/crop/(\d+)x(\d+)(/.+\.jpe?g)$ {
    image_filter crop $1 $2;
    image_filter_jpeg_quality 80;
}
```

### Защита от DoS (ограничение размеров)

Использование регулярных выражений вида `(\d+)` позволяет злоумышленникам генерировать бесконечное количество вариантов размеров, что приведет к исчерпанию ресурсов CPU и места в кэше.

**Рекомендуемый подход:** разрешать только фиксированный набор размеров.

```nginx
# Вместо (\d+)x(\d+) используем конкретные значения
location ~* ^/img/(100x100|200x200|400x400)(/.+\.jpe?g)$ {
    # Переменная $1 будет содержать одну из разрешенных строк, 
    # её нужно распарсить или использовать фиксированные значения
    image_filter resize 200 200; # Пример для конкретной локации
}
```

Или использование более строгих регулярных выражений для ограничения диапазонов.

## Дополнительная информация

### Рекомендации по sharpen

При уменьшении изображений рекомендуется повышать резкость для компенсации размытия:

```nginx
image_filter_sharpen 1;   # Лёгкая резкость (рекомендуется для большинства случаев)
image_filter_sharpen 2;   # Средняя резкость (для текста и мелких деталей)
image_filter_sharpen 3;   # Высокая резкость (может вызвать артефакты)
```

Допустимые значения: `0–100`. На практике достаточно `1–3`.

### Особенности работы

- **Пропорции:** Сохраняются всегда. При использовании `resize` изображение вписывается в прямоугольник, при `crop` — заполняет его с обрезкой лишнего.
- **Производительность:** Операция `crop` обычно выполняется чуть быстрее или аналогично `resize`, так как требует схожих вычислительных мощностей.
