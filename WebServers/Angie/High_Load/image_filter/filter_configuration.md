# Модуль image_filter в Angie: конфигурация внутреннего сервера

## Определения

**Image Filter Server** — внутренний экземпляр Angie (обычно работающий на порту 8081 или через unix-сокет), предназначенный исключительно для выполнения ресурсоёмких операций обработки изображений в изолированной среде.

**Внутренняя трансформация** — архитектурный паттерн, при котором запросы на обработку передаются от внешнего фронтенда к внутреннему серверу, что упрощает кэширование и повышает безопасность.

## Базовые концепции

### Роль внутреннего сервера

Использование выделенного сервера для обработки позволяет:
- **Изолировать нагрузку:** Ресурсоемкие операции `resize` и `convert` не блокируют воркеры фронтенда, отвечающие за TLS и доставку статики.
- **Нативная наблюдаемость:** Каждая зона обработки может быть выделена в отдельную `status_zone` для мониторинга в API Angie.
- **Управление ресурсами:** Возможность задать специфичные лимиты буферов и таймаутов для операций фильтрации.

### Основные директивы Angie

| Директива | Описание |
|:----------|:---------|
| `image_filter` | Основная операция: `resize`, `crop`, `rotate` или `convert` (WebP/AVIF/HEIC). |
| `image_filter_jpeg_quality` | Уровень сжатия JPEG (1–100). |
| `image_filter_webp_quality` | Уровень сжатия WebP (1–100). |
| `image_filter_avif_quality` | Уровень сжатия AVIF (1–100) и опционально скорость (0–10). |
| `image_filter_heic_quality` | Уровень сжатия HEIC (1–100). |
| `image_filter_sharpen` | Коэффициент повышения резкости (0–100). |
| `image_filter_buffer` | Лимит памяти на одно изображение (по умолчанию 1M). |

## Практические сценарии

### Комплексная конфигурация внутреннего сервера

Пример конфигурации, поддерживающей современные форматы и нативный мониторинг.

```nginx
server {
    listen 127.0.0.1:8081;
    server_name localhost;

    # Путь к исходным изображениям высокого качества
    root /var/www/images/originals;

    # Общая зона мониторинга для всех операций фильтрации
    status_zone image_filter_backend;

    # 1. Изменение размера JPEG
    location ~* ^/resize/(?<w>\d+)/(?<h>\d+)/(?<file>.+\.jpg)$ {
        alias /var/www/images/originals/$file;
        image_filter resize $w $h;
        image_filter_jpeg_quality 85;
        image_filter_sharpen 1;
        image_filter_buffer 15M;
        
        error_page 415 = @empty;
    }

    # 2. Конвертация в AVIF (оптимально для современных браузеров)
    location ~* ^/convert/avif/(?<file>.+\.(png|jpg))$ {
        alias /var/www/images/originals/$file;
        image_filter convert avif;
        # Качество 60, скорость кодирования 8 (баланс CPU/размер)
        image_filter_avif_quality 60 8;
        image_filter_buffer 20M;
        
        error_page 415 = @empty;
    }

    # 3. Конвертация в HEIC (высокая эффективность сжатия)
    location ~* ^/convert/heic/(?<file>.+\.png)$ {
        alias /var/www/images/originals/$file;
        image_filter convert heic;
        image_filter_heic_quality 75;
        
        error_page 415 = @empty;
    }

    # Возврат пустого изображения при ошибках трансформации
    location @empty {
        default_type image/gif;
        return 200 "\x47\x49\x46\x38\x39\x61\x01\x00\x01\x00\x80\x00\x00\xff\xff\xff\xff\xff\xff\x21\xf9\x04\x01\x00\x00\x00\x00\x2c\x00\x00\x00\x00\x01\x00\x01\x00\x00\x02\x02\x44\x01\x00\x3b";
    }
}
```

## Дополнительная информация

### Наблюдаемость через API Angie

Включение `status_zone` позволяет отслеживать работу внутреннего сервера через дашборд или API:
- `http://127.0.0.1:80/status/http/server_zones/image_filter_backend`
- Отслеживаемые метрики: количество запросов, время ответа бэкенда (фильтра), количество ошибок 415 (Unsupported Media Type).

### Рекомендации по оптимизации

- **Таймауты:** Устанавливайте адекватные `proxy_read_timeout` на фронтенде, так как генерация AVIF большого размера может занимать сотни миллисекунд.
- **Буфер:** Директива `image_filter_buffer` может быть установлена глобально в блоке `server` или переопределена для конкретных форматов (например, больше для тяжелых оригиналов под AVIF).
- **Использование Unix-сокетов:** Для снижения накладных расходов на сетевой стек при работе на одном хосте используйте `listen unix:/var/run/angie_img.sock;`.
