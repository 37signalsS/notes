# Установка и настройка модуля image_filter в Angie

## Определения

**Модуль image_filter** — динамический модуль для Angie, предназначенный для трансформации и конвертации изображений.

## Основные концепции

В отличие от стандартного Nginx, в Angie модуль `image_filter` поставляется в виде готового динамического модуля и обладает расширенными функциями конвертации (WebP, AVIF).

## Практические сценарии

### Шаг 1: Установка пакетов

Модуль устанавливается из официального репозитория Angie.

```bash
# Для Debian/Ubuntu
sudo apt update
sudo apt install angie-module-image-filter
```

### Шаг 2: Подключение внешних библиотек

Для работы форматов WebP и AVIF в системе должны быть установлены соответствующие библиотеки.

- **WebP:** обычно поставляется с библиотекой `libwebp`. На Ubuntu 24.04 доступна «из коробки».
- **AVIF:** требует `libavif`. Если библиотека отсутствует в системе, Angie не сможет кодировать в этот формат.

### Шаг 3: Загрузка модуля в конфигурации

В самом начале основного конфигурационного файла `/etc/angie/angie.conf` добавьте:

```nginx
load_module modules/ngx_http_image_filter_module.so;
```

### Шаг 4: Проверка установки

После редактирования конфигурации проверьте её на ошибки:

```bash
sudo angie -t
```

Если модуль загружен успешно, вы увидите сообщение `syntax is ok`.

## Дополнительная информация

### Особенности для разных ОС

- **Ubuntu 24.04:** Хорошая поддержка WebP, но поддержка AVIF через `libavif` может потребовать установки дополнительных пакетов или отсутствовать в стандартных репозиториях (на момент записи транскрипта).
- **RHEL/CentOS:** Используйте `yum install angie-module-image-filter`.

### Рекомендации

Если вы планируете использовать AVIF, обязательно убедитесь, что версия `libavif` в вашей ОС поддерживает кодирование (encoding), так как некоторые версии библиотек могут поддерживать только декодирование.
