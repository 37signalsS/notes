# Модуль image_filter в Angie: установка и настройка

## Определения

**Модуль image_filter** — динамическое расширение веб-сервера Angie, предназначенное для трансформации изображений (изменение размера, обрезка, поворот) и их конвертации между форматами в режиме реального времени.

## Базовые концепции

В отличие от стандартного Nginx, версия модуля в Angie обладает расширенными возможностями:
- **Нативная поддержка современных форматов:** Чтение и запись WebP, AVIF и HEIC (начиная с версии Angie 1.11.0).
- **Динамическая загрузка:** Модуль поставляется в виде отдельного бинарного пакета и подключается без перекомпиляции основного сервера.
- **Внешние зависимости:** Работа модуля напрямую зависит от системной библиотеки `libgd` и связанных с ней кодеков (`libwebp`, `libavif`, `libheif`).

## Практические сценарии

### Сценарий: Установка пакета модуля

Модуль устанавливается из официальных репозиториев Angie.

```bash
# Для Debian/Ubuntu
sudo apt update
sudo apt install angie-module-image-filter

# Для RHEL/AlmaLinux/Rocky Linux
sudo dnf install angie-module-image-filter
```

### Сценарий: Верификация поддержки форматов

Перед использованием убедитесь, что установленная версия Angie и системные библиотеки поддерживают нужные форматы.

1.  **Проверка версии и флагов сборки:**
    ```bash
    angie -V 2>&1 | grep -E "1.1[1-9]|image_filter"
    # → Должна быть версия >= 1.11.0 и флаг --with-http_image_filter_module
    ```

2.  **Проверка линковки с библиотеками (для HEIC/AVIF):**
    ```bash
    ldd /usr/lib/angie/modules/ngx_http_image_filter_module.so | grep -E "webp|avif|heif"
    # → Должны отображаться пути к соответствующим .so файлам
    ```

### Сценарий: Активация модуля в конфигурации

Для активации добавьте директиву `load_module` в глобальный контекст файла `/etc/angie/angie.conf` (вне блоков `http` или `events`).

```nginx
# Загрузка модуля
load_module modules/ngx_http_image_filter_module.so;

events {
    worker_connections 1024;
}

http {
    # Параметры обработки изображений настраиваются в блоках server/location
    include /etc/angie/http.d/*.conf;
}
```

### Сценарий: Проверка корректности загрузки

После правки конфигурации выполните проверку синтаксиса и перезагрузите сервер:

```bash
sudo angie -t
# → angie: the configuration file /etc/angie/angie.conf syntax is ok
# → angie: configuration file /etc/angie/angie.conf test is successful

sudo systemctl reload angie
```

## Дополнительная информация

### Устранение неисправностей

- **Ошибка "unknown directive image_filter":** Указывает на то, что модуль не был загружен через `load_module` или путь к `.so` файлу указан неверно.
- **Ошибка 415 (Unsupported Media Type):**
    - Размер исходного изображения превышает `image_filter_buffer` (по умолчанию 1M).
    - Формат файла не поддерживается системной библиотекой `libgd`.
- **Проблемы в Docker:** При использовании официальных образов Angie (например, `angie:latest`), дополнительные модули могут отсутствовать. Рекомендуется использовать образы с суффиксом `-buildinfo` для проверки состава или устанавливать модуль вручную в Dockerfile.

### Особенности дистрибутивов

- **Ubuntu 24.04 / Debian 12:** Имеют отличную поддержку AVIF/HEIC "из коробки" в системных репозиториях.
- **RHEL 8/9:** Может потребоваться подключение репозитория EPEL для установки некоторых графических библиотек-зависимостей.
