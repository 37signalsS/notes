# Модуль image_filter в Angie: установка и настройка

## Определения

**Модуль image_filter** — динамический программный компонент для веб-сервера Angie, предоставляющий инструменты для трансформации (resize, crop, rotate) и конвертации изображений на лету.

## Базовые концепции

В отличие от стандартного Nginx, в Angie модуль `image_filter` поставляется в виде готового бинарного пакета и обладает расширенной поддержкой современных форматов (WebP, AVIF).

Для корректной работы модуля необходимо выполнение двух условий:

1. Наличие установленного базового веб-сервера. См. руководство по [установке Angie](../../angie_installation.md).
2. Наличие в операционной системе библиотек для кодирования изображений (`libwebp`, `libavif`).

## Практические сценарии

### Сценарий: Установка пакета модуля

Модуль устанавливается из тех же официальных репозиториев, что и основной веб-сервер.

```bash
# Для Debian/Ubuntu
sudo apt update
sudo apt install angie-module-image-filter

# Для RHEL/AlmaLinux
sudo dnf install angie-module-image-filter
```

### Сценарий: Настройка системных зависимостей

Для поддержки трансформации в форматы WebP и AVIF убедитесь в наличии соответствующих библиотек:

- **WebP:** Требуется `libwebp`. В большинстве современных дистрибутивов (Ubuntu 22.04+) установлена по умолчанию.
- **AVIF:** Требуется `libavif`. Если библиотека отсутствует или не поддерживает кодирование (encoding), операции с форматом AVIF будут недоступны.

### Сценарий: Активация модуля в конфигурации

Модуль является динамическим и должен быть явно загружен до блока `http`. Отредактируйте основной файл конфигурации `/etc/angie/angie.conf`:

```nginx
# Загрузка модуля в начале файла
load_module modules/ngx_http_image_filter_module.so;

events {
    worker_connections 1024;
}

http {
    # Дальнейшая конфигурация...
}
```

После внесения изменений обязательно выполните проверку синтаксиса:

```bash
sudo angie -t
# → angie: the configuration file /etc/angie/angie.conf syntax is ok
```

## Дополнительная информация

### Особенности операционных систем

- **Ubuntu 24.04:** Библиотека `libavif` доступна в стандартных репозиториях, однако рекомендуется проверить поддержку кодирования через инструменты командной строки (например, `avifenc`).
- **Изоляция:** При запуске в Docker используйте образы с тегом `-buildinfo` или проверьте наличие установленного пакета модуля внутри контейнера. См. [запуск Angie в Docker](../../angie_installation.md#сценарий-3-запуск-в-docker-контейнере).
