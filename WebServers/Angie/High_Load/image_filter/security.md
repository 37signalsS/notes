## Практические сценарии

### Сценарий 6: Безопасность и защита от DoS

**Проблема:** Злоумышленник может генерировать запросы с произвольными размерами, вызывая нагрузку на CPU.

**Решение:** Ограничение допустимых размеров:

```nginx
# Разрешенные размеры
map $arg_size $valid_size {
    default 0;
    "100x100" 1;
    "200x200" 1;
    "300x300" 1;
    "400x400" 1;
    "800x800" 1;
}

location ~* ^/img/ {
    if ($valid_size = 0) {
        return 400;
    }

    # Обработка...
}
```

Или использование именованных параметров в regex:

```nginx
location ~* ^/img/(100|200|300|x(100|200|300))(/.+)$ {
    # Только разрешенные размеры
}
```
