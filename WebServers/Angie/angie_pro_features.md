# Возможности коммерческой версии Angie Pro

Angie Pro — это коммерческая версия веб-сервера Angie, предназначенная для корпоративных пользователей и высоконагруженных систем, требующих расширенной функциональности, гарантированной поддержки и соответствия регуляторным требованиям. Angie Pro полностью совместим с Open Source версией, но предоставляет ряд дополнительных возможностей.

## 1. Гарантированная техническая поддержка

Приобретая лицензию Angie Pro, вы получаете прямую техническую поддержку от команды разработчиков. Это включает в себя:
-   Консультации по настройке и оптимизации.
-   Помощь в решении инцидентов с гарантированным временем ответа (SLA).
-   Возможность заказной разработки функционала под нужды вашего проекта.
-   Полное юридическое сопровождение и документооборот в соответствии с законодательством РФ.

## 2. Расширенные возможности балансировки нагрузки

### 2.1. Активные проверки работоспособности (Health Checks)

В отличие от пассивных проверок в Open Source версии, Angie Pro умеет проактивно отправлять специальные запросы на бэкенд-серверы, чтобы проверить их состояние. Это позволяет быстрее обнаруживать неработающие серверы и исключать их из балансировки еще до того, как на них попадут запросы пользователей.

### 2.2. Продвинутые алгоритмы балансировки

-   **`least_time`**: Направляет запрос на сервер, который быстрее всего отвечает. Учитывается не только время соединения, но и время получения первого байта ответа. Этот алгоритм доступен в Nginx Plus и был перереализован в Angie Pro.
-   **`feedback` (на основе обратной связи)**: Более продвинутый алгоритм, который анализирует сразу несколько метрик производительности бэкенда (время ответа, количество ошибок, загрузка) и на основе этого динамически распределяет нагрузку. Считается более эффективным, чем `least_time`.

### 2.3. Очередь запросов (`queue`)

Позволяет поставить запрос в очередь ожидания, если все бэкенд-серверы в `upstream` группе заняты. Это предотвращает немедленный возврат ошибки клиенту и позволяет обработать запрос, как только один из серверов освободится.

### 2.4. Продвинутые режимы `sticky sessions`

В дополнение к режимам `cookie` и `route`, доступным в Open Source, Angie Pro предлагает более интеллектуальные способы привязки сессий:
-   **`sticky learn`**: Angie Pro автоматически создает и управляет сессионными куками для привязки клиента к бэкенду.
-   **`sticky learn remote action`**: Расширение предыдущего режима, которое позволяет "дергать" специальный эндпоинт на бэкенде для создания или валидации сессии.

## 3. Улучшенное управление и мониторинг

-   **Управление `upstream` через API и веб-интерфейс:** Angie Pro позволяет на лету изменять параметры `upstream` серверов (вес, лимиты соединений, статус `up`/`down`/`drain`) через `ng console` или HTTP API без перезагрузки конфигурации.
-   **Расширенная статистика:** В API и консоли доступно больше метрик, включая детальную статистику по времени ответа от апстримов (`response time`).

## 4. Расширенные возможности кэширования

-   **Сегментирование кэша:** Позволяет разделять кэш на сегменты для более гранулярного управления и повышения производительности, например, для распределения кэша по разным дискам.

## 5. Кастомизация

-   **Изменение заголовка `Server`:** Angie Pro позволяет изменять или удалять заголовок ответа `Server: angie`, что может быть полезно для брендирования или сокрытия информации о используемом ПО.

## 6. Соответствие требованиям в РФ

-   **Реестр отечественного ПО:** Angie Pro включен в Единый реестр российских программ для электронных вычислительных машин и баз данных.
-   **Сертификация ФСТЭК:** Продукт имеет сертификаты, позволяющие использовать его в государственных информационных системах и для обработки чувствительных данных.

Этот список может меняться, так как Angie Pro активно развивается. За актуальной информацией обращайтесь к официальной документации и сайту разработчика.
