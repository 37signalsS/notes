# Балансировка нагрузки HTTP в Angie

**Angie** — это форк Nginx, который включает в себя некоторые функции из платной версии Nginx Plus в своей открытой версии. Основы балансировки HTTP-трафика в Angie идентичны Nginx.

**Для получения полной и основной информации о балансировке L7, включая подробное описание архитектуры, всех алгоритмов и директив, обратитесь к основной статье:**
> **[Балансировка нагрузки L7 (HTTP/HTTPS) с помощью Nginx](../Nginx/Proxy/nginx_load_balancing.md)**

Ниже перечислены ключевые возможности, которые доступны в Open Source версии Angie "из коробки" и расширяют функциональность Nginx Open Source.

## Ключевые встроенные функции в Angie

### 1. Встроенный модуль `sticky`
Angie включает в себя полнофункциональный модуль для "прилипания" сессий, который в Nginx Open Source требует установки стороннего модуля. Это позволяет использовать режимы `cookie` и `route` без дополнительной компиляции.

Подробнее см. раздел [Sticky Sessions в основной статье](../Nginx/Proxy/nginx_load_balancing.md#43-sticky-sessions-прилипание-сессий).

### 2. Плавное управление серверами (`slow_start`, `drain`)
-   `slow_start=T`: Позволяет плавно вводить сервер в ротацию, постепенно наращивая его вес от 0 до номинального значения в течение времени `T`. Это защищает "холодные" бэкенды от перегрузки.
-   `drain`: Позволяет плавно выводить сервер из ротации. Angie перестает направлять на него новые запросы (кроме "прилипших"), давая возможность обработать текущие.

### 3. Динамическое разрешение DNS (`resolve`)
Параметр `resolve` у директивы `server` позволяет Angie периодически перечитывать DNS-записи для upstream-серверов, что критически важно для динамических окружений типа Docker или Kubernetes. Эта функция также была перенесена в Nginx Open Source, но исторически появилась в форках, подобных Angie.

### 4. Динамические группы серверов
Angie поддерживает [динамическую конфигурацию upstream-серверов](./dynamic_upstreams.md) с помощью SRV-записей или через API, что упрощает управление бэкендами в автоматизированных средах.
