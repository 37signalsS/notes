# Мониторинг Angie — возможности Angie Pro

## Определения

**Angie Pro** — коммерческая редакция веб-сервера Angie, предназначенная для эксплуатации в критически важных инфраструктурах (Enterprise). Включает расширенный набор инструментов для динамического управления трафиком, глубокого мониторинга состояния и обеспечения высокой доступности, сопоставимый с функционалом Nginx Plus.

## Базовые концепции

### Ключевые отличия мониторинга и управления в версии Pro

| Функция | Angie OSS | Angie Pro |
|:---|:---|:---|
| **API управления** | Чтение / Ограниченная запись | Полнофункциональный REST API (`write=on`) |
| **Активные проверки** | Директива `check` | Директива `health_check` (совместима с Plus) |
| **Хранилище Key-Value** | Нет | Да (`keyval_zone`) |
| **Балансировка** | RR, Least Conn, Least Time | + Dynamic Feedback |
| **Sticky Sessions** | Cookie, Route | Cookie, Route, Learn (расширенно) |
| **Консоль управления** | Console Lite | Console Pro (Enterprise UI) |

### Динамическое управление Upstream и персистентность

В версии Pro реализована поддержка директивы `state`, которая позволяет сохранять все изменения, внесенные через API (смена весов серверов, перевод в `down` или `drain`), в файл на диске. Это гарантирует сохранение актуального состояния балансировщика после перезагрузки сервиса без необходимости ручной правки основного файла конфигурации.

### Нативные активные проверки (`health_check`)

Директива `health_check` в Angie Pro обеспечивает более гибкую настройку по сравнению с модулем `check` в OSS. Она позволяет использовать именованные блоки `match` для валидации ответов бэкенда по множеству параметров:
- Коды состояния (диапазоны).
- Содержимое заголовков (включая регулярные выражения).
- Тело ответа (поиск подстроки или regex).

### Хранилище Key-Value (KV Store)

Angie Pro предоставляет механизм разделяемой памяти для хранения пар ключ-значение. Это позволяет динамически управлять поведением сервера без перезагрузки:
- Управление списками доступа (IP blacklist/whitelist).
- Динамическое ограничение скорости (Rate limiting) по ключам.
- Переключение флагов функциональности (Feature flags) на уровне L7.

### Алгоритм Dynamic Feedback

Интеллектуальный алгоритм балансировки, который автоматически корректирует нагрузку на серверы на основе их текущей производительности. В отличие от статических весов, `feedback` анализирует время ответа и процент ошибок, снижая приоритет деградирующих узлов.

## Практические сценарии

### Сценарий 1: Динамическое управление через API с сохранением состояния

```nginx
http {
    upstream backend_cluster {
        zone backend_cluster 128k;
        # Сохранение динамических изменений состояния на диск
        state /var/lib/angie/backend_cluster.state;
        
        server 10.0.0.1:8080;
        server 10.0.0.2:8080;
    }

    server {
        listen 8888;
        location /api/ {
            api write=on; # Разрешение модификации через API
            allow 127.0.0.1;
            deny all;
        }
    }
}
```

### Сценарий 2: Глубокая проверка состояния с использованием Match

Проверка доступности API, которая ожидает корректный JSON-статус.

```nginx
http {
    match status_ready {
        status 200;
        header Content-Type = application/json;
        body ~ '{"health": "OK"}';
    }

    upstream api_service {
        zone api_service 64k;
        server app1.internal:8443;
        
        # Активная проверка по заданному шаблону
        health_check interval=5s uri=/v1/status match=status_ready;
    }
}
```

### Сценарий 3: Использование Key-Value для динамической блокировки IP

```nginx
http {
    # Объявление KV-зоны на 10 МБ с сохранением на диск
    keyval_zone zone=blocked_ips:10m state=/var/lib/angie/blocked.keyval;
    keyval $remote_addr $target zone=blocked_ips;

    server {
        if ($target) {
            return 403;
        }
        ...
    }
}
```
**Добавление IP в список блокировки через curl:**
```bash
curl -X POST -H "Content-Type: application/json" \
     -d '{"192.168.1.100": "blocked"}' \
     http://localhost:8888/api/v1/http/keyvals/blocked_ips
```

### Сценарий 4: Настройка балансировки по методу Feedback

```nginx
upstream highload_app {
    zone highload_app 128k;
    server srv1.example.com;
    server srv2.example.com;

    # Активация адаптивной балансировки
    feedback;
}
```

## Дополнительная информация

### Console Pro

**Console Pro** — это расширенная версия графического интерфейса, которая дополнительно предоставляет:
- Управление зонами Key-Value через GUI.
- Визуализацию распределения времени ответа (Latency percentiles).
- Детальную статистику по каждой сессии липкой привязки (Sticky sessions).
- Просмотр и фильтрацию активных соединений в реальном времени.

### Совместимость и миграция

Angie Pro обеспечивает полную бинарную и конфигурационную совместимость с Angie OSS. Переход на Pro-версию не требует изменения существующей логики работы, но позволяет заменить сторонние модули (например, `check` или `sticky`) на нативные и более производительные реализации.
