# Мониторинг Angie — Console Lite и API

## Определения

**Angie Console Lite** — встроенный веб-интерфейс для интерактивного мониторинга метрик Angie в режиме реального времени. Позволяет визуализировать данные из HTTP API без необходимости развертывания внешних систем сбора данных.

**HTTP API мониторинга** — программный интерфейс Angie, предоставляющий статистику о работе сервера в формате JSON (JavaScript Object Notation). Включает данные о запросах, соединениях, состоянии upstream-групп, кэше и зонах разделяемой памяти.

## Базовые концепции

### Архитектура взаимодействия

Console Lite представляет собой набор статических файлов (HTML/JavaScript), которые исполняются в браузере пользователя и с заданной периодичностью (по умолчанию — 1 секунда) запрашивают данные у эндпоинта API.

```
┌─────────────┐      ┌──────────────┐      ┌─────────────┐
│   Browser   │─────>│ Console Lite │─────>│  Angie API  │
│  (UI)       │      │  (Static)    │      │  (/status/) │
└─────────────┘      └──────────────┘      └─────────────┘
```

### Безопасность и ограничение доступа

Поскольку API предоставляет доступ к внутренним метрикам инфраструктуры, его публикация в открытый доступ запрещена. Для защиты эндпоинтов используются следующие механизмы:

- **Списки контроля доступа (ACL):** ограничение по IP-адресам через директивы `allow` и `deny`.
- **Шифрование:** использование протокола TLS (Transport Layer Security).
- **Изоляция:** размещение интерфейса мониторинга на отдельном порту или внутреннем адресе.

### Сравнение с Prometheus

| Характеристика | Console Lite / API | Prometheus |
|:---------------|:-------------------|:-----------|
| **Тип данных** | Текущее состояние | Исторические ряды |
| **Обновление** | Реал-тайм (~1 сек) | Интервал сбора (15–60 сек) |
| **Хранение** | Нет (только в памяти) | База данных (TSDB) |
| **Назначение** | Оперативная отладка | Анализ трендов, алертинг |

## Практические сценарии

### Сценарий 1: Установка и базовая настройка

Установка пакета Console Lite производится отдельно от основного веб-сервера.

```bash
# Для Ubuntu/Debian
sudo apt-get install angie-console-lite

# Для RHEL/AlmaLinux
sudo dnf install angie-console-lite
```

Файлы интерфейса размещаются в директории `/usr/share/angie-console-lite/html`.

### Сценарий 2: Настройка эндпоинтов в конфигурации

Для корректной работы консоли необходимо создать `server` блок, в котором будут определены пути к API и статическим файлам.

```nginx
server {
    listen 8888;
    server_name monitor.local;

    # Ограничение доступа только для доверенной сети
    allow 192.168.1.0/24;
    deny all;

    # Интерфейс Console Lite
    location /console {
        alias /usr/share/angie-console-lite/html;
        index index.html;

        # Проксирование запросов консоли к API для обхода CORS
        location /console/api/ {
            api /status/;
        }
    }

    # Эндпоинт API
    location /status/ {
        api;
    }
}
```

### Сценарий 3: Получение метрик через интерфейс командной строки

К API можно обращаться напрямую с помощью утилиты `curl` для автоматизации или быстрой проверки.

```bash
# Получение общего состояния сервера
curl -s http://127.0.0.1:8888/status/ | jq

# Проверка состояния конкретной группы upstream
curl -s http://127.0.0.1:8888/status/upstreams/backend_cluster/ | jq

# Статистика активных соединений
curl -s http://127.0.0.1:8888/status/connections/
# → {"active": 124, "idle": 15, "accepted": 4502, "dropped": 0}
```

## Дополнительная информация

### Версионность и ограничения

- **Версия:** Функционал доступен начиная с версии Angie 1.5.0.
- **История:** Данные не сохраняются после перезапуска сервера или закрытия вкладки браузера.
- **Масштабирование:** При использовании кластера Angie консоль показывает данные только для того узла, к которому выполнен запрос.

### Возможности Angie Pro

В коммерческой версии API поддерживает метод записи (`write=on`), что позволяет динамически управлять параметрами серверов (изменение весов, перевод в `down`) без перезагрузки конфигурации.

Подробнее: [Возможности Angie Pro](./angie_monitoring_pro.md).
