# Мониторинг Angie — Работа с конфигурацией через API

## Определения

**API конфигурации Angie** — интерфейс, позволяющий не только читать метрики, но и получать текущую активную конфигурацию сервера и отслеживать поколения (generation) рабочих процессов. В отличие от `angie -T`, которая читает файлы с диска, API отдаёт конфигурацию, которую Angie использует в данный момент.

## Основные концепции

### Поколения конфигурации (Configuration Generation)

Каждый рабочий процесс Angie (worker process) связан с определённым поколением конфигурации. При выполнении `reload` номер поколения увеличивается. Это позволяет:

- Подтвердить, что изменения конфигурации применились
- Обнаружить старые рабочие процессы, которые не завершились после reload
- Диагностировать проблемы с применением новой конфигурации

## Практические сценарии

### Получение текущей конфигурации

В отличие от `angie -T`, которая парсит файлы с диска, API позволяет получить конфигурацию, которую Angie использует в данный момент. Это полезно для диагностики и восстановления.

```bash
# Получить содержимое angie.conf
curl http://monitor.example.com:8888/status/config_files/angie.conf

# Вся конфигурация в виде JSON
curl http://monitor.example.com:8888/status/config_files/ | jq
```

### Отслеживание поколений конфигурации

Angie отслеживает поколение конфигурации каждого процесса. При `reload` номер поколения увеличивается. Это позволяет отследить, применились ли изменения, и есть ли старые рабочие процессы, которые не завершились.

```bash
# Проверка текущей генерации через API
curl http://monitor.example.com:8888/status/angie/ | jq .generation
# → 5 (номер текущей конфигурации)

# Сравнение с процессами — PID и поколения
ps aux | grep angie
# → angie: worker process (gen=5)
# → angie: worker process (gen=4) ← старый процесс, ещё не завершился
```

Если после reload появляются процессы со старым generation — это сигнал: старые воркеры всё ещё обрабатывают запросы или не смогли корректно завершиться.

### Диагностика проблем с применением конфигурации

```bash
# Получить номер поколения master-процесса
curl -s http://monitor.example.com:8888/status/angie/ | jq '.generation'

# Если generation не изменился после reload — конфигурация не применилась
# Проверьте синтаксис:
angie -t
```

## Дополнительная информация

- Файлы конфигурации через API доступны только при включённой директиве `api` в конфигурации сервера
- Эндпоинт `/status/config_files/` возвращает только те файлы, которые были загружены через динамическую конфигурацию (включая `angie.conf`)
- Поколение конфигурации не сбрасывается при перезапуске сервиса — оно хранится в разделяемой памяти зоны `status`
