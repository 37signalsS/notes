# Мониторинг Angie — Работа с конфигурацией через API

## Определения

**API конфигурации Angie** — интерфейс, позволяющий не только читать метрики, но и получать текущую активную конфигурацию сервера и отслеживать поколения (generation) рабочих процессов. В отличие от команды `angie -T`, которая читает файлы с диска, API отдаёт конфигурацию, которую сервер использует в рантайме.

## Основные концепции

### Поколения конфигурации (Configuration Generation)

Каждый рабочий процесс Angie (worker process) связан с определённым поколением конфигурации. При выполнении операции `reload` номер поколения увеличивается. Это позволяет:

- Подтвердить, что изменения конфигурации успешно применились.
- Обнаружить старые рабочие процессы, которые не завершились после перезапуска.
- Диагностировать проблемы с применением новой конфигурации.

## Практические сценарии

### Получение текущей конфигурации

В отличие от `angie -T`, которая парсит файлы с диска, API позволяет получить конфигурацию, которую Angie использует в данный момент. Это критически важно для диагностики, когда файлы на диске могли быть изменены или удалены после запуска.

```bash
# Получить содержимое angie.conf
curl http://monitor.example.com:8888/status/config_files/angie.conf

# Вся конфигурация в виде JSON
curl http://monitor.example.com:8888/status/config_files/ | jq
```

### Отслеживание поколений конфигурации

Angie отслеживает поколение конфигурации каждого процесса. Это позволяет отследить статус применения изменений.

```bash
# Проверка текущей генерации через API
curl http://monitor.example.com:8888/status/angie/ | jq .generation
# → 5 (номер текущей конфигурации)

# Сравнение с процессами через ОС — PID и поколения
ps aux | grep angie
# → angie: worker process (gen=5)
# → angie: worker process (gen=4) # старый процесс, ещё не завершился
```

Если после `reload` в выводе `ps` остаются процессы со старым `generation` — это сигнал, что старые воркеры всё ещё обрабатывают долгоживущие соединения или не смогли корректно завершиться.

### Диагностика проблем с применением конфигурации

```bash
# Получить номер поколения master-процесса
curl -s http://monitor.example.com:8888/status/angie/ | jq '.generation'

# Если generation не изменился после reload — конфигурация не применилась
# В таком случае следует проверить синтаксис:
angie -t
```

## Дополнительная информация

- **Доступность:** Файлы конфигурации через API доступны только при включённой директиве `api`.
- **Ограничения:** Эндпоинт `/status/config_files/` возвращает только те файлы, которые были загружены через динамическую конфигурацию (включая `angie.conf`).
- **Персистентность:** Поколение конфигурации хранится в разделяемой памяти зоны `status` и не сбрасывается при мягком перезапуске.
