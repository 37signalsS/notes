# Автоматические TLS-сертификаты в Angie: Обзор модуля ACME

Модуль `acme` в Angie — это встроенное решение для автоматического получения и обновления SSL/TLS сертификатов от центров сертификации, использующих протокол ACME (Automated Certificate Management Environment), таких как Let's Encrypt. Это избавляет от необходимости использовать внешние утилиты и интегрирует процесс управления сертификатами непосредственно в конфигурацию веб-сервера.

## 1. Let's Encrypt: Повсеместный HTTPS и бесплатные сертификаты

Let's Encrypt — это некоммерческий центр сертификации, предоставляющий бесплатные SSL/TLS сертификаты. Он был создан при поддержке крупных игроков индустрии (Google, Mozilla и др.) с целью сделать использование HTTPS повсеместным, устранив финансовые и технические барьеры.

### 1.1. Преимущества Let's Encrypt:
*   **Бесплатность:** Основное преимущество, позволяющее владельцам любых сайтов (от хобби-проектов до крупных порталов) использовать шифрование.
*   **Широкая доступность:** Сертификаты Let's Encrypt работают во всех основных операционных системах, браузерах и устройствах.
*   **Поддержка разных типов криптографии:** Поддерживает как традиционные RSA, так и современные эллиптические (ECDSA) сертификаты. Angie может использовать оба типа для максимальной совместимости и производительности.
*   **Wildcard-сертификаты:** Позволяет выпускать Wildcard-сертификаты (например, `*.example.com`), покрывающие неограниченное количество субдоменов третьего уровня.
*   **Короткий срок действия (90 дней):** Сертификаты выдаются на 90 дней. Это сделано для стимулирования автоматизации процесса обновления, что снижает риски в случае компрометации ключей. При правильной настройке автоматизация делает этот процесс прозрачным для пользователя.
*   **Протокол ACME:** Основан на протоколе ACME, который позволяет автоматизировать весь процесс взаимодействия с центром сертификации.

## 2. Методы верификации домена (ACME Challenges)

Для подтверждения владения доменом ACME протокол использует "вызовы" (challenges), позволяющие центру сертификации убедиться, что запрашивающий сертификат действительно контролирует домен.

### 2.1. HTTP-01 Challenge
*   **Принцип:** Центр сертификации предоставляет уникальный токен. Веб-сервер должен разместить этот токен по определенному URL (например, `http://your-domain.com/.well-known/acme-challenge/YOUR_TOKEN`).
*   **Проверка:** Центр сертификации отправляет HTTP-запрос по этому URL. Если он получает ожидаемый токен, владение доменом считается подтвержденным.
*   **Требования:** Веб-сервер должен быть доступен из интернета по 80-му порту. Angie автоматически обрабатывает этот тип проверки "под капотом", устраняя необходимость в ручной настройке `location` блоков.
*   **Ограничения:** Не подходит для Wildcard-сертификатов.

### 2.2. DNS-01 Challenge
*   **Принцип:** Центр сертификации предоставляет токен, который необходимо добавить в виде TXT-записи в DNS-записи вашего домена (например, `_acme-challenge.your-domain.com IN TXT "YOUR_TOKEN"`).
*   **Проверка:** Центр сертификации выполняет DNS-запрос для этой TXT-записи. Если он получает ожидаемый токен, владение доменом считается подтвержденным.
*   **Преимущества:** Подходит для выпуска Wildcard-сертификатов. Не требует доступности веб-сервера по 80-му порту извне.
*   **Особенности:** Требует автоматизированного управления DNS-записями (через API DNS-провайдера) или делегирования DNS. Модуль ACME Angie поддерживает работу в качестве мини-DNS-сервера для таких запросов (`acme_dns_server`) или вызов внешних скриптов (`acme_dns_hook`).

## 3. Преимущества встроенного модуля ACME в Angie

Модуль `acme` в Angie предоставляет ряд существенных преимуществ по сравнению с использованием внешних утилит:
*   **Полная автоматизация:** Angie самостоятельно инициирует получение, продлевает сертификаты и перезагружает конфигурацию для их применения.
*   **Отсутствие внешних зависимостей:** Вся логика встроена в веб-сервер, нет необходимости устанавливать и поддерживать сторонние скрипты или пакеты (например, Certbot, acme.sh).
*   **Простота конфигурации:** Управление сертификатами осуществляется декларативно через директивы в конфигурационных файлах Angie.
*   **Гибкость:** Поддержка обоих методов верификации (`http-01` и `dns-01`) позволяет получать как обычные, так и Wildcard-сертификаты.
*   **Мониторинг:** Информация о процессе получения и обновления сертификатов записывается в `error.log`.

## 4. Ограничения Let's Encrypt и их учет

Let's Encrypt имеет определенные лимиты на количество выдаваемых сертификатов, количество некорректных попыток и т.д. (например, 50 сертификатов на домен в неделю, 5 ошибок авторизации в час). Для тестирования рекомендуется использовать staging-окружение Let's Encrypt, чтобы не исчерпать "боевые" лимиты.

## 5. Альтернативы: Certbot и acme.sh

До появления встроенных решений, таких как модуль ACME в Angie, популярными инструментами для работы с Let's Encrypt были Certbot и acme.sh. Эти утилиты также автоматизируют процесс получения и обновления сертификатов, часто предлагая интеграцию с различными веб-серверами (Certbot) или широкую поддержку DNS-провайдеров через API (acme.sh). Модуль ACME Angie является современной альтернативой, интегрирующей эту функциональность непосредственно в веб-сервер.
