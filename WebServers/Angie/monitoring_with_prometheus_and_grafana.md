# Мониторинг Angie с помощью Prometheus и Grafana

Это руководство описывает процесс настройки мониторинга веб-сервера Angie с использованием Prometheus для сбора метрик и Grafana для их визуализации. В отличие от облачных решений, таких как NGINX Amplify, мониторинг через Prometheus является более независимым и стабильным подходом.

## Шаг 1: Настройка Angie для экспорта метрик

Angie может самостоятельно экспортировать метрики в формате Prometheus без установки дополнительных модулей.

1.  **Убедитесь, что подключен шаблон с метриками.**
    В основном конфигурационном файле `angie.conf` должен быть подключен шаблон `prometheus.conf` или `prometheus_all.conf`, который содержит стандартный набор метрик. Обычно это уже сделано в конфигурации по умолчанию.

2.  **Создайте эндпоинт для метрик.**
    В конфигурацию вашего виртуального хоста (например, `default.conf`) добавьте `location`, который будет отдавать метрики. Рекомендуется ограничить доступ к этому эндпоинту.

    ```nginx
    # Пример добавления location в конфигурацию сайта
    server {
        listen 80;
        server_name your_domain.com;

        # ... другие настройки вашего сайта

        # Эндпоинт для метрик Prometheus
        location = /p8s {
            # Директива prometheus с флагом 'all' подключает все метрики из шаблона
            prometheus all;

            # Ограничьте доступ к эндпоинту для повышения безопасности
            # Пример: разрешить доступ только с localhost
            allow 127.0.0.1;
            deny all;
        }
    }
    ```

3.  **Примените конфигурацию.**
    Проверьте синтаксис и перезагрузите Angie:
    ```bash
    sudo angie -t
    sudo systemctl reload angie
    ```

4.  **Проверьте эндпоинт.**
    Вы должны увидеть текстовый вывод с метриками в формате Prometheus.
    ```bash
    curl http://localhost/p8s
    ```

## Шаг 2: Настройка Prometheus для сбора метрик

Добавьте в конфигурацию Prometheus новую задачу (`job`) для сбора метрик с Angie.

1.  **Отредактируйте конфигурационный файл Prometheus.**
    Откройте `prometheus.yml` (обычно находится в `/etc/prometheus/prometheus.yml`) и добавьте следующий блок в раздел `scrape_configs`:

    ```yaml
    scrape_configs:
      # ... другие ваши jobs (например, node_exporter)

      - job_name: 'angie'
        # Путь к эндпоинту с метриками, который вы настроили в Angie
        metrics_path: /p8s
        static_configs:
          # Список серверов Angie для мониторинга
          - targets: ['localhost:80'] # Замените на IP или домен вашего сервера
    ```
    *   `job_name`: Имя задачи, которое будет присвоено метрикам.
    *   `metrics_path`: Эндпоинт, настроенный на Шаге 1.
    *   `targets`: Адреса ваших серверов с Angie.
    *   Убедитесь, что глобальный `scrape_interval` в Prometheus (обычно 15 секунд) не превышает интервал сбора метрик, чтобы избежать потери данных.

2.  **Перезапустите Prometheus.**
    ```bash
    sudo systemctl restart prometheus
    ```

3.  **Проверьте в веб-интерфейсе Prometheus.**
    Откройте веб-интерфейс Prometheus (по умолчанию `http://<ip_сервера>:9090`). Перейдите в раздел **Status -> Targets**. Вы должны увидеть эндпоинт `angie` в состоянии `UP`.

## Шаг 3: Настройка Grafana и импорт дашборда

1.  **Добавьте Prometheus как источник данных (Data Source).**
    *   Войдите в Grafana (по умолчанию `http://<ip_сервера>:3000`).
    *   Перейдите в **Connections -> Data Sources**.
    *   Нажмите **Add data source** и выберите **Prometheus**.
    *   В поле **Prometheus server URL** укажите адрес вашего Prometheus сервера (например, `http://localhost:9090`).
    *   Нажмите **Save & test**. Вы должны увидеть сообщение об успешном подключении.

2.  **Импортируйте готовый дашборд.**
    Для Angie существует официальный дашборд.
    *   Перейдите в **Dashboards -> New -> Import**.
    *   В поле **Import via grafana.com** введите ID дашборда: `2719`.
    *   Нажмите **Load**.
    *   На следующей странице выберите ваш источник данных Prometheus.
    *   Нажмите **Import**.

После импорта у вас появится готовый дашборд для мониторинга основных показателей Angie.

### Обзор метрик дашборда Angie

Импортированный дашборд предоставляет обширный набор метрик для мониторинга веб-сервера Angie. Все данные собираются напрямую из API, обеспечивая высокую точность и минимальное влияние на производительность.

Ключевые панели дашборда:
*   **Общая статистика:** Активные и новые подключения, версия Angie.
*   **HTTP Zones:** Детальная статистика по зонам, определенным директивой `status_zone`: запросы в секунду, трафик, количество ответов по кодам (2xx, 3xx, 4xx, 5xx).
*   **HTTP Upstreams:** Состояние и метрики для каждой `upstream` группы: статус серверов, количество запросов, ошибки.
*   **Caches:** Статистика по зонам кэширования: коэффициент попадания в кэш (`hit ratio`), использование диска, количество `HIT`/`MISS`.
*   **Shared Zones:** Использование всех зон разделяемой памяти, что помогает контролировать их заполнение.

**Важное замечание:** Одна из ключевых метрик — **время ответа от апстрима (`upstream response time`)** — доступна только в коммерческой версии [Angie Pro](./angie_pro_features.md) и, соответственно, не отображается на дашборде для Open Source версии.
