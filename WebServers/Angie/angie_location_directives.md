# Директивы `location` в Angie

## Определения

**Директива `location`** — фундаментальный элемент конфигурации Angie, определяющий правила обработки HTTP-запросов в зависимости от URI. Она позволяет гибко настраивать маршрутизацию внутри блока `server`.

## Основные концепции

### Совместимость с Nginx

Angie является форком Nginx и **полностью сохраняет** логику работы и синтаксис директивы `location`. Все алгоритмы выбора, модификаторы и приоритеты идентичны Nginx.

Подробный разбор алгоритма выбора наиболее подходящего блока, приоритетов и модификаторов содержится в основном справочнике: [Директива location в Nginx — полный справочник](../Nginx/Core/Location/basics.md).

### Краткий обзор модификаторов

| Модификатор | Тип совпадения | Приоритет |
|:------------|:---------------|:----------|
| `=` | Точное совпадение | Наивысший |
| `^~` | Приоритетный префикс | Высокий (прекращает поиск regex) |
| `~` | Регулярное выражение (регистрозависимое) | Средний (по порядку в файле) |
| `~*` | Регулярное выражение (регистронезависимое) | Средний (по порядку в файле) |
| (нет) | Префиксное совпадение | Низкий (самое длинное совпадение) |

## Практические сценарии

В Angie директива `location` часто выступает "точкой входа" для различных функциональных возможностей.

### Интеграция с функциями Angie

- **Обратный прокси:** использование `proxy_pass` для передачи запросов на бэкенды ([подробнее](./angie_reverse_proxy.md)).
- **Управление трафиком:** настройка редиректов через `return` и `rewrite` ([подробнее](./angie_redirects_and_rewrites.md)).
- **Балансировка:** распределение нагрузки между upstream-группами ([подробнее](./angie_http_load_balancing.md)).
- **Безопасность:** настройка mTLS аутентификации для специфических путей ([подробнее](./angie_client_cert_auth.md)).

### Сценарий: встроенный экспорт метрик Prometheus

Одной из уникальных особенностей Angie является нативная поддержка экспорта метрик в формате Prometheus без использования дополнительных скриптов (njs).

```nginx
location /metrics {
    # Ограничение доступа по IP
    allow 127.0.0.1;
    allow 10.0.0.0/8;
    deny all;

    # Зона для сбора статистики этого location
    status_zone metrics_endpoint;
    
    # Включение экспорта метрик
    prometheus on;
}
```

Подробнее об этом сценарии в [Мониторинг Angie: Prometheus](./angie_monitoring/angie_monitoring_prometheus.md).

## Дополнительная информация

### Рекомендации по использованию

1. **Минимизируйте использование регулярных выражений** — префиксные совпадения (особенно `^~`) работают быстрее и предсказуемее.
2. **Проверяйте синтаксис** перед перезагрузкой: всегда выполняйте `angie -t`.
3. **Единый источник знаний** — для изучения базовой логики и приоритетов всегда используйте справочник по Nginx, так как в Angie она идентична.
