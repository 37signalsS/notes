# Lens: Графический интерфейс для Kubernetes

## 1. Определения

**Lens** — это мощная интегрированная среда разработки (IDE) для Kubernetes, предназначенная для управления кластерами в режиме реального времени. Она предоставляет богатый графический интерфейс, который упрощает взаимодействие с API Kubernetes и визуализирует состояние кластера. Приложение является клиентским и устанавливается на локальную машину (Windows, macOS, Linux).

## 2. Основные концепции

### Ключевые возможности

*   **Управление несколькими кластерами:** Позволяет легко переключаться между различными кластерами из одного интерфейса.
*   **Визуализация ресурсов:** Наглядное отображение всех объектов Kubernetes (поды, деплойменты, сервисы, и т.д.) и их связей.
*   **Метрики в реальном времени:** Встроенная интеграция с [Prometheus](../../Prometheus/prometheus_overview.md) позволяет отображать использование CPU, памяти и сетевых ресурсов для узлов и подов.
*   **Встроенный терминал:** Доступ к оболочке узлов и контейнеров прямо из приложения.
*   **Управление Helm-чартами:** Возможность просматривать, устанавливать и управлять релизами Helm.
*   **Логи контейнеров:** Удобный просмотр логов для одного или нескольких контейнеров одновременно.

### Подключение к кластеру

Lens использует стандартные файлы `kubeconfig` для подключения к кластерам. Чтобы добавить новый кластер:
1.  Найдите ваш `kubeconfig` файл (обычно находится в `~/.kube/config`).
2.  Скопируйте его содержимое.
3.  В Lens нажмите `File > Add Cluster` и вставьте содержимое `kubeconfig`.

При использовании [Kubespray](../Installation/Kubespray/installation.md), файл `admin.conf` можно найти в директории `inventory/имя_кластера/artifacts/`.

## 3. Практические сценарии

### Отображение метрик производительности

По умолчанию после подключения к кластеру метрики производительности (CPU, memory) могут не отображаться с пометкой `metrics not available`.

Для их активации необходимо установить встроенный в Lens стек метрик:
1.  Кликните правой кнопкой мыши на иконку кластера в левой панели.
2.  Выберите **Settings**.
3.  Пролистайте вниз до раздела **Metric Stack**.
4.  Нажмите кнопку **Install**. Lens автоматически развернет в кластере адаптированную версию Prometheus, после чего метрики начнут отображаться в интерфейсе.
