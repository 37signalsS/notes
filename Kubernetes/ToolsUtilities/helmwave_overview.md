### Определения

**Helmwave** — это декларативный инструмент для управления релизами [Helm](./helm_overview.md), написанный на Go. Он позиционируется как более гибкая и мощная альтернатива [Helmfile](./helmfile_overview.md) и следует принципам Infrastructure as Code (IaC).

Ключевая особенность — использование движка шаблонов Go для всей конфигурации, что позволяет реализовывать сложную логику развертывания.

### Основные концепции

1.  **Полная шаблонизация на Go.** В отличие от Helmfile, где шаблонизируются в основном значения, в Helmwave весь конфигурационный файл (`helmwave.yml`) может быть шаблоном. Это позволяет динамически формировать списки релизов, их параметры и зависимости.

2.  **Продвинутое отслеживание ресурсов с `kubedog`.** Helmwave интегрирован с библиотекой `kubedog` от Flant. Эта утилита отслеживает состояние ресурсов Kubernetes в реальном времени, анализируя события и логи подов. Это делает флаги `--wait` и `--atomic` более надежными, чем стандартный механизм Helm.

3.  **Работа с репозиториями.** Инструмент спроектирован для работы с чартами, опубликованными в репозиториях Helm, что стимулирует строгую практику версионирования и публикации.

4.  **Локальный файл состояния.** Команды `build` и `up` создают директорию `.helmwave/`, где хранится сгенерированный план развертывания (state). Это отделяет фазу планирования от фазы применения и обеспечивает предсказуемость операций.

### Практические сценарии

Рабочий процесс включает создание файла `helmwave.yml`, который описывает репозитории, релизы и их зависимости.

**Пример `helmwave.yml`:**
```yaml
# helmwave.yml
version: 0.30.0
project: my-infra
repositories:
  - name: jetstack
    url: https://charts.jetstack.io
releases:
  - name: cert-manager
    namespace: cert-manager
    chart:
      name: jetstack/cert-manager
    version: v1.11.0
    wait: true
```

**Основные команды:**
*   `helmwave build`: Генерирует и отображает план развертывания.
*   `helmwave up`: Применяет план развертывания.
*   `helmwave down`: Удаляет все развернутые релизы.

### Дополнительная информация

Helmwave является более "инженерным" инструментом, который требует понимания Go-шаблонов, но предоставляет мощные возможности для построения сложных и надежных CI/CD-пайплайнов.
