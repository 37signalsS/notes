# kor

## Определения

**`kor`** — это инструмент командной строки (CLI) на Go для обнаружения и удаления неиспользуемых ресурсов в кластере Kubernetes. Он помогает поддерживать чистоту в кластере и сокращать затраты, выявляя ресурсы, не связанные с активными рабочими нагрузками (например, `ConfigMaps`, `Secrets`, `Services`).

## Основные понятия

### Ключевые особенности

* **Широкий охват:** Поддерживает множество типов ресурсов Kubernetes.
* **Интеграция с CI/CD:** Может использоваться в пайплайнах для регулярной очистки кластера.
* **Уведомления:** Интегрируется со Slack для отправки отчетов о найденных неиспользуемых ресурсах.
* **Безопасность:** Позволяет выполнять "сухой запуск" для предварительного просмотра неиспользуемых ресурсов перед их фактическим удалением.

### Установка

Установка `kor` выполняется с помощью `go install`:

```bash
go install github.com/yonahd/kor/cmd/kor@latest
```

## Практические сценарии

### Поиск неиспользуемых ресурсов

* **Вывод всех неиспользуемых ресурсов:**
    (для текущего контекста `kubeconfig`)

    ```bash
    kor --all
    ```

* **Поиск конкретных типов ресурсов:**
    (например, `ConfigMap` и `Secret`)

    ```bash
    kor configmap secret
    ```

### Удаление неиспользуемых ресурсов

Для удаления всех найденных неиспользуемых ресурсов используется флаг `--delete`:

```bash
kor --all --delete
```
