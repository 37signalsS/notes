# Lens: Определения и базовые концепции

## Definitions

**Lens** (теперь **OpenLens** / **Lens Desktop**) — IDE для Kubernetes, предоставляющая графический интерфейс для управления кластерами и визуализации их состояния.

**Важно:** Открытая версия — **OpenLens** (MIT), коммерческая — **Lens Desktop**.

---

## Basic Concepts

### Ключевые возможности

| Возможность | Описание |
| :--- | :--- |
| **Управление несколькими кластерами** | Переключение между кластерами из одного интерфейса |
| **Визуализация ресурсов** | Отображение объектов K8s и их связей |
| **Метрики в реальном времени** | Интеграция с Prometheus для CPU, memory, network |
| **Встроенный терминал** | Доступ к оболочке узлов и контейнеров |
| **Управление Helm-чартами** | Просмотр, установка, обновление релизов |
| **Логи контейнеров** | Просмотр логов для одного или нескольких подов |
| **Редактор манифестов** | Редактирование YAML с подсветкой и валидацией |
| **Расширения** | Поддержка плагинов |
| **Port Forwarding** | Проброс портов с централизованным управлением (Network > Port Forwarding view) |
| **Hotbar** | Панель быстрого доступа к кластерам и ресурсам |
| **Command Palette** | Универсальный поиск и выполнение команд |
| **Security Center** | Сканирование уязвимостей через Trivy Operator (образы, ресурсы, роли) |

### Архитектурные компоненты (современная версия)

| Компонент | Назначение |
| :--- | :--- |
| **Lens Desktop** | Основное десктопное приложение |
| **Lens MCP Server** | Интеграция с Kubernetes и Prometheus через Model Context Protocol |
| **Lens Prism** | AI-ассистент (поддержка OpenAI, Azure, совместимых API) |
| **Lens Teamwork** | Командные пространства с ролевой моделью и управлением кластерами |
| **Lens Security Center** | Сканирование уязвимостей, air-gapped режим, отчёты |
| **Hardened Lens IDE** | Строгое управление доступом к функциям (Feature Management) |

### Поддерживаемые платформы кластеров

- **Локальные** (minikube, kind, k3s и др.)
- **Облачные:** AWS EKS, Azure AKS, Google GKE, Red Hat OpenShift

### Подключение к кластеру

Lens использует стандартные файлы `kubeconfig`.

**Автоматическое обнаружение:** сканирует `~/.kube/config`, все найденные контексты отображаются в списке кластеров.

**Ручное добавление:** `File > Add Cluster` (или `⌘/Ctrl + K`) → вставить содержимое kubeconfig → **Add Cluster**.

**Из файла:** `File > Add Cluster` → выбрать файл kubeconfig → подтвердить.
