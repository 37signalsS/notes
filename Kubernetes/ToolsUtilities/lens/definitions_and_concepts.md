# Lens: Определения и базовые концепции

## Определения

**Lens** (теперь **OpenLens** / **Lens Desktop**) — IDE (Integrated Development Environment — интегрированная среда разработки) для Kubernetes, предоставляющая графический интерфейс для управления кластерами и визуализации их состояния.

**Важно:** Открытая версия — **OpenLens** (распространяется под лицензией MIT), коммерческая — **Lens Desktop**.

---

## Основные концепции

### Ключевые возможности

| Возможность | Описание |
| :--- | :--- |
| **Управление несколькими кластерами** | Переключение между кластерами из одного интерфейса |
| **Визуализация ресурсов** | Отображение объектов Kubernetes (K8s) и их связей |
| **Метрики в реальном времени** | Интеграция с Prometheus для CPU, memory, network |
| **Встроенный терминал** | Доступ к оболочке узлов и контейнеров |
| **Управление Helm-чартами** | Просмотр, установка, обновление релизов |
| **Логи контейнеров** | Просмотр логов для одного или нескольких подов |
| **Редактор манифестов** | Редактирование YAML (Yet Another Markup Language) с подсветкой и валидацией |
| **Расширения** | Поддержка плагинов |
| **Port Forwarding** | Проброс портов с централизованным управлением |
| **Hotbar** | Панель быстрого доступа к кластерам и ресурсам |
| **Command Palette** | Универсальный поиск и выполнение команд |
| **Security Center** | Сканирование уязвимостей через Trivy Operator |

### Архитектурные компоненты (современная версия)

| Компонент | Назначение |
| :--- | :--- |
| **Lens Desktop** | Основное десктопное приложение |
| **Lens MCP Server** | Интеграция с Kubernetes и Prometheus через MCP (Model Context Protocol) |
| **Lens Prism** | AI (Artificial Intelligence — искусственный интеллект) ассистент (поддержка OpenAI, Azure, совместимых API) |
| **Lens Teamwork** | Командные пространства с ролевой моделью и управлением кластерами |
| **Lens Security Center** | Сканирование уязвимостей, air-gapped режим, отчёты |
| **Hardened Lens IDE** | Строгое управление доступом к функциям (Feature Management) |

### Поддерживаемые платформы кластеров

- **Локальные** (minikube, kind, k3s и др.)
- **Облачные:** AWS EKS, Azure AKS, Google GKE, Red Hat OpenShift

## Практические сценарии

Основные сценарии использования, включая установку, подключение к кластерам и настройку мониторинга, подробно описаны в файле [Практические сценарии](./practical_scenarios.md).

Краткий перечень возможностей для практического применения:

- Установка через менеджеры пакетов (Homebrew, Chocolatey, APT)
- Импорт существующих конфигураций kubeconfig
- Визуальное управление ресурсами и Helm-релизами
- Анализ логов и интерактивная работа через терминал
