# Lens: Дополнительная информация

## Определения

**Air-gapped mode** — режим работы Lens в изолированной среде без прямого доступа к интернету. Требует оффлайн-активации и ручного обновления.

**Hardened mode** — режим эксплуатации со строгим управлением функциями (Feature Management) для обеспечения безопасности в корпоративных средах.

**Lens MCP Server (Model Context Protocol)** — встроенный сервер для интеграции Lens с AI-инструментами и внешними системами через стандартизированный протокол.

## Дополнительная информация

### Безопасность

- **Защита kubeconfig:** файлы конфигурации содержат чувствительные данные. Рекомендуется устанавливать права доступа `600` на локальные файлы.
- **RBAC (Role-Based Access Control):** Lens использует права текущего контекста kubeconfig. Для production-кластеров необходимо ограничивать права пользователей (принцип минимальных привилегий).
- **Телеметрия:** сбор данных можно отключить в разделе `Preferences > Application > Telemetry`.

### Интеграции и компоненты

Подробное описание настройки расширений, AI-ассистента, командных пространств и корпоративных SSO-интеграций приведено в файле [Практические сценарии](./practical_scenarios.md).

- **AI-провайдеры (Lens Prism):** поддержка OpenAI, Azure OpenAI и других совместимых API.
- **Lens Cloud:** сервис для синхронизации настроек и управления доступом к кластерам в командах.

### Ограничения

- **Потребление ресурсов:** приложение построено на базе Electron и может занимать значительный объем оперативной памяти при работе с большим количеством кластеров.
- **Функциональность CLI (Command Line Interface):** некоторые сложные или специфические операции Kubernetes по-прежнему требуют использования `kubectl`.
- **Активация:** для использования Lens Desktop требуется Lens ID (онлайн или оффлайн активация).

### Режимы развёртывания

- **Standard mode** — стандартная работа с подключением к интернету для активации и обновлений.
- **Air-gapped mode** — работа в изолированных средах. Поддерживает сканирование Security Center без доступа к внешним базам.
- **Hardened mode** — полное управление доступными функциями через административную панель.

### Альтернативные инструменты

- **Octant** — легковесный инструмент с открытым исходным кодом от VMware (разработка приостановлена).
- **k9s** — терминальный интерфейс (TUI — Terminal User Interface) для быстрого управления кластером.
- **kubectl + vim** — классический метод управления через CLI и текстовые редакторы.
