# kubeswitches

## Определения

`kubeswitches` — это утилита командной строки (CLI) для управления несколькими файлами `kubeconfig` и быстрого переключения между контекстами кластеров Kubernetes. Она обеспечивает организацию конфигурационных файлов для различных кластеров (например, `development`, `staging`, `production`) в отдельных подкаталогах, упрощая переключение активного `kubeconfig`.

## Основные понятия

### Структура каталогов

Для функционирования `kubeswitches` требуется централизованная директория, содержащая подкаталоги для каждого контекста Kubernetes.

Пример структуры:

```
~/.kube/contexts/
├── dev
│   └── config
├── stage
│   └── config
└── prod
    └── config
```

### Переменная окружения

Необходимо определить переменную окружения `KUBESWITCH_CONTEXT_DIR`, указывающую на основную директорию с контекстами.

Пример:

```bash
export KUBESWITCH_CONTEXT_DIR="~/.kube/contexts"
```

### Установка (macOS)

Установка на macOS предполагает загрузку бинарного файла и его размещение в каталоге, доступном в `$PATH`.

Пример команды установки:

```bash
curl -L <URL_на_бинарный_файл> -o kubeswitches
chmod +x kubeswitches
sudo mv kubeswitches /usr/local/bin/
```

### Основные команды

*   `kubeswitches list`: Отображает список всех доступных контекстов из директории, указанной в `KUBESWITCH_CONTEXT_DIR`.
*   `kubeswitches set <имя_контекста>`: Переключает активный `kubeconfig`, копируя файл `config` из выбранного подкаталога в стандартное расположение `~/.kube/config`.
*   `kubeswitches help`: Выводит справочную информацию по командам утилиты.

## Практические сценарии

### Пример использования

1.  Убедитесь в отсутствии файла `~/.kube/config` по умолчанию или создайте его резервную копию.
2.  Выведите список доступных контекстов:
    ```bash
    kubeswitches list
    ```
3.  Выберите и установите требуемый контекст (например, `dev`):
    ```bash
    kubeswitches set dev
    ```
4.  Проверьте успешность переключения контекста с помощью `kubectl`:
    ```bash
    kubectl config view
    ```
    Вывод команды подтвердит детали конфигурации для кластера `dev`.
