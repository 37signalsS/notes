# kubeswitches

`kubeswitches` — это утилита командной строки (CLI) для управления несколькими файлами `kubeconfig` и быстрого переключения между контекстами кластеров Kubernetes.

Основная идея заключается в организации файлов конфигурации для разных кластеров (например, `development`, `staging`, `production`) в отдельных подкаталогах. Утилита позволяет легко переключаться между этими конфигурациями, изменяя активный `kubeconfig`.

## Настройка

1.  **Структура каталогов**:
    Создайте основную директорию, в которой будут храниться конфигурации для разных кластеров. Внутри этой директории создайте подкаталоги для каждого контекста.

    Пример структуры:
    ```
    ~/.kube/contexts/
    ├── dev
    │   └── config
    ├── stage
    │   └── config
    └── prod
        └── config
    ```

2.  **Переменная окружения**:
    Необходимо экспортировать переменную окружения, указывающую на вашу основную директорию с контекстами. В видео автор экспортирует переменную, которая указывает на путь `~/.kube/contexts`.

    ```bash
    export KUBESWITCH_CONTEXT_DIR="~/.kube/contexts"
    ```
    *(Имя переменной `KUBESWITCH_CONTEXT_DIR` является предположением, основанным на анализе).*

## Установка (macOS)

Согласно видео, установка на macOS выполняется с помощью `curl` для скачивания бинарного файла и его перемещения в каталог, доступный в `$PATH`.

```bash
# Примерная команда на основе видео
curl -L <URL_на_бинарный_файл> -o kubeswitches
chmod +x kubeswitches
sudo mv kubeswitches /usr/local/bin/
```

## Основные команды

*   `kubeswitches list`
    Показывает список всех доступных контекстов (имен подкаталогов) из директории, указанной в переменной окружения.

*   `kubeswitches set <имя_контекста>`
    Переключает активный `kubeconfig`. Утилита, скорее всего, копирует файл `config` из выбранного подкаталога (например, `~/.kube/contexts/dev/config`) в стандартное расположение `~/.kube/config`.

*   `kubeswitches help`
    Отображает справочную информацию по командам.

## Пример использования

1.  Убедитесь, что у вас нет файла `~/.kube/config` по умолчанию или сохраните его резервную копию.
2.  Выведите список доступных контекстов:
    ```bash
    kubeswitches list
    ```
3.  Выберите и установите нужный контекст, например `dev`:
    ```bash
    kubeswitches set dev
    ```
4.  Проверьте, что контекст успешно переключился, с помощью `kubectl`:
    ```bash
    kubectl config view
    ```
    Вывод должен показать детали конфигурации для кластера `dev`.
