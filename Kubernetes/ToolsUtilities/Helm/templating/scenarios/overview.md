# Helm Templating Scenarios Overview

---

## Definitions

**Сценарии шаблонизации** — практические примеры применения Helm-шаблонов к типовым задачам: параметризация, условная логика, адаптация под кластер, работа с файлами и конфигурацией.

---

## Basic Concepts

Сценарии сгруппированы по области применения. Каждый файл посвящён одной задаче и содержит практические примеры с пояснениями.

---

## Practical Scenarios

### Основы шаблонизации

[**Параметризация**](./parameterization.md) — вынос хардкода в `values.yaml`, единый источник правды, типы параметров.  
[**Условная логика**](./conditionals.md) — `if/else`, условное создание ресурсов, составные условия с `and`/`eq`.

### Работа с данными и файлами

[**ConfigMap и файлы**](./configmap_files.md) — вставка файлов из `files/` через `.Files.Get`, массовая вставка через `.Files.Glob`, экранирование `{{ }}` обратными кавычками.

### Адаптация под кластер

[**API-версии**](./api_versions.md) — использование `.Capabilities` для адаптации манифестов под версию Kubernetes.  
[**Restart on Change**](./restart_on_change.md) — автоматический rolling update при изменении ConfigMap через checksum-аннотации.

### Инструкции и документация

[**NOTES.txt**](./notes_txt.md) — пост-установочные инструкции пользователю, функция `lookup` для чтения состояния кластера.

### Сетевые политики

[**NetworkPolicy**](./networkpolicy.md) — шаблонизация сетевых политик с именованными шаблонами, условное включение, cross-namespace трафик.
