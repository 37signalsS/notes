# Работа с ConfigMap и файлами

---

## Определения

**.Files** — встроенный объект Helm для чтения файлов из директории чарта (не из `templates/`). Определение и полный список методов — в [Встроенные объекты Helm](../objects.md).

**Экранирование шаблонизатора** — приём с обратными кавычками (`` ` ``) для предотвращения интерпретации пользовательских `{{ }}` в конфигурационных файлах.

---

## Основные концепции

Файл охватывает два практических сценария при работе с ресурсами ConfigMap:

1. **Вставка файлов в ConfigMap** — чтение содержимого из директории `files/` через методы `.Files.Get` и `.Files.Glob`.
2. **Экранирование `{{ }}`** — конфигурационные файлы (например, Postfix, Prometheus) могут содержать синтаксис, конфликтующий с Helm-шаблонизатором.

Оба сценария не дублируют определение объекта `.Files`, а показывают его практическое применение. Ключевые методы объекта:

| Метод | Назначение |
|-------|------------|
| `.Files.Get "path"` | Чтение содержимого файла |
| `.Files.Glob "pattern"` | Поиск файлов по шаблону (паттерну) |
| `.Files.AsSecrets` | Кодирование как Base64 для ресурсов Secret |
| `.Files.AsConfig` | Вставка как данные для ресурса ConfigMap |

Структура чарта для работы с файлами:

```text
chart/
├── files/
│   └── config.json
└── templates/
    └── configmap.yaml
```

Файлы из директории `templates/` **недоступны** через объект `.Files` — они обрабатываются шаблонизатором Helm. Файлы из директории `files/` доступны как сырые (raw) данные.

## Практические сценарии

### Вставка отдельного файла

Чтение файла формата JSON (JavaScript Object Notation):

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: {{ include "myapp.fullname" . }}-config
data:
  config.json: |
    {{ .Files.Get "files/config.json" | nindent 4 }}
```

### Массовая вставка всех файлов из директории

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: {{ include "myapp.fullname" . }}-config
data:
  {{- $files := .Files }}
  {{- range $path, $bytes := .Files.Glob "files/**" }}
  {{ $path | replace "files/" "" }}: |
    {{ $files.Get $path | nindent 4 }}
  {{- end }}
```

Каждый файл из директории `files/` становится отдельным ключом в блоке `data` объекта ConfigMap с именем, равным относительному пути файла.

### Экранирование `{{ }}` в конфигурационных файлах

Файлы вроде Postfix или Prometheus могут содержать конструкции `{{ .Value }}`, которые Helm попытается интерпретировать как шаблон.

**Неправильно (ошибка рендеринга):**

```yaml
data:
  config.file: |
    value = {{ .POSTFIX_VALUE }}
```

**Правильно (использование обратных кавычек):**

```yaml
data:
  config.file: |
    value = `{{` .POSTFIX_VALUE `}}`
```

В итоговом манифесте останется литерал `{{ .POSTFIX_VALUE }}` — Helm не будет его интерпретировать.
