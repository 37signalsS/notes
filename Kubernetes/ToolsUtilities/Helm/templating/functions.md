# Функции Helm-шаблонов

---

## Определения

**Функции Go Templates** — базовые функции движка шаблонов Go (стандартная библиотека `text/template`), такие как `and`, `or`, `not`, `index`, `print`. Они обеспечивают фундаментальную логику и манипуляцию данными.

**Функции Sprig** — библиотека из более чем 100 функций (строковых, математических, коллекционных, криптографических), интегрированная в Helm для расширения возможностей стандартного движка Go.

**Helm-функции** — специализированные функции (`required`, `fail`, `lookup`, `tpl`, `include`), предназначенные для взаимодействия с инфраструктурой Kubernetes и управления процессом рендеринга шаблонов.

---

## Основные концепции

### Конвейеры (Pipelines)

Функции в Helm вызываются либо напрямую, либо через конвейер (`|`). При использовании пайплайна результат предыдущего выражения передаётся в следующую функцию в качестве последнего аргумента.

```yaml
# Использование пайплайна (предпочтительно)
name: {{ .Values.name | default "myapp" | lower | quote }}

# Прямой вызов
name: {{ quote (lower (default "myapp" .Values.name)) }}
```

### Область видимости и контекст (Scope)

Символ точки (`.`) указывает на текущий контекст. Внутри циклов (`range`) и блоков `with` контекст меняется. Для доступа к глобальным объектам (`.Release`, `.Values`) из любой точки шаблона следует использовать префикс `$`.

```go
{{- range .Values.env }}
  - name: {{ .name }}
    value: {{ $.Release.Name | quote }} # Доступ к корню через $
{{- end }}
```

## Ключевые функции по категориям

### Строковые функции

| Функция | Назначение | Пример |
|---------|------------|--------|
| `quote` / `squote` | Оборачивание в двойные/одинарные кавычки | `{{ .Values.val | quote }}` |
| `default` | Значение по умолчанию, если переменная пуста | `{{ .Values.tag | default "latest" }}` |
| `cat` | Объединение строк через пробел | `{{ cat "v" .Chart.AppVersion }}` |
| `trunc` | Обрезка строки (важно для лимитов DNS в K8s) | `{{ .Release.Name | trunc 63 | trimSuffix "-" }}` |
| `trimSuffix` / `trimPrefix` | Удаление суффикса или префикса | `{{ "v1-app" | trimPrefix "v1-" }}` |
| `replace` | Замена всех вхождений подстроки | `{{ "a+b" | replace "+" "-" }}` |
| `lower` / `upper` | Смена регистра символов | `{{ .Values.name | lower }}` |
| `printf` | Форматирование по шаблону (стиль Go/C) | `{{ printf "%s-%s" .Chart.Name .Release.Name }}` |
| `ternary` | Тернарный оператор (условие ? истина : ложь) | `{{ .Values.debug | ternary "on" "off" }}` |
| `coalesce` | Возвращает первый не пустой аргумент | `{{ coalesce .v1 .v2 "fallback" }}` |
| `plural` | Выбор формы слова в зависимости от числа | `{{ .Values.count | plural "item" "items" }}` |

### Коллекции и словари

| Функция | Назначение | Пример |
|---------|------------|--------|
| `dict` | Создание словаря (key-value) | `{{ dict "k1" "v1" "k2" "v2" }}` |
| `list` | Создание списка элементов | `{{ list "a" "b" "c" }}` |
| `index` | Доступ к элементу списка или ключу словаря | `{{ index .Values.data "config.yaml" }}` |
| `has` | Проверка наличия элемента в списке | `{{ if has "prod" .Values.tags }}` |
| `hasKey` | Проверка наличия ключа в словаре | `{{ if hasKey .Values "config" }}` |
| `merge` | Слияние словарей (модифицирует первый) | `{{ merge $dest $src }}` |
| `mergeOverwrite` | Слияние с перезаписью существующих ключей | `{{ mergeOverwrite $dest $src }}` |
| `deepCopy` | Полная копия объекта (защита от мутаций) | `{{ $copy := deepCopy .Values.orig }}` |
| `omit` / `pick` | Исключение или выбор конкретных ключей | `{{ omit $dict "key1" "key2" }}` |
| `set` / `unset` | Установка или удаление значения в словаре | `{{ set $dict "new" "val" }}` |
| `compact` | Удаление пустых элементов из списка | `{{ list "a" "" "b" | compact }}` |
| `uniq` | Удаление дубликатов из списка | `{{ .Values.tags | uniq }}` |

### YAML, JSON и сериализация

| Функция | Назначение | Пример |
|---------|------------|--------|
| `toYaml` | Сериализация объекта в YAML-строку | `{{ toYaml .Values.resources }}` |
| `fromYaml` | Парсинг YAML-строки в объект | `{{ $obj := fromYaml .Values.raw }}` |
| `nindent` | Отступ с новой строкой в начале (рекомендуется) | `{{ toYaml . | nindent 8 }}` |
| `indent` | Только отступ (без новой строки) | `{{ toYaml . | indent 4 }}` |
| `toJson` / `fromJson` | Сериализация и парсинг JSON | `{{ .Values.data | toJson }}` |
| `toToml` | Сериализация в формат TOML | `{{ .Values.config | toToml }}` |

### Helm-специфичные функции

| Функция | Назначение | Пример |
|---------|------------|--------|
| `required` | Обязательный параметр (ошибка при отсутствии) | `{{ required "Field X is required" .Values.X }}` |
| `fail` | Принудительная остановка рендеринга с ошибкой | `{{ if .Values.bad }}{{ fail "Error!" }}{{ end }}` |
| `tpl` | Рендеринг строки как шаблона | `{{ tpl .Values.config . }}` |
| `include` | Вызов именованного шаблона (возвращает строку) | `{{ include "chart.fullname" . }}` |
| `lookup` | Чтение ресурсов напрямую из кластера | `{{ lookup "v1" "Secret" .Namespace "my-sec" }}` |

### Криптография и хеширование

| Функция | Назначение | Пример |
|---------|------------|--------|
| `sha256sum` | Вычисление SHA256 хеша (для аннотаций) | `{{ .Values.config | sha256sum }}` |
| `sha512sum` | Вычисление SHA512 хеша | `{{ .Values.data | sha512sum }}` |
| `b64enc` / `b64dec` | Кодирование и декодирование в Base64 | `{{ .Values.pass | b64enc }}` |
| `genPrivateKey` | Генерация приватного ключа (rsa, ed25519) | `{{ genPrivateKey "rsa" }}` |
| `derivePassword` | Детерминированная генерация пароля | `{{ derivePassword 1 "long" .Pass .User .Site }}` |
| `htpasswd` | Генерация хеша пароля для nginx/apache | `{{ htpasswd .User .Pass }}` |

### Регулярные выражения (Regex)

| Функция | Назначение | Пример |
|---------|------------|--------|
| `regexMatch` | Проверка соответствия шаблону | `{{ if regexMatch "^v[0-9]" .val }}` |
| `regexReplaceAll` | Замена всех совпадений | `{{ .val | regexReplaceAll "\\." "-" }}` |
| `regexFind` | Поиск первой подстроки по шаблону | `{{ regexFind "[0-9]+" .val }}` |

### Математика и даты

| Функция | Назначение | Пример |
|---------|------------|--------|
| `add`, `sub`, `mul`, `div`, `mod` | Арифметика | `{{ add 1 2 }}` |
| `max`, `min`, `floor`, `ceil`, `round` | Округление и сравнение | `{{ max 1 5 10 }}` |
| `until` | Генерация диапазона чисел для циклов | `{{ range until 5 }}` |
| `now` | Текущее время | `{{ now | date "2006-01-02" }}` |
| `dateModify` | Модификация даты (например, `+24h`) | `{{ now | dateModify "+24h" }}` |
| `unixEpoch` | Время в формате Unix timestamp | `{{ unixEpoch now }}` |

### Версионирование

| Функция | Назначение | Пример |
|---------|------------|--------|
| `semverCompare` | Сравнение версий по стандарту SemVer | `{{ if semverCompare ">=1.23-0" .Capabilities.KubeVersion.Version }}` |

## Практические сценарии

### Использование nindent для корректного YAML

Функция `nindent` является «золотым стандартом» для вставки блоков данных, так как она автоматически вставляет символ новой строки перед отступом.

```yaml
spec:
  template:
    spec:
      {{- if .Values.affinity }}
      affinity:
        {{- toYaml .Values.affinity | nindent 8 }}
      {{- end }}
```

### Безопасное слияние с deepCopy

Функции `merge` и `mergeOverwrite` модифицируют свой первый аргумент. Чтобы не повредить глобальный объект `.Values` или другие данные, всегда используйте `deepCopy`.

```go
{{- $config := deepCopy .Values.defaultConfig -}}
{{- $overrides := .Values.overrides -}}
{{- $_ := mergeOverwrite $config $overrides -}}
data:
  {{- toYaml $config | nindent 2 }}
```

### Безопасное использование lookup

Функция `lookup` возвращает `nil` в режимах `helm template` или `--dry-run`. Необходимо всегда предусматривать fallback-логику.

```yaml
{{- $secret := (lookup "v1" "Secret" .Release.Namespace "my-secret") -}}
{{- if $secret }}
password: {{ index $secret.data "password" }}
{{- else }}
password: {{ "default-pass" | b64enc }}
{{- end }}
```

### Динамическая оценка строк (tpl)

Позволяет рендерить значения из `values.yaml` так, как если бы они сами были шаблонами Helm.

```yaml
# values.yaml:
# custom_config: "app-{{ .Release.Name }}"

# template.yaml:
config_name: {{ tpl .Values.custom_config . | quote }}
```

## Дополнительная информация

### Лучшие практики

- **`required` для критических данных**: Всегда помечайте обязательные параметры (пароли, домены), чтобы прервать деплой при их отсутствии.
- **`nindent` вместо `indent`**: Избегайте `indent`, так как он требует ручного управления переносом строки перед вызовом.
- **`trunc 63 | trimSuffix "-"`**: Используйте этот пайплайн для имен ресурсов, чтобы соответствовать стандартам DNS Kubernetes.
- **Валидация через `fail`**: Используйте для сложной логики проверки (например, проверка конфликтующих параметров).

### Устранение неисправностей

| Ошибка | Вероятная причина | Решение |
|--------|-------------------|---------|
| `nil pointer evaluating...` | Обращение к полю несуществующего объекта | Используйте `if` или `default` для проверки наличия данных. |
| `wrong type for value` | Тип данных в пайплайне не соответствует ожидаемому функцией | Проверьте входные данные (например, `toYaml` требует словарь/список). |
| `lookup` возвращает пустой объект | Режим отладки или неверные права RBAC | Помните об ограничениях `--dry-run` и проверьте ServiceAccount. |
| Ошибка парсинга YAML | Неверное количество отступов или лишние пустые строки | Проверьте значение в `nindent` и наличие `{{-` в управляющих блоках. |
