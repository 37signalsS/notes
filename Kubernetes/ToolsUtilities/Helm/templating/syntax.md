# Синтаксис Helm-шаблонов

---

## Определения

**Go templates** — движок шаблонизации, используемый Helm для генерации YAML-манифестов на основе параметров и логики. Основан на стандартной библиотеке Go [`text/template`](https://pkg.go.dev/text/template).

**Контекст (Scope)** — область видимости данных в шаблоне. Текущий контекст обозначается точкой (`.`).

---

## Основные концепции

### Вставка значений и пайплайны

Базовый синтаксис — двойные фигурные скобки `{{ }}`. Результат выражения можно передавать по конвейеру (pipeline) через символ `|`.

```yaml
# Простая вставка
name: {{ .Values.appName }}

# Конвейер функций
name: {{ .Values.name | default "myapp" | lower | quote }}
```

### Управление пробелами (Whitespace control)

Дефис (`-`) внутри тегов удаляет пробелы и переносы строк вокруг блока.

| Синтаксис | Описание |
|-----------|----------|
| `{{ value }}` | Сохраняет все окружающие пробелы |
| `{{- value }}` | Удаляет пробелы слева (включая переносы строк) |
| `{{ value -}}` | Удаляет пробелы справа |
| `{{- value -}}` | Удаляет пробелы с обеих сторон |

### Комментарии

Комментарии в шаблонах не попадают в итоговый отрендеренный YAML.

```go
{{/* Это многострочный 
   комментарий Helm */}}
{{- /* Комментарий с удалением пробелов */ -}}
```

### Переменные

Переменные объявляются с префиксом `$` и оператором `:=`. Они полезны для сохранения значений и использования их в разных областях видимости.

```go
{{- $relName := .Release.Name -}}
release: {{ $relName }}
```

### Глобальный контекст ($)

Символ `$` всегда ссылается на корневой контекст (объект верхнего уровня). Это критично при работе внутри циклов `range` или блоков `with`, где точка (`.`) меняет свое значение.

```go
{{- range .Values.items }}
  # . ссылается на текущий элемент списка
  item: {{ . }}
  # $ ссылается на корень для доступа к .Release или .Values
  release: {{ $.Release.Name }}
{{- end }}
```

### Группировка выражений

Скобки `()` используются для управления приоритетом выполнения функций или группировки логики.

```go
# Сначала выполняется конкатенация, затем quote
name: {{ (printf "%s-%s" .Release.Name .Chart.Name) | quote }}
```

## Управляющие конструкции

### Условные переходы (if / else)

Блок выполняется, если условие истинно.

**Правила истинности (Truthiness):**
В Helm `false` — это:
- Булево `false`
- Числовой `0`
- Пустая строка `""`
- `nil` (null)
- Пустая коллекция (список или словарь)

Все остальные значения считаются `true`.

```yaml
{{- if .Values.metrics.enabled }}
# Метрики включены
{{- else if .Values.metrics.legacy }}
# Используется старый формат
{{- else }}
# Метрики отключены
{{- end }}
```

**Логические операторы:** `and`, `or`, `not`, `eq`, `ne`, `lt`, `le`, `gt`, `ge`.

### Изменение контекста (with)

Блок `with` устанавливает точку (`.`) на указанный объект. Если объект пустой (см. правила Truthiness), блок не рендерится.

```yaml
{{- with .Values.resources }}
resources:
  limits:
    cpu: {{ .limits.cpu }}
{{- else }}
resources: {}
{{- end }}
```

### Циклы (range)

Используется для итерации по спискам и словарям.

```yaml
# Итерация по словарю (ключ + значение)
env:
{{- range $name, $value := .Values.envVars }}
  - name: {{ $name }}
    value: {{ $value | quote }}
{{- end }}

# Итерация по списку элементов
args:
{{- range .Values.args }}
  - {{ . | quote }}
{{- end }}
```

## Практические сценарии

### Использование глобального контекста в цикле

```yaml
{{- range .Values.services }}
---
apiVersion: v1
kind: Service
metadata:
  name: {{ .name }}
  namespace: {{ $.Release.Namespace }} # Доступ к корню через $
spec:
  selector:
    app.kubernetes.io/instance: {{ $.Release.Name }}
{{- end }}
```

### Сложные условия с группировкой

```yaml
{{- if or (and .Values.ingress.enabled .Values.ingress.host) .Values.ingress.force }}
host: {{ .Values.ingress.host | default "localhost" }}
{{- end }}
```

### Объявление переменных для упрощения путей

```yaml
{{- $labels := .Values.commonLabels -}}
metadata:
  labels:
    {{- range $k, $v := $labels }}
    {{ $k }}: {{ $v | quote }}
    {{- end }}
```

## Дополнительная информация

### Лучшие практики

- **Минимизация пустых строк**: Используйте `{{-` в начале управляющих конструкций (`if`, `range`, `with`).
- **Явное приведение типов**: Используйте функции `toString`, `toInt` при необходимости.
- **Экранирование строк**: Всегда используйте `quote` для строковых значений из `.Values`, чтобы избежать ошибок парсинга (например, когда строка похожа на число или `true`).
- **Проверка на существование**: Используйте `if .Values.key` перед обращением к вложенным полям, если они могут отсутствовать.

### Устранение неисправностей

| Ошибка | Вероятная причина | Решение |
|--------|-------------------|---------|
| `nil pointer evaluating...` | Обращение к полю несуществующего объекта | Используйте `with` или `if` для проверки родительского объекта |
| `can't evaluate field... in type string` | Попытка обратиться к полю `.Values` внутри `range` без `$` | Используйте `$.Values` для доступа к глобальному контексту |
| Лишние отступы в YAML | Неверное использование `nindent` или пробелов | Проверьте количество пробелов в `nindent <N>` и наличие `{{-` |
| Ошибка парсинга YAML | Переменная содержит спецсимволы без кавычек | Добавьте пайплайн `| quote` |
