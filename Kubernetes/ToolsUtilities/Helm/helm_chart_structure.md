# Структура Helm-чарта

### Определения

**Helm-чарт (Chart)** — это пакет преднастроенных ресурсов Kubernetes, упакованных для удобного управления и развертывания с помощью [Helm](./helm_overview.md). Физически представляет собой архив (`.tgz`) или директорию со стандартизированной структурой файлов.

### Основные концепции

Стандартизированная структура каталогов и файлов чарта является ключевым элементом, обеспечивающим его переиспользуемость и предсказуемость.

#### Ключевые файлы и директории

*   **`Chart.yaml`**
    *   **Назначение:** Файл с метаданными о чарте. Является обязательным.
    *   **Основные поля:**
        *   `apiVersion`: Версия API чарта (для Helm 3+ это `v2`).
        *   `name`: Имя чарта.
        *   `version`: Версия самого чарта в формате [семантического версионирования](https://semver.org/).
        *   `appVersion`: Версия приложения, которое разворачивается этим чартом.
        *   `description`: Краткое описание назначения чарта.
        *   `maintainers`: Список ответственных за разработку и поддержку чарта.

*   **`values.yaml`**
    *   **Назначение:** Файл со значениями по умолчанию для переменных, используемых в шаблонах. Позволяет пользователям настраивать чарт без изменения его шаблонов, переопределяя значения при установке или обновлении.

*   **`templates/`**
    *   **Назначение:** Директория, в которой хранятся все [шаблонизированные](./helm_templating.md) манифесты Kubernetes (например, `deployment.yaml`, `service.yaml`, `ingress.yaml`). Helm рендерит файлы из этой директории, подставляя в них значения из `values.yaml`.

*   **`charts/`**
    *   **Назначение:** Директория для зависимостей — других чартов, от которых зависит текущий чарт. Зависимости указываются в файле `Chart.yaml` в секции `dependencies` и могут быть автоматически загружены с помощью команды `helm dependency update`.

*   **`templates/NOTES.txt`**
    *   **Назначение:** Текстовый файл, содержимое которого выводится пользователю после успешной установки чарта. Используется для отображения инструкций по дальнейшим действиям (например, как получить доступ к приложению).

### Практические сценарии

#### Создание нового чарта

Команда `helm create` генерирует бойлерплейт-чарт с полной структурой, готовый к наполнению.

```bash
helm create my-new-chart
```

Эта команда создаст директорию `my-new-chart` со всеми необходимыми файлами и поддиректориями, включая примеры `Deployment`, `Service`, `Ingress` и тестов. Подробнее о процессе шаблонизации см. в [соответствующем разделе](./helm_templating.md).

### Дополнительная информация

*   **Хуки и тесты:** В директории `templates/` также могут располагаться ресурсы для [хуков и тестов](./helm_hooks_and_tests.md), которые выполняются на определенных этапах жизненного цикла релиза.
*   **Игнорируемые файлы:** Файл `.helmignore` позволяет указать, какие файлы и директории не должны включаться в пакет чарта.
