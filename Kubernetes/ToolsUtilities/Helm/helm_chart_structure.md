# Структура Helm-чарта

### Определения

**Helm-чарт (Chart)** — это пакет преднастроенных ресурсов Kubernetes, упакованных для удобного управления и развертывания с помощью [Helm](./helm_overview.md). Физически представляет собой архив (`.tgz`) или директорию со стандартизированной структурой файлов.

### Основные концепции

Ключевым элементом, обеспечивающим переиспользуемость и предсказуемость чарта, является его стандартизированная структура, включающая следующие компоненты:

* **`Chart.yaml`**: Обязательный файл с метаданными, включающими `apiVersion`, `name`, `version` (версия чарта), `appVersion` (версия приложения) и `description`.
* **`values.yaml`**: Файл со значениями по умолчанию для переменных, используемых в шаблонах. Позволяет настраивать чарт без изменения его кода.
* **`templates/`**: Директория для [шаблонизированных](./helm_templating.md) манифестов Kubernetes (`deployment.yaml`, `service.yaml`). Helm генерирует финальные манифесты, подставляя значения из `values.yaml`.
* **`charts/`**: Директория для зависимостей (subcharts). Зависимости объявляются в `Chart.yaml` и могут быть загружены командой `helm dependency update`.
* **`templates/NOTES.txt`**: Шаблон, содержимое которого выводится пользователю после успешной установки чарта для отображения инструкций.

### Практические сценарии

**Создание нового чарта**

Для генерации стандартной структуры чарта используется команда `helm create`.

```bash
helm create my-new-chart
```

Эта команда создает директорию `my-new-chart` со всеми необходимыми файлами и подкаталогами, включая примеры `Deployment`, `Service`, `Ingress`, а также заготовки для тестов. Процесс шаблонизации подробно описан в [соответствующем разделе](./helm_templating.md).

### Дополнительная информация

* **Хуки и тесты**: В директории `templates/` могут располагаться ресурсы для [хуков и тестов](./helm_hooks_and_tests.md), выполняемых на определенных этапах жизненного цикла релиза.
* **Игнорируемые файлы**: Файл `.helmignore` используется для исключения файлов и директорий из пакета чарта.
