## Basic Concepts

### Оркестрация Helm-релизов

Для декларативного управления множеством Helm-релизов в парадигме Infrastructure as Code используются специализированные инструменты. [Helmfile](../helmfile_overview.md) — популярный оркестратор, использующий `helmfile.yaml` для описания желаемого состояния релизов. Альтернативный вариант — [Helmwave](../helmwave_overview.md), которая использует Go-шаблоны для всей конфигурации, обеспечивая максимальную динамичность.

### Расширение функциональности через плагины

Функциональность Helm расширяется с помощью плагинов. Один из наиболее востребованных — [helm-diff](../helm_plugins.md#helm-diff), позволяющий просматривать изменения перед применением обновления.

### Интеграция с другими инструментами

Продвинутые сценарии часто включают интеграцию Helm с [Kustomize](../../kustomize/kustomize_overview.md) для наложения окруженческих патчей на сгенерированные манифесты, а также использование [базовых команд Helm](../helm_commands_and_workflow.md) в составе CI/CD-пайплайнов.
