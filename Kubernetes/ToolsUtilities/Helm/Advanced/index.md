# Продвинутые возможности Helm

## Определения

**Продвинутые возможности Helm** охватывают расширенные сценарии управления инфраструктурой, включая создание кастомных репозиториев, использование декларативных оркестраторов (Helmfile, Helmwave), интеграцию с Kustomize, а также применение паттернов безопасности и стандартизации.

---

## Основные концепции

### Оркестрация Helm-релизов

Для управления множеством релизов в парадигме Infrastructure as Code (IaC) используются внешние инструменты, обеспечивающие декларативность и предсказуемость:

- **[Helmfile](../helmfile_overview.md)** — популярный оркестратор на базе YAML-конфигурации.
- **[Helmwave](../helmwave_overview.md)** — Go-инструмент с поддержкой шаблонизации всей конфигурации, обеспечивающий максимальную динамичность.

### Расширяемость через плагины

Функциональность Helm дополняется плагинами для специфических задач. Один из наиболее востребованных — **[helm-diff](../helm_plugins.md#helm-diff)**, позволяющий визуализировать планируемые изменения в кластере перед их применением. Подробнее см. **[Плагины Helm](../helm_plugins.md)**.

### Интеграция с инструментами конфигурации

Использование Helm совместно с **[Kustomize (Обзор и основные концепции)](../../kustomize/kustomize_overview.md)** позволяет разделить логику шаблонизации и специфические настройки окружений, накладывая патчи на сгенерированные манифесты.
