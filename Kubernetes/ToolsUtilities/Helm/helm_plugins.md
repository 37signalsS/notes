# Плагины Helm

---

## Определения

**Плагин (Plugin)** — скрипт или исполняемый файл, расширяющий функциональность `helm` CLI, но не являющийся частью основного кода.

---

## Основные концепции

### Управление плагинами

Управление плагинами осуществляется с помощью встроенных команд `helm plugin`:

* **Установка:**

    ```bash
    helm plugin install <path|url>
    ```

    Плагин может быть установлен из локальной директории или по URL (например, из GitHub-репозитория).

* **Просмотр списка:**

    ```bash
    helm plugin list
    ```

* **Обновление:**

    ```bash
    helm plugin update <plugin_name>
    ```

* **Удаление:**

    ```bash
    helm plugin uninstall <plugin_name>
    ```

## Практические сценарии

#### `helm-diff`: Предпросмотр изменений

**Назначение:** `helm-diff` показывает `diff` между текущим состоянием релиза и тем, что будет применено после `helm upgrade`. Это незаменимый инструмент для безопасного развертывания, позволяющий избежать случайных или некорректных изменений.

**Использование:**

```bash
# Показать diff для обновления релиза
helm diff upgrade my-release ./my-chart -f values.yaml

# Показать diff для отката релиза
helm diff rollback my-release 1

# Сравнить две ревизии релиза
helm diff revision my-release 1 2
```

#### `helm-monitor`: Мониторинг и автоматический откат

**Назначение:** `helm-monitor` отслеживает состояние релиза после развертывания, используя запросы к системам мониторинга (Prometheus, Elasticsearch). Если метрики указывают на проблему (например, рост 5xx ошибок), плагин автоматически выполняет `helm rollback`.

**Использование с Prometheus:**

```bash
# Мониторить релиз, откатываясь при росте 5xx-ошибок
helm monitor prometheus \
  --prometheus=http://prometheus:9090 \
  my-release \
  'rate(http_requests_total{code=~"^5.*$"}[5m]) > 0'
```

## Дополнительная информация

### `helm 2to3`: Миграция с Helm v2

**Назначение:** Плагин `helm 2to3` был создан для миграции релизов и конфигурации из Helm v2 в Helm v3.

**Статус:** **Устарел.** Helm v2 был официально признан устаревшим в ноябре 2020 года. Этот плагин больше не поддерживается и актуален только для тех, кто работает с унаследованными системами.
