# Calico HostEndpoint и GlobalNetworkPolicy

**Calico** расширяет стандартные сетевые политики Kubernetes, предоставляя возможности управления трафиком на уровне узлов и всего кластера.

> Основная документация: [NetworkPolicy: Сетевая безопасность](../../network_policies.md)

## Определения

**HostEndpoint** — ресурс Calico, представляющий один или несколько сетевых интерфейсов на узле Kubernetes. Позволяет применять политики безопасности к трафику узла до того, как он достигнет уровня Pod'ов, создавая **периметральный файрвол** для всего кластера.

**GlobalNetworkPolicy** — кластерная сетевая политика Calico, область действия которой распространяется на все namespace. В отличие от стандартного `NetworkPolicy`, она поддерживает:
- Селекторы на уровне узлов (`HostEndpoint`)
- Приоритеты выполнения (`order`)
- Фильтрацию до применения NAT (`preDNAT`)
- Логирование заблокированного трафика

**Felix** — агент Calico, работающий на каждом узле кластера. Felix отвечает за применение сетевых политик через механизмы `iptables` или `eBPF`.

## Основные концепции

### Поведение по умолчанию: Deny All

При создании `HostEndpoint` для конкретного интерфейса Calico немедленно активирует правило **"запретить весь трафик"** для этого интерфейса.
**Важное предупреждение:** Чтобы избежать потери доступа к узлу, необходимо сначала создать разрешающие политики и только после этого применять `HostEndpoint`.

### Failsafe Ports (Безопасные порты)

Механизм `Failsafe Ports` позволяет держать открытыми критически важные порты управления независимо от применённых политик:

| Направление | Порты | Назначение |
|-------------|-------|------------|
| **Inbound** | 22 (SSH), 179 (BGP), 6443 (K8s API), 2379-2380 (etcd) | Управление кластером и связность |
| **Outbound** | 53 (DNS), 67 (DHCP) | Базовая сетевая инфраструктура |

Настройка портов осуществляется через ресурс `FelixConfiguration`:

```yaml
apiVersion: projectcalico.org/v3
kind: FelixConfiguration
metadata:
  name: default
spec:
  failsafeInboundHostPorts:
  - protocol: TCP
    port: 22
  - protocol: TCP
    port: 6443
  failsafeOutboundHostPorts:
  - protocol: UDP
    port: 53
```

### Политики preDNAT

Для эффективной фильтрации трафика до того, как произойдёт трансляция адресов (NodePort, LoadBalancer), используются следующие параметры:

| Параметр | Описание |
|----------|----------|
| `preDNAT: true` | Правила `ingress` применяются в цепочках `iptables` до выполнения DNAT |
| `applyOnForward: true` | Политика применяется к транзитному (проходящему через узел) трафику |

При использовании `preDNAT: true` необходимо добавлять явное правило `action: Deny` в конце цепочки политик для блокировки всего неразрешённого трафика.

### Приоритеты выполнения (order)

Политики применяются последовательно в порядке возрастания значения поля `order`:
- Чем меньше значение `order`, тем выше приоритет политики.
- Политики с одинаковым значением `order` применяются аддитивно (объединяются).
