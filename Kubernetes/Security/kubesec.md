# Kubesec: Анализ рисков и сканер безопасности в Kubernetes

## Определения

**Kubesec** — это инструмент с открытым исходным кодом для статического анализа безопасности манифестов Kubernetes (YAML). Он оценивает риски конфигурации и выставляет оценку (score) на основе соответствия лучшим практикам безопасности.

* **Статический анализ:** Проверка манифестов до момента их деплоя в кластер.
* **Score (Оценка):** Численное значение, отражающее уровень безопасности конфигурации.

**Важно:** Kubesec предназначен для анализа манифестов. Для проверки конфигурации работающего кластера используйте [kube-bench](./kube-bench.md), а для применения политик во время деплоя — [Kyverno](./kyverno/policies/practical_scenarios.md).

## Основные концепции

* **Анализ ресурсов:** Поддержка проверки Pod, Deployment, Service, DaemonSet, StatefulSet, CronJob и других стандартных ресурсов Kubernetes.
* **Kubesec-as-a-Service:** Возможность сканирования через публичный API (`v2.kubesec.io/scan`) для быстрой проверки без локальной установки.
* **Встроенный HTTP-сервер:** Запуск локального API для автоматизации проверок в локальных средах или CI.
* **JSON-отчеты:** Вывод результатов в формате JSON для удобной машинной обработки и интеграции в пайплайны.
* **Quality Gates (Ворота качества):** Возможность блокировки CI/CD пайплайнов, если итоговая оценка манифеста ниже установленного порога.
* **Плагин для kubectl:** Интеграция с CLI Kubernetes для ручного сканирования ресурсов "на лету".

## Практические сценарии

### Установка Kubesec

* **Использование через Docker:**

    ```bash
    docker run kubesec/kubesec:latest
    ```

* **Установка бинарного файла:**
    1. Скачайте релиз для вашей ОС с официального репозитория.
    2. Установите права на выполнение:

        ```bash
        chmod +x ./kubesec
        ```

* **Установка как плагин kubectl:**

    ```bash
    kubectl krew install kubesec
    ```

### Примеры использования

* **Сканирование локального манифеста:**

    ```bash
    kubesec scan pod.yaml
    ```

* **Запуск локального сервера и сканирование через curl:**

    ```bash
    # Запуск сервера
    docker run -p 8080:8080 kubesec/kubesec:latest serve

    # Отправка манифеста на проверку
    curl -X POST --data-binary @pod.yaml http://localhost:8080/scan
    ```

* **Сканирование через публичный API:**

    ```bash
    curl -sS --request POST --data-binary @pod.yaml https://v2.kubesec.io/scan
    ```

### Интеграция в CI/CD (GitLab CI)

Пример использования Kubesec для блокировки пайплайна при обнаружении критических проблем:

```yaml
security-scan:
  stage: test
  image: kubesec/kubesec:latest
  script:
    - SCORE=$(kubesec scan k8s/manifest.yaml | jq '.[0].score')
    - test "$SCORE" -gt 0 || exit 1
```

## Дополнительная информация

### Пороговые значения Score

* **Score < 0:** Обнаружены критические уязвимости. Рекомендуется немедленно исправить и блокировать деплой.
* **Score 0–5:** Есть потенциальные риски. Рекомендуется изучить отчет и внести улучшения.
* **Score > 5:** Конфигурация соответствует базовым стандартам безопасности.
