# Мониторинг и обслуживание Ceph

## Определения

**Мониторинг Ceph** — непрерывное наблюдение за состоянием здоровья кластера, производительностью и утилизацией ресурсов.

**Обслуживание Ceph** — регламентные операции по оптимизации распределения данных, управлению доступом и аудиту системных событий.

> **Базовые концепции и архитектура:** [Администрирование Ceph — Обзор](./index.md)

---

## Базовые концепции

### Источники данных для мониторинга

Ceph предоставляет несколько механизмов для получения метрик и статусов через **MGR (Manager — менеджер)** и другие компоненты:

| Источник | Описание | Команда включения |
|:---------|:---------|:------------------|
| **Встроенный модуль Prometheus** | Экспортирует метрики для интеграции с Prometheus/Grafana. | `ceph mgr module enable prometheus` |
| **Ceph Dashboard** | Графическая панель управления с визуализацией состояния. | `ceph mgr module enable dashboard` |
| **Интерфейс командной строки (CLI)** | Получение статуса в реальном времени (`status`, `health`). | Доступно по умолчанию |

## Практические сценарии

### Мониторинг использования дискового пространства

Для предотвращения блокировки кластера из-за переполнения необходимо контролировать свободное место на **OSD (Object Storage Daemon — демон хранения объектов)**:

```bash
# Использование дискового пространства в разрезе OSD
ceph osd df
```
# Общий статус заполнения и доступности
ceph status

# Детальный отчет о проблемах со свободным местом
ceph health detail
```

**Особенности расчета полезного объема** (при коэффициенте репликации `size=3`):
Любая единица полезных данных занимает в 3 раза больше физического места на дисках. При планировании расширения критическим порогом считается заполнение на 80%.

### Балансировка данных в кластере

Если данные распределены по дискам неравномерно, необходимо запустить процесс балансировки:

```bash
# Проверка текущего распределения данных
ceph osd df

# Автоматическая корректировка весов на основе утилизации
ceph osd reweight-by-utilization

# Ручное изменение веса конкретного OSD
ceph osd reweight <osd_id> <weight>
```

### Управление ключами доступа (`ceph auth`)

Управление правами доступа к ресурсам кластера для клиентов и сервисов:

```bash
# Просмотр всех существующих записей авторизации
ceph auth list

# Создание пользователя с ограниченными правами доступа к пулу
ceph auth get-or-create client.<name> mon 'allow r' osd 'allow rw pool=<pool_name>'

# Экспорт ключа в файл keyring
ceph auth get client.<name> -o /etc/ceph/ceph.client.<name>.keyring

# Отзыв прав (удаление пользователя)
ceph auth del client.<name>
```

### Анализ логов и событий

```bash
# Просмотр лога событий в реальном времени
ceph -w

# Вывод последних записей системного лога
ceph log last 100

# Получение детальных логов по конкретной подсистеме
ceph log dump
```

### Регламентное обслуживание

| Задача | Периодичность | Цель |
|:-------|:--------------|:-----|
| Проверка статуса `ceph status` | Ежедневно | Оперативное обнаружение инцидентов |
| Контроль свободного места | Еженедельно | Предотвращение блокировок записи |
| Аудит пользователей | Ежемесячно | Обеспечение безопасности доступа |
| Анализ EOL (End of Life) версий | Ежегодно | Планирование обновлений (см. [Обзор Ceph](../ceph_overview.md)) |
