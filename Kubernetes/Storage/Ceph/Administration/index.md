# Администрирование Ceph

## Definitions

**Администрирование Ceph** — совокупность операций по управлению, мониторингу и обслуживанию кластера Ceph: управление демонами (MON, MGR, OSD, MDS), пулами, Placement Groups, ключами доступа, балансировкой и логированием.

**SSoT-файлы по темам:**

- **Операции** — управление компонентами кластера: OSD, пулы, мониторы, MGR, MDS, PG ([operations.md](./operations.md))
- **Мониторинг** — наблюдение за состоянием, использование ресурсов, балансировка, ключи доступа, логирование ([monitoring.md](./monitoring.md))

## Basic Concepts

### Архитектура администрирования

Администрирование Ceph строится вокруг управления ключевыми демонами и данными кластера:

1. **Демоны (services)**:
   - **MON** (мониторы) — карта кластера, кворум, консенсус
   - **MGR** (менеджеры) — метрики, мониторинг, внешние API
   - **OSD** (демоны хранения) — хранение данных, репликация, восстановление
   - **MDS** (серверы метаданных) — метаданные для CephFS

2. **Данные (data)**:
   - **Пулы (pools)** — логические разделы для хранения объектов
   - **Placement Groups (PG)** — группы размещения, распределение по OSD
   - **Объекты** — единицы хранения данных

3. **Здоровье кластера**:
   - `HEALTH_OK` — все компоненты работают штатно
   - `HEALTH_WARN` — есть предупреждения, работа продолжается
   - `HEALTH_ERR` — критические ошибки, требуется вмешательство

## Practical Scenarios

Основные сценарии администрирования распределены по специализированным файлам:

### Управление компонентами ([operations.md](./operations.md))

- Проверка состояния кластера (`ceph status`, `ceph health`)
- Управление OSD (добавление, удаление, замена)
- Операции с пулами (создание, настройка, удаление)
- Управление мониторами (кворум, добавление, удаление)
- Управление MGR (модули, перезапуск)
- Управление MDS для CephFS
- Диагностика и восстановление PG

### Мониторинг и обслуживание ([monitoring.md](./monitoring.md))

- Контроль использования дискового пространства
- Балансировка кластера (`reweight-by-utilization`)
- Управление ключами доступа (auth list, get-or-create, delete)
- Логирование и отслеживание событий (`ceph -w`)
- Настройка Prometheus-алертов
- Рекомендуемые практики и периодичность обслуживания
