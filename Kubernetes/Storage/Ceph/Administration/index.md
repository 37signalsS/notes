# Администрирование Ceph

## Определения

**Администрирование Ceph** — совокупность операций по управлению, мониторингу и обслуживанию кластера Ceph: управление демонами (мониторами, менеджерами, демонами хранения), пулами, группами размещения, ключами доступа, балансировкой и логированием.

**Ключевые области администрирования:**

- **Операции** — управление компонентами кластера: демонами хранения, пулами, мониторами, менеджерами, серверами метаданных и группами размещения. Подробнее: [Операции Ceph](./operations.md).
- **Мониторинг и обслуживание** — наблюдение за состоянием, использование ресурсов, балансировка, управление доступом и анализ логов. Подробнее: [Мониторинг Ceph](./monitoring.md).

## Базовые концепции

### Архитектура администрирования

Администрирование Ceph строится вокруг управления ключевыми демонами и данными кластера:

1. **Сервисные демоны (services)**:
   - **MON (Monitor — монитор)** — хранение карты кластера, обеспечение кворума и консенсуса.
   - **MGR (Manager — менеджер)** — сбор метрик, мониторинг и предоставление внешних API (Application Programming Interface).
   - **OSD (Object Storage Daemon — демон хранения объектов)** — хранение данных на физических дисках, репликация и восстановление.
   - **MDS (Metadata Server — сервер метаданных)** — хранение и обработка метаданных для файловой системы CephFS.

2. **Структуры данных (data)**:
   - **Пулы (pools)** — логические разделы для хранения данных.
   - **PG (Placement Group — группа размещения)** — абстракция для распределения объектов по OSD.
   - **RADOS (Reliable Autonomic Distributed Object Store)** — базовый уровень распределенного хранилища объектов.

3. **Состояния здоровья кластера**:
   - `HEALTH_OK` — все компоненты работают штатно.
   - `HEALTH_WARN` — обнаружены проблемы, не требующие немедленной остановки, но требующие анализа.
   - `HEALTH_ERR` — критические ошибки, требующие немедленного вмешательства.

### Основные инструменты управления

| Инструмент | Назначение | Описание |
|:-----------|:-----------|:---------|
| `ceph` | Основной CLI (Command Line Interface) | Утилита для выполнения большинства административных задач. |
| `rados` | Низкоуровневый CLI | Инструмент для прямого взаимодействия с хранилищем объектов RADOS. |
| `cephadm` | Оркестрация демонов | Утилита для развертывания и управления жизненным циклом демонов Ceph. |
| Ceph Dashboard | Веб-интерфейс | Графическая панель для мониторинга и базового администрирования. |

## Практические сценарии

Основные сценарии администрирования распределены по специализированным разделам:

### Управление компонентами кластера

В рамках оперативного управления выполняются следующие задачи:

- Проверка статуса и детального здоровья кластера (`ceph status`).
- Жизненный цикл OSD: добавление, вывод из эксплуатации, замена дисков.
- Настройка пулов: управление количеством реплик и группами размещения.
- Поддержка кворума мониторов.
- Управление модулями менеджера (dashboard, prometheus).

Подробные инструкции и примеры команд: **[Операции Ceph: управление компонентами](./operations.md)**.

### Мониторинг и регламентное обслуживание

Для обеспечения стабильной работы кластера проводятся:

- Контроль утилизации дискового пространства и прогнозирование расширения.
- Балансировка данных между узлами и дисками.
- Управление ключами доступа и правами пользователей (`ceph auth`).
- Сбор и анализ логов и событий в реальном времени.
- Настройка оповещений (алертов) в системах мониторинга.

Подробные инструкции и примеры команд: **[Мониторинг и обслуживание Ceph](./monitoring.md)**.
