# CephFS: Дополнительная информация

## Опции монтирования

| Опция | Описание | Рекомендация |
|-------|----------|--------------|
| `noatime` | Не обновлять время доступа | ✅ Production |
| `relatime` | Обновлять atime периодически | ✅ Компромисс |
| `rw` | Чтение и запись | По умолчанию |
| `ro` | Только чтение | Для резервных узлов |
| `norecover` | Отключить восстановление | Только для отладки |
| `recover_session=clean` | Очистка сессии | При проблемах |

---

## Производительность

### Рекомендации по настройке

1. **Размер кэша ядра**:

   ```bash
   # Увеличение кэша
   echo 1048576 > /sys/module/ceph/parameters/mds_cache
   ```

2. **Параллелизм операций**:

   ```bash
   mount -o ... ,congestion_kb=8388608 /mnt/shared_fs
   ```

3. **Использование FUSE vs Kernel**:
   - Kernel: выше производительность, меньше совместимость
   - FUSE: ниже производительность, больше совместимость

---

## Безопасность

- Используйте отдельных пользователей для разных приложений
- Ограничивайте доступ на уровне путей (path-based)
- Шифруйте трафик (ms_mode=secure)
- Регулярно ротируйте ключи
