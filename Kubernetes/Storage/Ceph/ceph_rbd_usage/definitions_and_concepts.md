# RBD: Определения и базовые концепции

## Определения

**RADOS Block Device (RBD)** — блочное устройство, хранящееся в виде объектов в кластере Ceph. Предоставляет дисковое пространство клиентским машинам как виртуальный диск.

**Image (Образ)** — отдельный RBD-том, доступный для монтирования.

**Snapshot (Снапшот)** — моментальная копия образа на определенный момент времени.

**Clone (Клон)** — образ, созданный на основе снапшота.

## Основные концепции

### Архитектура RBD

```
Клиент → librbd → Ceph Cluster (RADOS) → OSD → Физические диски
```

### Особенности RBD

| Характеристика | Описание |
|----------------|----------|
| **Тонкое выделение** | Thin provisioning — место выделяется по мере записи |
| **Снапшоты** | Моментальные копии без дублирования данных |
| **Клонирование** | Создание образов из снапшотов |
| **Шифрование** | LUKS-шифрование на уровне образа |
| **QoS** | Ограничение IOPS и пропускной способности |

### Требования к клиенту

- Пакет `ceph-common` (версия ≈ версии сервера)
- Ядро Linux с модулем `rbd` (5.4+)
- Конфигурация `/etc/ceph/ceph.conf`
- Ключ доступа `/etc/ceph/ceph.client.<user>.keyring`

### Функции RBD (image-features)

| Функция | Описание | Требование |
|---------|----------|------------|
| `layering` | Слои для снапшотов/клонов | Обязательно для CSI |
| `striping` | Распараллеливание записи | По умолчанию |
| `exclusive-lock` | Эксклюзивная блокировка | Для снапшотов |
| `object-map` | Карта объектов | Для быстрых операций |
| `fast-diff` | Быстрый diff | Для инкрементальных бэкапов |
| `deep-flatten` | Полное выравнивание | Для удаления снапшотов |
