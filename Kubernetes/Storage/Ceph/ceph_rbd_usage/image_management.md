# RBD: Управление образами

## Определения

**Образ (Image)** — виртуальный диск, распределенный в виде набора объектов RADOS внутри кластера Ceph.

**Снапшот (Snapshot)** — копия образа в режиме "только для чтения" на конкретный момент времени. Не занимает места, пока данные в основном образе не изменены.

**Клон (Clone)** — полноценный записываемый образ RBD, созданный на основе конкретного снапшота.

**Корзина (Trash)** — механизм отложенного удаления, позволяющий восстановить случайно удаленный образ в течение заданного времени.

## Основные концепции

### Пространства имен (Namespaces)
Внутри одного пула можно создавать изолированные пространства имен (`namespaces`). Это позволяет разделять образы разных приложений или окружений внутри одного пула, обеспечивая дополнительный уровень организации.

### Защита и выравнивание (Flattening)
Чтобы создать клон, снапшот родительского образа должен быть «защищен» (`protected`). Клон зависит от родительского снапшота до тех пор, пока не будет выполнена операция «выравнивания» (`flatten`). После выравнивания клон становится полностью независимым образом, копируя все данные из родителя.

## Практические сценарии

### Создание и базовая настройка

**1. Создание образа:**
Рекомендуется всегда явно указывать функции образа для совместимости с клиентами.
```bash
# Создание образа 10 ГБ в пуле 'kube' с включенными функциями
rbd create --size 10240 --pool kube \
  --image-features layering,exclusive-lock,object-map,fast-diff \
  my-image

# Создание образа в конкретном namespace
rbd create --size 5120 --pool kube --namespace staging stg-image
```

**2. Изменение функций (Features):**
Вы можете включать или отключать функции "на лету" (если это поддерживает клиент).
```bash
# Включение эксклюзивной блокировки
rbd feature enable kube/my-image exclusive-lock

# Отключение функций для совместимости со старыми ядрами
rbd feature disable kube/my-image object-map,fast-diff
```

### Просмотр и мониторинг

```bash
# Список образов (включая информацию о namespace)
rbd ls -p kube --all

# Детальная информация и статус блокировок
rbd info kube/my-image
rbd status kube/my-image # Показывает активных клиентов (watchers)

# Фактическое использование места в кластере
rbd du kube/my-image
```

### Модификация и перемещение

```bash
# Изменение размера
rbd resize --size 20480 kube/my-image
rbd resize --size 5120 kube/my-image --allow-shrink

# Переименование образа
rbd rename kube/old-name kube/new-name
```

### Безопасное удаление через корзину

```bash
# Перемещение в корзину (образ будет храниться по умолчанию 0 секунд, если не задано)
rbd trash mv kube/my-image

# Список удаленных образов
rbd trash ls -p kube

# Восстановление из корзины
rbd trash restore kube/<id-образа> --image new-name

# Окончательное удаление
rbd trash rm kube/<id-образа>
```

### Снапшоты и клонирование

**1. Работа со снапшотами:**
```bash
# Создание и просмотр
rbd snap create kube/my-image@v1.0
rbd snap ls kube/my-image

# Откат образа к состоянию снапшота (требует unmap)
rbd snap rollback kube/my-image@v1.0
```

**2. Создание клонов и разрыв зависимости:**
```bash
# Шаг 1: Защита снапшота
rbd snap protect kube/my-image@v1.0

# Шаг 2: Создание клона
rbd clone kube/my-image@v1.0 kube/clone-image

# Шаг 3: Выравнивание (разрыв связи с родителем)
rbd flatten kube/clone-image
```
