# RBD: Управление образами

Документ является основным руководством по управлению жизненным циклом блочных устройств (RBD) в кластере Ceph.

## Определения

**Образ (Image)** — виртуальный блочный диск, данные которого распределены в виде набора объектов RADOS внутри пула или пространства имен.

**Снапшот (Snapshot)** — неизменяемая копия образа в режиме "только для чтения" на определенный момент времени. Снапшоты в Ceph используют механизм **Redirect-on-Write (RoW)**, поэтому создание снимка происходит мгновенно и не потребляет место до начала изменений в основном образе.

**Клон (Clone)** — полноценный записываемый образ RBD, созданный на основе конкретного снапшота. Использует механизм **Copy-on-Write (CoW)**, считывая данные из родительского снапшота до тех пор, пока они не будут изменены в клоне.

**Корзина (Trash)** — механизм отложенного удаления, позволяющий переместить образ в защищенное хранилище перед окончательным удалением для предотвращения случайной потери данных.

## Базовые концепции

### Пространства имен (Namespaces)
Пространства имен позволяют логически изолировать группы образов внутри одного пула. Это критично для мультиарендных (multi-tenant) сред, где разные команды или приложения (например, разные кластеры Kubernetes) используют один и тот же пул.

### Цепочки зависимостей и выравнивание (Flattening)
Клоны жестко привязаны к своим родительским снапшотам. До тех пор, пока существует хотя бы один клон, родительский снапшот не может быть удален (он находится в статусе `protected`).
*   **Flattening** — процесс копирования всех родительских данных в клон. После завершения операции клон становится независимым образом («плоским»), а родительский снапшот можно будет удалить.

### Метаданные и тегирование
RBD позволяет назначать пользовательские метаданные (ключ-значение) образам. Это полезно для автоматизации, инвентаризации или интеграции с внешними системами (например, указание владельца или ID проекта).

## Практические сценарии

### 1. Создание и инвентаризация

```bash
# Создание образа 20 ГБ с рекомендуемым набором функций для CSI
rbd create --size 20480 --pool kube \
  --image-features layering,exclusive-lock,object-map,fast-diff,deep-flatten \
  my-production-disk

# Установка метаданных (тегирование)
rbd image-meta set kube/my-production-disk project "alpha-7"
rbd image-meta set kube/my-production-disk owner "devops-team"

# Список всех образов в пуле с выводом метаданных
rbd ls -p kube -l
```

### 2. Управление пространствами имен

```bash
# Создание namespace
rbd namespace create kube/production

# Создание образа внутри namespace
rbd create --size 5120 --pool kube --namespace production prod-db-01

# Список образов в конкретном namespace
rbd ls -p kube --namespace production
```

### 3. Изменение размера (Online Resize)

Ceph поддерживает изменение размера образа "на лету". Если образ используется через `librbd` (QEMU/KVM), клиент автоматически увидит новый размер. Для модуля ядра (`krbd`) может потребоваться запуск `blockdev --setrw` или аналогичных команд внутри ОС.

```bash
# Увеличение до 40 ГБ
rbd resize --size 40960 kube/my-production-disk

# Уменьшение размера (опасная операция, требует флага)
rbd resize --size 10240 kube/my-production-disk --allow-shrink
```

### 4. Работа со снапшотами и клонами

```bash
# Создание снапшота
rbd snap create kube/my-production-disk@backup-v1

# Защита снапшота для последующего клонирования
rbd snap protect kube/my-production-disk@backup-v1

# Создание клона в другом пуле (например, для тестов)
rbd clone kube/my-production-disk@backup-v1 test-pool/test-disk-01

# Разрыв связи (flatten) — превращение клона в полноценный образ
rbd flatten test-pool/test-disk-01
```

### 5. Безопасное удаление (Trash)

```bash
# Перемещение образа в корзину с задержкой удаления (например, 7 дней)
# Внимание: по умолчанию задержка 0, если не настроено в ceph.conf
rbd trash mv kube/my-production-disk

# Список образов в корзине с указанием даты истечения
rbd trash ls -p kube

# Восстановление образа по его ID
rbd trash restore kube/1546738290 --image restored-disk

# Очистка корзины (удаление всех образов, срок хранения которых истек)
rbd trash purge -p kube
```
