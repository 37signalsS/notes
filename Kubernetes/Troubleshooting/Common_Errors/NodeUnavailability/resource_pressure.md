# Недоступность узла: Давление ресурсов

Давление ресурсов (Resource Pressure) — это защитное состояние узла, при котором `kubelet` обнаруживает критическую нехватку аппаратных мощностей и ограничивает планирование или начинает принудительное выселение подов для предотвращения системного сбоя.

## Основные определения

**Давление ресурсов (Resource Pressure)** — набор флагов в `status.conditions` объекта Node, указывающих на дефицит конкретного ресурса (RAM, Disk, PID).

**Выселение (Eviction)** — процесс превентивного завершения подов компонентом `kubelet`. В отличие от OOM-killer ядра, выселение в Kubernetes основано на достижении порогов, настраиваемых в `KubeletConfiguration`.

**Типы ресурсов и их поведение:**
- **Несжимаемые (Incompressible)**: Память (RAM), дисковое пространство, PID. Дефицит приводит к выселению подов.
- **Сжимаемые (Compressible)**: CPU. Дефицит приводит к Throttling (замедлению), но не к выселению.

## Основные концепции

### Состояния узла (Conditions)

| Состояние | Причина | Параметр конфигурации |
| :--- | :--- | :--- |
| **`MemoryPressure`** | Нехватка RAM | `evictionHard: {memory.available: "..."}` |
| **`DiskPressure`** | Нехватка места / Inodes | `evictionHard: {nodefs.available: "...", imagefs.available: "..."}` |
| **`PIDPressure`** | Исчерпание лимита процессов | `evictionHard: {pid.available: "..."}` |

### Раздельные файловые системы (nodefs vs imagefs)

Начиная с современных версий Kubernetes (стабильно в 1.31), `kubelet` может отслеживать две разные файловые системы:
1.  **`nodefs`**: Основная ФС узла (используется для `/var/lib/kubelet`, логов и `emptyDir`).
2.  **`imagefs`**: Опциональная ФС, используемая Container Runtime для хранения образов и слоев записи контейнеров.
Если `imagefs` выделена в отдельный раздел, `DiskPressure` на нем инициирует очистку только образов, не затрагивая поды с данными в `nodefs`.

### Пороги выселения (Thresholds)

| Тип порога | Поведение | Grace Period |
| :--- | :--- | :--- |
| **Hard (Жесткий)** | Немедленное выселение по `SIGKILL`. | Нет |
| **Soft (Мягкий)** | Выселение по `SIGTERM` после ожидания. | `eviction-soft-grace-period` |

## Практические сценарии

### Сценарий 1: MemoryPressure и поддержка Swap (K8s 1.31)

**Контекст**: В 1.31 поддержка Swap стабильна. Если Swap включен, `MemoryPressure` может не наступать дольше, но производительность приложений упадет из-за Page Faults.

**Диагностика**:
```bash
# 1. Проверка условий через API
kubectl describe node <node-name> | grep -A 5 Conditions

# 2. Проверка использования Swap на узле
free -h
# Если Swap используется активно (>50%), узел близок к деградации.
```

**Решение**: Настройте `swapBehavior: LimitedSwap` в `KubeletConfiguration`, чтобы K8s корректно учитывал лимиты памяти. Подробнее: **[Выселение по памяти](../PodEvicted/memory_eviction.md)**.

### Сценарий 2: DiskPressure — объем против Inodes

**Симптомы**: На диске много свободного места (ГБ), но узел в `DiskPressure`.

**Причина**: Исчерпание индексных дескрипторов (Inodes) из-за миллионов мелких файлов.

**Диагностика**:
```bash
# Проверка Inodes
df -i /var/lib/kubelet
# Если IUse% > 90%, Kubelet установит DiskPressure.
```

**Решение**:
1. Очистка кэша образов: `crictl rmi --prune`.
2. Поиск источника мелких файлов (часто это логи или сессии приложений):
   ```bash
   du --inodes -xS /var/lib/kubelet/pods | sort -rh | head -n 10
   ```
Подробнее: **[Выселение по диску](../PodEvicted/disk_eviction.md)**.

### Сценарий 3: PIDPressure и защита от Fork-бомб

**Симптомы**: Узел `Ready`, но команды `exec` или запуск новых контейнеров падают с ошибкой `resource temporarily unavailable`.

**Диагностика**:
```bash
# Проверка лимитов ядра
sysctl kernel.pid_max

# Проверка текущего количества процессов
ps -eLf | wc -l
```

**Решение**:
1. Увеличьте системный лимит: `sysctl -w kernel.pid_max=4194304`.
2. Настройте `podPidsLimit` в `KubeletConfiguration`, чтобы один проблемный под не мог захватить все PID узла.

### Взаимодействие с резервированием
Формула доступных ресурсов для подов:
`Allocatable = Capacity - [kube-reserved] - [system-reserved] - [hard-eviction-threshold]`
