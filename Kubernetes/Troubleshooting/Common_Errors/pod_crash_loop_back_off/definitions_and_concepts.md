# Pod в состоянии `CrashLoopBackOff`: Определения и концепции

## Определения

**CrashLoopBackOff** — состояние пода в Kubernetes, указывающее на то, что контейнер многократно запускается, падает и перезапускается с экспоненциальной задержкой.

**BackOff** — механизм экспоненциальной задержки между перезапусками: 10s, 20s, 40s, 80s, ..., максимум 300s (5 минут).

## Причины состояния CrashLoopBackOff

Под переходит в состояние `CrashLoopBackOff` когда:

1. **Ошибка приложения** — баг, исключение, паника
2. **Неверная конфигурация** — отсутствующие ConfigMap, Secret, переменные окружения
3. **Проблемы с зависимостями** — недоступность БД, кэша, внешних API
4. **Недостаточно прав RBAC** — приложение не имеет доступа к Kubernetes API
5. **Неудачная livenessProbe** — probe не проходит из-за долгого старта или ошибки
6. **OOMKilled** — нехватка памяти, выход за пределы limits

## Архитектура перезапуска

```
┌─────────────────┐
│  Container      │
│  Starts         │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  Container      │
│  Crashes        │
│  (Exit Code ≠0) │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  Restart Count  │
│  Incremented    │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  BackOff Delay  │
│  (10s→300s)     │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  Retry          │
└─────────────────┘
```

## Exit Codes

| Код | Значение | Возможная причина |
|-----|----------|-------------------|
| **0** | Успех | Контейнер завершил работу нормально (проблема для долгоживущих процессов) |
| **1** | Ошибка приложения | Исключение, баг, ошибка конфигурации |
| **137** | OOMKilled | Превышен лимит памяти (SIGKILL) |
| **143** | Graceful shutdown | SIGTERM, graceful shutdown |
| **127** | Command not found | Неверная команда в ENTRYPOINT/CMD |

## Диагностика

Основной инструмент диагностики — комбинация команд:

1. `kubectl describe pod` — статус и события
2. `kubectl logs --previous` — логи предыдущего запуска
3. `kubectl get events` — события namespace
