# Проблемы с загрузкой образов (`ImagePullBackOff` / `ErrImagePull`)

### Определение

Состояние `ImagePullBackOff` означает, что `kubelet` на узле не может скачать образ контейнера из репозитория. `ErrImagePull` — это начальная ошибка, которая при повторных неудачах переходит в `ImagePullBackOff` с нарастающей задержкой между попытками.

### Основные концепции

* **Kubelet:** Агент, работающий на каждом узле и отвечающий за жизненный цикл контейнеров, включая скачивание образов.
* **Репозиторий образов:** Хранилище (например, Docker Hub, GCR, Harbor), откуда скачиваются образы.
* **ImagePullSecrets:** Секрет Kubernetes, содержащий учетные данные для доступа к приватным репозиториям.

### Практические сценарии

#### Диагностика

`kubectl describe pod <pod-name>` покажет детальную ошибку в разделе `Events`.

```
Events:
  Type     Reason     Age                From               Message
  ----     ------     ----               ----               -------
  Warning  Failed     2m (x4 over 3m)    kubelet            Failed to pull image "my-app:1.1": rpc error: code = Unknown desc = Error response from daemon: manifest for my-app:1.1 not found
```

#### Распространенные случаи и их решения

1. **Неверное имя или тег образа**
    * **Причина:** Опечатка в `spec.containers.image`.
    * **Решение:** Проверьте и исправьте имя и тег образа в манифесте.

2. **Проблемы с доступом к приватному репозиторию**
    * **Причина:** Отсутствует или неверно настроен `imagePullSecrets`.
    * **Решение:** Убедитесь, что `imagePullSecrets` создан корректно, содержит правильные credentials и указан в спецификации пода.

3. **Образ не существует**
    * **Причина:** Образ с указанным тегом никогда не был загружен в репозиторий.
    * **Решение:** Проверьте наличие образа и тега в репозитории.

4. **Сетевые проблемы**
    * **Причина:** Узел не имеет сетевого доступа к репозиторию (проблемы с DNS, firewall, прокси).
    * **Решение:** Проверьте доступность репозитория с узла (например, с помощью `curl` или `docker pull` непосредственно на узле).
