Базовые понятия и терминология (включая политики загрузки и SHA256 digest) приведены в разделе [Определения](./definitions.md).

## Основные концепции

### Принципы предотвращения ошибок

| Категория | Рекомендация | Обоснование |
| :--- | :--- | :--- |
| **Управление тегами** | Использовать конкретные версии (`:v1.2.3`) или SHA256 digest | Исключает ошибки `manifest not found`, гарантирует воспроизводимость среды |
| **Аутентификация** | Привязка `imagePullSecrets` к `ServiceAccount` | Автоматизирует доступ к приватным реестрам для всех подов в namespace |
| **Реестры** | Использование локальных реестров (Harbor, Nexus) | Обеспечивает контроль доступа, кэширование и независимость от внешних лимитов |
| **Мониторинг** | Настройка алертов на `ImagePullBackOff` | Позволяет обнаружить проблемы с инфраструктурой или CI/CD до массовых сбоев |

### Рекомендации по выбору imagePullPolicy

При использовании конкретных тегов в production рекомендуется политика `IfNotPresent`. Это позволяет экономить трафик и ускорять запуск за счёт использования локального кэша узла. Подробное описание политик доступно в [Определениях](./definitions.md#политики-загрузки-образов-imagepullpolicy).

## Практические сценарии

### Сценарий 1: Глобальная настройка аутентификации

Для автоматического применения секретов ко всем подам в пространстве имен (namespace), привяжите созданный секрет к `default` ServiceAccount:

```bash
kubectl patch serviceaccount default \
  -p '{"imagePullSecrets": [{"name": "regcred"}]}' \
  -n my-namespace
# → serviceaccount/default patched
```

Инструкции по созданию секрета `regcred` приведены в разделе [Распространённые ошибки](./common_errors.md#сценарий-2-ошибки-аутентификации-в-приватном-репозитории).

### Сценарий 2: Мониторинг через Prometheus (Kube-State-Metrics)

Настройка оповещения (Alert Rule) для Prometheus позволит оперативно реагировать на зависшие загрузки образов:

```yaml
- alert: ImagePullBackOff
  expr: kube_pod_container_status_waiting_reason{reason="ImagePullBackOff"} == 1
  for: 10m
  labels:
    severity: warning
  annotations:
    summary: "Под {{ $labels.pod }} застрял в ImagePullBackOff"
    description: "Контейнер {{ $labels.container }} в namespace {{ $labels.namespace }} не может скачать образ"
```
