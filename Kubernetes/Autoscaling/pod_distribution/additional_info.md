# Распределение подов: Дополнительная информация

## Интеграции

Механизмы распределения подов взаимодействуют с другими компонентами Kubernetes:

- **[HPA](../HPA/index.md)** — созданные HPA поды распределяются согласно настроенным правилам Affinity и Topology Spread
- **[Pod Disruption Budget](pod_disruption_budget.md)** — совместное использование обеспечивает доступность при потере узла (Anti-Affinity распределяет поды, PDB защищает от массового выселения)
- **[Cluster Autoscaler](cluster_autoscaler_detailed.md)** — CA может создавать новые узлы для соблюдения правил распределения подов
- **[Sharding](sharding/definitions_and_concepts.md)** — при шардировании настраивайте распределение для изоляции сбоев между шардами

## Ограничения

| Ограничение | Описание |
|-------------|----------|
| Требуется достаточное количество узлов | При малом кластере правила могут блокировать планирование |
| Может блокировать масштабирование | При нехватке ресурсов HPA не сможет создать поды |
| Не защищает от недобровольных прерываний | Без PDB сбой узла нарушит доступность |
| Сложность отладки | Комбинация правил может давать неожиданные результаты |
