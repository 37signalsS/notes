# Kibana: Практическое руководство

> Данное руководство сфокусировано на практическом использовании Kibana для анализа логов в среде Kubernetes, собранных с помощью Fluent Bit. Для общего обзора см. [Kibana: Обзор и ключевые концепции](../../../ELK_Stack/Kibana/kibana_overview.md).

## Определения

**Kibana** — это веб-интерфейс для [Elasticsearch](../../../ELK_Stack/Elasticsearch/elasticsearch_sharding_replication_cluster.md), предоставляющий мощные инструменты для поиска, анализа и визуализации данных. В контексте EFK-стека Kibana является окном в мир ваших логов.

**Индекс-паттерн (Index Pattern)** — это шаблон, который позволяет Kibana работать с несколькими индексами Elasticsearch как с единым источником данных. Он использует wildcard-символы (`*`) для объединения индексов по имени. Например, Fluent Bit часто создает ежедневные индексы (`kube-2025.11.11`, `kube-2025.11.12`), и паттерн `kube-*` объединит их все.

## Основные концепции

### Интерфейс `Discover`

Вкладка **Discover** — это основной инструмент для интерактивного поиска и просмотра логов в реальном времени. Ключевые элементы интерфейса:

-   **Список индекс-паттернов:** В левом верхнем углу можно выбрать, какой набор данных вы хотите исследовать (например, `kube-*` для логов приложений).
-   **Строка запроса (Query Bar):** Позволяет вводить запросы на языке KQL для фильтрации данных.
-   **Гистограмма времени:** Визуализирует распределение логов по времени и позволяет задавать временной диапазон.
-   **Список полей (Field List):** Слева отображаются все доступные в логах поля. Их можно добавлять в основное окно для просмотра.
-   **Поток логов:** Основная область, где отображаются сами записи логов в виде документов.

### Язык запросов KQL (Kibana Query Language)

KQL — это простой и интуитивно понятный язык для фильтрации данных прямо в строке поиска.

-   **Фильтрация по значению поля:**
    ```kql
    kubernetes.namespace_name: "default"
    ```
-   **Использование операторов `and`, `or`, `not`:**
    ```kql
    kubernetes.pod_name: "app-*" and not kubernetes.namespace_name: "kube-system"
    ```
-   **Фильтрация по числовым значениям:**
    ```kql
    response_code: >=400
    ```
-   **Проверка существования поля:**
    ```kql
    kubernetes.labels.app: *
    ```

### Визуализации и дашборды

Kibana позволяет преобразовывать результаты поиска в графики, таблицы и диаграммы (визуализации) и объединять их на дашбордах. Это помогает отслеживать состояние системы и выявлять тенденции. Качественная визуализация требует структурированных логов (например, в формате JSON).

## Практические сценарии

### 1. Создание индекс-паттерна для логов Kubernetes

1.  Откройте веб-интерфейс Kibana.
2.  В боковом меню выберите **Stack Management** → **Index Patterns**.
3.  Нажмите **Create index pattern**.
4.  В поле "Index pattern name" введите шаблон, соответствующий префиксу логов из [конфигурации Fluent Bit](./fluentbit_deep_dive.md) (например, `kube-*` для логов контейнеров или `node-*` для логов хостов).
5.  На следующем шаге в выпадающем списке **Time field** выберите `@timestamp`. Это поле Kibana будет использовать для фильтрации по времени.
6.  Нажмите **Create index pattern**.

### 2. Поиск и фильтрация логов пода

Перейдите в **Discover** и выберите нужный индекс-паттерн (например, `kube-*`).

-   **Найти все логи конкретного пода:**
    ```kql
    kubernetes.pod_name: "my-app-pod-xyz123"
    ```
-   **Найти все логи подов определенного приложения (по лейблу):**
    ```kql
    kubernetes.labels.app: "my-app"
    ```
-   **Показать все ошибки (HTTP 5xx) из неймспейса `production`:**
    ```kql
    kubernetes.namespace_name: "production" and http.status_code: >=500
    ```

### 3. Кастомизация отображения полей

В Discover по умолчанию каждая запись лога отображается как JSON-документ. Для удобства анализа можно настроить табличное представление:

1.  В списке полей слева найдите интересующие вас поля (например, `log`, `kubernetes.pod_name`, `kubernetes.namespace_name`).
2.  Наведите курсор на поле и нажмите кнопку `+`, чтобы добавить его в виде колонки в основной области.
3.  После добавления нескольких полей Kibana автоматически построит таблицу, которую легко читать.
