# MicroK8s: обзор

## Определения

**MicroK8s** — легковесный дистрибутив Kubernetes от компании Canonical. Представляет собой полноценный upstream-кубер, упакованный в Snap-пакет с изолированными компонентами и встроенной системой аддонов.

### Ключевые отличия

- **Упаковка:** Snap-пакет — каждый компонент работает как отдельный systemd-процесс со своими зависимостями
- **Хранилище:** по умолчанию используется DQLite — встроенная распределённая БД на основе SQLite
- **Архитектура:** максимально близка к классическому K8s — отдельные процессы для apiserver, scheduler, controller-manager и т.д.

## Основные концепции

### Требования к ресурсам

| Ресурс | Минимум | Рекомендуется |
|:-------|:--------|:--------------|
| RAM | 2 ГБ | 4+ ГБ |
| CPU | 2 ядра | 4+ ядра |

Из-за оверхеда Snap и раздельных процессов пустой кластер потребляет 2–4 ГБ RAM. На Raspberry Pi или виртуалках с 1–2 ГБ RAM предпочтителен K3s.

### Система аддонов

MicroK8s предоставляет встроенную систему управления аддонами — не требуется искать и применять манифесты вручную:

```bash
# Включение стандартных компонентов
microk8s enable ingress
microk8s enable storage
microk8s enable monitoring

# Просмотр доступных аддонов
microk8s status
```

Из коробки доступны аддоны для Ingress, Storage, Monitoring, Dashboard, Registry и многих других компонентов.

### Сравнение с K3s

| Параметр | MicroK8s | K3s |
|:---------|:---------|:----|
| Размер | Snap-пакет (сотни МБ) | Один бинарник <100 МБ |
| RAM (idle) | 2–4 ГБ | ~512 МБ |
| Хранилище | DQLite | SQLite (Kine) |
| Процессы | Раздельные systemd | Единый процесс |
| Система аддонов | Встроенная (`microk8s enable`) | Нет (auto-deploy dir) |
| Разработчик | Canonical | SUSE / Rancher |

## Практические сценарии

### Установка

```bash
sudo snap install microk8s --classic
sudo usermod -a -G microk8s $USER
```

### Базовое управление

```bash
# Статус кластера
microk8s status

# kubectl через microk8s
microk8s kubectl get nodes

# Просмотр конфигурации для внешнего доступа
microk8s config
```
