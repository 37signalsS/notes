# Kubespray: Установка — Основные концепции

## Основные концепции

Kubespray — инструмент автоматизации развертывания Kubernetes на базе Ansible. Архитектура основана на трёх компонентах:

**Inventory** — файл `inventory.ini`, определяющий состав кластера и роли узлов.

**Group vars** — переменные для групп хостов:

- `group_vars/all/` — общие переменные для всех хостов
- `group_vars/k8s-cluster/` — переменные для компонентов Kubernetes

**Плейбуки** — Ansible playbook для развертывания:

- `cluster.yml` — основной плейбук для развертывания кластера
- `scale.yml` — масштабирование (добавление узлов)
- `upgrade-cluster.yml` — обновление Kubernetes
- `remove-node.yml` — удаление узлов

## Требования

### Требования к машине управления

Машина управления — узел, с которого запускается Ansible. Обычно это одна из будущих control plane нод или отдельная рабочая станция.

- **Python 3.9+ + pip** — для установки зависимостей Ansible
- **Ansible** — устанавливается через `pip install -r requirements.txt`
- **SSH-доступ** — приватный ключ для подключения к целевым хостам
- **git** — для клонирования репозитория Kubespray

> **Примечание:** Kubespray — обёртка над `kubeadm`. После установки кластера возможно дальнейшее управление через команды `kubeadm` (обновление сертификатов, upgrade и т.д.).

### Требования к узлам кластера

Перед запуском каждый узел (control plane и worker) должен соответствовать требованиям:

| Требование | Значение |
| :--- | :--- |
| **ОС** | Ubuntu, CentOS, Rocky Linux, Debian |
| **SSH-доступ** | Ключи с машины запуска Ansible (root или sudo без пароля) |
| **SELinux** | Отключен (`sudo setenforce 0`) |
| **Swap** | Отключен (`sudo swapoff -a`) |
| **Firewall** | Отключен (`systemctl stop firewalld`) |
| **DNS** | Разрешение FQDN узлов (локальный DNS-сервер) |
| **Python** | Установлен на всех узлах (Kubespray устанавливает автоматически) |

**Команды для подготовки:**

```bash
# Отключить SELinux
sudo setenforce 0
# Отключить навсегда: /etc/selinux/config

# Отключить Swap
sudo swapoff -a
# Закомментировать строку swap в /etc/fstab

# Отключить Firewall
sudo systemctl stop firewalld
sudo systemctl disable firewalld
```

## Этапы установки

Процесс развертывания включает 6 этапов:

1. **Предварительные требования** — подготовка серверов (см. выше)
2. **Установка Kubespray** — клонирование репозитория и установка зависимостей
3. **Конфигурация Inventory** — определение состава кластера
4. **Конфигурация group_vars** — настройка параметров
5. **Запуск развертывания** — выполнение `ansible-playbook cluster.yml`
6. **Действия после установки** — проверка кластера и настройка kubeconfig

Подробные команды для каждого этапа — в [Практических сценариях](./practical_scenarios.md).
