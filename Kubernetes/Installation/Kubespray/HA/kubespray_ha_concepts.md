# Kubespray: Развертывание HA-кластера — Основные концепции

## Definitions

**HA-кластер (High Availability)** — кластер Kubernetes с несколькими узлами Control Plane для устранения единой точки отказа (SPoF).

**VIP (Virtual IP)** — виртуальный IP-адрес, который служит единой точкой входа к API-серверам через механизм VRRP.

**Kubespray** — инструмент автоматизации развертывания Kubernetes на базе Ansible, поддерживающий встроенную настройку HA через Keepalived + HAProxy.

## Basic Concepts

### Архитектура HA через Kubespray

Kubespray автоматизирует настройку HA следующим образом:

```
                    ┌─────────────────┐
                    │      VIP        │
                    │  192.168.1.100  │
                    └────────┬────────┘
                             │
              ┌──────────────┼──────────────┐
              │              │              │
     ┌────────▼───────┐ ┌───▼────────┐ ┌───▼────────┐
     │   Master-1     │ │  Master-2  │ │  Master-3  │
     │  Keepalived    │ │ Keepalived │ │ Keepalived │
     │    MASTER      │ │  BACKUP    │ │  BACKUP    │
     │   HAProxy:6443 │ │HAProxy:6443│ │HAProxy:6443│
     │ apiserver:6444 │ │apiserver:6444│ │apiserver:6444│
     └────────────────┘ └────────────┘ └────────────┘
```

#### Компоненты

| Компонент | Назначение | Порт |
| :--- | :--- | :--- |
| **Keepalived** | Управление VIP через VRRP | 112 (VRRP) |
| **HAProxy** | Балансировка трафика к API-серверам | 6443 (VIP), 6444 (local) |
| **kube-apiserver** | API Kubernetes | 6444 (локально) |

#### Отличия от ручного kubeadm

| Аспект | Kubespray | Ручной kubeadm |
| :--- | :--- | :--- |
| **Автоматизация** | Полная (Ansible) | Ручная настройка |
| **Keepalived/HAProxy** | Устанавливается автоматически | Ручная установка |
| **Сертификаты** | Авто-генерация с VIP | Ручное добавление SAN |
| **Время развертывания** | 15-30 минут | 1-2 часа |

Подробное описание архитектуры Keepalived + HAProxy см. в [ручной настройке HA с kubeadm](../../kubeadm/ha_concepts.md).

### Альтернатива: Локальный балансировщик на worker-нодах

Kubespray предоставляет упрощённый вариант HA без внешнего балансировщика или Keepalived. В этом режиме на каждой **не-master ноде** (worker) разворачивается nginx-proxy, который выполняет локальную балансировку трафика к API-серверам control plane.

#### Архитектура с nginx-proxy

```
Client
  │
  ▼
┌─────────────────────────────────────────────────────┐
│  Worker-1          Worker-2          Worker-3       │
│  nginx:6443  ◄──►  nginx:6443  ◄──►  nginx:6443    │
│      │                 │                 │          │
└──────┼─────────────────┼─────────────────┼──────────┘
       │                 │                 │
       ▼                 ▼                 ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ Master-1     │ │ Master-2     │ │ Master-3     │
│ apiserver    │ │ apiserver    │ │ apiserver    │
│ :6444        │ │ :6444        │ │ :6444        │
└──────────────┘ └──────────────┘ └──────────────┘
```

#### Компоненты

| Компонент | Назначение | Порт |
| :--- | :--- | :--- |
| **nginx-proxy** (на worker) | Локальная балансировка к API-серверам | 6443 |
| **kube-apiserver** (на master) | API Kubernetes | 6444 (локально) |

#### Ключевые переменные

| Переменная | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `loadbalancer_apiserver_localhost` | `true` | Включить локальный балансировщик на worker-нодах |
| `loadbalancer_apiserver_port` | `6443` | Порт локального балансировщика |
| `loadbalancer_apiserver` | — | Адрес и порт балансировщика (если внешний) |

#### Преимущества и ограничения

| Аспект | Описание |
| :--- | :--- |
| **Простота** | Не требует внешнего балансировщика или VIP |
| **Эффективность** | Менее эффективен — создаёт дополнительные сетевые хоппы (клиент → worker → master) |
| **Практичность** | Подходит для учебных и тестовых кластеров, где нет необходимости в единой точке входа |
| **Отказоустойчивость** | Кластер продолжает работать при потере одного мастера, но клиенты должны подключаться через разные worker-ноды |
| **Единая точка входа** | Отсутствует — для production рекомендуется внешний балансировщик с VIP |

#### Сравнение подходов

| Подход | Сценарий | Единая точка входа | Сложность |
| :--- | :--- | :--- | :--- |
| **nginx-proxy (локальный)** | Учебные/тестовые кластеры | Нет | Низкая |
| **Keepalived + HAProxy** | Production bare-metal | Да (VIP) | Средняя |
| **Внешний балансировщик** | Cloud/managed инфраструктура | Да (VIP/LB) | Высокая |
