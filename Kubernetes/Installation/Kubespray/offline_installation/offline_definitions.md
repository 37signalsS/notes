# Kubespray: Offline установка — Определения

## Определения

**Offline-кластер (Air-gapped)** — кластер Kubernetes, развёртываемый в изолированной среде без доступа к интернету. Все необходимые пакеты, образы контейнеров и зависимости должны быть предварительно загружены и доставлены в закрытый контур.

**Закрытый контур** — изолированная сеть без прямого доступа к интернету, требующая локальных реестров образов и зеркал пакетов.

**Открытый контур** — сеть с доступом к интернету, используемая для предварительной загрузки артефактов.

**Kubespray** — инструмент автоматизации развёртывания Kubernetes на базе Ansible, поддерживающий встроенную настройку offline-режима через механизм кэширования артефактов. Обзор в [overview.md](../overview.md).

**Harbor** — корпоративный реестр контейнерных образов с поддержкой Helm-чартов, используемый в offline-средах для локального хранения образов. Обзор в [Harbor overview](../../../../Docker/Docker_registries/Harbor/overview.md).

**Локальный кэш Kubespray** — директория на узле с интернетом, куда Kubespray загружает все необходимые артефакты (бинарные файлы, образы, Helm-чарты) для последующей передачи в закрытый контур.

**Артефакты** — бинарные файлы Kubernetes, образы контейнеров, Helm-чарты и Python-зависимости, необходимые для установки кластера.

**CNI (Container Network Interface)** — плагин сетевой связности подов; в данном гайде используется Cilium. Подробнее в [CNI definitions](../../../Networking/Network/CNI/definitions.md).

**MetalLB** — балансировщик нагрузки для bare-metal кластеров, назначающий внешние IP сервисам типа `LoadBalancer`. Подробнее в [MetalLB](../../../Networking/metallb.md).

## Основные концепции

### Архитектура offline-развертывания

```
┌─────────────────────────────────────────────────────────────┐
│                   Открытый контур (INET)                    │
│  ┌─────────────┐                                            │
│  │   pc-inet   │ ──┐ Загрузка артефактов:                  │
│  │ 192.168.1.99│   │ - Python зависимости                  │
│  └─────────────┘   │ - Образы контейнеров                  │
│        │           │ - Helm чарты                          │
│        ▼           │ - Бинарные файлы (kubeadm, helm)      │
│  ┌─────────────────┴─────────────────────────────────────┐  │
│  │        /opt/kubespray-cache/                          │  │
│  │        /opt/kubespray-releases/                       │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
                          │
                          │ Перенос архивов
                          ▼
┌─────────────────────────────────────────────────────────────┐
│                   Закрытый контур (NO INET)                 │
│  ┌─────────────┐     ┌─────────────────────────────────┐    │
│  │ Harbor      │     │  master-1-k8s (Ansible control) │    │
│  │192.168.1.100│◄────┤  192.168.1.101                  │    │
│  │  - k8s/*    │     │  - Kubespray inventory          │    │
│  │  - helm/*   │     │  - group_vars                   │    │
│  └─────────────┘     └──────────┬──────────────────────┘    │
│                                 │                            │
│              ┌──────────────────┼──────────────────┐         │
│              ▼                  ▼                  ▼         │
│       master-2,3           node-1,2        MetalLB VIP       │
│      192.168.1.102-103   192.168.1.104-105   192.168.1.200   │
└─────────────────────────────────────────────────────────────┘
```

### Версии компонентов (гайд)

| Компонент | Версия |
| :--- | :--- |
| Kubespray | v2.29.1 |
| Kubernetes | v1.34.3 |
| Cilium | v1.18.5 |
| MetalLB | v0.13.9 |
| Ingress-nginx | v1.13.3 |
| Helm | 3.18.4 |

> **Важно:** Версии должны соответствовать матрице совместимости Kubespray. Проверьте поддерживаемые версии в файле `roles/download/defaults/main.yml`.
