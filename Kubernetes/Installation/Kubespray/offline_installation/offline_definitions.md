# Kubespray: Offline установка — Определения

## Определения

**Offline-кластер (Air-gapped)** — кластер Kubernetes, развертываемый в изолированной среде без доступа к интернету. Все необходимые пакеты, образы контейнеров и зависимости должны быть предварительно загружены и доставлены в закрытый контур.

**Kubespray** — инструмент автоматизации развертывания Kubernetes на базе Ansible, поддерживающий встроенную настройку offline-режима через механизм кэширования артефактов. Подробнее в [обзоре Kubespray](../overview.md).

**Harbor** — корпоративный реестр контейнерных образов с поддержкой Helm-чартов, используемый в offline-средах для локального хранения образов. Подробнее в [обзоре Harbor](../../../../Docker/Docker_registries/Harbor/overview.md).

**Локальный кэш Kubespray** — директория на узле с интернетом, куда Kubespray загружает все необходимые артефакты (бинарные файлы, образы, Helm-чарты) для последующей передачи в закрытый контур.

## Ключевые компоненты offline-установки

| Компонент | Назначение |
| :--- | :--- |
| **pc-inet** | Узел с доступом в интернет для предварительной загрузки артефактов |
| **Harbor** | Локальный реестр образов в закрытом контуре |
| **Control Plane** | Узлы управления кластером (master) |
| **Worker Nodes** | Рабочие узлы для запуска нагрузок |
| **MetalLB** | Балансировщик нагрузки для bare-metal кластеров |
| **Cilium** | CNI-плагин на базе eBPF для сети и безопасности |

## Архитектура offline-развертывания

```
┌─────────────────────────────────────────────────────────────┐
│                   Открытый контур (INET)                    │
│  ┌─────────────┐                                            │
│  │   pc-inet   │ ──┐ Загрузка артефактов:                  │
│  │ 192.168.1.99│   │ - Python зависимости                  │
│  └─────────────┘   │ - Образы контейнеров                  │
│        │           │ - Helm чарты                          │
│        ▼           │ - Бинарные файлы (kubeadm, helm)      │
│  ┌─────────────────┴─────────────────────────────────────┐  │
│  │        /opt/kubespray-cache/                          │  │
│  │        /opt/kubespray-releases/                       │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
                          │
                          │ Перенос архивов
                          ▼
┌─────────────────────────────────────────────────────────────┐
│                   Закрытый контур (NO INET)                 │
│  ┌─────────────┐     ┌─────────────────────────────────┐    │
│  │ Harbor      │     │  master-1-k8s (Ansible control) │    │
│  │192.168.1.100│◄────┤  192.168.1.101                  │    │
│  │  - k8s/*    │     │  - Kubespray inventory          │    │
│  │  - helm/*   │     │  - group_vars                   │    │
│  └─────────────┘     └──────────┬──────────────────────┘    │
│                                 │                            │
│              ┌──────────────────┼──────────────────┐         │
│              ▼                  ▼                  ▼         │
│       master-2,3           node-1,2        MetalLB VIP       │
│      192.168.1.102-103   192.168.1.104-105   192.168.1.200   │
└─────────────────────────────────────────────────────────────┘
```
