# Kubespray: Offline установка — Шаг 1: Подготовка виртуальных серверов

## Определения

**VM Preparation (Подготовка ВМ)** — процесс первичной настройки виртуальных машин перед развёртыванием Kubernetes, включающий выделение ресурсов, установку ОС, конфигурацию SSH и системных параметров.

**k8s-ans-bootstrap** — вспомогательный Ansible-плейбук, предназначенный для автоматизации базовой подготовки узлов кластера (отключение swap, настройка сетевых модулей и т.д.).

---

## Основные концепции

### Инфраструктура offline-кластера

Специфика offline-установки требует наличия выделенных узлов для локального реестра (Harbor) и шлюза управления (pc-inet). Детальное описание ролей и IP-адресации приведено в [практических сценариях offline-установки](./offline_practical.md#инфраструктурный-план-кластера).

### Минимальная конфигурация виртуальных машин

Детальные параметры ресурсов (CPU/RAM/SSD) и целевой IP-план для каждого узла приведены в **[Инфраструктурном плане offline-установки](./offline_practical.md#инфраструктурный-план-кластера)**.

### Предварительные требования

Перед началом автоматизированной подготовки необходимо обеспечить:

1. **Установленную ОС Ubuntu 24.04** на всех узлах.
2. **Наличие пользователя с правами sudo** (в примерах используется `admin`).
3. **SSH-доступ** с узла `master-1` ко всем остальным участникам кластера.

---

## Практические сценарии

### Настройка SSH-доступа

Все операции по установке запускаются с `master-1-k8s`. Необходимо сгенерировать и распространить SSH-ключи.

**Генерация ключа на master-1:**

```bash
ssh-keygen -t rsa -b 4096
```

**Копирование ключа на узлы:**

```bash
ssh-copy-id admin@192.168.1.102
ssh-copy-id admin@192.168.1.103
ssh-copy-id admin@192.168.1.104
ssh-copy-id admin@192.168.1.105
```

### Автоматизация подготовки через k8s-ans-bootstrap

Для минимизации ручных операций используется плейбук, который выполняет стандартные требования Kubernetes (отключение SWAP, Firewall, SELinux).

1. **Клонирование репозитория (на pc-inet):**

   ```bash
   git clone https://github.com/ZM56/k8s-ans-bootstrap.git
   ```

2. **Запуск плейбука:**

   ```bash
   cd k8s-ans-bootstrap
   # Отредактируйте inventory.ini и group_vars под вашу инфраструктуру
   ansible-playbook -i inventory.ini play.yml -u admin
   ```

### Обязательные настройки узлов

Плейбук автоматически реализует требования, описанные в **[SSoT: Подготовка узлов](../../HA_Cluster_Bare_Metal/k8s_ha_node_preparation.md)**. Основные действия включают:

- **Отключение SWAP** (требование kubelet).
- **Отключение Firewalld/UFW** (предотвращение блокировок CNI).
- **Настройка SELinux** (перевод в режим Permissive).

### Проверка готовности

После завершения работы плейбука убедитесь в корректности настроек:

**Проверка SSH и беспарольного sudo:**

```bash
ssh admin@192.168.1.102 "sudo whoami" # Должен вернуть root
```

**Проверка системных параметров:**
Подробный алгоритм проверки приведен в разделе **[Итоговая проверка готовности](../../HA_Cluster_Bare_Metal/k8s_ha_node_preparation.md#шаг-10-итоговая-проверка-готовности)**.
