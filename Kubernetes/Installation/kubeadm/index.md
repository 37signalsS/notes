# Установка Kubernetes через kubeadm

## Определения

**kubeadm** — официальная утилита для создания и управления жизненным циклом кластеров Kubernetes. Автоматизирует инициализацию Control Plane и присоединение рабочих узлов.

**CRI (Container Runtime Interface)** — стандарт интерфейса для взаимодействия `kubelet` со средой выполнения контейнеров (например, `containerd`).

**CNI (Container Network Interface)** — стандарт интерфейса для сетевых плагинов, обеспечивающих связность между подами.

**Control Plane** — уровень управления кластером (API-сервер, планировщик, контроллеры).

**Worker Node** — узел, на котором запускаются пользовательские контейнеры под управлением `kubelet`.

**cgroup driver** — механизм управления ресурсами в Linux. В Kubernetes рекомендуется использовать `systemd` для стабильной работы.

## Основные концепции

### Структура процесса развёртывания

Развёртывание через `kubeadm` включает следующие этапы:

1. **Подготовка ОС**: настройка модулей ядра, отключение swap, настройка `sysctl` параметров сети.
2. **Runtime**: установка и настройка среды выполнения (рекомендуется `containerd` с драйвером `systemd`).
3. **Утилиты**: установка пакетов `kubeadm`, `kubelet` и `kubectl` одной версии.
4. **Инициализация**: выполнение `kubeadm init` на первом узле управления.
5. **Сеть (CNI)**: установка плагина (например, Calico) для обеспечения межподового взаимодействия.
6. **Масштабирование**: присоединение воркеров или дополнительных мастеров через `kubeadm join`.
