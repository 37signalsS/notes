# Управление кластером RKE с помощью kubectl

При развертывании кластера Kubernetes с помощью RKE (Rancher Kubernetes Engine) через Rancher UI, `kubectl` не устанавливается автоматически на узлы Control Plane, как это происходит при использовании `kubeadm`. Для управления таким кластером из командной строки необходимо вручную установить `kubectl` и получить конфигурационный файл (`kubeconfig`) из Rancher.

## Установка kubectl

1.  **Скачайте бинарный файл `kubectl`**: Загрузите соответствующую вашему окружению версию утилиты `kubectl` с официального сайта Kubernetes. Убедитесь, что версия `kubectl` соответствует версии вашего кластера Kubernetes.

    ```bash
    # Пример для Linux AMD64 (замените версию на актуальную)
    curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
    ```

2.  **Сделайте файл исполняемым**:

    ```bash
    chmod +x kubectl
    ```

3.  **Переместите в PATH**: Переместите бинарный файл в директорию, доступную в вашем `$PATH` (например, `/usr/local/bin`).

    ```bash
    sudo mv kubectl /usr/local/bin/
    ```

4.  **Проверьте установку**:

    ```bash
    kubectl version --client
    ```

## Получение kubeconfig из Rancher

1.  **Перейдите в Rancher UI**: Откройте веб-интерфейс Rancher.
2.  **Выберите кластер**: Перейдите в `Cluster Dashboard` для вашего RKE-кластера.
3.  **Получите `kubeconfig`**: Найдите кнопку `Kubeconfig File` (или аналогичную, обычно в верхнем правом углу) и скопируйте ее содержимое в буфер обмена.
4.  **Сохраните `kubeconfig` локально**: На вашей локальной машине (или на Control Plane узле, если хотите управлять оттуда), создайте директорию `~/.kube`, если ее нет, и сохраните скопированное содержимое в файл `config`.

    ```bash
    mkdir -p $HOME/.kube
    # Используйте текстовый редактор для вставки содержимого в $HOME/.kube/config
    # nano $HOME/.kube/config
    # (вставьте содержимое)
    ```
    *Примечание: Если у вас уже есть `~/.kube/config`, рассмотрите возможность слияния конфигураций или используйте переменную окружения `KUBECONFIG`.*

5.  **Установите права доступа** (если необходимо):

    ```bash
    chmod 600 $HOME/.kube/config
    ```

## Проверка подключения

Теперь вы можете использовать `kubectl` для взаимодействия с вашим RKE-кластером:

```bash
kubectl get nodes
kubectl get pods --all-namespaces
```
