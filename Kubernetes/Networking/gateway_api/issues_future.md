# Нерешенные вопросы и будущее Gateway API

## Нерешенные вопросы и будущее

### Проблема тонкой настройки (Provider-Specific Configuration)

Одной из нерешенных проблем Gateway API является механизм тонкой настройки специфичных для провайдера параметров (аналогично аннотациям в Ingress). Стандартные ресурсы `HTTPRoute` и другие не покрывают все возможные опции, которые предоставляют контроллеры (например, таймауты, лимиты, специфические алгоритмы балансировки).

Есть вероятность, что решение вернется к использованию аннотаций на ресурсах Gateway API, что может частично подорвать идею полной переносимости. Этот вопрос активно обсуждается в сообществе.
