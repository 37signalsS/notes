# Сводка по типам Service

## Определения

**Сводка по типам Service** — сравнительный анализ всех типов сервисов Kubernetes, предназначенный для выбора оптимального способа публикации приложения.

Для понимания основ архитектуры и принципов работы см. [Обзор Service](./service_overview.md).

## Основные концепции

### Иерархия и взаимосвязь типов

Большинство типов сервисов (кроме `ExternalName` и `Headless`) расширяют функциональность базового типа:

1. **ClusterIP** (базовый) — только внутренний доступ.
2. **NodePort** (ClusterIP + порт на узлах) — внешний доступ через IP любого узла.
3. **LoadBalancer** (NodePort + облачный балансировщик) — автоматическая внешняя публикация в облаке.

### Сравнительные характеристики типов

| Тип | Доступность | Уровень OSI | Основной сценарий |
| :--- | :--- | :--- | :--- |
| **[ClusterIP](./service_type_clusterip.md)** | Внутри кластера | L4 | Внутренние связи (backend ↔ db) |
| **[NodePort](./service_type_nodeport.md)** | Снаружи (через узлы) | L4 | Разработка, отладка, on-prem |
| **[LoadBalancer](./service_type_loadbalancer.md)** | Снаружи (через IP облака) | L4 | Production в облачных средах |
| **[ExternalName](./service_type_externalname.md)** | Только DNS | DNS | Доступ к внешним ресурсам (CNAME) |
| **[Headless](./service_type_headless.md)** | Прямой доступ к подам | L4 | Stateful-приложения (StatefulSet) |
| **[Ingress](../Ingress/overview.md)** | Снаружи (L7 прокси) | L7 | HTTP/HTTPS маршрутизация |

### Ограничения и особенности

| Тип | Ключевое ограничение |
| :--- | :--- |
| **ClusterIP** | Недоступен извне без port-forward. |
| **NodePort** | Требует открытия портов 30000–32767 на узлах. |
| **LoadBalancer** | Зависит от облачного провайдера (в bare-metal требует MetalLB). |
| **ExternalName** | Только перенаправление DNS, трафик не проксируется. |
| **Headless** | Отсутствует балансировка на уровне сервиса. |

## Практические сценарии

### Матрица принятия решений

| Критерий | Рекомендуемый тип |
| :--- | :--- |
| Нужно ли обращаться к сервису снаружи? (Нет) | ClusterIP |
| Нужно ли обращаться к сервису снаружи? (Да, разработка) | NodePort |
| Нужно ли обращаться к сервису снаружи? (Да, Cloud Production) | LoadBalancer или Ingress |
| Это HTTP/HTTPS трафик с маршрутизацией по путям? | Ingress |
| Требуются ли стабильные имена для каждого пода? | Headless (для StatefulSet) |
| Нужно ли обратиться к внешней БД по доменному имени? | ExternalName |

## Дополнительная информация

### Расширенные свойства сервисов

Помимо основных типов, существуют механизмы, уточняющие поведение трафика:

| Свойство | Описание | Подробнее |
| :--- | :--- | :--- |
| **externalIPs** | Привязка сервиса к статическим внешним IP | [ExternalIPs](./service_externalips.md) |
| **externalTrafficPolicy** | Сохранение IP клиента (Cluster vs Local) | [NodePort](./service_type_nodeport.md#политика-внешнего-трафика-externaltrafficpolicy) |
| **sessionAffinity** | Привязка сессии клиента к одному поду | [ClusterIP](./service_type_clusterip.md) |
