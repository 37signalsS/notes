# Red Hat OpenShift

## Определения

OpenShift — это дистрибутив Kubernetes от компании Red Hat, который предоставляет готовую к использованию платформу (PaaS) с дополнительными возможностями. Он является надстройкой над "ванильным" Kubernetes, добавляя инструменты и ужесточая политики для упрощения разработки и повышения безопасности в enterprise-среде.

## Основные концепции

OpenShift отличается от "чистого" Kubernetes следующими ключевыми особенностями:

* **Строгая безопасность по умолчанию:** Запрещает запуск контейнеров от root-пользователя и использует более строгие Security Context Constraints (SCC).
* **Встроенные инструменты для разработчиков:**
  * **Source-to-Image (S2I):** Механизм для сборки образов контейнеров из исходного кода без Dockerfile.
  * **Встроенный CI/CD:** Предоставляет Jenkins-пайплайны и Tekton для автоматизации сборки и развертывания.
  * **Веб-консоль:** Удобный UI для управления приложениями.
* **Встроенный реестр образов:** Интегрированный Docker Registry.
* **Коммерческая поддержка:** Полноценная поддержка от Red Hat.

## Практические сценарии

* **Ускорение разработки:** Готовый UI и инструменты (S2I, CI/CD) упрощают и ускоряют жизненный цикл разработки.
* **Повышенная безопасность:** Строгие политики безопасности по умолчанию делают его предпочтительным в enterprise-сегменте.
* **Решение "под ключ":** Команда эксплуатации поддерживает платформу, а разработчики сосредоточены на использовании ее возможностей.

## Дополнительная информация

* **Сложность и "Vendor Lock-in":** Являясь надстройкой над Kubernetes, может вносить дополнительную сложность в управление и создавать зависимость от экосистемы Red Hat.
* **Требовательность к ресурсам:** Может потреблять больше ресурсов, чем "чистый" Kubernetes.
