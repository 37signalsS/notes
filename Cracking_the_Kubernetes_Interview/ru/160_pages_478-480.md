Диагностика входного пути
Ingress — это не что-то одно, а цепочка компонентов, которые должны работать вместе.Запрос
от пользователя должен успешно пройти по этому пути:
Внешний DNS → Облачный балансировщик нагрузки → Ingress Controller → Сервис → Pod
Весь этот путь вместе с ключевыми командами и проверками для каждого этапа представлен на рис.

•
Узнайте, есть ли какие-либо ошибки в их журналах, выполнив следующее:
kubectl журналы <ingress-controller-pod>
Это может выявить такие проблемы, как невозможность найти серверную службу или ошибки с
перезагрузка его конфигурации.

Контроллер может добраться до конечного пункта назначения.Самый точный тест – это выполнить

curl http://<имя-службы>.<пространство имен службы>.svc.cluster.local

правильно, и проблема находится дальше по течению.
