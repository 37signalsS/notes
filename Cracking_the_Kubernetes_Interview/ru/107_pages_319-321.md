Рабочие процессы GitOps.

Что такое архитектура Argo CD?
Компакт-диск Argo состоит из трех основных компонентов, которые работают вместе, обеспечивая бесперебойную работу ваших приложений. 
синхронно с желаемым состоянием, определенным в ваших репозиториях Git:
1.	
Контроллер приложений. Этот компонент постоянно отслеживает приложения, сравнивая 
их живое состояние по сравнению с желаемым состоянием, указанным в репозитории Git. Когда расхождение
обнаружены отклонения, контроллер приложения может предпринять корректирующие действия для согласования 
два государства.
2.	
Сервер репозитория. Сервер репозитория поддерживает локальный кеш ваших репозиториев Git и 
отвечает за создание манифестов Kubernetes. Этот механизм кэширования помогает оптимизировать 
производительность за счет уменьшения необходимости частых операций выборки git.
3.	
Сервер API. Сервер API предоставляет конечные точки для веб-интерфейса пользователя Argo CD, интерфейса командной строки и внешних 
систем, облегчая управление развертыванием и повышая безопасность. Это позволяет пользователям 
взаимодействовать с Argo CD через RESTful API, что упрощает автоматизацию и интеграцию.
