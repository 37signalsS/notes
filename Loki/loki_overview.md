# Обзор Loki

Loki — это горизонтально масштабируемая, высокодоступная, мульти-тенантовая система агрегации логов, разработанная Grafana Labs. Она вдохновлена Prometheus и использует аналогичный подход к индексации логов, фокусируясь на метаданных (метках), а не на полном тексте логов.

## Ключевые особенности

*   **Индексация только метаданных:** Loki индексирует только метки (labels) логов, а не их полное содержимое. Это значительно снижает затраты на хранение и повышает производительность запросов.
*   **Prometheus-подобная модель:** Использует те же механизмы обнаружения сервисов и тегирования, что и Prometheus, что упрощает интеграцию.
*   **LogQL:** Язык запросов, похожий на PromQL, для фильтрации и агрегации логов.
*   **Масштабируемость:** Разработан для горизонтального масштабирования и высокой доступности.
*   **Интеграция с Grafana:** Идеально интегрируется с Grafana для визуализации и анализа логов.

## Компоненты Loki

Типичная архитектура Loki включает следующие компоненты:

1.  **Loki (сервер):** Основной сервер, который принимает логи от Promtail, индексирует их метки и хранит данные логов.
2.  **Promtail:** Агент для сбора логов, который устанавливается на каждой ноде кластера. Он обнаруживает логи, добавляет к ним метки и отправляет их в Loki.
3.  **Grafana:** Используется для создания дашбордов, выполнения запросов LogQL и визуализации логов, собранных Loki.

## Принцип работы

1.  **Сбор логов:** Promtail считывает логи из файлов (например, из `/var/log/pods` в Kubernetes), добавляет к ним метки (например, `namespace`, `pod_name`, `container_name`) и отправляет их в Loki.
2.  **Индексация и хранение:** Loki получает логи, индексирует только их метки и сохраняет сами логи в объектном хранилище (например, S3, GCS) или локальной файловой системе.
3.  **Запросы:** Пользователи используют Grafana и LogQL для запроса логов. Loki использует индексированные метки для быстрого поиска релевантных потоков логов, а затем извлекает фактические данные логов из хранилища.

## Преимущества Loki

*   **Экономичность:** Низкие затраты на хранение благодаря индексации только метаданных.
*   **Простота эксплуатации:** Относительно прост в развертывании и управлении по сравнению с полнотекстовыми системами индексации логов.
*   **Производительность:** Быстрые запросы благодаря эффективной индексации и LogQL.
*   **Интеграция:** Глубокая интеграция с экосистемой Grafana.

Loki является отличным выбором для тех, кто ищет экономичное и масштабируемое решение для централизованного сбора и анализа логов, особенно в среде Kubernetes.
