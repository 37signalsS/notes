# Настройка Grafana для визуализации логов Loki

## Определения

**Grafana** — универсальная платформа для визуализации и анализа данных телеметрии. В контексте работы с Loki она выступает в роли основного интерфейса для выполнения запросов на языке LogQL, отображения логов и корреляции их с другими сигналами (метриками и трассировками).

**Loki Data Source** — специализированный коннектор Grafana, оптимизированный для работы с лейблами Loki. Он поддерживает расширенные функции, такие как автоматический парсинг логов, визуализация частоты сообщений и глубокая интеграция с распределенными трассировками.

**Подробнее:** [Обзор Grafana](../../Grafana/grafana_overview.md), [Обзор Grafana Loki](../loki_overview.md)

## Основные концепции

### Интеграция Grafana и Loki

| Компонент | Назначение | Примечание |
| :--- | :--- | :--- |
| **Loki Gateway** | Единая точка входа для запросов | Обычно реализуется через Nginx или Ingress |
| **LogQL Query Engine** | Выполнение запросов на стороне Grafana | Поддерживает как чтение сырых логов, так и генерацию метрик |
| **Explore Mode** | Инструмент для оперативной диагностики | Позволяет быстро переключаться между логами разных подов и сервисов |
| **Data Links** | Кликабельные ссылки в логах | Позволяют переходить к дашбордам или внешним системам на основе подов/лейблов |

### Механизмы корреляции данных

1.  **Derived Fields (Производные поля):** Метод извлечения данных из текста лога (например, `trace_id`) с помощью регулярных выражений для создания ссылок на другие источники данных.
2.  **Internal Links:** Начиная с Grafana 10+, реализована более тесная интеграция, позволяющая настраивать связи между источниками данных непосредственно в конфигурации JSON/YAML.
3.  **Ad-hoc Filters:** Возможность фильтрации логов на дашбордах с использованием переменных, общих для метрик Prometheus и логов Loki.

## Практические сценарии

### Сценарий 1: Конфигурация через Provisioning (Helm)

Использование `values.yaml` для автоматического развертывания настроенного источника данных. Это гарантирует воспроизводимость конфигурации.

**Пример конфигурации для Helm-чарта Grafana:**

```yaml
datasources:
  datasources.yaml:
    apiVersion: 1
    datasources:
      - name: Loki
        type: loki
        access: proxy
        url: http://loki-gateway.logging.svc.cluster.local:80
        isDefault: true
        editable: false
        jsonData:
          maxLines: 1000
          # Настройка связи с Tempo для TraceID
          derivedFields:
            - name: TraceID
              matcherRegex: "trace_id=(\\w+)"
              url: "$${__value.raw}"
              datasourceUid: tempo
              matcherType: Label
          # Оптимизация запросов
          queryTimeout: 60s
          incrementalLoading: true
```

### Сценарий 2: Настройка Data Links для быстрой навигации

Data Links позволяют превратить лейблы (например, `pod` или `container`) в активные ссылки, ведущие на специализированные дашборды.

1.  Откройте настройки источника **Loki**.
2.  Перейдите в раздел **Data links**.
3.  Добавьте новую ссылку:
    *   **Label:** `pod`
    *   **URL:** `/d/k8s-pod-resources?var-pod=${__value.raw}`
    *   **Title:** «Посмотреть ресурсы пода»

### Сценарий 3: Визуализация и поиск в Explore

Инструмент Explore является основным для работы SRE-инженера при локализации инцидента.

**Рекомендуемый рабочий процесс:**
1.  Выбрать источник **Loki**.
2.  Использовать **Log Browser** для выбора нужных лейблов (`app`, `env`, `namespace`).
3.  Применить парсеры (например, `| json`) для превращения неструктурированного текста в таблицу полей.
4.  Нажать на `trace_id` в результатах поиска для мгновенного перехода в **Grafana Tempo**.

## Дополнительная информация

### Устранение неисправностей

| Проблема | Возможная причина | Путь решения |
| :--- | :--- | :--- |
| **Ошибка 502/504 при запросе** | Таймаут Querier или Gateway | Увеличьте `query_timeout` в настройках источника и в конфигурации Loki |
| **Пустые результаты поиска** | Несоответствие лейблов или временного диапазона | Проверьте наличие данных через `logcli` и синхронизацию времени на нодах |
| **Derived Fields не работают** | Ошибка в регулярном выражении | Проверьте формат логов (json vs logfmt) и экранирование спецсимволов в Regex |
