# Vagrant на macOS Apple Silicon (M1/M2/M3)

## Определения

**Apple Silicon (M-серия)** — архитектура процессоров Apple (ARM64), которая требует специфических методов виртуализации. В отличие от систем Intel (x86_64), здесь невозможно использовать стандартный VirtualBox (на момент 2026 года его поддержка остается экспериментальной или нестабильной).

**vagrant-qemu** — специализированный плагин-провайдер для Vagrant, использующий эмулятор **QEMU** и нативный гипервизор Apple (**Hypervisor.framework**) для достижения нативной скорости работы.

## Этап 1: Установка системных компонентов (Host)

На macOS Apple Silicon используется нативный гипервизор Apple через эмулятор QEMU.

1. **Установка QEMU:**
   ```bash
   brew install qemu
   ```
   Устанавливает `qemu-system-aarch64` (движок виртуализации) и `qemu-img` (утилита для работы с образами дисков).

2. **Установка Vagrant:**
   ```bash
   brew install --cask vagrant
   ```

3. **Установка плагина-провайдера:**
   ```bash
   vagrant plugin install vagrant-qemu
   ```
   **Почему QEMU:** Плагин разработан специально для macOS, не требует прав root и использует **SLIRP (User-mode networking)**, что предотвращает конфликты с сетевым стеком macOS (в отличие от Libvirt, который часто ломается при создании Bridge-интерфейсов на Mac).

## Этап 2: Выбор базового образа (Box)

Для Apple Silicon подходят **только** образы архитектуры `arm64` или `aarch64`.
* **Рекомендуемые:** `cloud-image/ubuntu-26.04` или `generic/ubuntu2204-arm64`.
* **Внимание:** Попытка запустить `x86_64` образ приведет к критическому падению производительности из-за программной эмуляции.

## Этап 3: Конфигурация Vagrantfile

Эталонный блок конфигурации для нативной скорости на чипах M-серии:

```ruby
Vagrant.configure("2") do |config|
  config.vm.box = "cloud-image/ubuntu-26.04"
  config.vm.guest = :ubuntu

  config.vm.provider "qemu" do |qemu|
    # 1. Тип машины и ускорение
    # virt — стандартная плата для ARM64.
    # accel=hvf — включает Apple Hypervisor.framework (нативная скорость).
    qemu.machine = "virt,accel=hvf"

    # 2. Проброс процессора
    # host — гостевая ОС видит реальные инструкции чипа M-серии.
    qemu.cpu = "host"

    # 3. Сетевой адаптер
    # virtio-net-pci — самый быстрый тип виртуальной сети.
    qemu.net_device = "virtio-net-pci"

    # 4. Ресурсы
    qemu.memory = "2G"
    qemu.smp = "cpus=2"    # ppggff/vagrant-qemu 0.6.0
  end

  # 5. Синхронизация папок
  # rsync — обязателен для QEMU на macOS.
  # Стандартные методы (vboxsf/9p) здесь работают нестабильно.
  config.vm.synced_folder ".", "/linux-lab", type: "rsync"
end
```

## Этап 4: Запуск и управление

1. **Первый запуск:**
   ```bash
   vagrant up --provider=qemu
   ```
   *Примечание: Vagrant может один раз запросить пароль администратора для настройки rsync.*

2. **Синхронизация файлов:**
   При использовании `rsync` изменения на хосте не попадают в ВМ мгновенно. Для автоматической синхронизации запустите в отдельном терминале:
   ```bash
   vagrant rsync-auto
   ```

3. **Вход в машину:**
   ```bash
   vagrant ssh
   ```

## Технические особенности (Шпаргалка)

* **Порты:** Плагин `vagrant-qemu` по умолчанию пробрасывает SSH на порт **50022** (вместо стандартного 2222) для избежания конфликтов.
* **UEFI:** Архитектура ARM64 всегда требует UEFI для загрузки. Плагин `vagrant-qemu` автоматически находит прошивку в `/opt/homebrew/share/qemu/`.
* **Архитектура бинарников:** Любое ПО, собранное внутри такой ВМ, будет иметь архитектуру `arm64`. Для запуска на серверах Intel потребуется мультиплатформенная сборка (см. **[Docker Buildx](../../Docker/Dockerfile/docker_buildx.md)**).
