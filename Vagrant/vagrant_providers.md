# Провайдеры и образы (Boxes) в Vagrant

## Определения

**Провайдер (Provider)** — программный слой или «движок» виртуализации, который Vagrant использует для создания и управления виртуальными машинами. Vagrant служит унифицированным интерфейсом, абстрагирующим работу с различными гипервизорами (VirtualBox, Libvirt, VMware), контейнеризаторами (Docker) и облачными платформами (AWS, Azure).

**Образ (Box)** — базовый шаблон виртуальной машины, упакованный в специфический формат Vagrant. Содержит предустановленную операционную систему, настроенного пользователя (обычно `vagrant`) и минимальный набор системных инструментов. Образы жестко привязаны к провайдеру: файл образа для VirtualBox несовместим с Libvirt из-за различий в форматах дисков и метаданных.

> **Важно:** С 2026 года компания Canonical прекратила выпуск официальных образов Ubuntu для Vagrant (начиная с версии 24.04 Noble Numbat). Для новых проектов рекомендуется использовать проверенные альтернативы от сообществ, такие как `bento/ubuntu-24.04` или официальные образы дистрибутивов, продолжающих поддержку (например, AlmaLinux, Debian).

## Базовые концепции

### Взаимосвязь провайдеров и образов

Каждый образ содержит файл метаданных, указывающий на поддерживаемого провайдера. При попытке запустить ВМ с несовместимым провайдером Vagrant выдаст ошибку.

**Просмотр установленных образов:**

```bash
# Список локальных образов с указанием их провайдеров
vagrant box list
```

**Поиск и Vagrant Cloud:**
Основным источником образов является [Vagrant Cloud](https://app.vagrantup.com/boxes/search). Здесь доступны как официальные образы вендоров, так и сборки сообщества.

### Версионирование образов

Vagrant поддерживает версионирование образов, что позволяет фиксировать окружение для всей команды.

```ruby
Vagrant.configure("2") do |config|
  config.vm.box = "bento/ubuntu-24.04"
  # Фиксация версии: ~> означает "совместимая с 202501" (например, 202501.1)
  config.vm.box_version = "~> 202501.0"
end
```

Доступные операторы: `>=`, `<=`, `>`, `<`, `~>`.

## Практические сценарии

### Сценарий 1: Расширенная конфигурация провайдеров

Настройка ресурсов и специфических функций гипервизора напрямую в `Vagrantfile`.

**Настройка Libvirt (рекомендуется для Linux):**

Требует плагин `vagrant-libvirt`.

```ruby
config.vm.provider "libvirt" do |lv|
  lv.memory = 4096
  lv.cpus = 4
  lv.nested = true                 # Включение вложенной виртуализации (VT-x/AMD-V)
  lv.cpu_mode = "host-passthrough" # Проброс модели CPU хоста для максимальной производительности
  lv.storage_pool_name = "default"
  lv.machine_virtual_size = 50     # Размер основного диска в ГБ
end
```

**Настройка VirtualBox (кроссплатформенный стандарт):**

```ruby
config.vm.provider "virtualbox" do |vb|
  vb.name = "project-dev-vm"
  vb.memory = 2048
  vb.cpus = 2
  vb.gui = false                   # Фоновый режим (без окна GUI)
  vb.linked_clone = true           # Быстрое создание из базового образа (экономия места)
  
  # Оптимизация сетевого резолвера
  vb.customize ["modifyvm", :id, "--natdnshostresolver1", "on"]
end
```

### Сценарий 2: Управление образами

**Добавление образов из различных источников:**

```bash
# Из Vagrant Cloud
vagrant box add bento/ubuntu-24.04

# По прямой ссылке (URL)
vagrant box add my-box https://example.com/custom.box

# Из локального файла
vagrant box add dev-base /path/to/package.box
```

**Работа с обновлениями:**

```bash
# Проверить наличие новых версий
vagrant box outdated --global

# Обновить до актуальной версии (не обновляет уже запущенные ВМ)
vagrant box update

# Удалить старые версии образов для освобождения места
vagrant box prune
```

### Сценарий 3: Аутентификация в Vagrant Cloud

Для доступа к приватным образам компании или организации необходимо авторизоваться:

```bash
# Интерактивный вход через браузер или токен
vagrant login

# Проверка текущего пользователя
vagrant whoami
```

## Дополнительная информация

### Сравнение производительности провайдеров

| Провайдер | Тип | Производительность | Платформа |
| :--- | :--- | :--- | :--- |
| **Libvirt (KVM)** | Нативный | Максимальная | Linux |
| **QEMU (HVF)** | Эмуляция | Высокая | macOS (Apple Silicon) |
| **VirtualBox** | Hosted | Средняя | Кроссплатформенный |
| **Hyper-V** | Нативный | Высокая | Windows |
| **Docker** | Контейнер | Экстремальная | Кроссплатформенный (без ядра ОС) |

### Создание собственных образов

Вы можете создать образ из текущего состояния вашей ВМ с помощью команды:

```bash
vagrant package --output my_new_box.box
```

Это упакует диск и конфигурацию в переносимый `.box` файл.
