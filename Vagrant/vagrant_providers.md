# Провайдеры и образы (Boxes) в Vagrant

## Определения

1.  **Провайдер (Provider)**
    *   Это "движок" виртуализации, который Vagrant использует для создания и управления виртуальными машинами. Vagrant выступает как унифицированная оболочка над этими системами.
    *   *Примеры*: VirtualBox, Libvirt (KVM/QEMU), Hyper-V, VMware.

2.  **Образ (Box)**
    *   Это базовый шаблон виртуальной машины, упакованный в специальный формат для Vagrant. Он содержит минимальную операционную систему и служит основой для быстрого клонирования новых, идентичных окружений.

## Базовые концепции

### Взаимосвязь провайдеров и образов

Ключевой аспект работы Vagrant — **образы создаются для конкретных провайдеров**. Нельзя использовать образ, предназначенный для VirtualBox, с провайдером Libvirt, и наоборот.

При поиске образов необходимо всегда проверять, для какого провайдера они предназначены.

### Поиск образов

Официальный портал для поиска и хранения образов — **[HashiCorp Vagrant Cloud](https://portal.cloud.hashicorp.com/vagrant/discover)**. Он позволяет фильтровать образы по имени и совместимости с нужным провайдером.

## Практические сценарии

### Сценарий 1: Настройка параметров провайдера

Вы можете задавать специфичные для провайдера настройки внутри блока `config.vm.provider` в `Vagrantfile`.

**Пример тонкой настройки для `libvirt`:**
```ruby
Vagrant.configure("2") do |config|
  # ... другие настройки ...

  config.vm.provider "libvirt" do |libvirt|
    libvirt.memory = 2048
    libvirt.cpus = 2
    # Использование virtio для лучшей производительности дисков и сети
    libvirt.disk_bus = 'virtio'
    libvirt.nic_model_type = 'virtio'
    libvirt.nested = true # Разрешить вложенную виртуализацию (KVM внутри KVM)
  end
end
```

### Сценарий 2: Смена провайдера для проекта

Чтобы сменить провайдера для существующего проекта (например, с VirtualBox на libvirt), необходимо удалить метаданные о старой машине.

**Процесс:**

1.  **Уничтожьте существующую ВМ (если она была создана):**
    ```bash
    vagrant destroy -f
    ```

2.  **Удалите директорию `.vagrant`:**
    Эта директория хранит метаданные, включая информацию о том, какой провайдер использовался.
    ```bash
    rm -rf .vagrant
    ```

3.  **Запустите окружение с новым провайдером:**
    Убедитесь, что в `Vagrantfile` указан новый провайдер, или передайте его через командную строку.
    ```bash
    vagrant up --provider=libvirt
    ```
Теперь Vagrant создаст машину с помощью нового провайдера.
