# Провайдеры и образы (Boxes) в Vagrant

## Определения

**Провайдер (Provider)** — программный слой или «движок» виртуализации, который Vagrant использует для создания и управления виртуальными машинами. Vagrant служит унифицированным интерфейсом для работы с различными гипервизорами (VirtualBox, Libvirt, VMware) и контейнеризаторами (Docker).

**Образ (Box)** — базовый шаблон виртуальной машины, упакованный в специфический формат Vagrant. Содержит предустановленную операционную систему и минимальный набор инструментов. Образы жестко привязаны к провайдеру: box для VirtualBox не будет работать с Libvirt.

> **Важно:** С 2026 года компания Canonical прекратила выпуск официальных образов Ubuntu для Vagrant (начиная с версии 24.04 Noble Numbat). Рекомендуется использовать проверенные альтернативы от сообществ HashiCorp или Bento.

## Базовые концепции

### Взаимосвязь провайдеров и образов

Образы всегда создаются под конкретный провайдер. При выборе образа необходимо убедиться, что он поддерживает используемый в проекте движок виртуализации.

**Проверка локальных образов:**

```bash
# Список установленных образов с указанием провайдера
vagrant box list
```

**Поиск в облаке:**
Все актуальные образы доступны в каталоге [Vagrant Cloud](https://portal.cloud.hashicorp.com/vagrant/discover).

### Популярные источники образов

| Источник | Описание | Имя (шаблон) |
| :--- | :--- | :--- |
| **Bento (Chef)** | Оптимизированные образы для множества ОС и провайдеров | `bento/*` |
| **HashiCorp** | Базовые демонстрационные образы | `hashicorp/*` |
| **Ubuntu** | Официальные образы от Canonical (до версии 22.04 включительно) | `ubuntu/*` |
| **AlmaLinux** | Официальные образы дистрибутива AlmaLinux | `almalinux/*` |

## Практические сценарии

### Сценарий 1: Конфигурация провайдера в Vagrantfile

Настройка ресурсов (CPU, RAM) и специфических параметров гипервизора.

**Для Libvirt (KVM/QEMU):**

```ruby
Vagrant.configure("2") do |config|
  config.vm.box = "bento/ubuntu-24.04"

  config.vm.provider "libvirt" do |libvirt|
    libvirt.memory = 2048
    libvirt.cpus = 2
    libvirt.disk_bus = 'virtio'
    libvirt.nic_model_type = 'virtio'
    libvirt.nested = true            # Включение вложенной виртуализации
  end
end
```

**Для VirtualBox:**

```ruby
Vagrant.configure("2") do |config|
  config.vm.box = "ubuntu/jammy64"
  
  config.vm.provider "virtualbox" do |v|
    v.name = "dev-machine"           # Имя в интерфейсе VirtualBox
    v.memory = 2048
    v.cpus = 2
    v.gui = false                    # Запуск без графического интерфейса
    v.linked_clone = true            # Использование связанных клонов для экономии места
    
    # Тонкая настройка через VBoxManage
    v.customize ["modifyvm", :id, "--natdnshostresolver1", "on"]
  end
end
```

### Сценарий 2: Переключение между провайдерами

Если проект поддерживает несколько провайдеров, можно переключаться между ними при запуске.

1. **Удаление текущей машины:**

   ```bash
   vagrant destroy -f
   ```

2. **Запуск с указанием провайдера:**

   ```bash
   vagrant up --provider=libvirt
   ```

### Сценарий 3: Управление жизненным циклом образов

```bash
# Добавление образа в локальное хранилище
vagrant box add bento/ubuntu-24.04

# Проверка наличия обновлений для используемых образов
vagrant box outdated

# Обновление образа до последней версии
vagrant box update

# Удаление старых версий образов
vagrant box prune

# Удаление конкретного образа
vagrant box remove ubuntu/jammy64
```

## Дополнительная информация

### Сравнение основных провайдеров

| Провайдер | Основная платформа | Производительность | Особенности |
| :--- | :--- | :--- | :--- |
| **VirtualBox** | Кроссплатформенный | Средняя | Прост в установке, стандарт по умолчанию |
| **Libvirt (KVM)** | Linux | Высокая | Нативная виртуализация, отличная производительность |
| **Hyper-V** | Windows | Высокая | Встроен в систему, требует прав администратора |
| **Docker** | Кроссплатформенный | Максимальная | Запуск контейнеров вместо полноценных ВМ |

### Рекомендации по выбору образа

- **Для разработки на Linux:** рекомендуется связка `bento/ubuntu-24.04` + `libvirt`.
- **Для кроссплатформенных команд:** рекомендуется `ubuntu/jammy64` + `virtualbox`.
- **Для минимизации размера:** образы `alpine` или `generic/*`.
