# Базовый рабочий процесс Vagrant

Vagrant упрощает управление жизненным циклом виртуальных машин с помощью нескольких ключевых команд.

## Инициализация проекта
Команда `vagrant init` создает базовый конфигурационный файл `Vagrantfile` в текущей директории.

```bash
# Инициализация с использованием образа (box) Ubuntu 22.04
vagrant init ubuntu/jammy64
```
Будет создан минимальный `Vagrantfile`:
```ruby
# Vagrantfile
Vagrant.configure("2") do |config|
  config.vm.box = "ubuntu/jammy64"
end
```

## Запуск окружения
Команда `vagrant up` скачивает box (если его нет в кэше), создает и запускает виртуальную машину согласно `Vagrantfile`.

```bash
# Запуск с указанием провайдера (например, VirtualBox)
vagrant up --provider=virtualbox
```

## Подключение по SSH
Vagrant автоматически настраивает SSH-доступ к гостевой машине.

```bash
# Посмотреть параметры для SSH-подключения
vagrant ssh-config

# Подключиться к машине
vagrant ssh
```

## Проверка статуса
Команда `vagrant status` показывает состояние управляемых машин (Running, PowerOff, Aborted и т.д.).

```bash
vagrant status
```

## Применение изменений (Provisioning и Reload)
Для применения изменений в `Vagrantfile` или повторного запуска скриптов настройки (provisioning) используются следующие команды:

```bash
# Перезагрузить машину для применения изменений в Vagrantfile
vagrant reload

# Запустить только provisioning на работающей машине
vagrant provision

# Перезагрузить и принудительно применить provisioning
vagrant reload --provision
```

## Приостановка и возобновление
Эти команды позволяют быстро сохранить и восстановить состояние ВМ.

*   `vagrant suspend`: Сохраняет текущее состояние ВМ на диск и останавливает ее (быстрый способ "поставить на паузу").
*   `vagrant resume`: Восстанавливает ВМ из сохраненного состояния.

## Остановка и выключение
*   `vagrant halt`: Корректно завершает работу гостевой операционной системы и останавливает ВМ.

## Удаление окружения
Команда `vagrant destroy` останавливает, удаляет виртуальную машину и все связанные с ней ресурсы (диски, сетевые интерфейсы).

```bash
vagrant destroy -f # Флаг -f для подтверждения без дополнительного запроса
```

При выполнении `vagrant destroy` происходит следующее:
1.  **Уничтожаются виртуальные машины**, определенные в `Vagrantfile`.
2.  **Удаляются диски** этих виртуальных машин из пула хранения провайдера. **Все данные внутри ВМ теряются безвозвратно.**
3.  **Удаляются созданные сетевые интерфейсы.**
4.  **Очищаются метаданные Vagrant** (директория `.vagrant`).

**Что НЕ будет удалено:**
*   **Базовый образ (box):** Он останется в кэше Vagrant (`~/.vagrant.d/boxes`).
*   **Файлы проекта:** `Vagrantfile` и другие ваши файлы остаются нетронутыми.
*   **Пул хранения провайдера:** Сам пул не затрагивается, удаляются только созданные Vagrant тома внутри него.
