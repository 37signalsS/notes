# Конфигурационный файл Vagrantfile

## Определения

**`Vagrantfile`** — это сердце любого проекта Vagrant. Это конфигурационный файл, написанный на Ruby, который описывает, как Vagrant должен сконфигурировать и настроить виртуальные машины. Он является единым источником истины для всего окружения.

## Базовые концепции

### Структура файла

Файл использует простой DSL (предметно-ориентированный язык). Основная конфигурация заключается в блок `Vagrant.configure`.

```ruby
# Указываем версию синтаксиса "2" (актуальная).
Vagrant.configure("2") do |config|
  # config - это главный объект, через который настраивается ВМ.
  # Все параметры, описанные ниже, задаются внутри этого блока.
end
```

### Ключевые параметры конфигурации

| Параметр | Пример | Описание |
| --- | --- | --- |
| `config.vm.box` | `"ubuntu/jammy64"` | Определяет базовый образ (box) для установки. Vagrant автоматически скачает его, если образа нет в кэше. |
| `config.vm.box_version` | `"20240912.0.0"` | Указывает конкретную версию образа для использования. |
| `config.vm.box_check_update` | `false` | Отключает автоматическую проверку обновлений для box'а при каждом `vagrant up`. |
| `config.vm.hostname` | `"web-server"` | Устанавливает имя хоста (hostname) внутри гостевой ВМ. |
| `config.ssh.username` | `"admin"` | Имя пользователя для SSH-подключения (по умолчанию `vagrant`). |
| `config.ssh.private_key_path`| `"~/.ssh/id_rsa"` | Путь к кастомному приватному SSH-ключу. |
| `config.vm.boot_timeout` | `600` | Время ожидания загрузки ВМ в секундах. |

## Практический сценарий: конфигурация веб-сервера

Этот `Vagrantfile` демонстрирует объединение всех основных концепций для создания готовой к работе машины с веб-сервером.

```ruby
Vagrant.configure("2") do |config|
  # 1. Определение базового образа
  # Vagrant скачает этот образ, если его нет в локальном кэше.
  config.vm.box = "ubuntu/jammy64"

  # 2. Настройка имени хоста для удобной идентификации в сети
  config.vm.hostname = "my-dev-machine"

  # 3. Настройка сети: проброс порта 8080 хоста на 80 гостя
  # Позволяет получить доступ к веб-серверу по http://localhost:8080
  config.vm.network "forwarded_port", guest: 80, host: 8080

  # 4. Настройка провайдера: выделение 2 ГБ ОЗУ для ВМ
  config.vm.provider "virtualbox" do |v|
    v.memory = 2048
  end

  # 5. Автоматическая установка ПО (provisioning)
  # При первом запуске ВМ будет обновлен список пакетов и установлен Nginx.
  config.vm.provision "shell", inline: "apt-get update && apt-get install -y nginx"
end
```
