# Конфигурация сети в Vagrant

Vagrant предоставляет три основных типа сетей для настройки взаимодействия виртуальной машины с хостом и внешним миром.

## 1. Проброс портов (Forwarded Port)

Этот тип сети позволяет "пробросить" порт с хост-машины на порт в гостевой ВМ. Это самый простой способ получить доступ к сервису (например, веб-серверу), запущенному внутри ВМ, с вашей основной машины.

| Параметр | Пример | Описание |
| --- | --- | --- |
| `config.vm.network "forwarded_port"` | `guest: 80, host: 8080` | Запросы, приходящие на порт `8080` хост-машины, будут перенаправлены на порт `80` гостевой ВМ. |
| `config.vm.network "forwarded_port"` | `guest: 22, host: 2222` | Позволяет переназначить стандартный SSH-порт Vagrant. |

**Пример в `Vagrantfile`:**
```ruby
config.vm.network "forwarded_port", guest: 80, host: 8080
```
Теперь, если в ВМ запущен веб-сервер на порту 80, вы сможете получить к нему доступ по адресу `http://localhost:8080` в браузере на хосте.

## 2. Приватная сеть (Private Network)

Приватная сеть (также известная как Host-only) создает сетевой интерфейс, доступный только между хост-машиной и гостевой ВМ. Другие устройства в вашей физической сети не будут видеть эту ВМ.

Этот способ идеален для создания изолированных окружений, например, для стенда из нескольких ВМ, которые должны общаться между собой.

| Параметр | Пример | Описание |
| --- | --- | --- |
| `config.vm.network "private_network"` | `ip: "192.168.50.4"` | Создает Host-only сеть и присваивает ВМ статический IP-адрес `192.168.50.4`. |
| `config.vm.network "private_network"` | `type: "dhcp"` | ВМ получит IP-адрес автоматически от встроенного DHCP-сервера Vagrant. |

**Пример в `Vagrantfile`:**
```ruby
config.vm.network "private_network", ip: "192.168.50.4"
```

## 3. Публичная сеть (Public Network)

Публичная сеть (также известная как Bridged) "подключает" виртуальную машину напрямую к вашей физической локальной сети. ВМ получит собственный IP-адрес из того же диапазона, что и ваш компьютер, и будет видна другим устройствам в сети.

При первом запуске Vagrant попросит вас выбрать, какой из физических сетевых интерфейсов хоста использовать для создания моста (bridge).

**Пример в `Vagrantfile`:**
```ruby
# ВМ получит IP-адрес от DHCP-сервера в вашей локальной сети
config.vm.network "public_network"
```
