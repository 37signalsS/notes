# Управление хранилищем и общими папками в Vagrant

## Общие папки (Synced Folders)

Общие папки позволяют синхронизировать директорию на хост-машине с директорией внутри гостевой ВМ. Это основной способ работы с кодом и файлами проекта.

По умолчанию Vagrant автоматически синхронизирует папку с `Vagrantfile` (корень проекта) в директорию `/vagrant` внутри ВМ.

### Настройка общих папок

| Параметр | Пример | Описание |
| --- | --- | --- |
| `config.vm.synced_folder` | `"./data", "/vagrant_data"` | Синхронизирует папку `./data` на хосте с `/vagrant_data` в гостевой ОС. |
| `disabled: true` | `config.vm.synced_folder ".", "/vagrant", disabled: true` | Отключает стандартную общую папку `/vagrant`. |
| `type: "nfs"` | `type: "nfs"` | Использовать NFS для синхронизации. Обеспечивает лучшую производительность по сравнению с типом по умолчанию (например, VirtualBox Guest Additions), особенно на Linux/macOS. |
| `type: "rsync"` | `type: "rsync"` | Синхронизация происходит в одну сторону (с хоста на гостя) при выполнении `vagrant up` или `vagrant rsync-auto`. |

**Пример:**
```ruby
Vagrant.configure("2") do |config|
  # Отключаем стандартную папку
  config.vm.synced_folder ".", "/vagrant", disabled: true

  # Монтируем папку 'src' как /srv/website с использованием NFS
  config.vm.synced_folder "src/", "/srv/website", type: "nfs"
end
```

## Управление дисками (для провайдера Libvirt)

Провайдер `vagrant-libvirt` позволяет гибко управлять дисками виртуальных машин.

| Параметр | Пример | Описание |
| --- | --- | --- |
| `libvirt.storage_pool_name` | `"default"` | Указывает пул хранения libvirt, в котором будут создаваться диски ВМ. Убедитесь, что этот пул существует и активен. |
| `libvirt.machine_virtual_size` | `10` | Устанавливает **минимальный** размер основного (корневого) диска в гигабайтах. **Работает только на увеличение**: если диск базового образа меньше указанного значения, он будет расширен. Если диск образа уже больше, этот параметр будет проигнорирован. |
| `libvirt.storage :file, size: '20G'` | — | Добавляет **дополнительный** диск размером 20GB к виртуальной машине. Этот параметр не управляет размером основного диска. |
| `libvirt.disk_bus` | `'virtio'` | Тип контроллера диска (`ide`, `sata`, `scsi`, `virtio`). `virtio` обеспечивает наилучшую производительность. |

### Пример добавления дополнительного диска

В этом примере к ВМ добавляется дополнительный диск размером 30GB, который будет сохранен в файле `suricata_diplom.qcow2` в пуле `default`.

```ruby
node.vm.provider "libvirt" do |libvirt|
  libvirt.storage_pool_name = "default"

  libvirt.storage :file,
    size: "30G",
    type: "qcow2",
    bus: "virtio",
    name: "suricata_diplom.qcow2",
    allow_duplicate: true
end
```

**Примечание:** Для корректной работы с дисками в Libvirt, необходимо убедиться, что указанный `libvirt.storage_pool_name` существует и активен на хост-системе.
