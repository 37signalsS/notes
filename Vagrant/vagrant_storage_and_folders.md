# Управление хранилищем и общими папками в Vagrant

## Определения

1. **Общая папка (Synced Folder)**
    * Механизм, который в реальном времени синхронизирует директорию на хост-машине с директорией внутри гостевой ВМ. Это основной способ работы с кодом и файлами проекта.

2. **Виртуальный диск (Virtual Disk)**
    * Блочное устройство внутри ВМ, на котором размещается ее файловая система. Vagrant позволяет управлять как основным (корневым) диском, так и подключать дополнительные.

## Базовые концепции

### Два подхода к работе с файлами

1. **Общие папки**: Идеальны для файлов, которые вы редактируете на хосте (исходный код, конфигурации). Изменения мгновенно отражаются в ВМ. По умолчанию Vagrant всегда синхронизирует папку проекта (где лежит `Vagrantfile`) в директорию `/vagrant` внутри ВМ.
2. **Виртуальные диски**: Используются для данных, которые должны жить и изменяться исключительно внутри ВМ (например, файлы баз данных, логи). Работа с ними обычно быстрее, чем с общими папками.

## Практические сценарии

### Сценарий 1: Настройка общих папок

**`Vagrantfile`:**

```ruby
Vagrant.configure("2") do |config|
  # Отключаем стандартную общую папку /vagrant
  config.vm.synced_folder ".", "/vagrant", disabled: true

  # Монтируем папку 'src' с хоста в /srv/website в ВМ
  # Используем тип NFS для лучшей производительности на Linux/macOS
  config.vm.synced_folder "src/", "/srv/website", type: "nfs"
end
```

*Для работы `type: "nfs"` может потребоваться установка `nfs-kernel-server` на хосте.*

### Сценарий 2: Управление дисками (для провайдера Libvirt)

Провайдер `vagrant-libvirt` позволяет гибко настраивать диски.

**Вариант А: Увеличение основного диска**

Параметр `machine_virtual_size` **увеличивает** корневой диск, если его размер в базовом образе меньше указанного значения.

```ruby
config.vm.provider "libvirt" do |libvirt|
  # Увеличить корневой диск до 15 GB, если он меньше
  libvirt.machine_virtual_size = 15
end
```

**Вариант Б: Добавление дополнительного диска**

Этот пример добавляет к ВМ второй диск размером 30GB.

```ruby
config.vm.provider "libvirt" do |libvirt|
  libvirt.storage_pool_name = "default"

  libvirt.storage :file,
    size: "30G",
    type: "qcow2", # Формат диска
    bus: "virtio",  # Использовать производительный virtio-контроллер
    name: "data-disk.qcow2"
end
```

**Важно:** После добавления диска его нужно будет отформатировать и смонтировать внутри гостевой ОС.

## Дополнительная информация

### Сравнение типов общих папок

| Тип (`type:`) | Производительность | Зависимости | Основной сценарий |
| --- | --- | --- | --- |
| (по умолчанию) | Средняя | VirtualBox Guest Additions, VMware Tools и т.д. | Простая настройка, работает "из коробки". |
| `nfs` | Высокая | NFS-сервер на хосте, NFS-клиент в госте. | Разработка на Linux/macOS, где важна скорость I/O. |
| `rsync` | (неприменимо) | `rsync` на обеих машинах. | Односторонняя синхронизация с хоста на гостя. |
