# Filebeat Overview

## Definitions

**Filebeat** — это легковесный, агент для пересылки логов (lightweight shipper), который является частью Elastic Stack. Он предназначен для сбора логов и файловых данных с серверов и отправки их в Logstash или Elasticsearch для индексации.

**Модули Filebeat** — это предварительно настроенные наборы конфигураций для определенных типов источников логов (например, Traefik, Fargate, HAProxy, Nginx, Apache и др.). Они упрощают процесс сбора, парсинга и визуализации логов, предоставляя готовые конфигурации для инпутов, парсеров (ингресс-пайплайнов в Elasticsearch) и даже дашбордов Kibana.

## Основные концепции

### Как работает Filebeat

Filebeat работает путем установки на серверы, за которыми он должен следить. Он отслеживает указанные файлы логов, считывает новые строки по мере их появления и отправляет эти данные в Elasticsearch или Logstash.

* **Harvesters (Сборщики):** Отвечают за чтение содержимого одного файла. Когда Harvester открывает файл, он держит его открытым и считывает новые данные по мере их появления.
* **Input (Ввод):** Управляет Harvesters и находит все источники, соответствующие заданной конфигурации. Например, `log` input будет искать файлы логов, а `container` input будет мониторить логи Docker-контейнеров.
* **Registry File:** Filebeat хранит состояние прочитанных логов в специальном `registry file`, чтобы знать, откуда начать чтение при перезапуске или ротации логов.

### Преимущества Filebeat

* **Легковесность:** Минимальное потребление ресурсов.
* **Надежность:** Гарантированная доставка данных (использует протокол `lumberjack` с подтверждениями).
* **Простота настройки:** Особенно с использованием модулей.
* **Интеграция:** Глубокая интеграция с остальными компонентами Elastic Stack (Logstash, Elasticsearch, Kibana).

## Практические сценарии

* **Сбор логов с серверов:** Основное применение для сбора системных логов, логов приложений, веб-серверов.
* **Мониторинг логов контейнеров:** Автоматический сбор логов из Docker-контейнеров и Kubernetes-подов.
