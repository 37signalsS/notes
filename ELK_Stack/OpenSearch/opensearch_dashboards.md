# OpenSearch Dashboards: Визуализация и управление

> Эта заметка является частью обзора [OpenSearch](./opensearch_overview.md) и детально описывает возможности веб-интерфейса для анализа данных и администрирования кластера.

OpenSearch Dashboards — это открытый веб-интерфейс для интерактивного исследования данных, построения аналитических панелей и управления компонентами OpenSearch. Начиная с версий 2.15+, Dashboards трансформировался из простого инструмента визуализации в полноценную платформу с поддержкой ИИ-ассистентов и унифицированной наблюдаемости (Observability).

## Определения

* **OpenSearch Dashboards** — веб-платформа для анализа данных и администрирования (изначально форк Kibana 7.10.2, значительно дивергировавший к 2026 году).
* **Index Pattern (Шаблон индекса)** — конфигурация, связывающая Dashboards с одним или несколькими индексами OpenSearch для выполнения запросов.
* **OpenSearch Assistant** — встроенный ИИ-помощник, позволяющий генерировать запросы (PPL, SQL) и визуализации на основе естественного языка.
* **Discover 2.0** — обновленный интерфейс исследования данных с повышенной производительностью и поддержкой унифицированного поиска по нескольким источникам.
* **Derived Fields (Производные поля)** — динамические поля, вычисляемые во время выполнения запроса без необходимости переиндексации данных.
* **Tenant (Тенант)** — изолированное рабочее пространство для разделения дашбордов и настроек между командами (часть плагина Security).

## Основные концепции

### Ключевые инструменты и интерфейс (Версии 2.x/3.x)

1. **Discover**: Основной инструмент для поиска логов. В версии 2.0 получил поддержку **Wildcard Fields**, что ускоряет поиск по регулярным выражениям в разы.
2. **Dashboard & Visualize**: Создание графиков и их объединение. Поддерживает интерактивную фильтрацию (Cross-filtering) — изменение фильтра на одном графике обновляет весь дашборд.
3. **OpenSearch Assistant**: Диалоговое окно для работы с данными. Поддерживает "Agentic AI" для выполнения многошаговых расследований инцидентов.
4. **Dev Tools**: Консоль для прямой работы с API. Незаменима для отладки сложных запросов и управления безопасностью.
5. **Observability**: Специализированные разделы для Trace Analytics (анализ трейсов), Log Explorer и Application Analytics.

### Безопасность и мультиарендность (Multi-tenancy)

Dashboards обеспечивает глубокую изоляцию данных через систему тенантов:
- **Global Tenant**: Общее пространство, доступное всем пользователям с соответствующими правами.
- **Private Tenant**: Личное пространство пользователя, недоступное другим.
- **Custom Tenants**: Создаются для команд (например, `Dev`, `SRE`, `Security`). Объекты (дашборды, сохраненные поиски) внутри тенанта полностью изолированы.

## Практические сценарии

### 1. Использование ИИ-ассистента для анализа
Вместо написания сложных запросов можно использовать естественный язык:
- **Запрос**: "Покажи топ-5 IP-адресов с кодами ответа 5xx за последние 24 часа".
- **Результат**: Ассистент автоматически сгенерирует PPL-запрос и предложит визуализацию (например, Bar chart).

### 2. Создание Derived Fields для быстрой аналитики
Если в данных отсутствует нужное поле (например, объединение `first_name` и `last_name`), его можно создать "на лету":
1. Перейдите в `Stack Management -> Index Patterns`.
2. Выберите шаблон и нажмите `Add derived field`.
3. Опишите логику на языке сценариев (Painless) и используйте новое поле в Discover и Visualize без нагрузки на дисковое хранилище.

### 3. Настройка мониторинга и алертинга
OpenSearch Dashboards позволяет создавать уведомления на основе данных:
1. **Define Monitor**: Укажите запрос (например, количество ошибок в логах приложения).
2. **Define Trigger**: Установите порог (например, `count > 100` за 5 минут).
3. **Destinations**: Настройте отправку в Slack, Microsoft Teams или через Webhook в вашу систему управления инцидентами.

### 4. Работа с данными Prometheus
Начиная с версии 2.17+, Dashboards поддерживает нативный PromQL:
- Вы можете добавлять источники данных Prometheus и строить графики по метрикам рядом с графиками по логам, используя единый интерфейс Dashboards.

## Дополнительная информация

### Производительность и тюнинг

| Параметр | Описание | Рекомендация |
| :--- | :--- | :--- |
| `discover:sampleSize` | Количество строк, загружаемых в Discover. | Уменьшите до 100-200 для ускорения работы на огромных индексах. |
| `courier:ignoreFilterIfFieldNotInIndex` | Игнорировать фильтры для отсутствующих полей. | Включите (`true`) при работе с разнородными логами в одном шаблоне. |
| `assistant.next.enabled` | Включение ИИ-возможностей нового поколения. | Требует настройки ML Commons в OpenSearch кластере. |
