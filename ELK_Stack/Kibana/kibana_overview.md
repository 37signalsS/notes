## Определения

> Эта заметка является частью обзора [ELK стека](../elk_stack_overview.md) и служит основной точкой входа для изучения Kibana.

**Kibana** — это компонент визуализации в стеке ELK. Это мощный веб-интерфейс, написанный на JavaScript, который позволяет в реальном времени искать, анализировать и визуализировать данные, хранящиеся в [Elasticsearch](../Elasticsearch/elasticsearch_overview.md).

## Основные концепции

- **Индекс-паттерн (Index Pattern)**: Шаблон, который позволяет Kibana работать с несколькими индексами Elasticsearch как с единым источником данных. Он использует wildcard-символы (`*`) для объединения индексов по имени (например, `logstash-*`). Создание корректного паттерна — первый шаг для работы с данными.

- **Интерактивный поиск (Discover)**: Основной инструмент для интерактивного поиска и просмотра логов в реальном времени.
  - **Язык запросов KQL (Kibana Query Language)**: Простой и интуитивно понятный язык для фильтрации данных прямо в строке поиска.
    - **Фильтрация по значению поля:** `response: "200"`
    - **Использование операторов `and`, `or`, `not`:** `method: "POST" and response: >=400`
    - **Фильтрация по числовым значениям:** `bytes: > 1024`
    - **Проверка существования поля:** `user.name: *`

- **Визуализация (Visualize)**: Позволяет создавать разнообразные графики, диаграммы, таблицы и карты для представления данных.

- **Дашборды (Dashboard)**: Визуализации можно объединять в интерактивные дашборды, которые предоставляют комплексное представление о состоянии системы или данных.

## Практические сценарии

### Конфигурация

- **Подключение к Elasticsearch**: В конфигурационном файле `kibana.yml` можно указать несколько эндпоинтов Elasticsearch для отказоустойчивости.
- **Безопасность**:
  - Если кластер Elasticsearch защищен, соответствующие учетные данные необходимо указать в `kibana.yml`.
  - **Отключение консоли**: Для обычных пользователей в продуктивной среде рекомендуется отключать консоль разработчика (`DevTools`), так как она позволяет выполнять любые запросы, включая удаление данных.

        ```yaml
        # kibana.yml
        console.enabled: false
        ```

### Администрирование и отладка

- **DevTools (Консоль разработчика)**: В Kibana встроена консоль, которая позволяет отправлять любые REST-запросы напрямую в Elasticsearch. Это мощный инструмент для отладки и администрирования.

## Дополнительная информация

### Kibana vs. Grafana

- **Kibana**: Тесно интегрирована с Elasticsearch, предоставляет мощные возможности именно для **поиска и анализа текстовых данных и логов**. Дашборды часто выглядят очень насыщенными и функциональными.
- **[Grafana](../Grafana/grafana_overview.md)**: Более универсальный инструмент, который отлично работает с **временными рядами (time-series)** из различных источников данных (Prometheus, Loki, InfluxDB и др.). Grafana больше ориентирована на лаконичное и чистое представление метрик.

**Выбор** между ними часто зависит от основного сценария использования: глубокий анализ логов (Kibana) или мониторинг метрик (Grafana).
