# Kibana: Обзор

> Эта заметка является частью обзора [ELK стека](../elk_stack_overview.md) и служит основной точкой входа для изучения Kibana.

## Определения

* **Kibana** — это компонент визуализации и управления в стеке Elastic. Представляет собой мощный веб-интерфейс для поиска, анализа и визуализации данных в реальном времени, хранящихся в [Elasticsearch](../Elasticsearch/elasticsearch_overview.md).
* **Data View (ранее Index Pattern)** — логическое представление одного или нескольких индексов Elasticsearch. Определяет доступные поля и форматы данных. Создание Data View — обязательный первый шаг для работы с данными в приложениях Discover и Dashboard.
* **KQL (Kibana Query Language)** — основной язык запросов для фильтрации данных прямо в строке поиска. Обладает простым синтаксисом и поддерживает автодополнение.
* **Elastic Agent и Fleet** — современный способ сбора данных. Elastic Agent — единый агент для логов, метрик и защиты, а Fleet — приложение в Kibana для централизованного управления парком агентов и их конфигурациями (Integrations).

## Основные концепции

Kibana предоставляет набор специализированных приложений для различных задач:

### Аналитика и визуализация
* **Discover** — интерактивный поиск и просмотр необработанных данных. Используется для отладки и быстрого анализа логов.
* **Dashboard** — интерактивные панели, объединяющие визуализации (графики, карты, таблицы).
* **Lens** — основной инструмент создания визуализаций методом drag-and-drop. Позволяет быстро строить диаграммы без глубокого знания синтаксиса агрегаций.
* **Canvas** — инструмент для создания анимированных, "пиксельно-идеальных" презентаций на основе живых данных.
* **Maps** — приложение для анализа геопространственных данных.

### Решения (Solutions)
Kibana включает готовые интерфейсы для профильных задач:
* **Observability** — мониторинг логов, метрик (Infrastructure), трассировок (APM) и доступности (Uptime).
* **Security** — SIEM (Security Information and Event Management) и защита конечных точек (Endpoint Security).

### Управление и разработка
* **Stack Management** — управление индексами, пользователями, ролями, лицензиями и сохраненными объектами.
* **Dev Tools (Console)** — консоль для отправки REST-запросов напрямую в Elasticsearch API.
* **Alerting (Rules and Connectors)** — система уведомлений. Позволяет создавать правила (например, "количество ошибок > 10") и настраивать действия (отправка в Slack, Email, Webhook).

## Практические сценарии

### Создание Data View

1. Перейдите в **Stack Management** → **Data Views**.
2. Нажмите **Create data view**.
3. Введите шаблон имени индекса (например, `logs-nginx-*`).
4. Выберите поле времени (обычно `@timestamp`) в качестве **Timestamp field**.
5. Сохраните изменения.

### Работа с языком запросов KQL

KQL использует синтаксис `<field>: <value>`. Примеры для `Discover`:

* **Поиск по точному значению:** `http.response.status_code: 200`
* **Логические операторы:** `service.name: "auth" and level: "error"`
* **Диапазоны:** `response_time: >500`
* **Проверка существования поля:** `user.id: *`
* **Поиск подстроки (wildcard):** `message: *timeout*`

> Для детального изучения Lens и сложных запросов обратитесь к заметке **[Kibana: Поиск, визуализация и управление](./kibana_search_and_visualization.md)**.

### Конфигурация сервера

Основные настройки задаются в `kibana.yml`. В современных версиях (8.x+) для безопасного подключения часто используются Service Tokens.

```yaml
# kibana.yml

# Сетевые настройки
server.host: "0.0.0.0"
server.port: 5601
server.name: "kibana-prod"
# Рекомендуется для корректной генерации ссылок (например, в алертах)
server.publicBaseUrl: "https://kibana.example.com"

# Подключение к Elasticsearch
elasticsearch.hosts: ["https://es01:9200"]

# Аутентификация (пример с service token)
elasticsearch.serviceAccountToken: "AAEAAWVsYXN0aWMva2liYW5hL2Vucm9sbC10b2tlbi0xNzA..."

# Настройки безопасности и SSL
elasticsearch.ssl.certificateAuthorities: [ "/etc/kibana/certs/ca.crt" ]

# Настройка языка интерфейса
i18n.locale: "en" # или "ru-RU" для русского интерфейса
```

## Дополнительная информация

### Сравнение Kibana и Grafana

* **Kibana** — это "родной" интерфейс для Elasticsearch. Она незаменима для полнотекстового поиска, глубокого анализа неструктурированных логов и использования встроенных решений (SIEM, APM).
* **[Grafana](../../Grafana/grafana_overview.md)** — универсальный комбайн для визуализации временных рядов (Time-series) из множества источников (Prometheus, Zabbix, SQL).

Выбор зависит от данных: если в основе лежат текстовые логи и события — Kibana; если числовые метрики из разных систем — Grafana. Часто эти инструменты используются параллельно.
