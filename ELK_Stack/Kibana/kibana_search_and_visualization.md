# Kibana: Поиск, визуализация и управление

> Эта заметка является частью обзора [ELK стека](../elk_stack_overview.md) и детально рассматривает инструменты Kibana для исследования данных, их визуализации и управления. Для ознакомления с базовыми понятиями, обратитесь к [общему обзору Kibana](./kibana_overview.md).

## Определения

*   **Data View (ранее Index Pattern)**: Логическое представление одного или нескольких индексов Elasticsearch в Kibana. Определяет, какие поля доступны для анализа и какое из них является полем времени (`@timestamp`).
*   **KQL (Kibana Query Language)**: Простой и интуитивно понятный язык запросов с автодополнением, используемый в строке поиска Kibana по умолчанию.
*   **Lucene Query Syntax**: Более мощный и сложный язык запросов, который также поддерживается в Kibana и позволяет использовать регулярные выражения и поиск по диапазонам.
*   **Saved Objects**: Любые сущности, созданные в Kibana (дашборды, визуализации, Data Views), которые можно экспортировать и импортировать.
*   **Spaces**: Изолированные рабочие области в Kibana, позволяющие разделить проекты и контент.

## Основные концепции

### Модель представления данных

Kibana работает как слой представления поверх данных в Elasticsearch и не изменяет исходные документы. `Data View` является основой для работы. Поля в нем наследуют типы из маппинга и получают свойства `searchable` и `aggregatable` (ключ к построению визуализаций).

### Сравнение KQL и Lucene

| Характеристика | KQL (Kibana Query Language) | Lucene |
| :--- | :--- | :--- |
| **Синтаксис** | Простой и читаемый: `status: "error" and service.name: "auth"` | Более строгий: `status:"error" AND service.name:"auth"` |
| **Диапазоны** | `bytes > 1000` | `bytes:{1000 TO *]` |
| **RegEx** | Нет | Да, с использованием `/.../` |
| **Автодополнение** | Развитое, с подсказками | Ограниченное |
| **Рекомендация** | Основной выбор для большинства пользователей | Для сложных случаев |

## Практические сценарии

### Построение визуализаций

Kibana предлагает несколько инструментов для создания визуализаций:

*   **Lens**: Современный и простой конструктор "drag-and-drop". Идеален для быстрого построения графиков (например, "Топ-5 сервисов по числу ошибок").
*   **TSVB (Time Series Visual Builder)**: Мощный инструмент для анализа временных рядов, позволяющий строить производные и скользящие средние.
*   **Vega**: Для полностью кастомных визуализаций с помощью декларативного языка (на основе JSON), когда стандартных средств недостаточно.

### Дашборды и интерактивность

*   **Дашборды** объединяют визуализации, карты и сохраненные поиски в единое представление.
*   **Фильтры и Timepicker** на дашборде применяются ко всем его панелям, обеспечивая единый контекст.
*   **Drilldowns**: Позволяют настроить действия при клике на элемент визуализации, например, переход на другой дашборд с передачей текущих фильтров для детализации данных.

## Дополнительная информация

### Управление объектами и доступом

*   **Saved Objects**: Все созданные в Kibana сущности хранятся как "сохраненные объекты". Ими можно управлять через `Stack Management`: экспортировать для переноса между окружениями (dev/prod) и импортировать.
*   **Spaces**: Позволяют создавать изолированные рабочие области для разных команд. У каждой области свой набор `Saved Objects`.
*   **Роли и доступ**: Безопасность настраивается через роли, которые могут ограничивать доступ как к функциональности Kibana (например, запретить доступ к Dev Tools), так и к данным на уровне индексов или документов.
*   **Отчеты (Reporting)**: Kibana позволяет генерировать PDF/PNG отчеты из дашбордов, которые можно отправлять по расписанию.
