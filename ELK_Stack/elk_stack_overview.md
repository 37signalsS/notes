# Обзор стека ELK (Elastic Stack)

## Определения

**ELK (Elastic Stack)** — набор продуктов с открытым исходным кодом от Elastic для централизованного сбора, обработки, хранения, поиска и визуализации данных в реальном времени (логи, метрики).

## Основные концепции

### Компоненты стека

Поток данных: `Beats -> Logstash -> Elasticsearch -> Kibana`

* **Beats**: Легковесные агенты для сбора данных (логи, метрики, трафик) и отправки в Logstash или Elasticsearch. Основной агент для логов — **[Filebeat](./filebeat_overview.md)**.
* **Logstash**: Серверный конвейер обработки данных: прием, парсинг, обогащение, фильтрация, трансформация перед отправкой в Elasticsearch.
* **Elasticsearch**: Распределенный поисковый и аналитический движок. Хранит и индексирует данные, обеспечивает быстрый поиск и агрегацию.
* **Kibana**: Веб-интерфейс для интерактивного поиска, анализа и визуализации данных из Elasticsearch через дашборды и графики.

### Дополнительные компоненты

Для надежности между Beats и Logstash/Elasticsearch интегрируют брокеры сообщений (**Kafka**, **Redis**) как буфер для предотвращения потери данных при сбоях.

### Альтернативы: OpenSearch

**[OpenSearch](./OpenSearch/opensearch_overview.md)** — полностью открытый форк Elasticsearch и Kibana под лицензией Apache 2.0, поддерживаемый AWS и другими компаниями в ответ на изменение лицензирования Elastic.

## Практические сценарии

* **Logging**: Централизованный сбор и анализ логов из множества источников.
* **APM**: Мониторинг производительности приложений через метрики и трассировки.
* **SIEM**: Анализ безопасности, выявление аномалий и угроз.
* **Бизнес-аналитика**: Анализ пользовательских данных и транзакций.
