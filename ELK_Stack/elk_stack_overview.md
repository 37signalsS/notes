# Обзор стека ELK (Elastic Stack)

ELK, также известный как **Elastic Stack**, — это набор из трех мощных продуктов с открытым исходным кодом от компании Elastic. Этот стек предназначен для сбора, обработки, хранения, поиска и визуализации больших объемов данных в реальном времени, чаще всего логов.

---
## Компоненты и схема работы

Основная схема потока данных в стеке выглядит следующим образом:

`Beats -> Logstash -> Elasticsearch -> Kibana`

1.  **Beats**: Легковесные агенты для сбора различных типов данных (логи, метрики, сетевой трафик).
2.  **Logstash**: Серверный конвейер, который централизованно принимает, парсит, обогащает и фильтрует данные.
3.  **Elasticsearch**: "Сердце" стека; распределенный поисковый и аналитический движок, который хранит и индексирует данные.
4.  **Kibana**: Веб-интерфейс для Elasticsearch, позволяющий выполнять интерактивный поиск, анализ и визуализацию данных.

Для повышения надежности и отказоустойчивости между Beats и Logstash часто встраивают брокер сообщений, такой как **Kafka**, который выступает в роли буфера.
