### Временное сохранение (Stash)

Сохранить незакоммиченные изменения:

```bash
git stash save "сообщение"
git stash # Короткий вариант
```
*   `git stash list`: Показать список.
*   `git stash pop`: Применить последние изменения и удалить их из списка.
*   `git stash apply`: Применить, но оставить в списке.
*   `git stash clear`: Удалить все.
