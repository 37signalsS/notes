# Git LFS (Large File Storage)

## Определения

* **Git LFS (Large File Storage):** Расширение для Git, предназначенное для эффективной работы с большими бинарными файлами путем хранения их вне основного репозитория Git.

## Базовые концепции

Традиционный Git неэффективен для хранения больших бинарных файлов (изображения, видео, аудио, архивы), так как он хранит полную историю всех версий каждого файла, что приводит к быстрому разрастанию размера репозитория и замедлению операций клонирования, выборки и переключения веток.

Git LFS решает эту проблему, заменяя большие файлы в репозитории Git на маленькие текстовые "указатели" (pointers). Сами большие файлы хранятся на удаленном LFS-сервере. Когда вы клонируете репозиторий или переключаете ветку, Git LFS автоматически скачивает нужные версии больших файлов с LFS-сервера.

### Преимущества Git LFS

- **Оптимизация производительности:** Ускоряет операции с репозиторием, поскольку Git работает только с легкими указателями.
- **Управление версиями больших файлов:** Позволяет эффективно версионировать файлы, которые обычно не подходят для Git.
- **Сохранение истории:** История изменений больших файлов сохраняется без раздувания основного репозитория.

## Практические сценарии

### Настройка и использование Git LFS

1. **Установка Git LFS:** Убедитесь, что Git LFS установлен в вашей системе. После установки необходимо инициализировать его для вашего пользователя:

    ```bash
    git lfs install
    ```

    Эту команду нужно выполнить один раз для вашей системы.

2. **Отслеживание типов файлов:** Укажите Git LFS, какие типы файлов (по расширению) он должен отслеживать. Эти правила записываются в файл `.gitattributes` в корне репозитория.

    ```bash
    git lfs track "*.psd"
    git lfs track "*.iso"
    # Можно отслеживать несколько типов файлов
    git lfs track "*.zip"
    ```

    Эта команда добавляет соответствующие строки в `.gitattributes` (или создает его, если он не существует).

3. **Добавление `.gitattributes` в репозиторий:** Файл `.gitattributes` должен быть зафиксирован в репозитории, чтобы правила отслеживания Git LFS применялись для всех пользователей.

    ```bash
    git add .gitattributes
    git commit -m "Configure Git LFS tracking for large files"
    ```

4. **Работа с файлами:** Теперь, при добавлении файлов, соответствующих настроенным паттернам, Git автоматически будет обрабатывать их через LFS.

    ```bash
    git add my-large-image.psd
    git commit -m "Add large PSD file"
    git push origin main
    ```

    В репозитории Git будет храниться только указатель на `my-large-image.psd`, а сам файл будет загружен на LFS-сервер.
