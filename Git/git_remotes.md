### Управление удалёнными репозиториями

*   `git remote -v`: Список удалённых репозиториев.
*   `git remote add <имя> <url>`: Добавить новый.
*   `git remote remove <имя>`: Удалить.
*   `git remote rename <старое> <новое>`: Переименовать.
*   `git remote set-url <имя> <url>`: Изменить URL.
*   `git remote show <имя>`: Показать подробную информацию.
