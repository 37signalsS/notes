# Инструменты Git TUI и CLI

## Определения

**TUI (Terminal User Interface)** — текстовый пользовательский интерфейс, работающий внутри терминала. Предоставляет интерактивные элементы управления (меню, списки, панели) без необходимости использования графического сервера (X11/Wayland).

**Git TUI-инструменты** — утилиты для визуализации истории Git, интерактивного стейджинга и управления репозиторием непосредственно в терминале.

**CLI-расширения (Pagers)** — инструменты, улучшающие стандартный вывод команд Git (например, `git diff` или `git log`), добавляя синтаксическую подсветку, выравнивание и интерактивность.

## Базовые концепции

### Категории инструментов

| Категория | Инструменты | Назначение |
| :--- | :--- | :--- |
| **Полноценные клиенты** | `lazygit`, `gitui` | Управление всем жизненным циклом (add, commit, rebase, push) |
| **Визуализация и Diff** | `git-delta`, `tig`, `difftastic` | Улучшение читаемости изменений и графа коммитов |
| **Интерактивный CLI** | `forgit`, `fzf` | Быстрый поиск и выбор через нечеткий поиск (fuzzy search) |
| **Анализ истории** | `git-igitt`, `gitalong` | Глубокое изучение структуры веток и изменений |

### Основные TUI-клиенты

*   **lazygit**: Самый популярный и функциональный TUI-клиент. Написан на Go. Поддерживает сложные интерактивные перебазирования (rebase), управление cherry-pick и работу с подмодулями.
*   **gitui**: Клиент на Rust, ориентированный на максимальную производительность. Идеален для очень больших репозиториев, где другие инструменты могут притормаживать.
*   **tig**: Классический инструмент на C. В основном используется для просмотра истории и быстрого стейджинга отдельных строк (hunks).

### Современные CLI-улучшения

*   **git-delta**: Современный пейджер (замена стандартному `less`). Добавляет подсветку синтаксиса, нумерацию строк и боковой (side-by-side) просмотр diff.
*   **forgit**: Набор утилит, использующих `fzf` для интерактивной работы с Git (например, выбор файлов для добавления или коммитов для фиксации).
*   **difftastic**: Дифференциальный инструмент, который понимает синтаксис языка программирования. Он сравнивает файлы на основе их структуры (AST), а не просто текста.

## Практические сценарии

### Сценарий 1: Настройка git-delta (рекомендуемый diff-пейджер)

`git-delta` значительно улучшает читаемость `git diff` и `git show`.

**Установка:**
```bash
# macOS
brew install git-delta

# Ubuntu/Debian
# Скачать .deb с GitHub релиза или использовать cargo
cargo install git-delta
```

**Настройка в `~/.gitconfig`:**
```ini
[core]
    pager = delta

[interactive]
    diffFilter = delta --color-only

[delta]
    navigate = true    # переход между чанками по n/N
    light = false      # использовать темную тему
    side-by-side = true # включить боковой просмотр по умолчанию
    line-numbers = true

[merge]
    conflictstyle = zdiff3
```

### Сценарий 2: Использование forgit для интерактивной работы

`forgit` позволяет использовать `fzf` для поиска по истории и статусу.

**Основные команды:**
*   `ga` (git add) — интерактивный выбор файлов для стейджинга с превью.
*   `glo` (git log) — интерактивный просмотр лога.
*   `gd` (git diff) — быстрый выбор файла для просмотра изменений.

### Сценарий 3: Полноценное управление через lazygit

**Установка:**
```bash
# macOS
brew install lazygit

# Go
go install github.com/jesseduffield/lazygit@latest
```

**Ключевые возможности:**
1.  **Интерактивный Rebase**: Нажмите `e` на коммите в списке для начала редактирования или `s` для склеивания (squash).
2.  **Работа с чанками**: В панели файлов можно нажать `Enter`, перейти к конкретным строкам кода и добавить в индекс только их (клавиша `space`).
3.  **Фильтрация лога**: Нажмите `f` для фильтрации коммитов по автору или ветке.

### Сценарий 4: Сравнение инструментов

| Критерий | lazygit | gitui | tig | git-delta |
| :--- | :--- | :--- | :--- | :--- |
| **Язык** | Go | Rust | C | Rust |
| **Тип** | Full TUI | Full TUI | Viewer/TUI | CLI Pager |
| **Производительность** | Высокая | Экстремальная | Высокая | Высокая |
| **Сложный Rebase** | Отлично | Базово | Нет | Н/Д |
| **Side-by-side Diff** | Через конфиг | Да | Нет | Да (лучший) |
| **Лучшее для** | Основной работы | Слабого железа | Быстрых правок | Чтения diff |

## Дополнительная информация

### Выбор инструмента
1.  Если нужен **основной интерфейс** вместо командной строки — выбирайте **lazygit**.
2.  Если важна **скорость** на огромных монорепозиториях — используйте **gitui**.
3.  Для **улучшения вывода** стандартных команд Git обязательно установите **git-delta**.
4.  Для **быстрого поиска** в CLI установите **forgit**.
