# Инструменты для работы с Git (TUI и CLI)

## Определения

**TUI (Terminal User Interface)** — это текстовый пользовательский интерфейс, который работает внутри терминала, предоставляя интерактивные элементы управления (меню, кнопки, списки) без использования графического сервера (GUI).

В экосистеме Git существует множество TUI-инструментов, которые делают работу с ветками, историей и коммитами более наглядной и быстрой.

## Основные инструменты

### 1. `git-igitt`

`git-igitt` — это специализированный инструмент для визуализации истории Git с акцентом на читаемые графы веток прямо в терминале.

* **Назначение:** Просмотр истории коммитов с наглядным отображением ветвлений.
* **Особенности:**
  * Визуальные Git-графы высокого качества.
  * Удобная навигация по коммитам (стрелки вверх/вниз).
  * Быстрый просмотр diff-ов для выбранного коммита.
  * Кроссплатформенность.

### 2. `lazygit`

Один из самых популярных TUI-клиентов для Git, предоставляющий полный спектр возможностей управления репозиторием.

* **Назначение:** Полноценный терминальный клиент для повседневной работы.
* **Особенности:** Интерактивное добавление файлов в индекс, разрешение конфликтов слияния, управление ветками и удаленными репозиториями.

## Практические сценарии

### Использование `git-igitt`

#### Установка

Для установки требуется менеджер пакетов Rust — `cargo`.

```bash
# Установка через cargo
cargo install git-igitt
```

Если Rust не установлен:

```bash
curl https://sh.rustup.rs -sSf | sh
```

Также бинарные файлы можно скачать со [страницы релизов GitHub](https://github.com/mlange-42/git-igitt/releases).

#### Навигация

Просто запустите команду в корне вашего Git-репозитория:

```bash
git-igitt
```

* **Стрелки вверх/вниз:** Перемещение по списку коммитов.
* **Стрелки влево/вправо:** Переключение между списком коммитов и панелью diff/информации.
* **Esc / Q:** Выход из программы.
