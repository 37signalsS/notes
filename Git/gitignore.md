### .gitignore
Файл `.gitignore` указывает Git, какие файлы или директории следует игнорировать в проекте.

| Паттерн              | Описание                                                                                                                            |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `*.log`              | Игнорировать все файлы с расширением `.log`.                                                                                        |
| `build/`             | Игнорировать директорию `build` и все ее содержимое.                                                                                |
| `/TODO`              | Игнорировать файл `TODO` только в корневой директории, но не в `subdir/TODO`.                                                       |
| `!important.log`     | Не игнорировать `important.log`, даже если он подпадает под правило `*.log`. **Важно:** правило не сработает, если родительская папка уже исключена. |
| `docs/**/*.txt`      | Игнорировать все файлы `.txt` в директории `docs` и всех ее поддиректориях.                                                          |
| `file?.txt`          | Игнорировать `file1.txt`, `fileA.txt`, но не `file10.txt`.                                                                           |
| `[abc].txt`          | Игнорировать `a.txt`, `b.txt`, `c.txt`.                                                                                             |
| `[0-9].txt`          | Игнорировать файлы с именами от `0.txt` до `9.txt`.                                                                                 |
| `\#file.txt`        | Игнорировать файл с именем `#file.txt` (экранирование специального символа).                                                        |

Иногда нужно временно игнорировать изменения в файле, который уже отслеживается Git (например, локальный файл конфигурации).

```bash
# Начать игнорировать изменения в файле
git update-index --assume-unchanged <файл>

# Возобновить отслеживание изменений
git update-index --no-assume-unchanged <файл>
```
