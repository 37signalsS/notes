# Обзор HashiCorp Consul

**Consul** — это комплексное решение от HashiCorp для организации сетевого взаимодействия и подключения сервисов в любых средах выполнения, от физических серверов до Kubernetes.

## Ключевые возможности

1.  **Обнаружение сервисов (Service Discovery):**
    Consul предоставляет централизованный реестр для регистрации сервисов. Другие сервисы могут находить актуальные IP-адреса и порты зарегистрированных служб через DNS-интерфейс или HTTP API. Это устраняет необходимость жестко прописывать сетевые адреса в конфигурациях приложений.

2.  **Проверка состояния (Health Checking):**
    Consul постоянно отслеживает работоспособность зарегистрированных сервисов. Он может выполнять различные проверки: от простого TCP-соединения до выполнения скриптов. Неработоспособные экземпляры сервисов автоматически исключаются из списка доступных.

3.  **Хранилище "ключ-значение" (Key/Value Store):**
    Consul включает в себя распределенное, иерархическое хранилище "ключ-значение". Оно идеально подходит для хранения динамической конфигурации, флагов функций (feature flags), а также для координации сервисов и выбора лидера. **Vault** может использовать это хранилище в качестве бэкенда для хранения своих зашифрованных данных.

4.  **Сервисная сетка (Service Mesh):**
    Consul может функционировать как полноценная сервисная сетка (service mesh), обеспечивая безопасное TLS-шифрование (mTLS) для трафика между сервисами, продвинутую L7-маршрутизацию, балансировку нагрузки и политики контроля доступа (Intentions).

5.  **Поддержка нескольких ЦОД:**
    Consul изначально спроектирован для работы в географически распределенных средах, позволяя объединять сервисы из разных дата-центров в единую сеть.

## Архитектура

Consul работает на основе **агентов**, которые запускаются на каждом узле. Агенты могут работать в двух режимах:
*   **Сервер (Server):** Несколько серверов (обычно 3 или 5) образуют кворум на основе алгоритма консенсуса [Raft](../Concepts/raft_consensus_algorithm.md). Они хранят состояние кластера, информацию о сервисах и данные K/V-хранилища.
*   **Клиент (Client):** Легковесные агенты, которые перенаправляют запросы серверам и кэшируют результаты.

Такая архитектура обеспечивает высокую доступность и отказоустойчивость.
