# Ansible Vault: Использование нескольких хранилищ (Multi-Vault)

## Определения

- **Идентификатор хранилища (Vault ID)**: Метка (например, `prod`, `dev`), которая присваивается зашифрованному файлу. Она позволяет использовать несколько наборов секретов, каждый со своим паролем, и управлять ими в рамках одного проекта.

## Основные концепции

### Как работает Vault ID

1. **При шифровании** вы связываете файл с ID и паролем. Этот ID записывается в заголовок зашифрованного файла, как описано в **[Алгоритмах шифрования](./algorithms.md)**.
2. **При выполнении плейбука** вы предоставляете Ansible пары "ID → источник пароля".
3. Ansible читает заголовок каждого зашифрованного файла, находит в нем ID и использует соответствующий пароль для расшифровки.

Это позволяет, например, хранить в `group_vars/` файлы `prod/secrets.yml` и `dev/secrets.yml`, зашифрованные разными паролями, и выбирать нужный набор секретов в зависимости от окружения.

### Поведение по умолчанию

Если вы предоставляете несколько паролей, а у зашифрованного файла нет ID, Ansible попытается перебрать все предоставленные пароли, чтобы найти подходящий. Такое поведение может усложнить отладку, поэтому рекомендуется всегда явно присваивать ID всем зашифрованным файлам.

## Практические сценарии

### Сценарий 1: Шифрование файла с указанием ID

Чтобы присвоить файлу ID, используется синтаксис `--vault-id <id>@<источник_пароля>`. Источники пароля подробно описаны в документе **[Управление паролями](./passwords.md)**.

```bash
# 1. Шифруем файл для prod, пароль будет запрошен в консоли
ansible-vault encrypt group_vars/prod/secrets.yml --vault-id prod@prompt

# 2. Шифруем файл для dev, пароль берется из файла
ansible-vault encrypt group_vars/dev/secrets.yml --vault-id dev@./dev_pass.txt
```

### Сценарий 2: Выполнение плейбука с несколькими Vault

При запуске плейбука укажите пароли для всех необходимых ID.

```bash
ansible-playbook my_playbook.yml \
  --vault-id prod@~/.prod_vault_pass \
  --vault-id dev@prompt
```

Ansible автоматически применит правильный пароль к каждому файлу. Если для какого-то файла не будет найден пароль, соответствующий его ID, выполнение прервется с ошибкой.
