# Ansible Vault: Алгоритмы шифрования

## Определения

- **Криптографическая схема (Cipher Suite)**: Набор алгоритмов, обеспечивающих защиту данных. В Ansible Vault используется фиксированная схема, которую пользователь не может изменить, что гарантирует высокий уровень безопасности и совместимость.
- **PBKDF2 (Password-Based Key Derivation Function 2)**: Функция формирования ключа на основе пароля. Она делает перебор паролей (брутфорс) вычислительно дорогим за счет тысяч итераций хеширования.

## Основные концепции

### Компоненты защиты

Ansible Vault использует симметричное шифрование. Это означает, что один и тот же ключ (полученный из пароля) используется и для зашифровки, и для расшифровки.

| Компонент | Технология | Описание |
| :--- | :--- | :--- |
| **Шифрование** | `AES-256-CTR` | Advanced Encryption Standard с ключом 256 бит в режиме счетчика (Counter mode). |
| **Производная ключа** | `PBKDF2-HMAC-SHA256` | Превращает ваш текстовый пароль в криптографический ключ. |
| **Целостность (MAC)** | `HMAC-SHA256` | Hash-based Message Authentication Code. Гарантирует, что данные не были изменены без знания пароля. |
| **Библиотека Python** | `cryptography` | Современная библиотека, необходимая для работы Vault (ранее использовалась PyCrypto). |

### Версии формата (заголовки)

Первая строка любого зашифрованного файла — это заголовок. Он указывает Ansible, как обрабатывать содержимое.

1. **Версия 1.1 (`$ANSIBLE_VAULT;1.1;AES256`)**:
   - Появилась в Ansible 1.5.
   - Не содержит метаданных о пароле.
   - Если используется несколько паролей, Ansible пробует их по очереди (метод перебора), что замедляет работу.

2. **Версия 1.2 (`$ANSIBLE_VAULT;1.2;AES256;prod`)**:
   - Появилась в Ansible 2.4.
   - Содержит **Vault ID** (в примере выше — `prod`).
   - Позволяет Ansible мгновенно выбрать нужный пароль из списка предоставленных, значительно ускоряя выполнение.

## Практические сценарии

### Проверка версии и алгоритма

Вы можете узнать параметры шифрования любого файла, просто прочитав его первую строку:

```bash
head -n 1 group_vars/all/vault.yml
# → $ANSIBLE_VAULT;1.2;AES256;dev
```

### Обновление безопасности (Rekey)

Если вы переходите со старых версий Ansible или хотите убедиться, что файл использует актуальный формат 1.2, выполните перешифрование:

```bash
# Обновление пароля и формата до 1.2 (если указан --vault-id)
ansible-vault rekey --vault-id new_label@prompt secret_file.yml
```

Это обновит не только сам ключ, но и метаданные в заголовке, что упростит дальнейшее управление секретами.
