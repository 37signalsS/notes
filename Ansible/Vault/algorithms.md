# Ansible Vault: Алгоритмы шифрования

## Определения

**Ansible Vault** защищает секреты с помощью симметричного шифрования. Ключевая особенность — фиксированная криптографическая схема: выбор алгоритма пользователем не предусмотрен, что снижает риск неправильной конфигурации и обеспечивает единообразие.

## Основные концепции

### Компоненты криптосхемы Vault

| Компонент | Используется в Vault | Назначение |
| :--- | :--- | :--- |
| **Симметричный шифр** | `AES-256` (в режиме `CTR`) | Конфиденциальность содержимого |
| **Производная ключа** | `PBKDF2` на базе `HMAC-SHA256` | Получение ключа шифрования из пароля |
| **Контроль целостности**| `HMAC-SHA256` | Обнаружение подделки или повреждения данных |
| **Случайность** | Соль для KDF, IV/nonce для AES | Невоспроизводимость шифртекста при одинаковом пароле |

Это означает, что для дешифровки нужен только пароль, а все остальные параметры (соль, вектор инициализации) хранятся вместе с шифртекстом.

### Формат зашифрованных данных

Любой файл или строка, зашифрованные Vault, содержат заголовок с версией формата и указанием шифра.

**Пример заголовка:**
```
$ANSIBLE_VAULT;1.1;AES256
3234626466333735373930656532666330376332386463...
```
- `$ANSIBLE_VAULT`: Маркер, указывающий, что это зашифрованные данные.
- `1.1`: Версия формата Vault.
- `AES256`: Используемый шифр.

### Совместимость версий

Существуют разные версии формата (`1.0`, `1.1`, `1.2`), но все они используют `AES-256`. Различия касаются метаданных и упаковки, а не смены алгоритма. Новые версии Ansible сохраняют обратную совместимость. Переход на новый формат происходит прозрачно при выполнении команд `ansible-vault encrypt` или `ansible-vault rekey` с помощью более новой версии Ansible.

## Практические сценарии

### Проверка формата шифрования

```bash
# Посмотреть заголовок зашифрованного файла
head -n1 group_vars/prod/vault.yml
```

### Перешифрование (Rekey)

Команда `rekey` позволяет сменить пароль и одновременно обновить формат шифрования до актуального.

```bash
ansible-vault rekey group_vars/prod/vault.yml 
  --vault-id old@prompt --new-vault-id new@file:./new_pass.txt
```

> Ansible Vault не предоставляет опций для выбора другого шифра (например, ChaCha20-Poly1305). Это умышленное ограничение для упрощения поддержки и аудита.
