# Ansible Vault: Алгоритмы шифрования

## Определения

- **Криптографическая схема (Cipher Suite)**: Комбинация алгоритмов, используемых для обеспечения конфиденциальности и целостности данных. В Ansible Vault эта схема жестко зафиксирована для обеспечения совместимости и простоты.

## Основные концепции

### Компоненты криптосхемы Vault

Ansible Vault защищает секреты с помощью симметричного шифрования. Ключевая особенность — выбор алгоритма пользователем не предусмотрен, что снижает риск неправильной конфигурации.

| Компонент | Используется в Vault | Назначение |
| :--- | :--- | :--- |
| **Симметричный шифр** | `AES-256` (в режиме `CTR`) | Конфиденциальность содержимого |
| **Производная ключа** | `PBKDF2` на базе `HMAC-SHA256` | Получение ключа шифрования из пароля |
| **Контроль целостности**| `HMAC-SHA256` | Обнаружение подделки или повреждения данных |
| **Случайность** | Соль (salt) и вектор инициализации (IV) | Невоспроизводимость шифртекста |

Для дешифровки нужен только пароль, а все остальные криптографические параметры (соль, IV) хранятся в самом зашифрованном файле.

### Формат зашифрованных данных

Зашифрованные данные содержат текстовый заголовок, который описывает формат и параметры шифрования.

**Пример заголовка:**

```
$ANSIBLE_VAULT;1.2;AES256;prod
3234626466333735373930656532666330376332386463...
```

- `$ANSIBLE_VAULT`: Маркер, указывающий, что это зашифрованные данные Vault.
- `1.2`: Версия формата.
- `AES256`: Используемый шифр.
- `prod`: Опциональный **[идентификатор хранилища (Vault ID)](./multi_vault.md)**, используемый для работы с несколькими хранилищами.

## Практические сценарии

### Обновление формата шифрования

Хотя алгоритм `AES-256` не меняется, формат "контейнера" может обновляться с новыми версиями Ansible. Команда `rekey` позволяет не только сменить пароль, но и обновить формат шифрования до актуального.

```bash
# Смена пароля и обновление формата для файла
ansible-vault rekey group_vars/prod/vault.yml
```

## Дополнительная информация

- **Отсутствие выбора алгоритмов**: Ansible Vault умышленно не предоставляет опций для выбора другого шифра (например, ChaCha20-Poly1305). Это сделано для упрощения поддержки, аудита и обеспечения обратной совместимости.
- **Основы Vault**: Для ознакомления с базовыми командами обратитесь к документу **[Основы Vault](./basics.md)**.
