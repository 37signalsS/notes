# Ansible Vault: Основы

## Определения

**Ansible Vault** — это встроенный в Ansible механизм для шифрования секретов, таких как пароли, API-ключи и SSL-сертификаты. Он позволяет безопасно хранить чувствительные данные (переменные) в системе контроля версий (Git) вместе с остальным кодом автоматизации.

## Основные концепции

### 1. Режимы работы: Шифрование файлов vs. строк

Ansible Vault поддерживает два основных подхода к шифрованию. Он может зашифровать **любой компонент Ansible**: плейбук, роль, инвентарь, шаблон или отдельную переменную. Расшифровка происходит прозрачно для пользователя, если предоставлен верный пароль.

#### Режим 1: Шифрование целых файлов (рекомендуемый)

**Преимущества:**

* **Удобство управления:** Все связанные переменные находятся в одном месте.
* **Смена пароля:** Пароль можно легко сменить для всего файла одной командой `rekey`, что критически важно для политик ротации секретов.
* **Портативность:** Файл легко перемещать между проектами.

**Пример:** Шифрование файла с переменными для группы `main`.

```bash
# Файл group_vars/main.yml содержит:
# test: var1
# test2: var2
ansible-vault encrypt group_vars/main.yml
```

После выполнения команды содержимое файла будет заменено на зашифрованный блок.

#### Режим 2: Шифрование отдельных строк

Этот режим позволяет зашифровать конкретное значение и вставить его прямо в плейбук.

**Преимущества:**

* Удобно для быстрых тестов, dev-окружений или когда нужно скрыть всего одну некритичную переменную.

**Недостатки:**

* **Сложность смены пароля:** Если пароль от Vault изменится, вам придется вручную найти и перезашифровать **каждую** зашифрованную строку во всех плейбуках.
* **Плохая масштабируемость:** Не подходит для управления большим количеством секретов.

**Пример:**

```bash
ansible-vault encrypt_string 'MySuperSecretValue' --name 'my_secret_var'
```

Команда вернет YAML-блок, который можно вставить в `vars` плейбука:

```yaml
my_secret_var: !vault |
  $ANSIBLE_VAULT;1.1;AES256
  396339623133326231336130393...
```

### 2. Основные команды `ansible-vault`

* **`encrypt <file>`**: Зашифровать существующий файл. После выполнения этой команды содержимое файла будет заменено на зашифрованный блок с заголовком, указывающим на используемый протокол шифрования и идентификатор (если указан).
* **`decrypt <file>`**: Расшифровать файл (использовать с осторожностью, не коммитить расшифрованные файлы).
* **`create <file>`**: Создать новый зашифрованный файл и открыть его для редактирования.
* **`edit <file>`**: Безопасно отредактировать зашифрованный файл (он расшифровывается во временный файл, а после сохранения снова шифруется).
* **`view <file>`**: Показать содержимое зашифрованного файла в консоли без редактирования.
* **`rekey <file>`**: Сменить пароль для одного или нескольких зашифрованных файлов.
