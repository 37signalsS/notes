# Ansible Vault: Основы

## Определения

**Ansible Vault** — это встроенный в Ansible механизм для шифрования секретов, таких как пароли, API-ключи и SSL-сертификаты. Он позволяет безопасно хранить чувствительные данные (переменные) в системе контроля версий (Git) вместе с остальным кодом автоматизации.

## Основные концепции

### 1. Шифрование файлов и строк

Ansible Vault может шифровать **любой YAML-файл** (плейбук, переменные, инвентарь) или **отдельные строки** внутри YAML. Расшифровка происходит "на лету" при выполнении плейбука, если предоставлен верный пароль.

- **Шифрование файлов (рекомендуется)**: Чаще всего шифруют файлы с переменными в `group_vars/` и `host_vars/`.
- **Шифрование строк**: Позволяет встраивать зашифрованные значения прямо в плейбуки с помощью `ansible-vault encrypt_string`.

### 2. Формат зашифрованных данных

Зашифрованный файл или строка начинаются со специального заголовка:
```
$ANSIBLE_VAULT;1.2;AES256;dev
6632343834353631...
```
Это позволяет Ansible автоматически распознать зашифрованные данные.

### 3. Основные команды `ansible-vault`

* **`create <file>`**: Создать новый зашифрованный файл.
* **`encrypt <file>`**: Зашифровать существующий файл.
* **`decrypt <file>`**: Расшифровать файл (не коммитить в Git!).
* **`edit <file>`**: Безопасно отредактировать зашифрованный файл.
* **`view <file>`**: Показать содержимое зашифрованного файла в консоли без редактирования.
* **`rekey <file>`**: Сменить пароль для зашифрованного файла.
* **`encrypt_string`**: Зашифровать отдельную строку для вставки в YAML.
