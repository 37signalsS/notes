# Ansible Vault: Основы

## Определения

- **Ansible Vault**: Встроенный в Ansible механизм для шифрования секретов, таких как пароли, API-ключи и SSL-сертификаты. Он позволяет безопасно хранить чувствительные данные в системе контроля версий (Git) вместе с кодом автоматизации.
- **Хранилище (Vault)**: Зашифрованный YAML-файл или отдельная зашифрованная строка, содержащие секреты.

## Основные концепции

### Принципы работы

Ansible Vault может шифровать как YAML-файлы целиком, так и отдельные строковые значения с помощью команды `encrypt_string`. Расшифровка происходит "на лету" во время выполнения плейбука при условии предоставления верного пароля.

Зашифрованные данные помечаются специальным заголовком `$ANSIBLE_VAULT;...`, по которому Ansible их распознает.

### Основные команды

- `create <file>`: Создать новый зашифрованный файл.
- `edit <file>`: Безопасно отредактировать зашифрованный файл.
- `encrypt <file>`: Зашифровать существующий файл.
- `decrypt <file>`: Расшифровать файл (не для коммита в Git).
- `view <file>`: Показать содержимое зашифрованного файла.
- `rekey <file>`: Сменить пароль для файла.
- `encrypt_string`: Зашифровать отдельную строку для вставки в обычный YAML-файл.

## Практические сценарии

### Сценарий 1: Работа с зашифрованными файлами

Самый частый сценарий — создание файла с секретными переменными для конкретного окружения.

1. **Создание файла**:

    ```bash
    # Будет запрошен пароль для нового файла
    ansible-vault create group_vars/all/vault.yml
    ```

    В открывшемся редакторе можно определить переменные:

    ```yaml
    # group_vars/all/vault.yml (содержимое)
    db_password: "MySecretPassword"
    api_key: "12345-abcde"
    ```

2. **Редактирование файла**:

    ```bash
    # Будет запрошен пароль для расшифровки
    ansible-vault edit group_vars/all/vault.yml
    ```

3. **Использование в плейбуке**:
    Ansible автоматически загрузит и расшифрует переменные. Вам нужно лишь предоставить пароль.

    ```bash
    ansible-playbook deploy.yml --ask-vault-pass
    ```

### Сценарий 2: Шифрование отдельных переменных (`encrypt_string`)

Этот подход позволяет хранить зашифрованные значения рядом с обычной конфигурацией, не шифруя файл целиком.

1. **Шифрование строки**:

    ```bash
    ansible-vault encrypt_string --stdin-name 'db_password'
    # Введите пароль и секретное значение (Ctrl+D для завершения)
    ```

    Результат будет выглядеть так:

    ```yaml
    db_password: !vault |
      $ANSIBLE_VAULT;1.1;AES256
      3534...
    ```

2. **Использование в файле**:
    Вставьте этот блок в любой файл с переменными, например `group_vars/prod/vars.yml`. Ansible распознает тег `!vault` и расшифрует значение.
