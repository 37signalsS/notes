# Ansible Vault: Управление паролями

## Определения

- **Источник пароля (Password Source)**: Метод, которым `ansible-playbook` получает пароль для расшифровки хранилища (Vault). Выбор правильного источника критичен для баланса между удобством и безопасностью.

## Основные концепции

### Иерархия и приоритет источников

Ansible ищет пароль в нескольких местах в строгом порядке приоритета. Будет использован **первый найденный** пароль.

1.  **Командная строка**: Флаги `--vault-password-file` или `--ask-vault-pass` имеют наивысший приоритет.
2.  **`ansible.cfg`**: Параметр `vault_password_file` в секции `[defaults]`.
3.  **Переменная окружения**: `ANSIBLE_VAULT_PASSWORD_FILE` (указывает на файл) или `ANSIBLE_VAULT_PASSWORD` (содержит сам пароль).

Рекомендуется использовать либо командную строку для ручных запусков, либо `vault_password_file` в `ansible.cfg` для проектов, чтобы избежать хранения паролей в переменных окружения.

## Практические сценарии

### Сценарий 1: Интерактивный ввод (для ручных запусков)
Ansible запросит пароль прямо в консоли. Это самый простой, но не автоматизируемый способ.
```bash
# Запросить пароль для хранилища по умолчанию
ansible-playbook my_playbook.yml --ask-vault-pass

# Интерактивно запросить пароль для конкретного vault-id
ansible-playbook site.yml --vault-id dev@prompt
```

### Сценарий 2: Файл с паролем (для CI/CD и проектов)
Пароль хранится в текстовом файле, путь к которому передается Ansible. Это предпочтительный способ для автоматизации и командной работы.

**Способ А: Через командную строку**
```bash
ansible-playbook my_playbook.yml --vault-password-file ~/.vault_pass
```

**Способ Б: Через `ansible.cfg` (рекомендуется для проектов)**
Добавьте следующую строку в `ansible.cfg`, чтобы не указывать флаг при каждом запуске:
```ini
[defaults]
vault_password_file = .vault_pass
```
- **Безопасность**: Защитите файл с паролем (`chmod 600`) и добавьте его в `.gitignore`.

### Сценарий 3: Исполняемый скрипт (для внешних хранилищ)
В качестве файла с паролем можно указать исполняемый скрипт. Ansible выполнит его и будет использовать стандартный вывод (STDOUT) в качестве пароля. Это позволяет интегрироваться с внешними системами (HashiCorp Vault, AWS Secrets Manager).

**Пример `vault.sh`:**
```bash
#!/bin/bash
# Команда для получения секрета из внешнего хранилища
/usr/local/bin/get-secret --name ansible-vault-password
```
**Запуск:**
```bash
ansible-playbook my_playbook.yml --vault-password-file ./vault.sh
```
