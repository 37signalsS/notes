# Ansible: Роли

Роли в Ansible — это основной механизм для инкапсуляции и переиспользования кода автоматизации. Они позволяют упаковать задачи, обработчики, переменные и шаблоны в стандартизированную, модульную структуру.

См. также: [Обзор Ansible](ansible_overview.md)

## Структура директорий роли

Стандартная структура роли, создаваемая командой `ansible-galaxy init <имя_роли>`:

```
<имя_роли>/
├── tasks/              # Основные задачи роли
│   └── main.yml
├── handlers/           # Обработчики, используемые в роли
│   └── main.yml
├── defaults/           # Переменные по умолчанию (низший приоритет)
│   └── main.yml
├── vars/               # Переменные роли (высокий приоритет)
│   └── main.yml
├── files/              # Статические файлы для копирования
├── templates/          # Шаблоны Jinja2
└── meta/               # Метаданные роли (включая зависимости)
    └── main.yml
```

## Использование ролей в плейбуке

Роли применяются к хостам с помощью ключевого слова `roles` в плейбуке.

```yaml
- name: Example playbook using roles
  hosts: webservers
  become: true

  roles:
    - common      # Роль для базовой настройки всех серверов
    - nginx       # Роль для установки и настройки Nginx
    - { role: memcached, port: 11211 } # Передача параметров в роль
```

## Зависимости ролей

Зависимости между ролями определяются в файле `meta/main.yml`. Это позволяет автоматически подключать другие роли при использовании текущей.

```yaml
# meta/main.yml в роли 'my_app'
dependencies:
  - role: nginx
  - role: postgres
```
