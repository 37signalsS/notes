# Введение в Ansible

## Определение

Ansible — это система с открытым исходным кодом для автоматизации развертывания программного обеспечения, управления конфигурацией и оркестрации. Он работает без агентов, подключаясь к узлам по SSH, и использует декларативные YAML-файлы (плейбуки) для описания желаемого состояния системы.

## Преимущества Ansible

-   **Быстрое освоение**: Достаточно поверхностного понимания синтаксиса YAML и Jinja2.
-   **Без агентов**: Нет необходимости устанавливать специальное ПО на управляемые хосты; нужен только SSH и Python.
-   **Подробная документация**: Обширная и наглядная официальная документация.
-   **Большое количество модулей**: Широкий набор готовых модулей для различных задач.
-   **Идемпотентность**: Позволяет реализовать принцип идемпотентности в управлении состояниями хостов, гарантируя, что повторные запуски приводят к одному и тому же желаемому состоянию без побочных эффектов.

## Ad-hoc команды

Ad-hoc команды — это способ выполнения быстрых, одноразовых задач на управляемых узлах напрямую из командной строки, без написания плейбуков. Это основной инструмент для оперативного управления и проверки состояния систем.

**Синтаксис:**
`ansible <pattern> -m <module> -a "<arguments>"`

-   `<pattern>`: Целевые хосты (например, `all`, `webservers`).
-   `-m <module>`: Используемый модуль (по умолчанию `command`).
-   `-a <arguments>`: Аргументы для модуля.

Например, чтобы проверить доступность всех хостов:
`ansible all -m ping`
