# Ansible: Дополнительная информация о модулях

## Определения

**Дополнительные рекомендации по использованию модулей Ansible** — это набор советов и лучших практик, которые помогают эффективно и безопасно использовать модули Ansible в повседневной работе.

## Основные концепции

- **Идемпотентность**: Большинство модулей Ansible спроектированы идемпотентными — повторное выполнение не изменяет систему, если она уже в желаемом состоянии.
- **Специфические параметры**: Каждый модуль имеет уникальные параметры — перед использованием изучайте документацию.
- **Справка через `ansible-doc`**: Утилита командной строки для быстрого доступа к документации по модулям.
- **Безопасность**: Для задач с чувствительными данными используйте `no_log: true` — подробности в [Лучшие практики Vault](../Vault/best_practices.md#сценарий-1-предотвращение-утечек-в-логах-no_log-true).

## Практические сценарии

### Получение справки по модулю

```bash
# Получить справку по модулю apt
ansible-doc apt

# Получить список всех доступных модулей
ansible-doc -l
```

### Выбор правильного модуля

Рекомендации по выбору модулей:

- **Специализированные модули предпочтительнее**: Отдавайте предпочтение модулям `apt`, `yum`, `service` перед `command`/`shell` — подробности в [Модули выполнения команд](ansible_command_execution_modules.md).
- **Проверяйте идемпотентность**: Если модуль не идемпотентен, используйте параметры `creates`, `removes` или `changed_when`.
- **Используйте `no_log`**: Для задач с чувствительными данными добавляйте `no_log: true` — см. [Лучшие практики Vault](../Vault/best_practices.md#сценарий-1-предотвращение-утечек-в-логах-no_log-true).
