# Ansible: Дополнительная информация о модулях

## Определения

**Дополнительные рекомендации по использованию модулей Ansible** — это набор советов и лучших практик, которые помогают эффективно и безопасно использовать модули Ansible в повседневной работе.

## Основные концепции

- **Идемпотентность**: Большинство модулей Ansible спроектированы быть идемпотентными. Это означает, что повторное выполнение задачи не приведет к изменениям, если система уже находится в желаемом состоянии.
- **Специфические параметры**: Каждый модуль имеет свои уникальные параметры. Перед использованием рекомендуется изучить документацию.
- **Официальная документация**: Ansible имеет обширную официальную документацию, которая является наиболее авторитетным источником информации.
- **Командная строка**: Утилита `ansible-doc` предоставляет быстрый доступ к справке по модулям прямо из командной строки.

## Практические сценарии

### Получение справки по модулю

```bash
# Получить справку по модулю apt
ansible-doc apt

# Получить список всех доступных модулей
ansible-doc -l
```

### Выбор правильного модуля

1. **Специализированные модули предпочтительнее**: Всегда отдавайте предпочтение специализированным модулям (например, `apt`, `yum`, `service`) перед универсальными (`command`, `shell`).
2. **Проверяйте идемпотентность**: Убедитесь, что выбранный модуль обеспечивает идемпотентность. Если нет, используйте параметры `creates`, `removes` или `changed_when`.
3. **Используйте `no_log`**: Для задач, работающих с чувствительными данными, добавляйте `no_log: true` для предотвращения утечек в логи.
