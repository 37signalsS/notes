# Модули синхронизации файлов Ansible

## Определения

**Модули синхронизации файлов** — это инструменты Ansible для эффективной передачи данных и синхронизации каталогов между хостами. Основным инструментом является модуль `synchronize`, который представляет собой обертку над системной утилитой `rsync` (Remote Sync).

## Основные концепции

### Модуль `ansible.posix.synchronize`

В современных версиях Ansible модуль входит в коллекцию `ansible.posix` (Portable Operating System Interface). Его главное преимущество — использование алгоритма `rsync`, который передает только измененные части файлов, что значительно ускоряет процесс по сравнению с `ansible.builtin.copy`.

**Ключевые особенности:**

- **Производительность**: Идеален для передачи большого количества мелких файлов или файлов большого объема.
- **Идемпотентность**: Модуль автоматически определяет различия и копирует только необходимое.
- **Направление синхронизации**: По умолчанию работает в режиме `push` (отправка на удаленный узел), но поддерживает и `pull` (загрузка с удаленного узла).
- **Требования**: Утилита `rsync` должна быть установлена как на контрольном узле, так и на управляемых хостах.

### Важные параметры

- **`archive`**: (по умолчанию `yes`) Включает режим архивации, сохраняя права доступа, владельцев и временные метки.
- **`delete`**: Если установлено в `yes`, удаляет файлы на целевой стороне, если они отсутствуют в источнике (создает точную копию).
- **`recursive`**: (по умолчанию `yes`) Рекурсивный обход директорий.
- **`mode`**: Определяет направление (`push` или `pull`).

## Практические сценарии

### Синхронизация статического контента

Создание точной копии локальной директории на сервере с удалением лишних файлов.

```yaml
- name: Синхронизация содержимого сайта
  ansible.posix.synchronize:
    src: files/html/
    dest: /var/www/html/
    delete: yes
    recursive: yes
```

### Загрузка бэкапов с сервера (режим Pull)

Синхронизация данных с удаленного хоста на контрольный узел.

```yaml
- name: Загрузка бэкапов базы данных
  ansible.posix.synchronize:
    mode: pull
    src: /var/backups/db/
    dest: ./backups/
```

### Нюансы работы в средах Vagrant (инструмент для создания и управления виртуальными средами)

Модуль `synchronize` инициирует прямое SSH (Secure Shell) соединение вне основного канала управления Ansible. Это часто приводит к ошибкам аутентификации в Vagrant, так как модуль не видит специфические ключи Vagrant.

**Рекомендации:**

1. Для малых объемов данных в Vagrant используйте `ansible.builtin.copy`.
2. Если `synchronize` необходим, укажите параметры подключения явно через `rsync_opts` или используйте `ansible.builtin.copy` с `remote_src: yes`, если данные уже на хосте.

```yaml
# Альтернатива для Vagrant при проблемах с SSH
- name: Копирование через стандартный модуль
  ansible.builtin.copy:
    src: files/html/
    dest: /var/www/html/
```
