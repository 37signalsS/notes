# Ansible: Обзор часто используемых модулей

## Определения

**Модули Ansible** — это автономные единицы кода, которые выполняют конкретные задачи на управляемых хостах. Они являются основой работы Ansible, предоставляя функциональность для автоматизации широкого спектра операций, от управления пакетами до настройки конфигурационных файлов и служб. Каждый модуль разработан для выполнения определенной операции и стремится быть идемпотентным.

## Основные концепции

- **Идемпотентность**: Ключевое свойство большинства модулей Ansible. Повторное выполнение не изменяет систему, если она уже находится в желаемом состоянии. Более подробно об идемпотентности см. в [Ansible: Основные концепции](../ansible_core_concepts.md#идемпотентность). Если модуль не идемпотентен, рекомендуется использовать параметры `creates`, `removes` или `changed_when`.
- **Специфические параметры**: Каждый модуль имеет уникальные параметры. Модули абстрагируют сложность работы с различными операционными системами, предоставляя унифицированный интерфейс.
- **Специализированные модули предпочтительнее**: Отдавайте предпочтение нативным модулям (`apt`, `yum`, `service`) перед общими (`command`, `shell`) — подробности в [Модули выполнения команд](ansible_command_execution_modules.md).
- **Безопасность и чувствительные данные**: Для задач с паролями или токенами используйте `no_log: true` — подробности в [Лучшие практики Vault](../Vault/best_practices.md#сценарий-1-предотвращение-утечек-в-логах-no_log-true).

### Получение справки по модулю

Справка по модулям доступна через утилиту командной строки `ansible-doc`:

```bash
# Получить справку по модулю apt
ansible-doc apt

# Получить список всех доступных модулей
ansible-doc -l
```
