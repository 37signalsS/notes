# Ansible: Обзор часто используемых модулей

## Определения

**Модули Ansible** — это автономные единицы кода, которые выполняют конкретные задачи на управляемых хостах. Они являются основой работы Ansible, предоставляя функциональность для автоматизации широкого спектра операций, от управления пакетами до настройки конфигурационных файлов и служб. Каждый модуль разработан для выполнения определенной операции и стремится быть идемпотентным.

## Основные концепции

- **Идемпотентность**: Ключевое свойство большинства модулей Ansible. Повторное выполнение не изменяет систему, если она уже находится в желаемом состоянии. Более подробно об идемпотентности см. в [Основные концепции Ansible](../ansible_core_concepts.md#идемпотентность). Если модуль не идемпотентен, рекомендуется использовать параметры `creates`, `removes` или `changed_when`.
- **Специфические параметры**: Каждый модуль имеет уникальные параметры. Модули абстрагируют сложность работы с различными операционными системами (ОС — Operating Systems), предоставляя унифицированный интерфейс.
- **Специализированные модули предпочтительнее**: Отдавайте предпочтение нативным модулям (`apt`, `yum`, `service`) перед общими (`command`, `shell`) — подробности в [Ansible: Модули выполнения команд](ansible_command_execution_modules.md).
- **Безопасность и чувствительные данные**: Для задач с паролями или токенами используйте `no_log: true` — подробности в [Ansible Vault: Лучшие практики](../Vault/best_practices.md#сценарий-1-предотвращение-утечек-в-логах-no_log-true).
- **Взаимодействие с результатом (register)**: Большинство модулей возвращают подробный JSON-ответ. Чтобы использовать эти данные (статус изменения, вывод команды, ошибки) в последующих задачах, используйте директиву `register`. Это критично для построения сложной логики и отладки — подробности в [Управление ходом выполнения](../PlaybookStructure/flow_control.md#регистрация-результатов-register).

### Получение справки по модулю

Справка по модулям доступна через утилиту командной строки `ansible-doc`:

```bash
# Получить справку по модулю apt
ansible-doc apt
# → (вывод документации в формате man-page)

# Получить список всех доступных модулей
ansible-doc -l
# → (полный список установленных модулей с описанием)
```
