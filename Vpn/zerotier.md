# ZeroTier: Виртуальные сети поверх интернета

ZeroTier — это платформа, которая позволяет создавать защищенные виртуальные сети (L2-сети) между устройствами, где бы они ни находились. Она решает проблему NAT-траверсала, позволяя устройствам общаться напрямую друг с другом, как если бы они были в одной физической локальной сети.

- **Сайт:** [zerotier.com](https://www.zerotier.com/)
- **Исходный код:** [github.com/zerotier/ZeroTierOne](https://github.com/zerotier/ZeroTierOne)

ZeroTier создает виртуальный Ethernet-свитч (называемый "контроллером сети"), к которому подключаются устройства ("узлы"). Каждый узел получает уникальный адрес в виртуальной сети и может напрямую связываться с другими узлами, используя стандартные протоколы. Соединения устанавливаются по принципу P2P, а если прямое соединение невозможно, трафик ретранслируется через корневые серверы ZeroTier.

- **Открытый исходный код:** Основной движок написан на C++. Для самостоятельно размещенных контроллеров существует альтернативный веб-интерфейс с открытым кодом — [ztncui](https://github.com/key-networks/ztncui).
- **Кроссплатформенность:** Серверная часть и клиенты доступны для Linux, Windows, macOS, BSD, а также для мобильных платформ (iOS, Android) и встраиваемых систем.
- **Надежное шифрование:** Все соединения шифруются end-to-end с использованием потокового шифра Salsa20, кода аутентификации Poly1305 и эллиптической кривой Curve25519 для обмена ключами.
- **Масштабируемость:** Одна сеть может поддерживать до ~16.7 миллионов устройств.
- **Собственный хостинг:** Можно развернуть собственный сетевой контроллер для полной независимости от инфраструктуры ZeroTier.
