# Unikernel Overview

## Определения

**Unikernel** — специализированный легковесный образ ОС для запуска одного приложения. Исходный код приложения компилируется с минимально необходимыми библиотеками и драйверами в единый исполняемый файл, работающий напрямую на гипервизоре.

Ключевая идея: вместо развертывания приложения поверх полнофункциональной ОС, unikernel объединяет приложение и ОС в одно целое.

### Архитектура: Традиционный подход vs Unikernel

| **Традиционная VM** | **Unikernel** |
| :--- | :--- |
| 1. Приложение | 1. Приложение + Библиотеки ОС |
| 2. Библиотеки User-space (libc и др.) | 2. Гипервизор / "Железо" |
| 3. Ядро ОС (со всеми драйверами) | |
| 4. Гипервизор / "Железо" | |
| **Размер:** сотни МБ – ГБ | **Размер:** единицы МБ |
| **Время старта:** десятки секунд | **Время старта:** миллисекунды |
| **Поверхность атаки:** Огромная | **Поверхность атаки:** Минимальная |

## Основные концепции

### Типы Unikernels

- **Clean-slate:** Написаны с нуля на типобезопасных языках. Пример: [MirageOS](./popular_unikernels.md) (OCaml).
- **POSIX-совместимые:** Поддерживают POSIX API для упрощения портирования. Пример: [OSv](./popular_unikernels.md).
- **На базе существующих ОС:** Используют компоненты из ядер NetBSD/Linux. Пример: [Rumprun](./popular_unikernels.md).

### Преимущества и ограничения

Unikernels предлагают улучшения в безопасности и производительности за счет минимализма, но с компромиссами в гибкости и простоте разработки.
