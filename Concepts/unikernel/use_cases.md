# Unikernel Use Cases

## Определения

Документ описывает практические сценарии применения **unikernels**. Выбор сценариев обусловлен ключевыми преимуществами технологии: малым размером, быстрым стартом и высокой изоляцией.

Базовая информация — в [обзоре unikernels](./unikernel_overview.md).

## Основные концепции

### Критерии выбора сценария

Unikernels наиболее эффективны в задачах, где важны:

- **Быстрый старт:** Serverless, FaaS, масштабирование на edge.
- **Минимальный размер:** IoT-устройства, ограниченные ресурсы.
- **Изоляция:** Мультитенант-среды, безопасность.
- **Производительность:** Сетевые функции с низкой задержкой.

## Практические сценарии

### Edge Computing и IoT

Unikernels подходят для устройств с ограниченными ресурсами и сетевых функций на границе сети.

**Примеры:**
- Легковесные DNS-серверы.
- SSL/TLS-терминаторы.
- Сетевые экраны (firewalls) и шлюзы безопасности.
- ПО для IoT-устройств.

**Преимущества:**
- **Мгновенный старт:** Быстрое развертывание и масштабирование на edge-локациях.
- **Малый размер:** Экономия дискового пространства и памяти.
- **Безопасность:** Минимальная поверхность атаки критична для устройств вне дата-центра.

### Serverless / Function-as-a-Service (FaaS)

Unikernel-подобный подход (MicroVMs) — эволюция FaaS-платформ.

**Пример:** **AWS Firecracker** (основа AWS Lambda и AWS Fargate) использует MicroVMs, близкие к unikernels по сути.

**Преимущества:**
- **Быстрый холодный старт:** Запуск функции за миллисекунды.
- **Высокая плотность:** Тысячи изолированных функций на одном хосте.
- **Надежная изоляция:** Каждая функция в собственной MicroVM (изоляция на уровне гипервизора).

### Высокопроизводительные сетевые приложения

Сетевые функции с минимальной задержкой и высокой пропускной способностью.

**Примеры:**
- Балансировщики нагрузки.
- Кэширующие прокси-серверы.
- Компоненты кастомных CDN.

**Преимущества:**
- Отсутствие переключений ядро ↔ user space минимизирует задержки обработки трафика.

### Специализированные устройства безопасности

Создание "закаленных" (hardened) виртуальных устройств.

**Примеры:**
- VPN-концентраторы.
- Системы обнаружения/предотвращения вторжений (IDS/IPS).

**Преимущества:**
- Устранение лишних компонентов ОС и утилит делает систему сложной для взлома.
