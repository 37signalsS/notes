# Популярные Unikernel-проекты

## Определения

В этом документе представлены примеры популярных фреймворков и реализаций **unikernels** с краткими характеристиками и фрагментами кода.

Для понимания базовых концепций unikernels ознакомьтесь с [общим обзором](./unikernel_overview.md).

## Основные концепции

### Критерии выбора unikernel-фреймворка

При выборе фреймворка для разработки unikernel учитывайте:

* **Язык разработки:** OCaml (MirageOS), C++ (IncludeOS), или поддержка существующего кода (OSv, Rumprun, Unikraft).
* **Совместимость:** Требуется ли POSIX-совместимость для портирования существующих приложений.
* **Размер образа:** От 1-2 МБ (MirageOS) до 10+ МБ (IncludeOS, OSv).
* **Экосистема:** Зрелость фреймворка и доступность библиотек.
* **Целевая платформа:** KVM, Xen, AWS, GCE, VMware, bare-metal.

### Сводная таблица проектов

| Проект | Язык / Совместимость | Статус | Размер | Особенности |
| :--- | :--- | :--- | :--- | :--- |
| **Unikraft** | C / POSIX (модульный) | Активен | ~1-5 МБ | Linux Foundation, высокая модульность |
| **Nanos/Ops** | Любой / Binary comp. | Активен | ~5-15 МБ | Запуск немодифицированных бинарников |
| **MirageOS** | OCaml / Clean-slate | Активен | ~1-2 МБ | Максимальная безопасность, OCaml-стек |
| **OSv** | C++ / POSIX | Стабилен | ~10-20 МБ | Оптимизирован для JVM и Python |
| **IncludeOS** | C++ / Минимальная | Legacy | ~5-10 МБ | Ориентирован на C++ и IoT |
| **Rumprun** | C / POSIX | Legacy | ~5-15 МБ | Использует драйверы NetBSD |

## Практические сценарии

### 1. Unikraft (Linux Foundation)

* **Описание:** Высокопроизводительный модульный юникернел. Позволяет выбирать только необходимые компоненты (файловая система, сеть) для сборки максимально компактного образа.
* **Пример использования:**

    ```bash
    # Инициализация проекта на базе Unikraft
    kraft init -t helloworld myapp
    
    # Сборка под конкретную платформу (например, QEMU/KVM)
    kraft build
    
    # Запуск образа
    kraft run
    # → Hello world!
    ```

### 2. Nanos / OPS

* **Описание:** Юникернел, нацеленный на простоту использования и запуск существующих приложений (Go, Node.js, Python, Java) без переписывания кода.
* **Пример использования (Node.js):**

    ```bash
    # Установка инструментария
    curl https://ops.city/get.sh -sSfL | sh
    
    # Запуск существующего Node.js приложения как юникернела
    ops run myapp.js -p 8080
    # → Запускает приложение в локальной KVM/QEMU среде
    ```

### 3. MirageOS

* **Описание:** "Чистый" unikernel-фреймворк на **OCaml**. Весь стек, включая драйверы, реализован на OCaml.
* **Пример (конфигурация):**

    ```ocaml
    (* config.ml *)
    open Mirage
    let main = foreign "Unikernel.Main" (stackv4 @-> job)
    let () = register "hello" [main $ default_stackv4]
    ```

### 4. OSv

* **Описание:** Оптимизирован для запуска JVM-приложений и других управляемых сред.
* **Пример запуска:**

    ```bash
    # Запуск образа с Java-приложением в облаке или локально
    scripts/run.py -e "java -jar myapp.jar"
    ```
