# Популярные Unikernel-проекты

## Определения

В этом документе представлены основные фреймворки и реализации **unikernels**, актуальные на 2026 год. Описаны их ключевые характеристики, статус разработки и приведены практические фрагменты кода для старта.

Базовые концепции технологии (Library OS, изоляция) описаны в [Обзоре Unikernel](./unikernel_overview.md).

## Основные концепции

### Критерии выбора unikernel-фреймворка

При выборе инструмента в 2026 году следует ориентироваться на следующие параметры:

*   **Язык разработки:** OCaml (MirageOS), C/C++ (Unikraft, OSv) или поддержка любого языка через бинарную совместимость (Nanos).
*   **Безопасность:** Наличие ASLR (экспериментально в OSv, нативно в Unikraft), W^X (Write XOR Execute) и механизмов типа **Network Shield**.
*   **Поддержка оборудования:** Требуется ли доступ к GPU (Nanos) или работа на ARM64/Apple Silicon (M1-M4).
*   **Размер образа:** От 1 МБ (MirageOS) до 50 МБ (Nanos с GPU-библиотеками).
*   **Совместимость:** Уровень поддержки POSIX и возможность запуска немодифицированных Linux ELF бинарников.

## Практические сценарии

### 1. Unikraft (Linux Foundation)
В 2026 году релиз 11 «Metis» превратил Unikraft в полноценную платформу для AI-агентов.

*   **Ключевые фичи Metis:**
    *   **Instance Branching:** Клонирование запущенной микро-ВМ за миллисекунды.
    *   **Snapshots:** Мгновенные слепки состояния системы для отката или горизонтального масштабирования.
    *   **AI Inference Plugins:** Нативная интеграция движков исполнения моделей.
*   **Пример управления через `kraft` CLI:**
    ```bash
    # Создание инстанса из снапшота (Metis feature)
    kraft cloud instance create --snapshot mysnap-v1 --name app-clone-1
    ```

### 2. Nanos / OPS
Лидер в области запуска существующих приложений с поддержкой аппаратного ускорения.

*   **GPU Support:** Единственный юникернел с нативной поддержкой NVIDIA GPU через `gpu_nvidia` klib.
*   **Inception:** Технология, ускоряющая работу в облаках (AWS/GCP) до 4 раз по сравнению с классической эмуляцией.
*   **Пример конфигурации для GPU (`config.json`):**
    ```json
    {
      "RunConfig": { "GPUs": 1 },
      "Klibs": ["gpu_nvidia"],
      "Dirs": ["nvidia_drivers"]
    }
    ```

### 3. MirageOS
Современная версия 4.5 полностью совместима с **OCaml 5**.

*   **Effects-based Concurrency:** Использование библиотеки `Eio` позволяет писать высокопроизводительный асинхронный код без использования монад (Lwt).
*   **Multicore:** Поддержка многоядерности находится в стадии стабилизации (через бэкенд Unikraft).
*   **Пример (OCaml 5 / Eio):**
    ```ocaml
    (* Использование прямых эффектов вместо Lwt.bind *)
    let main ~net =
      Eio.Net.listen net ~port:8080 @@ fun socket ->
        (* Обработка соединений *)
    ```

### 4. OSv
Остается лучшим выбором для запуска legacy Java-приложений. В 2026 году основные усилия сообщества направлены на внедрение **ASLR** (Address Space Layout Randomization).

*   **Статус безопасности:** Официальная ветка всё еще не имеет ASLR по умолчанию, однако существуют стабильные патчи 2026 года для рандомизации базы приложения и стека.
*   **JVM:** Бесшовная поддержка OpenJDK 17/21.
