# Основы мониторинга

Мониторинг — это постоянный сбор и анализ различных параметров поведения системы для обеспечения её стабильности, производительности и для своевременного обнаружения проблем.

## Области мониторинга

Мониторинг можно разделить на три основные категории:

1.  **Мониторинг оборудования (инфраструктуры):**
    *   **CPU:** Нагрузка на процессор.
    *   **Память:** Использование оперативной памяти (свободно, занято).
    *   **Диск:** Свободное место на диске, нагрузка (количество операций ввода/вывода).
    *   **Сеть:** Нагрузка на сетевые интерфейсы.
    *   **Системные процессы:** Количество задач в различных статусах (running, blocked и т.д.).

2.  **Мониторинг приложений:**
    *   **Производительность:** Количество запросов в секунду (RPS), время ответа.
    *   **База данных:** Количество запросов к БД, время выполнения.
    *   **Ошибки:** Количество и типы ошибок, которые генерирует приложение.
    *   **Пользовательская активность:** Количество активных пользователей в единицу времени.

3.  **Бизнес-метрики:**
    *   **Конверсии:** Количество покупок, подписок, регистраций.
    *   **Вовлеченность:** Какие функции продукта используются наиболее часто, а какие — игнорируются.
    *   **Финансовые показатели:** Доход, средний чек.

## Системы мониторинга

Существует множество инструментов для реализации мониторинга. Некоторые из популярных:

*   **Prometheus + Grafana:** Современный стек, ставший стандартом де-факто в Cloud Native среде. Prometheus отвечает за сбор и хранение метрик, а Grafana — за их визуализацию.
*   **Zabbix:** Более "классическая" система мониторинга с богатым функционалом, включающим сбор метрик, их хранение, визуализацию и алертинг в одном продукте.
*   **Самописные скрипты:** Простые решения на базе скриптов, которые могут быть полезны для специфических задач, но плохо масштабируются.
*   **Nagios / Icinga:** Системы, исторически сфокусированные на проверках доступности (health checks) и алертинге.
