# Подходы к мониторингу

### 1. The Four Golden Signals (SRE-подход Google)

- **Latency (Задержка):** Время, необходимое для обслуживания запроса. Важно отслеживать не только успешные, но и неудачные запросы.
- **Traffic (Трафик):** Нагрузка на систему, измеряемая в специфичных для системы единицах (например, запросы в секунду).
- **Errors (Ошибки):** Частота неудачных запросов.
- **Saturation (Насыщенность):** Насколько "заполнен" сервис. Это мера загрузки наиболее ограниченного ресурса системы (например, CPU, память). Позволяет прогнозировать проблемы до их наступления.

### 2. The USE Method (Utilization, Saturation, Errors)

- **Utilization (Утилизация):** Процент времени, в течение которого ресурс был занят. Например, утилизация CPU 90%.
- **Saturation (Насыщенность):** Мера перегрузки ресурса, которую утилизация не может показать. Обычно выражается в длине очереди запросов к ресурсу.
- **Errors (Ошибки):** Количество ошибок, связанных с ресурсом.

### 3. The RED Method

Метод, сфокусированный на мониторинге сервисов (особенно микросервисов).

- **Rate (Частота):** Количество запросов в секунду, которые обрабатывает сервис.
- **Errors (Ошибки):** Количество неудачных запросов в секунду.
- **Duration (Длительность):** Распределение времени, которое требуется для обработки запросов.
