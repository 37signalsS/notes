# Инструкция по развертыванию RAG-системы

Это руководство объясняет, как восстановить и запустить систему поиска RAG (Retrieval-Augmented Generation) после клонирования репозитория на новую машину.

## Требования
- **Python 3.9+**
- **Git**

## Шаги установки

### 1. Создание виртуального окружения
Перейдите в директорию RAG-системы и создайте новое окружение `venv`:
```bash
cd AI/rag_system
python3 -m venv venv
```

### 2. Установка зависимостей
Активируйте окружение и установите необходимые библиотеки:
```bash
source venv/bin/activate
pip install -r requirements.txt
```
*Примечание: При первом запуске система скачает модели эмбеддингов (BGE-M3 и MPNet) с HuggingFace (общий объем около 2-3 ГБ).*

### 3. Сборка поисковых индексов
Так как тяжелые файлы индексов исключены из Git, их необходимо собрать заново из ваших заметок:
```bash
chmod +x refresh_rag.sh
./refresh_rag.sh
```

## Использование
После индексации агент Gemini CLI и скрипт `unified_search.py` станут полностью функциональными.

## Обслуживание
Запускайте `./refresh_rag.sh` каждый раз после внесения значительных изменений в заметки, чтобы результаты поиска оставались актуальными.
