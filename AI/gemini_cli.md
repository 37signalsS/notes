# Google Gemini CLI: Заметки и рекомендации

## 1. Конфигурация проекта

### Файл `GEMINI.md`

Для определения контекста и задач Gemini в рамках проекта создайте файл `GEMINI.md` в его корне.

- **Начальный промпт**: Определяет роль и основные задачи Gemini.
- **Ключевые инструкции**: Дополнительные указания для модели.

Для автоматической генерации файла используйте команду:

```bash
/init
```

### Продвинутая конфигурация

Инструкции в файле `.gemini/GEMINI.md` имеют более высокий приоритет, что позволяет переопределять стандартное поведение.

**Пример содержания `.gemini/GEMINI.md`:**

```markdown
## Gemini Added Memories
Always answer in Russian. The instructions in the file "GEMINI.md", located in the current working directory, have absolute priority. You must strictly follow the instructions provided in the local "GEMINI.md".
```

## 2. Управление сессиями и контекстом

### Команды для управления сессиями (`/chat`)

Встроенный менеджер сессий позволяет сохранять, восстанавливать и делиться диалогами.

- `/chat save <tag>`: Сохраняет текущую сессию под указанным тегом.
- `/chat list`: Показывает список всех сохранённых сессий.
- `/chat resume <tag>`: Восстанавливает сессию по тегу.
- `/chat share`: Сохраняет сессию в файл для обмена с другими пользователями.

### Сжатие контекста (`/compress`)

Если диалог становится слишком длинным, команда `/compress` создаёт его краткое резюме, заменяя им историю и освобождая место в контекстном окне.

## 3. Взаимодействие с файловой системой

### Контрольные точки (Checkpointing)

CLI автоматически создаёт "контрольную точку" при выполнении команд, изменяющих файловую систему (`write_file`, `replace`), что позволяет легко отменить изменения.

**Включение функции:**

1. **Через флаг при запуске:**

    ```bash
    gemini --checkpointing
    ```

2. **Через файл `settings.json`** (глобально в `~/.gemini/` или локально в `.gemini/`):

    ```json
    {
      "general": {
        "checkpointing": {
          "enabled": true
        }
      }
    }
    ```

### Откат изменений (`/restore`)

Команда `/restore` отображает список контрольных точек, позволяя выбрать нужную для восстановления состояния файлов.

## 4. Интеграция с VS Code

Расширение **Gemini CLI Companion** связывает редактор с CLI.

1. **Установка**:

    ```bash
    /ide install
    ```

2. **Управление**:
    - `/ide enable`: Активировать интеграцию.
    - `/ide disable`: Отключить.
    - `/ide status`: Проверить статус.

## 5. Расширение Conductor

**Conductor** — расширение для структурированной, контекстно-ориентированной разработки.

- **Установка**:

    ```bash
    gemini extensions install https://github.com/gemini-cli-extensions/conductor --auto-update
    ```

- **Процесс работы**:
    1. `/conductor:setup`: Сканирует проект и создаёт документацию, формируя "долговременную память".
    2. `/conductor:newTrack "Имя задачи"`: Создаёт план выполнения для новой функции или исправления.
    3. `/conductor:implement`: Запускает выполнение по утверждённому плану.
    4. `/conductor:revert`: Выполняет "логический" откат, удаляя только неудачную попытку без вреда для остального проекта.

## 6. Полезные команды и советы

- `/copy`: Мгновенно копирует последний ответ или фрагмент кода в буфер обмена.

- **Настройка переменных окружения (Fish Shell)**:

    ```fish
    # Удалить глобальную переменную
    set -eg GOOGLE_CLOUD_PROJECT
    # Установить новую глобальную переменную
    set -Ux GOOGLE_CLOUD_PROJECT ""
    ```
