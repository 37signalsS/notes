# Google Gemini CLI

Для эффективной работы с Gemini CLI рекомендуется создать файл `Gemini.md` в корне проекта. Этот файл должен содержать:

-   **Начальный промпт (Initial Prompt)**: Определяет роль и задачи Gemini в рамках проекта.
-   **Ключевые инструкции**: Любые другие важные указания для Gemini.

### Продвинутый контекст: приоритет и переопределение

Для более сложной настройки и переопределения стандартного поведения можно использовать директорию `.gemini`. Если создать файл `GEMINI.md` внутри этой директории (`.gemini/GEMINI.md`), его инструкции получат более высокий приоритет. 

Cодержание GEMINI.md в .gemini может быть следующим: 

```
## Gemini Added Memories
Always answer in Russian. The instructions in the file "GEMINI.md", located in the current working directory, have absolute priority. You must strictly follow the instructions provided in the local "GEMINI.md".
```

### Инициализация проекта

-   Создание файла `GEMINI.md` с описанием проекта:
    ```bash
    /init
    ```

### Управление сессиями

-   **Сохранение чата**:
    ```bash
    /chat save <имя_сессии>
    ```

## Контрольные точки (Checkpointing)

Когда вы одобряете инструмент, который изменяет файловую систему (например, `write_file` или `replace`), CLI автоматически создаёт «контрольную точку». 

Если вы хотите отменить изменение или просто вернуться назад, вы можете использовать команду `/restore`. 

#### Использование флага командной строки

Вы можете включить контрольную точку для текущего сеанса, используя флаг `--checkpointing` при запуске Gemini CLI:

```bash
gemini --checkpointing
```

#### Используя файл `settings.json`

Чтобы включить контрольные точки по умолчанию для всех сеансов, вам нужно отредактировать файл `settings.json`.

> **Примечание:** Этот файл может находиться в двух местах:
> *   `~/.gemini/settings.json` — для глобальных настроек текущего пользователя.
> *   `.gemini/settings.json` — в корне проекта, для настроек конкретного проекта (имеет приоритет).

Добавьте следующий ключ к вашему `settings.json`:

```json
{
  "general": {
    "checkpointing": {
      "enabled": true
    }
  }
}
```

### Использование команды `/restore`

```
/restore
```

Интерфейс командной строки отобразит список доступных файлов контрольных точек. Имена этих файлов обычно состоят из метки времени, имени изменяемого файла и имени инструмента, который должен был быть запущен (например, `2025-06-22T10-00-00_000Z-my-file.txt-write_file`).

## Интеграция с VS Code: Gemini CLI Companion

1.  **Установка**: Самый простой способ — выполнить команду в терминале с запущенным Gemini CLI:
    ```bash
    /ide install
    ```
    CLI сам предложит установить расширение, если оно отсутствует.

2.  **Управление**: После установки интеграцией можно управлять с помощью команд:
    *   `/ide enable`: активировать связь с редактором.
    *   `/ide disable`: деактивировать связь.
    *   `/ide status`: проверить текущий статус.

### Fish global env

```
# Удаляем глобальную переменную в текущей сессии
  set -eg GOOGLE_CLOUD_PROJECT

# Теперь добавляем новую глобальную переменную
  set -Ux GOOGLE_CLOUD_PROJECT ""
```
