# Плагины Grafana

## Определения

**Плагины** — это пакеты, которые расширяют стандартную функциональность Grafana. Экосистема плагинов позволяет подключать новые источники данных, добавлять уникальные типы визуализаций и даже встраивать целые приложения в интерфейс Grafana.

Плагины могут состоять только из фронтенд-компонента или также включать бэкенд-компонент, который расширяет возможности сервера Grafana.

## Базовые концепции

### Типы плагинов

Существует три основных типа плагинов:

*   **Panel:** Добавляет новые типы визуализаций (например, `Pie Chart`, `Worldmap`).
*   **Data Source:** Добавляет поддержку новых источников данных (например, Zabbix, ClickHouse, GitHub).
*   **App:** Добавляет комплексную функциональность, включая новые страницы, источники данных и панели в интерфейс Grafana (например, Zabbix App, Kubernetes App).

## Практические сценарии

### Установка плагинов как код (Provisioning)

Автоматическая установка плагинов является лучшей практикой для обеспечения согласованности окружений и упрощения развертывания.

#### Способ 1: Через переменные окружения (Docker)

Grafana позволяет указать плагины для автоматической установки при старте через переменную окружения `GF_INSTALL_PLUGINS`. При запуске контейнера Grafana автоматически вызовет `grafana-cli` для установки указанных плагинов.

**Пример для `docker-compose.yml`:**
```yaml
services:
  grafana:
    image: grafana/grafana:10.4.2
    container_name: grafana
    ports:
      - "3000:3000"
    environment:
      # Список плагинов через запятую или пробел
      - GF_INSTALL_PLUGINS=grafana-piechart-panel,grafana-worldmap-panel
```

#### Способ 2: Через Helm (Kubernetes)

Helm-чарт Grafana позволяет определить список плагинов для установки в файле `values.yaml`. При развертывании чарта, init-контейнер установит эти плагины перед запуском основного контейнера Grafana.

**Пример в `values.yaml`:**
```yaml
plugins:
  - grafana-piechart-panel
  - grafana-worldmap-panel
```

### Ручная установка

Этот способ подходит для тестирования или разовых установок.

1.  **Найдите плагин** на официальном маркетплейсе [Grafana Plugins](https://grafana.com/grafana/plugins/). На странице каждого плагина указан его ID (например, `grafana-piechart-panel`).

2.  **Выполните команду установки.** Для этого необходимо зайти в командную оболочку пода или контейнера Grafana.

    Пример для Kubernetes:
    ```bash
    # Зайти в под
    kubectl exec -it <grafana-pod-name> -n <namespace> -- /bin/bash

    # Выполнить установку внутри пода
    grafana-cli plugins install grafana-piechart-panel
    ```

3.  **Перезапустите сервер Grafana**, чтобы изменения вступили в силу.

    Пример для Kubernetes:
    ```bash
    kubectl scale deployment/grafana -n monitoring --replicas=0
    kubectl scale deployment/grafana -n monitoring --replicas=1
    ```

4.  **Проверьте установку.** Новый плагин появится в разделе **Administration -> Plugins** и станет доступен для использования в дашбордах.

## Дополнительная информация

*   **Устаревший метод:** В старых версиях Grafana можно было использовать файловый провиженинг через `provisioning/plugins.yaml`, но сейчас этот метод считается устаревшим.
