# Grafana Плагины

Плагины — одна из ключевых возможностей Grafana, позволяющая значительно расширять её стандартную функциональность. Экосистема плагинов огромна: существуют сотни плагинов от официальных разработчиков, коммерческих партнеров и сообщества. Они позволяют подключать новые источники данных, добавлять уникальные типы визуализаций и даже встраивать целые приложения в интерфейс Grafana.

Плагины расширяют функциональность Grafana новыми панелями, источниками данных или приложениями.

**Типы плагинов:**

*   **Panel:** Добавляет новые типы визуализации (например, Pie Chart, Worldmap).
*   **Data Source:** Добавляет поддержку новых источников данных (например, Zabbix, ClickHouse, GitHub, Google Sheets).
*   **App:** Добавляет совершенно новые страницы и функции в пользовательский интерфейс Grafana (например, интеграция с Zabbix, приложение для мониторинга Kubernetes).

Плагины могут быть только для фронтенда или иметь бэкенд-компонент, который расширяет сервер Grafana.

## Установка плагина

1.  Найдите плагин на торговой площадке [Grafana Plugins](https://grafana.com/grafana/plugins/) (например, `grafana-piechart-panel`).

2.  На странице каждого плагина есть команда для установки. Вам нужно выполнить эту команду внутри контейнера Grafana.

    ```bash
    grafana-cli plugins install grafana-piechart-panel
    ```

3.  Чтобы выполнить команду, войдите в под Grafana:

    ```bash
    kubectl exec -it <grafana-pod-name> -n <namespace> -- /bin/bash
    ```

    Затем выполните команду установки плагина.

4.  После установки плагина вы должны **перезапустить сервер Grafana**, чтобы изменения вступили в силу. Обычный способ сделать это в Kubernetes — уменьшить масштаб развертывания до 0, а затем снова увеличить:

    ```bash
    kubectl scale deployment/grafana -n monitoring --replicas=0
    kubectl scale deployment/grafana -n monitoring --replicas=1
    ```

    После перезапуска убедитесь, что под Grafana снова запущен.

5.  Новый плагин появится в разделе **Plugins** в Grafana и будет доступен для использования в ваших дашбордах (например, при создании новой панели, вы сможете выбрать тип визуализации "Pie Chart").

## Установка плагинов как код (Provisioning)

Установка плагинов может и должна быть автоматизирована, чтобы обеспечить согласованность окружений и упростить развертывание.

### Способ 1: Через переменные окружения

Grafana позволяет указать плагины для автоматической установки при старте через переменную окружения `GF_INSTALL_PLUGINS`. Это основной способ для Docker-контейнеров.

**Пример для Docker Compose:**
```yaml
# docker-compose.yml
services:
  grafana:
    image: grafana/grafana:10.4.2
    container_name: grafana
    ports:
      - "3000:3000"
    environment:
      # Список плагинов через запятую
      - GF_INSTALL_PLUGINS=grafana-piechart-panel,grafana-worldmap-panel
```
При запуске контейнера Grafana автоматически вызовет `grafana-cli` для установки указанных плагинов.

### Способ 2: Через Helm (Kubernetes)

Helm-чарт Grafana также позволяет определить список плагинов для установки в файле `values.yaml`.

**Пример в `values.yaml`:**
```yaml
# values.yaml
plugins:
  - grafana-piechart-panel
  - trafficlight-panel
```

При развертывании Helm-чарта init-контейнер установит эти плагины перед запуском основного контейнера Grafana.

### Способ 3: Файловый провиженинг (устаревший)

В старых версиях Grafana можно было использовать `provisioning/plugins.yaml`, но сейчас этот метод считается устаревшим в пользу переменных окружения или нативных механизмов Helm.

Подробнее о концепции провижининга в целом можно прочитать в заметке [[grafana_provisioning.md]].
