# Grafana: Обзор

## Определения

**Grafana** — open-source платформа для аналитики, мониторинга и интерактивной визуализации данных. Ключевой принцип: Grafana **не хранит данные** (stateless в контексте данных), а выступает единым интерфейсом для запроса и визуализации информации из множества подключенных систем (Prometheus, Loki, ClickHouse, PostgreSQL и др.).

**Текущая версия (июль 2026):** Grafana 13.1.1 (мажорный релиз 13.0 вышел в апреле 2026).
- **Статус поддержки:** 13.x — актуальная ветка, 12.x — поддержка безопасности, 11.x — EOL (июнь 2026).

### Grafana Stack (бывший LGTM)

Комплексное решение для реализации [наблюдаемости (observability)](../Concepts/Observability_and_Monitoring/observability_definitions.md). Включает:
- **Grafana** — визуализация и анализ.
- **Mimir/Prometheus** — метрики.
- **Loki** — логи.
- **Tempo** — распределенные трассировки.
- **Alloy** — универсальный сборщик телеметрии.

## Базовые концепции

### Архитектура и лицензирование

- **Стек:** Бэкенд написан на **Go**, фронтенд на **TypeScript/React**.
- **Лицензия:** Основные компоненты распространяются под лицензией **AGPLv3**.
- **Observability as Code:** Начиная с версии 13.0, функционал **Git Sync** перешел в стадию General Availability, позволяя полноценно синхронизировать дашборды и настройки напрямую из Git-репозиториев.

### Ключевые возможности Grafana 13.x

| Возможность | Описание |
| :--- | :--- |
| **Grafana Assistant** | ИИ-помощник (OSS/Enterprise), помогающий генерировать запросы (PromQL/SQL) и строить визуализации. |
| **Git Sync** | Нативная синхронизация с GitHub/GitLab для реализации GitOps-подхода к мониторингу. |
| **Suggested Dashboards** | Автоматическое предложение дашбордов на основе обнаруженных схем данных в источниках. |
| **Unified Alerting** | Единая система алертинга для всех источников данных с поддержкой сложных условий и маршрутизации. |

## Практические сценарии

### Реализация Full-Stack Observability

1. **Сбор:** Агент **Alloy** собирает метрики, логи и трейсы из Kubernetes-кластера.
2. **Анализ инцидента:**
   - На дашборде виден всплеск ошибок (Метрики Mimir).
   - Через **Data Links** осуществляется переход к логам конкретного пода (Loki).
   - ИИ-ассистент помогает расшифровать ошибку в логах и предлагает SQL-запрос для проверки БД.
   - По `TraceID` открывается трассировка запроса (Tempo), выявляющая задержку во внешнем API.
3. **Исправление:** Изменение кода фиксируется в Git, и через **Git Sync** обновленный дашборд с новыми порогами алертов автоматически применяется в Grafana.

### Работа с Git Sync (Observability as Code)

В версии 13.x ручной импорт JSON-файлов становится вспомогательным методом. Основной рабочий процесс:
- Создание дашборда в UI (Development instance).
- Экспорт в Git-репозиторий.
- Автоматическая синхронизация с Production-экземпляром Grafana через встроенный Git-коннектор.

| Компонент | Область | Описание |
| :--- | :--- | :--- |

| **Faro** | **RUM** | Мониторинг фронтенда и пользовательского опыта. |
| **OnCall** | **Инциденты** | Система дежурств (Self-hosted версия ограничена в обновлениях с 2026). |
