# PostgreSQL: Обзор

PostgreSQL — это мощная, объектно-реляционная система управления базами данных (ОРСУБД) с открытым исходным кодом. Она заслужила репутацию надежной, функциональной и производительной СУБД, подходящей для широкого круга задач, от небольших приложений до крупных систем с высокой нагрузкой.
