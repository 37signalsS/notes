### **5. Показать таблицу iptables, запретить ICMP и убедиться, что ping не работает**

```bash
# -L — список правил (chains: INPUT, FORWARD, OUTPUT)
#	-n — без разрешения IP-адресов в DNS
#	-v — подробный вывод (включая счётчики пакетов и байт)
sudo iptables -L -n -v

# Протокол: ICMP
#	Тип ICMP: echo-request (это ping-запрос)
#	Действие: DROP (отбрасывает без ответа)
sudo iptables -A OUTPUT -p icmp --icmp-type echo-request -j DROP

ping google.com
```

### **7. Список процессов, объяснение ps auxft, PID 1 и дочерние процессы**

```bash
ps auxft
```

- **a**: все пользователи
- **u**: с указанием пользователя
- **x**: включая без терминала
- **f**: древовидное отображение
- **t**: привязка к терминалу

```
ps -p 1 -f
# -f - подробно

ps --ppid 1
```

**Пояснения:**

- **PID** – ID процесса
- **RSS (Resident Set Size)** – память в RAM (КБ)
- **VSZ (Virtual Set Size)** – виртуальная память (КБ)
- **NI (Nice)** – приоритет процесса (-20 высокий, 19 низкий)
- **PRI (Priority)** – фактический приоритет (*эффективный приоритет* процесса)
- **STAT** – статус процесса (R - running, S - sleeping и т.д.)

**Процесс, используемый терминалом:**

```
ps -t $(tty)
# -t - фильтр по терминалу
```

### **8. Systemd службы, перезапуск nginx (easy/hard), поиск службы**

```
systemctl list-units --type=service
systemctl status nginx
```

- **Easy restart**:

```
sudo systemctl reload nginx
```

- **Hard restart**:

```
sudo systemctl restart nginx
```

**Разница**:

- reload — перезагружает конфиг без прерывания соединений (если поддерживается)
- restart — полностью останавливает и запускает службу заново

### **“Стоимость потребления”**

- Ориентируется на **фактическую стоимость ресурсов без учета скидок и промокодов**, то есть позволяет **отслеживать именно расход**, а не то, сколько в итоге списалось с баланса.
- Нужно получать уведомление независимо от скидок или остатка средств.
- Чтобы контролировать, когда **расход по услугам превысит 700 рублей** — именно это делает “Стоимость потребления”.

### **Другие типы — почему не подходят:**

- **“К оплате”** — учитывает скидки и промокоды, может не дать точной картины расходов.
- **“Остаток средств”** — реагирует на баланс счета, а не на конкретный расход за неделю.

В traceroute три столбца со значением в миллисекундах (ms) — это **время отклика (RTT — round-trip time)** до каждого узла (hop), измеренное **тремя отдельными попытками (пакетами)**.

**Default-маршрут (маршрут по умолчанию)** используется, когда:

- **Не найдено более конкретного маршрута** в таблице маршрутизации.
- Для **выхода в интернет** или внешние сети.
- В небольших сетях — для **маршрутизации всего “остального трафика”** (0.0.0.0/0).
- В корпоративных сетях — может указывать на **основной шлюз или NAT-устройство**.

Таким образом, он как “путь по умолчанию”, если IP-адрес назначения не совпадает с каким-либо другим маршрутом.
