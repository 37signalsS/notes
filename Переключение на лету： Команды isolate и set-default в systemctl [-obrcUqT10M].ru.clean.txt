Привет. Это семьдесят девятый день
нашего марафона по LPC 1. Вчера мы
разобрались с теорией целей и узнали,
чем мультиюer Target отличается от
графического режима. Но представь
реальную задачу на работе. Тебе нужно
провести техническое обслуживание
сервера, отключить всех пользователей от
сети, остановить базы данных и перевести
систему в изолированный аварийный режим.
Перезагружать сервер ради этого долго,
да и не всегда возможно. В Systemd ты
можешь менять состояние всей
операционной системы за одну секунду
прямо на лету, вообще без ребута. За 3
минуты мы освоим две важнейшие команды:
Isolate и set default. Разберём хитрую
синтаксическую ловушку экзамена и сдадим
тест. Поехали. Для управления таргетами
на экзамене LP1 проверяют два
принципиально разных действия. Запомни
разницу. Первое действие - это изменение
режима прямо сейчас в оперативной
памяти. За это отвечает встроенная
команда Isolate изолировать. Когда ты
пишешь System CTL Isolate Rescue Target,
система мгновенно гасит все сетевые
службы, выкидывает пользователей и
переходит в аварийный режим. Но стоит
тебе перезагрузить сервер, всё вернётся
на круги своя. Второе действие - это
настройка режима по умолчанию навсегда.
Чтобы сервер при каждой последующей
загрузке включался в нужном тебе
состоянии, используется команда set
default. На экзамене LPI обожают ловить
студентов на путаницы между этими двумя
глаголами. Давайте проверим их синтаксис
вживую. Переходим в наш терминал.
Давайте сделаем так, чтобы наш сервер
железно и навсегда загружался строго в
текстовом многопользовательском режиме.
Пишем от имени суперпользователя suudo
system c set default multiuser target и
нажимаем enter. Посмотрите на экран.
Утилита выдала отчёт. Она удалила старую
символическую ссылку default target и
создала новую, которая указывает на
мультиuser Target. Теперь настройки
зафиксированы на жёстком диске. А если
мне нужно прямо сейчас без перезагрузки
уйти в аварийный режим обслуживания, мы
пишем команду Sudo System CL Isolate
Rescue Target. Запускать её на боевом
сервере по SSH я не буду, иначе связь
мгновенно оборвётся, так как Isolate
принудительно закроет все юниты, кроме
аварийных. Но синтаксис этой команды ты
должен помнить на автопилоте. Типичный
каверзный вопрос на внимательность. Нам
нужно изменить конфигурацию для всех
последующих загрузок. Смотрим на
варианты. Команда Isolate вариант A
изменит режим прямо сейчас, но сбросится
после первого же ребута сервера.
Варианты C и D - это синтаксическая
выдумка экзаминаторов. Таких аргументов
у System CTL нет. За персистентные
изменение дефолтного режима загрузки
отвечает исключительно команда Set
default. Правильный ответ- B. Твоё
домашнее задание на сегодня - зайти в
консоль и вручную прописать команду
проверки или установки дефолтного
таргета, чтобы набить руку на синтаксисе
set default. Подписывайся на канал,
включай уведомления. Завтра
восьмидесятый день марафона. Мы временно
оставим в покое софт и перейдём к
тотальному аудиту железа. Научимся
шпионить за материнской платой и всеми
PCI устройствами сервера с помощью
мощной команды LSPCI.
