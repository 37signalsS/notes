# Kibana

> Эта заметка является частью обзора [ELK стека](../ELK_Stack/elk_stack_overview.md).

Kibana — это компонент визуализации в стеке ELK. Это мощный веб-интерфейс, написанный на JavaScript, который позволяет в реальном времени искать, анализировать и визуализировать данные, хранящиеся в [Elasticsearch](../Elasticsearch/elasticsearch_lecture_summary.md).

## Основные функции

- **Интерактивный поиск**: Kibana предоставляет удобный интерфейс для выполнения запросов к Elasticsearch. Хотя Elasticsearch имеет REST API и к нему можно обращаться напрямую (например, через `curl`), Kibana делает этот процесс значительно удобнее.
- **Визуализация**: Позволяет создавать разнообразные графики, диаграммы, таблицы и карты для представления данных. Можно строить гистограммы, круговые диаграммы, геотеги на карте и многое другое.
- **Дашборды**: Визуализации можно объединять в интерактивные дашборды, которые предоставляют комплексное представление о состоянии системы или данных.
- **DevTools (Консоль разработчика)**: В Kibana встроена консоль, которая позволяет отправлять любые REST-запросы напрямую в Elasticsearch. Это мощный инструмент для отладки и администрирования.

## Настройка и конфигурация

- **Подключение к Elasticsearch**: В конфигурации Kibana можно указать несколько эндпоинтов Elasticsearch для отказоустойчивости. Обычно это адреса мастер-узлов кластера.
- **Безопасность**:
    - Если кластер Elasticsearch защищен авторизацией, соответствующие креды необходимо указать в настройках Kibana.
    - **Отключение консоли**: Консоль разработчика (`DevTools`) по умолчанию включена. Поскольку она позволяет выполнять любые запросы, включая удаление данных (`DELETE`), в продуктивной среде для обычных пользователей ее рекомендуется отключать через параметр `console.enabled: false` в `kibana.yml`.

## Сравнение с Grafana

- **Kibana**: Тесно интегрирована с Elasticsearch, предоставляет мощные возможности именно для поиска и анализа текстовых данных и логов.
- **[Grafana](../Grafana/grafana_overview.md)**: Более универсальный инструмент, который отлично работает с временными рядами (time-series) из различных источников данных (Prometheus, Zabbix, InfluxDB, и т.д.), но также может работать и с логами (например, из Loki или Elasticsearch).

Часто дашборды в Kibana выглядят очень насыщенными и функциональными, в то время как Grafana больше ориентирована на лаконичное и чистое представление метрик. Выбор между ними часто зависит от основного сценария использования: глубокий анализ логов (Kibana) или мониторинг метрик (Grafana).
