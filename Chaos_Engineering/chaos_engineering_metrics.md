# Метрики в Chaos Engineering

## 1. Определения

**Метрики в Chaos Engineering** — это количественные показатели, используемые для проверки гипотезы об устойчивости системы. Основная задача — объективно сравнить состояние сервиса до, во время и после проведения эксперимента, чтобы подтвердить, что показатели качества (SLI) остались в пределах целевых уровней (SLO).

## 2. Основные концепции

### Ключевые категории метрик

| Категория | Примеры | Что показывает |
|---|---|---|
| **Пользовательские** | Задержки (p95/p99), доля ошибок | Опыт взаимодействия с сервисом. |
| **Системные** | Утилизация CPU/Memory, глубина очереди | Здоровье и насыщение ресурсов. |
| **Бизнесовые** | Конверсия, успешные платежи | Влияние на бизнес-процессы. |

### Дизайн сравнения

* **Baseline:** Зафиксируйте базовый уровень метрик в сопоставимом по нагрузке окне времени до эксперимента.
* **Окна сравнения:** Сравнивайте одинаковые временные интервалы.
* **Когорты:** Если возможно, разделяйте трафик на контрольную и экспериментальную группы для параллельного сравнения.
* **SLO Budget:** Эксперимент должен учитывать доступный бюджет ошибок. Выход за пределы SLO во время эксперимента — признак того, что система не готова к данному виду отказа.

## 3. Практические сценарии

### Примеры вычислений в PromQL

**1. Сравнение p95 задержки с baseline:**

```promql
# Текущий p95
p95_now = histogram_quantile(0.95, sum by (le) (rate(http_request_duration_seconds_bucket{job="api"}[5m])))

# p95 30 минут назад
p95_before = histogram_quantile(0.95, sum by (le) (rate(http_request_duration_seconds_bucket{job="api"}[5m] offset 30m)))

# Дельта в процентах
delta_p95_pct = (p95_now - p95_before) / p95_before * 100
```

**2. Сравнение когорт (control vs experiment):**

```promql
# p99 для экспериментальной группы
p99_treated = histogram_quantile(0.99, sum by (le) (rate(http_request_duration_seconds_bucket{variant="experiment"}[5m])))

# p99 для контрольной группы
p99_control = histogram_quantile(0.99, sum by (le) (rate(http_request_duration_seconds_bucket{variant="control"}[5m])))
```

## 4. Дополнительная информация

### Интерпретация и типичные ловушки

* **"Хвосты" важнее среднего:** Рост p99 даже при стабильном среднем значении (avg) указывает на проблемы у части пользователей.
* **Скрытые ретраи:** Повторные попытки могут маскировать ошибки, но увеличивают нагрузку и задержки.
* **Сезонность:** Сравнивайте периоды с одинаковой интенсивностью трафика.
