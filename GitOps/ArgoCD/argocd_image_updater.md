# Argo CD Image Updater: Автоматизация обновления образов

**Argo CD Image Updater** — это вспомогательная утилита для Argo CD, которая отслеживает изменения в реестрах контейнеров (Container Registries) и автоматически обновляет теги образов в приложениях Argo CD. Это позволяет реализовать полностью автоматический цикл CD, где обновление версии в реестре инициирует деплой в кластер без ручного изменения Git-репозитория.

## Определения

- **Image Updater**: Контроллер, работающий в кластере и опрашивающий реестры образов на наличие новых тегов.
- **Write-back Method**: Способ фиксации изменений тега.
    - **Imperative (API)**: Обновление параметров приложения через API Argo CD (не сохраняется в Git).
    - **Declarative (Git)**: Запись нового тега обратно в Git-репозиторий.
- **Update Strategy**: Алгоритм выбора нового тега (semver, latest, name).

## Базовые концепции

### Принцип работы
1. Контроллер сканирует приложения Argo CD, имеющие специфические аннотации.
2. Для каждого образа опрашивается реестр (Docker Hub, Harbor, GitLab Registry и др.).
3. Если найден новый тег, соответствующий стратегии (например, `semver:~v0.1`), Updater инициирует обновление.
4. В зависимости от настроек, Updater либо вызывает API Argo CD, либо создает коммит в Git.

### Ограничения
- Приложение должно быть создано и управляться через Argo CD.
- Поддерживаются только инструменты **Helm** и **Kustomize**.
- Для Helm параметр тега образа должен быть вынесен в переменные (например, `image.tag`).

## Практические сценарии

### 1. Настройка отслеживания образа
Добавьте аннотации к объекту `Application`:

```yaml
metadata:
  annotations:
    # Список образов для отслеживания (псевдоним:фильтр)
    argocd-image-updater.argoproj.io/image-list: frontend:registry.gitlab.com/org/app/frontend:~v0.4
    # Стратегия выбора (semver по умолчанию)
    argocd-image-updater.argoproj.io/frontend.update-strategy: semver
    # Метод записи изменений (git или api)
    argocd-image-updater.argoproj.io/write-back-method: git
```

### 2. Метод записи Git (Write-back)
При использовании метода `git`, Updater создает в репозитории специальный файл `.argocd-source-<appName>.yaml`. 
- **Преимущество**: В отличие от Flux CD, Updater не правит основные файлы `values.yaml` или манифесты напрямую. Это минимизирует риск конфликтов слияния (merge conflicts) при ручных правках.
- **Прозрачность**: Изменение четко локализовано в отдельном файле, который Argo CD подхватывает автоматически.

### 3. Настройка прав доступа
Updater использует те же учетные данные для Git, что и Argo CD. Для реестров образов можно настроить секреты (Pull Secrets) или использовать анонимный доступ для публичных образов.

## Дополнительная информация

### Сравнение с Flux CD Image Automation
| Характеристика | Argo CD Image Updater | Flux Image Automation |
| :--- | :--- | :--- |
| **Интеграция** | Внешний аддон (labs) | Встроенные контроллеры |
| **Метод записи** | Отдельный файл или API | Прямая правка YAML-кода |
| **Гибкость** | Привязка к `Application` | Глобальные политики (`ImagePolicy`) |
| **Конфликты** | Низкий риск (свой файл) | Риск конфликтов в `values.yaml` |
