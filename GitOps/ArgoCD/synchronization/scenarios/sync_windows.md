# ArgoCD — окна синхронизации

## Определения

**Sync Windows** — механизм ограничения автоматической или ручной синхронизации на основе временного расписания. Настройки окон задаются на уровне `AppProject`.

## Базовые концепции

Окна синхронизации позволяют контролировать, когда изменения могут быть внесены в кластер. Это критично для поддержания стабильности в периоды высокой нагрузки или при необходимости соблюдения регламентов (например, запрет деплоев по пятницам).

### Когда использовать

- **Запрет деплоев (Deny):** в нерабочее время, выходные или периоды "заморозки" кода (code freeze).
- **Разрешение деплоев (Allow):** ограничение обслуживания приложений строго в определенные технологические окна.

### Параметры конфигурации

| Параметр | Описание |
| :--- | :--- |
| **kind** | `allow` (разрешить) или `deny` (запретить). |
| **schedule** | Расписание в формате Cron. |
| **duration** | Длительность действия окна (например, `1h`, `168h`). |
| **timeZone** | Часовой пояс (например, `Europe/Moscow`). |
| **applications** | Список имен приложений или шаблоны (wildcards). |
| **manualSync** | Флаг, разрешающий ручную синхронизацию даже при активном окне `deny`. |

## Практические сценарии

### Пример конфигурации в AppProject

```yaml
apiVersion: argoproj.io/v1alpha1
kind: AppProject
metadata:
  name: production-apps
  namespace: argocd
spec:
  syncWindows:
  # Пример: Разрешить деплой только в будни с 9:00 до 18:00 по московскому времени (MSK)
  - kind: allow
    schedule: '0 9-18 * * 1-5'
    duration: 1h
    timeZone: "Europe/Moscow"
    applications:
    - '*-prod'
    manualSync: true  # Разрешить ручную синхронизацию в любое время
  
  # Пример: Запретить любые изменения на неделю (например, праздники)
  - kind: deny
    schedule: '0 0 25 12 *'
    duration: 168h
    timeZone: "Europe/Moscow"
    applications:
    - '*'
```

### Команды CLI

Просмотр текущего состояния окон в проекте:

```bash
argocd proj get production-apps
```
